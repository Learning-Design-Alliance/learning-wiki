# Small-Group Instruction

> **Element** · [All elements](index.md)

## Description
Small-group instruction is the element in which learners work with an instructor or facilitator in a reduced-size group for targeted teaching, discussion, or support. It is useful when instruction benefits from more responsiveness than whole-class delivery allows.

## Design Implications

### Context
#### Requirements
- **A reason for grouping learners together**
- **Instruction or support tailored to the small group**
#### Constraints
- **Grouping without differentiated purpose can waste time**

### Target Learning Goals
- Support targeted instruction, discussion, and responsive feedback.
