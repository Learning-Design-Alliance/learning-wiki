# Performance-Based Assessment

## Description
Performance-based assessment is the element in which learners demonstrate knowledge or skill by performing, producing, or solving something observable rather than only selecting answers. It is useful when the learning target involves application, integration, or authentic performance.

## Design Implications

### Context
#### Requirements
- **A task that reveals the target competence**
- **Clear performance criteria or rubric**
- **Observation or artifact review**
#### Constraints
- **Scoring can be labor-intensive**
- **Poor rubric design can reduce reliability**

### Target Learning Goals
- Assess applied competence, transfer, and integrated performance.
