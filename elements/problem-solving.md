# Problem Solving

## Description
Problem solving is the element in which learners identify, analyze, and respond to a challenge by generating and evaluating possible solutions. It is useful when the instructional goal is not only recall, but reasoned action in the face of constraints.

## Design Implications

### Context
#### Requirements
- **A meaningful problem or challenge**
- **A process for evaluating possible solutions**
#### Constraints
- **Ill-structured problems may require stronger scaffolding for novices**

### Target Learning Goals
- Develop analytical reasoning, strategy use, and solution generation.
