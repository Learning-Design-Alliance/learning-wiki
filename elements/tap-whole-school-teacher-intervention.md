# Teacher Advancement Program (TAP) whole-school intervention

## Description
TAP is a whole-school intervention that aims to improve schools by raising teacher quality. It provides teachers with "opportunities for professional growth, promotion to school leadership roles without leaving the classroom, structured feedback, and performance-based compensation." Chicago Public Schools began implementing TAP in 2007, and this report evaluates its first-year impacts in the district's K-8 schools.
