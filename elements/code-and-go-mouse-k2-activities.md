# Code and Go Mouse robot activities combining mapping, story ordering, and number-line arithmetic

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The webinar describes Code and Go Mouse activities in which students build a Noun Town map for the mouse to travel through, reinforcing map skills, or recreate a story by drawing portions and coding the mouse around the map to order it. A number-line variation has students roll two dice, add or subtract, and move a toy car along a road.
