# Edmentum Exact Path: computer-adaptive supplemental program supporting instruction and assignment

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 1 claim rests on one study

## Description
Exact Path Growth is described as "a computer-adaptive supplemental program" that supports instruction within TSI sessions. The related Exact Path Insights diagnostic serves as the assignment mechanism: in the study, students were assigned to tutoring based on fall diagnostic scores at or below the 25th percentile. It thus functions both as an instructional support and as a screening tool for targeting struggling learners.
