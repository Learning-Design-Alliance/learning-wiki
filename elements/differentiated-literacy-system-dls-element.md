# Differentiated Literacy System (DLS): assessment-driven grouping tool plus instructional coaching for K-3 teachers

> **Element** · [All elements](index.md)
> **Evidence** · 5 claims (5 mixed) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
DLS is a tool and instructional coaching program designed to help K-3 teachers meet individual students' literacy needs. The article describes that DLS helps teachers meet individual students' needs, "using assessment data to group students and recommend the number of minutes by instruction type (decoding and comprehension, either independently or with the teacher) for each student group." Participating schools receive access to the tool and coaching from DLS coaches, who hold monthly meetings helping grade-level teams use the tool, interpret DLS data, implement small group instruction, and change instructional activities.
