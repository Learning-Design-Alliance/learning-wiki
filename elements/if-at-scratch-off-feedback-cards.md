# IF-AT scratch-off lottery response cards for immediate team feedback in tRAT sessions

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
Immediate Feedback Assessment Technique (IF-AT) forms are scratch-off, lottery-style cards used during the tRAT so teams "receive immediate feedback on the submitted responses." The correct answer is marked by a star beneath removable silver material; incorrect choices prompt teams to try again. This reduced the need for faculty proctors and created a fun, game-like atmosphere, with students audibly reacting as they scratched off answers.

## Design Implications

### Context
#### Requirements
- Faculty must scramble response items to match the pre-determined key on the ordered card version
#### Constraints
- Several card versions exist with different pre-determined keys, requiring item reordering before distribution

### Target Learners
- first-year D.M.D. professional students

### Target Learning Goals
- physiology content mastery
- team-based problem solving
