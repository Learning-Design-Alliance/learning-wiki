# Semantic network: content words connected by lines as the starting point of the production model

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The semantic network is the first of Labov's five segments of linguistic description. In the production model it "starts with a semantic network which is a connection of content words connected by lines," with two kinds of lines described so far, including object relations. Co-reference problems are handled by drawing more than one line from the appropriate noun rather than by grammatical machinery.

## Design Implications

### Context
#### Requirements
- Content words connected by lines, with relation types such as object relations, to represent an utterance's content
#### Constraints
- So far Labov only talks about two kinds of lines; co-reference is sidestepped rather than formally resolved
