# Iterative Learning

> **Element** · [All elements](index.md)

## Description
Iterative learning is the element in which learners improve through repeated cycles of attempt, feedback, revision, and retry. It is useful when quality emerges through refinement rather than one-shot performance.

## Design Implications

### Context
#### Requirements
- **A task that benefits from revision**
- **Feedback between attempts**
- **Time for another cycle**
#### Constraints
- **Repeated attempts without feedback produce limited improvement**

### Target Learning Goals
- Improve quality through revision and refinement.
