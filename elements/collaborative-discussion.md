# Collaborative Discussion

## Description
Collaborative discussion is the element in which learners build understanding together through shared talk, comparison of ideas, and negotiated meaning. It is useful when the task requires collective reasoning rather than isolated response.

## Design Implications

### Context
#### Requirements
- **A shared question, problem, or text**
- **Norms for equitable participation**
- **Prompts that encourage building on others' ideas**
#### Constraints
- **Can drift into unequal participation or shallow talk**

### Target Learning Goals
- Support co-construction, perspective comparison, and shared synthesis.

### Affordances
- [Social Constructivism](../theories/sociocultural-theory.md)
