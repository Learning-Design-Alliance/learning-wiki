# Classtime digital formative assessment platform

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Classtime is a web-based digital formative assessment platform supporting mathematics, English Language Arts, and science instruction through interactive practice and real-time feedback. Teachers assign problem sets aligned with state standards and use dashboards that display student responses instantly, allowing them to identify misconceptions and adjust instruction during or after lessons. It runs in any modern web browser on any device, requires reliable internet connectivity, and supports two-way synchronization and SSO with tools like Google Classroom and Clever.

## Design Implications

### Context
#### Requirements
- Computers or tablets for students and teachers
- Reliable internet connectivity
- Any modern web browser (e.g., Chrome, Safari, Firefox, Edge)
#### Constraints
- The evaluated outcome evidence is a single quasi-experimental study in mathematics, grades 3–6, in one large urban California district, qualifying only for a Promising rating

### Target Learners
- Students in grades 3–6
- Elementary and middle-grades mathematics, ELA, and science students

### Target Learning Goals
- Mathematics achievement
- Strategic thinking in math, science, and ELA
- Familiarity with state assessment question formats
