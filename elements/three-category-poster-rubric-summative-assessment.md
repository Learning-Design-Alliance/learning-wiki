# Three-category rubric for summative assessment of inquiry poster presentations

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
A rubric used to score individual poster presentations as a summative assessment of student learning in the inquiry. Facilitators graded three categories: describing the encoding process, describing the image file, and practicing good communication skills, awarding 1 point per cell to allow for uneven mastery across rows. The design team was "one of the ﬁrst PDP design teams to pilot use of a rubric for inquiry."

## Design Implications

### Context
#### Requirements
- Students present individually to a facilitator; rubric rows advance from did-not-meet to exceeded expectations, with mastery expected to progress left to right along a row.
#### Constraints
- One point per cell was awarded to allow for a student achieving mastery in one row yet missing more basic items in another.

### Target Learners
- undergraduate engineering technology students presenting inquiry posters

### Target Learning Goals
- describing image encoding choices
- explaining image file formats
- communication skills
