# SEERNet shared digital learning platform infrastructure enabling a performer community model

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 3 studies (2 design, 1 qualitative), `q1`–`q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
SEERNet is a research infrastructure initiative that stimulates researchers to work with data available in digital learning platforms while incentivizing developers to improve their research infrastructure. The paper reports it enables a performer community model in which many researchers work in coordinated cycles, use real-world usage data, and contribute to a cumulative evidence base, democratizing access by lowering technical and logistical barriers.

## Design Implications

### Context
#### Requirements
- The model depends on platform instrumentation, shared telemetry, and a network among participants that builds understanding of shared challenges.
#### Constraints
- The paper notes open issues around cross-platform interoperability and balancing openness with privacy.

### Target Learners
- Education researchers and digital learning platform developers

### Target Learning Goals
- Enabling larger-scale, faster, more replicable inquiry using learning process data from online environments
