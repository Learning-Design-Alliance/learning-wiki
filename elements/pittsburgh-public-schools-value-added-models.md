## Description
A set of value-added models created for the Pittsburgh Public Schools and the Pittsburgh Federation of Teachers. The report states that "Pittsburgh's VAMs use not only state assessments but also course-specific assessments, student attendance, and course completion rates", broadening the outcome measures beyond state test scores alone. The models are intended to produce estimates of the contributions of teachers and schools.
