# Assess performance

> **Element** · [All elements](index.md)

## Description
Assessing performance is the instructional event in which learners demonstrate what they can do and the instructor or system evaluates that demonstration against criteria. It functions both as a measurement of mastery and as a learning event in its own right — the act of retrieving and producing performance strengthens memory and reveals gaps that instruction has not closed.

## Design Implications

Performance assessment is most effective when criteria are transparent and feedback follows quickly, so learners can connect evaluation to the specific actions that produced it [Feedback that specifies the gap between current and desired performance improves achievement.](../principles/assessment-for-learning.md) [+S]. Assessments that require learners to *generate* performance — solving, writing, producing — produce stronger retention than recognition-based formats, because retrieval practice strengthens memory more than re-exposure [Testing produces stronger retention than restudying.](../principles/active-learning.md) [+S]. Rubrics and criterion-referenced scoring make judgments interpretable and support learner self-assessment.

### Context
#### Requirements
- Tasks that align with the stated objectives — the assessment must sample the actual performance, not a proxy for it
- Explicit criteria or [Rubrics](rubrics.md) shared with learners before the assessment
- A feedback loop: results must reach learners in actionable form ([Formative Assessment](formative-assessment.md)) or the measurement value is lost
- Sufficient task fidelity that success on the assessment predicts success in the target context

#### Constraints
- High-stakes summative use without prior formative opportunities produces anxiety and shallow strategies rather than learning [~M]
- Assessments of isolated knowledge fragments fail to predict integrated performance; whole-task assessment is needed for transfer [Whole-task performance improves transfer.](../claims/whole-task-performance-improves-transfer.md) [+M]
- Over-reliance on outcome measures (scores, completion) rather than process measures can undermine motivation for novices, who benefit more from process-oriented goals [Process goals outperform outcome goals for novices.](../claims/process-goals-outperform-outcome-goals-for-novices.md) [+M]
- Poorly aligned assessment drives teaching toward the test rather than toward the objective (construct-irrelevant washback) [-M]

### Target Learners
- Learners in structured programs with defined mastery standards — certification, licensure, competency-based courses
- Novices benefit when assessment emphasizes process and progress rather than rank ordering [Process goals outperform outcome goals for novices.](../claims/process-goals-outperform-outcome-goals-for-novices.md) [+M]
- Self-regulating learners gain additional benefit when assessment includes self-monitoring components [Self-monitoring improves self-regulation.](../claims/self-monitoring-improves-self-regulation.md) [+M]

### Target Learning Goals
- Skill acquisition: verifying that procedures can be executed to standard
- Conceptual understanding: diagnosing whether explanations reveal underlying mental models
- Mastery decisions: determining readiness to advance ([Competency-Based Assessment](../principles/competency-based-assessment.md))

### Affordances
- [Assessment for Learning](../principles/assessment-for-learning.md) — performance assessment enacts this principle when results are used to adapt subsequent instruction rather than only to certify; the same task serves diagnosis and accountability
- [Competency-Based Assessment](../principles/competency-based-assessment.md) — criterion-referenced performance assessment is the mechanism by which advancement is tied to demonstrated mastery rather than time on task
- [Active Learning](../principles/active-learning.md) — requiring a performance forces retrieval and production, which strengthen memory more than recognition or review
- [Scaffolding](../principles/scaffolding.md) — assessment results determine where scaffolds should be added or faded

## Examples
**[Khan Academy](https://www.khanacademy.org)** — Mastery-based exercise system where learners must demonstrate consistent performance across skill checks before a skill is marked "mastered"; assessment is continuous and criterion-referenced.

**[Duolingo](https://www.duolingo.com)** — Checkpoint assessments and adaptive review that re-test previously learned items, using performance data to schedule spaced practice.

**[Western Governors University](https://www.wgu.edu)** — Fully competency-based degree programs in which students advance by passing performance assessments and objective exams whenever they can demonstrate mastery.

**[Codecademy](https://www.codecademy.com)** — Project-based assessments in which learners build working artifacts evaluated against checklists, assessing integrated skill rather than isolated syntax.
