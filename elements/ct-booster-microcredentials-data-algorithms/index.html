Micro-credential stack pairing data analysis with algorithm creation¶

Element · All elements Evidence · no claims cited

Description¶

The deck lists micro-credentials teachers can pursue alongside the boosters: under Data and Analysis, "Analyzing and Communicating with Data" and "Collecting and Structuring Data"; under Algorithms, "Creating Algorithms." These credential offerings frame the professional-learning pathway around the same data-and-analysis content.
