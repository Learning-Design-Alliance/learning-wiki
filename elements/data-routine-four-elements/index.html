The Data Routine: a four-element structure for student engagement with data in science investigations¶

Element · All elements Evidence · 2 claims (2 for) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The Data Routine (Penuel et al., 2023) "identifies four elements that help teachers structure their students' engagement with data in a science investigation": Framing Questions, Orienting to the Data, Exploring the Data, and Sensemaking about the Data. Each element describes ways for students to reason with data mathematically, and example prompts map onto GC and CoV trajectory levels. In this study it served as a lens for teachers to explore teacher guides and inform lesson adaptation, and as a coding framework for classroom observations.

Design Implications¶

Context¶

Requirements¶

  • Teacher facilitation across all four elements for full enactment; the report observed all four elements in only 24% of lessons

Constraints¶

  • Sensemaking about the Data was least commonly enacted, often due to limited instructional time after procedurally complex investigations

Target Learners¶

  • middle school science students

Target Learning Goals¶

  • graph comprehension
  • covariational reasoning
  • scientific sensemaking

Affordances¶

Claims¶

  • Teachers varied in Data Routine enactment, with Sensemaking about the Data least common, and sensemaking activities were strongly associated with open-ended questioning [+W]
  • Teachers addressed graph comprehension consistently at high levels across observed lessons, while covariational reasoning enactment varied widely by lesson [+W]
