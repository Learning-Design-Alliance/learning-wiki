# Summative Assessment

## Description
Summative assessment is the element in which a learner's performance is judged at the end of a unit, course, or other instructional sequence. It is useful when the task is to make a cumulative judgment rather than guide the next immediate revision.

## Design Implications

### Context
#### Requirements
- **A clear end-point performance target**
- **Evidence that samples the intended learning**
- **Criteria for judgment**
#### Constraints
- **High stakes can narrow performance**
- **End-point assessments do not replace formative support during learning**

### Target Learning Goals
- Judge cumulative achievement or demonstrated competence.
