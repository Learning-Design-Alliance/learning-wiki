# Reading Plus web-based literacy program for grades 3-12+

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Reading Plus is a web-based literacy program for grades 3-12+ designed to strengthen reading comprehension, vocabulary, efficiency, and motivation. It "combines personalized practice and adaptive instruction, and offers students choice and control over their program experience." The program includes a valid and reliable assessment and is designed to develop critical reading skills for deep, meaningful understanding of complex texts. It was evaluated in a randomized study that qualified it for a Strong evidence rating.
