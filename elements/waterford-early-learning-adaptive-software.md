# Waterford Early Learning (WEL) adaptive software

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The core instructional component of Waterford Upstart is the Waterford Early Learning (WEL) software, which "sequences adaptive lessons, digital books, songs, and practice activities based on each child's progress." The software "adjusts the level of support and difficulty as children demonstrate new skills," personalizing the daily lesson flow across reading, math, and science content.
