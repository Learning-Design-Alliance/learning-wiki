The Framework for Teaching observation rubric with 22 components in four domains¶

Element · All elements Evidence · 4 claims (1 for, 3 mixed) · 2 studies (2 associational), q2 · 0 of 2 report an effect size · 4 claims rest on one study

Description¶

The Framework for Teaching is a classroom-observation rubric used by principals to evaluate teaching practices. The report describes it as "a rubric that includes 22 components grouped into four broad teaching practice domains": planning and preparation, classroom environment, instruction, and professional responsibilities. It served as the observation instrument in Phase 2 of the Pennsylvania evaluation pilot.

Design Implications¶

Context¶

Requirements¶

  • Principals must be trained to apply the rubric's components when observing teaching practice

Constraints¶

  • Principals did not typically use all 22 components in their observations

Target Learners¶

  • K-12 teachers evaluated by school principals

Target Learning Goals¶

  • Improving teaching practice as measured against professional standards

Claims¶

  • Teachers with higher Framework for Teaching scores tended to make larger contributions to student achievement (value added) [+W]
  • Principals in the pilot did not typically use all 22 rubric components when observing teachers [~W]
  • Variation across schools in principal-assigned professional practice ratings suggests principals' standards may not be fully consistent across schools [~W]
  • Fairness of overall observation scores may not be substantially compromised by principals using different sets of rubric components [~W]

Related Elements¶

  • Framework for Teaching (FFT) observation instrument with 22 components scored into four domains and an overall Professional Practice Rating
  • Pennsylvania Teacher and Principal Evaluation Pilot (2010-2015), Phase 2 classroom-observation study
  • Charlotte Danielson Framework for Teaching as a classroom-observation evaluation tool

Examples¶

  • Use multiple classroom observations with rubric-based ratings and evidence as the evaluation component teachers perceive as fair
