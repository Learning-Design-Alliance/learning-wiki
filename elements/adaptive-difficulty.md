# Adaptive Difficulty

## Description
Adaptive difficulty adjusts task challenge in response to learner performance so work remains demanding enough to promote growth without becoming discouraging or trivial.

## Design Implications

### Context
#### Requirements
- A way to detect current performance or readiness
- Rules or instructor judgment for increasing, decreasing, or stabilizing challenge
- Feedback that helps learners understand why the task changed

#### Constraints
- Poor calibration can frustrate learners or create false ease
- Opaque adaptation can make the system feel arbitrary or unfair
- Difficulty should change the learning challenge, not only the speed or quantity of work

### Target Learners
- Learners with wide variation in prior knowledge
- Learners practicing skills that benefit from repeated attempts
- Learners in digital environments where task sequencing can update quickly

### Target Learning Goals
- Sustaining productive challenge
- Preventing boredom from under-challenging tasks
- Reducing disengagement from overwhelming tasks

### Affordances
- Keeps learners closer to a productive difficulty range
- Supports persistence by making progress visible
- Can help systems respond to readiness without forcing a uniform pace
