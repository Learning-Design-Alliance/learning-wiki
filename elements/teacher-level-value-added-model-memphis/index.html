Teacher-level value-added model adaptation for identifying high-performing teachers in Memphis¶

Element · All elements Evidence · no claims cited

Description¶

This element is a teacher-level value-added application described on the publication page. Mathematica Policy Research states it "has adapted its school-level value-added model to teacher-level data" for a partner. The purpose is to "help New Leaders for New Schools identify high-performing teachers in award-winning schools within Memphis City Schools." The page provides no technical detail, data description, or results beyond this project summary.
