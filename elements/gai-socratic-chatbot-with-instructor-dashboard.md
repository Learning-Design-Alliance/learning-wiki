# Web-based GAI chatbot with instructor-facing learning analytics dashboard

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (1 for, 3 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The third-cycle tool is a standalone, login-based web application powered by OpenAI's Assistants API (GPT-4o-mini) with a file search tool for course-specific content. Instructors design learning activities that are converted into structured prompts constraining the LLM to function as a Socratic tutor, and can specify communicative tone, teaching style, level of answer disclosure, and supporting documents. It includes a built-in LA dashboard with four tabs—Conversation Stats, Student Stats, Engagement, and Raw Data—showing message counts, average message length, conversation duration, GPT-4o-Mini message summaries, word clouds, and customizable scatterplots of lexical diversity and vocabulary size, plus verbatim transcripts.
