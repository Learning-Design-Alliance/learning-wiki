# JUMP Math program

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 1 claim rests on one study

## Description
JUMP Math is a highly-scaffolded, direct instruction approach covering all strands of K to 8 math, including computation and problem-solving. It is described as "guided discovery", with teachers implementing lessons from "detailed, explicit teachers guides". All students in a class work on the same concepts while progressing at their own pace, and there are no student textbooks; students work in practice and assessment guides.
