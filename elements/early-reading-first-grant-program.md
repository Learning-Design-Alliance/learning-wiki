# Early Reading First grant program for preschool language and literacy

## Description
Early Reading First was a federal grant program for preschools, evaluated in a national report to Congress. Grants were "designed to enhance teacher practices, instructional content, and classroom environments in preschools" so that young children, especially those from low-income families, begin school with the skills needed for academic success.
