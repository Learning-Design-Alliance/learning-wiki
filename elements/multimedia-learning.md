# Multimedia Learning

## Description
Multimedia learning is the element in which learners engage with coordinated combinations of words, visuals, audio, animation, or interactive media. It is useful when multiple representations clarify structure, process, or relationship more effectively than a single mode alone.

## Design Implications

### Context
#### Requirements
- **Media chosen for instructional value rather than decoration**
- **Alignment between modes so they reinforce rather than compete**
#### Constraints
- **Excessive or poorly integrated media can increase cognitive load**

### Target Learning Goals
- Improve comprehension and access through coordinated multimodal representation.
