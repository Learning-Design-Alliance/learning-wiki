# Gradual Release

## Description
Gradual release is the element in which responsibility for performance shifts from teacher or system to learner across stages of modeling, guided practice, and independent work. It is useful when learners need structured support that is intentionally reduced.

## Design Implications

### Context
#### Requirements
- **A sequence from strong support toward learner independence**
- **Checks that indicate when responsibility can shift**
#### Constraints
- **The release can fail if support is removed too early or never reduced**

### Target Learning Goals
- Support the transfer of responsibility from guided performance to independent competence.
