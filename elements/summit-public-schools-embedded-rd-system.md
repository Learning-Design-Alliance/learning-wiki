# Summit Public Schools' embedded R&D system: internal R&D team, mentoring program, self-directed learning curriculum, and progress-tracking platform

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
Summit Public Schools, a charter network in California and Washington, embeds R&D in its educational model using continuous improvement principles. The report states: "The charter network built an internal R&D team to study student persistence and cognitive development. Drawing on teacher and student feedback, they developed a mentoring program and self-directed learning platform, which were piloted, adapted, and eventually scaled across their network." System-wide outputs include a technology platform tracking student progress with real-time data for educators, a multi-year alumni study informing advising changes, and a community-designed post-secondary pathways program.

## Design Implications

### Context
#### Requirements
- A dedicated internal R&D team that partners with teachers, leaders, and external researchers
#### Constraints
- The report notes stakeholder involvement is "not always full co-design"

### Target Learners
- Secondary students in a charter network preparing for four-year colleges

### Target Learning Goals
- Student persistence, cognitive skill development, personalized student-centered learning, and college readiness
