# Mathematical Imagery Trainer for Proportion (MIT-P): an embodied-interaction environment where the screen turns green only when cursor heights relate by a target ratio

> **Element** · [All elements](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The MIT-P is a design solution to students' enduring challenges with proportional relations: a student sits before a large red screen and is asked to 'make the screen green', which occurs only when the cursors' heights relate by the correct ratio (e.g., 1:2). The activity advances through stages, each launched when the instructor introduces a new display overlay — cursors, a grid, numerals along the y-axis — after the student satisfies a protocol criterion, with a full design including a ratio table for indirect control. An iPad version was released at the printed URL.

## Design Implications

### Context
#### Requirements
- A facilitator who incrementally overlays display elements after protocol criteria are met, and tasks sequenced from making green to maintaining green while moving
#### Constraints

### Target Learners
