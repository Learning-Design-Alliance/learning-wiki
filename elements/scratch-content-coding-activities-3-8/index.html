Scratch coding activities expressing content as interactive illustrations, games, or stories¶

Element · All elements Evidence · no claims cited

Description¶

The deck proposes Scratch as a block-based coding environment for content-area algorithm lessons, stating "Students will use Scratch to code: Rock Cycle, Animal Ecosystems, Story retellings or new endings". It notes that "Content can be expressed through an interactive illustration, game or story", and references a YouTube video tutorial. The activities let students represent science and literacy content through programmed artifacts.
