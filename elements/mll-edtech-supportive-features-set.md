# MLL-supportive technology features identified across research and design practice

> **Element** · [All elements](index.md)
> **Evidence** · 5 claims (5 mixed) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The report catalogs the technological features that reviewed studies and interviewed designers embed to support multilingual learners, spanning multiple modes of engagement, emerging technologies, and pedagogy-specific features. As the review states, features "included dual coding (visual and auditory congruence), word prediction software, sound features, animated pictures, text-to-speech capability, voice recognition, and virtual tutors." Interviewees additionally discussed pause points, voice-over, leveling, multimodal expression, language translation, reduced text, localization, and in-the-moment player support. The element serves as an inventory of candidate design features for future MLL-centered edtech.

## Design Implications

### Context
#### Requirements
- Features must be embedded in technologies designed to promote target disciplinary content for young multilingual learners ages 3-8
#### Constraints
- Only 28% of reviewed articles included systematic evaluations of such features, so evidence of effectiveness is limited

### Target Learners
- Young multilingual learners ages 3-8 in preschool through third grade

### Target Learning Goals
- Literacy and language development
- Subject-area learning including science and mathematics
