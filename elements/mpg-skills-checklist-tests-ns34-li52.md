# MAP for Primary Grades Skills Checklist tests (NS34 and LI52) as the empirical data source

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The study uses two computerized linear Skills Checklist tests from NWEA's Measures of Academic Progress for Primary Grades: the 34-item Number Sense (NS34) mathematics test and the 52-item Letter Identification (LI52) reading test, drawn from 27 mathematics and 13 reading Skill Checklists. The MPG is designed "to provide information about specific skills and concepts" and "can be used prior to instruction to help teachers determine which skills need the most instructional focus." Samples came from 2009 administrations across 50 states (including Washington DC), about 1454 students per test matched from a 66712-student pool.

## Design Implications

### Context
#### Requirements
- Administered by computer so item-level response times are recorded
#### Constraints
- Only one math and one reading Skills Checklist test were used; all MPG tests are computerized linear tests

### Target Learners
- Primary grades K-12 students

### Target Learning Goals
- Diagnosing specific skills and concepts in reading and mathematics to guide instructional focus
