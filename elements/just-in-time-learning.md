# Just-in-Time Learning

## Description
Just-in-time learning is the element in which information, guidance, or resources are provided at the moment they are needed for the task at hand rather than front-loaded in advance. It is useful when the task context can make support more relevant, memorable, and easier to apply.

## Design Implications

### Context
#### Requirements
- **A task that creates a real information need**
- **Fast access to targeted support**
- **Support timed to the decision or step where it matters**
#### Constraints
- **Too-late support still fails**
- **Fragmented access can interrupt flow if retrieval is cumbersome**

### Target Learners
- Learners working on applied tasks who need timely guidance without excessive front-loading.

### Target Learning Goals
- Improve transfer and reduce unnecessary upfront cognitive load.

- A teacher provides a mini-lesson after a misconception appears during application.
