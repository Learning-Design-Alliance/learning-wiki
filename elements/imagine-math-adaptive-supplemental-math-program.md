# Imagine Math: adaptive digital supplemental mathematics program with on-demand live certified teacher support

> **Element** · [All elements](index.md)

## Description
Imagine Math by Imagine Learning is "a digital supplemental mathematics learning solution designed to support Pre-Kindergarten through Geometry students of all backgrounds." It provides "adaptive and developmentally appropriate instruction that focuses on building students' conceptual understanding of mathematics," supplemented by "scaffolded, rigorous instruction by live, certified teachers ... available on-demand."
