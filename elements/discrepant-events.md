# Discrepant Events

## Description
Discrepant events are demonstrations, observations, or scenarios that violate learner expectations in a noticeable way. They are useful when the instructional goal is to provoke rethinking, explanation, and conceptual change.

## Design Implications

### Context
#### Requirements
- **An event that clearly contradicts an expected outcome**
- **A follow-up prompt that asks learners to explain the mismatch**
#### Constraints
- **Without debrief, surprise alone may entertain more than teach**

### Target Learning Goals
- Surface misconceptions and create readiness for explanation revision.
