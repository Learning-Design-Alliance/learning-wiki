Adaptive Through-Year Assessment (ATYA) system proposed by NWEA¶

Element · All elements Evidence · 4 claims (4 mixed) · 1 study (1 review), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The ATYA is NWEA's proposed through-year assessment system designed to replace the end-of-year state summative while measuring both grade-level standards proficiency and academic growth. The review states "The interim tests will adapt within grade to accurately assess every student against grade-level expectations, as well as above and below grade level as needed," using a state-specific vertical scale linked to the Rasch Unit (RIT) scale. It is designed to address challenges inherent to non-adaptive TCSAs.

Design Implications¶

Context¶

Requirements¶

  • A vertical scale unique to each state's academic standards that links to the RIT scale

Constraints¶

  • The proposed design is tentative; the review presents it as an application of literature findings rather than an evaluated system

Target Learners¶

  • K-12 students, e.g., a Grade 4 targeting example

Target Learning Goals¶

  • Measuring command of grade-level standards and academic growth while producing end-of-year accountability proficiency scores

Claims¶

  • Distributed blueprints with differing district pacing guides risk testing students on content they had no opportunity to learn [~W]
  • The TCSA literature is sparse, with very few empirical or quantitative studies of the models' measurement properties [~W]
  • Simple addition of through-course results is appropriate only when learning is bounded to each testing period [~W]
  • Wise's simulation under continuous learning recommended projection-based weighted averages for aggregating interim scores [~W]
