# BRIDGE teacher and principal evaluation value-added models

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The BRIDGE educator evaluation system incorporates value-added models that measure school and teacher contributions to student achievement in Charleston County School District. The report states: "we describe the value-added models that are used as part of the BRIDGE teacher and principal evaluations." The models were developed by Mathematica Policy Research under a project running from 2013 to 2018 and prepared for the district.

## Design Implications

### Context
#### Requirements
