# Computerized adaptive tests (CATs) as a motivational design feature in low-stakes assessment

## Description
Computerized adaptive tests (CATs) are a test-delivery format in which item selection adapts to the examinee, and the article evaluates them as a design feature with motivational benefits in low-stakes testing. The review "examines the motivational benefits of computerized adaptive tests (CATs)" and concludes they hold advantages over conventional tests for detecting low examinee effort and addressing the resulting validity threat. The element is treated here as the assessment technology whose motivational properties the review synthesizes.
