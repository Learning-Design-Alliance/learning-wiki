# Reading Corps supplemental tutoring program

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
Reading Corps is an AmeriCorps program that provides schools with trained literacy tutors for students in Kindergarten through grade 3. Full-time tutors "work with approximately 15-18 students for 20 minutes each day", implementing "evidence-based literacy instruction and assessment protocols" that are "supplemental to the core reading instruction provided at each school". The goal is to raise individual students' literacy levels so they are on track to meet or exceed the next program-specified literacy benchmark.

## Design Implications
