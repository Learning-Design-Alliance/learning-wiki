# Knowledge object for a whole task: component analysis with defining and ordering properties

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
A knowledge object is "a framework consisting of containers for different kinds of general information and specific portrayals (the knowledge components) that are required for instruction." For a whole task, the component analysis comprises a desired consequence (artifact), subtasks (how-to information), artifacts resulting from each subtask, defining properties that determine class membership, ordering properties that rank artifact adequacy, procedures for finding or creating artifacts, and portrayals of someone performing the steps. Content is represented as information (general) and portrayals (specific instances).

## Design Implications

### Context
#### Requirements
- Content analysis requires specification of both information and portrayals to be useful in instruction.
#### Constraints
- The knowledge object for a whole task described in the paper is comprised primarily of kinds-of and how-to knowledge and skill.

### Target Learners
- instructional designers analyzing content for task-centered courses

### Target Learning Goals
- identifying the knowledge components needed for task-centered instruction
