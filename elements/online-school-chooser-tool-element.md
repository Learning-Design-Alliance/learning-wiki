# Online school chooser tool for low-income parents

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 causal), `q3` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The article evaluates an online school chooser tool through which low-income parents shop for and choose schools for their children. The experiment manipulated how school information was presented within this tool, measuring "knowledge about the schools, attitudes about using the online school chooser tool, and school choice behavior." The tool is the delivery platform for the five tested design factors, including the default sort order manipulation.
