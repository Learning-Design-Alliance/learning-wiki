# Enhanced Core Reading Instruction program for struggling first-grade readers

> **Element** · [All elements](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
Enhanced Core Reading Instruction is "a program for struggling first grade readers" that focuses on Tier 2 supplemental teaching. It provides teachers with professional development and materials to improve the alignment of Tier 2 with Tier 1 core instruction, with small groups of 3-5 students pretaught content soon to appear in the core classroom.

## Design Implications

### Context
#### Requirements
- Training is required for the instructor
- The program assumes that the instructor has some experience with reading instruction
#### Constraints
- Designed for struggling first grade readers in a Tier 2 supplemental role alongside 90 minutes of core reading instruction

### Target Learners
- struggling first grade readers

### Target Learning Goals
- phonemic awareness
- sound blending
- word reading
- fluency
- reading decodable text
- irregular words
