# Knowledge-Building

## Description
Knowledge-building is the element in which learners collectively construct, refine, and extend ideas rather than only consume or repeat them. It is useful when the goal is shared understanding that improves through contribution and revision.

## Design Implications

### Context
#### Requirements
- **A shared problem, text, or idea space**
- **Opportunities for learners to contribute and revise ideas**
#### Constraints
- **Without shared norms, contributions can stay disconnected**

### Target Learning Goals
- Build collective understanding and progressively improve explanations.

## Description
A pedagogical framework associated with Scardamalia and Bereiter that organizes inquiry, dialogic discourse, and collaborative creation and refinement of community knowledge, with students sharing responsibility and teachers facilitating.

## Components
<!- - A programme's own frameworks, tools, indicators and instruments, as its sources describe them - ->

A distinguishing characteristic is "students’shared responsibility for learning and propelling the discourse forward," with teachers facilitating rather than leading. The article treats KB discourse as the ideal context in which antecedents, triggers, and manifestations of curiosity can be examined. (Ali et al. (2025))
