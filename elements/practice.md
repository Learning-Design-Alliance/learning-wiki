# Practice

## Description
Practice asks learners to actively apply new knowledge or skills through structured activities rather than passively receiving information. It converts exposure into fluency and retention by requiring learners to generate responses, solve problems, or perform procedures under conditions that gradually approximate the target performance.

## Design Implications

Practice is one of the most consistently supported instructional elements: active application produces better retention and transfer than re-reading or re-watching [Testing effect: retrieval practice improves long-term retention.](../claims/worked-examples-with-practice-improve-transfer.md) [+S]. Its effectiveness depends on structure — early practice should reduce unnecessary search for novices, for example by following worked examples [Worked examples reduce unnecessary search for novices.](../claims/worked-examples-reduce-novice-search.md) [+M], and part-task practice can isolate difficult components before whole-task integration [Part-task practice reduces cognitive load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]. Practice should be distributed over time and interleaved with feedback; massed, uncorrected repetition builds fluency in errors as readily as in correct performance.

### Context
#### Requirements
- Clear performance criteria so learners know what correct application looks like
- Timely, specific feedback following each attempt ([Feedback](feedback.md))
- Sequencing that manages load: worked examples or part-task practice for novices, whole-task practice as competence grows ([Fading](fading.md))
- Sufficient volume and spacing — one or two attempts rarely produce fluency

#### Constraints
- Unguided problem solving early in learning imposes extraneous load and can underperform worked-example study [Example-problem sequences reduce cognitive load compared to pure problem solving.](../claims/example-problem-sequences-reduce-cognitive-load.md) [+M]
- Practice without feedback entrenches errors; repetition alone does not correct misconceptions
- Blocked, predictable practice produces strong short-term performance but weak retention and transfer compared to spaced, varied practice [~S]
- Less effective when tasks exceed working memory capacity and no load-reduction supports are in place ([Cognitive Load Management](../principles/cognitive-load-management.md))

### Target Learners
- Novices in skill domains (STEM, vocational training, applied sciences) who need fluency before transfer [Worked examples reduce unnecessary search for novices.](../claims/worked-examples-reduce-novice-search.md) [+M]
- Learners building procedural fluency who benefit from part-task isolation of difficult steps [Part-task practice reduces cognitive load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]
- Advanced learners should shift toward whole-task, varied practice; excessive scaffolding at this stage reduces effectiveness [Guidance becomes less effective as learner expertise increases.](../claims/worked-examples-less-effective-with-expertise.md) [~M]

### Target Learning Goals
- Procedural fluency: automating steps so working memory is freed for higher-order reasoning
- Retention: strengthening memory through retrieval rather than review [Retrieval practice improves long-term retention.](../claims/worked-examples-with-practice-improve-transfer.md) [+S]
- Transfer: whole-task practice under varied conditions supports application to new problems [Whole-task performance improves transfer.](../claims/whole-task-performance-improves-transfer.md) [+M]

### Affordances
- [Deliberate Practice](../principles/deliberate-practice.md) — practice enacts this principle when activities target specific weaknesses just beyond current ability, with immediate feedback and repetition with refinement rather than mere repetition
- [Active Learning](../principles/active-learning.md) — practice is the primary mechanism by which learners generate responses instead of receiving them, producing the generative processing passive formats lack
- [Retrieval Practice](../principles/retrieval-practice.md) — practice from memory (rather than with open notes) converts each attempt into a retrieval event that strengthens long-term retention
- [Cognitive Load Management](../principles/cognitive-load-management.md) — sequencing practice from worked examples to faded to independent problems keeps load within working memory limits as expertise grows
- [Scaffolding](../principles/scaffolding.md) — practice difficulty and support should fade in step with demonstrated competence

## Examples

**[Use Worked Examples](../strategies/use_worked_examples.md)** — Alternates fully solved problems with isomorphic problems for learners to solve; the practice problem immediately follows the demonstration.

**[Khan Academy](https://www.khanacademy.org)** — Practice exercise sets with immediate feedback, hint scaffolds, and spaced review built into the mastery system.

**[Duolingo](https://www.duolingo.com)** — Distributed, interleaved practice with adaptive review scheduling; a large-scale implementation of spacing in practice design.

**[Codecademy](https://www.codecademy.com)** — Learners write code in every lesson unit, practicing immediately after annotated demonstrations with automated feedback.
