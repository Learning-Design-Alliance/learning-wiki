# Spiral Curriculum

## Description
Spiral curriculum is the element in which important ideas are revisited repeatedly over time, with each return expanding complexity or depth. It is useful when learning should grow cumulatively rather than be treated as covered once and complete.

## Design Implications

### Context
#### Requirements
- **Intentional revisiting of core ideas**
- **A plan for increasing depth or complexity across iterations**
#### Constraints
- **Repetition without added depth can feel redundant**

### Target Learning Goals
- Build cumulative understanding and more durable transfer over time.
