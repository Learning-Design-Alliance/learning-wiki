# Flowcharts as a representation for planning algorithms

> **Element** · [All elements](index.md)

## Description
The deck introduces flowcharts as a planning representation, defining them as "A diagram that shows a process, made up of boxes representing steps, decision, inputs and outputs". It connects flowcharting to algorithm construction, noting that a step-by-step program "will need planning, and to do this we use an algorithm", and points teachers to a YouTube video. This aligns with the Kentucky standard M-AP-04 on creating flowcharts and pseudocode.
