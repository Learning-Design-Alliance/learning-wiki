# Linguatorium: a web-based spaced-repetition vocabulary tutoring system with automatic activity generation and instructor curriculum control

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (2 for, 1 against) · 1 study, `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Linguatorium is a web-based CALL tool for pair-associate vocabulary learning that generates exercises automatically from instructor-entered wordlists. "The tool (named Linguatorium) takes the form of a web-based system that runs in any modern Web browser on both personal computers and touch-screen tablets." It supports custom "lexical themes" with definitions retrieved from online dictionaries and WordNet, image search, corpus frequency data, due dates, progress reports, and an adaptive tutoring algorithm driven by computational models of student lexical memory. In the study it was used as a supplementary activity alongside unchanged classroom pedagogy.

## Design Implications

### Context
#### Requirements
- Instructors enter lexical units with glosses, images, and context usage examples; lexical themes should correspond to units of instruction in the curriculum for synchronization with classroom activities.
#### Constraints
- The authors intended it as a supplemental tool rather than a comprehensive vocabulary learning solution, given limited support for productive vocabulary use stemming from limits of automated natural-language semantics processing.

### Target Learners
- EFL students, specifically third-year marine engineering cadets in the study

### Target Learning Goals
- Foreign language vocabulary acquisition and long-term retention
