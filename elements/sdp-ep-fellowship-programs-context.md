# SDP and EP fellowship programs as the intervention context for agency data-use change

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (2 qualitative, 1 design), `q1`–`q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The Strategic Data Project (SDP) and Education Pioneers (EP) fellowship programs are the intervention whose agency-level effects the Year 2 report evaluates. The document provides "background on the SDP and EP fellowship programs and the study's purpose and methodology" in the main report, while the companion profiles document each agency's partnership experience, including fellows' projects and lessons learned during the partnership.

## Design Implications

### Context
#### Requirements
- Fellowship placements in education agencies for agency-specific data projects
#### Constraints
- Associated project time frame 2011–2015; Year 2 report covers the 2013–14 school year

### Target Learners
- Education agencies hosting fellows
- Fellows in the SDP and EP programs

### Target Learning Goals
- Effective data use in education agencies
