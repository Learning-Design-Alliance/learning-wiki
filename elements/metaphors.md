# Metaphors

## Description
Metaphors are explanatory comparisons that map a less familiar concept onto a more familiar image or experience. They are useful when learners need a concrete entry point into abstract or complex ideas.

## Design Implications

### Context
#### Requirements
- **A familiar source idea**
- **A target concept with meaningful relational overlap**
- **Clarification of where the metaphor fits and where it breaks**
#### Constraints
- **Overextended metaphors can create misconceptions**

### Target Learning Goals
- Support comprehension, imagination, and conceptual access.
