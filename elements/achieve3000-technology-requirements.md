# Achieve3000 technology requirements: individual device per lesson with optional apps

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The program requires "student individual use of a laptop, workstation, Chromebook, or mobile device (such as a tablet) for each lesson." Installing the program itself on the device is not necessary, and apps are offered for Windows, Macs, Chromebooks, iPads, and Android mobile devices so students can use Achieve3000 away from school.
