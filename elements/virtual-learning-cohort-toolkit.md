# Toolkit for Building a Virtual Learning Cohort with ten transferable planning tools

## Description
A toolkit published by Mathematica in October 2021 for learning cohort facilitators. It offers guiding values for planning activities for a cohort organized around a common theme and provides ten transferable tools, including a scheduling survey, activity-planning template, activity flyer template, meeting design template, tools for planning a virtual retreat, and an evaluation form. It emerged from the CBSL pilot initiative with the Gates Foundation and nine K–12 education grantees.

## Design Implications

### Context
#### Requirements
- A facilitator planning a variety of learning activities for a learning cohort organized around a common theme
#### Constraints

### Target Learners
