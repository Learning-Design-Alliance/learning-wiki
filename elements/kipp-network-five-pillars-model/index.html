KIPP charter school network and its Five Pillars model¶

Element · All elements Evidence · 2 claims (2 for) · 2 studies (1 quant-synthesis, 1 theoretical), q2–q3 · 0 of 2 report an effect size · 2 claims rest on one study

Description¶

The Knowledge Is Power Program (KIPP) is described as "the largest public charter school network in the United States, with 141 elementary, middle, and high schools in the 2013–2014 school year." The report identifies "the Five Pillars that helped lay the foundation for the 'No Excuses' model" as key elements of KIPP's model, noting the network grew rapidly from its first fifth grade classes in 1994 and planned to add 23 more schools in fall 2014.
