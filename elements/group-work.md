## Description
Group work is the element in which learners work together on a shared task, product, or problem. It is useful when the task benefits from distributed reasoning, division of labor, or collaborative sensemaking.

## Design Implications

### Context
#### Requirements
- **A task worth doing together**
- **Clear expectations for roles, contribution, or output**
- **Structures for accountability and coordination**
#### Constraints
- **Unequal participation is common without structure**
- **Poor task design can reduce collaboration to parallel solo work**

### Target Learning Goals
- Build collaboration, problem solving, and collective reasoning.
