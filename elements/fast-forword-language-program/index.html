Fast ForWord Language computer-based instructional program¶

Element · All elements Evidence · 3 claims (2 for, 1 against) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

Fast ForWord Language is "a computer-based instructional program developed to build cognitive skills students need to improve English language proficiency and reading skill." It consists of seven game-like exercises covering nonverbal and verbal sound discrimination, phonological processing, vocabulary recognition, and language comprehension, each building from basic to more complex skills. The program uses "acoustically modified speech and language training that approach the normal speed and volume of speech as the student progresses." It was designed for students struggling with reading but has been used with English language learners, and has been on the market since 1997.

Design Implications¶

Context¶

Requirements¶

  • All instructions on how to use the program are included in the software package; the developer recommends one to three days of online and instructor-based teacher training varying by implementation scale and model

Constraints¶

  • This WWC review focuses only on Fast ForWord Language as used with English language learners, not the multiple other Fast ForWord products

Target Learners¶

  • elementary school English language learners
  • students struggling with reading

Target Learning Goals¶

  • English language proficiency
  • reading skill
  • listening accuracy
  • phonological awareness
  • language structures

Claims¶

  • The WWC improvement index is +31 percentile points for English language development and +3 percentile points for reading achievement [+W]
  • Fast ForWord Language shows no discernible effects on reading achievement of elementary school English language learners [-W]
  • Fast ForWord Language has potentially positive effects on English language development of elementary school English language learners [+W]

Related Elements¶

  • Fast ForWord® adaptive computer-based reading program

Examples¶

  • Implement Fast ForWord Language at high intensity over a compressed period (100 minutes a day for four to six weeks, or 50 minutes a day for 8 to 12 weeks)
