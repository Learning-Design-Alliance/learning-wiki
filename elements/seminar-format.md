# Seminar Format

## Description
Seminar format is the element in which learning is organized around sustained discussion of a shared text, question, or issue with facilitator support but strong learner participation. It is useful when interpretation, reasoning, and dialogue are central.

## Design Implications

### Context
#### Requirements
- **A common text, question, or topic**
- **Participation norms and discussion prompts**
#### Constraints
- **Weak preparation can flatten discussion**

### Target Learning Goals
- Support interpretive dialogue, critical reasoning, and sustained discussion.
