New Teacher Center system of supports for instructional coaching¶

Element · All elements Evidence · 2 claims (2 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A district-level system of supports for instructional coaching drawn from the New Teacher Center's experience and described in this Mathematica brief. It comprises three components: "tracking coaching activities, providing clear guidance to coaches, and engaging district leaders as they implement a coaching program." The brief positions it as a way to make districtwide coaching implementation succeed where coaches might otherwise lack expectations and support.

Design Implications¶

Context¶

Requirements¶

  • Districts implementing coaching programs need clear expectations and support structures for coaches.

Constraints¶

Target Learners¶

  • district leaders
  • instructional coaches

Target Learning Goals¶

  • improving teachers' instruction through coaching

Claims¶

  • Without clear expectations and support from district leaders, coaches might not devote sufficient time to the full range of coaching activities needed to improve teachers' instruction [+W]
  • Instructional coaching provides individualized support adapted to teachers' needs and classroom contexts, in contrast to traditional professional development workshops [+W]

Related Elements¶

Examples¶

  • Engage district leaders as they implement a coaching program
  • Provide clear guidance to coaches when implementing a districtwide coaching program
  • Track coaching activities to support districtwide coaching implementation
