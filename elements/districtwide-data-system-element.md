# Districtwide data system for secure, reliable data management

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size

## Description
The guide states that "effective, sustainable data use requires a secure and reliable data-management system at the district level". Checklist actions are involving a variety of stakeholders in selecting a data system, clearly articulating system requirements relative to user needs, determining whether to build or buy the data system, and planning and staging its implementation. The guide also presents considerations for built and purchased data systems and sample stakeholder perspectives on data system use.

## Design Implications

### Context
#### Requirements
- Involve a variety of stakeholders in selecting a data system
- Clearly articulate system requirements relative to user needs
- Plan and stage the implementation of the data system
#### Constraints
- The panel notes it would be impractical to structure a rigorous study investigating the effects of implementing a districtwide data system because it is difficult to establish an appropriate comparison

### Target Learners
- District leaders and education administrators

### Target Learning Goals
- Organizational and technological conditions that support effective data use for instructional decision making
