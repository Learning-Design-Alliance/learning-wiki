Exact Path Proficiency + Exact Path Growth digital learning system¶

Element · All elements Evidence · 9 claims (9 for) · 3 studies (3 causal), q2–q3 · 3 of 3 report an effect size · 9 claims rest on one study

Description¶

Exact Path Proficiency + Exact Path Growth is a bundled digital learning system for K-12 students that pairs two components: Proficiency, which "delivers grade-level, standards-aligned practice assessments and test-readiness activities", and Growth, which "provides adaptive, skill-based instruction informed by diagnostic data". Together the components are intended to address skill gaps while maintaining progress toward grade-level expectations. The page reports the bundle qualified for a Moderate evidence rating based on one study of 3,323 students with an average effect size of +0.14.

Context¶

Requirements¶

  • Implemented by a district's current teachers, school leaders, and district leaders, with guidance from Edmentum's Customer Success Managers; no additional staffing is required.

Constraints¶

  • The moderate evidence rating rests on a single quasi-experimental study in one large Florida district.

Target Learners¶

  • middle school students

Target Learning Goals¶

  • ELA achievement
  • Mathematics achievement
  • closing skill gaps while maintaining grade-level progress

Claims¶

  • Using Exact Path Proficiency combined with Exact Path Growth is associated with a +0.14 improvement in middle school ELA achievement on the FAST assessment [+W]
  • The combined Exact Path program shows statistically significant positive effects in Mathematics, with the strongest impacts in Grade 6 [+M]
  • Exploratory analysis suggests students using the combined program outperformed peers using Exact Path Growth alone [+W]
  • Exact Path Proficiency + Growth improves middle school Mathematics achievement (ES +0.11) [+W]
  • Students using Proficiency + Growth outperformed peers using Growth alone (exploratory) [+W]
  • Exact Path Proficiency + Growth shows statistically significant positive ELA effects across Grades 6-8 [+W]
  • Exact Path use produced a statistically significant positive effect on 6th-grade ELA achievement (effect size = +0.16) in a quasi-experimental study [+W]
  • Exact Path use produced a statistically significant positive effect on 6th-grade Mathematics achievement (effect size = +0.06) in the same quasi-experimental study [+W]
  • The Exact Path evaluation sample was demographically diverse, including 42% African American, 47% economically disadvantaged, and 22% ESE students [+W]
