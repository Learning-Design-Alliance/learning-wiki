# Seven agency profiles companion document

> **Element** · [All elements](index.md)

## Description
The companion document is a released artifact presenting "seven profiles, one for each agency in the study," describing each agency's experience with data-driven decision making groundwork. The profiles were "developed using data collected from interviews" and accompany the full Year 1 report on laying the groundwork for data-driven decision making.

## Design Implications

### Context
#### Requirements

#### Constraints
- Covers the seven agencies in the study only

### Target Learners

### Target Learning Goals
- understanding agency experiences building data capacity
