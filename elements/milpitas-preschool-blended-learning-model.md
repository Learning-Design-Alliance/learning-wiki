# Blended learning model in Milpitas preschool classrooms

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
In 2012–2013 both child development centers began using "a blended learning model... that combines teacher-directed instruction and small-group learning with opportunities for children to work independently on computers or tablets." This instructional arrangement is the classroom context into which the CPAA assessment was integrated.

## Design Implications

### Context
#### Requirements
- Classrooms equipped with computers or tablets for independent children's work
#### Constraints
- Described only for the two Milpitas CDCs beginning in 2012–2013

### Target Learners
- preschool children ages 3 to 5

### Target Learning Goals
- literacy and mathematical skills through mixed instructional formats
