# Teacher Advancement Program (TAP): a whole-school teacher evaluation, compensation, and professional development model

## Description
The Teacher Advancement Program (TAP) is described as "a whole-school approach to evaluating and compensating teachers and providing professional development opportunities". Its stated aims are twofold: "to both improve teaching and help schools attract and retain good teachers". The program operates at the whole-school level rather than targeting individual teachers in isolation.
