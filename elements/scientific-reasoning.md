# Scientific Reasoning

## Description
Scientific reasoning is the element in which learners generate explanations, evaluate evidence, test claims, and revise models using disciplinary norms of inquiry. It is useful when understanding depends on explanation and evidence, not memorization alone.

## Design Implications

### Context
#### Requirements
- **Claims or models that can be tested or evaluated**
- **Evidence relevant to those claims**
- **Prompts that require explanation and revision**
#### Constraints
- **Learners may describe observations without reasoning from them unless prompted**

### Target Learning Goals
- Build evidence-based explanation, model revision, and disciplined inquiry.
