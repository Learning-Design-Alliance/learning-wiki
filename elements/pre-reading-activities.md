# Pre-Reading Activities

> **Element** · [All elements](index.md)

## Description
Pre-reading activities are tasks completed before reading in order to activate prior knowledge, establish purpose, surface key vocabulary, or prepare attention for important ideas. They are useful when learners need orientation before engaging the text itself.

## Design Implications

### Context
#### Requirements
- **A specific purpose tied to the upcoming text**
- **Prompts that prepare attention rather than duplicate the reading**
#### Constraints
- **Overlong pre-reading can delay the actual text unnecessarily**

### Target Learning Goals
- Prepare comprehension by activating knowledge and setting expectations.
