# EDIT measure for examining teachers' use of ongoing child assessment to individualize instruction

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The EDIT is a measurement tool developed for OPRE by Mathematica Policy Research and its partners. It is "designed to help researchers understand how teachers conduct ongoing assessments for individualization and use those assessments to guide instruction." It targets early childhood teachers' assessment and instructional decision-making practices.

## Design Implications

### Context
#### Requirements
- Requires researchers or observers trained to gather evidence about how the teacher collects and uses ongoing assessments
#### Constraints
- Developed specifically in the context of early childhood settings under OPRE/ACF commissioning

### Target Learners
- Early childhood teachers

### Target Learning Goals
- Using ongoing child assessment data to individualize instruction
