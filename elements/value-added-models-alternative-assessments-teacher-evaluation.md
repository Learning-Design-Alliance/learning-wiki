## Description
One of the two alternative measure types profiled in the report: value-added models that substitute different assessment sources for typical state assessments. The summary describes "value-added models that use the results of end-of-course assessments or commercially available tests in statistical growth models instead of typical state assessments." The report profiles how early-adopting districts implement this approach for teacher evaluation.
