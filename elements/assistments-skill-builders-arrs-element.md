# ASSISTments Skill Builders with the ARRS delayed reassessment system

> **Element** · [All elements](index.md)
> **Evidence** · 6 claims (6 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 6 claims rest on one study

## Description
ASSISTments is a free online formative assessment and tutoring system for middle school mathematics, used by 650 teachers with over 5,000 student users a day. Within its Skill Builder problem sets, students master a skill by answering three questions correctly in a row, after which "a single -item test is administered after a pre -defined period of time, with a gradually increasing space in between reassessments" through the Automatic Reassessment and Relearning System (ARRS). This study used ARRS test outcomes to define productive persistence versus wheel-spinning.

## Design Implications

### Context
#### Requirements
- Students must attempt 10 or more problems in a problem set and complete an ARRS test for the productive/wheel-spinning classification to apply
#### Constraints
- Success on the ARRS test can be noisy due to slips or guessing, and ARRS administration can be customized by teachers, producing missing data

### Target Learners
- middle school mathematics students

### Target Learning Goals
- retention of mathematics skills mapped to U.S. Common Core standards
