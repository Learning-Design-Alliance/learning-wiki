# Team Pennsylvania Foundation teacher and principal evaluation pilot project

## Description
The Team Pennsylvania Foundation pilot project is a statewide initiative for which this report was prepared "as a first step ... to inform the development of a full, statewide model evaluation system". The project used the research synthesis and implementation scan as groundwork for building a value-added-based evaluation system in Pennsylvania. Funders listed include the Team Pennsylvania Foundation and the Gates Foundation.
