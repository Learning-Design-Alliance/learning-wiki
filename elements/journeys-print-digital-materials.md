# Flexible print or print-plus-digital delivery of Journeys materials

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
Journeys can be implemented using only print resources or a combination of print and digital resources. Student and teacher digital materials can be accessed on desktop computers, laptops, or tablets with an Internet connection, allowing schools with different technology access to adopt the same program. This flexibility is described as part of the program's implementation requirements rather than as a tested feature.
