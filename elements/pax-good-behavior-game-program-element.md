# PAX Good Behavior Game program package (team-based behavior management with training, manuals, timers, and parent materials)

> **Element** · [All elements](index.md)
> **Evidence** · 6 claims (5 for, 1 mixed) · 3 studies (2 causal, 1 quant-synthesis), `q2` · 3 of 3 report an effect size · 6 claims rest on one study

## Description
PAX Good Behavior Game is a commercial version of the long-standing Good Behavior Game, described as "a commercial version that is very widely used in the U.S. and elsewhere". Students are divided into teams; teachers monitor behavior and teams violating agreed class rules receive checkmarks, with the team receiving the fewest checkmarks earning a small privilege. The package includes onsite training by experienced therapists, plus manuals, timers, and auxiliary materials, and parents receive manuals to use similar methods at home.
