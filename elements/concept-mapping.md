## Description
Concept mapping is the element in which learners represent concepts and their relationships visually, typically as nodes and labeled links. It is useful for organizing prior knowledge, identifying structure, and making connections visible before, during, or after learning.

## Design Implications

### Context
#### Requirements
- **A set of concepts or ideas worth relating**
- **A prompt for how relationships should be represented**
- **Time to revise or discuss the map**
#### Constraints
- **Maps can become decorative lists if relationships are not explicit**
- **Overly dense maps may increase confusion**

### Target Learners
- Learners building conceptual structure in content-rich or relationship-heavy domains.

### Target Learning Goals
- Organize knowledge, surface misconceptions, and strengthen integration across ideas.
