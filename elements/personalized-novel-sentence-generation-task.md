# Personalized novel-sentence generation task for L2 vocabulary lessons

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (2 for, 2 against) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
An instructional task component in which learners write two to three personalized novel sentences for each target vocabulary item, based on a provided model answer, integrating the word's meaning, grammar, and personal relevance. The instructor verified each student's sentences for sufficient content, accurate usage, and genuine personalization before submission. It was implemented as the generation treatment alongside baseline non-generative tasks (fill-in, synonym comparison, definition matching, crossword) balanced to roughly 40 minutes each.

## Design Implications

### Context
#### Requirements
- Instructor verification of sentence completion, accuracy, and personal specificity to the individual student.
#### Constraints
- Bilingual dictionaries were allowed but example sentences from the dictionaries were not.

### Target Learners
- First-year Japanese university ELLs at B1 to B1+ CEFR level

### Target Learning Goals
- Producing personalized definitions and context-based example sentences using target academic vocabulary
