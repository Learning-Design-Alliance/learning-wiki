# Support for data-driven instruction intervention (coaching and support to schools for using student data)

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (2 for, 2 against) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
An intervention evaluated in a random assignment study that involved "providing coaching and support to schools to help them use student data to inform teachers’ instruction." It was examined for effects on "teachers’ practices and student achievement" and included additional resources and emphasis placed on data-related activities. Most aspects were implemented as planned, but it did not increase key data-related activities, teachers' data use, or instructional practices.
