NWEA College Explorer tool linking MAP Growth scores to higher-education benchmarks¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The College Explorer is a data visualization tool that "links MAP® Growth™ scores with national benchmarks for colleges, universities, and even specific majors." It is intended for use by students, parents, and teachers to develop pathways to higher education, and the page notes it can be combined "with goal setting and parent conferences" to help students plan for post-secondary education.
