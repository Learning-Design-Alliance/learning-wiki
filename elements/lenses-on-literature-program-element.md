# Lenses on Literature: a comprehensive disciplinary-literacy instructional framework built around a Driving Task Prompt

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Lenses on Literature is a comprehensive instructional framework engaging all students in daily, standards-driven reading, writing, and discourse grounded in disciplinary literacy. Curriculum units and modules are organized around a Driving Task Prompt and follow a sequenced instructional journey including comprehension, knowledge building, genre study, synthesis, and writing. The program provides print and digital experiences, scaffolds for multilingual learners, and embedded formative assessments using standards-aligned rubrics from the Stanford Center for Assessment, Learning, and Equity.
