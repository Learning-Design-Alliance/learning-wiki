# SIPPS foundational skills reading curriculum

## Description
SIPPS is a foundational skills reading curriculum for new and struggling readers in grades K–12 that provides "a structured-literacy approach to instruction through explicit routines focused on phonological awareness, spelling-sounds, and sight words." It can serve as a core/Tier I program supporting grade-level foundational skills standards, or as a Tier 2/Tier 3 intervention to accelerate progress and close gaps. It is designed for small-group format and can be implemented by classroom teachers, interventionists, or paraprofessionals.
