# Self-Assessment

## Description
Self-assessment is the element in which learners judge their own work, understanding, or progress against explicit criteria. It is useful when the goal is not only better immediate performance, but stronger self-monitoring and more accurate judgments about what to improve next.

## Design Implications

### Context
#### Requirements
- **Visible criteria**: Learners need examples, rubrics, or success indicators to compare against.
- **Reflection prompt**: The task should ask learners to identify strengths, gaps, or next steps.
- **Low-stakes use**: Self-assessment works best when honesty is safer than impression management.
#### Constraints
- **Weak calibration**: Novices may misjudge quality without models or coaching.
- **Performative reflection**: Generic prompts can produce superficial responses.

### Target Learners
- Learners developing self-regulation, revision habits, and metacognitive accuracy.

### Target Learning Goals
- Improve monitoring, revision, and ownership of progress.
