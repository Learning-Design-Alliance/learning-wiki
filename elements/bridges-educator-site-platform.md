# Bridges Educator Site: web-based platform providing digital curriculum materials and interactive displays

## Description
The Bridges Educator Site (BES) is a web-based platform through which The Math Learning Center provides "access to all curriculum materials in a digital format." It "operates on all modern browsers," hosts interactive display materials, and offers optional digital manipulatives for use by teachers and students, complementing the curriculum's print materials.
