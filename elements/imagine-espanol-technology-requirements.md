# Technology requirements for implementing Imagine Español

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
Implementation requires standard networked computers or tablets with microphone access, preferably a headset, to get the most out of the instructional content. The article states that "Network configuration to permit the specified allowed URLs through any firewalls on designated ports is essential for an easy set up," and depending on the device, the Imagine Learning Student App may need to be installed or the program accessed in a supported web browser.

## Design Implications

### Context
#### Requirements
- Network bandwidth and device hardware should meet minimum system requirements noted on the Imagine Learning website
#### Constraints
- Firewall configuration on designated ports is required; app installation depends on the device

### Target Learners
- students in grades Pre-K–6 using the program

### Target Learning Goals
- access to adaptive Spanish literacy instruction
