# Justification

## Description
Justification is the element in which learners explain why a claim, choice, or solution is warranted using reasons, criteria, or evidence. It is useful when the instructional goal is to strengthen explanation quality rather than only reach an answer.

## Design Implications

### Context
#### Requirements
- **A claim, decision, or solution to defend**
- **Criteria or evidence that can support the defense**
#### Constraints
- **Learners may state conclusions without explaining the warrant unless prompted**

### Target Learning Goals
- Improve reasoning quality, evidence use, and explanation of decisions.
