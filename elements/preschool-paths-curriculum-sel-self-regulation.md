## Description
The Preschool PATHS® Curriculum is the social-emotional learning component REDI provides to students. It "promotes social-emotional learning, which has an emphasis on self-regulation, self-awareness, social problem-solving, and emotional control." It is embedded within the broader REDI program rather than delivered alone.
