# Value-Added Assessment System for DC Schools and Teachers (2009–2015 project context)

## Description
The article is associated with the project "Value-Added Assessment System for DC Schools and Teachers," with a stated time frame of 2009–2015, prepared for District of Columbia Public Schools. It investigates empirical Bayes shrinkage of teacher value-added estimates within this district accountability context, examining how the adjustment relates to teachers of students with hard-to-predict achievement levels.
