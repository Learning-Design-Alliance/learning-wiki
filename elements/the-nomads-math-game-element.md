# The Nomads — a 3D math game training adaptive expertise in rational number arithmetic

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q3` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
The Nomads is "a 3D math game designed to train adaptive expertise in rational number arithmetic", in which players serve as tribal leaders collecting resources, exchanging with their tribe, and bartering with another tribe. Players perform nine game tasks (calculate energy, feed the tribe, hunt buffalo, collect berries, mine gems and ore, cut logs, make weapons, build tipis, trading post) whose answers are not fixed, so success depends on adaptive and strategic use of numbers. The game uses an event-based learning analytics strategy recording six log parameters per completed item, including skills required, correctness, and scaffold use.

## Design Implications

### Context
#### Requirements
- An event-based data-tracking system sending a line of game logs to the server every time a player completes a game item
- Instructional scaffolds built into select tasks to facilitate student learning
#### Constraints
- Game tasks demand basic understanding of arithmetic facts associated with whole numbers, which aligns with the Common Core Mathematics Standards for fourth graders
- Skills 3 and 6 only simultaneously appear in the Cut Logs tasks, so they are combined into attribute 3 in the Q matrix

### Target Learners
- Fourth to sixth graders in mathematics classrooms

### Target Learning Goals
- Adaptive expertise in rational number arithmetic
- Flexible and adaptive arithmetic problem-solving
