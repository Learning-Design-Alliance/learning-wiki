# Building Blocks computer activities with automatic adjustment

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (4 for) · 4 studies (3 causal, 1 quant-synthesis), `q3`–`q4` · 4 of 4 report an effect size · 4 claims rest on one study

## Description
The Building Blocks computer activities are learning tasks related to the day's mathematics topic that "automatically adjust when children progress well or need additional help." Children worked on them individually during center time, often while teachers led small-group instruction, for approximately 10–15 minutes twice per week. The report notes they are recommended (but not required) for effective implementation, and an online subscription can be purchased per student.

## Design Implications

### Context
#### Requirements
- Desktop or tablet computers are required for use of the Building Blocks computer activities.
#### Constraints
- The computer activities are recommended (but not required) for effective implementation of the Building Blocks program.

## Claims

- [In a 28-classroom cluster randomized trial, Building Blocks raised end-of-intervention REMA scores with an effect size of 1.07 (improvement index +36)](../claims/building-blocks-clements-2008-large-effect.md) [+M]
- [In a large-scale 106-classroom cluster randomized trial, Building Blocks raised end-of-intervention REMA scores with an effect size of 0.48 (improvement index +18)](../claims/building-blocks-clements-2011-scale-up-effect.md) [+M]
- [In a 139-classroom scale-up cluster randomized trial (TRIAD), Building Blocks raised end-of-intervention REMA scores with an effect size of 0.55 (improvement index +21)](../claims/building-blocks-hofer-2013-scale-up-effect.md) [+M]
- [Building Blocks has a potentially positive effect on preschool mathematics achievement, with a pooled effect size of 0.58 across three studies meeting WWC standards](../claims/building-blocks-potentially-positive-preschool-math-effect.md) [+M]
