AI-enabled SST/MTSS meeting agenda tool built on Solara's custom configuration¶

Element · All elements Evidence · 2 claims (2 mixed) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A configuration solution built with Warwick Public Schools on Panorama's Solara platform: an AI-enabled MTSS meeting agenda generator that standardizes SST/MTSS meetings and automates data pulls. Users "select one or more students and input any other contextual information about the upcoming meeting," and the tool "generates a complete data-driven agenda for the meeting that the educator can review," pulling from all available data sources and including a recommended timeline for follow-up. It was developed by leveraging existing Solara capabilities rather than new product functionality.

Design Implications¶

Context¶

Requirements¶

  • Requires access to the district's integrated student data sources so the tool can pull comprehensive snapshots
  • Requires training and follow-through for quality usage, especially given varied staff comfort with AI

Constraints¶

  • Adoption depended on fitting existing meeting routines and workflows; teams accustomed to discussing without agendas skipped the tool

Target Learners¶

  • K-12 educators and student support team members in Warwick Public Schools

Target Learning Goals¶

  • Data-driven intervention decision-making in SST/MTSS meetings
  • Reduced administrative burden on educators

Claims¶

  • The co-designed AI-enabled SST meeting agenda tool saw mixed district-wide adoption despite enthusiasm in facilitated meetings [~W]
  • Three factors influenced adoption of the SST agenda tool: lack of guided practice, inconsistent routines, and value not visible to teachers [~W]
