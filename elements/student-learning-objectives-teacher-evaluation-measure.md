# Student learning objectives set by individual teachers and approved by principals

> **Element** · [All elements](index.md)

## Description
The second alternative measure type profiled: student learning objectives (SLOs). The summary defines them as "determined by individual teachers, approved by principals, and used in evaluations that do not involve sophisticated statistical modeling." The report profiles how early-adopting districts use SLOs as an alternative to statistically modeled growth measures in teacher evaluation.

## Design Implications

### Context
#### Requirements
- Objectives determined by individual teachers and approved by principals
#### Constraints

### Target Learners
