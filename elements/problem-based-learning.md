## Description
Problem-based learning, as an element, refers to the use of an authentic or ill-structured problem as the immediate driver of inquiry, information seeking, and solution development inside a larger design. This page serves as the canonical short-form target for element links that point to PBL-style problem framing.

## Design Implications

### Context
#### Requirements
- **A meaningful problem**
- **Need for investigation or reasoning**
- **Space for learners to propose and test ideas**
#### Constraints
- **Weakly framed problems produce shallow inquiry**
- **Novices often need more structure and support**

### Target Learners
- Learners developing applied reasoning and inquiry strategies.

### Target Learning Goals
- Use problems to drive knowledge construction and solution development.
