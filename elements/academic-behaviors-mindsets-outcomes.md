# Academic behaviors and mindsets as student outcomes beyond test scores

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The paper treats a set of non-tested student outcomes — "a range of academic behaviors and mindsets other than test scores" — as important contributors to children's long-term success and as legitimate targets of teacher effects. The measured outcomes named in the summary are self-reported behavior in class, self-efficacy in math, and happiness in class. This outcome set functions as the paper's focal construct, contrasted throughout with math test scores.

## Design Implications

### Context
#### Requirements
- Measures of these outcomes must be collected from students, e.g., self-reported behavior, self-efficacy, and happiness in class.
#### Constraints
- The paper's evidence concerns upper-elementary students and math-related outcomes.

### Target Learners
- upper-elementary students

### Target Learning Goals
- academic behaviors in class
- self-efficacy in math
- happiness in class
