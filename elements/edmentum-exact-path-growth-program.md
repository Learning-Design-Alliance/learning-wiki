# Edmentum Exact Path Growth personalized learning program

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Exact Path Growth is a personalized learning program for K-12 learners in Math and English Language Arts standards. It offers "individualized learning paths, adaptive diagnostic assessments, and educator-led interventions" and provides flexible assessment options, integrating with NWEA MAP Growth, Renaissance Star, or select state assessments to personalize learning paths.

## Design Implications

### Context
#### Requirements
- Implemented by a district's current teachers, school leaders, and district leaders, with guidance from Edmentum's dedicated Customer Success Managers; no additional staffing is required.
#### Constraints
- Operates on commonly used district devices and browsers and does not require additional technology applications or devices.

### Target Learners
- K-12 learners

### Target Learning Goals
- Mathematics achievement
- English Language Arts achievement
