# Effort monitoring with proctor notification feature for computer-based tests

> **Element** · [All elements](index.md)
> **Evidence** · 6 claims (6 for) · 4 studies (2 causal, 1 associational, 1 design), `q2`–`q3` · 0 of 4 report an effect size · 6 claims rest on one study

## Description
A computer-based testing feature that detects rapid guessing as it occurs and notifies proctors that a test taker has become disengaged. The article describes it as "a new effort monitoring feature that can detect rapid guessing, as it occurs, and notify proctors that a test taker has become disengaged." The feature was evaluated empirically for its effects on engagement, performance, and score validity.

## Design Implications

### Context
#### Requirements
- Requires computer-based test delivery so that rapid-guessing behavior can be detected in real time, and proctors available to receive and act on notifications.
#### Constraints
- The article evaluates it in the context of tests perceived as low stakes, where disengaged test taking occurs.

### Target Learners
- K-12 students taking computer-based achievement tests

### Target Learning Goals
- Valid measurement of what test takers know and can do
