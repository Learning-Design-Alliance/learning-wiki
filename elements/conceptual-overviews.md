# Conceptual Overviews

## Description
Conceptual overviews are elements that present the broad structure, central idea, or organizing logic of a topic before moving into details. They are useful when learners need a stable frame for understanding later elaboration.

## Design Implications

### Context
#### Requirements
- **A coherent big-picture representation**
- **Explicit links between the overview and later detail**
#### Constraints
- **Overviews that stay too general may not help later application**

### Target Learning Goals
- Support schema formation and orientation to the whole.
