# Collaboration

## Description
Collaboration is the short-form canonical target for learners working together toward a shared product, understanding, or decision.

## Design Implications

### Context
#### Requirements
- **A shared task**
- **Coordination and accountability**
#### Constraints
- **Parallel solo work is not the same as collaboration**

### Target Learning Goals
- Support shared reasoning, participation, and collective problem solving.
