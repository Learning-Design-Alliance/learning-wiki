# Scaffolding

## Description
Scaffolding is the element in which support is added temporarily so learners can perform tasks they could not yet complete independently.

## Design Implications

### Context
#### Requirements
- **A task just beyond current independent performance**
- **Support that can later be faded**
#### Constraints
- **Over-support can reduce productive effort**
- **Withdrawing support before checking understanding blocks uptake, even when the support itself was well-calibrated** — see [Students' application of teacher support predicts accurate answers in small-group work](../claims/student-uptake-of-support-predicts-small-group-answer-accuracy.md) [-M]

### Target Learning Goals
- Extend capability while building toward independence.
