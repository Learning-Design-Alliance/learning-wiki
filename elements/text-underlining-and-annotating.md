# Text underlining and annotating

## Description
A study aid involving marking text to indicate importance. The article defines annotating as "making marginal notes or in some way designating important information."

## Design Implications

### Context
#### Requirements
- Can be experimenter-generated or student-generated.
#### Constraints
- Experimenter-generated markings reduce the number of decisions a reader makes regarding importance.

### Target Learners
- College students

### Target Learning Goals
- Test performance and information retention
