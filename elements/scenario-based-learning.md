# Scenario-Based Learning

## Description
Scenario-based learning is the element in which instruction is organized around a realistic situation, case, or mission that requires learners to interpret information and make decisions in context. It is useful when the goal is application, transfer, and judgment under conditions that resemble real use.

## Design Implications

### Context
#### Requirements
- **A credible scenario**
- **Decisions or actions learners must take**
- **Relevant information embedded in context**
#### Constraints
- **Can become decorative if the scenario does not shape decisions**
- **High design effort when realism matters**

### Target Learners
- Learners preparing to apply knowledge in professional, social, or complex problem contexts.

### Target Learning Goals
- Support transfer, judgment, and context-sensitive application.
