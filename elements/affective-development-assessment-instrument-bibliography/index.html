Annotated bibliography of 27 instruments for assessing preschool affective development¶

Element · All elements
Evidence · no claims cited

Description¶

Chapter 3 of the report catalogs the available assessment instrumentation for measuring affective development in the preschool child, presented as a chart plus "an annotated bibliography on 27 instruments." The chapter covers types of assessment, the search procedure used to find instruments, and the organization of the chart, with the annotated bibliography describing each instrument. It serves the project objective to "Analyze available instrumentation for assessing affective development."
