# Data Analysis

> **Element** · [All elements](index.md)

## Description
Data analysis is the element in which learners inspect, interpret, organize, or transform data in order to answer questions, identify patterns, or justify conclusions. It is useful when evidence comes in quantitative, qualitative, or observational form.

## Design Implications

### Context
#### Requirements
- **A question that data can illuminate**
- **Relevant data and tools for interpretation**
#### Constraints
- **Learners may describe data patterns without connecting them to claims**

### Target Learning Goals
- Improve interpretation of evidence and support justified conclusions from data.
