# Early Learning in Mathematics (ELM) kindergarten core mathematics curriculum

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (2 for, 1 against) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
ELM is "a core mathematics program for kindergartners that provides 120 45-minute lessons, in addition to daily 15-minute calendar activities." It is designed to be delivered by the kindergarten teacher to a whole class, with calendar lessons schedulable separately or incorporated into morning circle/opening activities. The program qualified for the "Promising" evidence category based on one study of 2,116 students.

## Design Implications

### Context
#### Requirements
- Delivered by the kindergarten teacher to a whole class of students; calendar lessons can be scheduled separately or incorporated into morning circle/opening activities.
#### Constraints
- Evidence base is a single study; the review notes the +0.11 effect was not statistically significant at the cluster level.
