# Same-day MAP Growth retest dataset spanning four test types and four testing terms

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The study extracted MAP Growth Common Core test events in Reading 2-5, Reading 6+, Math 2-5, and Math 6+ from four testing terms: Fall 2017, Winter 2018, Spring 2018, and Fall 2018. Table 1 prints total test events ranging from 4,324,638 (Reading 6+) to 4,864,398 (Math 2-5), with retests within one day of 36,971 (Reading 2-5), 31,694 (Reading 6+), 16,106 (Math 2-5), and 16,938 (Math 6+), over 100,000 retests in total.

## Design Implications

### Context
#### Requirements
- RIT score with standard error and percent rapid guesses recorded for each test event
#### Constraints
- Analyses focused on retests within one day of the initial test event, which effectively ruled out changes in true achievement between the two test events

### Target Learners
- Students in grades 2-5 and 6+ taking MAP Growth Reading and Math tests

### Target Learning Goals
- Understanding the relationship between test-taking engagement and measured achievement
