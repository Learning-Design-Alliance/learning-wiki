# Goal Setting

> **Element** · [All elements](index.md)

## Description
Goal setting is the element in which learners or instructors establish clear targets for performance, progress, or improvement. It is useful when visible goals help focus effort, strategy choice, and persistence.

## Design Implications

### Context
#### Requirements
- **Specific targets**
- **Criteria or indicators for progress**
#### Constraints
- **Vague or unrealistic goals reduce usefulness**

### Target Learning Goals
- Focus effort, guide monitoring, and support persistence.
