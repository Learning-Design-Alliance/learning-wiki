# Project CRISS® professional development program for teachers of grades 3–12

## Description
Project CRISS® is "a professional development program for teachers that aims to improve reading, writing, and learning for 3rd- through 12th-grade students." It requires no curriculum change but a change in teaching style, embedding comprehension strategies such as using background knowledge, questioning, organizing graphically, and summarizing into regular instruction. Training runs from Level I (12–24 hours, $50–$200 per participant) to Level II certification for trainers, and participants receive a teacher resource guide. Related programs include CRISS for Administrators, Students, Parents, and Homeschool Parents.
