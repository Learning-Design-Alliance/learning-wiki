# Data infrastructure tools supporting rapid-cycle testing: Edtech Pilot Framework, TeamSpace, and Dynamic Learning Project

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The report describes three tools from Digital Promise's portfolio that provide infrastructure for piloting and data analytics. The Edtech Pilot Framework guides educators and product developers through an eight-step evidence gathering process with free online tools and videos. TeamSpace is a cloud-based analytics workspace helping educational organizations securely and collaboratively analyze complex data from one or more digital sources. The Dynamic Learning Project uses a Qualtrics platform with snapshot pre/post surveys, giving schools analyzed and visualized data at the end of each eight-week cycle.
