Free CBL resource set: global competence resources and Ciena Solutions Challenge supports including a Facilitation Guide and Challenge Builder¶

Element · All elements Evidence · no claims cited

Description¶

The presentation catalogs free supports for implementing CBL: global competence resources such as "UN SDG Project Examples", "Topic-Specific Projects", "Student Global Competence Modules", and "Free Online Courses for Educators", plus Ciena Solutions Challenge resources including a "Resource Library", "Facilitation Guide", "Challenge Builder", and "Video Learning Series".
