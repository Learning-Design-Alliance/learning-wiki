# Adaptive interim assessment with an automated disengagement-detection engagement feature

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article evaluates an adaptive interim assessment administered to K-12 students both in school and remotely. Its engagement feature "automatically paused the test event of a disengaged student and notified the test proctor," enabling proctors to intervene whether they were "in the same room as the student" or proctoring remotely. The study used disengagement on this assessment to compare remote and in-school testing contexts.

## Design Implications

### Context
#### Requirements
- Requires a test proctor, in the same room or remote, to receive notifications and respond when the feature pauses a disengaged student's test event.
#### Constraints
- Remote testing is less controlled than in-school testing, which raised the engagement concerns motivating the study.

### Target Learners
- K-12 students

### Target Learning Goals
- Valid measurement of student learning through low-stakes interim assessment with adequate test-taking engagement
