# Over My Shoulder (OMS) media: screen-capture videos, Flash animations and text instructions modeling instructor problem-solving

> **Element** · [All elements](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
OMS materials were videos of the instructor's computer screen with a think-aloud soundtrack, plus Flash animations using thought balloons, plus text-based instructions. They "purposefully included errors made by the instructor along with articulated problem-solving strategies," and were deliberately not skill tutorials. The three formats provided decreasing levels of scaffolding: videos the most, animations less, text the least. They were offered in three file formats and as CDs, DVDs or VHS tapes.

## Design Implications

### Context
#### Requirements
- Creation time using Camtasia screen-capturing software and Flash animation tools
- Multiple file formats and physical media options to accommodate student access
#### Constraints
- Large file sizes caused download waits of one to two hours for some students

### Target Learners
- Pre-service K–12 teacher education students in a Web-based course

### Target Learning Goals
- Modeling internal problem-solving and troubleshooting processes when creating educational media
