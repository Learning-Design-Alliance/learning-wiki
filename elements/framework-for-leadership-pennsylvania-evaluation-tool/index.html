Framework for Leadership (FFL), Pennsylvania's tool for evaluating principals' and assistant principals' leadership practices¶

Element · All elements Evidence · no claims cited

Description¶

The Framework for Leadership (FFL) is Pennsylvania's tool for evaluating the leadership practices of principals and assistant principals. It measures leadership practices across "four categories of leadership practices," each rated on a scale of "four possible performance levels." The report evaluated three psychometric properties: internal consistency via Cronbach's alpha, score variation across the rating scale, and concurrent validity via regression against estimated contributions to student achievement growth.

Context¶

Requirements¶

  • Rated by supervisors as part of a pilot evaluation of school leaders

Constraints¶

  • Interim findings from a 2012/13 pilot; the report concludes more validity evidence is needed before using FFL scores to identify effective and ineffective school leaders
