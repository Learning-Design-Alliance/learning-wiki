# Resource Hubs

> **Element** · [All elements](index.md)

## Description
Resource hubs are centralized collections of materials, links, tools, or references that learners can return to during a course or project. They are useful when learners need organized access to shared resources.

## Design Implications

### Context
#### Requirements
- **A clear organizational structure**
- **Materials that remain relevant across the task or unit**
#### Constraints
- **Large undifferentiated hubs can overwhelm learners**

### Target Learning Goals
- Improve access to needed resources and reduce search friction.
