# Cignition virtual group math tutoring program

> **Element** · [All elements](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (2 causal, 1 quant-synthesis), `q2`–`q3` · 1 of 3 report an effect size · 5 claims rest on one study

## Description
Cignition is a virtual math tutoring program delivering "live virtual one-on-one and group math tutoring using video conferencing and interactive tools." It uses "experienced educators as tutors" and provides "formative data for teachers and parents via an online platform." The evaluated configuration served groups of up to four 5th-grade students and was tested against a control condition in a randomized controlled trial measuring fractions knowledge, confidence, enjoyment, and student–tutor relationships.

## Design Implications

### Context
#### Requirements
- Experienced educators serving as tutors
- Video conferencing and interactive tools for live virtual sessions
- An online platform providing formative data for teachers and parents
#### Constraints
- The evaluated evidence covers 5th-grade students in group sessions of up to four students

### Target Learners
- 5th-grade students

### Target Learning Goals
- fractions knowledge
- math confidence
- math enjoyment
