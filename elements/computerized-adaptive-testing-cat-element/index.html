Computerized adaptive testing (CAT) as an assessment component¶

Element · All elements Evidence · 3 claims (3 for) · 2 studies (2 theoretical), q1 · 0 of 2 report an effect size · 3 claims rest on one study

Description¶

Computerized adaptive testing (CAT) is a technology-based assessment approach in which the test adjusts its questions as testing proceeds. The article introduces it as an approach "being used by increasing numbers of schools" and explains that it gives a more precise, accurate picture of achievement for both low-achieving and high-achieving students. It serves as the measurement component that produces the immediate results teachers use for differentiation.
