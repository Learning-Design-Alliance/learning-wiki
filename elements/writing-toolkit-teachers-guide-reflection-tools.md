# Teacher's Guide with activities, self-reflection, and goal-setting tools

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The Teacher's Guide contains activities to be completed during and between PLC sessions, extending the professional learning into teachers' own classrooms. It also includes self-reflection and goal-setting tools, and videos and lesson plans on the Toolkit website supplement the Teacher's Guide. This positions teacher self-reflection and goal setting as part of the professional development design.
