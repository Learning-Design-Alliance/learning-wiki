# Curated list of data repositories for classroom data collection

> **Element** · [All elements](index.md)

## Description
The session defines a data repository as "a place that holds data, makes data available to use, and organizes data in a logical manner," possibly a subject-specific location where researchers submit data. It supplies a linked list of repositories including data.gov, US Census Bureau, Google Trends, Kaggle, FiveThirtyEight, USGS, and Harvard Dataverse for teacher and student use.
