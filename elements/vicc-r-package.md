## Description
The vICC R package is the software implementation of the article's methods. The article states that "The methods are implemented in the R package vICC", making the Bayes factor test of homogeneous within-person variance and the membership model available to researchers working in R. It serves as the released artifact through which the individually varying ICC approach can be applied to hierarchical models of repeated-measures data.
