## Description
NWEA built interactive data visualizations to accompany the report on learning during COVID-19. As the page states, "Using data from schools all over the country, we’ve built these visualizations to explore three key questions" about fall performance, growth since closures, and comparison to projections. The visualizations are the artifact through which the report's findings on reading and math achievement are explored.
