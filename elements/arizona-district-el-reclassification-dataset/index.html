Large Arizona school district dataset for EL reclassification modeling¶

Element · All elements Evidence · 2 claims (2 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article's empirical application uses data from a large Arizona school district to fit and evaluate the shared random effects model. The dataset supports simultaneous estimation of English proficiency development and time to reclassification, and it is the basis for the reported 93% versus 85% accuracy comparison against a conventional discrete-time hazard model.
