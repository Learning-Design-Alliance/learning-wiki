## Description
The MAP® Growth™ National Dashboard is an NWEA data tool accompanied by a user guide and technical appendix. The guide "explains how to navigate the MAP® Growth™ National Dashboard, understand the key metrics and terms, make appropriate comparisons of data, and communicate findings responsibly," and includes "a robust 'Frequently Asked Questions' section." The technical appendix provides "more details of the data and describing more fully the sample and methods used within the dashboard."
