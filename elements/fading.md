# Fading

## Description
Fading is the element in which instructional support is deliberately reduced as learner competence grows. It is useful when the design goal is to transition from supported performance to independence without either over-supporting or abandoning learners too early.

## Design Implications

### Context
#### Requirements
- **An initial scaffold or model to reduce**
- **Evidence that the learner is ready for less support**
- **A planned progression from more support to less**
#### Constraints
- **Premature fading can trigger failure or overload**
- **Late fading can create dependence and redundancy**

### Target Learning Goals
- Support transfer of responsibility and increasingly independent performance.
