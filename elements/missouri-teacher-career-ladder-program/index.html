Missouri Teacher Career Ladder program¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

A state teacher performance-incentive program operating in Missouri since 1987, in which districts participate and teachers can earn career-ladder rewards. The article evaluates it as a district-level program using "longitudinal data on district math and reading scores for 524 Missouri school districts over a nine-year period," comparing participating with matched nonparticipating districts.
