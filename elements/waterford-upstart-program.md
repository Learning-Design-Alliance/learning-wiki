# Waterford Upstart early learning program

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 2 studies (2 causal), `q2` · 1 of 2 report an effect size · 4 claims rest on one study

## Description
Waterford Upstart is an early learning program for children in PreK–2 that "delivers daily 15–20 minute online lessons in reading, math, and science." It is designed for consistent weekly use at home, with families receiving progress updates and coach support, and it earned a Promising rating in the Academic Performance domain with an average effect size of +0.65 across 1,675 students.
