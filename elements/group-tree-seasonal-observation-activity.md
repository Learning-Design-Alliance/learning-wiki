# Group tree seasonal observation activity

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The group tree is a K-2 activity in which students draw a tree at various times during the year and observe how it changes across seasons, generating comparative data. The webinar instructs: "Draw a tree at various times during the year. Students will observe the changes throughout the seasons." It functions as a longitudinal observation and comparison task for young learners.
