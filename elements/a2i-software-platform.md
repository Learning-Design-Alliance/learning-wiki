# A2i Software Platform

> **Element** · [All elements](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 quant-synthesis), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The A2i Software Platform is described as "a key component of the A2i Professional Support System". It can be accessed on any device with a screen wider than 768 pixels (any full-sized screen). The online assessments are the only student-facing component and can be taken on most up-to-date tablets, Chromebooks, or laptops, while teacher-facing supports run on full-sized screens.

## Design Implications

### Context
#### Requirements
- Access requires a device with a screen wider than 768 pixels
- Student assessments require up-to-date tablets, Chromebooks, or laptops
#### Constraints
- The platform is not usable on screens narrower than 768 pixels

### Target Learners
- Pre-K through Grade 3 students

### Target Learning Goals
- Individualized literacy instruction and reading assessment
