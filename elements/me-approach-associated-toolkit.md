# M&E toolkit accompanying the four-phase approach

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The M&E approach ships with an associated toolkit that supports evidence building across the four phases. The publication states the "approach and associated toolkit provide a road map for generating evidence about new or evolving solutions." The toolkit operationalizes the phased approach so practitioners can tailor evidence generation to a solution's current stage of development.
