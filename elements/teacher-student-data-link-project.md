# Teacher-Student Data Link project supporting states in linking student and teacher data

## Description
The Teacher-Student Data Link (TSDL) project is an initiative contracted by the Bill & Melinda Gates Foundation with Mathematica to conduct an implementation study. The article states the project "aims to support states in developing best practices for linking student and teacher data to improve educational outcomes." Its first-year implementation findings (2011) are reported in this publication.

## Design Implications

### Context
#### Requirements
- State participation in developing data-linking practices
- Contracted implementation study support (Mathematica, Gates Foundation funding)
#### Constraints
- Findings reported cover only the project's first year of implementation (2011)

### Target Learners
- State education agencies
- K-12 students and teachers whose data are linked

### Target Learning Goals
- Effective data use in education
- Accurate linkage of student and teacher data for improving educational outcomes
