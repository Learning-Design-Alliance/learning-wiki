# IMSE's OG+ Structured Literacy foundational skills program

> **Element** · [All elements](index.md)

## Description
IMSE's OG+ is "a Structured Literacy core foundational skills program based on Orton-Gillingham principles" for whole-class, small-group, and one-on-one reading and spelling instruction in grades K–5. It uses multimodal techniques to build phonological awareness, phonics, fluency, vocabulary, and comprehension, and is implemented as the foundational skills component of a school's literacy block with lessons following "a consistent, cumulative progression."
