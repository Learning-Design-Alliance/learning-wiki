# Authentic Instructional Assessments (AIA)

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
Authentic Instructional Assessments are "a detailed procedure and rubric for examining assessments and assignments" used by each of the three case-study schools to monitor instructional practice. The system provided a concrete blueprint for giving and receiving feedback among department colleagues, and CHSRI conducted workshops for all schools on using the process, which these three schools continued using beyond the initial training.
