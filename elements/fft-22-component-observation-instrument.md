# Framework for Teaching (FFT) observation instrument with 22 components scored into four domains and an overall Professional Practice Rating

> **Element** · [All elements](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (2 associational), `q2` · 1 of 2 report an effect size · 5 claims rest on one study

## Description
The Framework for Teaching of Charlotte Danielson is an observation-based teacher performance measure whose "22 components" each "is designed to capture a separate teaching practice." The pilot used observation data to estimate four domain scores and one overall Professional Practice Rating (PPR) score, which were merged with value-added measures based on student test scores for analysis.

## Design Implications

### Context
#### Requirements
- Classroom observation data describing teacher performance on the 22 FFT components, plus student test-score data to compute value-added measures for validity analysis
#### Constraints
- As piloted in Pennsylvania districts including Pittsburgh public schools during the 2010-2015 evaluation pilot

### Target Learners
- K-12 teachers in Pennsylvania public school districts

### Target Learning Goals
- Measuring teaching practice across planning, instruction, and classroom domains for educator evaluation
