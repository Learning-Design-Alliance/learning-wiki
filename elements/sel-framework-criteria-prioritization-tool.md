# Criteria prioritization tool for SEL framework selection

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The brief includes a tool, printed as a low/medium/high priority rating grid on its penultimate page, that practitioners use to rate each of the ten criteria by priority for their own context. The brief states: "A tool at the end of this brief encourages you to prioritize these criteria based on your context and practice needs." It supports the recommended workflow of building a priority profile before evaluating candidate frameworks.
