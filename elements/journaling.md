# Journaling

> **Element** · [All elements](index.md)

## Description
Journaling is the element in which learners record reflections, observations, questions, or progress over time in written form. It is useful when learning benefits from continuity, introspection, and visible documentation of change.

## Design Implications

### Context
#### Requirements
- **A recurring prompt or purpose**
- **Time and psychological safety for honest writing**
- **A reason to revisit or use prior entries**
#### Constraints
- **Can become performative if prompts are generic or over-evaluated**
- **Heavy grading can suppress candor**

### Target Learners
- Learners building self-awareness, reflective habits, and longitudinal understanding.

### Target Learning Goals
- Support reflection, synthesis, and noticing change over time.
