# Oriented semantic network: linear ordering of the semantic network treated as psychological rather than grammatical

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The oriented semantic network is the second segment, produced when the semantic network "is put in some linear order." Labov treats this ordering as "a psychological matter more than a grammatical matter," allowing any of the possible orderings of a network; each legitimate ordering gives rise to some corresponding sentence, such as a passive for one ordering of the boy-hurt-father network.
