# Promise Neighborhoods Case Studies: a 2014-2015 multi-site profile project for the Promise Neighborhoods Institute at PolicyLink

> **Element** · [All elements](index.md)

## Description
Promise Neighborhoods Case Studies is the associated project under which this site profile was produced, with a stated time frame of 2014-2015. The work was "Prepared for: Promise Neighborhoods Institute at PolicyLink" and conducted by Mathematica Policy Research, whose site profiles document how individual Promise Neighborhood sites define boundaries, draw on partnerships, and expand service models across communities.

## Design Implications

### Context
#### Requirements
- Access to implementation sites for case-study documentation

- Profiles cover the 2014-2015 time frame and describe site decisions rather than measuring outcomes

### Target Learners
- children and families served by Promise Neighborhoods sites

### Target Learning Goals
- documenting implementation of cradle-to-career community initiatives
