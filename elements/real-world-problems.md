# Real-World Problems

## Description
Real-world problems are tasks framed around authentic issues, needs, or dilemmas outside purely academic abstraction. They are useful when learners need to see relevance and apply knowledge in contexts that resemble actual use.

## Design Implications

### Context
#### Requirements
- **A problem with real stakes, constraints, or context**
- **A clear connection between the problem and the learning goals**
#### Constraints
- **Artificial “real-world” framing can feel contrived if the problem does not actually matter**

### Target Learning Goals
- Support application, transfer, and learner investment through authentic context.
