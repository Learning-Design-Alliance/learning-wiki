# Multimedia Instruction

## Description
Multimedia instruction is the element in which teaching combines spoken or written language with visuals, diagrams, animation, or other media in a coordinated instructional sequence. It is useful when multiple representations clarify explanation and support comprehension.

## Design Implications

### Context
#### Requirements
- **Intentional coordination of media**
- **Instructional use of media that supports the target understanding**
#### Constraints
- **Extra media can distract if it is not aligned**

### Target Learning Goals
- Improve explanation and comprehension through coordinated multimodal instruction.
