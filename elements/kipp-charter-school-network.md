# KIPP: a network of charter middle schools for disadvantaged students evaluated over multiple years

> **Element** · [All elements](index.md)

## Description
The Knowledge Is Power Program (KIPP) is described as "a network of charter schools for disadvantaged students." The evaluation covered 22 KIPP middle schools as the first findings of a multi-year study (associated project time frame 2007-2017), prepared for Arnold Ventures by Mathematica Policy Research using a matched comparison group design to estimate achievement impacts.
