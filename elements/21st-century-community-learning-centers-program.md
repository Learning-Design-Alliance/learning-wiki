# 21st Century Community Learning Centers after-school program

## Description
The 21st Century Community Learning Centers program is a national after-school initiative in which schools stay open late to serve students. The national evaluation compared elementary students participating in the program with students not enrolled, examining safety feelings, negative behaviors, achievement, and homework assistance or completion. The evaluation summary states "There were few impacts on student achievement overall" for this program.
