# ALF (Augmented Lectures Feedback System): AR glasses displaying student understanding symbols for teachers

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
ALF is an AR-based classroom feedback system developed by Zarraonandia and colleagues (2019) as reported in the review. "ALF, utilized by teachers wearing AR glasses, displayed virtual symbols above students' heads to depict their understanding in real time or responses to questions." Students selected their status and responded via mobile phones, enabling anonymous contributions. The review reports the real-classroom study showed promising results for communication and class adaptation, fostering increased participation and engagement.
