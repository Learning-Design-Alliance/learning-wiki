# Prior Knowledge Activation

## Description
Prior knowledge activation is the element in which learners recall, surface, or organize what they already know before engaging with new material. It is useful when new learning depends on connection to existing ideas or experiences.

## Design Implications

### Context
#### Requirements
- **A prompt that surfaces relevant prior knowledge**
- **A connection between recalled knowledge and the new task**
#### Constraints
- **Activated misconceptions may need correction, not just recall**

### Target Learning Goals
- Prepare learners to connect new material to what they already know.
