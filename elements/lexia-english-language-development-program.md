# Lexia English Language Development program

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
A blended learning program designed to accelerate academic English proficiency for English Learners in grades K–6. It integrates interactive, student-directed online lessons with teacher-led instruction focused on oral language, grammar, and vocabulary, using speech recognition to give immediate feedback as students practice listening and speaking across 19 content-based levels. Teachers receive real-time progress data and small-group lesson plans aligned with English Language Development state standards.
