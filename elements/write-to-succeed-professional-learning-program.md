# Write to Succeed professional learning program for literacy instruction

> **Element** · [All elements](index.md)
> **Evidence** · 6 claims (6 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 6 claims rest on one study

## Description
Write to Succeed is a professional learning program that the SWELL partnership will "iteratively enhance and test" to "help teachers improve their literacy instruction." The partnership adapts, implements, and refines the program across 2023/24 through 2025/27, adding enhancements for teacher collaboration and culturally and linguistically relevant instruction before statewide scale-up.

## Design Implications

### Context
#### Requirements
- Recruitment sufficient to support implementation as planned
- District- and NMPED-based coaches who are effective instructional coaches
#### Constraints
- Key assumptions state that short-, medium-, and long-term outcomes must be realized within the REL Southwest contract period

### Target Learners
- New Mexico teachers of English learner students

### Target Learning Goals
- Literacy instruction
- Supporting English learner students
- Culturally and linguistically relevant instruction
