## Description
New Heights is described as "a voluntary school-based program that provides a well-defined system of supports for expectant and parenting students in Washington, DC". The program operates within schools and targets expectant and parenting youth, and it was evaluated for its effects on educational outcomes. This page summarizes a study of the program elements and practices behind its measured success.
