Technical appendix documenting dashboard data, sample, and methods¶

Element · All elements Evidence · no claims cited

Description¶

This technical appendix accompanies the MAP Growth National Dashboard. Per the page, it provides "more details of the data and describing more fully the sample and methods used within the dashboard," serving as the methodological documentation for the dashboard's national growth and achievement estimates. It is authored by Karyn Lewis and Megan Kuhfeld and dated September 2026.
