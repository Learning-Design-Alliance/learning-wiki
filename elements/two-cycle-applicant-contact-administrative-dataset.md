## Description
The study's data source is a comprehensive administrative record from a medium-sized highly selective university. The article describes using "unique and comprehensive administrative data, which include all contacts made by each applicant to the admissions office" during two admission cycles. This dataset links applicant contact behavior to admission outcomes and underpins the article's findings on demonstrated interest.
