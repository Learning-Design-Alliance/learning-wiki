The Expert Mathematician: a Logo-based generative mathematics curriculum with 196 lessons¶

Element · All elements Evidence · 3 claims (2 for, 1 mixed) · 1 study (1 causal), q3 · 1 of 1 report an effect size · 3 claims rest on one study

Description¶

The Expert Mathematician is a three-year middle school mathematics program combining computer software with consumable print materials. It uses "196 lessons that teach the Logo programming language," each lasting 40–120 minutes (one to three class periods), with a test of unit concepts at the end of each instructional unit. The developer built it with LogoWriter, covering general mathematics, pre-algebra, and algebra I, and describes it as covering the concepts in the NCTM Curriculum and Evaluation Standards.

Claims¶

  • Random assignment in the Baker (1997) trial produced pretest differences favoring the comparison curriculum, controlled by using the pretest as a covariate [~W]
  • The Expert Mathematician shows a positive but not statistically significant effect on middle school math achievement (effect size 0.35, improvement index +14 percentile points) [+W]
  • The WWC rates The Expert Mathematician as having potentially positive effects on middle school mathematics achievement [+W]
