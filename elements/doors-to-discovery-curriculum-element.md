# Doors to Discovery™ preschool literacy curriculum with eight thematic units and shared literacy

> **Element** · [All elements](index.md)
> **Evidence** · 4 claims (2 for, 2 mixed) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
Doors to Discovery™ is a preschool literacy curriculum distributed by Wright Group/McGraw-Hill, built on eight thematic units (e.g., Backyard Detectives; Build it Big!; Healthy Me!; Vroom! Vroom!) targeting oral language, phonological awareness, concepts of print, alphabet knowledge, writing, and comprehension. Its focus is "shared literacy," in which adults and children work together on literacy skills, using techniques such as cloze, student retelling, think alouds, and scaffolding within literacy-enriched learning centers. The complete set cost $2,654.25, with theme kits at $371.37 each.
