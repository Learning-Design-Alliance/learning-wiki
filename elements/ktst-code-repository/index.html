KTST released code repository¶

Element · All elements Evidence · 4 claims (3 for, 1 against) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The authors released implementation code for knowledge tracing set transformers. The article states: "Code is available at github.com/kainbr/kt_set_transformers." The repository accompanies the KTST model class, its three set-based interaction embeddings, and the learnable ALiBi attention mechanism, and is intended to support the article's position that KTSTs are easy to implement and may serve as a foundation for future research in knowledge tracing and intelligent tutoring systems.

Claims¶

  • KTST performance gains over baselines using the expanded representation are most pronounced on datasets with high knowledge-component-to-question ratios [+W]
  • KTST models achieve state-of-the-art AUC results on pyKT benchmark datasets except Statics2011 [+W]
  • Learnable ALiBi with query equal to key in cross-attention is the best-performing attention configuration for KTSTs [+W]
  • Replacing Rasch embeddings with mean set embeddings under AKT's attention improves AUC on AS2009, evidence against the expanded representation [-W]
