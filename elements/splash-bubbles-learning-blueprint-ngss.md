# Learning blueprint aligned to NGSS

## Description
A learning blueprint developed to guide the design of all project resources, including the app and research instrumentation. It outlined science content learning goals for children "aligned to the Disciplinary Core Ideas identified in the Next Generation Science Standards (NGSS)" and science practice learning goals aligned to skills identified across the NGSS and Head Start Frameworks, serving as an anchor throughout development.
