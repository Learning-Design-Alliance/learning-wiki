# Children's Progress Academic Assessment (CPAA)

> **Element** · [All elements](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The CPAA is "a computerized, adaptive assessment" integrated into teachers' practice in preschool classrooms as a key ELTM feature. It "assesses literacy and mathematical skills" and is intended to complement the DRDP-PS teacher rating, expanding the information available to teachers and parents about children's progress.

## Design Implications

### Context
#### Requirements
- Integration into preschool classroom teachers' practice
#### Constraints
- Intended as a complement to the DRDP-PS, not a replacement

### Target Learners
- preschool children ages 3 to 5

### Target Learning Goals
- literacy and mathematical skills
