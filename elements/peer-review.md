# Peer Review

## Description
Peer review is the element in which learners examine and respond to one another's work using shared criteria, prompts, or examples. It can improve drafts directly, but it is also valuable because evaluating peer work often sharpens learners' own judgment about quality.

## Design Implications

### Context
#### Requirements
- **Clear criteria**: Reviewers need guidance on what to notice and comment on.
- **Structured prompts**: Specific feedback stems or rubrics improve consistency and usefulness.
- **Revision opportunity**: The reviewed work should be revisable after feedback.
#### Constraints
- **Low trust or weak norms**: Learners may avoid candor or overcorrect each other.
- **Uneven expertise**: Peers need support to give accurate, actionable feedback.
- **Social risk**: Public criticism can suppress participation if norms are weak.

### Target Learners
- Learners revising visible work products and developing evaluative judgment.

### Target Learning Goals
- Improve drafts, strengthen criteria use, and develop feedback literacy.
