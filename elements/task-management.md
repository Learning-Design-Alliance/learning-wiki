# Task Management

## Description
Task management is the element in which learners organize, track, assign, or sequence work across a project or collaborative activity. It is useful when success depends on planning and coordination, not just content knowledge.

## Design Implications

### Context
#### Requirements
- **A multi-step task or project**
- **A way to track responsibilities, deadlines, or progress**
#### Constraints
- **Overhead can become excessive if the management system is more complex than the task**

### Target Learning Goals
- Improve planning, coordination, and follow-through.
