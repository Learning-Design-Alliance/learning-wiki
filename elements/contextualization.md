# Contextualization

> **Element** · [All elements](index.md)

## Description
Contextualization is the element in which new ideas, texts, or tasks are framed within a meaningful situation, purpose, domain, or prior experience. It is useful when learners need to understand why something matters before they can engage with it deeply.

## Design Implications

### Context
#### Requirements
- **A meaningful context connected to the target learning**
- **Explicit links between the context and the new content**
#### Constraints
- **Weak or decorative context adds little instructional value**

### Target Learning Goals
- Improve relevance, comprehension, and transfer by situating learning in a meaningful frame.
