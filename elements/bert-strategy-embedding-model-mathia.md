## Description
A BERT-based model the authors train to learn embeddings for math strategies from MATHia student log data, together with a prediction task that distinguishes between successful and unsuccessful strategy use. The authors analyze the model's results to reveal deeper insights into student strategies. Code for the fine-tuned BERT model is released in a public GitHub repository.
