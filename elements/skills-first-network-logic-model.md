# Skills-first network logic model

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The report provides a logic model intended as an action guide for building an aligned skills-first system. It states the logic model "builds on the aforementioned guiding principles/key elements and provides a roadmap for the strategic planning and essential pathways that various stakeholders can take to ensure an accessible, opportunity-driven, and outcome-oriented skills-first system." The model organizes inputs (e.g., existing skills-first frameworks, funding, technology platform access), activities (e.g., facilitating cross-sector collaboration, providing technical assistance), outputs (e.g., worker advisory council, shared resource library), and outcomes (e.g., enhanced career and economic mobility opportunities).
