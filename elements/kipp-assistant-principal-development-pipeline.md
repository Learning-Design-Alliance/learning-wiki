# KIPP assistant principal development pipeline

> **Element** · [All elements](index.md)

## Description
An organizational element of KIPP, described in this publication as the largest charter school network in the country. It consists of identifying principal candidates "primarily from a talent pool of assistant principals" and layering on strategies that turn the assistant principal experience into a structured program for developing the skills required to serve as a school's top administrator. The publication presents it as KIPP's response to the principal demand created by its growth.
