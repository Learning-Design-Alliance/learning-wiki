# Sound Partners phonics-based tutoring program

> **Element** · [All elements](index.md)

## Description
Sound Partners is "a phonics-based tutoring program that provides supplemental reading instruction to elementary school students grades K–3 with below average reading skills." It consists of scripted lessons in alphabetic and phonics skills emphasizing letter-sound correspondences, phoneme blending, decoding and encoding phonetically regular words, and reading irregular high-frequency words, with oral reading practice in Bob Books® decodable texts. It is designed for tutors with minimal training and can be delivered as pull-out, after-school, or homeschool tutoring.
