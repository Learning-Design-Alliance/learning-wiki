# ArgumentPeer project: argument diagramming with peer review and intelligent help

> **Element** · [All elements](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (3 review), `q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The primer describes the ArgumentPeer project as a technology example in which "students relate hypotheses and claims in an argument diagram and submit them online for review by their peers, each of whom is randomly assigned a set of arguments to review". An intelligent help system prompts students as they draw diagrams and write reviews, and reviewers who have read the same sources critique each other's arguments while refining their own knowledge.

## Design Implications

### Context
#### Requirements
- Students read the same sources and prepare their own argument diagrams before reviewing
#### Constraints
- The primer presents this as one example of technology and AI techniques supporting argument construction and critique

### Target Learners
- Students in technology-supported science learning settings

### Target Learning Goals
- Constructing and critiquing arguments
- Refining knowledge through peer review
