School-based coaching and support for using student data to inform instruction¶

Element · All elements

Description¶

The evaluated intervention is a set of coaching and support services delivered to schools to help teachers use student data when planning instruction. The page describes it as "providing coaching and support to schools to help them use student data to inform teachers' instruction." It was studied as part of an IES-funded evaluation running from 2012 to 2019, prepared for the U.S. Department of Education's Institute of Education Sciences.
