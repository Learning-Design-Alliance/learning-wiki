# Chicago TAP evaluation project (2006-2012), prepared for the Joyce Foundation

## Description
The evaluation of the Chicago Teacher Advancement Program was a multi-year project with a stated time frame of 2006-2012, prepared for the Joyce Foundation and conducted by Mathematica Policy Research. The project produced this Year Two Impact Report, whose abstract notes that "The TAP model offers teachers performance pay, professional development, and advancement opportunities based in part on their students' achievement growth." The project sits within Mathematica's Teacher and Principal Effectiveness area of work.
