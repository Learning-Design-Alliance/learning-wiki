Digital Literacy¶

Learner Variable · All learner variables Evidence · 47 claims (34 show a difference, 6 mixed, 7 no difference) · 40 studies (15 associational, 9 causal, 5 qualitative, 4 review, 3 quant-synthesis, 3 design, 1 theoretical), q1–q4 · 8 of 40 report an effect size · 45 claims rest on one study

Description¶

Whether a learner can operate the interface — distinct from access, which is whether they can load it at all. It covers navigation, file handling, knowing what is clickable, and the confidence to explore without fear of breaking something. Every course here is delivered digitally, so this is never out of scope, and it is the dimension most often assumed away: a designer fluent in the interface cannot see it.

Implications¶

Context¶

  • Decides whether an interaction needs a walkthrough before it needs content, and how much of the UI can be assumed.
  • Interacts with cognitive load: an unfamiliar interface consumes the working memory the task needed [~M].
  • Not age-determined. Fluency with consumer apps does not transfer to file systems, forms, or academic tools.

Target Learners¶

  • Adult and returning learners, for whom this is the dimension most likely to be underestimated.
  • Anyone meeting a genre of interaction for the first time — a simulation, a code editor, an annotation tool.

Target Learning Objectives¶

  • Gates every other outcome in a digital course: a learner who cannot operate the tool produces no evidence of anything else.
  • Affects measured performance without affecting the underlying competence, so it is a validity threat as much as a learning one.

The evidence by question¶

  • Do learners who differ in digital literacy differ in learning, engagement and later outcomes? Digital skills gaps span demographic groups and shape e-learning, job performance, and earnings [+M]
  • Does explicit instruction raise learners' AI and digital literacy, and for whom? AI literacy interventions show a large, statistically significant overall positive effect on student AI literacy outcomes (g = 0.837) [+M]

Related Learner Variables¶

  • Access — whether they can load it, as against whether they can drive it.
  • Working memory — an unfamiliar interface spends the same limited resource the task needs.
  • Affect regulation — fear of breaking something suppresses the exploration that builds fluency.

Examples¶

  • Address Digital Literacy — explicit instruction in the tool before instruction through the tool
  • Digital Literacy Instruction — builds the operating competence as content rather than assuming it
  • Accommodate Varying Technology Experience — designs for a spread rather than a modal user
  • Address Technology-Related Fears — targets the affective barrier that keeps a learner from exploring
  • Navigator-Tourist Peer Learning — pairs learners so operating the tool is shared, not a private failure
  • Hypertext Navigation — the element whose demands this variable is about
  • Self-Paced Learning — lets interface fluency and content pace decouple
