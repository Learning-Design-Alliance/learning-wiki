Long-Term Memory¶

Learner Variable · All learner variables
Evidence · 80 claims (54 show a difference, 18 mixed, 8 no difference) · 54 studies (22 causal, 12 review, 11 quant-synthesis, 4 associational, 3 theoretical, 2 qualitative), q1–q4 · 21 of 54 report an effect size · 73 claims rest on one study

Description¶

Long-term memory holds information, such as words, facts, events, concepts and procedures, so that it can be retrieved and used later, over spans from hours to decades, and in principle indefinitely. Skills and knowledge get there through repeated practice and use, and stay accessible while they continue to be used. It matters for learning because what is stored there is the base for everything that follows: the prior knowledge and vocabulary that support reading and writing, and the arithmetic facts and procedures that free a learner to work on new mathematics problems. It develops through childhood and adolescence as the brain systems supporting it mature, and older learners lean more on memory-based strategies, for example in mathematics. It is measured with standardised memory batteries that ask learners to recall stories, lists or figures after a delay. It is distinct from working memory, which holds information briefly while it is being used; rehearsal and use move material from one to the other.

Implications¶

Context¶

  • Spaced, repeated practice and use is how skills and facts become durable.
  • Background knowledge and vocabulary carried in memory shape how well new reading and problems are understood.
  • Sleep, exercise and fewer distractions at retrieval all bear on what is stored and recalled.

Target Learners¶

  • Every age group; children building early reading and number facts, and adults drawing on accumulated knowledge.
  • Learners whose memory may be affected by trauma, sleep loss or poor health.

Target Learning Objectives¶

  • Retention of knowledge and skills over time.
  • Reading comprehension, writing, arithmetic fluency and problem solving that depend on stored knowledge.

Measures¶

  • Wechsler Memory Scale (WMS) (Wechsler, 2010): its logical memory subtest asks for details of a story heard once, as a measure of declarative memory.
  • Children's Memory Scale (CMS) (Cohen, 1997): assesses long- and short-term memory in verbal, visual and attention domains for ages 5 to 16.
  • Test of Memory and Learning (TOMAL) (Reynolds & Voress, 2007): measures verbal, nonverbal and composite memory for ages 5 to 59.

Related Learner Variables¶

  • Adverse Experiences: childhood trauma is linked with changes in brain structures that form long-term memories.
  • Affect Regulation: emotion colours which experiences are stored and recalled.
  • Sleep: sleep consolidates newly learned material into long-term memory.
  • Working Memory: rehearsal moves information from short-term into long-term memory.
  • Executive Function: inhibition helps encode and retrieve the right information by suppressing competing meanings.
  • Prior Knowledge: relevant background knowledge helps new experiences get encoded.
  • English-Learner Status: bilingual learners may show an advantage in recalling verbal material.
  • Attention: attention guides what is retained, and distraction weakens retrieval.
  • Physical Well-Being: exercise before learning can help encoding.
  • Processing Speed: weak representations in memory slow retrieval and processing.
  • Academic and Critical Literacy: acquiring academic literacies depends on storing and retrieving what is learned.
  • Interest: curiosity can strengthen memory for new information.
