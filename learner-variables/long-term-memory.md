## Description
Long-term memory holds information, such as words, facts, events, concepts and procedures, so that it can be retrieved and used later, over spans from hours to decades, and in principle indefinitely. Skills and knowledge get there through repeated practice and use, and stay accessible while they continue to be used. It matters for learning because what is stored there is the base for everything that follows: the [prior knowledge](prior-knowledge.md) and vocabulary that support reading and writing, and the arithmetic facts and procedures that free a learner to work on new mathematics problems. It develops through childhood and adolescence as the brain systems supporting it mature, and older learners lean more on memory-based strategies, for example in mathematics. It is measured with standardised memory batteries that ask learners to recall stories, lists or figures after a delay. It is distinct from [working memory](working-memory.md), which holds information briefly while it is being used; rehearsal and use move material from one to the other.

## Implications

### Context
- Spaced, repeated practice and use is how skills and facts become durable.
- Background knowledge and vocabulary carried in memory shape how well new reading and problems are understood.
- Sleep, exercise and fewer distractions at retrieval all bear on what is stored and recalled.

### Target Learners
- Every age group; children building early reading and number facts, and adults drawing on accumulated knowledge.
- Learners whose memory may be affected by trauma, sleep loss or poor health.

### Target Learning Objectives
- Retention of knowledge and skills over time.
- Reading comprehension, writing, arithmetic fluency and problem solving that depend on stored knowledge.

## Measures
- **Wechsler Memory Scale (WMS)** (Wechsler, 2010): its logical memory subtest asks for details of a story heard once, as a measure of declarative memory.
- **Children's Memory Scale (CMS)** (Cohen, 1997): assesses long- and short-term memory in verbal, visual and attention domains for ages 5 to 16.
- **Test of Memory and Learning (TOMAL)** ([Reynolds & Voress, 2007](https://doi.org/10.5014/ajot.63.4.433)): measures verbal, nonverbal and composite memory for ages 5 to 59.

## Related Learner Variables
- [Adverse Experiences](adverse-experiences.md): childhood trauma is linked with changes in brain structures that form long-term memories.
- [Affect Regulation](affect-regulation.md): emotion colours which experiences are stored and recalled.
- [Sleep](sleep.md): sleep consolidates newly learned material into long-term memory.
- [Working Memory](working-memory.md): rehearsal moves information from short-term into long-term memory.
- [Executive Function](executive-function.md): inhibition helps encode and retrieve the right information by suppressing competing meanings.
- [Prior Knowledge](prior-knowledge.md): relevant background knowledge helps new experiences get encoded.
- [English-Learner Status](english-learner-status.md): bilingual learners may show an advantage in recalling verbal material.
- [Attention](attention.md): attention guides what is retained, and distraction weakens retrieval.
- [Physical Well-Being](physical-wellbeing.md): exercise before learning can help encoding.
- [Processing Speed](processing-speed.md): weak representations in memory slow retrieval and processing.
- [Academic and Critical Literacy](academic-and-critical-literacy.md): acquiring academic literacies depends on storing and retrieving what is learned.
- [Interest](interest.md): curiosity can strengthen memory for new information.
