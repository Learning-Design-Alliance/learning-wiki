# Prior Knowledge

## Description
A learner's existing domain knowledge in the subject area before instruction begins — typically measured via a pretest, self-report, or standardized prior-achievement score. Prior knowledge is conceptually related to [Expertise Reversal Effect](../theories/expertise-reversal-effect.md): the level of prior knowledge/expertise a learner brings is what changes which instructional techniques help versus hinder them.

## Implications

### Context
- Typically measured before the instructional intervention begins, so it can be used as a covariate or grouping variable rather than an outcome.

### Target Learners
- All learners — this is a population-wide variable, not specific to one subgroup.

### Target Learning Objectives
- Predicting which learners benefit from a given instructional design, and which need a different approach.
