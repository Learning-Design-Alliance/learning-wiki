## How to add a source

Create a file in `sources/` using the Source template in [CLAUDE.md](/CLAUDE.md).

Source pages are created when a claim or principle cites a specific paper or book. Each source page needs: full citation, DOI/URL, a 2–4 sentence summary, and links to claim pages the source supports.
