# Journaling

## Description
Journaling is the pattern-level target for recurring written reflection used to track learning, sensemaking, or growth over time.

## Implications

### Context
#### Requirements
- **A recurring prompt or focus**
- **Time and continuity**
#### Constraints
- **Can become formulaic if prompts are too generic**
#### Grain Size
- Lesson
- Unit

### Target Goals
- Support reflection, synthesis, and self-monitoring over time.

### Target Learners
- Learners benefiting from longitudinal reflective writing.
