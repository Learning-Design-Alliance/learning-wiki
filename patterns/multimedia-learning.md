# Multimedia Learning

## Description
Multimedia Learning is the short-form canonical target for patterns that combine verbal and visual media in intentionally coordinated ways to support understanding.

## Implications

### Context
#### Requirements
- **Coordinated use of words and visuals**
- **Attention to how media choices affect comprehension**
#### Constraints
- **More media is not automatically better**
#### Grain Size
- Lesson

### Target Goals
- Improve comprehension through well-aligned multimodal representation.
