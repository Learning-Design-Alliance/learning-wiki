# Flipped Learning

## Description
Flipped Learning is a pattern that moves some initial content exposure outside class so synchronous time can be used for application, discussion, and feedback. This page serves as the canonical short-form target for links that refer to the flipped model under the broader "flipped learning" label.

## Implications

### Context
#### Requirements
- **Accessible pre-class materials**
- **Clear connection between preparation and class activity**
- **Active in-class design**
#### Constraints
- **Preparation compliance is variable**
- **Access inequities can weaken the model**
- **Moving lecture out of class is not enough by itself**
#### Grain Size
- Lesson
- Course

### Target Goals
- Better use of synchronous time.
- Replayable initial exposure before class.
- More guided application during class.

### Target Learners
- Learners who benefit from replayable inputs and interactive class time.

### Theory
#### Supporting
- Active-learning and blended-learning perspectives.
- Self-regulated learning perspectives.
#### Contradicting / Qualifying
- The quality of the in-class redesign matters more than the label.

- [[claims/self-monitoring-improves-self-regulation]] [~M]

## Design

### Sequence
1. Assign pre-class exposure to key content.
2. Check preparation briefly.
3. Use class for problem solving, discussion, and feedback.
