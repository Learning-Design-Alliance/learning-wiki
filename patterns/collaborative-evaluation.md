# Collaborative Evaluation

## Description
A structured learning activity where a group of learners evaluates resources, applies shared criteria, and reaches a consensus on quality or effectiveness.

## Implications

### Context
#### Requirements
- Requires a collection of resources, clear evaluation criteria, and a structured discussion environment
#### Constraints
- Requires active participation from all learners; Groupthink can occur if not facilitated well
#### Grain Size
Unit, Lesson
