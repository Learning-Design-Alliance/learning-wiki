# Goal-Based Scenarios

## Description
Goal-Based Scenarios organize learning around a mission or role-based objective pursued inside a realistic scenario. This page serves as the canonical short-form pattern target for references that point to the GBS family without the explicit acronym.

## Implications

### Context
#### Requirements
- **A meaningful mission**
- **A realistic scenario with consequences**
- **Just-in-time supports and feedback**
#### Constraints
- **High design burden**
- **Weak authenticity undermines engagement**
- **Novices may need more scaffolding**
#### Grain Size
- Unit
- Course

### Target Goals
- Contextualized decision making.
- Transfer through realistic application.

### Target Learners
- Learners preparing for scenario-based or role-based performance.

### Theory
#### Supporting
- Situated learning perspectives
- Experiential learning perspectives
#### Contradicting / Qualifying
- Scenario immersion alone does not guarantee learning without debrief and support.

### Claims
- [[claims/whole-task-performance-improves-transfer]] [+S]
- [[claims/contingent-scaffolding-improves-learning]] [~M]

## Design

### Sequence
1. Present a mission inside a realistic scenario.
2. Let learners make decisions and gather information.
3. Provide consequences, feedback, or coaching.
4. Debrief decisions and connect them to future use.
