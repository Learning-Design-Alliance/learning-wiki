# Explicit Instruction in Historical Contextualization

## Description
This pattern operationalizes [Historical Reasoning Framework](../theories/historical-reasoning-framework.md)'s contextualization aspect as a two-part instructional sequence within a CLIL (Content and Language Integrated Learning) history course. Part one gives students a *reason* to engage with historical background knowledge, using discussion-based case studies (students decide how a fictional historical actor would have acted given provided context, then defend the decision) and a quote-sorting activity (unattributed primary-source quotes sorted into the correct historical period using only evidence in the quote). Part two targets the separate *procedural* skill of writing contextualization effectively: modeling via annotated sample essays with guiding questions ("what did this essay forget to account for?"), paired-paragraph comparison (with and without effective contextualization), and focused language practice for chronological phrasing ("for at least 500 years," "before the Empire began") and connective phrasing ("this demonstrates...", "it is reasonable to conclude that..."). In the source study, this pattern improved unexpected downstream aspects of writing (claim quality, explicit connection-making, contextualization placement) without moving the contextualization rubric score itself — see the linked claim for the full, more cautious pattern of results.

## Implications

### Context
#### Requirements
- A course topic with genuine period-contrast material (e.g., a political-system transition) so that quote-sorting and case studies have real discriminating content to work with
- Sufplemental language scaffolding capacity if learners are L2/multilingual, since chronological and causal-connective phrasing is a separate skill from historical content knowledge
#### Constraints
- In the one controlled test of this pattern, explicit contextualization instruction did **not** significantly improve contextualization rubric scores relative to a content-matched active control — see [Explicit contextualization instruction improves procedural aspects of historical writing without improving contextualization scores themselves](../claims/explicit-contextualization-instruction-improves-writing-procedure-not-scores.md) [-M]
- Requires around 28 instructional hours to implement as tested; effectiveness of a substantially shorter version is untested

## Design

### Sequence
1. **Case studies (discussion-based)**: Students answer guided questions about provided historical background for a fictional historical actor, then independently argue how that actor would have acted, defending their position with the background context.
2. **Quote-sorting**: Students sort unattributed primary-source quotes into the correct historical period using only internal evidence, forcing active retrieval and comparison of period characteristics.
3. **Text models with guided questions**: Students evaluate sample document-based-question (DBQ) essays against guiding questions targeting contextualization placement and completeness.
4. **Paired-paragraph comparison**: Students compare parallel paragraphs with and without effective contextualization to see its argumentative function directly.
5. **Focused language practice**: Explicit practice with chronological-duration/sequence phrasing and evidence-connective phrasing, plus a quote-sorting extension requiring students to justify sorting decisions using this language.

### Affordances

### Personalization
- Where L1 (native-language) students are the audience, the focused-language-practice component can likely be reduced or dropped, since it targets an L2-specific hurdle; this has not been tested.
