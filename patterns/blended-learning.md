# Blended Learning

## Description
Blended Learning is the pattern-level target for instruction that intentionally combines in-person and digital learning experiences so each mode does some work the other does not.

## Implications

### Context
#### Requirements
- **A clear division of labor between online and in-person components**
- **Coordination across those components**
#### Constraints
- **Poor integration can leave the modes feeling redundant or disconnected**

### Target Goals
- Combine flexibility of digital learning with the support or interaction of live learning.
