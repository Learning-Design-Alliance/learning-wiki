# Description questions are answered by addressing a topic-dependent subset of Wh- and How subquestions

> **Pattern** · [All patterns](index.md)
> **Evidence** · no claims cited

## Description
Description questions ask students to describe a person, place, or thing by giving its characteristics or properties, including definitions of concepts. The authors analyze answering as decomposition into subquestions: "The key to answering Description questions is knowing which responses to which subquestions must be included in the answer." Which subquestions apply, and their form, depends on the topic — for a group the key What subquestion concerns key beliefs, whereas for a policy or doctrine it concerns provisions. Table I illustrates probable subquestions for common social studies topics, though the authors do not claim the analysis is exhaustive and invariable.

## Design Implications

### Context
#### Requirements
- Students must learn which subquestions to address for each topic, gather the appropriate information from the text, and weave the responses into a coherent answer
#### Constraints
- Not all subquestions are appropriate for all topics; the answer format varies with what is being described

### Target Learners
- middle school students answering description questions in social studies

### Target Goals
- composing coherent descriptive and definitional answers from textbook text
