# Self-Directed Learning

> **Pattern** · [All patterns](index.md)

## Description
Self-Directed Learning is the pattern-level target for designs in which learners take substantial responsibility for setting goals, selecting resources, monitoring progress, and evaluating outcomes within a structured environment.

## Implications

### Context
#### Requirements
- **Learner agency over goals, resources, or pathways**
- **Supports for planning and reflection**
#### Constraints
- **Many learners need scaffolds before they can direct learning effectively**
#### Grain Size
- Unit
- Course

### Target Goals
- Build autonomy, monitoring, and adaptive learning strategies.
