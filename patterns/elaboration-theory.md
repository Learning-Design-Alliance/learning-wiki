# Elaboration Theory

## Description
Elaboration Theory is the short-form canonical target for Reigeluth's elaboration pattern, which sequences from simple, inclusive ideas toward more complex detail.

## Implications

### Context
#### Requirements
- **A domain that can be sequenced from simple to complex**
- **A stable organizing idea or epitome**
#### Constraints
- **Can feel overly linear if the domain is not well structured**
#### Grain Size
- Lesson
- Course

### Target Goals
- Improve sequencing and cumulative understanding.

### Target Learners
- Learners who benefit from structured expansion of complexity.
