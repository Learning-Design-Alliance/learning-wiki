# Gagné's 9 Events

## Description
Gagné's 9 Events is a lesson pattern that sequences attention, objectives, recall, presentation, guidance, practice, feedback, assessment, and transfer. This page serves as the canonical short-form pattern target for pages that reference the nine-event lesson arc.

## Implications

### Context
#### Requirements
- **Explicit lesson objective**
- **Instructional materials for each event**
- **Time for practice, feedback, and transfer**
#### Constraints
- **Can become mechanical if followed rigidly**
- **Weaker fit for open inquiry**
#### Grain Size
- Lesson

### Target Goals
- Structured concept and skill learning.
- Coherent sequencing from introduction through transfer.

### Target Learners
- Novices and learners benefiting from explicit lesson structure.

### Theory
#### Supporting
- [[theories/information-processing-theory|Information Processing Theory]]
- Guided instruction traditions
#### Contradicting / Qualifying
- Inquiry-heavy work may need nonlinear movement across the events.

### Claims
- [[claims/contingent-scaffolding-improves-learning]] [~M]
- [[claims/self-monitoring-improves-self-regulation]] [~M]

## Design

### Sequence
1. Gain attention.
2. State objectives.
3. Stimulate recall.
4. Present content.
5. Provide guidance.
6. Elicit performance.
7. Provide feedback.
8. Assess performance.
9. Enhance retention and transfer.
