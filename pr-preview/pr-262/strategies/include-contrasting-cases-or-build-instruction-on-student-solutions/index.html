When implementing PS-I, include contrasting cases or build the instruction phase on student solutions¶

Strategy · All strategies Evidence · 1 claim (1 for) · 1 study (1 review), q3 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

Based on its synthesis, the review supports implementing PS-I with one of two specific design features: contrasting cases, or instruction that builds on the solutions students produced during the problem-solving phase. The article's conclusion — that "PS-I fosters learning only if specific design features (namely contrasting cases or building instruction on student solutions) are implemented" — makes these features the actionable design levers for practitioners adopting PS-I. Approaches lacking these features are not supported as effective by the review.
