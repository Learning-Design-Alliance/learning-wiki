Adding symbolic number variables to models already containing demographics, domain general, and counting predictors significantly increased R2 for fluency (R2 change = .101), computation (R2 change = .099), applied problems (R2 change = .034), and story problems (R2 change = .042). → Martin Rebecca B. 2014

Evidence¶

Martin Rebecca B. 2014¶

Martin Rebecca B., Cirino Paul T., Sharp Carla, Barnes Marcia. (2014). Number and counting skills in kindergarten as predictors of grade 1 mathematical skills. Learning and Individual Differences. https://doi.org/10.1016/j.lindif.2014.05.006

q3 · i? · associational · r2

Hierarchical regression for the fluency outcome showed the symbolic number step added R2 change = .101, p < .001, with "the only significant predictors were the symbolic number variables" plus verbal working memory. Comparable significant R2 changes were reported for the other three outcomes.

"Model 2b added symbolic number variables (symbolic number identification and symbolic number comparison), and the full model showed R2 = .495, R2 change = .101, p < .001. In this model, the only significant predictors were the symbolic number variables (both p < .001)"
