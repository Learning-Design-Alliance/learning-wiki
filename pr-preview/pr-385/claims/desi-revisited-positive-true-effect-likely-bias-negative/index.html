Evidence¶

Köhler 2021¶

Köhler, C., Hartig, J., & Naumann, A. (2021). Detecting Instruction Effects—Deciding Between Covariance Analytical and Change-Score Approach. Educational Psychology Review. https://doi.org/10.1007/s10648-020-09590-6

q2 · i? · theoretical · r3

Bias approximation using the syntax of Köhler et al. (2020a) with assumed parameter values (state variance 0.2, trait variance 0.8, trait effect on instruction −.2, trait effect on gain .3). The article concludes "it is unlikely that the true effect was zero (or negative)".

"Given the data-generating model holds, both approaches would show a negative bias and report a negative instruction effect if the true effect δ was zero. Since we found positive regression coefficients in the data, it is unlikely that the true effect was zero (or negative)."

Related Claims¶
