The review attributes this comparative conclusion to Gupta and Heggond's (2026) review of multi-agent cognitive architectures for personalised adaptive learning, covering specialised agents for profiling, content selection, difficulty adjustment, and engagement monitoring. It is a review-reported comparison, not an effect-size finding.

"Their analysis demonstrates that multi-agent systems exhibit superior behaviour model - ling, more fine-grained organisation of individualised learning processes, richer real-time feedback, and stronger metacognitive enhancement capacities compared to traditional single-agent or rule-based tutoring technologies."
