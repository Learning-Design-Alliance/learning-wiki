Evidence¶

Sonja Kälin 2022¶

Sonja Kälin, Claudia M. Roebers. (2022). Longitudinal associations between executive functions and metacognitive monitoring in 5- to 8-year-olds. Metacognition and Learning. https://doi.org/10.1007/s11409-022-09306-x

q3 · i? · associational · r2

Cross-lagged panel model in N = 84 children testing the reverse path from monitoring at T1 to inhibition at T2. The article reports no significant effect; no effect size is printed, so the null is reported as a non-significant test, not as equivalence.

"Interestingly, earlier monitoring skills had no significant effect on later inhibition skills."
