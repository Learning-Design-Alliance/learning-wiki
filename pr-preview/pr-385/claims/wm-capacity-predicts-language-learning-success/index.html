Evidence¶

Demir 2021¶

Demir, Bora. (2021). Working Memory Model and Language Learning. Shanlax International Journal of Education. https://doi.org/10.34293/education.v9iS2-Sep.4366

q2 · i? · theoretical · r2

The article's narrative review asserts, citing a large body of prior research (e.g., Engle et al., 1999; van den Noort et al., 2006), that "individuals' memory capacity is a robust indicator of success or failure in language learning". No effect size is reported in this article itself.

"Today, it is well established that individuals' memory capacity is a robust indicator of success or failure in language learning."

Related Claims¶

  • A shared attentional resource for storage and processing is the best supported resource theory of WM capacity but faces empirical challenges — related
  • Working-memory capacity correlates positively with accuracy on all four sentence-production conditions — related
  • After controlling for age, WM correlates significantly only with the most demanding condition (priming task, noncanonical word order) — related
  • Evidence on working memory capacity as a moderator of the interleaving effect is mixed, but WM does not appear to be a major barrier to classroom use — related
  • Cascade models in which IQ mediates the WM-to-achievement path fit comparably to, but not significantly better than, the original correlated models — related
  • Two distinct implicit cognitive processes show different predictive links: implicit learning predicts skill learning, associative memory activation predicts language task success — related
