Arthur S. Otis 1917¶

Arthur S. Otis. (1917). An Absolute Point Scale for the Group Measurement of Intelligence.—Part II. The Journal of Educational Psychology. https://doi.org/10.1037/h0074753

q2 · i? · design · r2

Analytical computation from the correlation between Scale I and Scale II, using the standard deviation of point scores (111 points). The author computes "P. E. = .6745 v/1 - .968 x 111 = 13.7," noting this is 2.7% of the median score of 500, and derives a mental-age probable error of 3.44 months using an age standard deviation of 28.1 months.
