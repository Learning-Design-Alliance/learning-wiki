q2 · i0 · associational · r3

Null cross-lagged paths in the same SEM; both constructs were instead strongly stable over time (β = .68 and β = .66, p < .001). Equivalence was not tested; the coefficients were small and non-significant.

"Paths from T1 academic self-efficacy to T3 attainment value and from T1 attainment value to T3 academic self-efficacy were not statistically significant (β = .11, p =.09; β = .01, p = .98, respectively)."
