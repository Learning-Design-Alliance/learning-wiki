Evidence¶

Yildirim-Erbasli 2026¶

Yildirim-Erbasli, S. N., Ilgun Dibek, M., Thomas, M. L., & Lesoway, N. (2026). When Do Undergraduate Students Prefer AI? Insights into AI Scoring and Feedback. Behavioral Sciences, 16(7), 1196. https://doi.org/10.3390/bs16071196

q2 · i1 · associational · r1

Chi-square test across five assignment types (general, low-stakes, high-stakes, creative, appeal-eligible) in the same survey. The association was significant, "χ2(12) = 35.19, p < 0.001", with printed effect size Cramér's V = 0.16 (small, coded i = 1); the article cautions about low expected cell counts.

"The results indicated a significant association between assignment type and preferred scoring/feedback method, χ2(12) = 35.19, p < 0.001, with a small effect size, Cramér's V = 0.16. Given that some expected cell counts were low, results should be interpreted with caution."
