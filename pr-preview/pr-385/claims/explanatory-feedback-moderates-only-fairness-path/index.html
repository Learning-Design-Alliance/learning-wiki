Evidence¶

Zhang Zhen; Fan Siyu; Qi Chunhui 2026¶

Zhang Zhen; Fan Siyu; Qi Chunhui. (2026). Teacher or Artificial Intelligence? The Effect of Decision-Making Agent on Junior High School Students’ Decision Acceptance: A Moderated Mediation Model. Behavioral Sciences. https://doi.org/10.3390/bs16071227

q3 · i? · causal · r2

In the PROCESS regression predicting perceived fairness (R2 = 0.17, F = 13.27, p < 0.001), the agent × feedback interaction was significant, β = 0.58, t = 2.45, p < 0.05, with a confidence interval excluding zero.

"There was a significant positive interaction between the decision-making agent and explanatory feedback (β = 0.58, t = 2.45, p < 0.05, 95% CI [0.11, 1.03], excluding zero), indicating that explanatory feedback attenuates the positive predictive effect of the decision-making agent on perceived fairness."

Zhang Zhen; Fan Siyu; Qi Chunhui 2026 (2)¶

Zhang Zhen; Fan Siyu; Qi Chunhui. (2026). Teacher or Artificial Intelligence? The Effect of Decision-Making Agent on Junior High School Students’ Decision Acceptance: A Moderated Mediation Model. Behavioral Sciences. https://doi.org/10.3390/bs16071227

q3 · i? · causal · r2

In the PROCESS regression predicting decision acceptance (R2 = 0.57, F = 51.60, p < 0.001), the agent × feedback interaction was non-significant, β = 0.19, t = 0.77, p > 0.05, with a confidence interval containing zero.

"By contrast, the interaction term between the decision-making agent and explanatory feedback failed to significantly predict decision acceptance (β = 0.19, t = 0.77, p > 0.05, 95% CI [−0.29, 0.66], containing zero)."
