Evidence¶

Holweger 1998¶

Holweger, Nancy; Weston, Timothy. (1998). Differential Item Functioning: An Applied Comparison of the Item Characteristic Curve Method with the Logistic Discriminant Function Method. https://eric.ed.gov/?id=ED422362

q2 · i? · associational · r2

Applied comparison on a state-level performance-based assessment with approximately 16,000 examinees (8,539 females, 8,029 males after removing zero scores). The authors report "there is no uniformity across techniques" in the seven-item lists each method produced, with only partial overlap.

"Items 3, 4 and 5 are identified by both techniques as having substantial DIF. However, items 12, 29, 13, and 24 show DIF using the LDF technique but not the ICC technique. Items 18, 23, 25 and 26 show DIF using the ICC technique but not the LDF technique."
