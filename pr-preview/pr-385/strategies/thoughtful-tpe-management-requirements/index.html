Manage TPE as a district-wide priority with clear expectations, training, principal evaluation, and technology platforms¶

Strategy · All strategies
Evidence · 3 claims (2 for, 1 mixed) · 3 studies (2 associational, 1 qualitative), q2 · 0 of 3 report an effect size · 3 claims rest on one study

Description¶

The report describes how effective district leaders make teacher and principal evaluation manageable by treating it as a district-wide priority: they set clear expectations tied to instruction, train principals and teachers, build a meaningful principal evaluation system, and create technology platforms that let districts spot recurring challenges across classrooms and schools. The article states that "The leaders who are effective in implementing TPE make it a district-wide priority to thoughtfully support and manage the evaluation system."

Design Implications¶

Context¶

Requirements¶

  • Set clear expectations for TPE to improve instruction, train principals and teachers on high quality implementation strategies, create a meaningful principal evaluation system, and build technology platforms and information management systems supporting TPE.

Constraints¶

  • The report notes some districts take shortcuts to make the process more manageable, which often undercuts TPE's power to improve instruction.

Target Learners¶

  • District and school leaders
  • Principals
  • Teachers

Target Learning Goals¶

  • Instructional improvement
  • Effective implementation of educator evaluation

Claims¶

  • Educators report that district and school support for TPE is more helpful than state support [+W]
  • Principals and teachers increasingly agree that school and district support for TPE implementation is helpful, with principals more positive than teachers [+W]
  • Districts are not yet systematically using TPE-generated information, with technology serving mainly as a repository [~W]
