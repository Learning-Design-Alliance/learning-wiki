Adopt an activist research paradigm: simultaneously create and study changes in learning with new cognitive and educational tools¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Pea recommends an "activist research paradigm" in which researchers do not merely observe existing practice but simultaneously create new cognitive and educational tools and study the resulting changes in the processes and outcomes of human learning. The urgency he attributes to updating education's goals and methods motivates this combined design-and-study approach.
