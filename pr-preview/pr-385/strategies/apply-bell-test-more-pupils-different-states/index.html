Apply the Bell Chemistry Test to additional pupils in different states before fixing standards¶

Strategy · All strategies
Evidence · 1 claim (1 mixed) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The article recommends extending the test to new samples to check whether Bell's tentative standards are set too low: "The list should be applied to a number of other pupils in different states." The appended correction sheet is offered "for the convenience of others desiring to use the test," making wider application practical.

Design Implications¶

Context¶

Requirements¶

  • Use the appended correction sheet prepared by Mr. Robert F. Payne for scoring.

Constraints¶

  • Current norms rest on only two small samples (Reading and Horace Mann boys, March 1920).

Target Learners¶

  • secondary school chemistry pupils

Target Learning Goals¶

  • establishing reliable norms for a chemistry achievement test

Claims¶

  • The Bell Chemistry Test correlates moderately with semester marks and teachers' estimates, and is judged a fairly good measure of class knowledge but unreliable for an individual. [~W]
