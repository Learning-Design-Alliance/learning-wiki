The LoU Chart: operational definitions of the eight levels across seven categories of user knowledge and activity¶

Element · All elements
Evidence · no claims cited

Description¶

The LoU Chart (Figure 2) displays operational definitions of the eight Levels of Use. Each level is defined across seven categories: "Knowledge, Acquiring Information, Sharing, Assessing, Planning, Status Reporting, and Performing", which "provide a wide range of behaviors that can be specified for individuals". Decision points A through F further delimit differences between the levels, e.g., Decision Point C "Begins first use of the innovation."

Design Implications¶

Context¶

Requirements¶

  • Raters use the chart's category-by-level definitions and decision points to assign levels from interview information

Constraints¶

  • Knowledge is defined as cognitive knowledge related to using the innovation, not feelings or attitudes

Target Learners¶

  • teachers and faculty using educational innovations

Target Learning Goals¶

  • classifying an individual's innovation use behavior into a level

Affordances¶

  • Levels Of Use Innovation Eight Level Framework

Claims¶

Related Elements¶

  • The Levels of Use Interview: a 20-minute focused branching interview assigning a LoU level to any individual

Examples¶

  • Use LoU data to monitor implementation, plan staff development, select research samples, and evaluate programs
