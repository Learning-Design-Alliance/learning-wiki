Ten-RCT empirical comparison of CACE variance formulas¶

Element · All elements Evidence · 2 claims (2 for) · 2 studies (2 causal), q2 · 0 of 2 report an effect size · 2 claims rest on one study

Description¶

An empirical analysis component of the report in which the authors "used data from ten large-scale RCTs" to compare significance findings for the CACE estimator. The comparison was conducted with the estimator "measured in nominal and standard deviation units", contrasting the correct variance formulas with those typically used in practice, and it grounds the report's conclusion that variance correction terms matter little.

Design Implications¶

Context¶

Requirements¶

  • Requires outcome and compliance data from large-scale clustered education RCTs

Constraints¶

  • The comparison concerns significance findings for the CACE estimator, not effect magnitude estimation

Target Learners¶

  • education researchers conducting RCT analyses

Target Learning Goals¶

  • understanding when CACE variance corrections affect significance findings

Claims¶

  • CACE estimators based on correct variance formulas and commonly used simplified formulas yield very similar significance findings across 10 education RCTs [+W]
  • Variance correction terms matter little for CACE significance findings in education RCTs [+W]

Related Elements¶

  • Set of 10 large-scale education RCTs used to compare CACE variance formula significance findings
