EdTech Index with third-party validations¶

Element · All elements Evidence · no claims cited

Description¶

The EdTech Index is a searchable directory of edtech tools that hosts each product's third-party validations. The guide states it is "a searchable directory of edtech tools that hosts each product's third-party validations," covering safety, evidence of effectiveness, usability, inclusivity, and interoperability. Examples include the 1EdTech Data Privacy Seal, iKeepSafe COPPA and FERPA certifications, Digital Promise ESSA Tier 3 and Tier 4 certifications, the ISTE Seal, CAST UDL certifications, and 1EdTech OneRoster and LTI Advantage interoperability certifications. Districts use these signals to narrow options before examining district-specific needs.

Design Implications¶

Context¶

Requirements¶

  • Validations are searchable by tool on the EdTech Index website; districts confirm which standards are relevant to their use case before filtering

  • The collaborative continues to expand the list of trusted validations, so the validation landscape is expected to evolve
