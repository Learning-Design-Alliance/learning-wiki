Galaxy Math one-to-one tutoring program for at-risk first graders¶

Element · All elements Evidence · 2 claims (2 for) · 1 study (1 causal), q3 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

Galaxy Math is "a one-to-one tutoring approach for at-risk first graders" in which "Paraprofessionals tutor students in 30-minute sessions 3 times a week for 16 weeks." The program has "a space theme" and focuses on "understanding and proficiency with addition and subtraction." It is disseminated through AIR tutor training.

Design Implications¶

Context¶

Requirements¶

  • Paraprofessionals or certified teachers as tutors
  • Tutors receive a 2-day initial workshop and weekly meetings with project coordinators

Constraints¶

  • The program is disseminated only as the strategic speeded practice version

Target Learners¶

  • at-risk first graders

Target Learning Goals¶

  • understanding and proficiency with addition and subtraction

Claims¶

  • Strategic speeded practice outperformed strategic non-speeded practice within Galaxy Math, with a +0.57 effect size for the disseminated speeded version [+W]
  • Galaxy Math improves first-grade math outcomes with a qualifying effect size of +0.24, qualifying it as Strong evidence [+W]

Examples¶

  • Use a themed token-reward system (moon rocks) to motivate on-task behavior during tutoring
  • Support tutors with a 2-day initial workshop plus weekly per-child progress meetings
