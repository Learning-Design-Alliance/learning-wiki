EdTech Pilot Navigator with four pilot models (Resource E)¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

Resource E is a quick-reference guide and planning template for choosing a pilot type before formal procurement. It describes four models: a Large-Scale Pilot Study getting more than 350 students to use the tool and measuring outcomes, useful for detecting differences in effects for special populations; a Small-Scale Pilot Study with a smaller group when conditions must be carefully controlled; Live Testing, where students practice using the tool while usage and feedback are observed; and Demonstration and Feedback for teachers when piloting with students is not allowed. Evidence-collection methods include embedded assessments, baseline/endline tests, propensity score matching with a control group, surveys, observation, and usage data.

Design Implications¶

Context¶

Requirements¶

  • Pilots build on what districts already know from external evidence and EdTech Index validations

Constraints¶

  • Demonstration and Feedback applies when piloting with students is not allowed under district policies or when teacher buy-in must be secured first

Target Learners¶

  • K-12 students and teachers participating in district edtech pilots

Target Learning Goals¶

  • Testing whether a tool is usable in local classrooms and whether research-based impact claims translate into practice

Affordances¶

Claims¶
