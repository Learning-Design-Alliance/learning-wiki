NSF Tough As Nails K-8 coding pathway for Kentucky Appalachia¶

Element · All elements Evidence · no claims cited

Description¶

Tough As Nails is an NSF-funded project (Grant No. 1923314) developing a K-8 coding pathway for Kentucky Appalachia. The presentation describes its guiding question as "How can we design & communicate a self-sustaining coalition for CT across 2 districts (9 schools total)?" and reports work on establishing a coherent vision for CT learning. It serves as the case in which the presenters enacted researcher roles beyond research.
