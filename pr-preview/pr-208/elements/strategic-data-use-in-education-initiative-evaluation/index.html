Strategic Data Use in Education initiative evaluation (2011-2015)¶

Element · All elements Evidence · no claims cited

Description¶

The brief draws its data and supporting examples from "work conducted as part of the evaluation of strategic data use initiatives." The associated project, Strategic Data Use in Education, ran from 2011 to 2015, was prepared for the Bill & Melinda Gates Foundation, and supported organizations and agencies helping school districts build their capacity to generate and use data. It functions as the evidence base for the brief's four recommendations.
