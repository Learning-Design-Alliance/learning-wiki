Edmentum Exact Path Growth personalized learning program¶

Element · All elements Evidence · 4 claims (4 for) · 2 studies (2 causal), q2 · 1 of 2 report an effect size · 4 claims rest on one study

Description¶

Exact Path Growth is "a personalized learning program for K-12 learners, designed to accelerate, measure, and report student achievement in Math and English Language Arts standards." It offers individualized learning paths, adaptive diagnostic assessments, and educator-led interventions. It provides flexible assessment options, using its own diagnostic assessment or integrating with NWEA MAP Growth, Renaissance Star, or select state assessments to personalize learning paths.

Design Implications¶

Context¶

Requirements¶

  • Requires a district's current teachers, school leaders, and district leaders for implementation, with guidance from Edmentum's Customer Success Managers; no additional staffing is required.
  • Operates on all commonly used devices and browsers in school districts; no additional technology applications or devices are required.

Constraints¶

  • Evidence base is a single quasi-experimental study in one district (Duval County Public Schools, Florida) with 6th-grade students, qualifying for a Moderate rating rather than strong.

Target Learners¶

  • K-12 learners, evaluated here with 6th-grade students

Target Learning Goals¶

  • English Language Arts achievement
  • Mathematics achievement aligned to standards

Claims¶

  • Exact Path use produced a statistically significant positive effect on 6th-grade ELA achievement (effect size = +0.16) in a quasi-experimental study [+W]
  • Exact Path use produced a statistically significant positive effect on 6th-grade Mathematics achievement (effect size = +0.06) in the same quasi-experimental study [+W]
  • The Exact Path evaluation sample was demographically diverse, including 42% African American, 47% economically disadvantaged, and 22% ESE students [+W]
  • Exact Path Proficiency + Growth shows statistically significant positive ELA effects across Grades 6-8 [+W]

Related Elements¶

  • Exact Path Proficiency + Exact Path Growth digital learning system
  • Edmentum Exact Path: computer-adaptive supplemental program supporting instruction and assignment
  • IXL Math personalized learning program with Real-Time Diagnostic and IXL Analytics
  • Edmentum Exact Path Growth personalized learning program

Examples¶

  • Implement Exact Path with existing district staff supported by vendor professional development and standard technology
  • Implement Exact Path with existing district staff plus vendor-provided professional development
