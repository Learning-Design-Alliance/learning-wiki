32-item global citizenship perspectives questionnaire adapted from Morais and Ogden (2011) and Roberts and Wilson (2016)¶

Element · All elements Evidence · 3 claims (3 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

A questionnaire 'adapted from the validated questionnaire from Morais and Ogden (2011) and Roberts and Wilson (2016)' consisting of 32 items with modifications such as country names and political policies. Items cover demographic features, social responsibility (GJD, AE, GIPR), global competence (SA, IC, GK), and global civic engagement (ICO, PV, GCA), all rated on a 5-point Likert scale from 1 (totally disagree) to 5 (totally agree).

Design Implications¶

Context¶

Requirements¶

  • Pilot testing before distribution to allow adjustments; PLS-SEM analysis for validation

Constraints¶

  • Some items required modification for the Vietnamese context, and several indicators were removed during validation

Target Learners¶

  • higher education students

Target Learning Goals¶

  • measuring student perspectives toward global citizenship

Claims¶

  • The original global citizenship scale is employable in a developing-country university context after adjustments to social responsibility and global competence [+W]
  • The social responsibility measurement model required the most item removals, with global justice and personal responsibility items dropped in the Vietnamese context [+W]
  • The global civic activism measurement model was fully valid with no items removed, appearing valid across contexts [+W]
