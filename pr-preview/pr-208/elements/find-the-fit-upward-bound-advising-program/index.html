Find the Fit: personalized planning materials, student text messaging, and advisor training webinars within Upward Bound¶

Element · All elements Evidence · no claims cited

Description¶

Find the Fit is a college-advising program delivered within Upward Bound. The article describes it as "a program called Find the Fit, which combines personalized planning materials and text messaging for students, and training webinars for advisors". It was evaluated in a six-year study, with this snapshot reporting the first impacts on students' steps toward college.
