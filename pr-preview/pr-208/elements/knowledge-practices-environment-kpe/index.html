Knowledge Practices Environment (KPE): a platform for object-centred collaborative knowledge creation¶

Element · All elements Evidence · no claims cited

Description¶

KP-Lab technology provided a basic platform, the Knowledge Practices Environment (KPE), to support knowledge creation processes and to offer tools and functionalities for innovative, reflective and object-centered knowledge practices such as planning, versioning, commenting, annotating and semantic search. KPE integrates processes supporting collaborative knowledge creation in flexible ways, including planning epistemic processes, producing texts and notes, organising work on shared objects across communities, and reflecting on planning processes. It consists of shared space views, support tools, and optional tools that are loosely integrated applications selectable by the user.

Design Implications¶

Context¶

Requirements¶

  • Integration with loosely coupled optional tools selected by users
  • Support for tracking the development cycle of specific knowledge objects

Constraints¶

  • The project developed its own tools because generic tools such as wikis, track-changes functions and smart-boards show certain limitations for supporting trialogical learning

Target Learners¶

  • higher education students
  • workplace teams

Target Learning Goals¶

  • collaborative knowledge creation around shared objects

Affordances¶

  • Trialogical Learning Framework

Claims¶

Related Elements¶

  • Cloud technology as information source and activity tool in the learning model
  • KP-Lab toolset supporting four types of mediation, including the Visual Model Editor and analytic mirroring tools

Examples¶

  • Pedagogical scenarios that organise learning around knowledge creation with shared objects
