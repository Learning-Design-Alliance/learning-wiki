Value-added models using end-of-course assessments or commercially available tests instead of state assessments¶

Element · All elements Evidence · 2 claims (2 for) · 2 studies (1 associational, 1 design), q1–q2 · 0 of 2 report an effect size · 2 claims rest on one study

Description¶

One of the two alternative measure types profiled in the report: value-added models that substitute different assessment sources for typical state assessments. The summary describes "value-added models that use the results of end-of-course assessments or commercially available tests in statistical growth models instead of typical state assessments." The report profiles how early-adopting districts implement this approach for teacher evaluation.

Design Implications¶

Context¶

Requirements¶

  • End-of-course assessments or commercially available test results suitable for statistical growth modeling

Constraints¶

Target Learners¶

  • K-12 students in early-adopting districts

Target Learning Goals¶

  • Measuring student growth for teacher evaluation

Claims¶

  • The Pittsburgh VAMs incorporate course-specific assessments, attendance, and course completion alongside state assessments [+W]
  • The choice of which assessment to use as the outcome measure matters more for value-added estimates than any student or peer control-variable specification choice [+W]

Related Elements¶

  • Student learning objectives set by individual teachers and approved by principals

Examples¶

  • Use early-adopting districts' experiences to decide whether and how to implement alternative teacher-effectiveness measures
