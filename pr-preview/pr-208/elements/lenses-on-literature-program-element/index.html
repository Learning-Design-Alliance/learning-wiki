Lenses on Literature: a comprehensive disciplinary-literacy instructional framework built around a Driving Task Prompt¶

Element · All elements Evidence · 3 claims (3 for) · 1 study (1 causal), q3 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

Lenses on Literature is a comprehensive instructional framework engaging all students in daily, standards-driven reading, writing, and discourse grounded in disciplinary literacy. Curriculum units and modules are organized around a Driving Task Prompt and follow a sequenced instructional journey including comprehension, knowledge building, genre study, synthesis, and writing. The program provides print and digital experiences, scaffolds for multilingual learners, and embedded formative assessments using standards-aligned rubrics from the Stanford Center for Assessment, Learning, and Equity.

Design Implications¶

Context¶

Requirements¶

  • Classroom teachers and instructional leaders staff the program, and implementation relies on high-quality instructional materials, professional learning and planning tools, and an implementation plan rooted in student work analysis and continuous improvement.

Constraints¶

Target Learners¶

  • eighth-grade students
  • middle school students
  • multilingual learners

Target Learning Goals¶

  • reading achievement
  • text-based analysis
  • writing and communication across genres and formats

Claims¶

  • Lenses on Literature produces a statistically significant positive effect on eighth-grade state reading scores in Kentucky (effect size +0.06) [+M]
  • In Pennsylvania exploratory analyses, Lenses showed a small, non-significant effect on reading (effect size +0.03) [+W]
  • Lenses impacts are significant for middle school students whose teachers have two years of program experience, with largest gains where over half of class time is Lenses-supported, but attrition makes these results suggestive [+W]
