PAX Good Behavior Game program¶

Element · All elements Evidence · 5 claims (3 for, 2 mixed) · 2 studies (1 causal, 1 quant-synthesis), q2 · 2 of 2 report an effect size · 5 claims rest on one study

Description¶

PAX Good Behavior Game is a commercial version of the long-standing Good Behavior Game, "very widely used in the U.S. and elsewhere". Students are divided into teams; teachers monitor behavior and teams violating agreed class rules receive checkmarks on a whiteboard, with the team receiving the fewest checkmarks (or all teams meeting a criterion) earning a small privilege. The program provides onsite training by experienced therapists, plus manuals, timers, and auxiliary materials, and parents receive manuals to use similar methods at home.
