Hypothesis-testing framework for computing error rates of value-added performance measurement systems¶

Theory · All theories Evidence · 4 claims (4 for) · 2 studies (1 associational, 1 theoretical), q2 · 0 of 2 report an effect size · 4 claims rest on one study

Description¶

The report frames teacher and school performance measurement as a hypothesis-testing problem, in which a decision (for example, whether an educator's performance differs from the average) can be a true positive, false positive, true negative, or false negative. "Using realistic performance measurement system schemes based on hypothesis testing, we develop error rate formulas based on OLS and Empirical Bayes estimators," allowing error rates to be computed as a function of data quantity and estimator choice.

Design Implications¶

Context¶

Requirements¶

  • Student test score gain data for the performance unit; a specified hypothesis-testing decision scheme; an estimator such as OLS or Empirical Bayes.

Constraints¶

  • Formulas and simulations address the upper elementary grades and value-added models applied to student test score gain data.

Target Learners¶

  • Upper elementary grade students

Target Learning Objectives¶

  • Reliable measurement of educator performance from student test score gains

Claims¶

  • Value Added Estimates Noisy Typical Data [+M]
  • Overall false positive and false negative error rates in teacher value-added performance classification are about 10 and 20 percent, respectively [+W]
  • Value-added error rates apply to measuring both teacher and school performance in the upper elementary grades using student test score gain data [+W]
  • Error rates for comparing a teacher's performance to the average are about 25 percent with three years of data and 35 percent with one year of data [+W]

Related Theories¶

  • Empirical Bayes shrinkage as a precision-based adjustment to teacher value-added estimates in accountability systems
