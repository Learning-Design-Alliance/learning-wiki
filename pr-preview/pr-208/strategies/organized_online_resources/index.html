Organized Online Resources¶

Strategy · All strategies Evidence · 3 claims (2 for, 1 mixed) · 7 studies (4 causal, 2 review, 1 quant-synthesis), q2–q3 · 1 of 7 report an effect size · 1 claim rests on one study

Description¶

Organized online resources is a strategy in which an instructor curates, annotates, and structures digital materials — readings, videos, interactive tools, worksheets, exemplars — into a single coherent collection (a course hub, curation tool, or shared workspace) with clear labels, sequencing, and purpose statements for each item. The organizational work is done up front by the instructor so learners spend their effort on learning rather than searching, evaluating, and assembling materials.

Design Implications¶

Curation reduces extraneous cognitive load: every navigation decision, broken link, or ambiguous file name consumes working memory that would otherwise support learning Chunking reduces working memory load. [+M]. Well-organized resource collections function as advance organizers — they show learners the structure of the unit before they encounter its parts, which improves encoding and retrieval Advance organizers provide a scaffold for new learning. [+M]. The critical design decision is selective curation: a small, purpose-annotated set of resources outperforms an exhaustive dump, because unstructured abundance increases search cost and choice paralysis [~M].

Context¶

Requirements¶

  • A single, stable access point (LMS module, curated binder, shared workspace) rather than scattered links
  • Descriptive labels and a one-line purpose statement for each resource ("watch this to see the procedure modeled")
  • Logical sequencing that mirrors the instructional flow, not just topic grouping
  • Periodic maintenance: dead links and outdated files rapidly erode trust in the collection

Constraints¶

  • Over-collection backfires: long undifferentiated resource lists increase search time and reduce actual use [-M]
  • Organization schemes that reflect the instructor's logic rather than the learner's task can confuse novices, who lack the schema to map between them [~M]
  • Heavy reliance on external curation can suppress learners' own information-literacy and self-regulation skills if resources are always pre-digested [-W]
  • Poorly labeled multimedia that splits attention between sources degrades learning Media combinations affect recall and retention. [~M]

Implementation Variability¶

  • Curated binders (e.g., LiveBinders, Wakelet) organize materials into tabbed, shelf-like collections for whole-course or unit-level use
  • Note-and-clipping tools (e.g., Evernote, Notion, Diigo) support instructor-side gathering with tags and annotation, then selective publication
  • LMS-embedded modules sequence resources directly alongside activities and assessments, keeping materials in the learning path rather than beside it
  • Learner-built collections invert the strategy: students curate and annotate resources themselves, shifting the goal toward information literacy

Target Learners¶

  • Novices, who lack the schema to evaluate and sequence resources independently and benefit most from pre-structured paths [+M]
  • Learners in fully online or blended courses, where the resource collection substitutes for the physical availability of the instructor's materials
  • Less beneficial for advanced learners, who can search and evaluate effectively and may find heavy curation constraining [~M]

Target Learning Goals¶

  • Efficient access to procedural and reference materials during task performance
  • Schema building: a well-sequenced collection makes the structure of a domain visible
  • Self-regulated resource use in blended and flipped formats, where learners access materials before class

Instructions¶

  1. Define the learning path for the unit and select only resources that serve a named purpose in it; cut anything that is merely "nice to have."
  2. Structure the collection into chunked sections that mirror the instructional sequence, using advance organizers at the top of each section to state what the resources are for.
  3. Annotate every resource with a one-line purpose and, where relevant, how it connects to an upcoming practice activity or assessment.
  4. Apply clear structure and presentation: consistent naming, visible hierarchy, and scannable layout so learners can locate an item in seconds.
  5. Pilot the collection with a learner, observe where they hesitate or ask "which one do I use?", and prune or relabel accordingly.
  6. Schedule recurring maintenance to verify links and retire outdated materials.

Related Strategies¶

  • Flipped classroom — organized pre-class resource collections are the delivery mechanism for flipped models
  • Clear structure — the organizational principle the collection itself must embody
  • Advance organizers — the framing statements that give a resource collection its navigational schema

Examples¶

  • LiveBinders (https://www.livebinders.com) — tabbed, binder-style curation used by teachers to assemble unit resources, exemplars, and tools into a single shareable link.
  • Wakelet (https://wakelet.com) — visual collections of links, videos, and documents commonly used for curated reading lists and research packets.
  • Diigo (https://www.diigo.com) — social bookmarking with highlighting and annotation, supporting both instructor curation and learner-built resource collections.
  • A flipped math course where each LMS module opens with a short "start here" note, then sequences a worked example video, a practice set, and an answer key in the order students should use them.
