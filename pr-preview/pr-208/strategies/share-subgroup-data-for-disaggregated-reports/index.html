Districts should share sufficient subgroup data with assessment providers to enable multi-subgroup disaggregation¶

Strategy · All strategies Evidence · no claims cited

Description¶

The guide's fourth recommendation addresses a practical barrier: many districts using MAP Growth do not share enough subgroup data for disaggregation within its reports. Sharing these data "enables deeper analysis across multiple subgroups simultaneously (e.g., Asian students who are also low-income)" and lets districts receive tailored insights informing strategies for improving student outcomes.

Design Implications¶

Context¶

Requirements¶

  • Districts must submit subgroup data to the assessment provider beyond what is currently shared

Constraints¶

Target Learners¶

  • K-12 students in districts using MAP Growth

Target Learning Goals¶

  • Clearer understanding of achievement patterns and equity gaps to inform improvement strategies

Related Strategies¶

  • Disaggregate attainment data by student subgroup to locate barriers and target supports
  • Examine data across subgroups and account for diversity within subgroup categories before interpreting score differences
  • Multi-stakeholder analytics partnership using improvement science with strict data governance
