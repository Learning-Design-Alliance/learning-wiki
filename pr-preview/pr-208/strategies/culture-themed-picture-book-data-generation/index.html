Use a culture-themed children's book to generate data for K-2 glyph and graph activities.¶

Strategy · All strategies Evidence · no claims cited

Description¶

This strategy has teachers anchor early data collection in a culture-themed children's book, using story content as the source of data students then organize. The webinar states: "Use a culture themed children’s book to generate data," with the example text 'When I was Young in the Mountains' listed on the agenda. Students' observations from the book become entries in glyphs, pictographs, bar graphs, or Google Forms.
