Philip Gleason 2018¶

Philip Gleason, Alexandra Resch, Jillian Berk. (2018). RD or Not RD: Using Experimental Studies to Assess the Performance of the Regression Discontinuity Approach. Evaluation Review, vol. 42. https://www.mathematica.org/publications/rd-or-not-rd-using-experimental-studies-to-assess-the-performance-of-the-regression-discontinuity

q2 · i? · causal · r2

Simulation study in which the authors "simulate a situation in which some students manipulate the value of the assignment variable to receive treatment" and compare RD estimates with and without manipulation. Bias is largest when manipulation is outcome-related and near the cutoff; no effect size is printed.

"Manipulation of the assignment variable can substantially influence RD impact estimates, particularly if manipulation is related to the outcome and occurs close to the assignment variable’s cutoff value."
