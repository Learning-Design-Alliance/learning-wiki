Cross-lagged panel model over six testing windows (Fall Grade 1–Spring Grade 2) fit with good fit indices (CFI = .99, TLI = .96, RMSEA = .06, SRMR = .03); Table 3 shows autoregressive paths (e.g., AL→AL .32) exceeding cross-domain paths, all p < .001.

"Those autoregressive coefficients were high relative to the cross-lagged ones, suggesting that the domain-level performance is most likely to be predicted by the preceding performance of the same domains."
