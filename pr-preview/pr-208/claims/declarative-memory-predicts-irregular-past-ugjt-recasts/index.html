Evidence¶

Yusuke Sato 2023¶

Yusuke Sato. (2023). Interactions Among Declarative and Procedural Memory Systems, Different Linguistic Structures, and the Efficacy of Different Corrective Feedback Types. Journal for the Psychology of Language Learning, 5(1). https://doi.org/10.52598/jpll/5/1/4

q2 · i3 · causal · r1

Multiple regression analyses for the irregular past tense UGJT across the same three classroom CF groups, with pretest as covariate. LLAMA_B was significant only for the recast group's immediate posttest (β = .38, p = .03, adjusted R² = .12); the article reports it was "significantly related only to the UGJT immediate posttest scores of the recast group."

"Declarative memory (LLAMA_B) scores were significantly related only to the UGJT immediate posttest scores of the recast group."
