q4 · i3 · causal · r3

Findings from the one RCT meeting WWC standards without reservations, on six researcher-designed number and operations measures with 1,152 fourth-grade students. The fraction calculation measure showed an effect size of 1.68 and improvement index of +45, p < .01; the domain average effect size was 0.89.
