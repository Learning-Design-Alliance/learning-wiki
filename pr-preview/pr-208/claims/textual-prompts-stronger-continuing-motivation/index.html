Reisslein 2004¶

Reisslein, J., Atkinson, R. K., & Reisslein, M. (2004). Exploring the Presentation and Format of Help in a Computer-Based Electrical Engineering Learning Environment. Arizona State University. https://eric.ed.gov/?id=ED484994

q2 · i2 · causal · r2

MANOVA of the 51-participant experiment's attitude survey found "a significant overall main effect... across the items relating to continuing motivation for the format of prompts", favoring text-based prompts with Cohen's f = .37.

"a significant overall main effect was discovered across the items relating to continuing motivation for the format of prompts ( M = 3.83 for text -based prompts and 3.36 for pictorial -based prompts), F(1,47) = 6.36, MSE = .45, p = .02. Cohen's f for these data yields an effect size of .37, which corresponds to medium to large effect."
