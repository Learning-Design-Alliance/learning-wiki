Evidence¶

Rachelle Esterhazy 2025¶

Rachelle Esterhazy, Rogers Kaliisa, Daniel Sanchez, Malcolm Langford and Crina Damsa. (2025). Advancing Multimodal Collaboration Analytics: A Scoping Review. Journal of Learning Analytics 12(2). https://doi.org/10.18608/jla.2025.8625

q2 · i? · review · r2

The review reports, citing Vrzakova et al. (2020), a study combining visual screen recordings and semantic audio data in remote collaborative problem-solving. "group silence correlates negatively with performance when only audio data is used", while visual data reversed the pattern. No effect sizes are printed.

"The authors find that group silence correlates negatively with performance when only audio data is used. However, when utilizing visual data, silence combined with activity on the shared screen shows a positive correlation with performance."
