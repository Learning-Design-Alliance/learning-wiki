In the Torgesen et al. (2006) randomized controlled trial (79 third-grade students), the WWC alphabetics findings table shows a word identification effect size of 0.22, statistically significant, improvement index +9; the sight word efficiency row shows an effect size of 0.30, statistically significant, index +12, while word attack (0.34) and phonetic decoding efficiency (0.02) were not significant.

q3 · i? · causal · r2

The WWC-computed domain average effect size for alphabetics was 0.22 across the four phonics outcomes in the single study, below the 0.25 substantiative-importance threshold and not statistically significant.

"The average effect size across the four outcomes was neither statistically significant nor large enough to be considered substantively important (that is, an effect size greater than 0.25)."
