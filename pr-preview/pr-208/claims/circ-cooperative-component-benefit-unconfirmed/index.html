Alternate contrast from the same cluster randomized trial (Appendix D.3): CIRC versus Direct Instruction without cooperative learning on Main Idea Questions yielded effect size 0.33, improvement index +13, p = 0.09. The Direct Instruction without cooperative learning group versus comparison yielded effect size 0.53, +20, p < 0.01 on the same outcome.
