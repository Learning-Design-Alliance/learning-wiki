The pilot study's key findings report that while virtual Pre-K CLASS observation was practical across setting types, "doing so comes with substantial logistical challenges." The report does not quantify the challenges in the excerpt provided.

"Conducting virtual observations using the Pre-K Classroom Assessment Scoring System (Pre-K CLASS) was practical in both centers and FCCs; however, doing so comes with substantial logistical challenges."
