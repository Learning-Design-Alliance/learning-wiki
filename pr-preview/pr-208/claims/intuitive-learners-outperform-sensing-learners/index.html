Intuitive learners tend to outperform sensing learners in media-based presentations¶

Claim · All claims Evidence · 1 study · causal r? · q3

Across a series of computer-based media experiments, learners with a preference for intuitive processing (abstract, symbolic) scored higher than sensing-preferring learners (concrete, factual), but the advantage was not uniform across presentation formats.

In an extended student-class experiment comparing text-only, voice, diagram, and combined media presentations grounded in dual coding theory, the author reports: "Intuitive Learners tended to out-perform Sensing Learners in all presentations, although in certain experiments, Sensing Learners using Voice/Diagrams outperformed Intuitive Learners using Text-only." The exception indicates that a well-matched multimedia format can compensate for — and reverse — the learner-preference disadvantage, consistent with the general finding that presentation quality matters more than preference matching.

Discussion¶

Format moderates the effect. The intuitive-over-sensing advantage held across presentation types, but the voice/diagrams exception shows it is not a fixed learner property: a concrete, dual-channel presentation (spoken narration plus visual diagrams) lifted sensing learners above intuitives receiving text alone [+M]. This aligns with the mechanism Alty proposes via dual coding theory — combining verbal and visual channels reduces reliance on a single representational system and lowers extraneous load, echoing cognitive overload degrades learning [~M].

Caution on learner-preference inference. This claim concerns measured performance differences associated with sensing/intuitive preference on an instrument (Myers–Briggs-style dimensions), not a validated learning-styles treatment. It should not be read as support for tailoring media to learner style; the data here point the other way — the presentation format, not the preference match, drove the reversal [+M].

Single-source limitation. Both subclaims rest on one conference-report series of classroom experiments by a single author, with sample sizes and effect magnitudes not fully specified. Replication in independent labs and with modern multimedia would be needed before treating the intuitive advantage as robust.
