Evidence¶

Tang J 2026¶

Tang J, Li P, Luo R (2026) Teacher feedback VS AI-assisted peer feedback in L2 writing: A quasi-experimental study in a Chinese University. PLoS One 21(6): e0345976. https://doi.org/10.1371/journal.pone.0345976

q3 · i2 · causal · r2

Independent-samples t-tests comparing feedback items per student across the two classes (control n = 31, experimental n = 30) in the first writing task. Vocabulary errors: t(59) = −2.677, P = .010, "Cohen's d = 0.66"; technical details: t(59) = −2.620, P = .012, d = 0.58.

"In the first task, the total amount of teacher feedback (316 items) was significantly higher than that of AI-assisted peer feedback (185 items)."

Related Claims¶

  • Feedback improves learning by a medium amount on average, but its effect varies widely with the information it carries, and more than a third of feedback interventions reduce performance — the general claim this finding bears on, with the studies behind it
  • Across tasks, teacher feedback shifted from basic error correction toward higher-order dimensions while AI-assisted peer feedback reduced content suggestions and increased technical-detail feedback — related
  • AI-assisted peer feedback enhanced lexical diversity only in the first writing task, with the group advantage disappearing by the second task — related
