Methodological quality check of the review's content analysis using Cohen's Kappa on six independently coded papers. After establishing agreement, the first author coded the remaining papers with continuous calibration through discussion.

"The Kappa results indicated very good agreement (κ = 0.89, p < 0.001), demonstrating high reliability and consistency in the coding process (Gisev et al., 2013)."
