Shahin Hossain 2026¶

Shahin Hossain. (2026). Four Types of LLM Reliance and Their Predictors Among Undergraduate Writers: A Mixed-Methods Study at a Minority-Serving R1 University. arXiv. https://arxiv.org/abs/2606.28749 doi:10.48550/arxiv.2606.28749

q3 · i? · associational · r1

Criterion validity analysis in the main study psychometric evaluation: one-way ANOVAs of reliance type on ten writing-process and outcome variables, all significant at p < .001 with a printed η² range of .166–.329. No single standardized effect size is printed for one pooled finding, so no magnitude code is assigned.

"Criterion validity was supported by significant one-way ANOVA effects of reliance type across all ten writing process and outcome variables (all𝑝<. 001;𝜂2 range =. 166–.329), confirming that type membership systematically predicts theoretically expected behavioral differences."
