Evidence¶

Ivory 2026¶

Ivory, M., Finnerty, S., Dunn, K., Philpot, R., & Warmelink, L. (2026). The Integrity of Psychology Assessments in the AI Age: A Critical Examination. Journal of Academic Ethics. https://doi.org/10.1007/s10805-026-09729-0

q2 · i? · design · r2

In statistics modules using R, ChatGPT lacked access to the datafile and could not execute code; the researchers ran its code after adding correct dataset naming, yielding 60% accuracy, which the authors note a student could easily improve by supplying column names.

"the accuracy was 60% for these types of questions, and it did not score higher mostly because it guessed at column names."
