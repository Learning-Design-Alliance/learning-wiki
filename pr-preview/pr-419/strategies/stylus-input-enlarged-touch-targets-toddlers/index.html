Use a stylus rather than finger touch as input for young children's tablet tasks, and enlarge clickable touch targets beyond visual object size¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The article recommends adapting tablet input to young children's limited visual-motor coordination. During pilot testing the multi-touch screen "had difﬁculties isolating the input of the child's index ﬁnger from other parts of the child's hand", so a stylus was introduced and gave children much better control. Clickable touch targets were also made twice each object's visual size because children had difficulty accurately hitting small targets, while keeping equal bounding boxes across objects.

Design Implications¶

Context¶

Requirements¶

  • Touch-input filtering or a stylus so incidental palm/knuckle contact does not register as input; enlarged clickable areas at least twice the object's visual size on small screens

Constraints¶

  • The stylus decision was based on pilot observations with young children on a multi-touch UMPC screen, not a controlled comparison

Target Learners¶

  • toddlers and preschool children under 5 years old

Target Learning Goals¶

  • enabling valid response input for visual-motor and cognitive assessment tasks

Related Strategies¶

  • Embed synchronized audio narration with finger-tracking animation in dual-language e-books to support independent bilingual reading
