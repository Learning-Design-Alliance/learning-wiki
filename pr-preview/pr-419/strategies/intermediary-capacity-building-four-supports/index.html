Strengthen grantee strategic learning capacity through scoping support, provider matching, cohort learning activities, and thought partnership¶

Strategy · All strategies
Evidence · no claims cited

Description¶

An intermediary-led capacity-building strategy in which the intermediary helps grantees "scope projects in their area of need, matching grantees with providers that could help build organizational capacity, delivering cohort learning activities, and offering thought partnership." The four supports combine individualized project scoping and provider matching with shared cohort learning and ongoing advisory partnership.

Design Implications¶

Context¶

Requirements¶

  • An intermediary able to scope projects, match providers, run cohort activities, and provide thought partnership

Constraints¶

Target Learners¶

  • K-12 education grantee organizations

Target Learning Goals¶

  • Organizational capacity for equity-centered strategic learning

Affordances¶

  • Equity Centered Strategic Learning Framework

Related Strategies¶

  • Use transferable planning tools to design virtual cohort learning activities
  • Engage a learning partner to support funders and grantees in designing and carrying out a learning plan and building M&E capacity
  • Four-part capacity-building support model: scoping, provider matching, cohort learning, and thought partnership
  • Intermediary-led grantee cohort model with four support components
