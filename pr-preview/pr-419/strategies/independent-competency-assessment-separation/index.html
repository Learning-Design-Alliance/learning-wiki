Separate competency assessment from courses, conducted by an independent unit using evidence-centered assessment design¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The paper proposes decoupling assessment from courses and programs because self-paced, unit-based learning makes simultaneous end-of-course exams unfit. It states: "We propose that, in future, the assessment process would be separated from courses or programs to align with the changes in the learning process." A possible solution is formal assessment conducted by an independent unit or organization that designs, organizes and conducts competency assessments and tracks competency changes across the overall learning portfolio, similar to evidence-centered assessment design (ECD) and to ETS/IELTS English proficiency assessment.

Design Implications¶

Context¶

Requirements¶

  • An independent assessment unit or organization
  • Analytics techniques tracking competency changes across the learning portfolio
  • Alignment with evidence-centered assessment design yielding real-time competency estimates

Constraints¶

Target Learners¶

  • learners following individualized, self-paced learning paths

Target Learning Goals¶

  • assessment of competencies including knowledge and skills, anytime and anywhere, rather than memorization-focused course exams

Affordances¶

  • Smart Learning Environments Framework

Related Strategies¶

  • Extend course-by-course learning portfolios into life-long learning profiles stored on the cloud with social media integration
  • Include learning analytics in the design loop of self-paced online course design, with diagnosis, learner profiling, continuous assessment, and adaptivity
