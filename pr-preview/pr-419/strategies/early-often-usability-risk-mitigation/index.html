Mitigate authoring tool investment risk with early-and-often user feedback and a theoretical understanding of users and tasks¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Because authoring tools are labor-intensive and the risk grows that investment will outweigh benefits if tools miss user needs, the article recommends risk-management practices from software industries (Fig. 1): empirical usability evaluation and user feedback from authentic contexts done "early and often", combined with a good theoretical understanding of the user and task, aiming for the sweet spot where risk is acceptably low and expected value relatively high.

Design Implications¶

Context¶

Requirements¶

  • Access to authentic users for iterative feedback, and a theoretical basis (such as the complexity-matching framework) for anticipating user requirements

Constraints¶

  • The article notes the 80/20 rule: perfecting the last 10–20% can take disproportionate effort while return on user value proportionately lessens

Target Learners¶

  • authoring tool development teams
  • educational technology R&D groups

Target Learning Goals¶

  • managing software development risk in authoring tool projects

Claims¶

  • Authoring tool usability trades off against the depth and flexibility of the ITSs that can be built [+W]
  • Allowing procedural constructs (branches, rules, loops, recursion) in an authoring tool dramatically raises authoring complexity and demands debugging support [+W]

Related Strategies¶

  • Use iterative design with short feedback loops and multiple user-feedback methods during product development
  • Center co-design with teachers and students throughout AI tool R&D, using human-in-the-loop workflows as a primary risk mitigation
  • Engage users and community members in the design process to make learning tools more attractive, useful, and effective
  • Involve end-users and teachers early in educational game development
  • Plan user administration and curriculum fit carefully for educational games
