Use closed-loop optogenetic manipulations to establish causal roles of oscillations in memory¶

Strategy · All strategies
Evidence · 4 claims (4 for) · 1 study (1 review), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The review recommends closed-loop optogenetic manipulation of neuronal oscillations as the route from correlational to causal evidence about memory mechanisms. It highlights experiments in which interfering with hippocampal theta during REM disrupted contextual memory consolidation, and in which synchronous versus asynchronous delta-frequency cortical activation during SWS respectively enhanced or dampened perceptual memory consolidation. It anticipates that real-time signal processing advances will enable controlling spontaneously occurring oscillatory bursts and sculpting gamma phase and amplitude.

Design Implications¶

Context¶

Requirements¶

  • Real-time signal processing and closed-loop optogenetic tools capable of detecting and perturbing spontaneous oscillatory events without wholesale disruption of the behavioral state

Constraints¶

  • The review states most existing findings implicating oscillations in memory are correlational, so causal tests remain the exception

Target Learners¶

  • experimental animal models and, by extension, human memory research programs

Target Learning Goals¶

  • establishing causal roles of theta, delta, and gamma rhythms in memory encoding and consolidation

Claims¶

  • Cortical delta oscillations during slow-wave sleep support declarative memory consolidation [+W]
  • REM theta supports consolidation of select procedural memories such as emotional memory, but not skilled motor memory [+W]
  • Hippocampal sharp-wave ripples during SWS and waking support memory consolidation and spatial task performance [+W]
  • Theta and gamma oscillations show similar relationships with memory encoding and retrieval across multiple memory systems and brain regions [+W]
