Treatment-characteristic moderators from the random-effects meta-regression (Table 2): implementation quality (p = .03), treatment duration (p = .03), and community-based setting (p = .00) were each significantly associated with outcomes.

"Key program characteristics associated with less dropout among treated students included implementation quality, shorter duration programs, and community-based programs."
