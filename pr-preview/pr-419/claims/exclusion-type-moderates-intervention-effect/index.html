Heterogeneity exploration via meta-regression in the updated multilevel meta-analysis indicates differential effects by exclusion type: "more serious disciplinary sanctions such as permanent exclusions and out‐of‐school suspensions appear less responsive" while in-school exclusion shows greater potential for reduction.
