Regression analysis separating the components of calibration discrepancy in the 210-student study found "pretest retrospective judgments—rather than actual pretest scores—sig - nificantly predicted students’ engagement in these metacognitive strategies", contradicting the hypothesis that actual performance would drive strategy use.
