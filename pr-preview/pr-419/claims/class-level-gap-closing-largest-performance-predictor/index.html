Evidence¶

Spitzer 2025¶

Spitzer, M. W. H., Moeller, K., Richter, E., Frede, L., & Bardach, L. (2025). A red button does it all: A red button nudges students to close their knowledge gaps in an intelligent tutoring system. Learning and Instruction 99 (2025) 102181. https://doi.org/10.1016/j.learninstruc.2025.102181

q2 · i? · causal · r1

Hierarchical linear regression on the badge-on period data (conditional R2 = 0.36, marginal R2 = 0.13, ICC = 0.26). Table 2 reports Knowledge gaps closed (student) b = 0.09 and (class) b = 1.04, both p < .001; the article states the class-level beta "was largest". No standardized effect size is printed for these coefficients.

"The results indicated a significant effect of closing knowledge gaps on students' performance. In particular, a higher relative number of closed knowledge gaps was associated with better performance (at the student-level and class-level)"
