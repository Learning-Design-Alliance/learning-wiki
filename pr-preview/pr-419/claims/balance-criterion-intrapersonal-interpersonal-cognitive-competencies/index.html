Blyth 2019¶

Blyth, D.A.; Borowski, T.; Farrington, C.A.; Kyllonen, P.; Weissberg, R.P. (2019). Ten Criteria for Describing and Selecting SEL Frameworks. Establishing Practical Social-Emotional Competence Assessments Work Group, Frameworks Briefs introductory series 3 of 3. https://consortium.uchicago.edu/publications/ten-criteria-for-describing-and-selecting-SEL-frameworks

q1 · i? · theoretical · r2

This is the brief's own conceptual argument for the Balance criterion, not a tested result. It asserts that intrapersonal competencies such as self-management, interpersonal skills such as social awareness, and cognitive competencies such as critical thinking all matter, and that "Frameworks that emphasize only one type are less balanced."

"Frameworks that emphasize only one type are less balanced. Similarly, we now know that social-emotional competencies involve not just behavioral skills"
