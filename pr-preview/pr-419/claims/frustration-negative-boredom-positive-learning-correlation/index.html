DeFalco 2018¶

DeFalco, J. A., Rowe, J. P., Paquette, L., Georgoulas-Sherry, V., Brawner, K., Mott, B. W., Baker, R. S., & Lester, J. C. (2018). Detecting and Addressing Frustration in a Serious Game for Military Training. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-017-0152-1

q2 · i1 · associational · r1

Pearson correlations between BROMP-observed affect frequencies and learning gains in the Experiment 1 baseline study (119 cadets, mean learning = −0.04). Frustration showed a marginal negative correlation: "r = − 0.169, n =1 0 0 ,p = 0.092".

"However, frustration was marginally significant and negatively correlated with learning outcomes (frustration, r = − 0.169, n =1 0 0 ,p = 0.092)."

DeFalco 2018 (2)¶

DeFalco, J. A., Rowe, J. P., Paquette, L., Georgoulas-Sherry, V., Brawner, K., Mott, B. W., Baker, R. S., & Lester, J. C. (2018). Detecting and Addressing Frustration in a Serious Game for Military Training. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-017-0152-1

Same correlational analysis of Experiment 1 data; boredom's positive correlation ("r =0 . 2 0 0", p = 0.046) was unexpected by the authors, while confusion, surprise, and engaged concentration correlations were not statistically significant.
