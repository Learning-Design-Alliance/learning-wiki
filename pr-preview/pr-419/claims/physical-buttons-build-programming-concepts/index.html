Bredder 2026¶

Bredder, E., Wilkens, K., Espinal, A., Vieira, C., Harris, P., Bailey, J., & Chiu, J. (2026). Roversa: A low-cost, multilingual robotics platform for K-12 computer science integration. Educational technology research and development. https://doi.org/10.1007/s11423-026-10628-9

q2 · i? · design · r2

Educator dialogue from the first session while assembling robots, coded under technology-interaction. Leonard and Leslie described why robotics helps students learn CS through physical manipulation, with Leslie adding the buttons let students "build upon it [basic directional programming]".

"The robots are huge because if you're just having them code on the computer, they don't physically see something happening… That's why this [Roversa] is cool, if I push this button, it does that."
