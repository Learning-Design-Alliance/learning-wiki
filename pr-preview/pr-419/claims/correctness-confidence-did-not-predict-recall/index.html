Xiaoyun Chen 2024¶

q3 · i? · associational · r2

Same binomial GLMM on 4010 incorrect-guess trials from 100 adults; the article reports "Correctness Confidence did not have a significant impact on test recall accuracy (β(logit) = 0.03, SE = 0.06, z = 0.58, p =.56)", different from the authors' hypotheses. No effect size printed.
