Evidence¶

Sun 2026¶

Sun, C., Major, L., Daltry, R., Obradovic, L., & Friedberg, A. (2026). Enhancing literacy and numeracy through teacher dashboards and digital personalised learning: an A/B/C test in Kenyan early years education. Education Tech Research Dev. https://doi.org/10.1007/s11423-026-10703-1

q3 · i? · causal · r2

Kruskal–Wallis H tests compared summative assessment scores across the three partitions for 68,666 learners from 4,155 schools. Significant partition differences emerged only for two literacy test units, with the Grouped Dashboard partition scoring highest.

"For the test unit “Letter sounds short”, the Grouped Dashboard partition significantly outperformed the List Dashboard partition (p <.001) and the control partition. The same was true for the test unit “Word sounds short”."
