Evidence¶

Uçar 2024¶

Uçar, S.-Ş., Aldabe, I., Aranberri, N., & Arruarte, A. (2024). Exploring Automatic Readability Assessment for Science Documents within a Multilingual Educational Context. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-024-00393-2

q2 · i? · design · r2

Feature-trend analysis across the three corpora using MultiAzterTest (125, 141 and 163 features for Basque, Spanish and English). Word length in Basque increases with grade (6.32 to 6.96) and Spanish left embeddedness rises (2.74 to 4.12), but other indices run counter to the expected trend, e.g. rare adjectives are mostly present in ESO-1 documents.

"The linguistic analysis carried out revealed few patterns across grades. This suggests that the beneﬁt of these particular linguistic features might be limited for the ARA models for classiﬁcation."
