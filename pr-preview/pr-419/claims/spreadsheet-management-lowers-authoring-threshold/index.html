Evidence¶

Luis de-la-Fuente-Valentín 2011¶

Luis de-la-Fuente-Valentín, Abelardo Pardo, Carlos Delgado Kloos. (2011). Generic service integration in adaptive learning experiences using IMS learning design. Computers & Education. https://doi.org/10.1016/j.compedu.2010.12.007

q2 · i? · design · r2

Questionnaire and group-discussion data from the workshop case study. Table 6 reports Q3.c at 3.19 and Q3.d at 3.88 out of 5; comments included "It's easy to analyse the received data" and storing registers so teachers can view students' progress. The authors contrast this with prior studies where IMS LD condition authoring was considered error prone.

"With no previous knowledge of the specification and no experience using IMS LD conditions, course participants had a positive opinion about the use of the spreadsheet."
