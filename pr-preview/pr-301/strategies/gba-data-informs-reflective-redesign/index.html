Use GBA data to identify perfunctory game moments and redesign them as reflective practices embedded in game-flow¶

Strategy · All strategies Evidence · no claims cited

Description¶

The article shows GBA data feeding back into game redesign: the semantic template served "as a tool to clarify how players should interact with the game cycles." In one cycle, a perfunctory click-through report screen was redesigned as an occasion for reflection-on-practice, with in-game consequences (making key resources available based on report recommendations) so that reflective practices were embedded in the game-flow rather than appended to it.
