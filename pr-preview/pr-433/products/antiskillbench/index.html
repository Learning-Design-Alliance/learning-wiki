AntiSkillBench¶

Description¶

AntiSkillBench is a benchmark dataset and evaluation suite created by Yongli Xiang et al. for assessing persona-skill privacy leakage, attribute disclosure, and behavioral impersonation risks in personalized LLM-based agent systems.

Components¶

Claims¶

  • Skill-level leakage is strongest for communication style and personality, not explicit demographics [+W]
  • Persona-skill distillation encodes substantial private information into skill artifacts, persisting across agent backbones and distillation protocols [+W]
  • Skill-equipped agents reproduce target users' attributes and language, enabling impersonation across unseen contexts [+W]
  • Active defenses (Privacy Sanitization, Adversarial Obfuscation) reduce but do not eliminate persona-skill leakage, leaving personality and background exposed [+W]
