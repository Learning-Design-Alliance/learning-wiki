Description¶

SMDEP is a free six-week residential science-enrichment programme run at 12 national sites for minority and socioeconomically disadvantaged undergraduates interested in medical or dental careers.

Components¶

  • Multi-site pipeline program with mixed component offerings across sites: SMDEP is implemented as a single program model across "12 sites across the nation," with variation in offerings: "Three sites offer only the program's medical component, whereas the others offer both the medical and dental components." This multi-site structure with site-level component variation is the implementation pattern the evaluation documents across sites. (Clemencia Cosentino et al. (2015))

Claims¶

  • The evaluation assesses SMDEP impacts on college graduation and medical or dental school matriculation using propensity score matching [+W]
