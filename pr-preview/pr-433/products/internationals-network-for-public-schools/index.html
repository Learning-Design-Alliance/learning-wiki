Internationals Network for Public Schools¶

Product or Programme · All products and programmes
Evidence · no claims cited

Description¶

The Internationals Network for Public Schools framework guides a network of schools serving recent immigrant and English-learner students through five principles covering collaboration, experiential learning, language–content integration, local autonomy, and a common learning model.

Components¶

  • Internationals Network five core principles for newcomer schools: The report describes the Internationals Network for Public Schools, a network of 28 schools serving recent immigrant and English-learner high school students, whose member schools align their work to five core principles: "1. Heterogeneity + Collaboration 2. Experiential Learning 3. Language + Content Integration 4. Localized Autonomy + Responsibility 5. One Learning Model for All." The model prioritizes relationships and social-emotional learning through cohorts, advisories, and interdisciplinary teacher teams with scheduled collaborative planning time. Localized autonomy lets each site tailor programming; at Oakland International this means operating as a full-service community school. (Charlie Thompson (2023))
