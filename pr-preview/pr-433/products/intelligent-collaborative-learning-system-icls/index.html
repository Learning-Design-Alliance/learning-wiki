Intelligent Collaborative Learning System (ICLS)¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

ICLS is a networked computer-supported collaborative-learning system developed by McManus and colleagues, incorporating the Group Leader Tutor to monitor and teach collaboration skills in Jigsaw teams.

Components¶

  • Group Leader Tutor: an ITS component that monitors and teaches collaborative skills in networked Jigsaw teams: The Group Leader (GL) Tutor was the software heart of the Intelligent Collaborative Learning System (ICLS), a client-server system on an Ethernet LAN using a shared FoxPro database. The authors state that 'The GL Tutor, a software process and the key contribution of our research, monitored and taught the effective use of collaborative skills.' It traced discussions through a finite state machine, compared used skills against optimal skills in the Collaborative Skills Network, assessed mastery by comparing successful uses to missed uses, and generated tutoring feedback based on previously stored feedback in a historical database. (McManus et al. (2015))

Claims¶

  • Students in the ICLS experiments were satisfied with the system and mostly found it useful for collaborating, but were concerned about its slowness [+W]
  • Using the ICLS improved students' knowledge of modular programming but produced no significant change in self-esteem or interest in the subject [+M]
  • Later research reported that students collaborated better and learned more when their collaborative work was monitored [+W]
