Description¶

A supplementary open dataset released by Hyoungwook Jin et al. containing college students' chatbot interaction logs, Vue.js code-edit snapshots, prompts, activity time, and knowledge and self-regulation measures for studying AI-supported programming help-seeking.

Components¶

Claims¶

  • Students rarely formulated questions specifying both knowledge component and scaffold type during chatbot problem-solving [+W]
  • The chatbot often provided more scaffold types than requested, and supplying classified question scope to the chatbot raised scaffold precision above .60 [+W]
