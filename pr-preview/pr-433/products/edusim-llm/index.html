EduSim-LLM¶

Description¶

EduSim-LLM is a zero-coding educational robotics platform developed by Shenqi Lu et al. that lets beginners control simulated robots through natural-language instructions using CoppeliaSim and LLM backends.

Components¶

  • EduSim-LLM, a zero-coding educational platform integrating LLMs with CoppeliaSim robot simulation: EduSim-LLM is an educational platform that integrates LLMs with the CoppeliaSim robotics simulator so users can control robots in natural language. Users type instructions and observe simulated robot behaviors, since it provides "a novice-friendly interface" allowing robot operation "without writing any code." It supports direct and autonomous interaction modes, multiple robot configurations including mobile robot teams and manipulators, and multiple LLM backends such as Groq's llama3-70b and Ollama's local llama3.1:8b. Its hierarchical pipeline comprises a natural language interface, an LLM-based instruction planner, a simulation control backend, and a Gradio user interaction frontend. (Shenqi Lu et al. (2026))

Claims¶

  • LLM-generated robot control code succeeds on 100%, 94.4%, and 88.9% of simple, composite, and complex instructions respectively [+W]
  • Natural language control requires less human operation time than manual control for all five complex tasks tested [+W]
  • A single natural-language command can be decomposed by an LLM into coordinated sequential action sequences for multiple robots [+W]
  • The article constructs an educational benchmark of 108 instruction instances grouped into simple, composite, and complex difficulty levels [+W]
