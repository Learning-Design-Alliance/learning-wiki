GAME: generic automated marking environment for programming assignments¶

Product or Programme · All products and programmes
Evidence · 1 claim (1 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

GAME is a generic automated marking environment developed by Blumenstein et al. for assessing university programming assignments in Java, C++, and C against instructor-supplied marking schemas and model solutions.

Components¶

  • GAME: generic automated marking environment for programming assignments: GAME is a system that "automatically assess programming assignments written in a variety of languages based on the "structure" of the source code and the correctness of the program's output." It currently marks Java, C++ and C programs. Instructors supply a "marking schema" specifying file locations and the model solution for each assessment item. (Blumenstein et al. (2008))

Claims¶

  • GAME's marks agree with a human marker's marks on student programming exercises and assignments [+W]
