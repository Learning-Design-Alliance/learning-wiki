MOOC Replication Framework¶

Product or Programme · All products and programmes
Evidence · no claims cited

Description¶

MORF, described by Gardner (2018), is a framework that supports controlled, privacy-preserving replication of predictive analyses across MOOC studies, courses, and datasets.

Components¶

  • MOOC Replication Framework (MORF): MORF, described as a close contemporary of SEERNet, "aims to facilitate more effective use of the data generated by online platforms for replication across studies, courses, and data sets" (Gardner, 2018). It provides a large, diverse data set collected from multiple MOOC offerings and a technical solution for running predictive models in a controlled environment, with parallels to SEERNet in offering evaluation as a service while protecting student privacy. (Looking Back to Move Forward)
