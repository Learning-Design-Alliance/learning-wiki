Publicly released UK Key Stage readability dataset of 20,000 balanced text chunks¶

Description¶

A publicly released corpus of 20,000 Project Gutenberg text chunks balanced across UK Key Stages 2–5 and linked to Lexile readability scores, created by Jordan J. Bird for matching literature texts to educational reading levels.

Components¶

Claims¶

  • Unimodal classification confuses Key Stage 4 with Key Stage 3, while the best multimodal model classifies Key Stages 4 and 5 perfectly [+W]
  • Fusing transformer text classifiers with a linguistic-feature neural network significantly outperforms unimodal models for UK Key Stage classification, with ELECTRA + ANN reaching F1 = 0.996 [+W]
  • BERT was the best unimodal text classifier for Key Stage classification with an F1 score of 0.75 [+W]
  • Neural networks on linguistic features classify Key Stages poorly, with deeper networks performing worse; the best (one hidden layer, 175 ReLU) reached F1 = 0.392 [~W]
