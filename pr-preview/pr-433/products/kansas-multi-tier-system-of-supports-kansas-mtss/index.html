Kansas Multi-Tier System of Supports (Kansas MTSS)¶

Product or Programme · All products and programmes

Description¶

A statewide framework run by the Kansas State Department of Education that organizes evidence-based academic and behavioral supports, assessment, data-based decision making, professional development, leadership, and implementation fidelity across Kansas public schools.

Components¶

  • Kansas MTSS framework: a system-level change framework integrating core components for academic and behavioral outcomes: The Kansas MTSS is a statewide framework aiming to improve outcomes for all students through system-level change across classroom, school, district, and state. It integrates effective-schools components into "a single framework for improved social and academic outcomes for all students." Core components include evidence-based curriculum, high-quality instruction, a comprehensive assessment system, data-based decision making, effective intervention, fidelity of implementation, ongoing professional development, and empowering leadership culture. Implementation features "frequent data-based monitoring for instructional decision making" and a continuum of evidence-based systemwide practices enabling rapid response to each student's needs. (Reedy et al. (2015))
