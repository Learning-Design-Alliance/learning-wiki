Description¶

A dataset assembled from 23 FutureLearn course runs across five University of Warwick MOOCs, containing learner clickstream activity, completion timestamps, derived time-spent measures, and optional demographic survey data for studying online-course participation and revenue-related outcomes.

Components¶

Claims¶

  • Machine learning models predict MOOC certificate purchasing with accuracies of 0.82–0.91 using only time spent on each course step [+W]
  • The run number (delivery iteration) is among the most representative features for predicting MOOC purchasing behaviour [+W]
  • MOOC certificate purchasing is rare: under 1% of enrolled learners purchase, with completion around 10% [+W]
