MuTAT (Multi-Touch Arithmetic Tool)¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

MuTAT is a tablet-based arithmetic assessment prototype developed by Adesina et al. that records learners’ stepwise touch interactions and solution traces.

Components¶

  • MuTAT: a multi-touch arithmetic assessment tool capturing solution steps via trace links: MuTAT (Multi-Touch Arithmetic Tool) is a tablet-based prototype for process-based computer-aided assessment in elementary mathematics. Its interface has a problem pane with draggable numeric values and a solution pane; a touch-and-hold gesture activates arithmetic operators, and interactions are recorded with timestamps and coordinates so that "visual representations of the process data is constructed" from traces of problem-solving actions. (Adesina et al. (2014))

Claims¶

  • Students' performance scores on the MuTAT touch-based assessment tool are comparable to paper-and-pencil test scores [+M]
  • Trace data from MuTAT can detect arithmetic strategy selection, with place-value strategy use varying across questions [+M]
