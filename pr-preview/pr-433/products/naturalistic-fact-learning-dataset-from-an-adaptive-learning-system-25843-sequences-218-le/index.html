Naturalistic fact-learning dataset from an adaptive learning system (25,843 sequences, 218 learners)¶

Description¶

An OSF-released dataset from Maarten van der Velde et al. containing naturalistic open-answer retrieval-practice sequences from 218 undergraduate cognitive psychology learners using an adaptive fact-learning system.

Components¶

Claims¶

  • Allowing ACT-R memory parameters to vary with the between-session interval produces a strong fit between model and recall data across timescales [+W]
  • A single time-invariant ACT-R forgetting function cannot simultaneously capture recall accuracy on short and long between-session intervals [+W]
  • Extrapolating from parameters fitted to a restricted range of between-session intervals produces worse predictions than time-variant fits [+W]
  • In 5-fold cross-validation, multi-bin time-variant model fits outperform single-bin fits, with diminishing returns beyond a 5-bin split and further gains from differentiating by learner and amount of practice [+W]
  • Optimal ACT-R parameter values change systematically and predictably with the length of the between-session interval [+W]
