Astus¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 design), q1 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

Astus is a model-tracing tutor framework whose knowledge-based system represents procedural and declarative task knowledge so its pedagogical module can generate interventions and instructional content.

Components¶

  • Astus's knowledge-based system: a knowledge representation approach in which each type of knowledge unit has a clearly defined semantic on which the MTT's pedagogical module can rely: Astus is a model-tracing tutor (MTT) framework whose knowledge-based system models the task as the teacher's instructions rather than as the procedural knowledge of an ideal learner. The article states this is "achieved by designing a knowledge representation approach in which each type of knowledge unit has a clearly defined semantic on which the MTT 's pedagogical module can rely on." Its procedural knowledge uses goals and procedures organized in a procedural graph comparable to hierarchical task networks; its declarative knowledge uses concepts, relations and functions accessed through a fixed task-independent query interface. This lets the pedagogical module "automatically generate interventions as well as the pedagogical content used to instantiate them." (Luc Paquette et al. (2015))

Claims¶

  • Astus's pedagogical module automatically generates next-step hint content from the task model, whereas frameworks such as TDK and CTAT require hint messages to be included in the model of the task [+W]
  • Astus diagnoses many learner errors without erroneous knowledge units by interpolating incorrect executions of procedures in the episodic tree [+W]
  • Astus prunes the episodic-tree interpolation search using two pre-computed methods to keep error diagnosis tractable despite exponential growth of interpolated branches in the worst case [+W]
