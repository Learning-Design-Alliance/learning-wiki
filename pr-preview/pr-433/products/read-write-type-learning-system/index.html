Read, Write & Type!™ Learning System¶

Product or Programme · All products and programmes
Evidence · no claims cited

Description¶

Read, Write & Type!™ Learning System is a game-like early-reading software program with supporting materials designed for beginning and struggling readers ages six to nine.

Components¶

  • Read, Write & Type!™ Learning System software and supporting materials: Read, Write & Type!™ is a software program with supporting materials "designed to teach beginning reading skills by emphasizing writing as a way to learn to read," developed for six- to nine-year-olds just beginning to read and for struggling readers and writers. Its main goal is helping students "develop an awareness of the 40 English phonemes" and associate each phoneme with letters and a keyboard finger stroke. Game-like computer activities with animated characters lead students through 40 lessons, each explicitly teaching one phoneme, with an activity book covering sound identification, rhyming, spelling, and dictation. (What Works Clearinghouse (2007))
