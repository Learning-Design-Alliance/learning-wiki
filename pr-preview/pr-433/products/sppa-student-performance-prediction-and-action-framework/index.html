SPPA: Student Performance Prediction and Action framework¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

An open-source web-based learning-analytics application developed by Alalawi et al. that builds course-specific performance-prediction models, identifies at-risk students, and supports targeted interventions across the course life cycle.

Components¶

  • SPPA: Student Performance Prediction and Action framework: SPPA is a web-based Learning Analytics Intervention framework covering the full course life cycle: Course Design, Course Delivery, and Course Evaluation. It lets academics generate course-specific predictive models from historical continuous assessment data, run predictions after each assessment, identify at-risk students via dashboards, and deliver personalised interventions. The article states that "SPPA is implemented as a web application and is accessible by course instructors (also called academics in this paper) and students via a web browser." It integrates pedagogical principles such as constructive alignment and Hattie and Timperley's feedback model, and is released as an open-source project. (Alalawi et al. (2024))

Claims¶

  • Academics piloting SPPA provided effective interventions and held positive views of the framework [+W]
  • Grounding LAI feedback in constructive alignment and the Hattie–Timperley feedback model structures personalised interventions [+W]
  • A self-service course-level framework lowers the infrastructure barrier to piloting learning analytics interventions [+W]
