Every Learner Everywhere Lighthouse Institution Program and Technical Assistance Model¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 qualitative), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A Gates Foundation-funded Every Learner Everywhere initiative in which a network of organizations helps participating colleges implement adaptive courseware in gateway courses through technical assistance, communities of practice, subgrants, and research support.

Components¶

Claims¶

  • Lighthouse institutions showed uneven baseline capacity for adaptive courseware implementation, lowest in course redesign capacity [+M]
  • Project leaders reported catalyzed changes in practice but concerns about rushed timelines and sustainability [+M]
