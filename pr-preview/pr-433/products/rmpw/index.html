RMPW¶

Product or Programme · All products and programmes
Evidence · no claims cited

Description¶

The RMPW software program, accompanied by online Stata code from Guanglei Hong et al., implements parametric and nonparametric RMPW procedures to support users' analytic decision making.

Components¶

  • RMPW software program and online Stata code: The article released two analytic tools to support users: online Stata code implementing the RMPW procedures and a stand-alone RMPW software program. The article states that "a detailed delineation of the analytic procedures is accompanied by online Stata code as well as a stand-alone RMPW software program to facilitate users' analytic decision making." These artifacts accompany the article's walkthrough of parametric and nonparametric RMPW. (Guanglei Hong et al. (2015))
