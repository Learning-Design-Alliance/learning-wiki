Open Source Physics (OSP) toolkit¶

Product or Programme · All products and programmes
Evidence · 6 claims (6 for) · 5 studies (4 design, 1 qualitative), q1–q2 · 0 of 5 report an effect size · 6 claims rest on one study

Description¶

A free, open-source physics software toolkit, including Easy Java Simulations and Tracker, developed for creating, customizing, analyzing, and sharing computer models and video-based investigations.

Components¶

  • Open Source Physics toolkit: Easy Java Simulations and Tracker for creating and customising free physics computer models: Open Source Physics (OSP) focuses on the design of computer models, such as Easy Java Simulations (EJS) and video modeling and analysis (Tracker). The tools are free, run on Windows, MacOSX and Linux with Java Runtime, and carry intellectual property rights that let teachers and students customise models to suit their teaching and learning needs. Students use them to investigate, explore and analyse data which is either real or simulated. (Wee Loo Kang (2013))

Claims¶

  • A Singapore teacher community has remixed 75 EJS models and lesson packages toward a national digital library [+W]
  • The OSP approach helps users overcome barriers in creating, using and scaling up meaningful ICT use in education [+W]
  • After a guided-inquiry lesson with the collision-carts simulation, students' self-reported knowledge of the physics increased and most rated the lesson enjoyable and valuable [+W]
  • Initial findings suggest video modeling pedagogy is suitable for active and deep learning through predicting, observing and explaining [+W]
  • Creating computational literature develops computational literacy even when code modification is minor [+W]
  • Student video analysis of vertical jumps yields a free-fall acceleration estimate close to the local value of g [+W]
