Open Learning Analytics Platform¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

An open learning-analytics software platform developed by the article's authors for educational stakeholders to implement, visualize, and integrate learning-analytics indicators.

Components¶

  • Indicator Editor: a no-code SSLA tool for user-controlled LA indicator implementation: The Indicator Editor is a no-code, low-cost, interactive LA tool implemented in React and Material Design within the Open Learning Analytics Platform. It guides students and teachers with data analysis and visualization knowledge through four steps—dataset selection, filters, analysis method, and visualization—to create personalized indicators, preview them, edit them, and embed Interactive Indicator Code in dashboards such as CourseMapper. The article states it is "a no-code, low-cost, interactive LA tool that enables educational stakeholders with knowledge of data analysis and visualization to implement LA indicators with minimal effort." (Joarder et al. (2026))

Claims¶

  • High-fidelity prototype evaluation found the form-like structure frustrating; a guided progressive-disclosure design replaced it [+W]
  • Low-fidelity prototype evaluation found initial UI options overwhelming and checkbox selections unintuitive [+W]
  • Supporting user interaction and control in the indicator implementation process positively affects transparency, trust, satisfaction, and acceptance in LA [+W]
