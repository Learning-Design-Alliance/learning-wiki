Student Performance and Learning Behavior Dataset for Educational Analytics (Zenodo, N = 14,003)¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 associational), q2 · 1 of 1 report an effect size · 3 claims rest on one study

Description¶

A CC0 Zenodo dataset of 14,003 anonymized higher-education student records compiled from two public Kaggle datasets for behavioral profiling, educational analytics, and adaptive-learning recommendation research.

Components¶

Claims¶

  • K-Means++ clustering of self-reported behavioral proxies yields six distinct, stable learner profiles (k = 6, Silhouette = 0.62) [+W]
  • The six clusters differ substantially in academic performance: Final Grade ANOVA η² = 0.770, with C0 exceeding C1 by 40.17 exam-score points [+W]
  • Cluster membership is significantly associated with gender, with a small-to-moderate effect (χ²(5) = 345.52, Cramér's V = 0.157) [+W]
