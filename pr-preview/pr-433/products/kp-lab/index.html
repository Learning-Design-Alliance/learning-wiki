Description¶

The KP-Lab toolset, developed by the European KP-Lab project, is a suite of digital tools for creating knowledge artefacts, coordinating collaborative knowledge-creation processes, supporting networked communities, and enabling reflection.

Components¶

  • KP-Lab toolset supporting four types of mediation, including the Visual Model Editor and analytic mirroring tools: The project developed and tested tools for four types of mediation: epistemic mediation for creating and working with knowledge artefacts, pragmatic mediation for organising and coordinating knowledge-creation processes, collaborative mediation for building and managing networked communities, and reflective mediation. Specific tools include the CASS-Query tool using 3G mobile phones, Map-It for collaborative knowledge creation in real time discussions, Activity System Design Tools (ASDT), Semantic Multimedia Annotation (SMAT) for video-based material, and the Visual Model Editor (VME) for creating and editing diagrams with predefined or custom visual languages.
