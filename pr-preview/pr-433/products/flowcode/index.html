Flowcode¶

Product or Programme · All products and programmes
Evidence · 5 claims (4 for, 1 against) · 1 study (1 design), q2 · 0 of 1 report an effect size · 5 claims rest on one study

Description¶

An AI-powered web-based creative-coding environment developed by Tseng et al. that combines code editors, live previews, code-structure flowcharts, and constrained LLM explanations to support novice learners iterating on web animations.

Components¶

Claims¶

  • An LLM-generated flowchart linking semantic feature descriptions to code across HTML, CSS, and JS files supports novice creative coders' orientation, navigation, and code understanding [+W]
  • In the pilot workshop, the LLM unreliably produced fill-in-the-blank snippets, often returning complete code solutions instead [-W]
  • Novice creative coders exhibited three distinct initial interaction patterns with Flowcode: flowchart-first, code-first, and prompt-first [+W]
  • Participants used the Flowcode LLM across all stages of their design process, most frequently asking for code explanations [+W]
  • Step-by-step explanations revealed one at a time, plus removed code auto-insertion and copy buttons, encouraged deeper engagement with generated explanations [+W]
