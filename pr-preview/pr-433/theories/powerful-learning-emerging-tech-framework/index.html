Powerful Learning with Emerging Technologies framework: three design principles¶

Theory · All theories
Evidence · no claims cited

Description¶

The report introduces a framework organizing guidance for developers, educators, and learners into three principles: Evidence-Based, Learner-Centered, and Skill-Building. Each principle is elaborated into practices and strategies; for example, Evidence-Based includes apply research, use meaningful measures, and leverage relevant expertise. The framework states that emerging technologies 'should build learners' agency, promote metacognition, and be designed for learner variability and accessibility so that every learner can leverage the tool to support their learning.' It is intended to guide product design, selection, and implementation.
