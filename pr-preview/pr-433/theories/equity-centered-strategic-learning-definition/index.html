Equity-centered strategic learning as a four-part organizational capability¶

Theory · All theories
Evidence · 1 claim (1 for) · 1 study (1 design), q1 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The article defines equity-centered strategic learning as an organizational capability with four linked parts: setting equity-focused goals, forming hypotheses about reaching them, building supportive culture and systems, and using information for ongoing improvement. It states this is "the set of efforts that enables organizations to set goals that contribute to increased educational equity" and that learning must itself be equity-centered.

Design Implications¶

Context¶

Requirements¶

  • Organizations must set goals, establish hypotheses, build supporting culture, practices and systems, and use information to improve their model on an ongoing basis.

Constraints¶

  • The definition is scoped to educational equity for Black and Latino students and students experiencing poverty, as stated by this partnership.

Target Learners¶

  • K–12 education grantee organizations and their staff
