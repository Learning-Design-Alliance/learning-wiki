Pennsylvania Teacher and Principal Evaluation Pilot (2010-2015)¶

Element · All elements

Description¶

A pilot of teacher and principal evaluation in Pennsylvania, running from 2010 to 2015, for which Mathematica produced value-added estimates in its first phase. The page lists the associated project with the time frame "2010-2015" and notes the report was "Prepared for: Team Pennsylvania Foundation" and "The Gates Foundation." The pilot used value-added models as part of educator evaluation.
