EXMARaLDA-based annotation scheme for negotiation of meaning and negative feedback in CMC data¶

Element · All elements
Evidence · no claims cited

Description¶

The study built a two-tier annotation scheme in EXMARaLDA Partitur Editor to code negotiation work and negative feedback across text and video data. Negotiation routines were annotated "as shown in Table 2" with tags for triggers (TLEX, TSYNT, TCONT), signals (SCR, SCC, SST), responses (RMIN, RSR, RPAR, RSC, RCOMPC) and reactions (REAC), on a speaker-dependent [NOM] tier separate from the verbal data tier [v]. Negative feedback was coded with tags EXCO, QUES, RECA, INC and SELCO (Table 3). EXAKT, EXMARaLDA's analysis and concordancing tool, was then used to count and analyse the tagged data, and the tool's ability to annotate both written and spoken language allowed all three CMC data types to be processed with the same tool.
