Technology-enhanced items (TEIs) as an assessment format adaptable to learning styles¶

Element · All elements
Evidence · 3 claims (3 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

Technology-enhanced items (TEIs) are an assessment item format that the article proposes developing based on students' learning styles. According to the abstract, "The authors suggest adapting student assessment utilizing technology-enhanced items (TEIs) developed based on students' LS may provide a more reliable measure of student ability." The element is positioned as a means of closing the identified gap between learning styles and assessment design in K-12 education.

Context¶
