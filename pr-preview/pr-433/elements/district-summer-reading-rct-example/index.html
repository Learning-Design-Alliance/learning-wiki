Real district example of an RCT on a summer reading program¶

Element · All elements
Evidence · no claims cited

Description¶

As an illustrative case, the guide includes "a real life example of how one district took advantage of an opportunity to learn whether a summer reading program worked." The example shows leaders how an opportunistic RCT was situated within an actual district program decision, complementing the guide's steps and question-and-answer material.
