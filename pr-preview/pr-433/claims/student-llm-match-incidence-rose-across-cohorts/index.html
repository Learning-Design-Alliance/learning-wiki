Correctness, Convergence, and AI-Generated Code Detection: A Longitudinal Study of Student and Large Language Model Code in Introductory Programming. https://arxiv.org/abs/2610.00863 doi:10.48550/arxiv.2610.00863

Observational cohort comparison of 29,970 final student submissions against 90,000 LLM attempts using MOSS with starter code excluded (Figure 2, Table 4). The article treats the interval tests as model-based descriptive annotations because of dependency in the data.

"Student–LLM match incidence was 1.06–1.19 times its 2021 rate in 2023 and 1.76–2.12 times that rate in 2025 (Figure 2). Every annotated incidence comparison had BH-adjusted 𝑞<. 001, including the small 2023 shifts."
