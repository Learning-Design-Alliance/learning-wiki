Smith 2025¶

Smith, D. D., Bartley, J. E., Peraza, J. A., Bottenhorn, K. L., Nomi, J. S., Uddin, L. Q., Riedel, M. C., Salo, T., Laird, R. W., Pruden, S. M., Sutherland, M. T., Brewe, E., & Laird, A. R. (2025). q2 · i? · associational · r2

Linear mixed-effects main effect of time on resting-state CAP metrics, controlling for demographics. Resting state showed the most widespread changes, with CAP-1 and CAP-4 decreasing and CAP-7 increasing in counts, temporal fraction, and persistence; many effects did not survive Benjamini–Hochberg correction.

"CAP-1 showed decreased counts (Δ = −1.942, puncorr < 0.001, pBH <0 . 0 0 1 ), temporal fraction (Δ = −0.019, puncorr < 0.001, pBH <0 . 0 0 1 ), and persistence (Δ = −0.202, puncorr = 0.036, pBH = 0.099)"
