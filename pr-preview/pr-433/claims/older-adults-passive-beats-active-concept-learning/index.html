Evidence¶

Zi-Wei Liang 2025¶

Zi-Wei Liang, Zhi-Jun Zhan, Ying-Chen Liu, Hong-Zhou Xu & Jing Yu. (2025). Interpersonal neural synchronization underlies interactive concept learning in older adults. npj Science of Learning 10:75. https://doi.org/10.1038/s41539-025-00368-5

q3 · i3 · causal · r2

Pre-registered mixed-design experiment (2 learner age × 2 learning approach, 27 young and 31 older learners in final analyses) using fNIRS hyperscanning during a social-psychology concept learning task. The significant age × approach interaction (F(1,56) = 44.97, p < 0.001, ηp2 = 0.45) showed "passive learning was more effective than active learning for older learners".

"Post hoc tests showed that passive learning was more effective than active learning for older learners (t(30) = 7.95, p < 0.001, Cohen’s d = 1.43), whereas the reverse was observed for younger learners ( t(26) = −4.02, p < 0.001, Cohen’s d = −0.77)."
