Evidence¶

Sweller 2010¶

Sweller, J. (2010). Element Interactivity and Intrinsic, Extraneous, and Germane Cognitive Load. Educational Psychology Review, 22, 123–138. https://doi.org/10.1007/s10648-010-9128-5

q1 · i? · theoretical · r2

Conceptual analysis in the article's abstract. The author argues that the same element interactivity construct can yield both load types, with the distinction resting on "whether element interactivity is essential to the task at hand"; no empirical test is reported.

"By defining extraneous cognitive load in terms of element interactivity, a distinct relation between intrinsic and extraneous cognitive load can be established based on whether element interactivity is essential to the task at hand or whether it is a function of instructional procedures."
