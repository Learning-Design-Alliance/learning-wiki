Wuji Lin 2024¶

Wuji Lin, Chenxi Lv, Jiejie Liao, Yuan Hu, Yutong Liu & Jingyuan Lin. (2024). Feature versus object in interpreting working memory capacity. npj Science of Learning 9:67. https://doi.org/10.1038/s41539-024-00279-x

q3 · i0 · causal · r2

Experiment 2, a within-subject change detection study with 40 right-handed college students comparing simple (single line) and complex (three superposed lines) items across set sizes 2–7. The main effect of complexity was significant ("F [1,39] = 821.349, p < 0.001"), with partial eta squared of 0.955.
