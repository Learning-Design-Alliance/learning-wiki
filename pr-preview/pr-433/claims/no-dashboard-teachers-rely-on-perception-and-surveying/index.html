Evidence¶

Ishari Amarasinghe; Davinia Hernández-Leo; H. Ulrich Hoppe 2021¶

Ishari Amarasinghe; Davinia Hernández-Leo; H. Ulrich Hoppe (2021). Deconstructing orchestration load: comparing teacher support through mirroring and guiding. Intern. J. Comput.-Support. Collab. Learn. https://doi.org/10.1007/s11412-021-09351-9

q2 · i? · causal · r1

ENA networks of six teachers' coded actions in the no dashboard condition. Strong co-occurrences appeared between individual and class interactions and between class interactions and perception; teachers reported being unable to follow activity evolution, e.g. "I had to ask students several times if they had finished the activity".

"the observation of absent connections between the node that represents announcements to class and other nodes in the ENA diagram suggests that in this condition teachers were not in a position to make announcements to the class regarding time available, phase transitions of the script and student participation."
