Craig Wright 2026¶

Craig Wright. (2026). Transcription is not generation: distinguishing non-generative AI tool use from academic misconduct in higher education assessment. International Journal for Educational Integrity. https://doi.org/10.1007/s40979-026-00234-w

q2 · i? · theoretical · r3

The paper reports, citing Weber-Wulff et al. (2023), a comparative study of fourteen commercially available AI detection tools which 'conclude that no tool tested reliably distinguished human-written from AI-generated text across all conditions'. The paper adopts this conclusion only to the extent supported in the cited source.

"Weber-Wulff et al. (2023), in a comparative study of fourteen commercially available AI detection tools published in this journal, conclude that no tool tested reliably distinguished human-written from AI-generated text across all conditions, and that false positives were a significant problem across all tools tested."
