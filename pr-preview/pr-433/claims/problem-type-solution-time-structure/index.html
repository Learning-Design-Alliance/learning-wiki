Evidence¶

Thevenot 2018¶

Thevenot, C., Dewi, J., Bagnoud, J., Wolfer, P., Fayol, M., & Castel, C. (2018). The use of automated procedures by older adults with high arithmetic skills during addition problem solving. https://eric.ed.gov/?id=ED

q3 · i3 · causal · r2

ANOVA on solution times across five problem categories in both age groups. "Large problems were solved slower (947 ms)" than +0 problems, which did not differ from small problems; ties (770 ms) and +1 problems (747 ms) were fastest.

"solution times varied as a function of Type of problems, F(4, 168) = 58.38, MSE = 1027741.17, ηp2 = .58, p < .001. Large problems were solved slower (947 ms) than problems involving 0 (835 ms, F(1, 42) = 32.71, ηp2 = .44, p < .001), which were not solved slower than small problems (809 ms, F(1, 42) = 2.14, p = .15)."

Related Claims¶

  • Older adults were slower than young adults overall on solution times, with no age difference in accuracy — related
  • Older adults' slowdown relative to young adults is far smaller for problems interpreted as procedurally solved than for retrieval-solved problems — related
  • Sign priming effects in addition occur for large, small, and +1 problems but not for tie or +0 problems in older adults — related
  • Presenting the '+' sign 150 ms before operands speeds up addition problem solving in expert older adults, replicating the effect found in young adults — related
  • Working memory demand increases with the complexity of arithmetic and math problems, including operand size and number of solution steps — related
  • Bayesian analyses strongly support sign priming for small addition problems in older adults but only anecdotal support for +1 problems — related
