q2 · i? · associational · r2

Regression Model 2 (N = 821) with socio-demographic controls: department (β = −0.221, p < 0.001) and income status (β = −0.084, p = 0.013) negative; education level (β = 0.215, p = 0.001) positive on job search anxiety.

"In Model 2, the department variable ( p < 0.001, β = − 0.221) and income status ( p = 0.013, β = − 0.084) were significantly and negatively associated with job search anxiety. By contrast, the variable representing education level ( p = 0.001, β = 0.215) had a significant positive effect on job search anxiety."
