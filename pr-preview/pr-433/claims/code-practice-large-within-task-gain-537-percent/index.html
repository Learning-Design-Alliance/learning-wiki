Evidence¶

Dearborn 1918¶

Dearborn, W. F., and Brewer, J. M. (1918). Methods and Results of a Class Experiment in Learning. The Journal of Educational Psychology, Vol. IX, No. 2. https://psycnet.apa.org/journals/edu/9/2/

q2 · i? · causal · r1

Class practice series with a class of about thirty-five educational psychology students, one five-minute trial each morning and afternoon for about two weeks. The article reports "The average number at the start was 43" and the highest-record average of 239, stated as a 537% improvement in speed of writing code.

"The average number at the start was 43, and the average of the highest records made was 239, a percentage of 537%."

Discussion¶

Related Claims¶

  • The practiced group exceeded the control group on three of five tests (complex dotting, number code, letter code translation) by 5, 9, and 15 percent respectively, but did no better on digit-symbol substitution and slightly worse on digit-letter substitution. — related
  • Correlations between individual gains in code practice and gains in the tests were generally small and positive, with the largest correlation for the code-translation test and a slight negative correlation for Test 5 suggesting interference between translating into and from code. — related
  • Practice produced large within-task speed gains: averaging 89 per cent for letter cancellation and over 200 per cent for digit-for-letter substitution — related
  • Practice in substituting digits for letters transferred positively to writing symbols for digits but interfered with writing digits for symbols — related
  • Individual differences in substitution-test learning are large, ranging from 8 to 44 substitutions on the first day and reaching 214 for the best performer by trial sixteen — related
