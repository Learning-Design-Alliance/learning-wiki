The review reports, from van der Wilt et al. (2016) (N = 54 children aged 3.83–6.25, Nijmegen Test for Pragmatics, correlation analyses, cross-sectional design), that competence "was associated with peer acceptance (although only for boys), but not with peer rejection." No effect size is printed.
