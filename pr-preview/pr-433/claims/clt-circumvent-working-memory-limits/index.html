Kirschner 2002¶

Kirschner, P.A. (2002). Cognitive load theory: implications of cognitive load theory on the design of learning. https://dspace.library.uu.nl/handle/1874/16884

q1 · i? · theoretical · r2

Theoretical statement in the editorial's abstract, presented as the theory's account rather than a tested result. It states that "the limitations of working memory can be circumvented by coding multiple elements of information as one element in cognitive schemata" and by automating rules and using more than one modality.
