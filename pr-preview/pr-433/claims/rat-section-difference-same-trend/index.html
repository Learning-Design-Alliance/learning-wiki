Evidence¶

Peterson 2015¶

Peterson, E.K. and Carrico, P. (2015). Laboratory Exercise in Behavioral Genetics Using Team-based Learning Strategies. Bioscene 41(2). https://visionandchange.org/files/2011/03/Revised-Vision-and-Change-Final-Report.pdf

q2 · i? · design · r2

Repeated Measures ANOVA (SPSS v. 22.0) comparing RAT scores between the two course sections, which took different RAT versions testing the same concepts. The article reports "a significant difference (p < 0.0001) between the two sections" while both sections showed the team-over-individual trend.

"We found a significant difference (p < 0.0001, see Figure 4B) between the two sections. However, each section followed the same trend: the students performed higher on the team portion of the RAT than the individual RAT."
