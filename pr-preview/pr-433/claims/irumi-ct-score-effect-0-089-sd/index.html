Evidence¶

Emma Näslund-Hadley 2026¶

Emma Näslund-Hadley, Juan Manuel Hernández-Agramonte, Humberto Santos, Pablo Zoido. (2026). Impact of an educational robot-based intervention on second-graders computational thinking skills: experimental evaluation of the Irûmi program in Paraguay. Education Tech Research Dev. https://doi.org/10.1007/s11423-026-10675-2

q3 · i0 · causal · r2

Cluster RCT with 104 treatment and 103 control schools; OLS with baseline CT score, controls, strata fixed effects, school-clustered SEs. The article reports the program "improved students' CT score by 0.089 standard deviations (SD)" (N = 1,871), a printed effect size of 0.089 SD, below d = 0.2.
