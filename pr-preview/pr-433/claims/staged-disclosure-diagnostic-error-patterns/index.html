Sara Riazi and Pedram Rooshenas. (2026). An Educator-Guided LLM Pedagogical Agent for Scaffolded Feedback in Conceptual Database Design. https://arxiv.org/abs/2610.00870 doi:10.48550/arxiv.2610.00870

q1 · i? · design · r2

Manual inspection of randomly sampled trajectories illustrating five divergence patterns (incorrect detail not exposed, contradictory diagnoses not disclosed, selective incorporation, incorrect target incorporated, correct diagnosis without incorporation). The article states these cases "do not estimate the prevalence of each pattern".

"In some Stage 1 trajectories, an inaccurate hidden diagnosis was used to select a related conceptual topic rather than being shown as detailed diagram feedback."
