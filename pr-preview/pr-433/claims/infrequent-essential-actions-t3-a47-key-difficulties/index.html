Shupin Li · Johanna Pöysä-Tarhonen · Päivi Häkkinen (2022). Patterns of action transitions in online collaborative problem solving: A network analysis approach. Intern. J. Comput.-Support. Collab. Learn (2022) 17:191–223 https://doi.org/10.1007/s11412-022-09369-7

q2 · i? · associational · r1

Author interpretation of the visualization of the transition network conducted by 83 pairs (Fig. 2), where edge weights ranged from 1 to 668 with a mean of 25.42 in the network. The authors "imply" that few dyads recognized "the importance of conducting these essential actions," calling them possible key difficulties.

"However, some essential actions (e.g., T3, A47) showed a lower frequency compared with other actions in the most efficient path. This implies that there are not many pairs that were able to recognize the importance of conducting these essential actions in the path to solve the problem, and these actions and related action transitions might represent key difficulties for the dyads."
