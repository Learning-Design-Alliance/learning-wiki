Loibl 2017¶

Loibl, K., Roll, I. & Rummel, N. (2017). Towards a Theory of When and How Problem Solving Followed by Instruction Supports Learning. Educational Psychology Review, 29, 693–715. https://doi.org/10.1007/s10648-016-9379-x

q3 · i? · review · r?

The review's synthesis of the mapped PS-I implementations associated design features with patterns in learning outcomes. It concludes that "PS-I fosters learning only if specific design features (namely contrasting cases or building instruction on student solutions) are implemented." No pooled effect size is printed in the supplied text.
