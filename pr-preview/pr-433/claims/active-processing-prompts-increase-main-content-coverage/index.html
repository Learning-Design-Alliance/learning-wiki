Sara Hiller · Stefan Rumann · Kirsten Berthold · Julian Roelle. (2020). Example-based learning: should learners receive closed-book or open-book self-explanation prompts? Instructional Science. https://doi.org/10.1007/s11251-020-09523-4

ANCOVA on instructional explanation processing in Experiment 2, controlling for pretest and chemistry grade, printed "F(1, 120) = 26.27, p < .001, ηp2 = .18"; Experiment 1 reported the corresponding main effect with ηp2 = .14.

"An ANCOVA showed that the active processing of instructional explanation prompts substantially increased the extent to which the learners covered the main content items of the basic instructional explanations in their text box entries, F(1, 120) = 26.27, p < .001, ηp2 = .18."
