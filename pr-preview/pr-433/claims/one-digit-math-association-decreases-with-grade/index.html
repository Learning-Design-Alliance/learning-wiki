Related Claims¶

  • SYMP Test performance correlates moderately and significantly with mathematics achievement in every grade of primary school, for both one-digit and two-digit comparison — related
  • Both symbolic and nonsymbolic magnitude processing correlate with subtraction accuracy, but subtraction speed is associated only with symbolic tasks — related
  • Children's symbolic magnitude comparison performance improves significantly across all primary school grades — related
  • Symbolic number comparison accuracy is the only number sense measure with a significant partial correlation with math — related
  • The SYMP Test shows convergent validity with a computerized version of the task and discriminant validity against spelling achievement — related
