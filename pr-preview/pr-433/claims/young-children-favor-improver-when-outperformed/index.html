Evidence¶

Ying Hu 2026¶

Ying Hu, Yuhang Shu & Xin Zhao. (2026). Children consider changes in performance over time when reasoning about academic achievements. npj Science of Learning. https://doi.org/10.1038/s41539-026-00401-1

q3 · i? · causal · r3

Preregistered Study 3 with 4- to 6-year-olds: children significantly favored the improving character in the outperformed condition (B = 0.97, p = 0.024) but not in the matched condition (p = 0.089); there was no significant age effect (p = 0.201).

"theﬁnal model revealed a signiﬁcant condition effect (B = 1.56, SE = 0.34, 95% CI [0.90, 2.22], p < 0.001; β = 1.56); children evaluated the improving character more favorabl y in the outperformed condition (M = 0.65, SD = 0.38) compared to the matched condition ( M = 0.41, SD = 0.39)."

Ying Hu 2026 (2)¶

Ying Hu, Yuhang Shu & Xin Zhao. (2026). Children consider changes in performance over time when reasoning about academic achievements. npj Science of Learning. https://doi.org/10.1038/s41539-026-00401-1

q3 · i? · causal · r2

Study 3 inference analysis: the overall condition effect was significant (B = 0.83, p = 0.015), but follow-up exploration showed it held only for hardworking (p = 0.032), not smart (p = 0.224); hardworking responses in the outperformed condition were a trend (p = 0.067).

"Follow-up exploratory analysis revealed that the condition effect was only signi ﬁcant for the hardworking measure ( B = 1.15, SE = 0.54, 95% CI [0.10, 2.21], p = 0.032; β = 1.15), but not the smart measure ( p = 0.224)."
