Evidence¶

Haifang Liu 2026¶

Haifang Liu. (2026). AI-enhanced legal pedagogy: a case study of generative AI integration in property law courses. Education Tech Research Dev. https://doi.org/10.1007/s11423-026-10698-9

q1 · i? · causal · r2

Analysis of iFlytek Spark usage logs recording interaction frequency, duration, and query types for the experimental group; frequencies are percentages of usage, not effect sizes, so impact is null. The article notes several usage types may occur simultaneously for the same students.

"case analysis help usage dominates with a usage rate of 42%, with students submitting case scenario queries asking for appropriate issues, rules, and framework applications. Socratic dialogue simulation usage follows with 38%"

Haifang Liu 2026 (2)¶

Haifang Liu. (2026). AI-enhanced legal pedagogy: a case study of generative AI integration in property law courses. Education Tech Research Dev. https://doi.org/10.1007/s11423-026-10698-9

q1 · i? · causal · r1

The authors' interpretive statement drawn from the usage-log analysis in the GenAI interaction patterns section; it is an interpretation rather than a tested contrast, so it is coded as such with no effect size.

"Efficient patterns, which reflect learning outcomes, incorporate dialogue interactions rather than the passive analysis of AI, suggesting the importance of engagement with GenAI tools as learning partners over just using the tools as resources to answer questions."
