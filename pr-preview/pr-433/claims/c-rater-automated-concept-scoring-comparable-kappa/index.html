Evidence¶

Steven Burrows 2015¶

Steven Burrows, Iryna Gurevych, Benno Stein. (2015). The Eras and Trends of Automatic Short Answer Grading. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-014-0026-8

q2 · i? · review · r2

Review narration of the c-rater line of work (Sukkarieh and Stoyanchev 2009), which replaced manual holistic scoring described as taking 12 hours of human time per question with automated concept-based scoring and lexicon generation via stratified sampling. The review reports the kappa comparison as second-hand. No effect size is printed.

"Results indicate that the unweighted kappa values for the automatically built models are “comparable” to the manually built models for 11/12 scenarios. The remaining scenario had seven concepts, which was the highest number of concepts among all scenarios"
