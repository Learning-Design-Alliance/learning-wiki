Evidence¶

Ines Zeitlhofer 2024¶

Ines Zeitlhofer, Joerg Zumbach, Judith Schweppe. (2024). Complexity affects performance, cognitive load, and awareness. Learning and Instruction 94 (2024) 102001. https://doi.org/10.1016/j.learninstruc.2024.102001

q3 · i3 · causal · r1

In the one-factorial between-subjects MANOVA (N = 98), with time, moves, GCL, meta-awareness, and intrinsic interest as dependent variables, the omnibus test showed "a strong main effect of task complexity" with printed effect size η2 = 0.50.

"The analysis revealed a strong main effect of task complexity on the dependent variables (F (11,74) = 6.58, p < .001, η2 = 0.50)."
