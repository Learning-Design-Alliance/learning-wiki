Evidence¶

Sydney Enock Msonde 2017¶

Sydney Enock Msonde, Jan Van Aalst. (2017). Designing for interaction, thinking and academic achievement in a Tanzanian undergraduate chemistry course. Education Tech Research Dev (2017) 65:1389–1413. https://doi.org/10.1007/s11423-017-9531-4

q3 · i? · design · r3

Chi-square tests on coded inquiry-thread data from forums 1, 3 and 5, using a scheme adapted from the Practical Inquiry Model. The article reports no first-iteration difference (p [ 0.05) and significant second- and third-iteration differences in knowledge exploration; no effect size is printed.

"during the second and third iterations there were significant differences in knowledge exploration between the students in the two treatments, v2 (df = 5, N = 68) = 12.369, p = 0.03, and v2 (df = 5, N = 68) = 11.663, p = 0.04 respectively."

Sydney Enock Msonde 2017 (2)¶

Sydney Enock Msonde, Jan Van Aalst. (2017). Designing for interaction, thinking and academic achievement in a Tanzanian undergraduate chemistry course. Education Tech Research Dev (2017) 65:1389–1413. https://doi.org/10.1007/s11423-017-9531-4

q3 · i? · design · r3

Chi-square tests on coded knowledge-integration acts (building on others' ideas, bridging with authoritative sources, reflective statements). Differences between treatments emerged only in iterations 2 and 3; no effect size is printed. The article notes advances were "much higher in the HIL environment".

"Chi square tests revealed no differences in knowledge integration during the first iteration, v2 (df = 2, N = 68) = 4.798, p [ 0.05. However, there were significant differences in knowledge integration during the second and third iterations, v2 (df = 2, N = 68) = 27.055, p \ 0.001, and v2 (df = 2, N = 68) = 4.798, p = 0.027, respectively."
