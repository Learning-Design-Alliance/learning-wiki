q2 · i? · design · r2

Same ablation series on the hybrid models; consistent drops across prompts indicated a feature type contains trait-relevant information not captured by embeddings or other features.

"Throughout traits, length features, in particular, emerged as an essential feature type capturing important and unique text characteristics for judging the student essays."

Discussion¶

Related Claims¶

  • Addition tests show trait-specific feature groups that most consistently enhance embedding-based models: morphological complexity for content, length for organization, and lexical sophistication, error, and occurrence features for language — related
  • A response-length-only baseline scores poorly, showing scores depend on broader linguistic features — related
  • For trait-specific automated essay scoring trained on a single resource, feature-based DNNs slightly outperform embedding-based DNNs, winning 11 of 16 trait-prompt comparisons — related
  • Adding fluency features to content features sharply increases scoring QWK for every prompt — related
  • Ablation study: removing any component lowers evaluation AUC, and removing all additional features yields the lowest public and private AUCs — related
  • Removing grammar and vocabulary features drops scoring QWK by 7-13% across prompts — related
  • Complex DNN architectures offer little advantage over simple linear ridge-regression baselines for trait scoring, implying nonlinearities and interactions were of minor importance — reports the opposite
  • Holistic scoring of German university students' essays posed significant challenges to both a neural model and an SVM with n-gram features — related
