Keyword/rule-based extraction of governance-proxy events from memory and lesson files in the single-investigator case study. The article states these events are author-coded and require independent validation before being treated as definitive rates; no effect size is printed.

Anas H. Alzahrani 2026 (2)¶

Anas H. Alzahrani, MD, PhD, MPH. (2026). Persistent AI Agents in Academic Research: A Single-Investigator Implementation Case Study. arXiv preprint. https://arxiv.org/abs/2605.26870

q1 · i? · design · r2

Descriptive characterization of the governance-event classes accumulated in the same memory layer during the 115-day case. The supplementary taxonomy separates verification, correction, protocol, safety, and failure events and notes the aggregate count of 889 should not be used as a rate until classified.

"These included deployment safeguards, external-action checks, credential-handling rules, citation-verification rules, and lessons from duplicate or unsafe actions."
