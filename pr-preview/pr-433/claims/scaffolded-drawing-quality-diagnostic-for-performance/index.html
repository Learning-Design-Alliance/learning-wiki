Evidence¶

Julia Kollmer 2020¶

Julia Kollmer, Katrin Schleinschok, Katharina Scheiter, Alexander Eitel. (2020). Is drawing after learning effective for metacognitive monitoring only when supported by spatial scaffolds? Instructional Science. https://doi.org/10.1007/s11251-020-09521-6

q3 · i3 · causal · r3

Manipulation check in the randomized experiment: overall drawing quality correlated with posttest scores (r = 0.43, p < 0.001), but condition-split correlations showed quality was diagnostic "only when drawings were made with scaffolds". The difference between coefficients was significant.

"the quality significantly related to performance only when drawings were made with scaffolds (r = 0.70, p < 0.001), but not when made without scaffolds (r = 0.18, p = 0.35). The difference between both correlation coefficients was significant, z = − 2.49, p = 0.006."
