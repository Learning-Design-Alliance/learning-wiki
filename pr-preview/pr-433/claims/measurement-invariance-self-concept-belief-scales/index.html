q2 · i? · associational · r?

Longitudinal measurement invariance tests (configural, metric, scalar) across T1 and T2 for five constructs with all participants (N = 857), using ∆RMSEA ≤ .015 and ∆CFI ≥ –.01 criteria. Scalar invariance for the temporal comparison-related belief in German "could not be achieved (∆RMSEA = .024, ∆CFI = –.015)".

"Overall, the results indicated that configural and metric invariance were supported across nearly all constructs (∆RMSEA ≤ .015, ∆CFI ≤ –.007), with one exception for the metric invariance in the German self-concept (∆RMSEA = .010, ∆CFI = –.011)."
