Multiple case study coding of five transcribed sessions per teacher for eight students, using the Instructional Quality and Implementation Coding system. The high-gain teacher followed ISA-X explicit instruction templates; the typical teacher's students received only partial or inappropriate instruction on how readers set purposes.
