Comparative evaluation in the Results section reports the proposed DMO-GRU model outperforming deep learning approaches (GRU, LSTM, CNN-GRU) and classical models (Random Forest, XGBoost), with "91.2% accuracy, 90.8% F1-score, 90.1% precision and 92.5% recall". Table 2 lists these outcome values alongside training times.

"Evaluation results suggest that the proposed DMO-GRU model outperforms both deep learning approaches (GRU, LSTM, CNN-GRU) and classical machine learning models (Random Forest, XGBoost). Among all models, DMO-GRU showed the best results: 91.2% accuracy, 90.8% F1-score, 90.1% precision and 92.5% recall."
