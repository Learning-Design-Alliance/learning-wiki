Evidence¶

Keith B. Lyle 2022¶

Keith B. Lyle, Campbell R. Bego, Patricia A. S. Ralston, Jason C. Immekus. (2022). Spaced Retrieval Practice Imposes Desirable Difficulty in Calculus Learning. Educational Psychology Review. https://doi.org/10.1007/s10648-022-09677-2

q3 · i2 · causal · r2

Completely within-participants 2 (timing) × 3 (question order) ANOVA on quiz scores from the same calculus course experiment (N = 180) showed "performance was overall worse when questions were spaced" with ηp² = 0.051.

"There was a main effect of tim- ing, F(1, 179) = 9.64, p = 0.002, ηp 2 = 0.051, suc h that, as anticipated, performance was overall worse when questions were spaced (M = 0.78, SD = 0.13) versus massed (M = 0.81, SD = 0.13)."
