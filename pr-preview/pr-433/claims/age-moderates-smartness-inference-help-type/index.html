Evidence¶

Sierksma 2023¶

Sierksma, J. (2023). Children perpetuate competence-based inequality when they help peers. npj Science of Learning. https://doi.org/10.1038/s41539-023-00192-9

q3 · i? · causal · r2

Mixed logistic regression on Study 1 data showed a main effect of age for smartness inferences (β = 0.66, p < .001) and learning inferences (β = 0.76, p < .001). Simple slopes showed "Younger children (1 SD below the mean) thought both groups were equally smart".

"Younger children (1 SD below the mean) thought both groups were equally smart ( β = 0.08, SE = 0.18, p = .66, 95% CI = [−0.28, 0.44]) but thought groups that received hints would learn more ( β = 1.20, SE = 0.32, p < .001, 95% CI = [0.63, 1.96])."
