Evidence¶

Yimeng Sun 2026¶

Yimeng Sun, Haiyang Xin, Qiannan Niu, Shuang Li, Lingyun Huang, Gaowei Chen. (2026). Computational Thinking Development in AI Agent Creation: A Mixed-Methods Study. https://arxiv.org/abs/2605.14330 doi:10.48550/arxiv.2605.14330

q2 · i? · associational · r2

Hierarchical regression on N=80 students using Days 4-5 platform behavioral logs; iterative testing engagement was the sole behavioral predictor of self-efficacy gains, a statistically significant regression coefficient with no standardized effect size printed, bootstrap validation (BCa 95% CI [1.10, 116.78]) and cross-validation (R² = .38) reported as confirming model stability.

"After controlling for initial self-efficacy (𝛽 = −.52,𝑝 < .001), iterative testing positively predicted gains (𝛽 = .20,𝑝 = .050,𝛥𝑅² = .035)."
