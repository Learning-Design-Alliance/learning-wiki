Evidence¶

Blobstein 2025¶

Blobstein, A., Facciotti, M. T., Igo, M., Karger, D., Ravi, P., Sripathi, K., & Gal, K. (2025). #let's-discuss: Analyzing Students' Use of Emoji when Interacting with Course Readings. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-024-00401-5

q2 · i? · associational · r2

Analysis relating emoji use to cognitive engagement (Chi & Wylie framework) using a predictive model trained and run on a subset of the data (winter 2021), reported in Table 2. The article reports that "#i-think and #lets-discuss emoji mostly align with the ’C’ category CE". No effect size is printed.

"As shown in the table, #i-think and #lets-discuss emoji mostly align with the ’C’ category CE, which is used for posts that describe a new idea but do not reason about them."
