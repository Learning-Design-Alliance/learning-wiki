Evidence¶

Linda Froese 2022¶

Linda Froese, Julian Roelle. (2022). Expert example standards but not idea unit standards help learners accurately evaluate the quality of self-generated examples. Metacognition and Learning. https://doi.org/10.1007/s11409-022-09293-z

q3 · i2 · causal · r2

The same 2×2 factorial ANOVA on overall absolute accuracy showed a significant main effect of expert example standards, ηp2 = .09; idea unit standards and the interaction were not significant.

"However, there was a statistically significant main effect of expert example standards, indicating higher absolute accuracy (i.e., values closer to zero) in the groups with expert example standards, F(1, 127) = 11.90, p = .001, ηp2 = .09."
