  • Self-efficacy and motivation positively predict self-directed learning, with motivation the strongest direct predictor — related
  • Self-efficacy has a significant positive effect on motivation among undergraduates using generative AI — related

  • Reflective AI use predicts programming self-efficacy and engagement, while PSE does not predict engagement (survey SEM) — related
