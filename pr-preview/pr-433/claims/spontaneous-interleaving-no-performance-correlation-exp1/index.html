Evidence¶

Roman Abel 2024¶

Roman Abel, Anique de Bruin, Erdem Onan, Julian Roelle. (2024). Why Do Learners (Under)Utilize Interleaving in Learning Confusable Categories? The Role of Metastrategic Knowledge and Utility Value of Distinguishing. Educational Psychology Review. https://doi.org/10.1007/s10648-024-09902-0

q3 · i0 · causal · r2

Correlational analysis in Experiment 1 (N = 190) found "Informative between-category switches did not correlate with the performance in the category assignment task, r = − 0.02". The authors call this null finding a utilization deficiency and note it is at odds with previous research.

"Informative between-category switches did not correlate with the performance in the category assignment task, r = − 0.02, p = 0.407 (one-tailed)."
