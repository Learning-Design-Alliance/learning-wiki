q1 · i? · design · r1

Theoretical argument drawing on the premise that LLM generations "result from the interplay between instructions (prompts), training data, and system processes" (attributed to prior work the authors cite) and on the mutual constitution of language, thinking and knowledge in writing. This is an authors' interpretation, not an empirical finding.

"Just as writing shapes thought, a prompt shapes the output. Therefore, task definition is not a neutral procedural step but a constitutive element of knowledge production."
