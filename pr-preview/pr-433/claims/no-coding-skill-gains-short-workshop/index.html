Ioannou 2025¶

Ioannou, A., Miliou, O., Georgiou, Y., Timotheou, S., Barkhuus, L., & Rode, J. (2025). Learning design for short-duration e-textile workshops: outcomes on knowledge and skills. Education Tech Research Dev, 73, 443–463. https://doi.org/10.1007/s11423-024-10411-8

Analysis of the 22 participants' MakeCode screenshots (group data, post-test): "the final code closely resembled the sample code demonstrated in Session 1"; only the Orange tiger pair added extra code, and the Audi logo pair's project turned off at boot, showing a failure of applying coding skills.

"In general, the study did not document any advancement in children's coding skills."
