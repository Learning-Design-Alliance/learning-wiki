Evidence¶

Alberto Quilez-Robres 2020¶

Alberto Quilez-Robres, Alejandro González-Andrade, Zaira Ortega and Sandra Santiago-Ramajo. (2020). Intelligence Quotient, short-term memory and study habits as academic achievement predictors of elementary school: a follow-up study. https://doi.org/10.1016/j.stueduc.2021.101020

q3 · i? · associational · r2

Amos Graphics v.23 path model comparing an unconstrained model (coefficients free to differ between grades) against a fixed model (coefficients equal), using structural weights. The comparison was non-significant at p=.393; equivalence was not otherwise tested.

"The results of the model comparison indicate that there are no statistically significant differences between the regression coefficients presented in the both grades (3rd vs 4th grade) (DF=5; CMIN= 5.189; p=.393), therefore, the weights of the predictor var iables are the same in the two consecutive years."
