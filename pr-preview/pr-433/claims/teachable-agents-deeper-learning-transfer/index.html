Evidence¶

Pareto 2014¶

Pareto, L. (2014). A Teachable Agent Game Engaging Primary School Children to Learn Arithmetic Concepts and Reasoning. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-014-0018-8

q3 · i? · causal · r2

Authors' conclusion from the quasi-experimental study and mental-model change analysis with 443 students. The article states "teachable agents in educational games can help achieve deeper levels of learning that transfer outside the game"; no effect size is printed for transfer specifically.

"Thus, we conclude that teachable agents in educational games can help achieve deeper levels of learning that transfer outside the game"
