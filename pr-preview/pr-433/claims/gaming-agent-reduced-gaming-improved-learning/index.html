q2 · i? · review · r2

Classroom study of an automated intervention built on a gaming-the-system detector (Baker et al. 2006, as reported in this article). The article reports the agent "reduced gaming by half and improved gaming students’ learning relative to the control condition".

"This agent gave students supplementary exercises on material bypassed through gaming, and displayed displeasure when the student games. In a classroom study in the USA, this agent reduced gaming by half and improved gaming students’ learning relative to the control condition"
