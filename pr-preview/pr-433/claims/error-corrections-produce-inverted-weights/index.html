Evidence¶

Lorenz Weise 2022¶

Lorenz Weise, Saskia D. Forster, Siegfried Gauggel. (2022). Reverse-correlation reveals internal error-corrections during information-seeking. Metacognition and Learning (2022) 17:321–335. https://doi.org/10.1007/s11409-021-09286-4

q2 · i? · causal · r2

Model comparison in which changes-of-mind were selectively removed before computing simulated decision weights. The no-error-corrections model could not explain the low-confidence pattern; the only-error-corrections model reproduced the behavioral pattern.

"when only error-corrections are allowed, while changes from correct- to incorrect responses are removed ("only error-corrections"), the model is able to reproduce the pattern of results observed in the behavioral data."
