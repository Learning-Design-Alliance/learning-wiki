Sébastien Puma 2018¶

This is a definitional/descriptive statement from the article's abstract about how Cognitive Load Theory has historically used working memory models: capacity models viewing working memory as "a discrete number of slots (i.e., chunks)". It frames the article's contribution rather than reporting a tested result.

"For a long time, Cognitive Load Theory has considered working memory models as tools to advance research on learning. It has used working memory capacity models, where working memory is viewed as being composed of a discrete number of slots (i.e., chunks) that can be kept active."
