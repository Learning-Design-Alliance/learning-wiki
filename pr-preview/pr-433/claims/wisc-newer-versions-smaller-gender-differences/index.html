Evidence¶

D. Giofrè · K. Allen · E. Toffalini · S. Caviola 2022¶

D. Giofrè · K. Allen · E. Toffalini · S. Caviola. (2022). The Impasse on Gender Differences in Intelligence: a Meta-Analysis on WISC Batteries. Educational Psychology Review. https://doi.org/10.1007/s10648-022-09705-1

q3 · i? · quant-synthesis · r3

Comparison of subtest-level pooled effect sizes from newer WISC versions (III/IV/V) against estimates using all versions, reported alongside the CHC-factor aggregates in Tables 1 and 2, which were all closer to zero with newer versions.

"for most subtests, the estimated mean effect sizes calculated using only the scores from the newer versions of the WISC, were generally smaller or they remained the same, but they were never larger, vis-à-vis the estimated effects using all scores."

Related Claims¶

  • Males show a small but significant advantage on WISC crystallized intelligence (gC, d = 0.14), driven mainly by the Information subtest — related
  • Gender differences in fluid intelligence (gF) on the WISC are negligible, and newer fluid-reasoning subtests show no difference or favour females — a narrower finding that bears on this claim
  • Males show a statistically significant but practically negligible advantage on WISC Full-Scale IQ (d = 0.09), which becomes non-significant with newer WISC versions — related
  • Females outperform males on WISC processing speed (gS) with a medium advantage (d = -0.37), larger for Coding than Symbol search — related
  • Males outperform females on WISC visual processing (gV) with a small advantage (d = 0.21), stable across battery versions — related
  • Gender differences on WISC working memory (gSM) are negligible and not statistically significant — related
