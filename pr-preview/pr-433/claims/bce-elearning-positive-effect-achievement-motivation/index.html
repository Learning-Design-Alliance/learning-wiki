Evidence¶

van Niekerk 2015¶

van Niekerk, J.F. (2015). The effectiveness of brain-compatible blended learning material in the teaching of programming logic. Nelson Mandela Metropolitan University. https://doi.org/10.1016/j.compedu.2016.09.008

q2 · i? · causal · r1

The dissertation reports a controlled experiment in which an e-learning intervention incorporating brain-compatible principles was administered, with impact "measured both qualitatively using an purpose-designed instrument and quantitatively through an analysis of the formal assessments". No effect sizes or test statistics are available in the supplied text, so the positive-effect finding is reported without magnitude.

"An e-learning based educational intervention which incorporated several brain-compatible learning principles was designed and administered as a controlled experiment intervention. The impact of the research experiment was measured both qualitatively using an purpose-designed instrument and quantitatively through an analysis of the formal assessments for this subject."
