Tanmay Sinha and Manu Kapur 2021¶

Publication-bias assessment of the meta-analysis using funnel plots, Egger's test, trim-and-fill, and p-curve analysis. The article reports that estimation "after accounting for publication bias suggested a strong effect size favoring PS-I (Hedge’ s g 0.87)", i.e., a bias-corrected effect size of Hedge's g = 0.87, which is large (g ≥ 0.8).

"Overall, an estimation of true effect sizes after accounting for publication bias suggested a strong effect size favoring PS-I (Hedge’ s g 0.87)."
