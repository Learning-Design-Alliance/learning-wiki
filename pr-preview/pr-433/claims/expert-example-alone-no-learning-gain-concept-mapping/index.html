Evidence¶

Elise H. Eshuis 2022¶

Elise H. Eshuis, Judith ter Vrugte, Ton de Jong. (2022). Supporting reflection to improve learning from self-generated concept maps. Metacognition and Learning. https://doi.org/10.1007/s11409-022-09299-7

q3 · i? · causal · r2

In the quasi-experiment (N = 144), post-hoc Bonferroni comparisons found no significant learning-gain differences between the example and control conditions; the authors state this in the discussion, contrasting prior example-benefit findings.

"the current study demonstrated that merely adding an example does not add to the value of students creating their own concept map (in terms of knowledge acquisition as measured by a pre- and posttest)"
