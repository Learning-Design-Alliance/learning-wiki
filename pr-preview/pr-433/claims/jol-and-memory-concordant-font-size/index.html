Evidence¶

Chang 2022¶

Chang, M., Brainerd, C.J. (2022). Association and dissociation between judgments of learning and memory: A Meta-analysis of the font size effect. Metacognition and Learning. https://doi.org/10.1007/s11409-021-09287-3

q3 · i? · quant-synthesis · r2

Synthesis across the JOL and memory meta-analyses in the same article. The authors conclude that "JOLs and memory accuracy both increase with font size", revising the classic dissociation account of the font size effect.

"This suggests that JOLs and memory accuracy both increase with font size, rather than being completely dissociated."

Related Claims¶

  • JOL-memory dissociation occurs only when font size ranges between very small and intermediate — reports the opposite
  • Larger fonts reliably increase both JOLs and memory only under specific boundary conditions: intermediate-to-very-large sizes, unrelated word lists, immediate JOLs, and brief study time — a narrower finding that bears on this claim
  • Larger font sizes produce modestly better memory than smaller font sizes, with a small but significant pooled effect — a narrower finding that bears on this claim
  • Larger font sizes produce higher judgments of learning than smaller font sizes, with a small-to-moderate pooled effect — related
