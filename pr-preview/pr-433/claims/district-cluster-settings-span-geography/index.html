Jacobson 2025¶

q2 · i? · associational · r?

Cluster analysis of state education data reported under Key Conclusion #2 for program design. The analysis grouped districts by English Learner populations, program sizes, and staff demographics and qualifications, finding similar settings across geographic boundaries, supporting cross-regional peer collaboration.

"Cluster analysis suggests that school districts with similar settings—specifically, similar English Learner student populations, program sizes, and instructional staff demographics and qualifications—span geographic boundaries."
