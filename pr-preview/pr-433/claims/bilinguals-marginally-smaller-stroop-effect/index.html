Blumenfeld Henrike K.; Marian Viorica 2011¶

q3 · i? · associational · r2

Nonlinguistic Stroop task (arrow direction vs. location) completed by the same 30 monolinguals and 30 bilinguals. "planned comparisons revealed a marginally larger Stroop effect for accuracy in monolinguals (Stroop size = 16.8%) than in bilinguals (Stroop size = 12.0%)"; group accuracy effect F(1,58) = 3.5, p = .07.

"planned comparisons revealed a marginally larger Stroop effect for accuracy in monolinguals (Stroop size = 16.8%, ηp2=.6) than in bilinguals (Stroop size = 12.0%, ηp2=.7, t(58) = 1.6, p = .05 (1-tailed)"
