Evidence¶

Pelánek 2025¶

Pelánek, R. (2025). Adaptive Learning is Hard: Challenges, Nuances, and Trade-offs in Modeling. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-024-00400-6

q2 · i? · theoretical · r2

Case analysis in the author's own system, whose mastery-criteria algorithm uses estimates of task time intensity: rapid guessing lowered those estimates, causing slower progress, frustration, and more guessing — "nearly half of all attempts" on some components.

"The consequence of this feedback loop was that for some knowledge components, the rapid guessing attempts comprised nearly half of all attempts, and it was not possible to reach mastery in a reasonable time."
