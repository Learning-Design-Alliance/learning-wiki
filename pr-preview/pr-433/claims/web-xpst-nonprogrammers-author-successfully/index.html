Evidence¶

Stephen B. Gilbert 2015¶

Stephen B. Gilbert, Stephen B. Blessing, Enruo Guo. (2015). Authoring Effective Embedded Tutors: An Overview of the Extensible Problem Specific Tutor (xPST) System. Int J Artif Intell Educ 25:428–454. https://doi.org/10.1007/s40593-015-0045-0

q2 · i? · design · r2

Course-assignment study in an HCI graduate class: ten non-programmers, given a worked example and brief videos, each authored three tutors for ACM Portal search tasks, scored on a 5-point rubric. "Eighteen (69 %) received a score of either 4 or 5".

"Eighteen (69 %) received a score of either 4 or 5, indicating that the tutor went above the minimum needed to scaffold the learner through the task."

Stephen B. Gilbert 2015 (2)¶

Stephen B. Gilbert, Stephen B. Blessing, Enruo Guo. (2015). Authoring Effective Embedded Tutors: An Overview of the Extensible Problem Specific Tutor (xPST) System. Int J Artif Intell Educ 25:428–454. https://doi.org/10.1007/s40593-015-0045-0

q2 · i? · design · r2

System-tracked timing in the same study, including time spent on learning materials; the quote shows declining time on task across the three successively authored tutors.

"we found that the time on task decreased as the participants moved from task to task: the average time to author Task A was 5.1 h, for Task B 2.5 h, and for Task C 1.7 h."
