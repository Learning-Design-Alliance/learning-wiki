Evidence¶

Shute 2016¶

Shute, V. J., Wang, L., Greiff, S., Zhao, W., & Moore, G. (2016). Measuring problem solving skills via stealth assessment in an engaging video game. Computers in Human Behavior, 63, 106-117. https://doi.org/10.1016/j.chb.2016.05.047

q3 · i? · associational · r2

Hierarchical regression analyses from the validation study predicting the overall estimate and each facet from MicroDYN components. The article reports significant R2change values for overall, planning, tool usage, and evaluating progress, and a non-significant result for analyzing givens; adding rule acquisition first contributed nothing (all p > 0.05).

"adding rule application significantly improved the model predicting the overall problem solving estimate ( R2 change ¼ 0.14, p < 0.05), planning ( R2 change ¼ 0.09, p < 0.05), tool usage ( R2 change ¼ 0.1 1,p < 0.05), and evaluating progress ( R2 change ¼ 0.1 1,p < 0.05). However, the same model did not significantly predict analyzing givens ( R2 change ¼ 0.05, p ¼ 0.12)."
