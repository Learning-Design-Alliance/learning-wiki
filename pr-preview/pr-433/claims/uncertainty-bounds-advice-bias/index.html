Evidence¶

Maayan Pereg 2024¶

Maayan Pereg, Uri Hertz, Ido Ben-Artzi and Nitzan Shahar. (2024). Disentangling the contribution of individual and social learning processes in human advice-taking behavior. npj Science of Learning 9:4. https://doi.org/10.1038/s41539-024-00214-0

q1 · i? · causal · r2

Theoretical argument in the Discussion: the task used a probabilistic reinforcement learning design in which the uncertainty level was high due to shifting card values, so the authors offer no empirical test of this boundary condition — it is a stated possibility, not a tested result.

"Hence, it is possible that a different (perhaps weaker) bias towards following advice would have been found with a different design in which the learning demands were lower"
