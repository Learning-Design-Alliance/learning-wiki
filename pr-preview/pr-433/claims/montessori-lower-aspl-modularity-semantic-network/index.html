Denervaud 2021¶

Denervaud, S., Christensen, A. P., Kenett, Y. N. & Beaty, R. E. (2021). Education shapes the structure of semantic memory and impacts creative thinking. npj Science of Learning 6:35. https://doi.org/10.1038/s41539-021-00113-8

q3 · i1 · associational · r2

Case-wise bootstrap comparison of semantic networks from the same verbal fluency data. The bootstrap test found "a signi ﬁcantly lower ASPL" for the Montessori group, t(1998) = −5.32, p < 0.001, d = 0.24.

"Additionally, the Montessori-schooled children had a signi ﬁcantly lower ASPL (M = 3.07, SD = 0.26) than the traditional-schooled children (M = 3.12, SD = 23), t (1998) = −5.32, p < 0.001, d = 0.24."

Denervaud 2021 (2)¶

Denervaud, S., Christensen, A. P., Kenett, Y. N. & Beaty, R. E. (2021). Education shapes the structure of semantic memory and impacts creative thinking. npj Science of Learning 6:35. https://doi.org/10.1038/s41539-021-00113-8

q3 · i1 · associational · r2

Case-wise bootstrap comparison of semantic network modularity for the two school groups. The test found "a signi ﬁcantly lower Q" in the Montessori group, t(1998) = −7.07, p < 0.001, d = 0.32.

"Finally, the Montessori-schooled children had a signi ﬁcantly lower Q (M = 0.582, SD = 0.03) than the traditional-schooled children (M = 0.589, SD = 0.02), t (1998) = −7.07, p < 0.001, d = 0.32."
