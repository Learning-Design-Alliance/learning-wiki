Ran Bi 2026¶

Ran Bi, Shiyao Wei, Yuanyiyi Zhou. (2026). Prober.ai: Gated Inquiry-Based Feedback via LLM-Constrained Personas for Argumentative Writing Development. https://arxiv.org/abs/2605.05598 doi:10.48550/arxiv.2605.05598

q2 · i? · design · r2

Functional validation observation of the two-layer gate. Because the first assessment layer is deterministic, the authors note this behavior "is reproducible and testable without a model call." No student-participant data was collected.

"The reflection gate reliably distinguished low-effort defenses from substantive ones: filler and one-word answers were coached rather than answered, while defenses that contained genuine reasoning engaging the specific question unlocked guidance."
