Evidence¶

Li 2020¶

Li, L., Luttgen, K., Huang, K., Weiser, G., Cornfield, O., Hess, H., Chow, E., & Schneider, M. (2020). Hero Elementary Playlist RCT Study in Formal School and Distance Learning Contexts. WestEd. https://www.cde.ca.gov/ds/dd/index.asp

q2 · i? · causal · r2

Teacher report on notebook implementation in the in-school implementation findings. Most teachers conducted a whole-class introduction using a projector but did not provide much instruction on responding to notebook prompts; teachers reported "technical difficulties related to projecting and loading the notebook activity". No effect size is reported.

"A few teachers noted some technical difficulties related to projecting and loading the notebook activity."
