Freydis Vogel 2016¶

Freydis Vogel, Christof Wecker, Ingo Kollar, Frank Fischer. (2016). Socio-Cognitive Scaffolding with Computer-Supported Collaboration Scripts: a Meta-Analysis. Educ Psychol Rev. https://doi.org/10.1007/s10648-016-9361-7

Between-outcome comparison within the meta-analysis testing the difference between the pooled collaboration-skills effect and the pooled domain-specific-knowledge effect; the printed test is zDiff = 3.24, p < .01, two-tailed, with no effect size for the difference itself.
