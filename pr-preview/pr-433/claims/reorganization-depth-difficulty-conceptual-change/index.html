Garvin Brod 2021¶

Theoretical argument from conceptual-change research, illustrated with taxonomic knowledge about whales: adding a habitat detail is enrichment; classifying orcas as dolphins requires differentiation; whales being mammals requires large-scale reorganization of the hierarchy. No effect size is printed.
