Evidence¶

Jaeseo Lim and Jooyong Park 2026¶

Jaeseo Lim and Jooyong Park (2026). Self-study followed by discussion enhances learning for high school students. Instructional Science (2026) 54:56. https://doi.org/10.1007/s11251-026-09801-7

q2 · i? · causal · r2

Simple mediation analysis using OLS path analysis (PROCESS Model 4), percentile bootstrap with 5,000 replications; model accounted for "73.86% of the variance in learning outcome, F (2, 18) = 25.43, p < .001."

"The indirect effect of condition on immediate learning through substantive comments was significant ( ab = 1.73, 95% CI [0.46, 3.38]), indicating partial mediation."

Jaeseo Lim and Jooyong Park 2026 (2)¶

Jaeseo Lim and Jooyong Park (2026). Self-study followed by discussion enhances learning for high school students. Instructional Science (2026) 54:56. https://doi.org/10.1007/s11251-026-09801-7

q2 · i? · causal · r2

Same mediation model with long-term learning scores; model accounted for 52.40% of the variance, F(2, 70) = 38.50, p < .001; the substantive-comment-to-outcome path (b) was not significant.

"the indirect effect of condition on long-term learning through substantive comments was not significant (ab = 0.11, 95% CI [-0.05, 0.27]). The direct effect of discussion condition on long-term learning (c') remained significant."
