Evidence¶

Lauren Sartain 2010¶

Lauren Sartain, Sara Ray Stoelinga, and Emily Krone. (2010). Findings From the First Year of the Excellence in Teaching Project in Chicago Public Schools: Rethinking Teacher Evaluation. Consortium on Chicago School Research, University of Chicago. http://ccsr.uchicago.edu/publications/Joyce_TE_yr1_finaldoc.pdf

q2 · i? · design · r2

Year-one reliability study using matched observations: external observers and school administrators observed the same classrooms simultaneously but rated independently; quantitative data included 277 matched observations across 44 pilot elementary schools. The study found "no significant difference between the ratings given by principals and those given by external observers" in aggregate.

"Considered in aggregate, there is no significant difference between the ratings given by principals and those given by external observers."
