Evidence¶

Hall 2014¶

Hall, L., Tazzyman, S., Hume, C., Endrass, B., Lim, M.-Y., Hofstede, G., Paiva, A., Andre, E., Kappas, A., & Aylett, R. (2014). Learning to Overcome Cultural Conflict through Engaging with Intelligent Agents in Synthetic Cultures. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-014-0031-y

q2 · i? · causal · r2

Pre-post far-transfer analysis of Bryant's Empathy Index (complete T1/T2 data n=119) with gender controlled as covariate; MIXER scores remained constant (T1 M=6.24, T2 M=6.30) while control slightly decreased. The quote reports no significant effects; no effect size is printed.

"No significant main effect of time or condition was found, and there was no significant interaction effect."
