Evidence¶

Nergiz Ercil Cagiltay 2015¶

Nergiz Ercil Cagiltay, Erol Ozcelik, Nese Sahin Ozcelik. (2015). The effect of competition on learning in games. Computers & Education. https://doi.org/10.1016/j.compedu.2015.04.001

q3 · i? · causal · r2

Independent-samples t-test on response time recorded by the game itself; the competition group "spent more time on responding to the questions in the game compared to the control group" (M = 165.65 vs 137.02, t(140) = 1.93, p = .05).

"However, the competition group ( M ¼ 165.65, SD ¼ 92.77) spent more time on responding to the questions in the game compared to the control group (M ¼ 137.02,SD ¼ 82.42), t(140) ¼/C0 1.93, p ¼ .05."
