Thomas M. Cavanagh 2023¶

Thomas M. Cavanagh, Christa Kiersch. (2023). Using commonly-available technologies to create online multimedia lessons through the application of the Cognitive Theory of Multimedia Learning. Education Tech Research Dev. https://doi.org/10.1007/s11423-022-10181-1

q2 · i2 · review · r2

The review reports meta-analytic results (Ginns et al., 2013) on the personalization principle, including "a large effect on cognitive processing (k = 4, d = .62, 95% CI [.13, 1.11])" and d = .54 for transfer, d = .46 for friendliness, d = .30 for retention.

"Personalization has a medium to large effect on perceived friendliness of instruction (k = 5, d = .46, 95% CI [.22, .70]), a large effect on cognitive processing (k = 4, d = .62, 95% CI [.13, 1.11]), a moderate effect on retention (k = 30, d = .30, 95% CI [.18, .44]), and a large effect on transfer (k = 25, d = .54, 95% CI [.25, .83])"
