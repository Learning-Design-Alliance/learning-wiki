Evidence¶

Minsun Kim 2026¶

Minsun Kim, S. Moonwara A. Monisha, Zihan Wu, David H. Smith IV. (2026). Exploring the Design Space of LLM-Based Programming Support in CS Education: A Scoping Review through the Lens of Assistance Governance. https://arxiv.org/abs/2607.21257 doi:10.48550/arxiv.2607.21257

q2 · i? · review · r2

Qualitative synthesis of the 90-system corpus coding Authority into four categories (system only, system + learner, system + instructor, system + learner + instructor), counting runtime features such as "selecting hint levels, enabling or disabling solution access". Authority was the most concentrated PEA dimension.

"Specifically, 69 studies (76.7%) were coded as System only. Systems with instructor-side runtime authority appeared in 11 studies (12.2%), and systems with learner-side runtime authority appeared in 9 studies (10.0%)."
