Rick de Graaff 1997¶

Rick de Graaff. (1997). The Experanto Experiment: Effects of Explicit Instruction on Second Language Acquisition. Studies in Second Language Acquisition, 19(2). https://doi.org/10.1017/S0272263197002064

q3 · i? · causal · r?

In the same two-group artificial-language experiment, the hypothesis that explicit instruction's effect would differ depending on the variable complexity was not supported: "no evidence could be reported" for it. No effect size is printed; equivalence was not tested.

"However, no evidence could be reported for the hypotheses predicting a differential effect of explicit instruction depending on the variables complexity andmorphology/syntax."
