The article proposes that analysis of gameplay data can be part of a feedback loop to improve a digital learning experience. Claims¶

  • Gameplay data analysis demonstrated multiple strategies and pathways available to Radix players for quest completion. [+W]
  • Use of certain tools in the Radix genetics quest may influence content-related game choices. [+W]
