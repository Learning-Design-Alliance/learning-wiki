Common Language for Multimodal Composition¶

Strategy · All strategies
Evidence · 3 claims (2 for, 1 against) · 7 studies (4 quant-synthesis, 2 causal, 1 review), q2–q4 · 4 of 7 report an effect size

Description¶

Creating a shared vocabulary or metalanguage empowers learners to analyze and discuss their multimodal composition process. The strategy involves selecting one mode (linguistic, visual, audio, gestural, or spatial), analyzing authentic examples together, and co-constructing class definitions of key terms. Explicitly connecting each mode to its use across subjects and contexts helps learners understand its versatility and application.

Design Implications¶

A shared metalanguage converts tacit design intuitions into discussable, revisable decisions — learners who can name a technique (e.g., salience, framing, vector) can critique and improve their own work rather than relying on vague impressions [~M]. Building the vocabulary through analysis of concrete exemplars, rather than delivering definitions first, grounds abstract terms in perceivable features and supports retention Dual coding improves recall. [+M]. The glossary itself functions as an Advance Organizer for subsequent composition and critique activities.

Context¶

Requirements¶

  • Time for discussion and analysis; vocabulary work cannot be compressed into a single lesson
  • Anchor charts, shared documents, or digital platforms for recording terms and definitions as they are co-constructed
  • A curated set of authentic multimodal exemplars in which the target features are clearly visible
  • Instructor fluency with multimodal terminology (e.g., Kress & van Leeuwen's grammar of visual design) or willingness to build it alongside learners
  • Curated examples of the target mode drawn from both academic and out-of-school texts (ads, film clips, infographics, picture books, game interfaces)
  • An anchor chart or shared digital reference where the class definition and examples accumulate
  • Structured time for class discussion and analysis, not just teacher presentation
  • A protocol for revising definitions as students encounter counterexamples

Constraints¶

  • Building a comprehensive glossary requires significant time investment that competes with composing time; vocabulary work that never feeds back into making becomes inert
  • Learners may struggle with abstract concepts if not grounded in concrete, contrasting examples
  • Overly technical metalanguage can raise extraneous load for novices Cognitive overload degrades learning. [-M] — introduce a small working set of terms per mode rather than a full taxonomy at once
  • Metalanguage alone does not improve composition; it must be coupled with Practice and Feedback tied to the named features
  • Time-consuming if every mode is treated exhaustively; one mode at a time with a tight analysis routine is more sustainable [-W]
  • Poorly chosen examples (all similar, or all atypical) produce fuzzy or overgeneralized definitions [~M]
  • Teacher facility with multimodal analysis matters; vague teacher talk produces vague student talk [~W]

Implementation Variability¶

  • Mode-by-mode sequencing: build vocabulary for one mode (often visual) before adding others
  • Learner-authored glossaries: students propose and define terms from their own analysis, with the class refining definitions
  • Cross-curricular mapping: explicitly pointing out how each mode operates differently in science, media studies, and the arts to show versatility
  • Digital annotation tools (e.g., hypothes.is, Thinglink) let learners tag named features directly on exemplars
  • Whole-class co-construction (stronger shared ownership) vs. small-group definitions compared and merged (faster, more discussion turns)
  • Digital anchor charts (shared slides, Padlet, Jamboard) allow embedding the actual multimodal examples rather than describing them
  • In secondary contexts, the routine can be run per discipline — the visual mode works differently in science diagrams than in persuasive posters

Target Learners¶

  • Learners new to multimodal composition who lack language for articulating design choices [~M]
  • Multilingual learners, who benefit from an explicit, accessible vocabulary with concrete referents Accessible vocabulary and syntax improves comprehension. [+M]
  • Advanced learners may find prescribed terminology constraining; allow them to extend or challenge the class glossary
  • K–12 students beginning multimodal composition, especially those who can do design moves but cannot yet name or explain them [~M]
  • Less necessary for students already fluent in design discourse, who may find the co-construction routine redundant [~W]

Target Learning Goals¶

  • Analytical literacy: naming and interpreting how modes make meaning
  • Metacognitive design talk: justifying compositional decisions during drafting and peer review
  • Transfer across contexts: recognizing that the same mode functions differently in different subjects and audiences
  • Metalinguistic and analytical: naming how modes make meaning
  • Intentional composing: applying the vocabulary to justify design choices in students' own work

Instructions¶

  1. Select one mode and gather 2–3 contrasting exemplars in which its meaning-making features are salient.
  2. Guide whole-class analysis using Direct Instruction to name key features, then Class Discussion to co-construct definitions grounded in the examples.
  3. Record agreed terms and definitions on an anchor chart or shared digital glossary; add examples alongside each definition.
  4. Have learners apply the vocabulary in their own composing and in structured peer critique, using Annotating to tag named features in drafts.
  5. Provide Feedback that uses the shared terms, reinforcing the metalanguage at the task and process level Feedback is most effective at task and process levels. [+S].
  6. Revisit and extend the glossary as new modes and contexts are introduced.

Related Strategies¶

  • Mentor Texts — exemplars supply the concrete instances from which shared vocabulary is induced
  • Peer Review — the shared metalanguage gives peer critique precise, actionable terms
  • Peer critique routines — the common language is what makes critique specific rather than generic
  • Mentor-text analysis — the example analysis phase is a mentor-text study applied to modes

Related Elements¶

  • Direct Instruction — efficient initial naming of features before learner-led analysis
  • Class Discussion — the vehicle for co-constructing and refining definitions
  • Annotating — tagging named features on exemplars and drafts links term to instance
  • Advance Organizers — the glossary structures subsequent analysis and composing

Patterns That Use This Strategy¶

  • Cognitive Apprenticeship — shared vocabulary supports the articulation and reflection phases
  • Discussion-Based Learning — metalanguage raises the quality and specificity of analytic talk

Examples¶

  • MODE multimodal glossary (2012, UCL Institute of Education) — a research-derived glossary of multimodal terms that classes can adapt: https://mode.ioe.ac.uk/whatismultimodality/
  • Australian Curriculum: English — requires a shared "language of visual design" (salience, vectors, framing) that teachers build with students before analyzing picture books and advertisements
  • A media arts unit where students co-construct definitions of shot type, gaze, and juxtaposition from film clips, then use those terms in storyboard peer critique
  • A grade 5 class studies the visual mode across book covers, infographics, and public-service posters, co-constructing definitions of salience, vector, and framing, then uses those terms in peer conferencing on their own infographic drafts.
  • A secondary media studies unit analyzes film title sequences for the audio mode (diegetic vs. non-diegetic sound, pacing, silence) before students storyboard their own sequences.
  • The New London Group's multiliteracies pedagogy frames this move: "Available Designs" — the named, teachable resources for meaning-making — precede "Designing" and "The Redesigned."
