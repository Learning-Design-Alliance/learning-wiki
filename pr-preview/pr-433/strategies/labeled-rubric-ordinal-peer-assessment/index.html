Use instructor-defined labeled rubric with ordinal levels to structure peer assessment and feedback¶

Strategy · All strategies
Evidence · 3 claims (3 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

Instructors define a set of labeled aspects (e.g., 'Quality of the composition', 'Economic analysis') each with an ordinal scale of levels, which peer graders use to assess answers. The article states that instructors could easily express assessment possibilities in terms of labels with levels and that students understood the task effortlessly. These labels serve both to structure grading and to generate explanatory feedback.

Design Implications¶

Context¶

Requirements¶

  • Instructors must provide a rubric with clear instructions and a list of labeled aspects with ordinal levels for graders to assess.

Constraints¶

Target Learners¶

  • university students across disciplines

Target Learning Goals¶

  • structured formative feedback on open-response assignments

Claims¶

  • Peer assessment systems can generate explanatory feedback for students by having graders assess multiple labeled aspects of an answer, not just an overall grade. [+W]
  • A matrix factorization model trained on sparse peer assessment data can predict grades for answers from students who did not participate in grading, reducing the grading burden on students. [+W]
  • A multitask matrix factorization approach that jointly learns grades across multiple assessment labels outperforms a single-task (binary relevance) baseline that learns each label separately. [+W]
