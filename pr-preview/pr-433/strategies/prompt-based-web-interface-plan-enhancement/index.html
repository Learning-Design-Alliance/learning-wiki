Use prompt-based LLM simulation and reflection via a web interface as a pre-class rehearsal for teaching plan refinement¶

Strategy · All strategies
Evidence · 1 claim (1 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The strategy guides a single LLM through three steps—simulating teacher-student interaction for a teaching plan, generating structured teaching reflections, and refining the plan using both—entirely through prompts on a web interface. The authors write that "This approach lowers the technical barrier for teachers, eliminating the need to write code to access LLMs," and that the visible simulation acts as a "thinking aloud" rehearsal before actual teaching. It is positioned as semi-automating teachers' daily preparation, teaching, and reflection cycles.

Design Implications¶

Context¶

Requirements¶

  • Prompt instructions must include few-shot examples of dialogs and reflections, lesson content, knowledge points, objectives, and at least two simulated student response types per teaching phase

Constraints¶

  • LLMs tend to directly provide correct answers, so prompts must use chains of thought or reasoning to elicit incorrect responses matching high school students' cognitive level

Target Learners¶

  • novice and pre-service teachers preparing high school mathematics lessons

Target Learning Goals¶

  • improved teaching plan quality and anticipation of student learning difficulties before class

Claims¶

  • LLM simulation, reflection, and refinement elevates the quality of LLM-generated teaching plans above their unenhanced baselines [+W]

Related Strategies¶

  • Teachers iteratively refine LLM-simulated student ideas with classroom context before instructional use
  • Co-create micro-intervention repertoires with generative AI through a seed-request-refine prompt sequence, with the instructor curating output
