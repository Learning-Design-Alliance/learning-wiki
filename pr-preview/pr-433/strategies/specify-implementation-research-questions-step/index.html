Specify implementation research questions as a distinct step in impact study design¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The guide treats the specification of implementation research questions as an explicit early step when embedding implementation research in an impact study. It 'provides steps and recommendations about ways to specify implementation research questions' so that what is implemented, how, and for whom is defined before data collection. This helps align implementation measures with the intervention's theory of action.

Design Implications¶

Context¶

Requirements¶

  • Research questions about implementation must be specified deliberately, using the guide's recommended approaches.

Constraints¶

Target Learners¶

  • Education researchers conducting impact studies

Target Learning Goals¶

  • Formulate implementation research questions for intervention evaluations

Related Strategies¶

  • Assess whether and how the planned intervention is implemented
  • Document the implementation context and measure the intervention-control contrast
  • Link implementation and impact findings when analyzing and reporting impact studies
  • Define the target population as the first step in designing a generalizable impact study
