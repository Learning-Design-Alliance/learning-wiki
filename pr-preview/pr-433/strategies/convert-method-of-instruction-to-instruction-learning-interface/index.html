Convert the data element Method of Instruction to Instruction/Learning Interface with morphology descriptions and paired generic outcomes¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The paper recommends restructuring the NCHEMS data element so that each instructional format is generic in kind and described in terms of the observable morphology of that format, and each generic instructional format has a generically described learning outcome. The author states he would like to see the datal element Method of Instruction converted to Instruction/Learning Interface, following his 1972 side-by-side chart of instructional formats and primary educational goals. Chart No. 1 instantiates this recommendation.
