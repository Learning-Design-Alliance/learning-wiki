Support district implementations of adaptive reading programs with a milestone-based implementation plan and ongoing data-informed coaching¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The page describes an implementation model in which the vendor partners with the district on a plan with key milestones: a discovery meeting, plan development, integration meetings for technical readiness, launch meetings, and a "Regularly scheduled cadence of communication" to monitor effectiveness data. Professional development includes initial live or virtual trainings, self-paced modules, ongoing coaching on using student data for instructional decisions, and regular impact reports.
