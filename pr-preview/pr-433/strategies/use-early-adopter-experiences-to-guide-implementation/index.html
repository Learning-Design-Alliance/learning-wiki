Use early-adopting districts' experiences to decide whether and how to implement alternative teacher-effectiveness measures¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The report positions its district profiles as implementation guidance for other systems. It states that "the districts' experiences can be used by other states and districts to decide whether and how to implement these measures," covering both value-added models on alternative assessments and student learning objectives. States and districts considering adoption can draw on these profiles before implementing.
