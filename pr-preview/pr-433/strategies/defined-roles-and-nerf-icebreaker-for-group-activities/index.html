Strategies

Mitigate reluctance to participate in group activities with clearly defined roles and an icebreaker interaction with the materials¶

Strategy · All strategies
Evidence · no claims cited

Description¶

Student feedback identified classmates' shyness or reluctance to fully participate as the main weakness of the activities. The author recommends mitigating this "by ensuring each student has a clearly defined role", and anecdotally "by also ensuring each student interacts with the Nerf toys before the start of the activities" — for example, a quick icebreaker in which each student in each group fires the Nerf gun once, with the first group to finish winning.
