Cueing category-level components of learned material as a low-effort reactivation strategy to support long-term retention¶

Strategy · All strategies
Evidence · 7 claims (3 for, 4 mixed) · 2 studies (1 causal, 1 quant-synthesis), q3–q4 · 0 of 2 report an effect size · 7 claims rest on one study

Description¶

The study shows that reactivation need not involve effortful full retrieval: briefly cueing a categorical feature of previously studied material (e.g., asking how many items belonged to a category without describing them) mitigated forgetting over long intervals. This component-cueing strategy is implementable as lightweight review questions distributed across a retention period. The authors conclude that "an effortful description of the target memory is not critical to enhance retention, at least gist-like information retention".

Design Implications¶

Context¶

Requirements¶

  • The reactivation content must pertain to the target memory

Constraints¶

  • Component cueing improved gist (images and details) but not memory precision; only descriptive reactivation improved details per image

Target Learners¶

  • adult university students

Target Learning Goals¶

  • long-term retention of studied material

Affordances¶

  • Reconsolidation Reactivation Strengthening Account

Claims¶

  • Component (category-cueing) reactivations mitigate forgetting relative to distractor controls but do not beat no-reactivation controls on image recall [~W]
  • Only descriptive reactivation improves memory precision (correct details per recalled image) [~W]
  • Descriptive reactivations significantly improve free recall of images compared with distractor and no-reactivation controls [+W]
  • At the 28-day retention interval, both descriptive and component reactivations outperform both controls, with relative gains of 58.8–67.2% for images and over 100% for details [+W]
  • Descriptive reactivations increase correct details recalled; component reactivations increase details only versus distractor [~W]
  • Reactivations do not increase false memories: no reactivation effect on falsely recalled images or details [+W]
  • The meta-analysis supports retrieval effort as a contributor to the testing effect [~W]

Related Strategies¶

  • Testing Effect
  • Retrieval Practice Activities
  • Flashcard Drill
  • Distributed Practice (Spaced Learning)
  • Apply retrieval practice (quizzes, peer teaching, flipped classroom) and monitor detail loss to balance gist and episodic memory
