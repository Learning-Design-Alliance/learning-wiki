Evaluate student-voice initiatives with a framework of key questions on institutional conditions¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article offers a framework consisting of key questions for evaluating whether a school's institutional conditions genuinely support student voice. The abstract states that one framework "suggests a number of key questions pertinent to any evaluation of the institutional conditions for student voice". It is intended as a practical evaluation tool for schools and researchers assessing consultation arrangements.
