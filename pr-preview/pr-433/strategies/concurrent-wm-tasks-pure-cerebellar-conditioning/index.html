Use concurrent working memory tasks during eyeblink conditioning to study cerebellar learning without awareness and volition¶

Strategy · All strategies
Evidence · 2 claims (1 for, 1 mixed) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article proposes presenting demanding working memory tasks concurrently with delay eyeblink conditioning to occupy cortical contributions and reduce awareness and volition. Participants did eight tests including Corsi, mental rotation, n-back (3-back), Stroop, and Wisconsin card sorting. The authors conclude that "having participants perform working memory tasks during eyeblink conditioning can be a viable strategy for studying cerebellar learning that is absent of in ﬂuences from awareness and volition."

Design Implications¶

Context¶

Requirements¶

  • Working memory tasks must be demanding, not directly require timing and motor skills, and be combinable with the conditioning protocol

Constraints¶

  • Working memory tasks did not prevent learning, only reduced the learning rate; the article notes several working memory tasks do involve the cerebellum

Target Learners¶

  • adult university students

Target Learning Goals¶

  • associative motor learning (conditioned eyeblink responses)

Claims¶

  • Concurrent working memory tasks significantly reduce conditioned response percentage [+M]
  • Working memory performance ranking does not predict conditioned response percentage [~W]

Related Strategies¶

  • Probe implicit statistical learning with concurrently demanding tasks to test whether learning is capacity limited
