Use simulated task environments for learning tasks so multimedia principles support inductive learning¶

Strategy · All strategies
Evidence · no claims cited

Description¶

For the learning-task component, the chapter recommends having students work on learning tasks in simulated task environments. The abstract states: "Students may work on learning tasks in simulated task environments, where relevant multimedia principles primarily facilitate a process of inductive learning." Multimedia design choices in these environments should therefore be selected for their support of inductive learning from the tasks themselves.
