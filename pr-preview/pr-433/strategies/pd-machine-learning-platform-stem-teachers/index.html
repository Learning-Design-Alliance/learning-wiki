Center teacher professional development on machine learning platforms so teachers can use AI in classrooms¶

Strategy · All strategies
Evidence · 1 claim (1 for) · 1 study (1 review), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The preface describes a professional development program for STEM teachers centered on machine learning, presented by Tang et al. It states the program "aims to introduce teachers to machine learning so that they can effectively utilize it in their classrooms," using a machine learning platform as the vehicle. Teacher preparation is presented as a key topic of the special issue, alongside grade band progressions.

Related Strategies¶

  • Use co-design approaches to develop grade-appropriate AI curricula for elementary students
  • Support program implementation with curriculum-embedded professional learning: workshops, planning and classroom coaching, leadership walkthroughs, and student-work data analysis
  • Layered professional learning and support for teachers implementing individualized software
  • Raise teacher awareness of new features through professional development and outreach
