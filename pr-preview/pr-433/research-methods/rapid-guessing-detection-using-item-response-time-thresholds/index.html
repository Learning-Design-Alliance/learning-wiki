Rapid-guessing detection using item response-time thresholds¶

Research Method · All research methods
Evidence · 6 claims (5 for, 1 mixed) · 5 studies (3 associational, 1 design, 1 theoretical), q1–q3 · 0 of 5 report an effect size · 6 claims rest on one study

Description¶

This framework identifies disengaged item responses on computer-based tests using response times—the seconds between item presentation and answer. Responses are "often termed “rapid guessing” because responses are, when effectively detected, correct at a rate no better than chance." Thresholds separate engaged from disengaged responses (e.g., 10% of average item response time, maximum 10 seconds), and student engagement is summarized as the proportion of non-rapid responses. The paper applies this framework to flag disengaged test events (rapid guessing on 10% or more of items) and re-estimate achievement for evaluation metrics.

Accounts¶

  • Rapid-guessing detection framework using item response time thresholds: This framework identifies disengaged item responses on computer-based tests using response times—the seconds between item presentation and answer. Responses are "often termed “rapid guessing” because responses are, when effectively detected, correct at a rate no better than chance." Thresholds separate engaged from disengaged responses (e.g., 10% of average item response time, maximum 10 seconds), and student engagement is summarized as the proportion of non-rapid responses. The paper applies this framework to flag disengaged test events (rapid guessing on 10% or more of items) and re-estimate achievement for evaluation metrics. (Kuhfeld et al. (2019))
  • Item response time as a measure of examinee test-taking effort classifying rapid-guessing versus solution behavior: Computer-based testing enables measuring examinee effort through response times: "At the item level, responses can be classified as exhibiting either rapid-guessing behavior or solution behavior based on the item response time." This study applied that classification approach to a commercially available, low-stakes instrument rather than the locally developed instruments used in most prior response-time research. (Steven Wise et al. (2013))

Claims¶

  • Disengaged test-taking rates varied greatly by subgroup, grade, and term in this sample [+M]
  • Response-time threshold-setting methods for detecting noneffortful item responses were compared using reading scores from over 728,923 US students in 2,056 schools [+M]
  • Rapid guessing can be identified from item-level response time, and its proper interpretation depends on contextual requirements [+M]
  • Information-based rapid-guessing threshold methods set thresholds more reliably than methods based on response accuracy or visual inspection [+M]
  • Rapid guessing on achievement tests varies across grades, subjects, and teachers [~W]
  • Detecting noneffortful responses requires setting response time thresholds that separate effortful from noneffortful responses [+W]
