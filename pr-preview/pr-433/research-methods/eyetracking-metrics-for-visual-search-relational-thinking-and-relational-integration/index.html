Eyetracking metrics for visual search, relational thinking, and relational integration¶

Research Method · All research methods
Evidence · 2 claims (2 for) · 1 study (1 causal), q3 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article develops an eyetracking framework for pinpointing the cognitive mechanisms behind improved reasoning. It operationalizes "efﬁciency of visual search as the number of ﬁxations needed to identify the relevant relations in a stimulus array, relational thinking as the total duration spent ﬁxating the relevant relations, and relational integration as the number of transitions between these relations." The metrics were refined after fixation-pattern analysis showed no clear-cut processing stages, and were defined on first-time-point data collapsed across groups to remain unbiased with respect to instruction effects.

  • Reasoning instruction produced a larger improvement than reading comprehension instruction in the ocular metric of relational thinking on the transitive inference task [+M]
