Pragmatic complexity–difficulty distinction for well-structured learning items¶

Research Method · All research methods
Evidence · 2 claims (2 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article proposes a pragmatic distinction between complexity and difficulty measures for well-structured problems in learning systems: "a complexity measure is based only on the item description, it does not use any data about student performance; a difficulty measure is based only on data about student performance". Complexity is "an intrinsic item characteristic" concerned with the structure of the item, while difficulty describes how hard the item is for students. The authors acknowledge that context, biases, and scaffoldings make the distinction "more convoluted", so measures "end up lying on a spectrum rather than at two clear poles".
