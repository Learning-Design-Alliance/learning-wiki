Three-construct framework for measuring challenge navigation in games¶

Research Method · All research methods
Evidence · 4 claims (3 for, 1 against) · 1 study (1 associational), q2 · 1 of 1 report an effect size · 4 claims rest on one study

Description¶

The article organizes in-game motivational behavior into three constructs: "challenge approach, challenge response, and general persistence". Challenge approach covers how players choose challenging situations and code; challenge response covers what players do after failure, such as reflecting on hints or downgrading code; general persistence is "simply the willingness to continue playing the game", without distinguishing easier from harder levels. The framework guided creation of eleven log-based measures validated against a classic persistence task and learning outcomes.

Claims¶

  • In-game willingness to solve hard levels with complex code is positively associated with posttest coding knowledge, controlling for pretest [+M]
  • Relative-Hards Solved Complex, a log measure of using complex code on personally difficult levels, predicts time spent on an unsolvable challenge task [+M]
  • Traditional challenge-navigation measures (level choice, replays, careful retries, hint reading, coding time) did not relate to learning outcomes [-W]
  • Downgrading to simpler code after failure on personally hard levels is negatively associated with persistence on an unsolvable task [+W]
