ICAP-CG lesson-task engagement coding protocol¶

Research Method · All research methods
Evidence · no claims cited

Description¶

The ICAP-CG is an observation protocol developed in prior work (Vosniadou et al., 2023) that codes lesson tasks minute-by-minute into Passive, Active, Active/Collaborative, Constructive, and Interactive engagement modes based on the verbs teachers use in task instructions. "The ICAP-CG was used to examine the transcripts of the filmed lessons on a minute-by-minute basis and to identify the lesson tasks." An Active/Collaborative code was added for cases where teachers asked students to work together using Active rather than Constructive or Interactive verbs.
