Synthetic benchmark development and stress-testing for trace-based learning-analytics evaluation¶

Research Method · All research methods
Evidence · 3 claims (1 for, 2 mixed) · 3 studies (2 design, 1 associational), q1–q2 · 0 of 3 report an effect size · 3 claims rest on one study

Description¶

When participant access is unavailable, release a synthetic dataset mirroring the intended logging schema and study design so that trace-based measures, modelling workflows, and analysis pipelines can be developed, compared, and stress-tested openly. The article states "the dataset is best interpreted as simulated evidence that supports benchmarking and method development", with methodological transparency (dataset, documentation, analysis blueprint) part of the contribution, to be validated later against ethics-approved deployments with participants.
