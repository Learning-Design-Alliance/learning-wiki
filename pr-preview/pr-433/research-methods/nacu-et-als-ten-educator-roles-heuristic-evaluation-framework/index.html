Description¶

The editorial centers the special issue on Nacu et al. (2018)'s framework of "10 educator roles that can cultivate autonomy and encourage learners as creative producers with 21st-century skills." The framework functions as a heuristic evaluation tool: "a heuristic evaluation of educator roles can provide guidance for designing these environments." All seven responses take this evaluation as their reference point.
