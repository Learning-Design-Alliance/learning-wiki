Adapted conjecture map framework for learning scientists and computer scientists¶

Research Method · All research methods
Evidence · 3 claims (3 for) · 1 study (1 qualitative), q1 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

An adaptation of Sandoval's conjecture mapping tool, created by Chang and Roschelle, that supports interdisciplinary design-based research teams in connecting learning theory to technical design. It distinguishes back-end technical decisions (e.g., training data for an AI model) from embodied front-end decisions users directly interact with, and it explicitly includes both beneficial and harmful consequences of technology as embodiments or mediating processes. In this report the framework structured a one-hour collaborative session in which the PECAS Mediator team filled out the map together on a Jamboard template.
