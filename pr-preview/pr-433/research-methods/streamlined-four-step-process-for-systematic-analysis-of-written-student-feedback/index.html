Streamlined four-step process for systematic analysis of written student feedback¶

Research Method · All research methods
Evidence · 4 claims (4 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The article proposes a repeatable mixed-methods pipeline that "combines text mining to pre-sort the open-ended feedback" with thematic analysis and multilevel modelling. It consists of four main steps: data collection, LDA topic model generation, evaluation of topic-model outcomes (qualitative via thematic analysis and quantitative via multilevel modelling), and reporting. The process is intended for programme- or institution-wide analysis of open-ended feedback rather than for an individual lecturer, and it connects qualitative findings to existing SET literature and quantitative feedback data.

Claims¶

  • LDA topic modelling of 6,087 written student feedback responses yields six SET-related topics [+W]
