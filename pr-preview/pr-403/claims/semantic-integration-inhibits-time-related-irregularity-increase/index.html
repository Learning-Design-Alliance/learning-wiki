Noguchi 2024¶

Noguchi, Y. (2024). Harmonic memory signals in the human cerebral cortex induced by semantic relatedness of words. npj Science of Learning, 9:6. https://doi.org/10.1038/s41539-024-00221-1

q3 · i0 · causal · r2

Experiment 1 comparison of IPI-SD between D1 and D5: NonSem trials showed prominent time-related SD increase (e.g., NonSemR T5 t(33) = 4.13, p = 0.0002, d = 0.22), which was "mitigated in Sem trials" (non-significant, p = 0.46 and 0.51), attributed to accumulating memory load without semantic support.

Related Claims¶

  • Semantically associated words induce similar distributions of inter-peak intervals: semantic structure is represented in IPIs, not in oscillation amplitude, and not explained by visual word similarity — related
  • Memorizing semantically related words increases the regularity of alpha-to-beta EEG oscillations (reduced IPI-SD) over posterior temporal cortex contralateral to the memory field — related
  • Semantic relatedness accelerates oscillation speed (reduced mean IPI / increased central frequency) only when memory words are memorized in the right visual field — related
