Regression sensitivity checks (Table 3) controlling for age group, gender, and year category, with GPA band entered as an ordinal predictor coded 1–9. All printed B coefficients were significant (p < 0.001 for four outcomes; p = 0.026 for negative affect); no standardised effect sizes are printed.
