Evidence¶

Benedict du Boulay 2015¶

Benedict du Boulay. (2015). Recent Meta-reviews and Meta-analyses of AIED Systems. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-015-0060-1

q2 · i? · review · r1

The letter reports the Kulik and Fletcher (2015) meta-analytic review, which found "similar sized improvements" to other reviews and distinguished studies using standardised tests from those using tests "more specifically tuned to the system providing tuition". No effect sizes are printed in the letter.

"Likewise Kulik and Fletcher ( 2015) found similar sized improvements but distinguished between studies that used standardised tests and those where the tests were more specifically tuned to the system providing tuition"
