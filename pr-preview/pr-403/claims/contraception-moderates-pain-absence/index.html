Stratified adjusted analysis by past-year oral contraceptive use in participants with complete contraception data (Table 2), using a likelihood ratio test for interaction. The stratum-specific Ns are as printed; the user stratum is small.

"menstrual pain was associated with higher rates of absen ce in participants not using contra-ception (N = 1093; 12.0%; 95% CI: 2.5, 22.5), but not in those using con-traception ( N = 165; −2.0%; 95% CI: −24.3, 26.9), although the CIs overlapped and there was no statisticalevidence of interaction."
