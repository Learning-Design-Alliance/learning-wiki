Evidence¶

Liang 2026¶

Liang, F., Zhu, Y., Li, R. & Fu, Q. (2026). Foil Type Modulates Developmental Changes in Statistical Learning Across Childhood to Adulthood. npj Science of Learning. https://doi.org/10.1038/s41539-026-00434-6

q3 · i? · causal · r2

Group × Foil Type GLMM (M2) on accuracy across Grades 1, 3, and 5 (N = 97); the omnibus interaction was significant in the frequentist analysis, while Bayesian evidence for the Group main effect favored the null (BF10 = 0.667).

"the frequentist analysis indicated a significant Group × Foil Type interaction, 𝜒2(2) = 6.57, 𝑝 = 0.037, B𝐹10 = 0.712"

Liang 2026 (2)¶

Liang, F., Zhu, Y., Li, R. & Fu, Q. (2026). Foil Type Modulates Developmental Changes in Statistical Learning Across Childhood to Adulthood. npj Science of Learning. https://doi.org/10.1038/s41539-026-00434-6

q3 · i? · causal · r1

Simple-effect analysis of the childhood interaction: Grade 5 exceeded Grade 1 (pHolm = 0.005, BF10 = 15.31) and Grade 3 (EMM = 0.636, pHolm = 0.049, BF10 = 3.11); Grade 1 vs Grade 3 was not significant (pHolm = 0.372).

"Simple effect analysis showed that for nonword foils, Grade 5 children (𝐸𝑀𝑀 = 0.714, 95% CI [0.660, 0.762]) significantly outperformed Grade 1 children (𝐸𝑀𝑀 = 0.603, 95% CI [0.544, 0.660])"

Liang 2026 (3)¶

Liang, F., Zhu, Y., Li, R. & Fu, Q. (2026). Foil Type Modulates Developmental Changes in Statistical Learning Across Childhood to Adulthood. npj Science of Learning. https://doi.org/10.1038/s41539-026-00434-6

q3 · i? · causal · r2

Simple-effect analysis of partword foil accuracy across the three child groups found no group differences; equivalence was supported by Bayesian factors below 1.00 for all pairs, but no effect size was printed for these null contrasts.

"However, for partword foils, no group differences emerged (all 𝑝𝐻𝑜𝑙𝑚 = 1, all 𝐵𝐹10 < 1.00)"
