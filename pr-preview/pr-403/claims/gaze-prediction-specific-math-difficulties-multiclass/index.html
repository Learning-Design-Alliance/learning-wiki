Three machine learning algorithms (KNN, Random Forest, SVM) applied to eye tracking features achieve an MCC around 0.78 in multiclass classification of five solution categories (correct, slope-height error, block-slope error, inverted-slope error, guess) on the one graphical differentiation item analysed; the authors propose, but did not test, transfer to other items. → Kennel 2025

Evidence¶

Kennel 2025¶

Kennel, K., Ishimaru, S., Küchemann, S., Steinert, S., Kuhn, J., & Ruzika, S. (2025). Gaze-Based Prediction of Students' Math Difficulties - A Time Dynamic Machine Learning Approach to Enable Early Individual Assistance. International Journal of Artificial Intelligence in Education. https://doi.org/10.1007/s40593-024-00447-5

q2 · i? · associational · r2

Machine learning classification study with 143 upper-secondary students using a stationary eye tracker, analysing one graphical differentiation item in depth; features included fixation counts, relative fixation counts, transitions, and saccade direction. The article reports "all 3 classifiers achieve values of the MCC around 0.78" for the multiclass case.

"Overall, all 3 classifiers achieve values of the MCC around 0.78, whereby the values after 50 s are already very good with values above 0.7 (for the KNN algorithm even a little earlier)."
