Evidence¶

Kenneth R. Koedinger 2007¶

Kenneth R. Koedinger, Vincent Aleven. (2007). Exploring the Assistance Dilemma in Experiments with Cognitive Tutors. Educational Psychology Review. https://doi.org/10.1007/s10648-007-9049-0

q1 · i? · review · r?

A definitional/interpretive note distinguishing passive instructional events from interactive ones: texts implicitly request understanding but not production, and any active learning event such as note-taking is not explicitly prompted.

"While texts come with an at least implicit request to have students try to understand them, they do not explicitly request students to produce a written or spoken output."
