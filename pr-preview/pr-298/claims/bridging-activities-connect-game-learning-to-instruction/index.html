Roschelle 2017¶

Roschelle, J., Martin, W., Ahn, J. & Schank, P. (Eds.). (2017). Cyberlearning Community Report: The State of Cyberlearning and the Future of Learning With Technology. Menlo Park CA: SRI International. https://digitalpromise.dspacedirect.org/items/dafbe585-c0f8-4693-bde8-a6d847a58aad

The report's executive summary cites this as one example of findings discussed in the report, stating that "students learn more from games when bridging activities connect implicit learning with the game" and classroom instruction. No effect size or study detail is printed in the supplied text.

"students learn more from games when bridging activities connect implicit learning with the game to formal, explicit classroom instruction – a connection that can be made stronger when learning analytics measure student progress in learning from their actions in the game."
