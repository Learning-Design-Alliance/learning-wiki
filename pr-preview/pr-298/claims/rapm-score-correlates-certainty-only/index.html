Evidence¶

Adam Chuderski 2021¶

Adam Chuderski, Jan Jastrzębski, Bartłomiej Kroczek, Hanna Kucwaj, Michał Ociepka. (2021). Metacognitive experience on Raven’s matrices versus insight problems. Metacognition and Learning 16:15–35. https://doi.org/10.1007/s11409-020-09236-6

q3 · i2 · associational · r2

Bayesian Pearson correlations across the 100 participants between RAPM scores and average ratings. Only Certainty correlated reliably (r = .328, BF10 = 30.55); links with Intuition, Suddenness, and solution time were not reliable, each r < .15, each BF10 < 0.35.
