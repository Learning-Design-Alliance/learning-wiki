Evidence¶

Eman Ganaiem 2025¶

Eman Ganaiem, Ido Roll. (2025). Investigating the order of example-problem sequences when learning experimental design and graphing competencies. Instructional Science. https://doi.org/10.1007/s11251-025-09750-7

q3 · i? · causal · r2

Randomized pre-treatment-post experiment with 113 seventh-grade students in the experimental design topic, assigned to WE→PS, PS→WE, or WE || PS. MANCOVA with pre-test covariate showed "no significant main effect for condition" (p = 0.963, partial η² = 0.003).

"Results show there is no significant main effect for condition: Wilk's Λ = 0.994, F (4, 212) = 0.15, p = 0.963, partial η 2 = 0.003."

Eman Ganaiem 2025 (2)¶

Eman Ganaiem, Ido Roll. (2025). Investigating the order of example-problem sequences when learning experimental design and graphing competencies. Instructional Science. https://doi.org/10.1007/s11251-025-09750-7

q3 · i? · causal · r2

MANCOVA on graphing application and transfer scores for 120 seventh-grade students randomized across the same three conditions found "no significant main effect for the condition" (p = 0.458, partial η² = 0.016).

"there was no significant main effect for the condition: Wilk's Λ = 0.969, F (4, 226) = 0.911, p = 0.458, partial η 2 = 0.016."
