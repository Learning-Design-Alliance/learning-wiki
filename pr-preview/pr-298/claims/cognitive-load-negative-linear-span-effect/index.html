Evidence¶

Cowan Nelson 2014¶

Cowan Nelson. (2014). Working Memory Underpins Cognitive Development, Learning, and Education. Educational Psychology Review. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4207727/

q2 · i? · review · r3

The review reports the complex-span tasks of Barrouillet, Portrat, and Camos, in which cognitive load is the proportion of time taken up by the processing task rather than free for refreshing items to be remembered. "The finding of Barrouillet and colleagues has been that the effect of cognitive load on the length of list that can be recalled, or memory span, is a negative linear (i.e., deleterious) effect."
