Evidence¶

Patel Nilam 2016¶

Patel Nilam, Vytal Katherine, Pavletic Nevia, Stoodley Catherine, Pine Daniel S., Grillon Christian, Ernst Monique. (2016). Interaction of Threat and Verbal Working Memory in Adolescents. Psychophysiology. https://doi.org/10.1111/psyp.12582

q3 · i3 · causal · r2

rANOVA on the anxiety-potentiated startle difference score with Load as within-subjects factor and Group as between-subjects factor, in the same 50-participant experiment. The analysis showed "greater anxiety-potentiated startle during the 1-back and 2-back tasks compared to the 3-back task (ps < .01)" with ηp2 = .34.

"Results revealed a main effect of Load (F(3,144) = 24.96, p < .001, ηp2 = .34) that showed greater anxiety-potentiated startle during the 1-back and 2-back tasks compared to the 3-back task (ps < .01)"
