Evidence¶

Stephan Vonschallen 2026¶

Stephan Vonschallen, Karim Kaufmann, Dominique Oberle, Friederike Eyssel, Theresa Schmiedel. (2026). Teachy Mini: Development and Preliminary Evaluation of a Knowledge-Based Generative Social Robot for Higher Education. arXiv. https://arxiv.org/abs/2607.22345 doi:10.48550/arxiv.2607.22345

q3 · i3 · causal · r2

Welch two-sample t-test in the preregistered two-group between-subjects experiment (KBD n = 12, control n = 12) comparing the 9-item Perceived Responsible Behavior scale. The KBD group scored "significantly higher perceived alignment with responsible robot behavior than the control group", d = 0.930, p = .034.

"The KBD group (M= 5.49,SD= 1.23) reported significantly higher perceived alignment with responsible robot behavior than the control group (M= 4.47,SD= 0.95),t(20.65) = 2.277,p = .034,CI= [0.087, 1.950],d= 0.930."

Related Claims¶

  • Qualitative transcript analysis showed the KBD robot used Socratic questioning, slide-grounded sourced claims, and explained feedback far more often, while the control robot produced false statements and never cited sources — related
  • KBD configuration produced no significant between-condition differences in system acceptance, intrinsic motivation, or subjective learning effectiveness in a single tutoring session — related
  • An exploratory path model suggests perceived responsible behavior mediates the association between KBD and both learner motivation and acceptance — related
  • Objective learning gains did not differ significantly by condition in the primary ANCOVA, but KBD showed a significant positive effect on learning gains in exploratory regressions accounting for learner covariates — related
