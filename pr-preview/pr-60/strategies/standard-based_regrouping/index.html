    Standard-Based Regrouping¶

    Strategy · All strategies

    Description¶

    Standard-based regrouping forms temporary, homogeneous groups based on learners' demonstrated mastery of specific standards rather than general ability. Learners are assessed formatively — through pre-assessments, warm-up questions, and exit tickets — to identify which standards they have not yet mastered; learners from multiple classes or sections can be pooled into groups targeted at a single standard. Groups are fluid: they dissolve and reform as mastery data change, so placement reflects current skill on a defined objective, not a fixed label.

    Design Implications¶

    Standard-based regrouping operationalizes Assessment for Learning: grouping decisions are driven by evidence of current mastery, and instruction in each group can be precisely targeted at the gap Formative assessment practices improve achievement. [+S]. Because groups are standard-specific and temporary, it avoids many of the documented harms of permanent, general-ability tracking while retaining the efficiency of teaching a narrower range of readiness in each group [~M].

    Context¶

    Requirements¶

    • Valid, quick formative assessment instruments aligned to specific standards (pre-assessments, exit tickets)
    • Flexible scheduling or timetabling that allows pooling learners across classes
    • Instructional materials and tasks aligned to each target standard, at varied difficulty
    • A data system or routine for tracking mastery and regrouping on a regular cycle

    Constraints¶

    • If groups become stable across the year, the approach collapses into conventional ability tracking, which depresses outcomes for lower-group learners Ability grouping effects depend on group stability and flexibility. [~M]
    • Frequent regrouping without clear communication can stigmatize learners placed in "remedial" groups [-M]
    • Requires substantial teacher time for assessment and data analysis; under-resourced implementations produce stale groupings that mis-target instruction [-M]
    • Pooling across classes depends on aligned pacing calendars; misaligned curricula make regrouping incoherent [-M]

    Implementation Variability¶

    • Within-class regrouping — temporary groups during a single lesson block, reformed weekly based on exit tickets
    • Cross-class regrouping ("regrouping for reading/math") — a grade level reorganizes learners across classrooms for one subject period
    • School-wide WIN (What-I-Need) time — a daily intervention block where all learners regroup by current standard need
    • Learner self-selection — learners choose which standard group to attend after seeing their own data, supporting autonomy [+M]

    Target Learners¶

    • Struggling learners, who receive targeted instruction at their actual entry point instead of instruction pitched beyond them Formative assessment practices improve achievement. [+S]
    • Advanced learners, who are regrouped toward extension rather than being held back by whole-class pacing [+M]
    • All learners benefit when groups are genuinely fluid; fixed placement benefits only already-advantaged learners [~M]

    Target Learning Goals¶

    • Closing specific skill gaps against defined standards (procedural and conceptual)
    • Mastery of prerequisite knowledge needed for subsequent units
    • Efficient whole-grade coverage of standards with differentiated practice

    Instructions¶

    1. Assess — administer a short pre-assessment or exit ticket aligned to the target standard; score against mastery criteria (Assess Performance)
    2. Group — form temporary groups of learners sharing the same standard deficit; release masters into extension or peer-tutoring roles
    3. Target instruction — deliver focused direct instruction on the specific gap, followed by guided practice
    4. Feedback and re-assess — provide immediate, task-specific feedback and re-assess to confirm mastery (Assessment for Learning)
    5. Regroup — dissolve and reform groups based on new data; move mastered learners out and new learners in
    6. Apply — return learners to mixed groups for application tasks that integrate the standard with others

    Related Strategies¶

    • Mastery Learning — standard-based regrouping is the grouping mechanism through which mastery pacing is managed across a cohort
    • Differentiated Instruction — regrouping is one structural form of differentiation by readiness
    • Formative Assessment Cycles — supplies the mastery data on which regrouping depends

    Related Elements¶

    • Assess Performance — the diagnostic engine of the strategy
    • Provide Feedback — targeted feedback within groups accelerates closure of gaps
    • Direct Instruction — the typical mode for gap-focused group teaching
    • Practice — distributed, standard-aligned practice within groups
    • Scaffolding — group-specific support that fades as mastery is demonstrated

    Patterns That Use This Strategy¶

    • Competency-Based Learning — regrouping by demonstrated mastery is the structural expression of competency-based progression
    • Direct Instruction — homogeneous skill groups make whole-group choral and scripted instruction feasible at the right entry level

    Examples¶

    • School-wide WIN time — many U.S. MTSS implementations (e.g., described by the RTI Action Network) run a daily 25–30 minute block in which all learners regroup across classrooms by current standard need, then return to homerooms.
    • Reading regrouping in Success for All — the Success for All program regroups learners across grade levels into reading groups by assessed reading level, re-assessing every eight weeks; this cross-class regrouping is a core design feature.
    • Zearn / Eureka Math small groups — teachers use digital lesson-level exit-ticket data to form next-day small groups targeted at specific standards, with the platform's reports driving the grouping (zearn.org).
