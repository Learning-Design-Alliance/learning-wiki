Evidence¶

Omarchevska 2022¶

Omarchevska, Y., Lachner, A., Richter, J., & Scheiter, K. (2022). Do Video Modeling and Metacognitive Prompts Improve Self-Regulated Scientific Inquiry? Educational Psychology Review. https://doi.org/10.1007/s10648-021-09652-3

q2 · i2 · causal · r2

Exploratory ENA on screen-capture and think-aloud process data (N = 88 coded; control N = 22 vs. VM conditions N = 66) in the training task. The X-axis centroid difference was significant, "t(39.23) = -2.32, p = 0.03, d = 0.54"; the article concludes VM participants were self-regulating during scientific reasoning activities more frequently.

"a two sample t-test showed that the position of the control group centroid (M = 0.33, SD = 0.76, N = 22) was significantly different from the VMP and VM centroid (M = -0.11, SD = 0.84, N = 66; t(39.23) = -2.32, p = 0.03, d = 0.54)"
