Evidence¶

Tim Kühl 2022¶

Tim Kühl, Benedict C. O. F. Fehringer, Stefan Münzer. (2022). Unifying the Ability-as-Compensator and Ability-as-Enhancer Hypotheses. Educational Psychology Review. https://doi.org/10.1007/s10648-021-09650-5

q2 · i? · causal · r2

Summary of the four prior experiments (Kühl, 2021; Kühl & Münzer, 2019; Kühl et al., 2018a, 2018b) whose pooled data were reanalyzed, establishing the animation as 'demonstrably the optimized visual design' for the Kepler's second law materials.

"All four single experiments have shown a main effect of visualization with an advantage of the dynamic visual design compared with the static visual design, especially for transfer tasks and partly also factual knowledge scores"
