Evidence¶

Frerejean 2021¶

Frerejean, J., van Geel, M., Keuning, T., Dolmans, D., van Merriënboer, J. J. G., & Visscher, A. J. (2021). Ten steps to 4C/ID: training differentiation skills in a professional development program for teachers. Instructional Science. https://doi.org/10.1007/s11251-021-09540-x

q1 · i? · design · r2

This finding emerged from the cognitive task analysis and expert consultations, and led the design team to add dedicated misconception-discussion activities (e.g., Learning task 1.3 using prepared statements) to the first group meeting. No quantitative data are reported.

"Contributions from the expert teachers and subject-matter experts revealed that novice teachers often suffered from misconceptions, for example that DI is equal to personalized instruction, or that adaptive training software takes care of DI. Specific activities were added to the program to explicitly address these misconceptions."
