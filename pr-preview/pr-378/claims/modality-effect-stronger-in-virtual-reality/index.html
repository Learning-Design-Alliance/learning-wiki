Evidence¶

Ginns 2005¶

Ginns, P. (2005). Meta-analysis of the modality effect. Learning and Instruction, 15(4), 313-331. https://doi.org/10.1016/j.learninstruc.2005.07.001

q3 · i3 · quant-synthesis · r2

Pairwise moderator comparisons of presentation modality (audio-tape, computer screen, virtual reality head-mounted display) in the between-subjects analysis. Table 2 reports virtual reality d = 1.34, audio-tape d = 0.64, computer screen d = 0.55.

"Larger effects were found in studies using virtual reality head mounted displays compared to studies using computer screens, z contrast = 3.43, p < 0.01; and larger effects were found in studies using head mounted displays compared to studies using audio-tapes, zcontrast = 2.81, p < 0.01."
