Evidence¶

Anders Bouwer 2010¶

Anders Bouwer, Bert Bredeweg. (2010). Graphical means for inspecting qualitative models of system behaviour. Instr Sci 38:173–208. https://doi.org/10.1007/s11251-008-9083-4

q2 · i? · design · r2

Evaluation study in which thirty first-year psychology students worked with VISIGARP on two Cerrado scenarios for about 80 minutes, with counterbalanced pre/post domain tests (CSH-A/CSH-B). Scores rose from "M = 42%, SD = 12.1%" to "M = 67%, SD = 14.2%", t(29) = -6.75, p < 0.001; 26 of 30 improved. No effect size is printed.

"the participant’s scores increased from the pre-test (M = 42%, SD = 12.1%) to the corresponding post-test (M = 67%, SD = 14.2%, t(29) =- 6.75, p\ 0.001)"
