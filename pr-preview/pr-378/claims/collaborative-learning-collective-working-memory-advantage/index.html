Evidence¶

Fred Paas 2010¶

Fred Paas, Tamara van Gog, John Sweller. (2010). Cognitive Load Theory: New Conceptualizations, Specifications, and Integrated Research Perspectives. Educational Psychology Review, 22, 115-121. https://doi.org/10.1007/s10648-010-9133-8

q2 · i? · review · r1

The review attributes this finding to F. Kirschner et al. (2009b), framing collaborative learners as "multiple, limited WMs that can create a collective working space". No effect size is printed in the review; the finding is second-hand.

"F. Kirschner et al. (2009b) have shown that because of the distribution advantage and expanded processing capacity, meaningful learning from tasks that impose a high cognitive load is more likely to occur in a collaborative learning setting than in an individual learning setting."
