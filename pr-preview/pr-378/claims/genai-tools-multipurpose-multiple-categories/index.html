Descriptive observation from the survey-based typology in the Introduction. The authors state that "many contemporary generative AI tools offer multi-purpose functionality" and cite ChatGPT appearing in three categories as an instance. No effect sizes or tests are reported.

"It is important to note that many contemporary generative AI tools offer multi-purpose functionality, and some tools appear in multiple categories within this typology based on their diverse applications in educational practice."
