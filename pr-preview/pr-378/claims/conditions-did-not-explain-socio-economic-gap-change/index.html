Giang Pham 2026¶

Giang Pham, Franziska Maria Locher, Dimitra Kolovou, Eliane Arnold. (2026). COVID-19: A cross-national analysis with PISA data. Learning and Instruction 105 (2026) 102366. https://doi.org/10.1016/j.learninstruc.2026.102366

q2 · i? · associational · r2

Double-selection lasso regressions (Table 3, N = 47 countries) with the Pandemic-Related Performance Gap as dependent variable. The article reports "no statistically significant differences between the three clusters"; only Average Pre-Pandemic Performance predicted gap differences in some mathematics and reading contrasts.

"Results of the regression analysis models (see Table 3) showed no statistically significant differences between the three clusters regarding changes in the social-economic performance gap conditional on the COVID-19 pandemic."
