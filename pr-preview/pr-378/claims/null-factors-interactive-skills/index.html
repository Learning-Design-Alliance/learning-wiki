Three-level meta-analyses found non-significant pooled correlations: work experience (k = 20, r = .026, p = .412), caregiver age (k = 9, r = .021, p = .650), tenure (k = 5, r = −.036, p = .424), perceived support (k = 3, r = .067, p = .281), center size (k = 5, r = −.124, p = .061), child sex (k = 3, r = −.090, p = .233), stability (k = 3, r = .066, p = .160).
