Evidence¶

Attout 2015¶

Attout, Lucie; Salmon, Eric; Majerus, Steve. (2015). Working memory for serial order is dysfunctional in adults with a history of developmental dyscalculia: Evidence from behavioral and neuroimaging data. Developmental Neuropsychology, 40. https://doi.org/10.1080/87565641.2015.1036993

q3 · i? · associational · r?

Behavioral experiment comparing adults with a history of developmental dyscalculia and matched controls on short-term memory tasks probing serial order versus item information. The article's title states that working memory for serial order "is dysfunctional in adults with a history of developmental dyscalculia".
