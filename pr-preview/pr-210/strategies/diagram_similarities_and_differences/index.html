Diagram Similarities and Differences¶

Strategy · All strategies Evidence · 4 claims (3 for, 1 mixed) · 9 studies (5 quant-synthesis, 3 causal, 1 review), q2–q4 · 5 of 9 report an effect size

Description¶

Learners identify two or more words, concepts, or cases, generate a list of similarities and differences, and represent those relationships in a Venn diagram or comparison matrix. The strategy is one of Robert Marzano's high-yield instructional strategies: identifying similarities and differences is the single largest-effect category in his synthesis of instructional research [Marzano, R. J. (1998) meta-analytic synthesis] [+S]. It is a structured form of Analogical Reasoning in which learners must analyze both items deeply enough to make justified comparisons.

Design Implications¶

Comparison forces elaborative processing: to state how two items differ, learners must retrieve the defining features of each and evaluate them against one another, which produces more durable encoding than studying either item alone [Schwartz & Bransford contrasting cases prepare learners for instruction] [+S]. The diagram format adds a spatial-visual representation of the same relationships, supporting dual coding Dual coding improves recall. [+M]. Critically, the learner-generated list matters more than the completed diagram — presenting a filled-in Venn diagram removes the analytical work that produces the benefit Active learning improves exam performance. [+S].

Context¶

Requirements¶

  • Two or more items that share enough structure to make comparison meaningful (not arbitrary pairs)
  • A graphic organizer — Venn diagram, comparison matrix, or T-chart — provided as a scaffold
  • Sufficient background knowledge of both items; pre-teach or allow resource access before comparing
  • A follow-up step where learners use the comparison (write a summary sentence, classify a new example) so the analysis is applied (Practice)

Constraints¶

  • Learners with limited background knowledge of either item produce superficial or invented comparisons [~M] — activate prior knowledge first (Activation)
  • Comparing items with no shared structure (e.g., a word and a random word) yields busywork rather than analysis [-M]
  • Overly open prompts ("compare these two chapters") without a dimension to compare along can overload working memory Cognitive overload degrades learning. [~M] — specify the comparison dimensions or provide a matrix with labeled rows
  • If the teacher completes the diagram, the strategy reduces to note-taking and loses most of its effect [-M]

Implementation Variability¶

  • Teacher-provided vs. learner-generated lists: begin with a provided list for novices, then fade to generation (Fading)
  • Item type: vocabulary words, historical figures, scientific processes, literary characters, solution methods
  • Organizer type: Venn diagram for overlapping categories; comparison matrix for multiple dimensions; analogy frames ("X is to Y as ___ is to Z") for relational comparison
  • Social format: individual reflection followed by pair comparison of lists (Individual Reflection → Class Discussion)

Target Learners¶

  • Intermediate learners who know both items at least at a surface level; novices need prior activation or resources first [~M]
  • Language learners building disciplinary vocabulary — comparison of near-synonyms (e.g., observe vs. infer) sharpens word meaning [+M]
  • Less effective for complete novices, who lack the knowledge to generate genuine similarities [~M]

Target Learning Goals¶

  • Conceptual discrimination: distinguishing confusable terms or categories
  • Vocabulary depth and disciplinary literacy
  • Relational and analogical reasoning: mapping structure from a familiar item to an unfamiliar one
  • Preparation for classification and categorization tasks

Instructions¶

  1. Select two (or three) items with genuine shared structure and display them.
  2. Activate knowledge of each item briefly — definition, example, or quick recall prompt (Activation).
  3. Learners individually list similarities and differences (Individual Reflection).
  4. Learners transfer the list onto a Venn diagram or comparison matrix, placing shared features in the overlap.
  5. Pairs or the class compare lists, resolving disagreements — the negotiation is where discrimination is refined (Class Discussion).
  6. Learners apply the result: write a summary sentence, classify a new example, or predict behavior of one item based on the other (Practice, Application of Knowledge).

Related Strategies¶

  • Concept Attainment — uses positive and negative examples to build the same discrimination skills that comparison sharpens
  • Case-Based Learning — comparing multiple cases is the multi-case extension of this strategy Cognitive flexibility theory: multiple cases. [+M]
  • [Frayer Model vocabulary instruction] — a comparison organizer applied specifically to single-word concept development

Related Elements¶

  • Individual Reflection — the generation step that produces the learning benefit
  • Practice — applying the comparison consolidates it
  • Graphic Organizers — the Venn diagram and matrix are instances of this element
  • Analogies — relational comparison as an instructional move rather than a learner task

Examples¶

  • Vocabulary (ELA/Science): Learners compare mass and weight, listing shared features (both measure "amount," both use units) and differences (scalar vs. location-dependent), then classify new statements as describing one, the other, or both.
  • History: Comparing two primary-source accounts of the same event in a comparison matrix with rows for author, purpose, and claims — a disciplinary literacy application.
  • Mathematics: Comparing multiplication and addition solution strategies for the same word problem, then explaining when each is more efficient.
  • ReadWorks and similar ELA platforms (https://www.readworks.org) include paired-text comparison tasks with Venn diagram printables as a standard comprehension activity type.
