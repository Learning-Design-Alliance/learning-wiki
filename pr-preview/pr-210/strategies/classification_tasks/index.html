Classification Tasks¶

Strategy · All strategies Evidence · 5 claims (4 for, 1 mixed) · 14 studies (6 causal, 3 quant-synthesis, 3 review, 1 associational, 1 theoretical), q1–q4 · 2 of 14 report an effect size

Description¶

Classification tasks ask learners to sort objects, examples, or concepts into categories based on shared properties, and to justify the criteria they used. Learners may develop their own classification schemes or apply a given one, working from binary sorts up to multi-level classification trees. Because learners must attend to features, compare cases, and defend boundaries, classification is fundamentally an inductive activity: the category structure is constructed from evidence rather than delivered as a definition.

Design Implications¶

Classification tasks build conceptual structure through comparison. Contrasting multiple cases — especially cases that differ on only one dimension — helps learners abstract the underlying features that define a category Comparing multiple contrasting cases supports abstraction of deep features. [+S]. Requiring learners to explain why an item belongs in a category converts sorting from a mechanical exercise into self-explanation, which improves conceptual understanding Self-explanation improves conceptual understanding. [+S]. Sorting also functions as chunking: grouping items under a category label reduces the number of separate elements learners must hold in mind Chunking reduces working memory load. [+M].

Context¶

Requirements¶

  • A set of items with enough shared and distinguishing features to make sorting non-trivial
  • Clear (or learner-generated) classification criteria, with recording sheets or sorting tools
  • A justification step — learners must articulate the properties that drove each placement
  • For science contexts, observation tools appropriate to the items (magnifiers, rulers, reference keys)

Constraints¶

  • Ambiguous or overlapping criteria produce arbitrary sorts; learners may learn that classification is idiosyncratic rather than principled [-M]
  • If all items differ on many dimensions at once, learners cannot isolate which features matter; sorting degenerates into guessing [~M]
  • Learners with strong prior knowledge of the categories gain little from simple sorting and may find it redundant Guidance becomes less effective as expertise increases. [~M]
  • Sorting alone, without feedback or a "time for telling," can leave learners with invented but incorrect category boundaries; classification works best when followed by explicit instruction that names and consolidates the structure [~S]

Implementation Variability¶

  • Given vs. generated criteria: learners apply a provided taxonomy (e.g., a dichotomous rock key) or invent their own scheme and defend it
  • Binary vs. hierarchical: two-way sorts (living/non-living) suit younger learners; multi-level trees (kingdom → species) suit advanced ones
  • Interleaved presentation: mixing category members across practice sets forces feature comparison, whereas blocked presentation lets learners sort by surface similarity alone [~S]
  • Erroneous examples: sorting items that have been deliberately misclassified and asking learners to find and fix the errors builds conceptual knowledge Erroneous examples build conceptual knowledge. [+M]

Target Learners¶

  • Novices and younger learners (K–4) encountering a new domain's category structure, particularly in science and mathematics
  • Learners who benefit from concrete manipulation before formal definitions are introduced
  • Less valuable for learners who already command the taxonomy; for them, application or exception-handling tasks are better Guidance becomes less effective as expertise increases. [~M]

Target Learning Goals¶

  • Concept formation: learning what defines a category and where its boundaries lie
  • Feature discrimination: noticing which properties are diagnostic versus incidental
  • Analytical reasoning and justification: defending a scheme with evidence
  • Preparation for later explicit instruction — sorting builds the differentiated intuitions that definitions then organize

Instructions¶

  1. Present a varied set of items and let learners explore their properties before any sorting (Activation).
  2. Ask learners to sort items into categories, initially with their own criteria (Application).
  3. Have learners compare their schemes with peers and reconcile disagreements (Class Discussion).
  4. Introduce contrasting cases that differ on a single dimension to sharpen attention to diagnostic features (Practice).
  5. Follow with explicit instruction that names the canonical categories and explains why the expert scheme works.
  6. Assess with novel items: can learners classify examples they have never seen and justify the placement?

Related Strategies¶

  • Case Studies — extended classification of a single rich instance rather than many small ones
  • Comparing Cases — the comparison mechanism that makes classification tasks build abstractions

Examples¶

  • Classifying Rocks (Kentucky DOE) — learners develop and justify classification schemes for rock samples based on observable properties, then compare their schemes to geologists' dichotomous keys.
  • Classifying Candy (NYSED) — elementary learners build binary classification systems from a set of candies, iterating on criteria as new attributes emerge.
  • Kornell's interleaved painting study — learners who viewed paintings interleaved by artist (an implicit classification task) outperformed blocked learners at categorizing new paintings, despite feeling they learned less.
