NASA Cognition battery for multi-domain astronaut cognitive assessment¶

Element · All elements Evidence · 2 claims (2 for) · 1 study (1 review), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The NASA Cognition battery is a cognitive assessment tool for astronauts that assesses multiple cognitive domains relevant to astronaut performance. The review states it "represents a significant advancement in cognitive assessment by assessing multiple cognitive domains relevant to astronaut performance", improving on approaches that evaluate only single domains because astronauts' operationally relevant cognitive profile differs from that of clinical or general-population individuals. The review still judges scheduled periodic testing alone insufficient for exploration-class missions.

Design Implications¶

Context¶

Requirements¶

  • Should be integrated with physiological, behavioral, and operational metrics rather than used as scheduled periodic testing alone

Constraints¶

  • The review notes current monitoring strategies remain limited in logistical validity, temporal resolution, and integration with real-time decision-making

Target Learners¶

  • astronauts in long-duration spaceflight

Target Learning Goals¶

  • monitoring cognitive readiness across domains relevant to operational performance

Claims¶

  • Sleep deprivation is associated with reduced psychomotor vigilance, impaired reaction time, and greater perceived workload and stress in astronauts [+W]
  • ICE environments are associated with mood disturbance, reduced motivation, social withdrawal, interpersonal conflict, and altered time perception [+W]

Examples¶

  • Cognitive performance training embedded in operational scenarios under fatigue
