Expository Reading and Writing Course (ERWC) for grade 12¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 causal), q3 · 1 of 1 report an effect size · 1 claim rests on one study

Description¶

The ERWC is a program for 12th graders designed to prepare them to enter the California State University and participating community colleges ready for credit-bearing English courses without remediation. It "replaces ordinary English classes for the whole twelfth grade" and provides curriculum materials, professional learning, professional learning communities, and on-site coaching days for each teacher.
