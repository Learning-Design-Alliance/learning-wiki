Magnetic Reading: print-based supplemental comprehension program for grades 3-5¶

Element · All elements Evidence · 3 claims (3 for) · 1 study (1 causal), q3 · 1 of 1 report an effect size · 3 claims rest on one study

Description¶

Magnetic Reading is a print-based, supplemental reading program intended for 30-45 minutes a day, designed to support grade 3-5 students' comprehension skills as the comprehension strand within the daily reading block. It provides students with "culturally-relevant and high-interest grade-level texts" and includes a digital library of educator resources supporting whole-class and differentiated instruction, as well as scaffolds and protocols.

Design Implications¶

Context¶

Requirements¶

  • Intended to be used for 30-45 minutes a day as the comprehension strand within the daily reading block
  • Implementations require points of contact to assist with initial set-up and disseminate communications, guided by i-Ready Partners

Constraints¶

  • Designed for grade 3-5 students

Target Learners¶

  • Grade 3-5 students

Target Learning Goals¶

  • Reading comprehension skills

Claims¶

  • Magnetic Reading use had a positive, statistically significant effect on spring i-Ready Diagnostic scores (ES = +0.23) in a 2021-2022 Iowa quasi-experiment [+W]
  • Magnetic Reading qualifies for a Moderate evidence rating based on two studies with an average effect size of +0.22 [+W]
  • Students in Magnetic Reading schools scored significantly higher on the Iowa state ELA test (ES = +0.22) in a 2022-2023 prospective matched study [+W]
