Read, Write & Type!™ Learning System software and supporting materials¶

Element · All elements Evidence · no claims cited

Description¶

Read, Write & Type!™ is a software program with supporting materials "designed to teach beginning reading skills by emphasizing writing as a way to learn to read," developed for six- to nine-year-olds just beginning to read and for struggling readers and writers. Its main goal is helping students "develop an awareness of the 40 English phonemes" and associate each phoneme with letters and a keyboard finger stroke. Game-like computer activities with animated characters lead students through 40 lessons, each explicitly teaching one phoneme, with an activity book covering sound identification, rhyming, spelling, and dictation.

Design Implications¶

Context¶

Requirements¶

  • Delivery in the evaluated study used groups of three students with four 50-minute sessions per week and a trained teacher devoting roughly half of each session to direct instruction

Constraints¶

  • Developed in 1994; the report notes information is not available on the number or demographics of students, schools, or districts using the software

Target Learners¶

  • Six- to nine-year-old beginning readers
  • Struggling readers and writers
  • Low-achieving first grade students

Target Learning Goals¶

  • Phonemic awareness of the 40 English phonemes
  • Letter-sound correspondence and keyboard finger strokes
  • Fluency in sounding out, typing, and reading regularly spelled words
