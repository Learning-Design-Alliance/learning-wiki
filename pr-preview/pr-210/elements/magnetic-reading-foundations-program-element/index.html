Magnetic Reading Foundations K-2 foundational skills program¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 causal), q2 · 1 of 1 report an effect size · 1 claim rests on one study

Description¶

Magnetic Reading Foundations is a comprehensive foundational skills program for students in grades K-2, intended for 30-45 minutes of daily use in conjunction with the existing reading curriculum. It covers phonological awareness, concepts of print, letter formation, phonics, high-frequency words, word analysis, and fluency, and includes digital lessons, assessments, and interactive tutorials for differentiation.

Requirements¶

  • Requires points of contact to assist with initial set-up and disseminate communications, guided by i-Ready Partners

  • Intended to be used in conjunction with the existing reading curriculum, not as a standalone curriculum
  • No additional staff are required to use Magnetic Reading Foundations
