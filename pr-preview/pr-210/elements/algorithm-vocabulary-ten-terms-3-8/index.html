Ten-term algorithm vocabulary set for grades 3-8¶

Element · All elements Evidence · no claims cited

Description¶

The deck specifies a vocabulary set labeled "Words to teach" for algorithm lessons. It defines "Algorithm - A list of steps to finish a task", "Bug - Part of a program that does not work correctly", "Debugging - Finding and fixing problems in an algorithm or program", "Loop - The action of doing something over and over again", and "Program - An algorithm that has been coded into something that can be run by a machine". It adds decomposition, abstraction, sequencing, and pattern recognition definitions.
