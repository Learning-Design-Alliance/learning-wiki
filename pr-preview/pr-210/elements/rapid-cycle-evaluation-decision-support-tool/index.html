Rapid-cycle evaluation as a decision support tool for continuous program and quality improvement¶

Element · All elements Evidence · 1 claim (1 mixed) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

Rapid-cycle evaluation is presented as an approach organizations can use when decision-makers 'often lack timely and reliable evidence of whether such changes produce the expected results.' The page frames it as a 'decision support tool for continuous program and quality improvement,' applied to 'small changes to operations or service delivery' in public programs, including education and human services contexts.

Design Implications¶

Context¶

Requirements¶

  • Timely and reliable evidence about whether operational or service-delivery changes produce expected results, which the page says decision-makers often lack

Constraints¶

  • Described for small changes to operations or service delivery in public programs, not for large-scale or wholesale redesigns

Target Learners¶

  • Public program administrators and decision-makers in education and human services

Target Learning Goals¶

  • Continuous program and quality improvement through evidence-based operational decision-making

Claims¶

  • Rapid-cycle evaluation determines with high confidence whether and for whom a program change causes intended improvements or unintended consequences [~W]
