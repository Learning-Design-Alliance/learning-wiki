NWEA MAP Growth assessment as national data source for seasonal skill-growth analysis¶

Element · All elements Evidence · 3 claims (2 for, 1 mixed) · 1 study (1 causal), q1 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

The NWEA MAP Growth assessment supplies the recent national data on U.S. public school students used in this study's seasonal comparisons. The abstract states the analysis covers "numerous grade levels from the NWEA MAP Growth assessment" and four domains: math, reading, language use, and science. In the article it functions as the measurement instrument enabling school-year versus summer variance comparisons.
