Test blueprints specifying content constraints for item selection¶

Element · All elements Evidence · 4 claims (4 for) · 2 studies (1 causal, 1 associational), q2–q3 · 0 of 2 report an effect size · 4 claims rest on one study

Description¶

Test blueprints are the mechanism by which achievement testing meets the practical requirement that administered items represent a target content domain. The article states this "is accomplished by establishing test blueprints specifying the content constraints to be followed when selecting the items for a test." Blueprints define the content constraints that item selection must follow, and the article's concern is that disengaged responses can undermine the content representation blueprints are meant to secure.
