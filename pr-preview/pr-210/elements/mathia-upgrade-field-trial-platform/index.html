MATHia/UpGrade: open-source field-trial platform integrated with Carnegie Learning's adaptive math tutoring system¶

Element · All elements Evidence · no claims cited

Description¶

UpGrade is "a free and open source platform for conducting field trials in EdTech software" integrated into MATHia, "an adaptive, intelligent tutoring system for learning math" used by over 600,000 students in over 3,000 schools each year. Researchers run content, feature, and sequence-based experiments in real classrooms, with weighted randomization or factorial designs, by-experiment outcome metrics, dashboard snapshots, and csv data exports. The article illustrates rewriting word problems for clarity and relatable scenarios such as a Taylor Swift security-guard problem.

Design Implications¶

Context¶

Requirements¶

  • Researchers must collaborate with the Carnegie Learning team to identify topics and publish content changes in MATHia before setting up the experiment

Constraints¶

  • Experiments are limited to classrooms already using MATHia as part of its blended curriculum

Target Learners¶

  • K-12 students using MATHia in blended math curricula

Target Learning Goals¶

  • mathematics learning under language clarity and relevance interventions

Related Elements¶

  • ASSISTments/E-TRIALS: free A/B testing platform integrated with a K-12 math practice platform
  • MATHia tutoring software
  • SEERNet: a network of five digital learning platforms operating as research infrastructure
  • MATHia intelligent tutoring system with adaptive mastery-based instruction
  • UpGrade open-source A/B testing platform for classroom-embedded field experiments

Examples¶

  • Leverage digital learning platforms to run unobtrusive randomized experiments on language modifications in math problems
  • Use a 2x2 factorial design to separate the effects of contextual relevance and linguistic detail in word problems
