ScratchJR app for young children to build interactive stories and games¶

Element · All elements Evidence · no claims cited

Description¶

ScratchJR is described as "An App for iPads or Android tablets where students can build their own interactive stories or games." The webinar points teachers to an introductory PBS Kids ScratchJR video and suggests example activities for using the app with K-2 learners as an entry point to block-based coding.
