q1 · i? · theoretical · r?

Methodological exposition in an IES analytic report: the author states that two-group design-based estimators "need to be modified for the multi-armed design when comparing pairs of research groups to each other." This is a theoretical/methodological argument, not an empirical test.

"This report describes how design-based estimators for the two-group design need to be modified for the multi-armed design when comparing pairs of research groups to each other."
