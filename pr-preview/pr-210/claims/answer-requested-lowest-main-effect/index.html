Lu 2024¶

Lu, Y., Tong, L., & Cheng, Y. (2024). Advanced Knowledge Tracing: Incorporating Process Data and Curricula Information via an Attention-Based Framework for Accuracy and Interpretability. Journal of Educational Data Mining, 16(2). https://osf.io/mdpzc/

Simulation with artificial action logs built from the top 100 popular in-unit problems, using Model 1 without action features and student/class embeddings (Figure 3). "Correct response" gave the highest and "open response" the second-highest average probability.

"Conversely, the action type “answer requested” results in the lowest average probability, even lower than that of “wrong response.”"
