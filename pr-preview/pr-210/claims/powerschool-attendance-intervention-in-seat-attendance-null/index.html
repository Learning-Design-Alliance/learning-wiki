PowerSchool Attendance Intervention 2024¶

PowerSchool Attendance Intervention. (2024). PowerSchool Attendance Intervention program description and evidence summary. https://www.powerschool.com/

q3 · i? · causal · r?

The same randomized control trial (31 teachers, nearly 1500 students, 3 DC public schools) reported that semester-long impacts "resulted in insignificant increases of in-seat attendance"; no effect size is printed for the in-seat attendance outcome.

"Semester-long impacts resulted in insignificant increases of in-seat attendance but did substantially reduce chronic absenteeism for students of teachers using the Attendance Intervention solution (effect size = +0.19)."
