q2 · i? · causal · r2

A quasi-experimental study compared 69 NNPS elementary schools with 69 matched comparison schools across Ohio, analyzing changes in average daily attendance from 2000 to 2001. NNPS schools "increased attendance by 0.5% on average" while comparison schools declined slightly; the result was statistically significant with effect size = +0.07. No standardized effect size beyond +0.07 is printed.
