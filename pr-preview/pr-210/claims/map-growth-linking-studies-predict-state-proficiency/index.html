The intended-uses chapter describes linking studies (e.g., Hu, 2021) whose results are combined with the norms model to predict state proficiency; the report states this "enables teachers to determine if a student is on track for proficiency by the end of the school year." Classification accuracy tables are referenced but no statistic is printed in the available text.

"Linking study results are combined with the statistical model used in the MAP Growth norms in order to predict proficiency on a state assessment using MAP Growth scores from fall, winter, or spring."
