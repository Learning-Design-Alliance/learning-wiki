One qualifying study evaluated Number Rockets with students below the 38th percentile in math; controls received no tutoring or organized remediation. The program "scored significantly higher than controls, with an effect size of +0.34" on TEMA-3, qualifying it as Strong evidence.

"On TEMA-3 tests, students in Number Rockets scored significantly higher than controls, with an effect size of +0.34. This qualifies the program for the "Strong" evidence category."
