Theoretical argument stated in the article's abstract: fixed-form alignment procedures are described as not readily applicable to CATs because CATs "require large item pools and do not use fixed test forms". No empirical test of this incompatibility is reported in the available text.

"Although procedures have been developed for evaluating the content alignment of linear tests, these procedures are not readily applicable to computerized adaptive tests (CATs), which require large item pools and do not use fixed test forms."
