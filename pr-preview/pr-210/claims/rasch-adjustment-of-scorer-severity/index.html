In the measure-development stage, the project used the Many-Facet Rasch model, noting that besides adjusting for rater severity and standard difficulty, "another advantage of the Rasch model is that it allows for missing data." Final assignment measures exist in a logit metric with standard errors, converted to a 0-10 scale for reporting.

"the student work and teacher assignment measures were developed using Many-Facet Rasch Analysis with statistical software specifically designed for this model, FACETS."
