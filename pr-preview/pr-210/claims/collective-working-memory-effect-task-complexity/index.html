q1 · i? · review · r2

The primer attributes the collective working memory effect to Kirschner et al. (2018): as group members coordinate and communicate about their knowledge, "a larger working memory is created." The primer reports this as background theory, not as a test conducted here.

"Kirshner and colleagues call this the 'collective working memory effect,' where multiple people working together can leverage the capacity of other group members' working memory."
