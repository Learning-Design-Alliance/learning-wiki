Dynamical systems theory as a framework for quantifying learning behavior patterns within intelligent tutoring systems¶

Theory · All theories Evidence · 3 claims (2 for, 1 mixed) · 1 study (1 design), q1 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

The article proposes dynamical systems theory and associated analysis techniques as tools for examining behavioral patterns and variations within ITSs. It treats time as a critical variable, focusing on "the complex and fluid interactions that occur within a given environment rather than treating behavior as static (i.e., set or unchanging), as is customary in many statistical approaches." The author hypothesizes these methodologies can quantify changes in students' interactions across time and inform user models about optimal and non-optimal learning behaviors.

Design Implications¶

Context¶

Requirements¶

  • Log data capturing students' choices and actions over time within the learning environment

Constraints¶

  • Prior applications described were conducted post hoc; real-time application is proposed but not yet tested

Target Learners¶

  • high school students using game-based ITSs

Target Learning Objectives¶

  • reading comprehension via self-explanation strategies

Claims¶

  • Students with more controlled interaction patterns in iSTART-2 generated higher-quality self-explanations than students with more random patterns [+W]
  • Hurst exponent calculation requires multiple data points (e.g., over 100), which may make real-time computation impractical in some situations such as single-session studies [~W]
  • Real-time dynamic analyses (Hurst exponents, Entropy) are hypothesized to inform user models about optimal and non-optimal learning behaviors within a game-based ITS [+W]

Related Theories¶

Examples¶

  • Use dynamic user models to recognize non-optimal learning behaviors and redirect students toward more effective behaviors
