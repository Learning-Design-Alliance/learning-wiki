Forms Use Types taxonomy: five pedagogical and four professional categories of teacher use¶

Theory · All theories Evidence · 6 claims (6 for) · 1 study (1 qualitative), q2 · 0 of 1 report an effect size · 6 claims rest on one study

Description¶

The report synthesizes interview data into categories of “Forms Use Types” characterizing how teachers used Forms. Pedagogical uses are student-focused, covering “formative assessment, differentiated instruction, peer collaboration, social emotional learning, and student engagement,” while professional uses include parent communication, professional learning, teaching efficiency, and administrative tasks. Both experienced and first-time users described uses in these purpose-driven terms, and all 22 teachers described at least one pedagogical use.
