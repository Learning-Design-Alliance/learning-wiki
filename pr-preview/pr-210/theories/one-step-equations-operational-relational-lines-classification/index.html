A cognitive load based classification of one-step equations into Type 1 and Type 2 by operational and relational lines¶

Theory · All theories Evidence · 4 claims (4 for) · 1 study (1 theoretical), q1 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The article proposes a framework that classifies one-step equations by counting operational lines (steps that alter the problem state while preserving equality) and relational lines (lines showing a quantitative relation between elements). Type 1 equations have one operational and two relational lines; Type 2 equations have two operational and three relational lines. The number of these lines indexes element interactivity, which determines intrinsic load and thus equation complexity, paralleling Mayer's classification of algebra story problems.

Design Implications¶

Context¶

Requirements¶

  • The classification assumes the balance method as the formal solution procedure against which operational and relational lines are defined

Constraints¶

  • The framework is developed analytically from cognitive load theory rather than tested empirically in this paper

Target Learners¶

  • students transitioning from pre-algebra to algebra learning

Target Learning Objectives¶

  • solving one-step equations with a formal method
  • preparation for multi-step equation solving

Claims¶

  • The complexity of one-step equations increases with the number of operational and relational lines [+W]
  • Special features (negative numbers, decimals, percentages, fraction solutions, pronumeral on the right) increase difficulty of one-step equations at constant element interactivity [+W]
  • Reliance on trial-and-error or substitution for one-step equations undermines later learning of multi-step equations where those methods become infeasible [+W]
  • Type 1 one-step equations (1 operational, 2 relational lines) are argued to be easier to learn than Type 2 (2 operational, 3 relational lines) due to lower cognitive load [+W]

Related Theories¶

Examples¶

  • Teach one-step equations in a hierarchical sequence: Type 1 without special features first, then Type 1 with special features, then Type 2 in the same order
