Equity-centered, vendor-accountable edtech evaluation system model¶

Theory · All theories Evidence · 3 claims (3 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

The report's organizing framework is an evaluation system that "codifies priorities and requirements of edtech tools and shifts some of the labor of evaluating edtech from CO administrators onto edtech vendors by requiring edtech companies to demonstrate alignment with institutional needs through two key assets: (1) the Contact Initiation Form and (2) product badges". It couples up-front vendor disclosure with competency badges co-designed with learners, a system-wide directory of badge-earning vendors, and transparent decision-making intended to incentivize vendors to use badge requirements as guideposts when developing products.
