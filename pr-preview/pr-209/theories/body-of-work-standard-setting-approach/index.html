Body of work approach to standard setting for alternate assessments¶

Theory · All theories Evidence · 4 claims (1 for, 3 mixed) · 1 study (1 design), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The body of work approach is a standard setting methodology in which "Reviewers examine all of the data for a student and use this information to place the student in one of the overall performance levels." Standard setters receive papers demonstrating the complete range of possible scores from low to high. This report applies it as the primary methodology for setting cut scores on an alternate portfolio assessment, adapted from components of several standard setting processes including contrasting groups and bookmarking.

Design Implications¶

Context¶

Requirements¶

  • Review of actual student work by diverse educator committees
  • Student work samples spanning the full range of performance

Constraints¶

  • The standard application involves range-finding and pin-pointing phases; this project included only the range-finding phase due to limited portfolios and time

Target Learners¶

  • Students with the most significant disabilities participating in alternate assessment

Target Learning Objectives¶

  • Determining performance level cut scores for literacy and mathematics alternate portfolio assessment

Claims¶

  • Body Of Work Agreement Rates 71 97 [+M]
  • Ordered Portfolio Presentation Contamination [~M]
  • Performance classifications varied considerably across grades in both literacy and mathematics for the alternate portfolio assessment [~W]
  • A mean-classification cut-score method outperformed a contrasting-groups-style mean method because it was more robust to outliers [~W]

Related Theories¶

Examples¶

  • Include both range-finding and pin-pointing phases when applying the body of work method
  • Select representative reduced portfolios with quality-control review and geographic-bias limits for standard setting
