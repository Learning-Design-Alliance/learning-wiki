Krashen's Monitor Model: acquisition versus learning as separate internal rule systems¶

Theory · All theories Evidence · 5 claims (5 for) · 3 studies (2 theoretical, 1 review), q1–q2 · 1 of 3 report an effect size · 5 claims rest on one study

Description¶

Krashen's Monitor Model divides classroom activities into acquisition activities, which expose students to comprehensible target language samples, and learning activities, which focus on particular language forms through error correction, drills, and grammar explanation. Performance is initiated by acquired basic competence, while learned Monitor rules can modify output only when there is enough time, as on paper-and-pencil tests. The article retains this acquisition-learning distinction as Krashen's basic insight even while criticizing its absolute conscious/unconscious split.

Design Implications¶

Context¶

Requirements¶

  • Learning is restricted to rules that are easy to remember and apply, such as subject-verb agreement; complicated rules like English preposition usage must be acquired.

Constraints¶

  • The article argues the model's absolute distinction between conscious and unconscious monitoring is unnatural, requiring two sets of linguistic rules that can never merge.

Target Learners¶

  • second language learners in ESL classrooms

Target Learning Objectives¶

  • internalizing a second language through meaningful use

Claims¶

  • Monitoring significantly improves a second language learner's accuracy on learnable rules (subject-verb agreement, regular past tense) in the most monitored style [+W]
  • Monitoring lowers accuracy for unlearnable rules: preposition usage was significantly less accurate in the more monitored style [+W]
  • Monitoring is a variable phenomenon, not all-or-nothing, and monitoring in formal styles may pull up accuracy in less formal styles [+W]
  • Repetitive drill and grammar-focused instruction are ineffective devices for second language acquisition [+W]
  • Comprehensible input in natural language contexts is presented as essential to second language acquisition [+W]
