Kentucky Academic Standards structure Data & Analysis into storage, collection/visualization/transformation, inference & models, and impacts of computing¶

Theory · All theories Evidence · no claims cited

Description¶

The webinar organizes the K-2 Computer Science standards for Data & Analysis into three sub-areas plus an ethics-related impacts standard: "E-DA-01: Appropriately store and modify digital files"; "E-DA-02: Standard 2: Collect and visually display data using appropriate applications"; "E-DA-03: Standard 3: Analyzing data for trends and relationships"; and E-IC-04 on proper use of data in a computing society. This taxonomy frames what K-2 data instruction should cover.

Design Implications¶

Context¶

Requirements¶

  • Alignment of classroom data activities to the KAS for Computer Science and Technology standards

Constraints¶

  • Standards are specified for the primary (K-2) grade band with guidance and support

Target Learners¶

  • K-2 primary grade students

Target Learning Objectives¶

  • data storage
  • data collection and visual display
  • analyzing data for trends and relationships
  • ethical use of data

Examples¶

  • Group tree seasonal observation activity
  • Seed germination observation activity for K-2 data collection

  • Use a culture-themed children's book to generate data for K-2 glyph and graph activities.
