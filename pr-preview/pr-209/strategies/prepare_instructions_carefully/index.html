Prepare Instructions Carefully¶

Strategy · All strategies Evidence · 3 claims (3 for) · 8 studies (3 quant-synthesis, 3 review, 2 causal), q2–q4 · 2 of 8 report an effect size

Description¶

Preparing instructions carefully means drafting, sequencing, and simplifying directions before instruction begins: grouping similar tasks so directions are given once, breaking multi-step procedures into short chunks, and writing instructions in plain, accessible language. The strategy treats instructions as a designed artifact — drafted, checked against the task, and often rehearsed or piloted — rather than improvised at the moment of delivery.

Design Implications¶

Instructions are the first cognitive task learners face; poorly structured directions impose extraneous load that competes with the actual learning task Cognitive overload degrades learning outcomes. [+S]. Careful preparation reduces this load by chunking steps and grouping similar tasks, so learners hold one coherent instruction set in working memory rather than a stream of unrelated directives Chunking reduces working memory load. [+M]. Advance organizers and stated objectives give instructions a structure learners can map new steps onto Advance organizers improve learning. [+M].

Context¶

Requirements¶

  • A written draft of all instructions, checked against the actual task materials for accuracy and completeness
  • Grouping of similar tasks so shared directions are delivered once, not repeated per task
  • Instructions segmented into short, ordered steps — one action per step where possible
  • Plain language consistent with Accessible Vocabulary & Syntax; define any task-specific terminology before using it
  • A stated goal or outcome at the start, so learners know what the steps are for (Advance Organizers)

Constraints¶

  • Preparation time is substantial up front; under time pressure, teachers revert to improvised instructions that are longer and less ordered [-W]
  • Over-scripted instructions can remove productive decision-making; for open-ended or inquiry tasks, step-by-step directions may reduce engagement and transfer [~M]
  • Grouping similar tasks helps only when learners perceive the similarity; forced groupings of superficially similar but structurally different tasks can cause negative transfer [-W]
  • Written instructions alone do not guarantee comprehension — learners with weak reading skills or limited language proficiency may need modeled or demonstrated instructions instead [-M]

Implementation Variability¶

  • Written checklists for multi-step procedures learners revisit independently
  • Modeled instructions — the instructor demonstrates the first step while narrating it, then hands over (Cognitive Apprenticeship)
  • Staged release — instructions for the next phase are withheld until the current phase is complete, preventing overload from a single long direction set
  • Pre-prepared FAQ — anticipated questions answered in the instruction sheet, reducing interruption during work time

Target Learners¶

  • Novices, who lack the prior knowledge to reconstruct missing steps or infer intent from vague directions Cognitive overload degrades learning outcomes. [+S]
  • Young learners and language learners, who benefit from short chunks and plain syntax Chunking reduces working memory load. [+M]
  • Less critical for experts, who can compensate for ambiguous instructions using domain knowledge [~W]

Target Learning Goals¶

  • Procedural fluency: executing multi-step tasks accurately
  • Independent work: enabling learners to proceed without continuous teacher support
  • Executive-function support: externalizing planning and sequencing for learners still developing these skills

Instructions¶

  1. List every task learners will complete; group tasks that share a procedure so directions are given once.
  2. Draft instructions as numbered steps, one action per step, applying Chunking to keep each step within working memory limits.
  3. Open with the goal and success criteria so steps have a purpose (Advance Organizers).
  4. Check each step against the actual materials — verify that every named resource, tool, or page reference is correct.
  5. Anticipate the three most likely points of confusion and address them in the instructions or a prepared FAQ.
  6. Deliver instructions, then have learners restate or begin the first step immediately to surface misunderstandings early (Check-In, Coaching).

Related Strategies¶

  • Modeling — demonstration can replace or supplement verbal instructions for complex procedures
  • Front-Loading Vocabulary — pre-teaching terms that instructions depend on
  • Routines and Signals — rehearsed routines reduce how much instruction is needed at all
  • Sequencing familiar everyday tasks to teach order of instructions

Examples¶

  • An elementary teacher prepares a picture-based checklist for a writing workshop, grouping all "drafting" tasks under one instruction set so directions are given once per phase rather than per student.
  • A lab instructor pre-writes numbered protocol steps and pilots them the day before, discovering that step 4 references a reagent stored in a different location — an error caught before students lost working time.
  • Khan Academy (https://www.khanacademy.org) — exercise instructions are short, pre-written, and paired with on-demand hints, so learners who miss a step get a sub-instruction without waiting for the teacher.
