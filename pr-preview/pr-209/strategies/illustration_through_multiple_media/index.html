Illustration Through Multiple Media¶

Strategy · All strategies Evidence · 3 claims (3 for) · 7 studies (4 causal, 2 review, 1 quant-synthesis), q2–q4 · 1 of 7 report an effect size · 1 claim rests on one study

Description¶

Illustration through multiple media presents a concept in more than one representational format — for example, an animated diagram with narrated explanation, a physical demonstration, and an interactive simulation of the same phenomenon. The goal is not variety for its own sake but complementary representations: each medium carries the part of the explanation it handles best, and together they support the construction of a richer mental model.

Design Implications¶

Multimedia learning research shows that well-designed combinations of words and pictures produce better learning than words alone, because learners can integrate verbal and pictorial mental models Media combinations affect recall and retention. [+S]. The benefit is conditional, however: media must be complementary and coordinated, not redundant or decorative. Adding more channels does not help when the additions duplicate content or overload working memory Cognitive load management principles — segmenting, signaling, and weeding — determine whether multiple media clarify or clutter [~S]. Note that the common rationale of "catering to learning styles" is not supported: matching media to a preferred style does not improve outcomes [X]; what matters is matching media to the content (e.g., animation for dynamic processes) and to learners' prior knowledge.

Context¶

Requirements¶

  • Media selected for explanatory fit: dynamic media for dynamic content, static diagrams when learners need to control inspection pace
  • Coordination across formats — narration and graphics presented simultaneously and spatially integrated, not split across screens or sequential blocks
  • Alignment with Clear Structure: each medium has a defined role in the explanation, with signaling (cues, highlighting) directing attention to the relevant content
  • A follow-on activity where learners apply or generate with the concept (Practice)

Constraints¶

  • Redundant media harm learning: on-screen text read aloud verbatim overloads the same channel and reduces retention compared with narration plus graphics [-S]
  • Seductive but irrelevant details — decorative images, background music, interesting tangents — divert attention from essential content and depress learning [-S]
  • Learners with low prior knowledge benefit from segmented, learner-paced media; continuous fast-paced video can overwhelm them [~M]
  • Translating the same text into multiple formats without integration adds processing cost rather than value [-M]

Implementation Variability¶

  • Static-first: labeled diagrams with Advance Organizers before any video, letting learners build structure before processing dynamic content
  • Simulation-based: interactive environments (e.g., PhET) where learners manipulate variables and observe outcomes, pairing illustration with guided inquiry
  • Learner-generated media: students create their own diagrams, videos, or Analogies to explain a concept, converting illustration into a generative activity
  • Contrast-based: side-by-side media comparing cases, which supports abstraction of the underlying principle Multiple contrasting cases support abstraction. [+M]

Target Learners¶

  • Novices, who benefit most from integrated words-and-pictures explanations that reduce unguided search Media combinations affect recall and retention. [+M]
  • Learners with limited domain vocabulary, for whom visuals carry meaning that dense text cannot (Accessible Vocabulary & Syntax)
  • Less beneficial for high-knowledge learners, for whom detailed graphics can be redundant with their existing mental models [~M]

Target Learning Goals¶

  • Conceptual understanding: building integrated verbal and pictorial models of systems and processes
  • Retention: dual coding of content in verbal and visual channels improves recall Media combinations affect recall and retention. [+M]
  • Transfer: contrasting representations and simulations support abstraction beyond the presented examples

Instructions¶

  1. Identify the core explanation and the content's demands — what is dynamic, spatial, or procedural — and choose the medium that fits each part, not one medium per "style."
  2. Open with an Advance Organizer or brief orientation so learners know what to attend to in the media that follow.
  3. Present the primary illustration: narration synchronized with integrated graphics or animation, segmented into learner-paced chunks (Chunking reduces working memory load Chunking reduces working memory load. [+S]).
  4. Add a second, complementary representation — a simulation, physical demonstration, or worked case — that adds information rather than repeating it.
  5. Follow with Practice in which learners apply, explain, or generate their own representation of the concept.
  6. Provide Feedback on learners' explanations or products, using the media formats to correct specific misconceptions.

Related Strategies¶

  • Use Worked Examples — worked examples are a media illustration of solution structure; multimedia design principles apply directly to their presentation
  • Analogies and Prior Knowledge Activation — analogies are a verbal illustration device that pairs naturally with visual models
  • Case-Based Learning — cases supply authentic contexts that multiple media can render vividly

Examples¶

  • PhET Interactive Simulations — University of Colorado Boulder physics and chemistry simulations combining dynamic visuals with learner-controlled variables, widely validated for conceptual learning in science.
  • Khan Academy — Narrated visual explanations paired with practice exercises; the drawing-plus-voiceover format follows modality and signaling principles.
  • 3Blue1Brown — Mathematics explainer videos using animation to illustrate abstract structures, demonstrating animation's fit for dynamic and geometric content.
  • Anatomy laboratory instruction — Combining 3D models (e.g., Visible Body), cadaver demonstration, and labeled diagrams so each representation contributes spatial information the others cannot.
