Use skill standards and certification tests to improve schools' information technology classes¶

Strategy · All strategies Evidence · no claims cited

Description¶

The article describes skill standards and certification tests as prominent tools in recent school-improvement efforts: "Skill standards and certification tests have figured prominently in recent efforts to improve schools' information technology classes." Schools and colleges can structure IT courses around industry skill standards and certification testing so that student learning is verified against workforce-relevant criteria.
