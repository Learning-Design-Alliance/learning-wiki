Use automated disengagement detection with proctor notification during remote low-stakes testing¶

Strategy · All strategies Evidence · no claims cited

Description¶

During remote testing, build an engagement feature into the assessment that "automatically paused the test event of a disengaged student and notified the test proctor." The study reports this feature "had a consistently positive impact whether the proctor was in the same room as the student or proctoring was done remotely," making it implementable for both in-person and remote proctoring setups.

Design Implications¶

Context¶

Requirements¶

  • A test proctor must be available to receive notifications and respond when a disengaged student's test event is paused.

Constraints¶

Target Learners¶

  • K-12 students taking remote or in-school low-stakes assessments

Target Learning Goals¶

  • Maintaining test-taking engagement so interim assessment scores validly reflect student learning

Related Strategies¶

  • Proctor Intervention for Rapid Guessing
  • Notify test proctors when students disengage so students give their best effort on testing day
