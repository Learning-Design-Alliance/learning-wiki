Create a Classroom Code of Conduct¶

Strategy · All strategies Evidence · 3 claims (3 for) · 7 studies (4 review, 2 theoretical, 1 quant-synthesis), q1–q4 · 1 of 7 report an effect size

Description¶

Teachers and students collaborate to establish a classroom code of conduct based on respectful, fair, kind, and empathetic behaviors. The process typically begins by asking students how they want to be treated, eliciting concrete behavioral examples, and converging on a shared norm — often framed as the Golden Rule ("treat others the way you want to be treated"). Because students participate in authoring the norms, the code functions as a social contract rather than an imposed rule list, which increases buy-in and the likelihood of self-enforcement.

Design Implications¶

Co-constructed norms combine two mechanisms: clear behavioral expectations, which are a core component of effective classroom management Emmer & Stough's review identifies establishing and teaching expectations as one of the most consistent predictors of classroom management success [+S], and autonomy support, since participation in rule-setting satisfies students' need for ownership and increases intrinsic motivation Autonomy supports intrinsic motivation. [+S]. The code should be phrased in positive, observable behavioral terms and revisited periodically rather than posted and forgotten.

Context¶

Requirements¶

  • Structured classroom discussion with genuine opportunity for student voice (Class Discussion)
  • Teacher facilitation that guides students from abstract values ("be nice") to concrete, observable behaviors ("listen when others speak")
  • A visible, durable artifact — chart, poster, or shared document — that the class can reference
  • Periodic revisiting and repair when norms are violated, not just initial creation

Constraints¶

  • Codes created but never referenced or enforced lose all effect; consistency of teacher follow-through is the limiting factor, not the quality of the code [-S]
  • Consensus-building can consume substantial instructional time, and dominant students can steer the discussion unless facilitation structures (e.g., Active Listening protocols, think-pair-share) equalize participation [~M]
  • A code alone, without taught routines and modeled behaviors, does not improve classroom climate; expectations must be explicitly taught and rehearsed like any other skill [-S]
  • Purely rule-based, punitive enforcement framed around the code can undermine the autonomy benefits of co-construction [~M]

Implementation Variability¶

  • Golden Rule convergence: teacher steers discussion toward "treat others as you want to be treated" as the single organizing principle, with student examples as sub-rules
  • Student-authored charters: students draft and vote on the full code; suited to older students with stronger self-regulation
  • Restorative variants: the code doubles as a repair framework — when harm occurs, the class asks which norm was broken and how to restore it
  • Digital adaptations: online discussion norms co-created for forums and video classes, following the same elicitation process

Target Learners¶

  • K–12 students, with the strongest evidence for elementary and middle school where climate interventions show the largest effects School-based SEL programs improve behavior and attitudes, with larger effects in elementary grades. [+S]
  • Students with low sense of belonging or prior negative classroom experiences, for whom visible ownership of norms signals safety [~M]
  • Less effective as a standalone intervention for students with significant behavioral or emotional support needs, who require individualized supports beyond class-wide norms [-W]

Target Learning Goals¶

  • Social-emotional learning: recognizing respectful, fair, kind, and empathetic behavior in self and others
  • Self-regulation: internalizing standards so monitoring shifts from teacher-enforced to self-enforced Self-monitoring improves self-regulation. [+M]
  • Community building: establishing a shared climate that supports academic risk-taking and engagement Task value increases motivation and engagement. [+M]

Instructions¶

  1. Open with elicitation: ask students how they want to be treated by classmates and by the teacher; collect responses publicly (Class Discussion).
  2. Guide translation from values to behaviors: cluster student responses into respectful, fair, kind, and empathetic categories and convert each into an observable "we" statement (Collaborative Decision-Making).
  3. Model and rehearse: demonstrate each norm in action and have students practice, treating the code as a taught skill rather than a posted list (Coaching).
  4. Finalize and post the code as a class-authored artifact; every student signs or otherwise commits to it.
  5. Revisit and repair: reference the code when conflicts arise, asking "which of our agreements does this touch, and how do we restore it?" rather than issuing top-down penalties.

Related Strategies¶

  • Active Listening — the facilitation stance that makes the elicitation discussion genuine rather than performative
  • Acceptance, Responsibility, and Sharing — the dispositions the code is designed to cultivate
  • Action Planning — converting agreed norms into concrete behavioral commitments
  • Student-co-created acceptable/unacceptable behavior guides for conflict management
  • Implement programs to improve students' classroom behavior and social skills

Examples¶

  • Responsive Classroom (Center for Responsive Schools) — the "Hopes and Dreams" + "Classroom Rules" routine: teachers elicit student learning goals, then co-create rules that support them; teacher models and students rehearse each rule during the first six weeks of school. https://www.responsivereads.com
  • Restorative justice implementations in Denver Public Schools — class agreements serve as the reference point for restorative conversations after conflict, replacing exclusionary discipline.
  • A fifth-grade teacher facilitates a discussion in which students list how they want to be treated, clusters the responses under "respectful, fair, kind, empathetic," and the class votes on a five-statement code that is posted and referenced daily.
