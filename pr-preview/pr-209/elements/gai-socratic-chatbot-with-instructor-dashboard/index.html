Web-based GAI chatbot with instructor-facing learning analytics dashboard¶

Element · All elements Evidence · 4 claims (1 for, 3 mixed) · 1 study (1 design), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The third-cycle tool is a standalone, login-based web application powered by OpenAI's Assistants API (GPT-4o-mini) with a file search tool for course-specific content. Instructors design learning activities that are converted into structured prompts constraining the LLM to function as a Socratic tutor, and can specify communicative tone, teaching style, level of answer disclosure, and supporting documents. It includes a built-in LA dashboard with four tabs—Conversation Stats, Student Stats, Engagement, and Raw Data—showing message counts, average message length, conversation duration, GPT-4o-Mini message summaries, word clouds, and customizable scatterplots of lexical diversity and vocabulary size, plus verbatim transcripts.

Constraints¶

  • Technical limitations such as delayed responses, occasional inaccuracies, and absence of multimodal features affected user experience

Target Learners¶

  • higher education students

Target Learning Goals¶

  • self-reflection
  • comprehension of course readings
  • study strategies

Affordances¶

  • Three Phase Srl Chatbot Scaffolding Framework

Claims¶

  • Chatbot engagement was highly uneven: 8 of 15 voluntary users interacted continuously while 7 interacted superficially [~W]
  • Students primarily used the Socratic-tutor chatbot as a study aid aligned with existing study habits rather than for the intended Socratic reflection [~W]
  • Telegram-based chatbot use declined after initial novelty, with platform friction cited as a barrier [~W]
  • Students find reflective prompts accompanied by visual elements more actionable and easier to interpret than plain-text prompts [+W]
