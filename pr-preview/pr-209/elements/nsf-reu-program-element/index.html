NSF Research Experiences for Undergraduates (REU) program¶

Description¶

The article describes the National Science Foundation's Research Experiences for Undergraduates (REU) program, an NSF initiative in the STEM workforce domain. The fact sheet states the program "was created in 1987 to strengthen the science, technology, engineering, and mathematics (STEM) workforce." It is presented as a program whose monitoring and evaluation capacity the fact sheet aims to expand.
