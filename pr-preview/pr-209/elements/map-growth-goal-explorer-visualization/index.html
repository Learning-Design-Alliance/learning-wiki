MAP Growth Goal Explorer: data visualization supporting fall-to-spring growth goal setting¶

Element · All elements Evidence · no claims cited

Description¶

The MAP Growth Goal Explorer is a data visualization designed to support and simplify the goal-setting process by showing a range of possible fall-to-spring growth goals against the backdrop of important academic benchmarks. The page states it is intended to help teachers, families, and students work together to establish goals that strike "a balance between what is meaningful and what is realistic." It is listed under the topics Equity and Growth, with an associated user guide and FAQ.

Design Implications¶

Context¶

Requirements¶

  • Requires MAP Growth assessment data, since the tool displays fall-to-spring growth goals drawn from MAP Growth benchmarks

Constraints¶

  • The page describes the tool's purpose only; it reports no evaluation of the tool's effects on goal setting or outcomes

Target Learners¶

  • K-12 students assessed with MAP Growth

Target Learning Goals¶

  • Setting realistic and meaningful academic growth goals for a school year

Related Elements¶

  • NWEA College Explorer tool linking MAP Growth scores to higher-education benchmarks
  • MAP Growth assessment
  • MAP Growth Goal Explorer: a tool for setting fall-to-spring growth goals against academic benchmarks

Examples¶

  • Set growth goals collaboratively so they balance meaningfulness and realism
  • Use score-linked college exploration alongside goal setting and parent conferences to build post-secondary plans
