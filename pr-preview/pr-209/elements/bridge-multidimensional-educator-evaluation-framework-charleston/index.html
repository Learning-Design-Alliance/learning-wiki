Charleston County School District BRIDGE multi-dimensional educator evaluation framework¶

Element · All elements Evidence · 2 claims (1 for, 1 mixed) · 2 studies (2 associational), q2 · 0 of 2 report an effect size · 2 claims rest on one study

Description¶

The BRIDGE framework is the district's multi-dimensional educator evaluation system, in which value-added measures are one component. The report states that value-added measures of teacher and principal effectiveness are "combined with other measures in the district's multi-dimensional BRIDGE evaluation framework." It was implemented in Charleston County School District as part of a Multi-Dimensional Educator Evaluation Framework and Educator Effectiveness Rating System project spanning 2013-2018.
