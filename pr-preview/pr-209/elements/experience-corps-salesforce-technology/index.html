Salesforce-based web database and online survey infrastructure for program management¶

Element · All elements Evidence · no claims cited

Description¶

The program's stated technology requirements include "Internet access with an updated web browser to access a web-based Salesforce database system". Volunteers, teachers, and staff need access to weblinks for online surveys, and the program needs capacity to manage the Salesforce database and to produce reports. This infrastructure supports volunteer data collection and program reporting.
