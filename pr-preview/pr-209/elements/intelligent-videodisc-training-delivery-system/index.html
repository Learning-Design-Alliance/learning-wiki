Intelligent videodisc training delivery system (VTDS)¶

Element · All elements Evidence · no claims cited

Description¶

An intelligent videodisc system is a configuration in which a computer drives the videodisc player's functions instead of manual control, adding to consumer-player capabilities all the capabilities of interactive computer-assisted instruction. The report reserves the title for a computer capable of generating the better-known CAI functions, and describes delivery software functions including display control, response acceptance, answer analysis, conditional selection and generation logics, and a student data area. It introduces the requirement and opportunity for interactive software delivering intelligent and semi-intelligent interactions between the soldier and the system.

Design Implications¶

Context¶

Requirements¶

  • A computer capable of generating the better-known CAI functions, linked to the player; delivery software must implement L0 functions and ideally L1 and L2 commands

Constraints¶

  • Consumer, I/E, and first-generation intelligent systems offer only two audio tracks, requiring an entire video frame to be played for every 1/30 second of audio

Target Learners¶

  • Army soldiers in institutional and field training

Target Learning Goals¶

  • Interactive practice with feedback, scoring, record-keeping, simulations, and learner-controlled sequencing

Claims¶

Related Elements¶

  • Videodisc authoring and production system (VAPS)

Examples¶

  • Build L1 commands for survey and learning tactics into delivery system software, with an L2 advisor when strategy is involved
