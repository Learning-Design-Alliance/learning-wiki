SRA 2Inform: web-based, teacher-facing data management application for tracking student performance¶

Element · All elements Evidence · 2 claims (1 for, 1 against) · 1 study (1 causal), q3 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

SRA 2Inform is "a data management application for teachers to enter and track student performance" supporting the Corrective Reading program. It is web-based and requires only an internet connection. The application is teacher facing only, meaning students do not interact with it directly.

Design Implications¶

Context¶

Requirements¶

  • Requires only internet connection

Constraints¶

  • The application is teacher facing only

Target Learners¶

  • Teachers of upper-elementary struggling readers using Corrective Reading

Target Learning Goals¶

  • Monitoring and tracking student reading performance data

Claims¶

  • Most outcomes of Corrective Reading, including state reading tests, did not show positive effects, yielding an average effect size of only +0.06 [-W]
  • Corrective Reading produced a significant positive effect on Woodcock Word Attack (effect size = +0.15) in its only qualifying evaluation [+W]
