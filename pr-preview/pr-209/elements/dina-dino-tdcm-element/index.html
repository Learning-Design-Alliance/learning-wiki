DINA and DINO models as typical theoretical diagnostic classification models¶

Element · All elements Evidence · 2 claims (1 for, 1 mixed) · 1 study (1 design), q1 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

The article identifies the DINA model and the DINO model as "two typical theoretical diagnostic classification models". Each TDCM makes different assumptions about the relationship between a student's response pattern and attribute profile. In this article they serve as the theoretical models combined with ANNs in the semi-supervised framework.

Design Implications¶

Context¶

Requirements¶

  • A Q-matrix and diagnostic assessment response data are needed to apply these models for classifying latent attribute profiles

Constraints¶

Target Learners¶

  • students assessed with diagnostic classification assessments

Target Learning Goals¶

  • classification of students' latent attribute profiles from diagnostic assessment responses

Affordances¶

  • Semi Supervised Ann Cdm Framework

Claims¶

  • A semi-supervised ANN method combining DINA and DINO achieves appreciated classification performance across test conditions, especially when diagnostic quality is not high or the Q-matrix contains misspecified elements [+W]
  • Misspecification of theoretical diagnostic classification models and inaccurate Q-matrices impact classification accuracy [~W]
