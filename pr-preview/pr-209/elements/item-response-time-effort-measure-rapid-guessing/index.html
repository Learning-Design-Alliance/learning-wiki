Item response time as a measure of examinee test-taking effort classifying rapid-guessing versus solution behavior¶

Element · All elements Evidence · no claims cited

Description¶

Computer-based testing enables measuring examinee effort through response times: "At the item level, responses can be classified as exhibiting either rapid-guessing behavior or solution behavior based on the item response time." This study applied that classification approach to a commercially available, low-stakes instrument rather than the locally developed instruments used in most prior response-time research.

Design Implications¶

Context¶

Requirements¶

  • Requires computer-based testing so that item response times can be captured for classifying responses.

Constraints¶

  • Most previous response-time research used locally developed instruments; this study extends the approach to a commercially available instrument.

Target Learners¶

  • Examinees taking large-scale low-stakes assessments

Target Learning Goals¶

  • Valid measurement of achievement under low-stakes testing conditions
