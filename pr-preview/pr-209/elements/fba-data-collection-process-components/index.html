FBA data collection and analysis process: indirect, direct observation, summarizing, and functional analysis¶

Element · All elements Evidence · no claims cited

Description¶

The report describes four components of FBA practice. "Indirect data collection involves reviews of existing behavioral records; the use of behavioral checklists or rating scales; and interviews or surveys with teachers, students, and other adults." Direct observation documents antecedents and reinforcements in the natural environment. Summarizing produces an operational definition, hypotheses about the behavior's function, and identification of manipulable contextual factors. Functional analysis tests the hypotheses experimentally, using single-case designs to manipulate environmental context and reinforcement and examine effects on behavior.

Design Implications¶

Context¶

Requirements¶

  • Data collection must identify the problem behavior, the context in which it occurs, and perspectives on why it occurs before hypotheses are generated and tested.

Constraints¶

  • Functional analysis requires a rigorous, experimental testing approach incorporating single-case designs.

Target Learners¶

  • Individual students with problem behavior in school-based settings

Target Learning Goals¶

  • Identifying the function of problem behavior to select an individualized intervention
