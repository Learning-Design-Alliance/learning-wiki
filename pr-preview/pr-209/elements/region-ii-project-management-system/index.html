Comprehensive project management system with PERT charts and critical work activities¶

Element · All elements Evidence · no claims cited

Description¶

To operate the project, a comprehensive management system was developed with an external agency (EPIC Diversified Systems Corporation). The report states that "the Project, with the assistance of an external agency, then developed a comprehensive management system* that would provide a step-by-step approach to Project operation." Components include a management schematic, goals, organizational charts, performance and process objectives, critical work activities, a Gantt chart, a monitoring system, and job descriptions; the Project Office prepared a PERT chart for each of the fifteen CWAs.

Design Implications¶

Context¶

Requirements¶

  • A field coordinator in each of the four state departments of education, responsible to both the Project Office and a designated state official

Constraints¶

  • Decision-making is shared, and the report notes that having a management system spelled out is one thing while dealing with reality is something else

Target Learners¶

  • project staff and state department administrators managing regional staff development

Target Learning Goals¶

  • coordinated, step-by-step management of a multi-state staff development project
