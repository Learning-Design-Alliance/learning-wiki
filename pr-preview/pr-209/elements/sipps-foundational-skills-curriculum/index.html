SIPPS foundational skills reading curriculum¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 causal), q2 · 1 of 1 report an effect size · 1 claim rests on one study

Description¶

SIPPS is a foundational skills reading curriculum for new and struggling readers in grades K–12 that provides "a structured-literacy approach to instruction through explicit routines focused on phonological awareness, spelling-sounds, and sight words." It can serve as a core/Tier I program supporting grade-level foundational skills standards, or as a Tier 2/Tier 3 intervention to accelerate progress and close gaps. It is designed for small-group format and can be implemented by classroom teachers, interventionists, or paraprofessionals.

Design Implications¶

Context¶

Requirements¶

  • Implemented in a small-group format with an identified teacher and ongoing progress monitoring

Constraints¶

Target Learners¶

  • New and struggling readers in grades K-12, including older students in grades 4-12 via SIPPS Plus

Target Learning Goals¶

  • Word recognition: phonological awareness, spelling-sounds, and sight words

Claims¶

  • SIPPS as a Tier 2 intervention significantly improves first- and second-graders' reading skills on DIBELS (effect size +0.25) [+W]

Related Elements¶

  • IMSE's OG+ Structured Literacy foundational skills program
  • OnYourMark virtual early literacy tutoring program

Examples¶

  • Provide implementation professional development and support approximately every three weeks
