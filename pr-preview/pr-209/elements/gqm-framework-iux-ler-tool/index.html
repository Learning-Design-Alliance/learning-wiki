Goal-Question-Metrics (GQM) framework adapted for IUX research on LER technologies¶

Element · All elements Evidence · no claims cited

Description¶

The toolkit adapts the GQM framework, "developed in 1984 at the Software Engineering Lab of the NASA Goddard Space Flight Center," as a "systematic and goal-oriented approach" to define, measure, and evaluate software quality. Applied to LER IUX, it captures discrete goals, guiding questions, and metrics for smaller projects. A template structures the goal-question-metric triplet, and a pilot example shows goals about accessible language, fee navigation, and privacy.
