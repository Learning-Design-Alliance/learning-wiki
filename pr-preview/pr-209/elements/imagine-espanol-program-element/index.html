Imagine Español: personalized Spanish language and literacy program for grades Pre-K–6¶

Element · All elements Evidence · 3 claims (3 for) · 1 study (1 causal), q2 · 1 of 1 report an effect size · 3 claims rest on one study

Description¶

Imagine Español is a personalized learning program designed to "accelerate Spanish language and literacy development for students in grades Pre-K–6" through engaging, culturally diverse content. It supports dual-language, transitional bilingual, or world languages programs and provides "adaptive and developmentally appropriate instruction" focused on conceptual understanding of Spanish language domains.

Design Implications¶

Context¶

Requirements¶

  • Network bandwidth and device hardware must meet minimum system requirements; standard networked computers or tablets with microphone access (preferably a headset) are needed

Constraints¶

  • Implementation requires network configuration to permit specified allowed URLs through firewalls on designated ports; the Imagine Learning Student App may need to be installed depending on device

Target Learners¶

  • students in grades Pre-K–6 in dual-language, transitional bilingual, or world languages programs

Target Learning Goals¶

  • Spanish language and literacy development
  • English reading proficiency

Claims¶

  • Imagine Español students in Grades 2–6 made significantly greater English reading gains than peers (ES +0.16) [+W]
  • In Grades K–1, Imagine Español students outperformed peers on earlyReading but the difference was not statistically significant (ES +0.13) [+W]
  • Imagine Español use is associated with significantly higher Spanish CIRCLE Progress Monitoring scores for Pre-K students (ES +0.25) [+W]

  • Lectura Proactiva: one-to-small-group Spanish reading intervention accelerating the transition to reading in English
