Grow Network reporting system for grades 3-9¶

Element · All elements Evidence · no claims cited

Description¶

The Grow Network is a contracted reporting program that, in the article's words, provides "a distinctive reporting system in print and online that trans- forms assessment results into clear and effective tools for action by principals, teachers, and parents." It includes customized printed reports showing performance in "clear, actionable topics" tied to state and local standards, personal web accounts for educators, instructional materials in Math and English Language Arts, and printed and online resources for parents explaining children's strengths and weaknesses. CPS, through DRE, contracted with the Grow Network to serve all CPS elementary schools beginning in September 2002, with DRE overseeing and coordinating the work.
