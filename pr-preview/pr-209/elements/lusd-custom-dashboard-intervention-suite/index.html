Lynwood Unified's custom dashboard and intervention tool suite (Secondary Data Dashboard, AIMS, LynPBIS+, LIVE, CAPS)¶

Element · All elements Evidence · 1 claim (1 for) · 1 study (1 design), q1 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

Lynwood Unified built a suite of in-house tools, developed by a Secondary Data Lead with software development skills, that integrate with the Aeries SIS and provide role-specific views for administrators, counselors, and teachers. "AIMS is a system for tracking academic interventions assigned by teachers"; it identifies EL typology, generates PDF contracts, and sends automated email alerts. The Counseling Intervention Management module syncs intervention data back into the SIS; LynPBIS+ logs check-in/check-out for tiered PBIS supports; LIVE links classroom observations to D/F data as a Tier 1 intervention; CAPS visually tracks progress toward A-G requirements for families.

Design Implications¶

Context¶

Requirements¶

  • An in-house data lead with software development skills
  • Integration with the district's existing SIS

Constraints¶

  • The report notes the tools are not fully integrated into one single platform but are strategically designed to work together

Target Learners¶

  • high school students in an urban/suburban district, including English Learners

Target Learning Goals¶

  • college and career readiness, on-track graduation, and aligned academic and behavioral supports

Claims¶

  • Lynwood Unified's custom dashboards and intervention tools were followed by a decrease in high school D/F rates of over 8% and 593 interventions logged in one year [+W]

Related Elements¶

  • Freshman On-Track dashboard aggregating attendance, grades, discipline, and momentum scores into a single student view
