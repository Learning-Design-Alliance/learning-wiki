Charts of available instrumentation and curriculum for affective development¶

Element · All elements Evidence · no claims cited

Description¶

The report supplies two appendix charts cataloguing existing resources: Appendix A charts available instrumentation for assessing affective development, and Appendix B charts available curriculum for affective development. The preface states the summary report accomplishes its aims by "supplying charts of the available instrumentation for affective development and available curriculum for affective development." These charts were intended to relate assessment devices and curriculum materials to the report's five dimensions of affective development.
