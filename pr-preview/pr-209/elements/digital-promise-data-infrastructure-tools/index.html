Data infrastructure tools supporting rapid-cycle testing: Edtech Pilot Framework, TeamSpace, and Dynamic Learning Project¶

Element · All elements Evidence · no claims cited

Description¶

The report describes three tools from Digital Promise's portfolio that provide infrastructure for piloting and data analytics. The Edtech Pilot Framework guides educators and product developers through an eight-step evidence gathering process with free online tools and videos. TeamSpace is a cloud-based analytics workspace helping educational organizations securely and collaboratively analyze complex data from one or more digital sources. The Dynamic Learning Project uses a Qualtrics platform with snapshot pre/post surveys, giving schools analyzed and visualized data at the end of each eight-week cycle.

Design Implications¶

Context¶

Requirements¶

  • Processes and tools to facilitate efficiencies in piloting and data analytics
  • Tools and processes to support exploratory data analysis as educational data expands in volume and variety

Constraints¶

Target Learners¶

  • Educators, school and district leaders, researchers, and technology companies

Target Learning Goals¶

  • Evidence-based decision making and continuous improvement through data

Related Elements¶

  • Learning management systems (LMSs) as infrastructure for competency-based, personalized learning

Examples¶

  • Conduct ed-tech pilots by articulating the instructional need, setting clear product-review criteria, involving educators in planning, supporting educators throughout, gathering data from all users, deciding from data, negotiating purchasing options, and sharing results
  • Provide professional learning opportunities and free tools to support educators in conducting edtech pilot studies
