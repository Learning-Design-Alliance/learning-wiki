Summit: an arithmetic tutoring system combining visual animation with spoken explanation in two representations¶

Element · All elements Evidence · no claims cited

Description¶

Summit (Feurzeig & White, 1984) is a computer system for teaching addition and subtraction that "combines visual animation with spoken explanation." It has two representations for addition and subtraction: the standard algorithm and a bin-model representation derived from Dienes blocks. In the bin model, when 9 icons are added to a ones bin holding 3, all 12 icons are displayed, then 10 are removed one at a time into a box that becomes a tens icon, with the computer narrating each step; the standard algorithm is modelled similarly with spoken explanation synchronized to on-screen actions.
