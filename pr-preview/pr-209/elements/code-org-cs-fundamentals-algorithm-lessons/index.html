Code.org CS Fundamentals unplugged lessons: Dice Race, My Robotic Friends, Paper Planes, Plant a Seed, Tangrams¶

Element · All elements Evidence · no claims cited

Description¶

The deck recommends five named Code.org CS Fundamentals lessons for introducing algorithms: "Dice Race", "My Robotic Friends", "Real-life Algorithms:Paper Planes", "Real-life Algorithms: Plant a Seed", and "Tangrams". These are unplugged-style activities that ground the algorithm vocabulary in physical tasks, and the deck points teachers to a Code.org YouTube video for support.
