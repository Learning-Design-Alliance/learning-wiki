Kotapish 1993¶

Kotapish, Carl E. (1993). The Place of Grammar in the ESL/EFL Classroom: An Annotated Bibliography. https://eric.ed.gov/?id=ED376699

q1 · i? · review · r1

The bibliography reports, citing Terrell (1991), a discussion of Krashen's model in which processing of input, not grammar instruction, plays the key role in second language learning. The annotation notes the informal evidence and that three ways grammar instruction might affect acquisition are proposed; no effect size is printed.

"However, some informal evidence exists that indicate that adults do not automatically process input in order to develop competence. This evidence again resurrects the question as to the role of grammar in second language acquisition."
