Enhanced Core Reading Instruction 2017¶

Enhanced Core Reading Instruction. (2017). Evidence review summary. https://www.evidenceforesight.org

q2 · i? · review · r?

Program description of the staffing model in the studied program: core reading instruction is provided by classroom teachers in whole-group settings, while "Most small-group instruction is provided by instructional assistants" working with groups of 3-5 students. The summary states minimum Tier 2 qualifications are paraprofessional status.

"Most small-group instruction is provided by instructional assistants. Teaching focuses on phonemic awareness, sound blending, word reading, fluency, reading decodable text, and irregular words."
