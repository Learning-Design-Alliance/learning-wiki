The synthesis reports that retrieval activities including "self-testing and low-stakes quizzing" strengthen and enrich memory, leading to stronger and more enduring learning.

"like self-testing and low-stakes quizzing, that ask students to practice remembering the information they’ve been taught by retrieving it from their long-term memory actually change the nature of memory by strengthening the path to memory and enriching the memory itself"
