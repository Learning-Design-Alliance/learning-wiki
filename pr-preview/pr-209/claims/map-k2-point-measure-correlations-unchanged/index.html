Evidence¶

He 2020¶

He, W. (2020). MAP Growth K–2 item fit analysis: A follow-up study. NWEA. https://www.nwea.org/research/publication/map-growth-k-2-item-fit-analysis-study-a-follow-up-study/

q2 · i? · associational · r2

Summary statistics in Table 2.2 show identical rpm_new and rpm_old means (0.31) for both content areas and samples; the report attributes the invariance to the linear transformation of ability estimates.

"The old and new statistics for the point measure correlations remained the same for both Reading and Mathematics items in the follow-up study, which is expected as the new person ability estimates for each content area were obtained by applying a linear equation to the old person ability estimates."
