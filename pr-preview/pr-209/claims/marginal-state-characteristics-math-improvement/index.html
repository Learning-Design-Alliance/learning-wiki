q2 · i? · associational · r1

State-level regression using NIEER data, accounting for differences between states. The association with the proportion of districts offering state-funded prekindergarten was marginal ("BPct =.07, SE =.036, p = .09").

"Residing in a state in which a higher proportion of districts offer state-funded prekindergarten is associated with a marginally higher likelihood of math improvement (BPct =.07, SE =.036, p = .09)."
