# Compile and bundle outreach analysis apps for cross-platform home use with runtime language selection

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends distributing outreach analysis software as optimized compiled binaries with easy installers rather than scripts. AppImage bundles the whole application for Linux; pkg and .msi installers serve MacOS and Windows. Runtime language selection supports "students not proficient in English". This hugely improves accessibility of the program.
