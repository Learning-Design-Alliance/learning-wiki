# Use LLMs in self-directed studio learning for structured precedent recall, critical-analysis scaffolding, and just-in-time software tutorials

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 3 studies (2 qualitative, 1 theoretical), `q1`–`q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
For self-directed learning, the article proposes LLM actions including systematic precedent recall via structured prompts, critical-analysis scaffolding through targeted why/how questions emulating expert feedback, design-validation prompting against rubrics, and personalized just-in-time tutorials for design software. It reports that "LLMs strengthen systematic precedent recall by converting textual and visual data into structured prompts that aid long-term memory and reduce bias toward visually striking examples," supporting interpretation through conceptual rather than aesthetic similarity.
