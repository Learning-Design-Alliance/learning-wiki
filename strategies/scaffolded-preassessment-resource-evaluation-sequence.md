# Scaffold learners with a preassessment resource-evaluation poll plus source-evaluation videos before a written assignment requiring cited resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article's most successful design sequence embeds short digital literacy activities before a peer-reviewed written assignment: a poll asking learners to select which of 4 online resources is reliable, a discussion step for justifying choices, and short videos on evaluating sources (author and organization, website content, summary). The authors conclude that "the final and most successful guidance and preparatory steps were tasks that scaffolded learners in the critical evaluation of online health care information," and suggest the approach is applicable to a wide range of online courses with diverse learner stakeholders.

## Design Implications

### Context
#### Requirements
- A written or poll-based assessment in which learners must find and cite online resources
- Discussion forums attached to each activity so learners can articulate their evaluation rationale
- A range of activities eliciting different learning types (acquisition, discussion, inquiry, practice, production)
#### Constraints
- From Run 6 onward only learners who paid for certification could access the written assessment, likely reducing engagement with the written assignment; findings from the small later-run samples warrant caution

### Target Learners
- heterogeneous MOOC audiences including patients, caregivers, students, and health care professionals

### Target Learning Goals
- evaluating the reliability and validity of online health care resources
- citing appropriate resources in written work

### Affordances
- Laurillard Conversational Framework Mooc Learning Types

## Claims

- [Adding preassessment digital literacy tasks and source-evaluation videos increased the average number of references per MOOC written assignment from 1.8 in Run 1 to 3.5 in Run 8 (P=.001)](../claims/mooc-digital-literacy-tasks-increase-references.md) [+W]
- [The resource-reliability poll task stimulated discussion, with 12 of 16 learner comments demonstrating correct evaluation of resource reliability with justification](../claims/poll-task-stimulates-reliability-discussion.md) [+W]
- [The percentage of assignments listing references rose from 55% in Runs 1-2 to 64% in Run 7 and 71% in Run 8, though the Run 1 versus Runs 7/8 comparison did not reach significance (P=.11)](../claims/referencing-proportion-trend-not-significant.md) [+W]
- [The Run 7 preassessment digital literacy poll task alone was associated with a significant increase in average references per summary (2.9 vs 1.8 in Run 1, P=.049)](../claims/run7-poll-task-references-increase.md) [+W]
