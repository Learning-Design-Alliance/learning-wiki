# Incorporate student feedback loops so AI assessment systems improve accuracy and guide learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Tip 8 recommends building feedback loops into AI-based assessment: AI models can provide near-instantaneous individualized feedback, AI tutoring systems can offer metric-based formative feedback on quantifiable criteria, NLP algorithms can categorize narrative feedback into competencies, and video-based assessments can yield automated ratings. The article presents these as ways student feedback improves assessment accuracy and enhances educational outcomes in medical education.

## Design Implications

### Context
#### Requirements
