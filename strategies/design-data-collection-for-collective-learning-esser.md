# Districts should design and implement data collection processes now to shape collective learning from ESSER interventions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The presentation recommends that district leaders act immediately on measurement infrastructure for recovery spending, asking "What can districts do now to design and implement data collection processes that will shape collective learning?" The strategy treats data collection design as the mechanism by which districts learn collectively from the unprecedented ESSER interventions rather than treating each intervention as an isolated expenditure.
