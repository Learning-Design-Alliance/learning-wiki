# Use response time to identify test taker disengagement as rapid-guessing behavior

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 mixed) · 3 studies (3 associational), `q2`–`q3` · 1 of 3 report an effect size · 4 claims rest on one study

## Description
This strategy uses item response time on computer-based tests to detect disengagement: when a test taker responds too quickly for the item to have been meaningfully considered, the response is flagged as rapid-guessing behavior. The presentation title frames the approach as "Identifying test taker disengagement using response time," and notes that on computer-based tests such item responses "can be identified as rapid-guessing behavior."

## Design Implications
