# Scaffold open-ended computational projects with professional-practice guidelines, rubrics, seed simulations, example essays, and TA drop-in sessions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (2 qualitative, 1 design), `q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The course supported students' computational essay projects with several scaffolds: a written assignment description framing the project as authentic research, a five-category grading rubric (investigation question, coding, physics, conclusions, written report, each 0-4), example computational essays showcasing best practices, pre-made "seed" simulations in Jupyter notebooks with suggested questions, and 2-hour TA drop-in sessions. Seed simulations were intended to add authenticity, reduce the difficulty of finding a question, and implicitly introduce notebook use.

## Design Implications

### Context
#### Requirements
- Instructors must provide example essays and working seed simulations, plus TA support sessions during the project period
#### Constraints
- Students still scaled back plans when seed simulation code structure resisted modification; finding a question remained difficult for some students

### Target Learners
- undergraduate physics students in courses integrating computation

### Target Learning Goals
- conducting independent computational research projects and writing computational essays

### Affordances
- Disciplinary Computational Literacy Three Pillars
