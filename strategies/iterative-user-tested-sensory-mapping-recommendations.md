# Iteratively refine non-visual data mappings through user testing, preferring identifiable timbres and non-volume parameters for distance

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 2 studies (1 causal, 1 design), `q2`–`q3` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The study's user testing yielded concrete mapping recommendations for representing data non-visually: pitch differences were "hardly quantifiable (it is preferable to use sound with an identifiable timber)", and "The differences in volume were hardly quantifiable (better using other parameters to represent distances)". The authors also recommend avoiding stereo sounds for objects at astronomical distances and avoiding connections between representation and physical reality that invite misconceptions. These recommendations were implemented in subsequent design iterations of the multi-sensory representation.

## Design Implications

### Context
#### Requirements
- Iterative testing with both BVI and sighted users plus expert advice, as the article did in collaboration with the Institute for Blinds Francesco Cavazza and Bologna University's Physics Department.
#### Constraints
- Recommendations derive from qualitative evaluation with 27 adult users, analyzed by direct text analysis rather than quantitative testing.

### Target Learners
- sighted and blind or visually impaired adult learners in outreach and educational settings

### Target Learning Goals
- mapping physical parameters of non-visible data onto perceptible sensory features without ambiguity
