# Offer optional professional development for administrators and educators alongside program implementation

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Imagine Learning offers optional virtual or on-site professional development and training in addition to Customer Success support. Administrator sessions focus on "how to lead with success", tailored to each school's implementation model and goals, while educator sessions include workshops on getting started and using program features "to help students achieve optimal learning outcomes".

## Design Implications

### Context
#### Requirements
- Access to Imagine Learning's Customer Success team and optional virtual or on-site training sessions
#### Constraints
- Professional development is optional rather than required for implementation

### Target Learners
- Elementary students in grades 1-5

### Target Learning Goals
- Effective implementation of the math fluency program
