# Provide organizers with a tree-structured hackathon planning kit that guides event design through questions about event goals

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Workshop participants proposed practitioner materials to lower the barriers to running hackathons. In the plenary session, "participants also proposed materials which might be useful for practitioners, e.g., a tree-structured hackathon planning kit which guides hackathon organizers towards a suitable event design based on a set of questions (e.g., about their event goals)". The discussion and conclusion section reports that the majority of participants agreed a decision tree allowing organizers to search for event design guidelines based on minimal questions about event goals or objectives would be helpful, alongside a collection of lessons-learned resources and training materials.
