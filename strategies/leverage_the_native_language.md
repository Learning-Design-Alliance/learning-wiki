# Leverage the Native Language

## Description
Integrate students' native languages into project work. Ask how you can leverage that asset. Can they create a product in both languages? Instead of seeing language as a barrier to the project, view it as an opportunity.

## Design Implications

### Context
#### Requirements
- Classroom environment that values linguistic diversity and opportunities for multilingual expression.
#### Constraints
- May require translation support and careful coordination to ensure understanding.
