# Deploy soft barriers transparently: institutional approval, policy-level disclosure, and accessibility testing

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper's responsible-use recommendations state that deployments of Unicode barriers should be institutionally approved and tested for accessibility, since zero-width characters can affect screen readers, and that "Unicode barriers operating without disclosure are deceptive". The claim is not that barriers are secure but that they change the default path for ordinary use.

## Design Implications

### Context
#### Requirements
- Institutional approval, disclosure at the policy level, and accessibility testing before deployment
#### Constraints
- Motivated users can bypass barriers by requesting clean output, running a text normalizer, or retyping the code

### Target Learners
- programming students
- institutional administrators deploying AI assistants

### Target Learning Goals
- ethical and transparent management of AI code handoff in educational settings

### Affordances
- Ai Code Handoff Problem
