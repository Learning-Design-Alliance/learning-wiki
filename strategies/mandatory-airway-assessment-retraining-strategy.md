# Mandatory pre-intubation airway assessment with retraining for non-compliance

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
In the Act phase, the program made airway assessment compulsory: "Airway assessment is now mandatory before intubation. Those who do not perform this assessment will require retraining." This responded to monitoring data showing that 80% of cases failing the clinical standard had skipped airway assessment. The updated SOP manual added an airway assessment flowchart and complication treatment list, and a new Difficult Airway Management module was added.

## Design Implications

### Context
#### Requirements
- Real-time operation monitoring forms to detect non-compliance
- Updated standard operating procedure manual with assessment flowchart
- One-on-one simulation training capacity for retraining
#### Constraints
- Derived from a single-center retrospective study; the authors recommend prospective randomised multi-center validation

### Target Learners
- standardised training residents in the emergency department

### Target Learning Goals
- difficult airway identification before first attempt
- adherence to standardised intubation procedures
