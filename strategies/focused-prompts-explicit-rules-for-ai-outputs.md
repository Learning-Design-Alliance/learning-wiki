# Use focused prompts naming educator decisions and explicit rules for knowledge sources when prompting AI

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
This strategy specifies how to prompt AI during prototyping: name the specific decisions educators need to make, request a small number of concrete options, and require the AI to draw on a defined set of research and curriculum materials. The team found that broad prompts like "What should this dashboard include for literacy educators?" produced long, generic outputs that sounded plausible but were not useful.

## Design Implications

### Context
#### Requirements
- Clear prompts, focused questions, and explicit rules for what knowledge shapes outputs, derived from trusted sources
