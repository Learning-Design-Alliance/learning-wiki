Use TPA results and completer-survey data to target programmatic support and continuous improvement¶

Strategy · All strategies
Evidence · 1 claim (1 mixed) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The report recommends that state agencies and preparation programs use TPA data alongside program completer survey data for continuous improvement. It notes that "many California programs already use these data to target support for individual candidates and make programmatic decisions and adjustments," and that the California Commission on Teacher Credentialing is well positioned to support low-passing-rate programs through accreditation. Creating resources for programmatic learning around TPAs is framed as strengthening preparation statewide.

Design Implications¶

Context¶

Requirements¶

  • Programs need data systems to track TPA scores and access to program completer survey results, as outlined in the CTC's program standards for TPA implementation

Constraints¶

  • Some programs may need better support or systems to be able to learn from their TPA results, per the report

Target Learners¶

  • preservice teaching candidates
  • intern teaching candidates

Target Learning Goals¶

  • readiness to pass a teaching performance assessment
  • programmatic improvement of teacher preparation

Claims¶

  • Racial disparities in TPA pass rates appear in low-performing programs but not in programs with passing rates above 90% [~W]

Related Strategies¶

  • Embed data-driven continuous improvement criteria into state EPP program approval
  • States conduct a statewide survey of new teachers with comparable questions across all programs
  • Use state completer survey data within accreditation to flag struggling programs and expand subsidized high-quality clinical pathways for underserved candidates
