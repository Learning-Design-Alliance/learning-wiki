# Sort papers to be rated into piles of approximately equal value before scoring against the scale

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A rating procedure for objective scales in which the rater first groups drawings into piles of similar quality before assigning scale values. The author writes that those using the scale will find it helpful to "sort the papers to be rated into piles such that the papers of any one pile shall be of approximately equal value and perceptibly different from those of the piles of nearest value." This gives the rater a double set of comparisons and permits faster work using only a limited range of the scale for each pile.
