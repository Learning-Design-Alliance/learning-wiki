# Reduce discrete learning objectives and replace multiple-choice tests with rubric-based assessments in introductory computer courses

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
Based on the analysis of the existing course, the design team determined that the number of discrete learning objectives should be revised from 750 to 150 by collapsing redundancies across programs, and that rubric-based assessments rather than multiple-choice tests were warranted. The course was also to be centered on larger learning projects and problem solving using the software rather than around disembodied learning tasks.
