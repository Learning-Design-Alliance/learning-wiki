# Add leaderboard-based virtual achievements to learning apps to increase user engagement time

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors recommend that developers and educators use incentivized achievement methods such as leaderboards to make learning platforms more engaging, based on their within-subject experiment showing increased engagement time. They write that "by using such incentivized methods, the web and app developers including educators can improve their existing systems to be more engaging for the users". The strategy targets platforms lacking an existing achievement system.

## Design Implications

### Context
#### Requirements
- An existing app with user activity that can be ranked, real-time ranking updates, and informed consent with a drop-out option for participants.
#### Constraints
- Participants ranked in last places may be demotivated to use the app; engagement also rises naturally in months just before exams, independent of the leaderboard.

### Target Learners
- Users of online learning applications, e.g. exam-preparation students

### Target Learning Goals
- Increasing engagement time and participation with learning content

## Claims

- [Average user engagement time in a learning app rose by around 68% from leaderboard off to leaderboard on in a one-group pre-post study of 10 students with no comparison group](../claims/leaderboard-increased-engagement-time-upsc-pre.md) [+W]
- [Participation rose from before to after leaderboard introduction, while answer quality did not decrease, in one single-group pre-post study with no comparison group, per the authors' report](../claims/leaderboard-participation-without-quality-reduction.md) [+W]
- [Participants found the leaderboard competitive, enjoyed gaining positions, and wanted it in other platforms' user interfaces](../claims/participants-found-leaderboard-competitive-enjoyable.md) [+W]
