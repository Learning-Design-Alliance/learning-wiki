# Computer-algebra Hamiltonian construction and numerical chaos exploration extension

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A computational extension in which students use a computer algebra package to construct the Hamiltonian from the full Lagrangian, identify generalised momenta, invert the velocity-momentum relations, and solve the resulting equations numerically. "The second extension aims to strengthen students' analytic and computational abilities by having them use a computer algebra package to construct the Hamiltonian given the Lagrangian in Eq. (13)." The system is a six-dimensional Hamiltonian system expected to behave chaotically in some regions, which students can explore numerically.
