# Fossil Analysis

## Description
Fossil analysis tasks involve examining and describing fossils to develop a 'Fossil Guide.' Learners create drawings and written descriptions for each fossil, enhancing understanding of fossil identification and paleontological concepts.

## Design Implications

### Context
#### Requirements
- Fossils, drawing materials, writing materials
#### Constraints
- Requires access to fossils. Accurate identification is essential.
