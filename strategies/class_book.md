# Class Book

## Description
Class books involve students creating individual pages that are compiled into a single book. This process combines shared writing with individual contributions, offering an audience for student work and encouraging revision and editing. The format invites students to create representations of their ideas, promoting mathematical communication.

## Design Implications

### Context
#### Requirements
- Shared writing activity, materials for creating individual pages (paper, art supplies), and a way to compile the pages into a book.
#### Constraints
- Requires time to create and compile the pages. The quality of the book depends on the engagement and effort of each student.
