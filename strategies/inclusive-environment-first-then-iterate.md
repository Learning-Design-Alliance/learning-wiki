# Build an inclusive classroom environment first, then adopt an EDI approach suited to local context and iterate on student resistance

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article's forward-looking recommendations for physics instructors: start by building an inclusive classroom environment, then try one of the shared approaches (reflection essays, readings, classroom discussions), seek opportunities to grow in facilitation ability, and use resistance and negative feedback to iterate and improve the materials. The authors also advise choosing between the offline Carleton model and the in-class CU model based on local contexts, opportunities, and constraints.

## Design Implications

### Context
#### Requirements
- An inclusive classroom environment built before introducing the EDI approaches
- Conversations with colleagues and students to inform which approach fits the environment
#### Constraints
- The authors note that many instructors are not trained in these approaches and that implementation specifics depend on local context and instructor positionality and strengths

### Target Learners
- undergraduate physics students in sophomore-level modern physics courses

### Target Learning Goals
- engaging with equity, diversity, and inclusion as part of professional physics practice
