# Restricted-Perception Wizard-of-Oz methodology for developing autonomous social robot behaviors

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The methodology involves gathering mock-up data from teacher-student interactions, building perception and interaction modules, conducting WoZ studies where experts remotely control the robot with access only to processed observations matching what the autonomous robot will perceive, and using that data to train a hybrid behavior controller. The article states this ensures "the decision-making of the wizard will be limited to the same perceptions that the autonomous robot will have over the interaction."

## Design Implications

### Context
#### Requirements
- Experts controlling the robot must access only processed perceptual features identical to those available to the autonomous robot
- Mock-up sessions with real teachers to gather pedagogical and empathic strategy data
#### Constraints
- Wizard behavior data is dependent on the same perceptual features that will drive autonomous behavior

### Target Learners
- Children in educational robot scenarios

### Target Learning Goals
- Developing socially plausible autonomous robot tutors
