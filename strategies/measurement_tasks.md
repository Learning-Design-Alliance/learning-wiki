# Measurement Tasks

## Description
Measurement tasks involve using measurement tools and techniques to quantify physical properties such as length, volume, and temperature. Learners devise techniques to measure the number of marbles that can be made out of a set volume of material and perform routine laboratory procedures using a balance. These tasks improve measurement skills and their application in scientific contexts.

## Design Implications

### Context
#### Requirements
- Rulers, balances, thermometers, various objects, materials for making marbles
#### Constraints
- Requires access to measurement tools. Precise measurements are essential for accuracy.
