# Data-Based Decision-Making for Core Instruction

> **Strategy** · [All strategies](index.md)

## Description
Data-based decision-making (DBDM) for core instruction is the systematic cycle of collecting student performance data during whole-class (Tier 1) teaching, analyzing it against learning goals, and using the results to adjust instruction — re-teaching, regrouping, changing representations, or accelerating. It treats core instruction itself as an object of continuous improvement rather than assuming that only intervention tiers need data.

## Design Implications

DBDM operationalizes [Assessment for Learning](../principles/assessment-for-learning.md) at the classroom level: frequent, curriculum-embedded measures give teachers evidence to close the gap between current performance and the goal [Formative evaluation produces substantial learning gains when it feeds instructional adjustment.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S]. The value lies not in the data but in the decision rules attached to it — data without a predefined action ("if fewer than 80% of students meet the criterion, re-teach with a different representation") rarely changes instruction [Data use improves outcomes only when paired with explicit instructional decision rules.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+M].

### Context
#### Requirements
- Brief, reliable, curriculum-aligned measures (e.g., [Curriculum-Based Measurement](../elements/assessment.md)) administered at regular intervals
- Predefined decision rules that map performance bands to specific instructional actions
- Time and structures for teachers to analyze data collectively (grade-team or PLC data meetings)
- Instructional alternatives ready to deploy — re-teaching scripts, alternative representations, flexible grouping plans

#### Constraints
- Data collection without protected analysis time produces compliance behavior, not instructional change [~M]
- Over-reliance on single high-stakes snapshots misleads; brief repeated measures outperform infrequent summative data for instructional decisions [~S]
- Teachers often interpret data to confirm existing beliefs; structured protocols and collaborative analysis reduce confirmation bias [-M]
- Poorly aligned measures (testing what was not taught) generate decisions that waste instructional time [-M]

#### Implementation Variability
- **Team-based:** grade-level teams analyze common assessment data in scheduled meetings (the professional learning community model)
- **Individual:** a single teacher uses exit tickets and quick checks daily to adjust the next lesson
- **System-supported:** platforms (e.g., [AIMSweb](https://www.pearsonassessments.com), [DIBELS](https://dibels.uoregon.edu)) automate progress monitoring and flag students against decision rules
- **DBDM plus inquiry:** teachers frame a hypothesis, collect data, and evaluate the instructional change (action-research variant)

### Target Learners
- Whole classrooms in Tier 1 settings — the goal is preventing failure rather than remediating it [Progress monitoring with decision rules improves achievement, with the largest effects when instruction is adjusted based on the data.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S]
- Students whose needs would otherwise go unnoticed until they require intensive intervention
- Teachers benefit as much as students: the cycle builds pedagogical content knowledge about which adjustments work [~M]

### Target Learning Goals
- Mastery of core academic content (reading, mathematics) at the whole-class level
- Early identification of skill gaps before they compound
- Teacher learning: calibrating instruction to actual student performance rather than pacing guides

### Instructions
1. Define the essential learning goal and the criterion for "enough" (e.g., 80% of students at mastery).
2. Select or design a brief, aligned measure; administer it at a regular interval ([Assessment](../elements/assessment.md)).
3. Analyze results against the decision rule — ideally with a team using a structured protocol ([Check-In](../elements/check-in.md) routines can structure the meeting).
4. Act: re-teach with a different representation, regroup for targeted practice ([Practice](../elements/practice.md)), or accelerate if the criterion is met.
5. Re-measure after the adjustment and evaluate whether the change worked; feed results into the next cycle ([Coaching](../elements/coaching.md) supports fidelity of this step).

## Examples
- **Response to Intervention (RTI)** — Tier 1 progress monitoring with decision rules (e.g., [DIBELS](https://dibels.uoregon.edu) benchmarks every 6–8 weeks) determines whether core instruction is sufficient or students need supplemental tiers [Fuchs & Fuchs, 2006].
- **Data Wise (Harvard)** — a structured 8-step cycle for school teams to analyze student work and adjust instruction ([https://www.gse.harvard.edu/data-wise](https://www.gse.harvard.edu/data-wise)).
- **CGI-informed math instruction** — teachers analyze student strategy use on problem sets to decide which problem types and representations to feature next ([Cognitively Guided Instruction](../patterns/cognitively-guided-instruction-cgi-for-math.md)).
