# Use Cash-Participation in small classes of twenty-four or fewer as a more personal alternative to clicker systems

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article recommends Cash-Participation for intimate gatherings of twenty-four or fewer students, where it simultaneously maximizes feedback, face-time and participation while lifting the veil of anonymity many students embrace at the introductory level. The author prefers it over Peer Instruction with a Class Response System in this setting, while conceding the Class Response System is effective in larger classrooms.

## Design Implications

### Context
#### Requirements
- Class size of twenty-four or fewer for the personal approach as described
- Daily cash-out providing face time and feedback with each student
#### Constraints
- The author states the Class Response System is effective in the larger classroom, limiting this strategy's comparative advantage to smaller gatherings

### Target Learners
- Introductory-level college students, particularly those embracing anonymity

### Target Learning Goals
- Maximizing feedback, face-time and participation
