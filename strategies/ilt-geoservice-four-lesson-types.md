# Organize geography lessons around four lesson types using interactive geoservices based on remote sensing data

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article categorizes interactive geoservices built on remote sensing data (e.g. Google Earth, Google Maps, NASA World Wind) as interactive learning tools and describes four lesson types for their classroom use: lessons to learn new material with pre-created labels and information layers; lessons of skills formation where students do individual practical work, mainly in small groups; lessons of generalization and systematization with creative laboratory tasks in the computer class; and lessons of knowledge, skills and abilities control and correction using control interactive questions based on Google Earth.
