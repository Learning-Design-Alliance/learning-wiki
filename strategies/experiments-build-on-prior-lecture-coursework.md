# Develop sophisticated experiments that build on students' prior lecture coursework

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
For the longer term, the authors recommend that given how experimental reasoning is limited by students' lack of background in modern physics and optics, 'a good strategy would be to develop sophisticated experiments that build as much as possible on students' prior course work in lecture courses.' This addresses the stated limitation that the lab lacks alignment with canonical undergraduate lecture courses, so students face new physics content alongside a new apparatus. The article also notes the reverse benefit: deeper theoretical knowledge enables more expert-like analysis of systematic error sources.

## Design Implications

### Context
#### Requirements
- Experiments designed so the underlying physics connects to content students have already studied in lecture courses
#### Constraints
- The lab course is not specifically aligned with any canonical undergraduate lecture courses, and labs are mostly done in random order, which limits instructional scaffolding because 'all of the labs should be about the same level of difficulty and sophistication'

### Target Learners
- upper-division undergraduate physics majors

### Target Learning Goals
- modeling the physical system
- analyzing systematic error sources
