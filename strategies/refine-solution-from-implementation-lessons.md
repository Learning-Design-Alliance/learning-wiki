# Refine a solution based on lessons learned during implementation

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Phase 2 of the M&E Checklist guides users through refining a solution using lessons learned while implementing it. Rather than treating the initial design as fixed, users explore how implementation experience should shape the solution, and the phase culminates in developing descriptive evidence that the refined version was successfully implemented in the priority community.

## Design Implications

### Context
#### Requirements
- The solution must first have been implemented so that lessons learned during implementation are available to inform refinement.
#### Constraints
- This strategy applies to Phase 2 of the evidence-building process; assessing early evidence of success and validating effectiveness are handled in later phases.

### Target Learners
- Students in the priority community for whom the solution is being refined

### Target Learning Goals
- Improving the design and implementation of teaching and learning solutions
