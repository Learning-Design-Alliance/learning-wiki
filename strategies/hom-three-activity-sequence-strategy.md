# Three-activity predict–observe–explain sequence: multi-metric comparison, metric-driven selection, and tolerance-based transfer

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A compact classroom workflow for a 50-minute meeting built on a predict–observe–explain structure, in which "students first record a written prediction, then interact with the simulator, and finally write a brief explanation reconciling the two." Activity A has students compare the four input families under all three metrics and record one example of metric agreement and one of disagreement. Activity B uses specification-style summaries to choose an input family for different objectives with metric-based justification and a named trade-off. Activity C has students interpret tolerance half-widths and discuss embedding the two-mode primitive in a larger network.

## Design Implications

### Context
#### Requirements
- Full prompts, instructor notes, concept checks, and answer-key details are provided in supplementary sections S5–S7; suggested timings are 10–15 min, 10 min, and 5–8 min for Activities A, B, and C
#### Constraints
- The implementation is intentionally adjustable: an instructor can use all three activity blocks in a full 50-minute format or shorten it by trimming one activity while retaining the same trade-off structure

### Target Learners
- upper-division undergraduate quantum optics students
- early graduate students

### Target Learning Goals
- recognize that interference quality is observable-dependent
- justify state selection with metric-based trade-offs
- connect two-mode reasoning to larger photonic systems
