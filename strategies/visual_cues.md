# Visual Cues

## Description
Using graphics or gestures can help learners who face auditory processing challenges. Providing visual support alongside spoken information can enhance comprehension and retention.

## Design Implications

### Context
#### Requirements
- Visual aids, such as graphics, diagrams, and gestures
#### Constraints
- May not be accessible to all learners due to visual impairments

### Target Learning Goals
<!-- Link to sub-claims -->
- Enhance comprehension, improve retention, support learners who face auditory processing challenges

### Affordances
- Provides reinforcement of concepts through an additional sense, visual cues are permanent so allow the students to revisit the information whenever necessary

### Personalization
- Allow different types of visual cues. Some learners might like to see literal graphics while others need a few gestures.
