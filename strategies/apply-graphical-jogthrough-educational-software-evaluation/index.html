Apply Graphical Jogthrough to evaluate the interface design of educational software¶

Strategy · All strategies
Evidence · 3 claims (3 for) · 2 studies (1 causal, 1 design), q1–q2 · 0 of 2 report an effect size · 3 claims rest on one study

Description¶

The strategy is to use the Graphical Jogthrough method as an expert-based evaluation of an educational program’s interface design, gathering evaluators’ ratings during interaction with the software. The article demonstrates this on the Network Simulator and examines “the possible benefits and limitations of the Graphical Jogthrough method when applied in the case of educational software interface design.”

Target Learners¶

  • designers and evaluators of educational software interfaces

Target Learning Goals¶

  • evaluating interface usability and estimating users’ novice-to-expert pace

Claims¶

  • Graphical Jogthrough applied to educational software offers quantitative and qualitative data for a rough estimation of the novice–becoming–expert pace [+W]
  • In Graphical Jogthrough, evaluators’ ratings yield a graph of estimated proportion of effective users versus the time needed to achieve effectiveness [+W]
  • Task progression graphs show difficult Narrative Manager events raise the distance-to-goal curve while assistive events such as hiding materials produce flat zones that cost user time [+W]
