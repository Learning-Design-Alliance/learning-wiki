# Use alternative strategies beyond error correction feedback for lexical collocation instruction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because error correction feedback was found to be more effective for grammatical collocations than lexical ones, the article recommends that teachers "place more emphasis on learning lexical collocations using other strategies than error corrective feedback." This addresses the finding that lexical collocation errors need attention beyond what error correction feedback provides. The article also notes that "we should pay more attention to some difficult distinguished categories like V+N while teaching collocations."

## Design Implications

### Context
#### Requirements
- Teachers must identify which collocation categories are lexical rather than grammatical
#### Constraints
- Based on findings from six collocation categories only

### Target Learners
- EFL learners at intermediate and advanced levels

### Target Learning Goals
- lexical collocation competence
- V+N collocations
- Adj.+N collocations
