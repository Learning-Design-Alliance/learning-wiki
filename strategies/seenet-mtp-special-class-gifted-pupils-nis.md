# Special class for gifted pupils in science in Nis attracting over one thousand pupils

> **Strategy** · [All strategies](index.md)
> **Evidence** · 8 claims (8 for) · 2 studies (2 causal), `q2` · 0 of 2 report an effect size · 8 claims rest on one study

## Description
An original program related to the Special class for gifted pupils in science in Nis combined public lectures by guest lecturers included in the Network program, educational excursions and competitions. The article reports it "has already attracted more than one thousand of pupils". The authors expect this part of the project to strengthen similar activities at all Network nodes and support contacts between similar school classes in Serbia, Bulgaria, Romania and others.
