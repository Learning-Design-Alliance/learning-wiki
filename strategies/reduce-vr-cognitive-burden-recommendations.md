# Design VR anatomy studies and implementations to reduce cognitive burden: longitudinal exposure, sufficient familiarization, and mixed-reality devices for drawing tasks

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 3 studies (2 causal, 1 theoretical), `q2`–`q3` · 2 of 3 report an effect size · 6 claims rest on one study

## Description
Based on the finding that VR referencing increased cognitive processing demands, the authors recommend that "future studies on VR should consider using a longitudinal design since the stereo and pictorial cues from the VR model require perceptual learning to be appropriately processed." They also suggest incorporating the Stroop test to track cognitive processing, and using mixed reality devices for drawing tasks so learners can simultaneously reference the model while illustrating.

## Design Implications

### Context
#### Requirements
- Extended exposure for perceptual learning of stereo and pictorial cues; a familiarization period with the VR platform
#### Constraints
- The 15-min practice session in this study may not have been sufficient for learners to become familiar with using VR; a VR headset cannot be worn while simultaneously drawing

### Target Learners
- graduate biomedical illustration students
- anatomy learners using VR visualization technologies

### Target Learning Goals
- interpreting visuospatial depth cues from 3D anatomical models
- depicting anatomical structures accurately
