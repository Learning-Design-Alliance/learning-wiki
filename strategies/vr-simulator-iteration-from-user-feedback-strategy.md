# Iterate VR procedural simulators using participant-requested improvements: more realistic ultrasound, movable display, template grid overlay, interface refinements, and a start-of-session tutorial

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The authors used structured free-text feedback after simulator sessions to identify concrete development priorities. Participants' "Additional themes included requests for more realistic ultrasound images, the ability to rotate the probe using the stepper, a movable ultrasound screen, a template grid overlay, user interface refinements for template coordinate selection, and a brief tutorial at the start of the session." These requests define the next iteration's feature list for the simulator.

## Design Implications

### Context
#### Requirements
- A mechanism for collecting structured free-text feedback after each session, as the authors did via post surveys in Google Forms.
#### Constraints
- Feedback came from small convenience samples in two single-session pilots and was coded by a single rater without inter-rater agreement.

### Target Learners
- Oncology staff and trainees learning HDR prostate brachytherapy

### Target Learning Goals
- Improving usability of procedural VR simulation so learners can focus on procedural content
