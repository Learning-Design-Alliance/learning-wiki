# Use employer convenings to identify the soft skills that local employers seek in new hires

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's approach is to gather employers directly: it used "a convening of regional employers in western Pennsylvania to describe soft skills that employers look for in new hires." Convening regional employers lets educators and workforce programs learn the soft skills valued locally, complementing published research. This is the method the publication itself employed.

## Design Implications

### Context
#### Requirements
- Access to regional employers willing to participate in a convening
#### Constraints
- Findings reflect the employers of one region (western Pennsylvania) as described in the publication

### Target Learners
- Students and new hires preparing for employment

### Target Learning Goals
- Aligning skill development with employer-identified soft skills
