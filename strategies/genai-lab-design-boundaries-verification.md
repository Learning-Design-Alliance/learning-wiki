# Design GenAI support in assessed laboratory courses with explicit boundaries, verification routines and assessment requirements that preserve epistemic responsibility

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article's educational implication is that GenAI use in advanced laboratories "requires explicit design boundaries, guidance on legitimate and prohibited practices, verification routines, and assessment requirements that preserve students' epistemic responsibility". Concretely, tutors should be role-constrained to formative functions, students should check AI-generated support against course materials, instructor guidance, tools and observational data, and assessment should require students to make conceptual, methodological and epistemic warrants explicit in downstream artefacts.

## Design Implications

### Context
#### Requirements
- Explicit guidance on legitimate and prohibited practices
- Verification routines against external sources and observational data
- Assessment requirements that preserve students' epistemic responsibility
#### Constraints
- Report scaffolding is an assessment-sensitive function: it can support learning if students inspect and revise their own reasoning, or weaken authorship if they treat generated structure as a substitute for epistemic work

### Target Learners
- Advanced higher-education laboratory students
- Instructors designing AI-supported laboratory courses

### Target Learning Goals
- Maintaining authorship and assessment integrity
- Making epistemic warrants visible in laboratory artefacts
