# Recommendations for STEM research and implementation practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article closes with recommendations for both researchers and practitioners: researchers should share study data, state which effect size is calculated, and include only large-sample studies in meta-analyses; educators can start STEM practices from preschool by providing a suitable learning atmosphere, use STEM in class programs, revise based on the program, and add STEM classes to bachelor's programs. The article states "it is advised that the sample in experimental studies be no less than 20 people."
