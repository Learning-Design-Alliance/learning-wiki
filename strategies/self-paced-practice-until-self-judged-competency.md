# Allow learners self-paced, unlimited practice repetitions until they judge themselves competent

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Rather than prescribing a fixed number of practice repetitions, the module let learners repeat the video-and-model simulation as often as they wished. The authors note that "learners were allowed as many practice opportunities with the instructional media and the simulator model as they thought necessary", and all learners reached competency without a set number of practice events, which they suggest accommodates different learning styles.

## Design Implications

### Context
#### Requirements
- A simulator model and instructional media available for unlimited repetition
- Learners able to judge when they have achieved competency
#### Constraints
- The authors note that for simpler tasks, overtraining may adversely affect performance, citing prior work

### Target Learners
- novice surgical trainees
- allied health professionals learning technical procedures

### Target Learning Goals
- acquisition and retention of technical procedural skills
