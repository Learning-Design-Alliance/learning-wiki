# Decodable Text Reading

## Description
Decodable texts are connected texts in which the majority of words can be sounded out using grapheme–phoneme correspondences that have already been explicitly taught, plus a small controlled set of irregular high-frequency words taught as exceptions. Learners read these texts aloud, applying their phonics knowledge to every word rather than relying on pictures, context, or memorized whole-word shapes. The strategy is typically sequenced so text difficulty tracks the scope-and-sequence of a phonics program.

## Design Implications

Decodable text enforces the alignment between what is taught and what is practiced: every word read is an opportunity to consolidate grapheme–phoneme mappings, building the automatic word recognition that frees attention for comprehension [Automatic word recognition frees cognitive resources for comprehension.](../claims/automatic-word-recognition-frees-resources-for-comprehension.md) [+S]. This follows from [Cognitive Load Management](../principles/cognitive-load-management.md): untaught patterns force beginning readers into effortful guessing that consumes working memory and can entrench ineffective word-reading habits. The texts are a practice vehicle, not a comprehension curriculum — meaning-making discussion should still accompany reading.

### Context
#### Requirements
- An explicit, systematic phonics scope and sequence; decodable text is meaningless without it ([Explicit Instruction](../patterns/direct-instruction.md))
- Texts whose word-level content is genuinely controlled to taught patterns — verified word-by-word, not by publisher label
- Repeated-reading opportunities so decoding becomes automatic rather than merely accurate ([Automaticity](../elements/automaticity.md))
- A small set of pre-taught irregular "heart words" so sentences remain natural

#### Constraints
- Texts containing untaught patterns push readers back to guessing from pictures or first letters, undermining the phonics habit being built [-S]
- Overly stilted, unnatural language ("Dan the tan man ran") reduces engagement and provides poor models of syntax and vocabulary [~M]
- Once readers are decoding most words automatically, continued reliance on strictly decodable text limits vocabulary, syntax, and knowledge building and should be faded [~M]
- Decodable text alone, without explicit phonics instruction, does not produce the effect — the text is practice for teaching, not a substitute for it [-S]

#### Implementation Variability
- **Fully decodable** (nearly every word taught) for earliest readers and newly taught patterns
- **Partially decodable** with a controlled set of irregular words, as readers grow
- **Cumulative review texts** that recycle earlier patterns alongside the new one
- **Writeable/constructible variants** where learners build or dictate sentences from taught patterns

### Target Learners
- Beginning readers (roughly K–2) in the earliest stages of grapheme–phoneme learning [+S]
- Struggling readers of any age who need targeted practice on specific patterns; older struggling readers need age-respectful content
- Less appropriate for fluent readers, for whom the constraint adds no decoding value and restricts text quality [~M]

### Target Learning Goals
- Phonics application: transferring taught sound–spelling correspondences from isolation to connected text
- Automaticity in word recognition [Automatic word recognition frees cognitive resources for comprehension.](../claims/automatic-word-recognition-frees-resources-for-comprehension.md) [+S]
- Foundational accuracy before fluency and comprehension work

### Instructions
1. Teach the target grapheme–phoneme correspondences explicitly before reading ([Explicit Instruction](../patterns/direct-instruction.md)).
2. Pre-teach the handful of irregular words in the text.
3. Have learners read the decodable text aloud, prompting them to sound out rather than guess; correct errors immediately by pointing to the letters.
4. Re-read the same text across days to build automaticity ([Automaticity](../elements/automaticity.md)).
5. Discuss the content for meaning and vocabulary so decoding practice stays connected to comprehension.
6. As patterns accumulate, fade the constraint — move learners toward authentic and trade books once decoding is largely automatic.
