Place input flooding before grammar presentation when the goal is accurate production¶

Strategy · All strategies
Evidence · 4 claims (1 for, 3 mixed) · 1 study (1 causal), q3 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

Because the pre-presentation flooding group produced significantly fewer dictogloss errors than the post-presentation group, the authors conclude that "the learners who are exposed to pre-presentation input flooding produced more accurate output than the ones in post-presentation group". Teachers aiming at production accuracy should flood reading input before explicit presentation of the target form.

Design Implications¶

Context¶

Requirements¶

  • Contextualized reading passages rich in the target form, delivered prior to explicit grammar presentation

Constraints¶

  • On recognition measures both timings performed similarly; the production advantage appeared only on the dictogloss task

Target Learners¶

  • young elementary-level EFL learners

Target Learning Goals¶

  • accurate production of the simple past tense

Claims¶

  • Pre-presentation input flooding reduces grammatical errors in dictogloss production more than post-presentation flooding [+W]
  • Pre- and post-presentation input flooding groups perform similarly on the recognition post-test [~W]
  • Post-presentation input flooding via reading significantly improves simple past tense recognition scores relative to traditional instruction [~W]
  • Pre-presentation input flooding via reading significantly improves young EFL learners' simple past tense recognition scores relative to traditional instruction [~W]
