# Use multiple, diverse data sources selected to offer distinct yet complementary information

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
This strategy recommends combining several intentionally chosen data sources rather than relying on a single measure, so that together they give a well-rounded picture of learning. The brief notes that "using multiple, diverse sources of data can provide a more robust picture of learning" and that sources should be "carefully selected to ensure that they offer distinct yet complementary information" to avoid knowledge gaps. It explicitly distinguishes this from examining an overwhelming deluge of data.

## Design Implications

### Context
#### Requirements
- Data sources must be analyzed collectively and chosen to be distinct yet complementary rather than redundant
#### Constraints
- Does not require examining a deluge of data that can be hard to untangle and understand

### Target Learners
- all students whose learning is being understood through data

### Target Learning Goals
- building a robust, well-rounded picture of student learning
