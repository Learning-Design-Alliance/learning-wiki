# Genre Study

## Description
Genre study is an approach to teaching literature and composition in which learners read multiple texts within a specific genre, discuss and chart the elements that define it (structure, voice, conventions, audience expectations), and typically write their own pieces in that style. By treating genres as socially evolved patterns rather than arbitrary categories, the approach builds both comprehension — readers can anticipate a text's moves — and writing transfer, since knowledge of a genre's conventions directly supports producing text in it.

## Design Implications

Genre study works because genre knowledge functions as a schema: knowing a text type's structure frees working memory for meaning-making and lets readers predict, question, and evaluate as they read [~M]. The multiple-text structure is essential — comparing several examples within a genre (and across genres) supports flexible, transferable understanding rather than single-text memorization [Multiple cases or representations support flexible transfer.](../claims/cognitive-flexibility-theory-multiple-cases.md) [+M]. Pairing reading with genre-conformant writing is what converts recognition into production ability; writing instruction with structured text models reliably improves writing quality [Writing strategy instruction with model texts improves writing quality.](../claims/strategy-instruction-improves-writing-quality.md) [+S]. Analysis prompts should push beyond labeling features toward explaining *why* the genre uses them — asking "why does a mystery withhold information?" produces deeper processing than listing mystery elements [Elaborative interrogation improves learning.](../claims/elaborative-interrogation-improves-learning.md) [+M].

### Context
#### Requirements
- A text set of 4–8 authentic examples of the target genre, varied in difficulty and perspective
- An analysis frame or chart (structure, language features, audience, purpose) that learners complete across texts ([Advance Organizers](../elements/advance-organizers.md))
- Discussion structures for comparing texts and building a class-generated definition of the genre ([Class Discussion](../elements/class-discussion.md))
- A culminating writing task in the genre, with the analyzed features as success criteria ([Application](../elements/application.md))

#### Constraints
- Rigid genre taxonomies mislead: many authentic texts blend or subvert conventions, and over-categorical instruction can produce brittle, checklist-based understanding [Multiple cases or representations support flexible transfer.](../claims/cognitive-flexibility-theory-multiple-cases.md) [~M]
- Ineffective if learners lack decoding or foundational comprehension skill — genre analysis presupposes fluent reading of the texts in the set
- Single-example "genre study" (one mentor text) does not support induction of conventions; learners need contrast across multiple texts
- Time-intensive: gathering varied, culturally responsive text sets and cycling through read–analyze–write takes several weeks per genre

#### Implementation Variability
- **Reading-focused**: learners categorize texts and defend classifications with textual evidence (works well for younger readers)
- **Writing-focused**: mentor texts serve as models for a genre writing unit (common in writing workshop models)
- **Disciplinary literacy**: applied to non-literary genres — lab reports, editorials, primary-source documents — where each discipline's text structures carry its epistemology
- **Multimodal**: film genres, podcasts, game narratives; same analysis frame applied to non-print texts

### Target Learners
- Students in grades 3–12; adaptable by adjusting text difficulty and analysis depth
- Developing readers who benefit from structural predictability as a comprehension scaffold [~M]
- Adolescent learners moving into discipline-specific texts, where genre conventions differ sharply from narrative reading [Disciplinary literacy instruction improves content-area comprehension.](../claims/disciplinary-literacy-instruction-improves-comprehension.md) [+M]
- English learners, who gain explicit access to text conventions that native-speaker immersion leaves implicit

### Target Learning Goals
- Categorization and analysis: identifying defining features of text types and justifying classifications with evidence
- Comprehension: using genre expectations to predict, monitor, and interpret
- Writing transfer: producing texts that meet genre conventions for an authentic audience ([Authentic Audiences & Purposes](../principles/authentic-audiences-purposes.md))
- Critical literacy: recognizing how genres shape — and are shaped by — audience expectations and power

### Instructions
1. **Immerse**: distribute a text set of the target genre via [Assigned Readings](../elements/assigned-readings.md); learners read widely and keep evidence notes using [Annotating](../principles/annotating.md)
2. **Analyze**: in small groups, learners chart recurring features (structure, language, point of view, audience) using an [Advance Organizers](../elements/advance-organizers.md) frame; groups compare charts in [Class Discussion](../elements/class-discussion.md) to build a class definition of the genre
3. **Contrast**: introduce a boundary case or near-genre text and ask learners to defend or revise their classification — productive disagreement sharpens the category boundaries [~M]
4. **Compose**: learners draft their own piece in the genre, using the class-generated feature chart as success criteria ([Application](../elements/application.md))
5. **Evaluate**: peer review against the genre criteria, followed by revision; teacher [Coaching](../elements/coaching.md) targets genre-specific moves rather than surface errors

## Examples
- **Reading & Writing Project genre units** ([Units of Study](https://www.unitsofstudy.com), Heinemann) — elementary writing units built on mentor text immersion, feature charting, and genre-conformant composition.
- **ReadWorks** ([readworks.org](https://www.readworks.org)) — organizes passages by genre so teachers can assemble text sets for comparison.
- **AP English Literature genre units** — students read multiple novels within a genre (e.g., Gothic) and write analytical essays on how conventions shape meaning.
- **Classroom example**: a grade-5 class reads six fractured fairy tales, charts how each subverts traditional elements, then writes original fractured tales evaluated against the class chart.
