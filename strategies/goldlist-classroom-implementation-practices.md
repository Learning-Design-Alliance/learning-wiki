# Classroom implementation practices for the GoldList Notebook Method

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article distills teacher takeaways from its classroom observations: keep notebooks in the classroom where feasible to prevent students forgetting them, check notebooks regularly, run distillations as a class warm-up to retrieve vocabulary and refocus attention from smartphones, provide a mentored worked example of each step, and use an A4 notebook so distillation 3 fits under the headlist with room for example sentences, drawings, or L2 synonyms.

## Design Implications

### Context
#### Requirements
- Regular checking of notebooks to ensure activities are done properly
- A4-size notebook to leave space under the headlist for the third distillation
#### Constraints
- Keeping notebooks in class "may not be feasible for all settings such as the university setting this study was set in"

### Target Learners
- University and pre-university L2 English learners

### Target Learning Goals
- Consistent spaced retrieval review of target L2 vocabulary
