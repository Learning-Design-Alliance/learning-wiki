# Supplement dichotomous test analysis with four-level MCMR scoring and item response curves when validating inventories with select-all-that-apply items

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The authors recommend supplementing classical test theory with analyses that preserve the complexity of multiple-choice/multiple-response data: a four-level scoring scale and Item Response Curves. They report that these methods "provide more information than traditional CTT analyses" and reveal patterns in student responses beyond dichotomous scoring, which informed decisions about which items to keep, eliminate, or modify.

## Design Implications

### Context
#### Requirements
- Items formatted as multiple-choice/multiple-response with instructions to select all statements that must be true; response-level data rather than only dichotomous scores
#### Constraints
- Typical CTT analyses assume single-response items, so dichotomous results for MCMR items are not entirely representative of student responses

### Target Learners
- students in calculus-based introductory physics courses

### Target Learning Goals
- valid measurement of quantitative reasoning
