# Caution recommendations for teachers, textbook writers, test designers, and lexicographers regarding semantic prosody

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
From the study's findings the article issues practical recommendations: teachers should be cautious when introducing vocabulary by giving synonyms, because near-synonyms differ in prosodic behavior; in same-background-language classes teachers should be cautious about using learners' background language to introduce prosodic behavior. Textbook writers should use authentic materials so words appear in appropriate prosodic contexts, test designers should use words with the same SP to avoid negative backwash, and lexicographers should consider prosodic behavior when selecting translation equivalents.

## Design Implications

### Context
#### Requirements
- Awareness of the prosodic behavior of vocabulary among material developers and test writers
#### Constraints
- English-Persian dictionaries have not paid serious attention to the prosodic feature of verbs in choosing equivalents

### Target Learners
- EFL learners in classrooms with a shared background language

### Target Learning Goals
- Avoiding inappropriate vocabulary choice and undesired connotations
