# Build online modules from existing lecture slides with narration, animations, and embedded formative review quizzes

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
A concrete recipe for converting existing lectures into online modules: use previous PowerPoint slides enhanced with animations and highlights, add narration from edited excerpts of prior lecture recordings, include interactive questions and review quizzes with immediate feedback, and publish as SCORM packages in the LMS. The article reports that "Typically, each 50-min lecture was converted into a set of 3 modules" and that quizzes with feedback were the most valued feature for deeper understanding.

## Design Implications

### Context
#### Requirements
- Access to previous lecture recordings and slides; software such as iSpring Pro and Audacity; estimated ~20 hours to develop and test each module
#### Constraints
- Technical issues can cause major teaching disruptions; students need reliable internet connections for streaming

### Target Learners
- undergraduate students in content-heavy university courses

### Target Learning Goals
- self-paced content learning
- formative self-assessment with feedback

### Affordances
- [Blended Learning Large Group Model](../designs/blended-learning-large-group-model.md)
