# Optimize remote feedback quality by reducing group size and improving audio/video equipment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 associational, 1 qualitative, 1 design), `q2`–`q3` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
To address participants' criticism of supervision and feedback quality in telesimulation, the authors recommend reducing the number of participants per session and improving audio/video quality. They state that "Reducing the number of participants and optimizing the audio/video quality, e.g., by using headphones and high-definition cameras, could help conquering this limitation," noting feedback is essential for the success of any simulation-based training.

## Design Implications

### Context
#### Requirements
- Headphones and high-definition cameras to improve audio/video quality
- Smaller participant groups per session
#### Constraints
- The article notes this addresses a limitation specific to remote feedback delivery; cited prior work suggests performance assessments generally do not differ between local and remote facilitators

### Target Learners
- health professions learners in remote simulation training

### Target Learning Goals
- psychomotor and procedural skills practiced under remote instructor feedback
