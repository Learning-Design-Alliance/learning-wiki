# Consider both in-person and virtual tutoring options when selecting a math tutoring program

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
This recommendation advises school districts exploring math tutoring programs to weigh both in-person and virtual delivery formats rather than restricting consideration to one modality. The brief states districts should "Consider in-person and virtual tutoring options—both can be effective," grounding this in the Middle Years Math evaluations, in which program models with varying key features showed promise. It functions as an initial screening guidance when building a portfolio of candidate tutoring programs.
