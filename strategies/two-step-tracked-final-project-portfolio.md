# Use a two-step open-ended final project — a common data-cleaning and modeling goal followed by student-chosen group tracks — and encourage posting portfolio items on GitHub.

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In undergraduate settings the author uses a final open-ended project resembling a real-world application, which helps students create a portfolio item for resumes and job interviews. "Step 1 sets a common goal for all students", covering data exploration, cleaning, and model optimization; "In Step 2, I propose possible tracks that can be worked on by small group of students", such as deploying a new algorithm, feature engineering, or analyzing dependence on signal-to-noise ratio. Students are encouraged to use Git and GitHub.

## Design Implications

### Context
#### Requirements
- Tracks must be proposed by the instructor for student groups to choose; graduate students instead devise their own project and data with a project plan and final report.
#### Constraints
- Applied in grade-bearing undergraduate courses; graduate-level classes use a different arrangement with student-proposed projects.

### Target Learners
- Undergraduate STEM students; graduate physics and astronomy students

### Target Learning Goals
- Comfort with open-ended research questions and portfolio development
