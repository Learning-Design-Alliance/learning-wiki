# Strategies to Remember Name Pronunciation

## Description
Use time-honored tricks to remember name pronunciation, like word association, writing down each syllable in English phonetics, and rhyming, as well as new-fangled ones like name pronunciation websites.

## Design Implications

### Context
#### Requirements
- Instructor should take the time to use the above techniques to help them memorize learners' names.
#### Constraints
- This can be time consuming and may not be possible in a large class.

### Affordances
- If the instructor makes an effort to learn and properly pronounce the learners' names, this demonstrates respect and care.

### Personalization
- Use word association to match learners' names with other well-known words. Use websites to find out how to pronounce names from other cultures.
