# Apply Graphical Jogthrough to evaluate the interface design of educational software

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (1 causal, 1 design), `q1`–`q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The strategy is to use the Graphical Jogthrough method as an expert-based evaluation of an educational program’s interface design, gathering evaluators’ ratings during interaction with the software. The article demonstrates this on the Network Simulator and examines “the possible benefits and limitations of the Graphical Jogthrough method when applied in the case of educational software interface design.”
