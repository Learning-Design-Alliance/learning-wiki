# Use built-in LMS wiki tools to create gamified review activities that avoid external game-development costs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (6 for, 1 mixed) · 2 studies (1 causal, 1 theoretical), `q1`–`q3` · 0 of 2 report an effect size · 7 claims rest on one study

## Description
Design gamified activities using "readily available collaborative tools (e.g., wikis) from a typical learning management system (LMS)" rather than custom educational games. The wiki's single-user editing lock creates a natural first-come, first-choice competition mechanic. This approach overcomes "high game-development costs and the challenge of aligning learning objectives perfectly with existing educational games."

## Design Implications

### Context
#### Requirements
- An LMS with wiki capability, which most LMS companies provide to higher education institutions
#### Constraints
- Only one student can edit the wiki table at a time, which some students disliked

### Target Learners
- Online graduate students

### Target Learning Goals
- Review and consolidate course concepts through competitive game-based activities
