# Compare the experimental result with the known theoretical value on a linear axis using confidence intervals

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The author recommends a discussion routine built around interval comparison: mark experimental results on a linear axis with cases where the known value falls inside and outside the confidence interval, since "The procedure of comparing the experimental πꓱ and theoretical results π has a great educational value." Students then play with "confidence intervals, probabilities, uncertainties, the number of data values" and discuss the relations between them.
