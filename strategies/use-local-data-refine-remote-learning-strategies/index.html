Use local data to identify which remote learning strategies work best for your own students¶

Strategy · All strategies Evidence · no claims cited

Description¶

The publication recommends that schools and teachers use their own data to refine remote learning strategies, asking which approaches "work best in your schools and for your students." The e2i Coach is offered as the tool for carrying out this locally grounded evaluation of remote learning practices.

Design Implications¶

Context¶

Requirements¶

  • Access to data about remote learning practices and student outcomes within the school or district

Constraints¶

  • Positioned for the remote learning context where established evidence is scant

Target Learners¶

  • K-12 students in schools using remote learning

Target Learning Goals¶

  • Selecting and refining remote learning strategies based on local evidence

  • E2I Coach Platform
