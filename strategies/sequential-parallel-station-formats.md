# Run the escape room in sequential or parallel team formats depending on group size

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A concrete session-management recipe: depending on the event type and number of participants, the activity runs either sequentially, with all participants proceeding through each station one after the other, or in parallel, with the group divided into three smaller teams each tackling a different station simultaneously. Both formats occur in a single physical room arranged to support the modular station layout, with a roughly three-minute recorded introductory narrative setting the scenario.

## Design Implications

### Context
#### Requirements
- A single physical room that can be arranged to support the modular layout of the stations
#### Constraints
- Format choice depends on the type of event and the number of participants

### Target Learners
- general public
- school students

### Target Learning Goals
- collaborative problem-solving
- learning about cosmic messengers
