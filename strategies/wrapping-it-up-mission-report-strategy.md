# Close each chapter with a data-based Wrapping It Up activity and a graded Mission Report for assessment and feedback

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
At the end of each chapter, the curriculum closes with "a longer summary 'Wrapping it Up' activity, and an exercise called a 'Mission Report.'" The Wrapping It Up involves students working with actual datasets and integrating the chapter's important topics. The Mission Report is graded for accuracy and serves as an easy way for instructors to assess mastery of the chapter's most important learning objectives, while also giving students an opportunity to provide feedback about the learning efficacy of the chapter materials.
