# Pre-distribute all lecture materials with a Book of Diagrams of tactile diagrams before class sessions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The framework provides all lecture content, including code examples, diagrams, and visual demonstrations, to all students before class sessions. Advance distribution lets students familiarize themselves with complex material using preferred assistive technologies and eliminates exclusion from impromptu visual content. A "Book of Diagrams: a collection of tactile diagrams corresponding to standard visual content" functions as a reference appendix instructors can point to when teaching visual concepts, producible with tactile printers or thread and paper.

## Design Implications

### Context
#### Requirements
- Lecture materials prepared in LaTeX so mathematical expressions, code formatting, and technical notation remain accessible in alternative formats
- Alt-text descriptions for all images, diagrams, and code snippets
#### Constraints
- Requires systematic advance material preparation, transforming ad-hoc visual demonstrations into structured accessible experiences

### Target Learners
- university students with visual impairments in introductory computer science

### Target Learning Goals
- equitable access to lecture content including visual demonstrations and diagrams
