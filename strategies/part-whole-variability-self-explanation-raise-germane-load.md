# Manage intrinsic load with a part-whole approach, task variability, and self-explanation to raise germane load

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article lists ways to manage intrinsic load and increase germane load: a part-whole approach that initially simplifies tasks by reducing elements and interactions and then adds more; increasing the variability of learning tasks; and asking learners to self-explain how they arrived at a problem solution. In both latter cases the nature of the task is changed so that intrinsic load and required WM resources increase appropriately.

## Design Implications

### Context
#### Requirements
- As more elements are added, germane cognitive load can increase without exceeding working memory capacity
#### Constraints
- A very heavy intrinsic cognitive load may exceed WM capacity and prevent processing of all elements

### Target Learners
- learners of complex cognitive tasks

### Target Learning Goals
- schema acquisition
- transfer of problem-solving skill
