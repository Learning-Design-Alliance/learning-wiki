# Four-action strategy for rapidly adapting a virtual patient collection to a changed clinical context

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Faced with a rapidly changing pandemic context and a short timeframe, the authors chose not to adapt all 75 VPs but pursued four actions: "Updating selected VPs with similar key-symptoms" without changing final diagnoses; creating and translating two new VPs with positive COVID-19 tests; providing an introduction explaining the non-pandemic design context with links to COVID-19 information sources; and expanding the collection by translating a subset into Spanish and Portuguese with local adaptations.

## Design Implications

### Context
#### Requirements
- A curated VP collection with cases grouped by key symptoms so that selected cases can be updated without changing final diagnoses
#### Constraints
- Applied when data on the new context is "often inaccurate and changing regularly" and the timeframe for implementing changes is short

### Target Learners
- Medical students
- Health profession students

### Target Learning Goals
- Clinical reasoning adapted to a changed epidemiological and clinical context
