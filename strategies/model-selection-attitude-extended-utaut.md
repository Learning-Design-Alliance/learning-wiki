# Choose among attitude-extended UTAUT models by outcome: Model 1 for BI-only studies, Model 2 for UB-only studies, Model 3 for both outcomes

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 quant-synthesis, 1 associational), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
Based on the comparative variance explained across the three fitted models, the article recommends: "For future UTAUT models extended with attitude as a construct that examines a single outcome, such as BI, it is recommended that Model 1 be adopted." Model 2 is recommended when the outcome is use behavior, as it yielded the highest explained variance for UB (51.5%); Model 3, which includes all possible direct relationships, is recommended when both BI and UB are examined.

## Design Implications

### Context
#### Requirements
- Researchers must have correlation matrices from primary studies reporting UTAUT constructs and attitude to fit the models via OSMASEM
#### Constraints
- All three models underperformed the original UTAUT model in explained variance, so none recovers the original model's explanatory power

### Target Learners
- researchers and staff implementing technologies in higher educational institutions

### Target Learning Goals
- modelling and predicting technology acceptance and usage behavior in education
