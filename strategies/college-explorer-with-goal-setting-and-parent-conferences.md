# Use score-linked college exploration alongside goal setting and parent conferences to build post-secondary plans

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends embedding the College Explorer in a wraparound planning routine: "Together with goal setting and parent conferences, College Explorer can help students develop a plan, consider new possibilities, and put post-secondary dreams within reach." The strategy pairs a data tool linking assessment scores to college benchmarks with structured student goal setting and family involvement so that exploration translates into concrete higher-education pathways.
