# Test VR learning applications on a high number of novices to VR during development

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article's take-home message is that testing on persons not familiar with VR is fundamental when building applications for self-practice among inexperienced users. The authors used 120 testers, which they note is "far beyond what is usually the case", involving students from various educations and professionals from healthcare and outside to assure both clinical relevance and software usability.
