# Planned future evaluation and review models for astroEDU: classroom randomized evaluations, open peer review, and SEO

## Description
The article's future-work section lays out concrete next steps for strengthening the platform: classroom-based randomized evaluations, post-publication evaluation through user comments, testing open peer review against the current anonymous model, and search engine optimization to improve discoverability. The authors write that "For classroom evaluation some randomized evaluations will be run in schools in Wales (UK) and the Netherlands." They also state that "Using techniques like Search Engine Optimization we expect to increase the number of users for the astroEDU activities."
