# Use first-course evaluation feedback to improve the structure of the next course iteration

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors state that "the primary goal of the evaluation procedures of this first attempt was to use the feedback to improve the structure of the second ABCS3", and that they "will improve the evaluation tools and procedures used for the second ABCS3 and then compare the new results to those of the first ABCS3". Evaluation is thus framed not as a one-off judgement but as an iterative design input: scenario-level satisfaction data (e.g. the low-scoring catheterization station) feeds directly into revisions of the next course offering.

## Design Implications

### Context
#### Requirements
- A structured multi-instrument evaluation (DREEM, internal feedback inventory, pre/post knowledge test) administered at the end of the first offering
- Willingness to revise specific components identified as weak by the feedback
#### Constraints
- The authors note that evaluations of this type rarely result in the alteration of educational structures, so the feedback was directed at their own next course iteration rather than institutional change

### Target Learners
- undergraduate medical students attending simulation courses

### Target Learning Goals
- continuous improvement of simulation course structure and evaluation methods
