# Start advanced courses with a Win-day-one approach that gives learners a complete answer first, then breaks down the code

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The upper-level Computational Physics course uses a Win-day-one approach to engage students immediately with high-level computational work. The article explains: "A “Win-day-one” exercise ﬁrst provides learners with an answer, then methodically breaks down the code to explain each step." Details are initially abstracted away in functions and objects and are explained in subsequent iterations; students extend snippets of user-developed code they might encounter in actual research.

## Design Implications

### Context
#### Requirements
- Students must be given snippets of user-developed code from actual research to extend, mirroring the practice of receiving and extending code from colleagues
#### Constraints
- The approach assumes students already have basic programming experience in Python and college-level math and physics beyond the first year

### Target Learners
- upper undergraduate and graduate physics and mathematics students

### Target Learning Goals
- develop sophisticated computational programs
- engage with research-level computational problems
