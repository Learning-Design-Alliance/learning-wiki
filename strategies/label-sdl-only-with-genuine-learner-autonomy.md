# Label interventions as SDL only when learners have genuine autonomy in resource selection and self-assessment

> **Strategy** · [All strategies](index.md)

## Description
Based on their synthesis, the authors recommend that "interventions should be labeled as SDL only when learners have genuine autonomy in both resource selection and self-assessment." This strategy addresses the implementation gap they identified, where most SDL-labeled interventions lacked these core components of Knowles' definition. The recommendation aims to ensure that future research and practice use the SDL label in a way that reflects authentic learner self-direction rather than partial implementation.
