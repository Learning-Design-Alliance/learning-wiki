# Use interactive vector objects and animated moving-frame scenarios to reify abstract physics concepts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (4 for, 1 mixed) · 4 studies (2 design, 1 causal, 1 review), `q1`–`q2` · 1 of 4 report an effect size · 4 claims rest on one study

## Description
A concrete implementation recipe from the article: let students create vectors in the workspace and drag their tips with the mouse to change magnitude and direction while observing scalar and vector components; animate a swimmer in a river with current so observers in different frames see different motions; and manipulate a net force vector in an iterative Euler-Cromer model to control a particle's motion in real time. These interactions were used to make abstract vector and reference-frame properties tangible.
