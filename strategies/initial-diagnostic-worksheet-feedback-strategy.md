# Open a MOOC with low-stakes diverse diagnostic worksheets whose results are fed back as strong and weak points

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends generating several diverse worksheets from a platform item bank so a learner can request k questions, attempt them, and "receive their ability features as feedback (strong and weak points), then ask for another worksheet", with previously administered items removed so the same learner does not repeat exercises. If course lessons are also mapped to knowledge components, the initial evaluation could drive lesson recommendations. The authors aim to apply this at the beginning of a MOOC and evaluate it on real students.

## Design Implications

### Context
#### Requirements
- A q-matrix naming knowledge components so ability features can be interpreted
- An item bank with calibrated question feature vectors
#### Constraints
- Evaluation on real students is stated as future work; current evidence comes from simulated cold-start cross-validation

### Target Learners
- MOOC newcomers

### Target Learning Goals
- formative self-knowledge of strong and weak knowledge components
- routing to needed lessons
