# Use improved communication strategies to drive family involvement and partnerships with schools

> **Strategy** · [All strategies](index.md)

## Description
The report addresses how schools can increase family involvement through better communication. Its description states it identifies "barriers to engagement and how improved communication strategies can drive more involvement and partnerships with families." This positions communication improvement as an implementable lever schools can use to move families from passive recipients to active partners in student learning, particularly in the post-COVID recovery context the report addresses.
