# Planned enhancements: patient-selected starting points, rewind/fast-forward, BUK templates, and learned VARK preferences

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The authors list planned features to address the framework's stated limitations: allowing patients to select the starting point within a course, developing rewind and fast-forward functionality, updating the BUK model to a template so textual content can be customized as the course is assembled, learning a patient's preferred VARK presentation mode from interactions, and using Health Literacy Toolshed measures to establish comprehension level. They also plan a pilot study with actual patients testing knowledge retention and adherence over a longer period.

## Design Implications

### Context
#### Requirements
- Current limitations to be addressed include that course structure is fixed and linear, comprehension level is assumed known in advance, and BUKs must be developed in advance for different comprehension levels
#### Constraints
- Only a Content BUK and the explanation part of a Q&A BUK are currently associated with multimodal presentation

### Target Learners
- patients using the mobile application at home over extended periods

### Target Learning Goals
- knowledge retention about treatment and adherence to prescribed therapy
