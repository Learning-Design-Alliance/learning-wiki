# Use data on students' college application and enrollment choices to support college-going decisions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The brief presents data analysis as a tool for supporting students' college-going decisions, motivated by the recognition of "the importance of using data to support students' college-going decisions." It describes a partnership in which an education organization analyzed graduates' college application and enrollment choices to inform practice. The strategy is to examine postsecondary application and enrollment patterns against students' high school academic achievement.
