# Calming Visual Input

## Description
Managing visual input involves altering the visual environment to reduce overstimulation and promote relaxation. Strategies include dimming lights, limiting visual distractions by creating a clear, clutter-free workspace, using visual dividers or study carrels, providing repetitive visual input like fish tanks or sensory bottles, and using a visual picture schedule. Decreasing visual stimulation can help children who are easily overwhelmed.

## Design Implications

### Context
#### Requirements
- Dimmer switches, storage containers, visual dividers or study carrels, fish tank, sensory bottles, visual picture schedule.
#### Constraints
- Some children may have specific visual needs that must be accommodated. Visual schedules must be clear and easy to understand.
