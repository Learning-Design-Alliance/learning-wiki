# Combine formative assessment information with MAP Growth scores for instructional decisions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Because formative assessment is not designed to measure growth over time, the article recommends that teachers "combine the formative assessment information with MAP Growth scores to make data-informed decisions about instruction and student growth." NWEA professional learning in responsive teaching and learning supports this, teaching teachers to create and use high-quality formative assessments for day-to-day instruction while interim scores supply the growth picture.

## Design Implications

### Context
#### Requirements
- Teachers need professional learning in creating and using high-quality formative assessments
- Aggregation level of scores should match the level of decision-making
#### Constraints
- MAP Growth itself is less useful for daily tailoring of instruction; formative assessment is not designed to measure growth over time

### Target Learners
- K-12 teachers

### Target Learning Goals
- Differentiated instruction
- instructional planning for a term
- data-informed decisions about student growth
