# Target instructional resources and support at the problem types and topics students found most difficult

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Based on the difficulty analysis, the article recommends designing new teaching strategies and resources for the challenging problem types and topics. It suggests that for 'Exact match (ignore case)' problems, "additional practice or guided examples can be provided to improve student understanding of required skills for this problem type", and for difficult topics such as Algebra II, offering creative examples, practice, interactive activities, and clear explanations with step-by-step instructions.

## Design Implications

### Context
#### Requirements
- Knowledge of which problem types, skills and subjects students find difficult, e.g. from average score analysis of clickstream data
#### Constraints
- Difficulty rankings are descriptive average scores from ASSISTments middle school math data with no inferential tests reported

### Target Learners
- middle school mathematics students

### Target Learning Goals
- mastering difficult math problem types and topics such as Algebra II, descriptive statistics and measurement skills

## Claims

- [Students scored lowest on 'Exact match (ignore case)', 'Check all that apply' and 'Ordering' problem types, indicating these types were more difficult.](../claims/check-all-that-apply-and-exact-match-problem-types-most-difficult.md) [+W]
- [Algebra II, Algebra I and Geometry were the most challenging assignment subjects, with Algebra II averaging 0.42.](../claims/algebra-ii-most-challenging-subject.md) [+W]
- [The most important feature for the ClickTree model was sequence folder path level 3, representing the subject of the assignment problem.](../claims/sequence-folder-path-level-3-most-important-feature.md) [+W]
