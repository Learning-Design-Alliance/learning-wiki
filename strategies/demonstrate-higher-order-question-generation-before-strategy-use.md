# Train teachers to demonstrate higher-order question generation before assigning the strategy

## Description
The article recommends that "Teachers should give more demonstrations regarding how to generate higher order questions before using the question-generation strategy." During instruction, teachers should act as facilitators helping participants individually. This preparation is presented as necessary for learners to benefit from generating their own exam-style questions from reading content.
