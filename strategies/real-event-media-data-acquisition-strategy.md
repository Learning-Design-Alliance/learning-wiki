# Use real-event media — videos, satellite maps and audio recordings — as data sources students acquire themselves in physics problems

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 review, 1 design, 1 theoretical), `q1`–`q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The article proposes that students search and analyze real data from a real event: "the analysis of images, videos, maps and audio recordings is suggested". Students measure fireball radii from video frames using Tracker, identify reference lengths and distances with Google Earth, and measure arrival-time intervals from audio tracks in software such as Audacity. This makes data acquisition part of the problem solution and integrates technologies as tools to learn physics.

## Design Implications

### Context
#### Requirements
- Internet availability and a suitable sound system in the classroom are stated as important for the wavefront problem; access to computers and internet is implied for the full analysis.
#### Constraints
- If students lack suitable software or computers, the teacher can share printed maps and audio tracks so students obtain data using a ruler.

### Target Learners
- higher education / university physics students

### Target Learning Goals
- data acquisition and analysis
- unit conversion
- constructing logarithmic graphs
- use of software useful for physics
