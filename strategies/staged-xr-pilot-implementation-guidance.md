# Stage XR pilot implementations for elementary STEM with small cohorts, co-design, and interpretable analytics

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
For institutions considering XR pilots in elementary STEM, the review prescribes a staged path: begin with small-scale deployments (1-2 classrooms, 4-6 week instructional units) aligned with existing STEM curricula, co-designing activities with classroom teachers. It advises implementing clear behavioral signal tracking from initial pilots to enable model validation, prioritizing interpretable analytics teachers can act upon, and maintaining transparent data governance with documented consent, storage, and usage policies. Evaluation should combine quantitative metrics with teacher interviews and classroom observations.

## Design Implications

### Context
#### Requirements
- Pilot studies with small cohorts (20-40 students across 2-3 classrooms) enable feasibility testing and preliminary effect size estimation before scaling to larger cluster-randomized trials
- Data pipelines must securely capture and store telemetry streams and preprocess behavioral logs for analysis
#### Constraints
- Hardware costs for HoloLens-class devices (typically $3000-3500 per unit) create barriers for under-resourced schools; rigorous randomized trials of XR in elementary STEM classrooms remain scarce

### Target Learners
- Elementary students ages 5-12 in pilot classrooms

### Target Learning Goals
- Embodied, spatially-grounded STEM learning with real-time adaptive support
