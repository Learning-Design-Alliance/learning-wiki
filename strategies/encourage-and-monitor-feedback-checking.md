# Instructors should actively encourage and monitor students' checking of auto-grader feedback

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (3 for, 1 mixed, 1 against) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article recommends that instructors treat feedback checking as a behavior to cultivate and watch. It states instructors "should consider actively encouraging students to check auto-grader feedback after each submission", especially students new to programming or auto-graded assignments, and should monitor who rarely checks feedback. It also recommends incorporating discussions about how to interpret feedback, debug from it, and connect it to learning objectives.

## Design Implications

### Context
#### Requirements
- A learning platform that logs or makes visible students' feedback-checking behavior so instructors can monitor it
#### Constraints
- The recommendation is grounded in an observational study where reading of feedback could not be verified, only logged navigation

### Target Learners
- adult community college students in introductory programming courses

### Target Learning Goals
- writing correct Python code
- effective use of automated feedback for revision
