# Design practice so that each stimulus is encountered many times within a session to make automatization observable quickly

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 3 studies (2 quant-synthesis, 1 theoretical), `q1`–`q3` · 1 of 3 report an effect size · 5 claims rest on one study

## Description
The article argues that apparent differences in the rate of automatization across studies may be artifacts of how data are plotted: instance theory "argues that means and standard deviations should be plotted as a function of the number of trials per stimulus because each trial potentially adds a new instance to memory." Tasks with more stimuli per session appear to automatize more slowly even when the per-stimulus learning rate is equal. Designers who want to observe automatization should keep the number of stimuli small and use easy-to-remember stimuli.

## Design Implications

### Context
#### Requirements
- A small set of stimuli so that each receives many trials per stimulus within practice; stimuli that are easy to remember
#### Constraints
- Automatization may never be complete, in that each additional instance has some effect even if it does not appear in primary performance data

### Target Learners
- novices in laboratory or instructional practice settings

### Target Learning Goals
- acquiring automatic (memory-based) task performance

### Affordances
- Instance Theory Automatization
