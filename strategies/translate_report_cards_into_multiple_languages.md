# Translate Report Cards Into Multiple Languages

## Description
Using communication apps to translate report cards into multiple languages (e.g., Spanish, Arabic, Vietnamese, and Mandarin Chinese) makes it easier for parents to understand their child's progress, particularly in districts with diverse populations of English language learners.

## Design Implications

### Context
#### Requirements
- Communication apps with translation features, translated report card templates
#### Constraints
- May be difficult to ensure accuracy of translations, requires ongoing effort to update translations
