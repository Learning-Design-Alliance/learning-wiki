# Replicate an intervention with the same teachers to isolate teacher experience, and embed fidelity measurement to identify critical program components

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article presents a replication design in which the Year 2 trial repeated Year 1 with the same teachers, now more experienced, holding other factors constant, and incorporated fidelity measures into multilevel analyses. The authors describe this as "a model for replicating effective intervention in the context of evaluating the relative contribution of its respective components", using fidelity data on features of the normative program model essential to its effect.

## Design Implications

### Context
#### Requirements
- Fidelity measures applied to both treatment and comparison conditions, as the article describes, so that achieved relative intervention strength can be examined
#### Constraints
- The authors note that an experimental manipulation of program elements would be necessary to address the relative contribution of components fully

### Target Learners
- middle school students in reading intervention efficacy trials

### Target Learning Goals
- reading comprehension intervention evaluation
- implementation fidelity assessment
