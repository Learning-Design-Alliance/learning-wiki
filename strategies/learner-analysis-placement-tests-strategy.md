# Instructors should conduct learner analysis using placement tests and surveys before designing blended MOOC instruction

## Description
The article recommends that in the planning phase, instructors first review learner profiles using placement tests and short surveys to identify students' English levels, learning preferences, and motivation. This practical guidance operationalizes the finding that learner analysis is a key driving factor in the ISM hierarchy.
