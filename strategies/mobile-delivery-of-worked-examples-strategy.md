# Deliver worked examples through mobile learning applications to support independent physics study

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends packaging worked examples as a mobile application so students can access structured example-problem sequences on widely available devices. It motivates this by noting the "huge percentage of mobile learning which spread out evenly across society" and that mobile learning makes learning access more affordable, personal, interactive and effective. The strategy was implemented as the WEIEC application with materials, worked example, evaluation and exam menus.

## Design Implications

### Context
#### Requirements
- A mobile application containing materials, worked examples, evaluation items with feedback gating, and independent exam questions
#### Constraints
- Validated only for high school direct current circuits material in an Indonesian setting

### Target Learners
- high school (class XII) physics students

### Target Learning Goals
- electric circuit interpretation ability
- independent learning of direct current circuits
