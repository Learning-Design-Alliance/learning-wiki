# Alternate pen-and-paper predictions with IBM Q runs so students test their own circuit calculations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
In the IBM Q sessions, students work examples by hand using pen and paper or tablets, then run the same circuits on the IBM Q site. The authors state this alternation "allows them to make predictions and then test to see that they get the expected results". Students start on the simulator and later try hardware, where they encounter errors that deviate from the error-free simulation.

## Design Implications

### Context
#### Requirements

### Target Learning Goals

- connecting formalism to real quantum devices
