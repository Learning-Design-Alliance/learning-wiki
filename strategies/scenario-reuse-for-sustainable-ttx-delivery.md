# Reuse and adapt existing scenarios to make repeated TTX delivery sustainable

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Because creating a TTX from scratch is time-consuming, the authors recommend reusing and adapting existing scenarios: once well-specified and implemented, redeploying for a new cohort requires only adjusting contextual details, refining content from previous runs, and assigning participants to a new instance. The open-source exercise library accelerates this by giving new designers a starting point.
