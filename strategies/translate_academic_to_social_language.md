# Translate Academic to Social Language

## Description
Model how to say something in a more academic way or how to paraphrase academic texts into more conversational language. Have teams reinterpret text using everyday language.

## Design Implications

### Context
#### Requirements
- Select academic texts.
#### Constraints
- May be challenging for learners with limited background knowledge.
