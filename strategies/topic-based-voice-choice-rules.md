# Teach voice choice through topic-based rules: active when the agent is the topic, passive when it is not

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 causal), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The instructional treatment taught two rules for voice selection. The first links sentence topic to voice: "If the topic is the agent, the active voice is used. If, alternatively, the agent is not the topic... the passive voice is used." The second teaches that the passive is used when the speaker does not want to mention the agent, for reasons such as the agent adding no new information, being unimportant, or being unknown. Both groups received these rules with the same materials.
