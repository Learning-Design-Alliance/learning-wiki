# Reduce entry barriers for underrepresented learners with cloud computing, payment, and mentorship

> **Strategy** · [All strategies](index.md)

## Description
The article identifies barriers facing underrepresented communities — income insecurity, computer and internet access, job networks — and recommends pursuing "cloud-based computing resources" so students can run costly analyses on inexpensive machines, avoiding required purchases, providing mentorship ideally from similar backgrounds, and adding financial and social support. DataTrail operationalizes this with Chromebooks, payment for participation, and internship placement via non-profit hiring partners.
