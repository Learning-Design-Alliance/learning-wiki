# Sequence instruction as Experience, Name, Speak, Apply, Repeat for each new abstract concept

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
This strategy implements the ENSAR components as a fixed instructional sequence for introducing an abstract concept. Learners first "interact with new concepts using all senses" with 3D materials or games; teachers then present the correct terminology, students practise names aloud in unison and pairs, articulate concepts in structured peer-to-peer sentences, apply the knowledge creatively in new sentences or scenarios, and repeat engagement with the material at home. The article states the components must be applied in order, starting with experiencing.
