# Use Single and Multiple Choice variable tests as a repeated-practice simulator and for individualized review tests

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Single Choice and Multiple Choice questions are described as optimal for checking knowledge of terminology and laws. "One of the options for such tests is using them as a simulator for repeated individual work to help students learn the material." Another option is forming an individual test for each student containing several tasks drawn from a single bank with various numeric parameters, which the author says is good for review exercises.

## Design Implications

### Context
#### Requirements
- A single bank of tasks with varying numeric parameters
- Easy creation of multiple test variants
#### Constraints
- Best suited to checking primary skills such as exact calculations, rounding, interest calculation, and use of multiple and sub-multiple units

### Target Learners
- first-year engineering students

### Target Learning Goals
- consolidating terminology and laws; reviewing material through individualized tasks
