# Attention Grabbing strategy for agent interventions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 causal), `q2` · 1 of 2 report an effect size · 3 claims rest on one study

## Description
The agent manages students' attention by not interrupting immediately when it detects an intervention opportunity. Instead, "It first displays a question mark icon above its avatar and, only after some time has passed will the agent's message appear," preparing learners for the intervention and turning their attention to the agent. The strategy was designed based on the work of Kumar and Rosé (2011) and is implemented in the MentorChat student module.
