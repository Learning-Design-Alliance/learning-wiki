# Implement situational simulation teaching before the OSCE to improve communication and cognitive skills in dentistry trainees

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The authors' forward-looking recommendation, based on their path analysis showing SSC participation directly affected OSCE performance: "we suggest implementing SSC teaching before the OSCE to improve communication and cognitive skills". The strategy places simulated patient encounters with feedback into the dental curriculum prior to the high-stakes OSCE, so students practice history taking, information giving, and interprofessional communication in a safe environment first.

## Design Implications

### Context
#### Requirements
- Structured scenarios with standardized patients, pre-briefing, simulation activity, and feedback/debriefing phases
- Voluntary or scheduled participation before the OSCE assessment period
#### Constraints
- SPs tend to be underutilized due to cost and resource constraints; the evidence base is a single-university cohort with possible volunteer selection bias

### Target Learners
- fifth-year undergraduate dental students preparing for the national qualification OSCE

### Target Learning Goals
- patient-centered communication
- cognitive skills such as clinical reasoning and decision-making
