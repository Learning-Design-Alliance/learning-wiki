# Ensure fluent handwriting before expecting executive resources to support higher-level composition

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Because handwriting fluency mediated EF effects on all narrative outcomes, the authors emphasize that "ﬂuent handwriting skills are essential for writing development, as non-automatized transcription skills are cognitively demanding and may constrain the use of EF". Instruction should build transcription automaticity so EF resources can serve text generation.

## Design Implications

### Context
#### Requirements
- Handwriting instruction achieving fluency/automaticity
#### Constraints
- Typing advantage may hold only for fluent typists; typing automaticity matters similarly

### Target Learners
- elementary school children learning to write

### Target Learning Goals
- narrative writing fluency, text length, complexity, and content
