# Use transferable planning tools to design virtual cohort learning activities

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A facilitator can use the toolkit when planning a variety of learning activities for a learning cohort. The strategy is to start activity planning from a set of guiding values and then apply ten transferable tools, including a scheduling survey, activity-planning template, activity flyer template, meeting design template, tools for planning a virtual retreat, and an evaluation form. The tools were developed to support creation of learning activities and a similar learning cohort.

## Design Implications

### Context
#### Requirements
- A cohort facilitator and a cohort of participants organized around a common theme
#### Constraints
- Tools were developed for virtual cohort settings in the CBSL pilot context

### Target Learners
- Learning cohort facilitators
- K-12 education grantees

### Target Learning Goals
- Planning and facilitating virtual cohort learning activities
