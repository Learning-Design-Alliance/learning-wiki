# Build a dynamic function-generation system so teachers can draw arbitrary 2D or 3D graphs without printing new markers

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
As future work, the authors intend to replace the current statically-compiled display of objects with a dynamic generation system that "allows the mathematics teacher to draw arbitrarily any three-dimensional or two-dimensional graph without the need to print a new Vumark every time". They want a dynamic platform letting users freely choose functions and immerse in the mathematical object, to study whether this develops a high level of understanding.

## Design Implications

### Context
#### Requirements
- a dynamic system for the generation of mathematical functions replacing compile-time static objects
#### Constraints
- The current system displays only objects statically compiled at compiling-time

### Target Learners
- high school mathematics teachers and their students

### Target Learning Goals
- deep understanding of the characteristics and properties of chosen mathematical functions
