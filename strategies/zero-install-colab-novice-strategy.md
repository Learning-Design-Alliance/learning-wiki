# Deliver beginner programming instruction through zero-install cloud notebooks to lower the entry barrier

> **Strategy** · [All strategies](index.md)

## Description
All hands-on instruction is delivered through an interactive web platform (Jupyter Book) and executed via Google Colab cloud notebooks, so any student can participate using only a web browser. The article reports that "Google Colab provided a free, cloud-based Python environment with all necessary libraries pre-installed, which dramatically lowered the entry barrier for novices." Clicking a Colab link lets students immediately run code on any computer. The authors found this approach crucial for inclusivity, leveling the playing field between students with and without prior coding experience.
