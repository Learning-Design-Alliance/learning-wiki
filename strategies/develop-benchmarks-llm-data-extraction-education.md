# Develop rigorous benchmarks for LLM data extraction tasks in education systematic reviews

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article identifies the absence of shared evaluation resources as a barrier: "at this time there are no existing benchmarks for data extraction tasks in systematic review contexts in education." The authors argue that developing rigorous benchmarks would help educational researchers select LLMs to assist data extraction, while cautioning that benchmarks are only indicators since creators could train models on public test items.

## Design Implications

### Context
#### Requirements
- Benchmarks should use non-public test items where possible to reduce contamination
#### Constraints
- Benchmarks are simply indicators; LLM creators could train their models on public test items to ensure strong performance

### Target Learners
- Education researchers and tool developers in research synthesis

### Target Learning Goals
- Selecting appropriate LLMs for data extraction assistance
