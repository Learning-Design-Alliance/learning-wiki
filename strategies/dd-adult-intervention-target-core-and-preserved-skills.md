# Interventions for adult DD should target both number-specific core deficiencies and domain-general skills while incorporating preserved skills

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The review recommends that intervention methods for adults with DD are likely to be most effective when directly targeted at observed cognitive core deficiencies, including both number-related skills (number magnitude knowledge, enumeration/subitizing, fact retrieval) and number-unspecific/domain-general skills (attention, working memory). Effective interventions should also incorporate preserved and well-established skills that can compensate for deficiencies, so diagnostic assessment should identify both deficits and preserved skills. The review stresses that without an empirically driven conceptual framework, intervention efforts remain unscientific and nonreplicable.

## Design Implications

### Context
#### Requirements
- Requires a conceptual framework incorporating core deficiencies and associated processing difficulties before intervention development
#### Constraints
- No controlled and systematic intervention studies have been reported for adults with DD to date, so recommendations are extrapolated from child DD literature

### Target Learners
- adults with developmental dyscalculia

### Target Learning Goals
- numerical magnitude knowledge
- enumeration and subitizing
- arithmetic fact retrieval
- attention
- working memory
