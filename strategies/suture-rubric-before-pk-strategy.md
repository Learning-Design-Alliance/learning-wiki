# Master corneal suturing with a dedicated rubric before proceeding to penetrating keratoplasty

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors identify corneal suturing as a skill on its own that was not included in the PK rubric, and recommend that 'a rubric be created for this purpose alone and should be mastered before proceeding to penetrating keratoplasty.' This sequences surgical training so foundational suturing competence is established prior to full PK training.

## Design Implications

### Context
#### Requirements
- A dedicated corneal suturing rubric would need to be created for this purpose
#### Constraints
- Corneal suturing is not part of the present PK OSCAR

### Target Learners
- ophthalmology residents beginning corneal surgery training

### Target Learning Goals
- corneal suturing skill
- progression to penetrating keratoplasty
