# Use risk-adjusted cumulative sum (RA-CUSUM) analysis to account for case-mix heterogeneity in learning curve assessment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The review recommends using risk-adjusted cumulative sum (RA-CUSUM) analysis to adjust for confounding variables that may influence operative performance, providing a more accurate representation of a surgeon's progression over time. This addresses the tendency to perform fewer complex cases early in learning followed by more challenging cases later, which distorts standard learning curve assessments. The authors note that effective application requires large datasets, which remains challenging given that LLND is not yet widely adopted globally.
