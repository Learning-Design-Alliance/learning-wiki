# Instructors should test leading AI tools regularly, benchmark assignments against them, and assess unaided student performance in person

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
A set of instructor recommendations grounded in the benchmark findings: test leading AI tools at least once a semester because capabilities change rapidly, test home assignments with the latest AI tools and plugins to gauge how much can be completed by AI, and assess unaided performance in person. The article states "Assessment of unaided student performance (i.e., without AI tools) should be done in person as much as possible, for example with in-class examinations."

## Design Implications

### Context
#### Requirements
- Access to the latest versions of generative AI tools and relevant plugins for benchmarking
#### Constraints
- User experience with earlier versions does not generalize, as the July 2023 introduction of Code Interpreter significantly improved problem-solving capacity

### Target Learners
- college engineering instructors
- students in courses with take-home assignments

### Target Learning Goals
- academic integrity in the era of generative AI
- awareness of AI tool capabilities
