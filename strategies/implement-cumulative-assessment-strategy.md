# Implement a cumulative assessment program to benefit students' study progress

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (1 for, 2 mixed) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors conclude that schools can integrate evidence-based assessment principles into a program: schedule mandatory subtests at fixed intervals across a module, make each subtest cumulative over preceding content, allow compensation across subtests, increase items and weight per subtest, and publish correct answers and item counts shortly after each subtest. They argue that "implementing a cumulative assessment program may benefit students' study progress" and that cumulative assessment shows how several evidence-based principles of assessment can be integrated for the benefit of student learning.

## Design Implications

### Context
#### Requirements
- Performance information between tests should be provided when students can actively process it
#### Constraints
- The study is exploratory and naturalistic; an experimental design in a high-stakes setting is suggested to further establish the value

### Target Learners
- undergraduate medical students; higher-education students generally

### Target Learning Goals
- continuous study effort
- improved test performance of initially low-scoring students without impairing high-scoring students
