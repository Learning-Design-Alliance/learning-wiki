# Implement micro-credentials through a peer cohort model with collaborative planning time

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The report recommends organizing teachers into peer cohorts that pursue the same micro-credential together, treating professional learning as a social endeavor where teachers "share problems of practice, questions, experiences, and insights." Cohorts reviewed each other's work, gave feedback, and shared instructional tools, which district leaders said strengthened classroom integration of computational thinking.
