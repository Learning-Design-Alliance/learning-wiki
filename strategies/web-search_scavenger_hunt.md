# Web-Search Scavenger Hunt

> **Strategy** · [All strategies](index.md)

## Description
A web-search scavenger hunt is a gamified activity in which students answer a series of questions by searching online, with points awarded for each credible source they identify and use. Students typically work in teams, combining search-skill practice with source evaluation. The activity converts the tacit skills of query formulation, result scanning, and credibility judgment into an explicit, practiced task with immediate feedback.

## Design Implications

Scavenger hunts sit within the broader goal of information literacy: students learn to formulate effective queries, scan results critically, and distinguish credible from unreliable sources. Because search skill is procedural, it improves mainly through repeated practice with feedback rather than through instruction alone [Practice with feedback improves procedural skill.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+M]. Team formats add accountability and discussion, which supports deeper processing of *why* a source is credible rather than merely *that* it was found [Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M].

### Context
#### Requirements
- A curated question set whose answers are findable but not trivially guessable
- Explicit criteria for what counts as a "credible" source (e.g., author, date, domain, evidence)
- Devices with internet access and a way to record answers and source URLs
- A debrief in which teams compare sources and justify credibility judgments

#### Constraints
- Without explicit evaluation criteria, students default to clicking the first result, so the activity trains speed rather than discernment [-M]
- Search engines personalize results, so teams may see different results for identical queries, complicating fair scoring [~W]
- Gamified point-chasing can shift attention from source quality to answer speed, undermining the evaluation goal [-W]
- Requires reliable connectivity and devices; inequitable access disadvantages some students [-M]

#### Implementation Variability
- **Evaluation-focused variant:** points awarded only for sources that meet stated credibility criteria, not for correct answers alone
- **Comparison variant:** teams must find two sources that disagree and explain the discrepancy, building source-contrast skills
- **Reverse variant:** students are given a deliberately unreliable source and asked to explain why it fails credibility tests
- **Individual vs. team:** solo versions suit assessment contexts; teams suit skill-building and discussion

### Target Learners
- Upper elementary through adult learners who have basic reading fluency and device familiarity
- Students with limited prior exposure to search operators or source evaluation benefit most; already-fluent searchers gain little unless the task emphasizes evaluation over retrieval [~W]
- Team formats suit mixed-ability groups, letting stronger searchers model query strategies for peers

### Target Learning Goals
- Procedural skill: formulating effective search queries and refining them
- Information literacy: evaluating credibility, authority, and recency of sources
- Metacognition: monitoring whether a source actually answers the question posed

### Instructions
1. Prepare 8–12 questions tied to the unit's content, each requiring a genuine search (not recall of prior lessons).
2. Brief students on credibility criteria and demonstrate one query aloud, modeling refinement of a failed search ([Think-Aloud](../elements/think-aloud.md)).
3. Organize students into teams of 3–4 and set a time limit ([Peer Collaboration](../elements/peer-collaboration.md)).
4. Teams search, record answers, and log the URL and a one-line credibility justification for each source ([Application](../elements/application.md)).
5. Award points for correct answers *and* credible sources; require teams to defend borderline sources during scoring.
6. Debrief: compare queries and sources across teams, highlighting which search strategies and evaluation heuristics worked ([Practice](../elements/practice.md) with feedback).

## Examples
- A middle-school media literacy unit uses a hunt in which teams must answer current-events questions and earn double points for primary sources, followed by a debrief comparing .gov, .com, and .org results.
- [Common Sense Education](https://www.commonsense.org/education) publishes scavenger-hunt-style lessons on search skills and source evaluation for K-12 classrooms.
- University library orientations frequently use hunts (e.g., through [Kahoot](https://kahoot.com) or paper worksheets) in which students locate a peer-reviewed article, a government statistic, and a book record, reinforcing database navigation.
