# Integrate affective computing to analyze user emotional state and adapt tutor responses

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A proposed future extension: integrate affective computing principles so the tutor can 'analyze the user's emotional state and adapt its responses accordingly.' The paper notes the current system 'lacks the ability to analyze the emotional valence of the user,' making this a targeted improvement path for engagement and personalization.

## Design Implications

### Context
#### Requirements
- Integration of affective computing principles into the existing Davinci-003-based tutor architecture
#### Constraints
- Unimplemented in the prototype; the paper reports only that further research could address this

### Target Learners
- all learners using the cognitive tutor, including those whose engagement depends on emotional responsiveness

### Target Learning Goals
- adaptive feedback and engagement responsive to learner emotional state
