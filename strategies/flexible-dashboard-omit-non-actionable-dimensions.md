# Allow flexible dashboard design that adjusts to the target teacher population, omitting non-actionable dimensions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 4 studies (2 theoretical, 1 causal, 1 qualitative), `q2` · 0 of 4 report an effect size · 4 claims rest on one study

## Description
The article's second design guideline is to "Allow a flexible dashboard design that adjusts to the specific needs of the target teacher population. For example, omit dimensions that do not provide actionable items." This implements the finding that teachers judged some dimensions, such as Proactivity, far more useful and actionable than others, such as Control, so dashboards should be tailored rather than uniform.

## Design Implications

### Context
#### Requirements
- Knowledge of which dimensions the target teacher population finds actionable
#### Constraints
- Stated as a design guideline from a single interview study with ten university teachers

### Target Learners
- university teachers in blended and flipped courses

### Target Learning Goals
- actionable monitoring of students' self-regulated learning
