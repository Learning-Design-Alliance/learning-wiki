# Checklists

## Description
Checklists can be used to measure and document student learning by tracking whether learners are accomplishing specific tasks or expectations.

## Design Implications

### Context
#### Requirements
- Requires clear learning objectives, well-defined criteria aligned to standards, and a rating scale with detailed descriptors.
#### Constraints
- If not constructed carefully, checklists may be too generic and not provide specific enough feedback.

### Target Learners
<!-- Link to sub-claims -->
- All learner levels, including K–12, higher education, and adult learners. Can be adapted for use in various subjects and skill-based areas.

### Target Learning Goals
<!-- Link to sub-claims -->
- Track task completion, document learning progress, provide a structured assessment tool

### Affordances
- Provides clear expectations, supports self-assessment, offers specific feedback, and aids in monitoring progress. Supports a shared understanding of learning targets between educators and students.

### Personalization
- Checklists can be customized with different scales (e.g., 4-point, 7-point), criteria, and descriptors to align with specific learning objectives and standards.
