# Dynamically Introduce Academic Vocabulary

## Description
Use repeated encounters with a word in various authentic contexts to help learners internalize the definition. Make the first encounter with vocabulary sticky by using the word in a funny or personal story.

## Design Implications

### Context
#### Requirements
- Find or create stories that incorporate academic vocabulary.
#### Constraints
- May be time-consuming to create engaging stories.
