# Use generative AI to produce analogies and visual storyboards for abstract STEM concepts

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends an AI-driven workflow: input a STEM concept, have GPT-4 generate multiple analogies, select one, generate a four-scene storyboard with images and descriptions, and transform it into an animated video. The authors state this approach could be "a valuable tool for educators, aiding them in planning engaging lessons" and reducing educators' workload in creating multimodal content.

## Design Implications

### Context
#### Requirements
- Access to a large language model for analogy generation and a text-to-image model for storyboards
#### Constraints
- Preliminary testing showed incomplete depiction of multi-component concepts in generated images

### Target Learners
- STEM learners and educators planning lessons

### Target Learning Goals
- understanding abstract STEM concepts through analogical reasoning and multimodal presentation
