# Intermediary-led grantee cohort model with four support components

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article describes an implementable model in which an intermediary supports a cohort of grantees by "helping grantees scope projects in their area of need, matching grantees with providers that could help build organizational capacity, delivering cohort learning activities, and offering thought partnership." Funders can adopt these four components to run similar capacity-building initiatives.

## Design Implications

### Context
#### Requirements
- An intermediary able to scope projects, match providers, run cohort activities, and provide thought partnership; a funding partner; and participating grantees.
