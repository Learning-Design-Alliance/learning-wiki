# Use free, text- and vocabulary-centered tools (MEM, WOW) as supplemental resources in resource-limited settings

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (2 for, 3 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article recommends that teachers consider free, open-source supplemental tools given the study's findings. It states that "MEM and WOW remain free, open-source tools available to any learner in the world with an Internet connection and therefore might represent the most potent supplemental tools for settings with limited resources." This strategy is grounded in the finding that text- and vocabulary-centered tools impacted writing and speaking performance more than practice-and-drill packages marketed as one-stop solutions.

## Design Implications

### Context
#### Requirements
- Internet connection for learner access
- supplementing rather than replacing classroom instruction
#### Constraints
- findings are from a single quasi-experiment with convenience sampling and small group sizes

### Target Learners
- Chinese university ELLs in cross-border higher education programs

### Target Learning Goals
- English writing, reading, speaking, listening, and grammar performance on high-stakes standardized tests
