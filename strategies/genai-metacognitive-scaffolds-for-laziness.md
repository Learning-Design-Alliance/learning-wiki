# Embed metacognitive scaffolds in GenAI search systems — prompting sub-question formulation, guiding output comparison, and encouraging reflection on AI-user knowledge discrepancies

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
This strategy recommends that GenAI academic search systems "embed metacognitive scaffolds, such as prompting sub-question formulation, guiding output comparison, or encouraging reflection on AI-user knowledge discrepancies, to mitigate each type of laziness". It is an implementable design recipe aimed at countering plan-, monitoring-, and regulation-deficit offloading and fostering adaptive human-AI collaboration in creative academic search.

## Design Implications

### Context
#### Requirements
- systems must be able to detect or infer which type of metacognitive laziness a user is exhibiting
#### Constraints
- addressing these challenges is framed as supporting human-AI symbiosis in creative academic search specifically

### Target Learners
- academic searchers using GenAI systems

### Target Learning Goals
- metacognitive engagement during search
