# Match mentors and mentees using application data via speed matching, a stable marriage algorithm, or manual pairing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The guide advises starting from an application collecting basic information about mentors and mentees, useful both for selecting members and generating mutually beneficial matches. It lists matching options: "group "speed-matching" events, using a "stable marriage" algorithm, or manually matching people." In speed matching, mentees rank mentors on a 5-point interest scale after a mingle event; the stable marriage (Gale-Shapley) algorithm ranks both groups' preferences and can be implemented in Mathematica or Python; manual pairing can weigh research-interest alignment.

## Design Implications

### Context
#### Requirements
- An application collecting basic information about mentors and mentees is needed regardless of matching method
- Pairing for one-on-one versus group mentorship requires different matching algorithms
#### Constraints
- With a large number of participants, each mentee can only meet a smaller subset of mentors, so an initial ranking based on mentor bios or a mixer is needed before ranking

### Target Learners
- undergraduate STEM mentees
- graduate and senior undergraduate mentors

### Target Learning Goals
- forming compatible, mutually beneficial mentoring relationships
