# Organize VAM development information around data elements, modeling considerations, role-specific features, and implementation features

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The report structures the information needed to develop a value-added evaluation system into four areas: "typical data elements, important modeling considerations, features specific to teachers or principals, and broad implementation features". This organization is offered as guidance for states or districts building VAM-based evaluation, separating technical modeling decisions from role-specific and system-level implementation choices.
