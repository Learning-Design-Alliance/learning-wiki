# Anchor each virtual experiment in a named OER simulation with a linked lesson video for data collection and spreadsheet analysis

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
Each experiment names the specific simulation students use and pairs it with a detailed lesson video: "A very detail lesson video with detail of data collection with simulator and data analysis with excel can be found here" appears in every experiment section. The procedure then gives concrete simulator operations, such as setting tube radii, adjusting masses with on-screen arrows, using pause and slow-motion modes, and reading force-sensor graphs, so students can collect data remotely as they would in a physical lab.

## Design Implications

### Context
#### Requirements
- Access to the specific OER simulation sites and the linked video resources for each experiment
#### Constraints
- Simulations are third-party OER resources, so available parameter ranges and features are fixed by each simulator

### Target Learners
- introductory physics students in virtual or remote lab courses

### Target Learning Goals
- data collection with simulations, spreadsheet-based analysis, connecting measurements to physical principles
