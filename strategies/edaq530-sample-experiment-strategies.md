# Use spreadsheet-based processing of level-crossing data from simple experiments (picket fence, heat conduction, spring oscillations) to demonstrate core physics concepts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (2 causal, 1 design), `q1`–`q3` · 0 of 3 report an effect size · 2 claims rest on one study

## Description
The article offers concrete classroom experiments built on Edaq530's level-crossing data exported to a spreadsheet. In the picket fence experiment, plotting speed against time shows linear increase and "the curve fitting function available to most spreadsheet programs can instantly yield an estimate of g". Heat conduction along a rod with three thermistors shows that heat takes time to travel and temperature peaks diminish; an accelerometer on a spring illustrates harmonic oscillations with the period read instantly via level-crossing detection.

## Design Implications

### Context
#### Requirements
- A photogate or suitable sensor connected to Edaq530
- A spreadsheet program with curve fitting for the picket fence analysis
#### Constraints
- With advanced groups, the error from using average speed during crossing intervals as an approximation of instantaneous speed should be analysed

### Target Learners
- secondary-school physics students

### Target Learning Goals
- linear motion with constant acceleration
- estimating g
- heat conduction
- harmonic oscillations
