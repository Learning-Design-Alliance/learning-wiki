# Intentionally design resource-equivalent questions in future conceptual surveys and map response choices to cognitive resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends that, if this line of research proves fruitful, researchers should design future conceptual surveys with deliberately resource-equivalent question sets and that experts should revisit existing conceptual assessments to identify the cognitive resources underlying response choices. The article states it "would encourage researchers to intentionally design resource-equivalent questions when developing future conceptual surveys". The TMA method requires such question sets so that inconsistent activation across contexts can be detected.

## Design Implications

### Context
#### Requirements
- Questions in a set must be answerable with the same underlying physics principle but designed in different contexts
- Choice options across the set must correspond to the same set of cognitive resources
