# Phase-aligned teaching applications for LLM-supported learning across five phases

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Table 3 outlines classroom activities aligned with each phase of the instructional model, designed to build technical fluency with LLMs while supporting ethical awareness, critical reflection, and learner agency. Activities include AI bias exploration, prompt remix workshops, AI plus human draft comparison, revision logs, and personal AI use policies. The authors state these strategies position students as co-constructors of knowledge exploring LLMs through creation, iteration, and inquiry.
