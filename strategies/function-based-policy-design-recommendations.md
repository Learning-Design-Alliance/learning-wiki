# Institutions should define generative-AI prohibitions by function, distinguish generation from format conversion, and require validated evidential methods before sanctions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper's normative policy recommendations are that institutions should consider 'defining 'use of generative AI' by reference to function rather than platform identity; explicitly distinguishing content generation from format conversion; adopting the operational criteria proposed in Section 4; and requiring validated evidential methods before imposing sanctions.' On the function-based interpretation, sanctioning students for transcription-only use is best characterised as policy misapplication rather than a proper misconduct finding. Policies should also specify which learning outcomes the prohibition serves.

## Design Implications

### Context
#### Requirements
- Policies must specify which learning outcomes are served by the prohibition so the function-based interpretation can be applied with precision
