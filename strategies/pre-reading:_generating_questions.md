# Pre-reading: Generating Questions

## Description
Generating a list of pre-reading questions that will help learners achieve their purpose for reading. Leading students in creating questions that will help them to achieve their purpose.

## Design Implications

### Context
#### Requirements
- A text and some time to formulate questions.
#### Constraints
- The questions must be relatable to the learner.
