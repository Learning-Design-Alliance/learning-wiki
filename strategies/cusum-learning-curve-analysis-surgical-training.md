# Use CUSUM analysis of procedure time to quantify the surgical learning curve for a novice team adopting a new procedure

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 associational), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The article applies the cumulative sum (CUSUM) method, which it calls "the most powerful and valuable technique" for detecting early trends, to estimate how many cases a novice operator needs to gain proficiency. Procedure time is subtracted from a running reference-based sum; the curve runs parallel to the x-axis when times are as expected, rises when higher, and falls when favorably low, with the cross point marking the learning-curve inflection. This supports novice-surgeon training planning and objective evaluation of new procedures.

## Design Implications

### Context
#### Requirements
- A prospectively collected series of consecutive cases with per-case procedure-time data from a single operator or team
- A reference value (the mean of the data points) for the CUSUM calculation
#### Constraints
- The article cautions the resulting case-count estimate "maybe not precise because we practiced by doing other similar procedures"; the analysis was retrospective and single-center

### Target Learners
- Novice surgeons and interventional teams adopting a new procedural technique

### Target Learning Goals
- Reaching procedural proficiency in a technically demanding new surgical technique
