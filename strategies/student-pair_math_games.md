# Student-Pair Math Games

## Description
Pair-based games facilitate active learning through friendly competition, requiring students to recall and apply math skills in a dynamic setting. Examples include:

*   Finger Speed-Sums: Students show fingers, and the first to call out the sum wins.
*   Finger Speed-Differences: Students show fingers, and the first to call out the difference wins.
*   Five High Fives: Students give high-fives to five different classmates; the game is only possible if there are an even number of people.

## Design Implications

### Context
#### Requirements
- Requires pairs of students and a space for movement.
#### Constraints
- Uneven numbers of participants may cause issues in some games (e.g., 'Five High Fives').
