# Offset added testing time and cost via computerized adaptive testing, shortened exam content, and remote proctoring

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (4 for, 1 mixed, 1 against) · 5 studies (3 theoretical, 1 review, 1 associational), `q1`–`q2` · 0 of 5 report an effect size · 6 claims rest on one study

## Description
To mitigate the cost of lengthening exams, the commentary proposes adopting computerized adaptive testing (CAT), which personalizes item selection to each learner's response pattern so mastering students finish quickly, shortening exam time. Additional strategies include "Shortening stems, reducing the number of multiple-choice response options (e.g., from five to three), and/or the total the number of response items," plus remote proctoring to reduce testing-centre costs.

## Design Implications

### Context
#### Requirements
- Items must be pre-calibrated for psychometric properties so an adaptive model can select optimal questions based on response pattern
- Content removed when shortening must not be essential to the validity of resulting score interpretations
#### Constraints
- CAT was not originally intended to reduce speededness, and it is not known to what extent students in the middle of the distribution experience speededness

### Target Learners
- licensure and certification candidates
- medical students

### Target Learning Goals
- efficient, valid measurement of medical knowledge
