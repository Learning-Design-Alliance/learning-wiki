# Teacher practices for building confidence and eliminating intimidation in P.E.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The SBSM curriculum trains teachers in six concrete practices: greet students by name; not use nicknames; encourage mistakes; not punish with exercise; not let students pick teams; and end each class as a group with a 'big finish.' These are taught in two 2-hour workshops prior to implementation and are intended to build confidence and create safe, welcoming P.E. environments.
