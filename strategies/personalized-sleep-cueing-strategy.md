# Tailor sleep cueing frequency to individual retrieval performance and task difficulty rather than using fixed uniform stimulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
A strategy for sleep-based memory interventions: instead of delivering cues uniformly, vary the number of cue repetitions according to each learner's prospective difficulty ratings and pre-sleep recall accuracy, cueing challenging items more intensively (up to 4 presentations) and skipping items judged already consolidated. The article states this "response-contingent protocol ensured that stimulus delivery was tailored to individual memory trace strength and learning outcomes". It recommends automated, real-time EEG-based cueing systems to make the approach scalable.

## Design Implications

### Context
#### Requirements
- Real-time sleep-stage monitoring to deliver cues only during stable NREM 2/NREM 3
- Learner-specific difficulty ratings and accuracy data collected before sleep
#### Constraints
- Manual stimulus administration by sleep experts currently limits real-world application; the article calls for automated systems

### Target Learners
- Adult learners in educational or cognitive rehabilitation settings

### Target Learning Goals
- Optimizing sleep-dependent consolidation of difficult-to-recall material

### Affordances
- Nrem Sw Spindle Consolidation Framework
