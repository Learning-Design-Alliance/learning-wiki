# Combine social web tools enabling social presence, teacher interaction and enjoyable collaboration to foster active learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 review, 1 associational), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
The article recommends promoting active collaborative learning "using tools that allow for an appropriate social presence", combining tools enabling a wide range of activities from collaborative wiki writing to simultaneous conversations via forums and Skype. Teachers should use these tools to interact with students, provide guidance and technical support, and design fun, attractive study situations while clearly establishing rules of operation and evaluation.

## Design Implications

### Context
#### Requirements
- Teachers must clearly define tasks, the evaluation system and their role
- Teachers must monitor and guide student activity on the platforms
#### Constraints
- The mere use of online tools does not guarantee the significant interactions that are conducive to active learning

### Target Learners
- higher education students in blended learning courses

### Target Learning Goals
- active learning
- collaborative case-study analysis
