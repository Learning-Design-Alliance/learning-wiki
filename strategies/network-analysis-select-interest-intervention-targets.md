# Use network analysis of interest indicators to select variables for intervention testing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The strategy is to model interest components as a network of interacting indicators, then select centrally or structurally important variables as "potential candidates for intervention". The article demonstrates this on PISA 2015 data from the Netherlands and Colombia, identifying variables of structural importance within the interest construct before any intervention study is run.

## Design Implications

### Context
#### Requirements

#### Constraints
