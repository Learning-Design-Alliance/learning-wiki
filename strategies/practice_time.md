# Practice Time

## Description
Practice time is scheduled, low-stakes opportunity for learners to apply a skill or concept immediately after instruction, without grading or evaluative consequences. The instructor's role shifts from presenting to circulating, monitoring, and giving [feedback](../elements/assessment.md) while learners attempt the task themselves.

## Design Implications

Retrieval and application during practice strengthen retention far more than rereading or listening, because the act of reconstructing knowledge from memory modifies it durably [Test-enhanced learning: Taking memory tests improves long-term retention.](https://doi.org/10.1111/j.1467-9280.2006.01693.x) [+S]. Practice time only pays off when it is *deliberate* — targeted at a specific subskill, at an appropriate difficulty, with feedback available — rather than mere repetition [The role of deliberate practice in the acquisition of expert performance.](https://doi.org/10.1037/0033-295x.100.3.363) [+M]. Removing grading pressure matters: low-stakes conditions keep learners willing to attempt and err, which is where much of the learning occurs.

### Context
#### Requirements
- A task that closely matches the target skill, attempted by every learner (not demonstrated only)
- Feedback available during or immediately after attempts, at task and process levels [The power of feedback.](https://doi.org/10.1080/00461520701430953) [+S]
- Explicitly low stakes — no grades or public evaluation attached to early attempts
- Enough time for multiple attempts, not a single token exercise

#### Constraints
- Practice without feedback entrenches errors; uncorrected practice can be worse than no practice [The power of feedback.](https://doi.org/10.1080/00461520701430953) [-S]
- Practicing a whole complex task at once overwhelms novices; isolating component skills first is more effective [Part-task practice reduces load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]
- Blocked, massed practice within one session feels productive but yields poorer long-term retention than spaced, varied practice [~S]
- If stakes creep in (peer ranking, immediate grading), learners shift from exploring to impression management, and error-driven learning shuts down [-M]

#### Implementation Variability
- **In-class guided practice**: instructor circulates, gives just-in-time coaching, and surfaces common errors for whole-class discussion
- **Retrieval practice formats**: short ungraded quizzes or free-recall prompts that make practice a memory exercise [Test-enhanced learning: Taking memory tests improves long-term retention.](https://doi.org/10.1111/j.1467-9280.2006.01693.x) [+S]
- **Example–problem pairs**: learners study a worked example, then immediately attempt a parallel problem [Example-problem sequences reduce cognitive load.](../claims/example-problem-sequences-reduce-cognitive-load.md) [+M]
- **Part-task drills**: isolated subskills practiced before integration into the full task [Part-task practice reduces load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]

### Target Learners
- Novices, who need immediate supervised application before errors consolidate [Part-task practice reduces load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]
- Anxious or low-confidence learners, for whom the no-grades condition lowers the cost of attempting
- Advanced learners may need less structured practice time and more challenge; highly guided practice can feel redundant to them [~M]

### Target Learning Goals
- Procedural fluency: automating skills so working memory is freed for higher-level thinking
- Retention and transfer: strengthening memory through retrieval and varied application
- Self-regulation: learning to monitor one's own performance against criteria

### Instructions
1. Present the skill or concept concisely, ideally with a worked demonstration ([Cognitive Apprenticeship](../patterns/cognitive-apprenticeship.md) modeling phase).
2. Pose a task that mirrors the target performance; start with a partial or component version for novices ([Part-task practice reduces load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]).
3. State explicitly that this is ungraded practice — errors are expected and useful.
4. Circulate and coach, giving feedback focused on the task and the process, not the person [The power of feedback.](https://doi.org/10.1080/00461520701430953) [+S].
5. Debrief: collect common errors and discuss them anonymously with the whole class.
6. Schedule revisits of the same skill on later days (spaced practice) rather than cramming all practice into one session.

## Related Strategies
- **Spaced practice** — distributing the same practice over time; the single strongest scheduling lever for retention
- **Retrieval practice** — a practice format where the act of recall itself is the learning event
- **Worked examples** — the instructional complement: demonstration first, then practice time on a parallel problem
- **Formative feedback loops** — practice time is the venue in which formative assessment actually happens

## Examples
- **Writing conferences (elementary)**: after a mini-lesson on a craft move, students write for 10–15 minutes applying it while the teacher confers individually; nothing collected for a grade that day.
- **Khan Academy (https://www.khanacademy.org)** — after each video demonstration, learners get unlimited ungraded practice exercises with hints and instant feedback, and mastery tracking only later.
- **Duolingo (https://www.duolingo.com)** — short low-stakes practice sessions with immediate item-level feedback, algorithmically spaced and revisited.
- **Codecademy (https://www.codecademy.com)** — annotated code examples followed immediately by an in-browser exercise where learners write and run their own version with instant feedback.
