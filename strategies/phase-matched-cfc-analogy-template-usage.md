# Match each approach to its phase: analogies for abstract concepts, templates for problem solving, CFC at the start of code writing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article derives concrete usage guidance from its results: instructors should deploy the three approaches at the points in the programming process where each showed its effect. The article reports that "instructors may use analogies when teaching abstract subjects like memory and disk allocations" and that templates are best used in problem solving to refer to good solutions, while CFC belongs in the first phase of code writing to help students confirm syntax and keep writing despite errors. Instructors may also combine approaches depending on the nature of the problem.

## Design Implications

### Context
#### Requirements
- Programming instructors should search the templates and think about analogies before lecturing
#### Constraints
- Special efforts must be made to correct mistakes, especially with regard to iteration, variable usage and memory operations

### Target Learners
- novice programmers in introductory programming courses

### Target Learning Goals
- writing syntactically correct code
- understanding abstract programming concepts
- problem solving and program decomposition
