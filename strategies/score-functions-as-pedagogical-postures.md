# Choose score functions and aggregation methods as explicit pedagogical postures, mixable to fit institutional needs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The framework offers three score functions — a linear baseline with direct proportionality, a logistic function where small deviations from the target highly affect scores (a strict policy), and a quadratic function that is lenient for small deviations but strongly penalises large ones — plus the two aggregation methods. The article states "these functions could be mixed (or replaced) in order to fit the HEI needs", for example strongly penalising the largest negative discrepancies while remaining linear for positive ones. The optimal function depends on the aims of the HEI.
