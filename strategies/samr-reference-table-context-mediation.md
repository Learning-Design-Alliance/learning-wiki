# Use a reference table linking SAMR levels to context of mediation, teaching intention, use strategies and teacher reflection

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 2 studies (1 review, 1 associational), `q2` · 0 of 2 report an effect size · 6 claims rest on one study

## Description
The article presents a table (adapted from the SAMR model) to "help teachers analyze how ICTs can add different values to practices, always linking them to the context and its conditions of mediation". It organizes Substitution, Augmentation/Modification and Redefinition by context of ICTs mediation, tendency of each level, teaching intentions, ICT use strategies, teacher reflection questions and added value (conservative, enriching or transformative).

## Design Implications

### Context
#### Requirements
- Teachers analyze pedagogical uses of ICTs within the scope of the joint activity involving teachers, students and contents.
#### Constraints
- The table supports both horizontal and vertical reading because of the fluid nature of the act of teaching and learning.

### Target Learners
- teachers

### Target Learning Goals
- analyzing how ICTs add value to teaching practices
