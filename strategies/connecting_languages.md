# Connecting Languages

## Description
Encourage students to see connections between their languages to better understand how languages are structured and organized.  Talk to ELLs about their home language — ask them how the home language is the same and how it is different from English. Ask if there are words in the home language that sound the same and mean the same thing in both languages, or if there are words in the home language and English that sound the same but mean different things.

## Design Implications

### Context
#### Requirements
- Requires teachers to be knowledgeable about language structures and to create a classroom environment that values multilingualism.
#### Constraints
- May be challenging for monolingual teachers to implement effectively.
