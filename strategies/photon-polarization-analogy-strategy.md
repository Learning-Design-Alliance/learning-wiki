# Use a familiar photon-polarization analogy to help students learn the Stern-Gerlach experiment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 mixed) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
To help students understand that a |↑⟩z state can be converted to the orthogonal |↓⟩z via an intermediate SGX−, the QuILT draws an analogy with photon polarization states: vertically polarized light passing directly through a horizontal polarizer yields no output, but inserting a 45° polarizer first produces light that is "a linear superposition of horizontal and vertical polarization," so some light exits the horizontal polarizer. Because the polarizer experiment is familiar from introductory physics, the analogy helps students learn about SGE in a familiar context.
