Use Mozilla's four basic web literacies to frame open learning for personal development¶

Strategy · All strategies Evidence · no claims cited

Description¶

The article presents web literacies — the abilities to utilize the Web for personal development — via Mozilla Foundation's four basic web literacies: Exploring (navigating while learning, questioning, evaluating), Creating (creating with the Web while respecting others' work), Connecting (communicating and participating in Web communities), and Protecting (protecting the Web as a public resource). The authors state this framework resonates with prior accounts of digital learning environments for Bildung.
