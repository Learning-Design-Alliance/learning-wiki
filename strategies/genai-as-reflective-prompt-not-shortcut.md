# Use GenAI as a reflective prompt in learning design, not as a shortcut for efficiency

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A specific implementable practice the article recommends: educators can strengthen learning design by prompting GenAI in ways that provoke their own reflection rather than outsourcing design decisions. The implications for practice state that "Educators can strengthen learning design by using GenAI as a reflective prompt, not as a shortcut for efficiency". This positions GenAI as a partner in the educator's thinking rather than an automated substitute.

## Design Implications

### Context
#### Requirements
- Educators retain ownership of design decisions and treat GenAI output as input to their own reflection
#### Constraints
- The article does not report empirical testing of this strategy; it is offered as a practice implication of the discourse analysis

### Target Learning Goals
