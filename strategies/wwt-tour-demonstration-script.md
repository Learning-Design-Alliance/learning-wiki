# Classroom demonstration script for WWT tour creation, contrasting numerical narration with interesting facts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A classroom demonstration script used to "quickly show a class some tour making ideas" and WWT's capabilities: a quick guided tour of WWT (solar system mode, sky mode, search), step-by-step tour creation (new tour, slides, view changes, end positions, smooth transitions, save), then playing a demo tour twice, once reciting numerical information and once revealing interesting facts, and asking which is more interesting.
