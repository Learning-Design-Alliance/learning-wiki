# Mitigate CBL-MDT implementation challenges through fixed protected scheduling, pre-course orientation, quarterly case review, and OSCE-based assessment.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 3 studies (2 causal, 1 review), `q2`–`q3` · 0 of 3 report an effect size · 6 claims rest on one study

## Description
Several implementation challenges warrant consideration including coordination complexity, student adaptation, case currency, and assessment validity. The authors' approach involved scheduling MDT sessions at fixed times protected in departmental schedules, maintaining a core MDT faculty pool with backup arrangements, and implementing quarterly case review sessions where teaching faculty discuss recent literature.

## Design Implications

### Context
#### Requirements
- Protected time for faculty participation
- Pre-course orientation explaining the pedagogical rationale
- Quarterly case review sessions
#### Constraints
- Comprehensive evaluation requires moving beyond traditional testing and requires additional resources
- Institutional support is essential given the resource-intensive nature of MDT teaching

### Target Learners
- Postgraduate medical students
- Senior attending physicians

### Target Learning Goals
- Teamwork competencies
- Assessment validity
