# Design recommendations for game-based performance assessment of professional competencies

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The review derives four recommendations for practice: design the serious game so both task and context are authentic; ensure in-game behavior is collected and use evidentiary frameworks such as ECD to determine which behavior informs ability; implement adaptivity where appropriate; and use low-risk mechanics for freedom of gameplay and progress feedback. It states: "First, regardless of the competency type: design the SG in such a way that both the task and the context are authentic." For freedom of gameplay it recommends free exploration, interactive elements, and providing options for cognitive skills and knowledge, and control over movements for motor skills.

## Design Implications

### Context
#### Requirements
- Use evidentiary frameworks (e.g., ECD) to determine which in-game behavior can be used to infer ability level, since usable behavior depends on the competency and game design
#### Constraints
- Implementing non-authentic (fantasy) contexts and tasks should be investigated further before being implemented in high-stakes performance assessment; adaptivity has no added benefit for competencies where ability cannot be differentiated

### Target Learners
- candidates for vocational certification in secondary vocational education, higher education, or vocational settings

### Target Learning Goals
- professional competencies specific to a work setting, including knowledge, motor skills, and cognitive skills
