# Live mentoring sessions and Slack support to tailor containerization training to participants' computing environments

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
During training events, the authors ran live mentoring sessions and support via Slack in which they "helped participants troubleshoot setup issues, review exercises, and understand how they can apply these tools to their own analysis". The authors state this interactive component was essential for tailoring advice to the computing environment available to each participant, complementing pre-recorded lectures and hands-on exercises.
