# Write with a Transition Handout

## Description
Before learners write, provide a handout of transitions. Model where transitions fit, and describe how they help the reader.

## Design Implications

### Context
#### Requirements
- Prepare handouts with common transitions.
#### Constraints
- Learners may overuse transitions or use them inappropriately.
