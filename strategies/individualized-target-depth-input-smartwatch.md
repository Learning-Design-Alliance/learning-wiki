# Input the measured anterior–posterior chest diameter into the smartwatch to individualize the target compression depth

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because the guideline depth of about 4 cm "might not be appropriate for all infants", the authors recommend measuring the infant's anterior–posterior chest diameter and entering it into the smartwatch so that "CC can be performed with a more accurate depth". This adapts the feedback threshold to the individual patient rather than a fixed 3.5–4.5 cm range.

## Design Implications

### Context
#### Requirements
- A measurement of the infant's anterior–posterior chest diameter
- A smartwatch application that accepts a user-input target depth
#### Constraints
- The evaluated application used a fixed 3.5–4.5 cm range; individualized input was proposed, not tested

### Target Learners
- rescuers of infants in cardiac arrest

### Target Learning Goals
- achieving an accurate, patient-specific compression depth
