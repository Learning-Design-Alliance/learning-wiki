# Use honor code reminders displayed during unproctored online tests as a privacy-non-invasive cheating-prevention measure

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends displaying a honor code reminder during an unproctored online test as the most effective privacy-non-invasive intervention, finding it "worked best in lowering the odds of cheating" compared to control. Unlike remote proctoring, this approach neither collects personal information nor controls test-takers' devices. The intervention is displayed between questions during the test itself, simulating perceived monitoring without privacy invasion.

## Design Implications

### Context
#### Requirements
- The intervention must be displayed during the test (not only before it) to simulate the perception of getting caught while cheating
#### Constraints
- The monitoring message variant did not reach statistical significance, so surveillance-only messaging without consequences may be less reliable

### Target Learners
- adult test-takers in high-stakes online assessments
- online higher-education students

### Target Learning Goals
- academic integrity
- valid summative assessment
