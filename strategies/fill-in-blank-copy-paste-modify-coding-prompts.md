# Use fill-in-the-blank and copy-paste-modify coding prompts so students can complete programming exercises without prior coding knowledge

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The activities scaffold programming by having students complete partially written code rather than write programs from scratch. The article states: "We have designed the coding activities as fill-in-the-blank prompts that ask students to replace question marks with the correct code or copy-paste-modify code from a previous section." This design, combined with a thorough Python introduction and instructor answer keys, lets students with no prior coding experience modify scripts and explore the FT toolkit. It was used with Trinity students, the majority of whom had no prior programming experience.
