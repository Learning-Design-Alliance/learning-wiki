# Telemetry-first coaching framework: set idle-time benchmarks, an Arm-4 budget for resection, and review phase timelines when RA-CUSUM inflects

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (7 for) · 1 study (1 associational), `q2` · 1 of 1 report an effect size · 7 claims rest on one study

## Description
The article proposes turning routine intraoperative telemetry into coaching targets for surgical training programmes. In practice, programmes can "set idle-time benchmarks and an Arm-4 'budget' for the resection phase, incorporate checklists for exposure/retraction choreography, and review phase timelines when RA-CUSUM inflects". Dashboards displaying idle time, arm-specific activity, and exchange rate per active hour are recommended to provide near-real-time feedback and shorten the path to proficiency.

## Design Implications

### Context
#### Requirements
- Access to automatically captured MyIntuitive (da Vinci Xi) telemetry data for each case
- Video-verified phase annotation to define operative windows such as Landmark-R
- RA-CUSUM monitoring with prespecified reference and decision parameters
#### Constraints
- The current application does not support time-sliced exports at user-defined landmarks
- Console telemetry cannot capture cognitive load, team dynamics, assistant manoeuvres, bedside ergonomics, or subtle anatomic variation
- Vendor-generated telemetry can evolve across software versions and is not yet standardised across platforms

### Target Learners
- surgeons in robotic pancreatic surgery training programmes

### Target Learning Goals
- acquisition of technical proficiency in robotic pancreaticoduodenectomy
- efficient console workflow and exposure/retraction choreography
