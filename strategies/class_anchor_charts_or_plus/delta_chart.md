# Class Anchor Charts or Plus/Delta Chart

## Description
After a formative assessment or test the class may have a discussion about what problems on the assignment caused concerns. The class then reflects on the processes used to find the answer and have a thorough discussion about the mathematical process.

## Design Implications

### Context
#### Requirements
- Formative assessments, time for class discussion, and a way for students to share their thinking.
#### Constraints
- Requires time and effort to facilitate the class discussion.
