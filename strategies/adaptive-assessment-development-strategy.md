# Develop next-generation visualization literacy assessments using adaptive testing, diagnostic item selection, and machine-generated items

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends building new assessments that combine psychometric best practices with machine learning item generation, and using item-response theory to select diagnostic items or "adaptive testing protocols that dynamically propose sequences of items to administer that will be most informative about an individual's literacy level given their responses so far". It suggests pairing these with the study's factor-analytic approach to estimate multiple facets of literacy rather than a single dimension.

## Design Implications

### Context
#### Requirements
- A larger and more varied item pool than existing fixed tests, since small fixed item sets make it hard to estimate skill reliability or measure within-person change
#### Constraints
- The article notes existing assessments confound graph type with plotted variables, and that broader coverage requires going beyond conceptualizing literacy as a single dimension

### Target Learners
- US adults and students in formal educational settings

### Target Learning Goals
- Reliable measurement of data visualization literacy components for educational assessment and instruction
