# Mark errors with correction symbols so students can self-correct from clues

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A concrete feedback technique from the article's conclusion: teachers mark written work with coded symbols rather than full corrections. The article states "it is compulsory that the teacher should rectify students' mistakes and errors using symbols [e.g., for spelling mistake 'SP'] indicating that there is something wrong with that sentence, word or punctuation", so students can correct themselves by getting the clue of their mistakes.

## Design Implications

### Context
#### Requirements
- Teachers must use a consistent symbol code (e.g., SP for spelling mistakes) that signals the location and type of error without supplying the correction.
