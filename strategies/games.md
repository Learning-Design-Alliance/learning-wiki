# Games

## Description
Gaming involves using games as a way to help learners learn by doing. Games can be organized in a way that individuals and groups play with each other, by either collaborating or competing, like in the real world. Motivation tools such as points, badges and certificates can be awarded to make the game more engaging for participants.

## Design Implications

### Context
#### Requirements
- A game or simulation, facilitator to guide the learning process, motivation tools such as points, badges and certificates
#### Constraints
- Games can be seen as frivolous by some, and outcomes need to be well-defined to ensure learning is effective.
