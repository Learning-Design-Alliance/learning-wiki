# Implement Hyland's (2007) four-stage genre-based writing cycle: modeling, joint construction, independent construction, and comparing.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The instructional approach used for all four groups was based on the model developed by Hyland (2007), consisting of four stages: modeling, joint construction, independent construction, and comparing. One instructional session was held for the modeling stage and one practice session for the remaining three stages. The practice session included composing jointly, giving feedback, composing independently, drafting, giving feedback, revising and editing, and comparing.

## Design Implications

### Context
#### Requirements
- All groups must be given the same model texts, with classified ads structures that are similar, straightforward, and easily identified, and of similar lengths.
#### Constraints
