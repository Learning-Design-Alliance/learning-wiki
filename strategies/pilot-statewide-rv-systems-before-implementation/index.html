Pilot statewide roster verification systems before full implementation¶

Strategy · All strategies Evidence · no claims cited

Description¶

Among the brief's implementation strategies is piloting the statewide roster verification system on a limited scale before statewide rollout. Piloting is intended to surface potential pitfalls states should consider, so that teacher-student data links are valid before results feed high-stakes decisions and are shared with districts.

Design Implications¶

Context¶

Requirements¶

  • A statewide ToR definition and RV system must exist before piloting can occur.

Constraints¶

Target Learners¶

  • K-12 students in state accountability systems

Target Learning Goals¶

  • Valid teacher-student data links for evaluation

Related Strategies¶

  • Have staff familiar with the students and their classroom experiences approve rosters
  • Provide guidance to districts on implementing the statewide ToR definition
  • Continue examining the FFL's statistical properties, especially score variation, during statewide implementation
  • Design a service-oriented resource allocation review using continuous improvement and design thinking, engaging LEAs and schools in design, pilot, and test phases before rollout.
