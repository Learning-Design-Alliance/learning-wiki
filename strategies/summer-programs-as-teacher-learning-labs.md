# Use summer programs as learning labs for teachers to practice new instructional strategies

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The brief suggests that "summer programs can be learning labs for new practices," because teachers made use of instructional practices they had learned while delivering the programs. Districts and program providers can therefore structure summer programs to give teachers supported opportunities to enact newly learned practices with students.

## Design Implications

### Context
#### Requirements
- Teachers must learn new instructional practices as part of program delivery.
