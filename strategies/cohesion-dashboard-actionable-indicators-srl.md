# Use automated cohesion assessment dashboards with actionable indicators to support student self-regulated learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors propose integrating the cohesion assessment model into student-facing dashboards that display actionable performance indicators, so that students can self-assess and address weaknesses in line with self-regulated learning principles. They suggest that "integrating this approach into dashboards could provide students with actionable performance indicators (e.g., 'Improve lexical diversity by 10%')", promoting autonomy and reducing dependency on automated tools. A related scenario flags weak referential cohesion and suggests pronoun-usage activities.
