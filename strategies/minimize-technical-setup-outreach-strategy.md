# Use online coding platforms and ready-made equations to minimize technical setup and math manipulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 5 studies (2 associational, 1 causal, 1 qualitative, 1 design), `q2`–`q3` · 0 of 5 report an effect size · 3 claims rest on one study

## Description
The authors found that measures reducing discussion of specific coding or software tasks improve the student experience. Specialized software can be minimized by using online coding platforms so that access to a web browser is all that is necessary, and whenever equations are needed, the exact final form should be provided in a clear and easy-to-use format without any manipulations. Programming concepts are introduced in a single short lecture with very little detail.
