# Offer interactive digital games like PàN as one option in teachers' pedagogical toolboxes for L2 vocabulary and engagement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (1 for, 3 mixed) · 2 studies (1 causal, 1 quant-synthesis), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The authors conclude that interactive games such as PàN can enhance L2 vocabulary learning for some participants and increase student interest and engagement, so they recommend such games as "another viable option for teachers' pedagogical toolboxes". The recommendation is hedged: statistical results showed limited advantage over paper-based gamified activities, so games complement rather than replace existing activities.

## Design Implications

### Context
#### Requirements
- Games should involve interactive, meaningful use of vocabulary connected to personal experiences, in a fun and competitive environment
#### Constraints
- Statistically, digital game-playing showed limited pedagogical value for vocabulary acquisition compared with paper-based gamified information gap activities; benefits were concentrated in some individual learners

### Target Learners
- intermediate-level L2 French learners in classroom settings

### Target Learning Goals
- L2 vocabulary acquisition
- student interest and engagement in learning
