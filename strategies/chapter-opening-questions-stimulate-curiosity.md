# Open each learning chapter with challenging questions before presenting key material to stimulate curiosity

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
In the NIHSS e-learning module, each chapter begins with challenging questions presented before the key learning material, a design the authors describe as intended "to stimulate curiosity" and increase interactivity and user involvement. Wrong answers lead to a cue or detailed explanation before the user can retry or move forward. This strategy operationalizes active-learning principles within self-paced e-learning.
