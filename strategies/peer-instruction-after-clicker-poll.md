# Add a peer instruction (think–pair–share) component after the initial clicker poll to build student connection

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Following the mixed survey response to feeling connected to classmates, the authors recommend peer instruction: students get extra time after the initial poll but before the solution is displayed to discuss results with each other, then a second poll records changes in opinion. They describe this as a well-established practice effective for engaging students, improving critical thinking and communication skills, and building a collegial atmosphere.

## Design Implications

### Context
#### Requirements
- Extra class time beyond the standard poll; can be introduced gradually and need not be used for every question
#### Constraints
- The authors note it "obviously consumes additional class time"

### Target Learners
- undergraduate students in large lecture courses

### Target Learning Goals
- collaborative engagement
- critical thinking and communication skills
