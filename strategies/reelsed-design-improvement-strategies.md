# Improve AI-assisted microlearning tools with transparency, instructor review, and navigation and note-taking features

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors recommend concrete design directions for AI-assisted microlearning tools: future iterations should add transparency about how content is created and features that help users understand the model's role and limitations; instructors should review and improve AI-generated summaries to guard against oversimplification or errors; and the ReelsEd interface could be improved by adding subtitles, a gallery view for navigation, and support for note-taking. These recommendations come directly from the study's trust findings, qualitative feedback, and limitations section.
