# Provide a practice environment in which students solve conceptual database design problems while the tutor adapts via student models

> **Strategy** · [All strategies](index.md)

## Description
The article's approach is to let students "practise conceptual database design using the Entity-Relationship data model" in a problem-solving environment, while the system observes their actions and adapts to their knowledge and learning abilities. Implementers should build the practice environment on constraint-based domain and student models so adaptation follows from observed student solutions.
