# Run inclusive classrooms with sticky-note help signals, multiple explanations, and accessibility checks

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends concrete inclusive-teaching practices: taking the temperature of the room with wait time and sticky notes — "people who need help with something can put up a different color post-it" — plus tools like Slido; explaining concepts in multiple ways; not assuming everyone knows the basics; using inclusive language guidelines; testing curricula with screen readers and ColorOracle for color vision compatibility; and being aware of implicit bias and stereotype threat.
