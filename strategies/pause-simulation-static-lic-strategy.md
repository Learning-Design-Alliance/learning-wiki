# Pause real-time field simulations to render static LIC images connecting dynamic and standard representations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
As part of the recommended representation combination, the authors propose letting students pause real-time simulations at any instant to create a single static LIC, rendered in tens of seconds. They write of "the ability to pause such real time simulations at any point in time to create a single static LIC, which can be rendered in tens of seconds". This connects the high-resolution texture representation to more standard field representations and shows the field configuration at selected times.
