# Anglo-Saxon Phoneme-Grapheme Mapping

## Description
Spelling by explicit phoneme-grapheme mapping requires the learner to match the letters/letter combinations in a word to the speech sounds they represent using a grid; each box of the grid represents a phoneme. This helps fix phoneme-grapheme correspondences in children’s minds and supports spelling, reading, and writing development.

## Design Implications

### Context
#### Requirements
- Phoneme-grapheme grids, word lists, direct instruction
#### Constraints
- Requires explicit and systematic instruction, may not be effective for learners with severe phonological deficits
