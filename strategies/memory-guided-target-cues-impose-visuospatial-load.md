# Display peg-transfer target positions for one second only at the start of each trial, removing online target cues to impose visuospatial working-memory load during practice.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 3 studies (3 causal), `q3` · 1 of 3 report an effect size · 1 claim rests on one study

## Description
This visuomotor manipulation increases working memory demands by displaying the target positions for 1 s at the start of each trial and then removing them, so participants must retain the target locations in working memory while executing the task without online target cues. The article notes this approach is widely used in visuomotor research to elicit memory-guided actions and increase reliance on stored spatial representations.

## Design Implications

### Context
#### Requirements
- A simulator or task setup capable of briefly displaying and then removing target position cues
#### Constraints
- The extent to which the manipulation selectively taxed working memory was inferred from the task design rather than directly quantified, as no workload assessment was included

### Target Learners
- surgical trainees and laparoscopically naive novices

### Target Learning Goals
- retention of efficient instrument movements in minimally invasive surgery
