# Implement Imagine Math within existing staffing, with educators monitoring engagement with individualized learning paths and progress reports

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The program requires no additional staffing: it "is typically implemented by students' mathematics teachers, mathematics specialists, or lab instructors." These educators are "responsible for monitoring student engagement with individualized learning paths and tracking reports within the Imagine Math program that provide data on student progress and growth."

## Design Implications

### Context
#### Requirements
- Educators monitor student engagement with individualized learning paths and track program reports on student progress and growth.
