# Refer to resolution as a number or value and emphasize that small values detect fine details

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A language-precision strategy for teaching interferometer resolution, where the calculated value is wavelength divided by baseline and smaller values mean finer detail — opposite to everyday usage such as HDTV. The authors report, 'the Lecture-Tutorial always refers to the resolution as a number or value and in our lecture preceding the Lecture-Tutorial we emphasize that this number must be small if you want to detect fine details,' because students otherwise think a large value is required to see fine details.

## Design Implications

### Context
#### Requirements
- An introductory lecture preceding the activity in which the instructor emphasizes that the resolution number must be small to detect fine details
#### Constraints
- Addresses a specific misconception arising from non-scientific usage of the word resolution (e.g. HDTV)

### Target Learners
- Astro 101 introductory astronomy students

### Target Learning Goals
- Correctly interpret calculated resolution values and which values correspond to detecting fine details
