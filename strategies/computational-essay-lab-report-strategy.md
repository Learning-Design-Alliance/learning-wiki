# Use a computational essay as the lab-report format for assessing the DFT vibration-analysis task

## Description
The article recommends that for full laboratory implementations "a computational essay is suggested as the lab report format for assessment". A computational essay is defined as "a type of essay or report that explicitly incorporates live code to support its thesis, usually written in a notebook environment", so code and code output appear directly in the body of text. The notebook itself doubles as an example of this format.
