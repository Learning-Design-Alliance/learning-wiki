# Game Based Review

> **Strategy** · [All strategies](index.md)

## Description
Game based review re-packages previously taught content into competitive or cooperative game formats — quiz games, board races, digital platforms, escape-room puzzles — so that learners repeatedly retrieve and apply material in a low-stakes, motivating context. The game structure supplies rules, feedback, and pacing; the content supplies the retrieval demands. It is a review strategy, not a first-teaching strategy: the learning target must already have been introduced.

## Design Implications

Game based review works primarily because it forces repeated retrieval of prior learning, and retrieval practice is among the most robust findings in learning science [Distributed practice improves retention.](../claims/distributed-practice-improves-retention.md) [+S]. The game layer adds engagement and immediate feedback, but it must not displace the retrieval itself — games where most players watch one person answer, or where luck dominates content knowledge, produce activity without learning [Active learning improves exam performance.](../claims/active-learning-improves-exam-performance.md) [+S].

### Context
#### Requirements
- Content that has already been taught and needs consolidation, not novel instruction
- Game mechanics that require *every* participant to retrieve (individual whiteboards, team answer sheets, simultaneous-response digital tools)
- Immediate feedback on answers so errors are corrected within the game loop ([Assessment](../elements/assessment.md) as formative check)
- Questions calibrated so success is possible but not guaranteed — near-100% win rates signal the review is too easy

#### Constraints
- Competition can suppress participation for anxious or low-performing learners; the same learners who most need review may disengage [-M]
- Extrinsic point structures can undermine intrinsic interest in the material itself when rewards feel controlling [Autonomy supports intrinsic motivation.](../claims/autonomy-supports-intrinsic-motivation.md) [~M] — cooperative or mastery-framed games reduce this risk
- Novelty and excitement consume working memory; heavily gamified formats can crowd out the content for learners with limited prior knowledge [Cognitive overload degrades learning.](../claims/cognitive-overload-degrades-learning.md) [-M]
- Games reward speed; fluency pressure can reinforce fast, wrong answers if feedback is delayed or absent [-M]

#### Implementation Variability
- **Digital platforms** (Kahoot!, Quizizz, Blooket, Gimkit): simultaneous anonymous response lowers social risk; self-paced variants (Quizizz) remove the speed penalty
- **Cooperative formats** (team-based trivia, escape rooms, [Jigsaw](../strategies/jigsaw.md)-style review): shift motivation from individual competition to group accountability
- **Low-tech formats** (board races, trashketball, bingo, flashcard tournaments): cheaper and easier to align tightly with specific content
- **Spaced review games**: short games revisiting content from prior weeks rather than only the current lesson, exploiting spacing [Distributed practice improves retention.](../claims/distributed-practice-improves-retention.md) [+S]

### Target Learners
- K–12 learners across subjects, especially where cumulative knowledge (vocabulary, math facts, science terms) needs automating
- Learners motivated by social, fast-paced activity; use non-competitive variants for learners with test anxiety or low confidence
- Less effective as-is for advanced learners working on open-ended or conceptual goals, where rapid-fire recall questions undershoot the target complexity

### Target Learning Goals
- Consolidation and fluency of declarative knowledge: facts, definitions, vocabulary, procedures
- Formative diagnosis: revealing which content the class has and has not retained [Assessment for learning improves achievement.](../claims/assessment-for-learning-improves-achievement.md) [+S]
- Spaced re-exposure to previously taught material across a unit or term

### Instructions
1. Identify the content to be reviewed and write questions spanning difficulty levels, including items from earlier in the term ([Retrieval](../elements/retrieval.md))
2. Choose a game structure in which all learners respond to every item simultaneously — individual whiteboards, response cards, or a platform like [Kahoot!](https://kahoot.com) — rather than one where a single player answers per turn
3. Set rules that balance competition with safety: team rotation, points for improvement, or cooperative goals against a timer
4. Run the game with immediate feedback after each item; briefly reteach any item the majority missed before moving on ([Feedback](../elements/feedback.md))
5. Close with a short individual retrieval task (exit ticket, mini-quiz) so learning is checked without game scaffolds ([Assessment](../elements/assessment.md))

## Examples
- **[Kahoot!](https://kahoot.com)** — multiple-choice quiz game with simultaneous responses, music, and scoring; widely used for unit review. Its self-paced sibling mode removes the speed advantage.
- **[Quizizz](https://quizizz.com)** — self-paced quiz games with memes and leaderboards; individual pacing makes it suitable for anxious learners.
- **Trashketball** — teams answer content questions on whiteboards; correct answers earn a shot at a basket, decoupling most points from speed and adding movement.
- **Escape-room review** — teams solve content-locked puzzles to "escape," trading speed pressure for collaborative problem application.
