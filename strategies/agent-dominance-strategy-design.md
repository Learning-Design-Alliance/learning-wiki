# Design agents with adaptable dominance strategies to optimize user dominance behavior

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors propose that because social dominance is dyadic and can be shifted by changing a speaker's co-speaker or situation, an agent could be designed with dominance strategies that favor control and/or agreement. If the paper's hypotheses are supported, the next step would be "to design an intervention to determine a causal relationship and to see how students react to a robot or agent that can adapt its dominance behavior", potentially using entrainment-based detection of social power from prior work.

## Design Implications

### Context
#### Requirements
- Validated measures of user control and agreement scores, and evidence that these scores predict rapport and learning gains, before an adaptive intervention is designed.
#### Constraints
- The article presents only a preliminary analysis; no intervention or causal test of adapted dominance behavior has been conducted.

### Target Learners
- middle-school students interacting with pedagogical agents

### Target Learning Goals
- rapport-building and learning gains in human-agent tutoring dialogue
