# Trajectory-oriented assessment using prompt histories as process evidence

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article proposes assessing prompt trajectories rather than final answers: a rubric could examine 'the adequacy of initial framing, the quality of uptake, the function of follow-up prompts, representational coordination, distribution of epistemic labour, and justification of closure'. Prompt histories serve as process evidence only when combined with calculations, diagrams, code, data analyses, written explanations, and independent learning measures. Feedback should direct attention to 'epistemic regulation rather than surface formulation'.

## Design Implications

### Context
#### Requirements
- Prompt histories must be interpreted alongside disciplinary artefacts and independent learning measures
#### Constraints
- The rubric should not reward prompt length, rhetorical polish, or the number of iterations

### Target Learners
- STEM students in AI-mediated courses

### Target Learning Goals
- Retaining responsibility for validation and justified closure
- Responding to contradictions and coordinating representations
