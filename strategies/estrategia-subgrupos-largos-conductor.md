# Distribuir las mediciones entre subgrupos (cada uno con distintos largos del conductor) para potenciar la dimensión colectiva del trabajo científico

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Estrategia concreta de organización cooperativa dentro del enfoque de pequeñas investigaciones: como la práctica reformulada se vuelve muy larga si un grupo mide el campo para varios largos de conductor, se asigna un largo distinto a cada subgrupo y se intercambian los resultados. El artículo afirma que "esta propuesta permite la posibilidad de plantearle a distintos subgrupos de práctico y que cada uno trabaje con distintos largos del conductor", generando interacción entre equipos y modelando el carácter colectivo de la ciencia.

## Design Implications

### Context
#### Requirements
- Coordinación entre subgrupos para reunir y contrastar las series de datos completas
#### Constraints
- Aplicada al caso de la práctica del conductor recto; se plantea como posibilidad en ese contexto

### Target Learners
- Estudiantes de bachillerato trabajando en grupos de laboratorio

### Target Learning Goals
- Trabajo cooperativo e intercambio entre equipos, replicando la dimensión colectiva del trabajo científico
