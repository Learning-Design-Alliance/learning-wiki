# Establish a minimum passing standard for communication on the clinical skills examination by increasing the number of communication-assessed cases to approximately 10 to 14

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors recommend that licensing authorities set a minimum passing standard for patient-physician communication on the clinical skills examination, as has been done in the US Step 2 Clinical Skills Examination. Because the communication score's reliability was poor to moderate (Cronbach alpha 0.25-0.50), they state that "the number of cases in which communication is assessed would need to be increased from the 3 to 4 cases to approximately 10 to 14 to obtain a sufficiently reliable score to make pass-fail decisions." The MCC has already increased the number of communication cases to meet this reliability threshold.

## Design Implications

### Context
#### Requirements
- Increasing the number of communication-assessed cases from 3-4 to approximately 10-14 to obtain a sufficiently reliable score for pass-fail decisions
#### Constraints
- With only 3 to 4 communication-assessed cases, the communication score reliability (0.25-0.50) is too low for pass-fail decisions

### Target Learners
- medical graduates taking a national licensing clinical skills examination

### Target Learning Goals
- patient-physician communication competence assessed prior to entry into practice
