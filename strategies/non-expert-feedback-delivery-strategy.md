# Use non-expert instructors to deliver simulator feedback to broaden delivery options

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The review reports that in a three-armed RCT of simulated renal artery angioplasty, non-expert delivered feedback was still effective, which the authors state may broaden options for educationalists and time-pressed senior surgeons. Feedback from inexperienced surgical trainees produced outcomes comparable to consultant-delivered feedback on nearly all measures. The authors caution that one must be careful not to implement counter-productive feedback initiatives.

## Design Implications

### Context
#### Requirements
- Feedback content relevant to the exercise, including standard instrument metrics, procedural time and errors
#### Constraints
- Error scores were lower with expert feedback when using VIST error metrics (p=0.009), so expert input may matter for some metrics

### Target Learners
- surgical trainees in simulation-based training

### Target Learning Goals
- endovascular technical skill acquisition
- error reduction
