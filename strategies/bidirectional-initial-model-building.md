# Build the initial procedure model in either direction — checklist-first or local-insight-first — depending on available resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors note that their checklist-first approach can be reversed: "an equally valid alternative approach is to build this initial model in the opposite direction: use local insights and then extend it". This variant suits contexts where local practice should carry more weight or where no sufficiently detailed validated checklist exists. Either way, the initial model is then enriched through expert consensus.

## Design Implications

### Context
#### Requirements
- Either validated checklists with sufficient detail, or access to local expert insight as the starting point
#### Constraints
- The choice depends on whether local vision should be weighted more heavily and on checklist availability

### Target Learners
- medical residents
- procedure instructors developing curricula

### Target Learning Goals
- generating procedure breakdowns under varying resource and localisation conditions
