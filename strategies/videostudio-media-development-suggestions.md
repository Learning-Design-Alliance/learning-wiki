# Develop the media into standalone interactive multimedia with portable QuizCreator quizzes and combinations with other interactive media

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The authors' forward-looking recommendations for the developed media. They suggest making the Corel VideoStudio Pro-based media interactive so it does not require a teacher to explain the material, making the QuizCreator quizzes usable on any computer without installation, and combining the media with other interactive media to raise student interest. The article states the quizzes "can be used in any computer wit hout any installation".

## Claims

- [Interactive multimedia materials using Wondershare Quizcreator produced significantly higher posttest listening scores than audio materials in a quasi-experiment with 72 undergraduates](../claims/wondershare-quizcreator-multimedia-higher-posttest-listening.md) [+W]
- [Expert validators rated the Corel VideoStudio Pro X7-based media very valid (97.7% material expert, 76.5% media expert) and a limited trial group rated it 93.06%](../claims/corel-videostudio-media-expert-validation-ratings.md) [+W]
- [The experimental class XI AP1 averaged 90 on the posttest after using the media, versus 79.7 for control class XI AP2](../claims/corel-videostudio-posttest-experimental-90-control-79-7.md) [+W]
- [A limited group of six students rated the media 94.4% overall, categorized as very valid](../claims/limited-group-testing-94-4-percent-very-valid.md) [+W]
