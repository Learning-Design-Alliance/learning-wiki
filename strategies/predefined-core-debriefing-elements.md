# Predefine mandatory core debriefing elements for each simulation scenario to standardize knowledge consolidation

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Before the course, the authors predefined five mandatory core elements per scenario (e.g., for acute stroke: history taking with symptom onset time, initiating the code stroke, thrombolysis contraindications, blood pressure management, and imaging protocol review). "In each scenario, five mandatory core elements (detailed in Table 1) were predefined and had to be addressed and integrated into the debriefing session." These measures were implemented "to maintain a consistent and standardized debriefing and knowledge consolidation process" across instructors and scenarios.
