## Description
The article's design implication is that instructional designers should treat uncertainty as a meaningful condition of complex learning rather than designing it out. The abstract states the framework supports "informing the design and facilitation of problem-based, inquiry-based, and case-based learning tasks in which uncertainty is anticipated and supported as part of complex learning." Designers can use the framework's seven sources to locate where uncertainty will arise in a task and plan how learners will recognize, sustain, and productively resolve it.

## Design Implications

### Context
#### Requirements
- A framework that distinguishes uncertainty from its sources and manifestations, so environments can be designed to raise uncertainty intentionally, support learners in sustaining it, and guide productive resolution
#### Constraints
- The article states traditional schooling structures often privilege clarity and predictability, positioning uncertainty as an error state, which designers must counteract

### Target Learners
- learners in problem-based, inquiry-based, or case-based learning
- novice problem solvers

### Target Learning Goals
- managing uncertainty as a core problem-solving skill
- problem representation and justification
- metacognitive monitoring
