# Mix concept introductions, general discussion and hands-on software tutorials with close support to maximise pupil interaction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The session design strategy used in the pilot combined short introductions of basic astronomy concepts, open discussion, and hands-on software tutorials, with astronomers providing close support throughout, so that pupils were fully involved in the learning process. The article states sessions were planned "with the intention of encouraging questions from and maximising interaction with the students". Skills were first taught using images containing previously discovered stars or asteroids before pupils were given new images to search independently.

## Design Implications

### Context
#### Requirements
- Close support from astronomers during sessions; step-by-step written instructions in clear, simple language
#### Constraints
- Software designed for professional astronomers was sometimes too difficult, requiring one-on-one help

### Target Learners
- Key Stage 3 pupils new to scientific research

### Target Learning Goals
- Research-level astronomy skills
- independent scientific discovery
- questioning and engagement
