# Seven-step moderator sequence for introducing Quantum Port

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article prescribes an introduction sequence in which the moderator first understands quantum teleportation, then motivates the game with storytelling about Alice and Bob, introduces Circuit Cards by wire color, states circuit-building conditions, explains Moves and Turns, demonstrates the Dice Rule for winning, introduces Action Cards, and finally runs the Beginner setup before the Default setup. This sequence is intended so the player will be invested during the gaming session.
