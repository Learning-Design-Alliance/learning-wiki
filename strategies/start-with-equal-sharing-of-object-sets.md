# Begin fraction instruction with activities that involve dividing groups of objects equally

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
An implementable activity sequence in which students first divide sets of objects into equal shares. The presentation advises: "Begin with activities that involve dividing groups of objects equally," illustrated by a problem where four friends share 12 pretzels and each must get the exact number. Teachers then vary the number of sharers to require different partitioning.
