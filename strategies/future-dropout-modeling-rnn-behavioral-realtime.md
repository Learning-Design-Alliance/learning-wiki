## Description
The authors' future-research agenda specifies four extensions: recurrent neural networks to extract temporal patterns in student behavior; incorporation of behavioral data such as class participation and extracurricular engagement; deployment of a real-time monitoring system to proactively support at-risk students; and adding unit-level performance features such as assignment types, grades received, and class participation for deeper performance insight.
