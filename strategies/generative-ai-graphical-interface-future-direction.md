# Future development: integrate generative AI and a graphical interactive interface to lower the learning curve

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In the discussion the authors propose extending the system: 'Looking ahead, we can further integrate generative AI models and provide real-time data analysis code and case generation functions. By developing a graphical interactive interface, we aim to reduce the learning curve for non-information students.' This responds to the stated limitation that technical tools such as Python may deter non-technical students.
