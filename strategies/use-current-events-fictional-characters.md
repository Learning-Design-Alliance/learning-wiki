# Use Current Events & Fictional Characters

> **Strategy** · [All strategies](index.md)

## Description
This strategy embeds target content in real-world current events or in fictional characters, stories, and scenarios. Learners analyze a live news event, debate a decision facing a character, or carry out tasks *as* a persona, so abstract concepts arrive attached to concrete people, stakes, and narratives rather than as decontextualized facts.

## Design Implications

Narrative and situational context give learners a structure for organizing new information and increase situational interest, which sustains attention and engagement [Interest supports engagement and learning when it directs attention to content.](../claims/activation-improves-learning.md) [+M]. Anchoring instruction in a realistic event or scenario improves problem-solving transfer because learners encode knowledge in the context where it must later be used [Anchored instruction improves transfer by embedding knowledge in realistic problem contexts.](../patterns/anchored-instruction.md) [+M]. Fictional narratives additionally support social-cognitive outcomes: reading and reasoning about characters improves perspective-taking and empathy [Fiction reading improves empathy and perspective-taking.](../claims/fiction-reading-improves-empathy.md) [+M]. The context must do real instructional work — carrying the target concepts — rather than serving as decoration [Decorative illustrations do not improve learning.](../claims/decorative-illustrations-do-not-improve-learning.md) [-M].

### Context
#### Requirements
- A current event or narrative whose structure genuinely maps onto the target concepts ([Analogies](../elements/analogies.md))
- Explicit debriefing that connects the event or story back to the abstract content ([Class Discussion](../elements/class-discussion.md))
- Accurate, current source material for events; internally consistent scenarios for fiction
- A task that requires learners to reason *with* the context, not merely read about it ([Case Studies](../elements/case-studies.md))

#### Constraints
- Salient but irrelevant narrative details consume working memory and can distract from the target content, especially for novices [Seductive details reduce learning when they compete for attention with core content.](../claims/decorative-illustrations-do-not-improve-learning.md) [-M]
- Current events age quickly and may carry bias or incomplete information; outdated "current" events lose motivational force
- Learners may remember the story but not the concept if the debrief does not explicitly extract the generalizable principle [Case-based learning improves exam performance when cases are followed by explicit abstraction.](../claims/case-based-learning-improves-exam-performance.md) [~M]
- Fictional personas can oversimplify complex social issues, reinforcing stereotypes if characters are thinly drawn

#### Implementation Variability
- **News analysis**: learners apply course concepts to a live event (economics of a current policy debate, physics of a recent disaster)
- **Character framing**: a recurring fictional character (e.g., a persona in a statistics course) encounters each new problem type across the term
- **Role embodiment**: learners argue or decide *as* a character, combining this strategy with [Act It Out](../elements/act-it-out.md) and role play
- **Serial narrative**: a semester-long storyline whose episodes introduce each unit's problem context

### Target Learners
- Novices who lack real-world examples to connect to abstract content and benefit from a provided concrete anchor [Graphic organizers and provided supports help novice comprehension.](../claims/graphic-organizers-support-novice-comprehension.md) [+M]
- Learners with low initial interest in the domain, for whom narrative and relevance raise engagement [Situational interest can trigger engagement that develops into individual interest.](../claims/activation-improves-learning.md) [+W]
- Learners developing social-emotional competencies, where character perspective-taking is itself a target [Fiction reading improves empathy and perspective-taking.](../claims/fiction-reading-improves-empathy.md) [+M]

### Target Learning Goals
- Concept application: using disciplinary concepts to interpret real or realistic situations
- Transfer: encoding knowledge in the authentic contexts where it will be used
- Perspective-taking and empathy: understanding stakeholders and viewpoints
- Argumentation: taking and defending a position grounded in evidence from the event or narrative

### Instructions
1. Select or construct a current event or fictional scenario whose causal structure matches the target concept; verify the mapping is exact, not superficial ([Analogies](../elements/analogies.md)).
2. Present the event or story vividly but economically — enough detail to motivate, not so much that extraneous load dominates ([Cognitive Load Management](../principles/cognitive-load-management.md)).
3. Activate relevant prior knowledge before or during the encounter ([Activation](../principles/activation.md)).
4. Pose a task that requires learners to reason within the context: predict, diagnose, decide, or argue as a stakeholder or character ([Case-Based Learning](../elements/case-based-learning.md)).
5. Debrief explicitly: extract the generalizable principle and contrast it with other contexts so learners do not bind the concept to a single story ([Comparing Cases](../elements/comparing-cases.md) if available; otherwise structured discussion).
6. Assess with a *different* event or scenario to check that the concept transferred beyond the original context ([Application of Knowledge](../elements/application-of-knowledge.md)).

## Examples
- **The Jasper Woodbury Problem Solving series** (Vanderbilt) — video-based fictional adventures ("Rescue at Boone's Meadow") that anchor complex mathematics problem-solving in a narrative; the canonical anchored-instruction curriculum. See [Anchored Instruction](../patterns/anchored-instruction.md).
- **[What Were You Wearing?](https://www.facinghistory.org)** — Facing History and Ourselves uses historical current events and first-person narratives to teach ethical reasoning in secondary social studies.
- **Fictional persona in statistics** — courses that follow a recurring character (e.g., a public-health investigator) across the term, with each unit's dataset framed as her next case, so statistical procedures are learned as tools for her decisions.
- **News-based economics courses** — weekly analysis of a live policy event (inflation report, trade dispute) using the week's course concepts, replacing textbook vignettes with authentic stakes.
