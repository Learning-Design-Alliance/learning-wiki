# Graph-communication task in which groups recreate each other's graphs from written descriptions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Early in the course, two groups each received a printed labeled graph and had to describe it in writing so the other group could recreate it. Pupils discovered representations such as edge lists and their limitations, leading naturally to adjacency matrices and discussion of dense versus sparse storage. The authors judged: "This simple task was very successful because it clearly motivates the definition of a graph as node and edge set."

## Design Implications

### Context
#### Requirements
- Printouts of one dense and one sparse labeled graph
- Two separated groups able to exchange written descriptions
#### Constraints
- Edge lists alone cannot represent isolated nodes; an additional node set is required

### Target Learners
- high-school pupils unfamiliar with formal set notation

### Target Learning Goals
- graph representations (edge lists, adjacency matrices)
- the formal definition of a graph
