# Generate AI personalized learning guides via standardized MeSH-anchored prompts with expert review before release

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article's pipeline is replicable as a recipe: for each incorrect answer, extract the case's MeSH terms, send a standardized prompt to ChatGPT-4o requesting "a personalized learning guide that includes: (1) the correct answer and a brief explanation, (2) a summary of the key diagnostic concepts related to the MeSH terms, (3) learning objectives, and (4) suggested study resources". Every generated guide followed a standardized format and was reviewed by two independent board-certified oral and maxillofacial radiologists, with inaccuracies corrected before delivery to students.

## Design Implications

### Context
#### Requirements
- A standardized prompt template including case diagnosis and associated MeSH terms to ensure consistency in feedback generation
- Review of all generated outputs by two board-certified radiologists for correctness, completeness, and alignment with the assigned MeSH terms
#### Constraints
- No formal pilot validation was conducted prior to the intervention, as the article states

### Target Learners
- Fifth-year dental students

### Target Learning Goals
- Remediation of diagnostic knowledge gaps identified through incorrect test answers
