# Break complex tasks into smaller sub-tasks when completing programming work with AI assistance

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 causal, 1 qualitative), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
An implementable strategy for students using generative AI on programming assessments. Participants "typically started using ChatGPT by breaking down the task to several sub-tasks" and generating code per sub-task, and the article concludes "Students needed to be able to break down a complex task to smaller sub-tasks" because AI assistance was not really helpful for complex ones.

## Design Implications

### Context
#### Requirements
- Students need to be able to break down a complex task to smaller sub-tasks and to integrate and repair generated code
#### Constraints
- AI assistance was not really helpful for the complex ones
- the generated code was more complex than it should be, less readable, and might contain errors

### Target Learners
- students completing programming assessments with AI assistance

### Target Learning Goals
- completing programming tasks with AI assistance
- task decomposition
