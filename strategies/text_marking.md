# Text Marking

> **Strategy** · [All strategies](index.md)

## Description
Text marking asks learners to interact physically or digitally with a text while reading: underlining key claims, circling unknown vocabulary, numbering steps in an argument, or applying a symbol code (e.g., ✓ for evidence, ? for confusion, ★ for main idea). Unlike passive highlighting, effective text marking is governed by an explicit purpose or code, making it a generative activity that forces selection, evaluation, and organization of ideas [Annotating](../principles/annotating.md).

## Design Implications

Text marking converts reading from passive reception into generative processing: learners must decide *what* matters and *why*, which produces better comprehension and recall than re-reading or unstructured highlighting [~M]. The critical distinction is structure — unguided highlighting is among the least effective study techniques, largely because learners mark too much and confuse fluency with understanding [-S], whereas code-driven or question-driven marking that requires evaluation of the text yields reliable gains [+M].

### Context
#### Requirements
- A clear marking purpose tied to the learning goal (find the claim, trace the argument, locate evidence)
- A limited, taught symbol code or annotation scheme — learners must be shown how to mark before being asked to do it ([Modeling](../elements/demonstration.md) of an annotated text helps)
- Texts complex enough to reward marking; marking trivial texts adds effort without benefit
- A follow-up use for the marks (discussion, writing, [Summarization](summarization.md)) so annotation serves a downstream task

#### Constraints
- Unguided highlighting is weak: learners over-mark, and the motor act of highlighting creates an illusion of mastery without deeper processing [-S]
- Over-reliance on marking can substitute for the harder work of summarizing or self-explaining; marking should complement, not replace, [Self-Explanation](../elements/self-explanation.md)
- Excessive codes or categories overload working memory and degrade the reading itself [~M]
- Benefits shrink for skilled readers with strong domain knowledge, who already mark selectively and may find imposed codes constraining [~W]

#### Implementation Variability
- **Symbol codes** (e.g., Reading with Meaning routines, AVID's marking-the-text): consistent symbols for claims, evidence, transitions
- **Question-driven marking**: mark only what answers a given focus question
- **Structured annotation protocols**: sentence-level tasks such as numbering the steps of a procedure or bracketing an argument's premises and conclusion
- **Digital annotation**: tools like [Perusall](https://www.perusall.com) and [Hypothesis](https://web.hypothes.is) add social layers, letting learners see and respond to peers' marks

### Target Learners
- Adolescent and adult readers of disciplinary texts (science, history, legal, technical) where identifying argument structure matters [+M]
- Struggling or unselective readers who highlight everything; an imposed code forces discrimination [+M]
- Less suitable for beginning readers still decoding, for whom marking competes with basic word recognition [~W]

### Target Learning Goals
- Comprehension monitoring and identification of text structure
- Evidence selection in support of argumentation or writing tasks
- Close-reading disciplinary practices (what counts as a claim, a warrant, a counterexample)

### Instructions
1. Set a purpose: state the focus question or what readers should be hunting for.
2. Teach the code: show a short marked excerpt, thinking aloud about each mark ([Demonstration](../elements/demonstration.md)).
3. Limit the code to 3–5 symbols to protect working memory ([Cognitive Load Management](../principles/cognitive-load-management.md)).
4. Learners mark the text independently, applying the code ([Annotating](../principles/annotating.md)).
5. Use the marks: pairs compare and justify their markings, or marks feed directly into a writing or discussion task ([Collaborative Learning](../principles/collaborative-learning.md)).
6. Fade the code over time, shifting learners toward self-selected marking strategies ([Fading](../elements/fading.md)).

## Examples
- **AVID "Marking the Text"** — a college-readiness routine used across thousands of schools: number paragraphs, circle key terms, underline claims (https://www.avid.org)
- **Perusall** — social annotation platform where students' marks and comments on shared readings are visible to peers and graded for engagement (https://www.perusall.com)
- **Hypothesis** — open web annotation used in many university courses for collaborative markup of assigned readings (https://web.hypothes.is)
- **AP seminar / DBQ training** — students code document excerpts for sourcing and evidence before writing argumentative essays
