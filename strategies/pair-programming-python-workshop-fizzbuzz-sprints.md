# Three-hour paired-development Python workshop introducing the rubric through peer review and pair-programming sprints

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (2 for, 2 mixed) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
A 3-hour introductory workshop supporting the rubric, built on "a series of paired-development exercises". Students first peer-review a classmate's solution to a pre-class coding exercise, then an instructor-led discussion introduces the rubric with a live demonstration transforming bad code to good, and finally pairs do a FizzBuzz pair-programming exercise, acting alternately as programmer and reviewer in short sprints with the reviewer attending to structure and style.

## Design Implications

### Context
#### Requirements
- Pairs of students, a short pre-class coding exercise to review, and the assessment rubric introduced with a live demonstration during the workshop.
#### Constraints
- Trialled within the 2021-22 delivery of a single MSc programme; the article reports no formal evaluation of the workshop itself.

### Target Learners
- postgraduate space-science students learning to write code that communicates intent

### Target Learning Goals
- writing readable, well-structured code; professional collaboration skills for software teams
