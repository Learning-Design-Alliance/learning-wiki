# Adapt the E-5C model for fully online delivery by converting each of the 5Cs to a virtual equivalent

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that when learning moves online, each element of the E-5C model be re-specified for a virtual environment: "The first element will be inclusive online communication with accessible learning tools." The remaining elements become virtual collaboration with online community-building activities, tech-oriented curriculum using online resources and simulations, confidence-building in a virtual world with self-directed/paced learning, and digital career pathways via online resources, virtual guest speakers, and online mentors. The authors report the model thrived in the digital space with this slight modification.

## Design Implications

### Context
#### Requirements
- Synchronous Zoom sessions supplemented by asynchronous interactions via tools such as Edmodo
- Rich resources and tutorials provided to support self-learning between sessions
#### Constraints
- Due to limited synchronous meeting time, girls received only minimal programming instruction during synchronous sessions

### Target Learners
- K-12 girls in online after-school coding programs, elementary through high school

### Target Learning Goals
- Learn coding and computational thinking in a fully online environment
- Build confidence and independent learning skills remotely
