# Provide scaffolded code and live coding exercises, and integrate computation into every assignment and modeling cycle

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
To address debugging difficulty and skill loss between exposures, the authors report adopting "scaffolded code and performing live coding exercises, both of which are best practices from computer science education," and call for tighter integration of computational modeling into each assignment and modeling cycle. PhysUtil supports this by providing classes whose initialization lines can be given to students, limiting the code students must write.

## Design Implications

### Context
#### Requirements
- Tighter integration of computational modeling into each assignment and modeling cycle
#### Constraints
- Presently the length of time between exposures to VPython is too long, and students spend too much time relearning old programming skills

### Target Learners
- 9th-grade physics students with no programming background

### Target Learning Goals
- computational modeling of physical systems
- debugging computational models
