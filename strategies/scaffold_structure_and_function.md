# Scaffold Structure and Function

## Description
Provide students with the language tools, such as sentence starters and stems, necessary for project success. By analyzing the PBL project, you will uncover specific functions and structures of the language that students will need in order to succeed in the project.

## Design Implications

### Context
#### Requirements
- Identification of key language structures and explicit instructional strategies.
#### Constraints
- May limit creativity if scaffolds are too prescriptive.
