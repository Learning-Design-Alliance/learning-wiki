# Introduce each representation in context and provide visual aids before classroom use of Quantum Composer

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
For classroom use of Quantum Composer, the article gives teachers a four-part recipe: "we advise teachers ( i) to introduce each representation in the speciﬁc context before using the tool," potentially provide visual aids supporting information identification, extraction and integration, demonstrate beforehand how to reason with the information depicted in representations, and use simple training tasks to familiarize students with the features and interface. For tool developers it likewise recommends coding the same information in different representation types and providing scaffolding such as visual highlights of relevant elements.

## Design Implications

### Context
#### Requirements
- Time for introductory instruction on each representation before tool use
- Simple training tasks for interface familiarization
#### Constraints
- Addressed to Quantum Composer and similar interactive visualization tools; the article notes the studied static interface may not have been intuitive or most effective for all students

### Target Learners
- students using Quantum Composer in class
- novices in quantum mechanics

### Target Learning Goals
- information identification, extraction and integration from representations
- familiarity with simulation tool features and interface
