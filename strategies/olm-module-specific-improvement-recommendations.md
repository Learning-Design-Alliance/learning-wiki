# Use OLM log analysis to target module-specific improvements: instructional-material quality, assessment-problem quality, difficulty, and engagement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (2 associational), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The article's analysis yields per-module improvement directions: for modules 3, 8, and 9, "improvements should first focus on the quality of assessment problems, such as adding more distractors", while modules 7 and 5 call for improved instructional materials, module 6 needs more challenging assessment problems, and module 10's outcomes might benefit more from strategies that improve engagement. This lets instructors with limited time and resources direct incremental improvements toward the most needed changes each semester.

## Design Implications

### Context
#### Requirements
- Log-data analysis of an OLM sequence with embedded pre/post assessment outcomes, test-taking effort, and learning effort measures
#### Constraints
- The recommendations rest on a narrow effectiveness definition — the increase in students passing each module before and after learning — and on data from one course's OLM sequence

### Target Learners
- college students in calculus-based introductory physics

### Target Learning Goals
- mechanical energy concepts and problem solving
