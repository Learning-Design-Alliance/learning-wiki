Use data collaboratively through a structured data analysis process among educators¶

Strategy · All strategies Evidence · no claims cited

Description¶

This strategy positions data use as a collective sense-making activity rather than an individual task. The brief states that "Data are most powerful when they are used as part of a collective sense-making process among educators" and that working in a collaborative group with a structured data analysis process lets educators harness multiple perspectives and ideas and develop and implement responses more systematically to support improved learning outcomes.

Design Implications¶

Context¶

Requirements¶

  • A structured data analysis process and a collaborative educator group

Constraints¶

Target Learners¶

  • students served by educator teams analyzing data together

Target Learning Goals¶

  • improved learning outcomes through systematic responses to data

Related Strategies¶

  • Collective Data Analysis
  • Interrogate bias in data analysis by unpacking biases with colleagues and building skills to name bias in action
  • Use multiple, diverse data sources selected to offer distinct yet complementary information
  • Preliminary Data Collection
  • Keep students' lived experiences at the center of data use and ensure data reflect students' lives
