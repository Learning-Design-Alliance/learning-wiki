# Use Mathematica functions to computationally derive group-theoretic structures such as subgroups and character tables

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article demonstrates group theory by having students compute it: a user-defined IsSubGroup function builds a subset's multiplication table and tests closure, a ConjugacyClassesNames function enumerates conjugacy classes, and a ProduceCharTable function solves the orthogonality constraints for characters. The authors write "We will use Mathematica to continue the example from the previous chapter and try to obtain the character table using basic properties derived from group theory and representation theory."

## Design Implications

### Context
#### Requirements
- Prior definition of a matrix representation of the group in the notebook
#### Constraints
- The character-table procedure may yield non-unique degree lists, which are then eliminated using further criteria

### Target Learners
- Undergraduate and graduate physics students

### Target Learning Goals
- Subgroups, conjugacy classes, and character tables of finite groups
