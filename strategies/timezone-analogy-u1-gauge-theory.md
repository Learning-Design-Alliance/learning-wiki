# Use a timezone analogy to teach U(1) gauge theory: timezone choice as a symmetry, then gauging it so different timezones apply at different points in space, requiring a vector field

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
For classes unfamiliar with lagrangians, the article proposes using timezones as an example symmetry: the choice of timezone should not impact any physics experiment, so changing timezone represents a symmetry. The next step gauges the symmetry by insisting different timezones may be used at different points in space, which requires something telling how the timezone changes from point to point in all three directions — a vector field transforming like the electromagnetic potential. The similarity between this field and Aµ establishes electromagnetism as a gauge theory.

## Design Implications

### Context
#### Requirements
- Learners must first have the concept of symmetry introduced carefully, since the classroom conclusion was that more effort needs to be spent on introducing symmetry.
#### Constraints
- There is a weak point in why the vector-field should be allowed to be dynamic, though the article notes this is usually not touched in higher-level courses either; the analogy covers U(1) only.

### Target Learners
- high school teachers
- classes unfamiliar with lagrangians

### Target Learning Goals
- understand gauge symmetry
- understand why a local symmetry requires a vector field
- understand electromagnetism as a gauge theory
