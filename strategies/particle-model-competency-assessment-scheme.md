# Competency assessment through functional code, scientific documentation, visualizations, experimentation, creative extension and communication

## Description
Section 8 enumerates how the project allows evaluating STEM competency development: "C´ odigo funcional" (correct implementation of the algorithm), scientific documentation explaining underlying principles and observed results, effective visualizations, systematic experimentation over the parameter space, creative extension of the basic model, and clear communication of results and conclusions. This gives instructors six concrete assessment products tied to the interdisciplinary project.
