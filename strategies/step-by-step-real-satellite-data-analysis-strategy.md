# Step-by-step guided analysis of real satellite data with embedded questions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The activity is set up as a step-by-step instruction to analyse real satellite data, interspersed with questions that evaluate students' understanding and point to the relevance of the satellite data. Some tasks contain very similar and repeating procedures that are used to reinforce the steps used in the analysis. The sequence moves from reading and displaying data, through contrast adjustment and RGB/false-colour construction, to computing spectral-index maps, so learners build procedural fluency incrementally on authentic data.
