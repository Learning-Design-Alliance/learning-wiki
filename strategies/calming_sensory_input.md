# Calming Sensory Input

> **Strategy** · [All strategies](index.md)

## Description
Calming sensory input gives learners access to sensory experiences that reduce physiological arousal and support self-regulation: tactile bins filled with sand, rice, or beans; weighted blankets or stuffed animals for deep pressure; chewy pendants or crunchy snacks for oral input; and white noise or calming music for auditory regulation. The strategy treats regulation as a precondition for learning — a dysregulated learner cannot attend, encode, or persist — and embeds sensory regulation tools into the learning environment rather than treating dysregulation as misbehavior.

## Design Implications

Sensory regulation supports learning indirectly: by lowering anxiety and arousal, it frees attentional and working-memory resources for the task itself [Excessive cognitive load degrades learning outcomes.](../claims/cognitive-overload-degrades-learning.md) [+M]. Evidence for specific sensory tools is thinner than the popularity of "sensory" products suggests — deep-pressure and tactile interventions show moderate support for anxiety reduction, but claims about broad sensory-integration benefits for attention are weaker [~W]. The strategy works best when learners are taught *when and how* to use tools as part of a self-regulation routine, not simply given access to them.

### Context
#### Requirements
- A collection of sensory tools and activities (tactile bins, weighted blankets, chewy pendants, noise-reducing headphones)
- A designated calming space or portable "calm kit" for use at the learner's seat
- Clear guidelines and explicit teaching for appropriate use of sensory tools ([Coaching](../elements/coaching.md) on when to seek input)
- Learner choice among input types and intensities, since sensory preferences are highly individual

#### Constraints
- Evidence for sensory-based interventions as treatments for attention or learning difficulties is limited and contested; benefits are best documented for anxiety and arousal reduction, not academic outcomes [-W]
- Some learners find weighted items, textures, or oral tools aversive or over-stimulating — the same input that calms one learner dysregulates another [~M]
- Tools can become avoidance behavior or classroom distraction if use is unstructured and unmonitored [-M]
- Some materials are expensive, require hygiene maintenance, or pose allergy and choking-safety concerns
- Over-reliance can substitute for teaching self-regulation skills rather than building them

#### Implementation Variability
- Whole-class access (a calm corner or sensory shelf) vs. individualized tool kits specified in an [Accommodations](../elements/accommodations.md) plan
- Scheduled sensory breaks vs. on-demand access chosen by the learner
- Passive input (weighted lap pad during seatwork) vs. active input (brief movement or tactile break between tasks) — active breaks have stronger attention evidence [Classroom physical activity improves attention.](../claims/classroom-physical-activity-improves-attention.md) [+M]

### Target Learners
- Learners with sensory sensitivities, autism, ADHD, or anxiety who show elevated arousal that interferes with participation [~M]
- Young children still developing self-regulation capacity
- Learners in high-stress moments (testing, transitions) where arousal reduction supports performance [~W]
- Not uniformly beneficial: learners without sensory or regulation needs typically gain little, and unstructured access can reduce engagement for them [-W]

### Target Learning Goals
- Self-regulation: recognizing arousal states and selecting tools to manage them
- Behavioral readiness: returning to task after dysregulation
- Reduced anxiety in evaluative or over-stimulating contexts

### Instructions
1. Identify learners' sensory profiles and triggers through observation, [Check-Ins](../elements/check-in.md), and family or specialist input.
2. Assemble a varied tool set (tactile, deep-pressure, oral, auditory) so learners can match input to need rather than receiving one prescribed tool.
3. Explicitly teach when and how to use each tool, framing it as regulation, not reward or escape ([Coaching](../elements/coaching.md)).
4. Establish clear norms for use — duration, location, and return-to-task signal — to prevent tools from becoming avoidance.
5. Pair sensory input with a regulation strategy (breathing, labeling the feeling) so learners build internal skills, not just tool dependence.
6. Review effectiveness regularly and fade or adjust tools as learners develop self-regulation.

## Examples
- A primary classroom maintains a "calm corner" with a weighted lap pad, noise-reducing headphones, and a rice bin; learners self-refer using a visual regulation chart and return with a timer.
- An occupational therapist embeds chewy pendants and scheduled movement breaks into a student's IEP [Accommodations](../elements/accommodations.md) plan, fading intensity as regulation improves.
- A secondary exam room offers white noise via headphones and stress balls during assessments to reduce test anxiety.
