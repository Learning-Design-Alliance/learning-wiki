# Integrate mastery learning principles into fixed-sequence simulation courses so trainees master earlier modules before progressing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors recommend that simulation courses with fixed module time adopt mastery learning, which "holds that trainees should master current content before progressing to new material". Because each module's training time was fixed and carried out in sequence, trainees who failed to master earlier modules still advanced, which the authors speculate posed greater challenges for inexperienced trainees with low baselines. The strategy is to restructure the course so progression depends on demonstrated module mastery.

## Design Implications

### Context
#### Requirements
- Module-specific mastery assessments (expert-established mastery levels per module); flexibility to provide additional practice or adjust progression based on mastery status
#### Constraints
- The evaluated course used fixed module hours in sequence, so this strategy is a proposed redesign rather than a tested manipulation

### Target Learners
- Inexperienced residents with low baseline skill
- Experienced residents seeking standardized proficiency

### Target Learning Goals
- Reaching mastery learning level across all obstetric ultrasound task modules
