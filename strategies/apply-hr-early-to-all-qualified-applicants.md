# Apply holistic review early so every qualified candidate receives a holistic file review before interview selection

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends positioning holistic review at the qualified-applicant-pool sorting stage rather than only at the interview stage. In the 2021–2022 cycle, "HR was applied early in the application process so that every qualified candidate received a holistic file review", whereas the prior cycle applied HR strategies only to interviewees. This placement was associated with equitable narrowing of the pool.

## Design Implications

### Context
#### Requirements
- Resources to complete a holistic file review for every qualified applicant
#### Constraints
- Generalizability is restricted by the single-program, observational before-and-after design

### Target Learners
- Qualified applicants to physical therapist education programs

### Target Learning Goals
- Equitable admission sorting that mitigates bias against racial and ethnic minority applicants
