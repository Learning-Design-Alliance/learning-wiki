# Use theoretical task analysis and individual talk-aloud interviews to develop and refine tutorials

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Before full deployment, each pre-test, tutorial and post-test was administered to five students individually who talked aloud while working, and the tutorials were revised after each administration. This was grounded in a theoretical task analysis: "making a ﬁne-grained ﬂow chart of the concepts involved in solving speciﬁc class of problems," which "can help identify stumbling blocks where students may have difﬁculty." The iterative cycle fine-tuned organization and flow.
