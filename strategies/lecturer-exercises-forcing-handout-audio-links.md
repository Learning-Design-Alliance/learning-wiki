# Lecturer-set exercises forcing explicit links between course handouts and lecture audio to grow the tag set

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors design lecturer-set exercises that 'require the students to make explicit the links between course handouts and lecture audio, so forcing an increase in the number of tags'. The intent is that enough accumulated tags create value in the tag set, so that students interact with them enough to 'cross a threshold to spontaneously adding more', aligning the system's interaction model with students' existing study habits.

## Design Implications

### Context
#### Requirements
- Exercises must force explicit link-making between course handouts and lecture audio, and enough tags must accumulate to create value in the tag set.
#### Constraints
- The article reports these as designs for the coming session, not yet trialled with students.

### Target Learners
- university students in lecture courses

### Target Learning Goals
- linking lecture notes and handouts with lecture audio; intellectual reprocessing of lecture content
