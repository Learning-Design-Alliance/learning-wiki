# Design simulation tasks and equipment setup to keep virtual content in the comfort zone and minimize user discomfort

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends that designers of HoloLens-based surgical simulators deliberately engineer the physical setup and task timing so that virtual content stays within the ergonomic comfort zone and head tilt remains sustainable. The authors state that "an optimal design of the simulation tasks and the simulation setup (time for each task, height of the surgical table, distance of user interaction) are required to minimize the user discomfort." They additionally advise attention to AR viewfinder design (shape, colour, transparency) to ease instrument alignment.

## Design Implications

### Context
#### Requirements
- Control over task duration, surgical table height, and user interaction distance so virtual content appears in the optimal/comfort zone for most of the simulation period
#### Constraints
- Alignment is already impaired by focus rivalry between physical and virtual content; discomfort from the vergence-accommodation conflict grows when content cannot be placed near 2.0 m

### Target Learners
- designers of mixed-reality surgical simulators
- orthopaedic trainees using such simulators

### Target Learning Goals
- sustained comfortable engagement in AR-based surgical skills practice
