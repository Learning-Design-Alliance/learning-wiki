# Preserve data integrity through input checks, deduplication, backups and access controls before deploying IoT

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that risks be addressed before implementing any technology that heavily deals with personal or academic student data. To preserve data integrity it lists implementing checks on errors when data is entered or transferred, removing duplicate and redundant files, backing up data (critical during a ransomware attack), and access controls so only authorized sources can access sensitive data.
