# Letter Names and Letter Sounds Instruction

## Description
Explicit and direct instruction of letter names and letter sounds, which is critical for early literacy development. Children need to learn the letter names and the letter sounds in kindergarten. Letters should be taught directly and systematically. Older poor spellers should be asked to write the alphabet in order,accurately, and quickly.

## Design Implications

### Context
#### Requirements
- Alphabet charts, letter cards, phonics materials, direct instruction
#### Constraints
- Requires explicit and systematic instruction, may not be effective for learners with severe cognitive deficits
