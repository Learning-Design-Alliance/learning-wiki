# Design student software to reach a large fraction of expert output quality with a small fraction of the steps

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
For astrophotography in AgA, the team set an explicit usability-quality tradeoff target: "Our goal is for students to be able to achieve ≈85% of the quality of, e.g., something that might be accepted to NASA's Astronomy Picture of the Day, but with only ≈15% of the steps/complexity." Rather than adopting existing packages with steep learning curves, they built student-appropriate capabilities into the tool students already use.
