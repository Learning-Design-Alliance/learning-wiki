# Future integration pathways: WebGL builds, the Ultra Extension Framework, and AI-generated personalized hypergamifications

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper's forward-looking recommendations for extending the prototype: building Unity games for WebGL, leveraging Blackboard's Ultra Extension Framework premium APIs for navigation and behavior data and UI modification, exploring cooperative multiplayer play, and using generative AI to automate hypergamification generation. The authors write that "Leveraging this framework could help a more se amless integration of Unity games built for the WebGL target platform with Blackboard" and propose exploring automated, personalized course hypergamifications.

## Design Implications

### Context
#### Requirements
- Access to Blackboard's Ultra Extension Framework premium APIs and generative AI methods for game development
#### Constraints
- Recommended pathways are untested proposals; the demo game does not utilize multiplayer capabilities

### Target Learners
- higher education students
- educators and game developers co-designing course games

### Target Learning Goals
- seamless in-game access to LMS content and personalized game-based course experiences
