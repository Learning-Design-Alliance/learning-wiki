# Pepperoni Pizza

## Description
Pepperoni Pizza is a concrete-representational game for early multiplication. Children roll a die twice: the first roll determines how many pizzas to draw, the second determines how many pepperonis to place on each pizza. Children then write the corresponding number sentence (e.g., 4 × 3 = 12) to answer "How many pepperonis in all?" The game converts the abstract structure of multiplication — equal groups — into a drawable, countable representation.

## Design Implications

The game exploits the concrete-representational-abstract progression: physical/drawn models build the equal-groups schema that symbolic multiplication notation presupposes [Concrete representations support early arithmetic learning when systematically faded toward symbols.](../claims/chunking-reduces-working-memory-load.md) [+M]. Because each roll generates a fresh problem, children repeatedly map between a situation (groups of items), a model (drawn pizzas), and a symbol (number sentence), which supports schema formation rather than rote recall alone. The random dice element adds engagement and variability, but the mathematical ceiling is fixed by the die faces.

### Context
#### Requirements
- Dice (standard six-sided or numbered) and paper/pencils for drawing
- A recording convention for the number sentence, modeled before play ([Demonstration](../elements/demonstration.md) of one full round)
- Time for children to count and verify their drawings against the sentence

#### Constraints
- Limited to multiplication facts within the range of the dice used (typically 1×1 through 6×6) [-W] — the game cannot by itself extend fluency beyond the dice range
- Drawing many items becomes slow and error-prone for larger products, shifting attention from mathematics to artwork [-W]
- Repeated equal-groups drawing does not develop the array or area model of multiplication, which supports commutativity and later multiplicative reasoning [-M]
- If children always count pepperonis one-by-one, the activity can reinforce additive counting rather than multiplicative strategies [-M]

#### Implementation Variability
- Use ten- or twelve-sided dice, or child-made spinners, to widen the fact range
- Replace drawing with physical counters on paper plates to speed up rounds and emphasize grouping
- Ask children to write both related sentences (4 × 3 and 3 × 4) and compare the drawings to introduce commutativity
- Progress to drawing arrays (rows of pepperonis) instead of separate pizzas as a bridge to the area model

### Target Learners
- Primary school children (typically ages 6–9) encountering multiplication for the first time
- Learners who benefit from concrete or pictorial support before symbolic work; manipulative-based instruction shows the strongest effects for younger learners [Manipulatives benefit learning most when learners actively connect them to underlying concepts.](../claims/chunking-reduces-working-memory-load.md) [+M]
- Less valuable for learners who already have fluent fact recall, for whom the drawing adds extraneous load without new learning [-W]

### Target Learning Goals
- Conceptual understanding of multiplication as equal groups
- Early multiplication fact fluency within the dice range
- Translating between situations, drawings, and number sentences (representational fluency)

### Instructions
1. Model one complete round aloud: roll, draw, count, and write the sentence ([Demonstration](../elements/demonstration.md))
2. Children roll the first die and draw that many pizzas
3. Children roll the second die and draw that many pepperonis on each pizza
4. Children write the number sentence and find the total, then verify by counting
5. Partner or teacher checks the sentence against the drawing and gives corrective feedback ([Practice](../elements/practice.md))
6. Repeat rounds; vary dice or representation as fluency grows

## Related Strategies
- Array-based multiplication activities — the natural next representation after equal groups
- Fact-fluency drill games — Pepperoni Pizza builds the concept that fluency practice presupposes

## Examples
- Roll a 4, so draw 4 pizzas. Roll a 3, so put three pepperonis on each pizza. Write 4 × 3 = 12, indicating there are 12 pepperonis in all.
- A Year 3 class plays in pairs with ten-sided dice; the teacher circulates, asking "How many groups? How many in each group?" to keep attention on the multiplicative structure rather than counting.
