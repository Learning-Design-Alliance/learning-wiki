# Pepperoni Pizza

## Description
A game where children roll a dice twice. The first roll tells them how many pizzas to draw, and the second roll tells them how many pepperonis to put on each pizza. They then write the number sentence that will help them answer the question, 'How many pepperonis in all?'

## Design Implications

### Context
#### Requirements
- Dice and paper for drawing
#### Constraints
- Limited to multiplication facts within the range of the dice used
