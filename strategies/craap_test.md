# CRAAP Test

## Description
Teach kids how to confirm the credibility of a website with a scoring guide like the CRAAP test worksheet (Yup, this is a real evaluation tool!). CRAAP stands for “currency,” “relevance,” “authority,” “accuracy” and “purpose.” Students score websites on things like domain, spelling and grammar, authors listed, and dates updated.
