# Analyse detailed simulation interaction logs to identify learning challenges and improve simulation design, especially in distance-learning scenarios

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors recommend analysing the detailed log of all user interactions with a simulation, which 'could provide insight into possible learning challenges or issues with navigating the simulation'. They add that in distance-learning scenarios, where such feedback is even more valuable, the learning analytics extension 'could help inform and improve simulation design'. These are the authors' stated expectations rather than evaluated outcomes.

## Design Implications

### Context
#### Requirements
- A detailed log of all user interactions with the simulation must be recorded by the extension.
#### Constraints
- The stated value is framed for distance-learning scenarios; the paper reports no study testing design improvements resulting from log analysis.

### Target Learners
- distance-learning students using simulations
- instructors and learning designers

### Target Learning Goals
- identifying learning challenges during simulation use
- improving simulation and navigation design
