# Use MESA-Web in courses lacking computing prerequisites by having students explore pre-generated and self-run models

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
In Stony Brook's upper-level AST 341 Stars and Radiation course, students had no computing prerequisite, so installing MESA was deemed inappropriate; instead they were given MESA-Web models to explore and encouraged to run their own. Output was converted to columnar data with py_mesa_reader since students might lack Python experience. The assignment had students verify trends discussed in class against the course textbook.

## Design Implications

### Context
#### Requirements
- MESA-Web access plus conversion scripts (py_mesa_reader) so students can work with columnar data without prior MESA or Python installation
#### Constraints
- The instructor generated a few models in advance to ensure data existed without overloading MESA-Web

### Target Learners
- upper-level astronomy majors without computing prerequisites

### Target Learning Goals
- verifying stellar structure and evolution trends from a textbook against computed models
