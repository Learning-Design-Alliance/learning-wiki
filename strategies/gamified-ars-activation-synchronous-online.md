# Use a gamified audience response system in the synchronous online phase to activate students

> **Strategy** · [All strategies](index.md)

## Description
A specific implementable recipe from the article: during the synchronous online session, repeatedly prompt students to answer questions about the event using a gamified audience response system. The article states "The gamified Audience Response System (ARS) Kahoot! was used to activate students", describing it as an online quiz system with points, badges and leaderboards, and notes the positive effect of gamification has been shown in several studies. Quiz questions then seeded discussions about the patient case and teaching content.
