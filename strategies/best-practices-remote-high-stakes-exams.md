# Adopt concrete best practices when running remote or semi-remote high-stakes examinations: dummy exams, user guides, rehearsals and onsite IT support

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends a set of implementable practices drawn from its own experience and from Hillier and Fluck's discourse on high-stakes e-examinations, advising organisers 'to avoid pedantry over software and hardware and instead focus on establishing and adhering to best practices'. These include providing an equivalent environment for all candidates, availing students of a dummy examination for practice, and provision of user guides. The authors' own examination added comprehensive briefing sessions, live rehearsals a week before to test connectivity, coexaminers from different hospitals, and an onsite IT technician.

## Design Implications

### Context
#### Requirements
- An equivalent technological environment for all candidates
- Familiarity with the remote technology among candidates and examiners before the examination
#### Constraints
- Technology hitches are common; the authors' own examination suffered a 2-minute loss of communications in two viva voce rooms
- Holding examinations remotely with candidates at home is not ideal because equity depends on home environments and internet access

### Target Learners
- specialty trainees sitting licencing examinations
- final-year medical students

### Target Learning Goals
- fair, secure, standards-consistent remote high-stakes assessment
