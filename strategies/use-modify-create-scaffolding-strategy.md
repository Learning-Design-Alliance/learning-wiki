# Use → Modify → Create scaffolding strategy to navigate tensions between personal and disciplinary authenticity

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends scaffolding authentic data science activities through the Use → Modify → Create strategy, which it describes as providing "scaffolded exposure to the practices as students build confidence and is an effective strategy for navigating such tensions." Students first execute predefined programs, then modify parts of them, and finally develop new programs querying datasets based on their interests, as with the IMDb Top 100 Movies API. This graduated structure lets students approach complex disciplinary practices while remaining situated in their interests.

## Design Implications

### Context
#### Requirements
- Structured scaffolds such as guided questions, tool walkthroughs, and sample programs
- A curated list of APIs aligned with different areas of interest
#### Constraints
- Offered as one way to tackle the tension between personal motivation and technical frustration with tools like EduBlocks and RapidAPI

### Target Learners
- high school students novice to programming and data science

### Target Learning Goals
- foundational computational data retrieval and manipulation skills
- confidence in disciplinary data science practices
