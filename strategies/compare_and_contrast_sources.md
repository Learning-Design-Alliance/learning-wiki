# Compare and Contrast Sources

## Description
Present learners with multiple sources on the same topic and have them compare and contrast the information presented. Encourage them to consider the information conveyed through photographs and other images as well as text. To aid their work, ask questions such as: When was each page created or updated? What is similar or different about the images on each page? What is the main idea or reason behind each page? What seems to be the author’s purpose on each page?

## Design Implications

### Context
#### Requirements
- Multiple sources on the same topic, guiding questions, and worksheets.
#### Constraints
- Requires time and effort. Some students may need additional support to analyze and compare sources effectively.
