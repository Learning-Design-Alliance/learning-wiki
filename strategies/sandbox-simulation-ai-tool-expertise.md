# Develop AI tool use expertise through simulation exercises in sandbox environments with tool prototypes

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article proposes simulation-based acquisition of AI tool use skills: 'Expertise in using AI tools can be developed using simulation exercises within sandbox environments using tool prototypes.' Beyond skill-building, these activities let physicians suggest interface or visualisation changes, foresee tool effects on clinical workflows, and inform regulatory approaches to AI tools. This strategy applies to human-computer task execution and workflow adaptation competencies in the use-of-AI-tools domain.

## Design Implications

### Context
#### Requirements
- Access to tool prototypes and sandbox environments before live deployment
#### Constraints
- Sandbox exercises precede deployment and do not by themselves establish real-world performance

### Target Learners
- practising physicians
- clinical teams adopting AI tools

### Target Learning Goals
- operating AI tools with mastery and efficiency
- adapting workflows to AI tool implementation
