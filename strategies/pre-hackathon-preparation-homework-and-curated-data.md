# Assign pre-hackathon homework, curated datasets, and virtual preparation meetings to accelerate on-site work

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Before each event, facilitators began meeting about six months prior to plan technical and learning goals, and "assigned homework to the participants related to the goals of that event, and provided links to relevant online resources including Python tutorials and example codes." The authors note this type of pre-event engagement "has been shown to improve hackathon success"; by Year 2, curated datasets were distributed about a month in advance.
