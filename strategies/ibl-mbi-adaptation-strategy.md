# Adapt the demonstration within Inquiry-Based Learning (IBL) or Model Based Inquiry (MBI) lesson structures

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors recommend situating the demonstration in inquiry-oriented teaching: "The proposed demonstration can be adapted and implemented in the classroom using either Inquiry-Based Learning (IBL) or Model Based Inquiry (MBI) strategies." They describe both approaches as suitable mechanisms to allow students to develop a deep understanding of abstract concepts.

## Design Implications

### Context
#### Requirements
- Instructors adapt the demonstration within an IBL or MBI lesson structure rather than as a standalone demonstration
