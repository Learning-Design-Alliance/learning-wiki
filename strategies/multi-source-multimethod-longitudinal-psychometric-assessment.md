# Evolve leadership assessment through multi-source, multimethod, longitudinal, psychometric, and effect-isolating practices

## Description
Following Hoole and Martineau's summary of best practices, the article recommends five evolutions in assessment methods and metrics: multi-source data, multimethod triangulation, longitudinal tracking, psychometrically validated measures, and isolating program effects. It argues that "Validity within outcomes assessment can be enhanced via triangulation, which can also provide a fuller picture for stakeholders," and warns against relying purely on self-report data.

## Design Implications

### Context
#### Requirements
- Assessment plans should be explicitly matched to program outcomes so that the assessment data provide meaningful information
