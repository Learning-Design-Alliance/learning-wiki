# Add a simulated student agent to collaborative systems to intervene in off-topic, passive, and learning-problem situations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article's implementable move is to add a Simulated Student, carrying the architecture's detection features, to a collaborative synchronous learning system so that negative collaboration situations are detected and avoided. The experiment in the programming-learning system showed the agent worked correctly in the majority of situations, which the authors take as evidence the approach is adequate for avoiding negative situations.

## Design Implications

### Context
#### Requirements
- A synchronous collaborative learning system in which the simulated student can participate
- The simulated student must implement the architecture's features for the three negative situations
#### Constraints
- The experiment showed correct operation in the majority, not all, of the situations

### Target Learners
- students learning collaboratively, e.g., in programming courses

### Target Learning Goals
- reducing off-task conversation
- encouraging passive students to participate
- addressing students' learning problems during collaboration
