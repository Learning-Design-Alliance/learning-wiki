# Balanced Assessment System

## Description
A balanced assessment system deliberately coordinates three assessment types — formative (day-to-day evidence gathered during instruction), interim (periodic checks used to adjust instruction across weeks or units), and summative (end-of-unit or end-of-course evaluations of achievement). The design goal is coherence: each layer answers a different decision question, and the system as a whole feeds instructional decisions rather than merely documenting outcomes. Most of the system's instructional value comes from the formative layer [Assessment for learning improves achievement when evidence is actually used to adjust teaching.](../principles/assessment-for-learning.md) [+S].

## Design Implications

A balanced system works when assessment is treated as a decision-support tool, not a reporting pipeline. Formative assessment embedded in instruction produces some of the largest achievement effects in educational research, but only when teachers act on the evidence and learners receive information about how to improve [Formative feedback improves learning when it specifies the gap and how to close it.](../principles/assessment-for-learning.md) [+S]. Feedback is most effective when it targets the task and the learning process rather than the learner's global ability [Feedback most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S].

### Context
#### Requirements
- A coherent map of which assessment answers which decision question (in-the-moment adjustment, unit-level reteaching, program-level evaluation)
- Clear learning targets shared with learners, so formative evidence can be interpreted against an expectation ([Assessment](../elements/assessment.md) aligned to visible criteria)
- Time and structures for teachers to analyze interim data and plan responsive instruction
- Feedback routines that convert assessment results into actionable next steps ([Check-In](../elements/check-in.md), [Coaching](../elements/coaching.md))

#### Constraints
- Interim and summative assessments consume instructional time; over-assessment crowds out the formative interactions that drive learning [-M]
- Interim benchmark data arrives too late to shape the lesson where a misconception forms — only in-the-moment formative checks can do that [~S]
- Poorly aligned interim assessments (testing items not yet taught) generate noise that erodes teacher trust in the system [-M]
- Data dashboards without protected time for collaborative analysis rarely change instruction [-W]

#### Implementation Variability
- Formative layer can range from embedded checks ([Practice](../elements/practice.md) with feedback, exit tickets, [Check-In](../elements/check-in.md) routines) to formal classroom assessment cycles
- Interim assessments may be curriculum-embedded (unit tests reused as benchmarks) or externally designed; curriculum-embedded items align better with instruction
- Summative layer may use traditional tests or [Competency-Based Assessment](../principles/competency-based-assessment.md) structures in which learners demonstrate mastery when ready

### Target Learners
- All learners benefit, but the largest gains accrue to lower-achieving students, for whom frequent feedback and instructional adjustment matter most [Formative assessment practices show the largest effects for low achievers.](../principles/assessment-for-learning.md) [+S]
- Learners who struggle to self-assess need explicit criteria and exemplars to use feedback productively
- Advanced learners benefit when the system supports acceleration decisions rather than only remediation

### Target Learning Goals
- All goal types are served, but the system is most powerful for goals requiring instructional adjustment: conceptual understanding and skill development
- Learner self-regulation: involving students in interpreting their own evidence builds evaluative judgment [Fading support promotes transfer of responsibility.](../claims/fading-support-promotes-transfer-of-responsibility.md) [+M]
- Data literacy for educators: interpreting evidence to make grouping, pacing, and reteaching decisions

### Instructions
1. Define learning targets for the unit and make success criteria visible to learners ([Assessment](../elements/assessment.md))
2. Embed short formative checks in every lesson — questions, tasks, or [Check-In](../elements/check-in.md) routines — and adjust instruction in the moment
3. Administer interim assessments at unit boundaries; analyze results in teams to plan reteaching or extension
4. Deliver feedback at the task and process level, with specific next steps [Feedback most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S]
5. Use summative assessment to evaluate achievement and to audit whether the formative and interim layers predicted it well
6. Involve learners in tracking their own progress against criteria, gradually transferring responsibility for evaluation [Fading support promotes transfer of responsibility.](../claims/fading-support-promotes-transfer-of-responsibility.md) [+M]

## Related Strategies

- [Competency-Based Learning](../patterns/competency-based-learning.md) — an alternative summative architecture in which the system certifies mastery rather than ranking

## Related Elements
- [Assessment](../elements/assessment.md) — the core element; every layer of the system is an instance of it

- [Coaching](../elements/coaching.md) — the interpersonal channel through which feedback becomes instructional adjustment

## Examples
- **[Khan Academy](https://www.khanacademy.org)** — mastery-based practice items act as continuous formative assessment; dashboards surface class-wide evidence teachers can use for regrouping, and unit tests serve as the interim layer.
- **[NWEA MAP Growth](https://www.nwea.org/map-growth/)** — a widely adopted interim assessment designed to be administered 2–3 times per year and interpreted alongside classroom formative evidence.
- **Assessment for Learning project (UK)** — Black and Wiliam's work with teachers embedding minute-to-minute formative checks (no-hands questioning, comment-only marking, peer/self-assessment) demonstrated large achievement gains from strengthening the formative layer alone.
