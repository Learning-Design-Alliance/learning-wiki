# Engineer purpose-built solutions using fit-to-context analysis and a Heilmeier Catechism-style question set

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Teams should identify use cases that fit the solution being designed and collect information about key context factors for implementation, such as technology systems, academic schedules, and policies, while accounting for developmental appropriateness — for example, whether an AI tool is appropriate for young children. The note adapts a set of eight questions inspired by the Heilmeier Catechism, asking whether stakeholders see the problem as pressing, what the theory of change is, whether users believe the solution is worth trying and fits existing routines, which core components are essential, which assumptions need testing before building, and what evidence exists that the solution could scale to have broad and meaningful effects on the US education system.

## Design Implications

### Context
#### Requirements
- Answers to the eight-question set before and during solution development, including identification of assumptions needing testing before building
#### Constraints
- Developmental appropriateness and feasibility must be assessed for users of particular age ranges

### Target Learners
- education technology and solution development teams

### Target Learning Goals
- designing solutions that fit real implementation contexts and serve historically underserved students
