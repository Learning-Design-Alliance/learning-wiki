# Gain Attention Before Giving Instructions

## Description
Use techniques such as clapping or knocking to signal students to stop, look, and listen before giving instructions.

## Design Implications

### Context
#### Requirements
- Consistent implementation of the chosen signal.
#### Constraints
- Signal may become ineffective if overused.
