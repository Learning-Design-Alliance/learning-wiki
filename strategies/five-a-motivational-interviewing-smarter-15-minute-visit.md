# Teach a 15-minute-visit obesity management workflow using the 5A approach, motivational interviewing, and SMARTER goal setting

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The module ends with practical recommendations for the busy primary care provider managing obesity in a 15-minute visit, combining the 5A approach, motivational interviewing for lifestyle changes, SMARTER goal setting, and online tools for lifestyle changes. This gives learners an implementable workflow for real clinic constraints.

## Design Implications

### Context
#### Requirements
- Learners should have completed the guideline and evidence sections of the module first
#### Constraints
- Designed for a busy outpatient primary care environment

### Target Learners
- Medical students
- primary care residents and physicians

### Target Learning Goals
- Counseling patients on lifestyle change
- structuring brief obesity management visits
