# Stratified randomization on baseline performance to ensure equivalent experimental and control groups

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (6 for, 1 against) · 7 studies (7 causal), `q2` · 0 of 7 report an effect size · 7 claims rest on one study

## Description
This allocation strategy balances groups on initial performance before the intervention begins. The protocol recommends assigning participants "only after (not before) the analysis of baseline performances", using a combined measure of baseline error rates in the visual and writing tasks to rank children into performance strata (for instance high, medium, and low performers), then randomly assigning within each stratum so high performers are equally distributed across groups. This prevents baseline differences from explaining post-intervention changes in either direction, including ceiling-effect confounds in control groups.

## Design Implications

### Context
#### Requirements
- Baseline tasks must be administered before training begins, and participants must not be assigned to groups until baseline performance has been analyzed.
#### Constraints
- The number of children across groups should be equivalent; the combined measure is specific to the visual and writing error-rate tasks used here.

### Target Learners
- School children in early literacy studies (5-7 year old first graders in this protocol)

### Target Learning Goals
- Causal measurement of intervention effects on literacy outcomes
