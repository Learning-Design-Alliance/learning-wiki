# Use a network simulator to simplify big network data into a single computer program

## Description
In Phase 1, the authors introduce Big Data through a software simulator for mobile networking that presents connected network devices graphically. Students retrieve critical content such as IP addresses and locations, allocate resources to mobile devices by solving linear equations, and implement the equations by programming, with results displayed in the simulator. The authors report this "provide[s] undergraduate students a unique opportunity to use experimental technologies to be adaptively involved in learning complicated Big Data problems".
