# Adopt a first-year research program by embedding it in an existing course, then converting it to a credited course

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 6 claims rest on one study

## Description
For institutions developing similar programs, the authors suggest starting the research element inside the second-semester introductory course or lab, as Loyola did, allowing the program to launch with relatively minor commitment. Assigning a faculty FP coordinator can unify activity across groups, and if possible the program should be developed as an innovative course with learning objectives, grading rubrics, and an assessment plan before implementation. Loyola later made FP a separate one-credit course in 2008, which also provided faculty incentive by counting toward teaching responsibilities.

## Design Implications

### Context
#### Requirements
- Faculty buy-in, which the authors call the most important key to success of the program
#### Constraints
- Implementation may need to be modified based on available faculty, the student body, and available resources; benefits may trickle in slowly, so patience is warranted

### Target Learners
- first-year undergraduate physics majors

### Target Learning Goals
- early integration into a research community
- development of research and communication skills
