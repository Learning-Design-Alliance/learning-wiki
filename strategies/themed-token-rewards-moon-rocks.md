# Use a themed token-reward system (moon rocks) to motivate on-task behavior during tutoring

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Galaxy Math embeds motivation in its space theme: "students can earn 'moon rocks' by completing work and staying on task." This token system ties rewards to both work completion and on-task behavior within one-to-one tutoring sessions for young at-risk learners.

## Design Implications

### Context
#### Requirements
- A consistent program theme providing the token framing
#### Constraints
- Evaluated only with first-grade math tutoring

### Target Learners
- at-risk first graders

### Target Learning Goals
- staying on task and completing work during tutoring sessions
