# Design simulation curricula through experiential learning theory, starting from a medical problem and defining measurable learning outcomes

## Description
The article describes a curriculum design process based on experiential learning theory: start by identifying a medical problem, use it to define learning needs for the target population, define educational goals and specific measurable learning outcomes, then select curriculum content and the best-suited educational strategy. Throughout, learning experiences must be "relevant, authentic, consistent and plausible to the trainees", maximising psychological engagement and learning outcome.
