# Embed situated, context-triggered language learning activities in learners' everyday environments

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends designing mobile language learning so that learning activities are triggered by and coupled to the learner's real-world context, using location-aware features such as geo-fence push notifications to initiate vocabulary sessions in relevant places. The authors conclude that "situated learning activities that pervasively transfers language learning into the immediate informal learning context of the student may increase the motivation of the student to engage in a learning activity." This shifts learning from formal settings toward informal, everyday usage scenarios.

## Design Implications

### Context
#### Requirements
- Context-acquisition via sensor technology (e.g., GPS) to detect the learner's location
- Learning content linked to predefined context categories matching real-world locations
#### Constraints
- The authors state contextual features can impact vocabulary learning success only if applied appropriately

### Target Learners
- mobile learners of a foreign language, e.g., students learning German or Thai vocabulary

### Target Learning Goals
- vocabulary acquisition embedded in everyday informal contexts
