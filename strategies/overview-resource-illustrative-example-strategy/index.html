Use an overview resource with an illustrative example to introduce phased evidence building¶

Strategy · All strategies Evidence · no claims cited

Description¶

To help practitioners adopt the phased M&E approach, the publication pairs the framework description with a worked illustration. It states: "This overview resource introduces four phases of evidence building and provides an illustrative example of this M&E approach in action." Pairing a framework summary with a concrete example makes the phased process visible for teams new to evidence-based development.
