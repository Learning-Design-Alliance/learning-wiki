# Adding quiz and crossword-puzzle activities to reduce monotony in the masterclass day

## Description
Based on participant feedback, the authors report that "New activities are currently being developed to make the project less monotonous". These include an astroparticle quiz and a crossword puzzle based on the topics learned during the day, with prizes awarded to the winner and runner-up. This responds to student requests for more engagement beyond the theory introduction.
