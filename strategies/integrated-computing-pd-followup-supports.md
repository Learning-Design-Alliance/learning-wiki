# Follow-up supports for integrated computing PD: technical programming coursework, professional learning communities, and student-outcome study

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Based on the sparse use of programming and CS skills in teachers' lesson plans, the authors recommend that future work provide a more technical course on how to employ programming skills for more advanced integration. They also note that ongoing professional learning communities can greatly support teachers as they implement activities and encounter student misunderstandings or technical issues, and that it would be important to explore student outcomes resulting from the lessons teachers create during these PD interventions.

## Design Implications

### Context
#### Requirements
- Teachers implementing integrated computing activities need support when they run into students' misunderstandings or technical issues.
#### Constraints
- The authors note the existing rubric should be applied to a larger population of teachers' lesson plans, potentially those in actual practice, to strengthen the case of integrated computing.

### Target Learners
- non-CS K-12 teachers who completed introductory integrated computing PD

### Target Learning Goals
- advancing from CT-concept integration toward explicit programming and CS-skill integration
