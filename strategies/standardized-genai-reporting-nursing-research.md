# Report generative AI inputs in a standardized manner in nursing research write-ups

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that nursing research using generative AI report, "in a standardized manner": the name and version of the generative AI model; presence of additional training, tuning, or knowledge transfer; prompt design and attached file formats; response generation parameters including number of iterations, temperature settings, and maximum token count; and the execution environment if applicable. This follows from the finding that file format materially changed performance.

## Design Implications

### Context
#### Requirements
- Reports should name the model version, prompt design, attached file formats, response generation parameters, and execution environment
#### Constraints
- The authors note investigations on other formats and AI models are warranted, so the recommendation rests on one model and one examination

### Target Learners
- nursing researchers
- nursing educators
- authors of generative AI evaluation studies

### Target Learning Goals
- transparent and reproducible reporting of generative AI methods in nursing education and practice
