# Add situational judgement tests to prescribing competence assessment practices

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The review recommends that situational judgement tests, which have demonstrated predictive validity in the affective domain, "would provide a valuable complement to tests in the cognitive and psychomotor domains." This addresses the current lack of assessment of the affective domain in prescribing competence testing.
