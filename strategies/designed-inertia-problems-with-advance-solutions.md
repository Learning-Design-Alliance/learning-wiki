# Design a small set of rotational-inertia problems solved by different techniques, with solutions handed out in advance to prompt classroom dialog

## Description
The article proposes carefully designing three rotational-inertia problems involving linear, superficial, and volumetric mass distributions about some axis, each solved using different techniques, to emphasize the thought processes needed to interpret the concepts. Instructors could hand out solutions in advance so a classroom dialog can establish, bookkeep, and address students' misconceptions, described as a kind of teaching strategy by thinking aloud.
