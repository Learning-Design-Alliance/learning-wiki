# Open the course with a two-week C programming crash course on a shared HPC system to level differing backgrounds

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because enrolled students arrive with varied programming experience, the course begins with a two-week crash course covering basic C concepts (data representation, conditionals, functions, arrays, strings) and advanced topics (pointers, structures, dynamic allocation, recursion, linked lists), plus the Linux command-line environment on the university's high-performance computing system. The article reports that "upon completion of this course, the students will have been exposed to about 90% of the C programming language features", and that no previous C experience is required because the teaching time is built into the course design.

## Design Implications

### Context
#### Requirements
- A compact language (C) whose bulk can be learned quickly; instructor and classmate support for students lacking C-like procedural experience
#### Constraints
- Designed for students whose prior exposure is mostly Python/MATLAB or lower-level languages; assumes multivariable calculus and linear algebra background

### Target Learners
- undergraduates with beginner-to-intermediate programming experience but little or no C or Linux experience

### Target Learning Goals
- C programming
- Linux command-line and HPC environment use
