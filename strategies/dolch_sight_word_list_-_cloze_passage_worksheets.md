# Dolch Sight Word List - Cloze Passage Worksheets

## Description
Grade-level cloze passage worksheets using Dolch sight words. Each grade level includes three worksheets, plus nouns, with missing words to be filled in.

## Design Implications

### Context
#### Requirements
- Printable worksheets, pencils
#### Constraints
- May not suit all learning styles, depends on comprehension skills, can be challenging for some learners
