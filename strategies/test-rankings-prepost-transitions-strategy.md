# Test and extend incorrect-response rankings using matched pre/post transitions and conditional probabilities

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors propose future methods to test the rankings and clarify ambiguously ranked responses. One method rests on the assumption that students choose better responses after instruction, and would "look for asymmetric transitions between response choices in matched pre/posttest data using a McNemar-Bowker chi-square test". Another uses conditional probabilities to identify a progression of responses, consistent with Thornton's conceptual dynamics, and both methods may be applied to other research-based assessments.

## Design Implications

### Context
#### Requirements
- Matched pre-/post-test response data
- Large data sets, which online tools such as PhysPort's Data Explorer and LASSO make achievable
#### Constraints
- The methods depend on alternative assumptions about what makes one response better than another, which the authors state they will explore in future work

### Target Learners
- introductory physics students

### Target Learning Goals
- progression toward correct responses on multiple-choice conceptual assessments
