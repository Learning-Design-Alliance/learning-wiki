# Provide pre-instructional activities and appropriately timed task design before DGE implementation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Among the article's final design suggestions: task design in the DGE "should be designed appropriately so that can be completed on time", and "the instructor should provide pre-instructional activities before implementing the DGE so that students can prepare their prior knowledge and skills." This responds to the study's findings that most students did not complete an absolute-value activity, most failed the main proof activity, and students struggled when they lacked prerequisite knowledge. The introduction section of the activity set operationalized this by having students recall the informal definition and needed basic algebra.

## Design Implications

### Context
#### Requirements
- Instructor-developed warm-up activities targeting prerequisite knowledge
- Task sequencing matched to available class time
#### Constraints
- Students lacking prerequisite knowledge and skills report difficulty understanding concepts in the DGE

### Target Learners
- undergraduate students learning Calculus

### Target Learning Goals
- preparing prior knowledge of absolute value and informal limit concepts before formal definition work
