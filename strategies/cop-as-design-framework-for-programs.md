# Use the Community of Practice framework as a design framework for developing future informal physics programs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 qualitative), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Beyond using CoPs analytically, the authors recommend turning the operationalized framework into a design tool: "we believe that future work in the PER community can utilize CoPs as a design framework for the development of future programs." The restructured framework is intended to profile identity/membership and give insight into what practices and structures can be changed or modeled in current or future programs to promote identity and membership development. Designing programs so that domain, community, and practice are identifiable is the implied design move.

## Design Implications

### Context
#### Requirements
- Program designers must be able to identify the domain, community, and practice characteristics within the program being designed
#### Constraints
- In this paper CoPs are used as an analysis framework; the design use is proposed for future work

### Target Learners
- university students in facilitator roles
- youth participants in informal programs

### Target Learning Goals
- supporting physics identity formation
- fostering sense of belonging in physics
