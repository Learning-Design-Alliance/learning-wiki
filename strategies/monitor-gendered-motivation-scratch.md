# Monitor motivation and willingness to continue programming when using educational software, watching for gendered effects

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The article advises teachers to be vigilant about gendered motivational effects of programming software, citing "evidence of a gender effect in the use of programming software, which may remind teachers to be vigilant in this regard". It also points to "the importance of using programming software to build up students' willingness to continue programming outside the school context".

## Design Implications

### Context
#### Requirements
- Use of educational programming software such as Scratch during programming instruction
#### Constraints
- The gendered motivational benefit for boys appeared only in the plugged-in condition; unplugged activities showed no gender differences in motivation

### Target Learners
- Primary school students, boys and girls

### Target Learning Goals
- Motivation toward programming
- Willingness to pursue programming activities outside school
