# Teachers review student performance data and deliver small-group oral language lessons

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The program's staffing model has teachers review student performance data generated by the online component and deliver small-group lessons to build oral language. This pairs the digital practice with targeted teacher-led instruction aligned to English Language Development state standards, using the real-time progress data and lesson plans the program provides.

## Design Implications

### Context
#### Requirements
- Access to the program's real-time progress data and small-group lesson plans
#### Constraints
- No professional development is required, though various implementation supports are available

### Target Learners
- English Learners in grades K–6

### Target Learning Goals
- Oral language development
