Use automated marking tools as supports for teaching and learning in programming courses¶

Strategy · All strategies
Evidence · 3 claims (2 for, 1 against) · 3 studies (2 design, 1 qualitative), q2 · 0 of 3 report an effect size · 3 claims rest on one study

Description¶

The article suggests employing GAME "as a tool for teaching and learning", beyond marking alone. Instructors provide a marking schema per assessment item, and the system assesses code structure and output correctness automatically, supporting feedback on programming exercises.

Design Implications¶

Context¶

Requirements¶

  • A marking schema must be provided for each assessment item, including file locations and the model solution.

Constraints¶

  • Applies to programming assessments in the languages GAME supports (Java, C++, C).

Target Learners¶

  • university programming students

Target Learning Goals¶

  • programming skills assessment and feedback

Claims¶

  • GAME's marks agree with a human marker's marks on student programming exercises and assignments [+W]
  • In a five-teacher pilot in a 160-student introductory programming course, teachers valued rapid process-level insight and the pilot drove iterative usability improvements [+W]
  • Students find computer-based simulation feedback insufficient because incorrect responses are marked without explanation [-W]
