# Use varied retrieval practice with feedback to support rule induction when no initial instruction is given

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (2 for, 2 mixed) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
When learners must induce rules during practice rather than apply pre-taught rules, the article's Experiment 2 shows varied retrieval practice with corrective feedback is an implementable alternative to worked examples. Students can "be asked to solve varied problems (e.g., 2(x + 3), 4(x + 5), 3(x + 1) and receive feedback that includes the correct answer," then "compare instances, identify common structure, and induce the rule" across problem–feedback cycles.

## Design Implications

### Context
#### Requirements
- Practice items must vary while sharing the same underlying rule
- Feedback must display the correct answer after each retrieval attempt
#### Constraints
- Varied retrieval took more learning time than worked examples, and improvement during practice was slower under varied items

### Target Learners
- novice learners without prior instruction on the target rules, e.g., mathematics students

### Target Learning Goals
- inducing underlying rules from varied practice instances
- transferring rules to novel problems

### Affordances
- Exemplar Based Variability Retrieval Account
