# Implementation practices for in-class tutorials in upper-division courses: sell students on group work, distribute worksheets just prior to use, and include challenge problems

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 mixed) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
From initial implementation in SP12, the authors report three lessons: instructors should "encourage peer discussion by reminding students that scientific argumentation is a skill that is developed through practice", because some upper-division students view tutorials as appropriate only for introductory courses; worksheets should be passed out just prior to beginning, since early distribution led some students to work ahead and discouraged later collaboration; and one or two challenge questions should be added at the end of each activity to keep fast-finishing groups productively engaged.

## Design Implications

### Context
#### Requirements
- Instructor attention to student attitudes about upper-division classroom norms
#### Constraints
- Some students may still subscribe to a transmissionist theory of learning despite instructor efforts

### Target Learners
- advanced undergraduate physics students

### Target Learning Goals
- engagement in collaborative conceptual work on advanced physics topics
