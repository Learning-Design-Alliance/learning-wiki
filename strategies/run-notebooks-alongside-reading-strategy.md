The article prescribes a specific study workflow: the reader keeps the GitHub repository open and executes each notebook as the corresponding code appears in the text, then experiments with the notebooks and attempts the exercises. The authors state "We encourage the reader to learn the concepts from the interactive notebooks, and try solving the unsolved exercises on their own, using Mathematica." This interleaves reading, running, modifying and problem-solving.
