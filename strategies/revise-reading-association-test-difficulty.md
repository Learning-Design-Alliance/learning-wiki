# Revise admission tests by grading reading difficulty more finely and making the association test of uniform difficulty

## Description
Based on experience with the 1916 testing, the article recommends two changes: "The reading test should be presented with more degrees of difficulty so as to distribute the individuals more widely," and the association test "should be made of more uniform difficulty throughout," substituting for the first three parts, which were so easy that writing answers consumed more time than thinking the correct response. These changes were made for the September 1917 testing.
