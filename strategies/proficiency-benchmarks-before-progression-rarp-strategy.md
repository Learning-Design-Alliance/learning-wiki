# Use validated procedure metrics to set proficiency benchmarks trainees must demonstrate before progression to real patients

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (1 causal, 1 review, 1 associational), `q2`–`q4` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
The article recommends implementing proficiency-based progression (PBP) training for RARP: the agreed metrics are used to establish quantitative performance benchmarks, and trainees advance to the next module — and eventually to operating on real patients — only after demonstrating the defined performance level. The article states these metrics 'will also be used to establish performance benchmarks (i.e. proficiency levels), which trainees must unambiguously demonstrate before training progression', so that trainees should not operate on patients until they can both 'know' and 'do' the procedure to the defined level.

## Design Implications

### Context
#### Requirements
- Validated, reliable performance metrics must exist for the target procedure
- A simulation or modular training pathway must be available before clinical practice
#### Constraints
- The article states a full implementation of standardised PBP-based training for RARP is only possible when objective and valid metrics are available; the metrics apply only to the classical anterior transperitoneal approach

### Target Learners
- robotic surgical trainees beginning RARP
- novice urology surgeons in structured curricula

### Target Learning Goals
- reaching quantitatively defined proficiency in RARP before independent practice
- reducing intraoperative errors during the learning curve
