# Select guidance style by context: start with the lightest effective intervention and stage interactive acknowledgment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article's practical recommendations for implementing pedagogical friction in password creation: "Choose the lightest effective intervention for the context", using brief single-rule prompts for familiar lower-risk actions, detailed compact explanations when short-term understanding is a goal, and interactive acknowledgment "when completeness at the point of creation is essential", used sparingly. A staged strategy is recommended: require acknowledgment after repeated violations and relax it once consistent compliance is observed.

## Design Implications

### Context
#### Requirements
- Each prompt tied to a single rule, presented one at a time, with a clear success indicator once the requirement is met
#### Constraints
- Interactive acknowledgment adds effort and should be used sparingly; recommendations are grounded in a single password-creation task with moderate perceived risk

### Target Learners
- general adult online users creating passwords

### Target Learning Goals
- improving password rule compliance and short-term rule knowledge
