# Integrate data science as a tool that enhances the existing physics curriculum rather than replacing it

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends that introducing data science should not displace fundamental physics content. As printed: "Teaching data science to physics students should not simply replace the existing physics curriculum with new content but try to enhance it using data science as a tool." Data science offers new ways to teach physics concepts and engage students in active learning through hands-on experience with physics-relevant datasets, and incorporating it does not detract from core physics topics but provides an enriched framework to understand and apply them.

## Design Implications

### Context
#### Requirements
- Educators need access to ready-made, physics-relevant materials (such as the DSECOP modules) so additions fit within an already full curriculum.
#### Constraints
- Curriculum pressure makes it difficult to target parts of physics courses to replace with data science education; the strategy is framed for integration within existing courses.

### Target Learners
- undergraduate physics students

### Target Learning Goals
- fundamental physics concepts
- data science skills
