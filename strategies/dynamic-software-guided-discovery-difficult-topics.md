# Use dynamic mathematics software with guided discovery for math topics students find difficult

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (2 causal), `q2`–`q3` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
The article recommends that instruction of mathematics subjects known to be difficult should use dynamic software that combines computer algebra systems and dynamic geometry, accompanied by guided discovery questions. GeoGebra "is able to represent functions in the forms: formula, graph, and numerical table, simultaneously", which helps students analyze parameter effects and focus on qualitative analysis instead of complicated calculations. The implementation gave students opportunities for reasoning, making discoveries, generalizing, and proving.

## Design Implications

### Context
#### Requirements
- Software accessible in the learners' language and usable without training, as GeoGebra was in Turkish and enabled use without training students about the software
#### Constraints
- The article's evidence concerns tenth-grade quadratic functions instruction in one high school

### Target Learners
- tenth-grade high school mathematics students

### Target Learning Goals
- connecting algebraic expressions with graphs and interpreting function graphs
