# Start with simple video analyses and a hands-on primer activity to reduce cognitive load before the performance task

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 causal, 1 review, 1 design), `q1`–`q3` · 0 of 3 report an effect size · 2 claims rest on one study

## Description
Before the performance task, groups of 3 to 4 students analyze three simple videos (cart push on level slope, cart on slope speeding up, bouncing ball), discuss, present and critique each other's work. A beginner-primer hands-on activity with marbles, a ramp and a metre rule then scaffolds a smaller set of the science practices (practices 1, 3, 4 and 6). The authors found simple videos effective in helping students relate physics in the software while reducing cognitive loading.
