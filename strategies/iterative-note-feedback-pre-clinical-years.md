# Provide iterative sequential feedback on note writing starting in pre-clinical years

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (3 for, 2 mixed) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
Students recommended that feedback on note writing be delivered earlier and iteratively. They suggested automated grading "might be very helpful" in M1 and M2 years and that receiving a model note on the first day of clinical rotations would improve notes. This aligns with deliberate practice principles where timely feedback after task completion drives skill improvement.

## Design Implications

### Context
#### Requirements
- A feedback system that can be deployed repeatedly across multiple encounters
#### Constraints
- Requires privacy-compliant end-to-end note capture systems

### Target Learners
- Pre-clinical medical students (M1 and M2)
- Third-year medical students

### Target Learning Goals
- Note writing
- Documentation skills
- Setting expectations for clinical documentation
