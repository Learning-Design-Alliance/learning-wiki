# Using Empathy Interviews for Family Engagement

## Description
Empathy interviews involve targeted, one-on-one conversations with a small sample of people to learn from their lived experiences, such as used by organizations like Stanford d.School and The Learning Accelerator. This strategy allows educators to collect stories that ultimately drive district decisions, build trust, and strengthen relationships between families and schools. The empathetic listening starts with asking questions to create a trusting environment for open communication.
