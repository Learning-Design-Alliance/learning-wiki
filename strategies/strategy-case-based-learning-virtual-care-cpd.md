# Incorporate case-based learning and interactive components into asynchronous virtual care CPD modules

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends enhancing asynchronous virtual care CPD modules by adding case-based learning and additional interactive components. Participants' qualitative feedback directly requested "more interactive components (e.g., case-based learning)", and the authors conclude that "future versions of the module should prioritize the inclusion of case-based scenarios to improve practical relevance." This strategy responds to identified gaps in learner engagement and application of knowledge.

## Design Implications

### Context
#### Requirements
- Access to case-based learning materials and interactive content delivery platforms
#### Constraints
- The recommendation is based on participant feedback and author interpretation rather than a direct experimental comparison of module versions with and without case-based learning

### Target Learners
- Healthcare providers
- Practicing physicians
- Nurse practitioners

### Target Learning Goals
- Virtual care delivery skills
- Clinical knowledge application
- Professional confidence in telemedicine
