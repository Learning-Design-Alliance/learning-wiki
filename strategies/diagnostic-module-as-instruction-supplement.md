# Deploy the diagnostic module as a supplement to any instruction strategy, from traditional to highly interactive

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends using the diagnostic module alongside any teaching approach: "The diagnostic module can be used as a supplement to any instruction strategy from the traditional to the highly interactive." It supports a student-centric approach in which students move at their own pace, seek help as suited to their needs, focus on one concept at a time, and confront misconceptions through immediate feedback, without requiring highly motivated and competent instructors.

## Design Implications

### Context
#### Requirements
- Student access to the module at any time and any number of times, one category at a time or all simultaneously.
#### Constraints
- It does not require highly motivated and competent instructors and can be used in an indifferent instruction environment.

### Target Learners
- undergraduate physics students in any instruction environment

### Target Learning Goals
- identifying and removing conceptual deficiencies
