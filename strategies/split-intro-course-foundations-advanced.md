# Split a broad one-semester introductory data science course into a slower-paced foundations course and an advanced course emphasizing machine learning and cloud computing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Based on their experience, the authors "decided to expand this existing course into two new courses: Foundations of Data Science which was first taught in the Fall 2015 semester, and Advanced Data Science which will be taught in the Spring 2016 semester." Splitting lets them "explore programming concepts at a slower pace in the first semester, and move on to more advanced topics, such as machine learning and cloud computing, in the second semester course," with five to six weeks planned for machine learning. Materials for both courses are publicly available at https://github.com/ui-datascience, again leveraging Docker and Jupyter notebooks.

## Design Implications

### Context
#### Requirements
- Publicly available course materials (GitHub repositories) to support reuse
- Instructors must secure sufficient computing resources if centralizing via JupyterHub, which "can be challenging, especially for large courses"
#### Constraints
- The authors found one semester inadequate to introduce all topics; Windows users faced installation and runtime problems with Docker tooling, motivating exploration of JupyterHub

### Target Learners
- University students from diverse disciplines, including those new to programming

### Target Learning Goals
- Foundational programming and data-science concepts, then advanced topics such as machine learning, text mining of social media, network analysis, probabilistic programming and cloud computing
