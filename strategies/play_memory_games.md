# Play Memory Games

## Description
Memory games help hone focus for learners in a fun way, enabling them to concentrate when something challenging is presented. These games force learners to concentrate. Add memory games to classroom electronics to encourage this type of play during free time.

## Design Implications

### Context
#### Requirements
- Memory game materials (e.g., matching cards, board games, digital apps), designated playtime.
#### Constraints
- Some learners may find memory games frustrating. The games should be relevant and engaging.
