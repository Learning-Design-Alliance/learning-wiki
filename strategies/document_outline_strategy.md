# Document Outline Strategy

## Description
Using the “Document outline” tool in Google Docs, students pick out evidence that supports the main ideas they've found. When this tool is turned on, students can write a heading for the paragraph or group of paragraphs and select “Heading 1” from the drop-down menu. When they come across a sentence or phrase that represents evidence supporting that main idea, they summarize it and label it “Heading 2.” At the end, the whole essay is outlined and can be “exported to table of contents,” which will put it at the top of the document, where it can be used as a jumping-off point for writing. The headings in the outline are links that automatically skip to the part of the text where students inserted that heading.
