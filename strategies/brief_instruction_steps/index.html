Brief Instruction Steps¶

Strategy · All strategies Evidence · 5 claims (3 for, 2 mixed) · 10 studies (4 causal, 4 review, 2 theoretical), q1–q3 · 0 of 10 report an effect size · 2 claims rest on one study

Description¶

Breaking up instructions into short, concrete steps allows learners to pay attention to and remember one instruction at a time. When there are multiple steps, providing written or visual instructions learners can refer back to supports Working Memory and processing speed. Combining audio and picture instructions engages both channels of working memory, increasing the likelihood that learners carry out all instructions Media combinations affect recall and retention. [+M].

Design Implications¶

Brief instruction steps manage extraneous cognitive load by keeping each instructional unit within working memory capacity, so learners spend effort executing the task rather than holding the instructions themselves Chunking reduces working memory load. [+M]. The strategy works best when each step names one observable action, is sequenced in the order it will be performed, and remains available for re-reference during task execution.

Context¶

Requirements¶

  • Task analysis that identifies the true sequence of sub-actions before instruction is written
  • One action per step, phrased in imperative, concrete language (Accessible Vocabulary & Syntax)
  • A persistent reference — written checklist, visual card, or on-screen display — so learners can re-check without holding steps in memory
  • Optional audio narration paired with visuals to use both working memory channels Media combinations affect recall and retention. [+M]

Constraints¶

  • Overly granular steps fragment the task and obscure its overall structure, harming learners who need a whole-task model Whole-task performance improves transfer. [~M]
  • Learners can become dependent on step-by-step guidance; without fading, they fail to develop independent task management Fading support promotes transfer of responsibility. [+M]
  • Verbal-only delivery of multi-step instructions overloads auditory working memory; steps must be externally recorded, not just spoken
  • Preparation is time-consuming, and poorly sequenced steps (out of execution order) force learners to re-order them mentally, adding load

Implementation Variability¶

  • Written checklists for independent work; laminated step cards at stations; narrated video demonstrations with on-screen step text
  • Progressive formats: full steps for novices, then keyword prompts, then goal-only statements as competence grows
  • Pair with a Demonstration so each step is both modeled and stated

Target Learners¶

  • Novices and young learners with limited working memory capacity for the domain Chunking reduces working memory load. [+M]
  • Learners with attention challenges, processing speed difficulties, or lower proficiency in the language of instruction
  • Less beneficial for experts, for whom step-by-step guidance is redundant and slows performance Expertise reversal effect. [~S]

Target Learning Goals¶

  • Procedural fluency: executing multi-step processes accurately and completely
  • Working memory management: reducing load during early skill acquisition Chunking reduces working memory load. [+M]
  • Executive function support: externalizing planning and sequencing until learners internalize it

Instructions¶

  1. Analyze the task and list every sub-action in execution order.
  2. Write each sub-action as one short imperative step; test each for a single observable action.
  3. Chunk related steps into labeled phases so learners also see task structure Chunking.
  4. Present steps in the learner's strongest modality — pair spoken instructions with written or pictorial references Media combinations affect recall and retention. [+M].
  5. Model the sequence with a Demonstration before learners attempt it.
  6. Fade the steps over successive attempts — from full steps to keyword prompts to goal-only — transferring responsibility to the learner Fading support promotes transfer of responsibility. [+M].

Related Strategies¶

  • Activating Prior Knowledge — primes relevant schemas so steps are easier to encode and link
  • Chunking — the underlying principle governing how large the steps should be

Examples¶

  • Elementary math instruction: A teacher breaks a multi-digit subtraction problem into numbered steps displayed on an anchor chart, models each with a worked example, then gives students the step card to reference during independent practice.
  • Lab procedures: Science curricula such as FOSS provide illustrated, numbered step cards for hands-on investigations so students can self-check mid-task.
  • Software onboarding: Tools like Duolingo deliver one instruction at a time with immediate visual feedback, never presenting more than a single action per screen.
