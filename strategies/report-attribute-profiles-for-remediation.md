# Report diagnostic attribute profiles back to examinees to guide targeted practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Use Rule Space diagnostic classifications to give examinees information beyond a global proficiency score. The authors write that "the diagnostic reports (which attributes are mastered and which aren't) does tell the examinee whattypes of problems they should seek out and practice solving, and what componentsof problem solving need special attention." In principle, classifications can be reported back so remediation in weak areas can proceed, serving the examinee's interests rather than only selection and placement decisions.

## Design Implications

### Context
#### Requirements
- A Rule Space analysis yielding per-examinee attribute mastery vectors that can be translated into diagnostic reports.
#### Constraints
- From a psychological viewpoint the higher-level attributes reveal little about fine-grained cognitive competence; their value is educational, pointing to problem types to practice.

### Target Learners
- examinees receiving diagnostic score reports

### Target Learning Goals
- identifying and remediating areas of non-mastery
