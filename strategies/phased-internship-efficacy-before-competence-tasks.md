# Phased internship mentorship: build self-efficacy before introducing complex teaching responsibilities

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Following the chain mediation logic, the article recommends mentorship programs adopt a step-by-step approach: in Phase 1 (Adaptation), mentors "should focus on social support and assigning 'low-risk' tasks to build the intern's Self-Efficacy first"; only in Phase 2 (Development) should complex teaching responsibilities be introduced to develop perceived teacher competence. This sequencing is said to prevent capacity overload and burnout.

## Design Implications

### Context
