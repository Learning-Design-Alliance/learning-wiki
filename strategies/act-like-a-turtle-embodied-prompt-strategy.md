# Use embodied turtle-acting prompts and color/step-through scaffolds to teach agent-based thinking

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
When students struggle to identify the turtle's heading or use control flow, the authors found that an effective prompt was "asking students to act like a turtle, i.e., physically carry out the commands themselves by moving their own bodies according to the ViMAP commands they composed." Combined with having students use the change color command after each step and the code step-through highlighter, this helps learners connect their ViMAP code in the C-World to the enacted output in the E-World.

## Design Implications

### Context
#### Requirements
- A visual programming environment with step-through highlighting and per-step color changes; instructor prompting during initial activities
#### Constraints
- Reported from qualitative observations in the two studies; teacher-led scaffolding was required primarily in the early phases

### Target Learners
- elementary and high school students with no prior programming experience

### Target Learning Goals
- agent-based thinking
- debugging
- connecting code to enacted output
