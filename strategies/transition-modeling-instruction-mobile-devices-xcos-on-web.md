# Transition electromechanics modeling instruction to mobile Internet devices once Xcos on Web implements full Scilab Xcos functionality

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 3 studies (1 review, 1 design, 1 theoretical), `q1` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The article recommends moving Bachelor's of Electromechanics instruction in modeling of technical objects toward mobile Internet devices, on the grounds that "Реалізація у Xcos on Web повної функціональності Scilab Xcos створює умови для переходу у навчанні бакалаврів електромеханіки моделювання технічних об’єктів до використання мобільних Інтернет -пристроїв." Until full functionality is reached, the interim path is exchanging data with traditional Scilab Xcos via export tools.

## Design Implications

### Context
#### Requirements
- Full Scilab Xcos functionality implemented in Xcos on Web with mobile Web-browser access
#### Constraints
- The project is still at the preliminary development stage; unconfigurable blocks currently prevent running experiments with the Simulate button

### Target Learners
- Bachelor's of Electromechanics students

### Target Learning Goals
- Modeling of technical objects using mobile Internet devices
