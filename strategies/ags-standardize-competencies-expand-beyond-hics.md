# Standardize core competencies and expand programs beyond high-income regions to strengthen academic global surgery

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The review concludes that standardizing core competencies and expanding programs beyond high-income regions may strengthen academic global surgery. It recommends developing a unified, consensus-driven core competency framework informed by existing programs and intentionally incorporating perspectives from low- and middle-income countries, alongside fostering equitable partnerships, supporting LMIC-led curriculum development, expanding accessible learning modalities, and implementing rigorous evaluation.

## Design Implications

### Context
#### Requirements
- Consensus-driven development of core competencies involving equitable North–South and South–South partnerships.
#### Constraints
- The review notes that establishing a foundational set of core competencies should allow room for contextual adaptation.

### Target Learners
- Health professionals in academic global surgery training programs

### Target Learning Goals
- Surgical systems strengthening, leadership, and health equity competencies in global surgery
