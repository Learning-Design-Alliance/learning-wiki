# Use computer simulation as a foundational prerequisite before scenario-based ACLS simulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (1 for, 1 mixed, 2 against) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends sequencing computer simulation before mannequin-based scenario training: computer platforms build individual technical decision-making, after which learners enter scenario simulation with higher readiness so facilitators can focus on team dynamics. As the authors state, computer-based training 'may be best utilized as a foundational prerequisite' for high-acuity resuscitation training.

## Design Implications

### Context
#### Requirements
- Learners first master individual technical decision-making through computer simulation before entering scenario-based sessions
#### Constraints
- Computer simulation alone cannot fully substitute scenario-based simulation for developing non-technical skills

### Target Learners
- Anesthesiology novice clinicians (first-year residents and interns)

### Target Learning Goals
- ACLS technical skills and non-technical teamwork skills
