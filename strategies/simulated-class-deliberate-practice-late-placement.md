# Use the simulated class as low-stakes deliberate practice placed late in teacher preparation, with transcript-based debriefs

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends a simulated class as a low-stakes setting for deliberate practice much earlier in a teacher's trajectory than the practicum, leaving a complete transcript for analysis and feedback. For the next iteration it recommends placing the simulation towards the end of the course, once participants have had extended practice with the questioning repertoire, and extending practice over multiple sessions, including individual homework sessions after a first in-class paired session.

## Design Implications

### Context
#### Requirements
- An instructional sequence introducing DPT and questioning strategies before the simulation, plus a debrief reconnecting the shared experience to the framework.
#### Constraints
- In this pilot the design could not separate the contributions of simulation, debrief and the surrounding sequence; each pair interacted for only a single session.

### Target Learners
- prospective physics teachers

### Target Learning Goals
- attending to the reasoning behind students' answers
- responding with the right question in real time
