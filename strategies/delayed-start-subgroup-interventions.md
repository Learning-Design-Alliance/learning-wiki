# Use delayed start sub-group membership to target classroom interventions: mentor roles for early starters and nudges for chronic delayers

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors recommend operationalizing the delayed start detector to target interventions aligned with what teachers already do when telling students it is time to get started. Specifically, "Identified early starters are likely more motivated and could be candidates to be student mentors in small-group settings; chronic delayers could be nudged by the instructor via goal-setting around time usage, prioritization for tutoring, or focused teacher attention at the beginning of the class period." The strategy uses simple raw-minutes benchmarks so no new index or framework must be taught.

## Design Implications

### Context
#### Requirements
- A delayed start detector operationalized with simple raw minutes benchmarks aligned with educator observation
- Session-level log data from DLPs already in classroom use
#### Constraints
- Sub-group thresholds are not prescriptive and could differ across contexts, e.g. schools with 60-minute class sessions

### Target Learners
- Grade 7 middle school students in K-12 classwork sessions

### Target Learning Goals
- Timely task initiation and self-regulated learning
- Improved math and ELA standardized test outcomes
