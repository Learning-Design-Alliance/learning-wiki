# Teachers demystify assessment and frame the over-preparation ethos within sustainable routines

> **Strategy** · [All strategies](index.md)

## Description
The article's practical recommendations for educators: teachers can "devote more time to demystifying assessment", including dissecting mark schemes, explaining the rationale behind seemingly "rogue" questions, and teaching metacognitive skills for unfamiliar problems. Teachers should also frame the student-led 'be better than you need to be' ethos within paced, sustainable routines to mitigate burnout and test anxiety.

## Design Implications

### Context
#### Requirements

#### Constraints

### Target Learners

### Target Learning Goals
