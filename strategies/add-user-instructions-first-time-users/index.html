Strategies

Add user instructions or interactive tips to the homepage for first-time users of an integrated learning system¶

Strategy · All strategies
Evidence · no claims cited

Description¶

Based on teacher and student user experience, the study recommends that systems integrating unfamiliar functions provide onboarding support: "If user instructions or interactive tips can be added to the homepage for first-time users, they can use the system more easily and intuitively." In the study, most subjects encountered setbacks interacting with the interface before detailed explanations were given, then gradually adapted after several tries.

Design Implications¶

Context¶

Requirements¶

  • An interface whose operating logic differs from learners' prior experience with related tools

Constraints¶

  • The recommendation addresses the adaptation period observed for this SMM system with young users, not other systems

Target Learners¶

  • first-time users of a new learning system
  • elementary school students

Target Learning Goals¶

  • effective and intuitive use of the learning system interface
