# Sequence microaggression curricula from foundational naming skills toward more complex debriefing skills

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors recommend ordering workshop topics so that faculty first build foundational awareness before practicing harder behaviors: "we decided to start this curriculum with foundational topics, such as acknowledging and naming bias and microaggressions, and gradually moved towards more complex skills such as debriefing microaggressions." They suggest this iterative format so faculty with little prior bias exposure can build the foundation before attempting other behavioral skills, and advise being explicit about each workshop's intended audience.

## Design Implications

### Context
#### Requirements
- Explicit advertisement of the intended audience for each workshop
#### Constraints
- Topic selection should reflect each institution's varying DEI-related needs

### Target Learners
- Faculty with varying prior exposure to bias awareness training

### Target Learning Goals
- Progressive acquisition of microaggression acknowledgment and response skills
