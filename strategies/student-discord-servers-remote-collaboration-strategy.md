# Support remote student collaboration with student-managed chat platforms such as Discord servers for sharing code and links

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors recommend facilitating student Discord servers in future course iterations because students in the remote pilot spontaneously adopted such tools beyond prescribed channels. They write that it "may be worthwhile to facilitate student Discord servers, as they allow for the smoothest exchange of messages, live video and text chat, and code via an integrated markdown system." Students used Google Hangouts, Discord, and Snapchat to share pictures, links, and code examples when Zoom breakout-room collaboration showed low engagement.

## Design Implications

### Context
#### Requirements
- Collaboration must be built into course activities
- Access to social/chat applications students will actually adopt
#### Constraints
- Engagement via formal video-conference breakout rooms was low during fully remote instruction, with some exceptions among groups that consistently collaborated

### Target Learners
- High school students in remote or hybrid course settings

### Target Learning Goals
- Collaborative problem solving and code sharing during project-based quantum computing work
