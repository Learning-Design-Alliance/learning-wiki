# Use Pendleton's feedback model so the learner reflects first on their own performance

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends a participant-driven feedback method, such as Pendleton's model, "to ensure the learner reflects first on their own performance." Feedback should be given immediately after the skill so the learner can correctly practise areas requiring improvement, and learners should have opportunities to ask questions at the end of the session. In teacher-training activities, each learner teaches a skill using Peyton's four-step approach and provides peer feedback using Pendleton's model.

## Design Implications

### Context
#### Requirements
- Feedback given immediately after performance; an appropriate environment; opportunities for learner questions
#### Constraints
- The article notes many feedback models exist (e.g., Silverman's SET-GO and ALOBA) and instructors should find methods they are comfortable and familiar with

### Target Learners
- Health professional learners and peer teachers

### Target Learning Goals
- Improving procedural skill performance through constructive feedback
