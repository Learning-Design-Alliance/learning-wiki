# Avoid averaging artifacts by using nonarithmetic averaging, individual analysis, or the stochastic parameter approach

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 3 studies (1 causal, 1 associational, 1 theoretical), `q2` · 0 of 3 report an effect size · 6 claims rest on one study

## Description
The article presents at least three ways to avoid the power law artifact when fitting nonlinear models to learning or forgetting data: use the model-preserving (nonarithmetic) averaging function matched to the model, fit the model to each individual's data separately and aggregate the fits, or use the stochastic parameter approach, which assumes individual parameter values are random samples of a fixed but unknown probability distribution. The authors state that "Averaging is problematic only when it is used in conjunction with nonlinear models" and that in such cases one can avoid artifactual effects by using nonarithmetic averaging.

## Design Implications

### Context
#### Requirements
- Individual differences must be detected by inspecting individual model fits prior to aggregating the data; software such as HLM or PROC MIXLIN is needed for the stochastic parameter approach
#### Constraints
- Arithmetic averaging across individual data sets is not justified unless the model is linear; the appropriate nonarithmetic averaging technique depends on the model under consideration

### Target Learners
- Researchers analyzing learning, memory, or skill-acquisition data across multiple subjects

### Target Learning Goals
- Ensuring model selection reflects the underlying process rather than an artifact of data aggregation

### Affordances
- Response Surface Analysis Method
