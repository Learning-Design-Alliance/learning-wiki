# Integrate the engine experiment into a multi-session sequence building DC circuit, oscilloscope, and data-analysis skills

## Description
The article recommends embedding the Stirling Engine experiment within a wider experimental skills development sequence: prior sessions develop competence with DC circuits, motion sensing, and signal measurement via oscilloscopes; the engine experiment then combines these skills; further sessions cover merging repeat data and statistical analysis. "For example, prior sessions can be devoted to developing competence with DC circuits, motion sensing and signal measurement via oscilloscopes." This multi-session approach was used with the student cohorts at the authors' institution.
