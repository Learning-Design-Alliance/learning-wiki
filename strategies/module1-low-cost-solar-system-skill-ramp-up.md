# Ramp students up on key technologies using bright, low-cost solar-system targets before deeper investigations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
MWU! opens with Module 1, which uses bright solar-system targets because they are cheap in telescope time, letting students build core skills before tackling fainter, harder targets. The article states: "The goal of Module 1 is to use bright (i.e., low-cost, in terms of telescope time) solar-system targets (1) to ramp students up on MWU!'s key technologies and concepts, and (2) to introduce them to radio astronomy on an equal footing with optical astronomy." Students learn mosaicking, radio mapping, aperture photometry, photometric calibration, and hypothesis testing across four investigations.

## Design Implications

### Context
#### Requirements
- Bright, observable targets that cost little telescope time so students can practice core skills repeatedly
#### Constraints
- Science content of the first lunar mosaicking investigation is deliberately low, serving skill building rather than depth

### Target Learners
- introductory astronomy students new to Skynet and radio observing

### Target Learning Goals
- mosaicking
- radio mapping and aperture photometry
- photometric calibration
- hypothesis testing
