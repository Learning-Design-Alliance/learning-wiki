# Pilot multi-component interventions before trial and choose outcome tests that capture the targeted skill

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Drawing on this evaluation, the report recommends that a multi-component literacy intervention should pass through a pilot stage to refine its elements before a full trial, and that future trials should select outcome measures aligned to what teachers actually emphasise. The report states that "a future trial might use a different test that captures this aspect better than the New Group Reading Test", given the emphasis some teachers placed on vocabulary skills, and that the intervention "would therefore have benefited from a pilot stage to refine the elements used in the Full Programme".

## Design Implications

### Context
#### Requirements
- A pilot stage before the main trial to refine how components are combined
- An outcome measure sensitive to the skill the delivered intervention actually emphasised
#### Constraints
- Recommendations arise from an efficacy trial in twelve schools in one local authority area, so generalisation beyond similar settings is not established

### Target Learners
- low-attaining Year 7 pupils at the primary-secondary transition

### Target Learning Goals
- reading comprehension
- vocabulary knowledge
