# Maintain agreements in an official editable document displayed daily and grade by alignment with the agreement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
Record both agreements in an editable document "accessible to all participants and displayed daily in class," treat it as an essential resource, create short names for key items, and grade by "alignment with the physics agreement as we had articulated it up to that point" rather than correctness.
