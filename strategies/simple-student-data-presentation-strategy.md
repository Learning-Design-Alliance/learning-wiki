# Simple data presentation: repeated trials, averaged run-off lengths, and hand-drawn or spreadsheet graphs

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
For introductory courses the authors recommend keeping analysis simple: "have each group repeat every trial three times, calculate an average run-off length, and display the results with hand-drawn or spreadsheet-generated graphs". A plot of Lwall against flow velocity can be paired with a bar chart comparing surface conditions; these figures reveal the main trends without advanced image analysis or specialized instrumentation.

## Design Implications

### Context
#### Requirements
- Each group repeats every trial three times to obtain average run-off lengths
#### Constraints
- Slow-motion smartphone video recordings can help distinguish partial sticking from clean ejection but are not essential for the core version

### Target Learners
- introductory physics students

### Target Learning Goals
- graphing and interpreting experimental trends
