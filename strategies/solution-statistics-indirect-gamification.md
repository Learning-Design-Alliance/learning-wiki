# Show solution statistics from automatic assessment tools as indirect gamification

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The paper recommends that teachers compute and show per-problem solution metrics to students, which can work indirectly as gamification even when the grading approaches are not used directly. It suggests that "it is suggested to add solution metrics regarding each problem submitted solutions", listing average solution time, wrong attempts average, least memory used, shortest execution time, and average execution time. These metrics let students compare with peers and let teachers understand students' problem-solving abilities.

## Design Implications

### Context
#### Requirements
- An automatic assessment tool that records submission data such as time, attempts, memory and execution time
#### Constraints
- Teachers might not want to use all of the grading approaches at the same time

### Target Learners
- programming students at introductory and advanced levels

### Target Learning Goals
- self-assessment against peers
- problem-solving approach awareness
- motivation through peer comparison
