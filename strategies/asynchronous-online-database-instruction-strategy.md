# Deliver database instruction asynchronously online using either interactive tutorials or screencasts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
The study supports moving database instruction online: both an interactive tutorial and a screencast produced significantly higher post-test scores than no instruction, leading the authors to assert that "dedicating time and resources to developing online learning tools is a worthwhile time investment for librarians." Because the two formats did not differ significantly, libraries may choose either format; the authors note each format possesses strengths and weaknesses for different learning objectives.

## Design Implications

### Context
#### Requirements
- Tutorials should be built around explicit learning objectives and a specific research task; screencasts can be created with software such as Adobe Captivate.
#### Constraints
- The authors recommend eliminating redundant text, simplifying instructions, and shortening tutorial length after finding the GotS length likely contributed to outlier scores.

### Target Learners
- undergraduate students

### Target Learning Goals
- database searching skills
