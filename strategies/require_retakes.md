# Require Retakes

## Description
Allowing or requiring retakes emphasizes a growth mindset and reinforces perseverance. It provides opportunities to learn from mistakes and successfully demonstrate learning.

## Design Implications

### Context
#### Requirements
- Flexible testing schedules, resources for remediation
#### Constraints
- Requires resources for additional testing and remediation
