# Scaffolded code stubs with TODO markers for novice programmers

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Students receive notebooks with complete template code and partial implementations marked "TODO: Put your code here." This lets students with minimal programming experience build increasingly sophisticated code, progressing from random key generation to conditionals and arrays of Qubit objects. The authors note this scaffolding approach "allows students with minimal programming experience to build off of prior templates and generate increasingly sophisticated code elements."
