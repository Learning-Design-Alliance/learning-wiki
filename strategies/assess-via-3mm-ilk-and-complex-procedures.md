# Base program skill assessment on intracorporeal knots with 3-mm instruments and extend assessment to complex simulated procedures

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors conclude that 5-mm suturing performance is insufficient to assess the program because it plateaus after session 1, and state that "skill assessment should be based on ILK with 3 mm instruments only to reflect the training of this program". They further plan to integrate evaluation of more complex tasks — running sutures during pyeloplasty or oesophageal anastomosis simulation on low-fidelity home-made models — using an adapted OSATS score that has yet to be validated.

## Design Implications

### Context
#### Requirements
- An adapted OSATS score for complex procedures, which the authors note has yet to be validated
#### Constraints
- The recommendation rests on this single retrospective cohort without a control group

### Target Learners
- residents in paediatric surgery and urology

### Target Learning Goals
- valid assessment of laparoscopic suturing competence, including with mini-laparoscopic (3-mm) instruments
