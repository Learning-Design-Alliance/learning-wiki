# Hexagonal Thinking

## Description
Hexagonal thinking is a mixed retrieval and elaboration strategy that uses hexagonal cards, paper, or programs to investigate how ideas and concepts are connected. Learners write historical events and forces on hexagons and arrange them in cause and effect relationships. The proposed connections are explained using arrows and a written document and shared with the whole class.

## Design Implications

### Context
#### Requirements
- Requires hexagonal cards, paper, or a program like PowerPoint or Google Slides.
#### Constraints
- Requires learners to have a foundational understanding of the concepts being connected.
