# Implement centralised scheduling, shared mapped scenario repositories, and inclusive access supports for virtual simulation IPE

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's discussion recommends institutional implementation practices for virtual simulation-based interprofessional education. Institutions "may consider implementing centralised scheduling hubs that support coordinated timetabling and on-demand access to simulation activities, including evening or off-shift offerings". It further suggests shared interprofessional scenario sets in digital repositories, each mapped to IPEC competency domains and assessed with consistent rubrics, plus equity audits of device availability, internet connectivity, and protected learning time, and inclusive access strategies such as loaner devices and asynchronous participation options.
