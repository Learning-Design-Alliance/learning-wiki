# Remix workflow: build on expert source code through analyze-then-modify stages

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper offers a concrete recipe for educator remixing: obtain a community-shared expert source file, study it, then ask "How can we build on this existing expert source codes?", "Save As" a personal copy, and work through non-linear design stages — examining variables, evolution, and simulation view; adjusting look and feel; adding fixed relations for physics quantities; implementing evolution equations and event conditions; and adding sliders and plotting panels. Community-donated code snippets (e.g., a number-formatting routine by Fu-Kwun Hwang) are copied "with accreditation" and adapted. This is "less taxing on educators coding skills" than authoring from scratch.
