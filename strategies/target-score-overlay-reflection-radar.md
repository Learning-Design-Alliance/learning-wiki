# Overlay self-set target scores onto the actual-performance radar chart to prompt reflection

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
In the reflection module, the dashboard overlays each student's self-set target scores onto the same radar chart as the AI-generated performance scores. The authors report this "direct visual comparison allows learners to intuitively see the gap between their self -set goals and their actual performance in each dimension", encouraging reflection and identification of areas for revision.

#### Requirements
