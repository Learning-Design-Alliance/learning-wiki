# Integrate theoretical lectures into PBL project work and provide one robot per group when using LEGO Mindstorms in programming courses

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (4 for, 2 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 6 claims rest on one study

## Description
Based on prior findings that robots limit time for reflection and that PBL benefits from combined activities, the authors designed their PBL+LM design by "integrating theoretical lectures about programming theory in the project work when relevant, and by providing one robot per group throughout the programming course." The PBL designs split lecture hours into lectures with small lab exercises and independent student-led project work, with three broad project topics from which groups formulated specific problems.

## Design Implications

### Context
#### Requirements
- Access to robots for each group and scheduled lab sessions; lecture hours divided between taught sessions and student-led project work
#### Constraints
- The article notes logistical problems in practice: students had to pick up robots, find rooms, and lacked floor space, which consumed project time and contributed to stress

### Target Learners
- first-year university Computer Science students in introductory programming courses

### Target Learning Goals
- object-oriented programming concepts such as selective and iterative structures, developed through collaborative problem-based project work
