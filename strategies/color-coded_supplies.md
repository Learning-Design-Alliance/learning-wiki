# Color-Coded Supplies

> **Strategy** · [All strategies](index.md)

## Description
Color-coding school supplies assigns a consistent color to each subject, task type, or workflow stage (e.g., red folders for papers that go home, blue for papers requiring a caregiver's signature, green for homework with "To Do" and "Completed" pockets). The color acts as a pre-attentive visual cue, letting learners identify and retrieve the right material without reading labels or remembering rules. The system only works if the mapping is stable, taught explicitly, and maintained by the learner or adult.

## Design Implications

Color is processed pre-attentively and rapidly, so a consistent color mapping reduces the search and decision steps involved in material management, easing extraneous load for learners whose working memory or executive function is already taxed [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]. The mechanism is dual coding: information is encoded both verbally (subject name) and visually (color), producing richer retrieval paths [Dual coding improves recall.](../claims/dual-coding-improves-recall.md) [+M]. However, the color must carry *informational* weight — decorative or inconsistent color use does not improve learning and can distract [Decorative illustrations do not improve learning.](../claims/decorative-illustrations-do-not-improve-learning.md) [+M].

### Context
#### Requirements
- A small, stable set of color categories (typically 3–6; more categories exceed what learners can reliably hold and apply)
- An explicit teaching episode: the learner must be told the mapping and practice using it, not merely be given colored supplies
- Consistent enforcement by adults across settings (home and school) so the mapping does not drift
- A fallback for learners with color vision deficiency (patterns, textures, or position cues alongside color)

#### Constraints
- Ineffective or exclusionary for learners with color vision deficiency (~8% of males) if color is the *only* distinguishing cue — always pair color with a redundant label or icon [-M]
- Systems with too many color categories collapse into arbitrary mappings and add load rather than reduce it [~M]
- Effectiveness depends entirely on consistent maintenance; an inconsistently applied system is worse than none, because it teaches learners the cues are unreliable [-W]
- Color coding materials is an organizational aid, not an instructional strategy — it does not by itself improve content learning [-W]

#### Implementation Variability
- Subject-based coding (one color per class) vs. workflow-based coding (one color per action: "to do," "return," "file")
- Physical supplies (folders, notebooks, bins) vs. digital parallels (colored tags in Google Classroom or Notion)
- Learner-maintained vs. adult-maintained systems; fading adult support as the learner internalizes the routine

### Target Learners
- Learners with executive function difficulties or ADHD, for whom material management is a recurring failure point [~M]
- Young learners and novices who cannot yet read fluently enough to use text labels as retrieval cues
- Learners with working memory constraints, for whom externalizing category structure reduces in-the-moment load [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]
- Less valuable for highly organized learners, for whom the system adds maintenance overhead without benefit [~W]

### Target Learning Goals
- Executive function support: organizing materials, transitions, and turn-in routines
- Procedural fluency: automating "what do I do with this paper?" decisions
- Independence: reducing adult prompting for material management

### Instructions
1. Define 3–5 categories that match the learner's actual workflow (by subject or by action).
2. Assign one color per category and add a redundant text label or icon to every item ([Accommodations](../elements/accommodations.md) for learners with color vision deficiency).
3. Explicitly teach the mapping and have the learner sort real materials as practice ([Practice](../elements/practice.md)).
4. Post the color key as a reference ([Advance Organizers](../elements/advance-organizers.md)) at the workspace and in the take-home folder.
5. Fade adult checking over several weeks, moving responsibility for maintaining the system to the learner.

## Related Strategies
- **Checklists and Routines** — color coding is a perceptual shortcut that serves the same externalizing function as a checklist
- **Visual Schedules** — same principle applied to time rather than materials
- **Accessible Syntax** — both use redundant, low-effort cues to reduce processing demands

## Examples
- A take-home folder with a red "Leave Home" pocket, a blue "Sign & Return" pocket, and a green homework pocket labeled "To Do" / "Completed."
- Middle school binder system: one notebook color per subject, mirrored by matching colors on the class schedule and locker shelf.
- Digital parallel: color-coded tags for assignments in Google Classroom by status (not started / in progress / submitted).
