Strategies

After initial use, let wizards skip feedback layers 1 and 2 when they are obvious and detail the program-code subcategory¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 qualitative), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Based on WOZ I, the authors adjusted the feedback procedure: wizards “should skip layer 1 and 2 if the feedback seems to be inappropriate because the students already addressed these layers with their own changes or if these layers are obvious for the students”. In addition, the subcategory program code was described in more detail, distinguishing whether a box is missing or the wrong program block is used.

Design Implications¶

Context¶

Requirements¶

  • Wizards must judge students' competencies and whether similar problems occurred earlier in the lesson to decide whether the layers are obvious.

Constraints¶

  • The article states whether layers are obvious seems highly related to the students' competencies and whether similar problems occurred before in the lesson.

Target Learners¶

  • secondary school students working in pairs on robotics programming tasks

Target Learning Goals¶

  • problem-solving and debugging during robotics activities
