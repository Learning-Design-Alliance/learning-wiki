# Repeat Key Points (Processing Speed)

## Description
Repeating key points for students several times and in several different ways to support processing speed. This strategy involves reinforcing essential information through varied repetition and rephrasing.

## Design Implications

### Context
#### Requirements
- Conscious effort to repeat and rephrase key points, use of diverse instructional methods, and awareness of student's processing needs
#### Constraints
- May become redundant if not varied effectively, requires careful planning to avoid overwhelming students, and some students may find repetition tedious

### Target Learners
<!-- Link to sub-claims -->
- Students who need extra time to process information and benefit from repetition

### Target Learning Goals
<!-- Link to sub-claims -->
- Reinforce key concepts, improve retention, and support students with slower processing speeds

### Affordances
- Enhances memory, provides multiple exposures to key content, supports diverse learning styles, and reinforces understanding

### Personalization
- Repetition can be tailored to individual needs, using different modalities (visual, auditory, kinesthetic) and varying levels of complexity.
