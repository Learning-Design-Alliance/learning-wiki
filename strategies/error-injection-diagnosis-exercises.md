# Error-injection exercises: diagnosing subtly wrong simulations as graded practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends giving students a subtly wrong simulation—sign error in the force, dt an order too large, the wrong potential—with the diagnosis as the graded object. The author states the exercise "provides the supervisory practice that the agentic workflow no longer provides by itself," and trains reading code one did not write, the fluency the oral defense's walkthrough demands. Several of the author's in-class quizzes have taken this form for years, and the richest source of injected errors is now real agent sessions. Its complement is computing education's prompt problems, where students author the specification.
