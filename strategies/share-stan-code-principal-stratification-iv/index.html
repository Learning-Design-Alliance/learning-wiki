Strategies

Share example Stan code so researchers can implement principal stratification and IV models on hierarchically structured studies¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The authors state their intention to share extensive example code for both Instrumental Variables and principal stratification models using Stan, so that researchers can implement the framework on studies with a similar structure. This supports applying the latent-subgroup approach to a broad range of interventions, especially settings in education that could benefit from hierarchical modeling.

Context¶

Requirements¶

  • A study with a hierarchical data structure similar to the HSIS design
  • The open-source Bayesian modeling platform Stan

Constraints¶

  • The authors note ongoing technical work is needed for a more complete understanding of the connection between random effects and the discrete choice model

  • education researchers analyzing randomized interventions
