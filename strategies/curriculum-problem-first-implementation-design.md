# Begin implementation with the curriculum problem rather than the AI tool, specifying learning outcome, learner task, AI contribution, educator role, and required learner action

## Description
The article recommends that implementation "should begin with the curriculum problem rather than with the AI tool". Educators should first identify the learning outcome, then define the learner task, specify what the AI system will contribute, clarify the human educator's role, and require a concrete learner action at the end of the activity. This design logic ensures feedback becomes formative by helping learners compare current performance with expected standards and use that information to improve.

## Design Implications

### Context
#### Requirements
- Educators must identify the learning outcome, define the learner task, specify the AI contribution, clarify the educator role, and require a concrete learner action
#### Constraints
- AI implementation should be guided by educational purpose, human oversight, and governance rather than technology adoption alone

### Target Learners
- Clinical educators, curriculum committees, and institutional leaders in health professions education

### Target Learning Goals
- Designing AI-assisted formative activities that support learning
