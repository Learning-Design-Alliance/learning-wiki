# Progressively unlock games to give children a sense of advancing to new challenges

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Games beyond the initial basic levels remain hidden until the child completes a related game's level, at which point new games or higher difficulty levels are activated. The article states this mechanism exists "para restringir otros juegos más complejos y darle la impresión al niño que está avanzando y obteniendo nuevos retos". Level configurations are stored as JSON so difficulty can be adjusted, though the authors note stricter level progression is not strictly necessary.

## Design Implications

### Context
#### Requirements
- Each game and its levels must be registered in the database with JSON configuration so levels can be instantiated with the established parameters
#### Constraints
- The article notes that enabling a next level with slightly greater complexity after each cleared level is not strictly necessary

### Target Learners
- Preschool children (ages 4-7) using the tablet application

### Target Learning Goals
- Maintaining engagement and a sense of progression while reinforcing specific skills
