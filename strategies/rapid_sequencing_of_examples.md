# Rapid Sequencing of Examples

## Description
Present instances of a concept in rapid sequence or allow all instances to be viewed simultaneously. This enables them to be active in working memory all at once, facilitating the process of generalization. If there is a time gap between the presentation of examples, the learner might not generalize from them.

## Design Implications

### Context
#### Requirements
- Requires a format that allows for simultaneous or rapid sequential presentation of examples.
#### Constraints
- May overwhelm learners if the pace is too fast. Requires careful design to ensure examples are clear and distinct.
