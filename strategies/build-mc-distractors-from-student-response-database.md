# Build multiple-choice distractors and reasoning elements from a database of authentic student free-response answers

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (5 for, 1 mixed) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 6 claims rest on one study

## Description
The article's development method: mine prior semesters' free-response solutions to identify common student ideas, then use them as reasoning elements and distractors. The authors "used this database along with research on students’ difﬁculties to create a multiple-choice version", so that the options reflect how real students reason rather than expert intuitions about errors. This makes the select-all format diagnostic of actual student thinking.

## Design Implications

### Context
#### Requirements
- An existing free-response version of the assessment administered across multiple semesters to accumulate a response database
- Research on students' difficulties in the domain to guide element selection
#### Constraints
- Element wording may need adjustment after expert review and think-aloud interviews; prompts were changed "only when necessary to accommodate the new format"

### Target Learners
- upper-division undergraduate physics students

### Target Learning Goals
- conceptual understanding of upper-division electrostatics
