# Use fitted learning curves to set competency standards and estimate required practice volume and time when planning a skills curriculum

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article proposes choosing a competency standard of diagnostic accuracy first and then using fitted learning curves to estimate how much deliberate practice students need. A two-stage model maps a target accuracy to a required number of modules via the Gompertz curve, then to practice time via the Michaelis-Menten curve; table 3 lists requirements for scores from 70 to 85%. The authors state this "can help inform a competency-based approach to curriculum development".

## Design Implications

### Context
#### Requirements
- Practice and performance data collected during core curricular activities, and fitted accuracy and time curves for the skill in question.
#### Constraints
- Estimates describe the average student; the authors note the mean of student performance rarely describes an individual learner, and results apply to ACLS-level rhythm strips, not 12-lead ECGs or long-term retention.

### Target Learners
- first-year medical students

### Target Learning Goals
- reaching pre-defined diagnostic accuracy standards on ECG rhythm strip interpretation

## Claims

- [Diagnostic accuracy during practice increased significantly between modules 1-3 and possibly to module 5, while per-module practice time decreased through module 8](../claims/accuracy-increased-speed-increased-through-practice-modules.md) [+W]
- [Mathematical models (Gompertz for accuracy, Michaelis-Menten for time) significantly correlated both cases practiced and practice time with exam diagnostic accuracy (p<0.001), estimating 34 cases and about 112 minutes for 75% accuracy](../claims/gompertz-michaelis-menten-learning-curve-ecg-exam-accuracy.md) [+W]
- [First-year medical students voluntarily completed a mean of 59 ECG rhythm strip practice cases when a mandatory module and summative exam were in place, yielding 18,466 feedback instances across 314 students](../claims/mean-59-ecg-rhythm-strips-practiced-18466-feedback-instances.md) [+W]
