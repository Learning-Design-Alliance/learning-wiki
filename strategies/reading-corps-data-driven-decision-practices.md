# Data-driven decision-making practices in tutoring programs

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The Coaching Specialist "supports all data-driven decision-making practices (e.g., eligibility; graph interpretation; exit decisions)". This strategy embeds regular progress data review into tutoring so that decisions about which students receive tutoring, how progress is interpreted, and when students exit the program are made from assessment data rather than judgment alone.

## Design Implications

### Context
#### Requirements
- A Coaching Specialist or equivalent role with capacity for regular (e.g., monthly) coaching.
- Progress assessment data from the tutoring protocols.
#### Constraints
- 

### Target Learners
- Kindergarten through grade 3 students in supplemental tutoring

### Target Learning Goals
- Literacy benchmark attainment and appropriate tutoring entry and exit decisions
