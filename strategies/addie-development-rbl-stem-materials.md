# Use the ADDIE model to develop RBL-STEM learning materials

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article specifies that "The framework for the process of developing the RBL-STEM learning activities, referred to ADDIE model of the research and development, namely Analyze, Design, Development, Implementation, and Evaluation." The Development stage tests content, format, and language validity plus practicability; the Implementation stage tests effectiveness in improving metaliteracy; the Evaluation stage uses inferential statistics. A 4D model (define, design, develop, disseminate) structures the learning-material process.
