# Embed computational competencies as early as possible in Astronomy/Astrophysics coursework

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 review, 1 qualitative, 1 design), `q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
Because modern astronomers rely heavily on programming and computation, and because these are highly transferable skills for the majority of majors who pursue careers beyond academia, the report recommends that departments "work to embed computational competencies as early as possible into the coursework for Astronomy and Astrophysics majors". It further asks the AAS to prioritize developing pedagogical resources for teaching scientific computing in astronomy.

## Design Implications

### Context
#### Requirements
- Departments lacking formal learning goals in data analysis and scientific computing should adopt them
#### Constraints
- The report notes many programs offer their own programming or data science courses specific to physics and astronomy, which may explain why separate computer science courses are not required

### Target Learners
- undergraduate Astronomy/Astrophysics majors

### Target Learning Goals
- data analysis, scientific computing, and programming skills
