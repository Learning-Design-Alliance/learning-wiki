# Use metric dashboards of the four quantitative measures for formative feedback in simulation-based surgical training

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends referencing dashboards that display individual data on margin error distance, tumor bed carbonization, resection time, and number of repeated grasps. Lower values indicate better performance on all metrics, so learners and instructors can quickly identify metric-specific strengths and weaknesses and target feedback. The authors published a performance dashboard figure showing individual expert and novice data points for each measure.

## Design Implications

### Context
#### Requirements
- Objective quantitative measurement of the four metrics after each task attempt
#### Constraints
- Feedback use is formative; the authors state that determining the oncologically appropriate resection remains a clinical judgment developed in vivo under senior supervision

### Target Learners
- Surgical trainees practicing oral cancer resection

### Target Learning Goals
- Technical precision in margin execution
- Safer electrosurgical handling and efficiency
