# Start introductory programming with structural language concepts rather than object-oriented concepts, and emphasize widely used languages

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends that beginning students not be given hard-to-understand topics: at the introductory stage, structural language concepts should be discussed instead of object-oriented language concepts. It also recommends that curricula weight world-accepted, high-trend languages, listing Java, C, C++, Python and C# as the world's most used languages, and notes Java's advantage across web, desktop and mobile platforms. Other languages should not be neglected and can be supported through extracurricular seminars, hackathons and competitions.

## Design Implications

### Context
#### Requirements
- Curriculum designers must track which languages are most used in industry when choosing the instructional language

- The recommendation concerns the introductory stage for students new to professional education, not advanced courses
