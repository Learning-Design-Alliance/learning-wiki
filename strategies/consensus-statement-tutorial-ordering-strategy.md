# Use a skills consensus statement to recommend an order of tutorial participation to students

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article proposes comparing the level of instruction at which a tutorial covers a learning objective with the level the consensus statement requires at specific milestones, so that "it is possible to recommend to students the tutorial participation in a specific order". The authors report they have begun integrating the tutorial curriculum into the Charité's teaching platform and are developing a student online navigation system that uses the collected data to suggest tutorials based on student interest or as follow-up to tutorials already visited.

## Design Implications

### Context
#### Requirements
- A mapped dataset linking each tutorial to learning objectives and their level of instruction
#### Constraints
- The recommendation relies on the consensus statement's milestone levels, which the study found covered at decreasing depth as students progress

### Target Learners
- medical students

### Target Learning Goals
- sequencing voluntary practical-skills tutorials to match required levels of instruction at educational milestones
