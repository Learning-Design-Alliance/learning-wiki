# Integrate FAST early in residency (intern year) with easy-access, pre-set workstations and a proctored introductory session to maximize independent practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors recommend integrating FAST "as early as the intern year in orthopedic training so that young surgeons can develop foundational psychomotor skills before even touching an arthroscope in the operating room". Their implementation recipe: keep all testing modules pre-set with instruments, mounted instructions, and QR-code task videos; run a 2-to-3-hour proctored session for all interns during their skills month; then expect practice to proficiency before arthroscopic rotations.

## Design Implications

### Context
#### Requirements
- Workstations accessible at any time in a skills laboratory with a monitor, instruments, and video instructions; modular design so programs can adapt visualization technology to local resources
#### Constraints
- Ease of implementation was judged essential for adoption; a single benchmark per task was chosen as a practical compromise rather than limb-specific thresholds

### Target Learners
- first-year (intern) orthopedic residents, progressing through residency

### Target Learning Goals
- foundational arthroscopic psychomotor skills, good early habits, and confidence before operating-room arthroscopy
