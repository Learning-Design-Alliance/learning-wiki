# Use an interactive tutorial with suggested moves as both accessibility aid and analysis reference point

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Version 5.0 added an interactive tutorial which suggests possible moves to the player. This is intended to make the game more accessible for casual gamers while giving potential citizen scientists a reference point when analysing their method, for example by examining which suggested moves they do and do not use and identifying moves they apply that are never suggested.
