# Link camp modules to QIS Key Concepts for K–12 framework standards

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
QCaMP modules were "linked with Quantum Information Science (QIS) Key Concepts for K–12 Framework from the National Q-12 Education Partnership", with Table IV listing the standards covered in the High School Physics, Computer Science, and Mathematics frameworks for each module. This alignment documents how each lesson maps to recognized standards, supporting adoption and credibility of the curriculum. The IBM Q Composer module is excluded from the table because its purpose was to introduce a tool and revisit practice problems.
