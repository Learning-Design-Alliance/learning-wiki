# Teachers build and host Monte Carlo virtual experiments as HTML/JavaScript applications on blogs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends that teachers use ordinary web-page tools, HTML and JavaScript, to develop simulations that let students run their own statistical experiments, and transmit these "experimentos virtuales" through blogs so students can access content outside class hours and practise. JavaScript adds dynamism and interaction to blogs, HTML5 enables 3D graphics, and the approach is operating-system independent and works offline.
