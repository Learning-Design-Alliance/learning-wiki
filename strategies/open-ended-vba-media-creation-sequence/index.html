Open-ended VBA-based learning sequence: pose questions from a given picture, propose solutions, then create new props or games¶

Strategy · All strategies
Evidence · 4 claims (4 for) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The article describes an open-ended approach in which "Students can bring up various ideas come to their mind using open -ended approach", useful when troubleshooting images provided in the Forms menu of Microsoft Excel. The sequence starts from students asking questions from a specified picture and planning a mathematical prop, then proposing solutions to make mathematical games, and finally proposing solutions after problem-solving by making a new props creation plan or developing props.

Design Implications¶

Context¶

Requirements¶

  • Microsoft Excel with the Forms menu and VBA, and starter pictures from which students pose their own questions

Constraints¶

  • The article notes constraints from students in using new mathematical software and mastering animation techniques

Target Learners¶

  • prospective-teacher students in an ICT Application for mathematics learning course

Target Learning Goals¶

  • creative thinking ability in designing interactive mathematics learning media

Claims¶

  • Students' creativity in creating interactive learning media combines mastery of school-level mathematics with the ability to apply Visual Basic Application for Excel [+W]
  • Prospective-teacher students learning with an open-ended VBA-for-Excel approach created more creative interactive learning media than students taught by an expository VBA-based method [+M]
  • After open-ended VBA-based learning, students showed gains in independent creation: 31.43% created new ideas without following examples and 20% made animation-based props, up from 8.69% and 60.86% example-dependence [+M]
  • Post-learning media products spanned multiple mathematics topics: 42.8% geometry-related props, 28.57% arithmetic-related props, 51.43% could explain prop creation, and 60% could use shapes to run their code [+M]
