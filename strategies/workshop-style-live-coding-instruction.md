# Teach programming with workshop-style live coding in which the instructor writes and executes code in real time

## Description
In the Scientific Computing with Python course, instruction is delivered in a workshop-style live programming environment where the instructor writes and executes code in real time during class. The article justifies it: "This method is an eﬀective way to teach programming concepts interactively because it allows students to witness the entire process of problem-solving, writing, testing, and debugging the code, and it provides immediate feedback." Students thereby observe the instructor's thought process and learn to anticipate and resolve errors.
