# Close the event with an anonymous participant questionnaire and use it to produce an Event Report guiding future improvements

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
At the end of the day, participants are asked "to complete a short anonymous questionnaire about their experiences of the event" to identify any highlights or weaknesses that might be improved in future events. These surveys are then used to make an Event Report. The article notes an example questionnaire is provided on the authors' website, alongside educational material for running different outreach events.
