# Use a single-sanction honor code to enable take-home daily assessments

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (4 for, 2 against) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 6 claims rest on one study

## Description
The article describes making daily assessments available on the faculty member's door for students to take, an approach the authors state "is the norm for the school" and is enabled by a single-sanction honor code under which "any student convicted of academic dishonesty is dismissed." The authors report that the distribution of grades indicated the integrity of the assessment scores had been maintained.

## Design Implications

### Context
#### Requirements
- A single-sanction honor code with meaningful consequences for academic dishonesty
- Assessments must be distributed in a location accessible to students, such as the faculty member's door
#### Constraints
- The approach relies on the institutional honor code; the authors note the school has a single-sanction honor code where any student convicted of academic dishonesty is dismissed

### Target Learners
- undergraduate business students in principles of financial accounting

### Target Learning Goals
- academic integrity in daily assessment completion
