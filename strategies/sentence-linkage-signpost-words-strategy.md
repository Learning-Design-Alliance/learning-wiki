# Link sentences old-before-new and use sign-post words to make text flow

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
To fix 'bumpy' text that does not flow, the guide teaches that 'In the English language the beginning of a sentence always provides context and linkage, generally by repeating a word or concept that has already been mentioned, while the end of the sentence presents the new information'. Renaming nouns, listing announced items ('three missions... First... Second... Third...'), and using sign-post words for examples, chronology, cause and effect, similarity and contrast improve linkage. It notes some languages, such as Persian, order old and new information oppositely.

## Design Implications

### Context
#### Requirements
- Each sentence opens with known information and ends with the new information
- Use sign-post phrases such as 'for example', 'consequently', 'similarly', 'in contrast' to mark idea relationships
#### Constraints
- The old-before-new order is language-specific and reverses in some languages such as Persian

### Target Learners
- beginning writers, particularly non-anglophones

### Target Learning Goals
- write flowing, linked academic prose in English
