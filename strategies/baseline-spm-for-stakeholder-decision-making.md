# Use the variable-based LRC model as baseline information for stakeholder decision making in programming courses

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends using the variable-based LRC model’s outputs as "baseline information about student s’ performance thereby  offering better decision making towards improving teaching/learning outcomes in programming courses", with stakeholders predicting performance in real time through the mobile application. It further recommends that future research adopt improved statistical machine learning approaches to comparatively model learning behaviour in private and public Nigerian universities and consider all programming courses with a larger population.

## Design Implications

### Context
#### Requirements
- questionnaire data on the identified hidden factors must be collected and the chosen underlying model applied
#### Constraints
- findings are scoped to students who offered Web programming, C or JAVA at Federal University, Oye-Ekiti between 2012 and 2016

### Target Learners
- undergraduate programming students and educational stakeholders

### Target Learning Goals
- improving teaching and learning outcomes in programming courses through performance prediction
