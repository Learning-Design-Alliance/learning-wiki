# Structure MicroSim lesson plans as a PRIMM progression: Predict, Run, Investigate, Modify, Make

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Each automatically generated MicroSim lesson plan structures learner activity as a PRIMM progression. Learners "begin by predicting what they think will happen in a dynamic simulation, then run the interactive model to observe real outcomes", then investigate variable relationships, modify parameters with buttons and sliders, and, with the right tools, generate their own versions or extensions. The cycle moves learners from passive observation to authentic construction of knowledge through experimentation and iteration.
