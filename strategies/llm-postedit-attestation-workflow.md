# Four-step LLM-assisted workflow for producing attested ancient-language sentences

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's workflow for generating authentic ancient-language text: "1. ask an LLM to translate the sentence; 2. check the result for morphological errors; 3. ensure chosen words are attested in a dictionary and replace/reprompt for alternatives as needed; 4. check a modern translation for equivalent modern construction instances, then ensure their original counterparts correspond to the selected constructions." It combines LLM drafting with dictionary attestation checks and cross-referencing authentic historical texts such as the Wessex Gospels.

## Design Implications

### Context
#### Requirements
- Access to an LLM, a historical dictionary such as Bosworth Toller's Anglo-Saxon Online Dictionary, and an authentic corpus of the historical language for cross-referencing constructions
#### Constraints
- LLM output alone does not reflect authentic historical syntax and requires post-editing; the workflow was developed for a small set of 20 sentences

### Target Learners
- students and instructors of historical languages and historical linguistics

### Target Learning Goals
- producing authentic historical-language text and understanding historical syntactic constructions
