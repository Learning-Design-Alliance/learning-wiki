# When reliability is too low, first improve the causes and retest; otherwise discount the scores' weight in decisions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 3 studies (3 theoretical), `q1` · 0 of 3 report an effect size · 2 claims rest on one study

## Description
The module recommends a sequence for handling unreliable scores: "the first priority should be to correct or improve the factors that contributed to the low reliability and then retest." If retesting is impractical, discount the scores by allocating less weight in decisionmaking than planned, or combine them with a revised test administration. The user must weigh discounting against the risk that discounted content (e.g., higher order skills) becomes misleadingly underrepresented.

## Design Implications

### Context
#### Requirements
- Diagnosing whether the test, the examinees, or the testing conditions caused the low reliability before choosing an option
#### Constraints
- Discounting scores related to significant or higher order content can make subsequent decisions grossly misleading

### Target Learners
- teachers deciding how to use scores from unreliable classroom tests

### Target Learning Goals
- appropriate use of test scores when reliability is questionable
