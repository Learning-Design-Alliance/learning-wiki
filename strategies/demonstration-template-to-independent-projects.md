# Incorporate computation into an existing classical mechanics course through in-class demonstrations followed by student projects that progress from template modification to independent construction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 qualitative, 1 design), `q1` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The authors use computation in two main ways: live demonstrations of computer solutions during lecture, with code made available for students to examine and experiment with, followed by computational projects completed individually or in small groups. Early projects involve "minor modiﬁcations of the code used in the demonstrations", so the demonstration code acts as a scaffold; later in the course students construct solutions without a template. Projects can become formal writing assignments with figures, typeset equations, and discussion of the physics.

## Design Implications

### Context
#### Requirements
- Access to a chosen computational platform and code that can be shared with students for experimentation
#### Constraints
- More can be done if students have had a course in programming or computational physics; students with no computational background limit what is possible

### Target Learners
- sophomore and junior undergraduate physics majors

### Target Learning Goals
- improved understanding of classical dynamics concepts
- computational skills with widely-used tools
- numerical algorithm literacy
