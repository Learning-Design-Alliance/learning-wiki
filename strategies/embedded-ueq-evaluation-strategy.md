# Evaluate educational e-learning systems with the validated 26-item UEQ embedded in the system

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (5 for, 2 mixed) · 4 studies (2 causal, 2 design), `q2`–`q3` · 0 of 4 report an effect size · 7 claims rest on one study

## Description
The article recommends evaluating web-based educational systems by embedding a validated user experience instrument directly into the platform so learners rate it immediately after use. A "validated Persian version of the 26-item User Experience Questionnaire (UEQ)" was integrated into the ESNPNSD, allowing "direct assessment of user experience within the context of the system's functionality." Scores are interpreted against standard guidelines where values above 0.8 indicate a positive evaluation, and Cronbach's alpha checks internal reliability.

## Design Implications

### Context
#### Requirements
- The UEQ instrument must be validated in the target language and integrated into the system so students complete it after using the system
#### Constraints
- The authors caution that user experience metrics alone do not comprehensively evaluate practical skill enhancement or documentation error minimization, and recommend objective learning-outcome measures in future studies

### Target Learners
- nursing students using web-based clinical education systems

### Target Learning Goals
- assessing user experience of educational electronic systems
