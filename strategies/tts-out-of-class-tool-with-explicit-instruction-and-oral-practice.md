# Use TTS as an out-of-class pedagogical tool accompanied by explicit instruction and oral practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that TTS be used to increase and improve target language input, preferably accompanied by explicit instruction and oral practice, and deployed as an out-of-class tool so that in-class time can be reallocated to feedback and communicative activities. It notes TTS can foster autonomous, anytime-anywhere learning and help develop grapheme-to-phoneme associations where orthography does not map transparently onto allomorphs. The recommendation follows from the finding that perception-only TTS listening did not transfer to production.

## Design Implications

### Context
#### Requirements
- Complement TTS listening activities with speaking activities, e.g. speech recognition software or silent practice, so perceptual knowledge can transfer to production
#### Constraints
- The study's four hours of implicit listening practice was possibly not enough; the article cites explicit pronunciation teaching as an alternative

### Target Learners
- intermediate English-as-a-foreign-language students

### Target Learning Goals
- L2 pronunciation and morphophonemic awareness
