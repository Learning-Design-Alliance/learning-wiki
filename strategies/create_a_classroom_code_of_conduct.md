# Create a Classroom Code of Conduct

## Description
Teachers and students collaborate to establish a classroom code of conduct based on respectful, fair, kind, and empathetic behaviors. The code is dictated by treating others the way you want to be treated and ensures a positive and productive learning environment. This involves asking students how they want to be treated, leading to a discussion of behaviors that are respectful, fair, kind, and empathetic. The class then agrees that treating others the way you want to be treated is the best code of conduct.

## Design Implications

### Context
#### Requirements
- Classroom discussion, collaborative decision-making, willingness to involve students in establishing classroom rules
#### Constraints
- May require time to reach consensus, students may need guidance in identifying appropriate behaviors.
