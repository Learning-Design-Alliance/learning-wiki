# When adding a language barrier to a simulation case, allocate time for recognizing the need for interpretation, interpreter arrival, and third-person history-taking

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
The authors offer design guidance for instructors adapting other scenarios to include a language barrier. They state it is "important to allocate sufficient time for the learner to recognize the need for interpretive services, for the MI to appear in the room, and for the history to be obtained using a third person." They also suggest a moderately difficult case in which key history elements must come via interpreter maximizes emphasis on proper interpreter use, that the emotional-distress element can be omitted, and that the case could use a phone interpreter positioned in the control room.

## Design Implications

### Context
#### Requirements
- A case in which key elements of the history must be obtained via an interpreter
- Sufficient case time for interpreter request, arrival, and mediated history-taking
#### Constraints
- If learners fluent in the case language are present, the instructor may need to choose a language unknown to learners, which complicates recruiting interpreters and actors

### Target Learners
- Emergency medicine residents
- Adaptable to medical students and other specialty trainees

### Target Learning Goals
- Appropriate use of medical interpreter services in simulated emergencies
