# Sequence the template-matching noise-removal activity before this extraction activity so students experience the idealized workflow of real gravitational wave analysis

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The discussion recommends pairing this clean-waveform extraction activity with a separate template-matching activity, in which "the template provides a way to subtract the noise away and leave a clean waveform behind". Sequencing the two means "a student is exposed, at least in an idealized way, to the methods used by gravitational wave astronomers to extract astrophysical information about the emitting systems".

## Design Implications

### Context
#### Requirements
- Access to the separate template-matching activity the authors reference, in which students "emulate the match ﬁltering process" by comparing ideal signals to mocked noisy detector output.
#### Constraints
- The exposure is explicitly idealized: "Real signal analysis is a more complex endeavor than what has been presented here."

### Target Learners
- introductory astronomy students

### Target Learning Goals
- understanding how gravitational wave astronomers identify signals and extract astrophysical information from detector data
