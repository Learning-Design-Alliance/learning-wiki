# Designate permitted AI use per assignment using color-coded levels (red, yellow, green, blue)

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article describes an institutional recommendation under consideration at NC State to designate appropriate AI use not only as a general syllabus policy but by assignment or problem, using color-coded levels. "Red could mean use of AI on that assignment or problem is prohibited and would be an honor code violation." Yellow signals some acceptable uses with caution, green allows any AI use, and blue requires some form of AI use.

## Design Implications

### Context
#### Requirements
- Color words must accompany colors for accessibility, since red/green colorblindness is common
#### Constraints
- Described as a recommendation the institution is considering, not an evaluated intervention

### Target Learners
- higher education students
- instructors

### Target Learning Goals
- clear communication of appropriate AI use
- academic integrity
