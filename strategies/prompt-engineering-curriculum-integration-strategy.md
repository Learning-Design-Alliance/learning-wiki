# Teach prompt engineering before programming concepts, with scaffolded guidance for novices and exploratory approaches for advanced students

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The review recommends integrating prompt engineering instruction into the programming curriculum, with prompt engineering instruction preceding programming concept introduction to develop AI interaction skills first. It distinguishes scaffolded approaches, such as structured exercises with clear instructions like the AI-Lab framework, from experiential discovery-based approaches like Prompt Problems, where students write natural language prompts to generate correct code. Novices need structured guidance while advanced students benefit from exploratory approaches, and new rubrics must evaluate both prompt quality and code correctness.

## Design Implications

### Context
#### Requirements
- Prompt engineering instruction should precede programming concept introduction
- Structured guidance for novices and exploratory approaches for advanced students
- New assessment rubrics evaluating both prompt quality and code correctness
#### Constraints
- Effective prompting requires balancing specificity with conciseness, as overly long or complex prompts can lead to a breakdown in AI comprehension

### Target Learners
- CS1 and introductory programming students
- advanced programming students

### Target Learning Goals
- prompt formulation and problem articulation skills
- critical evaluation of AI output
- computational thinking

### Affordances
- Responsible Ai Integration Framework Programming
