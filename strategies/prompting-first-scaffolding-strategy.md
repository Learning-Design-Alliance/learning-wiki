# Restructure AI-assisted programming courses to teach prompting skills before programming and scaffold with simplified examples and formative checks

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 1 study (1 design), `q3` · 1 of 1 report an effect size · 6 claims rest on one study

## Description
A set of mentor-derived instructional refinements for AI-assisted programming courses. Because learners found it "challenging to simultaneously learn Python and generative AI prompting during Week 2", the strategy reorders the curriculum so students develop confidence in AI prompting techniques before applying them in programming contexts. It also pairs AI assistance with deliberate scaffolding: simplified early code examples, stepwise decomposition of code, formative quizzes, lightweight slide-based summaries, and learner reflection opportunities.

## Design Implications

### Context
#### Requirements
- Instructors or mentors who provide narrative engagement, real-world context, and step-by-step explanation of code blocks
- Instructional materials sequenced so prompting fluency precedes programming application
#### Constraints
- The article warns that overreliance on AI-generated solutions may hinder development of independent reasoning if learners do not engage in reflection or deliberate practice

### Target Learners
- adult novice programmers without STEM backgrounds in self-paced AI-augmented courses

### Target Learning Goals
- foundational programming proficiency, prompt-formulation and iterative refinement skills, and reduced early frustration
