Assign a dedicated site expert and site-developed professional learning plan when implementing Imagine Language & Literacy¶

Strategy · All strategies Evidence · no claims cited

Description¶

The program's stated implementation supports are a dedicated on-site facilitator and customized professional learning. Imagine Learning "recommends each school site have a dedicated site expert to help facilitate the program", and professional learning plans are "developed based on the school's desired outcomes" in a plan developed with each site. This pairs the adaptive software with human facilitation at the school level.

Design Implications¶

Context¶

Requirements¶

  • A dedicated site expert at each school
  • A professional learning plan developed with Imagine Learning based on the school's desired outcomes

Constraints¶

Target Learners¶

  • Students in pre-kindergarten through sixth grade using the program schoolwide

Target Learning Goals¶

  • Effective implementation of adaptive literacy instruction
