# Lecture demonstration plus student-side smartphone exploration with no prerequisites beyond smartphone access

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
For classroom deployment, the article describes a split use pattern: "Lecturers can easily display the web version using a projector to demonstrate the effects of varying specific cosmological parameters, while students can download the iOS application or use the mobile web version to follow along and explore the parameter dependencies themselves." Because the only prerequisite is access to a smartphone, the tool can be adopted in lectures and self-guided study without technical setup or prior experience running Einstein–Boltzmann solvers.
