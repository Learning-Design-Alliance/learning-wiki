# Individualized "Highlighter Tool"

## Description
Students use an individualized "highlighter tool" (e.g., a Google Doc add-on) to create custom highlighters in different colors. They label the colors (e.g., "Argument #1" in red) and use them to highlight relevant text. The highlights can be exported by color to create a table, where students summarize each highlighted category.

## Design Implications

### Context
#### Requirements
- Access to a digital highlighter tool, documents for highlighting, and a means of exporting and summarizing the highlights.
#### Constraints
- Depends on the usability of the highlighter tool and requires careful planning and organization.
