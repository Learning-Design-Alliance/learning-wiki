# Use a structured debriefing script (modified PEARLS) to scaffold self-guided debriefing in VR simulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (3 for, 1 against) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
In self-guided debriefing, dyads reflect on each VR scenario using the PEARLS debriefing script, modified from previous research to fit the VR context; the facilitator-guided group used the same script with an experienced debriefer. The authors argue that effective self-regulated learning requires appropriate scaffolding and that "the structured debriefing script likely provided this support, helping learners engage meaningfully in reflection". This made facilitator-free debriefing feasible with performance outcomes comparable to facilitator-guided debriefing.

## Design Implications

### Context
#### Requirements
- A structured debriefing script such as modified PEARLS, with time allocated (20 min per debriefing in this study)
#### Constraints
- Learners with less developed self-regulated learning skills may struggle to frame experiences without a facilitator; participants still perceived self-guided debriefing as less effective

### Target Learners
- postgraduate trainee doctors
- postgraduate nurses

### Target Learning Goals
- reflective learning from simulation
- self-regulated learning
- paediatric emergency performance
