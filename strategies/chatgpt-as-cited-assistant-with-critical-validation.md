# Use ChatGPT as a cited assistant and reference for programming and general tasks, with logical and critical thinking to validate its output

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 7 studies (3 qualitative, 2 review, 1 quant-synthesis, 1 design), `q1`–`q2` · 0 of 7 report an effect size · 5 claims rest on one study

## Description
Based on survey items Q21-Q24, the article recommends ChatGPT as an assistant for programming and general assignments, used like a search engine reference, with credits and citations in code comments even when only part of the code is generated. Participants stressed that "logical and critical thinking are needed to validate the result presented by ChatGPT", and saw it as a focused alternative to Stack Overflow.

## Design Implications

### Context
#### Requirements
- Proper citation of ChatGPT in program comments, including when only part of the code is generated
- Validation of generated code against expected outputs and course-taught style before acceptance
#### Constraints
- Generated code is sometimes difficult for beginners to understand
- Belief in correctness was only moderate (41% neutral in Q19)

### Target Learners
- first-year computing undergraduates
- students completing general assignments

### Target Learning Goals
- programming task completion
- learning to program from retrieved code examples
- academic integrity
