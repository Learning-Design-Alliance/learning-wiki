# Sequence multimedia-package implementation as demonstration, supported operation, self-paced learning, self-monitoring and self-evaluation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article prescribes a six-step activity sequence for classroom use of the package: the teacher "taught the operating system of the Interactive-Multimedia Package", students were stimulated to operate it, problems were explained on the spot, a package was given for self-paced learning, self-monitoring was the liberated strategy, and learners evaluated themselves. This recipe operationalises learner-paced practice that conventional methods did not allow.
