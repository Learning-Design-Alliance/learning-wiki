# Distributed Practice (Spacing Effect)

## Description
Distributed practice, also known as the spacing effect, is a learning technique where reviews of information or practice of a task are spaced out over time rather than massed together. This method promotes long-term retention because it forces the brain to actively retrieve the information from memory during each review session, making the memory more durable. Distributed practice contrasts with massed practice (cramming), where study sessions occur immediately following the initial learning event.

## Design Implications

### Context
#### Requirements
- Scheduled review sessions, awareness of optimal spacing gaps, technology to sequence assignments effectively
#### Constraints
- Requires planning and discipline, may be inconvenient to implement in traditional linear instruction settings

## Assessment Evidence
- Improved scores on delayed recall tests, better ability to apply concepts to novel situations

## Impact
- Research consistently shows that distributed practice is superior to massed practice for long-term learning and retention. It enhances memory by making retrieval more effortful and by encoding variable contextual information.
