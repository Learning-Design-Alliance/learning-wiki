# Use biometric mood sensing with machine learning to adaptively personalize the learning experience

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper proposes incorporating sensory data that can "measure and quantify one's mood" as a key component of a next-generation engine. "Using machine learning algorithms and neural networks to analyze user data would allow for biometric data anomaly prediction and prescriptive automation." The system would infer a user's mood from biometric readings, warn the user with full disclosure, and procedurally alter the experience by narrating environment, tone, pace or progression. The authors state this could provide insight on the physiology of learning and customizable approaches to introducing new information.

## Design Implications

### Context
#### Requirements
- A sensor array collecting biometric data; machine learning algorithms and neural networks for analysis; full-disclosure warning to the user before experience modification.
#### Constraints
- Speculative proposal: the article reports no implementation, and it poses as an open question whether the algorithm can create a model and teach any user after studying the data.

### Target Learners
- learners of all ages using immersive learning environments

### Target Learning Goals
- personalized introduction to new information
- improved decision making with the aid of automation and biometric data
