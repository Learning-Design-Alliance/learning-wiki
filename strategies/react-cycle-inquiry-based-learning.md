# Embed the ReACT reasoning-acting-observing-reflecting cycle in tutoring systems to mirror inquiry-based learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends embedding the ReACT cycle — reasoning, acting, observing, reflecting — into intelligent tutoring systems or classroom simulations. As the article states, "the ReACT cycle mirrors effective inquiry-based learning": students hypothesize (reason), experiment (act), interpret evidence (observe), and engage in metacognition (reflect). An agent designed with ReACT principles could guide students through scientific experiments, prompting them to predict outcomes, test hypotheses, and reflect on discrepancies, aligning with constructivist pedagogy.
