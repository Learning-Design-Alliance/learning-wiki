# Personalised email interventions via a student data table and mail-merge filtering

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
SPPA supports academic-led personalised email interventions by integrating class list, assessment data and prediction results into a single Student Table. Building on Pardo et al.'s OnTask idea, "SPPA incorporates this idea to enable personalised email interventions": academics import the table to a spreadsheet, filter to select student groups, and generate emails with the Microsoft Word Mail Merge tool, personalising fields such as student name and assessment scores. Academics are encouraged to follow the Hattie and Timperley feedback model in drafting emails, to attach personalised revision plans, and to save templates for reuse in future course iterations.

## Design Implications

### Context
#### Requirements
- Access to class list, assessment and prediction data to build the Student Table
- Academic drafting of intervention email templates
#### Constraints
- Emails are drafted and sent by academics; the tool facilitates rather than automates intervention content

### Target Learners
- at-risk tertiary students

### Target Learning Goals
- targeted support for predicted at-risk students
