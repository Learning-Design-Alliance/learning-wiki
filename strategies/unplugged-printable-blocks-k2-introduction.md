# Unplugged coding with printable motion and trigger blocks as a physical introduction to online coding

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The webinar provides printable block images of motion and trigger blocks so young children can manipulate physical blocks before coding online. Teachers use them to "let students create dance routines, maps, or directions around the classroom by writing their own code," making this a movement-based first introduction to coding.

## Design Implications

### Context
#### Requirements
- Printed block images for motion and trigger blocks
#### Constraints
- Positioned as an introduction before online coding, not a replacement

### Target Learners
- K-2 students

### Target Learning Goals
- Creating sequences of instructions (algorithms)
- Understanding that order of instructions matters
