# Number Rack App

## Description
Helps kids learn to use numbers and master them in a visual way, offering moveable, colored beads. Encourages learners to group and sort and, in the process, learn addition and subtraction. An engaging math app ideal for kids at the elementary level, offering learning modules for different skill levels and comes packed with text tools for writing equations.
