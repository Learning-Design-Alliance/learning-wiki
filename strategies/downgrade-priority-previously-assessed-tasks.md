# Downgrade assessment priority for tasks already assessed earlier in the course or program

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A concrete move within the prioritization process: "The instructor may find that the need to assess tasks which had been assessed earlier in the course (or, in the case of an upper-level course, earlier in the program) can be set at a lower priority, permitting the GenAI workforce competency to prevail." Instructors scan the inventory for tasks whose performance has already been assessed previously and lower their assessment priority, freeing those tasks for GenAI-supported competency building.

## Design Implications

### Context
#### Requirements
- Knowledge of which tasks were assessed earlier in the course or, for upper-level courses, earlier in the program
#### Constraints
- Applies only to tasks that have already been assessed earlier in the course or program

### Target Learners
- students in upper-level courses where tasks were assessed earlier in the program

### Target Learning Goals
- GenAI workforce competency development on previously assessed skills
