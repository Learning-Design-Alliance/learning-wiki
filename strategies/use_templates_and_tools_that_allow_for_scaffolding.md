# Use Templates and Tools That Allow for Scaffolding

## Description
Using templates and tools that allow for scaffolding involves providing students with structured supports to guide their writing process. This approach includes using planning templates, graphic organizers, and post-it notes to help students organize their ideas and develop their writing skills. Scaffolding is gradually removed as students become more proficient, fostering independence and confidence.

## Design Implications

### Context
#### Requirements
- Requires access to templates, graphic organizers, and other tools for planning and organizing ideas. Also requires explicit instruction on how to use these tools effectively.
#### Constraints
- May be perceived as overly structured by some students. Requires consistent implementation and ongoing support to be effective.
