# Accommodate slower processing speed in academic interventions for children with ADHD, alongside existing WM-focused approaches

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that academic interventions for underperformance in children with ADHD, which currently primarily target WM deficits, also consider processing speed. Concretely, it suggests children "can for example be provided with additional time to process assignments and tests or delivered important information or course content in advance to allow them more time to prepare and process certain materials." This follows from the finding that PS mediates the inattention–achievement relation.

## Design Implications

### Context
#### Requirements
- Interventions should include measures of or accommodations for processing speed, not only working memory targets
#### Constraints
- The mediation evidence is cross-sectional and observational, so no causal inferences can be made about the current results

### Target Learners
- Children aged 6–12 diagnosed with ADHD, particularly those with elevated inattention symptoms

### Target Learning Goals
- Reading, mathematics and spelling achievement
