# Using Mechanical Techniques: flashcard-based vocabulary practice with spaced self-testing

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
Using Mechanical Techniques is a direct vocabulary learning strategy in which learners use flashcards with the new vocabulary written on one side and the definition written on the other. Students write the new expression in a full sentence on flashcards to use vocabulary in context and get writing practice. Flashcards are moved from one pile to another depending on how well the students know them, and learners are required to read and practice the vocabularies during free time.
