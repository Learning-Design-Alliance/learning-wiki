# Assign the fractal drum project to pairs of students and integrate it into a computational physics class

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors recommend running the fractal drum project with students working in pairs and embedding it in a computational physics course, where the instructor's understanding of student difficulties improves support. They state "The ideal group size for conducting the proposed activities is two students to allow for discussions between them." Step-by-step student instructions from the authors' course are available as supplementary material for instructors adopting the project.

## Design Implications

### Context
#### Requirements
- Instructor access to the project formulation and step-by-step instructions provided as supplementary material
#### Constraints
- The recommendation reflects the authors' own experience presenting and supervising the project several times, not a controlled comparison of group sizes

### Target Learners
- advanced undergraduate physics students

### Target Learning Goals
- numerical problem solving
- collaborative discussion of computational methods
