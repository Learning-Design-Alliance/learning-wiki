# Use a set of predefined central-force exercises, solvable by simulation and in some cases analytically, as classroom activities

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article provides a list of predefined force fields the author "have used in the classroom, in the form of exercises to be solved by means of the program and, in some cases, by using analytical methods". Each exercise has a short formulation and comment: Newtonian Keplerian orbits for various energies and angular momenta; harmonic potentials to show every orbit is elliptic; Bertrand potentials to introduce precession and Bertrand's theorem; spring, constant-force, galaxy, Yukawa, ion-atom, Cotes, open-orbit, precession (general-relativistic perihelion) and light-deflection examples. Users can also define their own force law starting from a predefined one.

## Design Implications

### Context
#### Requirements
- Access to the Central Force Workbench program; exercises use units chosen so that k = m = GM = 1 in the included examples.
#### Constraints
- Some exercises, such as the light-deflection case, note that real physical values are too small to display, so the article advises using a not so small value for the parameter a.

### Target Learners
- students in an introductory course on mechanics

### Target Learning Goals
- understanding Keplerian and non-Newtonian orbits
- precession and Bertrand's theorem
- existence and stability of circular orbits
- numerical simulation of singular force laws
