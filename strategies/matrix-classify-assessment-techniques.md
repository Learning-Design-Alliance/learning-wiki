# Use the knowledge matrix to classify and select assessment techniques by type and quality of knowledge measured

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
As an example application, the authors used the matrix to classify assessment techniques by which knowledge types and qualities they can measure. The extended report indicates "the suitability of assessment techniques such as reproduction, thinking aloud, discontinuous thinking aloud, stimulated process recall, conversations, logfiles, card sorting, concept asso- ciation, external material, explanations, reconstruction, speed tests, and transfer for measuring specific types and qualities of learning."
