# Cue learners that interpreter services are available upon request in the case prompt or nurse script

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
Because some residents did not realize an interpreter could be called and later said they would have requested one, the authors recommend building an availability cue into the scenario materials. They write that "the door prompt or nurse script include a cue that MI services are available upon request or that all ancillary services typically available at the hospital are available," so that the assessment targets interpreter-use skill rather than awareness that services exist.
