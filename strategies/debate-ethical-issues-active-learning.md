# Use debates on controversial clinical issues as active-learning tools for higher-order thinking

## Description
In synchronous sessions, students debate ethical issues arising in clinical practice. The article states that "Debates allow students to argue about controversial problems using higher-order thinking skills" and that both the debate itself and its preparation "are considered active learning tools and can assist students in critical thinking skills development," citing prior work on debate in problem-based learning.
