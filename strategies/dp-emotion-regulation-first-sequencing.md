# Sequence DP training from emotion regulation and foundational skills to higher-order skills

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that when emotion regulation is necessary for skill performance, it takes precedence over other competencies: "Training progresses from basic to advanced, with foundational skills typically preceding higher-order ones." Supervisors create an emotionally safe space with clear boundaries and acceptance of mistakes, because direct feedback can trigger self-criticism and shame, and high emotional arousal limits therapists' capacity to learn. In the case, practicing emotional capacity and validation simultaneously was too challenging, so the supervisor removed the validation criterion and focused only on staying present with unpleasant feelings.

## Design Implications

### Context
#### Requirements
- A supervisory relationship with trust and flexibility to pause DP learning if needed
- Willingness to reduce skill criteria when practice is too emotionally demanding
#### Constraints
- Practicing emotional capacity and validation simultaneously hindered learning in this case, so feedback on validation skills was saved for the next session

### Target Learners
- early-career therapists whose emotional reactions interfere with skill performance

### Target Learning Goals
- managing the fix-it urge and staying present with difficult client emotions before rehearsing interventions

### Affordances
- Deliberate Practice Supervision Model
