# Use common departmental assessments written by an independent committee to benchmark instruction across sections

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The strategy is to coordinate common examinations at the course level—prepared jointly by all instructors roughly one week before each midterm and the global exam—so that pass rates can be compared across sections under a shared grading standard. The article concludes that "it enables cross-section comparison without relying on instructor-specific grading practices, and it provides a feasible reporting pipeline that can be repeated" term-to-term. In this implementation the common exams accounted for 50% of the final mark, with the remainder at instructor discretion.

## Design Implications

### Context
#### Requirements
- A coordinator or committee independent of the mode of instruction to prepare the common exams
- Instructor convening before each exam to align the exam with material covered
#### Constraints
- The final mark remains only partially standardized because 50% is determined by each instructor's own assessment design

### Target Learners
- undergraduate students in large multi-section gateway courses

### Target Learning Goals
- comparable measurement of passing outcomes across instructional modalities
