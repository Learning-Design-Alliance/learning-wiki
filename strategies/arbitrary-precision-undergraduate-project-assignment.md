# Undergraduate project assignment investigating exact calculation of numbers beyond floating point precision in Fortran

## Description
The paper's instructional strategy is an undergraduate project in a basic computational physics course, motivated by student questions about computing numbers beyond the machine's numerical limit. "The assignment asks students to investigate the approach of calculating the exact value of a large number beyond the ﬂoating point number precision, using the basic scientiﬁc programming language Fortran." Students implement array-based multiplication and division algorithms and explore methods such as successive multiplication of even numbers and division of overflowing floats.
