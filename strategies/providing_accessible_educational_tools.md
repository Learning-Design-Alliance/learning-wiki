# Providing Accessible Educational Tools

> **Strategy** · [All strategies](index.md)

## Description
Providing easy access to a variety of educational tools empowers students to take control of their learning. This approach involves making resources readily available in the classroom and explicitly teaching students how and when to use each tool. Tools include manipulatives, graphic organizers, audio recordings, magnifying paper, highlighters, [Choice Boards](../elements/choice-boards.md), learning menus, and timers — functioning both as [Accommodations](../elements/accommodations.md) for identified learners and as universal supports available to all.

## Design Implications

Tool access shifts the burden of adapting a task from the teacher to the learner, but only when tool use is explicitly modeled and practiced; unstructured access to tools tends to produce off-task use or tool avoidance rather than independence [~M]. External supports such as manipulatives and graphic organizers reduce working-memory demands during learning [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+S], and giving learners choice over which support to use builds autonomy and engagement [Autonomy supports intrinsic motivation.](../claims/autonomy-supports-intrinsic-motivation.md) [+M].

### Context
#### Requirements
- A curated set of tools matched to the tasks of the classroom, not a maximal collection
- A well-organized, labeled environment so tools can be located and returned independently
- Explicit instruction in how and when to use each tool, with [Practice](../elements/practice.md) and [Coaching](../elements/coaching.md) during authentic tasks
- Norms for self-service access so tool retrieval does not require teacher permission

#### Constraints
- Tool access without instruction in tool use yields little benefit; students may initially struggle or use tools as distraction [~M]
- Over-reliance on supports can persist past the point of usefulness; supports should be faded as competence grows, or automaticity of the underlying skill is delayed [-M]
- Requires upfront investment in materials and ongoing maintenance of the organized environment
- Poorly matched tools add extraneous load rather than reducing it [Cognitive overload degrades learning.](../claims/cognitive-overload-degrades-learning.md) [-M]

#### Implementation Variability
- Physical classrooms: manipulatives, highlighters, timers, magnifying paper, reference charts on open shelving
- Digital environments: text-to-speech, calculators, graphic organizer apps, and accessibility features built into platforms; digital tool access requires attention to device equity and training [~W]
- Tool menus ([Choice Boards](../elements/choice-boards.md)) can be teacher-curated, co-constructed with students, or fully student-generated as independence grows

### Target Learners
- Students with disabilities who benefit from [Accommodations](../elements/accommodations.md) embedded in general access rather than pull-out provision [+M]
- Multilingual learners using vocabulary supports, audio, and visual organizers [~M]
- All learners benefit when tools are universally available; restricting tools to labeled students stigmatizes and withholds useful supports from others [~M]

### Target Learning Goals
- Learner independence and self-regulated tool selection
- Reduced extraneous cognitive load during content learning
- Strategy knowledge: knowing *which* tool fits *which* task demand

### Affordances
- [Cognitive Load Management](../principles/cognitive-load-management.md) — tools such as manipulatives, organizers, and timers externalize memory and monitoring demands, freeing working memory for the actual learning task
- [Chunking](../principles/chunking.md) — graphic organizers and structured mats pre-chunk information into manageable units
- [Accessible Vocabulary & Syntax](../principles/accessible-vocabulary-syntax.md) — glossaries, audio recordings, and sentence frames make the same content reachable at varied language levels
- [Clear Structure](../principles/clear-structure.md) — learning menus and choice boards make the path through a task visible and navigable without teacher mediation

### Personalization
- Tools can be selected based on students' interests, needs, and task demands; the goal is progressive transfer of selection decisions from teacher to student, so learners learn to diagnose their own needs and choose supports accordingly.

### Instructions
1. Audit the tasks of the unit and identify the points where learners typically stall; select tools that address those specific demands.
2. Introduce each tool with a brief [Demonstration](../elements/demonstration.md) of its purpose and use — name the situation in which it helps.
3. Provide structured [Practice](../elements/practice.md) using the tool during authentic work, with [Coaching](../elements/coaching.md) and [Feedback](../elements/feedback.md) on tool selection, not just task performance.
4. Make tools self-service: label, organize, and normalize access so retrieval requires no permission.
5. Offer a [Choice Board](../elements/choice-boards.md) or tool menu so students select supports themselves; discuss choices during [Check-ins](../elements/check-in.md).
6. Fade supports as fluency develops, and teach students to recognize when they no longer need a tool.

## Examples
- **Elementary mathematics:** Place-value mats, base-ten blocks, and number lines kept on open shelves; students retrieve them during problem solving rather than waiting for distribution. Research on concrete manipulatives supports moderate learning benefits when use is connected to abstract representation [+M].
- **English language arts:** Story planners, graphic organizers, and highlighters available at a writing station; audio recordings of texts provide access for striving readers.
- **UDL-aligned platforms:** [CAST's UDL Guidelines](https://udlguidelines.cast.org) treat multiple means of action and expression — including tool access — as a core design principle; tools like [Khan Academy](https://www.khanacademy.org) embed hints, audio, and pacing controls that learners self-select.
