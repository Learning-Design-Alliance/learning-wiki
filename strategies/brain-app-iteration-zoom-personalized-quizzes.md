# Iterate the app with automatic zoom for small structures and longitudinally saved, personalized quiz content

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The authors recommend two concrete improvements for future app versions. First, adding "an automatic zoom function during user interactions with these minute components" to improve visibility of small anatomical structures. Second, building on the existing 10-question multiple-choice quiz by longitudinally saving students' quiz results so subsequent quizzes can personalize their content focus, since personalized activities targeting areas of weakness best support student success.

## Design Implications

### Context
#### Requirements
- A measure of individual progress via saved quiz results within the app's framework
- Automatic zoom functionality during interactions with minute components
#### Constraints
- These improvements are predictions for future versions; neither has been implemented or evaluated in the current app

### Target Learners
- anatomy students using the mobile or desktop app

### Target Learning Goals
- identifying small neuroanatomical structures
- improving areas of individual weakness through self-assessment
