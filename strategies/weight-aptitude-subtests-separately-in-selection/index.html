When using aptitude tests for selection, consider each subtest component separately and weight components by their known predictive power and curriculum emphases¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 quant-synthesis), q3 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

The article recommends that medical schools using aptitude tests evaluate subtest domains individually rather than relying on the overall score. It states: "when medical schools use aptitude tests, they should consider each component separately rather than relying on the overall score." This follows from the meta-analysis finding that subtest predictive power varies by outcome and program stage.

Design Implications¶

Context¶

Requirements¶

  • Aptitude tests with separable subtest domains (abstract, interpersonal, verbal, quantitative reasoning) must be in use

Constraints¶

  • The recommendation rests on the article's own meta-analytic effect sizes; the authors note more evidence is needed on interpersonal reasoning's predictive value for clinical and end-of-program outcomes

Target Learners¶

  • undergraduate medical program applicants

Target Learning Goals¶

  • predicting academic and clinical performance during the medicine program

Claims¶

  • Within aptitude test subtests, verbal reasoning (d=0.704) and quantitative reasoning (d=0.643) best predict early program academic results, while abstract and verbal reasoning predict end-of-program outcomes [+W]
  • Overall aptitude tests predict early program academic results (d=0.550), end of program academic results (d=0.371), and end of program clinical exams (d=0.448), but not early program clinical exams [+W]

Related Strategies¶

  • Develop tests of native aptitude for each school subject separately and question the Accomplishment Quotient
