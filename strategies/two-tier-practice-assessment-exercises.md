# Two-Tier Interactive Exercise Design: Practice Exercises with Hints vs Assessment Exercises without Feedback

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The system provides two types of interactive exercises: practice exercises equipped with hints and assistance during learning sessions, and assessment exercises used to examine student progress without providing feedback during interaction. Practice exercises provide help and immediate feedback after incorrect actions because the main objective is to help the student learn. Assessment exercises provide feedback only after the student submits an answer. This separation supports both guided learning and independent knowledge demonstration.

## Design Implications

### Context
#### Requirements
- System must distinguish between practice and assessment modes
- Hint and feedback mechanisms for practice exercises
- Delayed feedback delivery for assessment exercises
#### Constraints
- Assessment exercises provide no feedback during student interaction

### Target Learners
- Undergraduate computer science students

### Target Learning Goals
- Applying search algorithms step by step
