# Using Technology

## Description
Technology is a powerful tool in math instruction for ELLs. Look for educational resources that accompany school's technology tools and programs. Find out what's available online. If students are using a calculator or other device, ensure that they learn how to use it. Learn more about how to use AI tools in math. Look for interactive games that offer students a chance to practice their mathematical skills.
