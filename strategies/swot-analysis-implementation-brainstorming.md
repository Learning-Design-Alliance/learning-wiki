# Use SWOT analysis as a brainstorming and strategic-planning tool at points where creative problem-solving is needed

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 qualitative, 1 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The chapter pairs SWOT Analysis (Strengths, Weaknesses, Opportunities, and Threats), drawn from Project Planning Research ([Madsen, 2016](https://doi.org/10.1119/1.5011826); Namugenyi et al., 2019), with the EPIS Framework. While EPIS ensures no critical step is skipped, SWOT analysis "stimulates creative problem-solving in selecting strategies to overcome the unique challenges and opportunities present in the local context of a project", and is recommended for the intervention fit assessment and the organizational capacity and barriers assessment.

## Design Implications

### Context
#### Requirements
- Diligence in using SWOT analysis to craft a detailed Theory of Change supports later strategizing
#### Constraints
- Because there is no formula for strategizing about contextual factors, implementation and sustainment planning remains a process of creative brainstorming

### Target Learners
- implementation teams including external experts and local organizational members

### Target Learning Goals
- identifying barriers, facilitators, and adaptable implementation strategies in the local context
