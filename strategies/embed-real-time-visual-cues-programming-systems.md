# Embed immediate, visually aligned cues in programming instruction systems to guide learners' strategic attention

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 causal, 1 theoretical), `q2`–`q3` · 1 of 2 report an effect size · 5 claims rest on one study

## Description
Based on their findings, the authors recommend that instructional systems go beyond textual hints or delayed feedback. They advise that "instructional systems can embed immediate, visually aligned cues that guide learners' strategic attention during problem-solving," for example by integrating real-time visual representations that dynamically reflect code execution and synchronizing color-coded code blocks with corresponding visual outputs to make abstract logic explicit and reduce cognitive load.

## Design Implications

### Context
#### Requirements
- A programming environment capable of displaying real-time program output synchronized with color-coded code blocks
#### Constraints
- The article notes the supportiveness of visual scaffolding for programming performance was not directly examined in the present study

### Target Learners
- Programming learners, especially those with lower executive function

### Target Learning Goals
- Adopting effective top-down programming strategies and constructing a global understanding of program flow
