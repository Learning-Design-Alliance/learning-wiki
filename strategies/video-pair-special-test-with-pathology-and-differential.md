# Design instructional videos that pair each special test with the underlying pathology it detects and how the result should shift the differential diagnosis

## Description
The article recommends that future instructional videos move beyond demonstrating anatomy and examination technique in isolation. Specifically, "videos could pair each special test with a brief discussion of the underlying pathology it is meant to detect, the range of conditions that could produce a similar finding, and how the result should shift or narrow the examiner's differential." This strategy aims to build diagnostic reasoning alongside procedural skill.

## Design Implications

### Context
