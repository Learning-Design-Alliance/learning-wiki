# Integrate peer assessment into game development activities to deepen student learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article proposes embedding peer assessment within student game development as a learning strategy. Students build educational computer games and evaluate peers' games, which the authors found promoted achievement, motivation, problem-solving skills and perceptions of educational games, and which students described as improving "in-depth thinking," "creativity," and "motivation." It is an implementable recipe for game-based learning courses.

## Design Implications

### Context
#### Requirements
- A course context in which students develop educational computer games
- A peer assessment mechanism through which students review each other's games
#### Constraints
- Evaluated with sixth graders in an elementary science course

### Target Learners
- elementary school students

### Target Learning Goals
- deep learning
- problem-solving skills
- learning motivation
