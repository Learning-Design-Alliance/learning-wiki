## Description
The editorial lists, as part of the special issue's coverage, "the use of external representations to help manage CL in Computer Supported Collaborative Learning environments (Van Bruggen, Kirschner, & Jochems)". As a strategy, it directs designers of CSCL environments to provide external representations so that collaborative learning does not overload working memory. The editorial announces this approach without reporting the article's findings or specifying which representations are used.

## Design Implications

### Context
#### Requirements
- CSCL environments must offer external representations that offload load that would otherwise burden learners' working memory during collaboration
#### Constraints
