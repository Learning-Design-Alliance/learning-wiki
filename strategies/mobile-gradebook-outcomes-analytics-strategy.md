# Adopt a mobile-based gradebook with outcomes analytics to support feedback and academic planning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors recommend using the tool to provide constant feedback to students as they progress toward intended learning outcomes and to support teachers' planning, feedback systems and academic improvement. Concretely they advise to "utilize the program by means of providing more learning outcomes based on Commission on Higher EducationMemorandum Order" and to improve update options so gradebook and evaluations can create different graphics in student outcomes analytics.

## Design Implications

### Context
#### Requirements
- Integration with a college enrollment system for more accurate data (recommended)
- Evaluation and gradebook data entry routines in place
#### Constraints
- Findings rest on one institution's computer studies department and a user-perception evaluation

### Target Learners
- higher education students
- higher education instructors

### Target Learning Goals
- enhancing feedback on learning outcomes
- supporting teaching and learning activity planning
