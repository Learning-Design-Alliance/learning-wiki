# Вибір моделі комбінованого навчання за вісьмома критеріями Дж. Берсіна

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Стратегія вибору моделі комбінованого навчання для конкретного курсу за критеріями, які «Дж. Берсін [3, 265–267] відносить: 1) тип навчального курсу (ознайомлювальний, практично-орієнтований, завершальний тощо); 2) культурні цілі (вплив очної частини курсу на досягнення цілей навчання); 3) аудиторію (розмір, розподіл навчальних ролей, рівень освіти, володіння засобами ІКТ, мотивація тощо); 4) бюджет; 5) ресурси; 6) розподіл навчального часу; 7) зміст навчання; 8) технологічні обмеження». Критерії ураховують специфіку конкретного курсу.

## Design Implications

### Context
#### Requirements
- оцінювання курсу за всіма вісьмома критеріями перед вибором моделі
#### Constraints
- критерії ураховують специфіку конкретного курсу, тоді як для побудови системи комбінованого навчання у вітчизняних ВНЗ потрібні додаткові врахування

### Target Learners
- студенти ВНЗ
- дорослі у корпоративному навчанні

### Target Learning Goals
- проєктування комбінованого навчання для конкретного курсу

### Affordances
- Bersin Five Blended Learning Models Taxonomy
