# Use key feature problems in written assessment and select CSE case elements targeting error-prone decisions to improve predictive validity

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors recommend expanding the key features approach, in which test material focuses on components of a case where physicians must make critical decisions where errors could affect patient outcome. They state "it may be useful to increase the use of key feature problems in traditional written assessment, as this format appears to be more predictive of quality-of-care complaints than ordinary multiple-choice questions," and that the discriminating ability of CSE data acquisition and problem-solving assessment may be improved by selecting aspects of data collection that are critical for a given clinical problem and where physicians tend to make errors.

## Design Implications

### Context
#### Requirements
- Selecting case and test elements on the same basis as key feature written problems: aspects critical for a given clinical problem where physicians tend to make errors
#### Constraints
- The data collection and problem-solving components of the CSE, not selected on this basis, showed no relationship to complaint rate

### Target Learners
- medical graduates taking national licensing examinations

### Target Learning Goals
- clinical decision making and data collection skills that predict quality-of-care outcomes in practice
