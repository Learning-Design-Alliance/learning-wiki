# Embed a CAS in an e-book file to give e-books interactive step-by-step problem solving, error feedback and interactive graphs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A proposed use of a computer algebra system to add special interactivity to electronic books: for an e-book built in an appropriate language such as EPUB, the possibility of step-by-step analytical solutions, feedback about errors and interactive graphs could be reached by attaching a CAS software to the e-book file. The e-book would send input lines to the CAS and get the output. The authors note a javascript version of the CAS could be necessary to keep the e-book compatible with the environment where it is usually run.

## Design Implications

### Context
#### Requirements
- An e-book built in an appropriate language (EPUB, for instance)
- A CAS attached to the e-book file, possibly a javascript version for compatibility
#### Constraints
- A javascript version of the CAS could be necessary to maintain compatibility with the environment where the e-book is usually run

### Target Learners
- readers of interactive e-books for Physics, Mathematics or Chemistry

### Target Learning Goals
- solving analytical problems step-by-step with feedback about errors and interactive graphs
