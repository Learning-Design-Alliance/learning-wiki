# Structure preceptorship around a written guide specifying case discussion, reasoning prompts, real-time feedback, and management-plan formulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (1 for, 1 mixed, 1 against) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The intervention used a written guide refined by experts that "specified the core structure of each session, including case discussion, prompting of clinical reasoning, real-time feedback, and formulation of management plans," grounded in real patient cases from the same day. Preceptors were trained in the six cognitive apprenticeship methods (modeling, coaching, scaffolding, articulation, reflection, exploration).

## Design Implications

### Context
#### Requirements
- Preceptor training in the cognitive apprenticeship model before the program
- A written session guide developed and refined by experts
#### Constraints
- Blinding of participants and preceptors was not feasible due to the visible nature of the intervention

### Target Learners
- pediatric residents in postgraduate specialist training

### Target Learning Goals
- clinical reasoning
- management decision-making
