# Use the diverse e-learning activity repertoire (microlearning, gamification, adaptive quizzes, virtual patients) matched to learning needs

## Description
The editorial enumerates the e-learning activity types available in medical education: "microlearning, gamification, case-based learning, video-driven spaced repetition, adaptive quizzes, interactive tutorials, blogs, mobile learning, and analytics-driven learning". It notes that integrating AI and machine learning enhances personalization, and that virtual patient platforms let learners practice clinical reasoning in safe, repeatable environments.
