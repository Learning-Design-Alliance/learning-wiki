# Rewrite multi-sign expressions so each minus sign sits next to the element it belongs to

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An in-the-moment algebraic move observed during the oral exam: Oliver rewrote his expression so each minus sign sat beside the element it belonged to. The article reports this 'helps Oliver better distinguish and understand the meaning of the signs', supporting a general practice of making sign ownership visible when several negative signs in one expression carry different physical meanings.

## Design Implications

### Context

- A mathematical expression in which multiple negative signs carry different physical meanings, so each sign's ownership must be made visible
