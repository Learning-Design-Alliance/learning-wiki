# Use generative AI as an on-demand alternative to manuals and web searches when learning unfamiliar research software

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (2 for, 3 mixed) · 3 studies (1 causal, 1 qualitative, 1 design), `q2` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
A concrete strategy demonstrated at the hackathon: instead of reading manuals and searching websites, users upload a task image or problem statement to ChatGPT and request step-by-step instructions for the target software, then execute them. The authors report that "using generative AI in this way, we can significantly reduce the effort required for learning the software", and several participants went on to successfully use software they had not used before.

## Design Implications

### Context
#### Requirements
- A generative AI tool such as ChatGPT and access to the target software to execute the generated instructions
#### Constraints
- The generated instructions must still be verified by running them, and correctness is not guaranteed

### Target Learners
- beginners encountering unfamiliar research software
- advanced users exploring advanced features

### Target Learning Goals
- rapid acquisition of software operation skills for data analysis tasks
