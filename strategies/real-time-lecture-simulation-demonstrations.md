# Real-time lecture demonstrations deriving theoretical predictions and testing them numerically with modifiable code

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The easiest use of the material is in lecture demonstrations, where the simple Python source code allows changes even during lecture. "It was found to be very useful to derive theoretical predictions and then test these numerically in real time." The author reports that these simulations made theoretical discussion much more tangible and led to a lot of questions and interaction during lectures, for audiences from lower-division undergraduates to graduate students.
