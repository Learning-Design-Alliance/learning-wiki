# Implement pencasts with a low-stakes trial recording, flexible device choice, and YouTube link submission

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors' practical implementation recipe: give instructions via example pencasts made with different technologies, start with "a short recording about themselves" as a trial run to identify and fix technical difficulties without the pressure of solving physics problems, let students use any device, and have students "export their videos to YouTube and then send the link to the instructor" when file sizes are too large to transfer directly.

## Design Implications

### Context
#### Requirements
- Students must choose YouTube's middle privacy level so the instructor can view the video via link
- A trial recording is needed to identify and fix production or uploading difficulties before graded assignments
#### Constraints
- Phones recording automatically in HD produced file sizes too large to transfer directly to the course management system or via email; this was the issue the YouTube workaround solved
- Some students worried about audio quality, though consumer-grade audio proved sufficient

### Target Learners
- university students in small-enrollment physics courses; the authors state the method suits any class of similar size

### Target Learning Goals
- documenting and communicating the problem-solving process in physics homework
