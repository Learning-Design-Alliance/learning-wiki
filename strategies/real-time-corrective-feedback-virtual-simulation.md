# Embed immediate corrective feedback in virtual simulation practice sessions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The platform "incorporates formative assessments by providing immediate feedback during practice sessions": when a student misidentifies a structure, the platform "offers real-time corrective feedback, thereby reinforcing the correct information". The authors align this with the testing effect, using formative assessment within simulation to reinforce learning. This is a design feature of the platform evaluated in the study, implemented via the platform's built-in assessment logic.
