# Adopt PBL-based techniques and strengthen curriculum coverage so linear programming is taught to all learners

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends that teachers use PBL-based techniques such as the origin test and extreme points technique, since results showed learners taught with PBL "achieved better results than those taught using conventional methods". It further urges curriculum planners (KIE) to examine the nature, depth and breadth of linear programming coverage, and addresses sequencing and timing so the topic is taught to all learners given its usefulness in daily life.

## Design Implications

### Context
#### Requirements
- Teacher familiarity with the origin test and extreme points technique as an alternative to trial-and-error or search line methods
#### Constraints
- Recommendations arise from one non-equivalent groups study in Kakamega County, Kenya

### Target Learners
- form four secondary school students in Kenya

### Target Learning Goals
- linear programming knowledge, skills, and acceptance of the topic as useful in daily life
