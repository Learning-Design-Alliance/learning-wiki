# Assign a language function to each 5E phase (describe, compare and contrast, classify, classify with justification) and align language objectives with science objectives

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The Montebello project added a language column to the 5E template so teachers identified the major language focus of each lesson phase. For example, in the Engage phase students might "use language to describe a concept," while in Explore and Explain they might compare and contrast and classify concepts, and in Elaborate they might classify a concept with justification. This reflects the principle that rich conversations do not just occur—language objectives, like science objectives, must be identified and learning experiences orchestrated.
