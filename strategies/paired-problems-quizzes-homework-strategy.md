# Assign paired problems as quizzes or homework so students transfer the tutorial-taught approach without help

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 causal, 1 design, 1 theoretical), `q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The article recommends that each tutorial problem be matched with paired problems that use similar physics principles but differ in context, so students learn to decontextualize the problem-solving approach. The paired problems serve the weaning function of the learning model, and the summary states that "The paired problems can be incorporated into regular quizzes or assigned as homework problems". Instructors can tell students the tutorials are available as a self-paced study tool if they have difficulty with the paired homework problems.
