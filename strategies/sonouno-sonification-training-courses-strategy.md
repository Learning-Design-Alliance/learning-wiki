# Combine sonification training courses with sonoUno use to strengthen both the technique and the tool

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends combining training courses for sonification with use of the sonoUno software as a starting point for learning data analysis through sound. The authors write: "Perhaps, a combinat ion of training courses for sonification using sonoUno cou ld be a good starting point, strengthening the technique al ong with making sonoUno more powerful and user-centred." Training addresses both the tool and the sonification technique itself, which participants found new and difficult to use for identifying trends.

## Design Implications

### Context
#### Requirements
- Training must cover both the use of the prototype and the sonification technique, with guidelines to ensure most people understand the same data in a cohesive manner
#### Constraints
- Sonification applied to analyse datasets is a new approach and participants lacked experience using sound, so guidance is needed to gain confidence in the technique

### Target Learners
- researchers and interested citizen scientists, with and without visual impairment

### Target Learning Goals
- analysing astrophysical data through sound

## Claims

- [Participants became much more confident using SonoUno in the second session, indicating a fast learning curve, but requested training in both the tool and the sonification technique](../claims/sonouno-fast-learning-curve-training-needs.md) [+W]
