# Use diverse facilitation techniques including think-aloud, semantic qualifiers, illness scripts, and case-based learning

> **Strategy** · [All strategies](index.md)

## Description
The review identifies multiple concrete techniques clinical teachers can implement to facilitate clinical reasoning. These include the "think-aloud" approach, using semantic qualifiers, self-explanation by students, illness script approach, peer teaching, presenting clinical cases, and conducting small group learning. The review also lists verbal case reports, virtual patient case simulation, problem-based learning tutorials, and Bayesian learning methods. Teachers should select techniques adapted to meet specific requirements of the learning context and students' needs.

## Design Implications

### Context
#### Requirements
