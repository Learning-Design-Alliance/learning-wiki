# Calibrated disclosure templates scaled to risk of the permitted use

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article proposes a three-tier disclosure model: no disclosure for embedded low-risk functions such as basic spellcheck; a one-line disclosure for external language editing; and a short process note only where an assessment expressly permits higher-risk assistance. The one-line disclosure is 'intentionally shorter than a typical bibliographic entry', so EAL students using routine language support face no greater compliance costs than monolingual peers. Box 2 provides ready-made templates.

## Design Implications

### Context
#### Requirements
- Disclosure requirements must be tied to what is meaningful for construct protection
- Assessment instructions must state which disclosure tier applies
#### Constraints
- Exhaustive prompt logging is disproportionate and can chill legitimate support; chat logs are curatable, incomplete, and differentially burdensome for EAL students

### Target Learners
- EAL and multilingual students in higher education

### Target Learning Goals
- Transparent, feasible disclosure of GenAI use without punitive burden on legitimate language support
