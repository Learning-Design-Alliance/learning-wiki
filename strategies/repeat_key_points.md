# Repeat Key Points

## Description
Repeat the key points for students several times and in several different ways. Multiple representations of the key ideas can provide learners the opportunity to absorb all concepts.

## Design Implications

### Context
#### Requirements
- Careful lesson planning to identify key concepts. Thoughtful language choices so students can follow along.
#### Constraints
- Repetition can be boring, so use sparingly. Students need to be self-aware to identify if they aren't processing information and ask for repetition.

### Affordances
- Provides multiple exposures to key concepts, uses plain language that provides comprehension.

### Personalization
- Allow students to repeat concepts for other students. Encourage self-monitoring so that students can realize what they didn't understand.
