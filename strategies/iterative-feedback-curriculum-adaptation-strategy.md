# Use iterative resident feedback to identify modifiable delivery barriers and make targeted, low-resource curriculum adaptations between iterations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article presents iterative curriculum evaluation as an implementation strategy: structured resident feedback identifies modifiable barriers to delivery, and targeted adaptations—such as adding explicit learning objectives and preparatory materials—are made while preserving core curriculum components. The authors state that "modest, low-resource modifications can enhance acceptability and effectiveness while preserving core curriculum components," and that this adaptive approach supports fidelity, scalability, and sustained integration of simulation into residency training.

## Design Implications

### Context
#### Requirements
- A structured learner feedback mechanism after each session or iteration, and a process for translating feedback into targeted adaptations between iterations
#### Constraints
- Outcomes in the supporting study were limited to learner-reported measures, with no objective assessments of technical performance

### Target Learners
- Residency trainees in simulation-based surgical curricula

### Target Learning Goals
- Improved perceived preparedness and educational value of simulation sessions through iterative curriculum refinement
