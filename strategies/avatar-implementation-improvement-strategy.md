# Implement four user-suggested improvements when deploying interactive clinical avatar simulations

> **Strategy** · [All strategies](index.md)

## Description
A concrete implementation recipe drawn from content analysis of user feedback: "Four improvements were suggested: providing an example simulation, including a help button or email address for technical issues, including key learning points at the end of the case study, and increasing the size of the question bank (most commonly suggested)." Increasing the question bank addresses free-text recognition frustrations; an example simulation and signposted help support first-time users; end-of-case key learning points support reflection.
