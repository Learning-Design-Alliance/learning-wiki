# Use opportunistic experiments embedded in ongoing program changes to build low-cost evidence

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that state and district administrators, with a research team, introduce experiments into the normal course of action. It states these "opportunistic experiments" can be cost effective, generate strong evidence for educational decisions, and replicate promising findings from previous evaluations. Federal guidance cited in the abstract encouraged agencies to propose high-quality, low-cost evaluations built into ongoing program changes using existing administrative data.

## Design Implications

### Context
#### Requirements
- Relatively easy access to data about key outcomes, such as administrative record data from SLDSs
#### Constraints
- Feasible only if administrative records data are readily available; obtaining data can be difficult and time-consuming due to data access issues and staff availability

### Target Learners
- Students in state and district education programs

### Target Learning Goals
- Estimating intervention effectiveness on achievement outcomes
