# Scaffold interaction by task type, gender pairing, proficiency, explicit instruction and pre-task planning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The review distills classroom recommendations from the pooled evidence: teachers should attend to task type when assigning interactive tasks, consider gender of paired partners using local research, scaffold beginners through activities with greater interaction as proficiency and confidence increase, and "provide explicit instruction in forms to be acquired and strategies to be used prior to interaction and offer opportunities for pre-task planning". Outside class, interaction need not be face-to-face: journals, online chats, email exchanges and computer feedback all count.

## Design Implications

### Context
#### Requirements
- Teachers must adjust interactive task assignments to local context, using local or action research on gender pairing effects
#### Constraints
- The review notes the number of eligible studies might have been larger if the search had not been limited to abstract keywords and three databases; quantitative studies mostly had small samples around 40

### Target Learners
- EFL learners in foreign language classrooms, university students predominantly

### Target Learning Goals
- Foreign language interaction and output quality
- question development
- reading and writing skills
