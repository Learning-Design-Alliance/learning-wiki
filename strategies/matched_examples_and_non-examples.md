# Matched Examples and Non-examples

## Description
Present matched examples and nonexamples for concepts with related attributes. Nonexamples are an instance that is specifically not an example of the concept being learned. Nonexamples should vary in one attribute from the example with which it is paired. Matched examples and nonexamples should be present in working memory simultaneously.

## Design Implications

### Context
#### Requirements
- Requires careful selection of examples and non-examples that differ by only one attribute.
#### Constraints
- Can be challenging to identify appropriate non-examples. Requires careful presentation to avoid confusion.

### Target Learners

- All learners, especially for concepts with closely related attributes

### Target Learning Goals
<!-- Link to sub-claims -->
- Promote accurate concept formation, avoid overgeneralization

### Affordances
- Sharpens discrimination skills by highlighting what a concept is and is not. Reduces the risk of overgeneralization.

### Personalization
- Select examples and non-examples that are relevant to learners' experiences and prior knowledge.
