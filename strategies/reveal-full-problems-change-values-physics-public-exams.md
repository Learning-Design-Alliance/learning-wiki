# Adapt Public Exams to physics by heavily emphasizing the procedural aspects of problems, e.g. fully revealed questions with changed values or figures on the actual exam

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (4 for, 1 mixed, 2 against) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 7 claims rest on one study

## Description
The article proposes modifying the Public Exam system, which discloses partial question content ahead of the exam and invites student edits, so that it suits physics' emphasis on applying procedural knowledge. The authors state that "it is possible to use afully revealedpublic question and just change the numbers to assess the application of procedural knowledge", and that the system "could be adapted to a physics context by heavily emphasizing the procedural aspects of a problem". Students themselves requested complete problem information with changed numerical values, and equations provided for each problem.

## Design Implications

### Context
#### Requirements
- Students must be able to see the complete problem format, including figures and equations, in the Public Exam version
- The actual exam must vary numerical values or figures from the publicly revealed version
#### Constraints
- The study's Public Exam window was only a few days, shorter than the one week in Wiggins et al.'s biology implementation
- The system as previously described is, in the authors' judgment, not optimized for use in physics

### Target Learners
- introductory algebra-based physics students at a Hispanic-Serving Institution

### Target Learning Goals
- applying procedural knowledge in physics problem solving
- reducing test anxiety
- directing study to core concepts
