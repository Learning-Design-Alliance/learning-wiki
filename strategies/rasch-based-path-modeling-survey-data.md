# Use Rasch-based path modeling to analyze Likert-scale survey data in learning technology acceptance research.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 associational), `q2` · 1 of 1 report an effect size · 5 claims rest on one study

## Description
The study demonstrates a two-step approach: Rasch analysis converts ordinal Likert-scale data into interval-level person measures, which are then subjected to path analysis. This addresses limitations of classical test theory approaches that treat ordinal data as interval. The authors state this "opens up a promising possibility for future studies in the field" needing "a more rigorous statistical approach to the analysis of survey scale data."

## Design Implications

### Context
#### Requirements
- Rasch analysis software such as WINSTEP
- Path analysis software such as IBM SPSS AMOS
#### Constraints
- Rasch-based path analysis does not take the measurement errors of person measures into account
