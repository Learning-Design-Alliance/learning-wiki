# Prioritize reforming in-class instruction toward student-centered pedagogy when instructors must choose one pedagogical element to improve first

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (1 for, 2 mixed) · 2 studies (1 associational, 1 theoretical), `q1`–`q3` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
Because instructors cannot improve all pedagogical elements at once, the article recommends weighing which element of learner-centered pedagogy to reform first and choosing in-class student-centered teaching. The authors state that "in-class student-centered teaching will positively impact students far more than any other component of pedagogy," based on their finding that RTOP learner-centeredness, not assessment level or alignment, explained gains in higher-order cognitive skills.
