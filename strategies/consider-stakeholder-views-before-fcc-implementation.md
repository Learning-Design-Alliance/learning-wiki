# Consider differing stakeholder views on family-centred care before implementing new FCC interventions into nursing practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Because the study found substantial disagreement among professionals on which FCC competencies matter most, the authors recommend that implementation of FCC into practice account for divergent stakeholder views. They write that "any implementation of FCC into practice should consider different views on FCC that might exist among stakeholders", and that the competency set can inform initial and continuing nurse education curricula and support evaluation of practising nurses.

## Design Implications

### Context
#### Requirements
- Education and implementation efforts should be supported by initial and ongoing education, organizational support and explicated professional expectations, as the article states
#### Constraints
- The low explained variance means no synthesized, shared perspective on competency importance is supported by the data, so the set should be used as a ranked item list rather than as consensus profiles

### Target Learners
- Registered nurses in hospitals
- Nursing educators and curriculum designers

### Target Learning Goals
- Delivery of family-centred care in daily hospital practice
