# Build a project-based computational physics course grounded in expert practice, culminating in a student-chosen final project

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 associational, 1 design), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
The article highlights Burke and Atherton's Tufts course, which modified its competency list based on interviews with faculty and postdocs active in computational physics research, producing a model that "included	meta-competencies	seldom	found	in	traditional	undergraduate	CP	courses". Learning goals span modeling a physical system, designing-implementing-validating code, numerical analysis, testing hypotheses via visualization, and connecting theory, experiment and simulation. Learning is implemented via short projects in classical, quantum and statistical physics culminating in a final project of the student's choice, with authentic research activities such as reading papers, working in groups, running and documenting code, and version control.

## Design Implications

### Context
#### Requirements
- Competency lists should be grounded in interviews with faculty and postdocs active in computational physics research
- Projects should highlight authentic research-related activities like reading papers, consulting Internet resources, working in groups, running code, testing performance, documenting, and version control
#### Constraints
- Course evaluations pointed to constructive changes such as additional scaffolded learning for students with different backgrounds, and better management of group dynamics

### Target Learners
- undergraduates at roughly a sophomore level

### Target Learning Goals
- model a physical system
- design-implement-validate code
- understand the importance of numerical analysis
- test hypotheses via visualization
- connect theory, experiment and simulation
