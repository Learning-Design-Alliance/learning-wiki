# Use the installation as a base for follow-up topics: changing constellations, star sizes, light travel times, and stellar evolution

## Description
The article lists possible follow-up activities that the installation supports: 'Changing constellations in space and time', 'Sizes of stars', 'Light travel times and light years', and 'Stellar evolution'. Because the model is full-scale and walkable, students can view the constellation from positions other than Earth's, seeing it distort, which opens these extensions.
