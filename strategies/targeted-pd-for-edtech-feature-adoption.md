# Provide targeted professional development to encourage teacher understanding and use of learner-variability features

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Because survey data showed many teachers believed features could support learning but far fewer knew about or used them, and student data showed a student's teacher strongly predicts feature use, the report recommends professional development that specifically encourages understanding and use of these features, perhaps through coaching or examples from other teachers. A teacher quoted in the report asked for "more tutorials on the different features…if you could model how some of these features are used," reflecting time constraints teachers face.

## Design Implications

### Context
#### Requirements
- Requires deliberate outreach beyond platform availability, since awareness and use lag behind perceived value.
#### Constraints
- Teachers report limited time to explore platform features on their own.

### Target Learners
- K-12 classroom teachers and school-based specialists using edtech platforms

### Target Learning Goals
- Effective adoption of learner-variability supports in edtech
