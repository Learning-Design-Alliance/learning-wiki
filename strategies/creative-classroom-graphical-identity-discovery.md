# Creative classroom: students exploratively discover vector calculus identities from the basic graphical grammar

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors propose presenting students only the basic grammar of the graphical notation and letting them spontaneously and exploratively find the identities, perhaps in a group; the teacher collects results, holds group presentations, and introduces missing identities. This turns a formula-memorizing class into an amusing voluntary learning experience in which students voluntarily build tensorial structures and gain intuitions.
