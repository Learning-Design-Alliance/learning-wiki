# Five design principles for responsible implementation of AI-generated course readings

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article proposes a replicable set of implementation principles for instructors using AI-generated readings: "treat generation as draft production; the instructor must review outputs and correct weak citations", maintain explicit norms requiring follow-up questions and verification, use applied activities (case analysis, simulations) as the quality-control layer, position the assistant as a fallible guide rather than an authoritative text, and build iterative refinement into the workflow so outputs improve across weeks.

## Design Implications

### Context
#### Requirements
- Requires instructor capacity for systematic review of generated outputs and explicit course norms for verification and follow-up questioning.
#### Constraints
- Documented in a single graduate course with a small sample; transferability to undergraduate or large-enrollment settings is untested.

### Target Learners
- graduate professional students
- instructors in higher education

### Target Learning Goals
- responsible use of AI-generated instructional text
- verification literacy and critical engagement with probabilistic text
