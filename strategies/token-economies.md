# Token Economies

## Description
A **secondary reinforcer** has no inherent reinforcing value of its own and only reinforces because it has been linked to a **primary reinforcer** (food, water, sleep, shelter, touch, pleasure — reinforcers organisms do not lose their drive for). Praise, money, and stickers are all secondary reinforcers. A **token economy** is an entire behavior-management system built around token-form secondary reinforcers: learners earn tokens for target behaviors, then exchange accumulated tokens for backup rewards or privileges. Token economies have been found effective at modifying behavior across settings including schools, prisons, and mental hospitals. A sticker chart, in which children earn a sticker per target behavior and redeem accumulated stickers for a prize, is a familiar classroom-scale token economy.

## Design Implications

### Context
#### Requirements
- Clearly and consistently defined target behaviors that earn (or lose) a token
- A meaningful, motivating backup reinforcer the learner can exchange tokens for
- Consistent, immediate delivery of tokens contingent on the target behavior
#### Constraints
- Tokens are secondary reinforcers — the system depends on the backup reward retaining genuine value to the learner; if the backup reward loses appeal, the tokens lose their reinforcing power
- As with any extrinsic-reinforcement system, an unmanaged token economy risks crowding out intrinsic motivation for the target behavior if never faded — see [Conditioning Natural Reinforcers](conditioning-natural-reinforcers.md) for a fading strategy
- Establishing and running a token economy well is a real time and record-keeping commitment (tracking token delivery/loss, exchange rates, and effectiveness), not merely handing out stickers

### Target Learners
- Learners for whom clear, immediate, tangible feedback on specific target behaviors is more motivating than delayed or abstract consequences
- Populations documented in research to benefit strongly from structured token systems, including autistic learners needing support reducing disruptive behaviors and increasing appropriate social behaviors

### Target Learning Goals
- Reducing specific undesirable behaviors (e.g., hitting, pinching) while increasing specific desirable replacement behaviors (e.g., "quiet hands"), and building classroom-wide behavior-management routines around clear, consistent contingencies

### Instructions
1. Identify the specific target behavior(s) to increase (and, if applicable, the incompatible behavior to decrease).
2. Select a token that is easy to deliver and track (physical tokens, points, stickers).
3. Select a backup reinforcer the learner can exchange tokens for (privileges, prizes, activity time).
4. Deliver a token immediately and consistently upon the target behavior; remove a token immediately and consistently upon the incompatible undesirable behavior, if using a loss condition.
5. Allow exchange of accumulated tokens for the backup reinforcer at defined intervals.
6. Monitor whether the target behavior is actually changing; if not, reassess whether the backup reinforcer still has value to the learner.

## Related Strategies
- [Conditioning Natural Reinforcers](conditioning-natural-reinforcers.md) — a token economy is an extrinsic system; this strategy addresses how to transfer control from tokens to natural, intrinsic reinforcers over time
- [Time-Out (Negative Punishment)](time-out-negative-punishment.md) — token loss and time-out are both negative-punishment techniques, but token loss removes a specific earned token while time-out removes access to an entire desirable activity

## Examples
- Cangi and Daly (2013) implemented a token economy with a group of autistic school children who tended toward disruptive behaviors such as hitting and pinching. Children received a "quiet hands" token for appropriate behavior and lost a token for hitting or pinching; accumulated tokens were exchanged for minutes of playtime. The intervention increased appropriate social behaviors and reduced inappropriate ones.
