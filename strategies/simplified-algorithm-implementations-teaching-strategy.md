# Teach data analysis methods through simplified implementations of advanced algorithms such as Metropolis-Hastings

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
AstronomyCalc implements simplified versions of advanced data analysis algorithms, such as the Metropolis-Hastings algorithm for Monte Carlo Markov chains, "to explain the fundamental workings of these methods". The strategy is to expose learners to simplified implementations so they understand how the methods work, rather than treating them as black boxes, while integrating theoretical concepts with observational data analysis.

## Design Implications

### Context
#### Requirements
- Simplified implementations must be paired with real or simulated data analysis to reflect empirical methods in the field
#### Constraints
- The implementations are simplified versions of the advanced algorithms

### Target Learners
- students learning astronomical data analysis methods

### Target Learning Goals
- understanding the fundamental workings of Monte Carlo Markov chain methods
