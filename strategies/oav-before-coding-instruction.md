# Introduce programming with online algorithm visualization before formal coding instruction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q1` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The study's design and student requests support using online algorithm visualization in the opening weeks of a programming course, before coding begins, to build algorithmic thinking and reduce bias against coding. Students "requested" a comprehensive application covering not only algorithm and logic but coding itself, and wished "to encounter OAV in primary school". The article concludes OAV "provided students explorative learning and progressive thinking opportunities that are hard to gain through traditional approaches".

## Design Implications

### Context
#### Requirements
- An online, free, user-friendly visualization environment such as code.org
- Instructor tracking of student progress during the activities
#### Constraints
- OAV activities did not completely reduce students' initial bias against coding; students wanted the visualization extended to cover the programming language itself

### Target Learners
- students beginning to learn programming with no prior experience

### Target Learning Goals
- algorithmic thinking
- preparation for coding
- positive attitudes toward programming
