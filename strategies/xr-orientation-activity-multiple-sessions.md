# Build an orientation activity into XR study designs and use multiple sessions to increase tool familiarity

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The review recommends that XR-based training designs include an orientation activity so students are not learning the software during the intervention, and that training occur over multiple sessions. It states "An orientation activity built into the study design would be useful so that when the XR scenario is presented, students will not be focused on learning the software" and that "multiple sessions would increase students' familiarity with the tools".

## Design Implications

### Context
#### Requirements
- Students must be oriented to the XR software before the assessed scenario so the intervention measures learning rather than software navigation
