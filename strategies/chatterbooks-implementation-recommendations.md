# Implementation recommendations: increase pupil motivation, clarify session structure in training, and trial an expanded dialogic reading component separately

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 causal), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The report's key conclusions set out what would need to change for future implementation: schools encountered problems with timetabling, planning and resourcing; motivation must be raised to mitigate behavioural issues; the dialogic reading component "could be expanded and trialled separately"; and reading-for-pleasure sessions need development to demonstrate impact on reading ability. It also recommends that if a strict format is used, it should be clear from the start and emphasised in training.

## Design Implications

### Context
#### Requirements
- A way of increasing motivation to mitigate behavioural issues when working with low-achieving pupils
- Clear communication of required session structure during training
#### Constraints
- The report judged the intervention unsuitable in its current format for school settings due to timetabling, planning and resourcing problems

### Target Learners
- Low-achieving Year 7 readers at the primary-secondary transition

### Target Learning Goals
- Reading ability
- Engagement with reading
