# Place GenAI entry after the learner's initial task attempt rather than before it

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's regulatory recommendation from the discussion: GenAI's effect on perceived agency depends on where in the self-regulated learning cycle it enters by default. 'If GenAI provides the student with information before attempting the task - thereby eliminating forethought - GenAI will likely increase the learner’s perception of their lack of agency. Conversely, if GenAI provides information after the attempt, thus allowing for performance and reflection, then it is likely to reduce that perception.' Institutions should therefore evaluate tools by default entry point, not only accuracy and safety.
