# Use assessment data to inform teacher practice in preschool

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The ELTM's approach, as titled by the report, is using assessment data to inform teacher practice: integrating a computerized adaptive assessment (CPAA) into preschool classroom practice alongside an existing teacher rating (DRDP-PS) so that "the addition of the CPAA expands the information available to teachers and parents regarding children's progress."

## Design Implications

### Context
#### Requirements
- Teachers with access to computerized adaptive assessment results in their classrooms
- An existing complementary assessment system (DRDP-PS)
#### Constraints
- Described for preschool classrooms in one district's transition-to-kindergarten program

### Target Learners
- preschool children ages 3 to 5

### Target Learning Goals
- informing teacher practice to support children's literacy and mathematical skill development
