# Introduce authentic listening materials to lower-level learners by simplifying the task, grading the text, and staging the listening

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends three techniques for introducing authentic listening materials at earlier stages: simplifying the task rather than the text, grading the text, and staging the listening in progressive steps. It states "There is a reverse relationship between text difficulty and task difficulty", so a passage beyond learners' level can be used if demands are simple. The discussion reiterates these should be taken into account for pre-intermediate students.
