# Highlighting Strategy with Add-on Tool

## Description
Students use a Google Doc add-on tool to create individualized highlighters in different colors. For example, all the text that supports “Argument #1” might be in red, while the evidence in “Argument #2” might be in green, and so on. The highlights can be exported by color, which creates a table with all the ideas. Students can then add another column to the highlighter table, where they can write summaries of everything in that highlighted category.

## Design Implications

### Context
#### Requirements
- Access to Google Docs and the highlighting add-on tool, time for reading, highlighting, and summarizing.
#### Constraints
- Requires learners to actively engage with the text and identify relevant information.
