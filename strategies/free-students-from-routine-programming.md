# Free students from routine programming work when using computer modelling in physics

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article identifies programming as the main technical obstacle to computer modelling in the physics course: building a model "з нуля" takes considerable time, unlikely within one or two lessons, and most of the work goes to programming service, secondary operations while the model itself is usually a simple algorithm. The recommended move is to "звільнити студента, що займається комп'ютерним моделюванням, від рутинної програмістської роботи", for example by using existing pedagogical software tools.

## Design Implications

### Context
#### Requirements
- Existing pedagogical software tools that remove the routine programming burden
#### Constraints
- Building a computer model from scratch is unlikely to fit within one or two lessons

### Target Learners
- university students in physics courses

### Target Learning Goals
- developing practical computer-modelling skills
- learning through research
