Create physical learning activities with gesture recognition for preschoolers by strengthening connections between life experiences and tasks¶

Strategy · All strategies
Evidence · 4 claims (4 for) · 2 studies (1 causal, 1 review), q2–q3 · 1 of 2 report an effect size · 4 claims rest on one study

Description¶

The article's pedagogy contribution is guidance for teachers who want to create a physical activity with gesture recognition for preschoolers. With gesture recognition, "the instructor enhanced the learning process of the children’s physical motions and cognitive knowledge by strengthening the connection between life experiences and specific tasks." The strategy embeds stability actions (crouching, twisting, waving, stretching, single-leg standing) and movement actions (running, cross-jumping, single-leg jumping) into themed English content.

Context¶

Requirements¶

  • Gesture-based devices with sufficient space and per-device group sizes of three to four children

Constraints¶

  • Future studies could explore additional variables, such as learning strategies, teacher roles, and attitudes

Target Learners¶

  • preschoolers in kindergarten Level 3

Target Learning Goals¶

  • English learning performance
  • motor skills
  • executive functions

Claims¶

  • Preschoolers using gesture recognition with the memory strategy achieved significantly better English learning performance than those using traditional activity learning with the memory strategy [+W]
  • Preschoolers using gesture recognition with the memory strategy achieved significantly better stability scores than the control group [+W]
  • Preschoolers using gesture recognition with the memory strategy achieved significantly better working memory scores than the control group [+W]
  • Physical activity is positively correlated with children's working memory, and integrated exercise with gestures yields the best preschool foreign-language vocabulary learning [+W]
