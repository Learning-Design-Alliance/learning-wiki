# Highlighting Strategy

## Description
The highlighting strategy is a digital approach to enhance text engagement, using tools to create individualized highlighters with different colors in digital documents. For example, Argument #1 might be in red, while Argument #2 might be in green. The highlights can be exported by color, creating a table with ideas that can be summarized. This supports deeper analysis and organization of information. Highlighting strategy is made much easier and more effective because it is digital. The various colors are labeled so the student doesn’t need a key to decipher highlights and all the information can be exported in one table, rather than having to sift back through the entire article.
