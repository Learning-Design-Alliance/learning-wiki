# Combine error-amplification visual feedback with balance-based exergaming systems to expedite balance training for older adults, delivered via VR

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article recommends pairing EA visual feedback with balance-based exergaming: "visual EA can be easily delivered via virtual reality (VR) technology, which can provide flexible manipulation of the postural error size within an immersive gaming environment." The authors call the combined approach "a promising intervention to improve postural balance in the rehabilitation realm" for healthy older adults training postural control.

## Design Implications

### Context
#### Requirements
- A balance-based exergaming or VR platform that can manipulate visualized error size in real time via mathematical transformation of the movement trajectory
#### Constraints
- Error-gain manipulation "should be done pragmatically": excessive amplification could raise cognitive load, performance stress, and perceptual conflicts among visual, vestibular and proprioceptive inputs, so appropriate error gain must be selected

### Target Learners
- healthy older adults in balance/rehabilitation training

### Target Learning Goals
- dynamic postural balance control on unstable surfaces
