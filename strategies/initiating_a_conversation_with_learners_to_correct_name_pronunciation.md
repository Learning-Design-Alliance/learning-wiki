# Initiating a Conversation with Learners to Correct Name Pronunciation

## Description
The instructor initiates a conversation with the learner by following the steps outlined below. Make sure not to laugh at a name or express frustration with having to learn it. Start with soul-searching to see if the name is only hard because it is coming from your perspective. Be explicit by stating that it is your limitation, not the learner's fault.

## Design Implications

### Context
#### Requirements
- Instructors should take the time to ask each learner their name, and make a good-faith effort to pronounce it correctly.
#### Constraints
- Some languages have different phonemes than the instructor is used to, which makes it difficult to achieve proper pronunciation.
