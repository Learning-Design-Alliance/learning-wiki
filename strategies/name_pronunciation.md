# Name Pronunciation

## Description
Pronouncing learners' names correctly can help develop trust and rapport. Mispronouncing a name can cause feelings of anxiety, invisibility, shame, resentment, and humiliation, all of which can lead to social and educational disengagement. When getting to know learners, make sure that you get their name pronunciation right from the start.

## Design Implications

### Context
#### Requirements
- Instructors should take the time to ask each learner their name, and make a good-faith effort to pronounce it correctly.
#### Constraints
- Some languages have different phonemes than the instructor is used to, which makes it difficult to achieve proper pronunciation.
