# Run a parallel video-conferencing session with chat and anonymous polls alongside physical classes

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The authors propose that teachers harness the engagement affordances of video-conferencing platforms by running "a parallel session deploying such platforms concurrently during physical classes". The parallel channel provides a live chatroom visible to all and anonymous response systems (polls, word clouds, multiple-choice responses), letting teachers solicit real-time feedback, track progress during activities, check well-being, and collect concept-question responses even while teaching face to face. The format was to be trialed in the course's Fall-term rerun.
