# Reform curricula so all students use, apply and create machine learning and develop machine learning literacies

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends that curricula be reformed so all students develop machine learning literacies by the end of compulsory education, needed to understand the machine learning processes supporting their own learning and to act as responsible citizens contemplating ethical issues. It argues that "students must have opportunities not only to use and apply machine learning but also to create their own examples", with such activities feasible from around age 11 and earlier-starting literacies including algorithmic literacy. Specific content and sequencing remain topics for future research.

## Design Implications

### Context
#### Requirements
- Teacher professional development introducing machine learning for education in pre-service and in-service education
- Resources, risk-analysis support and interdisciplinary approaches for educators and learners
#### Constraints
- Many hands-on student ML tools still hide the machine learning as a black box behind API calls, so students cannot scrutinise how the systems they train work

### Target Learners
- all students in compulsory education
- teachers
- policymakers

### Target Learning Goals
- machine learning literacy and responsible citizenship regarding machine learning
