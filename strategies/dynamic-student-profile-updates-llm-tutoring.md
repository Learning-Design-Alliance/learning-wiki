# Update student profiles dynamically as learners interact with an LLM-powered environment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The authors recommend moving beyond the static four-choice profile of this trial: "these profiles can be updated as students interact with the learning environment, refining their placement along the dimensions of the Felder-Silverman model and improving the LLMs overall performance." They envision chat-style interaction in which students ask questions without fear of judgement, receive quick feedback, and whose insights from student questions feed back into the profile, steadily improving personalization quality over time.

## Design Implications

### Context
#### Requirements
- An LLM-powered learning environment supporting ongoing student interaction beyond initial profile creation
#### Constraints
- The trial itself only tested a static profile built from four training-session choices in a 25 to 35-minute session

### Target Learners
- middle-school students, with future work urged across a wider range of students before, during, and after the middle-school years

### Target Learning Goals
- sustained personalization of educational content and feedback across extended use
