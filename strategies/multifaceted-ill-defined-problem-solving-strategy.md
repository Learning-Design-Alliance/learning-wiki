# A multifaceted approach combining incentivized higher-order assessment points, transparent rubric criteria, and facilitated scientific communication to improve ill-defined problem solving

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (6 for) · 1 study (1 associational), `q2` · 1 of 1 report an effect size · 6 claims rest on one study

## Description
The article recommends combining several strategies because the reasons underlying poor performance vary by domain. It suggests that "a multifaceted approach that combines the following strategies may help students realize more gains" than observed: reserving 10–20% of assessment points for higher-order objectives, making rubric criteria transparent and modeling them, and facilitating scientific communication skills through student-centered writing techniques and peer review.

## Design Implications

### Context
#### Requirements
- Sufficient course points must address higher-order learning objectives (10–20% per Felder and Brent) so students see those objectives as important.
- Rubric criteria must be made transparent and modeled, e.g., classifying hypotheses as mechanistic or unmechanistic.
#### Constraints
- The article notes its own 10% course-point weighting may not have fully incentivized attainment of the learning objectives.

### Target Learners
- undergraduate biochemistry majors in upper-level science courses

### Target Learning Goals
- solving ill-defined biochemistry problems using the scientific method
- reflecting on performance using metacognitive strategies
- scientific writing and communication skills
