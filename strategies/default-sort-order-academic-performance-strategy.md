# Default school-listing sort order to academic performance rather than distance from home

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A specific, implementable interface strategy: when presenting school options to parents, set the default ordering of listings by academic performance rather than by proximity. The article reports this as one of the design factors tested, finding that "setting the default sort order to academic performance instead of distance from home, could induce parents to choose academically higher performing schools."

## Design Implications

### Context
#### Requirements
- A school chooser interface that supports configurable default sort orders
#### Constraints
- Tested with low-income parents in an online school chooser context

### Target Learners
- Low-income parents choosing schools for their children

### Target Learning Goals
- Selecting higher-performing schools for their children
