# Analyze the Project

## Description
Before launching a project, teachers should analyze it through the lens of English Language Learners (ELLs) by considering: What language skills will students need? What vocabulary instruction might they need? What speaking and listening skills should we scaffold? What functions of the language must be considered? This type of analysis should occur before the project launches.

## Design Implications

### Context
#### Requirements
- Understanding of language acquisition and the needs of ELLs, along with detailed project planning.
#### Constraints
- Requires extra time and effort in project design and may require additional resources for language support.
