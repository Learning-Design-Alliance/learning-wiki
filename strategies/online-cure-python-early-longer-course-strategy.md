# In future online CURE iterations, introduce Python coding early, extend course length, and assign individual reports with phased feedback

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Based on survey feedback, the authors recommend concrete revisions for future iterations of the online CURE. They state that "a potential solution would be to introduce Python coding much earlier and to have more time dedicated in general to learning and practicing," that respondents favored extending the course from six to 8-15 weeks, and that report writing could become individual with multiple phases of feedback throughout the course. Spreadsheet practice can run simultaneously with coding to give students multiple analysis options.

## Design Implications

### Context
#### Requirements
- Instructor capacity to restructure the schedule so coding instruction is distributed across the term rather than concentrated at the end
#### Constraints
- Recommendations arise from a single pilot offering with eight survey respondents and no pre-post comparison

### Target Learners
- online undergraduate astronomy majors new to programming

### Target Learning Goals
- Python programming confidence
- scientific report writing
- evenly distributed skill development across the course
