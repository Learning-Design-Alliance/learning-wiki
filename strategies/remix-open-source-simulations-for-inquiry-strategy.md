# Remix existing open source simulation models into inquiry learning environments matched to the local syllabus

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (3 design), `q1` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
A concrete workflow for teacher designers: start from an existing simulation in the open source library, examine its Ejs source code, then customize interface, representations and variables so the model supports inquiry for a specific syllabus. The author concludes by hoping "more teachers will find the simulation useful in their own classes and join in the journey of remixing simulations as a form of se lf directed professional learning to deepen our own teaching practices".

## Design Implications

### Context
#### Requirements
- An existing library of open source simulation models with modifiable source code
- The Ejs toolkit for editing and regenerating the models
#### Constraints
- Remixes were tailored to the Singapore science curriculum framework and GCE A-level physics syllabus

### Target Learners
- Physics teachers undertaking self-directed professional learning

### Target Learning Goals
- Building inquiry-based physics learning environments
- Self-directed professional learning in simulation design
