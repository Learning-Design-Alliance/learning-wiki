# Run outreach analyses via Jupyter/binder accessed from mobile phones through a QR code

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
A specific outreach recipe: run ADL analyses through the CutLang Jupyter kernel on binder, which requires only web browser access, and share a QR code that redirects to the interface so participants can execute analyses from mobile phones. The article calls this setup "an excellent tool for short outreach exercises".
