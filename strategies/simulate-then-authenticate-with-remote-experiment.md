# Sequence learning from literature, through simulation, to authentication via real remote experiments

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 3 studies (2 design, 1 qualitative), `q1`–`q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The website operationalizes a learning sequence in which students first read on-site literature, then run virtual-lab simulations, and finally authenticate results by performing real experiments via remote access. Design goal 2 states: 'perform simulations and find the results via virtual lab and authenticate it with performing the real experiments via remote access'. Theoretical resource material is placed next to experiments on the website to support this sequence.

## Design Implications

### Context
#### Requirements
- A web portal offering both simulation examples and a remotely controllable physical experiment
- Resource material on theory available alongside the experiments
#### Constraints
- The simulation examples constrain parameters to laminar, steady regimes in several cases (e.g. low Rayleigh numbers)

### Target Learners
- 4th year undergraduate and 1st year postgraduate engineering students

### Target Learning Goals
- Interferometry fundamentals and applications
- Interpretation of optical images of heat transfer and fluid flow
