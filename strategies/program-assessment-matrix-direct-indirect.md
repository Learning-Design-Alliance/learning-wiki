# Use program assessment matrices combining direct course-based and indirect survey-based relevance ratings to evaluate SOs and PEOs

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article constructs a program assessment matrix (PAM) where each course gives a relevance number (1-3) for each mapped SO, and an identical matrix for indirect assessment from surveys. It states "Entries of 1, 2, and 3 for each SO in the matrix denote slight, moderate, and substantial relevance to the program outcomes". Program-level direct assessments use weighted averages of course-level SO attainment values placed in the matrix.

## Design Implications

### Context
#### Requirements
- All core courses must have mapping between CLOs and SOs; a PEO-to-SO mapping designed by stakeholders is required to derive PEO achievement values
#### Constraints
- Elective courses whose CLOs are not consistent in subsequent offerings should not be considered in program assessment; indirect assessments are very subjective and their weights may differ institute by institute and region by region

### Target Learners
- undergraduate computer engineering students

### Target Learning Goals
- program-level student outcomes attainment
- program educational objectives attainment
