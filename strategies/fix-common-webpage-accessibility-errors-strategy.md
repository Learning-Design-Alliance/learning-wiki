# Fix the five most common webpage accessibility errors with targeted content and markup corrections

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article pairs each frequent error type with a concrete fix: unbold and lowercase overly formatted text, shorten and improve descriptions of non-text elements, enter "unique and descriptive alternative text and metadata into each web element", increase small font sizes, and give hyperlinks unique informative descriptions so differing descriptions do not lead to the same page. For 4.1.2 name, role, value errors, which require markup knowledge, the article recommends web administrators and developers make the corrections.

## Design Implications

### Context
#### Requirements
- Content editors must write unique, informative alternative text and hyperlink descriptions; 4.1.2 fixes require web administrators and developers with markup-language knowledge
#### Constraints
- Level-A 4.1.2 errors are most prevalent when proprietary web elements are developed but under-described, such as missing href or ARIA attributes

### Target Learners
- postsecondary students with disabilities using screen readers, keyboard-based assistive technology, or low-vision aids

### Target Learning Goals
- access to physics curriculum and program information online
