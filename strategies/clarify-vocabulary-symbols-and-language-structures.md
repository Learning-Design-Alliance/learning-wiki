# Clarify Vocabulary, Symbols, and Language Structures

> **Strategy** · [All strategies](index.md)

## Description
This strategy ensures learners can construct meaning from the words, symbols, notation, and sentence structures of a discipline before being asked to use them for higher-order work. It is carried out by pre-teaching or glossing key vocabulary, defining symbols explicitly, providing multiple representations (verbal, visual, numeric) of the same concept, and unpacking complex syntax into accessible forms. The goal is not simplification of content but clarification of the *language of the content*, so linguistic demands do not masquerade as conceptual difficulty.

## Design Implications

Clarifying language reduces extraneous cognitive load: when learners must simultaneously decode unfamiliar vocabulary, notation, and syntax while learning new concepts, working memory is consumed by language processing rather than learning [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]. Vocabulary instruction is most effective when it targets high-utility terms, provides multiple encounters in varied contexts, and connects new terms to prior knowledge rather than relying on dictionary definitions alone. Pairing verbal and visual representations supports comprehension because the two channels reinforce each other [Media combinations affect recall and retention.](../claims/media-combinations-affect-recall-and-retention.md) [+M].

### Context
#### Requirements
- A linguistic analysis of the materials: which terms, symbols, and structures are discipline-specific, which are everyday words with specialized meanings, and which are likely unfamiliar to this population
- Definitions, examples, and non-examples for key terms, ideally with visual or concrete representations ([Analogies](../elements/analogies.md) are a common vehicle)
- Explicit unpacking of dense syntax — long noun phrases, passive constructions, conditional language ("if and only if"), and mathematical or scientific notation
- Multiple encounters with each term across contexts, not a single definition event

#### Constraints
- Over-simplification can strip the disciplinary precision learners ultimately need; simplified language should be a bridge to, not a substitute for, canonical forms [~M]
- Pre-teaching too many terms dilutes instruction; robust vocabulary research favors fewer, high-utility words taught deeply over long lists taught shallowly [-W]
- Glossaries consulted passively produce weak gains; definitions without contextualized encounters rarely stick [-M]
- Excessive simplification can feel patronizing to adolescent and adult learners, reducing engagement [~W]

#### Implementation Variability
- Pre-teaching a small set of critical terms before a unit vs. just-in-time glossing embedded in materials
- Bilingual glossaries, home-language cognates, and translated supports for English language learners
- Symbol charts and notation guides in mathematics, chemistry, and logic
- Syntax scaffolds: sentence frames, sentence deconstruction, and morphological analysis (roots, prefixes, suffixes)

### Target Learners
- English language learners, who face a "double burden" of learning content and the language of instruction simultaneously [~M]
- Learners with limited prior knowledge of a discipline, for whom specialized vocabulary is a primary barrier to accessing [Advance Organizers](../elements/advance-organizers.md) and texts
- Struggling readers and learners with language-based learning disabilities, who benefit from explicit syntax and morphology support
- All learners benefit to some degree; disciplinary language is a barrier even for proficient readers when terms carry specialized meanings (e.g., "force," "limit," "argument")

### Target Learning Goals
- Comprehension of disciplinary texts and problems
- Vocabulary depth and academic language development
- Symbol and notation fluency in mathematics, science, and programming
- Reduced extraneous load so working memory is available for conceptual learning [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]

### Instructions
1. Audit the learning materials for high-utility vocabulary, specialized symbols, and syntactically dense passages; prioritize a small set of terms essential to the unit's concepts.
2. Pre-teach or gloss critical terms with student-friendly definitions, [Analogies](../elements/analogies.md), examples, and non-examples — not dictionary definitions alone.
3. Pair every key term and symbol with a visual or concrete representation to engage both verbal and visual channels [Media combinations affect recall and retention.](../claims/media-combinations-affect-recall-and-retention.md) [+M].
4. Unpack complex sentences and notation: break long sentences into clauses, make hidden relationships explicit, and provide a notation guide learners can reference.
5. Arrange multiple, varied encounters with each term across the unit — reading, discussion, writing, and application — so meaning is consolidated through use [Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M].
6. Gradually release learners to the canonical disciplinary language, connecting simplified formulations back to the precise forms.

## Examples
- **Word Generation** (SERP Institute, https://www.wordgeneration.org) — a published middle-school program teaching high-utility academic vocabulary through repeated encounters across subject areas, with discussion and writing activities.
- **Bringing Words to Life (Beck, McKeown, & Kucan)** — the robust vocabulary framework underlying most tiered vocabulary instruction: choose Tier 2 words, provide friendly definitions, and require multiple contextualized interactions.
- A chemistry instructor provides a symbol and notation guide (subscripts, coefficients, state symbols) alongside worked examples, so notation decoding does not compete with learning stoichiometry.
- An ELL-supporting math course pairs each new term ("denominator," "quotient") with a visual model, a home-language cognate, and a sentence frame for explaining solutions aloud.
