# Reframe Negative Self-Talk

## Description
Practice reframing negative thoughts, statements, or situations into more positive alternatives. Use the self-talk journal or notes. Start with examples of negative self-talk (e.g., 'Everyone knows I can’t win this challenge'). Ask students to restate the fixed mindset phrase into a positive message using the name they chose for their negative voice (e.g., 'Good try, Ruthless Ralph. Even if I don’t win, I will learn something from this challenge!').
