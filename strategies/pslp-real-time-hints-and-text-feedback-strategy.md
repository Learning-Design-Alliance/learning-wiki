# Provide real-time hints and automated feedback on qualitative analysis within an unconstrained online problem-solving environment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (1 for, 3 mixed) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The authors propose improvements to the PSLP pedagogy: automatically analyzing each group's behavior in real time so the system can provide hints, "e.g. if the group is indiscriminately opening all the data resour ces, suggest that they perform a qualitative analysis of the problem", and using text-classification software trained on prior student answers to give real-time feedback on typed qualitative analyses. TAs are also encouraged to push groups to analyze qualitatively earlier.

## Design Implications

### Context
#### Requirements
- An online environment that tracks student pathways in real time, and for text feedback, a large set of prior student answers to train the classifier
#### Constraints
- TAs have responsibility for many groups during each session and may not be able to provide timely advice, motivating the automated option

### Target Learners
- undergraduate physics students working in teams of two to three

### Target Learning Goals
- earlier qualitative analysis and more selective, expert-like information gathering in multifaceted problem solving
