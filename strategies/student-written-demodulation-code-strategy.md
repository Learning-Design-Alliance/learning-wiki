# Have students write the demodulation code themselves, or supply instructor-provided code, scaled to student skill level

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In the data-analysis phase of the laboratory, Python code reads in the files, examines the data, and performs the lock-in measurement. The article states: "Depending on the skill level of the students, this code can either be supplied by the instructor for the use of the student, or generated by the students themselves from the principles of the lock-in technique." Writing the demodulation code gives students a tangible understanding of the technique's details while avoiding the cost of a hardware lock-in amplifier.
