# Deploy a narrated self-learning module with embedded checkpoints flexibly, as independent learning or as a facilitated small-group activity

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article's SLM is a fully narrated PowerPoint presentation with embedded self-assessment checkpoints that can run without a facilitator. "it also can be deployed as an independent learning resource accessible anywhere at any time without the strict need for a facilitator", and it can equally be projected for a group didactic with consensus answers. This suits institutions lacking TMS expertise, since facilitation is largely automated.

## Design Implications

### Context
#### Requirements
- A fully narrated presentation with embedded self-assessment checkpoints in place of a facilitator
#### Constraints
- Automated resources carry a higher likelihood of technical issues; the authors report audio volume variation problems, remedied by rebalancing recordings in Audacity

### Target Learners
- Medical students
- Psychiatry residents (PGY 1–4)

### Target Learning Goals
- Basic science, indications, contraindications, side effects, and treatment process of TMS for treatment-resistant depression
