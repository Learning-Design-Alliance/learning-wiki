Assign a language function to each 5E phase (describe, compare and contrast, classify, classify with justification) and align language objectives with science objectives¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The Montebello project added a language column to the 5E template so teachers identified the major language focus of each lesson phase. For example, in the Engage phase students might "use language to describe a concept," while in Explore and Explain they might compare and contrast and classify concepts, and in Elaborate they might classify a concept with justification. This reflects the principle that rich conversations do not just occur—language objectives, like science objectives, must be identified and learning experiences orchestrated.

Design Implications¶

Context¶

Requirements¶

  • Teachers identify the primary language function for each phase before creating supporting materials such as sentence frames

Constraints¶

Target Learners¶

  • elementary English learners across proficiency levels

Target Learning Goals¶

  • academic language functions (describing, comparing, classifying, justifying)
  • science explanation and communication

Affordances¶

  • Modified 5E Template Concept Language Columns

Related Strategies¶

  • Use backward design: complete the concept column first, mapping prior-knowledge, connecting, and application concepts before planning activities
  • Front-load Tier 1 vocabulary before the science lesson and teach embedded scientific vocabulary in the lesson's context
  • Support English learners with sentence frames, graphic organizers, and word walls—but supplement frames with level-appropriate strategies because frames can limit the range of student responses
