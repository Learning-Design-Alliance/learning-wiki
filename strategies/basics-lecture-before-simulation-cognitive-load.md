# Sequence a basics lecture before simulation practice to manage cognitive load

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 causal, 1 review), `q2`–`q3` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The authors recommend, invoking cognitive load theory, that "instructors should optimize the design of simulation by minimizing extraneous cognitive load". Concretely, "Undergraduate students unfamiliar with the topic should be given a lecture on the basics of the terminology, definition, and innervation of extraocular muscles, providing a preparatory overview before the simulation session." This is the study's own forward-looking design recommendation for deploying hands-on simulation models.

## Design Implications

### Context
#### Requirements
- A preparatory lecture covering terminology, definition, and innervation before the simulation session
#### Constraints
- The authors state simulation "should not replace traditional teaching methods in undergraduate education"

### Target Learners
- undergraduate medical students

### Target Learning Goals
- complex anatomical topics such as extraocular muscle anatomy
