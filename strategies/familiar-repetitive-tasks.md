# Familiar, Repetitive Tasks

> **Strategy** · [All strategies](index.md)

## Description
This strategy provides learners with familiar, quiet, repetitive fine motor and visual tasks — stringing beads, sorting activities, put-in tasks, file folder tasks — to complete at the beginning of the day or during transition times. The purpose is regulatory rather than instructional: predictability and low cognitive demand reduce anxiety and support a calm, focused entry into subsequent learning activities.

## Design Implications

Familiar, repetitive tasks lower working memory and decision-making demands, freeing attentional resources for self-regulation [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]. Predictable routines are especially valuable for learners who find novelty and unpredictability aversive; environmental predictability is consistently associated with reduced problem behavior and anxiety in learners with developmental disabilities [~M]. The tasks must be genuinely mastered — a task that still requires effortful problem solving defeats the regulatory purpose.

### Context
#### Requirements
- A collection of already-mastered, low-demand tasks (sorting, matching, beading, file folder activities)
- A designated, low-stimulation space for completing the tasks
- Clear, consistent guidelines for when and how tasks are used, so the routine itself is predictable
- Periodic rotation of task options without changing their difficulty or familiarity

#### Constraints
- Tasks that are novel or still being learned impose problem-solving demands and lose their calming function [-M]
- Overuse can produce boredom or prompt repetitive behavior that interferes with engagement in later instruction [-W]
- If tasks are used primarily as behavior management rather than as part of a coherent schedule, learners may come to see them as busywork, reducing their regulatory value [-W]
- Requires ongoing monitoring: as learners grow, tasks must be reassessed so they remain familiar but not infantilizing [-W]

#### Implementation Variability
- Structured work systems (as in TEACCH-style classrooms) formalize the routine with visual schedules and left-to-right task completion
- Transition "toolkits" — a small set of portable repetitive tasks used between activities or in waiting periods
- Individual choice boards letting learners select which familiar task, when, and for how long
- Group calm-start routines using parallel individual tasks at a shared table

### Target Learners
- Learners with autism spectrum disorder or intellectual disability, for whom predictability reduces anxiety and problem behavior [~M]
- Learners who experience sensory overload or difficulty with transitions
- Learners building self-regulation: completing a short, achievable task independently can function as a self-monitoring routine [Self-monitoring improves self-regulation.](../claims/self-monitoring-improves-self-regulation.md) [+M]
- Less appropriate for learners seeking novelty or challenge, who may disengage [-W]

### Target Learning Goals
- Emotional and behavioral regulation: establishing a calm, predictable baseline
- Executive function: practicing task initiation and completion routines with minimal support
- Fine motor and visual discrimination maintenance through repeated practice [Part-task practice reduces load for novices.](../claims/part-task-practice-reduces-load-for-novices.md) [+M]

### Instructions
1. Select or create tasks the learner has already mastered, so success is guaranteed and demand is minimal.
2. Establish a consistent time and place (arrival, transitions) and teach the routine explicitly with [Practice](../elements/practice.md) and modeling.
3. Introduce a visual cue or mini-schedule so the learner can initiate the task independently.
4. Set a clear duration or completion criterion, then transition to the next scheduled activity.
5. Monitor engagement and rotate task options periodically while keeping difficulty constant; fade adult prompting as independence grows.

## Related Strategies
- Structured work systems (TEACCH) — a formalized, research-based version of this strategy for autistic learners
- Sensory breaks — serve the same regulatory function with movement-based rather than fine motor tasks
- Visual schedules — provide the predictability scaffold within which these tasks sit

## Related Elements
- [Practice](../elements/practice.md) — the tasks are repeated, mastered practice; the strategy depends on prior overlearning
- [Cognitive Load Management](../elements/cognitive-load-management.md) — the low-demand design is what makes the tasks calming rather than taxing

## Examples
- **TEACCH structured teaching** ([https://teacch.com](https://teacch.com)) — classrooms use individual work systems with familiar, mastered tasks at predictable points in the day to build independence and reduce anxiety.
- **Early childhood arrival routines** — children choose a table task (beading, pegboards, sorting) on arrival while the class settles, providing a calm, predictable start.
- **Special education transition bins** — labeled bins of file folder tasks given to individual learners during transitions between settings or while waiting.
