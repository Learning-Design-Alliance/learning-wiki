# Start AI-based MCQ generation from a test blueprint specifying topic and cognitive domain

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's first tip instructs item writers to define learning objectives and a blueprint before prompting AI. Blueprints identify knowledge and skill domains and distribute weightage across topics, and the knowledge to be tested is communicated to the AI using at least two dimensions, such as topic and domain, included in the prompt. The authors illustrate this with a pulmonary diseases blueprint table in which choosing a topic and domain directs the AI to generate an item assessing that area.

## Design Implications

### Context
#### Requirements
- A blueprint section and the domain to be tested must be specified so the AI can generate relevant items
#### Constraints
- The approach is illustrated for medical education assessment, e.g. internal medicine pulmonary system blueprints

### Target Learners
- undergraduate and graduate medical education trainees

### Target Learning Goals
- content-valid assessment items aligned with learning objectives
