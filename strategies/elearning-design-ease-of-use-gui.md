# Design e-learning systems to emphasize ease of use with user-friendly GUIs, navigation, FAQs and user manuals

## Description
The article recommends that "the development of e-learning should focus on ease of use in order to attract learners to use the system and should also emphasize the development of Graphic User Interfaces (GUI) that are user -friendly, application navigations, frequently as ked questions (FAQs), and user manuals". It also suggests interfaces allowing users to customize systems according to learning preferences, and that designers focus on valuable content and the accuracy and availability of information.

## Design Implications

### Context
#### Requirements
- User-friendly graphic user interfaces and application navigation
- Frequently asked questions and user manuals
- Customizable interfaces matching learning preferences
#### Constraints
- The article notes computer self-efficacy in each context differs depending on the characteristic of usage, and user perception may change with continuous use

### Target Learners
- university e-learning users

### Target Learning Goals
- acceptance and sustained use of e-learning systems
