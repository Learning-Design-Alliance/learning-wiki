# Open the curriculum with an embedded introductory Python module so students with no prior coding experience can engage scientific content immediately

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
To reduce barriers to entry, GW Explorer "opens with an introductory Python module covering variables, loops, functions, and data plotting" embedded directly in Notebook 1. This front-loads computational skills so students without programming background can start the physics content immediately, and the article credits it, with mentor support, for outcomes observed "even for students with minimal prior programming experience".

## Design Implications

### Context
#### Requirements
- The Python tutorial covering variables, loops, functions, arrays, and plotting must be embedded in the first notebook rather than assumed as prerequisite.
