# Test the architecture against five sequenced empirical questions, beginning with a direct comparison against the best available content-adaptive system

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The paper states the architecture has not been empirically tested and proposes five questions in sequence: whether it produces better measurable learning outcomes than content-only adaptation; whether co-authorship reduces power asymmetry or is performative; whether the Solaria effect emerges; whether the labelling line between learning observations and psychological claims holds in practice; and whether meta-literacy training changes how students use the architecture. "If the architecture does not outperform content-only adaptation on learning outcomes, the framework fails and the remaining questions are moot."

## Design Implications

### Context
#### Requirements
- A direct comparison: students using a system built on these principles compared against students using the best available content-adaptive system, on the same learning objectives and over the same period.
- Studies measuring whether co-authorship mechanisms actually change what the system does, and metrics capable of detecting losses of collective capacity.
#### Constraints
- The first question is a viability test: failure on it makes the remaining questions moot, per the paper's own sequencing.

### Target Learners
- Students using behavioural-architecture systems across the population the architecture serves

### Target Learning Goals
- Measurable learning outcomes; genuine shared control; preserved collaborative capacity; teachable co-authorship
