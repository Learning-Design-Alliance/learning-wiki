# Use the TARGET model dimensions to design medical courses that elicit mastery goal orientations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends designing medical learning environments with the TARGET model — "task, authority, recognition, grouping, evaluation and time" — to elicit more mastery goal orientations among medical students. Tasks should be relevant and allow multiple ways to demonstrate competence; authority should be shared communally; recognition should reward effort and commitment, not only results; grouping should be collaborative to reduce competitiveness; evaluation should remain confidential rather than overtly rank students; and time should favor learning over assessment.

## Design Implications

### Context
#### Requirements
- Course staff can redesign tasks, authority, recognition, grouping, evaluation and time structures of the learning environment
#### Constraints
- The current course did not apply goal orientation theory, so these applications are prospective; the underlying study is correlational and the authors call for studies establishing causal relationships
