# Add a self-assessment mode without real-time instructions to immersive VR procedural training modules

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 1 of 1 report an effect size · 4 claims rest on one study

## Description
Participants suggested that the VR module, which currently includes audio and visual instructions for every step, should offer a mode without instruction so learners can self-assess. The authors state this "can be helpful feedback to the software developer" and would suit learners who want to self-assess performance in a competency-based learning framework.

## Design Implications

### Context
#### Requirements
- The VR module must already deliver step-by-step audio and visual instructions, as the current chest tube module does.
#### Constraints
- The suggestion comes from participant feedback (three of 22 participants) rather than from a tested manipulation in this study.

### Target Learners
- Medical students learning procedural skills with no or limited prior VR experience

### Target Learning Goals
- Technical skill acquisition and self-assessment in procedural skills such as chest tube insertion
