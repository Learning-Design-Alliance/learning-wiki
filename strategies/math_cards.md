# Math Cards

## Description
An activity that uses cards with different representations of the same numerical answer (area model, dominoes, number sentence) to encourage number sense and understanding of multiplication, as opposed to memorization and time pressure.

## Design Implications

### Context
#### Requirements
- A set of math cards with different representations of numbers
#### Constraints
- Requires preparation of the math cards
