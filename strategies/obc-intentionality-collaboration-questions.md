# Structure OBC procurement around intentionality questions on learner goals, populations, outcomes, and stakeholders

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The presentation offers a structured set of intentionality and collaboration questions districts should answer before contracting: what learner goals to explore and what the data says, which learner populations and grade levels would benefit from intervention, what the ideal outcome is and how it will be measured including mid-year data points, and which roles and areas of expertise need to be involved to set the vision. This sequence is intended to make goal definition deliberate before vendor selection and contract drafting.
