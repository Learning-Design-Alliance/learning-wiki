# Modular chart design with three scaled versions matched to audience size, from a school-bag set to the full seven-metre chart

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The instruction design makes the chart modular: "we can decide to build either the entire chart or build only a speciﬁc region, and similarly that if we build the full chart in an educational setting, individual groups can work on each their part of the chart". Three physical versions support this: a smallest set of roughly 2,000 bricks filling a school bag for one ambassador with a small group, an iron-region version of roughly 7,000 bricks for a full class or small public event, and the full chart of over 26,000 bricks for multi-school and large public events.

## Design Implications

### Context
#### Requirements
- An overview file plus detailed plate layouts so that regions can be built independently and by separate groups
- Transport and ambassador numbers scaled to chart size, from a school bag up to a car or van for the full chart
#### Constraints
- Fission is "accessible only with the full chart", so smaller versions restrict which physics topics can be discussed
- The full implementation costs approximately 3,500, so budget may constrain chart size

### Target Learners
- small groups of school-children with a single ambassador
- full school classes
- large public events with many hundreds of visitors

### Target Learning Goals
- fusion and light-nuclei physics in all versions
- astrophysical reactions terminating in the iron region for iron-region builds
- fission and heavy-element physics with the full chart
