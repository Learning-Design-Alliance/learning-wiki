# Use App Inventor block-based app development to focus students on Big Data problem solving rather than coding syntax

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
In Phase 2, students develop Android apps in App Inventor, a visual, block-based platform where they do not write code. The authors report that although an app looks simple, it "incorporates a large amount of data with different formats (e.g. images, sounds, labels, etc.)", letting students focus on handling big data rather than syntax. Students progressed from simple apps to databases, interactive maps, and client-server communication.
