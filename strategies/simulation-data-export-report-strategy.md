# Have students export simulation data and write short reports explaining the results

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The module saves the evolution of position and momentum expectation values and the transmission and reflection coefficients into a text file. The authors recommend building on this: "this simulation program exports calculation data so that the students can write a short report describing the simulations they have performed explaining the results obtained". This turns the simulation activity into a written communication and interpretation exercise.
