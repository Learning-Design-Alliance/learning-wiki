# Archive clicker ConcepTest data across semesters to refine and build a core set of effective questions

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Because clickers let instructors archive ConcepTest data, the data can be used instructionally "to sort out useful ConcepTests from those th at work poorly". Questions of questionable effectiveness can be reformulated, and a core set of questions can evolve from one semester to the next. Flashcards do not enable collection of any ConcepTest-related data, so this refinement loop is impossible with them.

## Design Implications

### Context
#### Requirements
- Use of clickers (or another system that records individual responses) so ConcepTest outcome data can be stored and analyzed
#### Constraints
- The article found no such cross-semester differences in its single-semester comparison, though it expects differences may emerge over time

### Target Learners
- first-semester community college students in algebra-based physics

### Target Learning Goals
- improving quality of conceptual questions used in class
