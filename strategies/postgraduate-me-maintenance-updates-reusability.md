# Maintenance domain: long-term access, updates, and evaluation of user experience, effectiveness, usability and cost

> **Strategy** · [All strategies](index.md)

## Description
The maintenance domain includes steps taken "to avoid the loss of knowledge after a user finishes the e-learning process", including reliable long-term access so end users can return to the platform. "Maintenance-related articles (n = 10) described the importance of evaluating a platform’s user experience, effectiveness, usability, and cost", and developers should estimate reusability and sustainability for maintainability.
