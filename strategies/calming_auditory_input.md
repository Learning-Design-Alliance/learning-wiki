# Calming Auditory Input

## Description
Using calming auditory input involves managing and altering sounds in the environment to reduce overstimulation and promote relaxation. Strategies include using a quiet voice, monitoring classroom noise with a noise meter, playing white noise (e.g., rain sounds, ocean sounds, a fan), playing quiet, calming music, and using noise-reducing headphones. Reducing or altering auditory input can help children who are easily overwhelmed by sound.

## Design Implications

### Context
#### Requirements
- Noise meter, white noise machine or recording, calming music, noise-reducing headphones.
#### Constraints
- Some children may find certain sounds irritating or distracting. Headphones should be used safely and appropriately.
