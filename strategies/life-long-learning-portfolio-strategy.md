# Extend course-by-course learning portfolios into life-long learning profiles stored on the cloud with social media integration

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper proposes replacing disconnected, course-by-course learning portfolios with life-long profiling. It argues that "the use of these portfolios should be extended to a life-long profiling, carried from one course to another, bridging the learning gap between courses." The portfolio is stored on the cloud, combined with social media at a macro level, and uses learning analytics/big data to automatically provide recommendations and record achievements, respecting learner-set access permissions, so learners can reflect on and share their accomplishments across their careers.
