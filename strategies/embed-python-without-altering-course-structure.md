# Embed computational skills into an existing lab course by replacing a preset analysis tool with Python while retaining original lab goals

> **Strategy** · [All strategies](index.md)
> **Evidence** · 9 claims (7 for, 2 mixed) · 3 studies (2 design, 1 qualitative), `q2` · 0 of 3 report an effect size · 9 claims rest on one study

## Description
The authors integrated Python data analysis into an existing first-semester laboratory course "without significant alterations to the existing course structure", retaining original laboratory goals while "slightly reducing in-class exercises and replacing the use of a scientific data analysis software (SciDavis) with Python programming". They defined computational learning goals first, then developed curricular materials, then evaluated via student work and pre-post questionnaires, keeping computational assessment distinct from existing lab-goal assessment.

## Design Implications

### Context
#### Requirements
- Defined laboratory computational learning goals, tailored curricular materials (Jupyter Notebooks), and separate formative and summative assessment of the computational goals
#### Constraints
- The study's context involved first-year physics students, some with prior programming experience, and the authors note the small sample size limits generalizability

### Target Learners
- first-year undergraduate physics majors in an existing laboratory course

### Target Learning Goals
- computational data-analysis skills
- professional practice of reading and building on others' code
