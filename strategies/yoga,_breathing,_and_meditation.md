# Yoga, Breathing, And Meditation

## Description
该策略将身体姿势练习（瑜伽）、呼吸调节（如箱式呼吸、鼻孔交替呼吸）和正念冥想系统地嵌入教学流程中，通常以短时、规律的形式出现（课前5–10分钟）。其机制是通过降低过度觉醒或提升过低觉醒，把学习者的生理状态调节到适合注意与编码的区间，并训练注意监控与情绪调节技能。

## Design Implications

身心练习通过改善注意稳定性和情绪调节，为后续认知加工创造条件，尤其对自我调节能力尚在发展中的学习者有价值 [Tang, Hölzel & Posner 的综述表明冥想训练可改变注意与情绪调节相关脑区的结构与功能。](https://doi.org/10.1038/nrn3916) [+M]。效果高度依赖剂量与实施质量：短时、高频、有引导的练习比偶发的长时练习更可靠；练习本身不替代教学设计，只是为 [Cognitive Load Management](../principles/cognitive-load-management.md) 创造生理前提。

### Context
#### Requirements
- 受过训练的引导者或经过验证的引导音频；即兴引导效果不稳定
- 规律的时间锚点（如每节课开始时），使练习成为可预期的常规
- 低门槛的身体变体（坐姿呼吸练习），照顾身体条件受限的学习者
- 与 [Check-In](../elements/check-in.md) 结合，帮助学习者觉察并命名当下的状态

#### Constraints
- 单次或低频"正念工作坊"对学业结果的效应微弱且不稳定 [-W]——收益随累积练习时长增长
- 对创伤经历的学习者，闭眼、身体扫描或被触碰调整姿势可能触发应激反应 [-M]——需提供睁眼、可退出、不触碰的替代方案
- 将练习作为行为管理工具强制推行会削弱其自主性基础，与 [Self-Determination Theory](../theories/self-determination-theory.md) 的预测一致 [自主感支持内在动机，被强化的"平静练习"可能变成另一种控制手段。](../claims/autonomy-supports-intrinsic-motivation.md) [-M]
- 在课堂时间紧张时挤占学术学习时间，机会成本需被评估 [~W]

#### Implementation Variability
- **呼吸优先**：仅用1–3分钟呼吸调节，适合过渡环节与考前情境
- **完整瑜伽序列**：体育课或课后项目中使用，兼顾身体活动收益
- **正念冥想**：以注意锚点（呼吸、声音）为核心的静坐练习，可结合 [Coaching](../elements/coaching.md) 进行个别化指导
- **整合式**：将状态觉察嵌入学科教学（如写作前的情绪标注），而非独立环节

### Target Learners
- 高觉醒、注意力易分散的学习者，呼吸调节可降低生理唤醒从而改善注意分配 [+M]
- 面临考试焦虑的学习者：正念干预对大学生焦虑与压力有中等程度的缓解效应 [Bamber & Schneider 的元分析显示正念干预降低大学生压力与焦虑。](https://doi.org/10.1007/s12671-016-0551-3) [+M]
- 自我调节能力尚在发展的儿童与青少年，练习提供可迁移的状态管理工具 [+W]
- 创伤史学习者需谨慎适配（见 Constraints）[~M]

### Target Learning Goals
- 自我调节与元认知：觉察并管理自身的觉醒与情绪状态，支撑 [Self-Regulated Learning](../theories/self-regulated-learning.md)
- 注意控制：延长可持续注意的时间，为需要持续认知投入的任务做准备
- 社会情感学习：情绪识别与压力应对技能

### Instructions
1. **建立常规**：固定在每节课或每天同一时段进行，时长从2–3分钟起步，逐步延长。
2. **引导状态觉察**：以 [Check-In](../elements/check-in.md) 开始，让学习者用简短标注（身体感觉、情绪、能量水平）确认当下状态。
3. **实施练习**：引导者示范呼吸或姿势要点，学习者跟随；提供睁眼/闭眼、坐姿/站姿等选择，支持自主感 [自主选择支持内在动机。](../claims/autonomy-supports-intrinsic-motivation.md) [+M]
4. **桥接学习任务**：练习结束后用一句话明确过渡（"现在把这份专注带到阅读中"），避免练习与学习脱节。
5. **逐步移交**：随熟练度提升，减少引导者话语，让学习者独立或互相引导练习，体现责任移交原则。

## Related Strategies
- [Active Recess](active-recess.md) — 同样通过身体活动调节觉醒状态以改善课堂学习，但依赖运动而非静观
- [Achievable Micro-Goals](achievable_micro-goals.md) — 短时规律练习的坚持可借助微目标设定来维持

## Examples
- **[Yoga Ed.](https://yogaed.com)** — 面向学校的瑜伽课程体系，提供K-12课程标准与教师培训，将呼吸、姿势与放松整合进课堂时段。
- **[Mindful Schools](https://www.mindfulschools.org)** — 为幼儿园至高中课堂设计的正念课程，采用每日短时练习加教师培训的模式。
- **[Calm Classroom](https://calmclassroom.com)** — 3分钟课内呼吸与放松脚本，供教师在过渡环节使用。
- **考前呼吸调节**：在标准化考试前进行2分钟箱式呼吸（吸气4秒—屏息4秒—呼气4秒—屏息4秒），以降低唤醒、改善工作记忆可用容量。
