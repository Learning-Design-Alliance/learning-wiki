# Consolidate Key Points

## Description
Summarizing and consolidating key points after pair talk helps to solidify understanding and ensure that all students have a clear takeaway. This can be done verbally or, better yet, by writing a list of key points on the board or via a visualiser. Organizing the ideas visually reinforces the meaning and provides a static reference for students to check against their own understanding.

## Design Implications

### Context
#### Requirements
- Requires allocating time for summarizing key points and providing a visual reference for students.
#### Constraints
- The summary must be clear, concise, and accurate. It should not simply repeat what was said during the discussion but should synthesize the key ideas.
