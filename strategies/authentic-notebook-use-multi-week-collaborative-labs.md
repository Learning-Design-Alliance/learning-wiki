# Design lab courses so notebooks are an essential, authentic part of lab activities via multi-week projects and peer-reliant collaboration

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors' forward-looking recommendation for lab-course design: notebooks need to be made "an essential and authentic part of the lab activities themselves" for more effective use of documentation skills. They speculate this could be done by "including multi-week projects as a part of the course curriculum" and by designing activities so each student must rely on the documentation their peers record, making the lab context more accurately reflect an authentic research setting.
