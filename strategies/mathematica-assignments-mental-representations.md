# Mathematica programming assignments to build mental representations of mathematical objects

> **Strategy** · [All strategies](index.md)

## Description
The course teaches with the programming language Mathematica, having students reproduce selected figures from the papers they read and manipulate equations symbolically with only high-level mathematical understanding. The authors report: "We have found, supported by post-class student feedback, that programming assignments reinforce students' emerging mental representations of unfamiliar kinds of mathematical objects." Notebooks are distributed pared-down and developed in front of students, with the full version provided only after class.
