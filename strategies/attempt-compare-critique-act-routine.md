# Use the attempt, compare, critique, and act learner routine to convert AI feedback into learning actions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 mixed) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article proposes a learner routine in which the learner first completes the task independently so their own reasoning is visible before AI feedback is introduced, then compares the response with AI-generated feedback and critiques both sources, and finally identifies one or two specific changes for the next case, encounter, or simulation. This supports "feedback literacy and evaluative judgment" and ensures feedback closes the loop by changing subsequent learning behavior.

## Design Implications

### Context
#### Requirements
- Learners must complete the task independently before AI feedback is introduced
- Learners must be taught how to formulate prompts, judge plausibility, verify sources, and recognize hallucinations
#### Constraints
- Feedback has limited educational value unless it closes the loop and changes subsequent learning behavior

### Target Learners
- Medical students and clinical trainees

### Target Learning Goals
- Developing feedback agency, evaluative judgment, and self-regulated learning
