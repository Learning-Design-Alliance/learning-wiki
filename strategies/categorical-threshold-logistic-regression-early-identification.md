# Adopt a categorical approach with a validated OSCE communication threshold and logistic regression to evaluate the predictive utility of simulated-patient evaluations in distinguishing lower-performing learners

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The article proposes a next step for using simulated-patient evaluations predictively: "defining a validated threshold for OSCE communication performance and using methods such as logistic regression to evaluate predictive utility of simulated-patient evaluations in distinguishing lower-performing learners." If confirmed, this early identification would enable targeted pedagogical interventions tailored to each learner's specific needs.

## Design Implications

### Context
#### Requirements
- A validated threshold for OSCE communication performance must first be defined
#### Constraints
- The underlying causes of underperformance can vary substantially from one student to another, so interventions would need to be carefully designed and tailored to each learner's specific needs

### Target Learners
- medical students showing early signs of difficulty in achieving communication skills standards

### Target Learning Goals
- communication skills
