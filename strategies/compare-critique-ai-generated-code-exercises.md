# Use structured exercises requiring students to compare, critique, and justify against AI-generated code

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A concrete integration recipe in which instructors design ChatGPT-supported activities that keep students in an evaluative, reasoning role rather than a consumption role. The chapter recommends that "Instructors can use ChatGPT to design structured exercises that require students to compare AI-generated code with their own, identify logic errors, and justify algorithmic choices." This positions the tool as an object of analysis that encourages analysis and deeper comprehension of programming structures, and it aligns with the chapter's broader call for active engagement and computational reasoning.

## Design Implications

### Context
#### Requirements
- Instructors need competence in AI literacy, prompt construction, and evaluation of AI-supported outputs
#### Constraints
- Aimed at programming courses; the chapter frames unstructured use as risking dependency and reduced persistence

### Target Learners
- novice and intermediate programming students in higher education

### Target Learning Goals
- computational reasoning
- debugging and logic-error identification
- algorithmic justification
- deeper comprehension of programming structures
