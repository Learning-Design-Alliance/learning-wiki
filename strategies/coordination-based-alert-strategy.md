# Use coordination-based indicators rather than inactivity alone to trigger alerts and adaptive interventions for struggling groups

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because the decision-tree analysis showed that coordination actions discriminate well-functioning groups better than gaps, the authors propose building alert mechanisms on these indicators. The abstract states: "These insights are now being used to design alert mechanisms to signal inefficient group work and to generate timely interventions." Once the influence of behavioral parameters on quality-oriented outputs is known, "we do no longer need to actually perform a sequence analysis but can use the decision rules as shortcuts", so monitoring can check coordination counts and gaps directly during the working period.

## Design Implications

#### Requirements

### Target Learners

### Target Learning Goals
- sustaining group activity, coordination and productivity in collaborative tasks
