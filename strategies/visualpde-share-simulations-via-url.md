# Share and embed interactive simulations via auto-generated URLs, embedded webpage fragments, or forked open-source code for course materials

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
VisualPDE's share menu generates a URL corresponding exactly to the current simulation and its specified initial conditions, so educators and researchers can distribute bespoke models as links. Simulations can also be embedded in webpages with customisable UI elements, and the entire codebase is forkable under a CC BY licence. The authors expect this "meets the requirements of the vast majority of users, including those creating bespoke models for teaching or research".

## Design Implications

### Context
#### Requirements
- A user designs or modifies a simulation in the browser interface; the share menu then generates the link or embed code
#### Constraints
- The generated URL does not include anything drawn with the brush, timesteps taken, or changes to uploaded image files

### Target Learners
- undergraduate students
- students with disabilities accessing HTML lecture notes
- collaborators and industrial partners

### Target Learning Goals
- distributing interactive course exercises and demonstrations
- communicating research models interactively
