# Include reference frames in a LAD and balance dashboard support with integration into existing educational structures

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that "LAD developers should consider including one or multiple reference frame(s) in a LAD" because participants struggled to establish acceptable scores (e.g., "39 out of 100 does not mean anything"). It also recommends developers "deliberately balance the support and guidance from a LAD with integration in to existing educational structures," noting participants suggested external stimuli such as reminders or integration into reflection exercises, and that progress reference frames allow comparison to an earlier self.

## Design Implications

### Context
#### Requirements
- Reference frames (e.g., norms or progress histories) to facilitate data interpretation; deliberate integration of LAD use into existing educational structures such as reflection exercises or tutor conversations
#### Constraints
- Reference frames can also elicit negative emotions, as the article notes citing prior work

### Target Learners
- University students

### Target Learning Goals
- Interpretation of study behaviour data; goal setting and follow-up activity selection in the preparatory SRL phase
