# Phase 0 validation pilot: 150 score-stratified PLEs rated by blinded experts to assess human-AI agreement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 8 claims (8 for) · 8 studies (4 design, 3 causal, 1 qualitative), `q2` · 4 of 8 report an effect size · 7 claims rest on one study

## Description
The planned phase 0 pilot enrolls up to 75 licensed physicians contributing up to 3 PLEs each, with 20 to 25 expert raters. The primary analysis requires "a minimum evaluable set of 150 eligible PLEs, each independently scored by at least 3 blinded expert raters." Primary human-AI agreement uses a prespecified absolute agreement ICC with 95% CI; weighted kappa and Bland-Altman analysis provide secondary checks.

## Design Implications

### Context
#### Requirements
- Ethics approval and consent; locked evaluator model artifact, prompt and rubric versions before the first participant PLE
#### Constraints
- Study scores will not be used to award actual CME/CPD credit, affect licensure, or make decisions about physician competence; if fewer than 150 PLEs are available, results are exploratory without claiming validation

### Target Learners
- Licensed physicians participating in the phase 0 pilot

### Target Learning Goals
- Establishing scoring reliability and workflow feasibility for AI-mediated learning assessment
