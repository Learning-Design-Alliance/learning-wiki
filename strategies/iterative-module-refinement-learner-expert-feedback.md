## Description
The authors refined the module after each 12-week clerkship block using evidence updates, student feedback, and feedback from primary care providers with expertise in the field. Free-text suggestions such as "enlarging the tables for clarity" and "add quiz questions" led to modified table settings and two added multiple-choice questions.
