# Treat GenAI output as a starting point requiring critical evaluation, personalization, and verification of original sources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
This strategy, articulated by study participants, directs students to use GenAI tools to generate ideas and surface connections, then dig deeper by reading original sources and drawing their own conclusions. It includes adapting AI suggestions to one's own writing style, verifying generated content against one's own knowledge, and consulting supervisors about permitted uses. As one participant put it, "the key to keep academic integrity while using GenAI tools like COREI is to view them as a starting point, not an endpoint."

## Design Implications

### Context
#### Requirements
- Students must possess their own knowledge base and critical thinking skills before using the tools effectively.
#### Constraints
- Copying and pasting AI output without adaptation was perceived by participants as violating academic integrity.

- graduate students
