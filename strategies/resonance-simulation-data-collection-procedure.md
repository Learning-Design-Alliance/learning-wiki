# Guided data-collection procedure for building comparative forced-resonance graphs across damping levels

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Students "select the desired damping option from the dropdown menu" and click play, then wait until most or all red maximum-amplitude points match the pink theoretical points before storing the data set. The run is repeated with a new damping level after re-initialization, building a comparative resonance graph across damping values.

## Design Implications

### Context
#### Requirements
- Each damping level must run for "a sufficient long time greater than 62.8 s" for b = 0.1 before maximum amplitudes are recorded.
