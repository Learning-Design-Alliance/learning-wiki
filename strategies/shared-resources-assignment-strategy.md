# Pilot shared-resources assignments in which students document solutions to common course challenges

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
As an implementable activity targeting social computational literacy, the authors piloted an assignment in which "students were asked to develop shared resources for overcoming common challenges they encountered in the computational physics course". They describe it as "an exercise primarily aimed at developing computational literacy skills" and hope to expand it in the redesigned course. It gives students practice communicating about code beyond their immediate working group.

## Design Implications

### Context
#### Requirements
- Students must encounter common challenges worth documenting, and the resources must be shared with peers rather than produced only for the instructor.
#### Constraints
- The strategy was only piloted in one winter term; the authors state they hope to expand upon it in the new version of the course.

### Target Learners
- junior-level undergraduate physics students in computational labs

### Target Learning Goals
- social computational literacy
- communicating about code
