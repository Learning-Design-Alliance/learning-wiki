# Use structured CL techniques such as Showdown and Trade-A-Problem when the whole class reads the same book

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
For class reader schemes in which "the entire class reads the same book", the article recommends structured techniques: Showdown, where students in groups of four each write answers to a teacher question independently, then compare responses and reach consensus before celebrating; and Trade-A-Problem, where groups write thinking questions, exchange them with another group, and discuss responses. Each technique is analyzed against PIES; e.g., in Showdown "Groupmates provide each other immediate feedback to questions."

## Design Implications

### Context
#### Requirements
- Groups of four with numbered roles such as a rotating Showdown Captain; questions distinguishing text retrieval questions from thinking questions for Trade-A-Problem.
#### Constraints
- The article presents these as a small sample of possibilities, noting some techniques were modified from their original version; they are suggestions, not tested interventions.

### Target Learners
- L2 students in classes doing extensive reading with a shared class reader

### Target Learning Goals
- comprehension of the shared book, question generation, and participation in post-reading discussion
