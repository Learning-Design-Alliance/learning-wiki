# Use video-vignette e-learning modules with expert explanation to teach guideline recommendations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 quant-synthesis), `q3` · 1 of 1 report an effect size · 1 claim rests on one study

## Description
The program's e-learning module for trainees consists of video vignettes in which experienced nurses, psychologists and psychiatrists interact with suicidal patients played by actors, teaching guideline recommendations. Characters vary in age, gender and diagnostic category and display prototypical suicidal symptoms, cognitions and interaction problems. Between vignettes, masters explain guideline topics, and trainees have personalized, repeatable access; total running time is 60 minutes.

## Design Implications

### Context
#### Requirements
- Personalized login access so the module can be viewed repeatedly by trainees
#### Constraints
- Access is protected with a personalized login code to prevent sharing with control departments

### Target Learners
- Psychiatric department staff in training (nurses, psychologists, physicians, psychiatrists)

### Target Learning Goals
- Learning guideline recommendations for assessing and treating suicidal behavior
