# Use GPT-4 or similar tools for immediate formative feedback on handwritten physics solutions, e.g., via smartphone-based scanning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (4 for, 3 mixed) · 3 studies (3 design), `q2` · 1 of 3 report an effect size · 7 claims rest on one study

## Description
The article proposes that if not used for grading exams, GPT or similar tools could assist student learning, especially connected with smartphone-based scanning of written work. This combines the immediacy of online solution-focussed systems with feedback on the full solution path, a domain the author calls "a far more classic domain for AI in physics education."

## Design Implications

### Context
#### Requirements
- A workflow for digitizing handwritten solutions (scanning, OCR, or pen-computing)
#### Constraints
- Whether the system can pinpoint particular errors is "still somewhat doubtful" at the moment

### Target Learners
- introductory physics students

### Target Learning Goals
- formative feedback on written physics problem solutions
