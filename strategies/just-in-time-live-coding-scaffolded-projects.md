# Teach realistically with just-in-time concepts, live coding, and progressively less scaffolded projects

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article advocates realism: using real data and workflows, teaching soft skills, and "just in time teaching" so concepts are applied immediately. It states "Live coding is more useful than long lectures about concepts" and describes restructuring DataTrail so projects parallel a typical data science workflow: "Our projects start out heavily scaffolded... but with each chapter we leave more and more of the data science process to the students to determine for themselves."

## Design Implications

### Context
#### Requirements
- Curriculum must include real datasets and real workflows, and concepts must be quickly followed by hands-on practice
#### Constraints
- Contextualizing must be done carefully to avoid overwhelming learners; simple examples with fewer datasets come first

### Target Learners
- data science students at beginner through advanced stages
- professional learners

### Target Learning Goals
- applied data analysis skills
- communication and career skills
- teamwork
