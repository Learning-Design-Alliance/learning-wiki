Classroom exercise cycle: select a task, formulate a baseline prompt, submit it to an LLM, then critically analyse the output before revising instructions¶

Strategy · All strategies Evidence · no claims cited

Description¶

The paper's core implementable recipe: students select a task relevant to the story they are working on, formulate the baseline prompt from the relevant table, and submit it to an LLM. They must then critically analyse the output by asking which elements are editorially significant, which reflect framing choices embedded in the prompt, which risks (such as hallucination, bias, or oversimplification) are visible and how they would be mitigated before publication, and what further reporting would be needed before the output could inform publication. Prompting is treated as both a practical and reflective activity fostering critical engagement with AI rather than routine use.
