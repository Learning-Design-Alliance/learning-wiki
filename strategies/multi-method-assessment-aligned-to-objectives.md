# Use multiple assessment methods aligned to learning objectives so students must apply information rather than recall memorized facts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The teachers provided multiple methods of assessment aligned to the course learning objectives, increasing the opportunities students had to demonstrate application of learning. Tests were developed so students were required to use information to demonstrate mastery of specific objectives rather than simply recalling memorized facts. The method set included a discursive written exam using video for problem situations, seminars with clinical cases, an OSCE with a simulated situation, and virtual patients; self-assessment was also built into the OSCE. Students rated this combination positively, and the strategy pairs with combining self-evaluations with objective measures of learning.
