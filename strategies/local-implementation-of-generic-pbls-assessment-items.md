# Implement the generic consensus assessment items locally by adding setting-specific components

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors recommend that future work be directed towards local implementation of the generic consensus items. They state this "could be accomplished by adding setting-specific components to the generic assessment items", since health care systems and settings differ across regions even though paediatric physiology does not. The strategy keeps the internationally agreed core while adapting assessment to local contexts.

## Design Implications

### Context
#### Requirements
- The generic consensus items for PBLS and FBAOM as the base instrument
#### Constraints
- The authors state that "the validity of such additions has to be established"

### Target Learners
- laypersons in specific local health care and training settings

### Target Learning Goals
- assess laypersons' PBLS and FBAOM competence in a given setting
