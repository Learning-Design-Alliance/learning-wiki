# Creating a Common Language for Multimodal Composition

> **Strategy** · [All strategies](index.md)

## Description
This strategy builds a shared vocabulary for analyzing and producing multimodal texts. The class selects one mode (linguistic, visual, audio, gestural, or spatial), analyzes authentic examples of that mode in and out of school, and co-constructs a working definition displayed on an anchor chart. The resulting common language lets students name design choices, critique drafts, and discuss their own composing decisions with precision rather than vague praise or complaint.

## Design Implications

Shared terminology reduces the working-memory and communication costs of peer talk about design: when students can name a move ("contrast," "salience," "framing"), discussion shifts from describing artifacts to evaluating decisions [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]. Co-constructing definitions from analyzed examples follows an inductive, concept-attainment logic — students generalize the category from cases before applying it to their own work [Example-problem sequences reduce cognitive load.](../claims/example-problem-sequences-reduce-cognitive-load.md) [+M]. The strategy also draws on dual coding: pairing each term with a concrete visual example creates two retrieval routes for the concept [Dual coding improves recall.](../claims/dual-coding-improves-recall.md) [+M].

### Context
#### Requirements
- Curated examples of the target mode drawn from both academic and out-of-school texts (ads, film clips, infographics, picture books, game interfaces)
- An anchor chart or shared digital reference where the class definition and examples accumulate
- Structured time for [class discussion](../elements/class-discussion.md) and analysis, not just teacher presentation
- A protocol for revising definitions as students encounter counterexamples

#### Constraints
- Time-consuming if every mode is treated exhaustively; one mode at a time with a tight analysis routine is more sustainable [-W]
- Poorly chosen examples (all similar, or all atypical) produce fuzzy or overgeneralized definitions [~M]
- Vocabulary without application decays quickly — terms must be used in [feedback](../elements/feedback.md) and peer critique within days, or the common language remains inert [-W]
- Teacher facility with multimodal analysis matters; vague teacher talk produces vague student talk [~W]

#### Implementation Variability
- Whole-class co-construction (stronger shared ownership) vs. small-group definitions compared and merged (faster, more discussion turns)
- Digital anchor charts (shared slides, Padlet, Jamboard) allow embedding the actual multimodal examples rather than describing them
- In secondary contexts, the routine can be run per discipline — the visual mode works differently in science diagrams than in persuasive posters

### Target Learners
- K–12 students beginning multimodal composition, especially those who can *do* design moves but cannot yet name or explain them [~M]
- Multilingual learners, who benefit from concrete exemplars paired with precise terminology [Dual coding improves recall.](../claims/dual-coding-improves-recall.md) [+M]
- Less necessary for students already fluent in design discourse, who may find the co-construction routine redundant [~W]

### Target Learning Goals
- Metalinguistic and analytical: naming how modes make meaning
- Collaborative critique: enabling specific, actionable peer feedback [Feedback is most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S]
- Intentional composing: applying the vocabulary to justify design choices in students' own work

### Instructions
1. Select one mode and gather 4–6 authentic examples spanning school and out-of-school texts.
2. Guide analysis with [annotating](../principles/annotating.md) — students mark where and how the mode operates in each example.
3. Facilitate [class discussion](../elements/class-discussion.md) comparing examples; surface patterns and disagreements.
4. Co-construct and record a class definition on the anchor chart, attaching the best example to each term.
5. Require immediate use: students apply the terms in [practice](../elements/practice.md) — analyzing a new text, then drafting their own composition and naming their choices.
6. Provide [feedback](../elements/feedback.md) using the shared vocabulary, modeling it in conferences so students adopt it in peer talk.

## Related Strategies
- Peer critique routines — the common language is what makes critique specific rather than generic
- Mentor-text analysis — the example analysis phase is a mentor-text study applied to modes

## Examples
- A grade 5 class studies the visual mode across book covers, infographics, and public-service posters, co-constructing definitions of *salience*, *vector*, and *framing*, then uses those terms in peer conferencing on their own infographic drafts.
- A secondary media studies unit analyzes film title sequences for the audio mode (diegetic vs. non-diegetic sound, pacing, silence) before students storyboard their own sequences.
- The [New London Group](https://www.jstor.org/stable/40231866)'s multiliteracies pedagogy frames this move: "Available Designs" — the named, teachable resources for meaning-making — precede "Designing" and "The Redesigned."
