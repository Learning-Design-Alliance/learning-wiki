# Link SNS applications with the LMS used in universities

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (7 for) · 2 studies (1 causal, 1 qualitative), `q2` · 0 of 2 report an effect size · 7 claims rest on one study

## Description
The article recommends integrating social networking site applications with institutional learning management systems. This strategy emerged from findings that Facebook supported collaborative knowledge creation and improved academic achievement. The authors specifically recommend to "link SNS applications with the LMS used in universities" as one of four recommended practices for advancing e-learning.

## Design Implications

### Context
#### Requirements
- Institutional LMS infrastructure
- Trained students familiar with SNS applications
#### Constraints
- The recommendation is based on a single study in one diploma program at one university

### Target Learners
- Higher education students
- University instructors and instructional designers

### Target Learning Goals
- Collaborative knowledge creation
- Academic achievement
