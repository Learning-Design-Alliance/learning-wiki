# Use serious games as formative, summative and preinstructional assessments in resuscitation training

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The review recommends exploiting serious games' assessment functions in three ways. During play, games "allow for immediate formative feedback", letting learners improve knowledge and skills before subsequent scenarios or real performance. Serious computer games can serve as summative assessments because they "collect the learner's action sequences, evaluate their correctness and provide a performance summary at the end of each scenario". They can also be used as preinstructional assessment tools, for example knowledge assessment before an NRP course, to identify a learner's strengths and weaknesses.

## Design Implications

### Context
#### Requirements
- The game must score performance against a resuscitation algorithm and provide feedback such as timestamped action lists or final percentage scores
#### Constraints
- Several reviewed games have not been scientifically evaluated or assessed for validity, so assessment interpretations remain unverified for those games

### Target Learners
- Neonatal healthcare professionals preparing for NRP provider courses

### Target Learning Goals
- Adherence to the resuscitation algorithm
- Identification of individual strengths and weaknesses before instruction
