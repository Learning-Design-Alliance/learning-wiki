# Develop profession-specific NTS observation tools by adapting existing instruments through iterative co-design with practitioners

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends building NTS observation tools through a bottom-up process: start from existing tools for similar professions (e.g., adapting the surgeon tool for gynaecologists and the scrub practitioner tool for midwives/nurses), then hold iterative meetings with representative practitioners, led by psychology researchers, to adapt and linguistically translate items to the local context. The main goal was "to list only the observable behavioural markers, while avoiding items that were too generic or that were inherent to unobservable mental states".

## Design Implications

### Context
#### Requirements
- Meetings with representative samples of professionals from each category, held by expert researchers, following an iterative design process
#### Constraints
- Where no existing tool exists for a profession (as for healthcare assistants), a new tool must be developed anew

### Target Learners
- simulation designers and healthcare education researchers developing observation tools

### Target Learning Goals
- creating usable, context-appropriate behavioural-marker instruments for peer observation and debriefing
