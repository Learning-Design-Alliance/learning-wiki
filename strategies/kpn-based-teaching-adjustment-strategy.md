# Use examination network properties to identify core themes, tailor instruction by question type, and train comprehensive thinking

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (7 for) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 7 claims rest on one study

## Description
The authors recommend that educators use KPN analysis in practice: teachers can "leverage the network properties of examination papers to accurately identify core themes and key knowledge", develop instruction matched to question types, and use small-world exam papers for training. They suggest experimental questions should focus on hands-on experiments while calculation questions emphasize comprehensive exercises. The method is also proposed for assessing difficulty in test design and post-assessment feedback.
