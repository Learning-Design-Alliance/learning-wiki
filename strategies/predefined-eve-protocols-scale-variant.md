# Predefined Eve protocols variant for high-scale or high-school delivery

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A variant of the project assigns each group a randomly chosen, predefined eavesdropper protocol instead of a peer group's anonymous protocol. The authors state this "can facilitate implementation at scale, where rubrics can be tailored to known eavesdropper techniques, but it lacks the peer-to-peer competitive nature that makes this project so appealing to many students."

## Design Implications

### Context
#### Requirements
- Instructors must prepare a set of predefined Eve protocols in advance
#### Constraints
- It lacks the peer-to-peer competitive nature that motivates students in the adversarial version

### Target Learners
- high school students

### Target Learning Goals
- experience eavesdropping and detection dynamics in QKD without needing full peer adversarial implementation
