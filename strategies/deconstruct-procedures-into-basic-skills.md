# Deconstruct procedures into basic skills, build dedicated exercises for each subskill, evaluate learners against them, and select activities to match the evaluation.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article's implementable recipe is to break procedures down into component basic skills and use that breakdown diagnostically: "This breakdown into subskills allows to (1) build dedicated exercises to specifically train these subskills, (2) more accurately evaluate the level of learners, the difficulties to be overcome, and the points for improvement, (3) more precisely adapt training to this evaluation by selecting relevant activities". When difficulties arise, educators can direct the learner back to targeted practice of a specific core skill.
