# Explicitly examine analogies and models as thinking tools, not merely use them to teach circuit ideas

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 mixed) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends treating analogies themselves as objects of study: analogies and models should not only be used to convey circuit ideas but should be examined explicitly with learners to see how such models function as thinking tools in science. It presents the epiSTEME project's electricity module as a concrete example of this model-based approach, consistent with curriculum moves toward model-based instruction in the United States and England.
