# Assess organisational readiness at the start of an adaptive learning implementation project by selecting context-relevant determinants from the framework

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that project leaders and researchers use the framework at the beginning of a project to reflect on the institution's context and readiness, selecting determinants relevant to their unique implementation setting. The framework "can be used to monitor and improve an ongoing implementation process by selecting and operationalising specific strategies that address the previously identified factors". It can also raise awareness of critical factors among researchers, instructors, and management.

## Design Implications

### Context
#### Requirements
- Determinants must be selected from the framework that are relevant for the institution's unique implementation setting
#### Constraints
- The framework was derived from two universities in Switzerland and South Africa with distinct structural and socio-economic contexts

### Target Learners
- higher education students

### Target Learning Goals
- successful and scaled implementation of adaptive learning
