# Combine refutation texts with visual metacognitive prompts during strategy practice to teach self-regulated interleaving

> **Strategy** · [All strategies](index.md)
> **Evidence** · 8 claims (7 for, 1 mixed) · 4 studies (2 causal, 2 quant-synthesis), `q3`–`q4` · 3 of 4 report an effect size · 7 claims rest on one study

## Description
The intervention has three components: refutation texts that explicitly name and challenge erroneous beliefs (e.g., "Many students believe that blocked practice leads to better learning than interleaved practice"), an experimenter-controlled strategy-implementation phase in which students experience both strategies, and visual metacognitive prompts showing how perceived effort and learning changed over time for each strategy. Prompt questions direct students to focus on temporal changes, interpret them, and associate them with strategy efficacy. Refutations are delivered before study so students are warned about misleading on-task experiences.

## Design Implications

### Context
#### Requirements
- Refutation texts must explicitly state the erroneous belief, mark it as false, and give an evidence-based explanation
- Metacognitive prompts require students to rate perceived effort and learning after each study unit so the visual summaries can be built
- Strategy implementation must let students experience both blocked and interleaved practice
#### Constraints
- Tested with visual category learning (painting styles, bird species) in undergraduates; the authors state it remains unclear whether students would adopt a similar approach with more relevant, real-world materials
- Whether a strategy is desirable depends on task demands, task complexity, (dis)similarity of materials, and test type

### Target Learners
- undergraduate students learning visual categories

### Target Learning Goals
- self-regulated use of interleaved practice in category learning
- accurate beliefs about learning strategy effectiveness
