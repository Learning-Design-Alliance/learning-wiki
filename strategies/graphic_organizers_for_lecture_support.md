# Graphic Organizers for Lecture Support

## Description
Instructors deliver lectures using a graphic organizer to visually connect concepts, rather than using PowerPoint or a standard outline. This approach provides students with a clear way to see how concepts relate to each other.

## Design Implications

### Context
#### Requirements
- Access to graphic organizer templates, lecture content organized visually.
#### Constraints
- Requires significant preparation by the instructor to translate lecture content into a visual format.

### Affordances
- Provides a clear and structured way to understand complex information. Aids in visual memory and information retention.

### Personalization
- Instructors can adapt the graphic organizer to fit the specific content and learning objectives.
