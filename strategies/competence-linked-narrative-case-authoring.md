# Author competence-linked narrative cases that adapt to similar story contexts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (1 review, 1 qualitative, 1 design), `q1`–`q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
Author a case representing a situated context for a target competence, such as conflict seeding for conflict management, and let the Drama Manager suggest the case's actions when the emerging fabula matches. Cases "can be transformed and adapted to match different similar contexts", for instance other character names or the protagonist performing other actions.

## Design Implications

### Context
#### Requirements
- The emerged fabula context must match the case for suggestions to trigger
#### Constraints
- Suggested actions depend on the Agent Framework accepting them as credible

### Target Learners
- corporate learners practising conflict management

### Target Learning Goals
- conflict management via conflict-seeding story situations
