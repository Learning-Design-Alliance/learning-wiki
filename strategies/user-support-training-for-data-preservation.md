# Extend in-house user-support training and robust documentation to preserve HEP data for future re-analysis by non-collaboration communities

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends that the methods and technology used to train CMS users in house be extended to train the non-CMS community interested in revisiting and re-analyzing preserved data. It argues that a very first step toward data preservation is robust, up-to-date documentation of software, analysis code and techniques, which the WorkBook, SWGuide and software reference already provide and the User Support periodically reviews. "Given the numerous tutorials, analysis schools held by User Support team, we have trained over ~500 CMS users over last 2 years."

## Design Implications

### Context
#### Requirements
- An immediate commitment and continued resources would be needed in CMS to fully exploit reuse of the data
- A responsible identified to maintain and update each documentation topic
#### Constraints
- Software and analysis techniques become non-usable as experts move on and new technology supersedes; computing power may not be available once host-lab commitment ends

### Target Learners
- future scientific community members re-analyzing preserved CMS data
- non-CMS HEP scientists, educators and citizen scientists

### Target Learning Goals
- re-analyzing preserved CMS data
- understanding CMS computing, software and analysis techniques
