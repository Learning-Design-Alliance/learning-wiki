# Use dynamic user models to recognize non-optimal learning behaviors and redirect students toward more effective behaviors

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends embedding dynamic user models that monitor students' interaction patterns in real time so the system can respond when learning goes off track. As stated, "Dynamic user models have the potential to recognize non-optimal learning behaviors and provide feedback or navigate students toward more effective learning behaviors within the practice environment." This supports adapting content presentation and feedback to each student's current learning trajectory.

## Design Implications

### Context
#### Requirements
- A dynamic user model fed by real-time analyses of logged student behaviors
#### Constraints
- Proposed for game-based practice environments with substantial student agency; implementation and testing are future work

### Target Learners
- high school students in game-based ITS practice environments

### Target Learning Goals
- self-explanation strategy practice
- sustaining optimal learning trajectories
