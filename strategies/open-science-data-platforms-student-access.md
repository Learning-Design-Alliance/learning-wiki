# Define the scope of publicly available HEP data and analysis platforms for education

## Description
The report states that broadly accessible data and analysis platforms will benefit student access and participation. In the true spirit of Open Science, the HEP community should define, with cogent arguments, what should be the scope of making data and resources publicly available, and the hardware, software and person-power costs associated with such implementation.
