# Structure remote MR tutorials as baseline assessment, metrics-based feedback and deliberate practice, preceded by device familiarisation training

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (4 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The tutorial recipe used in this study: students complete a familiarisation session with the device, then a baseline competency assessment on a simulation model using a 29-point validated tool, followed by stepwise metrics-based feedback that "informed sequential deliberate practice of the procedure", then a second assessment. Familiarisation used the Microsoft Tips application to build competence in device start-up, initiating a Teams call and interacting with holographic artefacts. This structure was applied identically to both randomised groups.

## Design Implications

### Context
#### Requirements
- A validated metrics-based assessment tool
- Structured pre-tutorial device familiarisation training developed and trialled by experienced users
- Supervised practice time (about 30 minutes per session in this study)
#### Constraints
- The familiarisation training was required only for the remote HoloLens format

### Target Learners
- undergraduate medical students on clinical attachment

### Target Learning Goals
- peripheral intravenous cannulation competency
