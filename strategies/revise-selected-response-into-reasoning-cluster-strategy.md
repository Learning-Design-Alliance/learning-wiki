# Revise a selected-response item into a cluster of related questions that provides evidence of reasoning and system interactions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
To obtain explicit evidence of student reasoning while remaining selected response, the article revises one traditional question into "a cluster of three related questions." Modifications place the question in a real-world setting (the original described an already idealized situation), ask students to select a free body diagram (supplying missing information about interactions with the surroundings), and include multiple reasoning options among the answers so that selected responses reveal the reasoning used. This follows the authors' claim that "the revised item was developed into a cluster of three related questions" aligning with the three dimensions.

## Design Implications

### Context
#### Requirements
- Reasoning options must be included among the answer choices so selected responses carry evidence of the reasoning used
- The revised cluster must include a representation choice (e.g., a free body diagram) that carries information about system-surroundings interactions
#### Constraints
- The article claims this is only "as close to aligning with the practice as it can be while remaining a selected response item"; it does not claim full engagement in a scientific practice

### Target Learners
- introductory college physics students

### Target Learning Goals
- developing and using models
- systems and system models
- interactions can cause changes in motion
