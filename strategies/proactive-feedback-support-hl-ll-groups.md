# Provide proactive feedback support for low-achieving student groups rather than waiting for requests

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
For low-achieving students the article recommends moving beyond staff responsiveness, because awaiting student requests "is less appropriate for HL and LL where the approach needs to be proactive." It further calls for "the development of tools to help staff be more aware of students' performance in class."

## Design Implications

### Context
#### Requirements
- Development of tools to help staff be more aware of students' performance in class
#### Constraints
- Reactive, request-based staff responsiveness remains appropriate for the HH, LH, HM and LM groups

### Target Learners
- low-achieving undergraduate programming students (HL and LL groups)

### Target Learning Goals
- understanding automated feedback and fundamental programming concepts
