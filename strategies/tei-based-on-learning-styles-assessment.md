# Adapt student assessment using technology-enhanced items developed based on students' learning styles

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors propose adapting student assessment by developing technology-enhanced items (TEIs) based on students' learning styles. The abstract states that "The authors suggest adapting student assessment utilizing technology-enhanced items (TEIs) developed based on students' LS may provide a more reliable measure of student ability." This is an implementable assessment-design strategy: item design follows the learner's classified learning style, with the intended benefit of more reliable ability measurement.
