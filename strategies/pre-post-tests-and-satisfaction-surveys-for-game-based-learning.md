# Assess game-based learning outcomes using pre/post knowledge tests and satisfaction surveys

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 3 studies (2 causal, 1 design), `q2`–`q3` · 1 of 3 report an effect size · 4 claims rest on one study

## Description
This study measured game-based learning outcomes using identical pre- and posttests consisting of short-essay questions, and assessed participant satisfaction using a five-point Likert scale across six domains. The authors recommend that future research should incorporate other assessment methods, compare serious games with standard educational formats, assess long-term knowledge retention, and further evaluate the validity of assessment tools.

## Design Implications

### Context
#### Requirements
- Tests should be developed based on key concepts outlined in the training curriculum
- Assessment content should be aligned with the educational objectives of the intervention
#### Constraints
- Short-answer questions may not fully capture the knowledge gained from game-based learning methods

### Target Learners
- Anesthesiology residents

### Target Learning Goals
- Evaluating knowledge acquisition and satisfaction from game-based learning
