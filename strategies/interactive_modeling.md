# Interactive Modeling

## Description
Interactive Modeling is an instructional practice where the educator provides instruction for self-checking and provides an example. For example, in a second grade classroom this might look like a student leading a meditation, where the educator provides instructions and background to the student or a video of him leading the class in the meditation itself.
