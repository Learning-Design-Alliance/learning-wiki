# Explicitly teach search-based heuristics and metacognitive skills using cognitive load techniques

> **Strategy** · [All strategies](index.md)

## Description
The article recommends teaching general problem-solving heuristics and metacognitive skills as biologically secondary knowledge, using cognitive load theory techniques to reduce unnecessary working memory load. It suggests "explicit instruction that models the application of means-ends analyses in solving selected domain-specific problems that are genuinely new to learners," worked examples for novices, and metacognitive prompts for more experienced learners.

## Design Implications

### Context
#### Requirements
- Problems used for modeling the heuristic must be genuinely new to the learners; explicit examples suit novices while metacognitive prompts suit more experienced learners.
#### Constraints
- The article states these are hypothetical approaches that should be tested experimentally against traditional approaches with delayed post-tests of genuinely novel problem solving.
