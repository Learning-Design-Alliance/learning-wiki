# Prepare and test technology before launch, scaffold the learning curve, and leverage tech-savvy students as peer resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The report's program lessons recommend that teachers using emerging technologies conduct substantial preparation to test drive the technology prior to introducing the project into the curriculum, since school firewalls and unfamiliar workflows create obstacles. During the project, teachers recommended developing scaffolds for students to navigate the steep learning curve, while recognizing that some students quickly develop familiarity and should be leveraged as resources for other students still struggling.

## Design Implications

### Context
#### Requirements
- Time and opportunity to test equipment and workflows before curriculum launch; scaffolds during the project
#### Constraints
- School system firewalls and restrictions can be incompatible with viewing media and video editing, particularly in a mobile app designed for a VR headset

### Target Learners
- high school students using emerging technologies such as 360 cameras and VR headsets

### Target Learning Goals
- media production skills with new technologies
