# Measure teachers' assessment-to-instruction practice across planning, collection, interpretation, and use

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's approach for examining data-informed individualization is to structure observation across the full cycle: planning data collection, collecting valid data, organizing and interpreting data, and using data "to inform both overall and individualized instruction." Researchers can apply this structure when building measures of teachers' assessment practice.

## Design Implications

### Context
#### Requirements
- Measurement instruments must cover each of the four processes rather than only data collection
#### Constraints
- Developed and framed for early childhood instructional settings

### Target Learners
- Early childhood teachers

### Target Learning Goals
- Individualizing instruction based on ongoing child assessment data
