# Use separately numbered questions asking students to explain how results can be seen in the simulation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors revised all applicable activities to include "separately numbered questions for these comparis ons, using formulations such as  'Explain how you can see these results graphically in the simulation'". This prompts students to compare their calculations with simulation results explicitly rather than restating them superficially.
