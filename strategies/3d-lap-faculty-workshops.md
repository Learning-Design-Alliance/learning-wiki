# Use the 3D-LAP in faculty development workshops to train instructors to write three-dimensional assessment tasks

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (4 for, 1 mixed) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
The authors propose using the 3D-LAP as a professional development tool to aid faculty in writing assessment tasks capable of eliciting evidence of engagement with scientific practices, crosscutting concepts, and core ideas. In workshops, participants are introduced to the protocol, asked to code existing assessment tasks, and then use it to develop their own tasks. Anecdotally the response is positive and novice use aligns with the designers' intentions.

## Design Implications

### Context
#### Requirements
- Faculty interested in bringing three-dimensional learning to their classroom must have ways to assess this kind of learning
- Participants will likely need to be trained to use the protocol in ways that align with the designers' intent
#### Constraints
- Workshop participants are a self-selected group; the extent to which other faculty need guidance has not yet been determined
- Evidence of workshop effectiveness is anecdotal

### Target Learners
- College science faculty teaching introductory biology, chemistry, and physics

### Target Learning Goals
- Designing assessment tasks that elicit evidence of engagement with scientific practices, crosscutting concepts, and core ideas
