# Use dusty plasma images and DC glow discharge time-series data to teach image processing and time-series data analysis techniques with ImageJ, MATLAB, and Python

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article proposes two linked data-analysis learning opportunities from one device. First, students analyze stored camera frames of dust grain oscillation, dust-acoustic waves, rotational motion, linear flow, and dusty plasma crystal using ImageJ, MATLAB, and Python; the article states "such hands-on experience will help students gain a better understanding of the image processing and image analysis techniques". Second, DC glow discharge plasma, assumed to be a highly complex non-linear system, provides floating-potential or discharge-current time series for learning fast Fourier transformation, phase space diagrams, and Lyapunov exponent methods.

## Design Implications

### Context
#### Requirements
- High frame rate CCD or CMOS camera frames transferred to PC for analysis
- ImageJ, MATLAB, Python or similar software for image processing and spectral analysis
- Recording of discharge current or floating potential time series at given discharge conditions
#### Constraints
- The pattern of the time-series data depends on discharge parameters such as gas pressure, discharge voltage, and external magnetic field; transitions between stable, chaotic, and periodic states occur with changing discharge parameters

### Target Learners
- undergraduate physics students
- postgraduate physics students

### Target Learning Goals
- learning image processing and image analysis techniques
- learning time-series data analysis methods (FFT, phase space diagrams, Lyapunov exponent) for nonlinear dynamical systems
