# Use multiple raters for principal-assigned professional practice ratings to improve consistency

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The report recommends improving the professional practice measure by drawing on more than one rater per teacher, because school-level variation in principal-assigned ratings suggests standards may differ across schools. The authors state the measure "might be improved by using more than one rater for each teacher."

## Design Implications

### Context
#### Requirements
- Requires additional trained raters beyond each teacher's school principal to produce practice ratings.
#### Constraints
- Recommended in the context of Pittsburgh Public Schools' newly implemented evaluation measures; the report notes variation across schools on the principal-assigned rating.

### Target Learners
- K-12 teachers in districts implementing multiple-measure teacher evaluation systems

### Target Learning Goals
- Accurate, consistent differentiation of teacher effectiveness for evaluation and staff development
