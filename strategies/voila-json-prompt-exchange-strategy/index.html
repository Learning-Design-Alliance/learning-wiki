Simulate collaborative GenAI use by exchanging JSON prompt scripts via the free Voilà tool¶

Strategy · All strategies
Evidence · no claims cited

Description¶

Because collaborative GenAI assistants required subscriptions and ChatGPT deprecated continuing shared conversations, the article simulates collaboration by exchanging prompt scripts with the freely available Voilà tool. Chat history can be exported and imported "in JSON formats", letting one team continue another team's conversation and return outcomes to instructors for analysis.

Design Implications¶

Context¶

Requirements¶

  • Instructors prepare initial prompt scripts from briefing contents; students need JSON import/export workflow support

Constraints¶

  • Voilà has a prompt size constraint; subscription-based collaborative GenAI tools were deemed unsuitable for instructional purposes

Target Learners¶

  • 3rd and 4th year university students in UX design courses

Target Learning Goals¶

  • collaborative UX ideation
  • persona creation
  • information architecture categorization

Related Strategies¶

  • Sequence CSCL research on human-AI knowledge construction from exploratory observation to experimental variable manipulation
  • Focus collaborative diagnosis on initially unshared information through a cycle of eliciting and sharing
