# Split ILB assessment between course-level formative assessment by instructors and block-level summative assessment by the ILB committee

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
In the ILB framework, formative assessment of a skill set emphasized in a specialized course is conducted regularly by that course's instructor using written examinations, hands-on laboratory data collection, and group reports. Summative assessment of the learning block is instead evaluated by the ILB committee, which considers the amalgamation of skills from the three target courses and how they contributed to the engineering design project. The ILB coordinator acts similarly to a project manager, meeting students regularly to verify periodic milestones are met.
