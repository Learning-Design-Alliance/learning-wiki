# Continuous user participation and feedback mechanism for iterative system improvement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
An implementable improvement cycle in which users submit feedback instantly through a prominent in-system feedback button, feedback is automatically categorized, and urgent problems trigger automatic responses or technical-support notification. The article states that "a real-time feedback tool is integrated into the system, allowing users to submit feedback instantly upon encountering any problems or suggestions during use". Collected feedback is sorted, classified and analyzed, and the design team refines the interface and logic accordingly.

## Design Implications

### Context
#### Requirements

- Automatic categorization of received feedback
