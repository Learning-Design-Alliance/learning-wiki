# Use the VPA implemented in Xcos as an interactive teaching route to physical intuition about scattering phase shifts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends having students compute phase shifts via the Variable Phase Approach in Scilab's Xcos GUI environment rather than solving the TISE and matching boundary conditions. It argues the VPA 'is a valuable teaching tool because it shows how the scattering phase shift is affected by the presence of a potential', and that the Xcos code for the demonstrated potentials 'is remarkably simple', with models supplied in supplementary material for students to implement for other phenomenological potentials.

## Design Implications

### Context
#### Requirements
- Access to Scilab and its Xcos toolbox, which is freely downloadable
- Potentials must be spherically symmetric with definite asymptotic behaviour for the phase function equation to be valid
#### Constraints
- The paper demonstrates the strategy on four model potentials (Kronig-Penney periodic and three Yukawa forms) rather than reporting classroom evaluation data

### Target Learners
- physics students in nuclear, atomic, and molecular scattering coursework

### Target Learning Goals
- developing physical feeling for the relation between potential and phase shift
- learning to solve complex differential equations interactively

### Affordances
- Variable Phase Approach Phase Function Method
