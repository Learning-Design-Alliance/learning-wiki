# Improve XR-CBL case presentations with labeled structures, step-by-step guidance, focused videos, technical reliability, and embedded assessment

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 causal, 1 qualitative), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
From student feedback, the article identifies concrete enhancements to XR-CBL case presentations: providing labeled structures and clearer controls for the DICOM viewer and Sketchfab, centralized step-by-step written or video instructions, more short focused videos with optional walkthroughs, more structured in-case guidance, improved DICOM viewer load speed and device compatibility, and embedded quiz questions with highlighted key learning points. The article reports that students suggested "the integration of embedded quiz questions and the highlighting of key learning points... suggesting a desire for more active learning and assessment within the presentations."

## Design Implications

### Context
#### Requirements
- Student feedback collection via mixed-format surveys to identify usability and pedagogical gaps
#### Constraints
- Technical barriers such as slow loading, limited device compatibility, and complex navigation with the initial DICOM viewer may challenge replication in other settings

### Target Learners
- First-year medical students using XR-based anatomy modules

### Target Learning Goals
- Navigating XR case platforms independently
- Active learning and self-assessment within case presentations
