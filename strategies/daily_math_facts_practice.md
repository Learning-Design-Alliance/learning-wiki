# Daily Math Facts Practice

## Description
Beginning each math lesson with spaced practice to review arithmetic facts. Sessions can be individual, small groups, or whole class, using songs, dry erase boards/pockets, and flashcards. Supports Arithmetic Fact Retrieval, Operations, and Place Value skills.

## Design Implications

### Context
#### Requirements
- Routine practice at the start of each math lesson, using flashcards, dry erase boards, or songs.
#### Constraints
- May become monotonous if not varied; requires regular implementation.
