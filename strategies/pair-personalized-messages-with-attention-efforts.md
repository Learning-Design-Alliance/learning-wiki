# Pair personalized messages with an effort to call attention to them

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The brief's key findings caution that personalized messages "might only work when combined with an effort to call attention to the messages." This recommends that practitioners implementing message-based nudges deliberately ensure students notice the messages, for example when delivering them through existing documents like test score reports.

## Design Implications

### Context
#### Requirements
- A delivery mechanism that ensures students actually notice the message
#### Constraints
- The brief states this condition tentatively ("might only work"), based on the AP study

### Target Learners
- high school students

### Target Learning Goals
- program participation decisions
