# Common Language for Multimodal Composition

> **Strategy** · [All strategies](index.md)

## Description
Creating a shared vocabulary or metalanguage empowers learners to analyze and discuss their multimodal composition process. The strategy involves selecting one mode (linguistic, visual, audio, gestural, or spatial), analyzing authentic examples together, and co-constructing class definitions of key terms. Explicitly connecting each mode to its use across subjects and contexts helps learners understand its versatility and application.

## Design Implications

A shared metalanguage converts tacit design intuitions into discussable, revisable decisions — learners who can name a technique (e.g., salience, framing, vector) can critique and improve their own work rather than relying on vague impressions [~M]. Building the vocabulary through analysis of concrete exemplars, rather than delivering definitions first, grounds abstract terms in perceivable features and supports retention [Dual coding improves recall.](../claims/dual-coding-improves-recall.md) [+M]. The glossary itself functions as an [Advance Organizer](../elements/advance-organizers.md) for subsequent composition and critique activities.

### Context
#### Requirements
- Time for discussion and analysis; vocabulary work cannot be compressed into a single lesson
- Anchor charts, shared documents, or digital platforms for recording terms and definitions as they are co-constructed
- A curated set of authentic multimodal exemplars in which the target features are clearly visible
- Instructor fluency with multimodal terminology (e.g., Kress & van Leeuwen's grammar of visual design) or willingness to build it alongside learners

#### Constraints
- Building a comprehensive glossary requires significant time investment that competes with composing time; vocabulary work that never feeds back into making becomes inert
- Learners may struggle with abstract concepts if not grounded in concrete, contrasting examples
- Overly technical metalanguage can raise extraneous load for novices [Cognitive overload degrades learning.](../claims/cognitive-overload-degrades-learning.md) [-M] — introduce a small working set of terms per mode rather than a full taxonomy at once
- Metalanguage alone does not improve composition; it must be coupled with [Practice](../elements/practice.md) and [Feedback](../elements/feedback.md) tied to the named features

#### Implementation Variability
- Mode-by-mode sequencing: build vocabulary for one mode (often visual) before adding others
- Learner-authored glossaries: students propose and define terms from their own analysis, with the class refining definitions
- Cross-curricular mapping: explicitly pointing out how each mode operates differently in science, media studies, and the arts to show versatility
- Digital annotation tools (e.g., hypothes.is, Thinglink) let learners tag named features directly on exemplars

### Target Learners
- Learners new to multimodal composition who lack language for articulating design choices [~M]
- Multilingual learners, who benefit from an explicit, accessible vocabulary with concrete referents [Accessible vocabulary and syntax improves comprehension.](../principles/accessible-vocabulary-syntax.md) [+M]
- Advanced learners may find prescribed terminology constraining; allow them to extend or challenge the class glossary

### Target Learning Goals
- Analytical literacy: naming and interpreting how modes make meaning
- Metacognitive design talk: justifying compositional decisions during drafting and peer review
- Transfer across contexts: recognizing that the same mode functions differently in different subjects and audiences

### Instructions
1. Select one mode and gather 2–3 contrasting exemplars in which its meaning-making features are salient.
2. Guide whole-class analysis using [Direct Instruction](../elements/direct-instruction.md) to name key features, then [Class Discussion](../elements/class-discussion.md) to co-construct definitions grounded in the examples.
3. Record agreed terms and definitions on an anchor chart or shared digital glossary; add examples alongside each definition.
4. Have learners apply the vocabulary in their own composing and in structured peer critique, using [Annotating](../principles/annotating.md) to tag named features in drafts.
5. Provide [Feedback](../elements/feedback.md) that uses the shared terms, reinforcing the metalanguage at the task and process level [Feedback is most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S].
6. Revisit and extend the glossary as new modes and contexts are introduced.

## Examples
- **MODE multimodal glossary** (2012, UCL Institute of Education) — a research-derived glossary of multimodal terms that classes can adapt: https://mode.ioe.ac.uk/whatismultimodality/
- **Australian Curriculum: English** — requires a shared "language of visual design" (salience, vectors, framing) that teachers build with students before analyzing picture books and advertisements
- A media arts unit where students co-construct definitions of *shot type*, *gaze*, and *juxtaposition* from film clips, then use those terms in storyboard peer critique
