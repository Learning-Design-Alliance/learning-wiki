# Use a two-phase pre-usability testing method (requirements gathering then questionnaire ranking) before developing a mobile collaborative learning application

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends conducting usability testing before development to bridge users with applications. Phase one collects user requirements through literature survey, interviews and coordination with experts; phase two sorts the most influential basic requirements through a questionnaire with a five-level Likert item and a mean-points formula. The authors state that "usability testing makes the work of bridging the users with applications", and that this method gives a complete picture for developing a mobile application meeting pedagogical targets.

## Design Implications

### Context
#### Requirements
- Access to participants across roles (students, teachers, teaching assistants, administrators)
- A Likert questionnaire and a scoring formula to rank requirements
#### Constraints
- The article notes existing literature is not sufficient for developing a general mobile application meeting most basic user requirements, motivating the method

### Target Learners
- students
- teachers
- administrators

### Target Learning Goals
- designing mobile applications that support collaborative learning
