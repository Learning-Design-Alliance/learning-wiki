# Use FIAS-coded teaching observation with cluster analysis to provide objective, profile-based feedback to clinical teachers

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article proposes extending FIAS-based observation with statistical clustering as an evaluation method for faculty development: videotape teachers in simulated teaching scenarios, code verbal behaviors with FIAS, apply Sparse K-Means clustering to identify behavioral profiles, and use the cluster characteristics to give teachers objective feedback on their teaching. The authors state "The evaluation method employed in this study can be extended to more teaching methods and skills" and that through teaching observation, "clinical teaching skills and reflection teaching can be improved". If qualitative feedback is provided together with timeline marking, more precise feedback and suggestions can be provided.

## Design Implications

### Context
#### Requirements
- Videotaped teaching sessions
- Trained coders with interrater reliability testing
- Statistical software for clustering (R with sparcl package in this study)
#### Constraints
- FIAS does not capture nonverbal behavior or content expertise
- Sample size should meet the 2^k rule for clustering variables

### Target Learners
- Clinical teachers
- Faculty development program participants

### Target Learning Goals
- Objective teaching self-assessment
- Identifying teaching behavior profiles
- Targeted teaching improvement
