# Future training plans: software understanding and in-house Python instruction for operations staff

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The mid-term future of PSO training is devoted to software: operators and astronomers will be primed on the software controlling VLT operations, not trained to write software, so that communication of needs and issues with the software team improves. The second half of the effort teaches the Python language to PSO members using in-house expertise, so more members can write scripts to improve efficiency and data quality.

## Design Implications

### Context
#### Requirements
- Collaboration with the software support team; in-house Python expertise as instructors
#### Constraints
- The goal is not to train PSO in writing software, but to give a more detailed understanding of the VLT software system

### Target Learners
- PSO operators and astronomers at Paranal

### Target Learning Goals
- understanding the VLT control software and writing Python scripts to improve efficiency and data quality
