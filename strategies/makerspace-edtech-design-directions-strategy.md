# Broaden the design space of educational technologies for makerspaces beyond technical skill support

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The authors argue existing maker tools 'primarily focus on one aspect, which is learning technical skills' and are designed from the learner's perspective, missing educators' values and goals. They identify opportunities for research on technologies for scaffolding problem-based and project-based learning, collaborative work, supporting communication within makerspaces, and building trust and care within makerspaces.

## Design Implications

### Context
#### Requirements
- Designers need an understanding of educators' practices, competencies prioritized, and challenges to align technologies with the actual context in which learning takes place.
