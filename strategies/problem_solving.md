# Problem Solving

## Description
Problem solving involves designing activities that require learners to come up with solutions - ways of dealing with issues or challenges that they can then use back on-the-job. With this approach, the process of determining a solution is where deep learning occurs, forcing learners to think outside of the box.

## Design Implications

### Context
#### Requirements
- Real-world problems that need solutions, facilitator to guide the learning process
#### Constraints
- Success depends on the relevance of the problems to the learner's job.
