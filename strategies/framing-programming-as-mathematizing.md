# Frame programming in science class as mathematizing: students design discrete measures of change over time

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The chapter recommends framing programming as "mathematizing" in the science classroom: students create computational models by "designing discrete mathematical representations of units of change, for representing change over time," so code defines a unit of measurement repeated when the program runs. The authors report this helped students overcome conceptual challenges with linear continuity and emergent aggregation, and aligns with teachers' reported learning goals around units and measurement in standardized assessments.

## Design Implications

### Context
#### Requirements
- Programming activities must ask learners to define events in discrete measures whose repetition generates motion or simulation state
- Iterative cycles of building, sharing, refining and verifying computational models
