# Organize PPOL teams of 3–4 students per solution method with staged data collection

## Description
An implementable recipe for running the CDIO-CT strategy: "It is feasible to organize a team or group with 3∼4 students to work on a project for solving the period of MP with one specific method". Teams collect data at each project stage — conceiving (recorded period derivations and block diagrams), problem description, decomposition, design (module outlines and interfaces), implementation (code with Git version control), and a final project report in LaTeX or Word — which the instructor uses to check teamwork and give feedback.
