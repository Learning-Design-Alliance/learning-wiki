# Phenomenon-based learning cycle: observation, questioning, investigation, modelling, explanation, extension

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Instruction across all QLP tiers is anchored in observable quantum phenomena — interference, entanglement, measurement outcomes — rather than abstract formalism. Learning activities follow a structured inquiry cycle (Fig. 2): Phenomenon → Question → Investigation → Model → Explanation → Extension, where each phase develops specific quantum competencies from intuition development to application development. The article states the cycle "supports gradual abstraction by allowing students to first build intuition, then formalize their understanding using mathematical and computational models."
