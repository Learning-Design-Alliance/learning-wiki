# Memory Game (Matching)

> **Strategy** · [All strategies](index.md)

## Description
A memory game in which learners turn over pairs of face-down word cards, attempting to find matching pairs. Each successful match triggers an elaboration step — the learner says the word aloud and uses it in a sentence drawn from a familiar context, such as a song or shared text. The game combines repeated exposure, [active recall](../elements/practice.md), and contextualized production in a low-stakes, playful format.

## Design Implications

The matching mechanic forces retrieval of each word's location and identity, and retrieval practice strengthens retention far more than re-reading [Spaced repetition improves retention.](../claims/spaced-repetition-improves-retention.md) [+S]. The sentence-production requirement converts passive recognition into generative use, which deepens conceptual understanding [Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M]. Because the game is turn-based and social, it also sustains engagement through peer observation and light competition [Active learning improves exam performance.](../claims/active-learning-improves-exam-performance.md) [+M].

### Context
#### Requirements
- Two identical sets of word cards, printed on cardstock (to prevent see-through) and cut apart
- A small-group setting (3–6 learners) with a surface large enough to lay out a grid of cards
- A shared familiar context (song, story, or text) from which matched words can be used in sentences
- Clear turn-taking rules and a teacher or peer monitor to verify sentence accuracy

#### Constraints
- Preparation and setup are time-consuming; laminated or digital card sets amortize this cost across uses
- If the sentence-production step is skipped or unmonitored, the game reduces to visual search and rote location memory, with little vocabulary learning [-M]
- Words that are too similar (e.g., minimal pairs) can frustrate beginning readers; words too easy make matching trivial and eliminate retrieval effort [~M]
- Turn-based play means individual learners get few turns in large groups — wait time between turns invites off-task behavior [-W]

#### Implementation Variability
- **Match word–to–definition** or **word-to-picture** instead of word-to-word, shifting the task from recognition to comprehension
- **Concentration with a twist**: after a match, the learner must also produce a *new* sentence (not one from the song) for an extra point
- **Digital versions** (e.g., Quizlet's "Match" mode, Flippity's Google Sheets template) remove the cardstock overhead and add timing data
- **Sentence frames** ("The ___ is ___.") scaffold production for [English language learners](../elements/practice.md)

### Target Learners
- Elementary learners (K–5) building decoding and vocabulary foundations
- English language learners, who benefit from the pairing of oral production with a visual/physical task
- Learners who need low-stakes repetition; the game format reduces anxiety around making errors in front of peers [~W]
- Less appropriate for advanced learners who already recognize the words fluently — matching then measures visual search speed, not vocabulary [~M]

### Target Learning Goals
- Vocabulary retention through repeated retrieval [Spaced repetition improves retention.](../claims/spaced-repetition-improves-retention.md) [+S]
- Contextual application: using target words in meaningful sentences
- Working memory and attention: holding card locations in mind across turns [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]
- Turn-taking and peer support as incidental social goals

### Instructions
1. Prepare two identical sets of target word cards (8–12 pairs for a first round) and lay them face down in a grid.
2. Model one full turn: flip two cards, read each aloud, and demonstrate a correct sentence for a matched pair ([Practice](../elements/practice.md) via modeling).
3. Learners take turns flipping two cards, reading each word aloud. Non-matches are turned back over; all players attend to locations.
4. On a match, the learner says the word aloud and uses it in a sentence from the shared context (e.g., the class song); peers verify.
5. Provide immediate, specific correction on mispronunciations or off-context sentences ([Provide feedback](../elements/provide-feedback.md)), targeting the word and sentence rather than the child [Feedback most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S].
6. Close with a quick check: each learner uses one matched word in an original sentence ([Assess performance](../elements/assess-performance.md)).

## Assessment Evidence
- Track the number of matches per learner across rounds as a rough fluency indicator
- Observe and note the quality and originality of sentences produced on matches
- Collect anecdotal records of participation, pronunciation, and peer support behaviors

## Impact
- Retrieval-based games produce better retention than recognition-only review of the same words [+S]
- Requiring contextual sentence production on each match converts a memory exercise into vocabulary application [+M]
- Game formats increase engagement and time-on-task, especially for young learners, but engagement alone does not guarantee learning without the production step [~M]

## Examples
- A first-grade class learning vocabulary from a songbook plays the game with words from the current song; on each match, the student sings the line containing the word, then says an original sentence using it.
- An ESL adult class matches words to picture cards; on a match, the learner produces a sentence about their own daily routine using the word, personalizing the context.
- A Quizlet Match set is used as a warm-up race in a middle-school science class to consolidate unit terminology before a lab.
