# Assign empirically tested animation-based learning modules as out-of-class preparation to free class time for active learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 6 claims (5 for, 1 against) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 6 claims rest on one study

## Description
The authors recommend using stand-alone, empirically tested online learning modules to present concepts to students outside the classroom, "thereby allowing time in class to be devoted to active learning and other teaching strategies." Because active-learning outcomes depend heavily on preclass preparation, a module that performs at least equivalently to lecture gives instructors — including lecturers hesitant to abandon traditional methods — an entry point into flipped teaching by assigning the module before class.

## Design Implications

### Context
#### Requirements
- Modules must be empirically tested and designed with multimedia learning principles (segmentation, pretraining, low cognitive strain)
- Students must have prior exposure to prerequisite concepts so the module can treat basics as review
#### Constraints
- Effectiveness in an actual flipped-classroom setting had not yet been investigated
- Comparison against other out-of-class methods such as reading assignments and recorded lectures remains future work

### Target Learners
- introductory undergraduate biology students

### Target Learning Goals
- preclass conceptual preparation enabling in-class active learning
