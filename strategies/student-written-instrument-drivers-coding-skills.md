# Have students write the instrument-control and analysis software themselves to build coding skills alongside experimental work

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Rather than adopting available software solutions, the students developed Python drivers for all the electronic instruments using common libraries such as PyVISA and PySerial, plus the proprietary Niscope library for the digitizer. The article states the decision "to have students write the software for the data acquisition and analysis themselves was motivated by the desire to encourage learning in coding skills alongside their experimental work."
