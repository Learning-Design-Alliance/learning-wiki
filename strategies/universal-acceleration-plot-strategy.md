# Use a universal constant-acceleration plot so students can solve relativistic acceleration problems graphically without equations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The paper recommends plotting v/c, ατ/c, w/c = αt/c, and γ versus αx/c² on a single dimensionless graph for the (1+1)D constant-acceleration case. It states "With plots of this sort, high school students can solve relativistic acceleration problems with no equations at all!", reading values directly with a straight edge. The plot can be replotted logarithmically to match the variable ranges needed.
