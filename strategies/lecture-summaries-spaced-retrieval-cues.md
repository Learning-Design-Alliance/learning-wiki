# Distribute lecture summaries between class meetings as spaced retrieval cues

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article proposes distributing automatically generated lecture summaries to students between class meetings so they function as spaced retrieval cues at the edge of forgetting—priming concepts from the previous lecture right before students need to build on them in the next class. The authors cite research on the spacing effect suggesting such timely reminders are more effective for long-term retention than massed review. Real-time per-lecture analysis is described as technically ready but deployment-blocked by institutional recording workflows.

## Design Implications

### Context
#### Requirements
- A per-lecture processing cadence, which currently requires direct audio capture with a USB microphone or open API access to institutional lecture recordings
#### Constraints
- Retrieval of recordings from the institutional Kaltura system has no bulk download API, so batch processing at semester end is currently the most practical approach

### Target Learners
- undergraduate students in lecture-based technical courses

### Target Learning Goals
- long-term retention of lecture content
