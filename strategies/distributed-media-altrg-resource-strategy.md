# Embed game activities and resources across distributed existing media rather than building a stand-alone immersive game world

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
Given the complications and expense of designing immersive game worlds that include both narrative plot and requisite scaffolds, the article recommends embedding game activities that reveal enabling information and resources in a variety of media distributed across the Internet. This approach maximizes resources such as MySpace, web logs, podcasts, YouTube, and Second Life that students use as part of their daily lives, creating an open system of resource distribution that more authentically mirrors the context to which learners will transfer skills.
