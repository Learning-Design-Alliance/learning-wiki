# Build POCUS curricula from applications that are simple, easy to learn, and frequently encountered

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
Based on their finding that some applications such as lungs (pleural effusion) and abdomen (ascites/bleeding) caused more difficulties for participants, the authors emphasize "the need for a curriculum of POCUS applications that are simple, easy to learn, and frequently encountered". This strategy directs curriculum designers to select scanning modalities by learnability and frequency of encounter in primary care, so that GPs can build and maintain routines despite infrequent use of some modalities.

## Design Implications

### Context
#### Requirements
- Knowledge of which POCUS applications are frequently encountered in the local primary care population
#### Constraints
- Some applications are harder to learn or were rarely used by participants, which the authors suggest may explain the difficulties observed

### Target Learners
- Office-based general practitioners

### Target Learning Goals
- Scanning competence across selected POCUS applications
- Retention of scanning competence despite infrequent use
