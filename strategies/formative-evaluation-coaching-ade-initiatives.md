# Provide formative evaluation and implementation coaching to strengthen ADE initiative design

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The logic model specifies two coaching activities: "Formative evaluation coaching to support rigorous evaluation design of AIIM initiative" and "THRIVE implementation coaching for balanced application process and rigorous evaluation design of the THRIVE initiative." These coaching supports are the mechanism by which ADE staff are expected to build capacity to conduct formative evaluation activities and select more balanced cohorts for the THRIVE initiative.
