# Sequence the computational project with an early submittable first part and analytical debug cases so students recover from bugs before later physics-focused parts

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The project is staged so the first part uses an analytical Matter Only solution for debugging against the numerical general solution. The authors state: "Submitting the ﬁrst part of the project well ahead of the others allows students time to recover from many of the bugs they may encounter." Students check numerical integration using analytical solutions for special cases, and later parts focus on physical implications of the integration.

## Design Implications

### Context
#### Requirements
- A first-part submission deadline well ahead of the others, so students have time to recover from bugs before later parts
#### Constraints
- In the later parts of the project the authors state it is important that the bugs are gone so students can focus on the physical implications of the integration

### Target Learners
- undergraduate astronomy students, both advanced and less advanced

### Target Learning Goals
- numerical computation of cosmological age and distance factors
- connecting observations and theory to build understanding of the Standard Model of Cosmology
