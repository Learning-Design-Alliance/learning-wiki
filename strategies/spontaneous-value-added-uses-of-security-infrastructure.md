# Once a security infrastructure is in place, support spontaneous value-added uses such as secure assignment submission for distance learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (1 for, 3 against) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The pilot found that once the PKI was in place, participants spontaneously devised new uses: one ITI lecturer marked module assignments at home, inserted marks into a spreadsheet class list and securely emailed it for import into the marks database. The authors note the infrastructure "could also be used as an aid to distance learning, for example, for the secure electronic submission of assignments, for remote student registrations etc.", and list allowing value-added electronic services to be organically added as a benefit of the established infrastructure.

## Design Implications

### Context
#### Requirements
- An operational PKI with certified users already installed and trained
#### Constraints
- Observed in a single pilot with one department's infrastructure; extension university-wide faced formidable obstacles of equipment compatibility and network reliability

### Target Learners
- university lecturers, administrators and distance-learning students

### Target Learning Goals
- secure electronic submission of assignments and remote student registration
