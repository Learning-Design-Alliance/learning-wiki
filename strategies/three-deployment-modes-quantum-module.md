# Three deployment modes for a single-meeting quantum module: full, compressed, and flipped

## Description
The supplementary material describes three deployment modes. In the full 50-minute mode all five activities run in sequence; in the compressed mode Activities 1-3 are completed in class and Activities 4 and 5 become follow-up work; in the flipped mode Activity 1 and part of Activity 2 are completed before class using the reference notebook. The article states the learning goals remain unchanged across deployment modes and instructors select the concept checks matching the activities completed during class.
