# Add a later scaffolded-weaning question to the CQS targeting the stationary-state learning goal

## Description
The article recommends improving the CQS by adding another question later in the sequence that more directly addresses the second learning goal about the special role of stationary states. Such a question "could provide an opportunity to wean students from the scaffolding provided in prior questions related to this learning goal" and may allow more effective learning in future implementations, responding to persistent difficulty on question 5.
