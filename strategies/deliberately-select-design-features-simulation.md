# Deliberately select instructional design features when developing simulation training modules

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The review recommends that when developing training modules with simulators, instructors should "actively and deliberately determine which instructional design features to include", marking a transition from trial‐and‐error to evidence‐based educational practice. It argues this approach can optimise and streamline training, create targeted programmes, ground interventions in proven methodologies, and potentially contribute to better clinical performance and patient care.

## Design Implications

### Context
#### Requirements
- Instructors must choose among the identified instructional design features when building simulation curricula
#### Constraints
- The review states optimal combinations of features for higher‐level outcomes (Kirkpatrick levels 3 and 4) remain unclear

### Target Learners
- healthcare providers learning ultrasound‐guided regional anaesthesia

### Target Learning Goals
- procedural skill acquisition in ultrasound‐guided regional anaesthesia
