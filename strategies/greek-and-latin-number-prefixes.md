# Greek And Latin Number Prefixes

> **Strategy** · [All strategies](index.md)

## Description
Greek and Latin number prefixes are a closed, finite set of morphemes — *uni-* (one), *bi-/di-* (two), *tri-* (three), *quad-* (four), *cent-* (hundred), *mono-* (one), *poly-* (many), *kilo-* (thousand) — that recur across academic disciplines. The strategy teaches these prefixes explicitly as a system: learners learn the prefix meanings, then apply them to analyze unfamiliar words (triangle, bicameral, monorail, centimeter, polygon) rather than memorizing each word as a whole.

## Design Implications

Number prefixes are among the highest-frequency, most transportable morphemes in academic English, so teaching them as a family leverages [Analogical Reasoning](../principles/analogical-reasoning.md): each new word becomes an analogy to already-known words sharing the prefix [Morphological instruction improves literacy outcomes.](../claims/morphological-instruction-improves-literacy.md) [+S]. Because the set is small and closed, it can be [Chunking](../principles/chunking.md)'d into a single memorable schema, reducing the load of analyzing long technical words [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+S]. Pairing the prefix with a visual quantity (one dot, two dots, hundred-grid) adds a second representational channel [Dual coding improves recall.](../claims/dual-coding-improves-recall.md) [+M].

### Context
#### Requirements
- A curated prefix set (typically 8–15 number prefixes) matched to the discipline's actual vocabulary
- Word examples drawn from content the learners are currently studying, not decontextualized lists
- Repeated opportunities to analyze and generate words, not just define prefixes ([Annotating](../principles/annotating.md) word structure, word-part sorts)
- Distributed review across weeks so the prefix schema consolidates [Distributed practice improves retention.](../claims/distributed-practice-improves-retention.md) [+S]

#### Constraints
- Prefix meanings are not always transparent in modern words (*bicycle* vs. *bilingual* vs. *bisect*), so instruction must address polysemy or learners overgeneralize [~M]
- Some high-frequency "number" words have obscured morphology (*university*, *monopoly* as business term); forcing prefix analysis on opaque words can produce false etymologies [-M]
- Isolated prefix drills without connected text application show weak transfer to comprehension [~M]
- Learners with limited English proficiency may lack the base-word knowledge needed for prefix analysis to pay off; pair with base-word instruction [~M]

#### Implementation Variability
- **Word-part analysis routine**: students segment a target word, identify the number prefix, and predict meaning before checking a definition
- **Cross-curricular mapping**: the same prefix chart used in math (triangle, quadrilateral), science (monocot, polymer), and social studies (bicameral, century)
- **Generation tasks**: students hunt for or coin words containing the target prefix and justify the quantity meaning
- **Cognate extension** for multilingual learners: Spanish/Latin cognates (*bicicleta*, *centavo*) make the system cross-linguistic

### Target Learners
- Upper-elementary through secondary students encountering disciplinary vocabulary in math and science [Morphological instruction improves literacy outcomes.](../claims/morphological-instruction-improves-literacy.md) [+S]
- Struggling readers, who benefit from a finite, high-utility strategy over whole-word memorization [+M]
- Multilingual learners, when cognates and base-word support are included [~M]
- Less useful for beginning readers still consolidating decoding; morphological analysis presupposes basic word recognition [-M]

### Target Learning Goals
- Vocabulary breadth and inferring meanings of unfamiliar words from parts
- Disciplinary literacy: reading mathematics and science terminology as structured, not arbitrary
- Morphological awareness as a transferable word-analysis skill

### Instructions
1. Select 8–15 number prefixes that appear in the current unit's vocabulary; build a visible anchor chart with prefix, meaning, and quantity icon.
2. [Activate prior knowledge](../principles/activation.md) by eliciting words students already know (*unicycle*, *tricycle*) and surfacing the shared part [Activation improves learning.](../claims/activation-improves-learning.md) [+M].
3. Model word-part analysis on one disciplinary word (e.g., *quadrilateral* = four + sides) using an [Advance Organizer](../elements/advance-organizers.md) showing the segmentation.
4. Have students analyze and generate words in pairs, then verify meanings in context — analysis must end in connected reading, not the chart alone.
5. Revisit the prefix set briefly across subsequent lessons (2–5 minute reviews) rather than one massed lesson [Distributed practice improves retention.](../claims/distributed-practice-improves-retention.md) [+S].

## Examples
- **Word Generation (SERP Institute)** ([https://wordgeneration.org](https://wordgeneration.org)) — a middle-school academic vocabulary program that organizes instruction around high-frequency morphemes, including number prefixes, within discussion and writing activities.
- **Elementary mathematics**: teaching *uni-, bi-, tri-, quad-, pent-, hex-, oct-* alongside polygon and quadrilateral units, so geometric naming and vocabulary instruction reinforce each other.
- **Science literacy**: using *mono-, poly-, cent-, kilo-, milli-* to decode measurement and biology terms (monomer, polymer, centriole, kilometer) during a units-and-measurement lesson.
