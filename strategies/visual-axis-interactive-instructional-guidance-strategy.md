# Visual-axis interactive instructional guidance via wireless AR/MR video-conferencing with educator-inserted 3D visual cues

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An implementable technique in which the learner's HoloLens headset video-calls an educator's laptop Skype application with HoloLens Add-in, screen-mirroring the learner's first-person view. This "resulted in lagless sharing of the learner's procedural performance perspective along with the ability for both the learner and educator to 'draw' into the shared view using an on-screen toolset," letting the instructor insert digital pointers and arrows to guide catheter positioning. An ad hoc device-laptop connection with a Bluetooth-connected pointing device was tested for environments without network connectivity or Skype.

## Design Implications

### Context
#### Requirements
- Requires a wirelessly networked AR/MR headset with Skype functionality and an educator laptop with the HoloLens Add-in and LCD projector.
#### Constraints
- For environments without network connectivity or Skype, an alternative ad hoc connection approach with a wireless pointing device is needed.

### Target Learners
- emergency medicine learners in simulation-based procedural training

### Target Learning Goals
- real-time instructor guidance during invasive procedure practice
