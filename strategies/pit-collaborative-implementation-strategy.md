# Implement invention tasks as brief collaborative small-group activities with constrained intervention and whole-group closure

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
The paper's implementation recipe: students work in small peer groups on a mission that establishes intellectual need; instructor intervention is limited to groups at an unproductive, frustrating standstill, without guiding toward normative reasoning; a full-group discussion afterward links students' sense-making to subsequent formal instruction. Time budget is modest — "We allow 20-40 minutes of class time per sequence initially" — settling near 20 minutes, roughly one sequence every two weeks when introducing a challenging new quantity. Follow-up questions address units of the invented index and scaling with whole-number factors.

## Design Implications

### Context
#### Requirements
- A mission that creates intellectual need; contrasting-case data with an imposed constraint (e.g., teams at the same outlet share an index value); drawings limited to few quantifiable features
#### Constraints
- Requires sacrificing some breadth of coverage; tasks complement rather than replace existing curriculum; intended for courses already using research-based collaborative methods

### Target Learners
- students in large-enrollment, studio, majors, and general-education introductory physics courses

### Target Learning Goals
- quantifying physical systems
- interpreting units of invented quantities
- proportional reasoning
