# Iterate real-time tutor feedback based on user questionnaires: add explanations, positive feedback, session summaries and pause warnings

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Participants' open-ended questionnaire answers should drive the next iteration of a real-time feedback system. For the CPR Tutor, requested features included better explanations of how to correct mistakes, positive feedback when few mistakes are detected, a visual performance summary at the end of the session, and warnings when CPR is suspended. The authors state the next iteration "should implement some features suggested by the questionnaire answers".

## Design Implications

### Context
#### Requirements
- collecting open-ended questionnaire data from participants after feedback sessions
#### Constraints
- The study's small participant number motivated open-ended questions rather than validated scales

### Target Learners
- psychomotor-skill learners using real-time tutoring systems

### Target Learning Goals
- improved usability and clarity of automated feedback
