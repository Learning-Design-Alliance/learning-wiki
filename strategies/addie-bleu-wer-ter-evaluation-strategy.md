# Adopt the ADDIE model for design and evaluation, with BLEU, WER, and TER for intrinsic system evaluation

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article adopts the ADDIE model (Analyze, Design, Develop, Implement, Evaluate) for the AI4KSL project, stating it "will not only support the instructional design as used in the design thinking process but also as an evaluation strategy for the project". Because conversion of spoken language to sign language is a machine translation task, BLEU, Word Error Rate (WER), and Translation Error Rate (TER) will also be used to intrinsically evaluate system performance. The article notes CIPP and Kirkpatrick's models suit evaluating already existing innovations, while ADDIE suits universally designed assistive technologies for learning.

## Design Implications
