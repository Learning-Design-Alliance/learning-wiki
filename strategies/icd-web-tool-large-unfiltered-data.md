# Provide a web-based tool so students without detectors can analyze large, unfiltered cosmic ray data intuitively

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In its outlook the article proposes providing measurement data in a suitable format for students without access to ICD experiments, and concludes that "tools need to be created that allow students accessing large and unﬁltered data in an intuitive way without requiring long special training", following examples such as the International Masterclass project and Cosmic@Web.

## Design Implications

### Context
#### Requirements
- A data set large enough to leave room for students to realize their own analysis ideas and make discoveries.
- Tools that let students access large and unfiltered data in an intuitive way without requiring long special training.
#### Constraints
- The larger the data set becomes, the more documentation must be read before starting an analysis and the more difficult the data are to work with using high-school tools; the threshold to start an analysis increases quickly to the point where working with the data becomes unattractive.
- Cosmic@Web, an existing example, is currently only available in German.

### Target Learners
- students without access to cosmic ray experiments

### Target Learning Goals
- analyzing real cosmic ray data
- realizing their own analysis ideas and making discoveries
