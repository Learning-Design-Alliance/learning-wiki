# Memory-style matching variant requiring valid particle combinations

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In the layperson-level variant, cards are placed face down and players turn two cards face up per turn. Unlike usual Memory games where matching identical cards wins, players keep cards only if a valid particle pair or triplet is formed: lepton-antilepton pairs, quark-antiquark mesons, or three-quark baryons featuring all three colors. Invalid combinations are returned face down.
