# Provide Instructions Before Starting Work

> **Strategy** · [All strategies](index.md)

## Description
This strategy delivers complete, comprehensible task instructions *before* learners begin work, so they understand the goal, the required steps, and the criteria for success before investing effort. Instructions specify what to do, in what order, with what resources, and against what standard — reducing aimless exploration and wasted effort during the task itself.

## Design Implications

Clear pre-task instructions reduce extraneous cognitive load by eliminating the need to hold unresolved questions about the task goal in working memory while working [Cognitive load theory treats goal clarity as a core load-reduction condition.](../principles/cognitive-load-management.md) [+M]. Specific, challenging goals produce reliably higher performance than vague "do your best" goals, but only when learners know exactly what is expected and how performance will be judged [Specific goals outperform vague goals when task strategies are known.](../claims/process-goals-outperform-outcome-goals-for-novices.md) [+S]. Instructions given *after* work begins — or discovered through trial and error — force learners to split attention between doing the task and figuring out what the task is.

### Context
#### Requirements
- A clearly specified task goal and success criteria, stated in language matched to learner vocabulary ([Accessible Vocabulary & Syntax](../principles/accessible-vocabulary-syntax.md))
- Sequenced steps or a task overview, chunked so learners can hold the whole task structure in mind ([Chunking](../principles/chunking.md))
- An advance organizer or worked model showing what a finished product looks like ([Advance Organizers](../elements/advance-organizers.md))
- A mechanism for checking comprehension of instructions before work starts (e.g., learners restate the task, or a quick [Check-In](../elements/check-in.md))

#### Constraints
- Overly detailed instructions for learners with high prior knowledge can be redundant and reduce engagement [Guidance that helps novices can hinder more knowledgeable learners.](../claims/expertise-reversal-effect.md) [-S] — experts prefer goal statements over step-by-step directives
- Instructions that prescribe *how* to solve a problem can eliminate the productive struggle that drives conceptual learning [Letting learners search for solutions before instruction can improve conceptual outcomes.](../claims/productive-failure-improves-conceptual-learning.md) [~M]
- Long instruction blocks delivered verbally without support decay quickly; learners forget steps mid-task unless instructions remain accessible as a reference
- Instructions cannot compensate for a poorly designed task — ambiguity in the task itself will surface regardless of how clearly it is announced

#### Implementation Variability
- **Full script vs. goal + criteria:** novices benefit from step-level detail; advanced learners need only the goal and success criteria
- **Just-in-time delivery:** in complex multi-phase tasks, instructions can be staged per phase rather than front-loaded, reducing load at each stage
- **Embedded reference:** written instructions posted alongside the workspace (rubric, checklist, task card) so learners can re-check without asking
- **Modeling the instructions:** pairing verbal instructions with a brief demonstration of the first step makes abstract directives concrete

### Target Learners
- Novices, who lack the schemas to infer task structure from a title or prompt [Novices search inefficiently without explicit task guidance.](../claims/example-problem-sequences-reduce-cognitive-load.md) [+M]
- Learners with working memory constraints or processing-speed challenges, for whom unresolved task ambiguity is disproportionately costly
- Less detail for experts, who experience step-level instruction as redundant and disengaging [Guidance that helps novices can hinder more knowledgeable learners.](../claims/expertise-reversal-effect.md) [~M]

### Target Learning Goals
- Procedural tasks: multi-step processes where sequence and completeness matter
- Production tasks: writing, design, and problem-solving where success criteria shape quality
- Self-regulated work: clear goals enable learners to monitor their own progress against a standard

### Instructions
1. Specify the task goal and success criteria in learner-accessible language, ideally as observable outcomes rather than abstract qualities
2. Chunk the task into sequenced steps and present them as a checklist or task card ([Chunking](../principles/chunking.md))
3. Show a model or exemplar of the expected product before work begins ([Advance Organizers](../elements/advance-organizers.md))
4. Verify comprehension — have learners restate the goal or identify the first step ([Check-In](../elements/check-in.md))
5. Keep instructions visible during work as an external reference rather than relying on memory
6. Fade instructional detail as learners gain experience with the task type [Guidance that helps novices can hinder more knowledgeable learners.](../claims/expertise-reversal-effect.md)

## Examples
- **Gagné's "inform learners of objectives" event** — the first instructional event in [Gagné's 9 Events](../patterns/gagnés-9-events-of-instruction.md) is precisely this strategy: state what learners will be able to do before instruction begins
- **[4C/ID](../patterns/4cid-four-component-instructional-design.md)** — learning tasks open with explicit task descriptions and performance standards before learners attempt supportive or procedural information application
- **Writing rubrics distributed with the prompt** — e.g., [NWP](https://www.nwp.org) practice of sharing scoring rubrics before drafting, so criteria shape composition rather than only grading
- **Recipe-style lab protocols in [Direct Instruction](../patterns/direct-instruction.md)** — scripted, sequenced instructions ensure learners execute procedures correctly before conceptual consolidation
