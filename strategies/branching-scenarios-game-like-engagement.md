# Use branching scenarios and game-like elements to foster engagement with authentic learning tasks

> **Strategy** · [All strategies](index.md)

## Description
The article recommends interactive storytelling, decision-based navigation, and game-inspired feedback mechanisms as deliberate design choices: "branching scenarios and game-like interactive elements" exhibit stronger interactive affordances and can make learning objects more dynamic and engaging. Designers can use these strategies to enhance learner-content interaction in a way that aligns with learning goals.
