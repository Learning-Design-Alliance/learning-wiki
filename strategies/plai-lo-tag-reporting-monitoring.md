# Report student success on PLAI-LO-tagged artifacts back to program leaders to monitor curriculum implementation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The framework's monitoring mechanism tags each learning artifact with the PLAI-LOs it serves and reports "student success on the corresponding learning artifacts with a PLAI-LO tag ... back to program leaders and evaluators to enable monitoring of the implementation across the curriculum." The authors state that "the use of tags and reporting enables easy monitoring and quantification of PLAI-LO implementation progress for program evaluators," giving administrators a way to assess curriculum redesign initiatives.
