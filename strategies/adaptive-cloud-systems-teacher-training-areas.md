# Areas of adaptive cloud-based system use in teacher training

## Description
The article enumerates areas of adaptive cloud-based system use for teacher training: organizing personalized educational communication via telecommunication tools; supporting individual and group learning activities through scientific-educational cloud services such as Microsoft Office 365 and G Suite for Education; using tested adaptive platforms (Alta, Cerego, Smart Sparrow, Socrative, Neo LMS, OLI, Typeform, Quizalize, Elevate); including open-science cloud services; using "adaptive content management tools based on a public cloud, for example, WPadV4 tool"; visualizing mathematical abstractions via AR; and forming a unified learning environment whose content is developed in the learning process.
