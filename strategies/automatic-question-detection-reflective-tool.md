# Use automatic teacher-question detection as a reflective tool revealing extremes in questioning practices

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article proposes that automatic detection of teacher questions can support teacher reflection on questioning practices. "As simplest, automatic detection can easily reveal the extremes (e.g., 27 questions vs. 101 questions in this data), which is useful information for further explorations and reflective discussion for example among peers." Automated methods can serve as "the initial filtering tool for detecting classrooms with potentially richer dialogue," supporting professional development at scale.
