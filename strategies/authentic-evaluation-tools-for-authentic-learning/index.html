Evaluate authentic learning outcomes with authentic evaluation tools¶

Strategy · All strategies
Evidence · 2 claims (2 for) · 1 study (1 causal), q2 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

In its recommendations the article argues that authentic learning instruction should be matched by authentic assessment. It notes that "Authentic learning is an insight where alternative measurement and evaluation methods can be used" and that in this study outcomes were determined only by an academic success test. The authors therefore recommend bringing authentic evaluation tools into the literature on authentic learning activities, so that assessment matches the authentic character of the instruction.

Design Implications¶

Context¶

Requirements¶

  • Assessment instruments aligned with the authentic character of the learning activities

Constraints¶

  • The study itself measured only academic success via an achievement test, so the recommendation is not tested here
