# Combine e-learning with repeated audits of residual block incidence when targeting low-monitoring settings

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (1 for, 3 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article's forward-looking recommendation: implementation of an e-learning module should be paired with repeated feedback on local residual neuromuscular block incidence, following the recent consensus statement. The authors suggest such studies "would probably be most likely to show an effect if conducted in settings where objective neuromuscular monitoring is used less frequently," since prior successful single-department efforts used audits and repeated training.

## Design Implications

### Context
#### Requirements
- Access to incidence data for repeated surveys of residual block incidence; a setting with low baseline monitoring use
#### Constraints
- The article did not test this combined approach; it is a recommendation, not a demonstrated result

### Target Learners
- anaesthesia departments with low routine use of objective neuromuscular monitoring

### Target Learning Goals
- increase use of objective neuromuscular monitoring
- reduce residual neuromuscular blockade
