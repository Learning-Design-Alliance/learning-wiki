## Description
A delivery strategy for outreach data-analysis activities: host the exercise on the web so that participants need only a browser rather than installed analysis software. The article argues the web-based Masterclass 'significantly lowers entry barriers, making it accessible to a much broader audience', including students and educators in remote or under-resourced areas.
