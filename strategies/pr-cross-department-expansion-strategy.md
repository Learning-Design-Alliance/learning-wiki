# Extend the Problem Roulette model to other departments and courses by adding data elements to the server tables, maintaining a single Responses table under a common interface.

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article's forward-looking recommendation is that "[a]ny course which administers tests in a choose-from-a-list format can establish a problem library within a topical structure and join the existing service simply by adding the relevant data elements to the server tables". The team is rolling out PR to four additional U-M departments—Chemistry, Biochemistry, Statistics, and Atmospheric, Oceanic and Space Sciences—for the 2013-14 academic year, with one server instance supporting all classes under a common interface and a single Responses table, requiring refined staff roles and extended reporting.

## Design Implications

### Context
#### Requirements
- A single server instance supports all classes under a common interface, with activity recorded in a single Responses table; departments maintain management of their problem libraries and topic structures.
#### Constraints
- For the tagging extension, choosing and managing the taxonomy of allowed tags is a challenge because current taxonomies designed for physics education researchers are too high level for novice learners.

### Target Learners
- undergraduate students in introductory courses across participating departments

### Target Learning Goals
- distributed practice testing in the disciplines' own choose-from-a-list assessment formats

## Claims

- [After adjusting for selection bias with beginning-of-term GPA, regular PR users show a grade point improvement of 0.22, significant above the random noise level of 0.04, with replication at 0.32 in Winter 2013.](../claims/gpa-adjusted-022-grade-boost-regular-pr-users.md) [+W]
- [Regular users of Problem Roulette in the Phys 240 electromagnetism course outperformed their complement by an average of 0.40 grade points (on a 4.0 scale), before adjusting for selection bias.](../claims/regular-pr-users-outperform-by-040-grade-points.md) [+W]
- [On repeated encounters with the same problem, median solution time halves by the second and third occurrences and the correct-response fraction climbs from 52% on first view to above 90% by the fourth and higher occurrences.](../claims/retention-improves-repeated-problem-encounters.md) [+W]
- [Random access to problems outside the textbook supports the two highest-utility study techniques—practice testing and distributed practice—and students report it helps them learn and synthesize concepts rather than rely on rote memory.](../claims/random-access-supports-practice-testing-and-distributed-practice.md) [+W]
- [PR usage spiked immediately before scheduled exams, with activity peaking at 800 problems served per hour on exam day, and no formal course credit was attached to use.](../claims/pr-usage-spikes-before-exams.md) [+W]
