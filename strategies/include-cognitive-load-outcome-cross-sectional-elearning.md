# Include cognitive load as an outcome measure when evaluating cross-sectional e-learning anatomy methods

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 2 studies (1 causal, 1 review), `q3` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
The article's stated future direction is to measure the cognitive burden of learning anatomy from cross-sections. The authors write that future studies should "include cognitive load as an additional outcome measure to assess the cognitive burden of cross-sectional learning methods" and their effects on retention. They ground this in cognitive load theory's account of limited working memory capacity for novel information in anatomy education.

## Design Implications

### Context
#### Requirements
- Cognitive load measurement must be added to study designs testing cross-sectional learning methods, as the current study did not include it
#### Constraints
- The authors state cognitive load was not included as a parameter in the present study, so the burden of PLI versus LFB methods remains untested

### Target Learners
- medical students learning neuroanatomy

### Target Learning Goals
- learning brainstem anatomy from cross-sectional images
- knowledge retention
