# Five-element prompt schema making the epistemic architecture of a solution explicit

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that students construct prompts around five elements: '(a) the disciplinary context of the problem; (b) the role assigned to the model; (c) the actions the model should and should not perform; (d) the representational or methodological path to be followed; and (e) the validation criteria required before accepting a result'. Such a prompt is 'a compact externalization of a problem frame' rather than a template to copy mechanically, delaying premature formalism and preserving learner agency.

## Design Implications

### Context
#### Requirements
- Students must be able to state which operations are delegated to the model and which remain their own responsibility
#### Constraints
- Should not be read as evidence that contextualised prompts automatically produce expert reasoning

### Target Learners
- Physics and STEM students using LLMs for problem solving

### Target Learning Goals
- Maintaining epistemic control over inquiry
- Connecting concepts to decisions and validation criteria
