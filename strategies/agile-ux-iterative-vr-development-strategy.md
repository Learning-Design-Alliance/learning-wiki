# Use agile UX methodology with early-stage pilot evaluation to guide iterative VR development

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article demonstrates an agile UX approach that integrates UX practices within agile development methodologies, prioritizing rapid iteration, collaboration, and continuous user feedback. Early-stage evaluation of user experience and perceived cognitive load is used to "guide iterative development" of the VR tool. This strategy treats pilot testing as a core part of the R&D cycle, feeding results back to developers for refinement before large-scale validation.

## Design Implications

### Context
#### Requirements
- Access to target user populations for feedback sessions
- UX and cognitive load measurement instruments
#### Constraints
- Pilot results are descriptive and preliminary; not a substitute for confirmatory studies

### Target Learners
- first-year kinesiology students
- anatomy teachers

### Target Learning Goals
- improved VR tool usability
- functional anatomy learning
