# Future research direction: verify the proposed resting effect, whereby spacing benefits may arise from working memory recovery after depletion

## Description
The article identifies working memory depletion after cognitive effort and recovery after rest as current work that may revise the theory's assumption of relatively stable working memory capacity. It suggests that some versions of the spacing effect, in which information processed with rest periods facilitates learning compared with massed presentation, may be due to working memory recovery during rest. The author states that further work on this resting effect will need to be carried out in the future to verify the effect, establish its limits, and then inform further cognitive load theory development.
