# Dolch Sight Word List - Flash Cards

## Description
Sets of printable flash cards for Dolch sight words, organized by grade level. Each set is displayed eight cards to a page.

## Design Implications

### Context
#### Requirements
- Printable PDF, scissors, optional laminator for durability
#### Constraints
- Requires rote memorization, may not suit all learning styles, lacks contextual application

### Target Learners
<!-- Link to sub-claims -->
- Elementary students, struggling readers, ESL learners

### Target Learning Goals
<!-- Link to sub-claims -->
- Improve sight word recognition, facilitate quick recall of high-frequency words, provide a tool for repeated practice

### Affordances
- Simple and direct method for memorizing sight words, easy to create and use, can be used in various settings

### Personalization
- Flash cards can be selected based on the Dolch word list and grade level of the student.
