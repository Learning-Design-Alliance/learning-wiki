# Design shared interprofessional learning so both professions contribute in a balanced, mutually transactive way, supported by trac training

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (1 for, 1 mixed, 3 against) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article recommends that shared learning situations be designed so that both professions can contribute their knowledge in a similar way, allowing development of high-quality, mutually transactive communication. It further suggests that measures to improve transactive communication, such as training sessions or specific communication exercises, and a prior trac training, could make interprofessional peer tutoring more effective by developing learners' transactive dialogue competence.

## Design Implications

### Context
#### Requirements
- Learners should ideally possess transactive dialogue competence so all learners can benefit from IP group work through balanced trac.
#### Constraints
- A 90-minute session can only initiate changes in stereotypes; long-term effects would require regular interprofessional contact with successful communication and cooperation.

### Target Learners
- medical students
- physiotherapy trainees
- future health professionals

### Target Learning Goals
- interprofessional communication
- knowledge exchange about the other profession
- stereotype reduction
