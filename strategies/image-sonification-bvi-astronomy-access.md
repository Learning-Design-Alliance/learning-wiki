# Use image sonification and screen-reader-compatible interfaces to make robotic-telescope image analysis accessible to blind and visually impaired students

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Partnering with accessibility specialists at GLAS, the project developed an image-sonification capability in Afterglow Access in which frequency conveys left-right information, time conveys up-down information, and volume conveys intensity. Both Skynet and Afterglow Access "are already compatible with standard screen readers used by BVI students", and a screen reader-compatible interface lets BVI students zoom into audio-distinct regions and re-sonify them for image exploration. BVI students already use these tools to identify astronomical objects and image characteristics.

## Design Implications

### Context
#### Requirements
- Screen-reader compatibility of Skynet and Afterglow Access, and stereo projection if available for sonification.
#### Constraints
- Sonification currently conveys monochromatic intensity; incorporating timbre/tone for color images is future work.

### Target Learners
- Blind and visually impaired students
- Deaf and hard-of-hearing students via enhanced captioned videos

### Target Learning Goals
- Exploring astronomical images and identifying objects and image characteristics through sound
