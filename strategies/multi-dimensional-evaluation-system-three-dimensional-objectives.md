# Constructing a multi-dimensional evaluation system aligned with three-dimensional teaching objectives

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
This evaluation system encompasses the entire instructional process (pre-class, in-class, post-class) and incorporates diverse evaluators including instructors, students via self- and peer-assessment, and external stakeholders. It leverages digital tools for learning analytics to enable "an integrated evaluation of knowledge, skills, and professionalism across diagnostic, formative, summative, and value-added dimensions," aligning assessment with three-dimensional teaching objectives.
