# Use explainability tools (SHAP/LIME) and human monitoring for fair, transparent AI-driven personalized learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends pairing AI-driven learning predictions with interpretability techniques and oversight. It states that "Techniques like SHAP or LIME can determine which input properties have the greatest effect on the model's conclusions, improving interpretability for stakeholders and educators", and, in its ethical implementations section, advises "utilising explainability tools and human monitoring" for fair and open decision-making in individualized learning settings. The strategy also includes examining model performance across groups and balancing datasets to minimise bias.

## Design Implications

### Context
#### Requirements
