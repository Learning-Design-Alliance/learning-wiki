# Include a fully solved test case before the graded case in computational homework to support debugging and build confidence

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 design), `q2`–`q3` · 0 of 2 report an effect size · 1 claim rests on one study

## Description
Each computational assignment contained a test case: "an initial problem was posed for which the full solution (i.e., the results from the numerical integration) was given". Students checked their program against the test case before completing the grading case, a problem without a given solution. The authors state the test case "ensured that a student’s program worked properly and helped to instill conﬁdence in students who might otherwise have been uncomfortable writing VPython programs without the help of their group members or TAs."

## Design Implications

### Context
#### Requirements
- Numerically pre-integrated reference solutions stored for each test case so students can verify their program's output
#### Constraints
- Only final numeric answers were graded; code was uploaded for verification but not graded

### Target Learners
- introductory physics students new to programming

### Target Learning Goals
- debugging computational models of force and motion
