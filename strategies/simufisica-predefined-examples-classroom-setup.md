# Use predefined simulator examples and shared configuration links to set up classroom activities quickly

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The simulator's lower toolbar provides an Examples button with predefined configurations such as Ethanol Heating or Aluminum in Water, and a Save button for registered users to store simulations with their parameters. The article also prints shareable configuration links for each worked problem. The authors state that saving "facilitat[es] fast setup for classroom activities" and that predefined examples "enhance student engagement and accessibility."
