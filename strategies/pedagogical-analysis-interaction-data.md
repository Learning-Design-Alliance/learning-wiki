# Use pedagogical analysis of learner interaction data to generate actionable insights for personalizing assessment and instruction

## Description
Gordon proposes pedagogical analysis as a systematic practice for the data-rich assessment environments modern technology enables. He defines it: "Pedagogical analysis refers to the systematic study of how teaching, learning, and assessment interact–using all available data to understand what works for whom and why." Using click streams, response times, and error patterns with analytical tools including machine learning, the goal is actionable insight, such as identifying hint sequences especially effective for learners who initially struggle. He cautions that this data-driven approach must be guided by sound theory and a humanistic compass rather than reducing learners to data points.

## Design Implications

### Context
#### Requirements
- Modern technology capturing rich process data, plus analytical tools and a guiding theoretical and humanistic framework
#### Constraints
- The article warns the approach must not reduce learners to data points; insights must augment understanding of intellective competence

### Target Learners

### Target Learning Goals
