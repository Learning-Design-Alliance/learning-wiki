# Use whole-number-by-decimal problems as a transition context for building decimal multiplication understanding

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (2 causal), `q3` · 1 of 2 report an effect size · 3 claims rest on one study

## Description
The article suggests that problems involving a whole number and a decimal below one "provide a possible transition context through which instruction could build on students’ understanding of whole number arithmetic and extend it to decimals". Because judgments were more accurate on WD than DD multiplication problems below one, instruction can start from WD problems before moving to two-decimal problems. The article also notes that explanations citing both the operation and the operands' magnitudes were strongly associated with accurate judgments, suggesting instruction should target that integrated reasoning.

## Design Implications

### Context
#### Requirements
- Students already have reliable whole number arithmetic direction of effect knowledge
#### Constraints
- The WD advantage held only for multiplication, not division; accuracy on WD multiplication below one was still only 47% and not above chance

### Target Learners
- middle school students learning decimal arithmetic

### Target Learning Goals
- accurate direction of effect judgments for decimal multiplication and division
