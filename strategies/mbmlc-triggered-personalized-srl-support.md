# Use moment-by-moment learning curve forms to trigger personalized support and interventions for students' self-regulated learning with ALTs.

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article proposes that moment-by-moment learning curves "could potentially be used in interventions to support SRL with personalized visualizations". Because different curve forms signal different regulation situations, visualizations of a student's own curve could help learners connect recent effort with recent progress and adjust effort to uphold accuracy. The authors also suggest ALT-level responses, such as providing more challenges to learners showing immediate drop curves to enhance learning efficiency.

## Design Implications

### Context
#### Requirements
- An ALT that logs per-problem performance from which moment-by-moment learning curves can be derived automatically.
#### Constraints
- The article presents this as a potential use; the study itself did not test an intervention.
- Students in the study had no means to select different subskills to work on, which the authors note limits efficiency.

### Target Learners
- Primary education students learning arithmetic with adaptive learning technologies

### Target Learning Goals
- Supporting students' regulation of effort and accuracy during learning with ALTs
