Employ Common Language and Strategies Across Disciplines¶

Strategy · All strategies Evidence · 3 claims (2 for, 1 unmarked) · 10 studies (4 causal, 3 quant-synthesis, 2 review, 1 associational), q2–q4 · 2 of 10 report an effect size

Description¶

Employing common language and strategies across disciplines means that teachers in different subject areas deliberately adopt shared terminology, shared instructional routines, and shared expectations for transferable skills such as writing, argumentation, and reading. Instead of each discipline using its own idiosyncratic vocabulary for the same moves (e.g., "claim–evidence–reasoning" in science but "thesis–support–conclusion" in English), the school or program standardizes the language and the strategy sequence, so students rehearse the same skill under multiple content conditions.

Design Implications¶

Consistency across contexts reduces the extraneous cognitive load of re-decoding instructions and rubrics in every class, freeing working memory for the content itself Chunking reduces working memory load. [+M]. Repeated, varied application of the same strategy across disciplines is also the classic condition for transfer: a skill practiced in only one context tends to stay bound to that context, while practice across multiple contexts supports abstraction and generalization Multiple contrasting cases support abstraction. [+M]. The approach draws on disciplinary literacy research, which argues that common skills (e.g., citing evidence) should be taught with a shared core language while acknowledging discipline-specific variations [Shanahan & Shanahan, 2008].

Context¶

Requirements¶

  • Cross-disciplinary teacher collaboration time to agree on shared terminology, graphic organizers, and rubric language
  • A small, well-defined set of common strategies (typically 3–5, e.g., a shared argumentation frame) rather than an exhaustive list
  • Discipline-specific adaptation guidance: each teacher maps the common frame onto their content, preserving the shared structure
  • Aligned assessment language, so feedback in history class uses the same terms as feedback in English class

Constraints¶

  • Effectiveness drops when the "common language" is imposed top-down without teacher buy-in; teachers revert to their own terminology and students receive mixed signals [-W]
  • Over-standardization can distort discipline-specific practices — writing like a historian is not writing like a literary critic, and forcing one template across disciplines can produce superficial compliance rather than transfer [~M]
  • Requires sustained coordination; benefits erode when only some departments participate, because students encounter the shared language inconsistently [-W]
  • Common frames can become formulaic; students may apply the template mechanically without understanding its purpose [~M]

Implementation Variability¶

  • School-wide writing frameworks (e.g., a shared claim–evidence–reasoning routine used in science, social studies, and English)
  • Shared literacy strategies (e.g., common annotation scheme, common vocabulary for text structures) applied in all reading-intensive courses
  • Cross-disciplinary rubrics with common criteria (clarity, evidence, organization) plus discipline-specific criteria
  • Scaffolded versions of the common language for multilingual learners, using the same structure with added sentence frames

Target Learners¶

  • Adolescents in grades 6–12, who encounter multiple teachers daily and benefit most from consistent expectations [Graham & Perin, 2007] [+M]
  • Struggling writers and multilingual learners, for whom inconsistent terminology across classes adds a substantial decoding burden [~M]
  • Students developing transferable academic skills; less relevant for advanced learners who have already abstracted the underlying skill

Target Learning Goals¶

  • Transfer of writing and argumentation skills across content areas Multiple contrasting cases support abstraction. [+M]
  • Reduced extraneous cognitive load during content learning Chunking reduces working memory load. [+M]
  • Academic language development and metacognitive awareness of transferable strategies

Instructions¶

  1. Convene a cross-disciplinary team and select a small set of shared strategies (e.g., an argumentation frame, an annotation protocol).
  2. Agree on exact terminology and a shared graphic organizer; publish a one-page reference used in every participating class.
  3. Introduce the strategy in one anchor class through Direct Instruction with Modeling and worked examples.
  4. Have every participating teacher require Practice with the same strategy on discipline-specific content, keeping the language identical.
  5. Use the shared rubric to Provide Feedback, so feedback terms match instruction terms.
  6. Use Peer Discussion and Self-Explanation to help students articulate how the strategy applies across subjects.
  7. Review annually: retire strategies that are not transferring and refine discipline-specific adaptations.

Related Strategies¶

  • Accessible Syntax — shares the goal of lowering linguistic barriers through consistent, controlled language
  • Activating Prior Knowledge — a common strategy vocabulary lets students recognize and reuse prior learning across classes
  • Teach literacy skills in every classroom across all content areas with common rubrics

Examples¶

  • Claim–Evidence–Reasoning (CER) frameworks — widely adopted in K–12 science (e.g., through the Krajcik-aligned NGSS materials) and extended into social studies and English, so the same three-part argument structure is named identically across departments.
  • The Writing Revolution (Hochman & Wexler, 2017) — a school-wide method in which all teachers use shared sentence-level strategies and terminology (e.g., "because, but, so"), regardless of subject. https://www.thewritingrevolution.org
  • Reading Apprenticeship (WestEd) — disciplinary teachers adopt a common metacognitive conversation routine and shared vocabulary for reading strategies across science, history, and English classrooms.
