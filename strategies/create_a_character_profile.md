# Create a Character Profile

## Description
Creating a character profile helps students form a deeper understanding of a book’s characters. Activities include creating a list of adjectives that describe a character, illustrating a character based on the description in the book, reflecting on a character's future occupation (for child characters), or describing how a character makes them feel in a particular chapter.

## Design Implications

### Context
#### Requirements
- Dedicated time for character analysis, creative materials for illustration, and prompts for reflection.
#### Constraints
- May require scaffolding for students who struggle with character analysis or creative activities. Success depends on students engaging thoughtfully and creatively.
