# Eleven-step project work sequence for the ESP classroom

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article presents an eleven-step sequence model gleaned from Stoller (2006), Richards and Renandy (2001), and Dhieb-Henia (1999) for developing and sequencing project work in ESP classrooms. The steps run from defining a theme and determining the final outcome through structuring the project, gathering and analyzing information, oral presentation, writing the final version, final presentation of projects, and scoring and grading. The article states this model allows easy management of project work and creates a relaxed learning environment.
