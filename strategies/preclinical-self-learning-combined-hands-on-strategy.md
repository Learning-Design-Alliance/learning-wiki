# Use the modular system to acquire basic vascular access skills before clinical activity, combining self-learning with interactive hands-on instruction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (2 causal), `q1`–`q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The authors recommend that novices use the system to acquire basic vascular access skills before starting clinical activity, and as additional training if a novice clinician has an insufficient clinical success rate. The system "can be used for e-learning by itself or it can be used as the content of a hands-on seminar", letting learners review material afterward and "learn at their own individual pace anytime and anywhere". The authors believe combining self-learning with interactive hands-on instruction, for example real-time instructor feedback via web conferencing, will improve learning effectiveness and maintain motivation.

## Design Implications

### Context
#### Requirements
- Each lesson has a staged goal that can be set and achieved by the learner themself, providing an environment for deliberate practice
#### Constraints
- The system was originally developed as a self-learning system, but its efficacy as a self-learning system must still be evaluated; this study tested it only within a hands-on seminar

### Target Learners
- novice clinicians before starting clinical vascular access activity

### Target Learning Goals
- basic in-plane vascular access skills and improved patient safety
