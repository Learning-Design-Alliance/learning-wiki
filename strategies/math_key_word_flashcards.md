# Math Key Word Flashcards

## Description
Learners create flashcards for each of the four mathematical operations. On one side, they write the operation and symbol (+, -, x, /). On the other side, they list key words associated with that operation. Students use their flashcards as visual aids in math coaching.

## Design Implications

### Context
#### Requirements
- Index cards, markers or colored pencils
#### Constraints
- Can be time-consuming to create flashcards.
