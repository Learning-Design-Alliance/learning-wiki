# Embed videos in active learning with interactive questions, student control, guiding questions, or homework integration

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The essay recommends packaging video with interactive questions (using tools like HapYak or Zaption), using interactive features that give students control such as labeled chapters, using guiding questions during viewing, and making video part of a larger homework assignment. It frames these as converting video watching from passive to active learning, noting "watching a video can be a passive experience, much as reading can be".
