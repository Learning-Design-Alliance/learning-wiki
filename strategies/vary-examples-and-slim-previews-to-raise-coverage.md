# Redesign preview content and vary examples across video types to raise coverage

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
To counter declining coverage, the article proposes two design solutions. First, previews may be slimmed: "Perhaps previews should concentrate on explaining only the concepts, just as in designs for the pre-training principle", so they no longer give the impression of a comprehensive view of task accomplishment. Second, drawing on the desirable differences hypothesis, "it is probably better to aim for a design that makes participants perceive all video types for a task as slightly different", for instance by using a superficially different example in reviews than in demonstrations.

## Design Implications

### Context
#### Requirements
- Video types for the same task must each support a different observational learning process
#### Constraints
- The article reports these as possible solutions to observed coverage declines, not as tested manipulations

### Target Learners
- novice software learners viewing video tutorials

### Target Learning Goals
- thorough viewing of all video types supporting retention
