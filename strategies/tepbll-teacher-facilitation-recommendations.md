# Teachers implementing TEPBLL should describe technological knowledge and learning objectives, match projects to proficiency levels, assign group roles, and provide staged progressive feedback

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The review distills teacher-facilitation recommendations from the included studies. The authors state that "teachers are urged to inaugurate TEPBLL activities by describing technological knowledge and learning objectives to students," and that teachers should understand students' perceived proficiency to set content and language objectives, present practical tutorials, "assign specific roles and responsibilities to each group member to ensure everyone participates," and set up staged project tasks with progressive feedback, since real-time corrective feedback sustains motivation.

## Design Implications

### Context
#### Requirements
- Teachers need technological pedagogical content knowledge; task design must align with learning objectives
#### Constraints
- Recommendations synthesized from the 31 included SSCI studies; the review notes these derive from studies with varied designs

### Target Learners
- language learners in TEPBLL classrooms

### Target Learning Goals
- language skills, motivation, and engagement through technology-enhanced project-based learning
