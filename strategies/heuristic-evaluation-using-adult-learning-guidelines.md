# Conduct heuristic evaluations of adult learning technologies using the 19 design guidelines

## Description
The article contributes "A method for conducting heuristic evaluations of adult learning technologies using these guidelines", demonstrating that "the utility of these guidelines" can be shown "through a heuristic evaluation of the deployed systems". Evaluators apply the guideline set to a system to surface opportunities for improvement and the trade-offs that emerge in real-world adult learning environments, using each guideline's annotations (stakeholders, problem types, CoI dimensions) to structure the assessment.
