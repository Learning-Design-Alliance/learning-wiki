# Curating Resources

> **Strategy** · [All strategies](index.md)

## Description
Curating resources is the practice of selecting a small, high-quality set of learning materials, organizing them into a coherent sequence or structure, and annotating them so learners know what each resource is for and when to use it. Unlike aggregating (collecting everything available), curation applies editorial judgment: inclusion criteria, sequencing, and framing notes that connect each resource to the learning goals.

## Design Implications

Curation manages extraneous cognitive load by removing the costs of search, evaluation, and relevance-judging from the learner, who has limited working memory for the actual content [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]. A curated set functions as an advance organizer for the domain: the structure imposed on resources signals what is central, what is supplementary, and how ideas relate. Curation quality matters more than quantity — large undifferentiated resource dumps reliably depress engagement and completion.

### Context
#### Requirements
- Explicit learning goals against which each resource is judged for inclusion
- Selection criteria: accuracy, currency, alignment to level, cognitive demand, accessibility
- Sequencing or grouping logic (prerequisite order, conceptual clusters, difficulty tiers)
- Annotations that state each resource's purpose and expected use ("read before X," "reference only," "optional extension")

#### Constraints
- Over-curation removes productive learner decision-making; advanced learners benefit from searching and evaluating sources themselves, and fully pre-digested collections can undercut development of information literacy [~M]
- Curator bias narrows the range of perspectives and examples learners encounter; a single-source collection risks anchoring learners to one framing
- Stale curation is worse than none: outdated links and superseded content erode trust and waste learner time [-M]
- Annotations that pre-explain everything suppress the generative processing learners get from resolving ambiguity themselves [~W]

#### Implementation Variability
- **Tiered collections**: core / extension / reference layers, letting learners self-select depth
- **Guided autonomy**: curated starting points plus a vetted "search here next" list, gradually shifting evaluation responsibility to learners
- **Learner co-curation**: students nominate and annotate resources, with the instructor curating the curation — builds evaluation skill while keeping quality control
- **Living collections**: scheduled review cycles with usage analytics to prune unused or ineffective items

### Target Learners
- Novices, who cannot yet judge source quality or relevance and waste significant effort on unguided search [~S]
- Learners in high-volume information domains (medicine, law, programming) where the cost of bad sources is high
- Advanced learners need less curation and more curated *criteria* — the expertise-reversal pattern applies to guidance on resources as to other guidance forms [Expertise reversal: guidance that helps novices can hinder experts.](../theories/expertise-reversal-effect.md) [~M]

### Target Learning Goals
- Foundational knowledge acquisition where efficient, accurate input matters most
- Conceptual integration — a well-sequenced curated set lets learners build connections across sources [Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M]
- Information literacy itself, when curation criteria are made explicit and learners progressively take over selection

### Instructions
1. Define the learning goals and the prerequisite knowledge map before touching any materials.
2. Apply inclusion criteria ruthlessly; target a set learners can actually work through in the available time.
3. Sequence resources from foundational to advanced, grouping into conceptual clusters ([Chunking](../principles/chunking.md)).
4. Annotate each resource with its purpose, expected depth of engagement, and relation to neighbors — a framing note acts as an [Advance Organizer](../elements/advance-organizers.md).
5. Pair the collection with an activity that requires using it ([Application](../elements/application.md), [Case Studies](../elements/case-studies.md)) rather than leaving it as passive reading material.
6. Schedule review; prune and replace based on usage data and currency.

## Examples
- **OER commons and MERLOT (https://www.merlot.org)** — curated repositories where editorial boards apply review criteria and user ratings to open educational resources.
- **A well-designed university reading list** — tiered into "essential," "recommended," and "reference," with weekly framing notes connecting readings to lecture topics.
- **Developer onboarding docs at major open-source projects** (e.g., the Mozilla Developer Network learning area, https://developer.mozilla.org/en-US/docs/Learn_web_development) — a curated pathway through a vast reference corpus, sequenced from first principles to applied projects.
