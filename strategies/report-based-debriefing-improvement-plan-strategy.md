# Run short report-based debriefing sessions in which coach and coachee pinpoint problems and set improvement plans for the next case

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
After each operation, hold a brief (30-minute) structured debriefing anchored to an objective, quantified surgical report rather than free-form video review. The article's workflow specifies that "efficient debriefing is conducted based on the surgical report and intelligent visualization system to pinpoint problems, which are then provided as feedback to the coachees while formulating subsequent improvement plans for the next surgery", keeping discussion focused within the limited time frame.

## Design Implications

### Context
#### Requirements
- An objective, quantifiable standard that comprehensively reflects surgical quality, so individualized assessments and immediate feedback are possible
#### Constraints
- The study conducted all coaching online with one coach from a single institution; the small sample limits generalizability

### Target Learners
- novice surgeons early in their learning curve

### Target Learning Goals
- surgical safety behaviors such as achieving the critical view of safety and setting targeted improvement goals
