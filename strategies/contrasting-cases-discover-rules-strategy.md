# Use carefully selected contrasting cases to have students discover general rules rather than explaining the rules first

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The instructor presented four non-interacting quantum field theories and asked which require a new anti-particle, challenging students to find the general rule instead of stating it. The cases were "carefully selected to make it difficult for students to fasten on a simpler rule": each surface feature (complex versus real, first-order versus second-order, scalar versus matrix) is relevant to the correct rule but none is definitive alone. The actual rule requires checking both negative-energy solutions and whether degrees of freedom require independent Fourier coefficients.

## Design Implications

### Context
#### Requirements
- Cases must be selected so every surface feature is relevant to the correct rule but none is definitive on its own
- Students should have partial familiarity with some cases from reading or prior exercises

### Target Learners
- graduate physics students learning quantum field theory

### Target Learning Goals
- distinguishing key underlying structures from surface features when approaching a new problem
- activating prior knowledge needed for expert reasoning
