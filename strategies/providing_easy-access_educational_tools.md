# Providing Easy-Access Educational Tools

> **Strategy** · [All strategies](index.md)

## Description
This strategy organizes learning materials, manipulatives, references, and digital resources so learners can locate and use them independently, without waiting for instructor distribution or permission. Tools are stored in predictable, labeled locations (physical or digital), accompanied by brief instructions for use, so that access friction does not become a barrier to self-directed work.

## Design Implications

Easy access reduces the extraneous cognitive load of hunting for materials, freeing working memory for the learning task itself [Cognitive overload degrades learning.](../claims/cognitive-overload-degrades-learning.md) [+M]. It also supports autonomy: when learners can select and use tools on their own initiative, they experience greater ownership of their learning, which sustains intrinsic motivation [Autonomy supports intrinsic motivation.](../claims/autonomy-supports-intrinsic-motivation.md) [+S]. Access alone is not sufficient — learners need brief instruction in *when and why* to use each tool, or the tools go unused or are misapplied.

### Context
#### Requirements
- Materials stored in consistent, labeled, reachable locations (hanging file folders, shared drives, LMS modules)
- Brief usage guidance for each tool — a one-line purpose statement or short model of use ([Advance Organizers](../elements/advance-organizers.md) work well here)
- Explicit teaching of tool-use routines early in the year, followed by [Practice](../elements/practice.md) using them within real tasks
- For digital tools: reliable accounts, device access, and low-friction login ([Accommodations](../elements/accommodations.md) may be needed for equitable access)

#### Constraints
- Unstructured access without instruction produces tool misuse or avoidance — learners with weak self-regulation rarely self-select helpful tools [Autonomy supports intrinsic motivation.](../claims/autonomy-supports-intrinsic-motivation.md) [~M] — autonomy benefits depend on learners having the skills to exercise it
- Overabundant tool availability adds choice overhead and can distract from the task; a curated, small set outperforms an exhaustive library
- Digital access assumes device and connectivity equity; otherwise the strategy widens rather than narrows gaps
- Tools can become crutches if never faded — e.g., calculators or sentence frames used past the point of need can prevent [Automaticity](../elements/automaticity.md)

#### Implementation Variability
- **Physical tool walls or supply stations** with labeled manipulatives, graphic organizers, and reference sheets
- **Digital resource hubs** — LMS folders, shared drives, or class websites with consistent naming conventions
- **Choice boards and learning menus** that present tool options alongside task options ([Choice Boards](../elements/choice-boards.md))
- **Personal toolkits** for learners with disabilities — pre-loaded audio recorders, highlighters, text-to-speech, organized per [Accommodations](../elements/accommodations.md) plans

### Target Learners
- All learners, but especially those who struggle with organization, working memory, or retrieval of materials
- Learners with disabilities who benefit from assistive tools being available without needing to request them each time ([Accommodations](../elements/accommodations.md))
- Developing self-regulators, who need scaffolded guidance in tool selection before independent use benefits emerge [Autonomy supports intrinsic motivation.](../claims/autonomy-supports-intrinsic-motivation.md) [~M]

### Target Learning Goals
- Self-directed learning: selecting appropriate resources for a task
- Metacognitive tool knowledge: knowing *which* tool serves *which* purpose
- Equity of access: ensuring all learners can reach the materials needed to succeed

### Instructions
1. Audit the tasks learners will face and identify the tools each requires; curate a small, high-value set rather than everything available.
2. Organize tools in labeled, consistent locations — physical stations or a clearly structured digital hub with predictable navigation.
3. Attach a one-line purpose statement or short [Advance Organizers](../elements/advance-organizers.md) to each tool so learners can match tool to need.
4. Explicitly teach and model tool use during an authentic task, then provide [Practice](../elements/practice.md) using the tools independently.
5. Build a routine in which learners check the tool station or hub at the start of independent work ([Check-In](../elements/check-in.md) structures can prompt this).
6. Periodically review usage and fade tools that learners have internalized, per [Scaffolding](../elements/scaffolding.md) principles.

## Related Strategies

- [Activating Prior Knowledge](activating-prior-knowledge.md) — access to reference tools works best when learners can connect new material to what they already know

## Examples
- **Manipulatives and graphic organizers in labeled hanging file folders** at a classroom station, so learners retrieve them at the start of independent work without teacher mediation.
- **Khan Academy** (https://www.khanacademy.org) — hints, videos, and practice are one click away at all times within each exercise, making support tools continuously accessible rather than teacher-dispensed.
- **Choice boards and learning menus** presenting several tool-and-product combinations (audio recording, slide deck, written report) from which learners select how to demonstrate learning.
- **Assistive technology kits** — text-to-speech software, audiobooks, and highlighters pre-assigned to learners with reading disabilities so support is available without a request ritual.
