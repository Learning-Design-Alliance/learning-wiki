# Direct Instruction Web Based Reading Strategies

## Description
This strategy applies [Direct Instruction](direct-instruction.md) to the specific demands of reading on the internet: navigating hyperlinks, evaluating source credibility, handling multiple open texts, and integrating information across pages. The instructor explicitly names, models, and sequences these strategies — often through screen-shared [Think-Alouds](../elements/think-aloud.md) — then guides practice before releasing learners to independent application. It treats web reading as a distinct skill set rather than an automatic extension of print reading.

## Design Implications

Web reading imposes extraneous demands (navigation, pop-ups, fragmented attention) that consume working memory before comprehension even begins [Cognitive overload degrades learning outcomes.](../claims/cognitive-overload-degrades-learning.md) [+S]. Explicit strategy instruction reduces unguided search and trial-and-error, which is especially valuable for novices [Worked examples reduce unnecessary search for novices.](../claims/worked-examples-reduce-novice-search.md) [+M]. Because skilled web readers deploy strategies flexibly rather than mechanically, instruction must include guided practice with [Fading](../elements/fading.md) of support, not just rule presentation [Fading support promotes transfer of responsibility.](../claims/fading-support-promotes-transfer-of-responsibility.md) [+M].

### Context
#### Requirements
- Live or screencast modeling of authentic web tasks (searching, evaluating a source, cross-checking claims), with narration of decisions
- A sequenced strategy set — e.g., question generation, search-term selection, credibility evaluation (author, evidence, corroboration), synthesis across sources
- Guided practice with immediate, task-focused [Feedback](../elements/feedback.md) [Feedback is most effective at task and process levels.](../claims/feedback-most-effective-at-task-and-process-levels.md) [+S]
- Authentic web texts and tasks; decontextualized worksheets do not transfer to live browsing

#### Constraints
- Highly scripted delivery can produce rigid rule-following that fails when pages or tasks deviate from the practiced format [~M] — web texts vary too much for fixed procedures alone
- Direct instruction alone underperforms discovery for learners who already have strong web reading strategies; the [expertise reversal effect](../theories/expertise-reversal-effect.md) applies [Guidance that helps novices can hinder more knowledgeable learners.](../claims/expertise-reversal-effect.md) [~S]
- Cluttered pages, ads, and multitasking during practice sessions add extraneous load that undermines the instruction itself [Cognitive overload degrades learning outcomes.](../claims/cognitive-overload-degrades-learning.md) [+S]
- Strategy instruction without independent application produces dependence on the teacher rather than self-regulated reading [Fading support promotes transfer of responsibility.](../claims/fading-support-promotes-transfer-of-responsibility.md) [-M]

#### Implementation Variability
- Gradual release ("I do, we do, you do") within a single lesson vs. a multi-week strategy unit
- Whole-class screen demonstration vs. small-group coaching with live browsing
- Curated link sets that reduce navigation demands as a scaffold, later removed
- Integration with [Annotating](../principles/annotating.md) tools (e.g., Hypothesis) to make evaluation visible and assessable

### Target Learners
- Adolescents and adults with adequate print decoding but weak online reading comprehension — the most common profile of struggling web readers
- Novices benefit most from explicit modeling; advanced readers gain little and may disengage [Guidance that helps novices can hinder more knowledgeable learners.](../claims/expertise-reversal-effect.md) [~S]
- English learners, when paired with [Accessible Vocabulary and Syntax](../principles/accessible-vocabulary-syntax.md) supports

### Target Learning Goals
- Online research and comprehension: locating, evaluating, and synthesizing web information
- Critical evaluation of source credibility and misinformation resistance
- Self-regulated reading: monitoring comprehension and adjusting strategy across texts

### Instructions
1. Name the strategy and its purpose (e.g., "triangulate a claim across three sources") using an [Advance Organizer](../elements/advance-organizers.md) to frame the sequence.
2. Model the strategy on a live page via [Think-Aloud](../elements/think-aloud.md), making evaluation decisions explicit ("this site has no author or date — I need corroboration").
3. Chunk the strategy into steps and post them as a visible reference, consistent with [Chunking](../principles/chunking.md) [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+S].
4. Guide whole-class practice on a new page, eliciting decisions rather than making them all yourself ([Coaching](../elements/coaching.md)).
5. Release learners to paired or independent practice on authentic tasks, fading prompts as accuracy grows [Fading support promotes transfer of responsibility.](../claims/fading-support-promotes-transfer-of-responsibility.md) [+M].
6. Debrief with [Class Discussion](../elements/class-discussion.md) on what strategies learners used and when they failed, building conditional knowledge.

## Examples
- **[Coiro's Online Reading Comprehension practices](https://www.joecoiro.com)** — classroom-tested protocols for modeling internet inquiry, including think-alouds of search and evaluation.
- **[News Literacy Project](https://newslit.org)** — direct instruction in evaluating source credibility, with modeled "lateral reading" demonstrations adapted from the Stanford History Education Group's research.
- **[Stanford History Education Group — Civic Online Reasoning](https://cor.stanford.edu)** — published curriculum of explicit, sequenced lessons in evaluating online sources, with modeling and guided practice materials.
