# Teach multiple quantum algorithms on the same QUBO task so students learn to select a proper algorithm for a given computing task

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors avoid bias toward any single quantum computing approach by teaching Grover's algorithm, quantum annealing, VQE and QAOA and applying each "on the same quadratic unconstrained binary optimization (QUBO) task". Through such training, they write, "students would have a better understanding of each quantum algorithm and a better vision on how to select a proper quantum algorithm when dealing with a specific computing task." This responds to segmented commercial tutorials, e.g. D-Wave teaching quantum annealing while IBM Qiskit mainly covers circuit-based computing.
