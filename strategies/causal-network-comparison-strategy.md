# Use causal network comparisons to specify the productive elements of incorrect explanations when designing physics instruction

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
The article proposes comparing student explanations to a causal network of the target phenomenon to identify which student ideas correspond to valid causal pathways and which inferential steps need refinement. It states the formalism "presents a path forward for specifying the productive elements of incorrect explanations" and "suggests new directions for instruction while also improving the clarity of the resources framework".

## Design Implications

### Context
#### Requirements
- A causal network representation of the canonical physics to be learned, and student explanations elicited on questions probing that phenomenon
#### Constraints
- Demonstrated only for qualitative projectile motion questions with undergraduate explanations; the article notes responses may not reflect students' own conceptual views

### Target Learners
- undergraduate physics students

### Target Learning Goals
- aligning intuitive causal reasoning with canonical physics models
