# Provide nearly completed code with only a few pieces to finish, plus full solutions for self-checking

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
To let most students experience coding in limited time without getting stuck or left behind, the authors provide nearly completed codes with only one or a few pieces that need to be finished, and fully completed codes so students may check their own work. They encourage students to look at solution code only after a strong independent attempt. This keeps emphasis off technical details and on broader scientific interest.

## Design Implications

### Context
#### Requirements
- Solution code should be withheld until students have made a strong independent attempt to solve the problem
#### Constraints
- Designed for the very short time typically available in outreach settings, not full programming courses

### Target Learners
- high school students
- early college students with a wide range of programming backgrounds

### Target Learning Goals
- basic scientific programming
- confidence in coding
