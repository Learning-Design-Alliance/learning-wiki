# Design guidelines for future LLM evaluation tools: configurable metric views, tighter metric-rubric integration, and comparison-foregrounding visualizations

## Description
The article synthesizes design guidelines for future LLM evaluation tools that enable pedagogically-aligned, LLM-powered learning tools. The guidelines include "configurable metric views, tighter integration between metrics and rubrics, and visualization techniques that foreground comparison and trade-offs." These directions aim to support hybrid human-centered approaches where automated metrics provide screening while domain experts handle complex judgments.
