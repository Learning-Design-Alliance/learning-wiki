# Do not assume that reducing orientation effort automatically frees resources for deeper learning when orientation and learning happen simultaneously

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (3 for, 2 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The article's design implication for VR learning environments is that attention guidance alone may not translate into learning gains in dual-task contexts. As the authors put it, "Designers should therefore be cautious in assuming that reducing orientation effort automatically frees up resources for deeper learning, if orientation and learning need to happen at the same time." They recommend exploring additional instructional strategies, such as more extended familiarization with the VR setup, and redesigning learning tasks to include more active participation so learners attend to the narration.

## Design Implications

### Context
#### Requirements
- Learners must simultaneously search and engage with instructional content for the dual-task mechanism to apply
#### Constraints
- Both tested cueing methods guided attention successfully yet did not improve learning outcomes in this study

### Target Learners
- adult learners using head-mounted display VR

### Target Learning Goals
- declarative knowledge acquisition during search tasks
