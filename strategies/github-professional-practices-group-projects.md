# Integrate industry-standard software development practices through GitHub-based group workflows

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Group projects embed professional software development practices: "Version Control and Collaboration requires students to use GitHub for all project work, including branch creation, pull request workflows, and systematic code review processes." Additional components mandate comprehensive documentation with README files and inline comments, project boards for task tracking, and within-group peer code review emphasizing code quality and knowledge sharing.
