# Adopt the Smart Class teaching module as an alternative when traditional class teaching is not possible

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Because the Smart Class module achieved exam outcomes similar to the Traditional Class module, the authors recommend it as a viable alternative where traditional teaching cannot be implemented, such as due to geographic restrictions or pandemics. The article states that "when the Traditional Class teaching module cannot be implemented (e.g., due to geographic restrictions or pandemics), the Smart Class teaching module is an effective and feasible way to sustain educational progress." Implementers should anticipate the higher perceived academic load and the self-discipline demands of prereview.

## Design Implications

### Context
#### Requirements
- A network teaching platform (here the Chaoxin platform) providing teaching resources, real-time classrooms, and interactive communication.
#### Constraints
- The article notes the Smart Class module did not show advantages over the Traditional Class module and imposed a significantly greater perceived academic load (P<0.001).

### Target Learners
- Undergraduate medical and rehabilitation students studying medical English

### Target Learning Goals
- Sustaining medical English learning progress when in-person teaching is unavailable
