# Monitor tutoring implementation and attendance regularly during program rollout

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
This recommendation directs districts to establish regular monitoring of how a tutoring program is being implemented and whether students attend sessions, as an ongoing support activity after selection. The brief lists it among the actions districts "should consider... when exploring tutoring programs and supporting their implementation": "Monitor implementation and attendance regularly." It treats implementation fidelity and attendance as key levers districts can track during the 2021-2022-evaluated program models' rollout.

## Design Implications

### Context
#### Requirements
- Districts must have processes in place for ongoing data collection on implementation and student attendance once a tutoring program is adopted
