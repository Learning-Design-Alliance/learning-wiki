# Future improvements: real-world user studies, advanced student modeling, and spaced repetition

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors recommend a forward-looking agenda for the platform: conduct real-world user studies to assess learning gains, user experience, and the practical utility of generated courses; improve personalization through advanced student modeling such as adding affective state detection; and integrate mechanisms such as spaced repetition. They also plan to explore different LLMs and RAG architectures, adaptability to other STEM domains, accessibility, and explainability.

## Design Implications

### Context
#### Requirements
- Real-world user studies to validate learning gains before pedagogical effectiveness claims
#### Constraints
- Current personalization operates on a basic set of attributes; system performance depends on underlying LLM capabilities and possible biases

### Target Learners
- mathematics students, with planned extension to other STEM domains

### Target Learning Goals
- measurable learning gains
- improved personalization through affective and advanced student modeling
- long-term retention via spaced repetition
