# Memory Game (Matching)

## Description
A memory game where learners match pairs of word cards to reinforce vocabulary and memory skills. Learners turn over cards, say the words aloud, and try to find matching pairs. Successfully matched words must be used in a sentence from a familiar context, like a song, to further reinforce understanding and application.

## Design Implications

### Context
#### Requirements
- Word cards (two sets of each), small group setting, and writing materials. Teachers must prepare the word cards by printing and cutting them apart. Printing on cardstock is recommended to prevent see-through.
#### Constraints
- Preparation and setup can be time-consuming. Implementation requires careful monitoring to ensure engagement. Effectiveness depends on clear instructions and appropriate vocabulary selection.

### Target Learning Goals

### Affordances
- Active recall and memory skills are reinforced through engaging gameplay. Vocabulary is contextualized through sentence creation. Collaboration and peer support are encouraged.

### Personalization
- Can adapt the content (e.g., simpler or more complex vocabulary). Provide sentence frames for extra support. Implement in small groups for personalized learning.
