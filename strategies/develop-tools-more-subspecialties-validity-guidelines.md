# Develop procedure-specific assessment tools in additional orthopaedic subspecialties using established validity guidelines

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The review's stated future direction is to expand the portfolio of procedure-specific assessment tools beyond the four currently covered subspecialties. New tools should be developed using the established validity guidelines and methodologies the review applied, so that validity evidence accumulates across all five domains rather than concentrating in content. The authors frame this as the response to the current paucity of tools and their lack of validity evidence for high-stakes use.

## Design Implications

### Context
#### Requirements

#### Constraints
- Current evidence base is low quality and heterogeneous, precluding comparative analysis
