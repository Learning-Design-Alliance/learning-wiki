# Lecturers convert example-sheet Feynman diagram problems into shareable, importable FeynCraft problem sets

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
In the Problem Set mode, users create tailored sets of problems specifying a list of processes for which other users must draw the diagrams, optionally limiting the available Standard Model particles per process. Problems are exported and imported via a text file for easy sharing. The authors write "We envisage this feature as being useful for lecturers, who can convert the list of Feynman diagram problems in their examples sheets toFeynCraftproblem sets, and distribute these to their students via the export feature."

## Design Implications

### Context
#### Requirements
- A text-file export/import mechanism for sharing problem sets between users
#### Constraints
- Problem sets are user-curated; the article does not report any classroom deployment of this feature

### Target Learners
- undergraduate students in introductory particle physics courses
- A-level school pupils with a particle physics curriculum segment

### Target Learning Goals
- practising drawing Feynman diagrams for curriculum-specified processes
