# Implement school-based self-monitoring by selecting and defining a target behavior, then adding self-assessment and self-recording

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 quant-synthesis), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article's implementation analysis supports a recipe: practitioners implementing self-monitoring should begin by "selecting a target behavior" and "defining the target behavior", then build in "self-assessment, and self-recording". The analysis found much of the intervention's effects are based on these four key components, and higher student involvement is associated with stronger effects.

## Design Implications

### Context
#### Requirements
- A target behavior must be selected and defined before self-assessment and self-recording procedures are introduced
