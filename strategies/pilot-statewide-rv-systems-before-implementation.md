# Pilot statewide roster verification systems before full implementation

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Among the brief's implementation strategies is piloting the statewide roster verification system on a limited scale before statewide rollout. Piloting is intended to surface potential pitfalls states should consider, so that teacher-student data links are valid before results feed high-stakes decisions and are shared with districts.

## Design Implications

### Context
#### Requirements
- A statewide ToR definition and RV system must exist before piloting can occur.
