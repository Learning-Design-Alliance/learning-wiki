# Architectural changes for ICT integration: larger classrooms, a technological classroom, and a library as resource centre

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 2 studies (1 associational, 1 theoretical), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The article lists architectural changes considered fundamental for ICT integration: "The larger size of the classrooms stands out most of all, and they are moreover conditioned for the use of audio -visual media"; creating a technological classroom usable like an auditorium and prepared for technological instruments; and modifying the library as a resource centre and database. The technological classroom houses all technological material, which can be used there or moved to classrooms where pertinent.

## Design Implications

### Context
#### Requirements
- The technological classroom must be "equipped sufficiently so as to be able to offer all the instruments necessary for the use of the emeging technologies and the audio-visual media in the centre".
#### Constraints
- Some instruments remain permanently in the technological classroom "whether due to its excessive weight, fragility or high price".

### Target Learners
- primary and secondary education students

### Target Learning Goals
- effective pedagogical use of ICT and audio-visual media
