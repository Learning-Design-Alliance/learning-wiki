# Provide open access to notebook source code to enable feedback, adaptation and peer instruction

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Each OSSCAR application displays a direct link to its source code at the top of the page, and all notebooks are released under open-source licenses in GitHub repositories that also contain the deployment configuration files, so each repository is a complete template for a new application. The article states that "code access encourages both students and other teachers to provide feedback and improvements via GitHub issues and pull requests, in a fully collaborative and open approach and in the spirit of Open Science". Engaging students in content preparation is said to support peer instruction and cooperative learning.
