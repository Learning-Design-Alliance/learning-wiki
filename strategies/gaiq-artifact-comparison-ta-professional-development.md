# Use a group-administered interactive-questionnaire artifact-comparison activity as a starting point for TA professional development on solution design

> **Strategy** · [All strategies](index.md)
> **Evidence** · 8 claims (8 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 8 claims rest on one study

## Description
The GAIQ activity has each TA first write a solution they would hand out to students, then read three example solutions, identify and rank prominent features, explain preferences, discuss in small groups and whole class, and complete a post-discussion worksheet matching features to a pre-defined list. The authors believe this activity "provides a starting point for TAs' professional development" because it elicits TAs' initial ideas about solution design, and recommend follow-up activities aligned with strategies for enhancing conceptual change, including importing new ideas from the research literature and explicitly guiding TAs to evaluate their practice in light of them.

## Design Implications

### Context
#### Requirements
- A set of contrasting instructor solutions for the same problem
- A pre-defined feature list from a pilot study for the matching task
- Small-group and whole-class discussion time
#### Constraints
- The article reports the activity with first-year graduate TAs in a TA training course; influence on future practice is anticipated rather than demonstrated

### Target Learners
- first-year graduate teaching assistants in physics

### Target Learning Goals
- beliefs and values about the design of instructor problem solutions
- explicit knowledge of expert-like problem solving features

- [Cognitive Apprenticeship Expert Problem Solving Framework Reif](../theories/cognitive-apprenticeship.md)
