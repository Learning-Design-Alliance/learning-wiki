# Use Sim-OSSCAR as formative assessment with a benchmark before progression to live surgery

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article recommends using the Sim-OSSCAR during initial instruction as a clear list of procedure steps and a guide to what is expected for each step to be deemed competent, then as a summative gate for progression. It suggests an example benchmark: "to require a mean of 75% score (30/40) over three cases, and no 'zero' scores in any of the 20 steps."

## Design Implications

### Context

### Target Learning Goals
