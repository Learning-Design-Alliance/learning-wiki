# Add a stopping condition to the free-fall simulation and update the rubric to reward recognizing model limits

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
For future implementations, the authors recommend modifying the Stage 3 simulation so the object stops at the ground, opening discussion of the role and limitations of mathematical models. They write that "it would be valuable to include a stopping condition in the simulation that prevents the object from continuing once it reaches the ground," and that the rubric should indicate the highest performance level is achieved when students recognize the model is no longer valid once position becomes negative.
