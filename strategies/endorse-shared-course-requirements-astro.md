# Endorse a shared set of recommended course requirements so the degree communicates common knowledge and skills

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because the only shared requirements across all programs are two semesters of calculus and two introductory physics courses — in stark contrast to relatively homogeneous programs in most other STEM disciplines — the report recommends the AAS Board of Trustees endorse recommended course requirements for Astronomy/Astrophysics programs. Appendix B proposes a possible course requirement list as a starting point for community conversation.

## Design Implications

### Context
#### Requirements
- Consultation with the AAS Employment Committee, Working Group on Graduate Admissions, and Beyond Academic Careers Advisory Committee
#### Constraints
- Any endorsed recommendations must remain relevant across the broad spectrum of careers majors pursue, not narrowly focused on graduate preparation

### Target Learners
- undergraduate Astronomy/Astrophysics majors

### Target Learning Goals
- a shared foundational set of physics, mathematics, and astronomy knowledge
