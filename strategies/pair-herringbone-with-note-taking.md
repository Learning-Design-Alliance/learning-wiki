# Pair the Herringbone technique with note-taking in classroom reading practice

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Because the authors observed that graphic representation reduced students' note-taking efforts, while note-taking supports concentration on relevant information, they recommend combining the two. They write that "teachers can apply the HT with note -taking alongside each other in the classroom practice for a more heightened development in reading comprehension." The strategy keeps the Herringbone diagram's main-idea work while restoring the metacognitive support of note-taking.

## Design Implications

### Context
#### Requirements
- Teachers implement the Herringbone diagram and note-taking activities together during reading lessons

### Target Learning Goals
