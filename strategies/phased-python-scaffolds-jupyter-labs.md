# Phase Python computational tasks into physics labs using scaffolded code modification in Jupyter Notebooks

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (2 design, 1 qualitative), `q2` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
A implementable approach in which computational tasks are introduced gradually across the semester and students engage with programming by modifying existing Python code tied to the laboratory's physical principles rather than writing code from scratch. Students build reports in Jupyter Notebooks hosted on Google Colaboratory, which "combine executable code and rich text" and require no downloads or installations. The strategy assumes no prior programming experience and embeds scaffolds within hands-on inquiry activities using PASCO equipment and Capstone software.

## Design Implications

### Context
#### Requirements
- Access to Jupyter Notebooks / Google Colaboratory at no cost with a Google account
- Existing Python code related to the laboratory's physical principles for students to modify
- Carefully designed scaffolds supporting programming in the context of experiments
#### Constraints
- The article restricts computational thinking to applying computational techniques using Python (CT-lite), not general programming instruction

### Target Learners
- introductory physics students without prior programming experience

### Target Learning Goals
- using coding to integrate physics and math into problem-solving
- breaking complex problems into simpler parts
- simulating and analyzing design challenges
