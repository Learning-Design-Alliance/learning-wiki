# Use a simple computational exercise that can be 'tweaked' with a few lines of code to solve a different, equally intensive problem almost for free

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 causal, 1 design), `q1`–`q2` · 1 of 2 report an effect size · 2 claims rest on one study

## Description
The course paired a heavily commented sample program solving a familiar problem with simple variations requiring only small code changes. After the Helmholtz coil program, students noted 'the initial investment involved in mastering the original program, could, by a very simple ''tweak'' of the notebook under discussion (requiring only changes in a few lines of code) solve a diﬀerent, equally mathematically intensive problem almost for free.' Links to the anti-Helmholtz coil variation (currents in opposite directions producing a uniform field gradient) made the payoff concrete.
