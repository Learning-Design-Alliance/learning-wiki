# Manipulatives

## Description
Provide manipulatives to help make complex concepts concrete. Abstract concepts can be tough to understand, but tangible objects make them easier to manage.

## Design Implications

### Context
#### Requirements
- Readily available manipulatives and a teacher that supports their use.
#### Constraints
- Some students might not have the cognitive awareness to benefit from manipulatives.

### Affordances
- Tangible objects help students better understand key concepts.

### Personalization
- Allow learners to find manipulatives that work for them. Use manipulatives for every content, not just numeracy.

- Observe whether students make connections between the manipulatives and concepts. Use assessment results to see if they are learning from the manipulatives.
