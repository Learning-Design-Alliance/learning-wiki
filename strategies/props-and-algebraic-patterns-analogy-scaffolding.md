# Use concrete props and algebraic patterns to scaffold analogical skill in geometry discovery lessons

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (2 causal, 1 review), `q2`–`q3` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The article's recommendations state that geometry material "should be presented with the help of props" to make learning meaningful, and that to develop analogical skill in geometry, "teachers can use algebraic patterns to present geometry shapes because junior high school students understand more about them". Scaffolding should be integrated with the geometry shapes' presentation, and materials should be designed after pedagogical-didactic analysis of analogical-skill obstacles.

## Design Implications

### Context
#### Requirements
- Learning materials prepared after pedagogical didactic analysis connected to analogical skill obstacles in geometry
- Scaffolding matched to students' pattern-finding difficulties, e.g. labelling successive pattern terms
