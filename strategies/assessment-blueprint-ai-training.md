# Adopt an assessment blueprint for AI training: define constructs, use multiple indicators, anticipate shortcuts, and refresh evaluations as models adapt

> **Strategy** · [All strategies](index.md)

## Description
The article translates assessment theory into an implementable evaluation recipe: "Concretely, the analogy motivates an 'assessment blueprint' for AI training: define target constructs, specify multiple observable indicators, anticipate predictable shortcuts, and update the evaluation as models learn the test (Burnell et al., 2023)." Supporting safeguards include protecting evaluation sets from contamination through holdout governance, reporting results with uncertainty and slice analyses, and rotating item pools and retiring saturated tests.

## Design Implications

### Context
#### Requirements
- Multiple indicators must be genuinely complementary, probing the same construct through different task formats, contexts, and failure modes
#### Constraints
- Because learning systems adapt to what is measured, the evaluation itself must be periodically updated to remain construct-aligned

### Target Learners
- AI training and evaluation teams
- educational psychologists designing AI intervention studies

### Target Learning Goals
- Distinguishing robust generalization from proxy optimization and teaching to the test in model evaluation
