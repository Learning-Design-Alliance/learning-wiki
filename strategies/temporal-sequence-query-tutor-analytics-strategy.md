# Extend tutor analytics with user-defined temporal sequence queries that automatically highlight concerning interaction patterns

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors propose letting teachers input user-defined temporal sequence queries to search for patterns of interest, such as a sequence of repeated incorrect inputs, which are then automatically highlighted. This would complement manual data exploration and surface insights specific to different user contexts, building on existing temporal sequence analysis and automatic data-fact generation research. The authors state they plan to implement this feature in future work.
