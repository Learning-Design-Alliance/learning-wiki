# Establish public computing spaces in the university where non-scientists access, modify and create authentic scientific work via open-source platforms

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The paper recommends that universities establish public computing spaces: "open-ended, public learning environment, in which visitors interac t with open source computing platforms to directly access, modify and c reate com- plex and authentic scientiﬁc work." By giving learners unrestricted access to the code itself, such spaces offer opportunities to play with disciplinary meanings and expertise, supported by open-source media affordances and collaboration with friends, strangers and experts.

## Design Implications

### Context
#### Requirements
- Open-source computing platforms whose code reifies expert epistemic and representational work; public physical accessibility; facilitation and just-in-time support for modifying live simulations
#### Constraints
- The authors present this as "a (not the) model solution" for public engagement with science

### Target Learners
- Non-scientists and members of the public, including university visitors

### Target Learning Goals
- Authentic and creative engagement with scientific computation and modeling
