# Use free open-source software (Audacity, Stellarium) that students can install at home for data analysis and ephemeris comparison

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The activity relied on Audacity, "a freely available open-source program, running under Windows, Mac OS X and GNU/Linux", for visualizing audio levels and isolating syllables and echoes, and on Stellarium to reproduce the Moon ephemerides, which "yields the same results and is much more fun for students". The authors report students very much appreciated open-source software they could easily install on their home computers, especially Stellarium.
