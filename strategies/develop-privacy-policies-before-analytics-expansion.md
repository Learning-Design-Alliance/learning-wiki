# Institutions implementing learning analytics should spend focused time developing privacy policies and procedures, with stakeholder input including students, before expanding analytics use

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article recommends that institutions beginning a focused push with learning analytics "spend time developing policies and procedures," since this focused time allows buy-in and surfaces issues early. Policies should address privacy alongside ethical, legal, and logistical questions, stakeholder responsibilities, and an action plan toward a code of practice, following Sclater's guidance.

## Design Implications

### Context
#### Requirements
- Policies should be developed with input from stakeholders, including students, to establish trust and buy-in
#### Constraints
- The case institution had only a functional communications component and had not fully implemented the learning analytics component

### Target Learners
- higher education administrators implementing learning analytics systems

### Target Learning Goals
- responsible and privacy-protective institutional use of student data in learning analytics
