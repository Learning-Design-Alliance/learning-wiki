# Use network analysis of course programmes as a systematic tool for constructing interdisciplinary curricula

> **Strategy** · [All strategies](index.md)

## Description
The article recommends using its themes-network model as a systematic aid when designing or revising pedagogical curricular programmes: mapping menu topics to nodes and dependencies to links yields degree distributions that reveal how prerequisites and topic relevance are sequenced across disciplines. The authors state the model "can be used as a systematic tool assisting the construction of a more interdisciplinary curriculum, articulating between disciplines of the undergraduate early-years in exact sciences."

## Design Implications

### Context
#### Requirements
- Known discipline programmes and a mapping of topic dependencies between disciplines
#### Constraints
- The analysis in the article covers only the basic cycle; the authors state it can be extended to the professional cycle and to the study of prerequisites in a PPC

### Target Learners

### Target Learning Goals
