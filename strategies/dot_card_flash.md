# Dot Card Flash

## Description
One learner flashes a dot card to another for 3 seconds, then hides it. The second learner tries to recreate the arrangement on their own dot card from memory. This helps them build visual memory and subitizing skills.

## Design Implications

### Context
#### Requirements
- Dot cards, dot card game mat, counters, timer.
#### Constraints
- Learners with visual processing difficulties or memory challenges may find this activity difficult. It may require adaptation for learners with attention deficits.

### Target Learners

- Pre-K to 1st Grade learners who are developing subitizing skills.

### Target Learning Goals
<!-- Link to sub-claims -->
- Improve visual memory, enhance subitizing skills, reinforce number arrangements

### Affordances
- Enhances memory and quick recognition of dot arrangements. Promotes cognitive processing speed. Reinforces number concepts through visual and memory recall.

### Personalization
- Adjust the flash time based on the learner's ability. Vary the complexity of dot arrangements to suit different levels of learners.
