# Plan ICM evaluations with multiple proximal outcome criteria, multiple data sources and time points, capture of unintended effects, moderators and process data

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The chapter recommends that evaluation start from a target state defined in advance and tailor strategy to the programme, combining summative and formative, process-accompanying evaluation. It advises: "Bestenfalls werden nicht nur mehrere Kriterien, sondern auch unterschiedliche Datenquellen und Datenerhebungsmethoden kombiniert eingesetzt", preferring proximal criteria such as competence gain and attainment of predefined learning goals over global ones like degree completion. It further recommends (quasi-)experimental designs with pre-measurement and comparison groups, capturing unintended effects (student time burden, lecturer workload), moderators (institution type, subject, group size, gender, prior knowledge, personality, lecturer), and process data including implementation control, usage behaviour and satisfaction.

## Design Implications

### Context
#### Requirements
- Cooperation willingness of students, who must work through the materials before in-person sessions
- Detailed documentation of all conditions and examined populations so later meta-analyses can integrate single findings
#### Constraints
- Single studies are only limitedly able to uncover moderator effects, which require meta-analyses; statistically testing effects requires relatively large study groups, so design choice often hinges on pragmatic resource considerations

### Target Learners
- Project staff and lecturers planning and evaluating inverted-classroom interventions at universities of applied sciences

### Target Learning Goals
- Judging whether an ICM implementation produces its intended added value and deciding on continuation, modification or termination
