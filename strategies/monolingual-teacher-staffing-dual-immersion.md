# Staff dual language classrooms with monolingual target-language teachers to prevent code-switching asymmetry

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article's discussion argues that evenly dispersing bilingual teachers across English-only and Spanish-only classrooms would only create illusions of symmetry, since code-switching potential would occur in both rooms. The author suggests that "monolingual Spanish and monolingual English teachers would facilitate an ideal match between instructional theory and program practices," allowing asymmetries to vanish while maintaining program quality. This is a forward-looking design recommendation derived from the observed trade-off between equality and quality.

## Design Implications

### Context
#### Requirements
