# Chalkboard Math App

## Description
App for students to practice basic math. The app, as the name suggests, comes with an interface offering a chalkboard to go with the math practice. It helps kids to learn all the basic math facts corresponding to addition, subtraction, multiplication and division in a quickly-engaging manner. It generates math practice in two different modes: answer mode and flashcard mode. While the first one allows entering answers and getting feedback, the second one allows verbal answering.
