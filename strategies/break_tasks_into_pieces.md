# Break Tasks into Pieces

## Description
Divide tasks into smaller chunks. The learner can focus long enough to perform part of the task, then take a break, coming back to the project to finish. This helps learners with attention struggles perform the requested task faster than if they tried to finish it all in one sitting.

## Design Implications

### Context
#### Requirements
- Structured tasks, designated break periods, clear checkpoints.
#### Constraints
- May disrupt workflow if chunks are too small. Requires structured task management.
