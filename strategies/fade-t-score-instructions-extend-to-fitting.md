# Fade explicit comparison instructions across the course and extend the t'-score structure to weighted least-squares fitting

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that with the t'-score framework introduced early, "these behaviours become habit and routine during the experiments as the explicit instructions are faded throughout the course". It further recommends that opportunities to evaluate models expand as the framework is mapped onto weighted least-squares fitting for continuous data, allowing the same comparison structure to be used across the lab curriculum.
