Plan a built-in stealth assessment dashboard that tracks student progress from gameplay data¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The authors' forward-looking recommendation is to embed an informal, metrics-based assessment directly in the app so teachers can monitor learning without administering separate tests. "Future goals include implementing and testing a built-in stealth assessment tool, which will function as an informal metrics-based assessment allowing teachers to track and monitor student progress as they advance through the app." Data from the debate assessment, mini-games, and reading behaviors (words per minute, selected reading level) would flow to a teacher dashboard, with the goal of eliminating outside assessments that cost class time.
