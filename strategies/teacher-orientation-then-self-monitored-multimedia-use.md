# Implement the multimedia package through teacher orientation followed by learner self-monitoring and self-evaluation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (3 causal), `q2` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The article prescribes a sequence of classroom activities for using the package: the teacher first taught the operating system of the Interactive-Multimedia Package, students were stimulated to operate it, and problems were explained at the spot. Learners then received "A package was given to the students to learn the content in their own", with "Self-monitoring of the students was the liberated strategy used in it" and self-evaluation done by the learners themselves.

## Design Implications

### Context
#### Requirements
- Teacher orientation to the package's operating system before independent learner use
#### Constraints
- Reported for standard VI English communicative-skill classes in one government school

### Target Learners
- standard VI students

### Target Learning Goals
- communicative skill in English (oral and written)
