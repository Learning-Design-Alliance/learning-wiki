# Blended Cognitive Tutor® implementation alternating collaborative textbook periods with adaptive software lab periods

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The curriculum's blended implementation splits weekly instruction between collaborative classroom work and individualized software work: "three periods per week are spent using the textbook for classroom activities" and "Two periods per week are spent in the computer lab using the software." Textbook periods foster cooperative problem solving, investigations, and comparing solutions; software periods let "students learn with the adaptive software at their own pace." This pairs student-centered discussion with self-paced adaptive practice.

## Design Implications
