# Use visual explanation tools to support learning in communities with scarce tailored learning resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article recommends that visual explanation tools such as nev can serve learners where dedicated learning materials are lacking, concluding that "visual explanation tools might alleviate the need for tailored learning resources". The strategy is to expose learners to expert-oriented debugging and tracing tools so they can inspect derivations, build and manipulate queries, and develop computational thinking without purpose-built curricula.

## Design Implications

### Context
#### Requirements
- A reasoning system that can compute proof traces (traces) for derived facts, exposed through a visual explanation interface
#### Constraints
- The study's positive results were influenced by interviewer assistance that alleviated the learning curve; learning benefits were not quantitatively measured

### Target Learners
- early and advanced learners of declarative logic programming
- students in knowledge-graph courses

### Target Learning Goals
- computational thinking skills such as decomposition, abstraction, and pattern recognition
- understanding and debugging rule-based programs
