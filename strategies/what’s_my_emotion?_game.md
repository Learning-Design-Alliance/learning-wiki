# What’s My Emotion? Game

## Description
One learner demonstrates an emotion through body language and facial expressions, while the rest of the class guesses the emotion.

## Design Implications

### Context
#### Requirements
- EQ Feeling Chart (optional), space for learners to act out emotions
#### Constraints
- Some learners may feel self-conscious acting out emotions. Requires a safe and supportive classroom environment.
