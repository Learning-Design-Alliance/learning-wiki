# Untimed Tests

## Description
Untimed tests remove the pressure of completing assessments within a set time limit, allowing learners to focus on problem-solving without time-related anxiety. This approach provides learners cognitive space to work through problems, potentially improving performance by reducing stress and allowing for deeper engagement with the material.

## Design Implications

### Context
#### Requirements
- Adjustments to testing procedures to remove time constraints. May require additional planning to accommodate extended testing periods.
#### Constraints
- May not be feasible in all testing situations (e.g., standardized assessments). Could potentially allow more time for cheating if not properly monitored.

## Assessment Evidence
- Compare performance on timed vs. untimed tests to assess the impact of time pressure. Observe learners' problem-solving approaches and depth of engagement during untimed tests.

## Impact
- Research indicates that timed tests can induce math anxiety, blocking working memory and hindering performance (Beilock, 2011; Ramirez, et al, 2013). Untimed conditions may improve performance and reduce anxiety.
