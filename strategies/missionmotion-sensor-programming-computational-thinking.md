# Program micro:bit or Arduino sensor boards so students develop computational thinking while exploring kinematics

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article proposes using ultrasonic sensors on micro:bit or Arduino to design activities in which "students program the boards, configure sensor connections, and use the playful environment as a resource to develop computational thinking". At more advanced stages, robots programmed to reproduce the target motion can be integrated, which the authors say enhances both technical competencies and conceptual understanding of the represented physical phenomenon.

## Design Implications

### Context
#### Requirements
- Ultrasonic sensors connected to micro:bit or Arduino devices
- Programming activities in which students configure sensor connections
#### Constraints
- Robot integration is described as possible at more advanced stages

### Target Learners
- secondary school physics students

### Target Learning Goals
- computational thinking
- conceptual understanding of kinematics
