# Use learning analytics with human-in-the-loop evaluation to disassemble the data jigsaw from VR training systems

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article proposes using learning analytics to disassemble the "data jigsaw quandary" from virtual reality training systems and enhance "human-in-the-loop evaluation". This combines classifier-based student modeling, feature importance analysis, and visualization-supported expert review of trace data to detect untrained students and identify error patterns.

## Design Implications

### Context
#### Requirements
- Requires trace data collected from students using a virtual reality training system
- Requires human expert aid for interpreting visualized error patterns
#### Constraints
- Demonstrated in the lineworker maintenance training context with data from 2008 to 2016

### Target Learners
- vocational trainees in high-risk occupations

### Target Learning Goals
- procedural skill in live-line maintenance maneuvers
