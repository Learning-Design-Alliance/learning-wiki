# Isolate a single cognitive ability with matched stimuli when testing IVR's effect on learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article recommends that researchers investigating how IVR improves learning isolate a single cognitive ability and match viewing conditions closely. Its own design did this by using "identical" visual stimuli in both conditions, giving both devices the same level of interaction, and using a surprise recall test measuring "basic memory processes in the absence of instruction". This stands in contrast to prior designs the authors say make it impossible to isolate individual cognitive abilities.

## Design Implications

### Context
#### Requirements
- Stimuli must be identical across conditions and both devices must allow comparable interaction with the content
#### Constraints
- The article notes the overall resolution, effective screen size and interaction source (touch vs. head movement) differed between its own presentation modes
