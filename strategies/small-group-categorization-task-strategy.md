# Small-group peer categorization of problems followed by class discussion and an individual follow-up categorization task

> **Strategy** · [All strategies](index.md)
> **Evidence** · 8 claims (8 for) · 3 studies (3 associational), `q2`–`q3` · 0 of 3 report an effect size · 8 claims rest on one study

## Description
The article recommends placing introductory physics students of different expertise levels in small groups and asking them to categorize problems by similarity of solution without solving them, discussing why different problems belong in the same group. Because individual performance varies widely, "introductory students can have meaningful discussions while categorizing problems in small groups." The activity is followed by a class discussion of why some categorizations are better and an individual follow-up task for accountability.

## Design Implications

### Context
#### Requirements
- A set of problems spanning diverse contexts but shared underlying principles, with instructions asking students to group by features that make problems similar rather than by difficulty, and to explain each category
#### Constraints
- Students are not asked to solve the problems explicitly; the task targets conceptual analysis and planning rather than plan implementation

### Target Learners
- students in large calculus-based introductory physics courses

### Target Learning Goals
- discerning the underlying similarity between problems with diverse contexts but the same underlying physics principles
