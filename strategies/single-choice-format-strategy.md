# Change complex multiple-choice items to single-choice format in concept inventories

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (2 review, 1 associational), `q2` · 1 of 3 report an effect size · 3 claims rest on one study

## Description
The article recommends that test developers replace complex multiple-choice response formats, in which test takers select combinations of graphs (e.g., "(a) graphs I, III and V"), with single-choice formats. The authors "encourage test developers to change the response format from complex multiple choice to single choice to have a consistent format", because in complex items incorrect answers can involve subsets of correct graphs, so eye-tracking analyses cannot discriminate visit duration on correct and incorrect options.
