# Implement computational essays via an open investigation challenge with pre-built simplified simulations, example essays, drop-in sessions, and peer presentations

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article's pilot recipe: give students the challenge to "use a simulation to investigate a problem that you find interesting, then write a computational essay about what you've learned," leaving the task open so investigations are driven by student interests. Provide pre-built, deliberately simplified Jupyter notebook simulations on course topics, an example essay to set expectations, twice-weekly drop-in help sessions, roughly 4-6 weeks of work time, and presentations to small peer groups modeled on research-group practice.

## Design Implications

### Context
#### Requirements
- Pre-built simulations on course topics
- an example computational essay
- scheduled drop-in support sessions
- several weeks of work time
#### Constraints
- The article notes students found the openness difficult for topic choice and struggled with notebook non-linearity, motivating added time, notebook training, and suggested topics in future iterations

### Target Learners
- college students in introductory physics courses

### Target Learning Goals
- independent investigation
- computational modeling
- communication of results
