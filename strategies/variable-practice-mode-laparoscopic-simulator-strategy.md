# Adopt variable practice for basic laparoscopic simulator training, with a variable practice mode in virtual reality simulators

> **Strategy** · [All strategies](index.md)
> **Evidence** · 5 claims (5 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 5 claims rest on one study

## Description
The authors recommend that "training centers should consider using the variable practice approach for basic laparoscopic simulator training", because it accelerates skills acquisition, leads to higher transfer and retention, and is more time-efficient for trainees and instructors since assistance is mainly needed at the beginning. They state implementation "comes with no additional costs and could easily be added as an automatic function in virtual reality simulators", and report being in dialog with simulator manufacturers to create a variable practice mode.

## Design Implications

### Context
#### Requirements
- Proficiency criteria must be defined so tasks can be removed once passed twice within five consecutive attempts
- instructor availability for early feedback is needed
#### Constraints
- Instructor feedback was given upon request and the effect was studied in novices using non-haptic simulators, not in clinical settings

### Target Learners
- novices in laparoscopic simulation training, e.g., medical students and new residents

### Target Learning Goals
- faster acquisition, transfer, and retention of basic laparoscopic skills

### Affordances
- Contextual Interference Desirable Difficulties Surgical Simulation
