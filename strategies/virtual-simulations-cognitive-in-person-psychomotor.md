# Use virtual simulations to enhance cognitive learning while prioritizing in-person laboratory sessions for psychomotor and technical skills

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 review), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The review's concluding recommendation for a balanced instructional approach: "the strategical using virtual simulations are recommended to enhance cognitive learning while in-person laboratory sessions for developing psychomotor and technical skills are prioritized too." This pairs virtual modules, which the review found strongest in the cognitive domain, with in-person sessions for hands-on skills. The take-home message frames virtual laboratories as "complementary tools along with traditional hands-on labs."

## Design Implications

### Context
#### Requirements
- Careful integration of virtual laboratories, addressing simulation accuracy, effective assessment methods, and maintaining student engagement
#### Constraints
- The review states virtual laboratories "cannot fully replace hands-on practical experience" and should be viewed as a complement to traditional education

### Target Learners
- Healthcare students in basic medical sciences courses

### Target Learning Goals
- Cognitive-domain learning and preparation for psychomotor laboratory skills
