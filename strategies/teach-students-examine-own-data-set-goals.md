# Teach students to examine their own data and set learning goals

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Teachers instruct students in using their own assessment data to develop personal achievement goals and guide learning. Action steps include explaining expectations and assessment criteria, providing feedback that is "timely, specific, well formatted, and constructive", providing tools that help students learn from feedback, and using students' data analyses to guide instructional changes. Teachers can then use these goals to understand factors motivating student performance and adjust instruction.

## Design Implications

### Context
#### Requirements
- Provide tools such as rubrics and reflection worksheets that help students learn from feedback
- Use students' own data analyses to inform instructional adjustments

### Target Learners
- K-12 students examining their own assessment data

### Target Learning Goals
- Setting and monitoring personal learning goals from assessment feedback
