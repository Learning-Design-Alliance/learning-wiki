# Adopt pedagogy that is explicit about epistemological issues and mixes epistemic tools from the beginning rather than adding tools in stages

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
For instructors working in a resources framework, the review recommends against pedagogy that adds epistemic tools in subsequent stages, since starting with simple tools might confirm epistemological misconceptions such as that memorizing is the main point. Instead, instructors "might rather adopt a pedagogy that is both explicit about epistemological issues and mixes epistemic tools from the beginning," scaffolding higher-order Bloom stages in simple situations, increasing complexity, and decreasing scaffolding as the class progresses.

## Design Implications

### Context
#### Requirements
- Scaffolding of higher-order epistemic tools in simple situations, with complexity increased and scaffolding decreased as the class progresses
#### Constraints
- The review presents this as what resources-framework instructors might do, not as a tested manipulation of this article

### Target Learners
- undergraduate science students, including novices with fragmentary epistemologies

### Target Learning Goals
- epistemic tool development and avoiding confirmation of epistemological misconceptions
