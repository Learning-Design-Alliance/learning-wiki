# Describe a support system's design intent by asking against whose Synthesis or Analysis it elicits a structural gap

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The paper proposes using the four-types vocabulary as a diagnostic question for any AI-era support system: "by what function, and against whose mapping—Synthesis or Analysis—does the system seek to elicit a gap?" Applying it, a tool where the AI generates text and the user merely approves lies in Type (II) and has no gap-eliciting function, while a tool that scores automatically implements part of Type (III) and, lacking a rebuttal route, delegates evaluative judgment after all. This lets designers name the site of metacognitive stimulation explicitly.

## Design Implications

### Context
#### Requirements
- The four-quadrant distinction of function and executing agent must be in place for the question to be answerable
#### Constraints
- The agent columns name principal carriers only; both Synthesis and Analysis are in practice carried by human and AI alike in Type (IV)

### Target Learners
- Designers and evaluators of learning- and research-support systems

### Target Learning Goals
- Diagnosing where a system stimulates or suppresses learner metacognition

### Affordances
- Four Quadrants Function Agent Taxonomy
