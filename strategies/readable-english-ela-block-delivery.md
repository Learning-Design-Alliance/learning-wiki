# Deliver Readable English as whole-class and small-group instruction within the regular ELA block

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In the qualifying study, the intervention was delivered "as a whole class and in small groups during the regular ELA instruction block", so students did not lose core ELA time to receive it. Implementation requires a "Small group reading instructor/teacher" and technology: a "Computer or tablet for student use, Smart Board for small group/whole class use". This makes the program embeddable in existing tiered support schedules.
