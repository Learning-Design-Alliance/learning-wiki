# Guide students to build their own EJS simulations in five steps: new project, design interface, add code, test and run, share

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article lays out a step-by-step recipe for students or tutors creating their own simulations in EJS: (i) create a new simulation from the File menu and set basic parameters; (ii) design the simulation by dragging and dropping components such as buttons, sliders, text fields, and graphs; (iii) add code in the Script tab specifying dynamical variables and equations of motion; (iv) test and run with one click, launching the simulation in a web browser; and (v) optionally export and share the simulation as a Java applet or standalone application. EJS includes numerical methods, so "the student does not need to re-implement them, only would need to provide the initial conditions".

## Design Implications

### Context
#### Requirements
- Students need some basic knowledge of programming, since EJS uses the Java programming language
- EJS installed from the Open Source Physics website
#### Constraints
- Depending on the complexity of the simulation, additional features and tools within EJS may be needed; consulting EJS documentation or tutorials may help

### Target Learners
- students creating their own physics simulations
- tutors and instructors

### Target Learning Goals
- computational modeling of physical systems
- authoring interactive physics simulations
