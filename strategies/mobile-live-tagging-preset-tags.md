# Mobile live tagging during lectures using a pre-set repertoire of tags

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 mixed, 1 against) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
An alternative interaction model, developed with an undergraduate Computing Science student, has 'students use a mobile device to add tags during a lecture, selecting from a pre-set repertiore of tags' (article spelling). Tags marking moments such as 'I'm lost here' or 'exam' are added while the user is already engaged with the live lecture, which the authors suggest might evade the review-model problems of the current interface.

## Design Implications

### Context
#### Requirements
- Keeping tags such as 'I'm lost' at least semi-private requires a non-trivial server change.
#### Constraints
- The approach was promising but was not possible to fully develop in this prototype cycle.

### Target Learners
- students attending live lectures

### Target Learning Goals
- in-lecture engagement and marking confusing or exam-relevant moments in the audio

## Claims

- [Only a very small number of students added tags to lecture audio despite demonstrations and encouragement across six astronomy courses](../claims/low-student-tagging-of-lecture-audio.md) [-M]
