# Develop a customer-specific implementation plan identifying targeted students and outlining professional development

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
As part of implementation, "Achieve3000 works with each customer to develop a plan that identifies the targeted students and outlines professional development and implementation services." This makes professional development and implementation support a planned, site-specific component of adopting the program rather than a fixed package.
