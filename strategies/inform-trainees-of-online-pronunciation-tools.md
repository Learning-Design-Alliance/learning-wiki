# Inform teacher trainees about online self-study tools and pair phonology coursework with web-based pronunciation resources

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article concludes that "theoretical knowledge about English pronunciation and phonology should be accompanied by useful web-based resources that the trainees can utilise for self-study" and "it might be suggested that language teacher trainees should be better informed regarding similar online tools". It argues that tools perceived as user-friendly and useful are more likely to be used again, yielding better learning outcomes over the long run.

## Design Implications

### Context
#### Requirements
- Tools that trainees perceive as user-friendly and useful
#### Constraints
- Text-to-speech websites are not the only or the best resource available for pronunciation development

### Target Learners
- EFL teacher trainees

### Target Learning Goals
- Autonomous pronunciation improvement and long-term self-study habits
