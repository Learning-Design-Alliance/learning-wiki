# Agent-based modeling as pedagogical approach for emergent mathematical behavior

> **Strategy** · [All strategies](index.md)
> **Evidence** · 9 claims (7 for, 2 mixed) · 7 studies (4 design, 3 theoretical), `q1`–`q2` · 0 of 7 report an effect size · 9 claims rest on one study

## Description
Learners iteratively design, evaluate and re-design mathematical models using agent-based modeling languages and platforms such as Scratch, Agentsheets, NetLogo and ViMAP. In agent-based modeling, "learners can simulate the relevant mathematical behaviors by programming the on-screen behavior of computational agents (e.g., the Logo turtle) using body-syntonic commands". Emergence is simulated as the aggregate-level outcome arising from interactions between many individual-level computational agents, giving learners access to fractal geometry, chaos theory, and dynamic modeling.

## Design Implications

### Context
#### Requirements
- Access to agent-based modeling languages and platforms
- learners programming agent behaviors with body-syntonic commands
#### Constraints
- Some advocates (English 2006; Lesh and Doerr 2003) argue the shift in sensibility from linearity to complexity matters more than computational competencies

### Target Learners
- K–12 students
- secondary and tertiary students

### Target Learning Goals
- modeling emergent phenomena
- recursive functions
- fractal geometry
- difference equations and iterations
