# Hands-on workshop sequence: study an existing model, modify it, then self-direct a personal customization project

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 2 studies (2 design), `q1` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The interactive event runs a fixed sequence: introduction to OSP, sharing of leaders' customized models, introduction to EJS, hands-on editing of the spring mass system model, tips for adapting code, then participants "download a simulation that is personally motivating to them from OSP Digital Libraries" and work in collaborative groups of 2-3, uploading results to the NTNU Java Virtual Lab. This moves teachers from guided study to self-directed creation.

## Design Implications

### Context
#### Requirements
- One shot 3-hour or half-day session; BYOL laptops and wireless access; assistance provided during sessions
#### Constraints
- Designed as a one-shot (3 hour or half day) format

### Target Learners
- teachers in professional development workshops

### Target Learning Goals
- learning to customize open-source physics simulations
- self-directed and collaborative model design
