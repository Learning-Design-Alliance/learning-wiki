# Set up problems so learners must use working memory to store information, fostering transferable insight over rote solution

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
For algebraic transitivity, the article notes that lining up equations vertically and inviting rote application reduces working memory load but "will not necessarily produce the insight needed to set up a new problem and solve it." Instead, the problem could be set up more challengingly so the learner must use working memory to store the information, with the hope that successful solution yields insight applicable to other problems.

## Design Implications

### Context
#### Requirements
- The learner must have sufficient working memory capacity to hold the relevant equations or relations concurrently
#### Constraints
- If the individual does not have sufficient working memory capacity, a rote method of solution may be helpful for the time being

### Target Learners
- students learning algebra and mathematics

### Target Learning Goals
- transitive inference
- setting up new problems
- application of principles beyond the original problem
