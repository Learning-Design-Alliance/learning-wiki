# Train peer tutors to mastery on the exact skill checklist before they teach, using the same Peyton's-method module as the trainees will receive

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article's peer tutor preparation involved selecting six phase 2 MBBS students with willingness and good communicative skills, training them individually with the same study module using Peyton's 4-step approach, then assessing them with the OSCE checklist where "They should score 15/15 on the checklist which was the maximum possible score to be selected as peer tutors." Faculty trainers were also trained via Peyton's method with the same checklist for uniformity. This mastery gate ensured peer tutors taught techniques they had demonstrably perfected.

## Design Implications

### Context
#### Requirements
- Peer tutors must achieve the maximum checklist score (15/15) on the OSCE proficiency assessment before selection
#### Constraints
- Both instructors and students volunteered, so highly motivated students may be overrepresented, introducing selection bias that limits generalization

### Target Learners
- Phase 2 MBBS students selected as peer tutors

### Target Learning Goals
- Basic suturing techniques taught via Peyton's four-step method
