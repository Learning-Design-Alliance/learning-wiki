# Design authentic tasks following Mishan's six guidelines for task authenticity

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article adopts Mishan's (2005) six guidelines for designing authentic tasks that emulate natural authentic language use: tasks should "Reflect the original communicative purpose of the text", be appropriate to the text, elicit response to and engagement with the text, approximate real-life tasks, activate learners' existing knowledge of the target language and culture, and involve purposeful communication between learners. The study applied these in designing the Tourism in Neiva and Pen-pals projects.

## Design Implications

### Context
#### Requirements
- Tasks based on authentic texts must reflect the original communicative purpose of the text
- Tasks must involve purposeful communication between learners
#### Constraints
- Brown and Menasche's controversial view that there is probably no such thing as real task authenticity since classrooms are artificial is noted in the theoretical framework

### Target Learners
- Foreign language learners in classroom contexts with scarce exposure to the target language

### Target Learning Goals
- Meaningful and purposeful target language use
- Real-world communicative behavior rehearsal
