# Redesign the entanglement mini-tutorial so students derive a process for determining entanglement from the definition rather than memorizing a result

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The authors observed that students who had developed an algebraic method for deciding whether a two-qubit state is entangled had incorrectly memorized its result and could not regenerate the method. They therefore recommend redesigning the entanglement mini-tutorial so that students "focus on understanding the development of the process and not just the process result," using the definition of entanglement to devise the determination process themselves.

## Design Implications

### Context
#### Requirements
- Class or tutorial time in which students are asked to come up with a method for determining if a two-qubit state is entangled or not
#### Constraints
- Applied to the entanglement mini-tutorial in this QC course; the same memorization difficulty was observed in both the F21 class problems and the F23 mini-tutorial

### Target Learners
- undergraduate students in an introductory quantum computing course

### Target Learning Goals
- determine whether a given two-qubit state is entangled by applying the definition of entanglement
