# Repeating Key Points in Different Ways

## Description
Repeating key points in different ways means restating core content through varied representations — paraphrase, concrete examples, visuals, gestures, or analogies — rather than verbatim repetition. Each restatement encodes the idea from a new angle, building redundant retrieval routes while giving learners who process slowly a second or third pass at the material.

## Design Implications

Varied repetition works because it exploits dual coding and elaboration: presenting the same idea in verbal and visual form creates two memory codes, and paraphrase forces learners to abstract the invariant meaning across surface forms [Media combinations affect recall and retention.](../claims/media-combinations-affect-recall-and-retention.md) [+M]. Verbatim repetition, by contrast, adds little once the words are understood and can invite shallow word-level processing. Spacing the repetitions across a lesson or across days outperforms massing them together [Spaced repetition improves retention.](../claims/spaced-repetition-improves-retention.md) [+S].

### Context
#### Requirements
- A small set of genuinely key points — repetition multiplies whatever is repeated, so the target ideas must be selected first ([Chunking](../principles/chunking.md))
- At least two distinct representations per key point (e.g., verbal restatement plus a diagram or worked example)
- A plan for *when* repetitions occur: opening preview, mid-lesson check, and closing summary, then spaced review in later sessions

#### Constraints
- Verbatim repetition of an already-understood point wastes time and can reduce attention [-M] — learners disengage from what they perceive as redundant
- Repeating too many points dilutes the effect; repetition of everything is repetition of nothing
- Adding a second modality does not help if it duplicates rather than complements — redundant on-screen text narrated aloud can impair learning compared with narration plus a relevant graphic [Media combinations affect recall and retention.](../claims/media-combinations-affect-recall-and-retention.md) [~S]
- Repetition within a single massed block produces short-lived gains; without spacing, retention decays quickly [Spaced repetition improves retention.](../claims/spaced-repetition-improves-retention.md) [-S]

#### Implementation Variability
- **Within-lesson:** preview → restate with example → student paraphrase → closing summary
- **Across lessons:** brief retrieval of the key point at the start of subsequent sessions ([Spaced repetition](../claims/spaced-repetition-improves-retention.md))
- **Across learners:** students generate their own restatements or examples ([Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M]), shifting repetition from teacher-provided to learner-generated

### Target Learners
- Learners with processing speed or working memory challenges who benefit from a second, differently-coded pass at content
- Novices, who lack the prior knowledge to extract the key point on first exposure [Chunking reduces working memory load.](../claims/chunking-reduces-working-memory-load.md) [+M]
- Less valuable for experts, who extract the point immediately and find repetition redundant (expertise reversal)

### Target Learning Goals
- Retention of core concepts and vocabulary
- Conceptual understanding, when repetitions use contrasting examples or analogies
- Transfer, when varied restatements help learners abstract the deep structure across surface forms

### Instructions
1. Identify the 2–4 key points of the lesson and write a one-sentence statement of each ([Clear Structure](../principles/clear-structure-presentation.md)).
2. Open with a preview of the key points ([Advance Organizers](../elements/advance-organizers.md)).
3. During instruction, restate each key point at least twice in different forms: a paraphrase, a concrete example, or an analogy ([Analogies](../elements/analogies.md)).
4. Pair verbal statements with a supporting visual so the idea is dual-coded ([Chunking](../principles/chunking.md)).
5. Ask learners to restate the point in their own words or generate their own example ([Practice](../elements/practice.md)) — learner-generated repetition beats teacher-provided repetition [Self-explanation improves conceptual understanding.](../claims/self-explanation-improves-conceptual-understanding.md) [+M].
6. Close by revisiting the key points, then schedule brief spaced reviews in later sessions [Spaced repetition improves retention.](../claims/spaced-repetition-improves-retention.md) [+S].

## Related Strategies
- [Chunking](../principles/chunking.md) — repetition only works on a small, well-chosen set of points

- [Spaced Repetition](../claims/spaced-repetition-improves-retention.md) — the scheduling principle that determines whether repetition sticks

## Examples
- **Explicit Direct Instruction lessons** (e.g., DataWORKS EDI) structure every lesson with a "concept development" phase in which the key concept is stated, restated with a non-linguistic representation, and checked through whole-class choral response and individual whiteboard checks.
- **Khan Academy** (https://www.khanacademy.org) videos restate each step of a procedure verbally while writing it, then the accompanying exercise repeats the same concept across multiple problem variants.
- **Language teaching recasting:** a teacher repeats a learner's utterance in corrected, expanded form — the same meaning delivered in a slightly different structure — a core technique in communicative and immersion classrooms.
