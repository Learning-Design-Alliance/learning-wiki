# Reconsider assigned problem-set size and stop collecting problem solutions

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Based on students performing comparably while completing only a small number of reported out-of-class problems each week, the article recommends that 'instructors may wish to reconsider the size of their assigned problem sets'. It further suggests that moving away from collecting problem solutions, which did not degrade performance, is a route for instructors who want to avoid plagiarism issues in introductory courses.

## Design Implications

### Context
#### Requirements
- A learner-controlled homework system with a suggested problem pool must replace the fixed assigned set
#### Constraints
- The recommendation rests on a single modified section compared with prior years, and the article reports most students did not engage in reflection

### Target Learners
- undergraduate introductory physics students

### Target Learning Goals
- out-of-class problem-solving practice
- academic integrity in homework

## Claims

- [Final exam performance in the learner-controlled section did not differ statistically significantly from prior sections that used required weekly problem sets.](../claims/learner-controlled-homework-comparable-exam-performance.md) [+W]
