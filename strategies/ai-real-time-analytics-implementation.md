# Use AI-driven real-time analytics during implementation to synthesize multi-level data and support timely instructional adjustment

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In RIGID's implementation phase, micro-, meso-, and macro-level considerations interact in real time, and AI supports this by synthesizing data and providing real-time analyses to different stakeholders. The article states that "AI can support this multi-level perspective by synthesizing data and providing real-time analyses to different stakeholders, enabling instructors to make timely adjustments during instruction." This reframes implementation as research-integrated practice rather than mere delivery.

## Design Implications

### Context
#### Requirements
- Learning platforms and institutional systems that generate data during instruction
- Technical and organizational capacity for real-time analytics
#### Constraints
- Making sense of large volumes of instructional data in real time remains difficult, posing technical and organizational challenges
