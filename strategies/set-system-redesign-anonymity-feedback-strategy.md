# Redesign medical-school SET systems for trustworthy anonymity, timely digital feedback, adequate evaluation time, and student participation in indicator development

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The article recommends concrete system-level changes to reduce bias: the conclusion calls for "establishing a digital evaluation system that ensures anonymity and timely feedback." Management should "ensure the anonymity of the evaluation process and the confidentiality of evaluation data, enhancing the transparency of the evaluation work," clearly state how results are used, increase students' trust and understanding of evaluations, allocate more time for evaluations (with post-exam timing suggested by participants), and involve student representatives in developing evaluation indicators so they align with actual classroom situations. Real-time data analysis tools are suggested to give students feedback and generate teaching-improvement suggestions.

## Design Implications

#### Requirements
