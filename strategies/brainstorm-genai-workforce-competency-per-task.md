# Brainstorm an emerging GenAI workforce competency for every task in the inventory

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
For each task in the inventory, the instructor generates the GenAI-related capability the task could develop: "The instructor brainstorms an emerging GenAI workforce competency for every task." This step connects routine course tasks to workforce-relevant AI skills, giving the later priority determination a competency candidate for every task rather than only for selected ones.
