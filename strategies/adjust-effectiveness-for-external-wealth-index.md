# Adjust school-effectiveness comparisons for territorial wealth using an external provincial index such as Gross Value Added

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
When evaluating school or class effectiveness in a system with marked territorial differences in wealth, the article recommends adjusting for area wealth with an external measure rather than principals' subjective judgements, which it calls "of little value due to the subjective nature of the judgement". It uses per-capita Gross Value Added at province level, modelled as a linear spline with a knot at the national average, and finds GVA "effectively replaced the dummy variables for the geographical areas, yielding a parsimonious and more interpretable model".

## Design Implications

### Context
#### Requirements
- An external wealth index available at the finest nation-wide geographical level (province here); recognition that it neglects within-province heterogeneity
#### Constraints
- The wealth-achievement relationship held only for provinces below the national average, so the spline slope above the average was constrained to zero

### Target Learners
- fourth-grade primary school students

### Target Learning Goals
- fair evaluation of school effectiveness
- identifying anomalous classes and territorial patterns
