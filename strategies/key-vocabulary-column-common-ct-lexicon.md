# Add a grade-by-grade Key Vocabulary column to give teachers a common CT lexicon and progress marker

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
In year two, when revisiting the pathway document, the district "opted to add a “Key Vocabulary” column for each grade level, formally identifying the key terminology associated with CT (and CS) starting in Pre-K all the way through high school." The report frames this as offering teachers a common lexicon and a way to mark progress, complemented by student exit tickets tied to the five competencies.

## Design Implications

### Context
#### Requirements
- A revised pathway document structure that can carry a per-grade vocabulary column
- Consistent CT/CS terminology defined in non-jargony language usable across K-12 contexts

- 

### Target Learners
- K-12 teachers and, via exit tickets, students from Pre-K through high school

### Target Learning Goals
- Shared computational thinking and computer science terminology across grade levels
