# Report HIL data extraction use explicitly, naming software, LLM, and extent of human validation

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends that researchers using human-in-the-loop LLM data extraction disclose its use in manuscripts. At minimum, authors should state "what software was used for HIL data extraction, what LLM was used, and to what extent humans validated the data extracted." This satisfies journal reporting requirements for generative AI use and makes clear that humans validated every data point extracted for analysis.

## Design Implications

### Context
#### Requirements
- Manuscripts must state the software used, the LLM used, and the extent of human validation
#### Constraints
- Many journals and professional organizations have strict reporting requirements for generative AI use

### Target Learners
- Education researchers publishing systematic reviews

### Target Learning Goals
- Transparent reporting of AI-assisted research synthesis methods
