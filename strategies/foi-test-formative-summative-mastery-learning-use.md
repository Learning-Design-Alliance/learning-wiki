# Use the validated VR simulator test for both formative feedback and summative certification within a mastery learning training program

> **Strategy** · [All strategies](index.md)
> **Evidence** · 7 claims (6 for, 1 mixed) · 1 study (1 design), `q3` · 0 of 1 report an effect size · 7 claims rest on one study

## Description
The article recommends using the test for both formative (feedback) and summative (certification) assessment. As stated: 'The test can be used for both formative (i.e., feedback) and summative (i.e., certification) assessment and thereby support a mastery learning simulation-based training program for FOI.' Six cases suffice for formative use and 10–12 cases for summative certification.

## Design Implications

### Context
#### Requirements
- The validated test with its established pass/fail standard
#### Constraints
- Developing a test with sufficient validity evidence is only the first step to FOI training and full mastery of the technique

### Target Learners
- anesthesiology residents
- anesthesiologists learning FOI

### Target Learning Goals
- flexible optical intubation competence
