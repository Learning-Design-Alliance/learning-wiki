# Make family caregivers explicit in existing nursing content rather than adding new material

## Description
The article recommends that integrating family caregiving competencies need not compete for curricular time because "Family caregivers are already present in nearly every healthcare context and setting." Educators should audit existing courses and curricula for gaps in learning outcomes and highlight where family caregiver competencies can be seamlessly integrated, using scaffolding and backward design for vertical and horizontal integration across courses.
