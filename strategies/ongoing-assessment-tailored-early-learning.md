# Use ongoing assessments to tailor early-childhood learning experiences

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The program emphasizes data-informed instruction: teachers use ongoing assessments to tailor learning experiences to individual children rather than delivering a fixed sequence. In Fueling Brains this operates alongside play-based executive function instruction, so assessment information informs how guided and open-ended play activities are arranged for each child.
