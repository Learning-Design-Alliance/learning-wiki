# Adapt existing professional research tools for education instead of building separate educational software

> **Strategy** · [All strategies](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The AIDA team's approach was to take widely used professional tools and modify them for learners: "In a first step, we chose existing professional software tools for the retrieval, visualization and analysis of VO data in order to adapt them for educational and outreach purposes." Aladin, developed by CDS, was transformed into a more comprehensible version because in its professional form it was too complicated and contained too many specialized functions; the sky browser Stellarium was likewise used and modified. This keeps the look and feel of professional tools while making them usable by non-professionals.

## Design Implications

### Context
#### Requirements
- Existing professional tools that access the data resource must be identified and modifiable
#### Constraints
- Professional versions may be too complicated and contain too many specialized functions for non-professional users, requiring a more comprehensible version

### Target Learners
- students
- teachers
- amateur astronomers

### Target Learning Goals
- accessing and visualizing real astronomical data
