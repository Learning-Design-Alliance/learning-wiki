# Shift perioperative code status conversations to an anesthesiologist-led perioperative surgical home

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The article proposes relocating perioperative code conversations to an anesthesiologist-led perioperative surgical home as a remedy for inadequate code status discussions. It reports that "Shifting the setting of perioperative code conversations to an anesthesiologists led perioperative surgical home has been proposed as a possible remedy for this clinical dilemma," potentially improving care coordination through established relationships, decreased time pressures, and room for nuance such as exceptions to a standing DNR order. It is a proposed remedy, not a tested intervention in this study.
