# During initial evaluation, scrutinize what data is collected, how it is stored and shared, and whether it is extraneous

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The framework's data-privacy criterion asks evaluators to investigate "what specific data is being collected from users, how safely that data is stored, and what is done with that data." The stated goal is that "there is no extraneous data being collected, data is surviving its intended purpose, and that data is not retained beyond its useful life." Questions cover storage, ownership after graduation, sharing with police, and accessible communication about data practices.

## Design Implications
