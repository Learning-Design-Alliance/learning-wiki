# Impart fundamental IT skills before leading learners into m-learning

> **Strategy** · [All strategies](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The authors recommend that educationalists consciously equip learners with a basic level of IT expertise before introducing mobile learning, since many actions performed on a mobile device are also carried out on an IT device. They state that "educationalists must be conscious to facilitate imparting the learners with a fundamental amount of IT expertise before the learners are led into m-learning," suggesting practice of tasks such as exchanging mails and surfing the web on an IT device first.

## Design Implications

### Context
#### Requirements
- Learners should first find executing common tasks on an IT device easy and relaxing before moving to a mobile setting.
#### Constraints
- The recommendation rests on a cross-sectional observational study in the Indian tertiary context.

### Target Learners
- tertiary students with low IT skills entering m-learning

### Target Learning Goals
- readiness to accept and use mobile learning
