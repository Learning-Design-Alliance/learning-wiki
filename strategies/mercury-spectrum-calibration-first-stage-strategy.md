# Градуировка спектрального прибора по спектру ртути как обязательный первый этап работы

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
Все три лабораторные работы начинаются с градуировки монохроматора по идеализированному линейчатому спектру атомарной ртути: студент сопоставляет каждую спектральную линию с отсчётом по шкале барабана и аппроксимирует результаты полиномом второго порядка методом наименьших квадратов. После этого по отсчёту барабана определяется длина волны неизвестной линии — «Монохроматор становится измерительным прибором».

## Design Implications

### Context
#### Requirements
- Таблица эталонных длин волн спектральных линий ртути
- Аппроксимация полиномом второго порядка
#### Constraints
- Спектр идеализирован: «убраны частные особенности, всегда присущие конкретному эксперименту»

### Target Learners
- студенты инженерных специальностей технического университета

### Target Learning Goals
- градуировка измерительного прибора
- определение длин волн спектральных линий
