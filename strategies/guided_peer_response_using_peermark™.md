# Guided Peer Response using PeerMark™

## Description
Guided peer response using Turnitin PeerMark™ involves instructors pre-setting specific questions for learners to answer when providing feedback to their peers. This method provides structured prompts that guide the feedback process, making it easier to supervise and collate learner responses. It focuses on assessment by ensuring feedback addresses specific criteria.

## Design Implications

### Context
#### Requirements
- Requires access to Turnitin PeerMark™ and clear instructions for learners on how to provide guided feedback.
#### Constraints
- May limit the spontaneity and creativity of feedback due to structured prompts. Requires instructors to invest time in creating effective questions.
