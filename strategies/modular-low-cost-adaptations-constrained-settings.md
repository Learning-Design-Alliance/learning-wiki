# Design high-investment surgical training pathways as modular programs so low-cost metric-based simulations, virtual/augmented reality, and remote-learning alternatives can substitute when resources are constrained

> **Strategy** · [All strategies](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (3 review), `q2`–`q3` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
To address cost, infrastructure, and accessibility barriers, the authors recommend building training pathways modularly so cheaper components can replace high-fidelity ones in resource-limited settings. They state that "the ASCEND pathway was designed to be modular, so that low-cost metric-based simulations, virtual/augmented reality, and remote-learning alternatives can be incorporated when resources are constrained", and report that several such initiatives are currently being piloted to ensure equitable access and global feasibility.

## Design Implications

### Context
#### Requirements
- A modular pathway structure that allows alternative simulation and remote-learning components to be swapped in
#### Constraints
- Access to high-fidelity simulators, porcine models, and robotic platforms entails substantial investment, which may limit availability in low- and middle-income countries

### Target Learners
- trainees in low- and middle-income countries and other resource-constrained settings

### Target Learning Goals
- robotic surgical skills acquisition where high-fidelity infrastructure is unavailable
