# Post-measurement data analysis and reflection: graphing in Excel, identifying correlations, and student-proposed improvements

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
After data collection, students use MS Excel to graph physical quantities over time and visually identify changes and correlations between variables, such as a sudden pressure change during an atmospheric front or humidity changes when temperature rises or falls. The teacher then creates space for final reflection, asking questions that prompt deeper thinking. "Students can suggest ways to improve the weather station's technical capabilities, such as adding additional sensors (rain gauge, anemometer, CO₂ sensor), expanding memory options with an SD card, or ensuring autonomous operation without the need for a computer."

### Target Learning Goals
