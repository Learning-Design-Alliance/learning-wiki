# Character Profile Creation

## Description
Students create character profiles to help them form a deeper understanding of a book’s characters. This can involve creating lists of adjectives, illustrating characters, reflecting on character motivations, and describing how characters make them feel.

## Design Implications

### Context
#### Requirements
- Materials for creating character profiles, such as paper, pencils, and art supplies, and a list of profiling prompts.
#### Constraints
- Requires structured activities to be effective. Some students may struggle with character analysis. Requires careful planning and management.
