Plan user administration and curriculum fit carefully for educational games¶

Strategy · All strategies
Evidence · no claims cited

Description¶

The authors highlight that user administration needs to be thought through very carefully, as registering and maintaining user accounts was labor-intensive. They also argue that a game should be complementary to activities at school, not supplementary, and recommend building a game with a narrower focus in terms of targeted end-users and the point at which it is to be used if curriculum fit is a priority.

Design Implications¶

Context¶

Requirements¶

  • An efficient process for user administration with clearly assigned responsibility

Constraints¶

  • Developing a game for multiple grades creates challenges for curriculum fit

Target Learners¶

  • Elementary students

Target Learning Goals¶

  • Math learning

Related Strategies¶

  • Involve end-users and teachers early in educational game development
  • Mitigate authoring tool investment risk with early-and-often user feedback and a theoretical understanding of users and tasks
