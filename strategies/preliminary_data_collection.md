# Preliminary Data Collection

## Description
Preliminary data collection involves gathering contextual data to gain a deeper understanding of the local settings where a problem exists. This includes collecting both quantitative and qualitative data to paint a comprehensive picture of the issue. Quantitative data can provide statistics and hard numbers, while qualitative data offers insights into the lived experiences and perspectives of individuals affected by the problem.

## Design Implications

### Context
#### Requirements
- Access to data sources, tools for data collection (e.g., surveys, observation protocols), and skills for data analysis.
#### Constraints
- Data collection can be time-consuming and may require navigating gatekeepers or obtaining permission to access data. Ensuring the quality and reliability of data is crucial.
