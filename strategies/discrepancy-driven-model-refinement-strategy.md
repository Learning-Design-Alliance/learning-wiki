# Use the discrepancy between estimated and accepted values as a teaching opportunity for approximations, limiting cases, and model refinement

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The article recommends exploiting the gap between the photograph-based estimate and the accepted Earth radius to teach iterative model refinement. It reports that the activity "develops the ability to make and account for approximations during problem-solving, compare alternative approaches, evaluate uncertainties, and study limiting cases as a method for verifying the relevance of results". Students thus learn that a physically meaningful result can come from simple observations even when imprecise.

## Design Implications

### Context
#### Requirements
- An estimation activity whose result can be compared with an externally accepted value
#### Constraints
- All identified uncertainty sources bias the result towards overestimate, so the comparison teaches bounds rather than precise measurement

### Target Learners
- upper-secondary physics students

### Target Learning Goals
- model construction and refinement
- uncertainty evaluation
- verification via limiting cases
