# Add interactive features — quizzes, gamified modules, and simulated clinical scenarios — to future versions of skills-training software

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors' forward-looking design recommendation is that "Future versions of the software could benefit from more interactive features, such as quizzes, gamified learning modules, and simulated clinical scenarios that enable students to apply their knowledge in a virtual environment." This is a stated development direction for the evaluated app, not a tested manipulation in the present study.

## Design Implications

### Context
#### Requirements
- Software development capacity to add interactive modules to the existing Android app
#### Constraints
- Not evaluated in the present study; the current app version lacked these features

### Target Learners
- Nursing students using clinical-skills training software

### Target Learning Goals
- Applying clinical knowledge in virtual environments
