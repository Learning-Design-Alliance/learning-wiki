# Board data dashboards for governance-level progress monitoring

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
A governance strategy in which the charter board receives monthly data dashboards aligned to the accountability framework, designed to identify priorities, set goals and milestones, and track progress. Before turnaround the board received varying data and outcomes went unchecked; TenSquare "introduced data dashboards, designed to identify priorities, set and review goals and frequent milestones, and track progress," and coached the board to ask probing questions. Dashboards grew in complexity as board data literacy increased, covering talent, teaching and learning, and finance by 2017–18.
