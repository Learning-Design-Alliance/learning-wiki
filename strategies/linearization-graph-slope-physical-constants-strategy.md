# Определение физических постоянных путём линеаризации спектральных данных

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
В лабораторных работах студенты строят график функции 1/λ от 1/n²: для серии Бальмера угловой коэффициент прямой равен постоянной Ридберга, для серии Пикеринга однократно ионизированного гелия — позволяет определить массу атома гелия и число нуклонов в ядре. Коэффициент оценивается «непосредственно по графику, разделив приращение функции на приращение аргумента» либо аппроксимационным уравнением.

## Design Implications

### Context
#### Requirements
- Измеренные длины волн спектральных линий и сопоставление их с главными квантовыми числами
#### Constraints
- Если теория Бора верна, график должен иметь вид прямой

### Target Learners
- студенты университетского практикума по общей физике

### Target Learning Goals
- экспериментальная проверка теории атома Бора
- расчёт постоянной Ридберга и отношения масс протона и электрона
