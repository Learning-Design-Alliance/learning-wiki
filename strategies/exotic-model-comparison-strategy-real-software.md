# Teach parameter dependence by having students compute spectra for deliberately ruled-out exotic models with real scientific software rather than parameter-slider applets

> **Strategy** · [All strategies](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 associational, 1 design), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
This teaching strategy has students compute CMB and matter power spectra themselves with a research-grade Boltzmann code for models chosen "purely for the sake of didactic usefulness and not because they are supposed to describe reality", comparing each against ΛCDM. By varying one ingredient at a time (no CDM, no Λ, more baryons) students directly attribute spectral changes to baryons, CDM and Λ. The author contrasts this with web applets, which "seems like a 'black box', and does nothing in teaching students to use real scientific software which is standard in the field".

## Design Implications

### Context
#### Requirements
- Limited lecture time or a diverse student background is sufficient, since the approach works well in those cases; students need access to the open-source code and enough time to compile, run and plot outputs
#### Constraints
- Parameter degeneracies made it necessary to focus on certain changes rather than sample an exhaustive number of illustrative models; the exotic models studied are firmly ruled out by observations

### Target Learners
- graduate cosmology students
- undergraduate physics students

### Target Learning Goals
- interpreting CMB temperature and matter power spectra
- understanding why ΛCDM is prevalent in interpreting modern cosmological data
