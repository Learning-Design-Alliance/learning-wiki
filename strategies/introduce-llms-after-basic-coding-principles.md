# Introduce LLM tools at later stages of programming education, after students have acquired basic coding principles

> **Strategy** · [All strategies](index.md)
> **Evidence** · no claims cited

## Description
The authors advocate a balanced approach to integrating LLMs into educational curriculums: "By introducing these tools at later stages of programming education, after students have acquired basic coding principles", so students gain both productivity benefits and problem-solving skills developed through traditional methods. The strategy responds to their finding that premature LLM use can diminish essential problem-solving experiences.

## Design Implications

### Context
#### Requirements
- Students must first acquire basic coding principles through traditional learning methods before LLM introduction
#### Constraints
- The article's evidence base is a correlational study with thirty-two participants over ten weeks, which the authors state may not generalize across all programming education contexts

### Target Learners
- undergraduate programming students

### Target Learning Goals
- independent problem-solving skills
- foundational programming competencies in web development
