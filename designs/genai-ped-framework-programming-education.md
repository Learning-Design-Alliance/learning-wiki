# GenAI-Ped framework for integrating GenAI in programming education

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The GenAI-Ped framework is a structured four-phase approach to guide GenAI integration in programming education while preserving foundational programming principles and higher-order thinking skills. The article states it is designed "to guide GenAI integration in programming education and ensure that foundational programming principles and higher-order thinking skills are preserved and enhanced." It adapts a self-regulated learning framework, Bloom's taxonomy, needs analysis, an AI-Lab prompt-engineering framework, and Universal Design for Learning principles across four phases: learner needs analysis and objective development, GenAI tool analysis, teaching/assessment/prompt engineering methods, and lesson-level GenAI integration.
