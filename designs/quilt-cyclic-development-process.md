# Cyclic development process for research-based QuILTs

## Description
The article describes a four-stage iterative development cycle for its tutorial: a preliminary version built from theoretical task analysis and difficulty research, individual implementation with expert faculty feedback, assessment of learning impact and remaining difficulties, and refinement. The development 'went through a cyclic interactive process' in which each interviewed version was modified based on student feedback before in-class administration.
