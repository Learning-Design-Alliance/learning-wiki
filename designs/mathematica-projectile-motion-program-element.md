# Mathematica projectile-motion program with DSolve worksheets and trajectory plots

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A set of Mathematica worksheets the authors used as the experimental instructional treatment. The worksheets solve the equations of motion symbolically with DSolve, substitute parameter values such as x1=350 and g=9.8, and plot trajectories for varying flight times and launch angles. The article states the program "can be experimented at home or at university", allowing students to learn and revise projectile motion at any time.
