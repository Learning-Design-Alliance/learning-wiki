# A three-phase hierarchical ISM model structures blended MOOC implementation into planning, implementation, and evaluation phases

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article develops a blended MOOC implementation model using Interpretive Structural Modeling (ISM) with expert input from 15 participants. The model organizes 20 accepted sub-indicators into three hierarchical phases: planning (learner analysis, objectives, materials), implementation (technology access, teaching methods, participation), and evaluation (assessment, feedback, final examinations). The hierarchical structure was derived from reachability matrix partitioning, assigning each sub-indicator a level from 1 (final examinations) to 13 (learners' backgrounds).
