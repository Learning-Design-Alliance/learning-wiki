# Integrated framework combining Bayesian cognitive diagnosis, knowledge space theory, and cognitive load theory for personalized path optimization

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article proposes and validates "a personalized learning path optimization framework that integrates Bayesian cognitive diagnosis, knowledge space theory, and cognitive load theory." Bayesian DINA estimation supplies attribute mastery probabilities on sparse data; knowledge space theory supplies prerequisite ordering so that "prerequisite attributes must be learned before target attributes"; and cognitive load theory supplies the psychological mechanism, since prerequisite-respecting sequences are held to reduce extraneous load. The framework links diagnosis, sequencing, and mediation testing in one pipeline.

## Design Implications

### Context
#### Requirements
- A Q-matrix mapping items to cognitive attributes and a specified attribute prerequisite hierarchy
- Sufficient response data for MCMC estimation of the Bayesian DINA model
#### Constraints
- The attribute hierarchy is a theory-driven specification based on Bloom's taxonomy rather than an official structure provided by EdNet
- The framework was validated on foundational probability content with undergraduates and on EdNet KT1 listening/reading skill tags interpreted as general cognitive attributes

### Target Learners
- undergraduate students learning foundational probability theory
- online platform learners in large-scale educational datasets

### Learning Goals
- mastery of prerequisite-ordered cognitive attributes such as foundation concepts, rule application, logical reasoning, procedural knowledge, and analytical thinking
