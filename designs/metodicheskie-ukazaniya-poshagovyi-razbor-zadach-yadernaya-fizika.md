# Пошаговый разбор задач с указаниями, выводом формул и численными ответами как формат методических указаний

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Пособие построено как сборник задач, каждая из которых сопровождается разделом «Указание», пошаговой выкладкой с нумерованными уравнениями и завершается блоком «Ответ». Автор формулирует цель так: «Основная цель сборника – выработать у студентов навыки научно-исследовательского подхода к решению практических задач по ядерной физике». Формат объединяет справочные сведения, теорию и эталонные решения.

## Design Implications

### Context
#### Requirements
- Задачи должны сопровождаться указанием с необходимыми формулами и обозначениями, а решение — пошаговой выкладкой с эталонным ответом
#### Constraints
- Составлено для практических занятий к курсу лекций «Ядерная физика» для студентов 4-х курсов физико-механического факультета по специальностям «Техническая физика» и «Медицинская ядерная физика»

### Target Learners
- студенты 4-го курса физико-механического факультета

### Learning Goals
- навыки научно-исследовательского подхода к решению практических задач по ядерной физике
