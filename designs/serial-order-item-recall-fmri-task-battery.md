# Serial order versus item recall short-term memory task battery with fMRI

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A task battery contrasting short-term memory for serial order with short-term memory for item information, administered behaviorally and inside the fMRI scanner to adults with a history of developmental dyscalculia and matched controls. The design allows the article to report that participants "were impaired for serial order recall but not for item recall", and to localize serial order processing to left intraparietal cortex.

## Design Implications

### Context
#### Requirements
- Tasks must separately probe serial order and item information to yield the dissociation
#### Constraints
- Administered to adults with a history of developmental dyscalculia and controls; not validated here for other groups

### Target Learners
- adults with a history of developmental dyscalculia
- matched control adults

### Learning Goals
- measuring serial order working memory
- measuring item short-term memory
