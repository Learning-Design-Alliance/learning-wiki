# Graduate coursework should be reformed and the advisor search explicitly integrated into the first-year curriculum

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors recommend reforming first-year graduate coursework so it no longer competes with the advisor search, and explicitly integrating the search into the curriculum, for example by revising course content to highlight available departmental research. They argue departments must assure "coursework is not in tension with students’ ability to ﬁnd a group," since the existing structure signals that classes should be the top priority.

## Design Implications

### Context
