# Cognitively demanding variant of the sequential visual isometric pinch task (SVIPT) with three sequences

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A computer-based force pinch task in which participants squeeze a transducer to move a cursor to five coloured targets in a specified sequence, with target orders pseudorandomly shuffled among 3 different orders. The article describes it as "a more cognitively challenging version of the SVIPT that requires the trial-to-trial recall, planning, execution, and learning of multiple sequences," engaging both explicit sequence learning and implicit force-to-cursor mapping. Skill was scored via a speed-accuracy trade-off function.

## Design Implications

### Context
#### Requirements
- A force transducer, on-screen cursor display, and per-block skill feedback to encourage improvement
#### Constraints
- Force target set at 45% of each participant's maximum voluntary pinch contraction; retention tested same-day after a 6-hour delay without sleep

### Target Learners
- healthy older adults (55–75 years)

### Learning Goals
- explicit and implicit motor sequence learning
