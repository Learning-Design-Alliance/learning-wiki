# Station types in blended learning rotation models: flip, practice, independent, teacher support, feedback, and assessment stations

> **Design** · [All designs](index.md)

## Description
The article's Table 2 provides a pedagogical description and classification of stations frequently used in BL rotation models, where a station is a learning space. The listed station types are flip stations (self-paced learning, multimedia review, mini-lectures), practice stations (active learning, inquiry-based activities, scaffolding), independent stations (individual work, reviews), teacher support stations (clarification, tutoring, feedback), feedback stations (peer and lesson feedback), and assessment stations (quizzes, tests, cumulative knowledge-based activities), each paired with its educational means.
