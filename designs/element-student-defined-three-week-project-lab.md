# Student-defined three-week remote project lab with three format options and expanded creativity rubrics

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A remote lab structured as "a three-week long, student-deﬁned project" offering "three diﬀerent project options" — a web-applet virtual experiment, an at-home physics experiment using smart-device sensors, and an Algodoo scene — so all students could participate regardless of circumstances or tool access. Students received example projects and detailed rubrics; new rubrics were "inspired by the ISLE rubrics" but "expanded to include topics such as creativity".

## Design Implications

### Context
#### Requirements
- example projects and detailed rubrics describing exactly how projects would be graded
- weekly AI guidance, with a scheduled virtual meeting for each lab group in each of the three weeks
#### Constraints
- project content was restricted to material "covered that semester (E&M, optics, circuits, atomic physics, nuclear physics)"

### Target Learners
- introductory algebra-based physics students (non-majors) in remote instruction

### Learning Goals
- designing and executing an experiment
- analyzing data and answering a self-defined question
