# Six-tool starter set for state and district evidence-based improvement

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The guide offers "a starter set of six tools to support this work, with an emphasis on the process of selecting evidence-based interventions." The first two tools (SEA and LEA Inventory of Current Practice) guide examination of the whole improvement cycle; the middle two guide SEA and LEA approaches to advising lower levels on selecting interventions; and the last two, as the guide states, "support selection of evidence-based interventions." Tools are provided as Word documents so they can be modified to fit local needs and contexts, and each tool includes purpose, intended outcome, materials, participants, time, instructions, and facilitation guidance.

## Design Implications

### Context
#### Requirements
- Preparation should include building understanding of ESSA evidence guidance and the state's own policy context before using the tools
#### Constraints
- The guide is explicitly not comprehensive: it is a starting point, and tools 3-6 cover only the Select step of the cycle

### Target Learners
- SEA staff teams
- LEA/district leadership teams

### Learning Goals
- Building capacity for evidence-based decision-making and intervention selection
