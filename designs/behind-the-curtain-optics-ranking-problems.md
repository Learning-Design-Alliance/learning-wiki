# Hidden-element (behind the curtain) ranking problems for geometrical optics

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A reusable Physlet problem pattern in which students are given a source and one or more regions hidden from view, asked to determine what optical element is behind each curtain, and then rank the objects by focal length. Students can move and resize the sources, and different source types are used so that "students must utilize their understanding of each." The authors note the pattern "is easily modifiable, resulting in an almost limitless number of similar problems" tailored to a specific classroom.
