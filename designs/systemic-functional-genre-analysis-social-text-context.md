# Systemic-functional genre analysis: a social account of text and context grounding genre-based writing pedagogy

## Description
The article presents genre analysis as a framework in which linguistic choices are shaped by register, field and mode, and by Halliday's ideational, interpersonal and textual meta-functions. It states that "systemic functional genre analysis is a social one which considers not only the text but also the context in which the text is happened which leads into different language patterns". Social-based genres are characterized by goal-orientation, stages or phases, culturally-laden nature, fuzzy borders, macro genres and semiotic modes. The study uses these tenets to design its genre-based writing instruction.
