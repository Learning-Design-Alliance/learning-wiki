# DigiPlay: a public walk-up installation of open-source, glass-box multi-agent simulations

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
DigiPlay is a public learning environment in an indoor walkway at the University of Calgary, consisting of three 80" touch screens displaying open-source simulations of complex systems programmed in Processing. Visitors can modify emergent flocking patterns by adding boids via touch, or "make deeper changes to the way the individual boids interact by accessing the underlying code" by hitting the Escape key to reveal the code while simulations run. Posters explain the boid rules, and an on-site facilitator encourages visitors to hack the simulations.

## Design Implications

### Context
#### Requirements
- Open-source, glass-box simulation code; touch-sensitive screens; just-in-time on-screen instructions; posters explaining agent rules; an on-site facilitator with deep understanding of the underlying code
#### Constraints
- The current setup comprises simulations of complexity (flocking boids) designed in the Processing language

### Target Learners
- Walk-in public of all ages, from elementary-grade children to graduate students

### Learning Goals
- Understanding agent-level rules and emergent system-level behavior in complex systems
