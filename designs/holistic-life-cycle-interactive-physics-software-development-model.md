# Holistic Model of Life Cycle Interactive Physics Learning Software Development

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The authors' development model combining the ADDIE instructional design model (Analysis, Design, Development, Implementation, Evaluation) with rapid prototyping from software engineering methodology. The article states the "developed life-cycle model is more comprehensive as it incorporates the ADDIE model, prototyping, model ID, software interface, teaching and learning environment and learning objectives". Prototyping is inserted into the ADDIE development phase, and the process is described as cyclical and repetitive rather than strictly linear, with summative evaluation validating effectiveness after the product is created.

## Design Implications

### Context
#### Requirements
- Begins with the analysis phase, followed by design, development, implementation with formative assessment elements, then summative evaluation to validate effectiveness
#### Constraints
- The authors note that in multimedia software design the process is not as easy as the original ADDIE model, so it was developed integrated with multimedia instructional design principles

### Target Learners
- senior high school physics students

### Learning Goals
- development of effective interactive physics courseware
