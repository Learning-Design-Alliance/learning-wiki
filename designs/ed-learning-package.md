# Experimenting and Discussion (ED) learning package

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
ED is a learning package in which three physics sections of 85 students covered classical physics topics in an active-learning way using sequential task structures such as Predict-Observe-Explain and Observe-Explain-Predict-Test. Simple experiments treated phenomena for which students' alternative conceptions are well known: force and motion, pressure (hydrostatic, hydraulic, atmospheric, hydrodynamic), and heat, each across four sessions. The sequences activate existing knowledge and test it by comparing the predicted and the observed.
