# A table of nine pedagogical activities for teaching interpretability, each paired with an assessment method

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Table 1 of the article lays out pedagogically-sound activities mapping learning-science best practices to RDS interpretability practice, including replicating an existing study, reverse engineering a platform, diagnostic learning logs, problem recognition tasks, process analysis, peer review, before-after iteration, design and deploy, and creating a nutritional label for a machine learning platform. "Table 1 showcases several pedagogically-sound activities that map to best practices in the learning sciences and to RDS interpretability practices." Each activity is paired with an assessment method such as metrics evaluation, open coding, cognitive walkthroughs, or A/B testing.
