# Negotiated narrative control balancing narrative interest with character credibility and simulation realism

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Drama Manager influences the emerging fabula in three ways: character actions, character goals and simulation events, each through a negotiation mechanism. Triggered events may be rejected by the Simulation Engine if simulation rules would not hold; goal changes depend on characters' Personal Values; and suggested actions carry a narrative interest score confronted with the Agent Framework's credibility classification via "balanced combination of a set of thresholds".

## Design Implications

### Context
#### Requirements
- Representation of Personal Values so characters can decide the adoption of suggested goals
- An Agent Framework that classifies suggested actions by credibility
#### Constraints
- Narrative control should not constrain simulation realism or character believability
- The set of proposed actions may contain no acceptable action, leaving the character uninfluenced

### Target Learners
- players of emergent-narrative serious games

### Learning Goals
- experiencing dramatic points tied to competence use

### Claims
- No Acceptable Action No Influence [~W]
