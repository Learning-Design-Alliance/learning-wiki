# Anchor AI instruction in chemical scenarios and reuse consistent coding patterns to manage novice cognitive load

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The course integrates Python instruction directly with chemical examples rather than treating programming as a separate prerequisite, and anchors every topic in a chemical scenario students might encounter in their own research. Code scaffolds support novices: long snippets are broken into smaller chunks with intermediate outputs, and consistent coding templates are reused across notebooks. The article states "This repetition built familiarity and reduced cognitive load when new concepts were introduced so that students could focus on the concept rather than getting lost in new syntax."
