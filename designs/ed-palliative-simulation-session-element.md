# Simulation-based palliative care educational session with standardized family member and facilitated debriefing for EM residents

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A 1-hour simulation session embedded in an emergency medicine residency program, run eight times for groups of 5–6 residents with a high-fidelity mannequin and a standardized participant portraying the patient's daughter. One randomly chosen resident managed the case while others observed via live streaming video, followed by "an approximate 45-min shared debriefing session" facilitated by an EM simulation faculty lead-debriefer and a resident associate debriefer. Predetermined educational points included providing an honest prognosis, honoring patient wishes, straightforward empathetic communication, and building trust, with the EPEC Rapid Palliative Care Assessment tool highlighted in each feedback session.

## Design Implications

### Context
#### Requirements
- Facilitator dyads of simulation-trained EM faculty and a resident investigator were used to assure that all debriefings were uniform
#### Constraints
- The case was deliberately designed with an obvious end-of-life disease trajectory so learners would focus on palliative issues rather than emergent resuscitation and stabilization

### Target Learners
- emergency medicine residents (PGY 1–3)

### Learning Goals
- confidence in palliative care skills including prognostication discussions, decision-making capacity determination, and goals-of-care communication
