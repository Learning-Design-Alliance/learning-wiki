# Game jam resource kit: non-digital and digital materials, software, venue and devices for 4C-focused jams

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A concrete set of materials, tools and venue conditions the article identifies as necessary to organize a game jam aimed at 4C skill development. It includes non-digital brainstorming materials ("pencils, sticky notes, colored paper, dice, cards, cardboard, scissors, and glue"), laptops with software such as Scratch, GameMaker Studio, Adobe Photoshop, Google Drive tools and Unity, plus a venue with electricity, Internet connection, tables, an eating area and quiet resting areas.

## Design Implications

### Context
#### Requirements
- A venue with electricity, Internet connection and working tables
- Laptops with event software installed, plus extra devices in case participants' laptops fail
- Tutors and voluntary workers to support idea generation, materials and technical problems
#### Constraints
- Even paper-based teams should have computer and Internet access to check game mechanics and the event theme

### Target Learners
- adolescent students (12–16) participating in game jams

### Learning Goals
- collaborative video-game concept development and 4C skill practice
