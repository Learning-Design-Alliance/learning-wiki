# Excel and python computational classroom experiment on the Rindler observer

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A hands-on computational classroom experiment in which undergraduates use elementary algebra and simple codes in excel and python to explore the worldline of a Rindler observer. The article states: "we design a computational classroom experiment in excel and python." Students plot spacetime diagrams, apply Lorentz transformations, numerically differentiate positions to obtain velocity and acceleration, and graph proper time and time dilation, with code snippets printed in the paper.

## Design Implications

### Context
#### Requirements
- Students are assumed to already know spacetime diagrams and the Lorentz transformation before attempting the activity.
#### Constraints
- For illustration the calculations set c = 1 and the spacetime interval l0 = 0.5, per the article: "For the purpose of illustration, in our calculations, we takec = 1, the spacetime intervall0 = 0.5."
