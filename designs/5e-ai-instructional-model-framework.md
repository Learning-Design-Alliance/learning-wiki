# The 5E+AI instructional model: the 5E cycle as organizational framework with generative AI supporting content generation, simulation-based training, and feedback optimization

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The 5E+AI model uses the 5E instructional model (Engage, Explore, Explain, Elaborate, Evaluate) as the "organizational framework, with generative AI tools serving as assistive technologies covering three task types: content generation, simulation-based training, and feedback optimization." AI supports learning through "on-demand information retrieval, simulated practice partners, and automated personalized feedback at each phase of the 5E cycle." The model was implemented in a 12-week medical science communication course for clinical medicine undergraduates.

## Design Implications

### Context
#### Requirements
- Requires generative AI tools integrated as a core component across all five 5E phases, not used as a standalone tool
#### Constraints
- Evaluated in a single elective course at one institution with limited enrollment per semester

### Target Learners
- clinical medicine undergraduates

### Learning Goals
- science communication competence
- medical knowledge acquisition
- classroom participation
