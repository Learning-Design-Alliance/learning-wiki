# The X1-X2-X3 three-part response structure for AI-integrated assessment

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (1 for, 2 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A three-part response structure for assessments that permit web and GenAI use. X1 requires a sourced extract with evidence: "a concise extract from the sourced answer, source identification, timestamp, and a mandatory full-screen screenshot". X2 requires the student's own answer plus an account of how it differs from the sourced answer. X3 requires a brief reflection on what was learned and a bounded quality rating of the sourced answer with justification. The pattern was stabilized across four deployments and scored with an 18-point rubric mapped across the three fields.

## Design Implications

### Context
#### Requirements
- Mandatory full-screen readable screenshot showing the sourced answer, current question, and student response fields
- Word limits (100 words for X1a, 200 for X2, 100 for X3 in the practice exam) and a reusable rubric applied consistently across markers
#### Constraints
- The design required substantial teaching-team effort shifted into assessment design, evidence checking, and more interpretive marking
- The exam format was very new to students, and early iterations showed incomplete triads and weak reflection

### Target Learners
- second-year undergraduate database systems students in a large cohort (270 students)

### Learning Goals
- database reasoning (SQL, data modeling, normalization)
- AI literacy and evaluative judgement about sourced answers
- transparent, documented tool use
