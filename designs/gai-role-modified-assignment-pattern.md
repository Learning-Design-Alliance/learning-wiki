# One assignment, three GAI role implementations: tutor, teammate, and tool modifications

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article presents a reusable assignment design pattern in which a single marketing assignment is modified for each GAI role. In a social media marketing assignment on viral campaigns, the tutor version uses a Socratic dialogue with GAI as an expert guide, the teammate version has students collaborate with GAI while maintaining a critical approach, and the tool version restricts GAI to data gathering and analysis while requiring independent recommendations. The pattern advances specific learning objectives within the role framework.

## Design Implications

### Context
#### Requirements
- Instructors provide explicit instructions (system prompts) to the GAI chatbot for each role
- Assignment instructions specify appropriate use cases for GAI
#### Constraints
- The tool implementation requires that final analysis and recommendations be independently formulated by students

### Target Learners
- undergraduate marketing students

### Learning Goals
- theoretical understanding
- collaborative problem-solving
- independent analysis with AI support
