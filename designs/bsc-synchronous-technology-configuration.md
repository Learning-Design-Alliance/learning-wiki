# BSC synchronous technology configuration (video conferencing, electronic whiteboards, interactive response systems)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The technology configuration through which BSC integrates classrooms: "various synchronous tools such as video conferencing systems, electronic whiteboards, interactive response systems". These tools connect urban and rural physical classrooms with synchronous cyber classrooms and asynchronous cyber classrooms to support online real-time interaction. The element was deployed in the two-year Ningbo project.
