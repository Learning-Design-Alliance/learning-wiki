# Three-layer competency map linking graduate attributes to measurable behaviors

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
To operationalize competency goals in the reformed curriculum, the authors developed a competency map that translates abstract professional requirements into measurable learning outcomes. As printed, "this map is structured in three hierarchical layers that link high-level graduate attributes to observable skills and measurable behaviors": AI-driven Core Competencies representing overarching graduate attributes, sub-competencies specifying observable skills such as algorithmic reasoning and data visualization, and performance indicators defining quantifiable behaviors and outputs used for assessment.

## Design Implications

### Context
#### Requirements
- Performance indicators must align directly with the core and sub-competencies and be paired with explicit scoring rubrics and assessment tools
#### Constraints
- The core competencies were drawn from the AI competency framework proposed by Huang (2021), recognized within China's educational reforms

### Target Learners
- undergraduate computer-related majors
