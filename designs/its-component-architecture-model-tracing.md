# Component architecture of intelligent tutoring systems, including the rule-based expert-system (model tracing) tutor class

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article describes the design factors of an intelligent tutoring system as the component expert simulator, tutor software, learner model, modeler, and knowledge base. Within this architecture, it identifies a class of intelligent tutors based on a rule-based expert system that determines whatever the student knows, doesn't know and knows incorrectly, and uses this information to adjust learning style. The proposed system instantiates this architecture by integrating pedagogy and an expert system with a web-based ITS structure.
