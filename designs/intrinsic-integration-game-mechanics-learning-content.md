# Intrinsic integration of learning content into game core mechanics

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Intrinsic integration is a game design approach in which the game's core mechanics are directly tied to the learning content, so that players process essential learning content through game actions. The article states it "refers to the general idea that there must be an intrinsic association between the game's core mechanics and the learning content or learning mechanic". The study applied it by implementing number line estimation as the game's walkable platform, letting learners experience fraction magnitudes as walking distances.

## Design Implications

### Context
#### Requirements

#### Constraints
- The article notes the concept of intrinsic integration has not been studied extensively yet, and that to what extent it interacts with essential processing needs well-controlled experimental manipulations
