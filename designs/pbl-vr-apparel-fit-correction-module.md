# PBL-VR desktop training module for apparel fit correction

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A desktop VR training module built in Unity using garment simulations exported from Clo3D, teaching apparel fit correction through five iterative problem-solving tasks on a sleeveless top, slacks, a full-sleeve t-shirt, a sleeveless dress, and a skirt. For each fit issue users see "a brief explanation of the garment fit issue that needs to be rectified" and choose among "three potential pattern modification options one of which would correct the fit issue," with immediate audio-visual feedback explaining why a pattern change corrected the fit. It was designed following Experiential Learning Theory, Constructivist Learning Theory, and PBL theory, and was refined via a five-person expert pilot panel.

## Design Implications

### Context
#### Requirements
- Learners need an introductory understanding of interpreting folds and draglines, so the module begins with an explanation of how draglines and folds originate and a short video on recognizing fit issues, plus a tutorial task on navigation
#### Constraints
- The prototype did not allow participants to manipulate the fabric of the garment due to constraints within the Unity platform
- The module shows the change in garment simulation only when the user selects the right pattern modification option
- Authors state it can supplement but not replace physical garment fitting practice

### Target Learners
- Novice apparel design students and college students without prerequisite patternmaking knowledge

### Learning Goals
- Apparel fit correction skills
- Apparel spatial visualization skills
- Understanding of body-to-pattern relationships for varied body shapes
