# ChatGPT-assisted asynchronous self-paced Python module within a sixteen-week applied generative AI professional course

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
A compressed introductory Python instructional module delivered asynchronously during Weeks three and four of a sixteen-week professional training course on applied generative AI, taken by 86 adult learners with no Python prerequisite. Rather than lecture-based instruction, learners used OpenAI's ChatGPT "to support code generation, interpretation, and debugging", generating initial code snippets, understanding functionality, and handling errors. The module comprised pre-recorded video lectures (3.5 hours), seven short coding assignments (5 hours), and a one-hour Python proficiency exam, all administered via a learning management system.

## Design Implications

### Context
#### Requirements
- Learners need access to ChatGPT and the learning management system delivering the digital materials
- Guided use of generative AI so students learn to generate snippets, understand functionality, and handle errors
#### Constraints
- Prior Python experience was not required, but the study population consisted of highly motivated adult learners in a professional training program, and the article cautions results may differ in traditional undergraduate settings

### Target Learners
- adult professional learners reskilling into technical roles, with varying prior programming experience

### Learning Goals
- foundational Python programming proficiency sufficient for an introductory undergraduate course level
