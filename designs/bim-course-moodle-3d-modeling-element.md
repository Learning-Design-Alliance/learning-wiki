# BIM course: moodle-based digital environment for 3D building modeling

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The BIM course was an elective online course for master Architecture students (n=6) teaching BIM basics through BIM-based modeling. It used "a complex digital environment using the learning management system moodle", which integrated task-completion software including IFCWebServer and a data repository. The overarching goal was to generate a 3D building model respecting design specifications, exportable in the IFC standard data format.

## Design Implications

### Context
#### Requirements
- A learning management system integrating modeling software and a data repository
- Design specifications for the building model
- IFC-compatible export and data exchange per buildingSMART Benelux specification
#### Constraints
- Taught only six Architecture master students in the pilot

### Target Learners
- master students in Architecture

### Learning Goals
- basic CAD software knowledge for 3D modeling
- knowledge of IFC as a data exchange format
- modeling a 3D building model from planning specifications
