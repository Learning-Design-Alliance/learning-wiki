# System of specialized courses based on a single problem with professionally-oriented interdisciplinary relationships

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
An organizing framework for engineering curricula in which specialized courses are systematized around one inter-scientific problem, so that interdisciplinary relationships identify "the structural elements of a relationship between objects" and make learning more integral and logical. The article applies it in the course system Innovation processes in modern knowledge-based industry (automotive industry case study), with interrelated functional components: identification, establishment, and implementation of interdisciplinary relationships. Research competence is treated as the result of learning within this system.
