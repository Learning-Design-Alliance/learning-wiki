# Scaffolded progression from household to community to regional to global systems in a climate change game

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 causal), `q4` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The game sequences five activities so that users "focus on increasingly more complex environments and systems," starting with background-knowledge questions, then household conservation, then community conservation, then an extended tutorial linking the problem to climate change, and finally a regional water-management simulation. The authors state the modules were created so students "could easily comprehend and digest climate change content and not be overwhelmed by the game as a whole." The game can be used as a whole or as separate modules.

## Design Implications

### Context
#### Requirements
- Modules can be used individually or together; a facilitator's manual with suggested activities and discussions supports classroom integration
#### Constraints
- Conservation feedback is given only on options the user selects, which the authors suspect produced uneven learning about conservation options

### Target Learners
- middle school students

### Learning Goals
- systems thinking about water supply and climate
- water conservation practices
- understanding the greenhouse effect
