# Fictional sensationalist news article framing with AI-generated seasonal dataset for correlation-causation analysis

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (2 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
A lesson-level pattern in which students receive a fictional news report claiming a connection between two variables, together with a monthly data table, and must plot the data, draw conclusions, and argue against the sensationalist claim. The report was "explicitly fictional", and the dataset was requested from an AI chatbot chosen to exhibit "a clear seasonal trend, such as a higher number of drownings in summer months". Groups work on whiteboards and present findings in a plenary session.

## Design Implications

### Context
#### Requirements
- A dataset exhibiting a clear seasonal trend so the hidden variable can be discovered; whiteboards for group work; a plenary session for sharing hypotheses.
#### Constraints
- The authors did not cross-check the AI-generated data with other sources, and the activity did not aim to verify data authenticity.

### Target Learners
- high school physics students in an introductory module on scientific work

### Learning Goals
- plotting data
- extracting relevant information from data
- distinguishing correlation from causation
