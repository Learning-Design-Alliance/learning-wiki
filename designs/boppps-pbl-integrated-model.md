# BOPPPS-PBL integrated teaching model: BOPPPS structure scaffolding PBL within the participatory learning phase

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
The model combines the six-stage BOPPPS sequence (Bridge-in, Objectives, Preassessment, Participatory Learning, Postassessment, Summary) with PBL embedded in the participatory phase as a four-stage cycle of "situational construction, problem exploration through core questions, collaborative solution design and reflective evaluation". BOPPPS provides sequencing, objectives and assessment checkpoints for novice learners, while PBL drives inquiry on real departmental problems. The course extended the in-class cycle with pre-class preparation and 1-year post-class mentoring and output tracking.
