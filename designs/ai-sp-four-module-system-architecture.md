# Four-module system architecture for AI-SPs: LLM core, affective computing, personality modulation, and safety guardrails

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article describes a system architecture comprising four core modules. The LLM core generates "natural language responses consistent with clinical scenarios and patient roles." The affective computing module identifies "emotional cues in learner input (eg, tone, keywords, and empathic expression)." The personality and communication stance modulation module integrates the Big Five personality model and Satir communication stance theory. The safety guardrail and content filtering module ensures responses "do not contain inappropriate content, do not provide medical advice beyond the SP role."
