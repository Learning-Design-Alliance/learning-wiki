# A sequence of six object types realizing Papert's learning path into Newtonian laws of motion

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
TATI offers six object types — NOROBJECT, GEOOBJECT, VELOBJECT, ACCOBJECT, NEWOBJECT and PHYOBJECT — corresponding to Papert's proposed sequence of geometry, speed, acceleration and Newtonian turtles plus the two basic Second Life object kinds. Each type accepts only a restricted command set (e.g. ACCOBJECTs "accepts only the command SETACCEL"), so each populates a microworld with its own physical laws. The authors believe this sequence "accomplishes his learning path (Ibid., p. 123) proposal, helping to alleviate students' difficulty in discriminating between the concepts of position, velocity and acceleration".

## Design Implications

### Context
#### Requirements
- Objects of each type must accept only commands appropriate to their physical state variables, so that position cannot be set directly on velocity, acceleration or Newtonian objects
#### Constraints
- The four turtle-type objects required carefully coded LSL scripts that superseded the standard SL object properties

### Target Learners
- Physics students learning Newtonian mechanics

### Learning Goals
- Progressing from Aristotelian ideas through Newton's Laws along a learning path
- Discriminating position, velocity and acceleration
