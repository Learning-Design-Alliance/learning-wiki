# Real-time wireless classroom demonstration: casting the professor's smartphone screen connected to a nano board onto a projector

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This lesson-level pattern uses wireless data monitoring to let a whole class watch an experiment's results in real time. By casting the professor's smartphone screen, connected to a nano board, onto a video projector, the class monitors results live, "which makes visible a quantity that is not easy to grasp". Examples include displaying the acceleration of an object thrown upward during free fall to address a typical students' misconception, measuring pressure inside a vessel connected to a water pump, and recording pressure inside an inflating balloon with the board fitted inside it.
