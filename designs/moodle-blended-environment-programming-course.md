# Moodle-based blended learning environment with SCORM learning objects, projects and forums for a Programming Languages course

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article designed a blended environment for a Programming Languages course combining face-to-face direct instruction and question-and-answer with a Moodle online component. Weekly materials included "presentations, videos, tests, projects and forums", and database topics were prepared as five interactive Adobe Captivate learning objects packed as compatible with SCORM, each ending with practice questions and visible scores so students "could evaluate their self -progress". A four-week text-file project and forums supported interaction.

## Design Implications

### Context
#### Requirements
- Learners need internet access to the web-based environment so they can reach materials at their convenience and at their own learning speed
#### Constraints
- Videos could be watched repeatedly but questions could be answered only three times

### Target Learners
- undergraduate students in Computer Education and Instructional Technologies and Electronic Engineering departments

### Learning Goals
- self-regulated learning skills
- self-directed learning skills
- programming languages content
