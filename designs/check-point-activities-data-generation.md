# Embedding check-point activities in a course so learning data are generated regardless of how and where students learn

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This course-level design pattern addresses SPOL's data-generation problem: students who learn offline or log in irregularly leave little learning data. If a course embeds a series of check-point activities (e.g., quizzes, posting, reflecting) in the learning system, students will periodically return and interact with it, so their learning progress, study pace, and knowledge and skill state can be consistently scanned and recorded. The article states that 'by purposefully designing check-points activities, course instructors can pre-determine what, when, where and how learning data are generated and recorded during a student's learning journey.'
