# Four-quadrant lesson design crossing context embeddedness with cognitive demand

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article proposes that juxtaposing context-embedded vs context-reduced communication with cognitively demanding vs undemanding talk yields 'four independent quadrants ready to contain any of the skill-practicing tasks'. Quadrant (a) is context-embedded, cognitively undemanding talk (e.g. informing learners of the lesson topic); (b) context-embedded, demanding talk (e.g. negotiating the term syllabus); (c) context-reduced, undemanding talk (e.g. oral task explanation); (d) context-reduced, demanding talk (e.g. discussion of a salient topic). Each quadrant trains a different context-searching technique.
