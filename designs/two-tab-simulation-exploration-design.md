# Two-tab simulation design: Simulation view plus Step-by-step Exploration view

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each curriculum simulation has two tabs toggling between views: "The Simulation view contains introductory text and interactive controls; the Step‐by‐step Exploration view allows the user to step through detailed text explanations with a nimated highlighting." The combination allows the simulations to be used as self-contained instructional resources, so students can explore freely and also receive stepwise scaffolding.
