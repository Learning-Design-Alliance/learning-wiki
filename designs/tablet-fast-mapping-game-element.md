# Ludic tablet-based fast-mapping game for word-object and letter-sound associations

> **Design** · [All designs](index.md)
> **Evidence** · 6 claims (6 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 6 claims rest on one study

## Description
A tablet game designed by a multidisciplinary team of early childhood educators, speech therapists, game designers, and cognitive neuroscience researchers, built on the fast-mapping paradigm. The main application taught 14 letter-sound associations and 59 infrequently used word-object associations across four to eight training sessions, each word-object association trained once to evaluate fast-mapping after a single exposure. Each trial comprised an encoding phase, a recognition phase, and, for preschoolers, a vocalization phase, with "contingent interaction, delivering immediate feedback to the children's responses". A tutor application allowed remote monitoring by a supervising educator.

## Design Implications

### Context
#### Requirements
- A supervising early childhood educator to minimally oversee sessions and evaluate preschoolers' vocalizations
- Tablets secured onto soft cushion-like supports, used individually in a quiet room setting
#### Constraints
- Training concentrated on uncommon word-object associations and letter-sound associations only, not all language features with semantic and grammatical contents

### Target Learners
- Toddlers (~24 months old)
- Preschoolers (~42 months old) from low-income families

### Learning Goals
- New word-object (vocabulary) associations
- Letter-sound (pre-reading) associations
