## Description
The 3C3R model is a systematic approach for designing effective PBL problems, which the article adopted to revise its problem bank. The article describes it as having "two components: core components and processing components". Core components (3C) — content, context, and connections — promote content/concept learning, while processing components (3R) — researching, reasoning, and reflecting — target learners' cognitive learning processes and problem-solving abilities. The article credits it with enhancing PBL qualities and resolving implementation challenges identified in prior PBL research.
