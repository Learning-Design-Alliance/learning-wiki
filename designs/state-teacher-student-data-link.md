# High-quality teacher-student data link (TSDL) built at the state level

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A teacher-student data link connects teachers to students by course at the state level, which the brief calls "critical to understanding the connection between student academic growth and teacher training and practice." It describes a best-practices TSDL as "a linchpin of state success in policy implementation and evaluation of educator preparation quality," and lists six focus areas: data linkages, teacher of record definition, roster verification, K–12 course scheduling and codes, governance, and teacher ID number. Assigning the educator ID at program enrollment is suggested to ease sharing.

## Design Implications

### Context
#### Requirements

#### Constraints
- States must establish clear privacy and security policies safeguarding individual teacher data, considering who should have access to which data at what level
