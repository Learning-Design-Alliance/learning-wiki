# An ethical framework integrating Experiential Learning Design with Bloom's revised taxonomy scaffolds GenAI-integrated journalism assessment

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article presents a practice-based curriculum intervention built on an ethical framework that embeds GenAI into undergraduate journalism assessment. The framework "integrates Colin Beard's Experiential Learning Design with Bloom's revised taxonomy to scaffold students' movement from human-only reporting tasks to AI-integrated work and critical reflection." It serves as the organizing model for the assessment design, linking professional values to staged task progression.

## Design Implications

### Context
#### Requirements
- Assessment tasks must be sequenced so students move from human-only reporting tasks to AI-integrated work and critical reflection
#### Constraints
- Developed for undergraduate journalism education in a Malaysian campus of an Australian university

### Target Learners
- Undergraduate journalism students

### Learning Goals
- Ethical decision-making about GenAI use
- Prompt engineering
- Verification of AI outputs
