# Seven progressive DSA coursework activities spanning linked-list, stack, queue, list, tree, graph and heap

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The DSA coursework was organised into seven distinct topics forming learning activities that gradually extended in complexity of programmatic concepts. "The DSA coursework was organised into seven distinct topics related to the different data structures, namely linked-list, stack, queue, list, tree, graph and heap." Table 1 details each activity's task (e.g., adding sparse matrices, evaluating RPNs, Dijkstra shortest path, heap sorting) and the automarker functionality for marking it, including stress tests, infinite-loop checks and tolerance-based verification.

## Design Implications

### Context
#### Requirements
- Activities must be pertinent to each topic since different programming skills apply to different topics/sub-topics
- Exercises need a justified pedagogical foundation formalizing skills and notions pertinent to the algorithmic field
#### Constraints
- Activities gradually extended in complexity to challenge students within one second-year course

### Target Learners
- second-year undergraduate computer science students

### Learning Goals
- algorithmic reasoning and programming practice across core data structures
