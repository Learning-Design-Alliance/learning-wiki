# Repeating module structure: prep reading, alternating lectures and labs, and an application day per topic

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each main course topic after the background module received 2-2.5 weeks with 4-5 lecture days and 3-4 lab days followed by a homework assignment, following a printed outline: "Prep Chapter/Sections Assigned from Text", a motivational example lecture, exploratory and application labs, a tuning-parameters lecture, and a final "Application Day". Labs were written in an active learning style with guiding questions and step-by-step R/Rcmdr instructions with flexibility in options. Labs always began with data visualization and exploratory analysis before the new technique.

## Design Implications

### Context
#### Requirements
- A computer lab classroom with a computer for every student (capacity 24) alternating with a lecture room across four fifty-minute weekly blocks
- Statistical software with a menu-driven interface accessible to non-programmers
#### Constraints
- Theoretical depth was limited due to having no prerequisites for the course

### Target Learners
- undergraduates with no statistics, linear algebra, or programming background

### Learning Goals
- applied understanding of exploratory data analysis and multivariate techniques including recognizing appropriate applications, interpreting results, justifying choices, and communicating results
