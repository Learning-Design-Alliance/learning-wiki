# Método científico como estrutura de padronização e replicação

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
O artigo enquadra o método científico — rastreado historicamente até Galileu, Descartes, Bruno e Bacon após o desenvolvimento da perspectiva no Renascimento — como a base organizacional da atividade. Seu objetivo declarado é 'padronizar a prática experimental dentro de certos preceitos' para que as observações 'tenham validade para a deﬁnição, ou constatação, de uma teoria cientíﬁca ou hipótese', e para permitir que 'a reprodução de uma prática experimental, seja pelo mesmo pesquisador ou por outro'. A atividade de germinação é construída para que os alunos experimentem diretamente por que a padronização, a descrição fiel e a replicação são importantes para a confiabilidade dos dados.
