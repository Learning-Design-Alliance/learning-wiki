# Computational essay projects structured as authentic research-like activities with oral presentation in mock research-group format

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The instructional pattern places an open-ended computational research project in the second half of a physics course: students individually or in pairs define a question, investigate it with a computational simulation, write a Jupyter notebook-based computational essay, and present it orally to peers in "a mock research-group meeting format, including 2 minutes for questions from the audience or TA." The pattern mirrors professional scientific computing practice, where scientists build on existing code and communicate via computational notebooks.

## Design Implications

### Context
#### Requirements
- Students need prior programming coursework; at this institution nearly all math and science majors take a first-year programming course
#### Constraints
- The pattern was studied in a 3rd-semester electricity and magnetism course at a university with deep curricular integration of computation

### Target Learners
- 3rd-semester undergraduate physics majors

### Learning Goals
- disciplinary computational literacy, electromagnetism understanding, scientific communication
