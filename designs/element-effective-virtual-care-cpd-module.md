# Effective Virtual Care: Elevating Primary Care through Virtual Practice asynchronous CPD module

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This is an asynchronous online continuing professional development module launched by Memorial University of Newfoundland's Office of Professional & Educational Development in February 2024. Hosted on the MDcme.ca platform, it covers virtual visit etiquette, technology troubleshooting, adapted physical examinations, documentation, and remuneration processes. Interactive features include "embedded videos, knowledge-check quizzes, and reflective questions." The module is certified for 1.5 Mainpro+ CPD credits.
