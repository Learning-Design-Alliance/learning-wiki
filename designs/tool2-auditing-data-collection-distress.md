# Tool #2: Auditing Your Data Collection for Indicators of Distress

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Tool #2 supports authorizers in "reviewing their data collection methods to determine where they are already collecting data on indicators and to close gaps to improve the identification of schools in distress." It maps each distress indicator to example artifacts and sources—board minutes, check-ins, audits, enrollment data, staff retention data—and asks authorizers to document informal versus formal collection mechanisms and identify gaps. Estimated time is 30 minutes.

## Design Implications

### Context
#### Requirements
- Data collection instruments, such as site visit protocols, annual reports, performance management frameworks

- The report advises that revamping data collection is not likely needed; minor modifications to existing methods suffice

### Target Learners

### Learning Goals
- Auditing and improving data collection to identify schools in distress
