## Description
This element is the early-elementary implementation of the Self-Determined Learning Model of Instruction described and validated in the study: a teaching model that young children ages 5-6 used to set goals for learning and achieve them. Teachers applied it "in a variety of subjects and settings with students having diverse learning needs," making it a reusable instructional component for early grades.
