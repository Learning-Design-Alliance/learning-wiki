# KSP Mün-landing final course project with six skill components and a written reflection

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
An optional final course project in which students land a Kerbal on the Mün and return it safely, covering spacecraft construction, launch to orbit, orbital circularization, orbital transfer, soft landing, and return and reentry. The author does not formally assess beyond the landing itself but asks students to submit a written reflection on the physics concepts they learned. A full project description and rubric are available as supplementary material.

## Design Implications

### Context
#### Requirements
- A significant time investment, typically 10+ hours, so the author recommends assigning it as a long-term project or over multiple consecutive lab periods
- Access to KSP and its tutorials; the author encourages students to use YouTube walkthroughs
#### Constraints
- Concepts covered fall far beyond the typical scope of an introductory astronomy course; assessment is limited to performing the landing itself

### Target Learners
- college introductory astronomy students

### Learning Goals
- Newtonian mechanics, achieving orbital velocity, orbit adjustment, orbital transfer timing and trajectory, landing and reentry planning
