# Site C intervention: five technology-enhanced, project-and-rubric-based ninth-grade language arts units

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Site C's intervention is "a set of five technology-enhanced, project-and-rubric-based ninth-grade language arts units that encourage proficiency-based teaching and learning," implemented in classrooms of seven teachers across six high schools, serving about 528 ninth-grade students. Outcomes are evaluated against student-level benchmark assessment data and attendance within the same schools, grades, and years.

## Design Implications

### Context
#### Requirements
- Rubric-based evaluation of project work within technology-enhanced units
#### Constraints
- Ninth grade is not part of the state accountability testing system, so state test scores cannot be examined; comparison teachers often differ from treatment teachers, limiting ability to separate teacher and curriculum effects

### Target Learners
- ninth-grade English language arts students in a large urban district

### Learning Goals
- English language arts proficiency
