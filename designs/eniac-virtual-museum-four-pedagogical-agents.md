# ENIAC virtual museum learning environment with four specialised pedagogical agents

> **Design** · [All designs](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (1 causal, 1 review, 1 theoretical), `q1`–`q3` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
The study's artifact is a learning environment representing "a virtual museum dedicated to promoting learning on ENIAC, the world's ﬁrst electronic computer", featuring a 3D replica of ENIAC and its components that participants could closely examine and interact with. Four PAs were implemented, named Mathew, John, George, and Guy, acting as two instructors, a teaching assistant answering questions, and an evaluator assessing learning through four embedded Q&As with adaptive feedback. All agents communicated via pre-recorded human voice coordinated with gaze, gestures, body movements and facial expressions, and maintained contextual knowledge, episodic memory and spatial awareness.
