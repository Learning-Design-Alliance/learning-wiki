## Description
The article accounts for how script components relate to one another computationally: "These mechanisms are encompassed in the transformation of data structures (social structure, resources structure and products structure) between script phases". Designing a script thus means specifying how the social grouping, the available resources, and the expected products are reconfigured from one phase to the next.
