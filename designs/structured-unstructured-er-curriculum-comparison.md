# Structured versus unstructured educational robotics curriculum comparison design for block-based programming

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The study implements a quasi-experimental comparison of two educational robotics curricula for young learners working in block-based programming: "a structured ER curriculum group and an unstructured one". Within the quasi-experiment, "both qualitative and quantitative data are collected", covering error frequency and type, debugging ability, and engagement in the learning process.

## Design Implications

### Context
#### Requirements
- Two comparison groups, one following a structured ER curriculum and one an unstructured ER curriculum
#### Constraints
- Quasi-experimental design with two comparison groups (n = 35), not a randomized experiment

### Target Learners
- young learners in block-based programming contexts

### Learning Goals
- debugging programs
- reducing programming errors
- engagement in the learning process
