# JiTT: a feedback loop between Web-based pre-class assignments and classroom instruction

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
JiTT is a teaching and learning approach that combines traditional in-class instruction with Web communication. Its essence is a feedback loop: faculty post Warm Up assignments before class, students respond, and faculty use those responses to tailor the class session. As the authors state, "The essence of JiTT is the feedback loop between the Web and the classroom," emphasizing active learning, constructivism, and prompt feedback while decreasing traditional lecture.

## Design Implications

### Context
#### Requirements
- Weekly Web-based Warm Up assignments due before class time
- Faculty time before class to read and select student responses
- A mechanism (CGI-bin or course management software) to collect and display student responses
#### Constraints
- JiTT is particularly useful in large enrollment courses and for commuting or part-time students, per the authors

### Target Learners
- undergraduate nonscience majors in large-enrollment biology
- advanced undergraduate biology majors and graduate students

### Learning Goals
- addressing misconceptions and activating prior knowledge
- active learning and cooperative problem solving
- formative assessment and prompt feedback
