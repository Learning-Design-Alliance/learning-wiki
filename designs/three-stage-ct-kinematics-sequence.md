# Three-stage didactic sequence pairing Python free-fall modeling with experimental measurement and individual code interpretation

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The pattern is a three-stage sequence: (1) subgroup programming of a free-fall function, testing it, simulating a 3.8 m drop with a 0.05-second time step, and graphing position and velocity; (2) deriving and implementing a fall-time formula, then comparing it with the mean of 30 experimental trials; (3) an individual written interpretation of a provided program simulating free fall from 100 m. The final stage "was designed to assess specific CT skills—particularly those related to describing and interpreting code—that had been progressively introduced in prior activities."

## Design Implications

### Context
#### Requirements
- Students need prior foundation in basic kinematics and elementary Python programming covering variables, data types, lists, functions, conditionals, loops, and graphs.
#### Constraints
- Implemented over two 2-hour class sessions within the same week during regular classroom hours, with students from the same school and academic year.

### Target Learners
- K9 students with basic kinematics and elementary Python background

### Learning Goals
- modeling accelerated motion with code
- interpreting and explaining code in physics terms
- comparing theoretical and experimental fall times
