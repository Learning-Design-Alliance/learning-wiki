# Exercise design pattern: real observatory data plus plug-in modularity as the distinguishing features of classroom astronomy software

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article's exercises follow a recurring design: students work with real, professionally obtained data within a modular, extensible tool. The authors state that "These two facts (real data and plug-in modularity) constitute the major differences from the plethora of software platforms for astronomy exploration making it a unique and suitable tool for schools." Exercises fall into recurring categories — aperture photometry, spectroscopy, and data acquisition via a webcam plugin — each pairing a simplified tool with authentic research data.

## Design Implications

### Context
#### Requirements
- A common, easy to use and flexible software platform able to manipulate real astrophysical data
- Access to professional observatory data suited to the pupil-classroom framework
#### Constraints
- Most available astronomical platforms are planetarium-type simulators without capabilities to introduce physics concepts and manipulate real data, per the authors' comparison

### Target Learners
- middle and high school students

### Learning Goals
- authentic scientific data analysis
- physics and mathematics concept application
