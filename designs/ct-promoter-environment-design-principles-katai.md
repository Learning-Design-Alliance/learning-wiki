# Design-principle framework for CT-promoter e-learning environments: sequenced multiple representation, genuine active involvement, selective hiding, and pattern-recognition orientation

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article organizes its learning environment around four research-based design principles for promoting computational thinking. Sequenced multiple representations exploit complementarity and redundancy: "We use four different representations of the number sequence to be sorted: embodied by a dancer-sequence, stored in a white-box array, stored in a black-box array and illustrated as a color-scale bar." Active involvement follows the meta-study conclusion that "AV's promote effective learning when users are engaged actively in the visualization process (instead of passively viewing it)", selective hiding forces learners to perform comparison operations explicitly, and a pattern-recognition strategy moves from carefully selected sample inputs to orchestration on random inputs. The framework is grounded in constructivist learning theory.
