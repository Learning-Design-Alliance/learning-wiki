# Generative learning model integrated with cognitive conflict strategy as a framework for multimedia design

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's organizing framework is a generative learning model combined with a cognitive conflict strategy, in which multimedia "can create cognitive conflicts that encourage students to think more deeply, explore new ideas, and discover innovative solutions". Rather than passive reception, the approach actively engages students in knowledge construction, addressing the lack of cognitive challenge the authors identify in commonly used discovery, problem-based, and project-based models. The framework underpins the article's recommendation for interactive multimedia design but is asserted from prior literature rather than tested here.
