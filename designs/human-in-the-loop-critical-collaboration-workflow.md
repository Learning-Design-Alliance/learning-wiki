# Human-in-the-loop human–AI–human collaboration workflow for critical prompt engineering

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A six-step structured workflow introduced in Week 3 to scaffold critical human–AI–human collaboration: cognitive activation before prompting, prompt formulation, AI output generation, critical evaluation with fact and bias checking as gatekeeping, iterative refinement via new prompts, and group consensus on final internalization. The article states that "Drawing on the principle of cognitive activation, students were instructed to generate their own initial ideas before querying the AI", a step explicitly intended to mitigate offloading and reduce anchoring effects. Groups applied the workflow in a TikTok script co-creation task using DeepSeek.
