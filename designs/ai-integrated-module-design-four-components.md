# AI-integrated module design combining lesson plans, videos, AI exercises, and curated readings

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The course redesign organizes each module around "four core components that support scaffolded learning—lesson plans, short videos, AI-focused exercises, and curated readings". Lesson plans state explicit learning outcomes framed by What/Why/How questions; 4–10 minute videos create a flipped-classroom dynamic; weekly AI Modules include prompting strategies, failure-mode analysis, and a recurring Santa's Workshop case study; curated readings reinforce foundations. Together these "systematically advance students from foundational knowledge to higher-order analysis, evaluation, and creation, aligning with Bloom's Taxonomy of learning".

## Design Implications

### Context
#### Requirements
- Modules must include AI-focused exercises that require students to inspect, diagnose, and revise AI-generated outputs
#### Constraints
- The design was deployed in a single-section, asynchronously delivered undergraduate database design course

### Target Learners
- undergraduate computer science students in a database design course

### Learning Goals
- database design competency (ER modeling, normalization, SQL, NoSQL)
- prompt engineering and AI error analysis
- metacognitive reflection
