# VIVEPAPER chemotherapy spill-management VR module

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A course-specific immersive VR training module delivered through the VIVEPAPER platform with technical support from DeepQ/HTC, using an HTC VIVE Pro head-mounted display with handheld controllers. Participants "progressed through a predetermined, guided instructional sequence" that included 360-degree instructional videos, written and visual materials, and embedded knowledge checks with immediate feedback. The module provided "a consistent, guided approach to reviewing spill-management procedures without exposure to hazardous drugs" but did not include free navigation, object manipulation, automated scoring, or adaptive feedback.

## Design Implications

### Context
#### Requirements
- Delivered as a 60-minute immersive session with operational assistance provided consistently by the same facilitator across both cohorts
#### Constraints
- The module did not include free navigation, manipulation of virtual objects, automated performance scoring, or adaptive feedback
- The available records did not document the platform's commercial or licensing status, the software version used, or any prior external technical or educational validation

### Target Learners
- Undergraduate pharmacy interns completing hospital internships

### Learning Goals
- Chemotherapy spill-management procedures
- PPE donning
- Spill-kit contents
