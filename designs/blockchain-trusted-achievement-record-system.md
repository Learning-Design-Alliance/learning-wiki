# Blockchain- and smart-contract-based trusted achievement record system (proposed)

> **Design** · [All designs](index.md)

## Description
A proposed secure system to record and authenticate certificates, key learning activities and achievements, using blockchain and smart contracts so stakeholders such as employers can validate learning records. The article describes a smart contract as "an event-condition-action stateful computer program" deployable on blockchain to automate validating and storing data for parties who do not fully trust one another. The element is motivated by poor data continuity across institutions' LRSs, diploma verification difficulty, and unrecorded non-academic achievements.
