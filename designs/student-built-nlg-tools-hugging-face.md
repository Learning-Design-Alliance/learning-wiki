# Student-built NLG tools on Hugging Face used for human-AI story writing in workshops

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The study's central artifact is a set of NLG tools that students composed themselves "using Python programming language and open-source AI on Hugging Face, a machine learning repository" during a first workshop. In a second workshop, students had 45 minutes to write a story of no more than 500 words using their own words and words generated from their tools, with the option to write from scratch or rewrite an existing story. The tool interface, called My First Text Generator, takes a prompt in a text box and generates output text beside it.

## Design Implications

### Context
#### Requirements
- Students must attend workshops teaching the Python programming and open-source AI needed to compose an NLG tool, including libraries, dependencies and functions
#### Constraints
- Story writing was capped at 500 words in 45 minutes; story-quality analysis covered only the 34 students who followed the word-limit instruction

### Target Learners
- EFL secondary school students

### Learning Goals
- English language short story writing
- prompt engineering of generative-AI tools
