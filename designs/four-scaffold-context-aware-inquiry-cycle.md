# Four-scaffold inquiry cycle delivered as context-aware game scaffolds

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The app structures each inquiry spot around four scaffolds following Stripling's social inquiry model. The "Connection scaffold, which is in the form of voice navigation, will provide students with background information about the societal issue"; Investigation guides data collection; Construction supports "generalising the information on hand via mind-mapping and making an interim conclusion about the issue via audio-recording"; and Reflection uses video-blogging to set goals for the next spot.
