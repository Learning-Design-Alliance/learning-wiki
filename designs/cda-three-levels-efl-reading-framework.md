# Fairclough-based three-level CDA framework for EFL analytical reading (description, interpretation, explanation)

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The study develops a conceptual framework, based on Fairclough (1995) and Cots (2006), in which an EFL reading lesson is a communicative event and reading is a social practice. To reveal a discourse, students move through three levels: "text analysis (description), discourse analysis (interpretation) and critical discourse analysis (explanation)". Each level reveals one layer of meaning: text analysis describes lexicon, grammar and semantics; discourse analysis interprets text production, consumption and intertextuality; critical discourse analysis explains the writer's point of view and sociocultural background. The framework was operationalized as classroom stages and measured with a 39-item questionnaire and a validated test.
