# Geometric functions approach

## Description
The geometric functions approach treats functions as "geometric transformations of a point in the plane — functions that have geometric points as their input and output" (Steketee, 2012, as cited in the article). Steketee gives four reasons to prioritise it when teaching functions: cognitive (independent variable, dependent variable, and the rule connecting them), kinaesthetic (students create and change the independent variable with a simple drag motion), visual (function behaviour is observed as a visual, dynamic change), and structural (comprehension of domain, range, symbolic display, and set matching in composite functions). The article applies it with GeoGebra dynamic mathematics software on interactive whiteboards in a functions unit.
