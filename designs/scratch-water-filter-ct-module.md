# Two-week Scratch-based computational thinking module with water filter simulation tasks

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The study's instructional element was a two-week computational thinking module in a science teaching methods course in which participants learned block-based programming in Scratch, created and tested a water filter, and coded science simulations analogous to the water filter. Tasks followed the computational thinking subskills: participants "decomposed the problem by coding the outcomes of using different purification media, applied abstraction skills by connecting code blocks to science concepts", designed algorithmic steps, applied patterns, and debugged code errors. This element generated the struggle episodes analyzed in the study.

## Design Implications

### Context
#### Requirements
- Participants had no prior training on computational thinking or block-based programming; the module was embedded in an existing course to circumvent curriculum overload.
#### Constraints
- The article notes the limited scope of data was due to restricted time allocated for computational thinking activities within the teacher education course.

### Target Learners
- preservice science teachers in secondary education methods courses

### Learning Goals
- computational thinking subskills: decomposition, abstraction, algorithmic thinking, pattern recognition, debugging
