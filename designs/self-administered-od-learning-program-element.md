# Self-designed, self-administered optical diagnosis learning program (NICE classification still pictures plus 50-lesion in vivo phase)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A non-guided learning program in which an experienced endoscopist reviewed the NICE classification and used a validated published set of still pictures to identify the main optical characteristics of hyperplastic and adenomatous polyps under narrow band imaging, then applied the classification to 50 consecutive colorectal lesions from CRC screening colonoscopies with pathology-based self-feedback. The article reports this program was "sufficient to achieve expert-level OD" in a single trainee.

## Design Implications

### Context
#### Requirements
- An experienced, highly motivated trainee; the article states an efficient self-learning program seems possible "when the trainee is highly motivated"
#### Constraints
- Single-endoscopist pilot; all patients were from a FIT-positive population, which the authors note may enhance the learning process

### Target Learners
- experienced endoscopists seeking competency in optical diagnosis

### Learning Goals
- expert-level optical diagnosis of diminutive and small colorectal lesions
