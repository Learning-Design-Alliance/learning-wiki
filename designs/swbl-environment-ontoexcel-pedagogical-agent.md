# SWBL environment with OntoExcel ontology, pedagogical agent and learning object repository

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The SWBL environment is a Semantic Web based learning system built around an ontology called OntoExcel developed in Protégé, a pedagogical agent, and a learning object repository. The agent reads the OntoExcel.OWL and LO.RDF files, answers queries through SPARQL, and lists prerequisite and posterior objectives with related learning objects. In the study it covered 5 spreadsheet topics with 74 learning objects created through PowerPoint videos with voice-over and PDF documents.

## Design Implications

### Context
#### Requirements
- Internet access for learners to reach the content
- learning objects and objectives defined in the ontology so the agent can list prerequisites

### Target Learners
- pre-service teachers in an ICT course

### Learning Goals
- ICT spreadsheets objectives such as listing process priorities, writing and copying formulas
