# CPS-ALM: Collaborative Problem Solving assisted by literacy media, structured in five collaborative learning stages

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
CPS-ALM is a learning model combining collaborative problem solving with literacy media (e.g., graphs from a mathematics blog) to build statistical literacy and self-concept in statistics courses. The article states "There are five stages in collaborative learning amo ng others are: Engagement, Exploration, Transformation, Presentation and Reflection (Reid, 2004)", and holds that collaboration lets students with diverse mindsets complete each other and improve weaknesses while constructing creative ideas.

## Design Implications

### Context
#### Requirements
- Group work in which students interact, argue, and cooperate, so learning results from diversity of individual opinions rather than unity
#### Constraints
- The article presents the model for statistics lecturing with elementary school student teachers in the PGSD program

### Target Learners
- elementary school student teachers in a statistics education course

### Learning Goals
- statistical literacy
- statistical self-concept
