# Interactive service scaffolding learners from guessing game to processing their own datasets

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The CNN client's interactive service combines a guessing game on gamma/hadron separation, an instruction for defining gamma-events from telescope images, prepared datasets ready for downloading, an application for processing a user's own dataset, and tools — a data-visualization script and a script "for converting data ﬁles to HDF5 format" with instructions. The component set moves learners from intuitive game-based discrimination toward working with real analysis tools and datasets.
