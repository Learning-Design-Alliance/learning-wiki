# Four guided experiments on Arduino, ESP32/IoT cloud, and Raspberry Pi including TensorFlow Lite object detection

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The proposed curriculum's close-ended component consists of four newly designed guided experiments: (1) Arduino with MQ2 gas sensor interfacing shown on an OLED display, (2) Wi-Fi communication and IoT cloud dashboards using the ESP-32's built-in Wi-Fi module, (3) introduction to Raspberry Pi Gen 4 Model B/B+ with ultrasonic distance measurement, and (4) image and video processing with the Pi camera. The article states there are "four newly designed guided experiments based on Arduino, ESP module, IoT cloud, and RPi", and that in experiment 4 students "complete object detection using TensorFlow Lite and OpenCV which make them prepared to solve computer vision-related problems". The experiments are assessed through Class Performance, Lab Reports, Mid Exam and Final Quiz carrying 40% of marks.
