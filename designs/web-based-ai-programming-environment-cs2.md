# Web-based CS2 programming environment with integrated GPT-4 AI assistant and interaction logging

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A web-based programming environment developed for this study in which "The system integrates the programming assign- ment description, a code editor, program execution output, and a conversational AI assistant within one single interface." The AI assistant was powered by GPT-4 accessed through the OpenAI API. The system automatically logged student prompts, AI responses, timestamps, user identifiers, and interaction metadata, enabling analysis of question-asking behavior during two 60-minute lab sessions.

## Design Implications

### Context
#### Requirements
- Students log in, complete a demographic survey, and work on assignments with unlimited AI interaction; assignments must be submitted through the system by the session's time limit.
#### Constraints
- The system was used during scheduled laboratory sessions of approximately 60 minutes in a single CS2 course at one university.

### Target Learners
- CS2 (second-year computer science) students, mostly freshmen and sophomores

### Learning Goals
- Object-oriented programming in C++, including constructors, encapsulation, inheritance, and polymorphism
