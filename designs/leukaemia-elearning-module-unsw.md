# Purpose-built e-learning module on leukaemia built in Adobe Captivate with concepts-and-causes and case-study sections

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A web-delivered multimedia module authored in Adobe Captivate v5.5, structured into 'concepts and causes' and 'case studies' sections covering ALL, AML, CLL and CML, with four authentic case studies, embedded videos, roll-over definitions and formative questions with immediate feedback. The module aimed to "link the clinical approach to leukaemia with the basic sciences, particularly in relation to diagnostic protocols". It was distributed via the web with password-protected access for the trial and evaluated in the randomised controlled trial reported here.

## Design Implications

### Context
#### Requirements
- Web browser access to the Flash-based module; password-protected server access during the trial
#### Constraints
- Some participants with limited rural internet speeds found the module took a long time to download; participants generally preferred more text per screen rather than audio

### Target Learners
- Senior (Phase 3, years 5-6) undergraduate medical students

### Learning Goals
- Understanding leukaemia pathogenesis, diagnosis and prognosis, linking clinical approach with basic sciences
