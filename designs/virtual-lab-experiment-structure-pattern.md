# Consistent virtual lab structure: objective, theory, simulation procedure, pre-lab and post-lab questions, and data analysis tables

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Every experiment in the manual follows the same reusable structure: an objective stating what is investigated, a theory and physical principles section with the relevant equations, an apparatus-and-procedure section built around a named simulation with step-by-step instructions, pre-lab questions, post-lab questions, and data analysis and calculations tables with percent-difference comparisons. For example, Experiment 1 asks students to "Compare observed and calculated coulomb force between charged objects by calculating percent difference." This consistent scaffold supports students working independently in a virtual setting.
