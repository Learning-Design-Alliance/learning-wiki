# Co-developed linear number board game with forward-only and bidirectional conditions

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q4` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A classroom number game in which pairs of children place number food cards in order on a tablecloth-shaped mat to feed a monster, building a linear number line. Children in the forward condition placed cards ascending (e.g., 1-10 or 6-15); bidirectional children placed cards forward then backward (e.g., 10-1 or 15-6). The interval moved from 1-10 in the first three sessions to 6-15 in the remaining five after pilot testing. The game was designed to "required limited input from adults to play, and children found highly playable, fun, and engaging."

## Design Implications

### Context
#### Requirements
- Played in small pairs in a quiet corner of the classroom with an experimenter prompting children to find the successive or preceding number and checking card order with scaffolded support
#### Constraints
- The article notes it used a one-size-fits-all difficulty level, with all children playing the same number intervals

### Target Learners
- four- to five-year-old children in primary schools in socioeconomically disadvantaged areas

### Learning Goals
- early numerical skills: counting, number naming, number order, number line estimation, number comparison
