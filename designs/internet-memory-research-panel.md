# Internet Memory Research panel: a web-based longitudinal testing panel for multi-session long-term memory experiments

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 review), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The study used a laboratory-formed "Internet Memory Research panel" of 1354 subjects for long-term repeat testing, with the experiment run on a web server using the open source LAMP framework and accessible from any standard web browser. The appendix argues web-collected data are credible: comparing roughly matched gap and RI values, average final-test performance was 41% in the internet study versus 45% in the laboratory benchmark, and the proportion of "surprisingly good" performers (85%+ correct) was 2.6% online versus 2.1% in the lab, offering little evidence of cheating.

## Design Implications

### Context
#### Requirements
- Email reminders to prompt subjects to return for later sessions; time windows for session completion
#### Constraints
- Non-completion rates increased at longer delays, though completers and non-completers showed no reliable differences in initial performance or demographics

### Target Learners
- adult volunteer panel members (mean age 34, 72% female)

### Learning Goals
- retention of obscure but true trivia facts
