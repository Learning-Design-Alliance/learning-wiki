# Structured 120-word exhibition label with three-paragraph description element

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The element structures the exhibition label students create for their final artwork, which is submitted as a PDF and printed professionally. The label description requires three paragraphs and acknowledgements, giving clear instruction that is brief to explain yet supports how the public will understand the work.

## Design Implications

### Context
#### Requirements
- Paragraph 1 describes and introduces the work; paragraph 2 explains the data and topic; paragraph 3 explains how the data is mapped, plus acknowledgements of sources, images, and libraries used
#### Constraints
- One student had a label that far exceeded the 120 word requirement, which needed to be edited

### Target Learners
- computing students exhibiting data-art publicly

### Learning Goals
- clear communication of complex data to a public audience
