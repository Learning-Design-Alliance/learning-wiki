# Mapped set of Blackboard tools (Syllabus, Content, Calendar, Self Test, Quiz, Drop Box) each tied to specific student learning activities

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article enumerates a set of Blackboard tools and maps each to the student learning activities it supports, presented in Table 1. It states: "Blackboard tools, such as Syllabus, Course Content, Calendar, Self Test, Quiz and Assignments, are used to support different e-Learning activities as listed in Table 1." For example, self-test questions per module "test the knowledge and learning objectives for that module and provide immediate feedback", the Quiz tool automates marking of multiple-choice formal assessment, and the Drop Box handles electronic submission of assignments and the final project.

## Design Implications

### Context
#### Requirements
- Module-level practice questions aligned with each module's knowledge and learning objectives
- Laboratory-hour scheduling for quizzes to enable automated multiple-choice marking and immediate feedback
#### Constraints
- Tool descriptions reflect the Blackboard Learning System functionality available to the author in 2010

### Target Learners
- Undergraduate computing students studying in mixed mode across multiple campuses

### Learning Goals
- Self-evaluation and self-review with instant feedback
- Meeting assessment deadlines through planning tools
- Formal module-level assessment
