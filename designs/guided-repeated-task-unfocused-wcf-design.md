# Unfocused WCF design that aligns delayed-posttest errors with revised-task errors via guided tasks, repeated tasks, and elementary-level scope

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
This design pattern addresses the validity critique that unfocused WCF studies cannot ensure delayed-posttest errors match those targeted during revision. It uses guided writing tasks drawn from the learners' textbook, multiple writing tasks with revisions so errors are addressed repeatedly, and an elementary proficiency level where the range of grammar used is narrow. As the article states, "the writing tasks were guided and the topics were chosen based on the learners' textbook which required them to use certain grammatical structures."

## Design Implications

### Context
#### Requirements
- Writing tasks must be guided and tied to grammatical structures learners are studying
- Multiple writing tasks with revisions so learner errors are addressed many times
- Feedback limited to grammar rules already studied or being studied during the semester
#### Constraints
- Findings apply to elementary-level learners who use a narrow range of grammar

### Target Learners
- elementary EFL students

### Learning Goals
- grammatical accuracy in L2 writing
