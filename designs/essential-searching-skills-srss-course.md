# Essential Searching Skills for Librarians on Systematic Review Teams course

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A required Level I core course in the Medical Library Association's Systematic Review Services Specialization, developed and taught by the authors across eleven cohorts from 2022 to 2024, with approximately thirty registered participants per class. Each class used a Slack channel for communication and an open course site on Open Science Framework with readings, handouts, slides, and activity instructions. PubMed is the primary platform because it is "fully accessible without restriction to anyone with internet access and incorporates the MeSH database of controlled vocabulary." The course includes a five-question pre-test, four modules, a breakout-group search-building activity, and an identical post-test.

## Design Implications

### Context
#### Requirements
- Delivered within the SRSS, which requires eight required core courses and four electives; participants are added to a Slack channel and given access to the OSF course site
#### Constraints
- The abbreviated three-concept activity was chosen over a full systematic review search because building a full search can take several weeks and requires input from an actual research team

### Target Learners
- librarians of all searching skill levels earning the Systematic Review Services Specialization

### Learning Goals
- comprehensive search strategy development, controlled vocabulary use, search peer review via PRESS, and search reporting via PRISMA-S
