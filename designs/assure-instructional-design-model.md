# Assure instructional design model for planning web-assisted instructional materials

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Assure model is a six-stage instructional design framework the article uses to plan web-assisted materials systematically. "Assure model is the acronym of the six stages that make up the model": analyze learners, state objectives, select media and materials, utilize media and materials, require learner participation, and evaluate and revise. The study applied all six stages, from learner analysis (age, input skills, learning styles) to activity-based evaluation with branching and revision.
