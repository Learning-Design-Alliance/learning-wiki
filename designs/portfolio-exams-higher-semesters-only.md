## Description
The article's proposed portfolio examination system applies only to advanced students. The authors state "die Grundausbildung von diesem Ansatz ausgenommen werden muss und der Ansatz nur die h¨ oheren Semester betrifft", and separately suggest "Eine Art Grundstudium ¨ uber 2-3 Semester sollte dem System vorgeschaltet sein." The principle is that application- and process-oriented portfolio assessment presupposes foundational competence already built.

### Context
#### Requirements
- A foundational study period of 2-3 semesters precedes the system, so students enter with basic competences established.
#### Constraints
- The authors state the approach concerns only the higher semesters and that foundational education must be excluded from it.
