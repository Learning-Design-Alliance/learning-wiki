# RIDE instructional program with prompts in a shared simulation discovery environment

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A computerized instructional program that teaches the RIDE collaboration rules before learners work in a shared discovery learning environment, plus pop-up prompts reminding learners of the rules during tasks. The program "consisted of a recorded computerized presentation, where the rules were explained by both audio and visual means", followed by practice with example chats and a SimQuest logical-reasoning application, and an evaluation form. In the experimental version of Collisions, a prompt pops up whenever an assignment is opened, reminding learners of one of the RIDE rules; the control group received no pop-ups. Evaluation forms showed 83% of learners mentioned they applied the rules with ease.

## Design Implications

### Context
#### Requirements
- Learners work in dyads on separate computers with a shared interface, communicating through a chat channel, in a simulation-based discovery learning environment
#### Constraints
- Reading prompts takes time, which the authors note can result in finishing fewer assignments in a fixed amount of time

### Target Learners
- tenth-grade pre-university physics students aged 15–17

### Learning Goals
- effective communication and collaboration during collaborative discovery learning in physics
