# Flipped-classroom pattern with preparatory WikiBook reading and class time dominated by active-learning tasks

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
In the small NEXUS/Physics test classes, "students did preparatory work on their own time and then spent a significant fraction of class time engaged in active learning tasks." Students read the WikiBook before class, wrote summaries, and asked a question; class time was mostly used for discussion, clicker questions, problem solving, and some lecture. All classes were videotaped to document how students responded to the material in interactive lecture and recitation discussions.
