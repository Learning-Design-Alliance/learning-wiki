# Bidirectional SLE built on etiquetAR bidirectional QR codes

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
An indoor situated learning environment in which each industrial machine carries a "bidirectional" QR code generated with etiquetAR, an authoring tool whose tags "provide information (as do tradition al QR codes )" but "also collect user -generated content". Each code links to a machine video, an image of main components, and a question; answers left by teams become visible to anyone scanning later, opening a cross-team collaboration channel. Students answer via their own smartphones or teacher-provided tablets, then peer-evaluate classmates' answers.

## Design Implications

### Context
#### Requirements
- Mobile devices (students' smartphones or teacher-provided tablets) with QR readers
- A reliable technological setting with adequate Internet connectivity for loading videos
#### Constraints
- Teachers reported the SLE "is not  designed to operate in settings with slow or limited Internet connectivity"
- Answers are removed after each session, so teams see only answers from their own laboratory session

### Target Learners
- post-secondary mechanical engineering students in laboratory sessions

### Learning Goals
- knowledge of machine pieces, functionality and usage
- collaborative knowledge construction and reflection on peer answers
