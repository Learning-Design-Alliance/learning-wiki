# Archaeobotany workshop with a visual identification key and environmental categorisation table for reconstructing Neolithic landscape change

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The workshop had students reconstruct changing landscapes during the transition from Neolithic hunter gatherers to the first farmers by analysing charred seed assemblages. A "simplified visual identification key was provided in figure 9, along with a basic environmenta l categorisation table (Table 1)" associating species such as hazelnut, wheat, hawthorn, oats, grass and oak acorn with forests, meadow and farmland. Instructions for creating a reference collection by charring plant remains at 220-240°C for four hours are included.
