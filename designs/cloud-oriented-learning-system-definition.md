# Cloud-oriented learning system and the adopted definition of cloud services

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The monograph adopts Bykov and Shyshkina's definition of cloud services as services giving the user network access to a scalable, flexibly organised pool of distributed physical or virtual resources supplied "в режимі самообслуговування і адміністрування за його запитом", and defines a cloud-oriented learning system as one in which separate didactic functions are supported through "доцільному, координованому та інтегрованому використанню сервісів хмарних технологій".
