# Flipped learning model for a theoretical nursing course: pre-class assignment, in-class activity, post-class assignment per topic

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article implemented flipped learning in a 10-topic theoretical nursing course structured so that "Each topic had one assignment before class, a learning activity during class, and one assignment after class." Pre-class work required studying lectures, viewing videos, or reading articles; in-class time used case studies, group projects, and discussions; post-class assignments assessed understanding. The instructor evaluated pre-class replies to choose class topics, facilitated activities, and graded assignments.

## Design Implications

### Context
#### Requirements
- Students must complete pre-class work to participate in in-class activities and discussions
- Instructor reviews pre-class submissions to decide which topics need class exercises and discussions
#### Constraints
- Assignments were graded and participation was required as part of student evaluation

### Target Learners
- third-year undergraduate nursing students

### Learning Goals
- understanding theoretical nursing course content
- communication and collaboration skills
- learning independence
