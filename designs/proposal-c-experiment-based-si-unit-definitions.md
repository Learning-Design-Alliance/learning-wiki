# Proposal C: an experiment-based introductory text deﬁning familiar SI units

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
Proposal C is the paper's alternative introduction text, built on the premise that familiar units are best introduced through "brief descriptions of experiments which could be used to realize those units". It lists the second, metre, volt, ohm, kilogram, and a joule section showing energy coherence and scalability across many orders of magnitude. An earlier longer version was pared down after students called it too long and complicated. The article reports it was rated more appealing and clearer than the constants list.
