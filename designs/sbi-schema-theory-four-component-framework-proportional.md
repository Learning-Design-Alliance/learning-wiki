# Schema-based instruction theoretical framework: an elaboration of schema theory integrating four instructional components

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 causal), `q4` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
SBI's theoretical framework is "an elaboration of schema theory" guided by cognitive models of mathematical problem solving (Mayer, 1999). The intervention integrates four major components: a focus on the mathematical structure of problems, use of visual representations (schematic diagrams), explicit problem solving and metacognitive strategy instruction, and an emphasis on procedural flexibility. These components correspond with What Works Clearinghouse recommendations and address CCSS mathematical practices. Instruction uses the four-step DISC strategy (Discover the problem type, Identify information, Solve, Check) with teacher modeling, scaffolded dialogues, and deep-level questions.

## Design Implications

### Context
#### Requirements
- Teachers require professional development (16 hours in this study) to learn to sort problems by type, use schematic diagrams, generate estimates, and select among multiple solution strategies
#### Constraints
- The framework was evaluated for seventh-grade proportional problem solving involving ratios/rates and percents; effects did not extend to a standardized general mathematics measure in this study

### Target Learners
- seventh-grade middle school students

### Learning Goals
- proportional reasoning with ratios, rates, and percents
- problem solving and metacognitive strategy use
- procedural flexibility in selecting solution methods
