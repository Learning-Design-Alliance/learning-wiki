# Dialogue data collection platform interfacing with LLMs via APIs and securely storing dialogue data in a cloud database

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
As the first component of the proposed solution, the authors developed a platform that interfaces with LLMs via application programming interfaces and securely stores dialogue data in a cloud database. Its purpose is an "accessible, secure, and user-friendly method for storing and managing dialogue data across multiple students and sessions". Each recorded dialogue entry includes a unique identifier, timestamp, participant role, model name, user ID, session ID (continuous dialogue with gaps under 15 minutes), and dialogue transcript content.
