# Five-step systematic planning process for designing Facebook-based learning

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A pattern for designing Facebook-based learning using the Isman model's five-step systematic planning process: input, process, output, feedback and learning. The input step identifies needs, contents, goals-objectives, teaching methods, evaluation materials and instructional media. The process step uses an expert panel to test prototypes and redesign instruction. The output step implements the learning with teacher and students. The feedback step revises instruction based on comments from students and teacher. The learning step conducts pre/posttests to test effectiveness.

## Design Implications

### Context
#### Requirements
- Requires an expert panel to redesign the Facebook-based learning produced during the process step.
#### Constraints
- The pattern was applied specifically to design Facebook-based learning to enhance creativity among Islamic Studies students in Malaysian secondary schools.
