# Complementary-advantages account of OBE and PBL integration

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article proposes that OBE's "reverse design" supplies clear direction and purpose while PBL's problem-driven approach offers an engaging context for applying knowledge, so the integration addresses each model's weaknesses. OBE's "goal orientation" compensates for ambiguity in learning direction in PBL, while PBL's "dynamic feedback" lets teachers adjust deviations from OBE's preset path, jointly countering passive indoctrination and disconnection from practice.
