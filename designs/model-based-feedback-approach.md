# Model-Based Feedback Approach

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A framework in which feedback is generated automatically from comparisons between a learner's externalized mental model (as a concept map or causal diagram) and an expert reference model. Two novel forms are introduced: cutaway feedback, which includes all propositions of the learner's model with semantically correct vertices highlighted, and discrepancy feedback, which includes only propositions with no semantic similarity to the expert model. The approach aims to restructure underlying representations and bridge expert-novice differences.
