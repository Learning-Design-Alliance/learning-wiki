# Dataset development exercise: web scraping for digital images and image metadata

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An exploratory assignment in which student groups scrape at least 100 digital images on an assigned theme (an artist's name, color palette, or genre) using tools such as BeautifulSoup, Scrapy, or ParseHub, gather metadata including source URL, image resolution, file size, and licensing information, and deliver a dataset in CSV or JSON format plus a 3-5 page report and commented Python scripts or Jupyter Notebooks. The article states it "was not intended as a worksheet exercise but rather was created as an exploratory assignment for students to research and determine the best choices". It was created for a junior level computer science data analytics or machine learning course.

## Design Implications

### Context
#### Requirements
- A working web scraping script, a dataset of at least 100 digital images with metadata, and a report detailing the scraping process, data collection, and issue resolution
#### Constraints
- The exercise requires multiple phases, iterations, and development experience; the article notes the process of developing a data set generator for an AI tool is a significant undertaking

### Target Learners
- junior-level computer science students in data analytics or machine learning courses

### Learning Goals
- understanding web scraping methods and their limitations and benefits
- examining image metadata for copyright and ownership issues
