# Progressive template-modification lab design: run a template, then modify and extend it

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Across the labs, students first load and run a provided template program, then modify it to explore variations, and finally extend it with their own code. In the BB84 lab, students run a template with n = 4 "a small value so students can trace the executions easily," mark same-basis bit positions, add code to select and compare half the same-basis bits, then increase n to 1000 to verify the program scales. Later experiments add Eve's interception to previously built programs.
