# 1-credit computational laboratory course taught with pair programming

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A 1-credit computational laboratory course accompanies the Paradigm courses and is now required, while a lower-division 3-credit computational physics requirement was removed. The article states the course is taught in a laboratory setting using pair programming to help new programmers learn, and that transfer students now take computation alongside non-transfer students. The removed lower-division course had mixed lower- and upper-division students with very different skill levels and needs, making it challenging to teach.
