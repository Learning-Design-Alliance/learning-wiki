# Dual-condition reinforcement-sensitivity indexing of visuospatial WM and STM in ADHD subtypes

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The study operationalizes reinforcement sensitivity by administering the same visuospatial WM and STM tasks under two conditions: a standard feedback-only condition and a high-reinforcement condition adding a monetary reward. Reinforcement sensitivity is then indexed as the difference in performance between the reinforcement conditions, allowing motivational impairment to be measured separately from baseline memory capacity. This design also permits subtype comparisons (ADHD-C vs ADHD-I vs controls) while controlling for the interaction between motivational impairments and cognitive performance.

## Design Implications

### Context
#### Requirements
- Administration of identical visuospatial WM and STM tasks under both a standard feedback-only condition and a high-reinforcement condition
#### Constraints
- Reinforcement sensitivity is operationalized only as the performance difference between the two conditions, not as a broader motivational construct

### Target Learners
- children aged 8-12 with ADHD-C or ADHD-I
- typically developing children aged 8-12

### Learning Goals
- measuring visuospatial working memory and short-term memory capacity
- indexing sensitivity to reinforcement
