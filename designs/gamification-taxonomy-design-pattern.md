# Gamification taxonomy-based design pattern for educational games

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The learning application incorporates seven key elements based on the gamification taxonomy of Toda et al.: Acknowledgement, Imposed Choice, Novelty, Objectives, Progression, Renovation, and Sensation. These elements are instantiated concretely in the game, e.g., confetti rain for acknowledgement, collider visualization for novelty, and level targets for objectives. This pattern links game mechanics to learning support by rewarding correct configurations and guiding players through progressive levels.
