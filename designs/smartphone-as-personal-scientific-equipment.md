# Smartphone as personal scientific equipment replacing shared data loggers

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The pattern substitutes a data logger with a smartphone so that every student can possess his/her own measuring tool inside and outside the classroom, instead of sharing within a large group in a scheduled lab. Sensor-aware apps built with Easy Java Script Simulation let students conduct experiments and collect real-time evidence anytime and anywhere, supporting the joy of learning.

## Design Implications

### Context
#### Requirements
- custom web, Android and iOS apps per experiment; web apps run in the Google Chrome browser for best compatibility
#### Constraints
- the iOS app is currently less developed

### Target Learners
- Grades 11 and 12 physics students

### Learning Goals
- conducting authentic physics experiments
- collecting and analyzing real-time experimental data
