# Teach programming through accompanied learning-by-doing on physics problems, with team-based tasks and clear disciplinary application context.

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The authors' stated pedagogical approach is that learning a programming language works best through "begleitetes Learning-by-doing anhand physikalischer Fragestellungen". Small programming tasks solved in teams strengthen peer exchange and build a solution-oriented discussion culture early in the degree, while the physics content must remain foregrounded so that motivation and durable competence arise from visible application relevance.

## Design Implications

### Context
#### Requirements
- Tasks must be tied to clear physics application context; "Nur wenn der Anwendungsbezug klar ersichtlich ist" will sustainable competence and motivation follow.
#### Constraints
- The authors caution that "vor lauter Programmieren die Inhalte des Fachstudiums nicht in den Hintergrund treten".

### Target Learners
- first-semester physics bachelor students with heterogeneous prior programming experience

### Learning Goals
- programming skills
- computational data analysis competence
- scientific discussion culture
