# Sim + LBL four-phase hybrid lesson pattern: preparation, scenario simulation, structured feedback, and post-session assessment

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A lesson-level instructional pattern combining scenario-based simulation with lecture-based learning in four sequential phases. Students first collaboratively develop and rehearse case scripts, then perform a timed simulation, then receive instructor-facilitated structured feedback with peer assessment, and finally complete a closed-book test and questionnaire. The article states the model "required students to preview core concepts before class and to engage in structured role-play during simulated outpatient consultations", embedding real-time simulation within lecture sessions.

## Design Implications

### Context
#### Requirements
- Cases must be designed to curriculum guidelines and reviewed by senior faculty to ensure consistent difficulty and learning objectives across groups
- Instructors act as non-intervening observers during simulation, interrupting only if performance deviates significantly from the intended theme
#### Constraints
- Evidence base is a single-site, non-randomized two-cohort comparison in one course module; the authors call for randomized trials and multi-center validation

### Target Learners
- undergraduate clinical medicine students

### Learning Goals
- clinical reasoning
- doctor–patient communication
- teamwork
- autonomous learning
- STD module knowledge
