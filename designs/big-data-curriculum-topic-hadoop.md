# Big data as a proposed curriculum topic built on open-source Hadoop and related technologies

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article proposes big data analysis as a curriculum addition, defining big data not only as large in size but as data that cannot be processed with traditional methods and tools. It cites 2012 figures that 2.5 exabytes of data were produced daily and that more than 80% of world data is unsecured with only 0.5% analyzed. It names "Hadoop, JAQL, HBASE, NOSQL kavramları büyük verinin ilgi alanındaki teknolojilerdir" and notes Hadoop is open source, so there is no barrier to adding it to the curriculum. Some universities such as Columbia offer graduate-level courses.
