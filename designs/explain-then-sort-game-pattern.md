# Two-activity gamified session: scene-based explanation followed by a step-sorting game with feedback

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The module's first activity explains the procedure through a succession of scenes, each describing one step; the second is a game in which the four steps are shown in the wrong order and the child assigns the correct figure to each number. "For each step, the robot gives feedback to the child, inviting him or her to try again if he or she has made a mistake," and the game ends with a score shown to the child.
