# Stokes–Mueller matrix framework for polarized light and optical elements

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article presents the classical Stokes-vector formalism: four Stokes parameters S0–S3 built from electric-field amplitudes, the degree of polarization Π, and depolarization D=1−Π, with the action of optical devices described by real 4x4 Mueller matrices via Sfinal=M.Sinitial. It supplies the Mueller matrices for a rotating linear polarizer and a rotating retarder used in the lab, and notes the Stokes nondiagonalizable Mueller matrix can describe depolarization. Students use this framework to derive expected detector intensities and compare them with measurements.

### Context
#### Requirements

- predict transmitted intensity through polarizing optical systems
