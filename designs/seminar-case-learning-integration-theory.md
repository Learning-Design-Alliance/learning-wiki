# Seminar-case learning (SCL) as an integration of seminar dynamics and case-based clinical reasoning

## Description
The article defines SCL as "an innovative teaching methodology that effectively combines seminar and case-based learning (CBL), which integrates the dynamic mutual communication characteristic of seminar learning with the clinical reasoning in CBL." Seminar learning uses small-group discussions under teacher guidance emphasizing continuous teacher-student interaction, while CBL employs clinical cases to link theoretical knowledge to practice through inquiry-based methods. The article applies this framework to postgraduate orthodontic education.
