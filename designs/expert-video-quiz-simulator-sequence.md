# Expert-video-then-quiz-then-simulator sequence providing real-lab context for each virtual experiment

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each experiment module opens with "a short video showing an expert instructor running the real experiment in the lab, which provides context for the simulator", followed by "a short quiz" testing comprehension. The video includes narration, close-ups and still images illustrating scale, layout and assembly, laser safety cautions, beam exploration with an index card, and alignment tips. Students then measure critical dimensions with uncertainties from images with an embedded ruler using ImageJ before running the simulator.
