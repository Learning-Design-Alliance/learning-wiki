# Kibana 2D dashboard as the on-screen comparison condition

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Kibana serves as the traditional 2D comparison condition: "a computer with a web browser displaying a K IBANA dashboard that includes var ious panels for visualizing repository metrics". In the planned experiment it shows the same CHAOSS and OpenShift repository metrics as the VR condition, at the same five aggregation levels, so that accuracy, efficiency, learning outcome, and experience can be compared across modalities.
