# Wavelet seminar series with computer-projector demonstrations using the Matlab Wavelet Toolbox

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A sequence of four two-hour seminars on wavelets given by the author, spanning introductions for scientists and applications in physics and astrophysics. Each used multimedia: a "computer-projector show using the Matlab Wavelet" Toolbox on a high-performance Linux machine in a public computer lab, with the final seminar also using the MR/1-MR/2 Software Packages documentation. The seminars were open to a wide scientific audience.
