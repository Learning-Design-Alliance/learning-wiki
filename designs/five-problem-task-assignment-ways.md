# Five ways of assigning problem tasks within interactive lessons

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Within the P&E method each problem task can be assigned in five ways, summarised in Table 1: text solved theoretically; text solved via a real or computer-aided experiment; an unfinished experiment/video-experiment/simulation where students predict the result and the experiment is then carried out to verify the theory; a finished experiment whose physical course or result must be reasoned theoretically; and a finished experiment solved via video-analysis. The authors report that "various variations of problem task solving influence students very positively", teaching them that a problem can be assigned and solved in different ways and that a procedure effective in one case need not be effective in another.

## Design Implications

### Context
#### Requirements
- Students' worksheets and teachers' guidelines created for each way of problem task assignment
#### Constraints
- Assignment formats rely on available experiments, video-experiments, simulations and applets

### Target Learners
- first-year university physics students

### Learning Goals
- physical reasoning and analysis of phenomena
- flexibility in problem-solving procedures
- connecting formalism to everyday life
