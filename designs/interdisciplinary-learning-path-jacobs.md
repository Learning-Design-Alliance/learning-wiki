# Interdisciplinary learning path (Jacbs-style conscious multi-discipline approach to a central theme)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article adopts Jacobs' definition that an interdisciplinary path applies methodology and language from more than one discipline to examine a central theme, and uses it to build the sound-and-noise path across physics, biology, phonetics and electronics. It argues this builds bridges between disciplines, aids understanding of complex concepts such as energy transport, resonance and transduction, and promotes advanced scientific literacy.
