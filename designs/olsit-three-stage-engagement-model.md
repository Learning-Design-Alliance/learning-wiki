# OLSit three-stage model of student-centered engagement (Own It, Learn It, Share It)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The OLSit model is a three-stage design framework for student-centered learning built from a literature synthesis of research on student engagement, autonomy, scaffolding, motivation, and meta-cognition. In the Own It phase, "students define their purpose and create a learning plan with the assistance of the teacher"; in the Learn It phase the student engages in learning activities operationalized through a learning plan; in the Share It phase the student identifies channels for sharing learning with an authentic audience. Edyburn re-examines the model as applicable to COVID-19 remote instruction.
