# HBOPPPS hybrid teaching model with online resource library for Physiology at Harbin Medical University

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
HBOPPPS is a hybrid teaching method introduced in 2019 that incorporates online instructional techniques into the offline BOPPPS framework (Bridge-in, Objective, Pre-assessment, Participatory learning, Post-assessment, Summary). The team built an online resource set including "course-associated micro-lecture videos (85 in total, 5 ∼ 10 min/video)", science stories, lectures by renowned doctors, virtual simulation experiments and chapter tests. Pre-class course guidance was delivered through the "Xuexi Tong" mobile application, with in-class interactive elements such as sign-in procedures, multi-choice questions and task allocation.
