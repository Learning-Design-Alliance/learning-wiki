# TTAT-derived game design framework for avoiding phishing attacks through motivation

> **Design** · [All designs](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (1 causal, 1 associational, 1 design), `q2` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
The book proposes a game design framework in which the elements of a model derived from Technology Threat Avoidance Theory are addressed so that computer users avoid phishing attacks through motivation. As the book states, "The elements of a theoretical model derived from Technology Threat Avoidance Theory (TTAT) were used to address in the game design framework (Liang and Xue, 2010)." Under TTAT, avoidance behaviour is predicted by avoidance motivation, determined by perceived threat, safeguard effectiveness, safeguard cost and self-efficacy, with perceived susceptibility and severity shaping threat perception. The framework treats game-based anti-phishing education as the safeguarding measure.

### Learning Goals
