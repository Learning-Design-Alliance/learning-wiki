# The ADDIE model as a framework for designing simulation-based delineation training

> **Design** · [All designs](index.md)

## Description
The article presents ADDIE (analysis, design, development, implementation, evaluation) as "a structured framework that is a widely used instruction" for building educational programs targeting learner needs, and applies it phase by phase to an SBL program for radiation oncology delineation skills. Each phase is mapped to concrete tasks: needs and learner analysis, course design, case scenario and rubric development, implementation logistics, and Kirkpatrick-based evaluation.
