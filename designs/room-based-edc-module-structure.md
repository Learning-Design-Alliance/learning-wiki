# Household-room-based e-learning module structure pairing interactive visuals, short videos, matching quizzes, and flash cards per thematic subsection

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The module was structured into 7 thematic subsections (introduction, kitchen, bathroom, bedroom and living room, outdoors, conclusion), each following a consistent structure of texts and interactive visuals, a video on health effects, matching-exercise quizzes, and flash cards presenting preventive measures. The article states "Each subsection followed a consistent structure (Table 1)" and that the module was developed using the Rise 360 platform enabling "interactive and adaptive e-learning content." Virtual rooms displaying household objects containing EDCs were created using Microsoft Copilot AI, and educational videos were ≤3 minutes each.
