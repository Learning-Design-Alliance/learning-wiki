# A code-hiding approach to physics programming exercises that shows students the physics aspects of simulation code while obscuring other details

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article describes an approach in which browser-based p5.js exercises expose only the physics-relevant code to students while hiding the rest in subroutines. The authors state that "this framework can be used to highlight the physics aspects of an interactive simulation code while obscuring other details", so that "absolute beginner programmers" can modify and run programs "without becoming overwhelmed". The result is "a kind of hybrid of a web interactive where the student sees some but not all of the code".

## Design Implications

### Context
#### Requirements
- Exercises must be simple, browser-based, interactive, step-by-step, and integrated into the physics curriculum, per the five design premises carried over from the classical mechanics exercises
#### Constraints
- Calculus content is limited because students need only first-semester calculus to enroll; exercises reflect this algebra-based emphasis

### Target Learners
- absolute beginner programmers in high school or early undergraduate introductory physics

### Learning Goals
- introductory electromagnetism concepts such as electric fields, circuits, magnetic force, and wave interference
