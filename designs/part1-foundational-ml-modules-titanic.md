# Part 1 foundational machine learning modules built around the Titanic dataset

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Part 1 comprises four integrated modules: data science fundamentals and exploratory analysis using the Titanic dataset, feature engineering and data preprocessing, model development and evaluation, and advanced machine learning concepts. Students "implement multiple algorithmic approaches (including logistic regression, random forests, and support vector machines) on consistent datasets, enabling direct performance comparisons" and build feedforward networks, CNNs on MNIST, and RNNs for sequence prediction.
