# A three-problem pedagogical sequence progressing from model construction to quantitative data analysis to wave kinematics

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article organizes its three Context-Rich Problems as a sequence: Problem 1 builds the fireball model by dimensional analysis, Problem 2 applies that model to real video data to estimate the energy, and Problem 3 analyzes wavefront arrival times. The authors state that "Although each problem is independent and self-contained, these three activities can also be regarded as a pedagogical sequence", with each problem formulated as a story, an explicit student-facing problem statement, and a proposed solution with data acquisition.

## Design Implications

### Context
#### Requirements
- Each problem is self contained, with a brief introduction, an explicit formulation of the problem written for students, and a proposed solution including data acquisition.
#### Constraints
- Appropriate planning is required for the teacher to allocate the necessary classroom time, roughly 45–60 minutes per problem with delivered data or about 90 minutes with student data acquisition.

### Target Learners
- higher education / university physics students

### Learning Goals
- dimensional analysis
- energy released by an explosion
- wave propagation
- collaborative problem solving
