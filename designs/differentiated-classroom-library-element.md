# Rich differentiated classroom library as a reading-motivation component

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each classroom maintained a library of children's newspapers, comics, poetry, story-books, fairy-tales, activity books, encyclopedias, and Bible stories, organised by topic across genres. The library was active all day long, accessible after task completion or for relaxation, with a lending system for take-home books and activity cards prompting written responses (letter to a character, alternative endings, story continuation).
