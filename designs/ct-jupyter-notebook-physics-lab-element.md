# Computational thinking tasks using Jupyter Notebooks in the physics laboratory

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Since Fall 2022 the laboratory has incorporated computational thinking tasks in which students, using "Jupyter Notebooks [41] hosted on Google Colab", created flowcharts to outline algorithms and/or coded in Python. Students were not required to have prior programming experience; tasks emphasized applying physics concepts by editing and modifying existing Python code related to the lab's physical principles, with carefully designed scaffolds supporting programming learning in context. This element underpins the CT component of WoT4EDP.

## Design Implications

### Context
#### Requirements
- Carefully designed scaffolds to support students learning programming within the context of their laboratory experiments
#### Constraints
- Computational tasks emphasized editing and modification of existing Python code rather than programming from scratch

### Target Learners
- Undergraduate introductory physics students without prior programming experience

### Learning Goals
- Computational thinking: decomposition, pattern recognition, abstraction, algorithm design, automation, and debugging
