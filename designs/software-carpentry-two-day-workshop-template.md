# Two-day workshop template: shell, Python/R, version control, and SQL in service of computational competence

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Software Carpentry's core pattern is a two-day workshop with four half-day blocks: the Unix shell, programming in Python or R, version control, and databases with SQL. The stated aim is not any specific tool but "to teach computational competence", using concrete tools to introduce higher-level concepts "without learners really noticing". Rooms are capped at 40 learners with at least one helper per eight learners, and a pre-assessment questionnaire streams learners by prior experience.

## Design Implications

### Context
#### Requirements
- Volunteer instructors recruited from past participants, plus local helpers during practicals
- A pre-assessment questionnaire to stream learners by prior experience
#### Constraints
- Software setup remains a persistent problem, and the pace of instruction suits some learners poorly
- Content varies widely across workshops, which the author calls a strength but wants to vary on purpose rather than by accident

### Target Learners
- Graduate students and researchers in the physical, life, and social sciences with little practical software training

### Learning Goals
- Program design, task automation, version control, testing, and working with structured data
