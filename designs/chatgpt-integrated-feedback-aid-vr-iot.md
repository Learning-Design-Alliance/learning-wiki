# ChatGPT-integrated feedback aid within a VR learning environment for embedded IoT tasks

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A VR learning environment for embedded IoT tasks in which ChatGPT supplies targeted, real-time feedback to learners, replacing or augmenting traditional VR feedback mechanisms. The environment was "structured into six learning units aligned with Bloom's taxonomy," and the experimental condition paired it with GPT feedback while the control used traditional feedback. The article presents it as a way of integrating generative AI technologies like ChatGPT into VR learning to support deeper engagement and more effective learning outcomes.

## Design Implications

### Context
#### Requirements
- A VR learning environment with learning tasks (here embedded IoT tasks) organized into units aligned with Bloom's taxonomy, into which ChatGPT-generated feedback can be integrated
#### Constraints
- The structured scope of learning tasks may not have encouraged open-ended creative exploration, per the authors' account of the limited creativity impact

### Target Learners
- undergraduate students

### Learning Goals
- embedded IoT task knowledge and skills across cognitive levels
- higher-order thinking skills
- self-regulated learning
