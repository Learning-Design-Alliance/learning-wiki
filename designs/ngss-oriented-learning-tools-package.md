# NGSS-oriented learning tools: lesson plans, worksheets, and a developing-and-using-models observation sheet

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A package of science learning tools developed for grade 8 human respiratory system instruction: lesson plans, student worksheets, and an observation sheet for assessing developing-and-using-models skill. The tools were validated by two expert lecturers, one science teacher, and nine students across two revision stages, and used in a quasi-experiment comparing an NGSS-oriented class with a control class using the teacher's tools. The article reports the tools "are feasible for use in learning, based on results of expert validation".

## Design Implications

### Context
#### Requirements
- Worksheets must meet didactic conditions so they "could be used well for students at all levels of intelligence", appropriate language and clarity, and technical requirements of writing, drawing, and appearance
- Lesson plans and worksheets are feasible if their average validation score is above 3.0; the skill appraisal tool if validation is in the good category at 76-85%
#### Constraints
- Validated for the human respiratory system theme in grade 8 at one Indonesian junior secondary school

### Target Learners
- Grade 8 junior secondary science students

### Learning Goals
- Developing and using models skill
- Practical skill assessment in science
