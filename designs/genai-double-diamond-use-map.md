# GenAI use across the Double Diamond design process: Discover brainstorming, Define storyboards and use cases, Develop assets and prototyping, Deliver documentation and feedback synthesis

## Description
The article maps the specific ways students applied GenAI onto the Double Diamond design process, based on 12 group interviews (see Figure 1). Uses span "Discover" (tech-driven idea brainstorming, user interview question and insight generation), "Define" (storyboard generation, use case development), "Develop" (visual asset creation, prototyping assistance, hardware integration), and "Deliver" (documentation automation, feedback synthesis). The mapping highlights how GenAI facilitated creativity in Discover and documentation and feedback analysis in Deliver.
