# Three-theory design framework for the VFT module: constructivism, information processing, and Mayer's Cognitive Theory of Multimedia Learning

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article states that "The concepts of learning using a VFT include the theories of constructivism, information processing and cogniti on of multime dia learning." Constructivist elements include communication columns and exploratory links so students actively construct knowledge; information processing motivates repeatable access so information moves from sensory register through short-term to long-term memory via repetition and encoding, following Gagne (1985); and Mayer's Cognitive Theory of Multimedia Learning (dual channel, limited capacity, active processing assumptions) motivates combining text, graphics, video and audio to deliver complex and abstract concepts more easily.

## Design Implications

### Context
#### Requirements
- Multimedia elements (text, graphics, video, audio) so learners process words and pictures in parallel channels
- Repetition: the module must be re-accessible so students can extend limited short-term memory through repetition
#### Constraints
- The framework is the article's stated design rationale for this module; the article does not test the theories themselves

### Target Learners
- Form Four (secondary) Biology students

### Learning Goals
- Understanding colonization and succession concepts in mangrove ecosystems through active, multimedia-supported construction of knowledge
