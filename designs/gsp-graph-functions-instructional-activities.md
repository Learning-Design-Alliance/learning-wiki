# Geometer's Sketchpad-based instructional activities for graph functions

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A ten-week set of instructional activities in which Form Six students used Geometer's Sketchpad worksheets, each student with access to one computer equipped with the software, to draw algebraic, trigonometric and absolute value functions. The article states the activities "allowed the students to explore, discover  and investigate the concepts of  graphing of functions". The control group used only textbooks with chalk-and-talk teaching.

## Design Implications

### Context
#### Requirements
- Each student has access to one computer equipped with the Sketchpad software
- Activities follow the Form Six mathematics syllabus and curriculum specifications for graph functions
#### Constraints
- Evaluated in a single urban Malaysian secondary school with intact Form Six classes

### Target Learners
- Form Six (Grade 12) secondary students

### Learning Goals
- Graphing and understanding properties of algebraic, trigonometric, and absolute value functions
