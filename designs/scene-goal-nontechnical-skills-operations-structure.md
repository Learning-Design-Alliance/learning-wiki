# Scene-oriented scenario structure pairing each scene's goal with required non-technical skills and concrete operations

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each simulation scene was standardized to include "a goal, the required non-technical skills, and the concrete operations needed to achieve that goal". For example, Scene 1's goal is identifying the need for basic hand hygiene and performing it, requiring the participant to use clinical reasoning to guide the nurse avatar to the sink and activate it. This structure anticipated future standardization of scenario description models for simulation.
