# Introduce jumping physics with a model solvable using only constant-acceleration equations so it fits algebra-based courses

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article argues the jump model's pedagogical value lies in its algebraic accessibility: "the motion can be calculated using only the constant acceleratio n equations, making the example suitable for algebra-based physics." Because collisions are traditionally taught after Newton's 3rd law and constant acceleration, Appendix A rederives the locking velocity Eq. (2) via a constant force impulse approximation (a large force F′ acting over a vanishing distance ǫ), so "the model can be introduced earlier" in the course.

## Design Implications

### Context
#### Requirements
- The Appendix A impulse approximation, in which the attractive force F′ is made very large while the distance ǫ is made very small so their product is unchanged, to avoid collision equations
#### Constraints
- Accurate biomechanical models with many rigid bodies "resists any attempts at an analytic solution", and spring-based analytic models "require the solving of diﬀerential equations"; this model is a simplified "budget model against which more so phisticated models can be compared"

### Target Learners
- Algebra-based introductory physics students

### Learning Goals
- Apply Newton's 3rd law and constant-acceleration kinematics to a realistic biomechanical scenario
