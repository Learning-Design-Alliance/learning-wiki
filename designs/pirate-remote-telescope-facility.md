# PIRATE robotic telescope facility for distance-teaching practical astronomy

## Description
PIRATE is the Open University's remotely operable robotic telescope, piloted in 2008 at the Observatori Astronomic de Mallorca and later relocated to the Observatorio del Teide in Tenerife as part of the OpenScience Observatories. It supports real-time student observing sessions and autonomous queue-scheduled operation: its ABOT control software "provides both a web control interface for real-time use and manages the fully autonomous queue-scheduled mode of operation." It is embedded in OU modules SXPA288 and S382 for color-magnitude diagram and variable-star projects.

## Design Implications

### Context
#### Requirements
- A robust site infrastructure and stable internet connection for sustainable curriculum use
- An on-call Night Duty Astronomer for the first session briefing and technical problems
#### Constraints
- In the Mallorca phase, unstable power supply and internet speed caused occasional system glitches affecting the observing experience
- The NDA post is a limited resource and not a full-time support astronomer

### Target Learners
- Open University distance-learning undergraduate and postgraduate students

### Learning Goals
- Basic experimental and observational skills including planning, record keeping, uncertainty awareness, and report writing
- CCD image data reduction and aperture photometry
