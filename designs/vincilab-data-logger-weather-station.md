# VinciLab data-logger weather station for ready-made long-term data collection

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A weather-station version built with the Coach system for STEM education and a VinciLab data logger, intended for schools whose primary goal is working with measured data rather than construction and programming. Pressure, temperature, and humidity sensors were installed in a 0.5 L plastic bottle on a windowsill out of direct sunlight, with the pressure sensor left in the room. The measurement used "a VinciLab data logger, set for long-term measurement (72 hours), with data recording every minute", after which data was processed in MS Excel.

## Design Implications

### Context
#### Requirements
- A VinciLab data logger and suitable sensors; data is transferred via USB flash drive after measurement and processed in Coach 7 software or MS Excel
#### Constraints
- The pressure sensor was kept indoors while temperature and humidity sensors were placed outdoors in a plastic bottle, so measured quantities come from different locations

### Target Learners
- secondary school students focusing on data acquisition, processing, and evaluation

### Learning Goals
- long-term measurement of atmospheric quantities
- data processing and graphing in MS Excel
