# Transparency-first design pattern: exploratory device-familiarization exercise with visualization before data collection

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1`–`q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
This lesson-level pattern opens a laboratory sequence with an exploratory exercise that makes the data-collection instrument itself an object of study before students use it for experiments. In MyTech, students first "undertake an initial exploratory laboratory exercise designed to introduce them to the operation of the smartphone as a kinematic data-taking device," examining the ball-and-spring visualization and predicting accelerometer graphs for hypothetical experiments using common active learning methods. The pattern aims to remove the black-box opacity that otherwise leaves students unable to explain their instruments.
