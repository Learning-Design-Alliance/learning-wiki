# Lecture video 'Creating a Computer Model of Constant Velocity Motion' with five instructor-created interaction points

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A ~17.5-minute (1052-second) Coursera-hosted video that was students' first introduction to using Python to model physical phenomena in a flipped M&I mechanics course. It teaches students to create a computational model based on Newton's 2nd law for constant-velocity motion of a ball, and "has five such interaction points" — instructor-created points that auto-pause the video and prompt students to click a link or answer a question. The second interaction point linked to the starter Python script files; the last three posed conceptual questions about the Python code.

## Design Implications

### Context
#### Requirements
- Students were given the same observational data and encouraged to practice creating the model themselves as they watched
#### Constraints
- Clicking the download link opens a new page without changing the URL, so students could ignore the video after clicking

### Target Learners
- undergraduate students in a flipped calculus-based introductory mechanics course

### Learning Goals
- building computational models of motion from Newton's 2nd law in Python
- variable assignment, iteration, and commenting
