# Paired-associate declarative memory task with letter-number working-memory control for circadian confounds

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The study's measurement package: a paired-associate test of semantically related and unrelated word pairs (e.g. tree/leaf; lamp/shoe) presented aloud three times, scored by number correct at 12-hour cued recall, plus a letter-number sequencing subtest of the WAIS-III/WMS-III given before learning and before testing. The letter-number task "was administered to control for possible circadian confounds and to control for attention and encoding", allowing the sleep effect to be isolated from time-of-day effects.

## Design Implications

### Context
#### Requirements
- Administration in a quiet, distraction-free room at matched 9am/9pm times of day
- Two alternate versions of the letter-number task used in random order
#### Constraints
- Applied to auditory verbal paired-associate material in adolescents aged 10-14 on non-school days

### Target Learners
- early adolescents aged 10-14

### Learning Goals
- declarative memory consolidation measurement
