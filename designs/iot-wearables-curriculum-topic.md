# Internet of things and wearable technologies as proposed curriculum topics centered on scenario-based system design

## Description
The article defines the internet of things as the capability of everyday objects to connect to the internet network and send and receive data, covering applications from smart cities and e-health to industrial control. It proposes a course focusing on how system design should be done, since designs are application-specific and need-driven. It illustrates with an electronic-card smart greenhouse automation for areas with limited internet and electricity access (Şekil 1), stating a student needs knowledge of databases, microprocessors, computer networks, mobile application development and web page development, so such a course targets senior students. Wearable technologies are treated as a possible sub-branch of IoT.
