# BT Access Database: a Moodle-built course for developing digital competences in databases and Microsoft Access 2007

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An educational software course built on the open-source Moodle platform (via www.edu.moodle.ro) for XII-grade technical-college students, covering the baccalaureate Databases unit. The article states "The software developed is a course called BT Access Database . A course can contain resources and activities." It uses LABEL for information, RESOURCE for Word documents and PowerPoint presentations, a video created with Adobe Captivate about creating databases, TESTS, LESSONs, CHAT, FORUM, CHOICE, WIKI, ASSIGNMENTS, WORKSHOPS, GLOSSARY and an "Upload a single file" option for checking Access activities. Moodle is described as a course management system designed on constructivist principles, used by over 34 million users in over 200 countries and available in over 70 languages.
