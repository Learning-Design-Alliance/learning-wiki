# Class experiment pattern: a practiced class and unpracticed control classes taking identical pre- and post-tests to study practice, transfer, and interference

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article demonstrates a class experiment in which one class practices a skill (translating English into a code) for twenty-two trials while control classes take the same five tests without intervening practice, twelve working days apart. Students plot their own learning curves, compute percentage gains, compare morning and evening performances, and write discussions of transfer and interference. The design lets a class illustrate individual differences, learning-curve characteristics, correlation, and facilitation or interference, with the article noting that "An unpracticed or control group is needed in order to test this question."

## Design Implications

### Context
#### Requirements
- Test intervals should be the same in all groups; the article notes circumstances made this impossible in the present experiment, with intervals of sixteen, nine, and nineteen calendar days.
#### Constraints
- Materials must be tasks in which the student is not already practiced and in which improvement is possible within a relatively short practice; the article calls the tasks used artificial and recommends more useful ones.
