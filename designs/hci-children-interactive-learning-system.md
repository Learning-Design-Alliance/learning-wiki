# Layered HCI interactive learning system for children's education with VR/AR content

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 3 claims rest on one study

## Description
An interactive learning system for children in grades 1–6 that integrates multimedia technologies including VR and AR to create a dynamic learning environment. Its architecture comprises a user interface layer, an interactive logic layer, a content management layer, a data management layer and a database system; the article states the user interface layer encompasses "all front-end elements, such as buttons, pictures, videos, and interactive games". Educational content is stratified by children's age and learning ability.

## Design Implications

### Context
#### Requirements
- Event-driven interaction logic with real-time response to user inputs
- Multi-level database architecture for user information, learning progress and interactive data
- Age-stratified educational content tailored to cognitive level
#### Constraints
- Evaluated primarily in a single educational institution
- Performance assessed under controlled conditions; real-world environments may vary due to network instability or differing hardware

### Target Learners
- children in grades 1–6 (ages 7–12)

### Learning Goals
- foundational mathematics and science knowledge
- engagement and personalized learning
