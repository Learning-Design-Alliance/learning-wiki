# Inquiry-based learning cycle as the organizing framework for AI-assisted lesson design

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article adopts the inquiry-based learning cycle, citing Pedaste et al., as the pedagogical framework structuring teacher–ChatGPT interaction. Its phases are named as "orientation, conceptualization, investigation, conclusion and discussion," and each phase receives its own prompt and set of three evaluated options, giving teachers a structured educational framework for receiving several perspectives on what they want to teach.
