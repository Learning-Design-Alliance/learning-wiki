# Instructional root-cause analysis fishbone diagram for diagnosing the CP course

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Before redesigning the course, the author integrated instructional and root-cause analysis techniques, using a fishbone diagram (Figure 1) with the main problem statement "poor PS sk ills and knowledge transfer". The main branches were Programming Language, Learners, Instructors and Instructional Approach, with sub-branches such as the language paradigm, learner attitudes, instructors' teaching styles and learning goals. The analysis "guided how to assess the current needs, learners, environment, tasks and goals" and informed the choice of C, PS strategies and web support.

## Design Implications

### Context
#### Requirements
- Systematic identification of potential main and sub-causes "before jumping to a conclusion"
#### Constraints
- Diagnosis was specific to the faculty's three-decade-old teacher-directed CP course context
