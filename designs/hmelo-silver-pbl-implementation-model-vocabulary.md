# Hmelo-Silver's four-step PBL implementation model applied to vocabulary tasks

## Description
The article used Hmelo-Silver's (2004) model for practical implementation of PBL. As printed, "the learning process begins by exposing a real-life problem to the students, generating hypothesis about the problem, application of hypotheses to check them, reapplication after amendment (through peer and tutor feedback)". The researcher extracted the teaching method from this model plus constructivism and Bloom's higher-order thinking, and designed the problem-based vocabulary tasks based on it.

## Design Implications

### Context
#### Requirements
- A real-life problem must be exposed to students to start the process
- Peer and tutor feedback must support amendment and reapplication
#### Constraints
- The article states availability of problem-based materials for language classes and a step-by-step procedure for PBL in language classes were limiting issues the researcher had to overcome by designing tasks herself
