# TARGET's adapted Fabula Model for narrative control rather than natural-language story generation

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
TARGET adapts the Fabula Model, whose elements (Event, Perception, Internal Element, Goal, Action and Outcome) are causally connected. Because TARGET formalises events for "narrative control" rather than semantic natural-language writing, the weak enablement relation is discarded and causal connections are left semantically untyped. Used with human characters, only the viewpoint character's actions are represented in the emerging fabula.

## Design Implications

### Context
#### Requirements
- Fabula elements causally connected, with enablement relations left implicit rather than explicit
#### Constraints
- Internal Elements, Goals, Outcomes and event Perceptions of a player cannot be perceived by the system, so only viewpoint character actions are represented
- What caused a given viewpoint character's action is not represented, which the authors argue is not a limitation because player actions are not controlled

### Target Learners
- players controlling a viewpoint character in TARGET serious games

### Learning Goals
- formalising story events to pursue learning-goal oriented narratives
