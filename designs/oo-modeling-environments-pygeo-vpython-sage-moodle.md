# Комплекс соціально-конструктивістських середовищ об’єктно-орієнтованого моделювання (PyGeo, VPython, Sage, Moodle, Web 2.0)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Монографія відбирає та описує набір програмних середовищ для навчання об’єктно-орієнтованого моделювання майбутніх учителів: PyGeo — «соціально-конструктивістське середовище об’єктно-орієнтованого моделювання геометричних об’єктів», VPython — «середовище об’єктно-орієнтованого моделювання фізичних процесів», Sage — «середовище об’єктно-орієнтованого моделювання математичних об’єктів», Moodle — «соціально-конструктивістське середовище підтримки навчання об’єктно-орієнтованого моделювання», а також соціально-конструктивістські засоби Web 2.0. Кожне середовище має окремий підрозділ розділу 2.4 з методикою використання.

## Design Implications

### Context
#### Requirements
- Використання в межах спецкурсу «Об’єктно-орієнтоване моделювання» разом із соціально-конструктивістськими формами організації та методами навчання
#### Constraints
- Середовища розглядаються стосовно моделювання об’єктів відповідної предметної природи (геометрія, фізика, математика)

### Target Learners
- майбутні учителі природничо-математичних дисциплін

### Learning Goals
- компетентність з об’єктно-орієнтованого та комп’ютерного моделювання
