# Dual CTML-CLT framework with Gagné's Nine Events guiding segmented-interactive video design

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The study's conceptual framework integrates Cognitive Load Theory, the Cognitive Theory of Multimedia Learning, and Gagné's Nine Events of Instruction to structure the segmented-interactive video. Intrinsic load reflects task complexity and extraneous load reflects poorly designed elements; reducing both optimizes germane load for schema construction. CTML rests on "dual channels (verbal and pictorial processing), limited capacity, and active processing", while Gagné's events sequence learning activities across communication, technical skills, and competency domains, supporting self-directed learning through structured segments.
