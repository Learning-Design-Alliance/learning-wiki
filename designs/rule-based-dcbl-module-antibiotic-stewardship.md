# Rule-based Digital Case-Based Learning (DCBL) module with algorithm-triggered formative feedback

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
A digital learning module comprising three online micro-cases (URTI, UTI, acute watery diarrhoea) built on "a rule-based branching logic architecture". At each decision node, "pre-authored, expert-reviewed formative feedback" was automatically triggered based on the learner's selection. The platform deliberately used no generative AI or large language model. Cases were designed to activate illness-script formation consistent with script theory.

## Design Implications

### Context
#### Requirements
- Requires pre-authored, expert-reviewed feedback content at each decision node
- Requires branching clinical logic with predefined response options
#### Constraints
- The platform did not use generative artificial intelligence and did not generate de novo adaptive text

### Target Learners
- Third- and fourth-phase MBBS learners

### Learning Goals
- Antibiotic-stewardship clinical reasoning
- Clinical decision-making under uncertainty
