# Game jams as pedagogical spaces combining co-creation, co-production and co-design with four learning types

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article frames game jams as constructivist learning environments that emulate industrial processes (co-creation, co-production, co-design) and host four learning types: "The type of learning that takes place during game jams is not very different from that from typical educational environments and includes (1) cooperative, (2) project-based, (3) problem-based, and (4) collaborative learning." Through these processes the events are said to contribute to 4C skill development.

## Design Implications

### Context
#### Requirements
- A tutor able to promote beneficial interaction, which is crucial for collaborative learning to succeed
#### Constraints
- In such a short collaborative event it is unrealistic to expect participants to acquire all skills or learn to program

### Target Learners
- adolescent students (12–16) in informal and extracurricular settings

### Learning Goals
- critical thinking, creativity, communication, collaboration
