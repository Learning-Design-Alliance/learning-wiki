# Task-Based Language Teaching as a communicative approach centered on meaningful tasks

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article presents TBLT as a subcategory of communicative language teaching developed in the 1980s, in which "the first priority should be given to the accomplishment of learning tasks rather than the mastery of language forms" (citing Skehan). Learners fulfill meaningful tasks using authentic target language, and language is acquired naturally through task accomplishment. The article applies this framework by teaching grammar through task-based instruction instead of examples and drills.

## Design Implications

### Context
#### Requirements

#### Constraints
- The article notes a disadvantage: learners' talk is not regularly articulated accurately, and they use strategies to fulfill tasks quickly
