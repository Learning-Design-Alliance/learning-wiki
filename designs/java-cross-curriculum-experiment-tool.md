# Java as the shared experimental tool across the programming curriculum, with the object-oriented course moved to the third semester

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The revised plan offers object-oriented programming in the third semester "ahead of the old plan", using Java with 3 credits (36 theory hours, 36 experiment hours) instead of the previous 54 theory and 28 experiment hours. Java is positioned as the experiment tool for later courses: Table I maps Java APIs (ArrayList/LinkedList, Thread/Runnable, JDBC, TCP Socket, etc.) to data structures, operating systems, databases and computer networks, and Table II schedules at least one programming-related course in every semester of the four years.

## Design Implications

### Context
#### Requirements
- Programming courses offered in each semester so the third-semester Java course supports subsequent courses
#### Constraints
- Describes one institution's (Yunnan University) curriculum; effects on later-course performance are not evaluated

### Target Learners
- computer science and technology undergraduates

### Learning Goals
- object-oriented design and programming skill reinforced throughout the curriculum
