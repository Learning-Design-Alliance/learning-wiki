# Open-ended data-challenge course structure: supervised-to-autonomous individual projects following the get–clean–explore–model–interpret pipeline

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The course's second part is built on three one-week individual “data challenge” projects (DC1, DC2, DC3) that “followed the pipeline: “Get data → Clean up data→ Explore data→ Model data→ Interpret data””. DC1 was fully supervised and guided while DC2 and DC3 were more autonomous, and each challenge ends with a three-page LaTeX report. The open-ended COVID-19 challenge formed the core of the course, with a common empirical peak-prediction task plus a self-chosen theme.

## Design Implications

### Context
#### Requirements
- Each challenge ends with a three-page LaTeX report describing the results achieved with the student's own graphics and figures
- Attendance restricted to a maximum of 25 students so that supervision of the projects is manageable
#### Constraints
- During DC1, the presence of the external supervisors was essential
- DC1 took a lot of time and commitment on both student and teaching staff, which led to DC3 being made optional

### Target Learners
- third-year undergraduate physics students

### Learning Goals
- model-guided data analysis and data visualization
- autonomous use of computational tools (Python, C++, shell scripting, LaTeX)
