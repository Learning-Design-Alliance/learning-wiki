# Combine unit testing, OOP and refactoring as a complete software engineering practice

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article argues that software engineering practice applicable to daily programming needs in HEP emerges only from three combined ingredients: "unit testing, OOP (including for our purposes class design principles and design patterns) and refactoring". The test discipline guides building working code with built-in verification, OOP helps find an appropriate code structure, and refactoring is the method to systematically change existing code. Refactoring is presented both to improve existing code and as design guidelines for new code.
