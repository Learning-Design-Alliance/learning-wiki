# Inductive and deductive grammar programs as contrasting example-rule-practice sequences

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article operationalizes the two teaching models as opposite instructional sequences. The inductive program is represented as "Specific examples → Practice → General rule", so learners work examples and practice before the rule is stated, while the deductive program runs "General rule → Specific examples → Practice". The researcher built one program of each type for each level, based on that level's syllabus, and taught them to the experimental groups.
