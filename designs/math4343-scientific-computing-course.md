# MATH 4343 Introduction to Scientific Computing: a project-based undergraduate CSE course using high-performance computing

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
MATH 4343 is an interdisciplinary undergraduate course first taught in Spring 2021 at the University of Arkansas, aimed at preparing students as future computational scientists and engineers. Its learning objectives are divided into three parts: "understanding the problem with its mathematical model", "learning the algorithms needed for solving the mathematical models", and "the implementation of algorithms in the Linux environment". Students learn C programming and work on real-world projects (e.g., Nelder-Mead simplex, finite difference and finite element methods) on the university's high-performance computing system, with only linear algebra as prerequisite and no prior C experience required.
