# Dual-version VR programming app with interactable objects for basic CS concepts (Meta Quest 2, Unity)

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A researcher-built Unity VR application for stand-alone Meta Quest 2 headsets that guides novices through a tutorial and four levels covering data types, sequences, arithmetic, string concatenation, Booleans, logical operators, and conditionals. Subjects connect "interactive rectangular text-based objects as physical representations of functional pieces of code and raw data, such as strings, Booleans, and integers" in the text version, or 3D everyday-object visual metaphors (e.g., a printer for a print statement) in the metaphor version, then run programs and verify output on a print log panel.

## Design Implications

### Context
#### Requirements
- Meta Quest 2 headset and controller-based interaction (lasers for clicking, grabbing, teleporting)
#### Constraints
- Known bug: connecting certain programming objects could cause a memory leak and app crash; lesson material was abbreviated due to session time limits

### Target Learners
- adults new to computer programming (age 18 or older)

### Learning Goals
- basic CS concepts: data types, print statements, arithmetic and comparison, string concatenation, sequencing, nesting, and conditionals
