# Thirty-frame PI sequence teaching entanglement coding in Qiskit for early-stage quantum software engineers

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article provides a toy-sized example PI sequence of 30 frames (Figs. 1-30) designed to teach generalist engineers with some previous exposure to quantum programming how to code entangled circuits using Qiskit. Learners must discriminate gate families that allow entanglement, identify entangleable systems, translate between circuit diagrams and code, and write circuits meeting given requirements. Solutions to the frames are provided in an annex.

## Design Implications

### Context
#### Requirements
- Prerequisites are assumed from prior PI sessions: quantum circuits, single and two-qubit gates (X, Z, H, CX, CZ), superposition, bracket notation, and the conventional initial state
#### Constraints
- The approach relies purely on the engineering aspects of quantum programming and makes no assumption about theoretical proficiency, which is treated as a separate piece of knowledge

### Target Learners
- early-stage generalist engineers with some previous exposure to quantum programming

### Learning Goals
- coding entangled quantum circuits in Qiskit
- discriminating entangling from non-entangling gates and circuits
