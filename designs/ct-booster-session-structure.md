# CT Booster session structure: timed segments for vocabulary, examples, micro-credentials, and Q&A

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Each CT Booster session follows a repeating timed structure: a short introduction and vocabulary segment, a set of worked examples anchored by guiding questions, a pointer to a related micro-credential, and a closing question-and-answer period. The deck prints the structure as "5-10 minutes: Introduction & Vocabulary" followed by "15-20 minutes: 3-4 Examples" and "2-5 minutes: Question & Answer Session". Guiding questions frame the examples, for example how teachers collect, analyze, and store data to understand relationships in intermediate and middle grades.

## Design Implications

### Context
#### Requirements
- Sessions need prepared example sets (3-4 examples) matched to a guiding question and a related micro-credential to point teachers toward
#### Constraints
- Structure is designed for short virtual booster sessions, not full-length courses

### Target Learners
- K-8 teachers in rural Kentucky

### Learning Goals
- Computational thinking: data analysis and algorithms
