# Four-task flipped-classroom task sequence: choose a tool, learn it, design a learning path, peer-share with explicit methodological remarks

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The flipped classroom was operationalised by assigning each student a task chain: "Choose a different MM tool" (promoting cooperation), "Learn to use the MM tool" (requiring active learning), design a physics-lab learning path where the tool helps learning, and share it by peer communication "with explicit remarks on methodological choices, strengths and weaknesses in the use of the software". Peer sharing occurred in a participate lesson with mandatory written worksheets for each learning path.

## Design Implications

### Context
#### Requirements
- A cloud storage service to share all produced materials
- A participate lesson for peer presentation
- Mandatory written worksheets for each proposed learning path
#### Constraints
- The flipped format was chosen partly because little time was available in the TFA course

### Target Learners
- pre-service physics and mathematics teachers

### Learning Goals
- independent learning of multimedia tools and design of laboratory learning paths
