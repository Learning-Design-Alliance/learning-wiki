# Curriculum of independent training modules with clearly marked prerequisites

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The HSF/IRIS-HEP curriculum is built as a set of training modules that learners can take in flexible order rather than as a fixed sequence. The article states that each module is independent from the others except for clearly marked requirements, so students can prioritize certain skills before others. The authors argue this matters especially in academia, where students are often expected to work directly towards scientific results with minimal time given for acquiring software knowledge or best practices. Modules range from Software Carpentry basics through C++, continuous integration, machine learning and HEP-specific tools to advanced core-developer topics.

## Design Implications

### Context
#### Requirements
- Prerequisites between modules must be clearly marked so learners can order their study.
#### Constraints
- The module list and material evolve continuously depending on input from participants and person-power available.

### Target Learners
- HEP graduate students and researchers with limited dedicated time for software training

### Learning Goals
- acquiring software skills in a priority order suited to immediate research needs
