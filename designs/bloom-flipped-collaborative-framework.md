# Three-module conceptual framework linking Bloom's Revised Taxonomy, flipped classroom and collaborative learning

## Description
The article proposes a synthesised conceptual framework (Figure 2) consisting of "three interrelated and integrated modules that constitute a flipped classroom: learning processes, assessment processes and collaborative-learning processes". Module 1 covers online self-learning of key concepts, Module 2 covers quizzes, self-assessments and formal exams, and Module 3 covers higher-order collaborative work culminating in a marketing plan. Lower-order cognitive work occurs online independently while higher-order work occurs in class with peer and instructor support. The framework served as the blueprint for the study's course restructuring.
