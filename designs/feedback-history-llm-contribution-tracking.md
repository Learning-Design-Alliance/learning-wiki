# Feedback History interface with LLM contribution tracking and draft management

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Teacher Dashboard includes a Feedback History interface providing a comprehensive log of all feedback sent to each student. For each entry it displays "a visual legend indicating the proportion of content contributed by each LLM", as well as the extent to which the teacher modified or curated the AI-generated text before sending it. This transparency mechanism lets teachers reflect on their own curation patterns and provides a data source for analysing teacher mediation at scale. The interface also supports saving intermediate drafts.
