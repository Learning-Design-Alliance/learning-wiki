# KSL glossing convention: upper-case glosses in Object-Subject-Verb or Subject-Object-Verb order

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Glossing in this project writes each sign word or sentence in upper case to mark signed content, following KSL rather than English syntax. The article states that "In KSL sentences, each sign word is glossed in upper case letters and it follows Object + Subject + Verb or sometimes Subject Object + Verb word order", contrasting with English Subject-Verb-Object order. This convention was applied to all collected sentences and recorded in Table 1 examples such as TABLE CAT UNDER// for 'the cat is under the table'.

## Design Implications

### Context
#### Requirements
- morpheme-by-morpheme translation using English words
- upper-case notation to distinguish signed words from unglossed English
#### Constraints
- KSL syntax differs from spoken-language syntax, so glosses do not mirror English word order

### Target Learners
- deaf learners using Kenyan Sign Language as medium of instruction

### Learning Goals
- accurate representation of KSL sentence structure for translation and research
