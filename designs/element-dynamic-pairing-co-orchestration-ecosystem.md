# A co-orchestration technology ecosystem combining intelligent tutoring systems, peer tutoring, and a teacher-facing orchestration tool.

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article describes a technology ecosystem for dynamic combinations of individual and collaborative learning. It consists of "two intelligent tutoring systems and a teacher-facing co-orchestration tool that allows dynamic pairing." The orchestration tool helps teachers make real-time, data-informed decisions about when students should switch between learning modes, using rule-based pairing suggestions based on Bayesian Knowledge Tracing, knowledge distance, and student struggle status.
