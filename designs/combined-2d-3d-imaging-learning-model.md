# Combined 2D+3D imaging learning model: "2D + 3D → 3D → 2D"

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article contrasts a classical learning model, "2D → 3D → 2D", in which trainees must imagine 3D structures from 2D cross-sectional images, a "long and difficult" process that often yields inaccurate 3D structures, with a new model, "2D + 3D → 3D → 2D". In the new model, combined 2D and 3D images allow structures to be corrected "in both a timely and repeated manner", producing accurate 3D structures that are then applied in clinical practice. The authors speculate that introducing this model at PGY1 may improve the anatomy-imaging-surgery learning curve.

## Design Implications

### Context
#### Requirements
- Requires 3D reconstructed images generated from the same CT cases as the 2D images, as provided by the multi-touch visualization touchscreen table used in the study
#### Constraints
- The model's benefit was observed for junior (PGY1) residents; senior residents showed no significant differences between modalities
- The authors state the hypothesis needs further confirmation with novel standard training courses combining 2D and 3D technology

### Target Learners
- surgical residents, especially junior (PGY1) residents

### Learning Goals
- anatomy learning
- imaging reasoning
- establishing accurate 3D anatomical structures from 2D images
