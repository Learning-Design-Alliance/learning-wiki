# DATA Lab course structure: small sections with persistent groups conducting different experiments with no set endpoint

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
DATA Lab organizes each 20-student section, staffed by a GTA and a ULA, into five persistent groups of four that rotate every 4–6 weeks, with each group conducting a different experiment across most two-week labs. Because "there is no set endpoint for any individual experiment," groups can all work toward the same learning goals while running different experiments. The article reports this design supports ownership and agency and removed the faculty concern about content breadth, since concepts are introduced through peer evaluation of communication projects.

## Design Implications

### Context
#### Requirements
- Twenty-student sections with one graduate teaching assistant and one undergraduate learning assistant
- Aligned assessments that can evaluate any experiment against the learning goals
#### Constraints
- Faculty initially raised the concern of not covering the same breadth of content, addressed by peer evaluation of communication projects

### Target Learners
- Introductory algebra-based physics students, mainly biological science majors, more than 2000 per year

### Learning Goals
- Experimental process
- Data analysis
- Collaboration
- Communication
