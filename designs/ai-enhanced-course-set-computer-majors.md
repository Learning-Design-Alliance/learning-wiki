# AI-enhanced course set spanning compulsory, elective, and practice categories

## Description
Table 1 of the article catalogs representative reformed courses. As printed, "the integration of AI into the curriculum is demonstrated through a selection of representative courses that highlight the breadth of the reform." Compulsory courses such as Network Security Technology introduce AI-driven intrusion detection with machine learning models for abnormal network traffic; electives such as Artificial Intelligence and Big Data Analysis introduce Python, TensorFlow, and big data frameworks; practice courses such as Enterprise Software Development Practice use AI-powered automated testing and code quality assessment tools.
