# Network-Based Instructional System Design (NBIS) model development process

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The program was developed following the "Network-Based Instructional System Design model", a five-step process of analysis, design, production, implementation, and evaluation. In this application, analysis involved needs interviews with nine nursing home practitioners and a literature review; design set goals, content, multimedia materials, and chatbot support; production created storyboards and Chrome-optimized software; implementation ran guided training meetings and a two-week web deployment; evaluation used a critical thinking disposition measure.

## Design Implications

### Context
#### Requirements
- Needs analysis with practitioners and literature review to set goals and content
- Technical support (e.g., chatbot) for learner–educator communication
#### Constraints
- Program was optimized for the Chrome environment only

### Target Learners
- Nursing home nursing staff in workplace training

### Learning Goals
- Infection control competence via critical thinking disposition
