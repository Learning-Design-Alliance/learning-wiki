# Three-step process for analyzing a physical situation: choose a state type, describe state change, give an initial state

## Description
A lesson-level reusable sequence from the article's mechanics summary: 'We summarize our state space view of mechanics by giving a three-step process for analyzing a physical situation.' Students choose a type for the state space, describe how the state changes in time through Newton's laws, and give an initial state, after which they can make graphs or animations.
