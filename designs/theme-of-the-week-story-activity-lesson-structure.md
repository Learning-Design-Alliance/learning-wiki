# Theme-of-the-week character lesson structure with story introduction and varied activities

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The curriculum uses a recurring weekly instructional pattern: a 'theme of the week' approach in which the teacher introduces the week's concept by reading stories portraying that value in action, then engages students in targeted activities, with a class project centered on the lesson's main idea. Supplemental materials support daily oral language development and weekly writing assignments designed to enhance understanding of the week's core concept. This structure integrates literacy activities with character value instruction.

## Design Implications

### Target Learners
- elementary school students (grades 4-5 in the reviewed studies)
