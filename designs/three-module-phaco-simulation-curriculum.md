# Three-module progressive simulation curriculum: basic wet laboratory skills, wet laboratory phacoemulsification, then proficiency-based virtual reality training

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The standardized curriculum consisted of 3 modules: a 6-hour supervised wet laboratory module on basic microsurgical skills (wound construction, viscoelastic use, instrument handling, wound closure, suture placement), a 6-hour wet laboratory module performing all phacoemulsification steps in synthetic model eyes, and a proficiency-based virtual reality module in which trainees practiced "for unlimited time until a score of 600 out of 700 was achieved" on validated Eyesi exercises. Randomization occurred only after module two.

## Design Implications

### Context
#### Requirements
- All trainees must complete the first module before proceeding to the second module
#### Constraints
- The virtual reality simulator does not yet provide tactile feedback, which wet laboratory training enables

### Target Learners
- novice ophthalmology residents with no prior microsurgical simulation or phacoemulsification experience

### Learning Goals
- phacoemulsification surgical competency transferable to the operating theater
