# Four-step language learning memory strategy integrated into gesture-based physical learning activity

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The study structures its learning activity around Oxford's (1990) memory strategy, whose "four steps of this memory strategy are: (1) creating mental linkages; (2) applying images and sounds; (3) reviewing; and (4) employing actions." Each step was implemented as a stage of the "Save the Prince/Princess" game, in which children used English knowledge, body movements, and memory to pass levels. The strategy was given to both the experimental and control groups, so the comparison isolates the gesture-recognition component.
