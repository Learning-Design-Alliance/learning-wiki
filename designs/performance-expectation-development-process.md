# A process for building performance expectations from negotiated lists of practices and core ideas

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article describes a repeatable process for converting faculty values into assessable course goals. Faculty first construct a negotiated list of scientific practices and core ideas, then elaborate them into practice statements and knowledge statements, and finally blend these into performance expectations. As the authors describe, "The process begins by identifying the scientiﬁc practices and core ideas in the introductory courses and then proceeds to blend these into a set of performance expectations for the course." The framework also focused individual discussions on specific elements.

## Design Implications

### Context
#### Requirements
- A facilitator to anchor discussions to the framework
- Early construction of a complete list of practices and core ideas
- Concrete examples of blended performance expectations
#### Constraints
- Faculty initially struggled to define performance expectations without a worked example

### Target Learners
- Undergraduate students in introductory physics courses

### Learning Goals
- Defining what students should know and be able to do with that knowledge
