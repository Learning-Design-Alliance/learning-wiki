# Minimally working programs with built-in checkpoints as computational physics activities

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The teacher's computational activities use a "minimally working program," defined as "a piece of starter code that will compile without errors and create a visual" with lines students must edit or add to build a realistic physical model. Activities include checkpoints students can reach even when their solutions depart from the intended one, so that "no matter how far they go, they still have some sense of success." The teacher writes the solution first, then removes parts students should rewrite.

## Design Implications

### Context
#### Requirements
- The teacher writes a full solution first and removes the parts students should rewrite, balancing how much starter code to give students against how much to leave for them
#### Constraints
- The teacher's main difficulty is that "students who struggle can still be working on that initial problem," so some students never experience the scaffolded checkpoints or tangible progress

### Target Learners
- high school physics students

### Learning Goals
- reinforce physics concepts through computational modeling
- build computational modeling skills
