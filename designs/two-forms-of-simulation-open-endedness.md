# Two forms of simulation open-endedness: alternative task pathways versus alternative interactions

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article distinguishes two ways a training simulation can be open-ended. The first, which the authors implemented, allows learners different pathways through the same tasks performed in the same way. The second, which they did not implement, "requires development of alternative interactions. The interactions that need to be developed would not create new tasks but additional ways of completing the same tasks," such as installing an edge finder in hand before mounting the chuck, or deburring a block held by hand. This framework frames the cost-benefit trade-off designers face: some open-endedness is attainable through task mapping, while the rest demands new interaction development.

## Design Implications

### Context
#### Requirements
- Task analysis identifying where multiple task orders can legitimately complete the same goal
- Additional development effort for interaction-level open-endedness beyond pathway-level open-endedness
#### Constraints
- The implemented system achieved only pathway-level open-endedness, not interaction-level open-endedness

### Target Learners
- novice learners of psychomotor manufacturing skills

### Learning Goals
- flexible execution of machine-shop tasks through multiple valid approaches
