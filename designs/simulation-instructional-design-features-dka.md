# Evidence-based instructional design features for simulation: interactivity, individualized learning, preset action categories, feedback, repetitive practice with varying difficulty, and contrasting cases

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The simulator was designed "in keeping with best practices for the instructional design of simulation activities", incorporating interactivity, individualized learning, preset action categories, feedback, repetitive practice with varying levels of difficulty, and contrasting cases. Users receive feedback throughout and upon completion, including Helpful Hints and a summary report of performance in each management category. Elements of deliberate practice were also implemented, including well-defined learning objectives and focused repetitive practice.
