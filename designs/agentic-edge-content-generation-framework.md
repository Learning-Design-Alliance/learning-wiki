# A four-agent hierarchical framework for decentralized, culturally adaptive educational content generation on edge devices

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article introduces an autonomous agent-orchestrated framework using "four specialized CrewAI agents with hierarchical coordination" for educational content generation on edge devices. The agents are a Curriculum Planning Agent using Markov Decision Processes for learning pathways, a Content Generation Agent interfacing with African Language Models using RLHF, a Linguistic Adaptation Agent, and an Assessment Synthesis Agent generating adaptive assessments using item response theory. Coordination occurs via message-passing for state synchronization.

## Design Implications

### Context
#### Requirements
- Requires edge hardware capable of running the African language models locally, and community partnership for cultural review of generated content
#### Constraints
- Designed for resource-constrained environments with limited internet connectivity; content generation depends on the small African language models it interfaces with

### Target Learners
- learners in Sub-Saharan Africa, including rural communities with unreliable internet

### Learning Goals
- access to culturally responsive educational content and assessments in indigenous African languages
