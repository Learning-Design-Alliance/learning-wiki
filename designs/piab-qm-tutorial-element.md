# Particle in a Box (PIAB) quantum mechanics tutorial

> **Design** · [All designs](index.md)

## Description
The Particle in a Box (PIAB) tutorial is a research-based quantum mechanics tutorial the authors are developing “to help students more consciously select between quantum, classical, or hybrid reasoning when problem solving.” Students worked through it in focus groups; the episodes analyzed here come from physics majors in the first semester of a QM course, and the transcript and tutorial are publicly available online.
