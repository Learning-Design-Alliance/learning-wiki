# Collaboration for PBL implementation proceeds through four sequential, overlapping stages

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The model describes collaboration as a dynamic, cyclical and beneficial procedure in which collaborators learn to function on behavioural, cognitive and affective levels. As printed, "The model proposes the collaborative activities that occur through four sequential stages, namely need analysis, planning and design, monitoring and evaluation." The stages feed on each other and overlap, and the outer circular arrows of the schematic imply that if objectives are not achieved the process should be repeated, starting with analysis.

## Design Implications

### Context
#### Requirements
- Collaborators from academia and clinical services participate jointly from need identification to monitoring and evaluation
#### Constraints
- The stages overlap and feed on each other rather than running strictly linearly

### Target Learners
- undergraduate nursing students in PBL programmes

### Learning Goals
- effective implementation of problem-based learning through structured collaboration
