# Seven-indicator weighted teaching ability assessment system with expert-validated dimension weights

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The platform operationalizes teaching ability through a hierarchical indicator system (Table 2) with seven primary indicators: instructional design (0.15), content knowledge (0.20), teaching implementation (0.25), student engagement (0.15), assessment practices (0.10), technology integration (0.05), and reflective practice (0.10), each with secondary indicators, evaluation dimensions, and named data supports. The aggregated competency score formula "was directly implemented in our platform's analytical engine with specific parameter values: ω = [0.25, 0.20, 0.25, 0.15, 0.15] for the five dimensions, validated through expert panel consensus (n = 12 education specialists)".
