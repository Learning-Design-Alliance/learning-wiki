# Five design characteristics of a complex-algorithm teaching example

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article enumerates the characteristics that distinguish its HHL teaching example from examples available elsewhere: a step-by-step, self-contained analytical discussion; a numerical example in bra-ket notation mirroring the analytical equations; Matlab code matching the numerical example exactly; qiskit code runnable in IBM simulation and hardware; and tracing all four qubits throughout without simplification. The article writes, "Firstly, the HHL algorithm is discussed analytically step-by-step and is self-contained. Secondly, a numerical example is given in bra-ket notation mirroring the analytical equations."

## Design Implications

### Context
#### Requirements
- Availability of both matrix-based code and a programmable quantum circuit corresponding to the same example
#### Constraints
- Existing simpler examples often lack matrix representation and combine fewer core concepts

### Target Learners
- students reinforcing basic quantum computing concepts with a relatively complex algorithm

### Learning Goals
- appreciating the roles and interplay of basic quantum concepts in a realistic algorithm
