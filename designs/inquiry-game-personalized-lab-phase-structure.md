# Three-phase laboratory structure: inquiry-based fixing of notions, game-based circuit building, then personalized design

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A laboratory-session design in which each of three laboratories moves through three phases: notions are first fixed with inquiry-based learning, then students use the Tinkercad website to develop a circuit from a provided schema in a game-based phase, and finally students apply personalized learning by coming up with "their own vision of resolving the problem". The professor guides students during their personal journey, and grades were given based on experience outcomes in the gamified environment.

## Design Implications

### Context
#### Requirements
- Access to a free online simulation environment (Tinkercad) where students can simulate sensors and write code
- A provided circuit schema for the game-based phase
#### Constraints
- The theoretical grounding of the personalized phase is not very consistent, so students choose the design for a described situation

### Target Learners
- university engineering students learning microcontrollers online

### Learning Goals
- problem solving
- circuit design and code writing
- creativity and ownership of the learning process
