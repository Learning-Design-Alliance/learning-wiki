# Interactive e-learning environment embedding a lumped-parameter cardiovascular model with virtual clinical cases

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The e-learning environment (ELE) was built in Microsoft Powerpoint, published as a PDF and hosted on the Sheffield Minerva managed learning environment. It combined physiology modules, three pathology areas with interactive pre-computed lumped-parameter model results, and "Three virtual cases ... developed for each pathology to map the model information and help the students place the physiology and model results in clinical context", with built-in questions on diagnosis, treatment, pathophysiology and severity. Outputs were pre-computed rather than solved in real time.

## Design Implications

### Context
#### Requirements
- Requires access via a web-based learning environment (Minerva) and pre-computed model outputs so students need not solve the model in real time
#### Constraints
- Students were restricted to a two-week access period and the software was not downloadable; final iteration contained over 200 pages
- Results pre-computed, so users could not choose their own combinations of resistance, compliance and cardiac performance

### Target Learners
- undergraduate medical students at all stages of training

### Learning Goals
- understanding cardiovascular physiology and pathophysiology (hypertension, heart failure, haemorrhagic shock) in a clinical context
