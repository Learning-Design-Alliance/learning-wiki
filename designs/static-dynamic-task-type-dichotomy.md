# Static versus dynamic task-type dichotomy in task-based language teaching

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article adopts Ellis's (2003) classic dichotomy of task types in task-based language teaching. The static type "pays more attention to form and transfers information in a linear sequence through the prescribed language" with material learned consciously, giving more control to the learner and more linguistic context. The dynamic type describes situations or actions and narrates, involving two-way conversations without prescribed language content, learned unconsciously, emphasizing free uncontrolled production and extra-linguistic context. The study operationalizes these as its control and experimental treatments.

## Design Implications

### Context
#### Requirements
- Both task types must fit within a balanced language course of meaning-focused input, deliberate language-focused learning, meaning-focused output, and fluency development strands
