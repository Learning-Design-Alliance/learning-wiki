# C-K theory as a systematic framework for developing creativity through design

## Description
The C-K theory is a systematic practice for designing products, services or solutions by reviewing abstract ideas. It operates through two spaces: the Concept Space, which contains ideas that do not yet exist in the world, and the Knowledge Space, which contains existing information about techniques, commerce, society, rules and regulations. The design process involves four operators (K→C, C→C, K→K, C→K) that expand and transfer ideas between spaces. In this study, the theory was applied to create workshop lesson plans for developing creativity in film and design courses.
