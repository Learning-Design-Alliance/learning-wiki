# LLM-as-co-teacher framework aligning AI interventions with studio learning modes and Bloom's taxonomy

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article proposes a conceptual framework that repositions AI in the architecture studio from a co-designer focused on form generation to a pedagogical agent. It states that "LLMs constitute an innovative framework for expanding the pedagogical functions of the design studio, repositioning AI as a co-teacher rather than a co-designer." The framework maps LLM actions onto three learning modes (self-, peer-, and professor-led) and onto Bloom's taxonomy levels: recall and understanding via automated summaries, application and analysis via interactive case studies, and synthesis and evaluation via hypothetical design scenarios.

## Design Implications

### Context
#### Requirements
- LLM interventions must be aligned with measurable learning outcomes using Bloom's taxonomy and matched to identified challenges in each learning mode
#### Constraints
- The framework is eminently conceptual in nature and has not been empirically validated; the authors recommend subsequent research test the identified AI tools in real studio contexts

### Target Learners
- architecture studio students in higher education

### Learning Goals
- design reasoning
- self-regulation
- peer critique quality
- creative exploration
