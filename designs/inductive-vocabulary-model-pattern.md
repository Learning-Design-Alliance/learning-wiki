# Multi-part inductive vocabulary model using semantic word families within basal reading stories

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A four-part instructional pattern built on 4-word semantic word families for 3 key vocabulary words in each basal reading story. Part 1 pre-teaches key words; Part 2 substitutes similar-meaning target words with queries about how the new word changes meaning; Part 3 substitutes untaught target words so students infer meaning in context; Part 4 has students present sentences about their own experience. The article describes it as "a multi-part, semantic word-family-oriented learning strategy to inductively expand vocabulary taught directly".

## Design Implications

### Context
#### Requirements
- Pre-planning identifies 4-word semantic word families for 3 key vocabulary words per story, with project-developed story-specific vocabulary guides for teachers
#### Constraints
- Implemented within a district-adopted basal reading series; experimental teachers committed to teaching 8 stories over 18 weeks with follow-up support

### Target Learners
- Grade 3-5 students in diverse elementary schools

### Learning Goals
- Vocabulary acquisition
- Reading comprehension
