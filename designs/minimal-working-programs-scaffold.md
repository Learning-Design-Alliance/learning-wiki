# Minimal working programs plus pre-class code-reading homework as scaffolds for introductory computational modeling

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This pattern scaffolds computational instruction by having students first read and interpret already-written code in pre-class homework, then extend minimal working programs during group projects rather than writing code from a blank screen. The article states that scaffolds such as pre-class homework and minimal working programs let students engage with the central aspects of computational modeling in mechanics: working with model parameters and initial conditions and constructing the loop that does the motion prediction. Tutors guide students to first reproduce analytical results in code before adding complexity such as air resistance.

## Design Implications

### Context
#### Requirements
- Pre-class homework focused on identifying and interpreting already written code
- Minimal working programs provided as starting points for projects
- Tutor guidance to check the simplest model before adding complexity
#### Constraints
- Students never write a computational model from scratch, which the authors chose intentionally given that less than 10% of students had prior computational modeling experience

### Target Learners
- introductory physics students with little or no prior programming experience

### Learning Goals
- interpreting VPython code
- constructing Euler-Cromer integration loops
- iterative prediction of motion
