# Five-exercise home simulation set covering incision, capsulorhexis, dexterity and suturing

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article defines a reusable set of five simulation exercises, each mapping a household material to an ophthalmic skill: corneal incisions on grape skin, capsulorhexis on boiled potato under a lozenge-packet 'anterior chamber', 'Loop the hoops' straw-threading, 'Dot the cross' poppy-seed placement with the non-dominant hand, and suturing an orange-peel graft disc. The authors state "Four important and basic skills of performing the corneal incisions, capsulorhexis, improving manual dexterity, and suturing were identified" and built one or more exercises per skill using validated techniques agreed among all authors.

## Design Implications

### Context
#### Requirements
- Each exercise requires its listed low-cost equipment (e.g. keratome and 15-degree blade for incisions; cystotome and rhexis forceps for capsulorhexis) and a prepared lozenge-packet incision port setup
#### Constraints
- The dexterity exercises emulate manipulation in a confined space rather than replicating actual ophthalmic surgical steps

### Target Learners
- junior ophthalmology trainees

### Learning Goals
- basic intraocular surgical skills
- manual dexterity
- suturing technique
