# Processing Instruction: an input-processing model of explicit grammar instruction

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Processing Instruction (PI), developed by VanPatten, is an explicit form-focused instruction model that targets how learners process input rather than output. Wong and VanPatten's three basic features are that "Learners are given information about a linguistic structure or form", learners are informed about a processing strategy that may negatively affect pickup of the form, and learners are pushed to process the form during structured input activities without producing it. The article applies this model by building a PI treatment package of explicit information plus structured input activities for six English tenses.

## Design Implications

### Context
#### Requirements
- PI requires a structural syllabus taught by means of structured input activities, with explicit information on the target forms and activities manipulated so learners depend on form to get meaning
#### Constraints
- Learners do not produce the target structure during structured input activities; the article notes PI's ultimate scope is not raising consciousness about grammatical form but making learners appreciate the form's communicative function

### Target Learners
- intermediate EFL learners
- adult learners aged 18-24

### Learning Goals
- grammatical accuracy in L2 writing
- acquisition of target grammatical structures (English tenses)
