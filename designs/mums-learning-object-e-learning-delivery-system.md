# MUMS Learning Object e-learning delivery system with multimedia formats and embedded assessment modules

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The e-learning delivery system evaluated in this study organised content into Learning Objects, each ending with formative and summative assessment modules. Content appeared in interactive multimedia formats including "slide-based lectures, standalone training videos, embedded videos, webinar or live training playback, podcasts, dialogue simulations, animations, and interactive videos". Students received asynchronous content through the MUMS Learning Management System NAVID and attended synchronous sessions via Adobe Connect and Skyroom.
