# Three-part authentic data-analysis masterclass structure: shower core, arrival direction, lateral distribution

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The masterclass activity is structured so each student reconstructs an event measured by the Pierre Auger Observatory. "The project is divided into three main parts": first reconstructing the impact point of the shower core via a signal-weighted center-of-mass calculation, then evaluating the arrival direction, and lastly analyzing the lateral distribution of the air shower. The activity "has been designed to be inexpensive and easy reproducible with little prior knowledge", using a common spreadsheet program.

## Design Implications

### Context
#### Requirements
- A common spreadsheet program such as Microsoft Excel or LibreOffice Calc
- Public event data from the Pierre Auger Observatory webpages
#### Constraints
- Designed for students with little prior knowledge
- Uses only surface detector station data

### Target Learners
- High school students aged 15 to 19

### Learning Goals
- Reconstructing basic properties of air showers using classical physics and high school mathematics
- Training the center-of-mass problem and spreadsheet use
