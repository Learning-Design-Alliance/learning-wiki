# Analytics reporting module with bar and pie graphs

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The analytics module shows analytics reports of student evaluation results stored in the mobile application database system, displaying tallies of how many students got the same score on a particular outcome. Bar-graph and pie-graph views let students "easily track what outcomes he/she need to focus more" and see the percentage of students scoring the same on an outcome, providing data for administrators' academic planning and program improvement.
