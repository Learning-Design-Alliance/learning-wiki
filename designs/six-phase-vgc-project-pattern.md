# Six-phase structured VGC project pattern integrating technical and intercultural components

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 1 of 1 report an effect size · 1 claim rests on one study

## Description
The VGC activity was "designed as a structured, project-based learning experience integrating both technical and intercultural components" with "explicit task structuring, role clarity, and scaffolded collaboration." It followed a six-phase structure: cultural introduction and orientation (cultural icebreaker with 'Cultural Data Points'), dataset selection and setup in a shared Google Colab workspace, data cleaning and planning with responsibilities divided across institutions, data analysis and modeling, structured reporting using a Question-Analysis-Conclusion (QAC) structure, and reflection and closure via a post-project survey and shared Figma Jam Board.

## Design Implications

### Context
#### Requirements
- Shared digital tools for communication and coding (Microsoft Teams and Google Colab in this study)
- Mixed-institution teams with members from both universities
#### Constraints
- The design emphasized asynchronous interaction, while allowing optional synchronous meetings; common challenges include time zone differences, uneven participation, and technological limitations

### Target Learners
- undergraduate computing students in data analytics and introductory machine learning courses

### Learning Goals
- data analytics and machine learning skills
- cross-cultural collaboration
- structured analytical communication
