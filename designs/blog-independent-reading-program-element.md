# Two-month blog-based independent reading program with eight passages, collaboration, and weekly summaries

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The treatment program consisted of eight reading comprehension passages on different fields, "from famous characters in history to legends", each followed by multiple choice questions. Students could collaborate to answer the questions and correct each other's mistakes, and at the end of each week each student wrote a summary of the two passages in their own words. The program ran for two months during the second term on a teacher's blog, with stated aims to develop students' reading skills and autonomy.

## Design Implications

### Context
#### Requirements
- Access to the teacher's blog and basic familiarity with blogs and computers, which the experimental group had
#### Constraints
- Extra teaching hours were not allowed at the college, so the program had to run independently of class time

### Target Learners
- first-year university English majors in Saudi Arabia

### Learning Goals
- reading comprehension
- learner autonomy
