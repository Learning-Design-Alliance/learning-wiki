# Variable learning path with beginner-advanced game pairs and a star-based reward system

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The eight games are organized into four modules of two games each, with a Beginner game that must be completed before its optional Advanced counterpart, forming "This variable path through the eight games". A reward system asks players to answer multiple choice questions and perform tasks, awarding stars for correct answers and successful task completion. Games cover basic imaging parameters, imaging anatomy and flow, MR physics, and projections to bridge high school curricula to the imaging process.
