# Repurposing virtual patient cases across seven axes (language, culture, pedagogy, level, discipline, content type, technology)

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article describes a reusable design in which a virtual patient case is semantically annotated so it can be repurposed into a different educational context along multiple axes: "to a different language, to a different culture, for a different pedagogical approach, for a different educational level, for a different discipline, to a different content type, and to a different educational technology". Repurposing actions create a social hierarchy of linked resources in a parent-child approach, recording who repurposed from whom, so a whole network of linked resources emerges. Export-import and duplication functionalities were extended according to the mEducator schema requirements.

## Design Implications

### Context
#### Requirements
- Semantic annotation of cases via the mEducator schema, plus extended export-import and duplication functionality carrying the metadata
#### Constraints
- Repurposing could refer to modifying at least the virtual patient node narrative, the media content, or the counter/timer measures during the evaluation

### Target Learners
- medical educators
- medical students

### Learning Goals
- reuse and adaptation of virtual patient cases across educational contexts
