# Four-component prompt structure with style checkpoints for generating Affective, Cognitive, and Action-Oriented instructional texts

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A reusable prompt architecture for generating style-consistent LLM instructional texts. The article states the prompt structure "consists of four key components: Skeleton Prompt, a standardized template for instructional content; Style Information, which defines the messaging style (Affective, Cognitive, or Action-Oriented) and ensures consistency via predefined checkpoints (Table 1)"; plus Additional Information and Original Instructions. Content followed Nonviolent Communication principles across ten learning items, generated with ChatGPT o1 pro mode from 30 prompts.

## Design Implications

### Context
#### Requirements
- Predefined style checkpoints (Table 1) to ensure consistency within each messaging style
- A fixed set of original learning items shared across styles for comparability
#### Constraints
- Instructional texts were approximately 400 characters each in Japanese and covered NVC-based communication skills only

### Target Learners
- self-directed adult learners building communication skills

### Learning Goals
- communication skills grounded in Nonviolent Communication
