# Six-phase AI-assisted instructional design pipeline under the Curriculum as Code paradigm

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article formalizes instructional material creation as an engineering process analogous to CI/CD pipelines, composed of six sequential phases: Context Injection, Pedagogical Calibration, Technical Calibration, Planning, Iterative Implementation, and Review. It "replaces unstructured human-AI interactions with a systematic, stage-gated pipeline" that embeds the instructor's tacit knowledge via few-shot calibration, enforces cognitive load theory constraints, and generates LaTeX/Beamer slides plus Python figures through text-based interfaces. Validation occurred in a PBL higher-education institution across eight modules and 28 project contexts.

## Design Implications

### Context
#### Requirements
- Instructor-supplied foundational scoping documents (syllabus, Project Charter), previously validated teaching materials for few-shot calibration, and an institutional custom Beamer class defining visual identity rules
#### Constraints
- Validated with a single authoring instructor in a single institution; generative models exhibit behavioral drift after provider updates, occasionally requiring prompt recalibration

### Target Learners
- Undergraduate computing and business administration students in project-based learning programs

### Learning Goals
- STEM content mastery (mathematics, computing, engineering topics) delivered through contextualized, active-learning instructional materials
