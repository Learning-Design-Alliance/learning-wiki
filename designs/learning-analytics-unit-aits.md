# Learning Analytics Unit for Monitoring Student Progress in AITS

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Learning Analytics unit records, analyses and visualizes learning data related to students' activities, aiming to assist the tutor in understanding students' learning progress on search algorithms. It provides information on individual student performance, disaggregates by characteristics such as major and year of study, shows statistics and common errors, tracks hints requested, and uses data mining techniques to make predictions regarding student performance.
