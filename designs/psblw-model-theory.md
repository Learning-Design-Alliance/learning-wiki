# Local wisdom-oriented problem-solving learning model (PSBLW)

> **Design** · [All designs](index.md)

## Description
The PSBLW model integrates Balinese local wisdom values into problem-solving learning. It embeds motivational slogans and character values from local culture into each stage of the problem-solving process, aiming to develop both cognitive and character outcomes.
