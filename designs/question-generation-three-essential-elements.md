# Question-generation strategy rests on three essential elements: active processing, metacognitive processing, and schema processing

## Description
The article organizes the question-generation strategy around three essential elements. Active processing holds that "students become active readers and independent thinkers via generating questions in order to understand the text" (Wong, 1985). Metacognitive processing involves planning, monitoring, and evaluating one's comprehension, so learners become aware of comprehension gaps. Schema processing holds that readers with rich prior knowledge comprehend text better than those with weak background.
