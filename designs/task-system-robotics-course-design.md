# A cross-cutting robotics course designed around a core system of specially selected tasks spanning preschool, school and university levels

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's redesigned methodology places a system of tasks at the core of the robotics course, with new knowledge acquired through solving problems rather than through fixed content sequences. As the authors state, "The main point of the task approach is that the acquisition of new knowledge occurs through the process of cognitive activity in solving the problem, which is set by a system of specially selected tasks." Tasks are organised in tables by competence (systems thinking, programming/artificial intelligence, project management, cross-industry communication) and by educational level, using medical-robotics problem situations. The set is explicitly not universal; it demonstrates the possibility of composing such a system.
