# Advanced Programming Concepts (APC) training program for physicists

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The APC is a training program introduced in 2010 that "introduces software concepts, methods and techniques to work eﬀectively on a daily basis in a HEP experiment or other programming intensive ﬁelds". It targets "students and young researchers involved in physics analysis and detector development" rather than core software developers, and four workshops were held between 2010 and 2014 attended by 138 participants in total. The program conveys object-oriented design, test-driven development, UML, design patterns, refactoring and performance techniques.

## Design Implications

### Context
#### Requirements
- Participants should be physicists whose programming skills are moderate on average and who work with large existing code bases in HEP experiments
#### Constraints
- The curriculum has evolved over the years and the paper focuses on the 2014 edition
- The program is deliberately distinct from computing schools teaching elementary C++ or addressing core framework developers

### Target Learners
- PhD students and young researchers in particle physics

### Learning Goals
- object-oriented programming and software design for daily work in HEP experiments
