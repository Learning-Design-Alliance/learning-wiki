# Paired proficiency tests and instructor guides for assessing each alignment skill

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
For every tutorial the package includes a matching proficiency test and an instructor guide, giving instructors ready-made instruments to check whether each student performed the alignment task correctly. The author writes that "The accompanying assessments and instructor guides for each tutorial are provided in this package for the convenience of the course instructor(s) to use in the course as-is, or to use for their own reference of what skills to assess and how to tell if the student did the tasks correctly." The instructor guides mirror the tutorial numbering (Instructor's Guide 1 through 8).

## Design Implications

### Context
#### Requirements
- Instructors use the guides to know what skills to assess and how to judge correct task completion
#### Constraints
- Assessments are keyed one-to-one to the eight tutorials and their specific alignment skills

### Target Learners
- students in the alignment course
- course instructors using the package

### Learning Goals
- demonstrated proficiency in each laser alignment skill
