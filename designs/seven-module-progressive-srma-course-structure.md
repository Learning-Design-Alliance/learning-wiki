# Seven-module progressive course structure with longitudinal manuscript preparation

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The proposed course comprises seven modules, each with learning outcomes, interactive elements, and assessment methods. Preparation for the final module (Module 7, manuscript preparation) starts at the beginning of the course and continues as an ongoing thread across all modules in a 'building blocks' fashion. Successful completion of interactive elements in each module is a prerequisite for progression to the next module.
