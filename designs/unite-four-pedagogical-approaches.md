# Four key pedagogical approaches (constructivist, blended, collaborative, active learning) derived from user requirements

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
User requirements collected across the 14-school network established that "teachers want to use the system while applying autonomous and active learning principles in both individual and collaborative contexts". Consequently, "principles of constructivist theory, blended, collaborative and active learning (all derived from user requirements) are the four key pedagogical principles" representing one PF component, integrated into the learning scenarios and promoted in the implementation phase.

## Design Implications

### Context
#### Requirements
