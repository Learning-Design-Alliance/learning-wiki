# Integrative project courses that link disciplinary knowledge across an interdisciplinary program

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The program includes five integrative project (IP) courses spanning from three-week projects to full-semester projects, in which student teams apply disciplinary knowledge to real-world problems. Beyond application and integration of disciplinary knowledge, the projects develop "autonomy, teamwork, communication, and project management" and include a reflective dimension in which groups question preconceptions, pose hypotheses and validate them. The sequence progresses from IP in Quantum Programming, through Quantum Solutions and Science Popularization, to an Entrepreneurial Project and a personalized Specialty Project aligned with career plans.

## Design Implications

### Context
#### Requirements
- Complementary course sequence adapted to students' progress through the curriculum
- Alignment with disciplinary content, supported by monthly meetings with teaching staff
#### Constraints
- Projects span from three weeks to a full semester; the first course uses smaller projects to acclimate students to the format

### Target Learners
- undergraduate QIS students from first semester onward

### Learning Goals
- integration of math, physics and computer science knowledge
- teamwork, communication and project management skills
