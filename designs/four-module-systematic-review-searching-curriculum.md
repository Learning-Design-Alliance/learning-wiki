# Four-module curriculum structure mapping learning objectives to systematic review competencies and SRSS skills

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The course is organized into four modules that together cover the systematic review searching workflow: consultation and pre-searching, searching, search strategy peer review, and search reporting. Each module is mapped in Table 1 to the learning objectives set by the MLA SR Workgroup and to corresponding SRSS skills (8–14). As the article states, "Four modules were established that would meet the course objectives: Module 1, consultation and pre-searching, Module 2, searching, Module 3, search strategy peer review, and Module 4, search reporting." The pattern is reusable for librarian evidence-synthesis training.

## Design Implications

### Context
#### Requirements
- Objectives must be defined in advance by a competency framework (here the Townsend et al. six competencies and the SRSS skills) so modules can be mapped to them
#### Constraints
- The pilot in-person offering was four hours and online offerings two 2.5-hour sessions; the article notes building a full systematic review search is not feasible in the course context

### Target Learners
- health science librarians, both new and experienced searchers earning the SRSS specialization

### Learning Goals
- systematic review searching skills: reference interviewing, preliminary searching, database selection, comprehensive search strategy building, search peer review, and search reporting
