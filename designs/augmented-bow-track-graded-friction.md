# Augmented bow track with graded friction feedback

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 2 studies (2 qualitative), `q2` · 0 of 2 report an effect size

## Description
A speculative clip-on augmentation positioned between the bridge and fingerboard, using two moving tensioners that hold the bow and shift position according to the string being played. Rather than enforcing a fixed path, it makes bow deviation perceptible through graded friction that increases as the bow drifts, aiming to build muscle memory through repeated practice. Envisioned functions include non-visual feedback for drift and contact-point change, continuous low-attention feedback enabling mid-stroke correction, adaptive bow-lane awareness for dynamics, and practice scaffolding with post-practice summaries.
