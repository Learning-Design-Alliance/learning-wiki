# Evolving-artifact course organization: each module's output becomes the next module's input

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A course-level structural pattern in which module deliverables chain across the lifecycle so that students revisit AI-related decisions repeatedly with accumulating evidence. The article states: "A key structural principle is theevolving-artifactorganization: each module's output becomes the next module's input, so students revisit AI-related decisions repeatedly with accumulating evidence." The author identifies it as the key transferable principle for educators integrating AI into existing BPM courses.

## Design Implications

### Context
#### Requirements
- Group work with results delivered at each module milestone
- module sequence spanning modeling, simulation, redesign, implementation, and mining
#### Constraints
- Instantiated in a single Master-level program with a banking onboarding case; generalization to other domains or study levels requires further evidence

### Target Learners
- Master-level university students in project-based BPM courses

### Learning Goals
- grounding AI adoption decisions in process-level evidence accumulated across phases
