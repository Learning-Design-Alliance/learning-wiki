# Self-regulation based strategic reading education program for 5th grade Turkish courses

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
A 12-week intervention program, delivered 4 hours a week in the second semester of the 2018-2019 academic year, designed to improve self-regulation based reading skills in 5th grade Turkish courses. Lesson plans were built using Zimmerman's phases and Pintrich's self-regulation learning strategies, reviewed by experts, and taught via gradual responsibility transfer. Outcomes were measured with a 45-item reading comprehension test, the Motivated Strategies for Learning Questionnaire, the Reading Strategies Cognitive Awareness Scale, and the Reading Motivation Scale. The program produced significant post-test advantages over the current program on all four measures.
