# Kern's 6-step curriculum development model applied as a closed-loop design framework for the virtual simulation system

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article structures its system development on Kern's 6-step curriculum development model, moving from problem identification and needs assessment through objective formulation, educational strategies, implementation, and evaluation. The design is described as embodying a closed-loop concept: interactive virtual microscopy addresses limited specimen types, the real-time feedback system corresponds to error-correction needs, and the automated assessment module enables both formative assessment and personalized learning curves supporting continuous curriculum improvement. The authors state this completely realizes a closed-loop curriculum development process from problem identification to effect evaluation.
