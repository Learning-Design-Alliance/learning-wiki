# Three-week module structure distributing simulation, experiment, and comparison work across days

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 2 studies (2 causal), `q2` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
Each module in the set "lasts for 3 weeks (21 weeks total for the whole set)", with work distributed across days: an introduction with starter code and theory reading, homework in which students code models and design experiments, an experimental session, and a final day for comparing, redesigning, and redoing work. Some modules let students schedule freely with instructor-provided starter code on the first days. The pattern fits a 40-minute weekly class slot plus out-of-class work.

## Design Implications

### Context
#### Requirements
- Students need time allocated outside the classroom for coding, reading, and data analysis
- A limited lab schedule motivated the design
#### Constraints
- Grain: operates at the level of a multi-week lab unit within a year-long physics course

### Target Learners
- advanced high school physics students
- college physics students

### Learning Goals
- iterating between modeling and experimentation
- managing an extended open-ended project
