# Five key representations for introductory statistics: verbal descriptions, visualizations, word equations, GLM notation, and R code

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The textbook asks students to repeatedly translate and connect among five representations: "verbal descriptions, visualizations, word equations, GLM (general linear model) notation, and R code." Students describe models in words, write word equations (e.g., Thumb Length = Height + other stuff), map them to DATA = MODEL + ERROR, write R code, and learn GLM notation, which the authors value for its generalizability, alignability with other representations, and ecological validity. Algebra was deliberately excluded because students do not find it accessible or useful.

## Design Implications

### Context
#### Requirements
- Selected representations must be accessible to novices, important for the field, and productive for making connections
- Learning a representational system requires an investment of time and effort, so the set must be limited
#### Constraints
- GLM notation is described as a difficult representational system for students to learn

### Target Learners
- Novice college students in introductory statistics

### Learning Goals
- Using and connecting multiple representations of statistical models
- Participating in computational, reproducible data analysis practices
