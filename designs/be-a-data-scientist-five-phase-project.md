# Be a Data Scientist: a five-phase mini citizen science project in which school working groups design, administer and analyse a survey

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Be a Data Scientist is a "mini" citizen science project investigating the dynamics of information among young people. School classes act as working groups that propose a survey, administer it via a google web app, analyse the data under supervision of scientists and teachers, and present results at the next Researchers' Night. The project "collected 1021 valid survey", with analysis expected to use "coding based on python and shared on 'colab research' by google".

## Design Implications

### Context
#### Requirements
- School classes as working groups, a scientific committee of journalists, social-media experts, data scientists and demographic-statistics experts, and a google web app for data collection
#### Constraints
- At extraction time the analysis phase was still upcoming: students were only starting to analyse data

### Target Learners
- school students (working groups) and their colleagues and parents as survey respondents

### Learning Goals
- scientific skills and competencies in survey design, data collection, coding, statistics and machine learning
