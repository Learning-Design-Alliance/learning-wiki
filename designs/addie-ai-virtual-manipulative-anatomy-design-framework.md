# ADDIE-based instructional design framework combining AI-supported virtual manipulatives with multimedia design principles for anatomy education

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 2 studies (2 causal), `q2` · 0 of 2 report an effect size

## Description
The article's design framework adopts the ADDIE (Analysis, Design, Development, Implementation, Evaluation) model, in which "each step has an outcome that strengthens the next step, and this progression does not require a linear sequence." Within it, interactive 3D anatomical models are treated as virtual manipulatives that "bridge the gap between concrete and abstract learning experiences," and multimedia design principles are applied to manage cognitive load by eliminating elements that challenge limited cognitive capacity. AI support supplies real-time feedback and personalized interaction so students work within their optimal cognitive capacity.

## Design Implications

### Context
#### Requirements
- Design features aligned with multimedia design principles to manage cognitive load
- Pilot application before student use; presenting the method as a single primary source
#### Constraints
- Effectiveness demonstrated for nervous-system anatomy with nursing students; generalizability to other systems and populations not yet examined

### Target Learners
- health sciences students, particularly nursing students in anatomy courses

### Learning Goals
- anatomical knowledge acquisition, retention, and reduced cognitive load
