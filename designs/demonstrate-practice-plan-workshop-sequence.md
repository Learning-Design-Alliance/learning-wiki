# Demonstrate-practice-plan workshop sequence for teaching virtual teaching tools

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The workshop follows a timed sequence: introduction and objectives (10 minutes), demonstration of interactive teaching tools (30 minutes), breakout sessions (40 minutes total: 15-minute small-group discussion plus 25-minute facilitated large-group discussion), and summary with evaluation (10 minutes). Participants first experience tools as learners, then apply them by planning a virtual case-based session in small groups, then share rationales in large-group discussion where participants learn from each other's stories.

## Design Implications

### Context
#### Requirements
- Prepared tech-tool accounts and pre-opened browser tabs for smooth transitions between tools
- A shared worksheet for participants to note tool features during demonstrations
#### Constraints
- Facilitators found it difficult to circulate among breakout groups without disrupting discussions; participants were told they could rejoin the main room with questions

### Target Learners
- Health professions educators

### Learning Goals
- Planning interactive virtual case-based teaching sessions
