# A blended learning model for large group teaching combining overview lectures, online modules, and integration/feedback sessions

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article presents a model for incorporating blended learning into large group university courses. For each topic, a single face-to-face overview lecture is retained, remaining content is converted into short online modules with interactive questions and review quizzes, and each topic concludes with an interactive large-group integration and feedback session using in-class questions. The authors state: "We believe this is an effective model for the introduction of blended learning for both new and existing large group university courses." The model shares similarities with the inverted classroom model but retains an in-class overview lecture.
