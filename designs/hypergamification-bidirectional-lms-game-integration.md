# Hypergamification: bidirectional LMS-game integration where the whole game environment is generated from LMS content

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Hypergamification is the authors' proposed concept in which a complete game environment, not just isolated game design elements, is generated from LMS learning materials and course structure, and gameplay translates back into course activities. The paper states that "In a bi directional integration model, learners will experience a virtual in -game environment that is generated based on the learning materials and course structure provided by the LMS." It is positioned beyond gamification's points, badges, and leaderboards.

## Design Implications

### Context
#### Requirements
- An LMS exposing course content and activity data through interoperability APIs, and a game engine able to consume and write back that data
#### Constraints
- The pilot implements only partial bidirectionality: most tested endpoints were GET retrieval, with CreateMessage() as the only method sending data back to the LMS

### Target Learners
- higher education students using an institutional LMS

### Learning Goals
- engagement with course materials, activities, and assessments through a game environment
