# Blueprinted feedback: automated individualised feedback generated by mapping assessment items to learning objectives

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Blueprinted feedback is a feedback model in which summative assessment items are mapped to learning objectives, creating a blueprint that "can be used on completion of the assessment to automatically create a report which lists the module learning objectives examined in the assessment, ranked according to the individual's achievement of each specific objective". It offers an automated yet personalised option for delivering feedback to large cohorts, presenting information as learning objectives to protect item validity and direct future learning. Reports can be delivered by automated email or online network, immediately or delayed to coincide with results.

## Design Implications

### Context
#### Requirements
- Summative assessment items must be mapped to their relevant learning objectives to create the blueprint
- E-assessment management software to generate and deliver the individualised reports
#### Constraints
- Developed for large class medical science teaching following summative e-assessment

### Target Learners
- large cohorts of undergraduate medical students

### Learning Goals
- self-directed correction of knowledge against module learning objectives
