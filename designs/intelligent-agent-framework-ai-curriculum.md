# Intelligent Agent Framework for AI Curriculum Organization

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The curriculum is organized around the concept of an intelligent agent situated in an environment, cycling through sensing and actuation stages. Five internal processes are identified: motivation, representation, learning, reasoning, and memory. The article states that 'the agent is continuously interacting with its environment in a cycle' and that 'the agent can learn from its experience in order to improve the action selection process.'

## Design Implications

### Context
#### Requirements
- The framework requires that all five operational blocks be present in any intelligent agent implementation, though their complexity can vary
#### Constraints
- Memory is excluded as a dedicated topic because 'a proper implementation of a memory system is out of the scope of this education level'

### Target Learners
- High school students aged 15-18 in scientific programmes

### Learning Goals
- Understanding the fundamental components and processes of intelligent agents
