# SRT and ASRT task designs distinguishing general skill, statistical, and high-order rule learning

> **Design** · [All designs](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 causal, 1 associational), `q3` · 1 of 2 report an effect size · 5 claims rest on one study

## Description
The serial reaction time (SRT) task presents a deterministic 12-element sequence; the alternating serial reaction time (ASRT) task interleaves four predetermined elements with four random ones, creating an eight-element probabilistic sequence. Trial types (pattern, random-high, random-low) allow the article to state that the structure "allows the distinction between (i) general skill learning, measured by a decrease in RT for all trials, (ii) statistical learning, measured by the difference in RT between the random-high trials and the random-low trials ... and (iii) high-order deterministic learning, measured by the difference in RT between pattern trials and random-high trials."

## Design Implications

### Context
#### Requirements
- Blocks binned into five bins to compute online and offline gains; warm-up trials, repetition and trill triplets, and error trials discarded from analyses
#### Constraints
- In the SRT task with only deterministic transitions, general skill cannot be dissociated from sequence learning within each block or rest period; high-order rule learning was only observable in the long ASRT task

### Target Learners
- healthy young adult participants in visuomotor sequence-learning experiments

### Learning Goals
- implicit visuomotor sequence learning and its subcomponents
