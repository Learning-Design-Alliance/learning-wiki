# The system approach: teaching language as an integrated system of interrelated subsystems grounded in meaningful verbal learning

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The system approach treats language as a schema with interrelated components — phonetic, morphological, syntax, and semantic subsystems — taught in integration rather than as separated disciplines. It is "developed based on Ausbel theory of meaningful verbal learning wherein experiences are presented schematically to demonstrate the connectivity, interactivity and interdependence between new and older experiences" and draws on constructivist theory, shifting emphasis from external to internal factors so meaningful learning arises from a network of interrelated concepts.
