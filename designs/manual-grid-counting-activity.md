# Manual grid-counting box-counting activity

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A paper-and-pencil activity in which students overlay a figure on checkered grids of decreasing square size and count occupied squares, building a table and a dispersion diagram of log m against log N. In the authors' leaf example the grids "were drawn with the aid of free software geogebra, but could easily be made by hand". The activity is designed so that students first understand how the box-counting method yields the Hausdorff dimension before any computational tool is introduced.

## Design Implications

### Context
#### Requirements
- Printed checkered grids of decreasing square size and a figure to overlay on them; the grid limit is set by visual ability.
#### Constraints
- Manual counting accuracy "is limited to the brain's ability to compute to the naked eye", which restricts application to more sophisticated problems.

### Target Learners
- high school students

### Learning Goals
- understanding how the Hausdorff dimension is calculated by the box count method
