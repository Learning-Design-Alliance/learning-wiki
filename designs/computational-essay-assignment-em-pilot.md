# Computational essay assignment in an introductory electricity and magnetism course

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A computational essay is "a type of essay or report that explicitly incorporates live code to support its thesis, usually written in a notebook environment," combining the elements of an ordinary essay with code blocks whose output drives the argument. In fall 2018, 17 students in Oslo's introductory E&M course (roughly 270 enrolled) optionally wrote one instead of a presentation-based assignment, working singly or in pairs over about 4-6 weeks to produce 11 completed essays, presented to peers and graded pass/fail.

## Design Implications

### Context
#### Requirements
- Scaffolds: a project description, an example essay, pre-built Jupyter simulations (cyclotron, storm cloud, lightning strike, magnetic trap), suggested questions, and staffed help-desk hours.
#### Constraints
- Participation was optional, so participants were likely those most comfortable with programming and open-ended projects.

### Target Learners
- introductory undergraduate physics, engineering, and geoscience majors

### Learning Goals
- open-ended computational investigation of electromagnetism phenomena
- communication of physics arguments
