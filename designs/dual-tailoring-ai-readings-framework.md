# Dual tailoring: simultaneous individualization of readings along interest and comprehension-level dimensions within an AI-mediated workflow

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Dual tailoring is the article's descriptive design label (explicitly "not a new theory") for an instructional configuration combining two individualization dimensions in one AI-mediated workflow. Interest tailoring adapts readings to professional context, sector, and role through examples and cases; comprehension-level tailoring adjusts "pacing, scaffolding, explanatory depth" via definitions, stepwise structures, and check-for-understanding prompts. Both are supported by iterative prompting, in which students request follow-ups to reframe, deepen, simplify, localize, or apply a first-pass reading.
