# GTX1301 Introduction to Python dual-modality course on EdX

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Georgia Tech's GTX1301 Introduction to Python course offers both on-campus and online versions with the same lectures, assessments, and content delivered on the EdX platform. The course covers standard introductory computer science topics and is intended for students with zero or near-zero programming experience. It comprises 4 submodules (Fundamentals, Control structures, Data structures, Objects & Algorithms) with 442 videos, 216 ungraded exercises, 235 coding exercises, and 295 graded problems. On-campus students take it for a letter grade on a semester calendar; online learners are open-enrollment without fixed dates and pay a fee for graded assessments.
