# Interactive P&E method (problem tasks and experiments)

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The interactive P&E method is the authors' own teaching approach whose "main idea is interactive working with students with the help of experiment and problem tasks analyses". It proceeds in five phases: preparation of 5–10 minute concept blocks, teaching the block, assigning a problem task in one of five ways (text solved theoretically; text solved via real or computer-aided experiment; unfinished experiment solved theoretically then verified; finished experiment reasoned theoretically; finished experiment solved via video-analysis), class discussion with brainstorming and elimination of incorrect solutions, and multi-level feedback. It combines experiments, problem tasks, and elements of Peer Instruction, Interactive Lecture Demonstrations, Just-in-Time Teaching and Interactive Computer Based Tutorials.

## Design Implications

### Context
#### Requirements
- A lecturer prepared with concept blocks and problem tasks, plus students' worksheets and teachers' guidelines for each way of task assignment
#### Constraints
- Developed and tested in first-year bachelor physics at technical universities in Slovakia with reduced lesson counts
- Exam includes problem tasks as part of the feedback loop

### Target Learners
- first-year bachelor students at technical universities

### Learning Goals
- conceptual understanding of Newtonian mechanics and basic physics
- problem solving and physical reasoning
- reduction of misconceptions
