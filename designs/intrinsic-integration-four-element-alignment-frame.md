# Guiding frame for intrinsic integration aligning game goal with learning goal and pedagogical approach with game mechanics

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article's design frame holds that an intrinsically integrated game integrates four key elements: "the learning goal, game goal, pedagogical approach and game mechanics". Integration means "the game goal is aligned as closely as possible with the learning goal", while the pedagogical approach needs to be aligned with the game mechanics. The frame guided the design of the game Newton's Race used in the evaluated lesson.

## Design Implications

### Context
