# Voluntary video game teaching basic computational concepts to early-age children, grounded in intrinsic motivation

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A voluntary video game addressing basic computational concepts, deployed for early ages and grounded in intrinsic motivation. The abstract notes that game-based environments often lack "sufficient voluntariness to assess aspects related to intrinsic motivation, such as interests, skills, persistence in solving a problem and behavior in response to rewards", which this design makes measurable. Data were collected via game learning analytics for 15 months, with 4124 users playing more than 28187 games.
