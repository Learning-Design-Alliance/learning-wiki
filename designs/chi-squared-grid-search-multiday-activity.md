# Multi-day chi-squared-reduced grid-search activity with two homework assignments and an in-class code-annotation workshop

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This end-of-semester capstone activity in the modern physics lab course had students compute reduced chi-squared from prior fit parameters, loop over fit parameters to produce 2D and 3D plots of the chi-squared surface, and annotate a TA-written grid search function using nested for loops. As printed, "Professor Evans structured it as two homework assignments, with an in-class workshop in between", and the second assignment asked students to overlay the grid search path on the 3D surface.

## Design Implications

### Context
#### Requirements
- Students needed for-loop knowledge, which they were directed to acquire from online references and course manuals before the workshop
#### Constraints
- Students had not used for loops in any capacity earlier in the semester

### Target Learners
- sophomore-level undergraduate physics students

### Learning Goals
- statistical data analysis with computation
- reading and annotating others' code
