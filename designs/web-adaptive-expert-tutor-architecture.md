# Adaptive web-based intelligent tutoring architecture combining learner modelling with an expert-system tutor

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article proposes an integration of adaptive web-based e-learning with expert systems: "This system is an integration of adaptive web-based E-learning with expert systems as well." The tutor first determines the learner's learning style and characteristics by a questionnaire and builds a learner model, then an expert-system simulator plans a pre-test, calculates the score, trains the concept if the required score is met, and evaluates with a post-test. The learner model is updated progressively as characteristics change with learner progress.
