# Lunar zone data analysis metric using LROC quickmap open-access layers

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
After observing, each member was assigned one of ten lunar near-side zones and completed a data analysis metric using LROC quickmap open-access data hosted by Arizona State University. The metric covers bounding coordinates and surface area, topographical description, mare identification, mountains, prominent craters, Apollo sites and man-made objects, plus terrain height, terrain slope, iron oxide abundance and regolith temperature layers. The paper's worked example analyzes Mare Crisium, reporting a zone surface area of 452724.970 km² and iron oxide abundance from around 5 to 19 percent wt.
