# Computer Numeracy Instructional Package for Primary School Children (CNIP 2SC)

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
CNIP 2SC is a computer-mediated instructional package developed by the researchers to teach primary school numeracy concepts. It was built "alongside with the scheme of work from the schools" and provided "the blueprint for teaching numeracy concepts (Numbers and Numeration, Basic Operations and Measurement)". It contained series of exercises pupils worked on, with the researcher serving as teacher/facilitator; it was used to teach both experimental and control groups for six weeks.

## Design Implications

### Context
#### Requirements
- Computer facilities available in the schools, which was the basis for purposive school selection
#### Constraints
- Used with primary three pupils in two Nigerian schools; the chalk method was not used, teaching was done using computers

### Target Learners
- primary three pupils (average age 8 years)

### Learning Goals
- numeracy concepts: Number and Numeration, Basic Operations, and Measurement
