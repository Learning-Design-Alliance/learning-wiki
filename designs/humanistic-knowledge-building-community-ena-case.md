# Humanistic knowledge building community studied over one semester with parallel ENA and qualitative analyses

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The study's empirical site is a classroom learning community studied during "a semester of studies," characterized as a humanistic knowledge building community. Data collected there were analyzed twice: with Epistemic Network Analysis and with a stage developmental analysis using qualitative methods. The case serves to investigate what and how ENA can contribute to socioemotionally-focused ethnographies of classroom learning communities.
