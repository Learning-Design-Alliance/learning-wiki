# LHC masterclass data exercises and analysis software for ATLAS, ALICE, and CMS

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Detector-specific exercises on real LHC data: ATLAS offered a W-path probing proton structure via the W+/W- ratio and a Z-path building a dilepton mass plot, where "The W-path exercise uses the MINERVA software" and the Z-path uses HYPATIA, both based on the Atlantis event viewer; ALICE students searched for strangeness with ROOT-based software, and CMS used iSpy-online.

## Design Implications
