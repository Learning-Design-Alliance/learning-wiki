# Three systematically operationalized pedagogical agent roles: Expert, Motivator, and Mentor

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
Baylor and Kim (2005) designed three instructional agent roles grounded in social-cognitive perspectives of learning. The Expert provided accurate information with authoritative speech and deictic gestures; the Motivator modeled coping strategies as a peer with emotional expressions; the Mentor combined both functions. Table 1 operationalized each role by "Appearance (image), Animation, Voice, Affect and messaging (script)." The roles were instantiated through pre-scripted agents with controlled gender, lip synchronization, and script length.

## Design Implications

### Context
#### Requirements
- Learners must perceive the agent as intended; role instantiations require coordinated appearance, animation, voice, affect, and script
#### Constraints
- Agent-learner interactions were pre-scripted so each learner received all guidance, which limited the intelligence of the agents

### Target Learners
- undergraduate students

### Learning Goals
- computer literacy skills
- instructional design skills
