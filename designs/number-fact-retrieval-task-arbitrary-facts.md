# Number-fact retrieval task with eight arbitrary numeric facts

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An online task (built with PsychoJs, run on Pavlovia) in which participants learn the results of 8 novel numeric facts presented with the nonexistent operator '&' (e.g., "3&8 = 29"), using only single-digit operands and 2-digit results with digits 2–9. Performance is quantified by a recall score where a correct result digit in the correct position scored 1 point and each correct digit in the incorrect position scored 0.5, scaled 0–100, plus response times and forced-choice tests with confidence ratings. It was used to mimic numeric fact learning in adults already familiar with elementary arithmetic.

## Design Implications

### Context
#### Requirements
- Participants already familiar with elementary arithmetic; facts generated with low between-fact similarity to avoid disrupting learning
#### Constraints
- The facts are arbitrary with no systematic rule, so the task isolates rote memorization rather than conceptual or rule-based arithmetic learning

### Target Learners
- Adults (ages 20-40) familiar with elementary arithmetic

### Learning Goals
- Memorization and rapid, accurate retrieval of numeric facts
