# Google NotebookLM-generated supplemental material set for an EAP course

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A set of AI-generated supplemental materials — videos, podcasts, infographics and individualized feedback reports — produced primarily with Google NotebookLM, "an AI-powered, RAG tool", from course worksheets, student work and score sheets for 106 EFL learners. Materials were organized in a shared Google Drive folder by curriculum area and class, linked from the College's LMS, and aligned to the course's intended learning outcomes. Table 1 lists quantities per curriculum area and the AI tools and custom prompts used.

## Design Implications

### Context
#### Requirements
- Input sources such as lesson worksheets with answer keys, student assignments or score sheets must be supplied to the tool
#### Constraints
- Google constrained free-version production, for instance limiting a user to generate three videos maximum in a 24-hour period

### Target Learners
- Second-year associate degree EFL students in a compulsory EAP course

### Learning Goals
- Argumentation language, describing charts and tables, research report writing, APA referencing
