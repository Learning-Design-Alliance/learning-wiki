# FBML-based e-learning model for the Processes for E-learning Resources course

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The researchers designed an e-learning model using Facebook Markup Language (FBML), an extension of HTML that works within Facebook Canvas pages. A Facebook page was created for the "Processes for E-learning Resources" course, with twelve lectures uploaded, a chat panel for questions, Google Drive e-tests, and Twitter feed notifications. Students created profiles, uploaded media, joined discussion groups, and published blogs within a closed group.

## Design Implications

### Context
#### Requirements
- A Facebook page created using FBML
- Teamviewer software to follow and edit student work online
- Google Drive for creating e-tests
- Twitter feed for sending notifications
#### Constraints
- Only class members were invited to join; no guests or outsiders were allowed

### Target Learners
- Higher education students in the Specialist Learning Resources Diploma program

### Learning Goals
- Academic achievement in knowledge and information
- Skill performance in educational content
