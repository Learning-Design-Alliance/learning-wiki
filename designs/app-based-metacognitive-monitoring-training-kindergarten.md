# App-based metacognitive monitoring training program with paired-associates memory tasks and feedback

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A computerized, self-paced training program delivered on tablet computers in which children completed paired-associates memory learning tasks (learning, delay, recognition, monitoring, and feedback phases) across 12 sessions. The article describes it as "a computerized method that is modern, economical in terms of human resources, and allows upscaling." Feedback was delivered visually (green tick, red cross) and auditorily depending on condition; the active control group completed a Hearts and Flowers executive function task instead.

## Design Implications

### Context
#### Requirements
- Some adult supervision during sessions, per the article's own note
- Trained research assistants for technical setup and instructions
#### Constraints
- The active control group did not participate in any memory tasks during training sessions

### Target Learners
- kindergarten-aged children (5.5 to 7.7 years)

### Learning Goals
- metacognitive monitoring accuracy
- confidence judgment calibration
