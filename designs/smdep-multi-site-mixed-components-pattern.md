# Multi-site pipeline program with mixed component offerings across sites

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
SMDEP is implemented as a single program model across "12 sites across the nation," with variation in offerings: "Three sites offer only the program's medical component, whereas the others offer both the medical and dental components." This multi-site structure with site-level component variation is the implementation pattern the evaluation documents across sites.

## Design Implications

### Context
#### Requirements
- National multi-site delivery with consistent core program features across sites
#### Constraints
- Component offerings vary by site, with three sites medical-only

### Target Learners
- Rising college sophomores and juniors interested in medical or dental careers

### Learning Goals
- Science enrichment and professional school preparation
