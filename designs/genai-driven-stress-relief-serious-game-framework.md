# Gen-AI driven design framework for serious games for stress relief

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article proposes a design framework in which generative AI drives the core gameplay of a stress-relief serious game: an LLM-powered NPC conducts multi-turn CBT-informed dialogue ("empathic acceptance—Socratic guidance—cognitive restructuring"), a scene design agent personalizes virtual scenes from the player's stated stress situation, an image-generation agent renders those scenes, and built-in mini-games serve as micro-interventions invoked on emotional bias. As the abstract states, "This study proposes a Gen-AI driven design framework for serious games for stress relief." The framework aims at personalized coping-strategy practice, immersion, engagement and scalable content generation.

## Design Implications

### Context
#### Requirements
- Integration of an LLM via API with preset prompts encoding CBT-informed dialogue rules, scoring rubrics and safety triggers
- A game engine client able to parse structured model output and drive NPC behaviour
#### Constraints
- The framework was evaluated only in a 14-day pilot with 20 college students, so its findings are exploratory

### Target Learners
- college students experiencing moderate to high stress

### Learning Goals
- stress relief
- cognitive emotion regulation
