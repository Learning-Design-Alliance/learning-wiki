# Lecture-Tutorial implementation pattern: targeted interactive lecture with TPS checks, followed by collaborative in-class worksheet work and a whole-class debrief

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The article prescribes a recurring classroom sequence: a tightly focused interactive lecture providing foundational knowledge and formative feedback, Think-Pair-Share questions checking readiness, then collaborative completion of the Lecture-Tutorial, and finally a debrief. The authors state the tutorials "are meant to be done in-class following a very targeted lecture on the topic". Debriefing, they report, "plays a critical role in improving our students' attitudes and beliefs about doing the Lecture-Tutorials" and supports self-efficacy.

## Design Implications

### Context
#### Requirements
- Lecture-Tutorials must be incorporated into class only after students have been taught the topic, and assessments must reflect Lecture-Tutorial content
#### Constraints
- Lecture-Tutorials require approximately 10-20 minutes of class time each

### Target Learners
- non-STEM majors in college introductory astronomy (Astro 101) courses

### Learning Goals
- conceptual understanding and reasoning abilities across astrophysical topics
