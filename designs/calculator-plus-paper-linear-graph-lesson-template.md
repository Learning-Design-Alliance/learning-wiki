# Lesson template pairing graphical-calculator graphing with pencil-and-paper drawing of linear functions

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's Table 1 lesson template for the linear function unit guides students to first familiarise themselves with the Microsoft Math Tool interface, then "use the graphical calculator to draw a graph of the linear function", then "draw the same graph using graph sheet, pencil and eraser", and finally identify and describe the y-intercept point and the gradient. This pairs visual tool-based exploration with manual construction of the same graph.

## Design Implications

### Context
#### Requirements
- Access to the Microsoft Math Tool graphical calculator interface and graph sheets for the parallel manual drawing activity
#### Constraints
- The template was described for a linear function unit with objectives of drawing graphs and identifying gradient and y-intercept

### Target Learners
- Senior High School mathematics students

### Learning Goals
- drawing graphs of linear functions
- identifying and describing gradient and y-intercept
