# Four-dimensional personalization framework for study planning: goals, time, pace, and path

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The four-dimensional personalization framework structures personalized study planning along four dimensions adapted from prior work on personalization in online learning. PlanMate "creates customized learning plans based on the four-dimensional personalization framework (goals, time, pace, and path) established in existing literature on personalization in online learning [33] and recent work on AI-based personalization [79]." Users explicitly provide these preferences through dedicated interface controls and natural-language inputs, which the system uses to generate an individualized study plan. The same four dimensions are also used by AdaptMate when determining plan modifications.

#### Requirements
- Users must explicitly provide preferences across all four dimensions through interface controls or natural-language inputs
