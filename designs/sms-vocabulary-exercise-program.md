# SMS-based vocabulary exercise program with dictation, gap-fill, and story-writing tasks

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 causal), `q2`–`q3` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
A seven-week instructional element in a Fundamental English I course in which all students joined ten dictation sessions covering 100 words, then completed two exercise types: filling blanks with target words and writing a short story using seven chosen words. The experimental group received these exercises via SMS after class and "send the answers via SMS from their mobile phones to the teacher on that week", while the control group did the same tasks on paper in class.
