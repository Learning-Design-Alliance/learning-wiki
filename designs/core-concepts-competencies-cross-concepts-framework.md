# Three-component reshaping of the curriculum framework: core concepts, core competencies, and cross-concepts

## Description
The article describes a current trend in curriculum design that divides the framework into three components: "core concepts" (domains and themes governing subjects), "core competencies" (skills students need by the end of each grade level), and "cross-concepts" (topics and competencies shared by multiple subjects), as shown in Figure 5. Using BERT topics, the current MOE framework shape can be transferred into these components; for example, collaboration as a core competency can be extracted from learning outcomes, with teamwork and collaboration appearing mostly in Moral Study across multiple grades.
