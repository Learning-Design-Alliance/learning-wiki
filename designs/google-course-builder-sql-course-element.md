# Introductory SQL Course built on Google Course Builder with three content levels and W3 SQL Tryit Editor practice

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
An introductory level SQL Course designed using Google Course Builder's infrastructure for the experimental group. The learning content was separated into three levels: the first covered the database concept, principles of database design, types of databases, database management systems, and an introduction to SQL; the second and third levels had students learn and practice writing SQL statements from simple to complex. At the end of each section, students wrote SQL statements using the "W3 SQL Tryit Editor", an online database editor. The platform was accessible for two weeks and included an introductory video and discussion forums.
