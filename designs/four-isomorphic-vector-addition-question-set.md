# Four isomorphic graphical vector addition questions varying arrangement and grid

> **Design** · [All designs](index.md)
> **Evidence** · 8 claims (8 for) · 2 studies (1 causal, 1 qualitative), `q2`–`q3` · 0 of 2 report an effect size · 8 claims rest on one study

## Description
The article developed a set of four graphical vector addition questions, each asking students to "Add the two vectors A and B to get a new vector R where R=A+B" and to explain their reasoning. The questions hold the same two vectors constant while varying two representational features — head-to-tail (aligned) versus tail-to-tail (divergent) arrangement, and presence versus absence of a coordinate grid — forming the 2x2 grid of representations shown in Fig. 1. Design choices were derived from prior research listing prominent student methods, hypothesizing which representational changes would cue each method.

## Design Implications

### Context
#### Requirements
- Same two vectors across all four versions so any method shift can be attributed to the representational change
- Random distribution of question versions to students
#### Constraints
- Only two representational changes were varied, limiting which methods could be cued

### Target Learners
- algebra-based introductory physics students

### Learning Goals
- vector addition in introductory mechanics
