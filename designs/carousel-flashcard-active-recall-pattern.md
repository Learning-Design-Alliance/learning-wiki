# Multislide carousel structure mimicking flashcard dynamics for active recall in image-based learning

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each Instagram post is structured as a multislide bilingual publication using the carousel feature to present content in stepwise progression through question, answer, and explanation phases. The swipe-based design mimics flashcard dynamics, prompting reflection before answer disclosure and promoting cognitive engagement. The first slide presents an image with an open-ended question, followed by annotated answer slides and detailed explanations in French then English.

## Design Implications

### Context
#### Requirements
- Visual material formatted in square layouts suitable for Instagram display
- Bilingual presentation in French and English
- Institutional logo on each slide for visual continuity
#### Constraints
- Dependent on Instagram's carousel feature and platform availability

### Target Learners
- Preclinical medical students

### Learning Goals
- Active recall
- Visual pattern recognition
- Concept reinforcement
