## Description
The Simulated Student is an agent embodying the features of the proposed architecture, added to a collaborative, synchronous system used for learning programming. Its role is to detect and avoid off-topic conversations, passive behaviour, and problems related to students' learning. The article describes it as a "Simulated Student, which has the features described in the model", deployed to check the model's efficiency in a real case.
