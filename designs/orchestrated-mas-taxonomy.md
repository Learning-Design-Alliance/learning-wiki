# Orchestrated multi-agent systems (MAS) as modular, pedagogically aligned AI agent constellations for learning

## Description
The paper distinguishes two readings of multi-agent systems and proposes orchestrated MAS as a design concept for AI in education. Coordinated MAS are tightly integrated agent ensembles within a single pedagogical domain, whereas "orchestrated MAS describe more expansive configurations in which specialised agents span across domains, operating in loosely coupled but pedagogically synchronised ways." Orchestrated systems form a modular AI ecosystem sustaining diverse learning trajectories, curated by educators, with differentiated agent roles such as Socratic tutoring, critical feedback, and affective support operating on a shared learner model.
