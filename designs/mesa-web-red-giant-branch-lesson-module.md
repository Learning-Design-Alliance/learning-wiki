# Red Giant Branch lesson module pairing MESA-Web exercises with a peer-explained drawing assignment

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A community-hub lesson module targets the objective "Explain what happens when a Sun-like star runs out of hydrogen fuel in its core", with a suite of exercises for a range of learners. Exercises move from submitting a default model and reproducing Figures 5 and 6 in a Jupyter notebook, to a drawing exercise in which learners annotate the evolution and explain it to another learner using only their drawing. A Jupyter workbook supports additional analysis.
