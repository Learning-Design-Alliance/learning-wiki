# Mobile CT framework adapting Brennan and Resnick's CT framework for App Inventor-based mathematics learning

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article develops a mobile CT framework built on Brennan and Resnick's (2012) CT framework, redefining its three dimensions for mobile app development in mathematics. Mobile CT concepts include 'screen interface, component abstraction, public web services, data persistence, loops, conditionals, operators, and procedural abstraction'; practices add modeling and algorithmic thinking; perspectives add socializing. The framework scaffolds design and evaluation of mobile app development activities in primary mathematics lessons.
