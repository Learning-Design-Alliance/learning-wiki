# Jane Willis' framework for task-based learning as a writing pedagogy

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Willis' framework for task-based learning organizes instruction into three components: "the ‘pre-task’, ‘task cycle’ and ‘language focus’ components". Applied to writing, the end product is introduced orally or through reading in the pre-task phase, discussed at the task stage, drafted collaboratively at planning, and finalized for the report stage. The article uses this framework as the experimental treatment, arguing it attends to both fluency during the task cycle and accuracy in the language-focus phase.

## Design Implications

### Context
#### Requirements
- A written task is set with useful words, phrases and background knowledge highlighted before the task cycle begins
- Learners discuss, plan, draft, exchange drafts for peer suggestions, redraft, and report to the class audience
#### Constraints
- Willis does not describe in detail how to employ the framework to organize writing classroom activities, so the writing-specific procedure is the author's reconstruction

### Target Learners
- college EFL learners
- graduate students in English writing courses

### Learning Goals
- English writing competence
- grammatical accuracy and fluency in meaning conveyance
