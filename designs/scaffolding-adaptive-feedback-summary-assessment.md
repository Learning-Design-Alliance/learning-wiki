# Scaffolding-based pedagogical model with adaptive feedback grounded in Zone of Proximal Development

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article's pedagogical model is "a 'scaffolding' model which is able to give students adaptive feedbacks based on their previous learning experience". It draws on Vygotsky's socio-cultural theory and the Zone of Proximal Development, where scaffolding provides "individualized support based on the learner's ZPD". A dynamically updated student model stores knowledge skill levels and learning records, and the system adapts its interactivity based on performance in practice exercises. The authors argue that combining adaptive feedback with the scaffolding teaching strategy provides a better learning experience.
