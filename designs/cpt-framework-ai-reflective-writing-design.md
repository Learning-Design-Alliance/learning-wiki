# Cognitive Process Theory of writing as a design framework for AI-supported reflective writing

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The Cognitive Process Theory of writing (CPT) conceptualizes writing as an interplay of planning, translation, and reviewing, and the article uses it as the organizing framework for where AI support should be placed in reflective writing. Pensée explicitly maps each CPT phase to concrete user interactions: the CA for planning, the sidebar and extracted key concepts for translation, and the writing feedback page for reviewing. The authors argue this shifts AI support from generic feedback on finished texts toward supporting the end-to-end cognitive processes that precede writing.

## Design Implications

### Context
#### Requirements
- Support must target the cognitive demands of each phase: idea generation and organization in planning, converting planned ideas into coherent text in translation, and evaluating structure and depth in reviewing
#### Constraints
- Effects observed during tool use did not transfer robustly to unsupported delayed writing, so the framework's support is scaffold-dependent in this implementation

### Target Learners
- vocational education students
- novice reflective writers

### Learning Goals
- reflection depth
- metacognition
- reflective text structure
