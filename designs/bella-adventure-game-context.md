# BELLA adventure game context: math problems emerge naturally from a 3D sandbox role-playing game rather than as isolated exercises

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
BELLA embeds all math problems in an engaging adventure game in which Elle's spacecraft has crash-landed and she faces challenges requiring mathematical help. The article emphasizes that "we have worked hard to make all the math problems emerge naturally in the course of that adventure, rather than being disembodied, isolated game show questions." For example, adding mixed numbers arises because Elle needs to find the shortest route on a map. Users who guess or bypass problems see consequences over time in wasted resources.
