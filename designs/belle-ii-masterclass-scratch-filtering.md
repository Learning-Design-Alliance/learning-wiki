# Belle II masterclass using SCRATCH-like code to filter large event samples

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Based on the highly successful KEK B-Lab for students, the Belle II masterclass studies B physics from electron-positron collisions and 'does not focus so much on individual events as on large numbers of events.' 'The student task, then, is to use code similar to SCRATCH in order to filter data and make a variety of plots.' It was piloted in International Masterclasses 2019, improved, and is expected to be available for 2020.
