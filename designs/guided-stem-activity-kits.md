# Guided STEM activity kits with embedded stories, parent tips, and extension ideas

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Guided activity kits are self-guiding material kits for parent-child play containing materials for building wooden structures plus guidance features. By random assignment, "kits were either “guided” (included embedded stories, parent tips, and extension ideas; n = 50) or “basic” (identical construction activities without guidance features; n = 25)." The guidance features are the manipulated component tested for increasing parents' STEM talk during play.

## Design Implications

### Context
#### Requirements
- Kits must pair construction materials with embedded stories, parent tips, and extension ideas, as the guided condition did
#### Constraints
- The comparison basic kits contained identical construction activities without guidance features

### Target Learners
- preschool children (Mage = 4.82 years) and their parents

### Learning Goals
- STEM vocabulary and scientific inquiry talk during parent-child play
