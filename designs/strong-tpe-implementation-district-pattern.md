# Strong TPE districts: teacher input on SLOs and a three-stage observation cycle with one evaluator

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The report characterizes the recurring design features of Maryland districts with strong TPE implementation. These districts develop the SLO process with teacher input and provide ongoing professional development, and they run observations as a cycle in which "Have a pre-observation conference, the observation of the teacher in the classroom, and a post-observation conference using the same evaluator for all three tasks." They also engage teachers in dialogue with evaluators and use results for continuous instructional improvement.

## Design Implications

### Context
#### Requirements
- District backing of SLO and observation implementation, including ongoing professional development that helps teachers use SLOs to improve classroom practice.
#### Constraints
- The report states quality depends on fidelity of implementation and full support of district leaders.
