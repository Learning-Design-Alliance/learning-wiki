# CBI module on basic Microsoft Excel functions and classroom spreadsheet application adapted from Pollard et al. (2003)

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The erratum corrects the attribution of the computer-based instruction (CBI) module used in the original study. As the corrected sentence states, "A CBI module on the basic functions of Microsoft Excel TM and the application of spreadsheets in the classroom, adapted from Pollard et al. (2003) was developed for this study by the first author using Macromedia Director." The module taught basic Excel functions and classroom spreadsheet application and included a problem scenario provided to students, adapted from the Pollard et al. (2003) curricular computing materials.
