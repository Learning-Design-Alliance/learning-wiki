# Mastery-oriented online-judge problem sets with a breadth gate

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
CP1's assessment core is twelve weekly online-judge problem sets of four problems each, dichotomously scored against hidden correctness, time, and memory tests, with unlimited resubmission before the deadline so failed attempts do not reduce the grade. The article states "CP1 uses twelve weekly problem sets with four problems each, for 48 possible accepted solutions". A breadth gate requires accepted problems across nearly all sets, preventing strategic narrowing, and weekly sets follow a deliberate progression from entry problem to transfer and optional stretch problems.

## Design Implications

### Context
#### Requirements
- Judge acceptance is treated as necessary but insufficient evidence for the full construct, so it must be paired with oral interviews and other evidence forms.
#### Constraints
- The article notes verdict-driven work can become unprincipled trial and error, hidden tests can obscure whether a defect is conceptual or local, and binary scoring cannot distinguish elegant solutions from copied or brittle code.

### Target Learners
- undergraduate students in a large-enrollment (~90–100 student) introductory competitive programming course

### Learning Goals
- broad algorithmic repertoire across topics
- correct and efficient implementation
- distributed goal-directed practice with feedback
