# Five-activity predict-observe-explain sequence from Hamiltonian structure to finite measurement statistics

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The module's classroom sequence follows the simulator's progression: Hamiltonian structure, eigenstates, computational-basis amplitudes, Born-rule probabilities, and finite measurement statistics. Each activity uses a predict-observe-explain structure in which students record a written prediction, compare it with simulator output, and write a brief explanation reconciling the two. The article states predictions are completed individually before simulator interaction and the final written explanations serve as the principal assessment artifacts.

## Design Implications

### Context
#### Requirements
- A simulator or display that keeps the full mathematical sequence visible so students can compare predictions against output at each step
#### Constraints
- Designed for a single 50-minute class meeting, with optional extensions assigned outside class; the article states unitary time evolution is not developed as a separate instructional topic

### Target Learners
- undergraduate quantum-mechanics students in a single class meeting

### Learning Goals
- distinguishing superposition representation from physical splitting; relating Hamiltonian parameters to eigensystem features; applying the Born rule; distinguishing probabilities from finite-sample frequencies; consistent notation
