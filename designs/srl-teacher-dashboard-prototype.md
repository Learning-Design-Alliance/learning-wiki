# Prototype SRL teacher dashboard with COPES-phase widgets and teacher-prioritized interface features

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A prototype teacher dashboard presenting students' metacognitive indicators organized by COPES phase in five widgets: task definition (prior knowledge, motivation), goal setting (self-determined and ALT-determined goals), enactment monitoring (assignment count, progress versus self-set goals), enactment control (planned and executed actions), and adaptations (learning curves). The design "aims to alleviate their cognitive load" while implementing prioritized interface features such as saved settings, color-coded data streams, information buttons, and a unified quick overview.

## Design Implications

### Context
#### Requirements
- Teachers' interface priorities (quick overview, personalization, few clicks) must be implemented for usability
#### Constraints
- Currently tailored for single-lesson use; additional data representations such as growth per grade will be incorporated upon classroom deployment

### Target Learners
- primary school students in grades 5 and 6

### Learning Goals
- self-regulated learning
- metacognitive feedback
