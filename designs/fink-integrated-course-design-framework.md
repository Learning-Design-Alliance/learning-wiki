# Fink's Integrated Course Design framework for aligning learning goals, teaching activities, and feedback and assessment

## Description
The study's organizing framework is Fink's (2013) Integrated Course Design, which "revolves around three primary components: Learning Goals, Teaching and Learning Activities, and Feedback and Assessment". The framework emphasizes creating significant learning experiences beyond simple content delivery, and holds that these three elements must be integrated and support each other; Fink warns that a course lacking this connection is a "broken course" that cannot work effectively because it is not integrated. The authors use it to structure their analysis of how dispositions are integrated across course design components.
