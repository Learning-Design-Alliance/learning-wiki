# DV-Praktikum „Datenverarbeitung in der Physik" – mandatory first-semester Python/Jupyter data-processing practicum

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A mandatory computer practicum "Datenverarbeitung in der Physik" introduced in winter semester 2018/19 and anchored in the first subject semester after a successful pilot. It runs weekly for two hours with tutor-guided team programming tasks and is accompanied by an interactive online course covering "Messunsicherheiten und Fehlerfortpflanzung, Interpolation, Fitten von Daten", Monte-Carlo simulations, Fourier transformations, numerical integration, differential equations, plotting, and good scientific practice. Python is used with numpy, scipy and matplotlib in Jupyter-Notebooks.

## Design Implications

### Context
#### Requirements
- A uniform, widely used programming language (Python) with free, well-curated base libraries, and Jupyter-Notebooks that let code, results and documentation share one document.
#### Constraints
- The practicum is placed before the Grundpraktikum (which starts in the second semester) to make curricular room in a tightly packed timetable.

### Target Learners
- first-semester physics bachelor students

### Learning Goals
- data processing and data analysis competence
- measurement uncertainty and error propagation
- numerical methods
- good scientific practice
