# Nine interactive task types for building linguistic and discursive competence

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article elaborates nine learning-activity options used to create linguistic and discursive competencies: questioning, completion, drill, expansion, gap-filling, jigsaw activities, matching, "odd word", and prediction. Each is defined by its operation — for example, jigsaw tasks share information "by the type of 'mosaic'" on an information gap, and prediction builds "the probabilistic predicting of the language". Additional tasks listed include ranking, rephrasing, selection, split dialogue, true-false statements, unscrambling, mapping, information transfer, interview and scenario.
