# DigiPlay public computation environment with glass-box open-source multi-touch simulations

> **Design** · [All designs](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (1 review, 1 qualitative), `q2` · 0 of 2 report an effect size · 5 claims rest on one study

## Description
DigiPlay is a public learning environment in an indoor walkway at the University of Calgary. As the authors describe it, "It consists of three 80" touch screens, each powered by  a desktop. The screens currently display open source simulations of complex systems" — multi-agent flocking simulations written in the Processing language, based on Reynolds' boids algorithm. Visitors add boids by touching the screens, can press Escape to open the live code in fullscreen visualization mode, read the boids' rules on glass-wall posters, receive just-in-time on-screen instructions, and interact with an on-site facilitator who is a member of the development team.

## Design Implications

### Context
#### Requirements
- Open source software designed for professional use, placed on large touch screens in a public walkway
- An on-site facilitator with deep understanding of the underlying code, plus posters and on-screen instructions explaining the agents' rules
#### Constraints
- It is housed within a university, so many observed visitors were likely affiliated with the university; visits were short, averaging 10-15 minutes

### Target Learners
- any member of the public walking into the space, including children and university-affiliated adults

### Learning Goals
- understanding emergence in complex systems
- direct engagement with open source scientific code
