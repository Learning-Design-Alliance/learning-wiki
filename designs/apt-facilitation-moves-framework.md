# Academically Productive Talk (APT) framework of facilitation moves for eliciting transactive discussion

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
Academically Productive Talk is a classroom discussion facilitation approach comprising core moves (Revoicing, Press for Reasoning, Challenge, Restate, Add More, Agree/Disagree, Explain Other) that teachers and agents employ to encourage discussions in which students make reasoning public and interact with it transactively. The article maps each move onto three transact dimensions (self/other-oriented, representational/transformational, consensus/conflict-oriented) and proposes these moves as content-independent building blocks for dynamic collaborative learning support. The framework posits a logical ordering of move demand, from self-oriented representational moves to other-oriented transformational conflict-oriented ones.

## Design Implications

### Context
#### Requirements
- Students must receive instruction on APT moves prior to online interaction so agent moves can model and facilitate the discussion style
#### Constraints
- The preconditions for successful use of specific APT moves and which learners benefit most from which moves remain unexplored in prior classroom literature

### Target Learners
- high school students
- undergraduate students

### Learning Goals
- articulate and monitor own reasoning
- evaluate and challenge peers' reasoning
- build deep understanding of causal mechanisms
