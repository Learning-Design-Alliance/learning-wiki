# Cyclic experiential cognitive chain replacing the linear BOPPPS sequence, building a three-dimensional disease-anatomy-operation schema

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article contrasts the traditional BOPPPS framework's linear sequence of "knowledge activation → objective setting → assessment → learning → summary" with the modified model's cyclic cognitive chain: "experiential anchoring (Bridge-in) → gap identification (Pre-assessment) → experience-based deepening (Participatory Learning) → application verification (Post-assessment) → schema refinement (Summary)". Each phase builds on the initial experiential input — for example, Participatory Learning via HIS/PACS scenario simulation becomes active integration of experiential insights with theoretical knowledge. The pattern fosters a three-dimensional "disease-anatomy-operation" cognitive schema rather than the traditional two-dimensional "disease-treatment" schema.

## Design Implications

### Context
#### Requirements
- The Bridge-in phase must supply concrete experiential input (ward observation and embodied simulation) that all later phases build on
#### Constraints
- Developed and evaluated against thoracic surgery's profession-specific competency demands (imaging-anatomy correlation, surgical instrument proficiency)

### Target Learners
- undergraduate clinical medicine students

### Learning Goals
- clinical reasoning
- knowledge transfer from classroom to clinical practice
