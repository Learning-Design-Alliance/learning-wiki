# Three-day teaching-hackathon schedule: Common Ground, Project and Analysis, Project Finalization

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A coarse-grained multi-day schedule for a teaching hackathon, based on the 2024 Göttingen implementation. Day 1 (Common Ground) provides initial nano-classes on the scientific topic and tool usage, followed by free self-learning, team formation, and project ideation. Day 2 (Project and Analysis) adds an analysis nano-class and project development. Day 3 (Project Finalization) is devoted to project development, finalization, and team presentations. Each day provides only necessary support while leaving most time free for independent self-charted work.

## Design Implications

### Context
#### Requirements
- Taught sessions providing minimal usage competence
- Free-form work periods for exploration and project development with minimal per-need individual guidance
- A final team presentation to consolidate understanding
#### Constraints
- The program can potentially be condensed to two days based on participant background
- The optimal duration depends on the scientific and computational background of the target audience and the goals set

### Target Learners
- students new to the scientific topic
- heterogeneous-interdisciplinary audiences

### Learning Goals
- transitioning from learning basics to project conceptualization, development, and analysis
- consolidating understanding via presentation
