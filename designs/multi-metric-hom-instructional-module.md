# Classroom-oriented multi-metric HOM instructional module for upper-division quantum optics

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A single-class-meeting module for upper-division undergraduate or early graduate quantum optics that broadens the standard Hong–Ou–Mandel treatment. As the authors state, "We present a classroom-oriented instructional module that broadens this treatment by comparing three output metrics—on/off coincidence probabilityP c, cross-correlationg (2)12 , and noise-reduction factor NRF—across four input families: Fock, superposition, coherent, and squeezed light." It combines a simulator, guided activities, specification tables, and a rubric, and is built around three instructional challenges (B1–B3) and five backward-mapped learning goals rather than around simulator features.

## Design Implications

### Context
#### Requirements
- Designed for a single 50-minute class meeting with a predict–observe–explain structure; a compressed version still supports LG1–LG3
#### Constraints
- Deliberately excludes multi-mode entanglement, detector dark counts, timing jitter, mode mismatch, and full loss channels, which the authors call intentional omissions requiring machinery beyond a single-class two-mode module

### Target Learners
- upper-division undergraduate quantum optics students
- early graduate quantum optics students

### Learning Goals
- distinguish quantum from classical interference using amplitude reasoning
- explain why coincidence probability, cross-correlation, and noise-reduction factor need not agree
- use multiple metrics to select input states for objective-dependent applications
