# Blended collaborative software development course using Discord, GitHub and Trello

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A blended course, Team software development methodology, designed with a Community of Inquiry framework in mind. Students studied materials in Moodle, discussed cases offline, and worked in teams of 4-6 people developing an application idea into functioning software. As the article states, "Students used Discord for communication with peers and the tutor, Github for collaborative code development and Trello for agile management", mirroring IT-industry teamwork practices and allowing activity data download via API.

## Design Implications

### Context
#### Requirements
- Student consent to use service activity data for research, obtained following ethical guidelines
- Students must work in teams of 4-6 people on a shared software project
#### Constraints
- The course is blended, with an offline part; the article does not evaluate it as a fully online design

### Target Learners
- university students in programming disciplines

### Learning Goals
- collaborative software development skills
- web and mobile development skills
