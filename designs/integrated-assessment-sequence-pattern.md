# Integrated assessment sequence alternating curriculum-based instruction, dynamic practice sessions, and CRA-based assessments across a semester

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The study's treatment followed a 14-week integrated sequence printed in Table 1, moving from a pre-CRA through intervening curriculum-based instruction, dynamic practice sessions, CRA-based DSAs, and a post-CRA revised to include the common-error DRA. This pattern embeds dynamic assessment inside a standard course calendar rather than treating assessment as a separate end-of-course event.

## Design Implications

### Context
#### Requirements
- A pre-/post-CRA with intervening curriculum-based instruction and dynamic practice sessions
#### Constraints
- The control group's speaking assessments were non-dynamic and curriculum-based

### Target Learners
- First-year university L2 learners

### Learning Goals
- L2 speaking development
