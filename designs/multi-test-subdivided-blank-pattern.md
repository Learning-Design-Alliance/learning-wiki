# Multi-test blank pattern: one drawn sheet subdivided to yield several independent Monte Carlo tests

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article's materials are organized so a single drawn blank supports repeated tests: dividing the circle-square drawing "into four parts (quadrants)" gives four tests, and "The Appendix 1 (at the end of the paper) presents the blank with five tests." Each tear-up is one trial; results are tabulated (k, N1, N0), averaged, and an uncertainty computed with Student's t-factor. This lesson-level design pattern makes replication and error analysis practical in class.

## Design Implications

### Context
#### Requirements
- A reproducible printed blank with a fixed number of test regions
- a results table for averaging and uncertainty calculation
#### Constraints
- The printed demonstration used kmax = 4 tests with tp,N = 2.35 at p = 90%

### Target Learners
- school and university physics students

### Learning Goals
- measurement uncertainty estimation
- experimental comparison with a known theoretical value
