# Scaffolded guided-inquiry sequence in which epidemiological models are built one parameter at a time in spreadsheets

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's curriculum is a guided-inquiry active-learning case study in which students start from the simplest unlimited growth model and systematically modify it into finite population, SIR and SIRV forms, fitting each to US cases-per-day data. The teaching materials use "a scaffolded approach that focuses on the impact of each model parameter in a step-by-step manner", so each new parameter's implications can be investigated systematically.

## Design Implications

### Context
#### Requirements
- Students add a new parameter only when the data call for it: "students are only asked to add additional model parameters if the data call for them (Occam's Razor)."
#### Constraints
- The step-by-step approach is motivated because epidemiological models inherently produce exponential growth or decay in the infection rate, and in analogous kinetic models too many parameters led to fitted parameters of questionable physical significance.

### Target Learners
- undergraduate students in a biophysics/physiological modeling curriculum

### Learning Goals
- apply finite difference methods to epidemiological models
- apply systematic model development techniques to a complex real-world problem
- use non-linear least-squares methods to test model predictions against published data
