# Digital multimeter input impedance investigation as an inquiry-based laboratory pattern for teaching non-ideal instrument behaviour

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
This pattern organises a lesson around investigating a real, easily available instrument's non-ideal behaviour. The comment argues that "Digital multimeter input impedance analysis is perfect for this, since these instruments are easily available, precise enough, have good value/price ratio and represent modern technology". Learners measure the voltmeter's input impedance with one or more of the three methods, compare results, and confront why apparently consistent readings (10.0 MΩ vs 10.1 MΩ) can hide very different accuracies, developing creative thinking about measurement quality.
