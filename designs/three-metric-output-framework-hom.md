# Metric-dependence framework: three output metrics answer three different technology-facing questions

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The module's organizing framework holds that interference quality is observable-dependent: coincidence probability, cross-correlation, and noise-reduction factor each probe a different statistical property of the same transformed output state. The article states that "they probe different statistical properties of the same transformed output state and need not rank sources in the same way." Each metric maps to a technological question: coincidence probability for coincidence-based logic and Bell-type measurements, cross-correlation for source characterization and classical–nonclassical distinction, and noise-reduction factor for interferometric sensing and sub-shot-noise applications.

## Design Implications

### Context
#### Requirements
- Requires comparing metrics side by side across multiple input-state families under a common beam-splitter sweep so that agreement and disagreement become visible
#### Constraints
- Applies within the idealized two-mode, pure-state setting of the module; for non-number-state inputs the on/off coincidence metric includes multiphoton threshold events and should be read as an on/off detection metric rather than a projection onto |1,1⟩

### Target Learners
- upper-division undergraduate quantum optics students
- early graduate students

### Learning Goals
- explain why the three metrics need not agree
- select input states for objective-dependent applications
