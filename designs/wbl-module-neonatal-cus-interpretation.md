# Web-based learning module on neonatal cranial ultrasound interpretation (seven chapters, 150+ images, embedded quizzes)

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A password-protected web-based learning module hosted on the CHEO intranet teaching neonatal CUS interpretation. It "consisted of seven chapters, accessible through a navigation menu bar or sequentially through a forward button" and is "composed of over 150 high-quality images, graphics, and text". Each chapter has an end-of-chapter quiz with answers revealed on demand, plus an end-of-module quiz, external hyperlinks, and self-paced step-by-step progression. Content was built from anonymized PACS images processed in Adobe Photoshop CS6, developed with an education technology specialist using Adobe Suite CS6, HTML, CSS3 and JavaScript.

## Design Implications

### Context
#### Requirements
- Access to a web browser on any operating system platform; content aligned with defined learning objectives framed by knowledge, skills and attitude categories
#### Constraints
- Initially available only to trainees on NICU rotations during the 6-month study period; time trainees spent studying the module was not recorded

### Target Learners
- pediatrics residents
- neonatal-perinatal medicine fellows

### Learning Goals
- interpreting neonatal cranial ultrasound studies
- identifying anatomical landmarks
- differentiating mature and premature brains
- diagnosing pathological changes
