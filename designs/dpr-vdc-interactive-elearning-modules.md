# Two interactive e-learning modules: DPR interpretation and a virtual dental clinic for communication skills

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 causal), `q2` · 1 of 2 report an effect size · 1 claim rests on one study

## Description
The article developed two e-learning modules using the ADDIE model, built in Articulate Storyline 360 and delivered via Moodle for self-directed, asynchronous use over four weeks. The first module trains DPR interpretation with "high‐resolution annotated images" and five patient-based cases (generalized periodontitis, periapical pathology, odontogenic cysts, dental trauma, fibro‐osseous lesions). The second is a case-based virtual dental clinic using role-play scripts and interactive patient simulations with a three-star patient satisfaction rating for immediate feedback on communication.

## Design Implications

### Context
#### Requirements
- Access via a learning management system (Moodle) on personal devices; content aligned with the final-year dental curriculum
#### Constraints
- The VDC did not fully replicate real-world patient interactions, particularly non-verbal communication and empathetic engagement, per student feedback

### Target Learners
- final-year dental undergraduate students

### Learning Goals
- DPR interpretation (anatomical landmarks, errors, pathology diagnosis)
- patient-centered communication of radiographic findings
