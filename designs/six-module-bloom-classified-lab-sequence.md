# Six laboratory modules totalling 32 units and 64 contact hours, classified by cognitive demand via the revised Bloom taxonomy

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (4 mixed) · 3 studies (1 causal, 1 qualitative, 1 design), `q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The tiers are realised as six modules (M1 data engineering through M6 deployment and clinical simulation) totalling "32 units and 64 contact hours in total". Units are classified by cognitive demand using "the revised Bloom taxonomy": foundation units target apply level, design units analyse and evaluate, and translation units create. Every unit follows a common documentation format with clinical rationale, failure modes and ethical notes, and is accompanied by a reference implementation students may read but must not submit.

## Design Implications

### Context
#### Requirements

#### Constraints
