# Quantitative comparison tool set with decision tree (t′-score, weighted χ2, residual plots)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The experimental curriculum taught a set of analysis tools "used regularly by scientists in any field": the t′-score index comparing two measured values with uncertainty (the difference over the uncertainty in the difference), weighted χ2 for least-squares fitting of data to models, and residual plots showing the point-by-point difference between measured data and a model. Each tool was paired with a decision tree for interpreting outcomes and choosing follow-up actions, such as improving precision when uncertainties may be overestimated or identifying systematic errors when the model appears limited. Procedural tools (histograms, mean, standard deviation, uncertainty propagation) were taught to both conditions.

## Design Implications

### Context
#### Requirements
- Students must be taught both the comparison tools and a framework for using them to decide how to act on comparisons
#### Constraints
- A large χ2 might reflect an issue with the model, but students were deliberately not told what to do about it, leaving room for autonomous decision making

### Target Learners
- first-year undergraduate physics lab students

### Learning Goals
- quantitative comparison of measurements and models
- interpreting disagreement in units of uncertainty
