# AI Study Coach: a notebook-embedded scaffolded AI tutor with two modes and four session constraints

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The AI Study Coach is an AI tool built into Jupyter-notebook laboratory sessions so students can consult it without leaving the task. It operates in two modes: Explainer mode, in which it "explained analytic outputs and the design choices behind the code", and Debugger mode, which gives stepwise hints from general to specific without generating code. Four constraints apply each session: a 25-hint budget, a fifteen-minute AI-use limit, an end-of-session written reflection, and tagging of AI-sourced code. Together these constituted the scaffold under study.

## Design Implications

### Context
#### Requirements
- Integration into the notebook environment so consultation happens within the laboratory task
- Teaching-team visibility of tagged AI-sourced code for the scaffold to be monitorable
#### Constraints
- The article's results say nothing about scaffolds in general, only that this particular scaffold did not produce the assumed learning advantage

### Target Learners
- master's-level students in a data analytics and machine learning course with varied prior programming experience

### Learning Goals
- data analysis and machine learning practice: understanding analytic outputs, debugging code, and responsible AI use
