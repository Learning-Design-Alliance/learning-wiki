# CHSH card game demonstrating Bell's inequality with classical objects

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A card game in which two decks of cards are dealt to Alice and Bob, each card carrying two dichotomous properties (back colour and front colour) coded as ±1. Because the system is classical, both properties can be measured on every card, so players can compute Si for each pair and see that "Si can assume only the values ±2", making the bound |⟨S⟩| ≤ 2 evident. The game is described as "an elementary way to show CHSH inequality, accessible to anyone who knows how to calculate mean values", and it introduces perfect correlation (⟨S⟩ = 2), perfect anticorrelation (⟨S⟩ = −2) and no correlation (⟨S⟩ = 0).

## Design Implications

### Context
#### Requirements
- A dealer (Charlie) preparing two decks of N cards whose pairs carry the correlations of interest, and players able to calculate mean values
#### Constraints
- The game relies on a gimmick: measuring all quantities at once is possible only because the system is classical; in a true experiment ⟨S⟩ is obtained by averaging each product column, and in the quantum case Si cannot be evaluated

### Target Learners
- high-school students
- general public

### Learning Goals
- understand the CHSH formulation of Bell's inequalities
- distinguish classical from quantum correlations
