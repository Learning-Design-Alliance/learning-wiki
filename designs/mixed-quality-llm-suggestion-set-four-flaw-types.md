# Mixed-quality LLM suggestion set with four deliberate AI flaw types

> **Design** · [All designs](index.md)
> **Evidence** · 5 claims (5 for) · 4 studies (2 theoretical, 1 causal, 1 design), `q2` · 0 of 4 report an effect size · 5 claims rest on one study

## Description
A structured set of eight GPT-4.1-generated revision suggestions per student proposal, deliberately varying in quality: four sound suggestions (theoretical grounding, data source, analytic approach, writing criteria) interleaved with four flawed ones. "Suggestions C, D, F, and H represented four distinct AI flaw types": fabrication (fabricated theory with fictitious references), decontextualization (irrelevant data source), invalid inference (logically incorrect interpretation), and genre mismatch (inappropriate proposal structure). Fidelity checking found 147 of 152 suggestions (96.7%) conformed to the intended design.

## Design Implications

### Context
#### Requirements
- Suggestions must be personalized to the student's draft and presented in a fixed interleaved sequence
#### Constraints
- The suggestion set was more adversarial than real-world use, with half of suggestions flawed, so absolute acceptance rates should not be read as real-world uptake

### Target Learners
- post-secondary students writing data analysis proposals

### Learning Goals
- identifying flaws in AI-generated writing feedback
- practicing critical evaluation of AI suggestions
