# Visitor annotation features enabling bi-directional curator-audience information flow

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The annotation system comprises a Visitor Annotation View (curator preset label plus expandable visitor comments and a comment input with virtual keyboard), an Annotation Summary View consolidating all annotations per artwork, and a virtual guestbook at the entrance. The design idea is "to enable the bi-directional information flow between the curator and the audience so that the dialogue between the curator and the public and the dialogue between visitors can be constructed." New comments become available for later visitors.

## Design Implications

### Context
#### Requirements
- Visitors interact with artworks or a laptop on a display case to trigger the views; a virtual keyboard is used for comment input
#### Constraints
- The annotation summary view currently offers the same user comment information as the individual artwork's annotation view; the authors propose ranking and filtering enhancements

### Target Learners
- art and archaeology students
- museum-style exhibition visitors in VR

### Learning Goals
- peer critique and commentary
- dialogue between curator and audience
- dialogue between visitors
