# Teach how AI models process prompts and how interactions can be exploited, to build cognitive resilience against manipulation

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article argues that integrating explicit instruction on how AI models process prompts, recognize system boundaries, and respond to linguistic cues serves a dual purpose in higher education: it builds technical proficiency and fosters "cognitive resilience against manipulation". By teaching both effective interaction and how interactions can be exploited, institutions can cultivate a more security-aware user base capable of identifying and resisting prompt injection attempts.

## Design Implications

### Context
#### Requirements
- Curricula or professional development that cover both legitimate prompt engineering and adversarial exploitation of the same techniques
#### Constraints
- Grounded in one AI tool and one grading scenario; the article does not empirically test the educational intervention

### Target Learners
- higher education students
- higher education faculty

### Learning Goals
- understanding AI prompt processing and system boundaries
- identifying and resisting direct and indirect prompt injection
