# Layered address mapping: quantum numbers as hierarchical features of a building

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The analogy's core organizing idea is that the four quantum numbers form a layered address within one shared structure rather than four isolated labels. Each number maps to a building feature: floors encode discrete ordered energy levels (n), suite layout encodes subshell type (ℓ), suite orientation encodes distinct variants of the same layout (mℓ), and occupant handedness encodes the intrinsic two-valued spin tag (ms). The authors state the building "gives students a familiar hierarchy to hang the four quantum numbers on before the formalism arrives," so students see them as a layered address system.

## Design Implications

### Context
#### Requirements
- Instructors should frame floors as ordered but not uniformly separated, encoding ranking rather than energetic distance
- Instructors should frame orbitals as categories of allowed quantum states, not physical containers
#### Constraints
- Floors suggest evenly spaced energy levels, which they are not; the number of suite types and orientations is fixed in a real building but not in quantum numbers; handedness is the weakest mapping since spin has no classical counterpart

### Target Learners
- Novice physics students in secondary or introductory undergraduate courses

### Learning Goals
- Organizing the four quantum numbers as coordinates within a structured system rather than arbitrary labels
