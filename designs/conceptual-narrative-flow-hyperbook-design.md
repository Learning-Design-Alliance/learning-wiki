# Conceptual and narrative flow as a design concern for open-ended hyperbook learning

## Description
The article frames hyperbook design around the problem that flexible, idiosyncratic navigation can break "conceptual and narrative flow". It treats learner reading as opportunistic and active, so the system must supply adaptive smoothing and linkage structures to keep a coherent storyline and concept structure intact across non-linear paths through richly interconnected material.

## Design Implications

### Context
#### Requirements
- Adaptive methods and interface features such as narrative smoothing, custom depth control, and thematic links
#### Constraints
- Applies to open-ended learning environments where users navigate flexibly and idiosyncratically

### Target Learners
- self-directed learners navigating hyperbook content

### Learning Goals
- sustained comprehension across non-linear navigation
