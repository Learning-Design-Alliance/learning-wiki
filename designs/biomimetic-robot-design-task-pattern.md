# Biomimetic design task pattern: study animal structure–function, then design and build a robot inspired by that analysis

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
In this pattern, students first study the natural world to learn how animals accomplish tasks, then engineer a robot inspired by what they learned. The design challenge (a biomimetic search-and-rescue robot) requires students to decompose the animal system, extract relevant principles to create a conceptual model, use the model as a basis for conceptualizing their robot design, and build a functional robot, engaging science, engineering, and CT practices across a 3- to 4-week unit.

## Design Implications

### Context
#### Requirements
- Biology resources (text and curated videos about animal structures and functions)
- Engineering resources (mechanism examples, design worksheets)
- Robotics kit and programming environment
#### Constraints
- Y1 experience showed an open-ended version of this pattern led to a wide range of outcomes; a narrowed task with targeted resources better enabled discipline-driven design

### Target Learners

### Learning Goals

- engineering design practices
