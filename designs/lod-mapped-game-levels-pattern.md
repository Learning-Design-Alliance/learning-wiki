# Game levels of increasing difficulty mapped to increasing BIM Levels of Development

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The prototype structures gameplay as sequential assemblage levels whose component detail corresponds to BIM LOD classifications: level 1 uses LOD 200 approximate geometry represented by LEGO, and level 2 uses LOD 300 precise building geometry. The authors borrowed from "universally established BIM Level of Developments standard classifications" and classified building construction components into game artifacts via two classes of LODs, so learners progress from abstract to precise geometry.

## Design Implications

### Context
#### Requirements
- BIM components classified by level of development; game levels sequenced from lower to higher LOD after precedent exploration and practice
#### Constraints
- The classification was created specifically for this game based on geometry complexity, similar to but not identical with the universal BIM LOD definition

### Target Learners
- architecture and construction students
- cross-disciplinary learners without prior design knowledge

### Learning Goals
- understanding design tectonics
- progression from abstract geometric concepts to precise building assembly
