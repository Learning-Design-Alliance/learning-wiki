# Lego Mindstorms EV3 robotics summer camp curriculum for elementary children (9 classes with lessons, worksheets, and hands-on activities)

> **Design** · [All designs](index.md)
> **Evidence** · 7 claims (4 for, 3 mixed) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size · 7 claims rest on one study

## Description
A 9-class summer camp curriculum (8-17 May 2016, Bangalore) teaching robotics to elementary children using the Lego Mindstorms EV3 kit. Each class combined lecture, practical hands-on activity, tests, and worksheets, progressing from kit basics through robot construction, tank steering, turning, robotic arm construction, and light, gyro, and ultrasonic sensor programming. The authors state each class had "a combination of lecture, practical hands-on activity, tests and work-sheets", and worksheets were evaluated to track improvement in robotics, one of six targeted skills (computational thinking, programming, handling complexity, project management, teamwork, robotics).
