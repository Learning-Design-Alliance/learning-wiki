# Sequenced tutorial progression in which each alignment skill builds on previously mastered skills

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The eight tutorials form a deliberate skill ladder: each tutorial lists explicit prerequisites drawn from earlier tutorials, and each ends with a "What is next?" section pointing to the tutorials its final setup enables. Tutorial 3 states plainly that "The prerequisite for this tutorial is the successful completion of Tutorial 2." This chaining lets complex skills such as aligning a second laser along an established beam path be decomposed into previously mastered components like establishing a bolt-hole line, inserting mirrors, and walking a beam.

## Design Implications

### Context
#### Requirements
- Tutorials must be completed in order, or the student must independently verify the prerequisite skill (e.g., that the beam already follows a bolt-hole line)
#### Constraints
- Later tutorials assume the final setup of specified earlier tutorials as their initial setup

### Target Learners
- novice optics laboratory students

### Learning Goals
- progressive mastery of optical alignment skills from basic to advanced
