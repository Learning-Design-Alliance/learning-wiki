# TAP's four-component whole-school design combining growth, leadership, feedback, and performance pay

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (2 for, 1 against) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
TAP bundles four school-wide components: professional growth opportunities, promotion to school leadership roles without leaving the classroom, structured feedback, and performance-based compensation. The report describes it as "a whole-school intervention that aims to improve schools by raising teacher quality," evaluating whether these combined changes affect teachers and students.

## Design Implications

#### Constraints
