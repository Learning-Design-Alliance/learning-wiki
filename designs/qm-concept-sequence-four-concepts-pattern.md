# Concept-sequence pattern for elementary Quantum Mechanics: Physical System → Dynamical Variables → State → Time Evolution, anchored in three situations

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A unit-level instructional pattern for teaching elementary Quantum Mechanics conceptually rather than only mathematically. The most general concept, Physical System, is taught first, followed by Dynamical Variables, State of a Physical System and Time Evolution, so that "Physical System (the most general) → Dynamical Variables → State of a Physical System → Time Evolution" facilitates progressive differentiation and later integrative reconciliation. Each concept is introduced through one of three situations — the Stern-Gerlach experiment, the hydrogen atom and the ammonia molecule — with the situation presented first, then the concepts, then differentiation and reconciliation, repeated for each situation.

## Design Implications

### Context
#### Requirements
- Presentation of situations belonging to different areas of Physics to facilitate concept acquisition
- Dirac notation used as representation so mathematics is not eliminated
#### Constraints
- The authors note teaching of State of a Physical System and Time Evolution is rarely found in bibliographic reviews, limiting prior guidance

### Target Learners
- undergraduate physics students taking introductory Modern Physics
- pre-service physics teachers

### Learning Goals
- concepts of Physical System, Dynamical Variables, State of a Physical System and Time Evolution
- predictivity and causality evoked by Time Evolution
