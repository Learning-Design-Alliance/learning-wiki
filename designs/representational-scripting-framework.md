# Representational scripting: sequencing part-tasks and matching each tool's ontology to part-task demands

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Representational scripting integrates collaboration scripts with representational tools so that the problem-solving process is sequenced into part-tasks whose demands are made explicit, and each tool's representational guidance is congruent with those demands. According to the article, a script is "a set of instructions regarding to how the group members should interact, how they should collaborate and how they should solve the problem". A tool's ontology (its objects, relations and combination rules) makes certain concepts and interrelationships salient: less expressive, first-order ontologies support qualitative causal inference-making, while more expressive, second-order ontologies support quantitative inference-making. In the study, a causal tool was matched to the problem–solution phase and a simulation tool to the solution–evaluation phase.

## Design Implications

### Context
#### Requirements

#### Constraints

### Target Learners
- secondary-school students (novices) working on complex learning tasks in teams

### Learning Goals
- acquiring a well-developed qualitative and quantitative understanding of a domain and applying it to solve complex problems
