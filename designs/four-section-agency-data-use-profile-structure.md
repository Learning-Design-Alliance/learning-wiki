# Four-section structure for documenting agency data-use partnerships

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Each profile follows a recurring four-part structure: background and context for data use; working with SDP/EP fellows; data analysis and reporting; and challenges encountered and lessons learned. The document states that "Each profile contains the following information" and lists these sections, giving a reusable template for describing how an education agency builds data-use capacity through an embedded fellowship. An organizational chart in each profile displays the path from the fellow's position to agency leadership.

## Design Implications

### Context
#### Requirements
- Site visit interview data from the agency
- An organizational chart showing the fellow's positioning within the organization
#### Constraints
- Structure reflects the SDP/EP fellowship partnership context and the 2013–14 school year

### Target Learners
- Education agency staff and leaders hosting data fellows

### Learning Goals
- Organizational data use
- Data analysis and reporting practice
