# G-Jump: a three-stage gamified Triple Jump Exercise assessment model for anesthesia education

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
G-Jump integrates the Triple Jump Exercise with gamification following the Werbach–Hunter framework. Its three jumps are a points-based competitive closed-book case MCQ test, an open-book case analysis scored for response quality and search strategy, and a structured reflective narrative scored by two evaluators (inter-rater reliability ICC = 0.87). Game elements include a "Plague Doctor" narrative, live leaderboards, badges, and real-time feedback. The study evaluated it against TJE and closed-book control in a three-group quasi-experiment.
