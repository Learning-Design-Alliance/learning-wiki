## Description
The authors released the learning path's instructional materials, including the post-test scoring criteria, in a public GitHub repository. The article prints: "Materials: https://github.com/tail-unica/ai-literacy-primary-ed ." The repository supports replication of the four-module path and of the expert scoring protocol, which the article says used predefined criteria per exercise (see our repository) for independent evaluation by three experts.
