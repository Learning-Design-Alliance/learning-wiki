# Multi-platform e-mentoring environment (Google Classroom, Nearpod, Facebook, Padlet) with distinct pedagogical functions

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The intervention combined four digital platforms, each with a distinct function: 'Google Classroom functioned as the main organizational platform through which participants accessed weekly tasks, instructional videos, and learning resources'. Nearpod delivered interactive presentations and lesson-design demonstrations, Facebook served as a collaborative mentoring space for sharing teaching videos and peer feedback, and Padlet supported anonymous reflection and scenario-based analysis. The article states the multi-platform use 'was intended to create an integrated mentoring environment and avoid repetitive interaction through a single tool'.

## Design Implications

### Context
#### Requirements
- Participants need access to all platforms so each pedagogical function is served
#### Constraints
- Platform roles were defined for this practicum context; the article does not claim the same configuration generalizes elsewhere
