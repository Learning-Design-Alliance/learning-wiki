# DeepSeek-based AI teaching assistant with anesthesiology knowledge graph, personalized plans, and real-time performance analysis

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
An AI teaching assistant built on the Shanghai Jiao Tong University online learning platform using the DeepSeek large language model. The developers uploaded course materials and lesson plans, created a Q&A database and test bank, and "A knowledge graph covering the core system of anesthesia and critical care emergency medicine was constructed, covering 1,215 high-frequency knowledge points". It provides 24/7 online support, targeted practice questions, personalized study plans, real-time performance reports for students, and flags class-wide knowledge gaps to teachers.

## Design Implications

### Context
#### Requirements
- Integration with an online teaching platform hosting a customized localized knowledge base so responses draw on course content rather than generic public knowledge
#### Constraints
- The system, as built, lacked spaced-repetition and active-recall modules for long-term retention

### Target Learners
- Fourth-year clinical medicine undergraduates
- Non-anesthesiology resident physicians

### Learning Goals
- Foundational anesthesiology theories
