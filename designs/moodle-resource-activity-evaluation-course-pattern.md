# Moodle course pattern combining resources, interactive activities, communication tools and automated evaluation for skills teaching

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article's course design combines content resources with interactive, communicative and evaluative Moodle modules. As printed: "We used the option LABEL for add itional information, and RESOURCE for Word documents and PowerPoint presentations." Communication and collaboration used CHAT and FORUM, group feedback used CHOICE, collaborative project work used the WIKI option, and student work was evaluated with ASSIGNMENTS and WORKSHOPS, whose evaluation forms "offer many options for automatic evaluation". Tests, lessons and SCORM-interoperable modules enabled individualisation depending on options selected by students.
