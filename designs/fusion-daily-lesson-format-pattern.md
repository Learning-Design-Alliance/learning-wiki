# Fusion Reading Daily Lesson Format: five rotating activities within each class session

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Daily Lesson Format is the lesson-level structure of Fusion Reading that ensures all critical instructional activities occur in every session. "During a 60-min class, teachers and students rotate through five activities: Warm-up (5 min), Thinking Reading (12 min), Explicit Instruction (20 min), Vocabulary (18 min), and Wrap-up (5 min)." The Warm-up is a scored vocabulary question about the class novel; Thinking Reading has the teacher model expert reading behaviors; Explicit Strategy Instruction includes explain, model, practice, and feedback; Wrap-up uses an exit ticket and previews the next lesson. The article states this structure helps ensure instructional variety and that every minute possible is an opportunity for explicit instruction.

## Design Implications

### Context
#### Requirements
- All five activities must be included in each class session
- A quick assessment of the main skill taught (exit ticket) during Wrap-up
#### Constraints
- Timings described are for a 60-min class; the course may also be taught in 50-min periods

### Target Learners
- Middle school students with reading disabilities in supplemental reading classes

### Learning Goals
- Application of reading strategies
- Vocabulary learning
- Daily comprehension checks
