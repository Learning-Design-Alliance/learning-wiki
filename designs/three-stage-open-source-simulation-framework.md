# Three-stage framework for using open source simulation: design, customization and implementation

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article proposes classifying the use of open source simulation into three stages. In the design stage the team decided on features in a paper design exercise and chose a base simulation close to requirements; in the customization stage cognitive-load principles were applied using EJS; in the implementation stage the customized simulation was taught in a 5E enrichment lesson. The authors state 'Such classification can possibly guide the interested educators and researchers in the use of open source simulation.'

## Design Implications

### Context
#### Requirements
- Requires access to source code and a relatively simple simulation author toolkit such as Easy Java Simulation
#### Constraints
- The article notes such teacher customization is rarely published because codes are not easily available or author toolkits are not simple to use

### Target Learners
- elementary school students (Grade 4 and 5)

### Learning Goals
- understanding energy conversion (gravitational potential energy and kinetic energy)
