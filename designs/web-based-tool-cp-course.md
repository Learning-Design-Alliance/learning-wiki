# Customized web-based tool supporting PS and traditional course groups

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A customized web-based tool offered two student interfaces, one per instructional group, with different menu functions but the same interface design principles: limited text per page, scrolling avoided, and multimedia learning principles applied, including "spatial contiguity", so that flowcharts and pseudo codes supported integrated display of text and images. For the PS group it guided and supported PS activities and presented course materials, conceptual models, practice problems and worked examples; for the control group it only posted course materials.

## Design Implications

### Context
#### Requirements
- Application of multimedia learning principles (Mayer, 2009) in page design
- Instructor guidance, since hypermedia enhanced understanding only "if it is guided by an instructor and supported by a PS context"
#### Constraints
- The tool served as an instructional guide only for the PS group's instructors; the control group's tool function was posting materials only

### Target Learners
- first-year undergraduate novice programmers

### Learning Goals
- C programming achievement
- problem-solving perceptions
