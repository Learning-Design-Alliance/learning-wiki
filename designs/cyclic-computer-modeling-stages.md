## Description
The article presents computer modeling as a sequence of stages shown in a flowchart (Figure 1), from structural analysis of the object through model construction to computing experiment. It states "The modeling method is cycling in character", so that for each concretized model all methodology steps are repeated, with the computing stage recurring checks and calculations for different model parameters. The stages serve one purpose: an adequate quantitative description of the studied phenomenon with necessary accuracy for minimal machine time.
