# Three overlapping CDA analysis groups with integrated whole-class discussion

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
During treatment, students were divided into three groups, each addressing one stage of analysis, since the levels "can be simultaneously operationalized in an EFL reading classroom as three overlapping stages". Group A describes vocabulary and sentence structure using context; group B interprets by writing about the topic from background knowledge, putting students "in the position of writers rather than readers"; group C explains using a question list, bringing ideologies and reading against the text. Representatives then present results and an integrated analysis is discussed.

## Design Implications

### Context
#### Requirements
- Teachers help groups extract meaning, encourage broader context use, and integrate the three layers in a whole-class discussion
#### Constraints
- The authors note that when using CDA's three levels, "not every CDA concept is equally useful"; facilitators and students can select tools

### Target Learners
- EFL undergraduate reading classes

### Learning Goals
- description of texts
- interpretation of texts
- explanation of sociocultural dimensions of texts
