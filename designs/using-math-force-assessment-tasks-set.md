# Seven paper-based assessment tasks eliciting Using Mathematics blended with force

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The authors designed seven constructed-response assessment tasks targeting the scientific practice of Using Mathematics blended with the concept of force in introductory mechanics, following ECD stages and 3D-LAP criteria. Each task gives an event or phenomenon, asks students to perform calculations or generate mathematical representations, and asks for an interpretation of results in context. An exemplar is the car accident reconstruction problem (Fig. 1), in which students determine a driver's pre-accident speed from skid-mark data and judge fault against an 18 m/s speed limit. Across 8 interviews the tasks yielded 53 analyzable verbal and written response instances.
