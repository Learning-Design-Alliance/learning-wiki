# UIDEL: user interface design for e-learning as the intersection of UI design principles and learning psychology

## Description
The article proposes that designing the user interface of educational software requires combining conventional UID principles with principles and concepts of learning. It frames UI as "the point of interaction between user and educational body" and argues that educational aims may fail even with good content if this correlation is unsuccessful. The framework organizes its analysis around stimulus/motivation, working memory, multimedia presentation, and availability as UI-relevant learning factors.
