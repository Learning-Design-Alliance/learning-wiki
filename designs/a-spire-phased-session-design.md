# Dual-track, phased session design pairing teacher and student activities across the six A-SPIRE stages

## Description
The article's instructional design divides the session into pre-class preparation, in-class A-SPIRE application, and post-class extended learning, with a flowchart aligning teacher activities, the teaching process, and student activities. Each phase has a set duration, e.g., an "Anchoring Phase (10 min)" using film clips, and a "Realizing Phase (45 min)" in which "Student groups created a precision science communication work (mask design) on 'oral health' for their assigned audience," followed by sharing and multi-dimensional evaluation.

## Design Implications

### Context
#### Requirements
- Pre-class questionnaire to assess prior knowledge and readiness; online assessment platform for questionnaires and tests; group work with a shared artifact and multi-source evaluation
#### Constraints
- The uniform output format (mask creation) meant suitability of format was not included as an evaluation criterion for this exercise

### Target Learners
- undergraduate medical students in elective courses

### Learning Goals
- translating audience-analysis theory into tailored communication artifacts
