# Набор из трёх виртуальных лабораторных работ по эмиссионным атомным спектрам

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Авторами разработаны три лабораторные работы на базе эмулятора спектрографа: «Определение постоянной Ридберга по эмиссионному спектру атомарного водорода», «Измерение изотопического сдвига линий спектров водорода и дейтерия» и «Эмиссионный спектр водородоподобного иона». Апробация прошла при изучении физики студентами инженерных специальностей технического университета.

## Design Implications

### Context
#### Requirements
- Доступ к кроссплатформенному web-приложению и Google-таблицам с индивидуальными параметрами

### Learning Goals
- экспериментальная проверка теории атома Бора
- измерение фундаментальных физических постоянных по спектрам
