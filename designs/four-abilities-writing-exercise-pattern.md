# Exercise set designed to form four writing abilities: chronological description, selecting main facts, causal relations, and forming conclusions

## Description
The article enumerates the abilities its exercise set was meant to form: describing events successively in chronological order, choosing main facts while describing things, characters and places, establishing causal relations in acts and events, and forming conclusions and summaries. This design pattern links each supplementary exercise to a target ability so students can "communicate their ideas in examinations, repo rts, etc."
