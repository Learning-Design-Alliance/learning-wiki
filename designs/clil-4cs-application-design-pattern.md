# CLIL applications planned through the 4Cs following the Coyle, Hood and Marsh guide

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
This pattern structures content-subject lessons as CLIL applications attending to the 4Cs: Content (subject topics), Communication (the four language skills), Cognition (Bloom's LOTS and HOTS) and Culture (the socio-cultural context as a thread through each application). The teachers "developed a total of 17 applications in which the 4Cs are taken into account according to CLIL", planned following the guide established by Coyle, Hood and Marsh (2010): define content, link it to communication, explore cognitive abilities, and establish culture contextually.

## Design Implications

### Context
#### Requirements
- Planning guided by an expert CLIL teacher through LOCIT accompaniment
- Selection of subjects and topics coherent with the students' English level
#### Constraints
- Applications were designed for first-semester Nursing program subjects at English level A1.1 of the CEFR

### Target Learners
- First-level (A1.1) English students in higher education Nursing programs

### Learning Goals
- English communicative competence
- Cognitive skills applied through a foreign language
