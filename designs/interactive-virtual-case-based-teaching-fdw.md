# 90-minute faculty development workshop on interactive virtual tools for case-based teaching

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A 90-minute virtual workshop, delivered twice, that demonstrates interactive teaching tools (Zoom chat, whiteboard and annotations, polling, breakout rooms; Backchannel Chat; Padlet; PollEverywhere) within videoconferencing platforms for case-based teaching. Participants experience each tool as learners, then work in small breakout groups to plan how to integrate tools into case-based sessions of different sizes, considering anonymity and learner level. Materials include six peer-reviewed appendices (readings, worksheets, presentation, facilitator guide, evaluation).

## Design Implications

### Context
#### Requirements
- Participants need basic videoconferencing knowledge (e.g., logging on, muting/unmuting)
- Facilitators need familiarity with the interactive tools and should test software and rehearse beforehand
- Computer with reliable internet, microphone, speakers; Zoom link; word-processing program
#### Constraints
- Technology changes rapidly, so specific tools may change or become unavailable; the workshop mitigates this by teaching broad tool categories and general features
- Small audience sample sizes and self-report evaluation limited robust effectiveness evaluation

### Target Learners
- Health professions educators
- Faculty small-group facilitators
- Graduate students in health professions education

### Learning Goals
- Explain learning theories underpinning a multimodal model of online learning
- Identify features and limitations of interactive virtual tools
- Integrate online tools into interactive case-based virtual teaching sessions
