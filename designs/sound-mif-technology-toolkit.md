# Multimedia and technology toolkit for the sound-and-music MIF

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
To increase effectiveness of the approach, the course used a set of instruments including "a particular care on graphics representation of sound" (spectrum, sonogram, harmonic table vibration figures), "interactive numerical tools, provided both by web applets and dedicated software to simulate sound properties and production processes", audiovisual presentations, scientific technology, musical instruments, and evaluation tools (income and outcome tests, student cards).

## Design Implications

### Context
#### Requirements
- Classroom access to web applets, dedicated simulation software, audiovisual means and musical instruments
#### Constraints
- In participants' later proposals, evaluation instruments from this toolkit were taken in very little consideration

### Target Learners
- prospective secondary-school physics teachers

### Learning Goals
- understanding wave and sound properties through graphical, interactive and musical representation
