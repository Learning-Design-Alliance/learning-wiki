# Interactive big visual data editing system for image retrieval and 3D reconstruction

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Phase 3 system operates on big visual data, supporting online picture sharing and virtual 3D world navigation built from large unordered collections of online images of landmarks and cities. Students used image feature descriptors such as SIFT or SURF to identify similar images for clustering, then estimated scene geometry from feature correspondences across multiple views. The system "can provide virtual environment and immersive experience that allows users to walk freely in a re-constructed virtual world".

## Design Implications

### Context
#### Requirements
- Image matching APIs and 3D transformation tools
- Feature correspondences detected across multiple views
- Experience from the first two phases
#### Constraints
- Requires students to explore core techniques and develop novel solutions, not only use available software tools

### Target Learners
- undergraduate students in an Interactive Media course

### Learning Goals
- visual data clustering and reconstruction
- manipulating and altering large visual data
