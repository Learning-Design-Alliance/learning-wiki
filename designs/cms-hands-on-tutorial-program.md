# CMS hands-on tutorial program on common physics analysis tools (CMSSW/Python, PAT, RooStats/RooFit, CRAB, Fireworks) with feedback forms

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The User Support organizes tutorials year-round, mostly at CERN and also at FNAL and DESY, given by experts and relying on the collaborative spirit. Topics include the CMSSW software framework with Python configuration, the PAT analysis toolkit, combined RooStats and RooFit statistics methods, the CRAB grid-submission utility, and the Fireworks event display. Presentations and video recordings are uploaded to Indico as persistent storage, and feedback forms supply suggestions and improvements.
