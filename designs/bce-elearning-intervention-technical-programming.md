# Brain-compatible e-learning intervention for Technical Programming 1 (Moodle lessons with interactive sorting and fizzbuzz tasks)

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The intervention is an e-learning package delivered via Moodle lessons augmenting lectures, containing an "Interactive sorting algorithm presentation", an "Interactive question during fizzbuzz code execution", and "Example of immediate interactive feedback during fizzbuzz task" (Figures 3.4-3.6). It "incorporated several brain-compatible learning principles" and was "administered as a controlled experiment intervention" to a sample group whose performance was compared to a control group of the rest of the class.
