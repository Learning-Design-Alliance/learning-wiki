# Representação multimodal tato-térmica para conceitos astronômicos visualmente dependentes

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Um padrão de design instrucional que converte conceitos normalmente apresentados visualmente em experiências táteis e térmicas. O kit didático é baseado "no uso do tato e dos receptores térmicos para o ensino de Astronomia", porque o braille é "limitado quando se deseja apresentar percepções normalmente apresentadas sob o ponto de vista visual, tais como a noção de espaço, tamanho e temperatura". Temperatura, textura, tamanho e distância tornam-se canais táteis paralelos na maquete.

## Design Implications

### Context
#### Requirements
- Um mapeamento físico consistente entre propriedade astronômica e canal sensorial: hemisférios para tamanho, textura para tipo de planeta, pastilhas para temperatura, marcações de cola relevo para distância
#### Constraints
- A escala linear de temperatura adotada é um artefato didático, não a temperatura real dos planetas

### Target Learners
- Estudantes com deficiência visual do ensino básico e público geral

### Learning Goals
- Noções de espaço, tamanho e temperatura no Sistema Solar
