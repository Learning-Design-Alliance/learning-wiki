# Xenograde Systems instructional project (BURN11 dataset): a four-unit, one-week hierarchical learning sequence on an imaginary science

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The instructional intervention comprised "a two-phase description of an imaginary science designated as Xenograde Systems: a lecture/discussion phase, and an individual working phase." Curricular materials spanned four hierarchical learning units delivered in booklets of four to five pages with written prose, diagrams, graphs, and tables: Unit 1 defined basic terms and operations, Unit 2 covered rules and procedures for reading graphs, Unit 3 introduced facts and concepts increasing system complexity, and Unit 4 presented the fully operating system. One multiple-choice achievement test per unit (18, 14, 16, and 16 items; reliabilities .83, .76, .80, .76) assessed knowledge, comprehension, and application.
