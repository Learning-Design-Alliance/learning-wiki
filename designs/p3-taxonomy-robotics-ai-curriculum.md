# Project-based robotics + AI curriculum structured by P3 Task Taxonomy with backward design

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The curriculum comprised 10 lessons followed by a robotics engineering design challenge, aligned with K-12 CS standards and structured using Barak and Assal's P3 Task Taxonomy: Practice tasks with predefined solutions, Problem Solving tasks allowing multiple approaches, and Project tasks as complex student-driven endeavors. It was developed with backward design, starting from the design challenge and working backward to essential learning objectives.

## Design Implications

### Context
#### Requirements
- mBot robotics kits with the mBlock block-based coding platform including AI/ML extensions
- alignment with K-12 CS standards
#### Constraints
- Sensor-based programming relied on student-written rules rather than data-driven learning, serving as a conceptual foundation for AI

### Target Learners
- high school students
- ninth and tenth graders

### Learning Goals
- programming concepts
- sensor-based robotics
- machine learning via image recognition
- engineering design process
