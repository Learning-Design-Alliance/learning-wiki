# Arduino microcontroller lab kit with sensors as a personal student-owned data-acquisition platform

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The element is a roughly $60 student-purchased lab kit consisting of an Arduino microcontroller and a set of sensors, used across the semester to build microcontroller-driven measurement systems. The Arduino UNO is described as "an 8-bit, 16MHz CPU with 2KB ram for program execution, and 32KB flash ram for program storage" with 20 pins of digital IO, some usable as analog inputs for temperature, humidity, pressure, and distance sensors. Students program it via C++ in the Arduino IDE or control it as a Labview 'slave' data acquisition device.

## Design Implications

### Context
#### Requirements
- All students buy the kit at the beginning of the semester
- The curriculum must begin with a simple discussion of electronics since most sensors interface via voltage
#### Constraints
- Units cost about $30 per board from a variety of vendors online

### Target Learners
- University Physics students, most of whom arrive with no programming background

### Learning Goals
- Programming and sensor development
- Interfacing sensors to microcontrollers
- Data collection and calibration
