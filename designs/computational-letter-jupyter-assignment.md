# Computational Letter writing assignment in a Jupyter notebook addressed to an external reader

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The Computational Letter (CL) is 'a Computational Essay written to an external reader,' implemented in a Jupyter notebook with starter instructional text that students replace with explanations for their reader. Students must make claims tied to student learning outcomes, present supporting evidence, describe how evidence was collected, and construct a reasoned argument connecting evidence to claims. The format combines the Computational Essay's code-narrative integration with the Letter Home's external-audience framing.
