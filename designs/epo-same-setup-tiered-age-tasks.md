# One shared experimental set-up with task difficulty tiered by age category

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
EPO uses a single physical apparatus for all participants while differentiating the written tasks by age group. The organizers explain: "One and the same experimental set-up is given to all participants but the tasks are different for the different age groups, the same as the swimming pool water is equally wet for all age groups in a swimming competition." In EPO8 the sections progress from getting to know the voltage source (tasks S), through LED light diffraction (M) and current-voltage characteristics (L), to university-level error analysis (XL).

# Tiered age-category tasks on one shared experimental set-up (S, M, L, XL)

> **Design** · [All designs](index.md)

## Description
The EPO format assigns every participant the same physical set-up but sequences the tasks by age category: the youngest (S) measure basic parameters, middle-age students (M) balance a Wheatstone bridge with resistors only, the oldest high-school category (L) performs the inductance measurement, and university students (XL) do error estimation and a professional measurement protocol. As the article puts it, "the tasks are diﬀerent for the diﬀerent age groups, the same as the swimming pool water is equally wet for all age groups in a swimming competition". This lets a single low-cost apparatus serve a wide age range in one event.
