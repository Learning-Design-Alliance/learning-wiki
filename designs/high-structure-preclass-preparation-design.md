# High-structure course design requiring preclass content acquisition paired with in-class active learning

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article situates reading guides within high-structure (and flipped) course designs, in which "students acquire content before class and then perform active-learning exercises in class" or complete graded preclass and weekly review assignments. The instructor-designed reading guides serve the preclass content-acquisition role in this structure, freeing class time for clicker questions, group work, discussion, and formative testing of misconceptions.

## Design Implications

### Context
#### Requirements
- Course content must be deliverable outside class time, via textbook reading or videos
- Some guidance and/or reward for completing preclass reading, which prior studies identified as common themes
#### Constraints
- Not reading before class "may be a recipe for disaster" in flipped or high-structure courses where preclass preparation is critical

### Target Learners
- Undergraduate students in large-enrollment college biology courses

### Learning Goals
- Active engagement with course content before class so class time can be used for active learning and scientific literacy skills
