# Two-phase scenario: initial competence-fostering course followed by a joint authentic practice task

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
Each educational scenario consisted of two learning activities: a semester-long online course (theory and practice lecture weekly) fostering either domain or meta competences, then a joint BIM practice task in which students had "to check a given building model using a previously unknown BIM validation software and to record issues found". The pattern lets two different initial courses be compared against one shared, authentic outcome task.

## Design Implications

### Context
#### Requirements
- An initial semester-long course aligned to an overarching goal
- A joint second learning activity assessable across cohorts
- Individual graded presentations of task results
#### Constraints
- Pilot field study with N=11; results are not representative
- The first measurement in the VirtuIng cohort preceded any domain input on BIM, so BIM-knowledge measurements carry a degree of inaccuracy

### Target Learners
- master students in Architecture
- bachelor students in Civil Engineering

### Learning Goals
- BIM domain competences
- meta competences such as communication and collaboration

- Similar Bim Test Performance Across Cohorts [+M]
