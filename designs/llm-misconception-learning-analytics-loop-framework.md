# Framework for closing the learning analytics loop via LLM-characterized misconceptions

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A cyclical framework in which data collection and analysis pinpoint challenging topics, LLMs characterize underlying misconceptions, and this analysis informs two intervention pathways: "cohort-level interventions for broad improvements and individualized learning paths for tailored support". Intervention effectiveness is then assessed with new data, refining the pedagogical process and revealing remaining or new misconceptions. The framework positions scalable misconception identification as the critical step toward closing the loop between learning analytics and instructional improvement.

## Design Implications

### Context
#### Requirements
- Formative assessment data (topic-focused quizzes) collected across cohorts
- LLM analysis grounded in quiz content, response patterns, and lecture transcripts
- Follow-up data collection to evaluate intervention effectiveness
#### Constraints
- The study focuses primarily on cohort-level analysis; individual student analysis is proposed for future work
- Intervention effectiveness measurement is proposed but not demonstrated in this study

### Target Learners
- medical students in online biomedical science courses

### Learning Goals
- identifying and remediating conceptual misconceptions in biomedical science
