# Biggs and Moore learning process model as the intervention framework

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article structures its 14-week intervention around the learning process model developed by Biggs and Moore, which the authors describe as comprising "four basic components that influence the learning outcomes": a well-structured knowledge base, motivational content, interactions (teacher-student and student-student), and active learning. Facebook sharing and feedback were used to operationalize the interaction and motivation components within constructivist, process-based writing instruction.
