# Multi-course project-based learning implemented in four phases: review, design, implementation and analysis

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article's MPL approach redesigns and tests a multi-course project in a four-phase cycle analogous to project-management process groups. As printed, "This study redesigns and tests a multi-course project-based learning case in four phases: a review phase, a design phase, an implementation phase, and an analysis phase". The review phase maps course learning outcomes to student learning outcomes across the two courses; the design phase produces project guidelines, grading rubrics and orientation; the implementation phase tracks student work with deadlines and training; and the analysis phase surveys perceptions and examines project grades.

## Design Implications

### Context
#### Requirements
- Explicit project rules and instructions stating deliverables, and a project-grading rubric aligned with the learning outcomes of every involved course
#### Constraints
- The stated difficulty of adopting MPL for senior-level courses is aligning the project toward fulfilling the learning outcomes of every individual course

### Target Learners
- senior-level undergraduate electrical engineering students

### Learning Goals
- course learning outcomes of an elective and a capstone course, including soft engineering and project management skills
