# ICT tool set used in the experimental Astronomy and Space Physics course

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The experimental group's instruction employed a specific set of ICT tools briefed to the course instructors: e-mails, Facebook and Twitter, on-line conference, and a learning site including YouTube-Cosmo Learning, space.com, universetoday.com, astronomynow.com, and astronomy101.jpl.nasa.gov. Instructors were also "trained on how to teach through employment of ICT using planning an educational tasks and worksheets by exploratory context". This tool set operationalised the ICT-based teaching whose literacy outcomes the study measured.
