# Two-part sequential curriculum bridging traditional machine learning and LLM applications

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The course is divided into two sequential, complementary components: Part 1 covers foundational machine learning and data science, while Part 2 covers LLM applications. The article states that "This sequential structure enables students to appreciate how modern LLMs extend and build upon traditional machine learning concepts rather than viewing them as entirely separate technological paradigms." Students then develop tool-selection ability based on problem requirements.

## Design Implications

### Context
#### Requirements
- Part 1 must establish core competencies in data preprocessing, feature engineering, model selection and evaluation before Part 2 introduces LLM technologies
#### Constraints
- Delivered as an intensive summer course spanning two seven-week terms

### Target Learners
- undergraduate and graduate computer science students at Oklahoma Christian University

### Learning Goals
- comprehensive understanding of the AI landscape
- practical skills with both traditional ML and LLM technologies
