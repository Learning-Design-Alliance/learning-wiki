# Python4Physics free summer outreach course using Python projects to cultivate STEM interest

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
Python4Physics is a free course created to teach students the minimal scientific background needed to perform computing-based research in a fun and accessible way. The course is organized around lessons in the Python programming language: short introductory slides followed by group work on open-ended problems such as projectile motion with graphing and animation, elastic collisions, and function fitting akin to particle-discovery identification. Lectures assume no calculus, only basic algebra.
