# Four active learning techniques adapted for asynchronous online anatomy delivery via Canvas discussion boards

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The course implemented four active learning techniques, each with a teaching phase and a learning phase, adapted for an asynchronous online format using the Canvas discussion board tool. As the article states, "The four active learning techniques implemented in the course were jigsaw, team‐learning module (TLM), concept mapping (CM), and question constructing (QC)." Jigsaw used recorded 3-minute PowerPoint presentations posted to shared boards; TLM used preparation, a five-question iRAT, and a shared 10-question tRAT worksheet; CM used concept-map creation with peer answering; QC used authoring two Bloom's-labeled multiple-choice questions and answering peers' questions.

## Design Implications

### Context
#### Requirements
- Discussion board tool in the Canvas learning management system; students subdivided into subgroups of approximately 9-13 students each assigned a designated unit objective
#### Constraints
- Activities were supplemental and did not introduce new course material; all techniques were worth the same points within the course grading structure

### Target Learners
- graduate health-professions students in a Master of Science in Medical Science program

### Learning Goals
- human anatomy content across five body-region units
