# Correlation-first inference via KL-divergence as a cross-disciplinary organizing framework

## Description
The article presents correlation-first inference as a paradigm following entropy-first thermodynamics, in which log-probability measures — surprisal, cross-entropy, and KL-divergence Iq/p ≥ 0, the negative of Shannon-Jaynes entropy — track subsystem correlations. It states these tools "have proven useful: (i) to engineers for measuring available-work or exergy in thermodynamic systems, (ii) to communication scientists and geneticists... and (iii) to behavioral ecologists wanting to select from a set of simple-models the one which is least surprised by experimental data". The framework connects thermodynamic availability, model selection, and complexity evolution for physics students.
