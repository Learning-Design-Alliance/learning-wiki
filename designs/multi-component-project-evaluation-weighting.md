# Multi-component project evaluation weighting presentations, reports, benchmark score, and peer assessment

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The course graded its team project through four weighted components: project report (25%), best registration result (5%), oral presentation (50%), and peer evaluation (20%). The design combines rubric-based instructor assessment, peer judgment, and a quantitative R-score to assess technical, communicative, and collaborative skills. The article describes it as balancing "technical rigor with collaboration, aligning with the course's learning outcomes".

## Design Implications

### Context
#### Requirements
- Rubrics shared with students in advance to clarify expectations
- Instructor assessments conducted in parallel with peer grading using the same rubric for triangulation
#### Constraints
- Peer evaluation can be influenced by interpersonal dynamics or inconsistent grading standards

### Target Learners
- Master's students in machine learning for health

### Learning Goals
- Technical proficiency in biomedical image processing
- Collaboration and communication skills
- Reproducible research practices
