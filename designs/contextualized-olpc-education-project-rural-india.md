# Contextualized-OLPC education project in rural India

> **Design** · [All designs](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A technology-implementation project in which OLPC laptops were introduced in nine rural Indian primary schools within a longitudinal quasi-experimental design (test n = 126, control n = 79) with pre- and post-experiment measures. The project "utilized strategies identified by the Technology-Community-Management model to address contextually germane factors of teacher training, unbiased gender access, and local language use."

## Design Implications

### Context
#### Requirements
- Strategies from the Technology-Community-Management model addressing teacher training, unbiased gender access, and local language use.
