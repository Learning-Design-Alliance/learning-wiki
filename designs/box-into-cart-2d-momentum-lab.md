# Box-into-cart momentum lab requiring 2D vector analysis with only stopwatch, ruler, and balance

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A laboratory activity in which a sliding mass (a 'box') slides down an incline and lands in a cart on a horizontal track, built from a Pasco track, collision cart, and mass set. The authors state: "In this work we present another experiment, using this aforementioned equipment, which only requires a stopwatch, ruler, and mass balance yet requires the two-dimensional analysis of the momentum vector." Unlike 1D collision labs, it requires resolving the momentum vector into components.

## Design Implications

### Context
#### Requirements
- Requires knowing the ramp/box coefficient of sliding friction, which could be established through a previous lab
- Setup must ensure the mass slides into the cart without bouncing out so the collision is perfectly inelastic
#### Constraints
- Without cameras or analysis tools it is difficult to predict final velocities unless the impact parameter is known, motivating this design

### Target Learners
- under introductory calculus-based or algebra-based physics students

### Learning Goals
- understanding the vector nature of momentum
- applying energy and momentum principles to collisions
