# Computer-Based Problem Solving (CBPS): problem-based learning combined with computer-assisted learning using GeoGebra as a cognitive tool

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
CBPS is defined in the article as "a combination of problem-based learning and computer-assisted learning", facilitating students "to use computer programs as cognitive tools to solve problems". In applying the model, learning uses a problem context and GeoGebra acts as the cognitive tool: students work in groups on staged questions, construct lines and observe how coordinates relate to line equations, formulating and communicating function equations. The article frames CBPS as engaging students in constructing knowledge, problem solving and critical thinking to improve HOTS.

## Design Implications

### Context
#### Requirements
- Problems must serve as triggers for learning activities; the article states the success of CBPS is greatly influenced by the problems chosen
#### Constraints
- The study applied CBPS only in Basic Mathematics content (linear equation and function) with prospective primary teachers; the authors note the focus was only on mathematics and recommend research in other subjects

### Target Learners
- prospective primary school teachers (5th semester, Jakarta State University)

### Learning Goals
- higher order thinking skills in mathematics: reasoning, mathematical connection, mathematical communication, problem solving
