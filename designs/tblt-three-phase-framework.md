# Task-based language teaching as a three-phase framework (pre-task, task cycle, post-task)

## Description
The article presents task-based language teaching as an approach using "tasks as the core unit of planning and instruction in language teaching", drawing on functional, interactional and structural models of language. Following Ellis (2003) and Willis (1996), procedures share "three principal phases: pre-task, during task, and post-task": pre-task activates schemata and topic-related vocabulary, the task cycle has learners work in pairs or groups toward a non-linguistic outcome, and the post-task phase provides form-focused work and reporting. The study operationalised this framework as its experimental treatment.
