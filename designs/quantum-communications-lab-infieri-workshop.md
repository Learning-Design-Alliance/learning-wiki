# Quantum Communications Lab — a 3-hours hands-on workshop at the 6th INFIERI Summer School

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A hands-on workshop delivered at the 6th INFIERI Summer School in 2021, where "Three types of teaching material were prepared for the workshop, whose purpose was mainly to provide the attendees with the necessary skills to continue their learning autonomously." It combined a short theoretical introduction, assisted setup of a Python environment with Qiskit and Netsquid, and six exercises for fixing contents and self-evaluation, including an exercise using the MadQCI network interface.

## Design Implications

### Context
#### Requirements
- Participants' own computers for setting up the working environment
- Access to the MadQCI network for the real quantum distributed key exercise
#### Constraints
- The workshop time was limited, so exercises were delivered in a single script so each attendee could start working when ready

### Target Learners
- young engineers and physicists who worked using sophisticated instrumentation daily
- PhD students

### Learning Goals
- simulating a whole QKD quantum system
- using a real quantum system
- continuing learning about quantum communications autonomously
