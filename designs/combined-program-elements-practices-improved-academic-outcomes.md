## Description
The study's central pattern is that it was the program elements and practices "when used together" that improved academic outcomes for New Heights participants, rather than any single component in isolation. The page frames this combination as defining "a possible roadmap for service providers interested in replicating the program's success". The pattern concerns a coordinated system of school-based supports for expectant and parenting students.
