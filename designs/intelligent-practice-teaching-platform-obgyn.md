# Intelligent practice teaching platform with three core modules

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The intelligent practice teaching platform is the article's central technological artifact, comprising three interconnected modules: a virtual simulation practice platform using LapSim® Haptic System VR/AR simulation for 10 common surgical procedures, an intelligent skills training platform with machine-learning competency assessment and personalized recommendations, and a clinical practice intelligent support platform with decision support and communication simulation. It included "a comprehensive virtual case learning environment containing 60 clinically representative cases stratified by complexity." Residents interacted with rule-based virtual cases in a turn-based format receiving automated feedback.

## Design Implications

### Context
#### Requirements
- VR/AR simulation hardware (LapSim® Haptic System) and expert-validated, rule-based virtual case scenarios
- Machine learning-based competency assessment algorithms fed by individual learning analytics
#### Constraints
- Evaluated only within obstetrics and gynecology residency training at a single institution

### Target Learners
- obstetrics and gynecology residents

### Learning Goals
- procedural skill proficiency, clinical reasoning, and clinical decision-making
