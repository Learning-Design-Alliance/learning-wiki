# Soft skill-based metacognitive learning (SSML) as an approach combining metacognitive awareness with soft-skill empowerment

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
SSML is the article's named framework: "Learning is instill awareness to the student a process of how to design, monitor, and evaluate the thought processes and activities carried out in solving problem." To solve problems, students connect past and present knowledge, use appropriate problem-solving strategies, and reflect on the process and solution, while soft-skill values (religious, self-confident, independent, curious, hard-working, courteous, respectful, honest, cooperative) are empowered throughout. The framework was tested against conventional learning in a quasi-experiment.
