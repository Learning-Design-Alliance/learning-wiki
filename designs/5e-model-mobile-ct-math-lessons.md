# 5E instructional model structuring mobile app development mathematics lessons in five stages

## Description
The article uses the 5E instructional model (engagement, exploration, explanation, elaboration, evaluation) as the instructional design framework for mobile CT-integrated mathematics lessons. Each stage maps to app development activities: engagement reviews prior area knowledge and arouses interest in calculation games; exploration has students design game interfaces on paper; explanation asks students to explain designs; elaboration extends to complex cases like null values; evaluation involves testing games and reflecting. The article states the model 'could be suitable for the instructional design of primary school CT-integrated mathematics curriculum.'
