# 24-task set derived from the Taxonomy of User Needs and Actions (TUNA) with easy and difficult variants

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article constructed a set of 24 tasks "derived from the Taxonomy of User Needs and Actions (TUNA), a framework of different ways that people use AI based on different degrees of cognitive effort required." The tasks span TUNA's four categories — information seeking, information processing and synthesis, procedural guidance and execution, and content creation and transformation — with three task types per category and an easy and difficult variant per task (e.g., naming one versus five Olympic medalists). All tasks were completable in under five minutes independently and were used across the three studies with a GPT-4o chat interface.
