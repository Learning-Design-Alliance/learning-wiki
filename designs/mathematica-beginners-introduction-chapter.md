# A beginner introduction to the Mathematica language preceding the group-theory content

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article opens with an informal chapter introducing Mathematica terms and definitions: notebooks, cells, cell types, output suppression, functions, user-defined functions, lists, matrices, modules, indices, and non-alphanumeric symbols, each with short code examples. It states the language "has greater strengths in terms of the way it allows one to use human-readable analytical expressions instead of a fully numerical setup like say, Python", which is why it is used in a theory-focused text.
