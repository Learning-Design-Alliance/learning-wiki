# Problem Patterns (PP) approach: a schema-based word-problem-solving model using colored circles, operators, and paths

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The Problem Patterns approach is a schema-based instructional model in which students represent word problems as diagrams of circles holding data points and operator circles, connected by colored lines showing the solution path. Students were "taught to break problems into data, units, and desired solution, removing irrelevant information, and make a solution model with manipulatives." The model distinguishes linear PPs, nonlinear PPs built from embedded linear sub-paths, and open versus closed forms, with irrelevant information appearing as unconnected circles.

## Design Implications

### Context
#### Requirements
- Students first identify main information, then relate known data and unknowns, then attach an operation to form the main path
- Different colors distinguish data circles, operator circles, and connecting lines so the main path can be found
#### Constraints
- Closed nonlinear PPs were very difficult for at-risk students, particularly second graders
- Nonlinear problems with more than one operation created greater information-processing load

### Target Learners
- at-risk grade 2 and 3 students with mathematical difficulties retained in grade at least once

### Learning Goals
- solving whole-number contextual word problems using addition, subtraction, multiplication, and division
