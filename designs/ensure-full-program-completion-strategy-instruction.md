# Ensure students complete the full set of strategy-instruction lessons, since effects grow with dosage

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article recommends that students complete the whole writing instruction program rather than only part of it, because the intervention effect was larger for students who finished all lessons. The authors state that "students will make more progress if they complete the whole program," noting this "can be achieved more easily when the implementation of Tekster is spread out over a longer period of time (e.g., one lesson a week), and/or if the program contained more lessons."
