# Set of OER physics simulations used as virtual apparatus across the twelve experiments

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The manual assembles existing open education resource simulations as the virtual apparatus for each experiment, including thephysicsaviary labs for buoyancy, Pascal's principle, and Bernoulli flow; an ophysics standing-wave simulation; an amrita.olabs resonance air-column simulation; a Pearson calorimetry simulator; and PhET simulations for gas properties and bending light. Each is credited to its source and operated through printed step-by-step instructions, with graphs inside the simulator serving as data-collection instruments.

## Design Implications

### Context
#### Requirements
- Internet access to the hosted simulations during lab sessions
#### Constraints
- The simulations determine which parameters students can vary, such as fluid type, tube radius, string tension, and gas temperature

### Target Learners
- introductory physics students in algebra-based and calculus-based lab courses

### Learning Goals
- conducting virtual versions of classic physics experiments and analyzing the resulting data
