# Secant–tangent transition applet characterized via the conceptual-structure variables

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
An interactive applet illustrates the metadata characterization: it represents a function graphically with a secant line defined by two points, one varying with a parameter h; as h approaches zero the secant converges to the tangent. It is characterized as derivative at a point (conceptual), with essential prior knowledge of functions, graphical interpretation, and slope, graphical predominant representation with implicit coordination of multiple representations, and process-level conceptual construction.
