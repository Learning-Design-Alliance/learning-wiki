# EAP's implicit structures build student agency within a rigorous scientific community

> **Design** · [All designs](index.md)

## Description
The article attributes the strength and longevity of the EAP model to "implicit structures that build student agency within a rigorous scientific community." These include flexible entry with pathway switching, representative instructors underrepresented in physics, a supportive environment where students can take risks, a deep learning focus on linear and inverse proportional relationships, and calculus foundations through precalculus reasoning.
