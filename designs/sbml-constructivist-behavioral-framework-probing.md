# Simulation-based mastery learning (SBML) framework integrating constructivist and behavioral learning theories

> **Design** · [All designs](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article grounds its training design in simulation-based mastery learning combined with deliberate practice, integrating both constructivist and behavioral learning theories. Constructivist learning theory emphasizes active, experiential learning in which learners build knowledge through direct engagement with tasks and reflective feedback, operationalized here as hands-on simulation-based procedural practice. Behavioral learning theory emphasizes repetition, reinforcement, and feedback in skill acquisition, operationalized through structured deliberate practice, repeated simulation sessions, immediate formative feedback from expert supervisors, and performance assessment using a standardized rubric. Together, this integrated framework supports progressive skill acquisition and consistent attainment of predefined competency standards, independent of fixed training time.
