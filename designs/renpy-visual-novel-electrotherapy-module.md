# Ren'Py-based interactive visual novel lesson package for the medium-frequency currents electrotherapy unit

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (1 for, 1 against) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A digital lesson package containing "a story in an interactive visual novel format created using Ren’Py", designed by the researchers to cover the theoretical and practical contents of the medium-frequency currents unit using CK4Stim project content. Design took approximately 45 days, and student participation was verified via embedded Google Forms surveys linked at the end of the lesson. In the trial it was delivered asynchronously by email over one week as the digital-only condition and as the digital component of the hybrid condition.

## Design Implications

### Context
#### Requirements
- Students needed access to a device compatible with Linux x86_64/Arm, Windows 7 or later, or Mac OS X 10.10 or later
- Completion was verified through embedded Google Forms linked at the end of the module
#### Constraints
- The authors report occasional software and hardware problems requiring researcher assistance, creating technical overhead
- The module alone was not sufficient to support practical performance

### Target Learners
- second-year undergraduate physiotherapy students

### Learning Goals
- theoretical knowledge of medium-frequency currents
- practical skills in applying electrotherapy modalities
