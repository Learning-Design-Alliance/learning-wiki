# MALL methodological framework combining mobile testing with enquiry-based learning and formative assessment

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A methodological framework for implementing the PeLe mobile testing system into the language classroom, developed and pilot tested in the MobiLL project. It combines enquiry-based methods ("collaborative and peer learning post-test activities, brainstorming, problem solving activities, group discussions") with mobile learning opportunities such as "immediate feedback, formative assessment, interactivity and flexibility". The framework was implemented through eight in-class PeLe grammar and vocabulary tests followed by teacher-led post-test activity grids.

## Design Implications

### Context
#### Requirements
- Handheld devices (smartphones or tablets) with Wi-Fi access in class for students to respond to PeLe tests
- Instructor-led post-test activities after each test to realize the enquiry-based component
#### Constraints
- The study's conclusions are based on subjective and objective data with a small sample (N=35)
- Data discussed cover only the first period of the MobiLL project and only the LMSU groups

### Target Learners
- University students of English as a foreign language at B1 level in a preparatory course

### Learning Goals
- English grammar and vocabulary skills
- Collaboration skills
- Learner motivation
