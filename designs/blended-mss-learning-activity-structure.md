# Learning activity structure for supporting blended math-science sensemaking (Table 2)

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
A general activity structure (Table 2) comprising pre-assessment, variable identification, qualitative and quantitative pattern identification using the simulation, mid-assessment, post-assessment with justification, constant calculation and meaning explanation, causal mechanism description, and application questions for transfer. Each task is aligned to a specific cognitive framework sub-level. The article states "This structure and the design principles discussed below are widely applicable for developing learning activities supporting blended MSS across STEM disciplines at the K-12 and undergraduate levels."

## Design Implications

### Context
#### Requirements
- Tasks aligned to specific sub-levels of the cognitive framework
- A simulation or data source supporting exploration of the target phenomenon
#### Constraints
- Implementation time varies: the chemistry activity had ~50 minutes while the physics activity had a 2-hour lab period

### Target Learners
- undergraduate STEM students
- K-12 students
