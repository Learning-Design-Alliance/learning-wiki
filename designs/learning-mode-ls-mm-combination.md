# Learning mode as a combination of learning style and multimedia preference

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article defines learning mode as "a combination of learning style and multimedia preference that is used in the adaptive e-learning system". It is measured by online questionnaires yielding an ls dimension (sequential versus global) and an mm dimension (multimedia versus non-multimedia), each scored from -11 to +11 with six preference-interpretation levels. Depending on questionnaire scores, the system presents material in one of four learning modes: Global-Multimedia, Global-nonMultimedia, Sequential-Multimedia, or Sequential-nonMultimedia.
