# Gradual-difficulty Jupyter Notebook curriculum combining in-person introductory sessions with asynchronous application notebooks

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The intervention's instructional pattern is a graded sequence of Jupyter Notebooks: four introductory JNs taught in two three-hour in-person lab sessions covering basics through scientific libraries, linear fits, χ², r² and histograms; five application JNs (e.g. sunspot moving averages, pendulum histograms, atmospheric CO2 data) and two data-import technique JNs for asynchronous independent work. The authors describe "a gradual increase in difficulty, from the basics of programming... to more advanced data-handling and analysis techniques", designed so no prior coding experience was required and building on existing graphical-analysis and uncertainty instruction.

## Design Implications

### Context
#### Requirements
- No prior coding experience required of students; activities build on existing course content on graphical analysis and measurement uncertainties
#### Constraints
- Due to privacy constraints in Germany, cloud platforms like Google Colab could not be fully exploited; the course worked within the Anaconda environment

### Target Learners
- first-year undergraduate physics majors in an introductory laboratory course

### Learning Goals
- Python data analysis and programming fundamentals
- graphical analysis and treatment of measurement uncertainties
