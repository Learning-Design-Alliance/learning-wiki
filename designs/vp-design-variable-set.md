# VP design-variable set spanning narrative structure, navigation, scoring, question types, feedback and data-gathering techniques

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The authors deliberately encoded a set of design variables into two 30-minute musculoskeletal VP cases, selected by consensus from a literature review and review of publicly available cases and restricted to features compatible with Medbiquitous interoperability standards. "These variables included: branching and linear case narratives; freedom of navigation through the case; visible scoring systems; different question types such as multiple-choice questions; key feature problems, and Bayesian reasoning." Learning strategies included worked examples, differential diagnosis listing, feedback mechanisms, and menu-driven history taking.

#### Requirements
