# Experiment Protocol.swf: a Flash-based multimedia program that administered the animation experiment and recorded participant responses

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The guide describes an interactive multimedia computer program, provided as the Adobe Flash file "Experiment Protocol.swf", that administered the experiment and "recorded all participant responses". The program "provides aural narration, which was a significant component of the protocol". Examiners can start the protocol at any point using drop-down list boxes for treatment condition and protocol location, controls that participants were not shown. Condition codes are entered on a code entry screen: "magenta" for the no animation condition, "purple" for directive animation only, "crimson" for representational animation only, or "violet" for both animations.

## Design Implications

### Context
#### Requirements
- Requires an appropriate version of Adobe Flash Player, which at the time of publication was available freely at http://get.adobe.com/flashplayer/.
#### Constraints
- The "no connection" message signifies the program cannot connect to the server needed to capture user input; the guide states that not connecting to the server will not impact how the program behaves from the participant's point of view.
- The drop-down list boxes for treatment condition and protocol location were not provided to participants; they exist so examiners can view different sections without starting from the beginning.

### Target Learners
- participants in the animation-and-understanding experiment administered by this program

### Learning Goals
- learning from a narrated multimedia protocol under four animation treatment conditions (none, directive only, representational only, both)
