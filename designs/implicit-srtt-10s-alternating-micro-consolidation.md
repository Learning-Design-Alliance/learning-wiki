# Implicit serial reaction time task with 10-s alternating practice-rest structure for measuring micro-consolidation

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 1 claim rests on one study

## Description
An implicit serial reaction time task (SRTT) in which "the task alternated every 10-s between task practice and rest for a total of 16 practice blocks, 320-s in total". Participants respond to visual cues with four fingers of the non-dominant left hand; undisclosed to them, cues follow a 12-item repeating sequence (2-3-1-4-3-2-4-1-3-4-2-1). Skill is conceptualised as number of correct responses per second, and micro-offline and micro-online changes are computed from block-start and block-end tapping speeds using a four-item sliding average.

## Design Implications

### Context
#### Requirements
- Correct response required to progress to the next cue; post-task questioning to detect explicit awareness of five or more sequence items
#### Constraints
- The 12-item sequence differs from the seminal explicit 5-item micro-consolidation work and from SRTT versions using fixed-versus-random comparison, limiting direct quantification of implicit learning magnitude

### Target Learners
- right-handed healthy young adults

### Learning Goals
- implicit motor sequence learning
