# Three-phase progression from easy to difficult projects for teaching Big Data to undergraduates

> **Design** · [All designs](index.md)
> **Evidence** · no claims cited

## Description
The article organizes Big Data instruction as a sequence of three project phases of increasing difficulty: network-data simplification with a simulator, Android app development, and big visual data editing and 3D reconstruction. The authors state they "assigned projects on networking and image processing for three phases from easy to difﬁcult", so that later phases build on experience from earlier ones.
