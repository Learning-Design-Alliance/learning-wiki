# Novel world knowledge-based audience design task with post-test knowledge attribution survey

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A modified director task measuring adaptation to addressees' world knowledge rather than visual perspective. In each trial a pictured addressee (a child or an elderly woman) appears while the speaker records a message about a target referent; "the participant knew the name of the target referent but was expected to assume that the addressee either (i) did not know the name of the target (unknown test condition) or (ii) did know the name of the target (known control condition)". A post-test survey controls for assumed knowledge, yielding a knowledge attribution score, and the AD score subtracts redundant describing in the known condition from sufficient describing in the unknown condition.

## Design Implications

### Context
#### Requirements
- Participants must know the names of target referents and hold condition-matching assumptions, verified by the post-test survey; stimuli require no more than one modifier for an unambiguous description
#### Constraints
- Conducted with passive confederates, which the authors note have been criticized since interactive contexts increase speakers' informativeness; individual language ability was not included as a model variable

### Target Learners
- adolescents aged 11–16

### Learning Goals
- pragmatic development
- audience design in referential production
- perspective taking in language production
