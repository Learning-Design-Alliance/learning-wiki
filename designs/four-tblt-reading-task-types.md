# Four task types for task-based reading instruction

> **Design** · [All designs](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The study designed four task types based on the students' book texts, identical for both groups in text but differing in activity. Task 1 was "Read and think" (deciding whether a visual aids comprehension), Task 2 "Read, note and discuss" (creating a visual to accompany a text), Task 3 "Read and discuss" (partner discussion of a visual's usefulness), and Task 4 "Read and write" (summarizing main points). Twenty tasks in four types were given across the sessions, one per session, and each performance was scored.

## Design Implications

### Context
#### Requirements
- Tasks are designed based on the texts in the students' book that will be taught during the term
- The same texts are used across comparison groups, with only the activities differing
#### Constraints
- Evaluated here only with intermediate-level Iranian EFL learners in institute settings

### Target Learners
- intermediate Iranian EFL learners

### Learning Goals
- L2 reading comprehension
