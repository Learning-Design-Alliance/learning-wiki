# Anatomage-table virtual case analysis as a simulation-based case-report assignment

> **Design** · [All designs](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The Anatomage Table is used in this study as a simulation platform on which students explore virtual 3D clinical cases "based on real anonymized radiologic data." A bank of cases was preloaded and thematically categorized (e.g., trauma, oncology, cardiology); each student selected a unique case, analysed clinical findings, formed differential diagnoses, and prepared an academic case report within 14 days after orientation on case analysis and report structure. It served as the intervention arm (Group D, n = 43) against paper-based case preparation, supporting both case understanding and written-report quality.

## Design Implications

### Context
#### Requirements
- Orientation sessions providing guidance on case analysis, diagnostic frameworks, and report structure
- Completion of basic science coursework before use
#### Constraints
- Students in this study had no prior Anatomage experience, so novelty effects cannot be ruled out
- The small simulation-component sample and single-institution context may limit generalizability

### Target Learners
- Undergraduate medical students (seventh semester)

### Learning Goals
- Clinical case analysis and differential diagnosis
- Academic case-report writing and science communication
