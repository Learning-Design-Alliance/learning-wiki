# Data-use cycle: collect and prepare data, interpret and hypothesize, modify instruction

> **Theory** · [All theories](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 review), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The guide frames using data to improve instruction as a cyclical process with three steps: "Collect and prepare a variety of data about student learning", "Interpret data and develop hypotheses about how to improve student learning", and "Modify instruction to test hypotheses and increase student learning". Teachers then restart the cycle with new performance data to evaluate their instructional changes. Because the process is cyclical, teachers can begin at any point, though the guide presents data collection as the first step.

## Design Implications

### Context
#### Requirements
- Teachers collect data from a variety of sources, including annual, interim, and classroom assessment data
- Hypotheses must be testable with future assessment data
#### Constraints
- No literature was located that assesses the impact on student achievement of using an inquiry cycle as a framework for data analysis

### Target Learners
- K-12 teachers

### Target Learning Objectives
- Using student achievement data to make instructional decisions that raise achievement
