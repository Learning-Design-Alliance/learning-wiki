Three Types of Use: Interacting with AI, Creating with AI, and Problem Solving with AI¶

Theory · All theories Evidence · no claims cited

Description¶

The framework distinguishes three Types of Use—distinct purposes for which users engage with AI-enabled tools. 'Interacting with AI' means 'Engaging with adaptive technology that adjusts to data collected'; 'Creating with AI' means 'Translating or synthesizing content'; and 'Problem Solving with AI' means 'Engaging in inquiry, including decomposing problems, and developing innovating solutions.' Each type carries distinct risks—such as personal data collection without consent for interacting, biased or subtly wrong synthetic content for creating, and biased training data for problem solving—and the report maps how each of the six AI Literacy Practices applies to each type.

Design Implications¶

Context¶

Requirements¶

  • Users must apply specific skills to remain critically aware of the information they are collecting, using, and sharing in each type of use

Constraints¶

  • The report notes there are unique risks associated depending on the use and context of the AI

Target Learners¶

  • K–12 learners
  • educators
  • educational leaders

Target Learning Objectives¶

  • understand risks inherent to each type of AI use
  • apply AI literacy practices to each type of use
