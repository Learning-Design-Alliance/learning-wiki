# Item response time as response-process metadata illuminating examinee response processes

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article treats item response time as one common type of test metadata generated by computer-based assessment. Such metadata relate to "examinees' response processes, which include solution strategies, concentration, and operating speed." Response times have been used extensively to improve achievement estimates, but the article extends this metadata concept to social-emotional constructs, using time-on-item after accounting for item difficulty and true achievement as an indicator of motivation and self-efficacy.
