# Value-added modeling as a framework for measuring educator effectiveness

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (3 for, 1 against) · 3 studies (3 associational), `q2`–`q3` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
Value-added modeling is a statistical framework for estimating the contribution that schools and teachers make to student achievement growth, operationalized here for use in a district educator evaluation system. The report frames its purpose as describing "the value-added models that are used as part of the BRIDGE teacher and principal evaluations," applying the framework at both school and teacher levels within one district's evaluation program.
