# Value added as a measure of teacher effectiveness

> **Theory** · [All theories](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (2 associational, 1 review), `q2` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
The brief defines value added as a way of quantifying teaching quality: "'Value added' is a teacher's contribution to students' learning gains." It frames emerging research on disadvantaged students' access to effective teaching as based on these value-added measures, while noting that researchers have presented such evidence in varied ways, making it hard for practitioners to interpret.

## Design Implications

### Context
#### Requirements
- Requires measures of students' learning gains from which a teacher's contribution can be estimated.
#### Constraints
- The brief states that because individual researchers have varied in their presentation of this evidence, it is challenging for practitioners to draw lessons from the data.

### Target Learners
- Students in grades 4-8 in the studied districts and states

### Target Learning Objectives
- Equitable access to effective teaching measured through student learning gains
