# Three-dimension framework for analyzing curriculum material design: mathematical emphasis, instructional approach, and support for teachers

## Description
The article organizes its comparative analysis of curriculum materials around three design dimensions: "mathematical emphasis, instructional approach, and support for teachers." The framework treats curriculum materials as designed artifacts whose features shape the potential opportunities to learn available to students, and it links those design features to student outcomes via findings from a large-scale experimental study of the curricula's achievement effects. It is used to explain why curricula targeting the same content can offer qualitatively different learning opportunities.
