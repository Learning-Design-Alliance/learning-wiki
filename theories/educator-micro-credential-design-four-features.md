# Educator micro-credentials as a competency-based, personalized, on-demand, shareable professional learning design

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (4 for) · 3 studies (1 review, 1 qualitative, 1 design), `q1`–`q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The report defines educator micro-credentials as an emerging learning design with four defining features: "They are competency-based, personalized, on-demand, and shareable." Educators select a discrete skill tied to practice, student needs, or school goals, learn the method, and submit evidence such as a classroom video, which experts assess; earned credentials and portfolios can then be displayed to signal competence. The report frames this as an on-ramp for meeting classroom-specific professional learning needs.

## Design Implications

### Context
#### Requirements
- An agile online platform that clearly identifies the competency associated with each micro-credential as well as the required evidence
#### Constraints
- Micro-credentials don't exist in a vacuum: they function within a larger context of needs, resources, and formal and informal learning opportunities

### Target Learners
- classroom teachers
- librarians
- instructional coaches
- principals

### Target Learning Objectives
- discrete instructional skills tied to student needs and school goals
