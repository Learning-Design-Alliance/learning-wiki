# Tools, Themes, and Competencies framework for organizing a CT/CS pathway

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The presentation distinguishes three layers of a CT pathway. Tools are "Curricula, technology, languages" (e.g., Scratch, Code.org, PLTW, ECS) which "Changes over time (especially as programs mature)". Themes are "Topics, integration approaches" such as "innovation, maker learning, STEAM, digital literacy" which "Remains consistent (may shift grade bands)". Competencies are "Student knowledge + abilities" such as "algorithms, data, simulations, etc." which "may reveal student outcomes that are uneven". The framework is used to fit together coding, computer science, and computational thinking, where CT is "a problem-solving process that is central to CS, and also applies to learning in any discipline".

## Design Implications

### Context
#### Requirements
- Districts must track how tools change over time while keeping themes consistent and monitoring competency outcomes
#### Constraints
- Implementation of tools may be uneven and competency outcomes may be uneven, per the presentation's own annotations

### Target Learners
- K-8 students

### Target Learning Objectives
- computational thinking competencies such as algorithms, data, and simulations
