Automaticity theory: automatizing component subskills frees controlled processing for higher-order functions such as comprehension¶

Theory · All theories Evidence · 2 claims (2 for) · 3 studies (1 causal, 1 review, 1 theoretical), q1–q3 · 0 of 3 report an effect size · 1 claim rests on one study

Description¶

The article draws on McLaughlin's (1987) cognitive theory and information processing models, in which learning a complex cognitive skill requires the automatization of component subskills. As the article states, "as automaticity develops, controlled search is bypassed and attentional limitations are overcome." In reading, the transition from controlled to automatic processing of lower-level components such as phonological decoding reduces discrimination time and frees attention for higher-order features like comprehension. The study applies this framework by treating pronunciation practice as a means of automatizing the phonological component.

Design Implications¶

Context¶

Requirements¶

  • Component subskills must be practiced and made routine through cumulative experience before controlled processing is freed for higher-order functions

Constraints¶

  • The framework is described as applying to skill learning in cognitive theory terms; the article tests it only for the phonological component in ESP reading instruction

Target Learners¶

  • ESP (English for Specific Purposes) undergraduate students

Target Learning Objectives¶

  • L2 reading comprehension
  • phonological processing efficiency
