# Ten-criteria taxonomy for evaluating SEL frameworks: five conceptual-clarity and five implementation-support criteria

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The Assessment Work Group's frameworks brief defines a two-part taxonomy for judging SEL frameworks. The conceptual-clarity set covers specificity, balance, developmental lens, cultural sensitivity, and empirical grounding; the implementation-support set covers intended for practice, resources for practitioners, resources for use with and by children and youth, resources for measurement and data use, and empirically tested. The brief states: "It defines 10 criteria for describing and selecting SEL frameworks for use in practice, from conceptual clarity to the availability of implementation supports." The criteria are meant to be applied to a whole framework, not to each competency, and no framework is expected to meet all of them fully.

## Design Implications

### Context
#### Requirements
- Criteria are applied to a whole SEL framework rather than to each specific competency
#### Constraints
- No framework will meet all criteria fully, and there is no one ideal set of scores related to the criteria

### Target Learners
- preschool to high school students

### Target Learning Objectives
- intra- and inter-personal social and emotional competencies
