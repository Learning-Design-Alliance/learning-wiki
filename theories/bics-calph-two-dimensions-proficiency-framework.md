# Cummins' BICS/CALP distinction: language proficiency divides into basic interpersonal communicative skills and cognitive/academic language proficiency, developmental along two continuums

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The packet presents Cummins' theoretical model of bilingualism, in which language proficiency has two dimensions: basic interpersonal communicative skills (BICS) and cognitive/academic language proficiency (CALP). It explains the common classroom phenomenon of students who seem fluent in English yet fail academic tasks, attributing this to lacking the language skills required for academic domains. The dimensions are described as developmental continuums rather than a dichotomy, and CALP is named as "the basis for a student's success in academic endeavors."

## Design Implications

### Context
#### Requirements
- Full development of both dimensions is considered essential for a person to be considered proficient in a given language
#### Constraints
- The packet notes the framework explains academic failure through lack of academic language skills, while allowing that low socio-economic status, motivation, or learning handicaps may also be reasons for poor performance

### Target Learners
- K-12 bilingual students
- second language learners

### Target Learning Objectives
- academic language proficiency
- distinguishing conversational from academic language use
