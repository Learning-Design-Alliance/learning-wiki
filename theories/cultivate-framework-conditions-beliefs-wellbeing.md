# Cultivate framework: classroom learning conditions shape students' learning beliefs, which shape learning and well-being

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (4 for) · 2 studies (1 associational, 1 design), `q2` · 0 of 2 report an effect size · 4 claims rest on one study

## Description
The Cultivate framework is an explanatory model in which students' experiences of nine classroom learning conditions (Meaningful Work, Learning Goals, Teacher Caring, Feedback for Growth, Supportive Teaching, Affirming Identities, Classroom Community, Student Voice, Well-Organized Classroom) predict learning beliefs (valued, can grow, class meaningful, empowered, capable), which in turn predict learning and well-being. The playbook states that "students' experiences of classroom learning conditions, measured by the Cultivate Survey predict… students' beliefs about themselves as learners, which then predict… students' learning & well-being." It is used by school teams to interpret survey data and target improvement.
