# Empirically based learning trajectories as the organizing framework of Building Blocks for Math

> **Theory** · [All theories](index.md)
> **Evidence** · 5 claims (3 for, 2 mixed) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 5 claims rest on one study

## Description
The curriculum is structured around "empirically based learning trajectories (i.e., what is appropriate for children at that age in terms of mathematics)", sequenced according to children's developmental progression. The software's management system presents tasks contingent on success along these research-based trajectories, and teacher training emphasized learning trajectories via a web-based application called Building Blocks Learning Trajectories. The framework connects children's informal math knowledge to more formal mathematical concepts.
