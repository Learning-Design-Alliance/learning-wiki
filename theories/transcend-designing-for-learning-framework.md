# Transcend's Designing for Learning framework as the organizing structure for the series

> **Theory** · [All theories](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The Designing for Learning framework is Transcend's learning sciences framework used to structure the four Edcamp sessions around the principles of individual variability, identity, motivation, and cognition. The report describes distributing "the Designing for Learning Primer and accompanying card deck" through the Edcamp Community, and quotes Transcend's principle explanations for each session (e.g., for motivation: "one of our central goals as designers should be to support motivation with each learner"). Each principle anchors one event's panel discussion and breakout topics.

## Design Implications

### Context
#### Requirements
- A primer and card deck translating the framework's principles for educator audiences
- Content expertise to prepare panelists and moderators in pre-Edcamp background building sessions
#### Constraints
- The report evaluates the framework only as delivered through this Edcamp series, not the framework itself

### Target Learners
- in-service K-12 educators, including teachers, librarians, and instructional coaches

### Target Learning Objectives
- understanding how learning happens and applying learning sciences principles to classroom design and instruction
