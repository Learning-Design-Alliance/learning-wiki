# Dashboard metric framework distinguishing single-point achievement metrics from between-test-event growth metrics

> **Theory** · [All theories](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The guide organizes the dashboard's measures into two families: "Achievement metrics capture students' performance at a single point in time, while growth metrics track their progress between two test events." Achievement metrics include RIT scores (100–350 scale) and achievement percentiles relative to the 2025 norms sample; growth metrics center on the conditional growth percentile, which compares growth to same-grade peers with the same starting fall achievement level. Supporting terms include on-track-for-proficiency projections and effect sizes on the Trends Over Time tab that show how far RIT scores have shifted from 2019 in a metric comparable across grades.

## Design Implications

### Context
#### Requirements
- Growth metrics require at least two test scores (fall-winter or fall-spring) to calculate, so they appear only after winter testing
- On-track-for-proficiency is available only on State Trends and State Groups pages and only in states with a current linking study
#### Constraints
- MAP Growth itself does not measure grade-level proficiency; the on-track metric only estimates likely performance on the state's summative assessment

### Target Learners
- K–8 students in US public schools

### Target Learning Objectives
- Interpreting achievement and growth data
- Comparing local results to national and state reference points
