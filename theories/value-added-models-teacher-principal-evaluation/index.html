Value-added models (VAM) as a framework for teacher and principal evaluation¶

Theory · All theories Evidence · 5 claims (5 for) · 3 studies (2 associational, 1 review), q1–q2 · 0 of 3 report an effect size · 5 claims rest on one study

Description¶

The report treats teacher and principal value-added models (VAM) as an organizing framework for educator evaluation, summarizing "research findings and implementation practices for teacher and principal value-added models (VAM)". VAM is presented as a measurement approach whose development requires decisions about data, modeling, and implementation. The report organizes the literature and practice examples around this framework for a state pilot project.

Design Implications¶

Context¶

Requirements¶

  • Empirical research findings and implementation practices must be summarized to inform VAM development, as the report does for the Team Pennsylvania Foundation pilot

Constraints¶

  • The report positions VAM work as a first step in a pilot project, not as a completed statewide evaluation system

Target Learners¶

  • K-12 teachers
  • School principals

Target Learning Objectives¶

  • Accurate measurement of educator effectiveness for evaluation and improvement

Claims¶

  • The report examined value-added implementation in seven school districts or states [+W]
  • The report synthesizes 21 empirical studies on value-added model key issues and findings [+W]
  • Phase 1 of the Pennsylvania pilot examined whether teachers with higher classroom observation scores on specific professional practices tended to have greater value-added impacts on student achievement [+W]
  • FFL evaluation scores are significantly and positively correlated with principals' contributions to student achievement (value-added) [+W]
  • There is little prior evidence on the validity of principal evaluation measures, and this is the first study linking practice ratings to credible value-added measures [+W]
