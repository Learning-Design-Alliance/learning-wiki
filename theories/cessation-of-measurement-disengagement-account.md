# Cessation-of-measurement account of test-taking disengagement identified via response time

## Description
The chapter advances an account in which disengaged test taking is understood as a momentary cessation of measurement that can be identified using response time. It holds that "the potency of an item response's information depends on the strength of a positive relationship between response correctness and achievement level," so rapid guesses that break this relationship degrade score validity. The chapter uses this account to frame both what happens when test takers disengage and how disengagement should be managed during scoring, drawing an analogy to classical test theory practice in which "authors routinely remove items that do not exhibit positive item-total correlations during item analyses."
