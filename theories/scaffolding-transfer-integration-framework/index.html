Scaffolding-Transfer Integration Framework for teacher observational skill development¶

Theory · All theories Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

A two-phase framework integrating Cognitive Load Theory and Situated Learning Theory for sequencing technologies in teacher observation training. Phase 1 (Focus Foundation) uses virtual simulation to simplify contexts and build basic observation schemas under low cognitive load; Phase 2 (Deepening Transfer) uses authentic video sequences "ranging from simple to complex and typical to atypical" to refine skills in a real problem space. The article operationalized it via pre-structured VS prompts and progressively complex unscripted AV.

Design Implications¶

Context¶

Requirements¶

  • Phase 1 requires VS design features aligned with CLT principles, such as clear narrative cues and observation prompts directing attention to focal children
  • Phase 2 requires learners to already possess preliminary observational abilities before authentic video exposure

Constraints¶

  • The framework's empirical support in this study is preliminary, from one intact class in a six-week course
  • Workshop 2 included a frontline teacher sharing session acknowledged as a potential confounding factor

Target Learners¶

  • preservice preschool (early childhood) teacher candidates

Target Learning Objectives¶

  • professional observation ability: purposeful perception, interpretation, and pedagogical response to classroom events
