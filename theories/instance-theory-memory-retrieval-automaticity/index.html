Instance Theory of automaticity: automatization as a shift from algorithmic processing to single-step memory retrieval¶

Theory · All theories Evidence · 2 claims (2 for) · 1 study (1 review), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Logan's Instance Theory explains automaticity as a memory phenomenon rather than a resource limitation: a novice performs a task with a general algorithm, and after repetitions retrieves specific past solutions, so performance is automatic when based on "single-step direct-access retrieval of past solutions from memory instead of an algorithm". It rests on three assumptions: obligatory encoding, obligatory retrieval and instance representation, with retrieval conceived as a race between memory traces. Each experience lays down a separate memory trace, so the task-relevant knowledge base grows with practice trials.

Design Implications¶

Context¶

Requirements¶

  • Attention to an object or event is sufficient to cause it to be encoded into memory (obligatory encoding)
  • A consistent environment, so that retrieved instances will be useful

Constraints¶

  • Automatic processing is not available to consciousness, because attention is the mechanism of consciousness

Target Learners¶

  • Adult foreign language learners

Target Learning Objectives¶

  • Automatization of L2 grammatical structures

Claims¶

  • Automatization of L2 skills requires extensive practice in a consistent environment, not repetition of grammar rules as in traditional exercises [+W]
  • Practice of grammar rules improves only the practiced skill, showing skill specificity of L2 automatization [+W]
