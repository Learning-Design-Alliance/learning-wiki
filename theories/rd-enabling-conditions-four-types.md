# Four types of R&D enabling conditions in school systems: mindsets, behaviors and routines, structures and tools, and systems supports

## Description
The report's framework identifies four condition types that school systems must shift to sustain R&D beyond isolated pilots. As printed: "Four Types of R&D Enabling Conditions: Mindsets: Openness to learning and iterating, and a shared value in designing and implementing new ideas and approaches." Behaviors and routines cover practices like regular reflection and early data collection; structures and tools include protected time, dedicated roles, and documented R&D processes; systems supports are policies such as shared vision and clear communication that embed R&D. An accompanying table defines each condition with illustrative examples (e.g., quarterly lessons-learned reflections, pre-scheduled pilot checkpoints, PDSA cycles, R&D coordinator roles).
