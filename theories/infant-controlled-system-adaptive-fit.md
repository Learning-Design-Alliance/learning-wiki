# Control systems view of the infant as a competent, adaptive system

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The report adopts a systems-theory viewpoint in which the infant is a "controlled system" in constant interaction with the environment, where mutual adaptation between child and environment establishes conditions for continuing growth. "Systems theory thus regards the infant as a competent organism equipped with purposive behavior patterns, efficient effectors,and feedback mechanisms which facilitate flexibility and goal-oriented behavior." The authors propose this framework as a unifying stance for viewing emotional development and use it to analyze the particular barriers handicapped children face in achieving an adaptive fit.

## Design Implications

### Context
#### Requirements
- An environment that makes accommodations for the individual, since adaptation involves exchange between individual and environment
#### Constraints
- The report notes handicapped children confront more barriers to adaptive fit, including negative evaluation and environmentally forced transitions such as labeling and segregation

### Target Learners
- infants and young children, including handicapped preschoolers

### Target Learning Objectives
- affective development and adaptation to the environment
