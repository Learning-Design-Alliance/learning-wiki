# Design-based estimators framework for analyzing grouped administrative data in RCTs

## Description
The article presents a framework of "design-based estimators, derived using the building blocks of experiments" for estimating average treatment effects in randomized controlled trials when analysts have access only to grouped administrative data. The framework is "conducive to grouped data for a wide range of RCT designs, including clustered and blocked designs, and models with weights and covariates." It aims to improve data access by allowing analysis at the group level rather than the individual level.
