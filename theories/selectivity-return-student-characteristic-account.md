# Human-capital sorting account in which measured selectivity returns reflect student characteristics rather than college effects

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The publication page frames college selectivity returns as an empirical quantity whose estimate changes with identification and data scope: the paper "uses administrative earnings data to the effect of attending a highly selective college on future earnings," and returns "fell substantially, often to near zero" with longer horizons and a newer cohort, while remaining large for disadvantaged subgroups. This pattern is consistent with the authors' framing that naive selectivity estimates partly reflect student characteristics, though the page itself prints no mechanism discussion.
