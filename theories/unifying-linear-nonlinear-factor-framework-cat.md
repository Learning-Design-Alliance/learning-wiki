# Unifying linear and nonlinear factor analysis framework for evaluating CAT construct validity at item and parcel levels

> **Theory** · [All theories](index.md)
> **Evidence** · 5 claims (5 for) · 3 studies (1 causal, 1 associational, 1 theoretical), `q2` · 0 of 3 report an effect size · 5 claims rest on one study

## Description
The study's theoretical framework treats IRT models as a special case of nonlinear factor analysis within latent variable modeling, so that linear and nonlinear factor analyses can be applied in a "unifying approach that combines both linear and non-liner factor analyses." This lets the impact of missing data on test factor structure be compared at both item and item parcel/testlet levels, with Rasch, 2PL, and bifactor IRT models equivalent to item factor analysis models with equal or unequal discrimination parameters.

## Design Implications

### Context
#### Requirements
- Dichotomously scored items and IRT-calibrated data, with calibration via WLSMV for categorical and ML for continuous observed data in Mplus
#### Constraints
- The study did not compare the nested models (Rasch, 2PL, bifactor) using chi-square difference, AIC, or BIC statistics

### Target Learners
- K-12 students assessed with large-scale standardized achievement tests

### Target Learning Objectives
- Valid interpretation of achievement test scores via internal-structure construct validity evidence
