# Pintrich's four-category model of self-regulated learning strategies

> **Theory** · [All theories](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 quant-synthesis), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The article organizes self-regulated learning strategies using the Pintrich model, in which "self -regulated learning model is explained in four categories: cognitive, metacognitive, resource management , and motivational strategies". Cognitive strategies cover rehearsal, elaboration, and organization; metacognitive strategies involve predicting, planning, monitoring, and evaluation; resource management strategies cover time, study environment, effort, peer cooperation, and help-seeking; motivational strategies cover intrinsic values, self-efficacy, and test anxiety. The meta-analysis uses these categories as coding categories and moderator groups.

## Design Implications

### Context
#### Requirements

- Some studies employ all strategy types together, so these were coded as combined self-regulated strategies
