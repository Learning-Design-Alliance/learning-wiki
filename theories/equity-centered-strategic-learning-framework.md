# Equity-centered strategic learning as an organizational capacity framework

> **Theory** · [All theories](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (2 design), `q1` · 0 of 2 report an effect size · 2 claims rest on one study

## Description
The partnership defines equity-centered strategic learning as the set of efforts that enables organizations to set goals contributing to increased educational equity for Black and Latino students and students experiencing poverty, establish hypotheses for reaching goals, build organizational culture, practices and systems to implement and test those hypotheses, and use information to improve their model on an ongoing basis. The framework holds that strong equity-centered strategic learning is demonstrated when equity is considered in both the organization's goal and its learning and decision-making approach.

## Design Implications

### Context
#### Requirements
- Organizational goals, hypotheses, culture, practices, systems, and ongoing information use aligned to equity aims
#### Constraints
- Equity must be considered in not only the organization's goal but also its learning and decision-making approach

### Target Learners
- K-12 education grantee organizations

### Target Learning Objectives
- Setting equity-focused goals
- Hypothesis testing
- Continuous organizational improvement
