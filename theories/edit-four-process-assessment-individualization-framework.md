# Four-process framework of teachers' ongoing assessment use for individualization

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The EDIT organizes teachers' assessment practice into four processes: "planning what information to collect and how to do so, collecting valid data, organizing and interpreting the data, and using the data collected to inform both overall and individualized instruction." This framework structures what the measure observes about data-informed individualization.

## Design Implications

### Context
#### Requirements
- Measurement must address all four processes to capture the full assessment-to-instruction cycle
#### Constraints
- Focuses on teacher processes rather than child outcomes

### Target Learners
- Early childhood teachers

### Target Learning Objectives
- Planning, collecting, organizing, interpreting, and applying child assessment data
