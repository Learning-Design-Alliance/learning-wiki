Value-added methods as a framework for estimating educator effectiveness, presented in technical and nontechnical terms¶

Theory · All theories Evidence · 7 claims (6 for, 1 mixed) · 6 studies (4 associational, 2 design), q1–q2 · 0 of 6 report an effect size · 7 claims rest on one study

Description¶

The report treats value-added methods as an organizing framework for measuring educator effectiveness, presenting "an overview of value-added methods in technical and nontechnical terms". The framework underlies the model used in Oklahoma's pilot evaluation system to estimate teacher and school effectiveness from instruction during the 2012-2013 school year. The page provides only a summary-level description of this framework.
