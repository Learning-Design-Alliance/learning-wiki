# Three-dimension classification of district-led innovations: technical infrastructure, implementation approach, and scalability

## Description
The report organizes its five featured District-Led Innovations along three dimensions: technical infrastructure requirements (foundational, enhanced, advanced), implementation approach (in-house, partnership, externally developed), and scalability (school-level, district-level, broadly replicable). It states "we've organized these examples across three key dimensions that emerged from our analysis," and notes the DLIs "exist along a spectrum of complexity and scale—from simple, spreadsheet-based tools used at individual schools to sophisticated district-wide platforms that integrate multiple data sources." This taxonomy lets readers locate their own context among the showcased approaches.

### Context
#### Requirements
