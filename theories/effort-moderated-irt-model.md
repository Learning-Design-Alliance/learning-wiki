# The effort-moderated IRT model of test-taking motivation

> **Theory** · [All theories](index.md)
> **Evidence** · 11 claims (11 for) · 4 studies (2 associational, 2 theoretical), `q1`–`q2` · 0 of 4 report an effect size · 11 claims rest on one study

## Description
The effort-moderated IRT model (S. L. Wise & DeMars, 2006) represents unmotivated test taking by specifying two item response functions: one for solution behavior, modeled with a monotonically increasing function such as the Rasch model, and one for rapid-guessing behavior, "modeled as a constant value at (or near) chance level regardless of the test taker's achievement level." Each response is classified by comparing response time to a per-item threshold, and rapid guesses are excluded from scoring. Unlike absorbing state, decreasing effort, or difficulty-based models, it "makes no assumptions about patterns of motivational behavior that are exhibited during a test event."

## Design Implications

### Context
#### Requirements
- Response times must be available so each item response can be classified as solution behavior or rapid guess using a time threshold, such as the normative threshold method setting thresholds at 10 percent of historical average response time with a 10-second maximum.
- Rapid guesses must be non-effortful and solution behaviors effortful, the model's two key assumptions, which the authors say can be readily evaluated using rapid-guessing analyses.
#### Constraints
- Scores based on very few solution behaviors have unacceptably large standard errors and diminished credibility; the authors note a policy on the minimum number of solution behaviors and content coverage would be needed for a score to be valid.
- The study's conclusions are from one low-stakes adaptive mathematics testing program; the authors caution that other tests and contexts may yield patterns more consistent with other models.

### Target Learners
- K-12 students taking low-stakes computerized adaptive achievement tests

### Target Learning Objectives
- Accurate measurement of achievement in the presence of unmotivated test taking
