# Four dimensions of connection underpin Powerful Learning

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (3 theoretical), `q1` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
The framework organizes connection into four essential dimensions: connection to ideas (bridging new concepts to learners' mental maps for real-world problems), to self (building skills, dispositions, and positive learning identities), to people (supporting relationships, cultures, and communities), and to place (grounding learning in local and global environments). Each dimension is anchored in named learning-science traditions, e.g., prior knowledge and conceptual change, identity development, collaborative learning, and place-based education.
