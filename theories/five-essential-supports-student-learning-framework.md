# Five Essential Supports framework for organizing school improvement measures

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 3 studies (2 associational, 1 design), `q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The Consortium's framework holds that five domains—school leadership, parent and community partnerships, a student-centered learning climate, professional capacity, and quality of the instructional program—are "frequently referred to as the Essential Supports for Student Learning in improving student achievement." The report uses these supports as the organizing structure for school survey profiles, with each support described by a set of related measures such as trust, program coherence, and professional development.

## Design Implications

### Context
#### Requirements
- All five supports should be considered together, since the article states it is the systemic blending of initiatives that makes a material difference in student learning
#### Constraints
- The framework derives from Consortium studies of Chicago public schools and is used here to organize profiles for one school

### Target Learners
- K-12 students in Chicago Public Schools
