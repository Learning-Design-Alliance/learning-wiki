# Five-pillar statewide blueprint: ACTIVATE, CONNECT, CREATE, ALIGN, ASSESS

> **Theory** · [All theories](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 theoretical), `q1` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The blueprint organizes pathway design into five pillars spanning state, region, school districts, postsecondary, and industry. Each pillar provides "Brief overview, Core factors, Top policies, conditions, systems, and practices that must be true, Key strategic questions." The pillars are ACTIVATE state and regional policy levers, CONNECT the regional infrastructure, CREATE K-12 pathways scale up models, ALIGN postsecondary and credentials landscape, and ASSESS state employment market and skills opportunity. The article says the blueprint "is designed as a starting point that can be used to define the foundation of a regional and/or statewide plan."
