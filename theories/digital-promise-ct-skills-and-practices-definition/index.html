Digital Promise defines computational thinking as a set of computational skills and computational practices that teachers can map onto subject-matter learning¶

Theory · All theories
Evidence · no claims cited

Description¶

The report defines computational thinking for practitioners as practices and skills rather than technical jargon. It states that "Computational skills are the cognitive processes necessary to engage with computational tools to solve problems" while "Computational practices combine many computational skills to solve an applied problem." Skills include problem decomposition, abstraction, debugging, algorithmic thinking, pattern recognition, and tool selection; practices yield artifacts such as programs, data visualizations, or computational models.
