# PETs as dual technical and social technologies for protecting data while preserving utility

## Description
The article defines Privacy Enhancing Technologies as tools that aim to increase the protection of individual data while retaining its utility. It frames them as both technical tools (e.g., math and software) and social technologies that reshape governance, trust, and data-sharing practices, noting that many can be thought of as purpose-limiting technologies that reshape data so it can only be used for specific ends. This framing underpins the brief's argument that PETs belong in data governance, not just engineering.
