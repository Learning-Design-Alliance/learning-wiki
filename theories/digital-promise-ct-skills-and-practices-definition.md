# Digital Promise defines computational thinking as a set of computational skills and computational practices that teachers can map onto subject-matter learning

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The report defines computational thinking for practitioners as practices and skills rather than technical jargon. It states that "Computational skills are the cognitive processes necessary to engage with computational tools to solve problems" while "Computational practices combine many computational skills to solve an applied problem." Skills include problem decomposition, abstraction, debugging, algorithmic thinking, pattern recognition, and tool selection; practices yield artifacts such as programs, data visualizations, or computational models. Figure 1 relates these aspects so teachers in any subject can find productive intersections with expected student learning.

#### Requirements
- Deliberately excludes technical terminology that can act as a barrier for practitioners without a computer science background, instead operationalizing concepts in everyday language

### Target Learners
- PreK-8 students across academic subjects

### Target Learning Objectives
