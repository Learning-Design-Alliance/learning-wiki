# Four design features of educator micro-credentials

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The report names four design features that define educator micro-credentials: competency-based, on-demand, personalized, and shareable. 'Four design features define educator micro-credentials,' the first being competency-based, which lets educators 'focus on a discrete skill related to their practice' and collect evidence such as classroom videos. On-demand earning happens on the educator's own time via an online platform; personalization lets educators build their own professional learning journey; and shareability lets earners display digital badges on Edmodo, LinkedIn, or a blog.
