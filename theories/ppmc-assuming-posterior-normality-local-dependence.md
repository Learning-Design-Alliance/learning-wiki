# PPMC assuming posterior normality (PPMC-N): a method for evaluating local dependence in IRT models

> **Theory** · [All theories](index.md)

## Description
The article introduces PPMC-N, a posterior predictive model checking method for assessing local dependence in unidimensional item response theory models. Unlike standard Bayesian PPMC, it applies to models "estimated using full-information maximum likelihood" and "provides a straightforward method to account for parameter uncertainty in model fit assessment." It extends PPMC, which is "increasingly being used to investigate multidimensionality in IRT models," to the maximum-likelihood estimation setting.
