# Instructional program coherence framework: common framework, supportive working conditions, and strategic resource allocation

> **Theory** · [All theories](index.md)
> **Evidence** · 6 claims (6 for) · 2 studies (2 associational), `q2` · 0 of 2 report an effect size · 6 claims rest on one study

## Description
The report defines instructional program coherence through three major conditions: a common instructional framework guiding curriculum, teaching, assessment, and learning climate; staff working conditions that support implementation of the framework; and strategic allocation of resources to advance the framework and avoid diffuse improvement efforts. The framework was operationalized through 13 rubric indicators and survey items. As the report states, "A common instructional framework guides curriculum, teaching, assessment, and learning climate." It distinguishes coherence from mere alignment with external policies.

## Design Implications

### Context
#### Requirements
- A common instructional framework combining specific expectations for student learning with specific strategies and materials to guide teaching and assessment
- Staff working conditions supporting implementation of the framework
- Strategic allocation of materials, time, and staff assignments to advance the framework
#### Constraints
- The definition does not stipulate alignment with external policies and standards, because external policies could promote, undermine, or have no effect on coherence

### Target Learners
- Elementary school students in urban public schools

### Target Learning Objectives
- Improving student achievement in reading and mathematics through schoolwide instructional organization
