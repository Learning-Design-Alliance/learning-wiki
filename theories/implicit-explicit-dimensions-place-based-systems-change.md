# Implicit and explicit dimensions of place-based systems change as complementary axes for funder assessment

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The organizing framework of the tool distinguishes implicit and explicit dimensions of place-based systems change that funders must consider together. The article states the tool helps funders "assess the extent to which their strategic intent, culture, and capacity can support complementary dimensions of systems change," treating strategy, culture, and capacity as facets of a funder's position that jointly determine whether investments can advance systems change. The framework is used as the reflective structure the tool applies to funder practice.
