# Three-stage skill trajectory: Basic, Intermediate, and Advanced technology use

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The Toolkit's Conceptual Frameworks describe a developmental trajectory of technology sophistication. For each type of work in the Matrix, the Frameworks "divide the four skill areas of Digital Skill, Media and Meaning, Point of View, and Audience ... into Basic, Intermediate, and Advanced skills and provide essential descriptions of each skill level." Teachers use these stages as roadmaps to locate a student's current level and identify the skills needed to become more sophisticated users.

## Design Implications

### Context
#### Requirements
- Frameworks must be used per skill area and per type of student work, since the trajectory differs across areas and work types
#### Constraints
- The document presents the levels as descriptions of how student work might look, not as empirically derived cut scores

### Target Learners
- K-12 students

### Target Learning Objectives
- Progression toward more sophisticated technology use within each skill area
