# The skills-first ecosystem framework

## Description
The report defines the skills-first ecosystem as "all of the systems, technologies, policies, organizations (e.g., employers, educational and research institutions, training providers, community based organizations), and that are interconnected in ways that collectively support the development, implementation, and scaling of skills-first practices." It maps nine key contributor categories with example roles, from community-based organizations providing trauma-informed supports to technology developers building skills identification and job-matching tools, with workers and jobseekers as a critical driving component. The framework organizes the report's challenge categories and recommended solutions.
