Composite transformation framework for MIRT equating: orthogonal procrustes rotation, translation, and single dilation¶

Theory · All theories Evidence · 4 claims (4 for) · 1 study (1 causal), q1 · 0 of 1 report an effect size · 4 claims rest on one study

Description¶

The article frames MIRT equating as transforming the equated group's reference system into the base group's system via a composite transformation: "an orthogonal procrustes rotation, a translation transformation and a single dilation". Because estimation programs impose abilities distributed as N(0, I), reference axes are orthogonal and of unit length, so rotation resolves rotational indeterminacy, translation coefficients shift the origin, and a dilation coefficient k rescales the unit. Three sets of equating methods were built on this framework and evaluated with BIAS and RMSE criteria.

Design Implications¶

Context¶

Requirements¶

  • Rotational indeterminacy must be resolved before estimating scaling coefficients; the framework assumes multidimensional abilities are distributed as N(0, I) by the estimation program.

Constraints¶

  • A single dilation parameter is preferred because it provides a more tractable mathematical problem and, in most cases, similar variance across dimensions; nonorthogonal rotation matrices would distort relative positions of item discrimination parameters.

Target Learners¶

  • test practitioners equating multidimensional test forms

Target Learning Objectives¶

  • accurate linking of item and ability parameters onto a common scale across test forms
