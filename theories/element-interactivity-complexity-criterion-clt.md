# Element interactivity as the CLT criterion of subject complexity

> **Theory** · [All theories](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
Within Cognitive Load Theory, element interactivity is defined as "the coordination of many information elements working simultaneously to complete a task" and is treated as the criterion of a subject's complexity. The higher the element interactivity, the heavier the working memory load. The article applies it to thermodynamics by having two expert lecturers classify the eight sessions' topics as low, high or very high element interactivity, judging interactivity relative to other topics within the unit rather than across chemistry.

## Design Implications

### Context
#### Requirements
- Students' prior knowledge must be determined first, since the number of items a learner must process depends on both the material's complexity and the learner's prior knowledge.
#### Constraints
- The classification compares subjects only within the thermodynamics unit, not against other chemistry subjects.

### Target Learners
- first-year university chemistry students

### Target Learning Objectives
- understanding thermodynamics concepts of varying complexity
