# Three powerful ways of using computers that integrate with academic subject matter: data work, automation, and modeling systems

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
The report organizes computational thinking integration around three uses of computers that align with goals for students: collecting, analyzing, and communicating data; automating procedures and processes; and using models to understand systems. Each practice is accompanied by teacher-facing "look fors" that operationalize it as observable student actions, such as "Using data to make predictions" for the data practice and "Considering efficiency" for automation. The framework is intended to help teachers identify where CT is or could be happening in classrooms regardless of subject area.

## Design Implications

### Context
#### Requirements
- Professional learning tools such as look fors to help teachers recognize productive CT use within learning activities

### Target Learners
