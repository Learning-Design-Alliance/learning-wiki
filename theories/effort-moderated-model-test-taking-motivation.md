# Effort-moderated model of unmotivated test-taking behavior

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (3 for, 1 mixed) · 3 studies (3 associational), `q2` · 0 of 3 report an effect size · 4 claims rest on one study

## Description
The effort-moderated model is one of several types of models proposed to represent unmotivated test-taking behavior, describing how response accuracy depends on test-taker effort as reflected in response times. In this study, observed rapid-guessing behavior on an adaptive achievement test was found to be "inconsistent with these models, with the exception of the effort‐moderated model", making it the only proposed account that matched the data. It also underpins effort-moderated scoring, which produced more accurate scores and improved person fit.

#### Requirements

#### Constraints

### Target Learners

### Target Learning Objectives
