# Cognitive apprenticeship applies the modelling, coaching, and fading paradigm of traditional apprenticeship to cognitive skills, with technology realizing resource-intensive learning environments

> **Theory** · [All theories](index.md)
> **Evidence** · no claims cited

## Description
Cognitive apprenticeship is Collins's framework for restoring the resource-intensive teaching of earlier apprenticeship-based eras using computers. The paper states that "cognitive apprenticeship employs the modelling, coaching, and fading paradigm of traditional apprenticeship, but with emphasis on cognitive rather than physical skills." The paper's basic thesis is that "technology enables us to realize apprenticeship learning environments that were either not possible or not cost effective before." It develops six characteristics—situated learning, modelling, coaching, reflection, articulation, and exploration—for which technology provides leverage, each defined, justified, and illustrated with an example system.

## Design Implications

### Context
#### Requirements
- Computational learning environments designed to embody the six characteristics of cognitive apprenticeship
#### Constraints
- The set of characteristics is described as tentative, developed from analyzing emerging tutoring systems and resource-rich learning environments

### Target Learners
- School students learning cognitive skills such as reading, writing, mathematics, and problem solving

### Target Learning Objectives
- Acquiring cognitive skills and knowledge in forms usable in real-life contexts
