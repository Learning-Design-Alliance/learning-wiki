The Fine-Tuning System (FTS): a scaffolding regulator that generates and fades learning support in serious games¶

Theory · All theories Evidence · 2 claims (2 for) · 3 studies (2 review, 1 causal), q1–q3 · 0 of 3 report an effect size · 1 claim rests on one study

Description¶

The Fine-Tuning System (FTS) is the paper's proposed mechanism for calibrating scaffolding in serious games to learners' changing needs. "The FTS works with a scaffolding regulator which facilitates the generation and fading of support", and the adjustment "can be made by the player -learner, teacher or an internal decision process". The system couples fading with game progress and knowledge gained, distinguishing expert from non-expert peers and triggering peer-tutoring collaboration. It is grounded in the ZPD and the fading concept, and is intended for classroom serious-game use with children.

Design Implications¶

Context¶

Requirements¶

  • A scaffolding regulator feature must be introduced into the serious game so instructional support can be calibrated
  • The game should be designed with sufficient learning support for all the ZPDs in the target group

Constraints¶

  • Fading can only go as far as the potential/target competence, since the target scaffolding level should be within the target learners' learning bandwidth
  • The system has not yet been empirically tested; the authors state future work will test it

Target Learners¶

  • Children aged 10-11 in classroom serious-game settings
  • Dependent learners in problem-based game-play

Target Learning Objectives¶

  • Problem-solving through scaffolded game-play
  • Completing tasks independently after scaffolds fade
