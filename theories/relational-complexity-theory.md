# Relational Complexity Theory

## Description
Halford, Wilson and Phillips (1998) propose that working-memory limits are best defined by the complexity of the relations that can be processed in parallel, not by the number of items held. Complexity is the number of related dimensions, or sources of variation: a unary relation has one argument, a binary relation two, a ternary three, and so on. Dimensions and chunks are both independent units of information of arbitrary size, which is how the measure links to chunk-count estimates of capacity. Studies of working-memory limits suggest a soft limit at about four dimensions processed in parallel, one quaternary relation.

Tasks more complex than that are handled in two ways. In **segmentation**, a task is broken into steps that each stay within capacity and are processed one after another. In **conceptual chunking**, a representation is recoded into fewer dimensions ("collapsed"), which lowers the load but makes some of the relations inside the chunk temporarily inaccessible. A task's effective complexity is therefore the smallest number of dimensions to which it can be reduced without losing information it needs. The authors relate relational complexity to processing load in reasoning and sentence comprehension, to differences between higher animal species, and to children's development: the complexity of the relations children can process grows with age. They add that it is not the only source of difficulty; domain expertise, problem-solving heuristics and memory availability also matter.

For design, the theory locates load in how many variables must be related at once, not in how many elements a task contains. A task with many elements but few that must be related simultaneously can be easier than one with few elements that must all be related together.

## Implications

### Context
- Reasoning, problem solving and sentence comprehension tasks, where the number of variables that must be related at once can be counted.

### Target Learners
- Adults, and children whose capacity for relational complexity increases with age.

### Target Learning Objectives
- Reasoning about relations; designing a sequence that segments a complex relation into steps, or teaches the chunks that let it be processed as fewer dimensions.
