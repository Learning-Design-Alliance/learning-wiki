# K‑12 AI infrastructure as shared public goods bridging general-purpose models and learning-specific applications

> **Theory** · [All theories](index.md)
> **Evidence** · 6 claims (6 for) · 7 studies (7 qualitative), `q2` · 0 of 7 report an effect size · 5 claims rest on one study

## Description
The report defines AI infrastructure for education as "foundational building blocks such as data, models, and algorithms needed to bridge the gap between general-purpose tools and learning-specific applications." It encompasses modular components (reusable design patterns, tool registries, Model Context Protocols) for agent harnesses, plus benchmarks measuring performance on education-relevant criteria. The K‑12 AI Infrastructure Program funds these as openly available public goods, identifying five priority areas: knowledge graphs and ambient assessment, child speech recognition and representative voice datasets, longitudinal student data infrastructure, shared evaluation benchmarks, and context engineering infrastructure.

## Design Implications

### Context
#### Requirements
- Digital assets must be openly available as public goods to shape the next generation of educational products and services
#### Constraints
- The report notes authentic educational datasets have limited availability due to privacy concerns, and only a small share of existing public datasets provide sufficient metadata, annotation, and licensing to be useful

### Target Learners
- K‑12 students, including multilingual learners, students with disabilities, and rural communities

### Target Learning Objectives
- Improving AI-based educational applications' performance on formative assessment, personalization, and accessibility use cases
