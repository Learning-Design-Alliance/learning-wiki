Membership model for classifying individuals into the common variance model¶

Theory · All theories Evidence · 2 claims (2 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A companion model to the Bayes factor test that moves from testing the average assumption to person-level classification. As the article states, "we introduce a membership model that allows for classifying which (and how many) individuals belong to the common variance model". It thereby identifies which individuals are adequately described by the average within-person variance in hierarchical models and which are not, complementing individually varying ICCs.
