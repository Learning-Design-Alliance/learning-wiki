Piaget's three memory types: recognition, reconstruction, and evocation¶

Theory · All theories Evidence · 2 claims (1 for, 1 mixed) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Zaichkowsky's paper presents Piaget's developmental distinction among memory types: 'Piaget uses hts rearth to demonstrate the developmental difference between threetypes of memory, which he callsrecognition, reconstruction and evocation.' Recognition relies on perception and sensorimotor schemes and appears in infancy; evocation requires mental imagery or language and emerges around 1.5-2 years; reconstruction is intermediate, resembling imitation. Piaget also divides memory into figurative and operational components.

Design Implications¶

Context¶

Requirements¶

  • Evocative memory depends on mental imagery or language, which develops only after the sensorimotor period

Constraints¶

  • The distinction is reported second-hand from Piaget's research and is tied to his developmental stage framework

Target Learners¶

  • children from infancy through the concrete operational period

Target Learning Objectives¶

  • memory for motor tasks and serial configurations

Claims¶

  • Piaget's memory experiments show children's memory for a model improves over retention intervals, attributed to change in the memory code [+W]
  • Memory performance can decrement over time when a model produces conflict between operational schemes [~W]

Related Theories¶

  • Piaget's stages as an ordinal hierarchy of schemes for coping with the environment
  • Piaget's stage theory of cognitive development: four fixed, hierarchical stages from sensori-motor to formal operations
