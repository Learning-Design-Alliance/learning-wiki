# Three-dimension sociotechnical-pedagogical usability framework for learning experience design

> **Theory** · [All theories](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article organizes its heuristic framework around three usability dimensions drawn from Jahnke et al. (2020): "Socio-Pedagogical Usability: How social interactions and pedagogical practices are supported by the learning design", "Socio-Technical Usability: How the technical features of the system or tool facilitate or hinder social interactions among users", and "Technical-Pedagogical Usability: How well the technical features support the pedagogical objectives of the learning environment". These dimensions structure both the draft and final heuristic sets and are used to ensure evaluation captures pedagogical and social concerns, not only technical usability.

## Design Implications

### Context
#### Requirements
- Heuristic evaluation of learning technologies must go beyond usability-only heuristics and address pedagogical values and learning objectives
#### Constraints
- The framework was developed to address contexts whose complexity is not captured by current heuristic frameworks, specifically simulation-based professional learning

### Target Learners
- professional learners in simulation-based training (e.g., maritime students)

### Target Learning Objectives
- professional competence development including collaboration, communication, and decision-making
