# A new approach for calculating sample sizes for school-based RCTs with binary outcomes

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article develops a method for computing appropriate sample sizes in school-based randomized controlled trials where the outcome is binary. It works by using logit models, with and without baseline covariates, to translate planned effect sizes into required sample sizes. As the abstract states, the article "develops a new approach for calculating appropriate sample sizes for school-based randomized controlled trials (RCTs) with binary outcomes using logit models with and without baseline covariates."
