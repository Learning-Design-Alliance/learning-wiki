## Description
The Character Strengths framework is a set of interpersonal, intrapersonal, and intellectual character strengths that benefit the self and others. The list of strengths was created by Character Lab, a non-profit with the mission of advancing the science and practice of character development. The framework focuses on character strengths that are tied to achievement and wellbeing.
