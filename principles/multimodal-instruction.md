# Multimodal Instruction

## Description
Instruction and training presented in multiple formats allow learners to activate different cognitive skills and Background Knowledge that are necessary to remember procedural and content information. Using text, visuals, gestures, audio, and digital formats facilitates retention of information into Short- and Long-term Memory and helps to accommodate learner preferences.
