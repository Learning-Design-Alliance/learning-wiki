# Flipped Learning

## Description
Flipped learning is the principle of shifting initial content exposure outside class so that live time can be used for application, coaching, and discussion.

## Implications

Flipped learning is most valuable when synchronous time is scarce and worth preserving for the kinds of work learners cannot do as well alone: coached practice, discussion, feedback, and collaborative sensemaking. The principle is not simply “watch videos at home.” Its value depends on redesigning in-person or live time around adaptive coaching and responsive support [[claims/contingent-scaffolding-improves-learning]] [~M] rather than moving a lecture file to another location. Flipped designs are also stronger when learners monitor and complete pre-class work reliably [[claims/self-monitoring-improves-self-regulation]] [~M] and when both pre-class prompts and in-class discussion ask them to explain ideas rather than merely consume content [[claims/self-explanation-improves-conceptual-understanding]] [+S]. The central risk is that preparation moves out of class while the pedagogy stays the same.

### Context
#### Requirements
- **Accessible pre-class materials** — learners need reliable, usable access to the initial exposure content
- **Clear connection between preparation and class activity** — what learners do before class must clearly matter to what happens during class
- **Active live-session design** — class time must be repurposed for problem solving, discussion, coaching, or feedback
#### Constraints
- **Preparation compliance is variable** — the model weakens when learners arrive unprepared and the class design assumes prior exposure
- **Access inequities can weaken the model** — devices, bandwidth, schedule constraints, and home conditions matter
- **Moving lecture out of class is not enough by itself** — the pedagogical gain comes from redesigning class time, not from relocation alone

### Target Learners
- Learners who benefit from replayable initial exposure and guided live practice
- Learners in courses where conceptual explanation can be handled asynchronously but application benefits from teacher presence
- Learners in blended or technology-supported environments where pre-class preparation is realistic

### Target Learning Objectives
- Use synchronous time for higher-value guided application
- Increase learner access to replayable initial explanations
- Improve feedback, discussion, and supported problem solving during live sessions

### Theory
#### Supporting
- [[principles/digital-learning|Digital Learning]] — digital delivery often makes replayable pre-class exposure feasible
- [[principles/guided-practice|Guided Practice]] — the main instructional benefit comes from shifting live time toward coached performance
- [[principles/active-learning|Active Learning]] — flipped learning is strongest when class time is redesigned around activity rather than passive review

#### Contradicting / Qualifying
- [[theories/self-regulated-learning|Self-Regulated Learning]] — flipped models depend heavily on learner preparation and time management before class

### Claims
- [[claims/self-monitoring-improves-self-regulation]] [~M] — flipped learning depends in part on learners tracking and completing pre-class work
- [[claims/contingent-scaffolding-improves-learning]] [~M] — the payoff increases when class time is used for adaptive coaching and responsive support
- [[claims/self-explanation-improves-conceptual-understanding]] [+S] — pre-class prompts and in-class explanation can make flipped designs stronger than content exposure alone

## Examples

### Illustrative

**[[patterns/flipped-learning|Flipped Learning]]** — Learners complete concise pre-class exposure, then spend class time in coached application, discussion, and feedback.

**Short video plus in-class problem solving** — Students watch a brief explanation or walkthrough before class and then use live time to solve problems in pairs while the instructor circulates and coaches.

**Pre-reading plus seminar discussion** — Learners encounter foundational ideas before class so that live time can focus on interpretation, debate, and clarification rather than first exposure.
