# Reduce teacher talk time and improve its quality to give students adequate discussion time

> **Principle** · [All principles](index.md)
> **Evidence** · no claims cited

## Description
The article reasons that students learn the target language as a communicative tool, so students' talk time is crucial; if teacher talk dominates, students have little time to discuss and some may never speak. It urges teachers to "plan carefully to decrease teacher talk time in a time-limited classroom and turn to student-centered approach", and, since talk time is decreased, to make teacher language accurate, logical, standard, succinct and rhythmical.

## Design Implications

### Context
#### Requirements
- Careful planning to decrease teacher talk time in a time-limited classroom
- Teacher talk that is accurate, logical, standard, succinct and rhythmical
- A student-centered approach
#### Constraints
- Classroom time is limited, so reduced talk time raises the demand for talk quality

### Target Learners
- English majors in English Reading classes

### Target Learning Objectives
- Expressing themselves deeply and fully in the target language
- Discussion and exchange of ideas
