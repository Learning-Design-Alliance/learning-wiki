# Assessment for Learning

## Description
Assessment for learning is the principle that assessment should be used during instruction to support learning, not only after instruction to certify it. The central question is not "What grade does this produce?" but "What does this evidence suggest we should do next?" It overlaps strongly with formative assessment, but highlights the instructional purpose of assessment evidence: clarifying goals, surfacing current understanding, and guiding revision.

## Implications
Assessment for learning works when evidence changes what happens next for the learner or the instructor. Midstream checks are most useful when they clarify the target, expose current misunderstandings, and create an immediate next move such as regrouping, reteaching, revising, or choosing a new strategy [[claims/contingent-scaffolding-improves-learning]] [+M]. This is also why low-stakes design matters: learners are more likely to reveal uncertainty when the checkpoint is framed as information for improvement rather than judgment, and that makes the evidence more instructionally useful for both self-monitoring [[claims/self-monitoring-improves-self-regulation]] [+M] and process-focused revision rather than mere answer chasing [[claims/process-goals-outperform-outcome-goals-for-novices]] [~M].

### Context
#### Requirements
- **Transparent goals and criteria**: Learners need to know what the evidence is about.
- **Evidence that informs a next step**: Assessment prompts should reveal something instructionally useful.
- **Revision pathways**: Learners need a chance to act on the result.
- **Instructional responsiveness**: Teachers or systems must be able to adapt based on what the evidence shows.
#### Constraints
- **Summative contamination**: Heavy grading pressure can make learners hide uncertainty instead of exposing it.
- **Weak task alignment**: Poorly designed prompts create misleading signals.
- **Performative checking**: Frequent assessment without instructional change turns the practice into compliance.

### Target Learners
- **Learners building foundational competence**: Benefit when misunderstandings are identified before they harden.
- **Learners who need more confidence to reveal uncertainty**: Low-stakes assessment can normalize partial understanding.
- **Instructors serving mixed-readiness groups**: Assessment evidence supports grouping, pacing, and differentiation.

### Target Learning Objectives
- **Clarifying the goal state**: Helping learners understand what quality looks like.
- **Guiding improvement**: Turning evidence into revision, re-teaching, or support.
- **Developing self-assessment**: Helping learners judge progress against criteria.

### Theory
#### Supporting
- Formative assessment theory emphasizes using evidence to adapt teaching and learning.
- Self-regulated learning supports using criteria and feedback for learner monitoring.
#### Contradicting / Qualifying
- Assessment does not automatically become "for learning" just because it happens midstream.
- High-stakes accountability systems can distort the learning function of assessment.

### Claims
- [[claims/contingent-scaffolding-improves-learning]] [+M] — assessment evidence matters when it leads to a responsive next instructional move
- [[claims/self-monitoring-improves-self-regulation]] [+M] — low-stakes checks help learners notice what they understand and what still needs work
- [[claims/process-goals-outperform-outcome-goals-for-novices]] [~M] — assessment for learning is stronger when it directs attention toward revision strategy and criteria, not only correctness

## Examples
- Using exit tickets to decide whether the next lesson should reteach, extend, or regroup.
- Giving draft feedback before a final submission so learners revise against criteria.
- Asking learners to self-rate confidence before checking answers and then discussing mismatches.
