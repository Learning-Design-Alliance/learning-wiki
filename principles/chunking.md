# Chunking

> **Principle** · [All principles](index.md)
> **Evidence** · 5 claims (3 for, 2 mixed) · 8 studies (4 causal, 2 quant-synthesis, 2 review), `q2`–`q4` · 2 of 8 report an effect size · 3 claims rest on one study

## Conditional relationship

For a learner who cannot yet treat the elements of a particular task as familiar units (a **novice on that task**, not necessarily in the wider domain), on material **high in element interactivity** or presented transiently (narrated animation, video, a long run of directions), presenting the material in **meaningful units with boundaries at conceptual breaks**, and then deliberately recombining those units, is expected to ease processing during study and may improve **immediate performance** or **near transfer**, compared with the same material presented as one continuous or ungrouped stream. What counts as one unit is not a property of the material: it depends on what the learner already holds as a chunk, so the same grouping can be necessary for one learner and redundant for another. Whether the gain survives to **delayed retention**, and whether it shows in performance or only in reported effort, has to be stated for each design. The wiki holds no claim that tests designer-grouped (as distinct from time-segmented) static material against ungrouped material; the instructional evidence below is mostly about segmenting transient media, plus one weak study of study-outline length.

This page owns the narrower question inside load management: **what size a unit is, where its boundaries fall, and how units are recombined**. [Cognitive Load Theory](cognitive-load-theory.md) states the general relationship that removing avoidable processing helps task-specific novices on high-element-interactivity material, and treats segmentation as one of several load-reducing techniques; its expertise qualification applies here and is not restated. No chunking pattern exists; strategies that apply this relationship include [Chunking Content](../strategies/chunking-content.md) and [chunked animations with pauses](../strategies/chunked-animations-with-pauses.md), and [Keep chunking study outlines short](chunking.md) is a narrower principle from one study.

## Observation, state and explanation

Record what the learner does **under stated conditions**: the unit size and boundary placement used, whether pacing was system- or learner-controlled, the representation, the support present, time and response mode. "Holds this as one chunk" is an inferred state; recalling a group intact, naming it, or using it as one step in a larger task are observations. Grouping the designer finds meaningful may be arbitrary to the learner, and an arbitrary grouping is expected to give no relief, because each element still has to be held separately (the claim page argues this; no study on it is recorded). Lower reported effort with smaller units is an observation, not evidence of learning.

| Response | Plausible explanations | Observation that could change the interpretation |
|---|---|---|
| Performs each unit correctly in isolation, but fails when the units must be used together | The relation joining units was never taught; a boundary cut through a causal or procedural link; coordinating the units still exceeds what the learner can hold | Give a recombination task that states the link between two adjacent units and one that does not; separately move one boundary to a different conceptual break and record which change restores performance. |
| Errors cluster just after a boundary | The boundary fragments a relation the next unit depends on; the previous unit's content has faded (transient media); the preceding unit was itself too long | Move the boundary, or add a one-line recap of the preceding unit at the start of the next, and compare where errors fall; check the preceding unit alone. |
| Moves through grouped material quickly, skips the pauses, and performs as well as with continuous material | The learner already holds larger units, so the grouping is redundant; disengagement; pauses felt as interruptions | Give an ungrouped changed problem or a larger unit; if independent success holds, lengthen units provisionally. If it fails, the grouping may still be doing work the speed hid. |
| Remembers only a few items of a list or sequence despite its being grouped | The groups are not meaningful to this learner; the learner lacks the knowledge that makes a group one unit; representation or language barrier | Ask the learner to name or explain each group; compare a grouping built on categories the learner already uses with the designer's grouping, recording recall for each. |
| Succeeds immediately after unit-by-unit study, fails a delayed whole-task test | Units learned separately but never integrated or retrieved together; forgetting unrelated to grouping; the delayed test samples a different task | Add a delayed test on the same items and a delayed recombination task; only a comparison against an ungrouped version attributes the delayed result to the grouping. |

These rows are proposals, untested with learners. The probes can shift confidence among explanations; a single contrast does not identify a cause, and every probe is itself a learning exposure that can change the learner's state.

## Evidence and qualifications

- [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [+W]: the explanatory basis, not an instructional test. Two narrative reviews and one set of experiments: Miller (1956) proposes that recoding input into fewer, larger chunks stretches the limit on immediate memory, and explicitly withholds judgment on what the recurring "seven" means, so the popular "7 ± 2" rule reads more into the paper than it says; Cowan (2001) puts the limit for novel material nearer three to five chunks; Thalmann et al. (2019) report that chunking helps by reducing the number of units maintained (sample size not stated). It concerns memory tasks, not designed lessons, and predicts nothing about which grouping a designer should choose. Not settled: the text available could not confirm its entries (abstract). The marker is weak here because it bears on this page's instructional relationship only through its mechanism.
- [Segmenting Improves Multimedia Learning](../claims/segmenting-improves-multimedia-learning.md) [+M]: a meta-analysis of 56 studies (88 pairwise comparisons) of segmented against continuous multimedia instruction reports small-to-medium effects on retention and transfer, lower overall cognitive load and longer learning time, with these effects holding specifically for **system-paced** segmentation (the claim's own summary says "learner-paced", which its entry does not bear out). No pooled value is recorded. A moderator analysis found learners with **high** prior knowledge benefited more on retention than those with low or no prior knowledge, which runs against the expertise qualification below. Read from the abstract; not yet checked against its sources.
- [Segmentation Benefits Shrink With Expertise](../claims/segmentation-benefits-shrink-with-expertise.md) [~M]: 75 secondary students, randomized to segmented (5–7 segments, 2-second pauses) or continuous animated worked examples on probability. Segmentation was more efficient (performance relative to mental effort) on near and far transfer at lower prior knowledge, and the difference disappeared, not reversed, at higher prior knowledge; there was no interaction on raw transfer performance alone. Horizon not reported on the claim page; no effect size printed. Not yet checked against its sources. It and the meta-analysis above disagree about prior knowledge, on different outcomes (efficiency against retention).
- [Letting learners pace instruction helped on complex material in one experiment, while learner control in general showed almost no effect across 18 studies](../claims/learner-paced-beats-system-paced-complex-material.md) [~M]: in one experiment with primary-school students on the causes of day and night, segmented and stop/play animations both outperformed a system-paced continuous animation, with lower cognitive load, but only on difficult, high-element-interactivity questions; the stop/play buttons were rarely used. A meta-analysis of 18 studies (29 effects) of learner control in educational technology generally found an overall effect near zero (g = 0.05). It limits the relationship to complex material and does not show that handing pacing to the learner substitutes for designed boundaries. Checked by the judge: both entries pass (abstract).
- [Short chunking study outlines produce higher test performance than long chunking study outlines](../claims/short-cso-improves-test-performance.md) [+W]: the only recorded comparison of unit size in a study aid. Two general-psychology classes used short or long outlines for three chapters each, order counterbalanced, quasi-experimental; short outlines scored higher on a 40-item multiple-choice immediate posttest (t(51) = 2.73, means 1.50 points apart). Conference paper, rigour r1, not yet checked against its sources. It does not show what made the long outline worse (length, added definitions, or study time).

Keep learners, material, unit size, pacing control, comparator, outcome and horizon with each result when transporting it. Efficiency, effort and performance are different outcomes; a non-significant difference is not equivalence; and none of these results says what unit size suits an individual learner.

## Objective and learner-valued goal

Ask what the learner wants to accomplish and why, separately from the designer's objective. Agreement, divergence and uncertainty are observations; do not infer motivation from compliance or from quick progress through short units. The designer chooses the representative task, the criterion, the permitted aids and the horizon; chunking is a means to that objective, and passing each unit's check is not the objective.

For example, a new support agent may value handling a whole customer call in the ticketing system without a checklist, while the designer's objective is passing a short quiz after each module on one screen of the workflow. Unit-by-unit quiz success says nothing about running the steps together under a live caller. Record both aims, plan where the units are recombined into the whole call, and check that whole performance at a stated delay.

## What would revise this model?

The expectation should weaken if learners who are novices on the task, given material grouped at conceptual breaks, repeatedly do no better than with continuous or ungrouped versions under defensible comparisons with aligned outcomes, or if grouped and arbitrarily grouped material do equally well (which would mean the benefit is pacing or pausing, not meaning). The prior-knowledge qualification should be revised if, as the segmenting meta-analysis reports for retention, more knowledgeable learners repeatedly benefit more. If smaller units lower reported effort without any gain in performance or transfer, the claim about learning is not supported for that design. Do not protect the model by calling every failure a badly chosen boundary after the fact.

Easier study, immediate performance on a unit, recombined whole-task performance and delayed retention are separate claims. The present evidence does not establish an ideal unit size or a fixed number of items per chunk, a rule for where to place boundaries, or when to lengthen units as a learner progresses.

## Description
Chunking is the instructional design strategy of breaking complex information or tasks into smaller, more manageable units (chunks) to align with the limited capacity of human working memory. By organizing discrete items into familiar, meaningful groups, chunking reduces intrinsic cognitive load and enhances learning retention.

## Implications
Chunking matters because learners cannot process unlimited novelty at once. When information is grouped into meaningful units, working memory can handle it more efficiently and learners are more likely to retain the underlying structure rather than just the surface details [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [+S]. The design challenge is that chunks are not universal: novices usually need smaller, more explicit units, while more experienced learners can handle larger integrated structures [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [~M]. Good chunking therefore reduces overload without hiding how the parts connect into a coherent whole.

### Context
#### Requirements
- **Logical Grouping**: Information must be organized into units that share a conceptual, functional, or structural relationship.
- **Hierarchical Structure**: Effective chunking often requires clear headings, bulleted lists, and a visual hierarchy to signal the boundaries of each chunk.
- **Fading Support**: For complex procedures, chunks should gradually be integrated into larger holistic units as learner expertise grows.

#### Constraints
- **Prior Knowledge Dependence**: What constitutes a "chunk" depends on the learner's existing schemas; an expert can process larger, more complex chunks than a novice [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [~M].
- **Over-segmentation**: Breaking information into too many tiny pieces can disrupt the learner's understanding of the global task structure or the relationships between parts.

### Target Learners
- **Novice Learners**: Benefit most from smaller, more frequent chunks to prevent cognitive overload [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [+S].
- **Learners with Low Working Memory Capacity**: Essential for managing the processing burden during acquisition of new concepts.
- **Learners with Attention Deficits**: Helps maintain focus by providing natural stopping points and "bite-sized" goals.

### Target Learning Objectives
- **Knowledge Retention**: Storing complex conceptual information in long-term memory.
- **Procedural Fluency**: Learning step-by-step processes by mastering individual stages before integration.
- **Reading Comprehension**: Improving the processing of dense or technical texts by segmenting them into thematic blocks.

### Theory
#### Supporting
- [Information Processing Theory](../theories/information-processing-theory.md) — identifies chunking as a key mechanism for transferring info from working memory to long-term memory.
- [Cognitive Load Theory (Sweller)](../theories/cognitive-load-theory.md) — chunking is the primary method for reducing intrinsic cognitive load [Chunking reduces working memory load by grouping information into fewer, more meaningful units.](../claims/chunking-reduces-working-memory-load.md) [+S].
- **Miller's Law (Miller 1956)** — establishes the average working memory limit of 7 (±2) units.

## Description
The chunking study outline (CSO) is a teacher-provided study aid consisting of chapter, section, and subsection headings plus key words that students process in quantities matching their cognitive processing capacity. The article's evidence shows longer outlines with added definitions and descriptions lower test performance, so outlines "should be limited to headings of. chapters, sections and subsections" and key words. This principle operationalizes the CSO as a "critical element" of the chunking method.

#### Requirements

#### Constraints
- Students observed disregarding the caveat by adding complete definitions and descriptions, which reduced performance
