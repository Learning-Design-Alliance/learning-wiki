# EJS vernier caliper computer model

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
An Easy Java Simulation model that lets secondary physics students practise reading vernier-caliper scales and compensating for zero error through configurable virtual measurements, hints, and answer checking.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **EJS vernier caliper computer model with hints, multiple vernier scales, zero error options, and answer-check input field**: A downloadable Easy Java Simulation model of a vernier caliper with a simple 2D view, consistent bottom control panel, zoom-in function, hints and answers check-boxes, selectable vernier scale versions (0.02 mm, 0.05 mm, 0.1 mm) and variable positive or negative zero error. The article states "The bottom control panel allows different measurements ( external, internal and depth), input field to check answers, different vernier scale versions and zero errors." It is offered under creative commons attribution for educators to customize the source code. (Wee et al. (2014))

### Claims
- [Singaporean secondary students using the real-and-virtual measurement lesson scored an average of 88% correct on seven formative measurement questions](../claims/students-88-percent-average-correct-measurement-questions.md) [+M]
