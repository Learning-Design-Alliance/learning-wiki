# Codeboard

## Description
Codeboard is an open-source, web-based integrated development environment that enables learners to write, compile, execute, and test code in browser-based courses, including MOOCs.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Codeboard web-based IDE integrated into MOOCs via IMS LTI**: Codeboard is an open-source, web-based development environment that lets learners "code directly in Codeboard without installing any additional software locally", supporting multiple languages (Java, C, C++, Python). Teachers provide base code and test cases; activities integrate into MOOC learning sequences through the IMS LTI standard and scale to thousands of concurrent learners. In this study a modified local instance collected compilation, execution, access and code data across 117 activities in three Java MOOCs on edX. (Gallego-Romero et al. (2020))

### Claims

- [Registered learners in programming MOOCs using Codeboard show greater engagement than anonymous learners, compiling and executing code more times per access](../claims/registered-learners-more-engaged-codeboard.md) [+M]
- [Registered learners modify the teacher-provided base code more than anonymous learners, both in share of sessions and in Levenshtein distance](../claims/registered-learners-more-code-changes.md) [+M]
- [Registered learners perform more actions and spend more time per Codeboard working session than anonymous learners](../claims/registered-learners-longer-sessions.md) [+W]
- [Registered learners have a higher ratio of compilation errors to total compilations, consistent with deeper code modification](../claims/registered-learners-higher-error-ratio.md) [+W]
- [When comparing only sessions in which the base code was actually modified, there are no significant differences between anonymous and registered learners in actions or time per session](../claims/no-difference-modifying-sessions.md) [~W]
