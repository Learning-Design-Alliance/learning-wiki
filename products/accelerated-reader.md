# Accelerated Reader

> **Product or Programme** · [All products and programmes](index.md)

## Description
Accelerated Reader™ is Renaissance's software-based K–12 reading practice and assessment system in which students read books, complete computerized quizzes, and receive progress data for teacher monitoring and goal setting.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Accelerated Reader™ guided reading practice and quiz system**: Accelerated Reader™ is "a guided reading intervention used to supplement regular reading instruction in K–12 classrooms." Students select and read a book, then take a computerized quiz on the book's content and vocabulary; the software reports quiz performance to teachers so they can monitor progress and identify students needing more reading assistance. Students earn points based on correct responses, book length, and readability level, which teachers use to set goals; point accumulation is intended to motivate learning, though the developer does not require extrinsic rewards. # Accelerated Reader™ guided reading practice and quiz system

## Description
Accelerated Reader™ is "a guided reading intervention used to supplement regular reading instruction in K–12 classrooms." Students select and read a book, then take a computerized quiz on the book's content and vocabulary; the software reports quiz performance to teachers so they can monitor progress and identify students needing more reading assistance. Students earn points based on correct responses, book length, and readability level, which teachers use to set goals; point accumulation is intended to motivate learning, though the developer does not require extrinsic rewards.

## Design Implications

### Context
#### Requirements
- A dedicated 30- to 60-minute reading practice block; an initial norm-referenced standardized reading measure to determine each student's independent reading level; access to the computerized quiz software and book quizzes
#### Constraints
- The program is designed to supplement, not replace, regular reading instruction; Renaissance Learning does not recommend or require the use of extrinsic rewards

### Target Learners
- K–12 students, including the grade 4–8 adolescent learners covered by this review

### Target Learning Goals
- Reading skills, reading comprehension, vocabulary development, and reading fluency through reading practice
