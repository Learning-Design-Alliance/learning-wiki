# Cerrado Succession Hypothesis (CSH) qualitative model library

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A GARP-based qualitative ecological model library developed by Anders Bouwer and collaborators to simulate Cerrado vegetation succession, population dynamics, and fire-management effects through composable model fragments and scenarios.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Cerrado Succession Hypothesis (CSH) qualitative model library for Brazilian Cerrado ecology**: The CSH model is a GARP model library for the Brazilian Cerrado ecosystem, whose goal is "to provide insight in the causal mechanisms involved in the development and management of the Cerrado ecosystem". "The library for the Cerrado domain contains 79 model fragments", covering description views (population concepts), assumptions (open/closed populations, immigration flows), process fragments (natality, mortality, emigration, immigration, colonization), agent fragments (fire management), and composition views for interactions and vegetational states. Scenarios range from single-population cases to the full three-population succession simulation. (Anders Bouwer (2010))
