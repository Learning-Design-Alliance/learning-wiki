# Generic Bayesian Student Model (GBSM)

> **Product or Programme** · [All products and programmes](index.md)

## Description
The GBSM is a generic Bayesian student-modelling framework used to construct domain-specific models for diagnosing learner knowledge in computerized assessment systems.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Generic Bayesian student model (GBSM) integrated into the PMatE computerized testing system**: The GBSM is an existing generic Bayesian student model that was integrated into an existing computerized testing system within the Mathematics Education Project (PmatE) of the University of Aveiro. In this work it "had been used" to define Bayesian Student Models (BSMs) "for a concrete domain: first degree equations", with separate BSMs built for the computer test and the written exam. Its diagnosis capabilities were then evaluated against expert grading. (Millán-Valldeperas et al. (2013))
