## Description
CureFun is a web-based virtual-patient platform that provides interactive clinical cases, learner action tracking, automated multidimensional feedback, and educator analytics for healthcare education.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CureFun virtual patient platform with 24 customized GP cases and six-domain automated feedback**: CureFun is an interactive web-based VP platform accessible via desktop and mobile devices, hosting "a library of over 1,500 clinical cases". For this program, experts built 24 customized cases for GP ambulatory care. Learners take histories from pre-formulated question menus, select examination maneuvers, order investigations, and formulate diagnoses and plans. An integrated assessment system provides "multi-dimensional scoring and immediate, automated feedback" across six domains including history-taking appropriateness, diagnostic accuracy, and cost-effectiveness awareness, plus an educator dashboard for comparing learners' actions. (Chen Yuanshuai et al. (2026))
