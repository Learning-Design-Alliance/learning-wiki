# Git, GitHub, and GitHub Classroom

> **Product or Programme** · [All products and programmes](index.md)

## Description
Git is a distributed version-control system, while GitHub and GitHub Classroom are software services from GitHub, Inc. for hosting repositories, reviewing changes, distributing coursework, and organising student collaboration.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Git with GitHub and GitHub Classroom as collaborative learning tools for methodological skills**: Git with the GitHub hosting service is presented as an educational tool for 'the development of methodological skills'. Its Pull Request mechanism lets users 'request, review, and discuss changes to be made in the content of a project', enabling a participatory culture; GitHub classroom adds repository distribution and working-group organisation through a web interface. (Gallardo-Alba Cristóbal et al. (2021))
