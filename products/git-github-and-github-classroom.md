# Git, GitHub, and GitHub Classroom

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Git is a distributed version-control system, while GitHub and GitHub Classroom are software services from GitHub, Inc. for hosting repositories, reviewing changes, distributing coursework, and organising student collaboration.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Git with GitHub and GitHub Classroom as collaborative learning tools for methodological skills**: Git with the GitHub hosting service is presented as an educational tool for 'the development of methodological skills'. Its Pull Request mechanism lets users 'request, review, and discuss changes to be made in the content of a project', enabling a participatory culture; GitHub classroom adds repository distribution and working-group organisation through a web interface. (Gallardo-Alba Cristóbal et al. (2021))
- **GitHub Classroom repository hosting course modules and student portfolios**: The author created a GitHub repository to host the course modules and set up a dedicated classroom for students. The article states: "Using GitHub Classroom, available through GitHub Education, I set up a dedicated class- room that allows students direct access to the material online at github.com/mbabiuc/computationalphysicsmu." It centralizes code examples, exercises, and documentation, serves as a repository for student portfolios, and lets students clone the repository, submit assignments, and collaborate while learning version control. (Maria C. Babiuc Hamilton (2024))
