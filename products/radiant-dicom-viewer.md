# RadiAnt DICOM Viewer

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
RadiAnt DICOM Viewer is a Windows application developed by Medixant for viewing and manipulating DICOM medical-imaging studies.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **RadiAnt DICOM Viewer teaching software with de-identified DICOM teaching file**: The teaching setup consists of raw CT and MR data copied from imaging machines or the PACS, stored in DICOM format with patient names and medical record numbers removed, transferred into a teaching file, and viewed with RadiAnt DICOM Viewer (version 4.0.3). Each student had a personal computer connected to a web server to download cases. The authors note the software 'is user friendly, which enabled students to read images freely on their own computers', supporting independent manipulation of window settings, sequences, and reconstructions. (Chen Yingqian et al. (2019))
