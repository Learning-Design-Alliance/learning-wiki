## Description
A TERC and WestEd professional-development and technical-assistance programme that supports teacher data teams and coaches in collaboratively analysing student data and developing instructional action plans.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TERC's Using Data (UD) professional development program**: The Using Data program, developed with NSF funding by researchers at TERC and WestEd, provides professional development and technical assistance aimed at helping teachers improve instruction through collaborative analysis of student data and action plans addressing systemic learning problems. As tested, it rolls out over a 2-year period. Data teams of four participating teachers and a data coach work through data analysis using collaborative inquiry, with data coaches typically school-based service providers such as instructional specialists. (Cavalluzzo et al. (2013))
