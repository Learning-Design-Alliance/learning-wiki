# Prompt Equity Transformer (PET)

> **Product or Programme** · [All products and programmes](index.md)

## Description
An LLM-based accessibility middleware agent developed by Lier Jin et al. that rewrites heterogeneous user inputs into semantically equivalent, standardized prompts for foundation models.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Prompt Equity Transformer (PET), an accessibility-oriented prompt normalization agent**: PET is an LLM-based agent that automatically transforms heterogeneous user inputs into semantically equivalent prompts with standardized reasoning guidance while preserving the user's original intent. It optimizes expected downstream task performance subject to a predefined semantic-preservation threshold, and does not introduce new information or modify the user's underlying request. Positioned as middleware, it functions as an intelligent accessibility layer between users and foundation models, shifting prompt-optimization responsibility from user to system without modifying the underlying foundation model. (Lier Jin et al. (2026))
