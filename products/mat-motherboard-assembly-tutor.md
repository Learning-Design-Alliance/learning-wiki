# MAT (Motherboard Assembly Tutor)

## Description
A constraint-based intelligent tutoring system combined with a spatially registered augmented-reality interface for teaching novice users to identify and assemble computer-motherboard components.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MAT: Motherboard Assembly Tutor combining a constraint-based ITS with a spatially-registered AR interface**: MAT is an intelligent AR system that trains users to identify and install components (memory, processor, graphics card, TV tuner card, heatsink) on a computer motherboard. A communication module relays information between the AR interface and the ITS over "XML remote procedure calls over a TCP/IP network connection"; the AR interface uses a head-mounted display, camera-based marker tracking, spatially-registered 3D models, animations, and a screen-aligned HUD with color-coded text and text-to-speech. The architecture is designed to be modular so it can be adapted to new assembly and maintenance tasks. (Giles Westerfield et al. (2015))
