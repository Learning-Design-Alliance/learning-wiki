# SmartPhysics: Rotation Lab

> **Product or Programme** · [All products and programmes](index.md)

## Description
A self-contained, AI-generated browser application developed by Josep Ll. Suñer et al. that uses mobile-device motion sensors to measure, visualize, and export rotational-kinematics data for introductory physics learning.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SmartPhysics: Rotation Lab — a single-file, no-installation, AI-generated browser application for measuring rotational motion**: SmartPhysics: Rotation Lab is a single self-contained HTML file requiring no installation, developed in one conversational session with Claude Sonnet 4.6 through natural-language prompting, with no code written or edited by hand. It reads the device's gyroscope and orientation sensors via the DeviceOrientation and DeviceMotion Web APIs, plots orientation angles and angular velocity components live, supports zoom and pan, and exports data as CSV and screen captures as PNG. Measurements reported used a Redmi Note 13 Pro 5G in Google Chrome at a 50 Hz sampling rate. (Josep Ll. Suñer et al. (2026))
