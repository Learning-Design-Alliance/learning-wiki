## Description
Microsoft PowerPoint is Microsoft's presentation-authoring software, used to create, annotate, revise, and share slide-based materials and storyboards.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PowerPoint storyboarding tool and procedures**: The tool used was Microsoft PowerPoint, chosen because it was already installed and easy to use. Copy and paste tools allowed new slides to be cloned with minor stepwise adjustments, and the "click to add notes" facility allowed slides to be annotated and date-stamped to build a time-line of evolving ideas. Files were shared with a colleague who added date-stamped comments as feedback. (Jones (2008))
