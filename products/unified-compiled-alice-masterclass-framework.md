# Unified compiled ALICE MasterClass framework

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A standalone cross-platform application that bundles ROOT and integrates the three ALICE MasterClass heavy-ion collision measurements for use by high-school learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Unified compiled ALICE MasterClass framework integrating three measurements**: Historically the three ALICE MasterClass measurements were developed independently from common ROOT EVE code and diverged "with no tracking of different versions". A unified framework, started as a 2018 summer student project, integrates all three into a single compiled binary standalone application for Windows, Linux and MacOS X, with ROOT bundled so it need not be installed separately. (Łukasz Graczykowski et al. (2020))
