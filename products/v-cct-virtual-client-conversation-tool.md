## Description
V-CCT is a website-based virtual-client conversation tool developed by Oster and colleagues for health-profession students to practise motivational-interviewing responses through simulated text dialogues.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **V-CCT: a virtual client conversation tool for practising motivational interviewing**: The V-CCT is a website-based conversation tool for teaching MI, built around a virtual client case study named Anna focused on diet and weight loss. It uses "a hybrid of classes two and three" of interactive virtual clients: the user types a question or response, then selects the closest match from a restricted set of options, and the client replies in text form. The dialogue is modelled in an SQL database that generates the client's response and four multiple-choice options each turn, and each conversation attempt is logged with date and time for retrospective analysis. (Oster Candice et al. (2020))
