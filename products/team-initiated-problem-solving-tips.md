# Team Initiated Problem Solving (TIPS)

## Description
A school-team problem-solving protocol developed for PBIS contexts that trains and coaches educators to define behavioral problems, select solutions, and monitor implementation and student outcomes.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Team Initiated Problem Solving (TIPS) protocol for school-team data-based decision making**: TIPS is a school-team problem-solving protocol in which teams define a problem with precision, build a goal, select a comprehensive solution, implement it, and monitor both implementation fidelity and impact on student behavior, adapting the solution based on evaluation data. It is delivered via a 6-hour team (with coach) training followed by two coached team meetings. In this study it was evaluated with 38 elementary school PBIS teams observed with the DORA tool across 152 meetings over 18 months. (Todd et al. (2019))
- **Team-Initiated Problem Solving (TIPS) model for data-based team decision making**: TIPS is a research-supported problem-solving model that guides school teams through an iterative data-based process. It "guides teams to use data to define precise problem statements" including where, when, who, and behavioral function, plus accompanying goals; teams then select contextually appropriate solutions, build action plans, and gather fidelity and outcome data to monitor implementation and impact, refining plans based on impact analysis. In this study it was taught via a 6-hour workshop plus two coached meetings. (Horner et al. (2018))
