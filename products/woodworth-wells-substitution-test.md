# Woodworth-Wells substitution test

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A speeded perceptual-substitution assessment in which examinees classify labeled forms or symbols into corresponding categories, developed by Woodworth and Wells and adapted here for children.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Geometrical form sorting practice test using gun wads with printed form labels**: A speeded sorting task in which children sort gun wads bearing printed outlines of five geometrical forms (star, circle, square, cross, triangle, from the Woodworth-Wells substitution test) into correspondingly labeled small boxes. Each trial involves sorting 250 wads within 4 minutes, using one hand, picking up one wad at a time. The box order is changed every second day to prevent the task from becoming too automatic. Scoring is the total number correctly sorted. (Woodrow (1915))
