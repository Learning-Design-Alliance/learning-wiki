# Sentinel AI-powered security game platform

> **Product or Programme** · [All products and programmes](index.md)

## Description
Sentinel is a mobile game platform developed by Bingjun Li et al. that uses AI-driven adversarial personas, subgames, analytics, and badges to train college students in phishing, password security, and social-engineering awareness.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Sentinel AI-powered security game platform with LLM-driven adversarial persona and badge system**: Sentinel is an AI-powered mobile game platform offering subgames on phishing detection, password cracking, text scams, and phone call scams. Its core interaction engine uses a Large Language Model (Google Gemini API) fine-tuned with system prompts defining the attacker's persona, with LLM output piped through a low-latency ElevenLabs text-to-speech engine for realistic voice modulation. The platform "provides player analytics and a badge-reward system to enhance motivation and sustained engagement," and adjusts scam sophistication based on the user's initial streak. (Bingjun Li et al. (2025))
