## Description
An open, searchable website run by the PLUMED community that distributes community-contributed online tutorials and supporting files for learning and using the PLUMED enhanced-sampling library.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PLUMED Tutorials website: a searchable collection of 47 community-contributed online tutorials**: PLUMED Tutorials (https://www.plumed-tutorials.org) is an open, community-driven collection of online tutorials for the PLUMED enhanced-sampling library. As of November 2024 it "includes 47 contributions" presented in a searchable table listing name, authors, and description. Topics span installing the software, PLUMED syntax, umbrella sampling, metadynamics, replica exchange, machine learning collective variables, and developer-oriented tutorials. The site is designed to let contributors create, share, and update tutorials collaboratively. (Tribello et al. (2024))
