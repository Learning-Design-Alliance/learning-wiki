# Teacher tablet package with Papaya and Tangerine:Class

> **Product or Programme** · [All products and programmes](index.md)

## Description
A PRIMR teacher-support package developed for Kenyan primary schools that combines multimedia lesson plans and pedagogical aids with Papaya letter-sound practice and Tangerine:Class continuous assessment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Teacher tablet package with Papaya and Tangerine:Class applications for PRIMR instruction**: In the teacher tablet treatment, teachers received a Google Nexus 7-inch tablet containing multimedia lesson plans, supplementary pedagogical aids, virtual letter flashcards, and the Papaya application with audio for practicing letter sounds. The tablet also included "the Tangerine:Class™ application, which contained a sophisticated continuous assessment program that allowed teachers to systematically investigate the quality of pupil learning and compare it with their instruction". Both programs were built with open-source software optimized for mobile devices. (Piper et al. (2015))
