## Description
A GitHub repository maintained by the Astro 17 course team containing Colab astronomy lab notebooks, associated data files, and an instructor guide for reuse in introductory astrophysics instruction.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **GitHub repository of GAI-assisted Colab notebooks and instructor guide**: A released repository (https://github.com/astrostubbs/harvard-astro17-labs) containing the course's Colab notebooks, associated data files, and a terse instructor's guide. It was produced at the end of term using the Claude Code command line GAI tool to clean up, test, and document the notebooks, an operation that took less than one hour. "The GitHub repository contains a dozen high-end Colab notebook/worksheets that were generated for this course", covering diffraction grating physics, observational extragalactic astronomy, and Hubble diagram fits using supernova luminosity distances. (Stubbs et al. (2025))
