# Learning Analytics-Moodle extension for EjsS virtual laboratories

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A Moodle plugin with a teacher-facing dashboard that records and visualizes students’ interactions and on-task activity in EJS simulations, developed by the authors for the Open Source Physics at Singapore server.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Moodle plugin and teacher dashboard for EJS simulation learning analytics**: The authors created a Moodle plugin that monitors and records, in real time, all standard student interactions with an EJS simulation embedded in a Moodle course. The information is displayed on an instructor dashboard with a metric of each individual student's degree of being "on task" and shows the students' current state on the simulation. The plugin is installed on the Open Source Physics at Singapore Moodle server and provides learning analytics capability for teachers running courses based on EJS simulations; it can be applied to existing simulations by regenerating them with EJS version 6.0 and installing the plugin. (Francisco Esquembre et al. (2019))
