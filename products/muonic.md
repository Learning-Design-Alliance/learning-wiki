## Description
Muonic is open-source Python software developed for the CosMO project that controls data acquisition and provides real-time visualisation and analysis of detector data.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Muonic open-source Python software for DAQ control and real-time data visualisation**: Muonic is the open-source software developed for the CosMO project to manage DAQ communications and visualise data. It was "developed entirely in Python, using PyQt4 for the graphical user interface", is modular and platform-independent, and needs no internet connection so it can operate in remote locations. Students use it to set thresholds and trigger conditions via GUI elements, view rate-per-channel plots over time, fit exponential decay histograms, and store raw or tab-separated data for offline analysis. (R. Franke et al. (2013))
