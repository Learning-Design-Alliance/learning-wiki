# PyNeuraLogic framework for lifted relational neural-symbolic learning

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
PyNeuraLogic is an open-source framework developed by Hooshyar et al. for building differentiable relational neural-symbolic models from logical facts and weighted rule templates, including learner-modelling applications.
