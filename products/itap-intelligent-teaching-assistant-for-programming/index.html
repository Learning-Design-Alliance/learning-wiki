ITAP (Intelligent Teaching Assistant for Programming)¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

ITAP is a data-driven intelligent tutoring system developed by Kelly Rivers and colleagues that generates personalized next-step hints for novice programmers solving code-writing problems.

Components¶

  • ITAP: data-driven hint generation via state abstraction, path construction, and state reification: ITAP (Intelligent Teaching Assistant for Programming) is a self-improving data-driven tutoring system that generates personalized next-step hints for code-writing problems. It combines algorithms for "state abstraction, path construction, and state reification to fully automate the process of hint generation", building a solution space graph from student states and constructing paths even for never-seen states. It requires only a reference solution and an automatic test method, and updates the solution space every time a student attempts a solution. (Kelly Rivers et al. (2015))

Claims¶

  • ITAP generated a full token-edit hint chain to a correct solution for 98.3% of semantically incorrect student states in submission order [+M]
  • ITAP's hint generation improves as solution data accumulates over time, supporting its self-improving design [+M]
