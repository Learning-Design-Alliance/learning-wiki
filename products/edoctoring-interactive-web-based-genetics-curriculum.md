# eDoctoring interactive web-based genetics curriculum

## Description
A six-hour interactive web-based genetics curriculum for primary care physicians, developed by consultants from six institutions and delivered through clinical cases, tutorials, multimedia, and interactive questions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **eDoctoring interactive web-based genetics curriculum for primary care physicians**: eDoctoring is a 6-hour interactive web-based genetics curriculum developed using Kern's curricular development model by 20 consultants from six institutions. It features "four clinical patient cases (breast cancer, cystic fibrosis, Huntington's disease, and venous thromboembolism)" plus four required tutorials covering core genetics concepts, screening and testing, ethics and legal issues, and shared decision making. Cases contain video-vignettes, animated physician avatars, and closed and open-ended questions; it was programmed in Flash and Python linked to MySQL and alpha-tested with primary care residents. (Wilkes Michael S. et al. (2017))
