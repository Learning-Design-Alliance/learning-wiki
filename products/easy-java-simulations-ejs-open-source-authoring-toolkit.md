# Easy Java Simulations (Ejs) open-source authoring toolkit

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Easy Java Simulations is an open-source Java-based authoring tool and library created by Francisco Esquembre for educators to create and customize interactive science and physics simulations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Easy Java Simulations (Ejs) open-source authoring tool and its simulation library**: Easy Java Simulations is "an authoring tool developed for the conceptual learning of science", created by Francisco Esquembre and distributed under a GNU GPL license, which allows Ejs and its JAR library files to be copied and distributed freely. Educators download Ejs with a Java Runtime Environment, launch EjsConsole.jar, and open community-shared XML source files such as those in the ComPADRE Digital Library and the NTNUJAVA Virtual Physics Laboratory. Starter materials include the Modeling Science Textbook chapters and Modeling Physics with Easy Java Simulations documents. (Loo Kang Wee et al. (2009))
- **Easy Java Simulation (EJS) authoring toolkit for teacher-built physics computer models**: Easy Java Simulation is an authoring toolkit that lets ordinary teachers build and customize interactive Java physics models. The article calls it an "innovative and versatile" tool that generates models running on mobile devices, offers a free model library, supports Moodle collaborative exploration, remote labs, and sensor interfaces, and connects teachers to the Open Source Physics community. (Loo Kang WEE et al. (2013))
