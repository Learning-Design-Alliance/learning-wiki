# Learning Object Repository for 9th-grade mathematics

> **Product or Programme** · [All products and programmes](index.md)

## Description
A web-based repository of interactive mathematics learning objects developed by Çakiroğlu et al. and hosted at ogrenmenesneleri.org for Turkish 9th-grade students and teachers.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Learning Object Repository for 9th-grade mathematics built on IEEE LOM standards**: The study designed a Learning Object Repository (LOR) aligned with the Turkish 9th-grade mathematics curriculum, covering sets, numbers, relations and functions domains. LOs were produced with the ADDIE model using java and action script codes, prioritizing student-computer interaction with "exercises, trial and special tutoring activities, animations". The repository "has been published on the website "www.ogrenmenesneleri.org"" and students used 38 objects over 11 weeks. (Çakiroğlu et al. (2012))
