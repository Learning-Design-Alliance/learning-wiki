# CognitiveFun.net

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
CognitiveFun.net is a web-based cognitive assessment and training platform operated through cognitivefun.net, providing interactive cognitive tasks with instructions, practice trials, feedback, and progress tracking.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CognitiveFun.net web-based cognitive assessment platform**: Cognitive Fun is a web application the study used to administer its cognitive tasks. The article describes it as "an advanced web-based application designed to assess and enhance various cognitive functions", hosted at cognitivefun.net since 2008, featuring "a simple interface with clear instructions" and interactive game tasks that provide feedback and track progress. In this study it delivered the Go/No-Go task for inhibitory control and the 2-back task for working memory, with practice trials before scored test blocks. (Kassaw Chalachew (2025))
