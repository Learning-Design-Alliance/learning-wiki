- **Tracker video analysis and modeling tool**: Tracker is a free, downloadable "video analysis and modeling tool built on the Open Source Physics (OSP) Java framework". Students use it to track a projectile's trajectory manually or automatically, fit linear and parabolic curves to position-time data, and build dynamic particle models juxtaposed against the real video. The article uses it in GCE Advanced Level and Ordinary Level projectile motion lessons and for teacher professional development with e-learning. (Loo Kang WEE et al. (2015))
- **Tracker video analysis and modeling tool**: Tracker is a free, open-source video analysis and modeling tool built on the Open Source Physics Java framework, continually improved by Douglas Brown and his OSP community. The article states it is a "video analysis and modeling tool built on the Open Source Physics (OSP) Java framework", installable on Windows, Mac OS X and Linux, with version 4.80+ files packaged as a single compressed *.trz file usable with a mouse click. It is used in the Singapore performance task for video analysis, parabola fitting and video modeling. (Loo Kang WEE (2014))
- **Tracker, a free open source video analysis and modelling tool for physics education**: Tracker is described as "a free open source video analysis and modelling tool" used by Grade 9 students to analyse videos of moving objects, generate s vs t, v vs t and a vs t graphs, fit lines (e.g. vx = -0.2456*t+0.7022), and build dynamics models with force statements such as fx = if (t<0.2,3.2*m,-0.246*m). Students each conduct a personal video analysis, and Tracker files (*.TRZ) are shared via Dropbox links and a shared library. (Loo Kang Wee (2014))
- **Tracker video analysis and modeling tool**: Tracker is "a video analysis and modeling tool built on the Open Source Physics (OSP) Java framework", available as installers for Windows, Mac OS X and Linux. In this study students loaded a tossup.mov video, tracked the ball's motion, and examined plotted graphs to connect real-life video with scientific kinematics representations. Students reported that Tracker helped them "see the connections between the real life [video] and the [scientific] graph[s]". (Loo Kang WEE et al. (2015))

## Description
Tracker is a "free video analysis and modeling tool built on the Open Source Physics (OSP) Java framework", downloadable from the OSP website or runnable via Webstart. It fits equations (e.g. parabola fits) to video data, displays world views comparing real data with dynamic particle models, and lets students build dynamic models by keying values such as vx and forces. The authors use it for falling-ball and projectile-motion activities and release all workshop materials on a blog for mass adoption.
