# ASU CreateAI Chat platform: secure closed-system GPT-4o environment with retrieval-augmented generation for qualitative analysis

> **Element** · [All elements](index.md)
> **Evidence** · no claims cited

## Description
The study conducted all LLM analyses on Arizona State University's CreateAI Chat, described as "a secure, closed-system environment that complies with institutional data protections and supports retrieval -augmented generation (RAG)". Its RAG architecture retrieved relevant segments from preapproved sources — the segmented focus group transcripts and Braun and Clarke's (2006) thematic analysis article — constraining output to contextually grounded information and reducing, though not eliminating, hallucination risk. The platform used GPT-4o with a fixed temperature of 0.5 and no system-level prompt capability.

## Design Implications

### Context
#### Requirements
- Preapproved retrieval sources uploaded to the platform, including segmented transcripts and a thematic analysis methods article
#### Constraints
- No system-level prompt could be created and the temperature setting was fixed at 0.5, so all role instructions were delivered through the initial user prompt

### Target Learners
- Researchers and educators conducting qualitative analysis of educational design data

### Target Learning Goals
- Inductive coding and theme generation from focus group transcripts supporting educational technology design
