# AutoTutor Script Authoring Tool (ASAT) and generic AutoTutor Conversation Engine (ACE)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
The AutoTutor project’s ASAT authoring tool and ACE conversation engine let organizations create and deploy scripted conversational tutoring applications across domains.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AutoTutor Script Authoring Tool (ASAT) and generic AutoTutor Conversation Engine (ACE) licensed for new content and applications**: The AutoTutor Script Authoring Tool (ASAT, Cai et al. 2015) lets researchers at other universities, businesses, and organizations develop their own content and integrate it with the generic AutoTutor Conversation Engine (ACE). The article reports that Wolfe et al. (2015) used the authoring tools to build a website on genetic risk factors for breast cancer (BRCA) and reported learning gains above the existing website on the same topic. Educational Testing Service is licensing ASAT for assessment in virtual worlds, and the Army Research Laboratory has incorporated AutoTutor in its open source Generalized Intelligent Framework for Tutoring (GIFT). (Graesser (2016))
