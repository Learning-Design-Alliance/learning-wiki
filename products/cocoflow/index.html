CocoFlow¶

Product or Programme · All products and programmes

Description¶

CocoFlow is an AI agent builder platform developed by COCOROBO Limited that enables teachers to create subject-specific pedagogical agents through prompt engineering, uploaded knowledge bases, and visual workflow design.

Components¶

  • CocoFlow AI agent builder platform used by teachers to construct pedagogical agents: CocoFlow is an AI agent builder platform developed by the EdTech company COCOROBO Limited, used as the core tool in both workshop cycles. Its "editing interface supports teachers in constructing pedagogical agents through prompt engineering, knowledge base creation via file upload, and workflow design via a visual drag-and-drop canvas." Teachers were expected to independently create at least one deployable AI agent aligned with their instructional subject and learning objectives. Platform behavioral logs over eight weeks provided the engagement data for Cycle 1's clustering analysis. (Haiyang Xin et al. (2026))
  • CocoFlow no-code AI agent creation platform: CocoFlow is a web-based platform enabling students to create conversational AI agents without programming. "Students drag pre-built components from a module library to a visual canvas, constructing dialogue workflows that define how agents respond to user inputs." Key components include intent recognition modules, entity extraction modules, and conditional logic nodes, with a real-time chat simulator for immediate testing and debugging. A pre-trained NLU engine handles intent recognition and entity extraction so students focus on system-level design. (Yimeng Sun et al. (2026))

Claims¶

  • 87% of K-12 teachers ceased meaningful AI agent creation within three weeks of completing a two-day professional development workshop [~M]
  • Five-day no-code AI agent creation improves students' CT self-perception, with large gains in abstract and algorithmic thinking and a medium gain in pattern recognition and generalization [+M]
  • Iterative testing engagement during AI agent creation predicts CT self-efficacy gains after controlling for initial self-efficacy [+M]
