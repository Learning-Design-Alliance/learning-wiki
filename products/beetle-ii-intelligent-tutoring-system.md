## Description
BEETLE II is an intelligent tutoring system developed by Dzikovska et al. that combines a simulated electricity-and-electronics workbench with natural-language dialogue, diagnosis, and dynamically generated tutoring feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **BEETLE II intelligent tutoring system with deep NLP and dynamic feedback generation**: BEETLE II is an intelligent tutoring system for basic electricity and electronics combining a simulated circuit workbench (integrated with the open-source GNUCAP simulator) with a tutorial dialogue capability. Its dialogue component "supports context-specific interpretation and diagnosis of natural language student explanations, and implements a set of generic tutoring tactics that can be instantiated in different problem-solving contexts". The pipeline runs deep parsing (TRIPS), contextual interpretation, domain reasoning and diagnosis, tutorial planning, and natural language generation, allowing feedback to be produced on the fly without authoring messages for every anticipated answer. (Dzikovska et al. (2014))
- **BEETLE II: a tutorial dialogue system for electricity and electronics with simulation and adaptive feedback**: BEETLE II, described in the third special-issue paper by Dzikovska et al., is a tutorial dialogue system for learning about electricity and electronics. It "tries to stimulate student meta-cognitive learning activities, such as self-evaluation and self-reflection, thus helping students achieve a deeper understanding of the basic underlying concepts and principles." Students experiment with a circuit simulator, examine incorrect hypotheses, and then engage in tutorial dialogue explaining the incorrect simulator behavior, with adaptive feedback generated using symbolic Natural Language Processing techniques. (Bruce M. McLaren et al. (2014))
