# Montoya-Castillo-Group/FourierTransforms GitHub repository of FT lab notebooks

## Description
A GitHub repository of freely available Google Colab/Jupyter lab notebooks for undergraduate chemistry students to learn Fourier-transform analysis of temporal datasets, released by the Montoya-Castillo Group.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Freely available GitHub repository of FT lab notebooks (Montoya-Castillo-Group/FourierTransforms)**: The article's Associated Content section releases the complete set of lab materials as open educational resources. The authors state: "Our materials are freely available at the following GitHub repository: https://github.com/Montoya-Castillo-Group/FourierTransforms." Students run each .ipynb file by manually uploading it to Google Colab, so no local installation is needed. The released set includes the prelab and activity notebooks referenced throughout the article (Prelab.ipynb, Activity 1-3, and Streamlined.ipynb in the Supporting Information). (Anthony J. Dominic III et al. (2024))
