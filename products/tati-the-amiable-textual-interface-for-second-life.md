# TATI (The Amiable Textual Interface for Second Life)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
TATI is a textual authoring interface developed by dos Santos that lets teachers and learners generate physics microworlds in Second Life through the accessible TATILogo language instead of directly programming in Linden Scripting Language.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TATI, a textual interface for generating physics microworlds in Second Life**: TATI (The Amiable Textual Interface for Second Life) translates simple Logo-like commands into Linden Scripting Language commands that generate objects following alternative physical laws, similar to Papert's turtles or diSessa's Dynaturtles. The article states its objective is to describe "TATI, a textual interface which, through TATILogo, an accessible Logo language extension, allows the generation of various physics microworlds in Second Life". It was built to spare teachers from learning LSL directly. (dos Santos (2012))
