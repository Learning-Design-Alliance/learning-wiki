# GenAICanHarmLearning anonymized dataset and code repository

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A GitHub release by Bastani Hamsa et al. containing anonymized practice- and exam-performance data, student–GPT-tutor conversations, covariates, and R, Python, and Stata analysis code from a high-school mathematics generative-AI learning RCT.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Anonymized dataset and code repository for the generative AI learning RCT**: The authors released anonymized data and analysis code at https://github.com/obastani/GenAICanHarmLearning. Data include "student performance on practice and exam questions for all sessions, as well as student-, class-, and grader-level covariates", plus anonymized, time-stamped student conversations with the GPT tutors. Code was written in R, Python, and Stata. (Bastani Hamsa et al. (2025))
