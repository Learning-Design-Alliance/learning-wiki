# Easy Java Simulation (EJS)

> **Product or Programme** · [All products and programmes](index.md)

## Description
A free Java-based authoring toolkit developed by Francisco Esquembre for creating and modifying interactive computer models and simulations, especially for science education.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Easy Java Simulation (EJS) free authoring toolkit for building and modifying physics computer models**: Easy Java Simulation is a free authoring toolkit that lets educators create and modify interactive physics computer models. The article introduces it so that participants "can modify the open source computer models for their own learning and teaching needs", using a spring mass system example built on ordinary differential equations. It is used in the workshop alongside the OSP library and Java Runtime. (Loo Kang WEE (2012))
- **Easy Java Simulation (Ejs) open source authoring toolkit for creating physics simulations**: Easy Java Simulation (Ejs) is a free authoring toolkit, described in the paper as "a software tool (java code generator) designed for the creation of discrete computer simulations". Teachers use it to examine and modify the open source codes of computational models created by practicing physicists, remixing them into customized virtual laboratory simulations such as the seven physics models the paper presents. The models are downloadable from digital libraries such as the NTNUJAVA Virtual Physics Laboratory under creative commons attribution licensing. (Loo Kang WEE (2010))
- **Easy Java Simulation (Ejs) open source authoring toolkit for creating physics computer simulations**: Easy Java Simulation (Ejs) is described as "a software tool (java code generator) designed for the creation of discrete computer simulations", a free authoring toolkit the author uses to create computer models that allow students to visualize physics phenomena. Because it exposes open source codes, educators can examine "the open source codes of the simulation through the Easy Java Simulation (EJS) toolkit" and make sense of the physics from computational models created by practicing physicists. The paper positions it as the enabling tool for teacher design and remixing within the Open Source Physics community. (Loo Kang WEE (2012))
- **Four syllabus-customized, free gravity computer models built with Easy Java Simulation for inquiry learning**: The article describes four teacher-customized computer models built on Open Source Physics templates with the free authoring toolkit Easy Java Simulation: a Kepler Solar System Model, a Geostationary Satellite around Earth Model, and two One Dimensional Gravitational Models. They are described as "syllabus-customized, free and rapidly-prototyped with Open-Source-Physics researchers-educators" and "based on real data". The models are downloadable from a blog and the ComPadre OSP and NTNUJAVA digital libraries under creative commons attribution licensing. (Loo Kang WEE et al. (2012))
- **Easy Java Simulation open-source authoring toolkit for browser-based physics models**: Easy Java Simulation (EJS) 5.1 is an open-source authoring toolkit, credited to Francisco Esquembre, for building interactive physics models. Models created in EJS have "open and freely editable source codes, typically licensed creative commons attribution", and EJS 5.1 models run on almost any device through the internet browser; the article's model source is editable in EJS 5.1 and above. (Loo Kang WEE et al. (2015))
- **EJS micrometer computer model with dial-scale hints, random-sized measurements, and zero error options**: A companion Easy Java Simulation model of the micrometer screw gauge with a simple 2D view, hints and answers, an input field to check answers, a slider and thimble control, and zero error options. The article notes "The bottom control panel allows a random sized external measurement, input field to check answers, (green) slider, (teal) thimble to take measurement and zero errors." Like the caliper model, it is downloadable from open digital libraries and intended for teacher customization. (Wee et al. (2014))
- **Ejs Open Source Alternating Current AC Generator Model Java Applet**: An open-source Java simulation of a hand-held AC generator used in Phase 3 (Operationalizing) of the exemplar for online concept internalization of Faraday and Lenz's Laws. The applet mirrors the physical demonstration set — "The handle bar, the magnets, 2 slip rings, the armature coil, axle, the output electromotive force (e.m.f.) measured by data-loggers" — and adds sliders, an input field for active inquiry, data for sense-making, and "Visualization of invisible electrons & magnetic field". (Chew et al. (2010))
- **EJS forced-resonance computer model with an array of 100 spring-mass systems across damping levels**: A computer model created with Easy Java Simulation in which (N=100) identical spring-mass systems are subjected to "periodic driving force of equal amplitude but different driving frequencies" and different amounts of damping. It displays theoretical steady-state amplitudes as pink dots, records red maximum amplitudes, and stores data sets so different damping runs appear on one resonance graph. (Loo Kang WEE et al. (2015))
