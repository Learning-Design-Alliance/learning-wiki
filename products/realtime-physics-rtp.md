## Description
RealTime Physics is a laboratory curriculum and manual developed for introductory physics courses that uses guided inquiry, prediction, group discussion, and real-time data collection and plotting.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **RealTime Physics guided-inquiry lab curriculum with real-time data plotting and prediction steps**: RealTime Physics (RTP) is a lab manual using "a guided-inquiry approach to the execution of the experiments", in which students predict results, discuss preconceptions within their group, and watch data plotted in real time as experiments run. Students make multiple runs comparing physical activity with mathematical plots, complete lab reports within class time, and answer follow-up homework questions. At UCF it was implemented in select lab sections using existing rooms, computers and Pasco interfaces. (Costas Efthimiou et al. (2011))
