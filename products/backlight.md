# Backlight

## Description
Backlight is a relativistically accurate computer-graphics code created and developed for rendering special-relativistic scenes, including pedagogically designed visualizations for undergraduate physics learning.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Backlight relativistic raytracer used to render photo-realistic relativistic scenes**: Backlight is a relativistically-accurate computer graphics code created by a student in 1997 and later rewritten to "allow for objects with different velocities in the same scene". It produced the videos Visualising Special Relativity and Seeing Relativity, the latter "explicitly pedagogic in its design, and featured Einstein's tram". Current development is towards allowing accelerating objects besides the camera and improving the illumination model. (Antony C. Searle et al. (2005))
