# Codio

## Description
Codio is a cloud-based coding education platform that enables instructors to author programming lessons and learners to write, run, test, and receive automated feedback on code.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Codio online learning environment with automated formative feedback**: Codio is the online learning environment used in the studied module, where "teachers prepare Codio units which include learning material and tasks that can provide formative feedback." Students enter and run code in a Linux terminal and click the check it button, which produces "a green tick if the code is correct" or a red cross with feedback when tests fail. (Feedback and Engagement on an Introductory Programming Module)
