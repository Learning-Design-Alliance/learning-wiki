ARTS: Adaptive Response Time Based Sequencing¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 causal), q2 · 1 of 1 report an effect size · 2 claims rest on one study

Description¶

ARTS is an adaptive learning system developed by Everett Mettler and colleagues that sequences practice items using learner accuracy and response time to regulate spacing, priority, interleaving, and retirement.

Components¶

  • ARTS: Adaptive Response Time Based Sequencing: ARTS is an adaptive learning system that uses response times along with accuracy as primary inputs to govern adaptive sequencing. All items receive priority scores updated after every trial as a function of learner accuracy and RTs, trials elapsed, and predetermined mastery criteria; retention intervals expand as an inverse function of response time, so faster accurate responses automatically produce longer recurrence intervals. The system implements rapid reappearance of missed items via a priority increment W, interleaving via an enforced delay constant D, dynamic spacing based on a log function of RT, and retirement criteria requiring several consecutive fast correct responses. The article states the algorithm "may utilize any equations relating elapsed time or trials, accuracy, and RT to the priority for presentation of an item." (Everett Mettler et al. (2011))

Claims¶

  • ARTS yields greater trial-based learning efficiency than Atkinson's (1972) scheduling algorithm in adult geography learning [+M]
  • Third graders using ARTS mastered basic multiplication facts in about two hours with large pretest-to-posttest gains [+M]
