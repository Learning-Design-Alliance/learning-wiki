# THE-RCT restricted-access database and the public empirical-benchmarks effect-size dataset

## Description
MDRC and ICPSR provide a restricted-access student-level database of postsecondary randomized controlled trials alongside a public study-level effect-estimate benchmark dataset and adjustment tool.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **THE-RCT: The Higher Education Randomized Controlled Trials Restricted Access File and associated public benchmark database**: THE-RCT RAF is a restricted-access student-level database created by MDRC and housed at ICPSR, including all RCTs MDRC conducted in postsecondary education from 2003–2019, with design indicators, student characteristics, and semester-level outcomes (enrollment, credits, degree completion). The present analysis uses 39 interventions and "a total of 65,604 students" across 44 institutions. A companion public-use dataset with study-level effect estimates and an online adjustment tool are available at the MDRC benchmarks site. (Michael J. Weiss et al. (2023))
