# CRITICS

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
CRITICS is a project-developed suite including an LLM-based scientific document translation system that preserves domain terminology, notation, and document structure for multilingual science education.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LLM-based scientific document translation system with domain-specific terminology glossaries**: The first CRITICS component is an LLM-based scientific document translation system intended to surpass conventional MT approaches, which often struggle with domain-specific terminology and notation. It uses "adapters fine-tuned on specialized scientific corpora to preserve structural elements and field-specific terminology". The project will develop domain-specific terminology glossaries integrated through prompt engineering or fine-tuning datasets, and tools to preserve layout, citations, equations, code and section formatting in translations. (Agerri et al. (2026))
