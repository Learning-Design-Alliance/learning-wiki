# Generalized Intelligent Framework for Tutoring (GIFT)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
GIFT is a software framework for authoring, integrating, and adapting computer-based tutoring and training environments, developed and maintained by the GIFT community.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **GIFT Gateway Module for real-time persistence assessment across game-based learning environments**: The Generalized Intelligent Framework for Tutoring (GIFT) supports open and dynamic game-based learning environments with distinct messaging protocols. To detect persistence regardless of the educational game used, "a 'Gateway Module ' is incorporated that associates an external educational/training system 's state data with a domain or competency model built within GIFT." This linkage lets disparate systems communicate, enabling real-time assessment of persistence in players, with progress communicated to the learner model for determining transitions in performance or competency and to the pedagogical model for selecting feedback and remediation tactics. (Ventura et al. (2013))
