# UniDental-MU01 virtual simulation system

## Description
UniDental-MU01 is a computer-based virtual simulation system made by UNIDRAW, China, for interactive preclinical dental preparation training with automated scoring and recorded practice.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **UniDental-MU01 virtual simulation system for dental preparation training**: A virtual simulation system (UniDental-MU01, UNIDRAW, China) used for preclinical inlay tooth preparation training, in which operators interact in real time with a 3D computer database and receive a scoring report after completing the preparation for every exercise. It provides "repeatable, recorded, and computerised training, which typically requires no supervision", saving teacher resources, and can simulate common and difficult clinical cases. Students rated its scores as accurate and its assessment items as perfect. (Sheng Jie et al. (2022))
