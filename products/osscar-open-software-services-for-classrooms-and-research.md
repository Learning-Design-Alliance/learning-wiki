# OSSCAR (Open Software Services for Classrooms and Research)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
An open-source collaborative software platform developed by Dou Du and colleagues for creating, deploying, and accessing interactive educational web applications with tools such as Python, Jupyter, ipywidgets, and Voila.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **OSSCAR open platform for collaborative development of interactive educational web applications**: OSSCAR (Open Software Services for Classrooms and Research) is an open collaborative environment to develop, deploy and access educational resources as web applications. It combines standard tools (Python, Jupyter/JupyterLab, ipywidgets, Voila) with custom domain-specific widgets, and releases all notebooks and configuration files as open source on GitHub. The article states it provides "an open collaborative environment to develop, deploy and access educational resources in the form of web applications", targeting teachers and students in computational science. (Dou Du et al. (2022))
