## Description
A machine-learning AI tutoring system developed by Fazlollahi and colleagues that classifies surgical-simulation performance and provides staged, metric-based audiovisual feedback to medical learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Virtual Operative Assistant: a machine-learning-powered intelligent tutoring system for neurosurgical simulation**: The Virtual Operative Assistant is described as "an intelligent tutoring system powered by machine learning for neurosurgical simulation" whose associated work "discusses the limitations and challenges of this technology." It embodies the article's model of deconstructing psychomotor skills into teachable metrics so trainees can obtain personalized feedback on algorithm-identified factors. The commentary presents it as a prototype direction for automated surgical training. (Mirchi N et al. (2020))
- **Virtual Operative Assistant: automated AI-powered educational feedback platform**: The Virtual Operative Assistant is a Matlab-built platform combining the trained classifier with an educational feedback system. It classifies a new user as skilled or novice, presents the classification "as a percentage of each class", and provides metric-wise feedback against expert proficiency benchmarks with red and green zones whose boundary is the mean of the training data (z-score of 0). It delivers written, auditory and video-based feedback mimicking operating-room instructor feedback, and all code is publicly available at https://github.com/Ai-SimCenter/Virtual-Operative-Assistant/. (Mirchi N et al. (2020))
