# GLITTER

## Description
GLITTER is an AI-assisted platform for asynchronous, course-material-grounded discussion in flipped university classrooms, developed by its article authors.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Closed-corpus RAG evidence anchoring that retrieves discussion evidence exclusively from course materials**: Glitter's conceptual blending feature uses Retrieval-Augmented Generation over a knowledge base built solely from the assigned course materials: text chunks are embedded with OpenAI's text-embedding-ada-002 and stored in a vector database. The article states that "By constraining the retrieval process to this closed set of materials, the system fundamentally prevents hallucination since the model can only access and reference content that exists within the course materials." Retrieved evidence appears as color-coded blocks visually linked to their original context, supporting material-grounded discussion contributions.
