# AstronomyCalc

> **Product or Programme** · [All products and programmes](index.md)

## Description
AstronomyCalc is a Python toolkit developed by Sambit K. Giri for interactive astrophysical and cosmological calculations, including cosmological-model exploration and astronomy data analysis.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AstronomyCalc dataset modules: synthetic Type Ia supernova data, Pantheon+, and the SPARC galaxy rotation curves**: AstronomyCalc includes modules for generating synthetic astronomical data or accessing publicly available datasets. Users can "generate synthetic Type Ia supernova measurements of cosmological distances" or use the publicly available Pantheon+ dataset, and the package supports download and analysis of the SPARC dataset, "which contains galaxy rotation curves for 175 disk galaxies". These datasets can be analyzed within the package to test cosmological and astrophysical models. (Sambit K. Giri (2024))
