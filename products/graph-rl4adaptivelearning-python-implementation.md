# graph-RL4AdaptiveLearning Python implementation

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
An open-source Python implementation of a graph-neural-network reinforcement-learning policy for personalized learning-path recommendation, released by Jean Vassoyan and colleagues for researchers and developers of adaptive learning systems.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Released Python implementation of the graph-RL adaptive learning policy**: The authors release their experimental implementation so the work can be reproduced. The paper states: "Our implementation is written in Python and is available on GitHub", with the repository at github.com/jvasso/graph-rl4adaptive-learning. Hyperparameters of the policy model (learning rate 0.0005, hidden dimension 32, two attention heads, Wikipedia2Vec embedding size 100, batch size 16, among others) are provided in Table 4 of the Appendix. (Jean Vassoyan et al. (2023))
