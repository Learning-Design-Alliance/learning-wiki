# AlgoBo: an LLM-based teachable agent with a Reflect-Respond prompting pipeline

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size

## Description
AlgoBo is a GPT-4-based chatbot that simulates a learner with prescribed knowledge states so programming novices can practice learning by teaching.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AlgoBo: an LLM-based teachable agent with a Reflect-Respond prompting pipeline**: AlgoBo is an LLM-based teachable agent (tutee chatbot) for learning by teaching, operated by the Reflect-Respond prompting pipeline on GPT-4. A JSON knowledge state with facts and code_implementation constrains its responses, letting it 'simulate misconceptions and unawareness prescribed in its knowledge state'. The Reflection flow extracts new information from recent conversation to update the knowledge state; the Response flow retrieves only from that state, and AlgoBo asks for explanation when nothing relevant is retrieved. (Teach AI How to Code: Using Large Language Models as Teachable Agents for Programming Educ)
