## Description
Insight is a web-based programming classroom assistant with instructor exercise authoring and a VS Code student interface, developed by Hoq et al. for introductory programming courses.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Insight classroom assistant with instructor authoring tool and VS Code student interface**: Insight is a web-based classroom assistant for introductory programming that supports "programming exercise authoring, distribution, and adaptive support". Instructors use a dashboard and authoring tool to create exercises, specify correct and incorrect solutions, and attach feedback to instructionally relevant misconceptions, optionally collaborating with an LLM. Students receive exercises, submit solutions, and view feedback through a Visual Studio Code extension that logs all interactions to a cloud backend. LLMs do not generate feedback shown directly to students. (Muntasir Hoq et al. (2026))
