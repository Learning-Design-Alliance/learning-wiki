## Description
TEACHANATOMY is a HoloLens 2 hologram-based augmented-reality application developed for teaching cranial-nerve anatomy through interactive 3D models, overlays, quizzes, adaptive review, and gamification.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TEACHANATOMY hologram-based AR learning application for cranial nerve anatomy on HoloLens 2**: An interactive hologram-based AR learning application built for the Microsoft HoloLens 2, digitizing a cadaveric head specimen via photogrammetry (approximately 300 images processed in RealityCapture) and imported into Unity 3D. Cranial nerves were segmented with textures for interactive selection, providing access to detailed educational information about each nerve's route and function. The application incorporated adaptive learning technology using an Anki-based algorithm and gamification elements including multiple-choice questions with 3 attempts. Routes of cranial nerves were projected onto the dissected head specimen, with structures highlighted and color coded. (Zingg L et al. (2025))
