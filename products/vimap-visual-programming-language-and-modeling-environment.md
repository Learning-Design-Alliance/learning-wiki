# ViMAP visual programming language and modeling environment

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 5 claims (5 for) · 4 studies (2 qualitative, 2 design), `q2` · 0 of 4 report an effect size · 5 claims rest on one study

## Description
ViMAP is a NetLogo-based visual programming and multi-agent modeling environment developed by Pratim Sengupta and colleagues for learners to construct and enact agent-based models, including kinematics models.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ViMAP-Tangible distributed computation learning environment**: ViMAP-Tangible couples the ViMAP visual, drag-and-drop agent-based programming language with ultrasonic distance sensors, so that gestures and physical machines set agent variables such as step-size, turn angle and displacement. In the version studied, "control of the behavior and attributes of a single computational agent is distributed across two ultrasonic sensors, which are connected to ViMAP via an ArduinoTM microcontroller", enabling two students to co-control one turtle on screen. (Pratim Sengupta et al. (2013))
- **ViMAP: an agent-based visual programming environment for kinematics learning**: ViMAP is an agent-based modeling and visual programming environment in which "the user creates a computer program by dragging and spatially arranging programming commands from a library of command blocks." When run, the commands are acted out by a Logo turtle in a NetLogo microworld. "ViMAP commands were specifically designed to support domain -specific learning in kinematics," and students used commands such as Forward <Step-size> and Speed-up <Change-in-Step-size> to model graphs of motion. (Farris et al. (2014))
- **ViMAP agent-based visual programming language and modeling platform**: ViMAP is described as "an agent-based visual programming language and modeling platform that uses NetLogo as the simulation engine". Instead of typing text commands, users drag and drop commands from a library to control a single computational agent, a turtle. The version used had a construction world, where learners organize visual programming blocks, and an enactment world, where a protean computational agent carries out users' commands through movement on the computer screen. (Amy Voss Farris et al. (2014))
- **ViMAP agent-based visual programming environment with grapher for designing mathematical measures**: ViMAP is "an agent-based visual programming language that uses NetLogo (Wilensky, 1999) as its simulation engine". Users construct programs with a drag-and-drop interface controlling the behaviors of one or more computational agents; primitives include domain-specific and domain-general commands plus a grapher with multiple graphing windows for designing and comparing mathematical measures of agent- and class-level variables. In the study, fourth graders used ViMAP across modeling cycles on constant speed, acceleration, gravity and friction, alongside physical modeling. (Amy Voss Farris et al. (2016))
- **ViMAP: an agent-based visual programming language with a grapher for designing mathematical measures**: ViMAP is an agent-based visual programming language using NetLogo as its simulation engine, in which "users construct programs using a drag-and-drop interface to control the behaviors of one or more computational agents". Its primitives include domain-specific and domain-general commands plus a grapher that lets users design mathematical measures from periodic measurements of agent-specific and aggregate-level variables such as speed and number of agents. In the study, third graders used ViMAP to model step sizes, motion, and the two-car problem. (Dickes et al. (2016))
