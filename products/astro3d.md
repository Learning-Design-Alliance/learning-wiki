# Astro3D

> **Product or Programme** · [All products and programmes](index.md)

## Description
Astro3D is a publicly available GitHub software module developed for transforming astronomical image data into 3D-printable textured representations, including accessible tactile astronomy materials.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Astro3D software module for transforming astronomical image data into 3D-printable textured models**: Astro3D is a publicly available software module on GitHub used to load astronomical image data and produce tactile textured representations; the article states "the data are loaded into a software module called Astro3D publicly available on GitHub". It was used to create the star cluster and galaxy prints in this project, with features assigned specific textures previously tested and adopted as a standard. The module supports the production pipeline from research imagery to 3D print files. (Carol A. Christian et al. (2024))
