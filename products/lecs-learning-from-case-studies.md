## Description
LeCS is a web-based collaborative case-study system developed by Marta C. Rosatelli for geographically dispersed learners working together on case-study solutions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LeCS: a web-based collaborative case study system for distance learning**: LeCS (Learning from Case Studies) is a web-based system supporting collaboration between distant learners on case study activities. The article states that "LeCS is a web-based collaborative case study system that can be applied to any domain in which the learning from case studies method is used." It "provides a set of tools for geographically dispersed students working collaboratively on the case study solution," and its design was informed by an empirical qualitative study of paired distance collaboration. (Marta C. Rosatelli (2004))
