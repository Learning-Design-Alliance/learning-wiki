# Obstetric Ultrasound Competency Assessment Tool (OUCAT)

## Description
OUCAT is a 123-item validated instrument for assessing PGY-2 and PGY-3 residents’ competency in routine mid-trimester fetal ultrasound scanning.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Obstetric Ultrasound Competency Assessment Tool (OUCAT) with 45-point pass/fail and 70-point mastery learning standards**: OUCAT is "a validated checklist" used to quantify residents' obstetric ultrasound skill levels on the simulator, with scoring videos rated by two blinded consultants and the average taken as the final score. Pass/fail standards were set by the contrast group method using expert data from 24 certified obstetric ultrasound experts: "45 points was taken as the pass/fail score, and mastery learning level was established at 70 points". Mastery levels were defined for the overall examination and each task module. (Zhao Yongfeng et al. (2025))
