## Description
MentorChat is a domain-independent conversational-agent-supported group-learning architecture developed by Tegos and colleagues that educators can customize to guide learner dialogue.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MentorChat configurable domain-independent conversational agent architecture**: MentorChat is a cloud-based dialogue-based ITS whose architecture consists of three core modules: student, conversational agent, and teacher. The agent module rests on three models — peer interaction, domain, and intervention — where the "peer interaction model analyses and stores the most important aspects of students' interactions" and the domain model comes from teacher-authored concept maps or rules. The design deliberately avoids hardwiring an explicit domain model, instead enabling teacher-led configuration of agent behavior, which the authors argue lowers development cost and increases reusability and teacher acceptance. (Tegos et al. (2013))
- **MentorChat system**: MentorChat is a cloud-based, web-technology application (MySQL, PHP, AJAX, HTML5, CSS3) available in English and Greek for synchronous text-based collaborative activities. Students discuss open-ended domain questions in phases and submit joint answers, while an animated two-dimensional avatar agent with Text-To-Speech tracks dialogue and delivers teacher-defined prompts. Teacher panels cover user management, activity structure, domain modeling, and real-time monitoring with interaction analysis indicators. (Tegos et al. (2013))
