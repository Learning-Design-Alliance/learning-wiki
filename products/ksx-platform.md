## Description
The KSX platform is a digital knowledge-sharing and exchange system developed by Heusler Andreas and colleagues, combining communication, content management, virtual stock-market, and gamified knowledge-challenge functions for learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **KSX platform architecture with four modules and gamification elements**: The KSX platform consists of four modules: a communication module with forum and notification services, a knowledge repository module covering content management, a VSM module offering trading and auction mechanisms, and a knowledge challenges module with gamification elements including a virtual currency (Virt$) system, a contribution point system and two leaderboards for performance and contribution rankings. The integration of VSMs with the gamified knowledge challenges module is described as the core contribution encouraging coopetitive knowledge sharing. (Heusler Andreas et al. (2019))
