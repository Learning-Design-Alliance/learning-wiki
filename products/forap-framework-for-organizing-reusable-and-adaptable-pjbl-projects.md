# FORAP (Framework for Organizing Reusable and Adaptable PjBL Projects)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A framework developed by Suleiman et al. for organizing reusable and adaptable computing project-based-learning projects into aligned objectives, project attributes, and coordinated instructor, student, and assessment support packages.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **FORAP: a framework organizing computing PjBL projects as coordinated adoption-ready packages**: FORAP (Framework for Organizing Reusable and Adaptable PjBL Projects) organizes each project as a coordinated package centered on aligned learning objectives, described through project attributes, and supported by three coordinated support packages: instructor, student, and assessment. Project attributes (greenfield vs. brownfield, scope and duration, technical complexity, domain, and optional competency specification such as CC2020 mapping) let instructors judge course fit and plan adaptation. The framework was used to package a 14-project portfolio and is grounded in PjBL principles of authentic, collaborative, and self-directed learning. (Suleiman et al. (2026))

### Claims
- [FORAP-packaged projects were deployed in 44 classroom trials across seven universities over four academic years, reaching about 2,000 students](../claims/forap-44-classroom-trials-seven-universities.md) [+M]
- [Instructors reported that FORAP packaging reduced the initial effort to adopt and adapt PjBL activities, based on anecdotal feedback](../claims/forap-packaging-reduced-instructor-adoption-effort.md) [+M]
