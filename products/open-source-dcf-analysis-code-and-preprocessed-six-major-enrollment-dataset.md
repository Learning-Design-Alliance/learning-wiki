# Open-source DCF analysis code and preprocessed six-major enrollment dataset

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A released dataset of undergraduate enrollment and grade records from six majors, together with code for conducting Differential Course Functioning analysis, created by the study authors.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open-source DCF analysis code and preprocessed six-major enrollment dataset from a large public US university**: The study's analysis pipeline and data are released for reuse: "we open-source our analysis code via GitHub to facilitate the adoption of DCF as a CA methodology". The analyzed dataset derives from enrollment and grade records collected between Fall 2011 and Spring 2022, covering over 196,000 students and 8,600 unique courses, preprocessed to "6 majors with 20,075 students and 364 unique courses" with grades dichotomized at the median grade (A). (Gaining Insights into Group-Level Course Difficulty via Differential Course Functioning)
