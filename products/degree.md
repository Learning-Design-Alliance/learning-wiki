## Description
DEGREE is a collaborative-learning environment and scenario-authoring framework that uses declarative dialogue, task, and outcome specifications to configure and run online collaborative learning activities.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Activity Theory-based declarative methodology for defining collaborative learning scenarios (dialogue, task, outcome template)**: The project's first core contribution is a methodology based on Activity Theory that provides declarative mechanisms for specifying collaborative scenarios. An intermediate language creates a generic template with three elements (dialogue, task, and outcome) used to build a scenario-instance from a taxonomy of values; a framework then interprets the instance to launch an interactive online learning environment. The authors situate this approach within the later development of collaborative scripts and collaborative learning flow patterns. It was implemented in DEGREE and re-implemented in subsequent system versions. (B. Barros et al. (2015))
- **DEGREE collaborative learning tool with semi-structured communication, experiment configuration, interaction analysis, and interventions**: DEGREE is a collaborative learning tool that "uses semi-structured communication (with sentence openers, tagged dialogs)" and offers tools to configure a collaborative experiment, provide an analysis of the collaboration process, and offer interventions to improve the interaction. The authors report that its sentence-opener model of facilitating collaborative interaction was re-implemented in a collaborative version of the SIETTE system for collaborative small-group assessment and interaction analysis. The community also cited DEGREE as an integrated approach to designing, conducting, and analysing a collaborative experiment. (B. Barros et al. (2015))
