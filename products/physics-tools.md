## Description
Physics Tools is a web-based HTML, JavaScript, and Java-applet problem-solving and virtual-experiment tool for algebra- and calculus-based physics students, developed by Roman Ya. Kezerashvili and colleagues.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LiDAR Motion app for real-time motion graphing and graph-matching challenges**: LiDAR Motion is a free mode within the Physics Toolbox Sensor Suite app for iPad and iPhone that plots a user's movement perpendicular to a flat wall. Its LiDAR hardware "emits an array of infrared laser pulses and then senses the reflected pulses, using the light's time of flight to calculate the distance," displayed as real-time position-time and/or velocity-time graphs. It also includes a graph-matching game in which motion data must be validated against expected values within an acceptable R2 threshold before congratulatory feedback appears. (O'Brien et al. (2022))

### Claims
