## Components

- **SWELL partnership logic model linking teacher professional learning to English learner literacy outcomes**: The SWELL logic model is a program theory that chains partnership activities (adapt, implement, and refine Write to Succeed; conduct optimization testing; conduct initial efficacy testing; statewide scale-up) through teacher-level outcomes to student-level outcomes. # SWELL partnership logic model linking teacher professional learning to English learner literacy outcomes

## Description
The SWELL logic model is a program theory that chains partnership activities (adapt, implement, and refine Write to Succeed; conduct optimization testing; conduct initial efficacy testing; statewide scale-up) through teacher-level outcomes to student-level outcomes. It states the partnership will "iteratively enhance and test the Write to Succeed professional learning program to help teachers improve their literacy instruction," so that English learner students ultimately experience positive impacts to English proficiency and literacy achievement.

## Design Implications

### Context
#### Requirements
- Recruitment sufficient to support implementation as planned
- The Write to Succeed program successfully supports educators and student learning
- District- and NMPED-based coaches are effective instructional coaches
#### Constraints
- Short-, medium-, and long-term outcomes are assumed realizable within the REL Southwest contract period

### Target Learners
- New Mexico teachers
- English learner students in New Mexico

### Target Learning Objectives
- English learner literacy
- Writing achievement
- Teacher literacy instruction quality
