# LabVIEW

## Description
LabVIEW is a graphical development environment from National Instruments for visual dataflow programming, measurement, automation, and hardware control, including educational engineering and physics applications.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Build the control software of an educational QKD system in LabVIEW because it is familiar to students and intuitive for novices**: The article recommends LabVIEW as the development environment for the system's control software because it is "already widely used in universities physical workshops, so it will be familiar to many students", while novices "can easily get involved, since the programming language is graphical and intuitive". The authors consider it "an optimal choice for educational purposes" and note post-processing can also be carried out in the environment. (A.K. Fedorov et al. (2017))
- **LabVIEW multimedia module solving the Time Dependent Schrödinger Equation for arbitrary potentials**: A stand-alone LabVIEW application for introductory quantum physics that numerically solves the Time Dependent Schrödinger Equation using a finite difference technique. The user sets the initial gaussian wave packet parameters, the potential characteristics, and the discretization steps, and the program displays the wave packet dynamics and exports expectation values and transmission/reflection coefficients. The authors state that "The program solves the Time Dependent Schrödinger Equation for arbitrary potentials" and that it was integrated into the Quantum Physics for Engineering course. (Ismael Orquín et al. (2004))
