## Description
CLASS is an open-source C codebase maintained by its developers for computing cosmological background evolution, perturbation spectra, and related observables from user-specified cosmological models.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CLASS Boltzmann code as a classroom tool for computing cosmological observables**: CLASS (Cosmic Linear Anisotropy Solving System) is open-source software, written in C and freely downloadable, that calculates background expansion history and linear perturbation spectra for user-specified cosmological models. In this exercise students downloaded and compiled CLASS version 2.7.1, ran ΛCDM reference input files, and adapted explanatory.ini for exotic models, producing density-parameter evolutions, CMB temperature spectra and matter power spectra. The author chose it because "the modular structure of CLASS makes it very easy to learn and use" and it "gives quick results which can be discussed and analyzed". (T. Rindler-Daller (2020))
