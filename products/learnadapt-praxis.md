## Description
LearnAdapt Praxis is a LearnAdapt web application that structures adult workplace-learning projects through the stages Frame, Learn, Build, Validate, and Transfer.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LearnAdapt Praxis five-stage learning workspace (Frame, Learn, Build, Validate, Transfer)**: Praxis is a web application in the LearnAdapt ecosystem that structures an adult workplace-learning project across five stages: Frame, Learn, Build, Validate and Transfer. Learners "begin with their own starting response, engage with course material, develop a five-field specification, record validation observations and respond to a different scenario." The server stores a locked baseline, versioned specifications, hint records, validation observations and a separate transfer response, and enforces prerequisites such as a saved specification and validation observations before transfer begins. (Nizam Kadir (2026))
