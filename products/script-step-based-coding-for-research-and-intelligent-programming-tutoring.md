# SCRIPT (Step-based Coding for Research and Intelligent Programming Tutoring)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
SCRIPT is a web-based intelligent tutoring system developed by Alina Deriyeva and colleagues for teaching Python programming while recording fine-grained learner data and supporting adaptable pedagogical and learner-model research.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SCRIPT: an adaptable Python programming ITS serving as both teaching and research platform**: SCRIPT (Step-based Coding for Research and Intelligent Programming Tutoring) is a web-based ITS supporting advanced undergraduates learning Python for data science and machine learning. The article states it "functions both as a teaching and as a research tool by enabling to record fine-grained, keystroke-level data" and is "easily adaptable to novel learner models and pedagogical models as well as randomized experiments." It was offered as voluntary exam preparation for an Introduction to Data Mining course and has supported prior learner-model and feedback research. Source code is released on a GitLab repository, though the system is still in alpha stage. (Alina Deriyeva et al. (2025))
