## Description
An open-source web-based database developed by the University of Alberta Libraries for creating, managing, and delivering test items.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **WASSAIL open-source test delivery database and 16-item post-test instrument**: Researchers created 16 multiple-choice test items based on the tutorials' learning outcomes, reviewed by librarians for content validity, each with four options plus an "I don't know" option. The items were loaded into WASSAIL, described in the article as "an open source web -based database from the University of Alberta Libraries that allows for the creation, management, and delivery of test items." The instrument served as the sole outcome measure for all three groups. (Mery et al. (2014))
