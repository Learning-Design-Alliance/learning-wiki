# REACT (Relatives' Education And Coping Toolkit)

## Description
REACT is an online supported self-management toolkit for relatives of people with psychosis or bipolar, delivered with psychoeducation modules, peer discussion, messaging, and resource support by participating mental-health teams.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **REACT (Relatives' Education And Coping Toolkit) online self-management toolkit for relatives**: REACT is a supported self-management toolkit providing accessible evidence-based information and support for relatives of people with psychosis or bipolar. It included "12 psychoeducation modules addressing key questions identified by relatives; peer support through a moderated group forum; a confidential direct messaging service; and a resource directory". Modules contained evidence-based written information, videos of clinical experts and experts by experience, and self-reflection tasks personalising content; a separate instance was set up for each case, with REACT Supporters moderating the forum and responding to messages. (IMPlementation of An online Relatives' Toolkit for psychosis or bipolar (IMPART study): it)
