# Indicator Editor: a no-code SSLA tool for user-controlled LA indicator implementation

## Description
The Indicator Editor is a no-code, low-cost, interactive LA tool implemented in React and Material Design within the Open Learning Analytics Platform. It guides students and teachers with data analysis and visualization knowledge through four steps—dataset selection, filters, analysis method, and visualization—to create personalized indicators, preview them, edit them, and embed Interactive Indicator Code in dashboards such as CourseMapper. The article states it is "a no-code, low-cost, interactive LA tool that enables educational stakeholders with knowledge of data analysis and visualization to implement LA indicators with minimal effort."

## Design Implications

### Context
#### Requirements
- Users need at least basic knowledge of data analytics and visualization
- Access to learning activity data in xAPI format stored in an LRS
#### Constraints
- The tool supports only basic indicators using simple statistics; complex indicators based on ML algorithms, classification, or prediction are beyond its scope

### Target Learners
- students
- teachers

### Target Learning Goals
- creating transparent LA indicators tailored to personal goals
- exploring educational data to answer self-formulated questions
