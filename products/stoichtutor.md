# StoichTutor

> **Product or Programme** · [All products and programmes](index.md)

## Description
StoichTutor is an intelligent tutoring system developed to teach undergraduate and graduate learners stoichiometry through factor-label problem solving with step constraints, immediate feedback, and hints.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **StoichTutor intelligent tutoring system with think-aloud and log-data integration**: StoichTutor is "an intelligent tutoring system designed to teach stoichiometry using the factor-label method, guiding learners to systematically convert units from a given to a target value". It requires learners to enter or select values and provides immediate feedback and hints, and has been shown to significantly improve students' stoichiometry skills. In this study, ten students' think-aloud utterances (401 utterances, coded into four SRL categories) were timestamp-linked to log transactions segmented into 117 clips of eight actions, 39 of which were coded as gaming. (Jiayi Zhang et al. (2026))
