# ACT (Accreditation Tool)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
ACT is a Microsoft Access database application developed by Adeel Sabir et al. for engineering faculty and accreditation evaluators to manage, analyze, and report ABET outcomes-assessment data.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ACT: a multi-user Microsoft Access application for managing and analyzing ABET accreditation assessment data**: ACT (Accreditation Tool) is a database application built entirely in Microsoft Access, with a distributed frontend of interactive forms and a backend on a secure network server. It manages data for ABET criteria 3 and 4 through six tabs (Basic Data, Metrics, Assessment, Feedback, Reports-1, Reports-2), and "allows efficient data management for the documentation-intensive criterion 3 and 4, and enables the users to manage and view the assessment data in the form of customized reports". The program and its user guide are available to educators and evaluators. (Adeel Sabir et al. (2018))
