# APLUS (Artificial Peer Learning Using SimStudent)

## Description
APLUS is an online learning-by-teaching environment developed by its researchers in which students tutor the SimStudent virtual agent to solve algebraic equations through guided problem solving.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **APLUS: a learning-by-teaching environment in which students tutor SimStudent to solve algebraic equations**: APLUS (Artificial Peer Learning Using SimStudent) is an online learning-by-teaching environment in which students, acting as tutors, "teach a virtual agent named SimStudent to solve algebraic equations through guided problem solving". SimStudent learns production rules via programming by demonstration (inductive logic programming), proposes solution steps, and asks focal questions when the tutor disagrees or lacks a production. Tutors can quiz SimStudent across four quiz levels and access a Problem Bank, Unit Overview, Introduction Video, worked Examples, and a meta-tutor agent, Mr. Williams, who gives voluntary metacognitive hints. (Fathima Ameen et al. (2026))
- **Simulated Student architecture for detecting and avoiding negative situations in collaborative learning**: The Simulated Student architecture is a model of a simulated peer agent that monitors collaborative learning interactions to detect and avoid situations that decrease the benefits of learning in collaboration. It targets three named situations: off-topic conversations, students with passive behaviour, and problems related to students' learning. The article presents it as a model whose features are instantiated in an agent added to a real collaborative system, and evaluates whether the model is adequate in the avoidance of negative situations. (Aurora Vizcaíno (2005))
- **SimStudent: a machine-learning agent that learns an expert model through tutored problem solving**: SimStudent is a domain-general machine-learning agent that learns an expert model of a target task through tutored problem solving, using the same tutor interface crafted for the target cognitive tutor. It learns production rules representing individual cognitive skills, with an if-part (information retrieval path and preconditions) and a then-part (operator function sequence). Three machine-learning techniques are combined: version spaces for the information retrieval path, FOIL inductive logic programming for preconditions, and iterative-deepening depth-first search for the operator function sequence. The domain dependency is implemented as background knowledge comprising a WME structure, feature predicates, and operator functions. (Matsuda et al. (2015))
- **SimStudent as a machine-learning teachable agent with high cognitive fidelity, including incorrect learning**: SimStudent is "a machine-learning architecture that learns procedural skills inductively from examples", integrated into APLUS where students tutor it with yes/no feedback, hints, quizzes, and self-explanation prompts. Its unique characteristic is the ability "to model both correct and incorrect learning": given prior knowledge based on surface features, it makes induction errors from correct examples, producing overly specific or general productions mirroring common algebra errors. The authors hypothesize such "high cognitive fidelity" teachable agents offer better learning-by-teaching opportunities. (Matsuda et al. (2013))
