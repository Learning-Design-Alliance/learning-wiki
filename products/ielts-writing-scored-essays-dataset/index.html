IELTS Writing Scored Essays Dataset¶

Product or Programme · All products and programmes
Evidence · 1 claim (1 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

A publicly available Kaggle dataset of 787 Academic IELTS Task 2 essays with official examiner-assigned band scores, used for automated writing-assessment research.

Components¶

  • IELTS Writing Scored Essays Dataset (Task 2 subset) with released bandit AES implementation: The study uses the IELTS Writing Scored Essays Dataset, a publicly available Kaggle resource comprising "787 Academic Task 2 compositions, each accompanied by an official band score ranging from 1 to 9, assigned by qualified IELTS examiners". The compositions respond to conventional Task 2 instructions requiring argument development or perspective presentation. The authors also release their complete implementation code publicly on GitHub and plan to release policy logs. (Olga Manakina (2026))

Claims¶

  • Expert human raters established an inter-rater reliability benchmark above ICC 0.89 on all four IELTS dimensions for the essay corpus [+W]
