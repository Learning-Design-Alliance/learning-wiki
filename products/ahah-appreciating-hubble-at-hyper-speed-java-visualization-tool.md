# AHaH — Appreciating Hubble at Hyper-speed Java visualization tool

## Description
A Java-based interactive three-dimensional visualization tool developed by Liam J. Nolan et al. for teaching redshift, galaxy morphology, Hubble's Law, and cosmological parameters in introductory astronomy.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AHaH — Appreciating Hubble at Hyper-speed Java visualization tool**: AHaH is a Java-based teaching tool for beginning astronomy and cosmology courses built on a redshift-sorted database of over 5000 HUDF galaxies. As the abstract states, "This tool lets the user hypothetically traverse the Hubble Ultra Deep Field (HUDF) in three dimensions" at over 500×10^12 times the speed of light, from z=0 to z=6, in standard expanding or static pseudo-Euclidean geometry, and with user-selectable cosmological parameters. Source code ships with the distribution under a BSD-like license, and exercises are available online. (Liam J. Nolan et al. (2021))
