# SCINE Interactive

## Description
SCINE Interactive is a free software package developed by the SCINE team for real-time interactive quantum-chemistry exploration through visual and haptic manipulation of molecular structures.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SCINE Interactive software package for real-time interactive quantum chemistry exploration**: SCINE Interactive is described as "the original implementation of real-time quantum chemistry" for molecular structure and reactivity exploration with self-consistent orbital optimizations. It delivers ultra-fast electronic structure calculations so a user can manipulate a molecular structure with a mouse or haptic device and directly perceive the system's response through visual and haptic feedback. It is available free of charge on the authors' webpage and runs on a standard laptop. (Thomas Weymuth et al. (2020))
