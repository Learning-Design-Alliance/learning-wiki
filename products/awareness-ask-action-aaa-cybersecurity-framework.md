## Description
A cybersecurity and privacy professional-development framework developed by Florence Martin and colleagues for K-12 school personnel, organizing edtech security learning into Awareness, Ask, and Action levels.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Awareness-Ask-Action (AAA) cybersecurity framework for K-12 educational technology**: The AAA framework is a three-level adaptation of the Cybersecurity and Infrastructure Security Agency's five-aspect framework (identify, protect, detect, respond, recover), tailored for an Edtech cybersecurity and privacy PD. The "Awareness" level "focuses on increasing awareness by K-12 school personnel on educational technologies used in various school districts, the data collected by these technologies, vulnerabilities associated with them, and the types of cyber-attacks". The "Ask" level helps personnel critically recognize which questions to ask software companies and understand functionality-versus-security tradeoffs. The "Action" level supports personnel as they detect, respond to, and recover from attacks. The PD's four modules were mapped onto this framework. (Florence Martin et al. (2025))
