# A2i

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
A Learning Ovations-partnered system that uses online assessments, instructional recommendations, lesson-planning support, and professional development to help Pre-K through Grade 3 teachers individualize literacy instruction.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **A2i Professional Support System**: The A2i Professional Support System is a systems-level approach intended to improve reading success in Pre-K through Grade 3 by individualizing instruction so that "learning experiences are tailored to account for each students' unique needs". It prepares teachers to vary the content and form of instruction according to students' prior performance, using quick online assessments, instructional recommendations, lesson planning support, and customized professional development, with Learning Ovations as the partner organization. (A2i Professional Support System (2013))
- **A2i Software Platform**: The A2i Software Platform is described as "a key component of the A2i Professional Support System". It can be accessed on any device with a screen wider than 768 pixels (any full-sized screen). The online assessments are the only student-facing component and can be taken on most up-to-date tablets, Chromebooks, or laptops, while teacher-facing supports run on full-sized screens. (A2i Professional Support System (2013))
- **Assessment-to-instruction (A2i) web-based planning software**: The Assessment-to-instruction (A2i) software "translates assessment results into specific recommendations for amounts and types of instruction for each student in the classroom". It automatically records teachers' use, including total minutes of active use, which the study used as a metric of planning and a proxy for intervention fidelity. An integral part of the ISI intervention, A2i includes planning-specific components such as the Literacy Minutes Manager and the Group Activity Planner, and is available at http://isi.fcrr.org. (Connor Carol McDonald et al. (2010))
