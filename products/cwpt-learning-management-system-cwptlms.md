# CWPT Learning Management System (CWPT–LMS)

> **Product or Programme** · [All products and programmes](index.md)

## Description
CWPT–LMS is computer-based software support for implementing, monitoring, and sustaining ClassWide Peer Tutoring, distributed by the Juniper Gardens Children's Project.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CWPT Learning Management System (CWPT–LMS) software support**: The CWPT Learning Management System is a computer-based version of the peer tutoring program distributed by the Juniper Gardens Children's Project. It is "a system of peer tutoring instruction with computer software support designed to help teachers implement effective instruction, monitor progress, and sustain use of the program over time." Training materials are available on the developer web site and training is available from Juniper Gardens' staff; the materials, including a CD, training, and teacher's manual, cost $245. (ClassWide Peer Tutoring: WWC Intervention Report (2007))
