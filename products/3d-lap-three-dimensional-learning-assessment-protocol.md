## Description
A protocol developed by Cooper and colleagues for evaluating the potential of educational assessment tasks to elicit three-dimensional student responses in STEM and other contexts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **3D-LAP: Three-Dimensional Learning Assessment Protocol for exam items**: The 3D-LAP is a protocol for evaluating assessment tasks. It "allows us to determine whether an assessment task has the potential to elicit a 3D response from students". The authors previously used it to code over 4,000 examination questions from midterm and final exams in introductory courses to evaluate change in 3D assessment over time, and report it is a useful tool for characterizing the extent of transformation focused on student use of knowledge in the context of Core Ideas. Its limitation, stated by the authors, is that it measures only the potential of an item, not whether students actually engage in 3DL. (Cooper M. M. et al. (2024))
- **Three Dimensional Learning Assessment Protocol (3D-LAP) for analyzing assessment items**: The 3D-LAP is a parallel instrument under development to determine whether assessment items contain scientific practices, crosscutting concepts, and disciplinary core ideas. It analyzes exams, homework, and clicker questions collected from each section of every introductory course, with collection planned to continue for several years. The article notes that "The coding structure for this tool is being ﬁnalized." (James T. Laverty et al. (2014))
- **Three-Dimensional Learning Assessment Protocol (3D-LAP)**: The 3D-LAP is a "soon-to-be released research instrument that can be used to both design and characterize assessment items." Its "principle components ... are sets of criteria that have been developed for each scientiﬁc practice, crosscutting concept, and core idea." It uses the Framework's lists of practices and crosscutting concepts, while core ideas for college physics were generated locally by Michigan State Physics and Astronomy faculty. Practice criteria focus on required actions ("verbs"), whereas crosscutting-concept and core-idea criteria include subconstructs that must appear in the question stem or correct answer. An item must meet all criteria for a dimension to count as Aligned. (James T. Laverty et al. (2015))
- **3D-LAP: a protocol for characterizing assessment tasks' potential to elicit three-dimensional learning**: The Three-Dimensional Learning Assessment Protocol (3D-LAP) is a coding protocol that describes criteria for each scientific practice, crosscutting concept, and core idea defining what is required for an assessment task to elicit that construct. It was developed by an interdisciplinary team of disciplinary experts and discipline-based education researchers in biology, chemistry, and physics through iterative negotiation against real assessment tasks. Each scientific practice includes 2–4 criteria all of which must be met; each crosscutting concept has a brief description; each core idea has a list where only one item must align. (Laverty JT et al. (2016))
