# KAR3L trivia flashcard study-log dataset

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
KAR3L is a publicly released dataset of 123,143 content-aware flashcard study logs from 543 adult trivia learners using the authors' web and mobile flashcard application.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **KAR3L trivia flashcard study-log dataset (123,143 logs from 543 users)**: A released dataset for training content-aware student models, collected via a web and mobile flashcard app built by the authors. Flashcards come from QANTA trivia questions spanning eleven topics including literature, history, fine arts, pop culture, and mythology, totaling 23,918 unique flashcards. The article reports that "Over four months, 543 users gave 123,143 study logs", each log containing the card studied, past study data, and a correctness label. Unlike prior datasets, it releases flashcard content for public use. (Matthew Shu et al. (2024))
