## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **WCAG 2.0 four-principle framework of web accessibility (perceivable, operable, understandable, robust)**: The World Wide Web Consortium's Web Content Accessibility Guidelines organize web accessibility into four principles: "perceivable, operable, understandable, and robust". Perceivable content offers multiple access and customization modes; operable content offers multiple control and navigation modes; understandable content is readable and helps users avoid mistakes; robust content works with multiple browsers and assistive technologies. Each principle contains guidelines delineated by success criteria rated at Level A, AA, and AAA, with levels assigned based on impact on accessibility and implementation difficulty. The article uses this framework, and Section 508's Level A/AA requirement, as the standard against which physics webpages were audited. (Scanlon et al. (2019))
