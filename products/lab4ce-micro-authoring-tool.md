## Description
Lab4CE is a micro-authoring tool developed by Julien Broisin and colleagues for designing and specifying configurable remote computer-science experiments.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Lab4CE micro authoring tool for experiment design**: An authoring tool for instructors that addresses the micro learning design capacity the authors find lacking in other remote labs such as Go-Lab's Graasp.eu. Designers first fill a form specifying learning metadata (name, description, pedagogical objective, availability period), then design the experiment's topology at two granularity levels by dragging Computer, Router and Switch components, each with adaptable default software configurations. Publication translates the configuration into OpenStack format, guaranteeing "independence between the authoring tool and the virtualization software". (Julien Broisin et al. (2017))
