# PACT (Promoting Adolescents' Comprehension of Text)

## Description
PACT is a social-studies curriculum package developed by Jeanne Wanzek and colleagues that integrates supported text-based learning, discourse, and application practices into middle-school content units.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PACT (Promoting Adolescents' Comprehension of Text) instructional practices for middle school social studies**: PACT is a set of text-based instructional practices integrated within social studies content units. It is "intended to be integrated within social studies content units to increase engagement of all students in supported text-based learning, discourse-based processes, and application of newly learned content." In this study teachers delivered three 10-day U.S. history units using semi-scripted lesson plans, with coaches supporting implementation at least weekly. The program was evaluated in a class-level randomized trial against typical instruction using the same content. (Jeanne Wanzek et al. (2019))
