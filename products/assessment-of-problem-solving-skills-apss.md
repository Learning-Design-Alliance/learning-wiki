# Assessment of Problem Solving Skills (APSS)

## Description
A scenario-based open-ended assessment developed by Jennifer M. Bekki and colleagues to measure learners’ ability to describe and apply interpersonal problem-solving skills using rubric-scored responses.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Assessment of Problem Solving Skills (APSS) scenario-based instrument and scoring rubrics**: The APSS is an open-ended, scenario-based assessment containing two questions: the first asks respondents to "list the steps taught by the CareerWISE learning environment to tackle interpersonal problems", and the second, a performance assessment, asks participants to describe how they would apply interpersonal problem solving skills to a realistic graduate-student scenario. Two versions (A and B) present different scenarios derived from focus groups with the target population. Responses were scored with rubrics using four-point coding schemes; inter-rater reliability via Krippendorff's alpha was 95% CI [0.48, 0.58] for Question 1 and 95% CI [0.71, 0.81] for Question 2. (Jennifer M. Bekki et al. (2014))
