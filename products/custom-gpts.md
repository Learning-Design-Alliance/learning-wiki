# Custom GPTs

## Description
Custom GPTs are OpenAI's user-configurable GPT applications that let educators and students create specialized assistants by setting instructions and supplying reference files.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Customised GPTs system integrating GPT-4 with retrieval-augmented generation of the classroom dialogue analysis scheme**: The authors built a customised GPTs application (OpenAI's "My GPTs") that codes classroom dialogue automatically. The system "integrated the GPT-4.0 API" and used "retrieval-augmented generation (RAG), we vectorized the classroom dialogue analysis scheme (CDAS) and fed these knowledge vectors into GPT-4", with a tuned prompt-engineering mechanism providing category definitions and inclusion/exclusion rules. It annotates dialogue turns autonomously under the same coding scheme used by human experts. (Long et al. (2024))
- **A bespoke custom GPT built on GPT-4-family LLMs with a standardised rubric and curated pharmacology references for SAQ feedback**: The article developed "a bespoke custom generative pre-trained transformer (GPT)-based model hosted on the ChatGPT platform" configured specifically for the project, built using OpenAI GPT-4-family large language models (primarily GPT-4o and GPT-4.1 variants). It was programmed to generate feedback using a standardised rubric assessing four pharmacology-relevant domains and was provided with curated reference materials including SmPC-derived content for the top 100 drugs. The model was constrained to provide similarly structured components of feedback, explicitly correcting misconceptions and providing references for major corrections. (Stephenson E et al. (2026))
- **GPT Reproductive Physiology Companion: a customized GPT-4o AI tutoring tool for medical students**: A customized AI companion built on the GPT-4o platform, developed using a six-step approach for customized GPTs in medical education. It was configured to align responses with the module's learning outcomes, competency framework, and national licensing examination (SMLE) blueprints. Key features included "summarized and simplified explanations of complex topics," step-by-step breakdowns of physiological pathways, mnemonic aids, clinical correlations (e.g., PCOS, infertility), audio voice-overs based on Guyton & Hall, and interactive formative assessments (MCQs and MEQs) with tiered feedback. (Elsamanoudy Ayman; Alhazimi Awdah; Hassanien Mohammed; Almarabheh Amer; Al-Aqidi Sultan; Alwalidi Raghad; Alrefaie Zienab zeinab (2026))
