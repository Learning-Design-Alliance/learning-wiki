## Description
SQL-Tutor is an intelligent tutoring system developed by Antonija Mitrovic and colleagues for practicing SQL Select query writing through problem solving, graduated feedback, hints, and solutions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SQL-Tutor, the first constraint-based tutor for SQL querying**: SQL-Tutor is an intelligent tutoring system for the SQL Select statement, designed as a complement to database courses that assumes students have some knowledge from lectures and labs. "The system provides numerous problem-solving opportunities in the context of various databases", which students can freely choose among. Its interface reduces working memory load by displaying the database schema and problem text, and it provides feedback at several levels of specificity, from simple correctness flags to hints and full solutions. The system has been in regular use in university database courses since the late 1990s. (Mitrovic et al. (2015))
