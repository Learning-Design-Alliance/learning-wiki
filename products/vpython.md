# VPython

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
VPython is an open-source programming environment that enables learners to construct and animate three-dimensional computational models while abstracting much of the graphics and interface implementation.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VPython open computational programming environment used for introductory mechanics modeling**: VPython is an open computational environment in which students write the program statements needed to model a physical system — creating objects, assigning variables, and performing numerical calculations — while VPython handles model-construction details such as drawing graphics invisibly to students. The article notes it "supports full three-dimensional graphics and animation" without requiring students to learn much object-oriented programming, and that it is open-source, freely available, and accessible on all major computing platforms. In this implementation it was the environment in which lab-built models were written and altered on homework. (Caballero et al. (2012))
- **VPython programming environment with the PhysUtil module for student computational modeling**: VPython is based on Python and "provides an environment to write simple programs that yield robust three-dimensional simulations"; it was designed to limit the programmatic statements needed for highly visual simulations. The authors developed the publicly available PhysUtil module to further limit code-writing and add Modeling Instruction features such as motion maps, adding four Python classes: PhysAxis, PhysTimer, MotionMap, and PhysGraph, each requiring a single initialization line and a single update line in the calculation loop. (Caballero et al. (2012))
- **Python/VPython Mercury perihelion simulation code with online repository and template files**: A step-by-step Python/VPython implementation of the Mercury simulation: parameter definitions in natural units, an evolve_mercury update function, a while-loop evolution, sphere and trajectory visualization, and perihelion extraction via minimal distance detection and angle computation. The article states "We provide online instructions for setting up Python and VPython on diﬀerent operating systems" and that Appendix A provides a working example with template files online. No prior knowledge of Python or any other programming language is required. (C. Körber et al. (2018))
- **Glowscript VPython as the programming language for computational modeling in physics classrooms**: Glowscript VPython is "a specialized form of Python and the \"Visual\" 3D graphics module that can be written and executed in a browser, thus, decreasing the barrier to entry to writing scientific programs". The language is "specifically designed for use in physics classrooms" and suits modeling motion, collisions, and other spatial features; visual animation is emphasized as a way of helping students learn physics. (Daniel P. Weller et al. (2021))
- **Glowscript: a web-based visual Python environment with built-in graphics and graphing for teaching simulation**: Glowscript (web VPython) is a web-based form of visual Python that runs in a standard browser and includes "a rich selection of visual objects and a graphing capability that can be used for displaying the results of a numerical simulation while the simulation is running." The authors use it in an undergraduate computational biology course because its dynamic plotting provides students with immediate feedback, its programs run without installation, and students "can easily embed their simulations in external websites." (Joshua G. Schreibeis et al. (2020))
- **VPython 3D visualization library for introductory physics simulations**: VPython is a Python library used in the Physics Playground in Python course to create 3D animations and visualizations of physical systems. The article states: "To enhance their engagement, students use VPython, a Python library that makes it easy to create 3D animations and visualizations of physical systems." Students use it to build simulations from a bouncing ball to planetary orbits, learning to create canvases, design objects such as spheres and walls, and animate them. (Maria C. Babiuc Hamilton (2024))
