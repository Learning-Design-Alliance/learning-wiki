# VPython

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
VPython is an open-source programming environment that enables learners to construct and animate three-dimensional computational models while abstracting much of the graphics and interface implementation.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VPython open computational programming environment used for introductory mechanics modeling**: VPython is an open computational environment in which students write the program statements needed to model a physical system — creating objects, assigning variables, and performing numerical calculations — while VPython handles model-construction details such as drawing graphics invisibly to students. The article notes it "supports full three-dimensional graphics and animation" without requiring students to learn much object-oriented programming, and that it is open-source, freely available, and accessible on all major computing platforms. In this implementation it was the environment in which lab-built models were written and altered on homework. (Caballero et al. (2012))
