# MCAT (Munich Cephalometric Application for Training)

> **Product or Programme** · [All products and programmes](index.md)

## Description
An open-source Python application released via Open Data LMU that uses a pretrained convolutional neural network to support dental students' self-paced cephalometric landmark-tracing practice with automated comparison and deviation feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MCAT: an open-source AI-supported application for self-paced cephalometric tracing practice with automated feedback**: MCAT (Munich Cephalometric Application for Training) is an open-source Python application, built on a pre-trained convolutional neural network for landmark recognition, through which "students had the opportunity to manually trace 16 cephalometric reference points on a lateral cephalometric image and compare their position with the points predicted by the pre-trained model". It provides ten training cephalograms across five dentoskeletal anomaly types, visual side-by-side display of student versus model points, and a quantitative diagram of absolute x/y deviations. It runs on students' personal computers, supporting location-independent, self-paced training, and was released via Open Data LMU. (H. Sabbagh et al. (2025))
