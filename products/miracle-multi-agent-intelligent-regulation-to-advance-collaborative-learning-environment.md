# MIRACLE (Multi-Agent Intelligent Regulation to Advance Collaborative Learning Environment)

## Description
MIRACLE is a GPT-powered multi-agent system developed by Shuang Li et al. for real-time planning, monitoring, reflection, knowledge support, and emotional encouragement during collaborative learning in the CocoNote platform.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MIRACLE multi-agent system for socially shared regulation of collaborative learning**: MIRACLE (Multi-Agent Intelligent Regulation to Advance Collaborative Learning Environment) is an orchestrated multi-agent system implemented in the CocoNote collaborative platform, powered by GPT-5-Nano, combining reactive metacognitive agents with one proactive emotional-support agent. Reactive agents use a hierarchical architecture in which a Boss Agent "intelligently routing student requests to four specialized agents: the Planning Agent, Monitoring Agent, Reflection Agent, and Knowledge Agent". The proactive Lightbulb Agent monitors chatroom and whiteboard activity for triggering events such as inactivity or frustration and flashes a lightbulb icon to intervene. All agents access shared real-time data from chatroom and whiteboard for contextually grounded responses. (Shuang Li et al. (2025))
