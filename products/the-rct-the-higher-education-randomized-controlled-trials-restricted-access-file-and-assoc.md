# THE-RCT: The Higher Education Randomized Controlled Trials Restricted Access File and associated public benchmark database

## Description
A dataset created by MDRC and housed at ICPSR that contains student-level data from postsecondary randomized controlled trials alongside a public study-level effect-size benchmark database.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **THE-RCT restricted-access database and the public empirical-benchmarks effect-size dataset**: THE-RCT RAF is MDRC's restricted-access student-level database of postsecondary RCTs conducted 2003–2019, housed at ICPSR, containing design indicators, student characteristics, and semester-level outcomes (enrollment, credits, degree completion) from college records, the National Student Clearinghouse, and baseline surveys. From it the authors built a public-use dataset of study-level effect estimates: "A public database with effect sizes is available to researchers." The full sample includes "39 postsecondary interventions and a total of 65,604 students." (Michael J. Weiss et al. (2023))
