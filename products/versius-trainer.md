## Description
Versius Trainer is CMR Surgical’s virtual simulation software for training and assessing robotic-console skills through proficiency-based surgical tasks and performance metrics.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Versius Trainer proficiency-based simulation with expert-benchmarked performance metrics**: The Versius Trainer is the virtual simulation component of the pilot pathway, consisting of 16 proficiency-based tasks such as instrument navigation, endoscope control, peg transfer and running suturing. Each task has "measurable metrics such as the combined instrument tip path length to reaching the object, combined instrument angular path and combined instruments out of view", and performance scores are "compared with benchmarks set to the average performance of experts completing the training tasks". Trainees' attempts per task were tracked and analysed in the pilot evaluation. (Al-Ani Mohammed et al. (2025))
- **CMR Versius immersive virtual reality headset training modules for operating room set-up**: A set of six VR headset modules for the CMR Versius robotic platform that let participants "complete 'learn mode' and subsequently 'practice mode' for each of the 6 modules to set up the robotic system in a simulated virtual reality operating room environment". Modules cover surgeon console preparation, connecting bedside units, draping, instrument identification and attachment, port training, and entering surgical mode. Unlike most surgical simulators, they focus on system set-up rather than surgical technique, using the platform's open console and modular design. (Eley Catherine L. et al. (2024))
