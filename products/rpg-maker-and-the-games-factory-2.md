## Description
RPG Maker and The Games Factory 2 are game-creation applications that provide non-programmers with integrated tools for designing video games, including serious games.

- **Game creation toolkits enabling non-programmers to build serious games**: For engineering students without programming knowledge, who dominated the classes, the authors offered simple-to-use entertainment video game design software like RPG Maker or The Games Factory 2, which they call "game creation toolkit" applications because they incorporate all the functions needed to design video games. Programming students instead used Java or C++. Most student games in Table 1 were made with The Games Factory 2, with others in RPG Maker XP, Flash CS4, or Java. (Damien Djaouti; Julian Alvarez (2012))
