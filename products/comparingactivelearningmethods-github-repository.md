> **Product or Programme** · [All products and programmes](index.md)

## Description
A public repository maintained by Meagan Sundstrom and collaborators containing de-identified study data, R analysis scripts, and course-network visualizations for replicating their multi-institution active-learning comparison.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open repository of de-identified data and analysis scripts for the multi-institution active learning comparison**: The authors released all de-identified study data and analysis scripts in a public GitHub repository, stating: "All de-identified data used in this study can be found at https://github.com/msundstrom33/ComparingActiveLearningMethods.git." The repository supports replication of the Hedges' g pooling, temporal exponential random graph models, and Latent Profile Analysis reported in the article, and provides course network visualizations. (Meagan Sundstrom et al. (2025))
