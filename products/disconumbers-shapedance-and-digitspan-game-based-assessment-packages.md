# Disconumbers, Shapedance, and Digitspan game-based assessment packages

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A package of serious games developed for assessing non-social cognitive abilities such as working memory, visuospatial ability, and math-based memory in job-selection contexts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Game-based assessment packages (Disconumbers, Shapedance, Digitspan) measuring non-social cognitive ability**: The study used two packages of serious games measuring cognitive ability: Disconumbers, a "memory and math-based game"; Shapedance, a "visuospatial ability task similar to the Mental Rotation task"; and Digitspan, a memorization game similar to the digit span task on the Wechsler Adult Intelligence Scale. Scores range from zero to five, are true interval scores, and games progress through timed levels with increasing challenge. Each game is a serious game intended not to entertain but to make a functional task more engaging. (Examining the Use of Game-Based Assessments for Hiring Autistic Job Seekers)
