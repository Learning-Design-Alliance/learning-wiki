## Description
Blogs are user-managed Web 2.0 publishing platforms that support chronological posting, archived hypermedia content, commenting, and collaborative educational communication without requiring programming or database expertise.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Blogs as educational Web 2.0 tools with four defining features**: Blogs are Web 2.0 tools whose educational use the review examines. The article defines them by four features: "(1) reverse chronological order, (2) archival o f posts, (3) hypermedia content, and (4) ease of use". Ease of use is described as one of the keys for the popularity and fast spreading of blogs, since a blog can be created and managed without any specific knowledge in programming and databases. Other potential characteristics include a search engine, multi-user collaboration with different roles, and posting of comments for third-party users fostering dialog and feedback with the internet community. (Carlos R. del Blanco (2018))
