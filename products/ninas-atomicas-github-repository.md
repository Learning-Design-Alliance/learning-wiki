# Niñas Atómicas GitHub repository

> **Product or Programme** · [All products and programmes](index.md)

## Description
An openly released Niñas Atómicas workshop package containing bilingual muon-detector assembly instructions, particle-physics learning materials, Python and Google Colab programming tutorials, example scripts, and experimental data for tutors, educators, and outreach groups.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Niñas Atómicas GitHub repository with detector assembly manual, particle physics handbook, and Python/Colab scripts**: The initiative releases its materials openly at https://github.com/gfcottin/Atomicas. The article states "A detector assembly manual and particle physics handbook created by our tutors can be found in [24]", alongside a step-by-step assembly tutorial in Spanish and English, example Python script files, and a Google Colab quick-start tutorial in Spanish. Data taken with the muon detectors can also be found in the repository, supporting replication of the workshop's experiment and lessons by other groups. (Giovanna Cottin et al. (2026))
