# ALICE MasterClass

## Description
ALICE MasterClass is an ALICE Collaboration and International MasterClasses programme in which high-school students use ROOT and ALICE software to analyse prefiltered real heavy-ion collision data and study quark–gluon-plasma observables.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Event Display plus injectable Widget architecture for multi-exercise outreach software**: The new ALICE MasterClass framework identifies common elements shared by all measurements. The main component is an Event Display handling 3D detector and track visualisation; selecting a measurement activates an Exercise object that can "inject" Widget elements such as a particle mass calculator or particle count histogram, dynamically modifying the GUI for each task. A VSD Reader handles data-file reading and a GUITranslation object serves translated text. (Łukasz Graczykowski et al. (2020))
