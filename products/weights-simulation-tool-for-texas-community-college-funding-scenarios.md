## Description
A simulation tool the study team developed alongside the cost function analysis. It "allows policymakers to analyze different funding scenarios based on assumptions about student need factors, institutional contexts, and desired outcomes to generate cost projections." Policymakers can adjust the outcome target, which affects projections of necessary spending, and apply the estimated weights to annually collected data to determine adequate funding levels per student. REL Southwest supported the Texas Higher Education Coordinating Board in using the tool in 2022.
