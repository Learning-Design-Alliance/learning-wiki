GenAI-Learning-Outcomes GitHub repository¶

Product or Programme · All products and programmes
Evidence · no claims cited

Description¶

A repository released by Jingwei Yi et al. containing analysis-result datasets, course materials, study materials, and experimental code for replicating and extending their GenAI learning-outcomes research, with raw participant-level data restricted to approved collaborators.

Components¶

  • Public analysis-result datasets, course materials, and code repository for the GenAI learning-outcomes study: The article releases supporting research artifacts for replication: "The analysis-result datasets supporting the findings, together with the course materials and other materials provided through the study platform, are publicly available athttps://github.com/yjw1029/GenAI-Learning-Outcomes." The code applied in the experiments is publicly available at the same repository. Raw participant-level experimental data are not publicly released because consent and ethics approvals restrict open release, with controlled access available to approved collaborators. (Jingwei Yi et al. (2026))
