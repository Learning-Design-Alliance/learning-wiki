## Description
A configurable learning-by-teaching web application developed by the authors that supports natural-language teaching dialogues between adult learners and an agent across classification tasks.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Curiosity Notebook with extended natural language teaching modality and mixed-initiative interaction**: The Curiosity Notebook is "a highly conﬁgurable, learning-by-teaching web application, which supports a natural language teaching dialog on a range of classiﬁcation tasks". This work extends it with a Snips NLU model parsing free-form teaching inputs into intents and slot values mapped to 30 rock features, and adds a mixed-initiative model where the agent initiates 25% of teaching actions and selects the focus rock 50% of the time. Users teach via Describe, Explain, and Compare buttons, check the agent's notebook, quiz it, and correct errors. (Rachel Love et al. (2025))
