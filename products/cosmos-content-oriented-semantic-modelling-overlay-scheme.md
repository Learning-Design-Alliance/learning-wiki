# COSMOS: Content Oriented Semantic Modelling Overlay Scheme

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A multimedia content-modelling framework developed by Angelides et al. that uses syntactic, semantic, and temporal m-frames, supported by COSMOS-DL and COSMOS-QL, to structure and query educational multimedia content.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **COSMOS: Content Oriented Semantic Modelling Overlay Scheme**: COSMOS is a content-modelling scheme for multimedia that uses the multimedia frame (m-frame) as its basis, a 'slot-and-filler' type structure with perspectives and instances. It defines three m-frame types: syntactic m-frames (SYMs) for spatial relationships, semantic m-frames (SEMs) for events, actions and object properties, and temporal m-frames (TEMs) for temporal relationships using Allen's 13 primitives. It has been used to develop several educational multimedia systems. (Angelides et al. (2001))
