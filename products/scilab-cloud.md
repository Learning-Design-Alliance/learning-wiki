# Scilab Cloud

> **Product or Programme** · [All products and programmes](index.md)

## Description
Scilab Cloud is a Scilab service that lets users create and publish interactive documents executed server-side and accessed through a web browser.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Scilab Cloud service for creating and publishing interactive Scilab documents, without Xcos access**: Scilab Cloud (http://scilab.io/services/development/web-application/) is a service for creating and publishing interactive documents whose software part runs on the server side, saving resources of the mobile Internet device; access is via any Internet browser. The article compares it to Wolfram Demonstrations Project but notes that, unlike the latter, all users can publish demonstrations, matching the SageMathCloud document-distribution model. However, the article states "Проте Scilab Cloud не надає доступ до модуля Xcos", which motivated the Xcos on Web project. (Y. O. Modlo (2015))
