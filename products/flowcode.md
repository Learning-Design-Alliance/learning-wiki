# Flowcode

## Description
An AI-powered web-based creative-coding environment developed by Tseng et al. that combines code editors, live previews, code-structure flowcharts, and constrained LLM explanations to support novice learners iterating on web animations.

### Claims

- [An LLM-generated flowchart linking semantic feature descriptions to code across HTML, CSS, and JS files supports novice creative coders' orientation, navigation, and code understanding](../claims/flowchart-supports-code-orientation-navigation.md) [+W]
- [In the pilot workshop, the LLM unreliably produced fill-in-the-blank snippets, often returning complete code solutions instead](../claims/pilot-llm-unreliable-fill-in-blank.md) [-W]
