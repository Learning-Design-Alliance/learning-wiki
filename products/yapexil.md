# YAPeXIL

> **Product or Programme** · [All products and programmes](index.md)

## Description
YAPeXIL is a JSON-based programming-exercise serialization format developed by Alberto Simões et al. for representing varied exercise types, resources, tests, tools, metadata, and automatic assessment in training environments.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **YAPeXIL exercise format supporting varied programming exercise types**: YAPeXIL is a programming exercise serialization format, based on PExIL, that changed the serialization format to JSON and supports "different types of programming exercises such as solution improvement, bug fix, gap filling, block sorting, and spot the bug". Like other formats, it follows a structure of an XML manifest referring to resources such as problem statements, images, input/output test files, validators and solution implementations, and allows inclusion of metadata, instructions, tests and tools. (Alberto Simões et al. (2020))
