## Description
PICUP provides a freely available library of peer-reviewed computation-infused physics activities, including instructor guidance, exercises, code templates, and solutions for courses from high school through graduate study.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PICUP Collection of peer-reviewed computation-infused physics Exercise Sets**: The PICUP Collection of Exercise Sets is a freely available online library of computation-infused physics learning activities, containing "over 60 peer-reviewed computation-infused activities for use in various physics courses from high school through graduate study". Each Exercise Set follows a required template including Description, Learning Objectives, Instructor's Guide, Theory, optional Experiments, Exercises, Pseudocode, Code Templates, Solutions, and Completed Code, and is peer reviewed by PICUP editors and referees on educational quality, consistency, curriculum appropriateness, and correctness. At the time of the article's submission the Collection included 62 Exercise Sets. (W. Brian Lane (2021))
