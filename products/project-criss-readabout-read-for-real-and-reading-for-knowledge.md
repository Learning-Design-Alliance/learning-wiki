# Project CRISS®, ReadAbout, Read for Real, and Reading for Knowledge

## Description
A set of four named supplemental fifth-grade reading-comprehension curricula designed for use alongside schools' existing core instruction, evaluated by James-Burdumy et al. (2010).

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Four supplemental reading comprehension curricula evaluated in a school-randomized design**: The element is the set of four fifth-grade supplemental reading comprehension curricula tested in the evaluation: Project CRISS, ReadAbout, Read for Real, and Reading for Knowledge. Schools were randomly assigned to use one of the four treatment curricula or to a control group, with teachers developing their own ways of fitting the assigned curriculum into daily schedules. The report states the curricula "were designed to supplement—not replace—the core curriculum being used by each teacher." (James-Burdumy et al. (2010))
