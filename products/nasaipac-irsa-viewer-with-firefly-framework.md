# NASA/IPAC IRSA Viewer with Firefly framework

> **Product or Programme** · [All products and programmes](index.md)

## Description
A browser-based interface operated by NASA/IPAC Infrared Science Archive for querying, filtering, visualizing, and analyzing astronomical catalog tables, images, and plots.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **NASA/IPAC IRSA Viewer with Firefly framework as a web-based interface for classroom astronomy data analysis**: The NASA/IPAC Infrared Science Archive provides a browser-based interface to publicly available astronomical datasets, built on the Firefly framework which "allows large data tables, rendered FITS images, and embedded plots to coexist in a single browser window". Students query the Gaia catalog via target names resolved through SIMBAD, filter tables with mathematical expressions, and plot catalog fields to produce color-magnitude diagrams. The article uses it as the professional tool for a scaffolded high school cluster activity. (Newland (2025))
