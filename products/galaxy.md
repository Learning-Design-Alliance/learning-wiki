# Galaxy

## Description
Galaxy is an open, web-based bioinformatics analysis platform developed and maintained by the Galaxy Project community, providing browser-accessible tools, workflows, datasets, histories, and visualizations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Galaxy platform for browser-based bioinformatics analysis in distance education**: The Galaxy project is a web-based framework for bioinformatics analysis which 'enables students without programming and system administration competences to perform computational analysis through the web browser'. It 'includes thousands of bioinformatic tools, integrated into an interface that allows connecting tools, setting tool parameters, and sharing datasets, histories, workflows, and visualizations', and integrates a community-driven teaching framework with training materials across bioinformatics domains. (Gallardo-Alba Cristóbal et al. (2021))
