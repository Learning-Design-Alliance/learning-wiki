# PhysicsApplet template and nine example applets

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A Java software package released by Michael E. Peskin containing a reusable PhysicsApplet template and nine computational-physics example applets for instructors and upper-division physics students.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Software distribution of nine example applets plus the PhysicsApplet template, released as a tar file with the eprint**: The article distributes Java code as a tar file posted with the eprint, unpacking to ten directories: Templates containing PhysicsApplet.java, and nine example applet directories. Each directory contains the student version B.java, the GUI parent BGUI.java, an html file, and a completed working version myB.java. The nine applets cover Laplace, Dielectric, Magnet, FourierLab (including a Fast Fourier Transform implementation), Wave, Disperse, Bessel, Antennae and Diffraction. (Michael E. Peskin (2003))
