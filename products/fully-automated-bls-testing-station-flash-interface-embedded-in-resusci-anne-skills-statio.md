# Fully automated BLS testing station (Flash interface embedded in Resusci Anne Skills Station software)

> **Product or Programme** · [All products and programmes](index.md)

## Description
A prototype automated assessment station developed by Mpotos et al. that uses a Flash interface, Resusci Anne Skills Station software, and a sensor-equipped torso manikin to guide and record medical students’ basic life-support performance.
