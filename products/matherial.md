## Description
A two-player interactive mathematics game created by Es-Sajjade et al. in which fifth- and sixth-grade learners solve and create equations while competing in parallel games.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MATHERIAL game design based on CLT and GDT**: MATHERIAL is a two-player interactive math game in which players solve and create mathematical equations while competing in parallel games. The design drew on cognitive load theory to minimize extraneous load and maximize intrinsic load, and on game design theory principles (identity, immersion, interactivity, increased complexity, informed teaching, and instruction). The game avoided animations to draw more on working memory capacity and used player status development instead of sophisticated avatars. (Es-Sajjade et al. (2020))
