# Circadian Performance Simulation Software (CPSS)

## Description
A software application developed by the CPSS research team that models minute-by-minute alertness and performance from work, sleep, and light schedules for evaluating resident and other shift-work schedules.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Circadian Performance Simulation Software (CPSS) for predicting resident performance and alertness minute-by-minute**: The CPSS is a software application implementing mathematical models of the effect of light on the circadian pacemaker and linked models of performance and alertness. As the article states, "it predicts performance and alertness for every minute that an individual is awake during the schedule," with output values from 0 (worst) to 100 (best). Version 1.2 was used to simulate the five schedules, with light set at 150 lux when awake and 0 lux when asleep. (Klerman Elizabeth B. et al. (2016))

### Claims
