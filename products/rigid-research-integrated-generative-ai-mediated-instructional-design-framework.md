# RIGID (Research-Integrated, Generative AI-Mediated Instructional Design) framework

## Description
A conceptual framework proposed by Kwak et al. for research-integrated instructional design in which generative AI coordinates heterogeneous knowledge across the instructional-design lifecycle while human experts retain interpretive and contextual judgment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **The RIGID framework integrates learning sciences research across the full instructional design lifecycle with generative AI as mediating mechanism**: RIGID (Research-Integrated, Generative AI-Mediated Instructional Design) is a unified framework organized around a typical ID process of Analysis, Design, Implementation, and Evaluation, reflecting an iterative cycle in which evaluation insights inform subsequent analysis and design. The article states it is "a unified framework that integrates LS research across ID workflows spanning analysis, design, implementation, and evaluation phases, while leveraging generative AI to mediate this integration at each stage." It positions AI as a coordination layer that synthesizes heterogeneous knowledge sources while instructors retain central interpretive roles. (Kwak et al. (2026))
