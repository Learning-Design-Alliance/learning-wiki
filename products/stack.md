# STACK

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
STACK is an open-source computer-algebra-based assessment system that interprets and automatically grades mathematical responses and provides feedback, commonly delivered through Moodle.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Moodle STACK front-end for automated grading of symbolic mechanics answers**: The front-end uses the Moodle learning management system with the STACK question type, an "open-source automatic assessment system based on the computer algebra system Maxima, which allows the interpretation and modification of mathematical expressions." Assignments are imported as a question pool via XML, distributed randomly among students, and graded automatically. Students enter answers in a web interface with multiple accepted syntaxes and receive direct feedback on how STACK interprets their input before submission. (Gfrerer et al. (2023))
