## Description
A benchmark released by Zhenlong Dai et al. containing learner buggy programs, correct versions, ground-truth bug descriptions, a large retrieval database, and automated code-repair and explanation evaluation tools for programming-learning research.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LPR-Bench: benchmark of learner buggy programs, bug descriptions, and retrieval database**: LPR-Bench is a benchmark for the LPR task that "includes students' buggy programs paired with their correct versions, detailed bug descriptions, and a large-scale retrieval database", plus an automatic evaluation framework for executing code and assessing bug descriptions. Its test set contains 407 challenging samples from 306 users across 65 programming problems with an average of 89 test cases per problem, filtered to remove overly simple samples. The retrieval database contains 21,584 users and 274,349 submissions across 110 problems, collected from CodeNet, with bug descriptions generated by GPT-4o and refined by three programmers with five years of experience. (Zhenlong Dai et al. (2026))
