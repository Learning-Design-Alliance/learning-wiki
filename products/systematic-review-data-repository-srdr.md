## Description

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Systematic Review Data Repository (SRDR) as a scaffolding tool for teaching data extraction and meta-strategic skills**: SRDR is a free, web-based, customizable data extraction tool the article uses to teach meta-strategic skills in evidence analysis instruction. The article describes "the main website providing a free, customizable data extraction tool" and notes that although SRDR was not deliberately designed for teaching inexperienced students, it "incorporate[s] user supports (e.g., tutorials, wizards)" and provides "constructive scaffolding". Its tabular structure, customizable fields, and Abstrakr consensus feature scaffold synchronic, diachronic, and iterative evaluation during extraction. (Parrott J. Scott (2015))
