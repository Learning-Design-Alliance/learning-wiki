# Aladdin machine learning code and CAD design-challenge data artifacts

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Jasmine Singh et al.'s released package provides CAD design-exercise and design-challenge data, example JSON action logs, a log-cleaning and error-highlighting parser, and Python code for predicting student design success.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Released machine learning code and design-challenge data artifacts for predicting student CAD success**: The article releases supporting artifacts: the small design exercise and design challenge journals students completed, an example JSON action log from the course, a JSON parsing tool built to "print out and highlight specific errors in each file," and the project's Python code, "found at https://github.com/singh486/Aladdin_machine_learning." The code implements scikit-learn linear and logistic regression models using tallied and sequenced design actions with an 80-20 train-prediction split. (Jasmine Singh et al. (2021))
