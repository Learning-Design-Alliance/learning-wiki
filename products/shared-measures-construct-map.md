## Description
The instrument is a one-page construct map titled "Shared Measures Construct Map" within a practical guide for measurement and progress monitoring of ELA and math curriculum shifts. It prints six numbered dimensions, each with a construct statement and lettered sub-constructs, and a KEY that defines "(Sub-constructs)", marks "Unidirectional" and "Bidirectional" relations, and flags "Items specific to ELA and Math". It is designed so instructional leaders can monitor implementation progress across the system.

- Users must interpret dimensions together with the KEY, which distinguishes sub-constructs, unidirectional and bidirectional relations, and ELA/math-specific items
#### Constraints
