# Semester-long simulated-MOOC EEG dataset from an 11-lesson biology course

## Description
A dataset of semester-long, stage-labeled 14-channel EEG recordings from six undergraduates completing lecture, virtual-lab, and quiz activities in an 11-lesson simulated-MOOC biology course, released by Hui Xie et al. for machine-learning and learning-stage analysis.

### Claims
