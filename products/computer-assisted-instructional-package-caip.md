# Computer Assisted Instructional Package (CAIP)

## Description
A researcher-developed interactive, self-instructional HTML and Flash biology package presenting modular ecology lessons for Nigerian senior secondary students.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Computer Assisted Instructional Package (CAIP) on ecology for Nigerian senior secondary biology**: The CAIP was a self-instructional, interactive biology package developed by the researchers with a professional programmer using Dreamweaver and Flash, written in HTML with GIF illustrations. It "contained five lessons structured into modules" covering six ecology topics from the Nigerian senior secondary curriculum, used intrinsic programming with reinforcement frames and navigation buttons. Development followed four phases: analysis, design, implementation and validation, including expert validation and a pilot usability evaluation. (Mudasiru Olalere YUSUF et al. (2010))
