## Description
AITS is a web-based intelligent tutoring system developed by Grivokostopoulou et al. for teaching undergraduate AI students search algorithms through theory, examples, visualizations, interactive exercises, tests, and adaptive assessment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AITS: An Intelligent Tutoring System for Teaching Search Algorithms**: AITS is an intelligent tutoring system developed to help students learn and tutors teach search algorithms, a fundamental AI topic. It consists of six main units: Student Interface, Tutor Interface, Automatic Assessment, Test Generator, Learning Analytics, and Domain Knowledge & Learning Objects. Learning is achieved through a wide range of learning activities including theory, examples, visualizations, interactive exercises, and tests. The system adapts test difficulty to individual students using a rule-based expert system. (Grivokostopoulou et al. (2016))
