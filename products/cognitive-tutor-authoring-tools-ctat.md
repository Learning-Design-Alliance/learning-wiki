# Cognitive Tutor Authoring Tools (CTAT)

## Description
CTAT is Carnegie Mellon University's suite of authoring tools for building and deploying example-tracing tutors with little or no programming.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Cognitive Tutor Authoring Tools (CTAT) with integrated SimStudent for intelligent authoring**: CTAT is a suite of software tools that helps authors build Tutoring Interfaces with virtually no programming effort and demonstrate solutions stored as model solutions in a behavior graph. When SimStudent is integrated into CTAT, it learns to solve problems and generates an expert model from the author's tutoring or demonstrations using the Tutoring Interface. The system supports two authoring strategies, Authoring by Tutoring and Authoring by Demonstration, and also allows authors to demonstrate incorrect steps so SimStudent learns buggy production rules. (Matsuda et al. (2015))
