# KLM Form Analyzer (KLM-FA)

> **Product or Programme** · [All products and programmes](index.md)

## Description
KLM-FA is a Windows desktop application that parses web forms, simulates user interactions, and estimates task-completion time using the Keystroke Level Model and Fitts' Law.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **KLM Form Analyzer (KLM-FA) tool for web form design and evaluation**: KLM-FA is a Windows desktop application for web form design and evaluation based on the Keystroke Level Model and Fitts' Law. It 'automatically detects the form elements and presents them in an embedded web form preview', simulates the modeled user's actions to reach and then manipulate each element, and estimates the predicted task completion time; in this study it mediated a graded essay activity. (Katsanos et al. (2018))
