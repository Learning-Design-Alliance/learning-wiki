## Description
HoloAnatomy is a mixed-reality anatomy-learning software platform developed by Case Western Reserve University for use with Microsoft HoloLens headsets.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **HoloAnatomy mixed-reality instruction delivered through Microsoft HoloLens 2 in a non-cadaveric osteopathic anatomy curriculum**: HoloAnatomy, a software platform developed by Case Western Reserve University, delivered through Microsoft HoloLens 2 headsets, was used as a mandatory, face-to-face, biweekly mixed-reality component of first-year anatomy Interactive Learning Sessions. Faculty guide students through "synchronized three-dimensional anatomical models" using a projected faculty view and pointer, alternating guided instruction with self-directed exploration and board-style questions. Each student is assigned an individual device for on-campus sessions and self-directed study. (Lin Joseph et al. (2026))
