## Description
Profy is a deep-learning automated pronunciation-feedback system developed by Kazuki Kawamura that evaluates learner speech against native-speaker data and highlights localized deviations for imitation-based skill practice.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Profy data-driven pronunciation feedback system learned from unannotated audio**: Profy is an automated feedback system for imitation-based skill learning, instantiated for second-language pronunciation. It constructs a deep learning model that "directly learns what constitutes good and poor performance from unannotated audio data", avoiding the annotated error-pattern databases of conventional CAPT systems. The system highlights waveform regions emphasized by the classifier and shows model-derived acoustic distances from native-speaker distributions in latent space, giving learners localized feedback on where their performance deviates. (Kazuki Kawamura (2025))
