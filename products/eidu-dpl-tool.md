# EIDU DPL tool

## Description
The EIDU DPL tool is an offline-capable Android-based digital personalised learning platform developed by EIDU to deliver curriculum-aligned literacy and numeracy content with learner-specific sequencing.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **EIDU DPL tool with LSTM-based personalised learning sequence**: The study was built on an existing DPL tool developed by EIDU, 'pre-installed as an application on low-cost Android devices purchasable for less than $50'. The tool offers learner-facing content aligned to the Kenyan national curriculum, structured by literacy and numeracy domains covering 25 literacy and 23 numeracy substrands across 2,239 units. 'The sequence of these learning units is personalised to support each learner's progression using a Long Short-Term Memory (LSTM) neural network', which functions offline to mitigate low-connectivity issues. (Sun et al. (2026))

### Claims

- [Learners in the Grouped Dashboard partition used the DPL tool significantly more than learners in the List Dashboard and control partitions](../claims/grouped-dashboard-increased-dpl-usage.md) [+M]
- [The Grouped Dashboard partition scored significantly higher on two literacy test units, with no significant differences on the other seven units including all numeracy tests](../claims/grouped-dashboard-literacy-gains-only.md) [+M]
