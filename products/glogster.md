## Description
Glogster is a Web 2.0 platform that enables learners to create and share interactive multimedia posters incorporating text, images, audio, video, and graphics.

## Components

- **Glogster as a Web 2.0 interactive poster tool for differentiated projects**: Glogster is a Web 2.0 tool used to create a glog, "an interactive platform in which users create an onlin e poster containing text, video, images, and graphics". The article states it "can be used easily by students of differe nt ages and learning profiles" and that it has 16 key features providing diverse ways of collaboration. In the study, students in groups of four or five created online interactive posters of assigned Science or English topics, embedding Windows Live Movie Maker videos, text, audio, and images, with product forms including PowerPoint, reports, and research findings. (Ghada M. Awada et al. (2016))
