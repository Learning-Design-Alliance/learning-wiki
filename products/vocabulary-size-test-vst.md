## Description
The Vocabulary Size Test, developed by Nation and Beglar, is a multiple-choice assessment of second-language English learners' written receptive vocabulary size across graded word-family levels.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **80-item Vocabulary Size Test (VST) measuring written receptive vocabulary to the eighth 1000-word level**: The Vocabulary Size Test (Nation & Beglar, 2007) is a multiple-choice instrument measuring second language English learners' written receptive vocabulary size in word-family units. The study used an 80-item version covering "the first 1000 to the eighth 1000-word families of English", with items based on the 10 million token spoken section of the British National Corpus. Each item presents the target word in a short non-defining context sentence with four substitutable options written in restricted defining vocabulary. (McLean et al. (2013))
