## Description
ICU Simulator is a browser-based, client-side educational simulation platform developed by İnan Onur and Akyüz Ali for practicing biomedical-device operation and troubleshooting.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ICU Simulator browser-based multi-device simulation platform**: ICU Simulator is a browser-based, client-side learning environment built with standard web technologies that "does not require local installation, a dedicated server, a database, or commercial software licenses." It integrates deterministic simulation modules for mechanical ventilators, patient monitors, infusion pumps and CRRT systems with a host interface and an AI-supported analysis panel, running at approximately 60 Hz. It was designed as a preparatory environment for biomedical device technology students. (İnan Onur; Akyüz Ali (2026))
