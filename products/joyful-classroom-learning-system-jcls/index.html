Joyful Classroom Learning System (JCLS)¶

Product or Programme · All products and programmes
Evidence · 3 claims (3 for) · 1 study (1 causal), q2 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

A robot-, RFID-, mobile-computing-, and network-supported classroom learning system developed by Wei et al. for elementary mathematics instruction, with instruction, collaborative-learning, self-learning, and teacher-monitoring functions.

Components¶

  • Joyful Classroom Learning System (JCLS) with robot learning companion and RFID input: The JCLS is a technology-enhanced classroom system whose learning stations comprise a robot learning companion (LEGO MINDSTORMS NXT), an RFID sensing input device, a mobile computation unit (laptop), a mobile display device and a Wi-Fi wireless local network, plus operating software with two agents (control and coordination) and five modules (notification, sound effect, motion, instruction, presentation). Learners answer multiplication exercises by touching RFID-tagged number and command symbols instead of typing, and the RLC reacts with actions, screen messages and sounds. It supports three application modes: instruction, collaborative learning and self-learning. The instructor's control station logs every learner's activities and displays summarised real-time status for timely assistance. (Wei et al. (2011))

Claims¶

  • Second graders learning multiplication with the JCLS rated experiential learning significantly higher than peers learning with a traditional blackboard [+M]
  • Second graders learning multiplication with the JCLS rated constructivist learning significantly higher than the blackboard control group [+M]
  • Second graders learning multiplication with the JCLS rated joyful learning significantly higher than the control group, though the p-value was near the significance boundary [+M]
