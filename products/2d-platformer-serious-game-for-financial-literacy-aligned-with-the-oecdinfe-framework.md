# 2D platformer serious game for financial literacy aligned with the OECD/INFE framework

> **Product or Programme** · [All products and programmes](index.md)

## Description
A Unity/WebGL serious game developed by Gabriel Machado Santos et al. in which K–12 learners make simulated spending, saving, investment, gambling, and credit decisions while their actions are logged for stealth assessment.
