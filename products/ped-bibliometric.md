> **Product or Programme** · [All products and programmes](index.md)

## Description
A public GitHub repository maintained by Santoso et al. containing a PRISMA-screened physics-education bibliometric dataset and R code for bibliometric and topic-modeling analyses.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open GitHub repository of the Physics Education bibliometric dataset and R code**: The authors released the study's data and analysis code as a public artifact: "The bibliometric dataset and R codes run in the present study have been made available in GitHub repository (https://github.com/santosoph/PED-Bibliometric)". The dataset comprises the PRISMA-screened corpus of 6,311 Scopus-indexed Physics Education documents (1966-2026), and the R code implements the bibliometrix-based screening, cleaning, bibliometric indicators, and LDA topic modeling reported in the study. The repository enables reuse and extension of the analysis pipeline. (Purwoko Haryadi Santoso et al. (2026))
