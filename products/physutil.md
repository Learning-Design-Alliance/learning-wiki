# PhysUtil

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
PhysUtil is a Georgia Tech-developed Python module that simplifies the creation of graphs, motion diagrams, axes, and timers for student computational modeling with VPython.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PhysUtil Python module for Modeling Instruction computation**: PhysUtil is a Georgia Tech-developed Python module designed specifically to support the Modeling Instruction curriculum. It "allows students to create  graphs, motion diagrams, axes, and timers  by writing only one or two lines of code", reducing the code burden during computational modeling activities. Students used it alongside VPython on laptops in the 9th-grade classrooms studied. (John M. Aiken et al. (2012))
- **VPython and the PhysUtil module as the computational environment for Modeling Instruction**: The pilot used the Python programming language with the Visual module ("VPython"), which "gives students access to animations, graphs, and a host of other scientific tools." Python was chosen for its clean syntax, dynamic typing, and interpreter's immediate feedback. The Georgia Tech-developed PhysUtil module was designed for MI classrooms: it "allows students to create graphs, motion diagrams, axes, and timers by writing only one or two lines of code," and was augmented to use the Python CSV module for comparing experimental data to model predictions. (Aiken (2013))
