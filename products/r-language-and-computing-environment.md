## Description
R is a free, open-source programming language and computing environment for data manipulation, statistical computing, and scientific graphing, maintained by the R Core Team and distributed through CRAN.

## Components

- **R language and computing environment for data manipulation, statistical computing, and scientific graphing**: R is both a language and an environment for "data manipulation, statistical computing, and scienti ﬁc graphing", founded on the S language and distributed as free software via the Comprehensive R Archive Network. It uses a command-line interface, encourages vector-based programming, fits linear models with lm() and non-linear models with nls(), plots histograms with hist(), and exports graphs as PostScript, PDF, or bitmap files. Scripts can be saved and re-executed with source(), supporting reproducible workflows, and over 1500 contributed packages are available on CRAN. (Primoˇz Peterlin (2009))
