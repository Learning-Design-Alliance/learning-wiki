## Description
LabNbook is a web-based platform for collaborative science learning and report writing, providing text, drawing, protocol, spreadsheet/graphing, and Python-notebook tools for higher-education science students.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LabNbook web platform for collaborative science report writing**: LabNbook is a web platform for learning sciences in which students write collaborative reports using five types of document. The article states that "In the LabNbook platform, students use 5 types of document to write a collaborative report" and lists a text and formula editor, drawing tool, experimental protocol editor, spreadsheet and graphing tool, and Python notebook. It serves about 3500 student-users per year and is the setting the doctorate aims to enhance with planning-support tools. (Simon Lecuyer-Chardevel et al. (2024))
