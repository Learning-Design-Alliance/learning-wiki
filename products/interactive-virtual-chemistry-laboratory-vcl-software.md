## Description
Interactive virtual chemistry laboratory software developed for teaching the ninth-grade chemical changes unit through virtual experimentation, prediction, equipment selection, and multiple chemical representations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Interactive virtual chemistry laboratory (VCL) software for the 9th-grade chemical changes unit**: The VCL is interactive software developed for the 'chemical changes' unit of the year-nine chemistry curriculum, built on constructivist theory and the POE strategy. It presents experiments at macro, micro (molecular) and symbolic levels, asks students to record predictions before experimenting, lets them select equipment and assemble experiments themselves, and includes a 'Relate it with Daily Life' button plus safety warnings such as 'The laboratory is kept clean and uncluttered'. Students used it in the information technology class with 2 or 3 students sharing one computer. (Zeynep Tatli et al. (2012))
