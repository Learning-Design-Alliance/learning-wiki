Description¶

BFpack is an R package developed by Mulder and colleagues that provides Bayesian factor hypothesis-testing functions for common statistical models and exploratory or confirmatory tests with equality and order constraints.

Components¶

Claims¶

  • BFpack handles common statistical analyses with default priors and data missing at random [+W]
  • BFpack provides both Bayesian exploratory and confirmatory hypothesis testing tools with equality and order constraints [+W]
