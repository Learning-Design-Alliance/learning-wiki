Prompt Programming¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

Prompt Programming is a web-based dialogue tool described by Victor-Alexandru Pădurean et al. for helping introductory programming students solve coding problems by iteratively refining natural-language prompts with GPT-4o mini.

Components¶

Claims¶

  • When prompts failed, students most commonly reported clarifying intent or specifying more detail, and reflecting on the problem depiction, rather than tracing code or examining test cases [+M]
  • CS1 students tend to agree it is easier to solve problems by writing natural language prompts than by writing code (mean 3.80 on a five-point scale) [+M]
