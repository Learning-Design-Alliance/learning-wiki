# Nuclear Building Blocks

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Nuclear Building Blocks is a companion educational website that provides an interactive N=Z chart and allows permitted users to submit and highlight nuclear structures built during classroom demonstrations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Companion website with N=Z chart and user-submitted nuclear discoveries**: The article describes a companion website (http://shellmodel.ascsn.net/, cited as Nuclear Building Blocks, 2024) that supports the demonstration. It offers an "N=Z" chart option that draws a line highlighting how heavier stable nuclei deviate from equal proton and neutron numbers, and bands underlying the chart corresponding to each magic number. The site also lets users submit structures they build in the demonstration to be highlighted as discoveries, connecting classroom play to the real nuclear landscape up to 48Ca shown in the article's Figure 3. (J. Wylie et al. (2025))
