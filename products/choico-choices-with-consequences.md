# ChoiCo (Choices with Consequences)

## Description
ChoiCo is an open-access web-based game-authoring environment for creating and modifying choice-driven simulation games through database, map-editing, and block-based coding tools.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ChoiCo environment and CT-Chef socio-scientific simulation game**: ChoiCo (Choices with Consequences) is a web-based open access game authoring environment with a Play Mode for choice-driven simulation games and a Design Mode offering three interconnected computational tools: an editable database of game fields and choices, a map editor connected to the database, and three block-based coding workspaces for game mechanics. CT-Chef is a game created for this study dealing with managing a sustainable, health-promoting restaurant, where choices affect five game fields including money, healthy food and customers per day. (Marianthi Grizioti (2025))
