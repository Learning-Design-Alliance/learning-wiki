# Python software for clustering students by achievement with fuzzy logic

> **Product or Programme** · [All products and programmes](index.md)

## Description
A Python-based Google Colab/Jupyter Notebook tool developed by Serhiy Balovsyak et al. for clustering students by achievement, calculating fuzzy memberships, visualizing results, and supporting difficulty-level adjustment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Python software for clustering students by achievement with fuzzy logic (Google Colab, scikit-learn, scikit-fuzzy)**: Software tools for clustering educational data and analyzing them with fuzzy logic, developed in Python using the Google Colab cloud service in a Jupyter Notebook. Clustering uses the KMeans() function of the sklearn.cluster library with Euclidean distance, and "Calculation of triangular fuzzy membership functions is performed by the trimf() function of the scikit -fuzzy library." The tool reads initial data, scales parameters, clusters, computes radii and membership functions, visualizes results, and stores results in files. (Serhiy Balovsyak et al. (2023))
