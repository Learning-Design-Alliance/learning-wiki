# Two-predictor screener ShinyApp

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 theoretical), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
A Shiny web application released by Shero et al. that lets educators and researchers test arbitrary correlations and cutoff choices for two-predictor academic-risk screening under the authors' probability-density model.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Two-predictor screener ShinyApp (two_predictor_screener)**: A web application released by the authors to accompany the simulation analyses. The article states that "a ShinyApp ( https://jshero.shinyapps.io/two_predictor_screener/) was developed allowing any combination of correlations among the variables to be tested as a screener for any cutoff in the same ways presented in this paper." It extends the paper's fixed grid of progress-monitoring correlations, PGS effectiveness values, and learning-disability cutoffs to arbitrary combinations, and was designed so schools can test screener cut-off choices and usage patterns beyond those analyzed. It operationalizes the paper's probability-density approach for practitioners. (Shero et al. (2021))
