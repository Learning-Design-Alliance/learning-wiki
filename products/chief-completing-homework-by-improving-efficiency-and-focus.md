# CHIEF (Completing Homework by Improving Efficiency and Focus)

## Description
CHIEF is a 16-session school-based intervention developed by Langberg and colleagues for middle-school students with ADHD that uses behavioral goals, token rewards, praise, and parent training to improve homework focus and completion.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CHIEF intervention: a 16-session brief school-based behavioral homework intervention**: CHIEF (Completing Homework by Improving Efficiency and Focus) uses the same service delivery model as HOPS but targets the behavioral aspects of homework completion. During each of 16 meetings the provider "implements a behavior management and points system, sets work completion goals, and has the student complete homework and study for tests," token-rewarding on-task behavior and providing verbal praise. Two parent meetings teach caregivers to set work completion goals and run the point system at home; adherence averaged 89.23% of criteria met. (Langberg et al. (2017))
