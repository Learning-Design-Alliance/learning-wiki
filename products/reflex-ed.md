## Description
RefleX ED is a tutor-support tool developed by Yilmaz et al. that presents standardised scores from observable self-regulated-learning behaviours to inform tutor feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **RefleX ED tutor-support tool presenting standardised SRL proxy scores**: RefleX ED is a tool the authors developed to help tutors interpret behavioural data when drafting feedback. It "presents each student's standardised scores derived from observable indicators of SRLs behaviours" across the five SRL pillars (GS, TS, TM, HS, SE), with z-scores centred on zero so negative values signal a need for corrective feedback and positive values for reinforcement. It was used to generate the tutor-feedback condition in the study. (Yilmaz et al. (2026))
- **RefleXED tutor-support tool for LA-driven feedback provision**: RefleXED is a practical tool developed in this study to support tutor-generated feedback. It "displays each student’s standardised SRLs proxy scores, cluster information based on the result of RQ1, and comprehensive insights into the SRLs pillars used in the study", while automatically retrieving the student's first name from the database. Tutors see only IDs, cluster membership and proxy scores, with tooltips explaining each proxy's behavioural variables and calculations, helping them craft tailored feedback regardless of familiarity with statistical terms. It was used by the control-condition tutor in the quasi-experiment. (Mutluhan Yilmaz et al. (2026))
