## Description
Kerbal Space Program is a commercial space-flight simulation game developed by Squad and published by Private Division in which users design and operate spacecraft in a physics-based orbital environment.

- **Kerbal Space Program as a classroom orbital-dynamics sandbox: cost, platform requirements, and supplementary save files**: KSP, released in 2015, is a commercial video game available from the Steam game store for $40 (often on sale for $10), compatible with all modern operating systems and requiring comparatively few graphical and computational resources. The author uses it as an accurate orbital sandbox in which students explore orbits only by mastering orbital dynamics, and provides save files for the paper's rockets as supplementary material. Console versions exist but the controls are more difficult and are not recommended. (Brian DiGiorgio Zanger (2025))
