## Description
MAIDR is a multimodal data-visualization and chart-exploration system developed by Seo and colleagues that supports blind and low-vision learners through customizable text, braille, and sonification modes.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MAIDR: a multimodal access and interactive data representation system for non-visual chart exploration**: MAIDR (Multimodal Access and Interactive Data Representation) is a system developed by Seo and colleagues to make data science and visualization education accessible to blind and low-vision learners. "The MAIDR system provides customizable multimodality modes (i.e., braille, text, and sonification) to learners with varying degrees of visual disabilities. It works with four types of graphs (bar plot, heatmap, box plot, and scatter plot)." In the course, participants learned to explore visualized data using dynamic sonification and a refreshable braille display through the MAIDR package; the four chart types were chosen partly for their compatibility with MAIDR. (JooYoung Seo et al. (2024))
