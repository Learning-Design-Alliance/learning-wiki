Description¶

The Wraparound program is a structured supplemental academic-services programme run by its provider to support academic achievement in a low student-to-teacher-ratio setting.

Components¶

  • Deliver supplemental academic services in a structured environment with a low student-to-teacher ratio: The Wraparound program is delivered in a structured environment with a low student-to-teacher ratio, which the page presents as part of how the program aims to accelerate academic achievement while fostering a supportive learning atmosphere. Staffing criteria by service type (certified instructors, certified counselors, experienced coaches) support this delivery model. (Catapult Learning's Wraparound Supplemental Educational Services (2024))
