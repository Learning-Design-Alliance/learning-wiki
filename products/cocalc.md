## Description
CoCalc is a web-based cloud platform for collaborative computation, course management, and document authoring, developed and operated by SageMath, Inc.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CoCalc cloud service as a training tool in pre-service mathematics teacher education**: CoCalc, a cloud service applied as a training tool in pre-service mathematics teachers' study of mathematical disciplines. Students create educational resources and "work with sagews s heets (including the most common modes, know the basics of languages: LaTeX, Python, HTML)" and use chats and tex-like educational resources; most can access it "both at universities and at home". (MaiiaV. Popel (2018))
- **CoCalc cloud service for mathematics teacher training**: CoCalc (formerly SageMathCloud) is a cloud computing and math calculations management platform created by William Stein and provided by SageMath Inc. It "enables Jupyter Notebook file sharing, which empowers group work" and supports a course and task manager for assigning tasks and grading; it supports simultaneous Google-Documents-style editing of Jupyter notebooks with integrated chat, and is free of charge with paid packages offering more stable servers and more computer resources. (Maiia Marienko et al. (2020))
- **Five criteria for selecting a cloud service to support mathematics learning**: The article proposes a set of selection criteria for choosing a cloud service appropriate to educational needs in mathematics disciplines. The criteria cover "computing power provided for the work of an individual user", tools for organizing and monitoring the learning process, tariff plans to expand computing capability, open source code with free access to additional modules, and tools for creating, storing and jointly editing resources in common formats. CoCalc is then evaluated against these criteria. (Maiia Marienko et al. (2020))
