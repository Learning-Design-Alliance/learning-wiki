# VISPA (visual physics analysis)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
VISPA is a browser-based physics data-analysis development environment developed by the VISPA project for students and researchers, integrating modular workflow design, Python programming, server-side execution, data inspection, and collaborative file sharing.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VISPA internet platform for physics data analysis**: VISPA ("visual physics analysis") is a browser-based development environment supporting the full workflow of a physics data analysis: modular program design as a flow chart in the analysis designer, Python programming in an editor, server-side execution with a job dashboard, and a data browser for inspecting input and processed data. It stores files on a central server so "No software installations are required for the user", and students can share analyses with peers and faculty for teamwork regardless of location and time. It is used with the PXL physics extension library and ROOT, interfaced to Python. (Erdmann M et al. (2014))
