# CAPA (Computerized Asynchronous Personalized Assignments)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
CAPA is a content-independent web-based homework and assignment-delivery system developed at Michigan State University that personalizes problem data or questions, provides immediate answer feedback, and supplies instructor reports.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CAPA: a content-independent, web-based system for personalized assignments with immediate feedback and real-time instructor reports**: CAPA (Computerized Asynchronous Personalized Assignments), developed at Michigan State University, is "a framework capable of delivering personalized assignments" that is content independent and web interfaced. Each student receives the same problem with different numerical data or different questions, answers can be tried repeatedly (typically 10 tries), and the system returns Y, N or U (wrong units) responses with immediate feedback. It provides the lecturer real-time difficulty reports and grade distributions, and includes a web forum enhancing student collaboration. (Itzhak Goldman (2007))
