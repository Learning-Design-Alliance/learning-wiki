# Motion and Vector Analysis

> **Product or Programme** · [All products and programmes](index.md)

## Description
A Delphi-built interactive physics learning package for Indonesian XI-grade students that provides visualizations and learning activities on motion and vectors.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Interactive physics software "Motion and Vector Analysis" for XI-grade motion and vector topics**: A CD-ROM-based interactive physics learning package on motion and vector analysis for XI-grade senior high school students, aligned to the KTSP curriculum and built using Delphi Seventh version. It displays learning competences and visualizations including "Parabolic motion and motion component display" and "Circular motion display", with home page, main menu and learning options screens. The software was evaluated by design, pedagogic, technical and content experts and by 31 experienced physics teachers before classroom use. (Mohd. Jasmy Abd Rahman et al. (2014))

### Claims
- [Learning physics with the interactive Motion and Vector Analysis software produced higher conceptual understanding than traditional instruction in a quasi-experiment with XI-grade students](../claims/interactive-motion-vector-software-improves-conceptual-understanding.md) [+M]
- [Students learning with the software showed higher learning motivation at post-test than students taught by traditional method](../claims/motion-vector-software-raises-learning-motivation.md) [+M]
