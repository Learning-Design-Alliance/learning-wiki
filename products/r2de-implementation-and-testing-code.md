# R2DE implementation and testing code

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
An open-source GitHub codebase implementing and testing R2DE for estimating item-response-theory parameters from question text, released by the authors for reproduction and evaluation on other datasets.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Released R2DE implementation and testing code on GitHub**: The authors released the code implementing and testing R2DE on GitHub (https://github.com/lucabenedetto/r2de-nlp-to-estimating-irt-parameters), explicitly so that future research "might be run and tested on other datasets". The release is meant to enable a comprehensive comparison with other NLP approaches for estimating latent traits of questions, which was previously impossible because prior works published no code and used private datasets. (R2DE: a NLP approach to estimating IRT parameters of newly generated questions)
