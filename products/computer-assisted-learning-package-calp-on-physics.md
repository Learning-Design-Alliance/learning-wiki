# Computer Assisted Learning Package (CALP) on physics

> **Product or Programme** · [All products and programmes](index.md)

## Description
A standalone computer-assisted physics learning package developed by Gambari et al. using Dreamweaver, Fireworks, and Flash, with sequenced lessons, simulations, drill-and-practice questions, and mastery-gated progression.
