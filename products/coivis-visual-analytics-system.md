# COIVis visual analytics system

> **Product or Programme** · [All products and programmes](index.md)

## Description
COIVis is an interactive visual analytics system developed by Zhiguang Zhou and colleagues for concept-level analysis of MOOC learner states using coordinated views and multimodal learning data.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **COIVis visual analytics system with five coordinated views for concept-level exploration of MOOC learning**: COIVis is an interactive visual analytics system that systematizes the COI pipeline in three stages: preprocessing (COI definition and eye-tracking integration), learner-state analysis, and visual analytics. It provides a Control Panel, Feature Panel, Main View, Projection View, Slide View, and Detail View. The Feature Panel "uses a bubble-based design to summarize the five learner-state features for each concept and allows instructors to filter and rank COIs according to their diagnostic needs, helping them quickly locate concepts with abnormal patterns." The Projection View embeds learners via Doc2Vec-encoded COI sequences reduced with t-SNE, adjusted by learner-state feature differences. (Zhiguang Zhou et al. (2025))
