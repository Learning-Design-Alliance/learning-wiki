# Three-component comprehensive assessment system with Angoff dimension thresholds and Bloom's taxonomy mapping

> **Product or Programme** · [All products and programmes](index.md)

## Description
A researcher-developed pre/post assessment instrument by Wei Mingchao et al. for undergraduate thoracic-surgery students, measuring theoretical knowledge, clinical imaging analysis, and comprehensive clinical application using dimension-specific Angoff thresholds and Bloom-aligned items.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Three-component competency-based assessment system with Angoff dimension thresholds and Bloom's taxonomy mapping**: The study's evaluation instrument is a "three-component comprehensive assessment system (total score = 100 points)": basic theoretical knowledge (50 points), clinical imaging analysis ability (30 points), and comprehensive clinical application ability (20 points), with all tools pilot-tested (Cronbach's α > 0.80; imaging inter-rater kappa = 0.89). A 5-expert panel set dimension-specific Angoff thresholds for minimally competent performance (32/50, 18/30, 12/20) while eschewing a rigid total-score passing line, and all items were mapped to the revised Bloom's taxonomy so imaging and clinical reasoning items covered the Analyze–Create levels. (Wei Mingchao et al. (2026))
