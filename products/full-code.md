## Description
Full Code is an internet-independent virtual medical simulation platform developed by Minerva Medical that provides realistic clinical cases, practice in clinical reasoning and decision-making, and automated performance reports.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Full Code Medical Simulation platform**: Full Code is a virtual simulation software by Minerva Medical, an internet-independent platform offering more than 150 realistic clinical cases for practicing clinical reasoning. Each completed case yields an automatically generated performance report that "assigns a score based on three weighted components: correct diagnosis (35%), correct disposition (20%), and individual actions taken (45%)", with actions categorized as critical, recommended, neutral, unnecessary or harmful. In this study instructors encouraged its voluntary use as a supplementary tool aligned to course learning objectives. (Salafia Maria Amalia (2025))

### Claims
