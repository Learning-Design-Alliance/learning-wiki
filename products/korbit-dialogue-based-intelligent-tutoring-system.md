# Korbit dialogue-based intelligent tutoring system

## Description
Korbit is a machine-learning, NLP, and reinforcement-learning platform developed to provide interactive, personalized tutoring through lecture videos, exercises, automated free-text solution checking, and adaptive interventions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Korbit: a large-scale dialogue-based intelligent tutoring system for data science topics**: Korbit is "a large-scale, open-domain, mixed-interface, dialogue-based ITS, which uses ML, NLP and reinforcement learning to provide interactive, personalized learning online", with thousands of students enrolled for topics related to data science, machine learning, and artificial intelligence. It tutors by alternating between short lecture videos and interactive problem-solving; incorrect solutions trigger an inner-loop system that selects among pedagogical interventions using an ensemble of ML models. (Kochmar et al. (2020))
- **Korbit's inner-loop finite-state machine architecture with reinforcement-learned intervention selection**: The Korbit ITS inner loop manages exercise interaction as a finite-state machine in which each pedagogical intervention is a separate state; 'each state operates independently of the rest of the system', and transitions between states are decided by a reinforcement learning model that continues to improve with data, while an outer loop selects content from a personalized curriculum. (Serban et al. (2020))
- **Korbit: a large-scale, open-domain, mixed-interface, dialogue-based ITS for STEM**: Korbit is 'a large-scale, open-domain, mixed-interface, dialogue-based ITS' using machine learning, natural language processing and reinforcement learning to provide interactive, personalized learning online. Launched with a machine learning course in 2019, it has enrolled over 7,000 students and teaches data science, machine learning and artificial intelligence topics. (Serban et al. (2020))
- **Mixed-interface lessons alternating short lecture videos with interactive dialogue-based exercises**: Korbit tutors students by 'alternating between short lecture videos and interactive problem-solving exercises', delivered through a mixed interface that 'includes videos, interactive dialogue-based exercises, question-answering, conceptual diagrams, mathematical exercises and gamification elements'. The outer loop decides which video or exercise comes next based on the personalized curriculum. (Serban et al. (2020))
