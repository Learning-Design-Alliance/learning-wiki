## Description
ALA-Reader is a software tool used with Pathfinder network analysis to automatically elicit and represent students’ knowledge structures from essay text.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ALA-Reader with Pathfinder network analysis for capturing knowledge structures in student essays**: ALA-Reader is a technology, used together with Pathfinder network analysis, that the special issue's first paper applied to student essays. According to the editors, it was used "to explore an automated procedure to capture and represent knowledge structures in student essays", making essay-based knowledge structure elicitation automated rather than manual. (Dirk Ifenthaler et al. (2009))
