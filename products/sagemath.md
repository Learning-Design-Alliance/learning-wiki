## Description
SageMath is an open-source mathematics software system developed by the SageMath community that supports symbolic and numerical computation, visualization, programming, and interactive mathematical documents.

- **Мобільне математичне середовище Sage як засіб мобільного курсу вищої математики**: Мобільне математичне середовище визначається як «мережне програмне забезпечення, що надає можливість доступу до математичних об'єктів в будь-який зручний час та будь-який спосіб». Sage — «яскравим представником мобільних математичних систем», що дозволяє аналітичні та чисельні обчислення, побудову дво- та тривимірних графіків, поєднання обчислень, тексту й графіки на робочих листах, створення моделей мовою Python. Автори вважають його ефективним засобом для створення мобільних курсів. (К.І. Словак (2010))
- **SageMath as a free open-source CAS for learning linear algebra**: SageMath is described as "a free open-source mathematics software system that uses Python as its primary programming language", offering symbolic manipulation, numerical computation, and strong linear algebra support including matrix decompositions such as LU, QR, and SVD. The article uses it via the Sage Cell Server for one-off cloud computations to compute eigen-data, perform Gram-Schmidt orthogonalization, verify factorizations, and compute pseudoinverses for checking hand calculations. (Natanael Karjanto (2023))
