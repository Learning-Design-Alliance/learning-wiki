## Description
An openly licensed set of Qibo-based Python/Jupyter notebooks developed by Isabella Masina et al. for simulating Bell inequalities and related quantum phenomena in JupyterLab or Google Colab.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Bell inequalities simulation code in Qibo released as Python notebooks under GNU GPL 3**: The article's educational tool is "a set of software simulations" based on Qibo, "an open-source quantum computing framework" offering "a simple Python interface to execute quantum circuits, both as a classical simulation and on real quantum computers". The code is written as Python notebooks executable on a standalone Jupyterlab setup or Google Colab, includes detailed step-by-step instructions, and allows variations of the resulting plots. It has been published in the Qiboedu GitHub repository under the GNU GPL 3 License at https://cern.ch/bell-in-qibo. (Isabella Masina et al. (2025))
