# Q# programming language and Microsoft Quantum Development Kit

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Microsoft's Q# language and Quantum Development Kit provide a programming language, compiler, simulators, debugger, and resource estimator for developing and analyzing quantum algorithms.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Q# programming language and Microsoft Quantum Development Kit as the course's single toolchain**: The course used Q#, "a high-level domain-specific programming language used for expressing quantum algorithms", together with the Microsoft Quantum Development Kit, an open-source SDK including a compiler, a general purpose quantum simulator, specialized simulators, a debugger, and an algorithm resource estimator. A single language and environment was used throughout the course for katas, assignments, and final projects. (Teaching Quantum Computing through a Practical Software-driven Approach: Experience Report)
