# ACoRD reusable learning objects (RLOs)

## Description
An open-access collection of 23 bite-sized, multimedia interactive learning resources for health-care education, developed by the ACoRD project for undergraduate medical, pharmacy, and biomedical science learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Flashcard-to-Notebook-to-Group aggregation implements learning object principles**: The platform structures content as nested reusable layers: Flashcards are the smallest blocks, custom aggregations of Flashcards form Notebooks, and Notebooks are shared within Groups belonging to institutions. The article maps this structure onto learning object principles, stating Flashcards accord "with the learning objects principles of stand-alone, reusability, interactivity and aggregation" (Table 2). MeSH terms index content so it "can be searched within the application by using these terms", supporting portability and reuse across Notebooks and learning situations. (Taveira-Gomes Tiago et al. (2014))
