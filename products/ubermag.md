## Description
Ubermag is an open-source Python interface developed by the University of Southampton and the Max Planck Institute for the Structure and Dynamics of Matter for specifying, running, analysing, and visualising micromagnetic simulations in interactive Jupyter notebooks.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Ubermag micromagnetic simulation package with Python interface and Jupyter notebooks**: Ubermag is an open-source Python package, developed at the University of Southampton and the Max Planck Institute for the Structure and Dynamics of Matter, that provides a Python interface to the OOMMF and mumax3 micromagnetic calculators. Its packages "allow the user to specify micromagnetic models, run simulations, and analyze and visualize data in interactive Jupyter notebooks". In the case study, students controlled and ran simulations via browser-based Jupyter notebooks, with only the numerical solving delegated to the calculators. (Martin Lonsky et al. (2024))
