## Description
Xcos is Scilab's open-source graphical block-diagram environment for modeling and simulating hybrid dynamic systems, developed and distributed by the Scilab Consortium.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **An Xcos (Scilab) block-diagram environment for solving the Riccati-type phase function equation**: The article describes a Scilab-Xcos implementation of the Variable Phase Approach for computing phase shifts. Xcos is 'a Scilab toolbox dedicated to the modeling and simulation of hybrid dynamic systems' with a GUI block-diagram editor, offering 'a step-by-step procedure for learning to solve complex differential equations interactively'. The author states that 'For the first time, an Xcos environment has been created to solve the Riccati type non-linear differential equation', with Xcos models given in supplementary material. (Anil Khachi (2024))
