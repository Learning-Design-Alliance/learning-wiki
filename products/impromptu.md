# Impromptu

## Description
Impromptu is a computer-based musical programming environment that includes the TuneBlocks PlayRoom for composing melodies by arranging programmable note blocks, developed for music and programming learning.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TuneBlocks musical programming environment within Impromptu**: The article describes Impromptu as "a computer-based musical programming environment in which students can learn to compose melodies using their musical intuitions by arranging small blocks that represent musical notes". The authors used one of Impromptu's five PlayRooms, called TuneBlocks, in which students composed tunes by editing existing tunes from the TuneBlocks library and used pitch or note duration to represent constant speed, constant acceleration and constant deceleration, adding musical attributes such as pitch and tempo to the representational palette. (Amy Voss Farris et al. (2014))
