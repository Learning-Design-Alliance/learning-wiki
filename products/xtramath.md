## Description
XtraMath is a computerized math-fact practice program made by XtraMath that adapts practice to learners' performance to build automatic recall of basic arithmetic facts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **XtraMath adaptive online math fact-fluency program**: XtraMath is an online, computerized math program that "continuously adapts to children's abilities" and "aims to help students transition from counting or calculating the basic math facts to automatically recalling them." It uses timed activities with 3-s thresholds, spaced repetition, and four operation components (addition, subtraction, multiplication, division), each starting with a placement quiz that sets the individual mastery score. In this trial, preterm first graders used the standard protocol of at least 5×/weekly 10–15 min practice for 5 weeks, with only one-digit addition tasks (0 + 0 to 9 + 9), weekly parent progress emails, and coach support. (Jaekel Julia et al. (2020))
