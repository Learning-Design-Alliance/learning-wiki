# VisTA (Visualizations for Tutor Analytics)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
VisTA is a JavaScript/D3 teacher-facing analytics system within the Apprentice Tutors platform that visualizes intelligent-tutor interaction and problem-solving provenance data.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VisTA: a visual analytics system for exploring student problem-solving provenance from intelligent tutor logs**: VisTA (Visualizations for Tutor Analytics) is an analytics tab teachers access through the Apprentice Tutors platform, implemented in JavaScript and D3. It has four coordinated views: Overview, Student view, Problem Type view, and Details view, which collectively let teachers “see aggregate metrics of student engagement, identify student problem solving strategies, compare problem solving provenance between different problem types and students, and identify skills students commonly struggle with”. The authors state it is the first analytics tool developed to visualize student provenance data from intelligent tutors. (Grace Guo et al. (2024))

### Claims
- [Stepwise provenance visualizations combined with summary metrics helped teachers form nuanced interpretations of when and why students make mistakes and tailor responses accordingly](../claims/provenance-visualization-nuanced-teacher-responses.md) [+M]
- [Aggregating multiple student solution paths in the Problem Type view helped teachers identify knowledge components requiring more classroom instruction and reflect on tutor design](../claims/problem-type-view-highlights-kcs-needing-instruction.md) [+M]
