Persona Problem Builder (PPB)¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A React and Flask web-based platform developed by Walkington et al. that uses GPT-4o to generate topic-aligned personalized mathematics problems for integration with ASSISTments.

Components¶

  • Persona Problem Builder (PPB) web-based platform: The Persona Problem Builder is a web-based platform developed using React for frontend code and Flask API for the backend, with GPT-4o underlying the system and leveraging its math reasoning capabilities. It is hosted on an EC2 instance and designed to integrate with ASSISTments, an online homework system. A teacher provides an ASSISTments problem ID and a topic, and the system generates a personalized version of the problem using a structured prompt that targets topic alignment and preservation of the underlying mathematics. (Walkington et al. (2025))

Claims¶

  • Teachers adjusted problem topics as the most common refinement move [+W]
  • PPB maintained comparable readability on three of four measures while increasing Flesch-Kincaid toward grade level [+W]
