## Description
An R package made by Federica Zoe Ricci and colleagues that supports automated grading workflows in RStudio, including rubric-guided grading, grade-sheet updates, individualized feedback files, regrading, and GitHub-based distribution.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **gradetools R package for automated grading workflows in RStudio**: gradetools is an R package implementing an automated grading workflow within the RStudio GUI. Its functions (assist_grading, assist_team_grading, assist_advanced_grading, assist_regrading, push_to_github, create_rubric_template) automatically open and close submissions, prompt the grader to apply rubric items via short prompt codes, update the grade sheet, and write individualized feedback files for each student. It integrates with ghclass to streamline feedback distribution for GitHub-managed assignments. (Federica Zoe Ricci et al. (2024))
