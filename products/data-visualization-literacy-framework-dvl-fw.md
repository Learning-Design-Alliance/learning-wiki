# Data Visualization Literacy Framework (DVL-FW)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A framework developed by Bueckle et al. for categorizing visualization types, graphic symbols, graphic variables, and data interactions to support the design and description of data visualizations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Data Visualization Literacy Framework (DVL-FW) as a design vocabulary for VR performance visualizations**: The Data Visualization Literacy Framework is a theoretical toolset to interpret, construct, and teach data visualizations, which the authors use to describe their VR interventions in abstracted terminology covering both traditional 2D charts and advanced VR visualizations. As the article states, "The DVL-FW comes with a series of seven typologies to categorize, among others, visualization types (such as graphs and maps), visual encodings via graphic symbols (such as points, lines, volumes) and graphic variables (such as color hue and size), and interactions with data (such as filter as well as link and brush)". In both studies the framework structured the Reflective-phase visualizations' encoding and interaction choices. (Bueckle et al. (2021))

### Claims
