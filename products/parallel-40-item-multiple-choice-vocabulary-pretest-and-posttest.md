# Parallel 40-item multiple-choice vocabulary pretest and posttest

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A pair of parallel researcher-made multiple-choice vocabulary tests used to measure vocabulary acquisition before and after instruction in pre-intermediate EFL university learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Parallel vocabulary tests (40 multiple-choice items each) used as pre- and post-tests**: The study used two parallel vocabulary tests as pre- and post-tests, each including 40 multiple-choice vocabulary items. Prior to the main data collection, a pilot study was run to verify that both tests were parallel and reliable. The tests were administered to 20 trial language learners with an interval of 2 days, and reliability was verified using the parallel tests method, with Cronbach's Alpha of 0.79 for Test 1 and 0.84 for Test 2. (Maki Naeimi et al. (2015))
