# TeachingMedicine.com virtual patient platform

## Description
TeachingMedicine.com virtual patient platform is a computer-based clinical-case simulation system that scores learners' diagnostic reasoning and provides individualized automated formative feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TeachingMedicine.com virtual patient platform with automated scoring and individualized feedback**: A computer-based virtual patient simulation platform on which students complete staged diagnostic cases (introduction, history, physical exam, investigations), building and revising a differential diagnosis of up to five conditions and assigning findings as pertinent positives or negatives. Each case generates "over 125 data points" that drive "individualized automated formative feedback for each completed case", covering Ddx building, DxJ, test ordering, cognitive errors, and final diagnosis. The platform uses free-text entry for diagnoses and test ordering to avoid multiple-choice cueing, and shows test results only for tests the learner ordered. (Waechter Jason et al. (2026))
