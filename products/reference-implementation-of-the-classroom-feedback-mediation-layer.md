## Description
A lightweight GitHub-hosted demonstration implementation by Junsoo Park et al. that accepts classroom-level observations and returns topic priorities, decision records, and recommendations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Reference implementation of the classroom feedback mediation layer (GitHub repository)**: A lightweight reference implementation of the mediation layer released for replication and exploratory use, hosted at github.com/park-jsdev/classroom-feedback-mediator. The article states it "accepts classroom-level observations and returns topic priorities, decision records, and recommendations." The authors present it as a demonstration artifact accompanying the study, not as a validated production system. (Junsoo Park et al. (2026))

### Claims

- [In a graduate CS course offering, mediated topic priorities aligned with instructor concerns (top-5 overlap 3/5; Spearman ρ = 0.80)](../claims/mediation-layer-priorities-align-instructor-concerns.md) [+W]
