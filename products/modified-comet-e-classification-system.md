# Modified CoMet-E classification system

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A modified Coordination System for Medical Teams-Emergency framework developed by Fornander et al. for coding information management, task management, relational and other communication, and closed-loop communication in interprofessional trauma teams.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **A modified CoMet-E classification system for trauma-team coordination behaviours adds confirmation and relational communication codes**: The article modified the Coordination System for Medical Teams-Emergency, which "descriptively categorizes coordination behaviour", into a three-level system: main categories (information management, task management, relational communication, other communication, not codable), 19-20 coordination behaviours, and closed-loop communication coding of applicable utterances. "two new coordination behaviours were added to the system": "confirmation" and "relational communication", with a relational category added at level 1. Intercoder agreement reached Cohen's κ = 0.86 for main categories, κ = 0.68 for coordination behaviours, and κ = 0.8 for CLC. (Fornander L et al. (2024))
