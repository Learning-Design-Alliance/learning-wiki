## Description
An R package by Wolfgang Rolke that provides a Shiny app for generating randomized Moodle quiz and exam files from instructor-specified parameters.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **shinymoodlequizR interactive app for beginners**: The package includes an interactive shiny app, started with moodlequizR::shinymoodlequizR(), in which the user enters quiz parameters such as sample size, distribution, mean, standard deviation, rounding, question text and answer type. Clicking Create the Files! produces three files: a saved settings list, an editable R script, and the XML file for Moodle import. The article says it "allows a new user to create a first test with almost no effort". (Wolfgang Rolke (2024))
