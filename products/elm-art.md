## Description
ELM-ART is a Web-based interactive and intelligent textbook system developed for adaptive, diagnostically supported introductory programming instruction.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **The interactive and intelligent textbook paradigm combining intelligent tutoring and adaptive hypermedia**: ELM-ART introduced a paradigm in which a Web-based textbook looks like a traditional programming textbook with sections of text, program examples and problems, but all content is interactive and the book is intelligent, using AI technologies such as intelligent program analysis, concept-based hyperspace organization, intelligent links between examples and problems, and adaptive navigation support. The article calls it "a winning approach to combine intelligent tutoring and adaptive hypermedia technologies into a consistent design that matches the hypertext nature of the Web". This paradigm served as a blueprint for later systems and authoring tools. (Gerhard Weber et al. (2016))
