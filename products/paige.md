# PAIGE

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
PAIGE is a prototype system developed by Tiffany D. Do and colleagues that converts textbook chapters and learner-profile information into fact-checked, personalized two-host educational podcasts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PAIGE system for converting textbook chapters into personalized AI-generated podcasts**: PAIGE is a system that converts OpenStax textbook chapters into two-host educational podcasts using "a multi-part generation pipeline using Gemini 1.5 Pro to generate podcast transcripts". The pipeline generates a configuration file from the textbook content and user profile, produces an outline based on the Skeleton-of-Thought concept, generates and fact-checks the transcript against the source textbook, and post-processes it for text-to-speech synthesis using an AudioLM-based voice model with two licensed voice-actor voices. (Tiffany D. Do et al. (2024))
