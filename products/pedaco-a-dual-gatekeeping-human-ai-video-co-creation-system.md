## Description
PedaCo is a human-AI collaborative software system that helps educators generate and evaluate instructional videos using CTML-informed script review and automated post-synthesis metrics.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PedaCo: a dual gatekeeping human-AI video co-creation system**: PedaCo (Pedagogical Co-creation) is a human-AI collaborative system that "integrates two complementary gatekeeping mechanisms: reviewing scripts through CTML-informed criteria, and an automated metric evaluating finished videos against computationally measurable CTML dimensions." Layer 1 intervenes before rendering: an LLM generates an initial script, an AI reviewer produces principle-organized feedback identifying potential violations, and the educator decides what to accept, revise, or regenerate. Layer 2 performs post-synthesis evaluation, automating five dimensions: coherence, redundancy, temporal contiguity, modality, and image quality. (When Saying No Makes Better Videos: Designing Dual Gatekeeping for Pedagogically Grounded )
