## Description
MissionMotion is a cross-platform web application developed to support kinematics learning by having students reproduce target motion graphs through real-time sensor or mouse-based interaction and feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MissionMotion web application for real-time kinematics graph reproduction**: MissionMotion is a cross-platform web application that "receives real-time data from sensors and displays it graphically alongside a target graph that the player/student must reproduce or imitate". A paper ball moves over a ruler-based reference system while position or velocity is visualized in real time; scoring is based on similarity between the student-generated and reference graphs. It offers difficulty levels, individual and collaborative modes, and input via mouse, trackpad, touchscreen, or ultrasonic sensors on micro:bit or Arduino, with immediate visual feedback intended to foster self-regulation through iteration. (Dutra et al. (2025))
- **Embodied gamified real-time graphing as a bridge between abstract representation and physical experience**: The article's explanatory framework situates the project at the intersection of physics education research, gamification, and computational thinking. It holds that linking real-world motion captured through sensors to a digital game interface lets students visualize their own movements as graphs in real time, and that this dual physical–digital interaction bridges abstract representations with embodied experience, reinforcing conceptual understanding through active participation. It is grounded in Pierre-Gilles de Gennes' critique that science education too often begins with abstraction rather than experience. (Mateo Dutra et al. (2025))
