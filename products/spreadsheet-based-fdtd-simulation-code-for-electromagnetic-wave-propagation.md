# Spreadsheet-based FDTD simulation code for electromagnetic wave propagation

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
An Excel-based finite-difference time-domain simulation code created by David W. Ward and colleagues that lets physics learners model and visualize one-dimensional electromagnetic-wave propagation using cell formulas, cut-and-paste operations, and updating charts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **A spreadsheet-based FDTD simulation code for electromagnetic wave propagation built entirely from Excel cell formulas and cut-and-paste**: The article describes an implementation of the one-dimensional finite difference time domain method in Microsoft Excel, where "columns represent spatial steps and pairs of rows (one for E and one for H) represent time steps." Students type formulas for only the second time step and first two columns; "cut and paste may be used to complete the remaining spatial columns and temporal rows." Graphs of the spatially and temporally evolving waveforms update in real time as the simulation runs. (David W. Ward et al. (2004))
