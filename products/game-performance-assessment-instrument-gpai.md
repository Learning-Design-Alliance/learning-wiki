# Game Performance Assessment Instrument (GPAI)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
The GPAI is a physical-education observational assessment instrument used to code students' in-game skill execution and tactical performance during live games or recordings.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Game Performance Assessment Instrument (GPAI) as the most utilized in-game performance tool in PE**: The GPAI is an observational tool developed and validated in 1998 specifically for PE settings, used to assess in-game performance variables such as skill execution and tactical variables (e.g., decision-making with the ball and off-ball support), with observations coded as successful/effective or unsuccessful/ineffective, typically during a game or from postgame video. The review reports that "the GPAI has become the most utilized tool to assess in-game performance (e.g., skill execution and tactical variables) in PE and sport school settings". Related tools named are the Team Sport Assessment Procedure (TSAP) and Game Performance Evaluation Tool (GPET). (Ray Breed et al. (2025))
