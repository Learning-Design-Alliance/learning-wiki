# 3DOVR-DR: a 3D object-based VR-simulation tool for learning dental radiography

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
3DOVR-DR is a Unity- and Oculus Quest 2-based virtual reality simulation tool developed by Im Ji-Eun et al. for teaching intraoral dental radiography procedures to dental hygiene students.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **3DOVR-DR: a 3D object-based VR-simulation tool for learning dental radiography**: 3DOVR-DR is an interactive virtual reality simulation of intraoral dental radiography built with the Unity 3D engine and displayed through an Oculus Quest 2 head-mounted display with controller interaction. A virtual dental radiography room and patient were modeled from 3D objects, and "The intraoral radiography process was divided into 12 steps" for step-by-step learning. Users manipulate the virtual sensor, positioning device and capture button, and review radiographs on a virtual monitor; successful completion of each task is required before advancing. (Im Ji-Eun et al. (2025))

### Claims
