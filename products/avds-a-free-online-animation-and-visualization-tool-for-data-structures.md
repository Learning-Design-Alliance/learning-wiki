# AVDS: a free online animation and visualization tool for data structures

## Description
AVDS is a free online web-based animation and visualization tool developed by Kogan et al. to support undergraduate learning of data structures and algorithms, with usage reports for teaching staff.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AVDS: a free online animation and visualization tool for data structures**: The AVDS tool is a free online animation and visualization tool developed to complement an undergraduate Data Structures course, covering "a classic set of algorithms and data structures commonly studied in the undergraduate data structures course." It provides interactive visualization of algorithm execution, including AVL tree rotations. Source code is available on GitHub, and the tool provides usage reports for teaching staff showing analytics per topic. (Kogan et al. (2024))
