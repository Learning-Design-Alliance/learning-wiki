## Description
A set of English group-administered intelligence-test instruments developed by Thomson and Ballard for school-age examinees.

## Components

- **New English group test materials: Thomson's Hindustani Test and Ballard's Cipher, Orientation, and Cryptogram Tests**: The reviewed book presents samples of group tests used in England, where many instruments are descended from American group tests but include new ideas the reviewer calls suggestive. Among the new types of material for group tests it names Thomson's Hindustani Test and Ballard's Cipher Test, Orientation Test and Cryptogram Test. As the reviewer puts it, "New types of material for group tests are Thomson's Hindustani Test and Ballard's Cipher Test, Orientation Test and Cryptogram Test." (R. P (1922))
