# Light and Shadow computer model (Easy Java Simulation)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
An interactive Easy Java Simulation model with draggable light sources, masks, objects, and screens for exploring umbra, penumbra, and antumbra formation, created by Mustafa Şahin Bülbül.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Light and Shadow computer model (Easy Java Simulation) with draggable sources, mask, object and screen and a 'what's wrong' trick mode**: A light and shadow computer model built in Easy Java Simulation whose main point is to show that "light rays leaving an object travel in straight lines". It has two independently switchable light bulbs that can be dragged to change positions; light passes through a mask with a hole or is blocked by an object travelling to a screen. Users can investigate how light and shadow patterns change by moving the bulbs, mask, object or screen and changing mask or object size. Selecting the "what's wrong" section makes the intersection area of two penumbras illuminated, creating the trick used in the study. (Mustafa Şahin Bülbül (2015))
