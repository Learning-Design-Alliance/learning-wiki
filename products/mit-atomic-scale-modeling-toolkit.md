# MIT Atomic-Scale Modeling Toolkit

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A nanoHUB graphical user-interface toolkit co-developed by MIT researchers that enables undergraduate and graduate learners to run research-grade DFT, quantum-chemistry, and molecular-dynamics simulations on remote computing clusters.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MIT Atomic-Scale Modeling Toolkit on nanoHUB for browser-based research-grade DFT and MD calculations**: The MIT Atomic-Scale Modeling Toolkit is a set of nanoHUB graphical-user-interface tools the author co-developed, which "can run first-principles density-functional theory (DFT) calculations on materials with the pseudo-atomic orbital code SIESTA and the plane-wave code Quantum ESPRESSO", quantum chemistry with GAMESS, and classical molecular dynamics in LAMMPS. Tools produce relaxed structures, band gaps, phonons, Raman and infrared spectra, and integrate visualization with XCrySDen and Jmol. "The GUI creates input files based on student-specified simulation parameters, and then launches the calculations in the cloud on remote clusters". (David A. Strubbe (2024))
