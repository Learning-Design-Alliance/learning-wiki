## Description
A multi-stage, multi-stakeholder assessment framework that converts reliability-aware linguistic evaluations into fuzzy values and ranks student performance criteria in PBL practical courses.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Z-MABAC multi-stage assessment framework for PBL practical courses**: The article introduces a data-driven assessment framework that integrates Z-number theory with the MABAC method to rank students in PBL practical courses. Z-numbers pair each evaluation with a reliability measure, so that 'assessments with higher uncertainty exert proportionally less influence on the final decision.' The framework runs in three phases — Pass check, Score determination, and Grading — aligned with PBL pedagogy, and uses a hybrid Entropy-CRITIC weighting scheme to set criteria weights objectively. (Yu Limin et al. (2026))
