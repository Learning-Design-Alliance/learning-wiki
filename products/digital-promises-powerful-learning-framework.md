## Description
The report defines Powerful Learning as Digital Promise's organizing framework for what powerful teaching and learning looks like. It states that Digital Promise defines Powerful Learning as 'fostering agency, purpose, curiosity, and connection, empowering learners with skills that prepare them for the future.' Each quality is elaborated: agency means learners pursue knowledge through action, choice, and voice; purpose means developing an authentic and meaningful contribution; curiosity means exploring new ideas; connection means making new connections among ideas, experiences, and people. The framework anchors the AI lab's vision and the report's recommendations.

# The Powerful Learning framework unifies learning science into a connection-centered vision

> **Theory** · [All theories](index.md)
> **Evidence** · 3 claims (3 for) · 3 studies (3 theoretical), `q1` · 0 of 3 report an effect size · 3 claims rest on one study

## Description
Powerful Learning is Digital Promise's unifying framework that synthesizes learning theories into a cohesive vision centered on human connection. It defines the construct as experiences that foster "agency, purpose, and curiosity through connection to ideas, self, people, and place," empowering learners with knowledge, skills, and dispositions for the future. The framework is intended to guide educators, designers, leaders, and policymakers toward shared design language.

- The report positions the framework as a response to fragmentation rather than as an empirically tested intervention

### Target Learning Objectives
