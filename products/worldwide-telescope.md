# WorldWide Telescope

> **Product or Programme** · [All products and programmes](index.md)

## Description
WorldWide Telescope is an interactive scientific data-visualization and aggregation software package developed by Microsoft Research, with astronomical imagery, a 3D Universe, and narrated interactive tours.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **WorldWide Telescope as a module-development technology requiring the least technical experience**: WorldWide Telescope (WWT) is described as "an interactive scientiﬁc data visualization and aggregation package developed by Microsoft Research," offering all-sky and high-resolution astronomical imagery and a 3D Universe visualization. Its key authoring feature is interactive narrated tours built from slides, which users can pause and manipulate during playback. The article identifies it as requiring "the least technical/programming experience of any of the technologies described here." (Nathan E. Sanders et al. (2013))
- **WorldWide Telescope (WWT) as a scriptable, interactive multi-wavelength browser of the Sky and Universe**: WWT is a free computer program released by Microsoft Research in 2008, described as "a scriptable, interactive, richly visual browser of the multi-wavelength Sky". It runs as a Windows desktop application and in a web browser via Silverlight, offering a menu-driven version and an API with a fully-functional data-viewing window plus added functionality such as the Finder Scope. It supports panning, zooming, a context globe, scale indicators, and all-sky multi-wavelength views. (Goodman et al. (2012))
- **WWT Tours: interactive paths through Sky or 3D content designed to make a point**: Tours are "interactive paths through WWT's Sky or 3D content designed to make a point". Ambassadors are trained to create Tours and to facilitate their use; expert-created or vetted Tours are served at the WWT Ambassadors website and from the program's Tours menu tab. Sample tours include Galileo's New Order and John Huchra's Universe. (Goodman et al. (2012))
- **WWT as a research data viewer interoperating with SAMP-compliant tools and serving professional research data via its web API**: In its web API format, WWT is used as a service to display professional research data; in desktop format it works in concert with traditional research applications such as ds9, Aladin, and TOPCAT thanks to SAMP and other IVOA standards. The article calls it "a fantastic viewer for manipulating, overlaying, and cross-matching image and catalog-based information". (Goodman et al. (2012))
