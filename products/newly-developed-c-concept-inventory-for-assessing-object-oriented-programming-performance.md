# Newly developed C++ concept inventory for assessing object-oriented programming performance

## Description
An 18-item multiple-choice concept inventory developed by Bostjan Bubnic and colleagues to assess second-course C++ students' knowledge of object-oriented programming concepts through definitional, code-tracing, and code-completion questions.
