# Orthotrainer

## Description
Orthotrainer is a web-based application developed for structured, case-based orthodontic diagnostic training, providing interactive 3D and radiographic cases with embedded sample-solution feedback for dental learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Orthotrainer web application for orthodontic case planning**: Orthotrainer is a web application for orthodontic case planning that combines "the analysis of intraoral 3D models, OPG evaluation and LCR landmarking in a single web application". Students can rotate and zoom digitised study models, mark cephalometric reference points, and receive immediate feedback after each task. Web-based delivery allows work on internet-enabled devices such as smartphones, tablets, PCs or laptops regardless of time and place. (Lang Norbert Alexander et al. (2025))
