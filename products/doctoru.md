## Description
DoctorU is a WeChat-based LLM virtual standardized-patient teaching system developed for medical history-taking practice, combining simulated patient dialogue with automated rubric scoring and formative feedback.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **DoctorU LLM-VSP teaching system with multiagent scoring and feedback workflow**: DoctorU is the LLM-VSP teaching system used for medical history-taking practice, built as "a multiagent workflow including LLM-VSPs agent, AI formative scoring agent, and AI feedback agent". The VSP agent simulates patient roles; the scoring agent scores single-session performance against a structured 100-point rubric (80 points content, 20 points communication) using semantic matching via a synonym library; the feedback agent generates immediate formative feedback covering completed content, missed information, logic deficiencies, and improvement suggestions. Thirteen cases were developed and reviewed by 8 diagnostic course instructors; the system was accessible via a WeChat miniprogram. (Stone Alicia et al. (2026))
