# VLab-HV

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
VLab-HV is an Unreal Engine 5 photorealistic 3D virtual high-voltage laboratory developed by Pliuhin et al. for conducting curriculum-aligned electrical-engineering experiments and simulations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Moodle API integration and Excel-compatible data logging in VLab-HV**: VLab-HV connects to institutional learning infrastructure in two ways. "Integration with Moodle via API enables instructors to track student progress, collect performance data, and provide targeted feedback, fostering a data -driven pedagogical approach." Separately, "The platform's data logging system records experimental parameters, such as voltage, current, electrode distance, and environmental conditions, in Excel -compatible formats, supporting advanced statistical analyses like regression mode ling or Monte Carlo simulations." C++ export code (Listings 3–4) writes logged data to files for instructor and researcher use. (Pliuhin et al. (2024))
- **AI-driven virtual assistant with NLP, voice prompts, and facial tracking in VLab-HV**: VLab-HV includes an AI assistant that guides learners through experiments. "The AI-driven virtual assistant, powered by Unreal Engine's behavior tree system and integrated with a natural language processing (NLP) module, supports voice prompts and facial tracking for an immersive user experience." It uses "a decision -making algorithm to guide users through experiments, administer real -time quizzes, and provide context -sensitive feedback." It also administers a quiz-based pre-assessment of 10 questions with a 60% passing score, incentivizing preparation through gamified rewards. (Pliuhin et al. (2024))
