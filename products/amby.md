## Description
AMBY is a graphical interface developed by Conrad Borchers and colleagues for middle-school students to create, train, test, and evaluate conversational agents while learning AI concepts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AMBY chatbot development environment for middle school conversational agent creation**: AMBY is "a graphical interface designed for middle school students to create conversational agents and learn about AI". Students test example agents, edit or create agents by defining intents, inputting training phrases, and writing responses, and submit training requests that update the chatbot's intent classification model. The system collects 23 types of timestamped user interaction logs, and pairs worked at one computer following the pair programming paradigm. In this study AMBY supplied both the learning task and the log data stream. (Conrad Borchers et al. (2025))
