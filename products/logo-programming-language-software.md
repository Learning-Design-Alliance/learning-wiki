# Logo programming language software

## Description
Logo is an educational programming language and turtle-graphics environment used in learning contexts, including for constructing geometric shapes and exploring mathematical concepts.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Logo programming language software for constructing two-dimensional shapes**: Logo is a dynamic educational programming language in which pupils write basic commands so that a turtle moves and constructs two-dimensional shapes. In this study, "The experimental group pupils were exposed to the construction of the two -dimensional shapes by writing the basic commands in Logo", requiring pupils to write commands so the turtle moves. The article positions Logo as software originally developed as a conceptual framework for children's construction of mathematical knowledge. (Boo Jia Yi (2016))
