## Description
A proposed multi-agent software workflow that transforms source problems into verified, isomorphic, LaTeX-formatted problem variants for introductory mechanics instruction.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **A five-stage LLM agent workflow for isomorphic problem generation: Normalizer, Extractor, Verifier, Generator, and Latexifier**: The article describes an agent-chain architecture in which specialized stages pass structured information to the next: a Normalizer converts the request into a configuration, an Extractor converts source problems into a schema-conformant file, a Verifier solves or checks items, a Generator creates isomorphic problems, and a Latexifier formats and compiles a PDF. The workflow uses "prompt chaining, structured agent-to-agent data passing, and containerized tool use" and includes automated verification and retry logic. (Xian Wu et al. (2026))
