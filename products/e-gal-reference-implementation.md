# e-GAL reference implementation

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
The e-GAL reference implementation is a web-based tool developed by Kremser Wolfgang et al. for remotely collecting, monitoring, and annotating webcam-recorded gesture-execution data.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **e-GAL reference implementation as a remote gesture-data collection and annotation tool**: Beyond its educational purpose, the article identifies a second use case for the reference implementation: collecting and labeling large amounts of gesture data remotely. During the field test the monitoring log accumulated 491 webcam-recorded gesture execution videos that instructors could review and label in the monitoring module's web interface. The article notes: "It can collect and label large amounts of gesture data remotely and with little effort." The authors suggest this can be used, for instance, to generate large gesture datasets for machine learning. (Kremser Wolfgang et al. (2021))
