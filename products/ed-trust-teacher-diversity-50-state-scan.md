## Description
A publicly available Ed Trust web-based data tool that lets state leaders, advocates, and researchers explore educator-diversity indicators by state.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Ed Trust Teacher Diversity 50-State Scan data tool**: The Ed Trust Teacher Diversity 50-State Scan is a publicly available data tool at https://edtrust.org/educator-diversity/ that lets users see how each state fares on educator diversity. The brief directs readers to visit each state's page for a deeper dive beyond the seven-state chart, and the tool underpins the state educator diversity briefs used at the convening. (EdTrust (2022))
