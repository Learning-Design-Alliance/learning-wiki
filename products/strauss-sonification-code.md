# STRAUSS sonification code

> **Product or Programme** · [All products and programmes](index.md)

## Description
An open-source code package with example scripts released by Chris Harrison and colleagues for creating sonifications of astronomical data for astronomy communication and education.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **STRAUSS sonification code released for others to develop their own sonifications**: STRAUSS is the open code the authors used to produce the show's sounds from actual astronomical data, "also used in astronomy research". The article states the code "is released on GitHub with some example scripts used to create the sonifications for Audio Universe: Tour of the Solar System", and the authors encourage show developers to explore using it for their own sonifications. It is presented as a reusable tool lowering the barrier to producing sound-based astronomy communication resources. (Chris Harrison et al. (2023))
- **STRAUSS: open-source Python package for flexible data sonification**: STRAUSS is the open-source Python code used to produce all sonifications in both versions of the show. As the article describes it, "STRAUSS is designed to flexibly generate rich data sonifications, through controlling a range of properties of sound." It can use data to directly synthesize audio or manipulate audio samples, and enables flexible spatialization by assigning each sound a directionality via polar and azimuthal angles mapped onto user-defined audio formats such as stereo and 5.1 surround sound. (Chris M. Harrison et al. (2025))
