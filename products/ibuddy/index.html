iBuddy¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

iBuddy is a locally hosted mobile, server, and browser software system developed by Botturi et al. for running classroom simulations that raise awareness of app-based personal-data collection and use.

Components¶

  • iBuddy simulation system (app, local server, browser client): iBuddy is a 2-hour class simulation in which students install an app to configure a fictional android classmate; the system collects personal data (gallery pictures, contacts, installed apps and usage time) on a local server and generates custom questions displayed to the class to produce a wow effect. The functional architecture is "composed by three parts": a Mobile Client, a local Server, and a Browser Client. The local network is isolated from the internet and all data are deleted during the session. (Luca Botturi et al. (2024))

Claims¶

  • The simulation with the creation of the artificial buddy was the most appreciated part of the session (45.40% of open answers) [+M]
  • Students across all school levels rated the iBuddy session as enjoyable, useful and important, with importance highest (M = 8.96) [+M]
