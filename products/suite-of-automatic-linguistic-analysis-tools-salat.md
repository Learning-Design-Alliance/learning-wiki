# Suite of Automatic Linguistic Analysis Tools (SALAT)

> **Product or Programme** · [All products and programmes](index.md)

## Description
SALAT is a researcher-developed software suite comprising GAMET, SEANCE, TAACO, TAALED, TAALES, and TAASSC for extracting linguistic and textual features from learner writing for analysis and scoring.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SALAT NLP tool suite extracting 1592 writing features for rubric scoring models**: The study processed 1567 essays with the Suite of Automatic Linguistic Analysis Tools (SALAT) — GAMET, SEANCE, TAACO, TAALED, TAALES, and TAASSC — yielding "a total of 1592 writing features" covering grammar/mechanics errors, sentiment and cognition, text cohesion, lexical diversity, lexical sophistication, and syntactic complexity. After filter methods (variance pruning, correlation pruning at |r| > 0.9, removal of word/token counts) features were reduced to 397, with Lasso/Ridge (ElasticNet) regularization performing customized per-rubric selection during training. (Kumar et al. (2020))
