Description¶

A school-based support programme for expectant and parenting teens, evaluated in Washington, DC, to improve students’ educational outcomes.

Components¶

  • The New Heights Evaluation: a set of 2017 impact and implementation studies underlying the roadmap: This page lists the evaluation publications on which the roadmap rests, including "The New Heights Evaluation: The Impact of New Heights on Closing the Achievement Gap" and "The New Heights Evaluation: Implementing an Effective School-Based Program for Expectant and Parenting Teens", both dated Jun 29, 2017, plus "Raising the Bar: Impacts and Implementation of the New Heights Program for Expectant and Parenting Teens in Washington, DC". These reports supply the impact and implementation evidence summarized here. (Subuhi Asheer et al. (2020))
  • Program elements and practices used together improved academic outcomes for New Heights participants: The study's central pattern is that it was the program elements and practices "when used together" that improved academic outcomes for New Heights participants, rather than any single component in isolation. The page frames this combination as defining "a possible roadmap for service providers interested in replicating the program's success". The pattern concerns a coordinated system of school-based supports for expectant and parenting students. (Subuhi Asheer et al. (2020))
