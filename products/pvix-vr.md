## Description
Pvix VR is a virtual-reality self-training system developed by eped Inc. that provides interactive simulated oral-health-care practice, instructions, and corrective feedback for nursing learners.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VR Oral Health Care Learning System (Pvix VR) for geriatric oral health care training**: A virtual reality self-training system (Pvix VR, eped Inc., Taiwan) that "utilized positioning motion recognition technology and a built-in virtual interactive software to assist in the self-training." Learners wear 3D glasses with a remote control and practice step actions in a simulated scene of an older man in a wheelchair with partial dentures, natural teeth, and dry mouth. The system presents speech and text instructions and generates corrective feedback when learners answer evaluation questions incorrectly. (Lin Pei-Chao et al. (2024))

### Claims
