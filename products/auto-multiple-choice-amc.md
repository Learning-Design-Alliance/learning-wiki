## Description
Auto-Multiple-Choice is free assessment software used by instructors to prepare, scan, and automatically grade paper-based multiple-choice tests and homework.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Auto-Multiple-Choice (AMC) program for computer-based grading of multiple-choice homework**: AMC is a free program for tests based on multiple choice questions, used to automate grading of the SST homework. It grades a scanned image of the answer matrix, offers an option allowing multiple correct answers (implying possible absence of any correct answer), and can attribute negative points to incorrect answers. It runs on Windows and most Linux releases, uses a graphical interface with LaTeX or its own command set, and is versatile but, per the author, not always easy to use. (G.L. Lippi (2018))
