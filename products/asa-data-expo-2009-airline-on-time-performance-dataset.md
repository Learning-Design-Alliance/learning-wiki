## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ASA Data Expo 2009 airline on-time performance dataset as the recurring data backbone for programming assignments**: Many programming assignments used "the airline on-time performance data set from the American Statistical Association (ASA) Data Expo 2009," originally from the Bureau of Transportation Statistics, tracking all commercial U.S. flights between 1987 and 2012. The full data set has "more than 120 million records in total and taking up twelve Gigabytes," so the course instead used the 2001 CSV file with around six million rows, twenty-nine columns, and 573 Megabytes. Assignments built on it included aggregating flight counts and temperatures for the top twenty airports and PCA-plus-k-means clustering of aircraft. (Robert J. Brunner et al. (2016))
