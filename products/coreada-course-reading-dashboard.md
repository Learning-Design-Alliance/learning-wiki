## Description
CoReaDa is a dashboard tool developed by Madjid Sadallah for course authors to interpret learners’ reading traces and generate targeted course-content revision recommendations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CoReaDa (Course Reading Dashboard) analytical tool**: CoReaDa is the article's analytical tool that "processes reading traces and suggests targeted revisions based on identified comprehension issues". It presents actionable insights from reading activity in an interactive dashboard so that authors, who may lack technical expertise, can iteratively refine their materials. The tool operationalizes the usage-based reengineering framework by turning raw interaction data into tailored content revision recommendations. (Madjid Sadallah (2024))
