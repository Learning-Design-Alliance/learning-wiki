# ML-enhanced nanoHUB tool: Ions in nanoconfinement

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A nanoHUB-hosted Jupyter-notebook web application developed by Vikram Jadhao for running or accelerating molecular-dynamics studies of ions in nanoconfinement for computational science and engineering education.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ML-enhanced nanoHUB tool: Ions in nanoconfinement**: A Jupyter-notebook-based nanoHUB web application wrapping MD simulations of ions confined between planar interfaces, with an added "Predict using ML" button that activates the ANN surrogate to predict half the density profile instantaneously. Users can run explicit simulation on a cluster or VM, or use the surrogate, with outputs plotted on tool tabs. It was deployed in October 2019 and used in two IU courses for in-class demonstrations and homework. (Vikram Jadhao (2020))
