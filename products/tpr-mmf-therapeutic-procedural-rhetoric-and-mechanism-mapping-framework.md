# TPR-MMF: Therapeutic Procedural Rhetoric and Mechanism Mapping Framework

> **Product or Programme** · [All products and programmes](index.md)

## Description
A three-layer framework developed by Hsu et al. for designing serious games that translate cognitive distortions into game mechanics, expectation violations, and feedback intended to support cognitive restructuring and mental-health reflection.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TPR-MMF: Therapeutic Procedural Rhetoric and Mechanism Mapping Framework**: TPR-MMF is a three-layer CBT-informed framework for designing serious games that abandon explicit mental health instruction in favor of procedural rhetoric. The first layer translates a target group's vulnerable psychological characteristics into cognitive restructuring goals; the second, the "construction layer of cognitive dissonance mechanism," turns those goals into game rules that deliberately block default paths and trigger "expectation violation"; the third builds feedback that guides players to try new approaches, so that success provides embodied "behavioral validation" that can "shake and reconstruct the original cognitive system." (Hsu et al. (2026))

### Claims
