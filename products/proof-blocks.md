# Proof Blocks

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Proof Blocks is a software tool that lets undergraduate students construct mathematical induction proofs from prewritten lines and receive automated feedback on incorrect steps and misconceptions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Proof Blocks learning activity with paired distractor lines and targeted feedback**: Proof Blocks is a software tool with which students "construct proofs by assembling prewritten lines" and receive automated feedback. In this study's Distractors condition, five induction problems showed distractor lines "visually paired with the corresponding correct line", with targeted feedback about the misconception when a distractor was selected. Activities and tests ran on the OHEP platform in a proctored testing center. (Seth Poulsen et al. (2023))
