## Description
A metadata schema developed by the mEducator project for semantically describing, retrieving, and repurposing medical educational resources such as virtual patient cases.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **The mEducator metadata schema for describing and repurposing medical educational resources**: The mEducator schema defines the metadata accompanying an educational resource such as a virtual patient case, and is designed to support specific functions including retrieval and repurposing. It is based on the established Health Care Learning Object Metadata standard, itself an extension of IEEE Learning Object Metadata, and "consists of 10 mandatory fields and a number of optional fields" covering identifier, title, creator, intellectual property rights license, language, dates, keywords, and description, with optional fields such as educational objectives and discipline. A widget for searching SNOMED and MeSH terms via the NCBO BioPortal platform supports coding consistency. (Dafli E et al. (2015))
