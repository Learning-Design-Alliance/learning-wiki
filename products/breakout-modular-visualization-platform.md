# Breakout modular visualization platform

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A JavaScript and D3.js platform developed by Dana Calacci and colleagues for researchers to build modular, real-time visualizations from analytics-engine data and display them alongside online group video communication.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Breakout modular visualization platform for real-time D3.js visualizations as interventions**: The visualization platform lets researchers build modular, real-time visualizations from analytics engine data, implemented in JavaScript using D3.js. The article states it "allows researchers to utilize real-time visualizations as an intervention strategy for online group communication studies". A built-in example is a Meeting Mediator visualization in which a central ball moves toward participants taking more turns and line thickness corresponds to participation levels, displayed beside the video chat and updating in real time. (Dana Calacci et al. (2016))
