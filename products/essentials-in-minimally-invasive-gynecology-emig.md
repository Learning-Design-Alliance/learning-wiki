# Essentials in Minimally Invasive Gynecology (EMIG)

## Description
AAGL's EMIG is a gynecologic minimally invasive skills-training package combining a cognitive question database, online didactic materials, and laparoscopic and hysteroscopic psychomotor simulation exercises.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Essentials in Minimally Invasive Gynecology (EMIG) laparoscopic and hysteroscopic simulation systems with seven structured manual skills exercises**: The EMIG simulation system comprises a LaparoBowl trainer for five laparoscopic exercises (L-1 sleeve-peg transfer, L-2 pattern cut, L-3 extracorporeal tie, L-4 intracorporeal knot, L-5 running suture) and a "low-fidelity" modular hysteroscopy system for two exercises (H-1 targeting, H-2 polyp removal). Each exercise has defined tasks, maximum allowable times (e.g. 330 seconds for L-1, 600 seconds for L-3 and L-5), and recorded error metrics such as dropped sleeves, crossing lines, and air knots. The system was developed by the AAGL as part of a project "comprising a cognitive question database with supportive online didactic materials and a psychomotor skills simulation system with laparoscopic and hysteroscopic exercises specific to gynecologic surgery." (Essentials in Minimally Invasive Gynecology Manual Skills Construct Validation Trial.)

### Claims
- [EMIG laparoscopic exercise completion times are significantly shorter for mid-level (PGY-3) residents than for novice (PGY-1) residents across all five laparoscopic exercises](../claims/emig-laparoscopic-times-distinguish-novice-midlevel.md) [+M]
- [EMIG hysteroscopic exercise completion times distinguish novice from mid-level residents and proficient from expert surgeons, though differences are less profound than for laparoscopic exercises](../claims/emig-hysteroscopic-times-distinguish-cohorts.md) [+M]
