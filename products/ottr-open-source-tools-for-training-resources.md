# OTTR (Open-source Tools for Training Resources)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
OTTR is an open-source toolset used by curriculum developers to create, version-control, automate, and maintain educational curricula and generate exercise notebooks.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **OTTR: Open-source Tools for Training Resources for curriculum creation and maintenance**: OTTR (Open-source Tools for Training Resources) is a toolset the authors use to create and maintain their curricula with minimal maintenance pain: "We use Open-source Tools for Training Resources (OTTR) to create our curriculum." It supports version-controlling curricula on GitHub, using permissive licenses such as CC-BY, and automating maintenance; the authors also use the exercise package to automatically generate exercise notebooks without solutions. (Savonen et al. (2023))
