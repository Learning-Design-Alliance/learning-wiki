## Description
A proposed intelligent learning-environment architecture that models students' cultural and linguistic backgrounds and dynamically adapts educational content through a contextual student model, repository, language adapter, and controller.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **ICON system: dynamic intracultural contextualisation architecture for ILEs**: ICON (Instructional Cultural cONtextualisation) models conceptual and linguistic variations across the subcultures in a student's background and generates culturally adapted educational content dynamically. Its architecture comprises four components: "a Contextual Student Model, Contextual Element Repository, Cultural Linguistics Adapter, and a Controller". The CSM estimates metacultural competence via weighted rule-based membership scores; the repository selects culturally appropriate images and terms using the CERA ontology; the adapter varies formality (acrolect/mesolect/basilect) and substitutes localized vocabulary measured as sentence distortion; the Controller links ICON to the host ILE. (Phaedra Mohammed et al. (2015))
