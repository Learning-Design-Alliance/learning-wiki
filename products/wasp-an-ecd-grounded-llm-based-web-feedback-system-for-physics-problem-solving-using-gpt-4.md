# WasP: an ECD-grounded LLM-based web feedback system for physics problem solving using GPT-4o

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
WasP is a web-based GPT-4o feedback system developed by Holger Maus et al. for German Physics Olympiad participants to receive evidentiary-scheme-grounded feedback and revise physics problem solutions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **WasP: an ECD-grounded LLM-based web feedback system for physics problem solving using GPT-4o**: The article describes a web application, made available to German Physics Olympiad participants as a voluntary training tool, in which students work on up to six problems in fixed sequential order and receive a two-step feedback process: feedback on their initial approach, a prompted revision, then final feedback on the revision. The backend uses "OpenAI'sGPT-4omodel (snapshot gpt-4o-2024-08-06)" via the API with temperature 0.7, and prompts combine the student solution with a problem-specific evidentiary scheme and a feedback specification that forbids revealing the full solution and caps feedback length at 100 words. A full response–feedback–response–feedback cycle cost "approximately USD 0.007 (0.7 cents)". (Holger Maus et al. (2025))
