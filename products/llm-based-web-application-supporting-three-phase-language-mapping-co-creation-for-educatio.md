# LLM-based web application supporting three-phase language-mapping co-creation for educational game design

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (1 for, 1 mixed) · 1 study (1 design), `q1` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A full-stack web application that uses structured LLM prompting, phase-based language mapping, collaborative editing, and versioned artifact storage to help instructors design educational games aligned with learning outcomes.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Three-phase instructor-AI co-creation workflow: requirement extraction, language translation, and language development**: A reusable co-creation workflow in which the web tool 'structures instructor–AI collaboration across requirement extraction, language translation, and language development'. Instructors iteratively refine both teaching-language and game-language representations while preserving fine-grained control; the translation phase generates multiple candidate game-language translations with component-wise rationales, and the interface uses color mapping to link corresponding grammatical elements, culminating in pseudocode as the design output. (Daijin Yang et al. (2026))
