## Description
An open-source JavaScript library maintained by the D3 community for binding data to web documents and producing interactive visualizations such as charts, network graphs, and maps.

# JavaScript with the d3.js library as a web-native module-development technology

> **Element** · [All elements](index.md)

## Description
JavaScript is an interpreted scripting language whose functionality "will be familiar to users of other scripting languages popular among graduate student researchers, such as Python." The d3.js library ("Data Driven Documents") supports display of scientific data in formats from line plots and bar charts to network graph browsers and map projections. Scores of example pages with full source code and data files serve as templates for student module development.

## Design Implications

### Context
#### Requirements
- Students need "familiarity with other web technologies, including HTML for web page development, and access to a web server for hosting."
#### Constraints
- Developing advanced visualizations requires "signiﬁcantly more technical expertise from authors" than WWT.

### Target Learners
- graduate students authoring modules
- undergraduate and graduate astronomy students using modules

- interactive visualization of astrophysical concepts
