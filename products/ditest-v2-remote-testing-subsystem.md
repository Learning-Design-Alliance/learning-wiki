# DiTest v2 remote testing subsystem

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
DiTest v2 is the IMS QTI 2.0-compatible browser-based testing subsystem of Novosibirsk State Technical University's DiSpace 2.0 distance-learning system, supporting remote assessment through computers and smartphones.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **DiTest v2 remote testing subsystem supporting IMS QTI 2.0**: DiTest v2 is the testing sub-system of the DiSpace 2.0 distance learning system developed at Novosibirsk State Technical University. It "supports the international Question&Test Interoperability (QTI) specification (version 2.0) from IMS", which standardizes test task databases and makes them independent of the program shell. It consists of three autonomous sub-systems and two databases, and is accessed via a browser so testing can use student smartphones. (A. D. Zaikin (2013))
