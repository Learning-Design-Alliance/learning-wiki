## Description
SoftBank Robotics' NAO humanoid robot and Choregraphe visual programming environment enable developers to create multimodal behaviors using voice, vision, touch, and movement for educational and other applications.

## Components

- **NAO humanoid robot with Choregraphe programming environment for embodied educational support**: The article cites the humanoid robot NAO, used to support students with autism spectrum disorders, as a notable advancement transferring Embodied AI principles into education. Its programming environment Choregraphe "relies on visual blocks and Python code, facilitates the creation of integrated multimodal behaviors (voice, vision, touch, movement)", yet the article reports it "still lacks flexibility in unpredictable scenarios", with improvisational and adaptive operation remaining in early stages.
