## Description
A computerized real-time classroom-observation instrument developed at UC Davis to code and quantify instructor–student interaction patterns for research and teaching-assistant or faculty professional development.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **RIOT: Real-time Instructor Observing Tool for coding instructor-student classroom interactions**: The Real-time Instructor Observing Tool (RIOT) is a computerized classroom-observation instrument developed at UC Davis to document instructor-student interactions in discussion/lab sections. It differentiates talking at students, dialoguing with students, observing students, and not interacting, each with subcategories; the authors describe it as 'a computer program that allows us to code during actual classroom observations, to time and quantify the instructor-student interactions.' It serves research and TA professional development. (Emily A. West et al. (2012))
- **Real-time Instructor Observation Tool (RIOT)**: The RIOT is a classroom observation tool, originally developed at UC Davis and later made publicly available by a team at San José State University, that "quantiﬁes and times these interactions, providing a more illustrative view of what actually takes place in a given TA's classroom." It categorizes instructor actions continuously in real time into four major groups — talking at students, shared instructor-student dialogue, observing students, and not interacting — each with subdivisions, logged with interaction type, start time, and duration. This study used it to code TA-student interactions, with inter-observer agreement of 88.5% and Cohen's kappa of 82.5%. (Eric Matthew Hickok (2015))
