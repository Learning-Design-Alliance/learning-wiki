StatBot¶

Product or Programme · All products and programmes
Evidence · 5 claims (5 for) · 1 study (1 associational), q2 · 1 of 1 report an effect size · 5 claims rest on one study

Description¶

StatBot is a retrieval-augmented GPT-4 chatbot developed and deployed by Yuan-Hsuan Lee et al. as a voluntary virtual teaching assistant for graduate statistics courses.

Components¶

  • Chatbot-based digital tutor app (progressive web app) for large-scale lectures: The developed artifact is a fully-functional progressive web app with a chat-based student interface, content overlays, and a sidebar, built with the Bootstrap framework and AJAX calls to RESTful web services, with a separate AdminLTE-based interface for teaching assistants and lecturers. Message processing uses the NLP.js library, with the natural language processing classifier "trained with approximately 3000 dialog entries". It integrates a learning object data storage, a micro content database, formative quiz question storage, an audience response system, and a learning action log. (Sebastian Hobert (2023))

Claims¶

  • Growing Achievers used StatBot significantly more than Declining Performers, driven mainly by initiating new inquiries [+W]
  • Female gender, higher autonomous motivation, lower prior knowledge, and higher final course grades each predict more frequent voluntary StatBot use among graduate statistics students [+W]
  • Voluntary StatBot use was highly uneven and deadline-driven, with about 27% of students never using the chatbot [+W]
  • Higher-achieving graduate students were less likely to abstain entirely from StatBot use [+W]
  • Student chatbot queries were overwhelmingly task-oriented initial inquiries, dominated by definition requests and pasted assignment questions rather than iterative critique [+W]
