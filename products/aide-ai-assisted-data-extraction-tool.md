# AIDE: AI-Assisted Data Extraction tool

## Description
A free, open-source R package and web application developed by Schroeder et al. that assists education researchers with LLM-based systematic-review data extraction while requiring human review and recording of each response.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AIDE: AI-Assisted Data Extraction tool (R package and web version)**: AIDE is a free, open-source tool for human-in-the-loop LLM-based data extraction in systematic reviews, available as an R package (https://github.com/noah-schroeder/AIDE) and a web version (https://noah-schroeder.github.io/AIDE-Web/). It sends a PDF's full text and coding-form prompts to an LLM API, auto-populates responses in a user interface, shows the LLM's reasoning and source page, and requires the user to press Record after reviewing or editing each answer. The web version stores API keys in sessionStorage and uses structured JSON response parsing. (Schroeder et al. (2025))
