## Description
A 29-item, seven-subscale fidelity assessment developed for evaluating implementation of school-wide positive behavioral interventions and supports through site visits, observations, and interviews.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **School-Wide Evaluation Tool (SET) for assessing SW-PBIS implementation fidelity**: The School-Wide Evaluation Tool (SET) is a research tool designed to assess and evaluate the critical features of SW-PBIS. "The SET consists of 29 items organized into the following seven subscales that represent the seven key features of SW-PBIS," including Expectations Defined, Behavioral Expectations Taught, and District-Level Support. In Minnesota, an independent SET evaluator completed the SET during a two and one half hour site visit, and full implementation is defined as a score of 80 or better overall and 80 or better in Behavioral Expectations Taught. (Ryoo et al. (2018))
