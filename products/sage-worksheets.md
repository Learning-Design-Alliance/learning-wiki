## Description
Sage Worksheets are interactive executable worksheets in the SageMathCloud environment, maintained by the SageMath project, for running mathematics, programming, and documentation commands within learning materials.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Sage Worksheets as interactive executable learning resources in SageMathCloud**: Sage Worksheets (*.sagews) are Sage working sheets that allow interactive execution of commands of computer mathematics systems (Sage, Axiom, R, Pari, Octave and others), of programming languages (C, C++, Python, Java, Julia and many others), and of documentation languages (HTML, Markdown). By default SageMath commands run on the sheets; commands of other systems are invoked via IPython magic commands such as %r, %octave or %julia at the start of a cell. The article shows reference-style materials and interactive workbooks built on them. (Shokaljuk S. V. et al. (2017))
