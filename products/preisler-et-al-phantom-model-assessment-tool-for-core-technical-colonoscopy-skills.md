# Preisler et al. phantom-model assessment tool for core technical colonoscopy skills

> **Product or Programme** · [All products and programmes](index.md)

## Description
A rater-administered 0–2 scoring instrument assessing five core technical colonoscopy skills during performance on an adjustable phantom model, developed by Preisler and colleagues for competency assessment and standard setting.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Purpose-built phantom-model assessment tool rating five core technical colonoscopy skills on a 0-2 scale**: Because the phantom model supplies no automatic metrics, the research group created "a simple and operational assessment tool" rated during the procedure. It scores five core technical skills — handling of the scope, safe scope advancement, extensive force used, visualized mucosa during withdrawal, and successful looping in rectum — on a scale from 0 to 2 points. Metrics with discriminatory ability were aggregated into a per-minute score used for standard setting. (Preisler Louise MD et al. (2015))
