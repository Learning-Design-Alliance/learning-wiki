## Description
An open-source Streamlit application developed by Elakkiya Rajasekar for traceable outcome-based attainment reporting and continuous-improvement records.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Public OBER+ implementation as a Streamlit web application with open source code and deployed instance**: The rules are implemented in Python as a single web application on the Streamlit framework, with three layers: an interface layer with reproduced reporting screens and one screen per 5R stage, a logic layer holding the attainment computation and rule engine, and a data layer storing courses, matrices, marks, mappings, decision records and the change log. The code is "version-controlled in the public repository github.com/Elakkiya16/OBER_Plusand deployed atoberplus.streamlit.app[5]", making every reported quantity independently reproducible. (Elakkiya Rajasekar (2026))
