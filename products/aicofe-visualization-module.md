## Description
AICoFe's Visualization Module is a Dash-based learning-analytics dashboard system developed by Becerra et al. that provides distinct evaluation, student, teacher, and administrator interfaces.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Role-specific Learning Analytics dashboards for evaluators, students, teachers, and administrators**: AICoFe's Visualization Module provides interactive Learning Analytics dashboards developed with the Dash framework, each tailored to the user's role. The Evaluator Dashboard supports Likert scoring with qualitative comments and captures interaction metadata such as timing of score selections to explore evaluation dynamics and detect potential biases. The Student Dashboard supports self-assessment against the same rubric and visualises differences between self-assessment and aggregated evaluations. The Teacher Dashboard supports feedback review and curation, and an Admin Dashboard handles configuration. (Alvaro Becerra et al. (2026))
