# Large-scale field study dataset and code release for AI-generated exam evaluation

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A publicly released dataset and code package containing field-study student responses, AI-generated and comparison exam materials, and analysis code for evaluating course-tailored exams, produced by Calvin Isley and colleagues.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Released dual-graded exam datasets, ablation grid, and grading, fine-tuning and analysis pipelines**: The article releases two anonymised dual-graded exam datasets (CV exam, 570 students; ML exam, 1,038 students), the rubrics and reference solutions, one result workbook per configuration, and the analysis, grading and fine-tuning pipelines. The authors state that "Every number in the paper is regenerated from released artifacts by released code", making the released ledgers the authority for the manuscript. The artifact supports replication of the persona-collapse and fine-tuning findings. (Habibullah et al. (2026))
- **Two-instrument evaluation dataset: chemistry diagnostic and psychometric quantitative chapter with injected chatbot responses**: The study's empirical base is a pair of authentic MCQ instruments from very different contexts. The first was "a chemistry diagnostic examination administered via a Moodle platform as a formative assessment activity" with 22 MCQs and 931 high-school respondents; the second was a 20-item quantitative chapter from a high-stakes psychometric entrance exam with over 4,800 respondents. Both are multi-modal, containing images/figures and formulas. GenAI responses were generated by running each of three premium chatbots 20 times per instrument as new sessions, with non-zero temperature, and non-answers counted as incorrect. (Alona Strugatski et al. (2025))
