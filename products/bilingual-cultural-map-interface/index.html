Bilingual Cultural Map Interface¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

An open-source AI-assisted bilingual geospatial visualization prototype created by the DiscoverKunshan project for mapping culinary and cultural heritage sites through categorized markers, filters, and bilingual information panels.

Components¶

  • Bilingual Cultural Map Interface (DiscoverKunshan open-source geospatial prototype): The Bilingual Cultural Map Interface is the AI-assisted prototype produced in the case: an interactive website with categorized location markers for culinary and cultural sites, bilingual (Chinese/English) pop-up panels, and filter controls, built via Python preprocessing and Plotly/Folium visualization with Claude Code as an AI-assisted design partner. The "MIT-licensed release enacted reciprocity as digital public goods," with data and source code released on a public GitHub repository for reuse by subsequent cohorts and community partners. (Jiaojiao Zhao et al. (2026))

Claims¶

  • Co-design dialogue with museum educators revealed an unmet need for digital infrastructure, which students addressed with a bilingual cultural map extending the museum's spatial storytelling [+M]
  • The bilingual cultural map functioned as a boundary object supporting divergent interpretations across students, museum educators, and end-users without requiring semantic consensus [+M]
