# STAC bystander bullying intervention program

## Description
A school-based bystander bullying intervention programme that trains selected junior-high students to act as defenders using the strategies Stealing the Show, Turning It Over, Accompanying Others, and Coaching Compassion, with follow-up support facilitated by school counselors.
