# Hybrid OBT+MBT framework for automatic MCQ stem generation

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A hybrid question-generation system that combines ontology-based Wh-question generation with machine-learning-based Cloze generation for technical-domain multiple-choice assessment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Hybrid OBT+MBT framework combining ontology-based and machine-learning-based generation of heterogeneous MCQ stems**: The article proposes a hybrid automatic question generation framework in which an Ontology-Based Technique (OBT) generates Wh-type question stems from DL and SWRL rules built over a domain ontology, while a Machine-Learning Based Technique (MBT) generates Cloze stems from unstructured textbook text. As the article states, it "describes a technique for combining semantic-based and machine-learning-based techniques to generate grammatically correct MCQ stems of various types for a technical domain." The two pipelines run simultaneously on a preprocessed text file, and the resulting stems are evaluated against Bloom's Taxonomy cognitive levels. (Praveen Kumar et al. (2024))
