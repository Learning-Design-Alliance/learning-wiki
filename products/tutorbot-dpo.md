## Description
The University of Massachusetts authors' tutorbot-dpo repository provides code and rubric- and student-model-based preference data for reproducing their distillation-plus-DPO training pipeline for LLM math tutors.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Publicly released code and preference-optimization data for training outcome-maximizing LLM tutors**: The authors release their code publicly at a GitHub repository (umass-ml4ed/tutorbot-dpo) to facilitate further research. They state: "to facilitate further research, we publicly release our code and encourage researchers and practitioners with access to real-world tutoring dialogue settings to build on our work." The release supports reproducing the distillation-plus-DPO training pipeline and the rubric- and student-model-based preference pair construction. (Alexander Scarlatos et al. (2025))
