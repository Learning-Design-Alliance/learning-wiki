## Description
Named projects providing standalone, scaffolded astronomy learning activities in which undergraduate, advanced, and self-directed learners analyze Sloan Digital Sky Survey data using professional interfaces.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SDSS Voyages activities working with professional survey data**: SDSS Voyages and Sky Server projects provide activities that work with professional data from the Sloan Digital Sky Survey, using the same interface professionals use. Activities cover introductory through advanced materials; participants build skills and scaffold so they can go farther if they want, and motivated users can extend to more SDSS projects or apply skills elsewhere. The article states these projects "provide activities that work with professional data from SDSS, using the same interface professionals use". No special software is needed and the exercises are standalone. (L. M. Rebull (2018))
