## Description
A prototype design-support tool implementing the Training Program Design phase of the MASTER method, developed by Verstegen et al. for novice instructional designers specifying training simulators.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **MASTER-TPD prototype tool for training program design**: A prototype tool implementing the Training Program Design phase of the MASTER method, customised from Designer's Edge (DE 2.0, 1997). It guides users through six main steps with sub-steps and Notepads, logs user actions, and 'supports iteration because intermediate results (including the subjects’ notes) remain available'. 'A small number of warnings appears automatically when an event that is a likely cause for iteration can be measured.' (Verstegen et al. (2006))
