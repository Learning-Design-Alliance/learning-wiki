# Digital evaluation system with 3D deviation maps and quantitative cavity parameters

## Description
A software system developed by the authors' team with a domestic company that registers scanned student-prepared teeth against reference models and reports color-coded deviations, preparation parameters, grades, and scores for dental training.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Aizhixing Digital Real-Time Evaluation System DHC210 for real-time Class II cavity preparation training**: The Aizhixing DHC210 is a real-time dental evaluation system using infrared navigation to track operator movements on realistic artificial teeth. The article states it "provides real-time spatial positioning and instantaneous grading of all preparation details through a combination of a phantom head and dentoform, dental instruments, infrared sensors, infrared cameras, and computer system". Operators monitor preparation on screen, compare it with standard morphological guidelines, and adjust cutting volume using graphical tips in practice mode; a step-by-step playback function supports targeted faculty feedback. It was used with four practice-examination cycles in this pilot. (Zhang Yuejiao et al. (2025))
