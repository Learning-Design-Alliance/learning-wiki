## Description
EduVideo Insights is a web-based application developed by Tolba et al. for scalable analysis and benchmarking of educational videos using automated metadata retrieval and audiovisual feature extraction.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **EduVideo Insights web-based application**: EduVideo Insights is a web-based application the authors are developing to operationalise the workflow: "a web-based application, named EduVideo Insights, is also under development, enabling scalable analysis and benchmarking of educational videos". It automates YouTube metadata retrieval via the YouTube Data API, extracts video characteristics using OpenCV (duration, scene transitions) and Whisper (word count, speaking speed), organises features into structured datasets tagged by video ID and dataset tag, and exposes all workflow stages through a navigation interface. (Tolba et al. (2025))
