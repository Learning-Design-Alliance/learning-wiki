# TATILogo

## Description
TATILogo is an accessible high-level Logo language extension and programming environment developed by dos Santos for modelling physical-law objects and building physics simulations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TATILogo, an accessible Logo language extension for manipulating physical-law objects**: TATILogo is a high-level programming language defined through a context-free grammar in an EBNF variant, parsed top-down and translated into LSL commands. The article motivates it with the argument that "programming is the prototypical tool for the constructionist vision, and a microworld without programming runs the risk of avoiding just the thing that gives a microworld its power". Commands include FORWARD, BACKWARD, SETVEL, SPEEDUP, SLOWDOWN, SETACCEL, APPFORCE and APPTORQUE, with simplified vector syntax without commas. (dos Santos (2012))
