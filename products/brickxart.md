## Description
BRICKxAR/T is an AR-enabled iPad application developed by the authors for learning spatial transformations and matrix algebra through interactive LEGO-based and virtual model manipulation.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **BRICKxAR/T augmented reality application for learning spatial transformation matrices**: BRICKxAR/T is an AR prototype, built for AR-enabled iPads, in which "The BRICKxAR/T app [31], [32] is an AR prototype for learning spatial transformations and matrix algebra." It is an RTS (rotation, translation, scale) puzzle game where moving a physical LEGO model updates a registered hidden virtual model, distance lines, rotation angle graphics, and the corresponding transformation matrices in real time. Students can also manipulate a virtual model via sliders to compose transformation matrices and practice AR registration. An equivalent non-AR version with the same visualization functions was developed for comparison. (Zohreh Shaghaghian et al. (2022))
