## Description
A public repository from Ananthanarayan et al. containing executable Mathematica notebooks that accompany a group-theory book and let physics students run and modify symbolic computations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **A public GitHub repository hosting the book's notebooks for hands-on use**: The article releases its supporting notebooks in a GitHub repository at https://github.com/iisc-ug-20/Group_Theory_for_Mathematica.git. Readers are told to keep the repository open while reading and to run notebooks as code appears in the text. This makes the resource executable rather than purely textual, supporting interactive learning of group theory concepts. (Ananthanarayan et al. (2024))
