# FeynCraft

> **Product or Programme** · [All products and programmes](index.md)

## Description
FeynCraft is a browser-based game developed by Gaunt et al. for drawing, validating, generating, and practising Standard Model Feynman diagrams.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **FeynCraft browser game for drawing, validating and practising Standard Model Feynman diagrams**: FeynCraft is a browser-based game, accessed at the authors' itch.io page with no installation, in which users draw particle lines and connect them at vertices; the game "determines invalid vertices using a sequence of simple rules, showing users which vertices are invalid and why". It supports fundamental particles and hadrons represented by quark content, randomly generated and curated problems, automatic generation of all diagrams for a specified process, information overlays, and LaTeX export. It runs on Windows, Linux, Mac, iOS and Android with a touchscreen interface. (Gaunt et al. (2025))
- **Automatic full diagram-set generation for a specified process as a self-checking aid**: When a user specifies the initial and final state of a process, FeynCraft generates the full set of Feynman diagrams for that process at chosen perturbative order(s), drawing them via its solution-generation algorithms and displaying them in a mini-diagram viewer with force and degree filters. The authors note "This can be useful for a student to check that they have managed to draw all the diagrams for a process." Generated diagrams can be re-saved in the viewer if topologically equivalent, to tidy the automatic layout. (Gaunt et al. (2025))
