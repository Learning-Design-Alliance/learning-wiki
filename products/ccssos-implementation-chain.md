## Description
A phased, multi-level implementation framework developed by the Council of Chief State School Officers (CCSSO) to guide coordinated adoption, implementation, and sustainability of educational initiatives.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **The implementation chain: HQIM implementation as a phased, multi-level, multi-year system process**: This report frames HQIM implementation through CCSSO's "implementation chain," in which coordinated actions must occur across levels of the education system, where "each level is responsible for creating coherence for the next level" (2025, p. 8). CCSSO's analysis proposes five phases unfolding over 4 or more years: exploration, program installation, initial implementation, consistent implementation, and innovation and sustainability. The report uses this framework to organize district leaders' accounts of IM implementation as an ongoing, cyclical process rather than a one-time adoption event. (Hannan et al. (2026))
