## Description
PerFit is an R package that computes person-fit statistics for item-response and assessment data, developed for researchers conducting person-fit analysis.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PerFit R package for computing person-fit statistics**: The study computed the four non-parametric person-fit statistics (G, G*, U3, ZU3) for every examinee using the R package PerFit, which the article cites as "PerFit: An R Package for Person-Fit Analysis in IRT". The statistics were chosen because they "have been shown to be the most effective in identifying cheating" in prior comparisons of 36 PFS measures. The package operationalizes the IRT-based detection approach for researchers wishing to replicate the method on their own assessment data. (Alona Strugatski et al. (2025))
