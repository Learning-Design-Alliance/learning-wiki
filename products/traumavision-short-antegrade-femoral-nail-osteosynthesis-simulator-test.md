# TraumaVision short antegrade femoral nail osteosynthesis simulator test

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A TraumaVision virtual-reality simulator module developed with Swemac Education for practicing and assessing short antegrade femoral nail osteosynthesis using haptic tools, simulated fluoroscopy, and performance metrics.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TraumaVision short antegrade femoral nail osteosynthesis simulator test with expert-selected scoring metrics**: A novel virtual-reality simulator software module for training short antegrade femoral nail osteosynthesis, developed with Swemac Education on the TraumaVision platform. It uses "a force feedback device ... that mimics the surgical tools and generates haptic feedback", displays simulated fluoroscopy via a foot pedal, and computes a combined percentage score from 20 metrics (e.g., total time, nail angle, tip–apex distance) selected by 2 orthopedic trauma specialists as clinically relevant. (Gustafsson A et al. (2024))
