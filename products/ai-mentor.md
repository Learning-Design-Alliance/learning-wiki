## Description
AI-Mentor is a Li Xiao et al. prototype intelligent virtual-patient system that uses constrained LLM dialogue, persona prompting, guardrails, and supervisory hints for psychiatric clinical-education practice.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **AI-Mentor multimodal simulation architecture for psychiatric clinical education**: AI-Mentor is an intelligent virtual patient framework for deliberate practice in psychiatric education, grounded in precision education and deliberate practice. The Phase 1 prototype implements "a constrained, case-script–anchored dialogue engine using a large language model (GPT-4o)" with persona-based prompting, guardrail rules, and real-time supervisor hints. A Phase 2 architecture (Fig. 2, Table 1) proposes integrating BERT, VGGish, ACRNN, and V-Express for multimodal affective computing, but this has not been implemented or empirically validated. (Li Xiao et al. (2026))
