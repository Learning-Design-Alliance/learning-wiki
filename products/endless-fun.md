# Endless Fun

> **Product or Programme** · [All products and programmes](index.md)

## Description
A strategic multiplayer card game and accompanying materials created by Lea Kopf and colleagues for learning quantum logic operations, superposition, interference, and entanglement through gameplay.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Endless Fun in high dimensions: a strategic card game for programming high-dimensional quantum computers**: Endless Fun is a strategic multi-player card game in which players play cards corresponding to quantum logic gates to manipulate their qudit values. The general goal is "to perform quantum state operations that are building blocks to program a quantum computer by playing the cards in such a way that the player's own qudit value is as high as possible and the opponent's values as low as possible". The game goes beyond existing qubit-based games by using high-dimensional qudits with three possible values, increasing complexity and difficulty-adjustability, and is provided with an instruction manual, cards, riddles and software in an online repository. (Lea Kopf et al. (2022))
