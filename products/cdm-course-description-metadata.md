# CDM (Course Description Metadata)

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A European course-description metadata framework developed by Mokhtar Ben Henda for structuring university course and programme-offering information so institutions can describe offerings consistently and students can compare them.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CDM (Course Description Metadata), modèle européen de description des offres de formation en 4 entités**: Le CDM est un modèle européen de description des offres de formation, structuré en 4 entités descriptives : orgUnitType (19 éléments), programType (24 éléments), courseType (27 éléments) et personType (6 éléments). L'article le propose comme standard international pour consigner une offre de formation dans « un descriptif cohérent qui constitue le référentiel de l'institution », afin d'assurer l'uniformité descriptive des offres et permettre aux étudiants de comparer cursus et diplômes. (Mokhtar Ben Henda (2008))
