## Description
GEAS is a suite of fourteen platform-independent web applications developed for astronomy students to analyze astronomical images, spectra, and plots without installing client-side software.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Fourteen platform-independent web applications for astronomical image, spectrum, and plotting analysis**: GEAS provides fourteen platform-independent web applications, including a general plotting tool (histograms, linear fits with slope, y-intercept, and correlation coefficients), a galaxy spectrum analysis tool for determining redshifts, a quasar spectral fitting tool with an archive of 1,300 moderate-resolution optical spectra and a focus mode fitting Gaussian line profiles, and a stellar spectrum tool with a temperature slider. The article states these applications "are designed so that students need not install software, compile packages, or learn complicated commands in order to examine data and conduct basic analyses," allowing use on public computers. (Nicole P. Vogt et al. (2012))
