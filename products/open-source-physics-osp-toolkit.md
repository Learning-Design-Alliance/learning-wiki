## Description
A free, open-source physics software toolkit, including Easy Java Simulations and Tracker, developed for creating, customizing, analyzing, and sharing computer models and video-based investigations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open Source Physics toolkit: Easy Java Simulations and Tracker for creating and customising free physics computer models**: Open Source Physics (OSP) focuses on the design of computer models, such as Easy Java Simulations (EJS) and video modeling and analysis (Tracker). The tools are free, run on Windows, MacOSX and Linux with Java Runtime, and carry intellectual property rights that let teachers and students customise models to suit their teaching and learning needs. Students use them to investigate, explore and analyse data which is either real or simulated. (Wee Loo Kang (2013))
- **Open Source Physics (OSP) library and Easy Java Simulations (EJS) package as resources for physics computation**: Open Source Physics (OSP) is a freely-available numeric library that reduces the time spent creating programs, and Easy Java Simulations (EJS) is an intermediate package that "automates many programming tasks and allows users to focus on the numerical algorithms". The authors use OSP applications, such as one simulating a charged particle in three-dimensional electric and magnetic fields, and plan to share their curricular materials through the BQ-OSP database and the Open Source Physics website. (Todd Timberlake et al. (2007))
- **Open Source Physics (OSP) library and digital libraries of shareable physics simulations**: The Open Source Physics project makes simulations and their source code freely available under the GNU General Public License. The article states its goal is to "make a large number of simulations together with source code available for education", providing high-level modeling tools and a lower-level computational physics library with an object-oriented framework for interfaces, 2D/3D drawing, solving differential equations, and data tables and graphs. (Loo Kang WEE (2012))
- **Open Source Physics (OSP) tools and resources for interactive computer-based modelling**: OSP is a National Science Foundation funded project providing "tools and resources for interactive computer-based modelling." Unlike common simulations and videos, OSP's open source codes enable students and teachers to "create, use, and customise the computer models or tools to suit their learning context and instructional needs." The OSP Collection engages students in physics through computer-based modelling, letting learners interact with simulations and change source codes. EJS models require only Java runtime or a modern browser, with no login or server setup. (Kwan et al. (2015))
- **OSP 3Ps scaling-up framework: Product, Process, People**: The article adapts Dede's (2007) scaling-up process into a three-dimension framework for spreading modelling practice using OSP. Product: EJS produces "free download and use accurate scientific models that can be traced from the open source codes, remixed, and reused." Process: many EJS models serve as a virtual laboratory supporting experiential learning, aligning with existing laboratory practice. People: passionate educators adapt or create customized computer models suited to their technology, pedagogy, content, and context knowledge, releasing models with activity worksheets for all. (Kwan et al. (2015))
