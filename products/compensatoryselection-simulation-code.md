## Description
Commented Matlab code released on the first author's GitHub for reproducing and extending simulations of applicant-pool selection, measurement noise, admissions policies, and compensatory-selection effects.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **CompensatorySelection simulation code (commented Matlab, GitHub)**: The article's released artifact is the commented Matlab code implementing the applicant-pool simulations, including latent characteristics, four observed predictors, measurement noise, and alternative admissions policies. The article states "The computer code for these simulations can be found on the first author's GitHub account", allowing readers to reproduce or extend the reported ground-truth conditions and selectivity sweeps. (Huber David E. et al. (2022))
- **Multi-variable tradeoff model of academic performance with diminishing marginal rate of substitution**: The article models student performance P as depending on two measured characteristics x and y (e.g., GRE score and research experience) via a function exhibiting diminishing returns on each variable and a diminishing marginal rate of substitution between them, so that "Different combinations of x and y values could give the same average level of performance P." Curves of constant P are analogous to indifference curves in microeconomics, meaning deficits in one trait can be compensated by strengths in another. The article uses this model in simulations to show that successful scientists with low test scores are consistent with multi-variable prediction rather than poor test validity. (Alexander Small (2016))
