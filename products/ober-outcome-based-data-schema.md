# OBER outcome-based data schema

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · 3 claims (3 for) · 2 studies (1 causal, 1 design), `q2` · 0 of 2 report an effect size · 3 claims rest on one study

## Description
A minimalist data schema developed by Askarbekuly et al. that adds learner outcomes, mastery scores, item–outcome alignment, and recursive competency refinement to learner–item recommender models.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **OBER+ 5R cycle: a computational traceability model from attainment evidence to evaluated corrective action**: OBER+ is a design stated as computational rules that connect attainment evidence, the corrective decision, the logged change and the measured movement afterwards. It "extends a deployed institutional attainment platform [4] with five connected stages, named Report, Reflect, Recommend, Redesign and Reassess and referred to together as the 5R cycle, which run on the attainment the platform already computes." Reflect raises alerts and flags with severity bands, Recommend records decisions against an evidence-graded practice catalogue, Redesign keeps an audited change log, and Reassess computes gap closure per intervention. (Elakkiya Rajasekar (2026))
