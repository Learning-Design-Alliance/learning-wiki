## Description
mBot is an educational Arduino-based robot programmed through Makeblock's mBlock visual programming environment for classroom coding and STEM activities.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **mBot robot with mBlock visual programming environment**: The mBot is an inexpensive educational robot built on an Arduino UNO board, programmed through mBlock, "a variant adapted to Scratch 2.0" that adds a 'robots' block category. It includes brightness, proximity and line-following sensors, two RGB LEDs, a buzzer and a button. The study used it in sixth-grade math and science units for engine-control and ultrasonic-sensor activities with immediate feedback. (Sáez-López et al. (2019))
