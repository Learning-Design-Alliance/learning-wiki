## Description
The TARGET-tool is an online teacher dashboard and mobile student-scan tool developed by Weeldenburg et al. to support secondary-school PE teachers in assessing and improving the motivational learning climate.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **TARGET Narrative Engine module for generating and controlling emergent stories**: The Narrative Engine is "the module that supports the generation and control of interesting stories" in the TARGET platform. Given a set of Story Elements it sets up and manages the storyline: Competences instantiate the Cases sub-module, Roles instantiate the Agent Framework, Processes and Rules instantiate the Simulation Engine, and Environment instantiates the 3D game world, while the Drama Manager builds the emerging fabula. (Edgar Santos et al. (2010))
