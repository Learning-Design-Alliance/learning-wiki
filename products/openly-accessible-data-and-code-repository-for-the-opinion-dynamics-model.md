## Description
A GitHub repository by Jibeom Seo containing data and code for reproducing and extending Monte Carlo simulations of an agent-based opinion-dynamics model.

### Claims

- [In the model's simulations, group performance increases through discussion even when no group member initially knows the correct answer, provided initial opinions sufficiently differ](../claims/simulation-group-discussion-improves-performance-diverse-initial-opinions.md) [+W]
- [In the simulations, replacing the similarity-weighted influence term with a simple average of group opinions lowers final performance and speeds up consensus, and removes the diversity-driven performance collapse](../claims/simulation-weighted-influence-term-outperforms-simple-average.md) [+W]
- [In the simulations, final group performance depends more on initial opinion diversity than on initial group performance, with a threshold diversity of about 0.5 above which final performance is high regardless of initial score](../claims/simulation-initial-diversity-beats-initial-performance-threshold-0-5.md) [+W]
- [In the simulations, the optimal group size for collaborative learning is three or four students, and a group of two performs worse than three](../claims/simulation-optimal-group-size-three-or-four.md) [+W]
