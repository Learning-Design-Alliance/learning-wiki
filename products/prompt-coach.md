## Description
Prompt Coach is a multi-agent tutoring software system for professional developers that provides in-IDE guidance on crafting code-generation prompts, developed by Rohit Mehra et al.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Socratic, consequence-grounded agentic tutoring paradigm for in-flow skill learning**: The paper's explanatory framework is that emerging human-AI collaboration skills are best learned through adaptive, interactive, context-aware guidance embedded in the learner's workflow rather than static formats. Its Socratic Guidance Agent generates "context-aware nudges that encourage developers to reflect on and refine weaknesses in their prompt instead of prescribing direct fixes", grounded in the project knowledge store and a Consequence Preview Agent that internally previews the code the prompt would generate without exposing it, so guidance targets concrete failure modes while preserving the learning process. (Rohit Mehra et al. (2026))

### Claims
- [A 60-minute session with Prompt Coach significantly improved professional developers' prompt quality, a 13.73% relative gain overall](../claims/prompt-coach-significant-overall-prompt-quality-gain.md) [+M]
