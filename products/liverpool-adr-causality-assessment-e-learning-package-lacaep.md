# Liverpool ADR Causality Assessment e-learning Package (LACAeP)

## Description
LACAeP is a web-based e-learning package developed by Conroy Elizabeth J. et al. to train paediatric healthcare professionals to use the Liverpool Causality Assessment Tool for adverse drug reaction assessment.
