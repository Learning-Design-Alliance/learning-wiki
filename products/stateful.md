# Stateful

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Stateful is a Moodle question type built on STACK that lets authors create parametric, stateful exercises whose learner actions trigger transitions between scenes and individualized feedback paths.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Stateful question type for Moodle: a stateful extension of STACK enabling adaptive, game-like exercise flows**: Stateful is a new Moodle question type that uses STACK as its engine and defines exercises as networks of parametric STACK-like scenes. Its defining feature is that "The student's action may affect the internal state of the question", triggering state transitions between scenes so that answers change the exercise's path. The article describes Stateful exercises as "state machines that accept external control" and notes this enables game-like adaptivity impossible in classical STACK, which has no internal state. It was used to build the Stateful Diesel Exercise studied in the teaching experiment. (Matti Harjula et al. (2024))
