## Description
Apprentice Tutors is a web-based intelligent tutoring platform developed by Grace Guo and colleagues that provides adaptive mathematics practice using Bayesian Knowledge Tracing and step-level problem solving.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Apprentice Tutors platform for adult College Algebra learners**: Apprentice Tutors is a tutoring platform offering ten tutors for College Algebra topics, developed through extensive cognitive task analysis and modeled on OpenStax's Intermediate Algebra, 2e. It uses "Bayesian Knowledge Tracing (BKT) [9] to personalize the learning experience by selecting problems that target unmastered skills", and provides real-time correctness feedback, multi-layered hints, a user profile screen with knowledge-component progress bars, and LTI-based deployment in Blackboard and Canvas. Extensions included tutorial videos, a bug submission and Q&A chat feature, links to OpenStax and YouTube resources, and more directed hint messages. (Adit Gupta et al. (2025))
