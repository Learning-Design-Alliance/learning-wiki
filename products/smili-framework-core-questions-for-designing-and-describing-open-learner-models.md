# SMILI☺ framework: core questions for designing and describing open learner models

## Description
A framework developed by Susan Bull and colleagues that guides designers in specifying, comparing, evaluating, and describing open learner models and their learner-facing interfaces.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **SMILI☺ framework: core questions for designing and describing open learner models**: The SMILI☺ (Student Models that Invite the Learner In) framework provides a systematic way to describe, compare and critique open learner models by answering a set of core questions: how the OLM fits into the overall interaction, how it was evaluated, why it was created, what aspects of the learner model are open, how they are presented, and who controls access. The revised version reformats these as "the set of essential questions which designers should consider and which can be used to describe OLMs". It is offered as a guide for designers of interfaces for OLMs, learning analytics and related fields. (Susan Bull et al. (2016))
