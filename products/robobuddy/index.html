RoboBuddy¶

Product or Programme · All products and programmes
Evidence · 2 claims (2 for) · 1 study (1 design), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

RoboBuddy is a browser-based teacher interface and locally deployable LLM-robot system developed by Tozadore et al. for generating, editing, and delivering curriculum-aligned storytelling activities through virtual or physical robots.

Components¶

  • RoboBuddy teacher interface for generating scenario-based robot activities from curriculum content: A browser-based system with three modules: a teacher-facing web interface for preparing storytelling activities, a web application connecting the interface to LLM modules, and a locally runnable fine-tuned LLM so data stays local. Teachers select predefined settings translated into specialized prompts, choose levels of AI assistance (five levels for Story Generation, three for Lecture Storification), specify the age group, and can edit, regenerate, or replace generated stories before approving questions for the robot. Activities run with a virtual avatar or an Alpha Mini robot, with DALL·E-3 image generation whose complexity is tailored to the age group. The article states the goal is to "grant teachers autonomy, using the AI as a supportive tool rather than the primary element in course creation". (Tozadore et al. (2025))

Claims¶

  • Teachers evaluated the LLM-robot system positively, citing ease of use for differentiated, multilingual lessons and no extra preparation time [+M]
  • Students exposed to robot storytelling report significantly higher enjoyment than students exposed to robot explanation in a 1-week classroom study [+M]
