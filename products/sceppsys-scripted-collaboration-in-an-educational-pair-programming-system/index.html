SCEPPSys (Scripted Collaboration in an Educational Pair Programming System)¶

Product or Programme · All products and programmes

Description¶

SCEPPSys is an Eclipse-based distributed pair-programming system developed by Tsompanoudi et al. that combines shared coding, communication, collaboration scripts, synchronous execution, administration, and interaction logging for computer-science education.

Components¶

  • SCEPPSys: an educational distributed pair programming system built on an Eclipse plugin with collaboration script authoring: SCEPPSys (Scripted Collaboration in an Educational Pair Programming System) is an educational DPP system based on the XecliP Eclipse plugin with a client-server architecture of server, database, and plugin. It supports standard DPP features (shared editor, floor control, chat, remote code highlighting, awareness) plus synchronic program execution, a collaboration script authoring tool for teachers, an administration panel with contribution statistics, and enhanced logging of user interactions. The article states "SCEPPSys extends existing plugins by combining collaboration scripts and DPP". (Despina TSOMPANOUDI et al. (2015))

Claims¶

  • Students gave positive feedback on DPP and rated guided problem solving highly, but hints, chat, and participation-rate display were rated less useful [~W]
  • System-initiated role switching produced more role switches than free collaboration in DPP [+W]
  • Structured collaboration did not significantly improve balance of student code contributions compared to free collaboration [-W]
  • The balanced knowledge acquisition policy achieved more even task distribution across learning goals than free collaboration [+W]
  • Both conditions improved Java knowledge from pre- to post-test, with no difference in learning outcomes between structured and free collaboration [~W]
  • Project scores were comparable between conditions except the fifth project, where the control group scored higher [~W]
  • Structured collaboration did not influence assignment completion time compared to free collaboration [~W]
