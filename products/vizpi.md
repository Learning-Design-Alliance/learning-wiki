## Description
VizPI is a learning platform developed for in-class peer instruction that lets instructors distribute coding exercises and form groups while providing students with an IDE, anonymous group chat, pass-rate sharing, and submission logging.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **VizPI learning platform for in-class Peer Instruction with group chat and pass-rate sharing**: VizPI is a learning platform used to collect student discussion and coding data during the experiment. Its instructor UI lets instructors "easily conduct peer instruction activity by creating and distributing coding exercises and dividing the class into small groups," while the student UI features an IDE and group chat window. Students in each group remain anonymous and can view each other's pass rates but not each other's code. It supported real-time grouping, chat-based discussion, and code submission logging across 11 sessions. (Tong Wu et al. (2024))
