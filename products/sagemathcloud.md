# SageMathCloud

## Description
SageMathCloud is a cloud-based computational mathematics environment that provides SageTeX-enabled LaTeX authoring for producing static and dynamic mathematical documents and presentations.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **LaTeX with SageTeX in SageMathCloud for preparing static and dynamic mathematical texts**: The LaTeX publishing system is included in SageMathCloud for preparing quality mathematical learning and scientific texts of both static and dynamic content for print or convenient pdf documentation work. The built-in SageTeX package commands, enabled with \usepackage{sagetex}, insert results of executed Sage commands into tex documents via \sage{<Sage code>} and produce graphics via \sageplot. Beamer-based slide presentations of mathematical content can also be created in the LaTeX editor. (Shokaljuk S. V. et al. (2017))
- **SageMathCloud as a cloud-oriented environment for computer-based learning of mathematics and informatics**: SageMathCloud is described as a cloud-oriented variant of the computer mathematics system SageMath hosted on Google servers, supporting interactive study of mathematical and informatics disciplines. The article lists its capabilities: creating and editing learning and scientific texts in LaTeX, Markdown or HTML, real-time collaboration with other users, organizing learning courses with student addition and progress monitoring, and uploading and processing files. It is positioned as one of the most powerful cloud-technology tools for teaching these disciplines. (Shokaljuk S. V. et al. (2017))
- **CoCalc: an open-source cloud service for learning mathematical disciplines**: CoCalc is defined in the monograph as a "хмарний сервіс з відкритим вихідним програмним кодом" whose main components are the Sage computer-mathematics web system, a course-management system, a LaTeX editor and an IPython interpreter. The monograph treats it as a means of forming professional competencies of future mathematics teachers and assigns it to the class of pedagogical software that deepens student–teacher interaction because it has "інструменти спілкування в реальному часі". (Попель М. В (2018))
