# Clustermancer

> **Product or Programme** · [All products and programmes](index.md)

## Description
Clustermancer is a Skynet software tool that lets learners match theoretical stellar isochrones to star-cluster photometry to investigate cluster distance, age, metallicity, and reddening.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Clustermancer tool for by-eye isochrone matching to star-cluster color-magnitude data**: Clustermancer is a Skynet software tool in which students match theoretical isochrones to brightness vs. color information from Skynet-acquired images of stars in a cluster, dating the cluster and measuring its metallicity and reddening. Figure 4 shows "A screenshot from Clustermancer, where the user has by-eye matched isochrones to brightness vs. color information from Skynet-acquired images of each star in intermediate-age, open cluster NGC 2437." It supports Module 2's HR-diagram work alongside Gaia data cleaning and distance measurement. (Reichart (2024))
