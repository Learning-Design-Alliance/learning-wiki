# Waiton et al. neutrino oscillation laboratory GitHub materials

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A GitHub-released undergraduate physics laboratory package providing students with scripts and code, instructors with solution materials, and public data for a portable neutrino-oscillation data-analysis experiment.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Publicly available GitHub laboratory materials with student and teacher copies**: The laboratory is released on GitHub in two forms: a public student copy containing the up-to-date lab script and code base, and a private teacher copy containing solutions, available on request by email. Data is publicly available at a link given in the paper, so other institutions can port the experiment; the article notes it "has been designed to be easily portable and has recently been implemented as a third-year laboratory project at Imperial College London." (Waiton et al. (2025))
