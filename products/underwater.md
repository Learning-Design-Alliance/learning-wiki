## Description
Underwater is a serious video game by Sfinx Games that uses a 3D-printed ultrasound-probe controller and playful object-finding tasks to train probe manipulation and basic ultrasound image acquisition.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Underwater serious video game for ultrasound hand-eye coordination training**: Underwater (Sfinx Games, Groningen, Netherlands) is a serious video game in which learners "find objects in a playful underwater environment" using 3D-printed ultrasound probes, practicing probe manipulation and the probe-movement-to-image relationship. In this trial it served as the intervention tool in four 20-minute sessions, compared against a mannequin-based ultrasound simulator for basic cardiac POCUS hand-eye coordination in medical novices. (Lintschinger Josef Michael et al (2026))
