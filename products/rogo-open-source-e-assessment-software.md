# Rogo open source e-assessment software

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
Rogo is an open-source University of Nottingham e-assessment management system that blueprints items to learning objectives and generates personalised attainment feedback reports.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Rogo open source e-assessment software facilitating blueprinted feedback**: The e-assessment management software which facilitates blueprinted feedback was developed in-house at the University of Nottingham and is now available free as an Open Source Project. It generates the personalised ranked learning-objective reports, supports a traffic light system (green for fulfilled, amber for partially fulfilled, red for cause for concern), and allows flexible timing of report release. The traffic light icon shapes were changed to aid accessibility for colour blindness. (Burr Steven A et al. (2013))
