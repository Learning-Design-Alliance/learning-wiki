# DataCanvas-EDU AI Agent Skill package

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
DataCanvas-EDU is an installable, versioned AI-agent software package developed by Bang An et al. that helps instructors generate synthetic teaching cases with verified reference analyses.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **DataCanvas-EDU AI Agent Skill package (version 0.1.3)**: The framework is implemented as a reusable AI Agent Skill: "a package of instructions, reference resources, and executable tools used within an existing agent environment." It is distributed as an installable folder, a versioned ZIP, and a plugin bundle, with an installation guide covering Claude, Claude Code, and compatible Codex/ChatGPT environments. The package and installation instructions are available on GitHub. The implementation described is version 0.1.3. (Bang An et al. (2026))
