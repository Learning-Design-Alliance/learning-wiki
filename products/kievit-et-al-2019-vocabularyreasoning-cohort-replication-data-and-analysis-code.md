# Kievit et al. (2019) vocabulary–reasoning cohort replication data and analysis code

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A dataset and R/lavaan analysis-code release on the Open Science Framework, provided by Kievit and colleagues for reproducing and reanalysing their longitudinal vocabulary–reasoning study.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open data and analysis code for the replication and simulation on the Open Science Framework**: The article's raw data and analysis code are "freely available on the Open Science Framework (OSF) at https://osf.io/xf7rn/", including simulation code, and the replication reused the original analysis scripts (https://osf.io/rvcph/files/) to demonstrate similarities between the two studies. The article received the Open Data badge, supporting transparency and reanalysis of the longitudinal vocabulary–reasoning cohort. (Kievit R. A. et al. (2019))
