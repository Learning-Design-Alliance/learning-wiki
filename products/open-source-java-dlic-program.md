# Open-source Java DLIC program

> **Product or Programme** · [All products and programmes](index.md)
> **Evidence** · no claims cited

## Description
A freely available Java implementation of the DLIC algorithm, distributed with documentation and electromagnetism examples for visualizing field structure and energy flow.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **Open-source Java DLIC program with electromagnetism examples, freely available with documentation**: The authors provide an open-source Java implementation of the DLIC algorithm together with many example applications to electromagnetism, distributed as an EPAPS document with documentation and an animation of the falling-ring example. They state: "We provide an open source Java program that implements the DLIC algorithm described here, and which contains many examples of applications of this method to electromagnetism." The code and documentation for creating the animated textures are freely available. (John Belcher et al. (2007))
