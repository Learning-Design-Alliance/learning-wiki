## Description
PeLe is a mobile testing system developed by HiST in Norway for administering classroom tests through students' smartphones or tablets and tracking individual responses across sessions.

## Components
<!-- A programme's own frameworks, tools, indicators and instruments, as its sources describe them -->
- **PeLe mobile testing system (HiST, Norway)**: PeLe is a mobile testing system developed at HiST (Norway) used in this study as a formative assessment tool. Students responded to in-class grammar and vocabulary tests using their smartphones or tablets over classroom Wi-Fi. The system stores each individual's responses, so "an individual student's performance can be tracked across multiple sessions", and it provides immediate feedback, interactivity and flexibility as pedagogical affordances. (Titova (2015))
