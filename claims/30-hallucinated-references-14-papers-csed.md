Manual verification of 464 candidates (225 from SET A author-field errors, 239 unmatched SET B titles) using bibliographic databases, publisher pages, DOI searches, and web search. Candidates were classified as hallucinated only when repeated searches found no valid record and the reference contained verifiably fabricated content.
