Chenguang Wang 2026¶

Chenguang Wang, Ming Li, Xinyue Zeng, Zhuochun Li, Hong Jiao, Tianyi Zhou, Dawei Zhou. (2026). Cognitive Episodes in LLM Reasoning Traces Enable Interpretable Human Item Difficulty Prediction. https://arxiv.org/abs/2606.28186 doi:10.48550/arxiv.2606.28186

q2 · i? · design · r2

Ablation study on the SAT Math dataset with all other settings fixed, comparing semantic-only, process-only, and full representations across trace sources and aggregation settings (Table 2). The study reports Sem. Only trailing "the full model by 7.4–12.1 macro-F1 points"; no standardized effect size is printed.

"Using either semantic embeddings alone or process features alone leads to clear drops, with Sem. Only trailing the full model by 7.4–12.1 macro-F1 points. Removing any one process feature family also consistently hurts performance, indicating that length, episode-distribution, and transition features provide complementary signals."

Discussion¶

Related Claims¶

  • Episode-composition and transition features contribute predictive process evidence beyond semantics, with Epi.+Tran. reaching 0.136 permutation importance versus 0.084 for Sem. in the Both (Role) setting — related
  • Ablation of feature-vector models: time-window features add no predictive power to logistic regression but boost a feedforward network, and total count features substantially boost performance on all datasets — related
  • Harder SAT Math items are associated with more implementation-centered and iterative episode dynamics — stronger Implement counts and Analyze–Implement transitions — rather than a proportional increase in all reasoning activity — related
  • Reasoning-process features are particularly useful when difficulty depends on multi-step problem solving, and the representation also generalizes to text-based assessment items — related
  • Profile-based aggregation across both trace sources achieves the best SAT Math performance and remains stronger than matched repeated direct-prompt generation under the same rollout budget — related
  • In the shallow-model ablation, class balancing lowered every metric, oversampling did not improve overall performance, and semantic embeddings raised ROC-AUC but lowered accuracy and F1 — related
  • LLM-extracted cognitive and linguistic features add predictive value beyond readily available item metadata (grade, domain, item type, word count) — related
