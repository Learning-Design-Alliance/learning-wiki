## Subclaims
`q2 i?` Open learner models vary along a continuum from system control of the learner model data, through joint control, to user control, depending on whether the user can directly edit, add evidence to, negotiate, or only inspect the model. ## Evidence

### Susan Bull & Judy Kay 2016

Susan Bull & Judy Kay. (2016). SMILI☺: a Framework for Interfaces to Learning Data in Open Learner Models, Learning Analytics and Related Fields. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-015-0090-8

`q2 · i?` · `theoretical · r3`

Conceptual analysis of OLM interaction modes. In negotiated learner models the negotiation moves available are the same for each party, while in editable models the learner can update the contents without challenge from the system.

> "Thus, there is a continuum of cases between system control of the learner model data, through joint control, to user control."
