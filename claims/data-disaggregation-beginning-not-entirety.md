# Leaders caution that disaggregating data by student demographics is only the beginning of using continuous improvement for equity, not its entirety

## Subclaims
`q2 i?` Disaggregating data by student identity characteristics is an essential early step, but some educators mistakenly believe data disaggregation is the entirety of using continuous improvement for equity. [→ Valdez 2020](#valdez-2020)

## Evidence

### Valdez 2020

Valdez, A., Takahashi, S., Krausen, K., Bowman, A., & Gurrola, E. (2020). Getting better at getting more equitable: Opportunities and barriers for using continuous improvement to advance educational equity. WestEd. https://eric.ed.gov/?id=ED606089

`q2 · i?` · `qualitative · r2`

In the promising-practice account of disaggregating data by student identity characteristics, leaders reported that the California School Dashboard publicly displays outcome data disaggregated by student groups, making inequities visible, and cautioned data disaggregation is "just the beginning".

> "Interviewed leaders cautioned that while disaggregating data by student demographics is an important step, it is just the beginning of using continuous improvement methods for equity."
