Evidence¶

Schuessler 2025¶

Schuessler, K., Fischer, V., & Walpuski, M. (2025). Investigating construct validity of cognitive load measurement using single-item subjective rating scales. Instructional Science. https://doi.org/10.1007/s11251-024-09692-6

q2 · i1 · causal · r1

Item-level comparison of 61 multiple-choice single-select items and 65 open-ended items from the competence test, using a bootstrapped t-test with adjusted results. The article reports the adjusted difference as "significant, t(112.133) = 2.13, p = 0.035, d = 0.38".

"This difference, ΔM = 0.49, 95% BCa CI [0.03, 0.94], is significant, t(112.133) = 2.13, p = 0.035, d = 0.38 (as the Levene–test revealed significant variance differences we report the adjusted results)."

Schuessler 2025 (2)¶

Schuessler, K., Fischer, V., & Walpuski, M. (2025). Investigating construct validity of cognitive load measurement using single-item subjective rating scales. Instructional Science. https://doi.org/10.1007/s11251-024-09692-6

q2 · i3 · associational · r2

Comparison of the open-ended correlation (r = -0.80, nitems open = 65) against the multiple-choice correlation (r = -0.45, nitems MC = 61) with perceived task difficulty; the comparison of correlations is computed for independent samples and yields the printed effect size "a large effect (q = 0.62, z = 3.41, p ≤ 0.001)".

"For the difference between correlations Cohen's q reveals a large effect (q = 0.62, z = 3.41, p ≤ 0.001)."

Schuessler 2025 (3)¶

Schuessler, K., Fischer, V., & Walpuski, M. (2025). Investigating construct validity of cognitive load measurement using single-item subjective rating scales. Instructional Science. https://doi.org/10.1007/s11251-024-09692-6

q2 · i? · associational · r2

Regressions predicting perceived task difficulty by relative item difficulty separately per answer format; the open-ended model explains 64.3% of variance, which the article calls "clearly higher than 19.9%" for the multiple-choice model. Only R² values are printed, so no standardized effect size applies.

"This is clearly higher than 19.9% of variance in perceived task difficulty, which is explained when using the relative item difficulty of multiple-choice single-select items as a predictor, R 2 = 0.20, F(1, 59) = 14.70, p ≤ 0.001, nitems MC = 61."
