# Exercise intensity differentially moderates acute exercise cognitive benefits, with moderate intensity favoring executive functions and high intensity favoring information processing

> **Claim** · [All claims](index.md)

## Subclaims
`q2 i?` Different exercise intensities may differentially improve distinct cognitive functions: moderate intensity for executive functions, high intensity for information processing. [→ Basso Julia C. 2017](#basso-julia-c-2017)
`q2 i?` In individuals with Down syndrome, moderate- but not high-intensity exercise facilitated information processing speed, while both intensities benefited inhibitory control. [→ Basso Julia C. 2017 (2)](#basso-julia-c-2017-2)
