## Subclaims
`q2 i?` Certificate rate per course declines inversely with the number of simultaneously co-registered courses in a burst; the βEND model captures this pattern but logistic regression overestimates it. [→ Wintermute 2019](#wintermute-2019)

## Evidence

### Wintermute 2019

Wintermute, E. H., Cisel, M., & Lindner, A. B. (2019). A survival model for course-course interactions in a Massive Open Online Course platform. arXiv. [doi:10.48550/arXiv.1905.04201](https://doi.org/10.48550/arXiv.1905.04201)

`q2 · i?` · `associational · r2`

Analysis of registration events grouped by burst size in the FUN dataset (Fig. 2D): the approximately inverse relationship between certificate rate and burst size was described by the βEND model but overestimated by logistic regression.

> "The per-course certificate rate drops in inverse proportion to the number of simultaneously co-registered courses."
