Evidence¶

Peters 2019¶

Peters, S. L., Fan, C. L., & Sheldon, S. (2019). Episodic memory contributions to autobiographical memory and open-ended problem-solving specificity in younger and older adults. Memory & Cognition, 47, 1592–1605. https://doi.org/10.3758/s13421-019-00953-1

q3 · i? · associational · r1

Pearson correlational analyses across tasks found generation and elaboration specificity correlated for memory in both age groups but not for problem solving; no effect sizes were printed for these correlations.

"For the memory experiment, the number of specific responses during generation significantly correlated with the number of internal details produced during elaboration for both age groups."
