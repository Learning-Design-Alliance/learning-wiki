## Evidence

### Dovis Sebastiaan 2015

Dovis Sebastiaan, Van der Oord Saskia, Wiers Reinout W., Prins Pier J. M. (2015). Improving Executive Functioning in Children with ADHD: Training Multiple Executive Functions within the Context of a Computer Game. A Randomized Double-Blind Placebo Controlled Trial. PLoS ONE. https://doi.org/10.1371/journal.pone.0121651

`q3 · i?` · `causal · r3`

Within-training process analysis comparing Start Index (day 2-3) with Max Index (best training days) using paired t-tests with Bonferroni correction (p < .0024). The full-active condition showed a "significant difference (improvement) between the Start Index and Max Index" on inhibition (t(30) = -18.66, p < .001) and cognitive flexibility (t(30) = -19.14, p < .001) and on all WM levels; the partially-active condition improved on inhibition and cognitive flexibility.

> "Within the full-active condition, paired t-tests showed a significant difference (improvement) between the Start Index and Max Index for the Inhibition training, t (30) = -18.66, p < .001, the Cognitive flexibility training, t (30) = -19.14, p < .001"
