Evidence¶

Zamzami Zainuddin 2026¶

Zamzami Zainuddin, Michael Sailer, Shurui Bai, Madziatul Churiyah, Agung Winarno. (2026). Quiz-based inquiry: embedding incrementally sequenced questions to enhance engagement and learning in synchronous online lectures. Education Tech Research Dev. https://doi.org/10.1007/s11423-026-10614-1

q3 · i3 · causal · r2

ANCOVA on weekly formative quiz scores for three intact class sections (N = 90), controlling Week 1 pre-quiz scores; the group main effect was significant, F(2, 86) = 5.46, p = .002, "partial η2 = .16". LSD post hoc showed both QBI groups beat control; the platform groups did not differ (p = .376).

"Post-hoc comparisons using the Least Significant Difference (LSD) test indicated that both experimental 1 (M = 85.03, SD = 4.21) and experimental 2 (M = 85.96, SD = 3.83) groups scored significantly higher than the Control group (M = 82.13, SD = 3.96), ps < .05. There was no significant difference between the two experimental groups (p = .376)"
