Qualitative survey excerpt from the pilot under the theme of well-designed lesson activities with real and virtual tools; the student valued being able to "verify if it really happens in the real world" with the real caliper.

> "[This lesson is sucessful] because we got to see it in the real world and the virtual world. For example if we wanted to verify if it really happens in the real world, we can try it with the [real] vernier calliper we were given."
