q3 · i? · causal · r2

Binomial model on the 60-participant pre/post experiment testing whether the intervention changed the assistant's tendency to carry over users' incorrect inputs. The article reports "b = 0.152, SE = 0.411, z = 0.37, p = .712"; no effect size is printed, so the null is reported as a non-significant test, not equivalence.

"A binomial model predicting the carryover of user errors showed no significant condition×time interaction, b = 0.152, SE = 0.411, z = 0.37, p = .712, indicating no reduction in general error propagation."
