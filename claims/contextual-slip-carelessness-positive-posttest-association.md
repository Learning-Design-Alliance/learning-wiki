# Carelessness detected by the BKT-based and ML contextual slip models is positively and significantly associated with post-test and delayed post-test scores

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r2` · `q3`

## Subclaims
`q3 i?` Contextual slip carelessness (BKT-based and ML variants) positively and significantly predicted both post-test and delayed post-test scores controlling for final knowledge level. [→ Jiayi Zhang 2025](#jiayi-zhang-2025)

## Evidence

### Jiayi Zhang 2025

Jiayi Zhang, Ryan S. Baker, Namrata Srivastava, Jaclyn Ocumpaugh, Caitlin Mills, Bruce M. McLaren. (2025). Carelessness Detection using Performance Factor Analysis: A New Operationalization with Unexpectedly Different Relationship to Learning. arXiv. [doi:10.1109/cste64638.2025.11092064](https://doi.org/10.1109/cste64638.2025.11092064)

`q3 · i?` · `associational · r2`

Regression analysis in the same 181-student Decimal Point dataset; for the BKT-based model the delayed post-test carelessness coefficient was b = 11.04, t(157) = 2.36, p = .02, and for the ML model b = 12.49, t(157) = 2.61, p = .01, both positive and significant.

> "Similar results were found when predicting delayed post-test scores, where carelessness detected using either the BKT-based contextual slip or the ML contextual slip model was positively and significantly associated with delayed post-test scores, while carelessness detected using the BKFC model was negatively associated with them (but not significantly)."
