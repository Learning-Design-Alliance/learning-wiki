# Whole-task, metacognitive knowledge, and external standard interventions significantly improve monitoring accuracy in problem solving

## Subclaims

## Evidence

### Noortje Janssen · Ard W. Lazonder 2024

Noortje Janssen · Ard W. Lazonder. (2024). Meta-analysis of Interventions for Monitoring Accuracy in Problem Solving. Educational Psychology Review. https://doi.org/10.1007/s10648-024-09936-4

`q4 · i1` · `quant-synthesis · r2`

Moderator analysis (Q-test) across the 35-study meta-analysis classified interventions into six types. Table 3 reports whole task k = 9, g = 0.38; metacognitive knowledge k = 3, g = 0.45; external standard k = 11, g = 0.28, each with confidence intervals excluding zero.

> "The 95% confidence intervals indicate that the intervention types whole task, metacognitive knowledge, and external standards all significantly improved students’ monitoring accuracy."
