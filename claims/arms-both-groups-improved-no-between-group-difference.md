Secondary-outcome analysis of the randomized trial using the 21-item Adult Reading Motivation Scale; within-group gains were significant in both arms while "the difference between groups did not reach statistical significance (Cohen’s d = 0.24, p = 0.495)".

> "the ARMS scores significantly improved in both groups, with a more pronounced effect in the AI-PBLG with a large effect size (d = 1.31, p < 0.001). Meanwhile, the PBLG group improved a moderate effect size (d = 0.64, p = 0.017). For ARMS, although both groups showed improvements over time"
