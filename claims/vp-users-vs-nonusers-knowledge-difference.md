# VP users outperformed experimental-group students who deliberately did not use VPs (ES = 0.68), while non-users did not differ from controls

## Subclaims
`q3 i2` Within the experimental group, VP users scored significantly higher than non-users (p < 0.001; ES = 0.68), and non-users did not differ from controls (p = 0.67). [→ Kononowicz AA 2012](#kononowicz-aa-2012)

## Evidence

### Kononowicz AA 2012

Kononowicz AA, Krawczyk P, Cebula G, Dembkowska M, Drab E, Frączek B, Stachoń AJ, Andres J. (2012). Effects of introducing a voluntary virtual patient module to a basic life support with an automated external defibrillator course: a randomised trial. BMC Medical Education. https://doi.org/10.1186/1472-6920-12-41

`q3 · i2` · `causal · r2`

Randomised trial comparing three subgroups: control (G1, n = 75), experimental non-users (G2, n = 37) and VP users (G3, n = 47). The quote reports the "significant difference (p < 0.001; ES = 0.68)" between users and non-users and the null contrast between non-users and controls.

> "Comparison of the experimental subgroup using and not using VPs also showed a significant difference (p < 0.001; ES = 0.68). There was no statistically significant difference observed in the post test between the control group and experimental group deliberately not using VPs (p = 0.67)."
