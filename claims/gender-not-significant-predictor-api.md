Supplementary regression analyses on the same five cohorts adding gender; no significant effect was detected, and the article reports "gender was not a significant predictor of academic performance". No effect size is printed, so no magnitude is claimed.

> "An additional multiple linear regression analysis was performed adding gender as an independent variable. However, for all of the analyzed degrees, gender was not a significant predictor of academic performance."
