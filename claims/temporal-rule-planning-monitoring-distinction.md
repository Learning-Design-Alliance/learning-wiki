# A temporal extraction rule classified the GENERAL INSTRUCTION -> PLANNER action pattern as Planning in the first 15 minutes but as Monitoring in the last 30 minutes

## Subclaims

## Evidence

### Fan 2022

Fan, Y., van der Graaf, J., Lim, L., Raković, M., Singh, S., Kilgour, J., Moore, J., Molenaar, I., Bannert, M., & Gašević, D. (2022). Towards investigating the validity of measurement of self-regulated learning based on trace data. Metacognition and Learning. https://doi.org/10.1007/s11409-022-09291-1

`q2 · i?` · `design · r2`

During multiple rounds of in-depth discussion among researchers, an extraction rule was created to resolve ambiguity in interpreting the GENERAL INSTRUCTION -> PLANNER action pattern. The rule distinguished Planning from Monitoring based on temporal position within the 45-minute learning session, and think aloud data supported this interpretation.

> "we created an extraction rule for this SRL process which considered "GENERAL INSTRUCTION -> PLANNER" in the first third of the learning session (first 15 minutes) as Planning but in the last two thirds of the learning session as Monitoring."
