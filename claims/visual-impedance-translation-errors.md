## Subclaims
`q2 i?` In an educational data mining analysis of logic students' submissions, fewest errors occurred on sentences containing only shape, size or space information (shape < size < space, where < means easier than), and combinations of spatial information with size or shape were associated with higher error rates. `q2 · i?` · `review · r2`

The review reports this as educational data mining by Barker-Plummer et al. (2011), who analysed a large corpus of logic students' submissions to an online grading system for English-to-first-order-logic translation exercises. No effect size is printed.

> "Fewest errors were made on sentences containing only shape, size or space information (shape < size < space where “ < ” = ‘easier than’). Combinations of spatial information with size or with shape were associated with higher error rates."
