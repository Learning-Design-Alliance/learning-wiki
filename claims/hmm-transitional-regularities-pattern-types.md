## Subclaims
`q2 i?` HMMs fitted per pattern type (5-state for Type 1, 7-state for Type 2, 5-state for Type 3, chosen by BIC) revealed a regular transition pattern from communication states to behaviour states and back to communication, with each type characterised by a distinct orientation. Separate HMMs were fitted and estimated with the EM algorithm over each cluster's sequences (15,750 codes Type 1; 32,130 Type 2; 13,000 Type 3), best of 100 runs; "A regularity was detected in the transition patterns" distinguishing the three types.

> "A regularity was detected in the transition patterns such that where Type 1 was characterized as a behaviour-oriented transition, Type 2 was characterized as a communication-behaviour-synergistic transition, and Type 3 was characterized as a communication-oriented transition"
