# When comparing only sessions in which the base code was actually modified, there are no significant differences between anonymous and registered learners in actions or time per session

## Subclaims
`q2 i?` Among code-modifying sessions, actions per session (7.88 vs 8.64) and time per session (322.62 vs 365.06 seconds) did not differ significantly (both p>0.1). [→ Gallego-Romero 2020](#gallego-romero-2020)

## Evidence

### Gallego-Romero 2020

Gallego-Romero, J.M., Alario-Hoyos, C., Estévez-Ayres, I. et al. (2020). Analyzing learners' engagement and behavior in MOOCs on programming with the Codeboard IDE. Education Tech Research Dev 68, 2505–2528 (2020). https://doi.org/10.1007/s11423-020-09773-6

`q2 · i?` · `associational · r2`

t-test restricted to sessions where learners changed the base code (339 anonymous, 135 registered) in the same Codeboard log analysis. The article reports t=-0.92 for actions and t=-0.96 for time, both p>0.1; equivalence was not tested.

> "Table 4 shows the number of actions per session in which the code was changed and the time per session for both anonymous and registered learners and in this case, there are no significant differences."
