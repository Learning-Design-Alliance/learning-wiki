## Evidence

### Denervaud Solange 2019

Denervaud Solange, Knebel Jean-François, Hagmann Patric, Gentaz Edouard. (2019). Beyond executive functions, creativity skills benefit academic outcomes: Insights from Montessori education. PLoS ONE. https://doi.org/10.1371/journal.pone.0225319

`q3 · i2` · `associational · r2`

Working memory measured with age-standardized digit span tasks (WISC-IV items); ANCOVA controlling for age gave d = 0.66 at kindergarten and d = 0.46 at elementary age, both favoring Montessori.

> "Working memory (score)	5.30 (1.85)	4.16 (1.56)	3.13, p = 0.016	7.01, p = 0.010	0.66"

### Denervaud Solange 2019 (2)

Denervaud Solange, Knebel Jean-François, Hagmann Patric, Gentaz Edouard. (2019). Beyond executive functions, creativity skills benefit academic outcomes: Insights from Montessori education. PLoS ONE. https://doi.org/10.1371/journal.pone.0225319

`q3 · i?` · `associational · r2`

Flanker fish task RT measures at kindergarten age: selective attention Yuen p = 0.100, ANCOVA p = 0.260; cognitive flexibility also non-significant (p = 0.380 and p = 0.554); no significant group differences.

> "Selective attention (ms)	74.5 (203)	144 (245)	–1.77, p = 0.100	1.29, p = 0.260	0.31"
