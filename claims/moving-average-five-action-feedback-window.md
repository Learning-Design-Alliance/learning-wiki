## Subclaims
`q2 i?` Pilot testing with eye-tracking and post-task interviews showed per-action feedback exceeded what participants could process, so feedback was given only after at least five actions using a moving-average performance state. [→ Gilbert 2017](#gilbert-2017)

## Evidence

### Gilbert 2017

Gilbert, S. B., Slavina, A., Dorneich, M. C., Sinatra, A. M., Bonner, D., Johnston, J., Holub, J., MacAllister, A., & Winer, E. (2017). Creating a Team Tutor Using GIFT. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-017-0151-2

`q2 · i?` · `design · r2`

Pilot observational testing of the Surveillance Scenario Tutor during development. Based on "gaze movement, as well as discussions with the participants," the number of actions required for feedback was set at five; no effect size or inferential statistic is printed.

> "To determine the window size of five actions, feedback was initially given after every action and the tutor was tested on pilot participants. Using eye-tracking and post-task interviews, it was confirmed that participants received much more feedback than they could process."
