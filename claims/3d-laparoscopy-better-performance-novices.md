## Evidence

### Harada Hitoshi 2017

Harada Hitoshi, Kanaji Shingo, Nishi Masayasu, Otake Yoshito, Hasegawa Hiroshi, Yamamoto Masashi, Matsuda Yoshiko, Yamashita Kimihiro, Matsuda Takeru, Oshikiri Taro, Sumi Yasuo, Nakamura Tetsu, Suzuki Satoshi, Sato Yoshinobu, Kakeji Yoshihiro. (2017). The learning effect of using stereoscopic vision in the early phase of laparoscopic surgical training for novices. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5654-2

`q3 · i?` · `causal · r2`

Randomized crossover comparison of 40 novices (20 medical students, 20 junior residents) performing three phantom tasks ten times each, with performance recorded by an optical position tracker. Median operative times favored 3D (e.g., task 2: 26.2 vs 19.5 s, P < 0.001), and median technical errors favored 3D on all tasks (e.g., task 2: 2.8 vs 0.9, P < 0.001).

> "Each score for all tasks performed under 3D was significantly better compared to those with the 2D system except for mean path length in task 1."

### Harada Hitoshi 2017 (2)

Harada Hitoshi, Kanaji Shingo, Nishi Masayasu, Otake Yoshito, Hasegawa Hiroshi, Yamamoto Masashi, Matsuda Yoshiko, Yamashita Kimihiro, Matsuda Takeru, Oshikiri Taro, Sumi Yasuo, Nakamura Tetsu, Suzuki Satoshi, Sato Yoshinobu, Kakeji Yoshihiro. (2017). The learning effect of using stereoscopic vision in the early phase of laparoscopic surgical training for novices. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5654-2

`q3 · i?` · `causal · r2`

The same crossover study reports median technical errors significantly lower under 3D on all three tasks, with "2.8 and 0.9 (P < 0.001)" for task 2 and "10.5 and 6.9 (P < 0.001)" for task 3. No effect sizes are printed, so impact is coded i? (no magnitude reported; not a null effect).

> "Median technical errors (times) were 1.2 and 0.7 (P < 0.001) with 2D and 3D systems for task 1; 2.8 and 0.9 (P < 0.001) with 2D and 3D systems for task 2; and 10.5 and 6.9 (P < 0.001) with 2D and 3D systems for task 3, respectively."
