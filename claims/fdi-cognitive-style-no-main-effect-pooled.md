## Subclaims

## Evidence

### Valencia-Vallejo et al. 2017

Nilson Valencia-Vallejo, Omar López-Vargas, Luis Sanabria-Rodríguez. (2017). Effect of Motivational Scaffolding on E-Learning Environments: Self-Efficacy, Learning Achievement, and Cognitive Style. Journal of Educators Online. https://eric.ed.gov/?id=EJ1168944

`q3 · i?` · `causal · r2`

The MANOVA main effect of cognitive style (field-dependent, intermediate, field-independent) was non-significant for self-efficacy ("F (2, 59) = 0.045, p = 0.956") and for achievement (F (2, 59) = 2.981, p = 0.058).

> "cognitive style does not have a significant main effect on academic self-efficacy (F (2, 59) = 0.045, p = 0.956, η2 = .002). A significant effect on learning achievement was not reported either (F (2, 59) = 2.981, p = 0.058, η2 = .09)."
