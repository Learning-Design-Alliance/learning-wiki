# Students' performance on vocabulary tests is influenced by familiarity with the test type rather than the test type itself

## Subclaims
`q1 i?` The type of vocabulary test (orthographical-cue vs. phonological-cue) did not systematically affect scores; rather, students' familiarity with the test type mattered. [→ Mihara 2015](#mihara-2015)

## Evidence

### Mihara 2015

Mihara, K. (2015). Effects of Phonological Input as a Pre-Listening Activity on Vocabulary Learning and L2 Listening Comprehension Test Performance. TESL-EJ 19(2). https://tesl-ej.org/pdf/ej74/a1.pdf

`q1 · i?` · `causal · r1`

In the present study of 40 experimental-group students, Class 2 (orthographical-cue tests) scored lower than Class 1 on Tests 5, 7, and 8, contradicting Tao's (2008) conclusion that orthographical-cue tests produce higher scores. The author attributes the discrepancy to students' lack of familiarity with phonological-cue test formats.

> "Thus, students' performance is not influenced by the type of vocabulary test they take per se. Rather, what is important is whether they are used to that type of test or not."
