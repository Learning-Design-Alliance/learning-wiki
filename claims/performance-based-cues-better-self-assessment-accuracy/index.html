Evidence¶

Waldeyer 2024¶

Waldeyer, J., Endres, T., Roelle, J., Baars, M., & Renkl, A. (2024). How to Optimize Self-Assessment Accuracy in Cognitive Skill Acquisition When Learning from Worked Examples. Educational Psychology Review, 36, 103. https://doi.org/10.1007/s10648-024-09944-4

q3 · i2 · causal · r3

Experiment 1, a 2 × 2 between-subjects ANOVA with N = 129 university students learning urn-model problems from worked examples. The main effect of prompted cue type was significant, F(1, 125) = 6.45, p = 0.012, with the printed effect size ηp2 = 0.05 favoring performance-based cues. The performance-based-cue-before condition showed lower absolute accuracy error (224.81) than the explanation-based counterpart (702.52).

"We found a statistically significant main effect of prompted cue type, F(1, 125) = 6.45, p = 0.012, ηp2 = 0.05. The groups that were prompted to utilize performance-based cues showed better self-assessment accuracy (i.e., values closer to zero)."
