# Funnel plot and Egger's test indicate publication bias in the PBL tutor-background data, and trim-and-fill suggests the overall effect is overestimated

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · quant-synthesis `r2` · `q2`

## Subclaims
`q2 i?` Egger's test indicates publication bias (t(352) = 5.15, p < .001), and a trim-and-fill analysis suggests 77 imputed studies would be needed to nullify it, dropping the overall effect to g = 0.103. [→ Walker 2023](#walker-2023)
`q2 i?` A vote count on the same data did not detect the publication bias that the funnel plot and Egger's test found. [→ Walker 2023 (2)](#walker-2023-2)

## Evidence

### Walker 2023

Walker, A., & Leary, H. (2023). Conducting Problem-Based Learning Meta-Analysis: Complexities, Implications, and Best Practices. The Interdisciplinary Journal of Problem-based Learning. https://doi.org/10.14434/ijpbl.v17i2.35844

`q2 · i?` · `quant-synthesis · r2`

New publication-bias analysis of the Leary et al. (2013) data. The article reports the Egger's test result and, in a trim-and-fill analysis, that "another 77 imputed studies would need to be added, dropping the overall effect size by almost two-thirds to g = 0.103."

> "Visual inspection of the funnel plot as well as the result of an Egger's test (see Egger et al., 1997) both suggest that there is publication bias for these data, t(352) = 5.15, p < .001."

### Walker 2023 (2)

Walker, A., & Leary, H. (2023). Conducting Problem-Based Learning Meta-Analysis: Complexities, Implications, and Best Practices. The Interdisciplinary Journal of Problem-based Learning. https://doi.org/10.14434/ijpbl.v17i2.35844

`q2 · i?` · `theoretical · r3`

The article contrasts the Egger's test result with an earlier vote count: "a vote count based on these same data for a conference paper did not find publication bias," illustrating the article's point that vote counting lacks sensitivity.

> "a vote count based on these same data for a conference paper did not find publication bias."
