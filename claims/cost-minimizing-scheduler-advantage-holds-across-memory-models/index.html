Claims

In a simulation built on vocabulary-app review logs, a cost-minimising review scheduler reached a target number of durable words in fewer days than other schedules under both a hand-built and a neural memory model

Simulating learners with two memory models fitted to 220 million vocabulary-app logs, a scheduler that minimises expected review time took 203 and 425 days to bring 2,000 words to a 360-day half-life, against 232 for MEMORIZE and 511 for reviewing at 90% recall, the best alternatives in each; on another group's dataset and memory model it matched a reinforcement-learning scheduler; no learners were tested.
