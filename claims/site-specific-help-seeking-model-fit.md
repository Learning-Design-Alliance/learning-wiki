# Each site's help-seeking model predicted learning in its own data, with widely differing fit (Costa Rica r=0.462, U.S. r=0.350, Philippines r=0.126)

## Subclaims
`q2 i?` Cross-validated regression models of effective help seeking predicted learning within each site, with the Costa Rican model fitting best (cross-validated r = 0.462) and the Philippines model worst (r = 0.126); the combined multinational model reached only 0.216. [→ Amy Ogan 2015](#amy-ogan-2015)

## Evidence

### Amy Ogan 2015

Amy Ogan, Erin Walker, Ryan Baker, Ma. Mercedes T. Rodrigo, Jose Carlo Soriano, Maynor Jimenez Castro. (2015). Towards Understanding How to Assess Help-Seeking Behavior Across Cultures. Int J Artif Intell Educ 25. https://doi.org/10.1007/s40593-014-0034-8

`q2 · i?` · `associational · r2`

Cross-validated linear regression models built per site from log-derived help-seeking features predicting learning; Table 3 prints cross-validated r values of 0.462 (Costa Rica), 0.126 (Philippines), 0.350 (U.S.), and 0.216 (combined).

> "The overall cross-validated correlation of the Costa Rica model to the Costa Rica data was a relatively high 0.462."
