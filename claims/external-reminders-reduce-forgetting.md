# External reminders dramatically reduce forgetting of delayed intentions

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · review `r2` · `q2`

## Subclaims
`q2 i?` Participants using their own memory forgot about 45% of intentions versus around 5% using external reminders, an almost order-of-magnitude reduction. [→ Gilbert 2023](#gilbert-2023)

## Evidence

### Gilbert 2023

Gilbert, S. J., Boldt, A., Sachdeva, C., Scarampi, C., & Tsai, P.-C. (2023). Outsourcing Memory to External Tools: A Review of 'Intention Offloading'. Psychonomic Bulletin & Review. https://doi.org/10.3758/s13423-022-02139-4

`q2 · i?` · `review · r2`

The review reports, citing the optimal reminders experiments of Gilbert et al. (2020), that 'using reminders reduced the forgetting rate by almost an order of magnitude', citing Jones et al. (2021) as further support. No effect size is printed.

> "participants in Gilbert et al. (2020) had a forgetting rate of about 45% when using their own memory but only around 5% using external reminders; in other words, using reminders reduced the forgetting rate by almost an order of magnitude"
