`q3 · i?` · `associational · r1`

One-sample t-tests in the RQ4 results (user subgroup): users found the chatbot "easy to use r ( p < .001, n = 37)", responses clear and relevant, information accurate (p < .001, n = 38), personalised (p = .026), and reported occasional errors (p = .003).
