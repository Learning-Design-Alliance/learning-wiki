Descriptive survey analysis (n = 24) of five rated Class Companion functions in Table 2. Assignment support was rated most strongly: "The strongest perceived value was assignment support: 83% rated the tool “Effective” or “Very Effective” (M = 3.38, SD = 0.77)."
