## Subclaims
`q1 i?` Based on in-person and online feedback, the developers simplified how the game registers that a feature has been found, replacing ship-touching with cursor scanning. [→ Jorge Cuadra 2023](#jorge-cuadra-2023)

## Evidence

### Jorge Cuadra 2023

Jorge Cuadra, Miguel Vergara, Bruno Escárate, Josué Sandoval, and Benjamín Cordero. (2023). Protoplanet Express, a video game based on numerical simulations. arXiv preprint. [doi:10.48550/arXiv.2303.17654](https://doi.org/10.48550/arXiv.2303.17654)

`q1 · i?` · `design · r2`

Developer report on iterative adjustment after presenting the game at science fairs and releasing an online beta. The authors state feedback "has been useful to make several adjustments to the game", including this change in feature registration. No systematic evaluation was performed.

> "In particular, we made it more straightforward for the software to register that a feature has been found. Originally we required the player to "touch" the feature with the ship, while in the current version the player scans the sky using the cursor."
