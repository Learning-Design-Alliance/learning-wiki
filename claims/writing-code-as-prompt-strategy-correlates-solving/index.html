Correlational analysis linking coded refinement strategies (Ref4) to the number of B2 problems solved; the only significant association was "Writing code as prompt" with "r = .20", p < .05, a small-to-moderate printed correlation based on twelve students.

"Notably, for each strategy, there was no significant relationship with problems solved in B2, except forWriting code as prompt(r = .20,p< .05), which should be treated cautiously given that only twelve students were coded using this."
