### Angelo Kyrilov and David C. Noelle 2015

Angelo Kyrilov and David C. Noelle. (2015). Using Automated Theorem Provers to Teach Knowledge Representation in First-Order Logic. 4th International Conference on Tools for Teaching Logic. [doi:10.48550/arXiv.1507.03670](https://doi.org/10.48550/arXiv.1507.03670)

`q2 · i?` · `causal · r1`

A planned two-tailed t-test on the fourth exam question, which required writing a successor-state axiom using the situation calculus, found "no detectable impact" of system use; no effect size is printed. The system offered no practice exercises of this kind.

> "Completing practice exercises using our system had no detectable impact on scores for this question (t(280) = 0 .856; p = 0.393)."
