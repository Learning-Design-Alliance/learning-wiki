## Evidence

### Jiayi Zhang 2025

Jiayi Zhang, Ryan S. Baker, Namrata Srivastava, Jaclyn Ocumpaugh, Caitlin Mills, Bruce M. McLaren. (2025). Carelessness Detection using Performance Factor Analysis: A New Operationalization with Unexpectedly Different Relationship to Learning. arXiv. [doi:10.1109/cste64638.2025.11092064](https://doi.org/10.1109/cste64638.2025.11092064)

`q3 · i?` · `design · r2`

Spearman correlations against existing Decimal Point detectors; Table IV reports BKFC carelessness with gaming the system r(158) = .22, p = .005 and with confrustion r(158) = .27, p < .001.

> "However, we found carelessness detected using BKFC is positively correlated to gaming the system, the opposite of the pattern seen for the other two models. Additionally, a positive correlation is found between carelessness and confrustion, again the opposite of the pattern seen for the other models."

### Jiayi Zhang 2025 (2)

Jiayi Zhang, Ryan S. Baker, Namrata Srivastava, Jaclyn Ocumpaugh, Caitlin Mills, Bruce M. McLaren. (2025). Carelessness Detection using Performance Factor Analysis: A New Operationalization with Unexpectedly Different Relationship to Learning. arXiv. [doi:10.1109/cste64638.2025.11092064](https://doi.org/10.1109/cste64638.2025.11092064)

`q3 · i?` · `associational · r1`

Spearman correlations in the same dataset; Table IV reports BKT-based carelessness with gaming the system r(158) = −.86, p < .001 and with confrustion r(158) = −.87, p < .001; ML values were −.84 and −.86.

> "we found carelessness detected using either the BKT-based contextual slip model or the ML contextual slip model is negatively associated with gaming the system."
