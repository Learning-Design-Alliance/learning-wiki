## Evidence

### Brender 2025

Brender, J., El-Hamamsy, L., Uittenhove, K., Mondada, F., Bumbacher, E. (2025). Structured Prompts, Better Outcomes? Exploring the Effects of a Structured Interface with ChatGPT in a Graduate Robotics Course. [doi:10.1007/978-3-032-03870-8_7](https://doi.org/10.1007/978-3-032-03870-8_7)

`q3 · i?` · `causal · r2`

T-tests on task logs from both sessions found no group differences in completed or attempted tasks (session 3 attempted: t(53) = 0.68, p = .50). No effect sizes were printed.

> "there is no difference between groups in terms of (i) the number of completed tasks (t-test, session 2: t(57) = 0.23, p = .81, session 3: t(53) = 0.74, p = .46)"
