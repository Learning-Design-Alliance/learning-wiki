# In Experiment 3, restudy plus a second retrieval attempt increased short-answer retrieval success, and final performance showed a format × question type interaction in which multiple-choice outperformed short-answer on inference questions

## Subclaims
`q3 i3` Restudy plus a second retrieval attempt raised short-answer performance from the first to the second retrieval period. [→ Smith 2014](#smith-2014)
`q3 i3` On the final assessment, a retrieval format × question type interaction emerged; for inference questions the multiple-choice condition outperformed the short-answer condition. [→ Smith 2014 (2)](#smith-2014-2)

## Evidence

### Smith 2014

Megan A. Smith and Jeffrey D. Karpicke. (2014). Retrieval practice with short-answer, multiple-choice, and hybrid tests. Memory, 22(7), 784-802. https://doi.org/10.1080/09658211.2013.831454

`q3 · i3` · `causal · r2`

Experiment 3 (48 undergraduates, short-answer vs multiple-choice, study–retrieve–restudy–retrieve) increased short-answer retrieval success: second-period performance (M = .65) exceeded first-period (M = .41), F(1, 23) = 102.46, η²p = .82.

> "There was a main effect of retrieval period, F(1, 23) 102.46, g2p ¼ :82; performance was higher on the second retrieval activity (M.65) than the first retrieval activity (M.41)."

### Smith 2014 (2)

Megan A. Smith and Jeffrey D. Karpicke. (2014). Retrieval practice with short-answer, multiple-choice, and hybrid tests. Memory, 22(7), 784-802. https://doi.org/10.1080/09658211.2013.831454

`q3 · i3` · `causal · r2`

Experiment 3 final assessment showed a format × question type interaction, F(1, 46) = 13.86, η²p = .23; for inference questions the multiple-choice condition outperformed short-answer, F(1, 46) = 3.97, p = .05, η²p = .08 — an effect in the opposite direction of some prior reports.

> "For these questions, subjects in the multiple-choice condition performed better on the final assessment than subjects in the short-answer condition, F(1, 46) 3.97, p .05, g2p ¼ :08."
