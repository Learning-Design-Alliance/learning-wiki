Claims

In vocabulary-app review logs, a memory model that tracks each item's review history predicted memory half-life after a review with less error than half-life regression

Fitted to 220 million review logs from a vocabulary app, a memory model whose state carries each word's difficulty, last half-life and recall probability at review predicted the half-life after a successful or failed recall with smaller errors than half-life regression, which uses only counts of past successes and failures.
