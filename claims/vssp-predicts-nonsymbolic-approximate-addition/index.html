Xenidou-Dervou 2014¶

Xenidou-Dervou, I., van der Schoot, M., & van Lieshout, E. C. D. M. (2015). Working memory and number line representations in single-digit addition: Approximate versus exact, nonsymbolic versus symbolic. Quarterly Journal of Experimental Psychology, 68(6), 1148–1167. doi:10.1080/17470218.2014.977303

Stepwise multiple linear regression on the nonsymbolic approximate task with WM and number line predictors; "the VSSP, t(102) = 2.83, p = .006, was the best and only unique predictor". The task did not correlate with either number line measure.
