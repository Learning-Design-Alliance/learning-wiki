# In-app automated data analysis shifts an experiment's instructional focus, e.g. from teaching data analysis to teaching basic kinematics

## Subclaims
`q1 i?` When the app performs the analysis of pressure and acceleration data, the elevator experiment becomes a tool for teaching basic kinematics, whereas recording raw data without in-app analysis serves to teach data analysis skills. [→ Staacks 2018](#staacks-2018)

## Evidence

### Staacks 2018

Staacks, S., Hütz, S., Heinke, H., & Stampfer, C. (2018). Advanced tools for smartphone-based experiments: phyphox. arXiv. [doi:10.1088/1361-6552/aac05e](https://doi.org/10.1088/1361-6552/aac05e)

`q1 · i?` · `design · r1`

The authors' descriptive account of the elevator experiment, which uses the atmospheric pressure sensor to calculate height differences and the accelerometer for vertical acceleration. They state that with in-app analysis "the experiment becomes a tool to teach basic kinematics", while the raw-data approach attributed to Monteiro and Martí teaches data analysis. This is an authors' interpretation, not a tested result.

> "In contrast, when using phyphox, all the analysis is done by the app and the students get graphs showing the altitude, vertical speed and acceleration as a function of time"
