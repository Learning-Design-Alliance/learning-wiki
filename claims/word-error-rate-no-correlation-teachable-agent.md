## Evidence

### Yuya Asano 2023

Yuya Asano, Diane Litman, Mingzhi Yu, Nikki Lobczowski, Timothy Nokes-Malach, Adriana Kovashka, and Erin Walker. (2023). Impact of Experiencing Misrecognition by Teachable Agents on Learning and Rapport. [doi:10.1007/978-3-031-36336-8_94](https://doi.org/10.1007/978-3-031-36336-8_94)

`q2 · i?` · `associational · r2`

Correlation analysis reported in a footnote, using the Web Speech API's word error rate (mean .226, SD = .102) against rapport, learning, and misrecognition measures for the same 38 students. All three correlations were non-significant.

> "Word error rates were not correlated with rapport ( r = .196, p = .239), learning (ρ = .246, p = .142), or overall dialogue misrecognition ( r = −.155, p = .354)."
