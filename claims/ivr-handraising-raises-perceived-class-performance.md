# Higher proportions of hand-raising virtual classmates raise sixth-graders' perceived class performance level and register more hand-raisers in an IVR lesson

## Subclaims
`q3 i2` Compared with 20% hand-raising classmates, 65% (d = 0.60) and 80% (d = 1.24) conditions produced significantly higher perceived class performance levels, while 35% did not. [→ Lisa Hasenbein 2024](#lisa-hasenbein-2024)
`q3 i3` Hand-raising conditions also predicted the number of registered hand-raising classmates (d = 0.79 for 65%; d = 1.48 for 80% vs. 20%). [→ Lisa Hasenbein 2024 (2)](#lisa-hasenbein-2024-2)

## Evidence

### Lisa Hasenbein 2024

Lisa Hasenbein, Ulrich Trautwein, Jens-Uwe Hahn, Stephan Soller, Richard Göllner. (2024). An experimental test of the Big-Fish-Little-Pond Effect using an immersive virtual reality classroom. Instructional Science. https://doi.org/10.1007/s11251-023-09646-4

`q3 · i2` · `causal · r2`

In the randomized IVR classroom experiment (N = 353 sixth-graders), regression analyses with dummy-coded hand-raising conditions against the 20% baseline showed the 65% and 80% conditions raised perceived performance, with printed effects "d = 0.60" and "d = 1.24"; the 35% condition (β = 0.06, p = 0.099) did not differ significantly.

> "However, compared with 20% hand-raising classmates, the perceived performance level was significantly higher for 65% (β = 0.25, SE = 0.04, p < 0.001, d = 0.60) as well for 80% (β = 0.45, SE = 0.07, p < 0.001, d = 1.24)"

### Lisa Hasenbein 2024 (2)

Lisa Hasenbein, Ulrich Trautwein, Jens-Uwe Hahn, Stephan Soller, Richard Göllner. (2024). An experimental test of the Big-Fish-Little-Pond Effect using an immersive virtual reality classroom. Instructional Science. https://doi.org/10.1007/s11251-023-09646-4

`q3 · i3` · `causal · r3`

Regression results on the reported number of registered hand-raising classmates showed participants recognized the manipulation, with the 65% and 80% conditions exceeding the 20% baseline; the article prints "d = 1.48" for the 80% contrast and no significant effect for 35% vs. 20% (β = 0.08, p = 0.069).

> "65% (β = 0.28, SE = 0.07, p < 0.001, d = 0.79) as well as 80% (β = 0.58, SE = 0.05, p < 0.001, d = 1.48) hand-raising classmates led to significantly higher numbers of registered hand-raising classmates compared with the 20% condition"
