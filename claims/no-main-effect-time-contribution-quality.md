`q3 · i?` · `causal · r1`

In the same mixed between-within subjects ANOVA of the 74-student intervention study, the main effect for time on M-PARS total score was not significant (p = 0.20); no effect size interpretation is warranted from the printed statistic alone.

> "There was, however, no main effect for time, Wilks’ Lambda = 0.98, F (1, 71) = 1.66, p = 0.20, partial eta squared = 0.02."
