Evidence¶

Chang 2014¶

Chang, Shu, Liang, Tseng, and Hsu. (2014). Is Blended E-Learning Better than Traditional Classroom Learning for Vocational High School Students? Vol 15 | No 2 April/14. http://el.evta.gov.tw/

q3 · i? · causal · r?

Quasi-experimental ANCOVA on 65 vocational 11th graders (experimental n = 33, control n = 32) using the last two midterms as covariance; Levene's test was insignificant (p = .858). The between-group effect size was .001, described as showing blended e-learning "did not significantly affect achievement test scores."

"The average score on the achievement test for the experimental group was slightly higher than that for the control group, but ANCOVA showed an insignificant result ( p = .825)"
