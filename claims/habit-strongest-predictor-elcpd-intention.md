SEM analysis (AMOS 23, bootstrapped maximum likelihood) of the cross-sectional survey; the structural model showed "habit (β = 0.473, 95% CI: [0.345, 0.608], P-value < 0.001)" as the largest path. Only standardized path coefficients are printed, so no effect size magnitude is coded.

> "habit (β = 0.473, 95% CI: [0.345, 0.608], P-value < 0.001) and computer literacy (β = 0.116, 95% CI: [0.053, 0.184], p-value < 0.001) had a significant influence the intention to use eLearning based continuing professional development."
