Evidence¶

Malkiewich 2016¶

Malkiewich, L. J., Lee, A., Slater, S., & Chase, C. C. (2016). Tenacious Assessments: Using In-Game Behaviors to Measure Student Persistence and Challenge Navigation. https://eric.ed.gov/?q=Tenacious+Assessments+Using+In-Game+Behaviors

q2 · i3 · associational · r2

Correlation of the challenge-response measure with challenge time in the log-data subset (N=18). The measure captured "transitions to simpler code on the next attempt of relative-hard levels"; the negative association was maintained in partial correlations controlling for pretest (r = -0.62, p < .01).

"Similarly, the response to challenge meas ure Relative-Hard Code Downgrades (r = -0.56, p = .02) was negatively associated with challenge time, which indicates that students who persist less on a challenging game level also choose to give up on writing challenging code more often."

Related Claims¶

  • In-game willingness to solve hard levels with complex code is positively associated with posttest coding knowledge, controlling for pretest
  • Traditional challenge-navigation measures (level choice, replays, careful retries, hint reading, coding time) did not relate to learning outcomes
  • Relative-Hards Solved Complex, a log measure of using complex code on personally difficult levels, predicts time spent on an unsolvable challenge task — related
  • In gamers' interview reports, sustained gaming engagement appeared closely related to controlling an optimal level of challenge: games too hard were often abandoned and games too easy lost their interest — related
