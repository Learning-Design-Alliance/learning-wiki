Cross-sectional survey of 23 prenatal clinicians using the TIC-KAP tool found the attitudes domain scored highest (M = 38.6, SD = 4.2) while practice scored lower (M = 25.3, SD = 2.4), indicating a "gap in translating TIC knowledge into practice despite favorable attitudes".
