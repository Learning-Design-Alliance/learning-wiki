The publication's key findings assert this phase-movement rule for its four-phase M&E approach. It is a descriptive statement of the approach's design logic; the overview reports no empirical test of the rule, offering it as the authors' framework for evidence-based iteration.

"Progress is not always linear. The evidence determines when a solution should move to the next phase, stay within a phase and continue development, or return to a prior phase."
