# Students' inquiry sequences differ by session: most start with Assertion questions in Session 1 (prob = 0.48) but with Instrumental/Procedural questions in Session 2 (prob = 0.43)

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r1` · `q2`

## Subclaims
`q2 i?` In Session 1 most students started with Assertion questions (prob = 0.48), while in Session 2 they mostly started with an Instrumental/Procedural question (prob = 0.43), and students tended to remain longer within Assertion, Request/Directive, and Instrumental/Procedural states in both sessions. State-machine (transition-diagram) analysis of question-type sequences within each session, shown in Figures 3 and 4 (Session 1: N = 60 students, 432 prompts; Session 2: N = 37 students, 398 prompts). Start probabilities are descriptive.
