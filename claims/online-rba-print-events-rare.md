### Bethany R. Wilcox and Steven J. Pollock 2020

Bethany R. Wilcox and Steven J. Pollock. (2020). Student behavior and test security in online conceptual assessment. arXiv:1912.05698v1 [physics.ed-ph]. Originally published 2019. [doi:10.1119/perc.2019.pr.wilcox](https://doi.org/10.1119/perc.2019.pr.wilcox)

`q2 · i?` · `associational · r1`

Behavioral log analysis of 207 online RBA responses using embedded JavaScript print detection. The study found "only 3 students (or 1.4%) had recorded print events", and a post-administration Google search of item prompts found no uploaded prompts or solutions ranking highly.

> "In the full data set of 207 responses, only 3 students (or 1.4%) had recorded print events; of these three, only one actually submitted the assessment"
