Evidence¶

de Jonge 2026¶

de Jonge, T. H. S., de Koning, B. B., & van Wermeskerken, M. (2026). It's all a matter of expectancy: How expectancies about task execution perspective influence learning through video modeling examples. Learning and Instruction, 105, 102422. https://doi.org/10.1016/j.learninstruc.2026.102422

q3 · i3 · causal · r2

Mixed-design ANOVA on task performance in the main analysis. The recording × expected angle interaction was the largest effect ("η2 = 0.27"); the recording × task angle (η2 = 0.04) and expected × task angle (η2 = 0.06) interactions were also significant.

"Significant interactions were found between recording and expected angle, F(1, 124) = 79.20, p < .001, η2 = 0.27, recording and task angle, F(1, 124) = 11.17, p = .001, η2 = 0.04, and expected and task angle, F(1, 124) = 18.84, p < .001, η2 = 0.06."

de Jonge 2026 (2)¶

de Jonge, T. H. S., de Koning, B. B., & van Wermeskerken, M. (2026). It's all a matter of expectancy: How expectancies about task execution perspective influence learning through video modeling examples. Learning and Instruction, 105, 102422. https://doi.org/10.1016/j.learninstruc.2026.102422

q3 · i? · causal · r2

Post-hoc linear mixed-effects contrast on task performance. The match-versus-mismatch contrast between recording and expected angle was significant, "t(125) = 8.74, p < .001", described as a moderate effect size; no standardized effect size value was printed for this contrast.

"a match between the recording angle and the expected angle yielded significantly better task performance compared to a mismatch, t(125) = 8.74, p < .001, corresponding to a moderate effect size"
