# Greater proportion of voice prompts used correlates moderately with greater stated preference for voice

Spearman rank-order correlations between preference (five-point scale from Text input only = 1 to Voice input only = 5) and proportion of voice prompts showed "a moderate, positive correlation" for both edited (ρ = .509) and unedited (ρ = .597) voice prompts, both p< .001.

> "there was a moderate, positive correlation between a greater proportion of voice prompts and a greater preference for using voice (𝜌𝑒𝑑𝑖𝑡𝑒𝑑 = .509,p< .001 and 𝜌𝑢𝑛𝑒𝑑𝑖𝑡𝑒𝑑 = .597,p<.001)"
