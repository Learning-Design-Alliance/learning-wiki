## Evidence

### Miller‐Cotto 2026

Miller‐Cotto, D., & Medrano, J. (2026). Does working memory moderate the effect of fading on math performance? British Journal of Educational Psychology, 96, 108–126. https://doi.org/10.1111/bjep.12781

`q3 · i?` · `causal · r2`

Pooled linear regression (Model 3) on the randomized homework study, posttest regressed on WOMBAT working memory scores, condition dummies, and their interactions controlling for pretest; the Johnson–Neyman probe returned a moderator range of 1.42 to 8.53, "beyond the maximum score of 8, p < .05."

> "We found no interaction between working memory and each condition (ps > .5) and no significant main effect of working memory (β = −.08, p = .66)."

### Miller‐Cotto 2026 (2)

Miller‐Cotto, D., & Medrano, J. (2026). Does working memory moderate the effect of fading on math performance? British Journal of Educational Psychology, 96, 108–126. https://doi.org/10.1111/bjep.12781

`q3 · i?` · `causal · r2`

Follow-up pooled regression collapsing fading and fading-with-self-explanation into one category versus combined BAU and worked-example conditions; the fading conditions still showed a significant effect (β = .53, p = .005) but no working memory moderation.

> "However, the interaction between working memory and fading was not significant, indicating that the effect of fading did not vary depending on students' working memory performance (Table 8)."
