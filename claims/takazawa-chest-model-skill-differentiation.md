### Zahradníková Petra 2025

Zahradníková Petra, Babala Jozef, Lindák Martin, Pechanová Rebeka, Hnilicová Silvia, Molnár Marián, Nedomová Barbora, Poš Lucie, Dotlačil Vojtěch, Kučerová Barbora. (2025). `q2 · i?` · `quant-synthesis · r2`

Study in which 53 surgeons each performed an endoscopic intracorporeal suturing and knot-tying task on both a 3D-printed pediatric chest model with embedded force sensors and a conventional box trainer. The review reports "Skilled surgeons outperformed unskilled ones in six key metrics using the pediatric simulator".

> "Skilled surgeons outperformed unskilled ones in six key metrics using the pediatric simulator, while no significant differences were found in the box trainer. The simulator effectively distinguished skill levels and offers valuable benchmarks for pediatric surgical training"
