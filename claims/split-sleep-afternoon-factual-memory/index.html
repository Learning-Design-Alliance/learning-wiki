Evidence¶

Cousins 2019¶

Cousins, J. N., van Rijn, E., Ong, J. L., Wong, K. F., & Chee, M. W. L. (2019). Does splitting sleep improve long-term memory in chronically sleep deprived adolescents? npj Science of Learning 4:8. https://doi.org/10.1038/s41539-019-0047-z

q3 · i2 · causal · r2

Three-day amphibian factual-knowledge experiment: 1 h morning and 1 h afternoon learning of 12 species, tested the evening after a recovery night. "signiﬁcantly better memory of species learned in the afternoon" was found for certain memories (d = 0.71); overall memory also favoured the split group, t(56) = 2.177, p = 0.034, d = 0.57.

"Independent samples t-tests revealed signiﬁcantly better memory of species learned in the afternoon for the split sleep group relative to the continuous sleep group, t(56) = 2.7, p = 0.009, Cohen's d = 0.71"
