## Evidence

### Joss Ives 2014

Joss Ives. (2014). Measuring the Learning from Two-Stage Collaborative Group Exams. Dept. of Physics & Astronomy, University of British Columbia. [doi:10.1119/perc.2014.pr.027](https://doi.org/10.1119/perc.2014.pr.027)

`q3 · i?` · `causal · r2`

Sensitivity analysis repeating the mixed-effects logistic regressions after removing the four question pairs with similarity ratings below 4.0 (three of which had discrimination index D < 0.3). Significance of β3 was unchanged for both midterms.

> "Removing these questions did not improve the quality of the fit of the model to the data nor did it change the significance level of β3 for the set of learning test questions for either midterm."
