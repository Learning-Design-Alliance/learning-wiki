## Evidence

### Von Korff 2016

Von Korff, J., Archibeque, B., Gomez, K.A., Heckendorf, T., McKagan, S.B., Sayre, E.C., Schenk, E.W., Shepherd, C., Sorell, L. (2016). Secondary Analysis of Teaching Methods in Introductory Physics: a 50k-Student Study. Originally published 2014. [doi:10.48550/arXiv.1603.00516](https://doi.org/10.48550/arXiv.1603.00516)

`q2 · i?` · `associational · r2`

ANOVAs on the secondary-analysis database of published class gains, with very small (<10 students) and very large (>400 students) classes discarded as probable outliers or artifacts (<5% of classes). The article reports no primary effect of class size, p>0.2.

> "We ran ANOVAs on test, teaching method, and class size to discover if there was a primary effect of class size after test and teaching method. We found none (p>0.2)."
