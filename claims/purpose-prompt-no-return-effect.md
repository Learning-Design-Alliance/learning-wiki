## Evidence

### Chen 2024

Chen, Y., Iyer, P., & Kizilcec, R. F. (2024). Reflection on Purpose Changes Students' Academic Interests: A Scalable Intervention in an Online Course Catalog. Originally published 2022. [doi:10.48550/arXiv.2412.19035](https://doi.org/10.48550/arXiv.2412.19035)

`q3 · i?` · `causal · r2`

Logistic regression of return behavior in the randomized field experiment prints only test statistics (e.g., "logOR = -0.06" for new users in the self-interest condition) and no standardized effect size, so no magnitude is claimed; equivalence was not tested.

> "Neither intervention significantly affected whether students would return to the platform, no matter if they were new or existing users (self-interest purpose intervention: for new users, logOR = -0.06, z = -0.57, p = 0.57, for existing users, logOR = 0.04, z = 0.30, p = 0.77"
