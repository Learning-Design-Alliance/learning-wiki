### Schapiro and McClelland 2009

Anna C. Schapiro, James L. McClelland. (2009). A connectionist model of a continuous developmental transition in the balance scale task. Cognition 110, 395–411. https://doi.org/10.1016/j.cognition.2008.11.017

`q2 · i?` · `theoretical · r3`

Numerical simulation result comparing pattern frequencies across the model's hysteresis and control tests (1680 test sessions). The control test used identical distance items with gradually changing weight greyness, which the model does not represent.

> "The difference between the distributions on the two tests was highly signiﬁcant [v2 (5, N = 1680) = 189.51, p < 0.0001]."
