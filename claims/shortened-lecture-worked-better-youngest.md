`q2 · i?` · `design · r2`

Observation across the two University sessions with 15–16-year-olds: many examples were too far from what the students knew, so the authors prepared a shorter version for the second day and report "the shortened lecture did work better with the students".

> "After the ﬁrst session we already noticed this problem so for the next day we prepared a somewhat shorter version of the talk. Both versions are available at the website for comparison. The second day we noticed an improvement of this issue: the shortened lecture did work better with the students."
