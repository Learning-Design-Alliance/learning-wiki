q3 · i3 · causal · r2

Homeroom teacher ADHD-RS ratings in the same RCT. For teacher-rated inattention the interaction was also significant (F(1,54) = 17.76, p < 0.001, η²p = 0.25); for hyperactivity the intervention group improved (p < 0.001) while controls were stable (p = 0.128), with a significant post-intervention group difference (p < 0.001).

"Hyperactivity/Impulsivity demonstrated a significant Time main effect (F(1,54) = 29.30, p < 0.001, η²p = 0.35), significant Group main effect (F(1,54) = 5.98, p < 0.05, η²p = 0.10), and significant interaction (F(1,54) = 9.94, p < 0.01, η²p = 0.16)."
