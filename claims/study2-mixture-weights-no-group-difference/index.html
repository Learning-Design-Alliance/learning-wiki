The Dynamic Interplay Between Goal Setting 2022¶

The Dynamic Interplay Between Goal Setting, Performance, and Emotions in Self-Regulated Learning: A Computational Modeling Approach — Supplementary Materials. (2022). https://gpemodel.shinyapps.io/gpe-model/

q3 · i? · causal · r?

Group-comparability check in Study 2 using mixture weights estimated by the hypothesized model for each participant. For the pre-learning model the control (M = .38) and experimental (M = .40) groups did not differ, t(303) = 1.175, p = .241; for the post-learning model, t(303) = 0.208, p = .836.

"For the pre-learning emotions model, there were also no differences in the estimated mixture weights between the control group (M = .38, SD = 0.12) and the experimental group (M = .40, SD = .11), t(303) = 1.175, p = .241."
