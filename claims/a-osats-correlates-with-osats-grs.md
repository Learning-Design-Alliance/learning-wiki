`q3 · i3` · `design · r3`

Spearman correlation analysis of the blinded video ratings (Results): both versions "correlated highly with the non-specific OSATS (unweighted AOSATS: r = 0.810, p < 0.001; weighted OSATS: r = 0.827, p < 0.001)" and r = 0.996 with each other.

> "Both scores correlated highly with the non-specific OSATS (unweighted AOSATS: r = 0.810, p < 0.001; weighted OSATS: r = 0.827, p < 0.001) and with each other (r = 0.996, p < 0.001)."
