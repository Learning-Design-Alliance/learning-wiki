In the same 27-school wait-list control study, ATI-UP schools showed "decreased chronic absenteeism (effect size =+0.08)" relative to controls after one semester, a small printed effect size that qualified the program for the Promising category for chronic absenteeism.

"After one semester, ATI-UP schools increased average daily attendance (effect size =+0.19) and decreased chronic absenteeism (effect size =+0.08), compared to controls."
