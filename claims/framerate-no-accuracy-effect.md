# Presentation framerate did not affect detection accuracy despite 28 images/s being judged too fast

## Subclaims
`q3 i?` Neither framerate nor the Framerate × Expertise interaction affected accuracy in either task, although the 28 i/s framerate was least appreciated. [→ Bertram Raymond 2013](#bertram-raymond-2013)

## Evidence

### Bertram Raymond 2013

Bertram Raymond, Helle Laura, Kaakinen Johanna K., Svedström Erkki. (2013). The Effect of Expertise on Eye Movement Behaviour in Medical Image Perception. PLoS ONE. https://doi.org/10.1371/journal.pone.0066169

`q3 · i?` · `causal · r1`

Null result from the same experiment: accuracy in both the ELN and ABN tasks was unaffected by presentation speed (7, 14 or 28 i/s); experts still achieved 86% ELN accuracy at 28 i/s. No effect size is printed, so no magnitude is claimed.

> "Surprisingly, framerate did not affect performance (see Table 3), as in neither task was there evidence for a Framerate × Expertise interaction or a main effect of framerate (all ps>.2)."
