Jung 2013¶

Jung, M., Hartman, P., Smith, T., & Wallace, S. (2013). The Effectiveness of Teaching Number Relationships in Preschool. International Journal of Instruction, 6(1). https://eric.ed.gov/?id=EJ1085361

q3 · i? · causal · r1

Linear model on the same 73-child sample testing whether the intervention effect varied by age, controlling for pretest. No effect size was printed for the null interaction, so no magnitude is reported.

"A subsequent linear model (Model 3) that included the interactive effect of Treatment Group × Age showed no statistically significant interaction effect (F(1, 68) = 0.12, p = .73)."
