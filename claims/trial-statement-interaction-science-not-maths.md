# The true-versus-false statement accuracy difference is larger for misconception than control trials, and significant for science but not maths

> **Claim** · [All claims](index.md)
> **Evidence** · 2 studies · `q3` peer-reviewed experiment · `i2`–`i3`

## Subclaims
`q3 i2` Trial type × Statement type interaction: the true–false accuracy difference was smaller in control trials (ηp2 = .120) than misconception trials (ηp2 = .256). [→ Brookman-Byrne A 2018](#brookman-byrne-a-2018)
`q3 i3` Discipline × Statement type interaction: the true–false difference was significant for science trials (ηp2 = .505) but not maths trials (p = .629). [→ Brookman-Byrne A 2018 (2)](#brookman-byrne-a-2018-2)

## Evidence

### Brookman-Byrne A 2018

Brookman-Byrne A, Mareschal D, Tolmie AK, Dumontheil I (2018) Inhibitory control and counterintuitive science and maths reasoning in adolescence. PLoS ONE 13(6): e0198973. https://doi.org/10.1371/journal.pone.0198973

`q3 · i2`

Follow-up repeated measures ANOVAs on the Trial type × Statement type interaction in the misconceptions task (N = 87) showed "less difference in accuracy between true and false statements in control trials" (ηp2 = .120) than misconception trials (ηp2 = .256).

> "The interaction was attributable to less difference in accuracy between true and false statements in control trials, F(1,83) = 11.33, p = .001, ηp 2 = .120, compared to misconception trials, F(1,83) = 28.57, p< .001, ηp 2 = .256."

### Brookman-Byrne A 2018 (2)

Brookman-Byrne A, Mareschal D, Tolmie AK, Dumontheil I (2018) Inhibitory control and counterintuitive science and maths reasoning in adolescence. PLoS ONE 13(6): e0198973. https://doi.org/10.1371/journal.pone.0198973

`q3 · i3`

The same ANOVA (N = 87) showed a Discipline × Statement type interaction; "the difference between true and false statements was significant for science trials" (ηp2 = .505) but not maths trials (p = .629). The authors attribute this partly to nine maths problem-sets containing equations requiring mental calculation in both statement types.

> "There was an additional significant interaction between Discipline and Statement type, whereby the difference between true and false statements was significant for science trials, F(1,83) = 84.75, p< .001, ηp 2 = .505, but not maths trials, p = .629 (Table 2)."
