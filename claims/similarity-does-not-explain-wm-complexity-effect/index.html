Wuji Lin 2024¶

Wuji Lin, Chenxi Lv, Jiejie Liao, Yuan Hu, Yutong Liu & Jingyuan Lin. (2024). Feature versus object in interpreting working memory capacity. npj Science of Learning 9:67. https://doi.org/10.1038/s41539-024-00279-x

q3 · i? · causal · r2

Experiment 5, a single-factor within-subject study with 24 students using one-item change detection tasks, following Awh et al.'s use of RT as an index of similarity. The main effect of material conditions was "not signiﬁcant" (F [2,46] = 0.512, p = 0.603).

"The repeated measures variance a nalysis for reaction time (RT) showed that the main effect of experiment material conditions was not signiﬁcant ( F [2,46] = 0.512, p = 0.603, ηp² = 0.022)."
