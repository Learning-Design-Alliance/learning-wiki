## Evidence

### Marta M. Koć-Januchta 2020

Marta M. Koć-Januchta, Tim N. Höffler, Helmut Prechtl, Detlev Leutner. (2020). Is too much help an obstacle? Effects of interactivity and cognitive style on learning with dynamic versus non-dynamic visualizations with narrative explanations. Education Tech Research Dev. https://doi.org/10.1007/s11423-020-09822-0

`q3 · i1` · `causal · r2`

GLM analysis of learning outcome with visual cognitive style as covariate in the randomized experiment (N = 235) found the expected triple interaction with printed effect size ηp² = .022 (small by the η² code); Fig. 2 displays it, showing visual style makes no difference for animations.

> "The expected triple interaction of visual cognitive style, type of pacing, and type of visualization, F(1,227) = 5.08, p = .025, ηp 2 = .022, see Fig. 2."

### Marta M. Koć-Januchta 2020 (2)

Marta M. Koć-Januchta, Tim N. Höffler, Helmut Prechtl, Detlev Leutner. (2020). Is too much help an obstacle? Effects of interactivity and cognitive style on learning with dynamic versus non-dynamic visualizations with narrative explanations. Education Tech Research Dev. https://doi.org/10.1007/s11423-020-09822-0

`q3 · i1` · `causal · r2`

Median-split simple-effects analysis of the static picture condition (HDV N = 118, LDV N = 117) showed highly developed visualizers benefited from system pacing with static pictures; printed effect size ηp² = .029 (small).

> "Highly developed visualizers (HDV) performed better on the learning outcome test when learning with system-paced static pictures (M  = 29.80, SD = 9.59) than when learning with self-paced static pictures (M  = 23.95, SD = 7.41), simple effect F(1,227) = 6.79, p = .010, ηp 2 = .029."

### Marta M. Koć-Januchta 2020 (3)

Marta M. Koć-Januchta, Tim N. Höffler, Helmut Prechtl, Detlev Leutner. (2020). Is too much help an obstacle? Effects of interactivity and cognitive style on learning with dynamic versus non-dynamic visualizations with narrative explanations. Education Tech Research Dev. https://doi.org/10.1007/s11423-020-09822-0

`q3 · i1` · `causal · r2`

In the median-split simple-effects analysis, highly developed visualizers underperformed less developed visualizers in the self-paced static pictures condition; printed effect size ηp² = .026 (small). The article reports "all simple main-effects F < 1" for the non-significant contrasts.

> "When learning with self-paced static pictures, highly developed visualizers (HDV¸ M = 23.95, SD = 7.41) performed poorer on learning outcome than less developed visualizers (LDV; M  = 29.59, SD = 9.47), simple effect F(1,227) = 6.00, p = .015, ηp 2 = .026."
