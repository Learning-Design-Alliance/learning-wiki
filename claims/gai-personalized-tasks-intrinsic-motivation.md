# Solving context-personalized AI-generated tasks raises intrinsic motivation more than solving standard tasks, with no task-type × group interaction

## Subclaims
`q3 i3` A main effect of task type on intrinsic motivation favored context-personalized tasks (η²p = .37). [→ Osman Tasdelen 2025](#osman-tasdelen-2025)

## Evidence

### Osman Tasdelen 2025

Osman Tasdelen, Daniel Bodemer. (2025). Generative AI in the Classroom: Effects of Context-Personalized Learning Material and Tasks on Motivation and Performance. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-025-00491-9

`q3 · i3` · `causal · r2`

2×2 repeated measures ANOVA with task type as within-subjects factor in the classroom experiment. Personalized-task motivation (M = 3.38) exceeded standard-task motivation (M = 2.86), with effect size "η 2 p = .37".

> "a main effect for task type was found, F(1, 112) = 64.61, p <. 001,η 2 p = .37. Students who worked on context-personalized tasks had signiﬁcantly higher intrinsic motivation scores (M = 3.38, SD = 1.18) than those who worked on standard tasks (M = 2.86, SD = 1.15)"
