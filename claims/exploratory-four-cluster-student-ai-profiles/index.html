Exploratory K-means clustering among students only (n = 961, nine features, fixed seed, ten initializations) identified four clusters, with Cluster 3 (n = 251) showing the highest experience, competence, usefulness, and trust and Cluster 1 (n = 111) the lowest.

"The primary student-only K-means specification identified four clusters in the complete-case subsample of n = 961. With the fixed random seed and ten initializations described above, cluster sizes were 221, 111, 378, and 251."
