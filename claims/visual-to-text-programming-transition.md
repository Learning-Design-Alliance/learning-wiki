# Dual-mode visual/text programming (ViMAP plus NetLogo) supported 8th-graders' transition to text-based programming

## Subclaims
`q2 i?` After visual programming of ant ecosystems, 8th-graders who modified underlying NetLogo code to create new ViMAP commands deepened their computational thinking, and independently created new commands for a different ecosystem in a post-assessment. [→ Sengupta 2018](#sengupta-2018)

## Evidence

### Sengupta 2018

Sengupta, P., Dickes, A., & Farris, A.V. (2018). Toward a Phenomenology of Computational Thinking in STEM Education. In Computational Thinking in STEM Discipline: Foundations and Research Highlights (Khine, M.S., Ed.). Springer. [doi:10.1007/978-3-319-93566-9_4](https://doi.org/10.1007/978-3-319-93566-9_4)

`q2 · i?` · `theoretical · r3`

Classroom study (Sengupta et al., 2015b) in an 8th grade classroom using ViMAP's dual-mode design, where visual commands are defined as "short NetLogo procedures". Students creating a capstone ViMAP-Ants version for 4th graders created classes, local variables, conditionals and lists; they "successfully created new commands for a NetLogo simulation of a different ecosystem without teacher-provided assistance."

> "Students’ growth in computational thinking was further evident in a post-assessment activity, in which they successfully created new commands for a NetLogo simulation of a different ecosystem without teacher-provided assistance"
