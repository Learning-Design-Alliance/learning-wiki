# LLM question types differed by condition: EDBook prompted more applying and analyzing questions, while webpage-plus-ChatGPT prompted more evaluating and solution-requesting questions

## Subclaims
`q2 i?` Questions asked to the LLM in the EDBook condition more often sought application of concepts to new situations and differentiation between concepts, whereas webpage-plus-ChatGPT questions more often sought explanations of code solutions or directly requested solutions. ## Evidence

### Steve Oney 2024

Steve Oney, Yue Shen, Fei Wu, Young Suh Hong, Ziang Wang, Yamini Khajekar, Jiacheng Zhang, and April Yi Wang. (2024). EDBooks: AI-Enhanced Interactive Narratives for Programming Education. [doi:10.48550/arXiv.2411.10687](https://doi.org/10.48550/arXiv.2411.10687)

`q2 · i?` · `causal · r2`

Manual coding of LLM questions using Bloom's Taxonomy levels in the within-subjects study. No questions at the remembering level were observed in either condition; the article reports the pattern qualitatively with no effect size.

> "InCEDBook, participants asked more questions for seeking usage of a concept in new situations (applying) and differentiating between two concepts (analyzing), whereas inCWeb+GPT, participants asked more questions for seeking explanations of a code solution (evaluating) or directly requesting a solution for a coding problem (creating)"
