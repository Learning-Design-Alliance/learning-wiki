# UDL implementation shifted instructional grouping: treatment classes spent significantly more time in small groups while control classes spent more time in whole class and independent structures

## Subclaims
`q3 i3` Post intervention, control classes spent significantly more time in whole class (partial η = .173) and independent structures (η = .093), while treatment classes spent significantly more time in small group/partner work (η = .281); the overall grouping effect had partial η = .289. ## Evidence

### Katz 2013

Jennifer Katz. (2013). The Three Block Model of Universal Design for Learning (UDL): Engaging students in inclusive education. Canadian Journal of Education, 36(1). https://journals.sfu.ca/cje/index.php/cje

`q3 · i3` · `causal · r2`

MANCOVA of observed grouping structures (Table 9): overall F(9,68) = 11.434, partial η = .289; whole class η = .173, small group η = .281, independent η = .093, all p < .001. Table 4 means show treatment small group time rising from 11.30 to 41.55 per 60 minutes.

> "In this study, control classes spent significantly more time in whole class and independent structures post intervention (see table 4), while treatment classes spent significantly more time working in small groups, thus perhaps influencing active engagement."
