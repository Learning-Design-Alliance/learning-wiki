# After repeated correct recall, higher left PFC activation during testing predicts subsequent failure rather than success

## Subclaims
`q3 i2` On the second test in the STT-T condition, left PFC showed a subsequent failure effect: higher activation predicted a lower probability of correct recall on the third test. [→ Liu 2016](#liu-2016)
`q3 i?` Exploratory whole-brain analysis likewise found a subsequent failure effect for the second test in left PFC (BA 45) and left PPC (BA 40). [→ Liu 2016 (2)](#liu-2016-2)

## Evidence

### Liu 2016

Liu, X. L., & Reder, L. M. (2016). fMRI exploration of pedagogical benefits of repeated testing: when more is not always better. Brain and Behavior. https://doi.org/10.1002/brb3.476

`q3 · i2` · `causal · r2`

ROI subsequent memory analysis of correct second-test (STT-T) trials back-sorted on Day 2 recall, fMRI experiment with 19 analyzed subjects. While right-hemisphere ROIs showed subsequent memory effects, "The left PFC showed a subsequent failure effect (t 18 = 3.11, P = 0.006, d = 0.71)".

> "The left PFC showed a subsequent failure effect (t 18 = 3.11, P = 0.006, d = 0.71)."

### Liu 2016 (2)

Liu, X. L., & Reder, L. M. (2016). fMRI exploration of pedagogical benefits of repeated testing: when more is not always better. Brain and Behavior. https://doi.org/10.1002/brb3.476

`q3 · i?` · `causal · r2`

Exploratory whole-brain analysis (P < 0.001, cluster-size corrected via Monte Carlo simulation) of the same second-test contrast. "a subsequent failure effect was found in left PFC (BA 45) and left PPC (BA 40)"; the subsequent memory effect for the second test was only found in right hemisphere.

> "For the second test, a subsequent memory effect was only found in right hemisphere (BA 6, BA 10, BA 2) (Fig. 4C) and a subsequent failure effect was found in left PFC (BA 45) and left PPC (BA 40) (Fig. 4D)."
