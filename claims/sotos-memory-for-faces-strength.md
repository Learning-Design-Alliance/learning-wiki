## Evidence

### Butti 2025

Butti, N., Urgesi, C., Decio, A., Pezzani, L., Milani, D., and Montirosso, R. (2025). A Further Characterisation of the Neuropsychological Profile, Social Perception, and Academic Skills in Sotos Syndrome. Journal of Intellectual Disability Research, 69: 664–674. https://doi.org/10.1111/jir.13250

`q3 · i3` · `associational · r1`

Paired-sample t test within the memory and learning domain of the NEPSY-II in the cross-sectional Sotos syndrome cohort. "better performance emerged in memory for faces than in memory for designs" with a large effect (Cohen's d = 1.16, p < 0.001).

> "For memory and learning, better performance emerged in memory for faces than in memory for designs (t 23 = 4.78, p < 0.001, Cohen's d = 1.16)."
