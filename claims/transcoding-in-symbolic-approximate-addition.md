# Symbolic approximate addition is predicted by nonsymbolic number line estimation, the VSSP and the CE, consistent with transcoding to the nonsymbolic code

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r2` · `q3`

## Subclaims
`q3 i?` Nonsymbolic number line estimation, VSSP and CE each significantly predicted symbolic approximate addition. [→ Xenidou-Dervou 2015](#xenidou-dervou-2015)

## Evidence

### Xenidou-Dervou 2015

Xenidou-Dervou, I., van der Schoot, M., & van Lieshout, E. C. D. M. (2015). Working memory and number line representations in single-digit addition: Approximate versus exact, nonsymbolic versus symbolic. *Quarterly Journal of Experimental Psychology, 68*(6), 1148–1167. [doi:10.1080/17470218.2014.977303](https://doi.org/10.1080/17470218.2014.977303)

`q3 · i?` · `associational · r2`

Stepwise regression on the symbolic approximate task; "nonsymbolic number line estimation, t(102) = -4.03, p < .001, the VSSP, t(102) = 2.91, p = .004 and the CE, t(102) = 2.18, p = .032" were significant, supporting the transcoding assumption.

> "As expected, nonsymbolic number line estimation, t(102) = -4.03, p < .001, the VSSP, t(102) = 2.91, p = .004 and the CE, t(102) = 2.18, p = .032, were demonstrated to be significant predictors of symbolic approximate addition."
