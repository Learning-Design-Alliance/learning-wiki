q2 · i? · causal · r?

Reading analysis of the same Duval County quasi-experimental study, with 4,367 students in the reading analysis; the ELA effect was statistically significant with effect size +0.16, larger than the mathematics effect in the same study.

"Results indicated that Exact Path had a statistically significant positive effect on both Mathematics (effect size = +0.06) and ELA (effect size = +0.16), with students in the intervention group outperforming their peers."
