Peter Fowles 2026¶

Peter Fowles, Erik Falor, Sulove Bhattarai, John Edwards, and Seth Poulsen. (2026). Combating Harms of Generative AI in CS1 with Code Review Interviews and a Flipped Classroom. https://arxiv.org/abs/2605.21374

q2 · i? · causal · r1

Required end-of-semester survey of the CS1-CR cohort (N=96) with Likert-scale items on code review perceptions. The article reports "65% of students agreed that code reviews helped to avoid over-reliance on AI tools"; percentages are descriptive, no inferential test or effect size is printed.

"Additionally, 65% of students agreed that code reviews helped to avoid over-reliance on AI tools, and 90% reported being motivated to understand their code better. Most students also agreed that the course should continue to use code reviews."
