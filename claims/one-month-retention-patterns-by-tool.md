# Retention after one month differs by tool: text-only retains only spatial knowledge, 3DM retains none of the three types, MR retains nominal and spatial but not mixed

## Subclaims

## Evidence

### Wang Chris 2020

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i3` · `causal · r2`

Within the text-only group (n = 18), paired comparison of test 1 and test 2 showed significant nominal decline (2.65 points, ηp2 = 0.58, p < 0.001) and mixed decline (0.88 points, ηp2 = 0.17, p = 0.003); a separate sentence reports the spatial decrease of 0.77 points was non-significant (ηp2 = 0.08, p = 0.053).

> "there was a significant decrease in nominal type question score (2.65 points, ηp2 = 0.58, Power = 1.00, p < 0.001) and mixed type question score (0.88 points, ηp2 = 0.17, Power = 0.87, p = 0.003)."

### Wang Chris 2020 (2)

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i3` · `causal · r2`

Within the 3DM group (n = 15), test 1 to test 2 comparisons showed significant decreases in nominal (1.93 points, ηp2 = 0.39, p < 0.001), mixed (0.73 points, ηp2 = 0.11, p = 0.018), and spatial (0.87 points, ηp2 = 0.09, p = 0.040) scores, summarised in Fig. 2b.

> "they had a significant decrease in all three question types (Fig. 2b); nominal question type (1.93 points, ηp2 = 0.39, Power = 1.00, p < 0.001), mixed question type (0.73 points, ηp2 = 0.11, Power = 0.67, p = 0.018), spatial question type (0.87 points, ηp2 = 0.09, Power = 0.54, p = 0.040)."

### Wang Chris 2020 (3)

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i1` · `causal · r2`

Within the MR group (n = 19), nominal (0.32 points, ηp2 = 0.02, p = 0.311) and spatial (0.58 points, ηp2 = 0.05, p = 0.119) declines were non-significant, indicating retention; a separate sentence reports the mixed type decline of 0.90 points was significant (ηp2 = 0.19, p = 0.002).

> "While there was no significant decline when comparing the anatomy test 1 to anatomy test 2 on the nominal type questions (0.32 points, ηp2 = 0.02, Power = 0.17, p = 0.311) score and spatial type questions score (0.58 points, ηp2 = 0.05, Power = 0.34, p = 0.119)."
