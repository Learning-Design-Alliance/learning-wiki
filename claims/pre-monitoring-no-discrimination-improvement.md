# Pre-monitoring does not significantly improve children's relative monitoring accuracy (discrimination between correct and incorrect answers)

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3`

## Subclaims
`q3 i?` The condition main effect on the discrimination score did not reach significance, and descriptively the control condition scored better. [→ Sophie Wacker 2024](#sophie-wacker-2024)

## Evidence

### Sophie Wacker 2024

Sophie Wacker, Claudia M. Roebers. (2024). Motivating children to (pre)monitor: positive effects on monitoring accuracy? Metacognition and Learning. https://doi.org/10.1007/s11409-023-09351-0

`q3 · i?` · `causal · r2`

ANOVA on the discrimination difference score in the same N = 305 randomized experiment. The condition effect (F (1, 301) = 2.64, p = .105) and interaction were non-significant; no effect size beyond ηp² = .01 is interpretable as magnitude, so impact is null.

> "The main effect of condition (F (1, 301) = 2.64, p = .105, ηp 2 = .01) and the interaction (F (1, 301) = 1.40, p = .24, ηp 2 = .01) did not reach significance."
