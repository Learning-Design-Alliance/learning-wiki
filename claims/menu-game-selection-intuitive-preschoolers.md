## Evidence

### Luis Ortegano 2019

Luis Ortegano, Esmitt Ramírez. (2019). Serious Educational Reinforcement Game in Preschool. Originally published 2018. [doi:10.48550/arXiv.1909.10337](https://doi.org/10.48550/arXiv.1909.10337)

`q2 · i?` · `design · r2`

Usability evaluation with the same 11 preschool children, first evaluation part, after profile creation. The authors conclude that "la selección de elementos en un menú es intuitiva", with most children starting a game without assistance.

> "El 72.73% pudo empezar un juego de forma intuitiva, el restante 27.27% necesito una explicación sencilla. Se nota que la selección de elementos en un menú es intuitiva."
