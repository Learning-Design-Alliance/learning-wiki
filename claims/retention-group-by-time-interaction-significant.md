# Learning groups differ significantly in change of anatomy test scores over one month (group × time × question type interaction)

## Subclaims
`q3 i?` A mixed ANOVA showed significant differences in the groups' change in question type scores over time. [→ Wang Chris 2020](#wang-chris-2020)
`q3 i?` Significant differences were also indicated for group-by-time score differences and for question type performance between groups. [→ Wang Chris 2020 (2)](#wang-chris-2020-2)

## Evidence

### Wang Chris 2020

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i?` · `causal · r2`

Mixed ANOVA comparing anatomy test 1 and test 2 across the three groups and question types showed a significant interaction, F(2,48) = 4.787, p = 0.013; one participant was lost at follow-up and no effect size was printed for the omnibus test.

> "A mixed ANOVA showed significant differences when comparing the learning groups' change in question type scores over time (F(2,48) = 4.787, p = 0.013)."

### Wang Chris 2020 (2)

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i?` · `causal · r2`

Follow-up mixed ANOVA terms were also significant: group differences in score change over time, F(2,48) = 5.624, p = 0.006, and question type performance between groups, F(2,48) = 3.566, p = 0.036; no effect sizes printed for these terms.

> "there were also indications of significant differences when comparing the differences in anatomy test scores between the learning groups over time (F(2,48) = 5.624, p = 0.006) and question types performance between learning groups (F(2,48) = 3.566, p = 0.036)."
