q2 · i? · qualitative · r3

In the utility-value findings of this interview study, six students questioned the career value of programming skill. P10 observed that AI "diminishes the value of coding, just because AI can code for you."

"Several students (n=6) questioned whether programming skills themselves were losing value, when asked whether AI availability had influenced how they saw the value of programming for their future career."
