## Evidence

### Spitzer Markus Wolfgang Hermann 2023

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Logistic mixed-model analysis of the coins outcome (at least 60% accuracy) for the first closure versus the prior year. The main effect of assignment was also significant (b = .25; z = 10.15; p < .001), with more coins on single problem set assignments.

> "The interaction of time window and assignment was significant (b = .10; z = 4.19; p < .001) suggesting that students who got assigned single problem sets showed a greater difference in acquired coins as a function of time window, as compared to students who got assigned entire books."

### Spitzer Markus Wolfgang Hermann 2023 (2)

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Replication for the second closure with the same model. The main effect of assignment was significant (b = .46; z = 19.07; p < .001), with more coins gained on single problem set assignments compared to book assignments.

> "The interaction of time window and assignment was significant (b = .23; z = 9.52; p < .001) with the difference in coins gained between the two time windows being more pronounced for single problem set assignments as opposed to book assignments."
