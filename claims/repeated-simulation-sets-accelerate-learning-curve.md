## Subclaims
`q2 i?` Learning-curve slopes differed significantly between sets (0.19 first vs 0.03 repeated, P < 0.001), with narrower confidence intervals in the repeated set (0.35 vs 1.04). [→ Oh Eun Jung 2020](#oh-eun-jung-2020)
`q2 i?` Median sessions to reach plateau fell from 7 (5–8) in the first set to 3 (2–4) in the second (P = 0.003). [→ Oh Eun Jung 2020](#oh-eun-jung-2020)

## Evidence

### Oh Eun Jung 2020

Oh Eun Jung, Lee Jong-Hwan, Kwon Eun Jin, Min Jeong Jin. (2020). Simulation-based training using a vessel phantom effectively improved first attempt success and dynamic needle-tip positioning ability for ultrasound-guided radial artery cannulation in real patients: An assessor-blinded randomized controlled study. PLoS ONE. https://doi.org/10.1371/journal.pone.0234567

`q2 · i?` · `causal · r2`

Learning curves fitted with a power model (Y = a·Xb) from checklist scores across simulation sessions in the simulation group (n = 11). The repeated set "started with higher performance level score and required fewer training sessions until reaching a plateau score".

> "the slopes of the two learning curves differed significantly (0.19 for first training set vs. 0.03 for repeated training set, P < 0.001), and the repeated training set showed a narrower confidence interval range reflecting reduced inter-individual variability (1.04 for first training set vs. 0.35 for repeated set)"
