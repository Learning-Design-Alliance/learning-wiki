Bethany R. Wilcox and Steven J. Pollock. (2014). Coupled Multiple-response vs. Free-response Conceptual Assessment: An Example from Upper-division Physics. arXiv preprint. [doi:10.48550/arXiv.1407.6310](https://doi.org/10.48550/arXiv.1407.6310)

Classical Test Theory reliability analysis of the split-class samples. Item-test correlations ranged 0.24–0.71 except CMR Q15 (r = 0.17); Ferguson's Delta was 0.97 for both versions, indicating good discriminatory power.

> "Using the point value of each item to calculate alpha, we ﬁnd α = 0.82 for the CMR version and α = 0.85 for the FR version. Again, this is consistent with the value of 0.82 reported historically for the FR CUE [11]."
