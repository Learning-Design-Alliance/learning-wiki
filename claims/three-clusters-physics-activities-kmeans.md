### Amin Bayat Barooni 2018

Amin Bayat Barooni, Joshua Von Korff, Brian D. Thoms, Zeynep Topdemir, Jacquelyn J. Chini. (2018). Three research-based approaches to the design of physics activities. [doi:10.1119/perc.2017.pr.098](https://doi.org/10.1119/perc.2017.pr.098)

`q2 · i?` · `qualitative · r3`

Quantitative clustering of coded student actions across 66 activities from 11 curricula (CL, OST, UMI, WP, SDI, TIP, TTU, UI, RTP, ISLE, SCL). The authors report that they "analyzed code frequencies using k-means cluster analysis" and obtained three clusters.

> "we coded student actions in sixty-six activities from eleven research-based curricula and analyzed code frequencies using k-means cluster analysis.  The result of this analysis was three clusters."
