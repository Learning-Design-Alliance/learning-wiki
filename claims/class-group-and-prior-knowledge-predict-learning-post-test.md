`q3 i2` Class group (G1-G4) had a medium-size effect on the learning post-test (F(3, 96) = 5.2, p<0.01, ht2 = 0.10), and learning pre-test a small effect (F(1, 96) = 8.6, p<0.01, ht2 = 0.06). [→ A. Gasparini 2026](#a-gasparini-2026)

## Evidence

### A. Gasparini 2026

A. Gasparini, F. Stern, M. Delaval, A. Müller. (2026). Using smartphones and tablets as experimental tools in the physics classroom: Effects on learning and motivation. Originally published 2021. [doi:10.48550/arXiv.2603.10959](https://doi.org/10.48550/arXiv.2603.10959)

`q3 · i2` · `causal · r2`

ANCOVA on the main-study learning post-test (N = 111) identified class group and learning pre-test as the only significant predictors, with the printed effect sizes ht2 = 0.10 (medium) and ht2 = 0.06 (small).

> "A medium size effect of the variable class group (G1-G4) on the result of the learning post-test (LPO) was observed (F(3, 96) = 5.2, p<0.01, ht2  = 0.10), as well as a small effect of the predictor learning pre-test (F(1, 96) = 8.6, p<0.01, ht2 = 0.06)."

### A. Gasparini 2026 (2)

A. Gasparini, F. Stern, M. Delaval, A. Müller. (2026). Using smartphones and tablets as experimental tools in the physics classroom: Effects on learning and motivation. Originally published 2021. [doi:10.48550/arXiv.2603.10959](https://doi.org/10.48550/arXiv.2603.10959)

`q3 · i?` · `causal · r2`

The same ANCOVA tested a priori-selected predictors; none besides class group and learning pre-test reached significance, including gender and self-concept regarding smartphone apps. Teacher assessment was excluded due to high correlation with class group.

> "no significant effects were found for gender, cognitive variables (prior grades in mathematics, physics and French, spatial abilities, cognitive load and activation during the experiments, cognitive load using the apps, involvement during the lessons), nor affective variables"
