Evidence¶

Bruno Sauce 2021¶

Bruno Sauce, John Wiedenhoeft, Nicholas Judd and Torkel Klingberg. (2021). Change by challenge: A common genetic basis behind childhood cognitive development and cognitive training. npj Science of Learning 6:16. https://doi.org/10.1038/s41539-021-00096-6

q3 · i? · associational · r2

From the baseline WM model on 344 participants: age significantly predicted baseline WM (β = 0.54, p < 0.001) while gender did not (p = 0.44). The change model separately showed no gender effect on WM change (p = 0.09); no effect sizes printed, so no equivalence claim.

"As expected, we found that age affected the baseline levels of WM ( β = 0.54, p < 0.001). There was no effect of gender (p = 0.44)."
