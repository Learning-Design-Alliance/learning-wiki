# Badges were the strongest predictor of learning outcomes among gamification elements (β = 0.54)

## Subclaims
`q2 i?` A multiple linear regression analysis found that the number of badges earned was the strongest predictor of post-test scores (β = 0.54, p <0.001), outperforming final leaderboard rank (β = 0.31) and total points accumulation (β = 0.28). [→ Wisnu Uriawan 2026](#wisnu-uriawan-2026)

## Evidence

### Wisnu Uriawan 2026

Wisnu Uriawan, Denis Firmansyah, Devi Mulyana, Dika Haekal Firza Pratama, Adly Juliarta Lerian, Fajar Satria Wiguna. (2026). Gamification-Based Learning Method for Hijaiyah Letters. Originally published 2025. [doi:10.48550/arXiv.2602.03851](https://doi.org/10.48550/arXiv.2602.03851)

`q2 · i?` · `design · r2`

A multiple linear regression analysis was performed to isolate the impact of specific game elements on final learning outcomes. The number of badges earned had "β= 0.54(p <0.001)", final leaderboard rank β = 0.31 (p <0.01), and total points accumulation β = 0.28 (p <0.05); the article calls the badge system "the strongest predictor (β= 0.54)".

> "The model revealed the relative contribution of each element to the final learning outcomes: a) Number of badges earnedβ= 0.54(p <0.001) b) Final leaderboard rankβ= 0.31(p <0.01) c) Total points accumulationβ= 0.28(p <0.05)"
