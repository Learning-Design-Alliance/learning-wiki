# Self-explanation prompts did not improve learning more than solving additional practice problems at equal time on task

## Subclaims
`q3 i?` There was no effect of explanation condition or an Order × Explanation interaction on conceptual knowledge (Fs < 1); self-explanation did not help beyond additional problem-solving practice. [→ DeCaro 2012](#decaro-2012)

## Evidence

### DeCaro 2012

DeCaro, M. S., & Rittle-Johnson, B. (2012). Exploring mathematics problems prepares children to learn from instruction. Journal of Experimental Child Psychology, 113, 552-568. https://doi.org/10.1016/j.jecp.2012.06.009

`q3 · i?` · `causal · r2`

In the same randomized ANCOVAs, the explanation-condition main effect and interaction were non-significant (Fs < 1): "self-explanation did not help children’s conceptual knowledge beyond additional problem-solving practice alone for either instructional order." Equivalence of time on task was achieved by equating problem counts.

> "There was no effect of explanation condition or an
Order × Explanation Condition interaction (Fs < 1), indicating that self-explanation did not help children’s conceptual knowledge beyond additional problem-solving practice alone for either instructional order"
