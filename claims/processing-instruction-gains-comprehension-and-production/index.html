Evidence¶

Bill VanPatten and Teresa Cadierno 1993¶

Bill VanPatten and Teresa Cadierno. (1993). Explicit Instruction and Input Processing. Studies in Second Language Acquisition, Volume 15, Issue 2. https://doi.org/10.1017/S0272263100011979

q3 · i? · causal · r?

The article's experiment compared processing instruction with traditional form-focused instruction using pretest and posttest measures "involving both a sentence-level interpretation (comprehension) task and a sentence-level production task" submitted to an analysis of variance. The reported result is a statistically significant gain on both measures for the processing instruction group; no effect size is printed.

"Results reveal significant gains in both comprehension and production for subjects who experienced processing instruction."
