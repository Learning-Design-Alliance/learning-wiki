## Evidence

### Loprinzi Paul D. 2019

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i3` · `causal · r2`

Experiment 1, a 4-arm randomized controlled trial (n = 80; Mage = 21.00), compared E+L, L, E, and C groups on the Logical Memory Test with immediate and delayed recall. The learning main effect was significant with a large printed effect size, eta-squared ƞ2 = 0.31, and post-hoc Mdiff = 10.26, t = 5.81, p < 0.001.

> "but there was a significant main effect for learning, F(1, 76) = 33.78, p < 0.001, ƞ2 = 0.31. Post-hoc tests were computed for the learning factor, which demonstrated a significantly greater memory performance among those who received the learning manipulation"
