## Evidence

### Peter Jamieson 2023

Peter Jamieson, Suman Bhunia, and Dhananjai M. Rao. (2023). With ChatGPT, do we have to rewrite our learning objectives - CASE study in Cybersecurity. [doi:10.1109/fie58773.2023.10343052](https://doi.org/10.1109/fie58773.2023.10343052)

`q1 · i?` · `theoretical · r2`

Authors' demonstration, not a learner study: a prompt asking whether a C program has a memory leak returns a diagnosis and fix, which the paper says shows how to accelerate "software security analysis from Apply to Analysis".

> "Figure 3 shows how we can use ChatGPT to accelerate a student's understanding of software security analysis from Apply to Analysis."

### Peter Jamieson 2023 (2)

Peter Jamieson, Suman Bhunia, and Dhananjai M. Rao. (2023). With ChatGPT, do we have to rewrite our learning objectives - CASE study in Cybersecurity. [doi:10.1109/fie58773.2023.10343052](https://doi.org/10.1109/fie58773.2023.10343052)

`q1 · i?` · `theoretical · r2`

Authors' proposal following the Linux file-permissions example: a student could test the command on a real system and "observe what the system does to manage access control for a shared system". No learner data is reported.

> "With ChatGPT acting as a tutorial agent, we can imagine a student being able to test out on a Linux system how the command works and observe what the system does to manage access control for a shared system."

### Peter Jamieson 2023 (3)

Peter Jamieson, Suman Bhunia, and Dhananjai M. Rao. (2023). With ChatGPT, do we have to rewrite our learning objectives - CASE study in Cybersecurity. [doi:10.1109/fie58773.2023.10343052](https://doi.org/10.1109/fie58773.2023.10343052)

`q1 · i?` · `design · r1`

Authors' interpretation of the network-security-tools query example (Figure 6): the query shows learners the possible system administrative tools for network security, with ChatGPT as a "personalized tutor" giving direct feedback. No learner data is reported.

> "Again, using ChatGPT as a personalized tutor allows the learner to get direct feedback on how to proceed in the space."
