## Evidence

### Tianlong Zu 2017

Tianlong Zu, John Hutson, Lester C. Loschky, and N. Sanjay Rebello. (2017). Use of Eye-Tracking Technology to Investigate Cognitive Load Theory. 2017 PERC Proceedings. https://doi.org/10.1119/perc.2017.pr.113

`q2 · i2` · `causal · r2`

Hierarchical regression (N = 46) on transitions between text and animation AoIs, run only in the redundant condition so ECL could not be tested. Table 5 reports ICL β = .351 (p < .001, a medium-to-large standardized coefficient); GCL and O-span were not significant, and the Model 2 R² increment was ns.

> "This analysis is only done for  the redundant condition , so it cannot be completed with respect to ECL. We conducted a hierarchical regression analysis for TBTA, using the same two models as before, except without ECL as an IV.  We found that only ICL can uniquely predict TBTA."
