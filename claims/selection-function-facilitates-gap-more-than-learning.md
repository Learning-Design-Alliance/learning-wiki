## Evidence

### Autin 2019

Autin, Frédérique; Batruch, Anatolia; Butera, Fabrizio. (2019). The function of selection of assessment leads evaluators to artificially create the social class achievement gap. Journal of Educational Psychology. https://doi.org/10.1037/edu0000307

`q3 · i?` · `causal · r?`

Experiments 3 and 4 (N = 374; N = 306) directly manipulated the function of assessment. Experiment 3 supported the hypothesis; Experiment 4's effect "did not reach significance"; no effect size is printed in the available text.

> "Results of Experiment 3 supported this hypothesis. The effect did not reach significance for Experiment 4, but an internal meta-analysis confirmed that assessment used for selection led evaluators to create a SES achievement gap more than assessment used for learning"

### Autin 2019 (2)

Autin, Frédérique; Batruch, Anatolia; Butera, Fabrizio. (2019). The function of selection of assessment leads evaluators to artificially create the social class achievement gap. Journal of Educational Psychology. https://doi.org/10.1037/edu0000307

`q3 · i?` · `causal · r?`

An internal meta-analysis across the four experiments confirmed the function-of-assessment effect: selection led evaluators to create a SES achievement gap more than assessment for learning. No pooled effect size is printed in the available text.

> "an internal meta-analysis confirmed that assessment used for selection led evaluators to create a SES achievement gap more than assessment used for learning, thereby contributing to the reproduction of social inequalities."
