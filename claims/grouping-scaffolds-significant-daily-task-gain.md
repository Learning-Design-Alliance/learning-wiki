# Varied grouping scaffolds produced significantly higher daily-task scores than graphic-organizer-only instruction in sixth-grade geometry

## Subclaims
`q2 i?` Students receiving grouping scaffolds (small groups, partners) scored significantly better on daily non-routine tasks than students working independently, p < 0.01. [→ Frederick 2014](#frederick-2014)

## Evidence

### Frederick 2014

Frederick, M. L., Courtney, S., & Caniglia, J. (2014). With a Little Help from My Friends: Scaffolding Techniques in Problem Solving. Investigations in Mathematics Learning, 7(2). https://eric.ed.gov/?id=EJ1052936

`q2 · i?` · `causal · r1`

Independent-samples t-test comparing daily task scores of the experimental class (grouping scaffolds plus graphic organizer) against the control class (graphic organizer only), conducted at alpha 0.05. The scaffolding condition mean was "M = 5.036, SD = 0.838" versus 4.861 (SD = 0.825); no effect size is printed.

> "There was a significant difference in the scores for scaffolding (M = 5.036, SD = 0.838) and no scaffolding (M = 4.861, SD = 0.825) conditions; p < 0.01."
