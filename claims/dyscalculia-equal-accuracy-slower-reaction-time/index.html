Evidence¶

Bulthé Jessica 2019¶

Bulthé Jessica, Prinsen Jellina, Vanderauwera Jolijn, Duyck Stefanie, Daniels Nicky, Gillebert Céline R., Mantini Dante, Op de Beeck Hans P., De Smedt Bert. (2019). Multi-method brain imaging reveals impaired representations of number as well as altered connectivity in adults with dyscalculia. Neuroimage, 190, 289-302. https://doi.org/10.1016/j.neuroimage.2018.06.012

q3 · i3 · associational · r2

2 × 2 ANOVA (group × format) on the in-scanner number comparison task of 24 dyscalculia and 24 control adults. Accuracy did not differ (95.75% vs 94.77%, p = 0.13, dCohen = 0.45), but dyscalculia participants were significantly slower, a large printed effect size (dCohen = 1.89).

"For reaction time, a significant group difference was observed, with faster response times for controls (M = 0.90s, SD = 0.07) than for individuals with dyscalculia (M = 1.18s, SD = 0.07) (F1,92 = 41.2, p < 0.001, dCohen = 1.89)."

Bulthé Jessica 2019 (2)¶

Bulthé Jessica, Prinsen Jellina, Vanderauwera Jolijn, Duyck Stefanie, Daniels Nicky, Gillebert Céline R., Mantini Dante, Op de Beeck Hans P., De Smedt Bert. (2019). Multi-method brain imaging reveals impaired representations of number as well as altered connectivity in adults with dyscalculia. Neuroimage, 190, 289-302. https://doi.org/10.1016/j.neuroimage.2018.06.012

q3 · i3 · causal · r2

Format main effect on accuracy in the same ANOVA: symbolic numbers were responded to more accurately than non-symbolic numbers, a large printed effect size (dCohen = 1.89); the RT format effect carried dCohen = 1.74 and group × format interactions were non-significant for both measures.

"A significant effect for format was observed and accuracy was higher for symbolic (M = 97.35%, SD = 1.45) than for non-symbolic numbers (M = 93.17%, SD = 1.41; F1,92 = 41.04, p < 0.001, dCohen = 1.89)."
