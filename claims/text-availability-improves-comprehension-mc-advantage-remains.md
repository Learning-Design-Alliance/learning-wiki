## Evidence

### Hildenbrand Lena; Wiley Jennifer 2025

Hildenbrand Lena; Wiley Jennifer. (2025). Supporting comprehension: The advantages of multiple–choice over true—false practice tests. Memory & Cognition. https://doi.org/10.3758/s13421-025-01726-9

`q3 · i1` · `causal · r2`

Experiment 4 assigned 288 undergraduates in a 2 (format) × 2 (text available yes/no) design. The format main effect was F(1, 284) = 5.03, p = 0.026, ηp2 = 0.02; the interaction was not significant, F(1, 284) = 0.37, p = 0.542, ηp2 = 0.001.

> "The main effect for text availability was also significant, F(1, 284) = 15.31, MSE = 1.40, p = 0.001, ηp2 = 0.04. Those who completed the practice test with the text available performed better on the final comprehension test compared with those who did not have access to the text during practice."

### Hildenbrand Lena; Wiley Jennifer 2025 (2)

Hildenbrand Lena; Wiley Jennifer. (2025). Supporting comprehension: The advantages of multiple–choice over true—false practice tests. Memory & Cognition. https://doi.org/10.3758/s13421-025-01726-9

`q3 · i2` · `causal · r2`

Practice-test accuracy in Experiment 4 rose when the text was available, "did improve performance in both" formats, with the printed effect sizes d = 0.42 and d = 0.82; all conditions scored significantly above chance.

> "The procedural change of presenting the text during the practice tests did improve performance in both multiple-choice, t(145) = 2.53, p = 0.01, d = 0.42, and true—false format conditions, t(139) = 4.83, p < 0.001, d = 0.82."
