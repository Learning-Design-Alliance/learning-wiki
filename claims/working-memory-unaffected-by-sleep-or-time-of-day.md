# Working-memory performance on the letter-number control task was not affected by time of day or relation to sleep in adolescents

## Subclaims
`q3 i?` Neither group changed significantly on the letter-number task between the first and second administration (paired t test p = 0.32 sleep, p = 0.45 no-sleep), and groups did not differ at either session. [→ Potkin KT 2012](#potkin-kt-2012)

## Evidence

### Potkin KT 2012

Potkin KT, Bunney WE Jr (2012) Sleep Improves Memory: The Effect of Sleep on Long Term Memory in Early Adolescence. PLoS ONE 7(8): e42191. https://doi.org/10.1371/journal.pone.0042191

`q3 · i?` · `causal · r2`

Null result from the same randomized experiment: the letter-number working-memory control task was given before learning and before testing. Initial scores were 6.58 (sleep) vs 6.06 (no-sleep, p = 0.13); "no statistically significant difference" across sessions. Equivalence was not tested.

> "There was also no statistically significant difference in performance for either group on letter-number task between the first and second administration (paired t test, p = 0.32 for sleep group and 0.45 for no-sleep group)."
