# Both cooperative and individual sections improved significantly on a key concepts test, with no significant difference between treatments at pretest or posttest.

## Subclaims
`q3 i?` Neither pretest (p = 0.86) nor posttest (p = 0.73) key concepts scores differed between treatments, but both sections improved significantly (p < 0.0001 each). [→ Linton Debra L. 2014](#linton-debra-l-2014)

## Evidence

### Linton Debra L. 2014

Linton Debra L., Farmer Jan Keith, Peterson Ernie. (2014). Is Peer Interaction Necessary for Optimal Active Learning? CBE—Life Sciences Education. https://doi.org/10.1187/cbe.13-10-0201

`q3 · i?` · `causal · r2`

Twenty-question key concepts test (one textbook test-bank question per chapter) administered pre and post; between-treatment comparisons by t test and ANCOVA, within-section gains significant. n = 86 cooperative, 92 individual. No effect size printed.

> "Neither pretest scores (p = 0.86) nor posttest scores (p = 0.73) were significantly different between treatments. However, scores on the key concepts test were significantly higher on the posttest than the pretest for both the cooperative (p < 0.0001) and individual (p < 0.0001) sections"
