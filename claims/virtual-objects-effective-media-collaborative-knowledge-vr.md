# Virtual objects serve as effective media for collaborative knowledge building in shared VR environments

## Evidence

### Wen Huang 2023

Wen Huang, Candace Walkington, Mitchell J. Nathan. (2023). Coordinating modalities of mathematical collaboration in shared VR environments. Intern. J. Comput.-Support. Collab. Learn. https://doi.org/10.1007/s11412-023-09397-x

`q2 · i?` · `qualitative · r2`

In the multimodal analysis of the three groups' collaborative VR geometry sessions, the real-time measurement data on modified virtual objects were found to enhance participants' ability to imagine and reason about geometric shapes, "thus lowering cognitive task demands." The virtual object also served as an external representation in the distributed cognitive system.

> "this change with the real-time data shown on the virtual object (e.g., size data and angle data) enhanced participants' ability to imagine and reason about geometric shapes, thus lowering cognitive task demands"
