# A systematic review of 168 papers yielded 1669 communication skills learning outcomes, refined to a final set of 205

## Subclaims
`q3 i?` Systematic searching of five databases identified 168 eligible papers from which 1669 individual learning outcomes were extracted, and qualitative synthesis condensed these to 205 refined outcomes. [→ Denniston C 2017](#denniston-c-2017)

Denniston C, Molloy E, Nestel D, Woodward-Kron R, Keating JL. (2017). Learning outcomes for communication skills across the health professions: a systematic literature review and qualitative synthesis. BMJ Open. https://doi.org/10.1136/bmjopen-2016-014570
