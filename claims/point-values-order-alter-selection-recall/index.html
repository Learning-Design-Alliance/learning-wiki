Evidence¶

Price 2010¶

Price, Jodi; Hertzog, Christopher; Dunlosky, John. (2010). Self-Regulated Learning in Younger and Older Adults: Does Aging Affect Metacognitive Control? Neuropsychology, development, and cognition. Section B, Aging, neuropsychology and cognition. https://doi.org/10.1080/13825580903287941

q3 · i2 · causal · r2

Experiment 2 first-selection analysis; the printed contrast is "(M = 2.08, SE = .11 versus M = 1.79, SE = .09, respectively), F (1, 79) = 4.79, p < .05, ηp2= .057". The effect was reliable only for the first selection.

"Those who had received the Difficult First point order, in which points initially favored the most difficult items, first selected items reliably more difficult than did those given the Easy First point order, (M = 2.08, SE = .11 versus M = 1.79, SE = .09, respectively), F (1, 79) = 4.79, p < .05, ηp2= .057."

Price 2010 (2)¶

Price, Jodi; Hertzog, Christopher; Dunlosky, John. (2010). Self-Regulated Learning in Younger and Older Adults: Does Aging Affect Metacognitive Control? Neuropsychology, development, and cognition. Section B, Aging, neuropsychology and cognition. https://doi.org/10.1080/13825580903287941

q3 · i2 · causal · r2

Experiment 2 recall by point order; printed effects are "F (1, 89) = 6.33, p < .05, ηp2= .066" (high value) and "F (1, 89) = 6.61, p < .05, ηp2= .069" (low value). Younger adults showed high/low recall differentiation regardless of order; older adults did not.

"Those given the Easy First point order (M = .53, SE = .02 for high and M = .50, SE = .02 for low) recalled reliably more than did those given the Difficult First point order (M = .45, SE = .02 for high and M = .42, SE = .02 for low) for both high, F (1, 89) = 6.33, p < .05, ηp2= .066, and lower valued items, F (1, 89) = 6.61, p < .05, ηp2= .069."

Related Claims¶

  • Older adults show no reliable deficit in assessing item difficulty (EOL accuracy) — related
  • Younger and older adults select study items in an easy-to-difficult order, consistent with the region of proximal learning model — related
  • Older adults allocate proportionally more study time to easy and medium items while younger adults allocate more to difficult items, yet older adults recall less despite studying more — related
  • Condition order did not affect working-memory performance but affected the magnitude of reaction-time deterioration when tasks were difficult — related
