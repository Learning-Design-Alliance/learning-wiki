## Evidence

### Zhang Jian-Wei 2026

Zhang Jian-Wei, Yue Li-Hong, Wang Yan, Duan Jia-Yu, Shan Hai-Hong. (2026). Influence of self-efficacy and self-directed learning competence on core competence among nurses specializing in infectious diseases: a cross-sectional study. Frontiers in Public Health. https://doi.org/10.3389/fpubh.2026.1775251

`q3 · i?` · `associational · r2`

Cross-sectional survey of 392 infectious disease nurses using Pearson correlations and multiple linear regression. Table 3 reports r = 0.795 between core competence and self-directed learning competence; regression B = 0.660 (p < 0.001), R2 = 0.711.

> "Pearson's correlation analysis indicated that the total core competence scores was positively correlated with both self-directed learning competence and self-efficacy (p < 0.001)."
