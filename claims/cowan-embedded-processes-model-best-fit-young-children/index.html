Evidence¶

Gray Shelley 2016¶

Gray Shelley, Green Samuel, Alt Mary, Hogan Tiffany P., Kuo Trudy, Brinkley Shara, Cowan Nelson. (2016). The Structure of Working Memory in Young Children and Its Relation to Intelligence. Journal of Memory and Language. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5157932/

q3 · i? · associational · r2

Confirmatory factor analysis comparing three working memory models in 168 children aged 7-9 with typical development. Both models evidenced good fit, but "the Cowan model showed better fit on all fit indices," with the AIC 6 points lower for the Cowan model.

"As shown in the top part of Table 5, both the Cowan embedded process model and the Baddeley and Hitch (1974) models evidenced good fit. However, the Cowan model showed better fit on all fit indices. For example, the AIC was 6 points lower for the Cowan embedded process model than for the Baddeley and Hitch model."

Gray Shelley 2016 (2)¶

Gray Shelley, Green Samuel, Alt Mary, Hogan Tiffany P., Kuo Trudy, Brinkley Shara, Cowan Nelson. (2016). The Structure of Working Memory in Young Children and Its Relation to Intelligence. Journal of Memory and Language. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5157932/

q3 · i? · associational · r2

CFA of Baddeley's four-component model in the same sample. The correlation between the visuospatial sketchpad and episodic buffer factors was 1.08, an out-of-bounds estimate, showing "an episodic buffer factor is empirically indistinguishable from the visuospatial sketch pad factor."

"The Baddeley four-component model converged to solution, but the correlation between the visuospatial sketch pad factor and the episodic buffer factor was 1.08, an out-of-bounds estimate. These results indicate that an episodic buffer factor is empirically indistinguishable from the visuospatial sketch pad factor."

  • Working memory is distinct from short-term memory in subsystem count and functional role in higher cognition — a broader claim this one bears on
  • The focus of attention factor was the only significant predictor of both fluid reasoning and visual processing intelligence when all three working memory factors were entered — related
  • A common attentional component is needed for feature binding, running digit span, and visual short-term memory tasks, while phonological storage is separate — related
