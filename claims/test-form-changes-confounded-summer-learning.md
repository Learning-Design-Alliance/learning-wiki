# Changes of test form confounded summer learning estimates in fixed-form seasonal studies

## Subclaims
`q2 i?` In the BSS, summer learning was estimated by comparing scores on different test forms, confounding summer gap growth with form changes. [→ von Hippel 2019](#von-hippel-2019)

## Evidence

### von Hippel 2019

Paul T. von Hippel, Caitlin Hamrock. (2019). Do Test Score Gaps Grow Before, During, or Between the School Years? Measurement Artifacts and What We Can Know in Spite of Them. Sociological Science 6: 43-80. https://doi.org/10.15195/v6.a3

`q2 · i?` · `associational · r2`

The article shows that in the BSS, "estimates of summer learning were confounded with changes in test form," since school-year learning compared same-form scores while summer learning compared different-form scores.

> "What this means is that estimates of summer learning were confounded with changes in test form. School-year learning was estimated by comparing fall and spring scores on the same test form, but summer learning was estimated by comparing spring and fall scores on different test forms."
