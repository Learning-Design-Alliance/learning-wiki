# Students interacted significantly more with an instructor-tuned LLM than with ChatGPT or web search when writing SQL queries

## Subclaims
`q2 i?` Students interacted more than twice as much with the instructor-tuned LLM compared to both ChatGPT (p = 0.01) and web search (p < 0.0001). [→ Kumar 2025](#kumar-2025)

## Evidence

### Kumar 2025

Kumar, H., Reza, M., Mitchell, J., Musabirov, I., Zhang, L., & Liut, M. (2025). Understanding Help-Seeking Behavior of Students Using LLMs vs. Web Search for Writing SQL Queries. Preprint. Originally published 2024. [doi:10.1145/3735091.3737569](https://doi.org/10.1145/3735091.3737569)

`q2 · i?` · `causal · r2`

Randomized interview study with 39 students in an SQL course; Kruskal-Wallis H test found a statistically significant difference between the three conditions (χ²(2) = 20.5, df = 2, p < 0.0001), with post-hoc Dunn's tests with Bonferroni correction showing "Students interacted with the Instructor-tuned LLM more than twice compared to ChatGPT (𝑝 = 0.01) and Web Search (𝑝 < 0.0001)."
