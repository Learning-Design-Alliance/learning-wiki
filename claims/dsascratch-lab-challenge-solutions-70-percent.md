### Ashwin Jagadeesha 2023 (2)

Ashwin Jagadeesha, Pranathi Rayavaram, Justin Marwad, Sashank Narain, Claire Seungeun Lee. (2023). Integrating Data Structures and Algorithms in K-12 Education using Block-based Programming. [doi:10.1109/educon54358.2023.10125165](https://doi.org/10.1109/educon54358.2023.10125165)

`q2 · i?` · `design · r2`

Qualitative analysis of an incorrect Lab-1 solution (Fig. 11): the student stored items in an array correctly with loops but the search logic was incorrect, apparently because the student used Scratch's contains? operator block for searching. For example, searching "ball" in "football" with contains? returns True.

> "Due to the fact that Scratch contains ? is a block used to perform string matching given a text contains ? block matches words or letters."
