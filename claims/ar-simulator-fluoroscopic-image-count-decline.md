In the same cohort, insertion X-ray counts "decreased significantly" from 4.6 to 2.5 (p = 0.0059). For alignment, counts fell from 6.3 to 3.2 (p = 0.0046), though retention differences were no longer significant (p = 0.059 insertion; p = 0.442 alignment).

> "For the insertion step, the average number of fluoroscopic images taken decreased significantly from 4.6 (median 3) in the first run to 2.5 (median 2) in the third run (p = 0.0059)."
