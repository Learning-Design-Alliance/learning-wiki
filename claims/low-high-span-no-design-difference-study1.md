# In the mental integration task, low-span and high-span groups showed no significant static-vs-dynamic differences (d = 0.09 and d = 0.03)

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3` · `i0` negligible

## Subclaims
`q3 i0` Performance did not differ between static and dynamic visual designs for the low-span group (d = 0.09) or the high-span group (d = 0.03). [→ Tim Kühl 2022](#tim-kuhl-2022)

## Evidence

### Tim Kühl 2022

Tim Kühl, Benedict C. O. F. Fehringer, Stefan Münzer. (2022). Unifying the Ability-as-Compensator and Ability-as-Enhancer Hypotheses. Educational Psychology Review. https://doi.org/10.1007/s10648-021-09650-5

`q3 · i0` · `causal · r2`

Illustrative subgroup analyses in the N = 77 experiment. For the high-span group 'the same was true', t(19) = 0.17, p = .433, Cohen's d = 0.03, [−0.61, 0.67]; both printed effect sizes are below d = 0.2.

> "For the low-span group, performance did not differ between the static and the dynamic visual design, t(34) = 0.73, p = .765, Cohen's d = 0.09, CI = [−0.39, 0.56]."
