## Evidence

### Liu and Koedinger 2017

Ran Liu, Kenneth R. Koedinger. (2017). Closing the loop: Automated data-driven cognitive model discoveries lead to improved instruction and learning gains. Journal of Educational Data Mining, Volume 9, No 1. https://eric.ed.gov/?id=EJ1155896

`q3 · i?` · `causal · r2`

Post-hoc ANOVA using condition (control, redesigned) and item type (forward, backward) to predict problems completed. The redesigned condition completed more backward items (mean = 13.4) than control (mean = 5.75), while control completed more forward items (mean = 12.3) than redesigned (mean = 11.5).

> "we did observe a significant interaction between condition and item type [F(1,1)  = 29.91, p < 0.0001]."
