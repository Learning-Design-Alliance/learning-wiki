# Working memory capacity predicts comprehension performance only in the disfluency condition, with higher WMC yielding better comprehension

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · causal `r2` · `q2`

## Subclaims
`q2 i?` In the disfluency condition, WMC was a significant positive predictor of comprehension performance, while in the fluency condition it was not. [→ Janina Lehmann 2015](#janina-lehmann-2015)
`q2 i?` The learning material × WMC interaction term significantly predicted comprehension performance. [→ Janina Lehmann 2015 (2)](#janina-lehmann-2015-2)

## Evidence

### Janina Lehmann 2015

Janina Lehmann, Christina Goussios, Tina Seufert. (2015). Working memory capacity and disfluency effect: an aptitude-treatment-interaction study. Metacognition Learning. https://doi.org/10.1007/s11409-015-9149-z

`q2 · i?` · `causal · r2`

Regression analysis for comprehension in the same randomized experiment with 47 university students. In the disfluency condition WMC significantly predicted comprehension: "The higher the WMC, the better the comprehension performance with the disfluent text."

> "As predicted in Hypothesis 2b, for the disfluency condition the WMC was a significant predictor for comprehension ( β=10.66, t(46)=2.86, p<.05): The higher the WMC, the better the comprehension performance with the disfluent text."

### Janina Lehmann 2015 (2)

Janina Lehmann, Christina Goussios, Tina Seufert. (2015). Working memory capacity and disfluency effect: an aptitude-treatment-interaction study. Metacognition Learning. https://doi.org/10.1007/s11409-015-9149-z

`q2 · i?` · `causal · r2`

Same regression model for comprehension: the learning material × WMC interaction term was significant, "β=12.62, t(46)=2.33, p=.0 3", confirming the hypothesized aptitude-treatment interaction for comprehension.

> "As predicted in Hypothesis 2, the interaction term was significant in the prediction of comprehension performance ( β=12.62, t(46)=2.33, p=.0 3)."
