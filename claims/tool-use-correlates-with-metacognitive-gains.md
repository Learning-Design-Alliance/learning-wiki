`q2 · i2` · `causal · r2`

Correlational analysis in the quasi-experiment relating tool-use measures to changes in metacognitive awareness. Only the sessions correlation (r = .244, p = .034) was significant; the other two were not, so the article's H4 support is partial.

> "Positive correlations between metacognitive awareness and number of sessions (r = .244, p = .034), interaction time (r = .083, p = .434) and metacognitive activities (r = .176, p = .096) were found (H4)."
