# Reasoning test performance was significantly lower in the red condition (Δ = -0.34), but the omnibus test across cognitive measures was not significant

## Subclaims
`q3 i?` For reasoning tests the pooled effect was Δ = -0.34, p = .016, 95% CI [-0.61, -0.06], indicating significantly lower scores in the red condition. [→ Gnambs Timo 2020](#gnambs-timo-2020)
`q3 i?` The omnibus test comparing anagram, reasoning, and knowledge effects did not corroborate the observed differences statistically (Qm(df = 2) = 2.22, p = .329). [→ Gnambs Timo 2020 (2)](#gnambs-timo-2020-2)

## Evidence

### Gnambs Timo 2020

Gnambs Timo. (2020). Limited evidence for the effect of red color on cognitive performance: A meta-analysis. Psychonomic Bulletin & Review. https://doi.org/10.3758/s13423-020-01772-1

`q3 · i?`

Subgroup analysis of the meta-analysis: reasoning tests showed "impaired performance for red color" with a pooled effect of Δ = -0.34, p = .016; the article calls this a medium-size effect in the conclusion.

> "descriptive comparisons for the cognitive measures (anagrams, reasoning, knowledge) showed impaired performance for red color on reasoning tests, Δ = -0.34, p = .016, 95% CI [-0.61, -0.06]"

### Gnambs Timo 2020 (2)

Gnambs Timo. (2020). Limited evidence for the effect of red color on cognitive performance: A meta-analysis. Psychonomic Bulletin & Review. https://doi.org/10.3758/s13423-020-01772-1

`q3 · i?`

Omnibus moderator test across the three cognitive measures in the same meta-analysis was non-significant, so the between-measure differences were not statistically corroborated.

> "However, the omnibus test did not corroborate the observed differences statistically, Qm(df = 2) = 2.22, p = .329, R2 < .001."
