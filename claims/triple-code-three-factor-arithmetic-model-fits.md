# A three-factor, format-specific arithmetic measurement model (Triple Code Theory) fits third-graders' arithmetic data, while single-factor and two-factor models do not

## Evidence

### Rhodes Katherine T. 2017

Rhodes Katherine T., Branum-Martin Lee, Washington Julie A., Fuchs Lynn S. (2017). Measuring arithmetic: A psychometric approach to understanding formatting effects and domain specificity. Journal of Educational Psychology. https://doi.org/10.1037/edu0000189

`q2 · i?` · `associational · r2`

Confirmatory factor analysis of 11 arithmetic measures in N=1314 third-grade children compared four theory-guided arithmetic-only measurement models. The article reports the Triple Code three-factor model (visual Arabic, auditory verbal, analog magnitude) fit; the abstract-code, encoding-complex, and exact-versus-approximate two-factor models did not.

> "Of these models, the Triple Code Theory model of arithmetic was an approximate good fit for the data, while the other three models of arithmetic measurement were not."
