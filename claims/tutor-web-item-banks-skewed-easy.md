# IRT analysis showed the tutor-web item banks contained more easy than difficult questions

## Subclaims
`q2 i?` Fitted IRT models predicting probability of a correct answer for an average student showed distributions centred to the right for all four question banks, implying more easy than difficult questions. [→ Anna Helga Jonsdottir 2013](#anna-helga-jonsdottir-2013)

## Evidence

### Anna Helga Jonsdottir 2013

Anna Helga Jonsdottir, Gunnar Stefansson. (2013). Enhanced Learning with Web-Assisted Education. [doi:10.48550/arXiv.1310.4667](https://doi.org/10.48550/arXiv.1310.4667)

`q2 · i?` · `associational · r2`

IRT model fits (ltm package in R) to quiz responses from the four item banks, with predicted correct-answer probabilities for an average student shown in Fig. 4. The mass was "mostly centred to the right for all four question banks"; in the continuous-distributions bank the average student had over 50% chance on each question.

> "This implies that the number of easy questions is higher than the number of diﬃcult questions in the question pools. The situations is worst in the second pool where the average student has more than 50% chance of answering each questions correctly."
