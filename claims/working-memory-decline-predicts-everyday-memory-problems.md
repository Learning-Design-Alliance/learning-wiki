# Greater ten-year working memory decline predicts more everyday memory problems in adjusted multilevel analyses

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q3` peer-reviewed experiment

## Subclaims
`q3 i?` In adjusted multilevel models, greater working memory decline over ten years was significantly predictive of a greater number of everyday memory problems. [→ Hahn Elizabeth A. Ph.D. 2014](#hahn-elizabeth-a-phd-2014)

## Evidence

### Hahn Elizabeth A. Ph.D. 2014

Hahn Elizabeth A. Ph.D., Lachman Margie E. Ph.D. (2014). Everyday Experiences of Memory Problems and Control: The Adaptive Role of Selective Optimization with Compensation in the Context of Memory Decline. Neuropsychology, development, and cognition. Section B, Aging, neuropsychology and cognition. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4156931/

`q3 · i?`

Adjusted multilevel analysis of 103 MIDUS/BOLOS participants with ten-year working memory difference scores and 12-week diaries. The article reports the main effect of memory decline was "significantly predictive, as expected, of a greater number of memory problems" (Est. = -2.45, p = .047).

> "In the adjusted model, the main effect of memory decline was significantly predictive, as expected, of a greater number of memory problems."
