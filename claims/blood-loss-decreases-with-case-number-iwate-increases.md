Multivariate linear regression on the bi-institutional cohort with clinically relevant covariates. Estimated blood loss showed "a small, but significant, reduction as case numbers progressed" (β = -0.55, p = .005); the coefficient is unstandardised, so no effect size magnitude is coded.
