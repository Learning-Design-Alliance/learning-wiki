# Successful encoding of schema-related information recruits the mPFC whereas successful encoding of schema-unrelated information recruits the medial temporal lobe

## Subclaims
`q3 i?` A Schema × Subsequent Memory interaction showed greater mPFC subsequent memory effects for schema-related than schema-unrelated items, and the opposite pattern in bilateral MTL. [→ van Kesteren 2014](#van-kesteren-2014)

## Evidence

### van Kesteren 2014

van Kesteren, M. T. R., Rijpkema, M., Ruiter, D. J., Morris, R. G. M., & Fernández, G. (2014). Building on Prior Knowledge: Schema-dependent Encoding Processes Relate to Academic Performance. Journal of Cognitive Neuroscience, 26(10), 2250–2261. https://doi.org/10.1162/jocn_a_00630

`q3 · i?` · `causal · r1`

fMRI subsequent memory analysis in 31 students during encoding of curriculum-embedded facts. The mPFC showed a positive Congruency × Memory interaction (Z = 3.30, SVC p < .05), and a medial temporal cluster showed the opposite, negative effect for schema-unrelated (correct > incorrect) > schema-related (correct > incorrect).

> "The whole-brain analysis (Figure 2A) revealed a positive effect for the Congruency × Memory interaction in the mPFC (peak [MNI 2, 46, 0], Z = 3.30, 27 voxels, SVC for an mPFC mask taken from van Dongen et al., 2011, p < .05) for schema-related (correct > incorrect) > schema-unrelated (correct > incorrect)"
