# There is no statistically significant difference in vocabulary post-test scores between students learning via animation and via paper-based text

## Subclaims
`q2 i?` Post-test achievement scores of the animation group and the paper-based control group did not differ statistically significantly (p>0,05). [→ Kayaoğlu 2011](#kayaoglu-2011)

## Evidence

### Kayaoğlu 2011

Kayaoğlu, M. N., Dağ Akbaş, R., & Öztürk, Z. (2011). A Small Scale Experimental Study: Using Animations to Learn Vocabulary. TOJET: The Turkish Online Journal of Educational Technology, 10(2). https://eric.ed.gov/?id=EJ932222

`q2 · i?` · `causal · r1`

Small-scale quasi-experiment with two pre-intermediate classes (experimental n=17, control n=22) analyzed with independent t-tests in SPSS 16.00. The post-test means were "X experiment = 24,06 ; X control = 21,45" with no statistically significant difference (p>0,05).

> "The analysis of post-tests show that there is no statistically significant difference X experiment = 24,06 ; X control = 21,45) between the experimental group who learned using animation-based method and those who learned using paper-based text in a traditional language teaching method (p>0,05)."
