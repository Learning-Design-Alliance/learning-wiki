Mixed-design ANOVAs on object counting and creation task accuracy with hearing status as between-subjects factor and set size as within-subject factor; no significant hearing-status effect or interaction. No effect size is printed, so the null is not an equivalence claim.

> "These analyses yielded no significant effects of hearing status, nor was the interaction with hearing status significant."
