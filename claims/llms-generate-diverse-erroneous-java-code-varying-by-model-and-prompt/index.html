Evidence¶

Ali Keramati 2026¶

Ali Keramati, Jie Cao, Iman Mohammadi, Mark Warschauer, Yang Shi. (2026). Simulating Students' Java Programming Errors with Large Language Models. arXiv preprint. https://arxiv.org/abs/2606.14113 doi:10.48550/arxiv.2606.14113

q2 · i? · design · r2

Automated AST analysis (Zhang-Shasha edit distance) of erroneous code generated by five LLMs under IO, CoT, and Self-Refine prompting for 37 Java problems. The study reports "non-trivial mean edit distances observed across all models and prompting techniques"; Gemini 2.5 Pro and Claude Sonnet 4 exceeded 60 under most prompts, GPT-4o ranged around 25-40.

"the results in Table 1 indicate that LLMs (across five models) are capable of producing diverse erroneous code, as reflected in the non-trivial mean edit distances observed across all models and prompting techniques"
