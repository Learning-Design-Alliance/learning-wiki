Achievement-group analysis of the same course-score data: students were grouped by overall semester examination performance and signed Cohen D values were computed per course (Table 4). "the average value of the effect sizes in all semesters was highest for low-achieving students"; the ordering holds for every semester, with no single effect size printed for the aggregate pattern.

> "the average value of the effect sizes in all semesters was highest for low-achieving students, followed in descending order by middle-achieving and high-achieving students (Table 4). Specifically, low achievers showed positive values for the effect size for all 3 semesters, indicating a decline in test scores in 2020 compared to 2019."
