Doğan Yunus 2026¶

q4 · i2 · quant-synthesis · r3

Class-size moderator analysis across the 35 studies, with class size coded as small (≤49), medium (50–99), large (≥100). Medium classes showed g = 0.687; the article reports the between-group test as "marginally significant (Q = 4.61, df = 2, p = 0.099)".

"Analyses based on class size revealed that the effect size was highest in medium-sized classes (g = 0.687). In small classes, the effect was lower (g = 0.448), while in large classes, it was moderate (g = 0.545)."
