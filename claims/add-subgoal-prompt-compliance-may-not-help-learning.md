# More fixations on the learning content after an add-subgoal prompt are associated with higher learning gains, suggesting complying with that prompt may not be effective

## Subclaims
`q2 i3` A main effect of fixations on learning content for the add subgoal prompt (F1,3 = 13, p = .03, ηp2 = .29) suggests complying with this prompt might not be effective for learning. [→ Lallé 2017](#lalle-2017)

## Evidence

### Lallé 2017

Lallé, S., Mudrick, N., Conati, C., Taub, M., Azevedo, R. (2017). On the Influence on Learning of Student Compliance with Prompts Fostering Self-Regulated Learning. Proceedings of the 10th International Conference on Educational Data Mining. https://educationaldatamining.org/EDM2017/

`q2 · i3` · `associational · r1`

Regression over inferred-compliance behaviors (window length, fixations, SRL strategies) for the 16 students with valid eye-tracking data. Students "learned more when they fixate more on the current page than when fixating less", though only seven students with valid gaze data received this prompt.

> "We found a main effect of fixation on lear ning content  for the “add subgoal” prompts  (F1,3 = 13, p = .03, ηp2 = .29 )"
