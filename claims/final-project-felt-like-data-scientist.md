`q2 · i?` · `qualitative · r3`

Post-survey open-ended prompt analysis ("When in particular did you feel like a data scientist in this curriculum?") supplemented by interviews. Five students mentioned class exercises and six highlighted the tools (RapidAPI, EduBlocks, CODAP) as moments of feeling like data scientists.

> "Seven students mentioned the final project as their peak experience. One student stated, "I mainly felt like a data scientist when working on the final project.""
