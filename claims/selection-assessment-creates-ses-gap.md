# Evaluators using assessment for selection find more mistakes in tests attributed to low-SES than high-SES students, creating an artificial SES achievement gap

## Subclaims
`q3 i?` In two experiments, evaluators using normative grading found more mistakes when the test was attributed to a low-SES rather than a high-SES student. [→ Autin 2019](#autin-2019)

## Evidence

### Autin 2019

Autin, Frédérique; Batruch, Anatolia; Butera, Fabrizio. (2019). The function of selection of assessment leads evaluators to artificially create the social class achievement gap. Journal of Educational Psychology. https://doi.org/10.1037/edu0000307

`q3 · i?` · `causal · r2`

Two experiments (N = 196; N = 259) in which participants assessed a test supposedly produced by a high- or low-SES student under normative grading or formative comments. The article reports that evaluators "found more mistakes if the test was attributed to a low- rather than a high-SES student"; no effect size is printed in the available text.

> "Results showed that evaluators using assessment for selection found more mistakes if the test was attributed to a low- rather than a high-SES student, a difference reduced in the assessment for learning condition."
