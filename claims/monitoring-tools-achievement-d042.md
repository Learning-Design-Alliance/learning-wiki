# Monitoring tools produce a moderate effect on academic achievement (d = 0.42), supporting a reactivity effect

## Subclaims
`q3 i2` Interventions using monitoring tools yield a moderate effect size on academic achievement (d = 0.42). [→ Dignath 2023](#dignath-2023)

## Evidence

### Dignath 2023

Dignath, C., van Ewijk, R., Perels, F., & Fabriz, S. (2023). Let Learners Monitor the Learning Content and Their Learning Behavior! A Meta-analysis on the Effectiveness of Tools to Foster Monitoring. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09718-4

`q3 · i2` · `quant-synthesis · r?`

Meta-analysis of 32 pre-post control-group intervention studies of monitoring tools (learning journals, rubrics, portfolios), integrating 109 effect sizes with 3492 participants. The pooled effect on academic achievement was "a moderate effect size on academic achievement (d = 0.42)".

> "The results of this meta-analysis, integrating 109 effect sizes with 3492 participants from 32 intervention studies, supported a reactivity effect by revealing a moderate effect size on academic achievement (d = 0.42)"
