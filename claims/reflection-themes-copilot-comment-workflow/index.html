  • Overreliance on AI is the most prevalent pedagogical limitation (27 studies, 50%), followed by reduced critical thinking (25 studies, 46%) — related
  • Low comment rewriting does not imply a smooth process: students describe the main effort as verifying generated code rather than revising prompts — related
  • Students' LLM use in CS2 fell into three themes: understanding, assisting code writing, and writing code, with only a few using LLMs to write code — related
  • Students predominantly recommended future students use office hours and formal course staff, with LLMs positioned as a supplement — related
  • GenAI use involves substantial hidden labor of prompting, verification, and correction that remains invisible in productivity evaluation — related

  • Teachers experienced AI as expanding design possibilities while increasing the burden of verification and professional responsibility — related
