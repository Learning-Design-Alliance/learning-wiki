Group comparisons by gender in the cross-sectional preterm cohort, using the parent-rated Vanderbilt scale (71 respondents), psychoeducational tests and WISC-4 indices; all three contrasts printed with p-values but no effect sizes.

> "Boys scored higher in the Vanderbilt Assessment test for lack of attention in comparison to girls (45.0 vs. 12.9%); p=0.003), and presented more frequent flaws in the reading test (66.0 vs. 42.3%; p=0.041), according to Table 3, and in the operational memory IQ test (34.3 vs. 10.0%; p=0.041), according to Table 4."
