# The overcoming-barriers intervention raises self-efficacy for using retrieval practice immediately after the intervention but not at three-week follow-up

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3`

## Subclaims
`q3 i?` Across both time points, only a main effect of time was statistically detectable for self-efficacy; the intervention main effect and interaction were not. [→ Lisi Wang 2023](#lisi-wang-2023)

## Evidence

### Lisi Wang 2023

Lisi Wang, Katherine Muenks, Veronica X. Yan. (2023). Interventions to Promote Retrieval Practice: Strategy Knowledge Predicts Intent, but Perceived Cost Predicts Usage. Journal of Educational Psychology. https://doi.org/10.1037/edu0000813

`q3 · i?` · `causal · r2`

Mixed ANOVA on self-efficacy across both sessions found only a main effect of time; the intervention effect did not persist, with 'no interaction, F (1, 277) = 3.20, p = .08'. No effect size for the version difference was interpretable at T2.

> "the mixed ANOVA revealed only a statistically detectable main effect of time, F (1, 277) = 10.33, p = .001, η 2 p = .036. There was no main effect of intervention, F (1, 277) = 1.63, p = .20, η 2 p = .006; and no interaction, F (1, 277) = 3.20, p = .08, η 2 p = .011"
