Zahra 2025¶

Zahra, F. T. (2025). Three Pathways of Student-AI Interaction: Constraint-First Design for Higher-Order Thinking. Manuscript under blind review; framework first presented at EAAI-25, Philadelphia, PA. https://arxiv.org/abs/2610.00338 doi:10.48550/arxiv.2610.00338

q2 · i? · qualitative · r2

Supplementary coding exercise in which GPT-5 applied the existing codebook to the same 50 messages and introduced "calculation_check" for 28% of messages. The scheme divergence reduced comparability and produced low pairwise kappas; no effect size is printed.

"It introduced calculation_check for messages in which students submitted completed work and asked about computational accuracy. The human codebook had distributed these messages across two improvement-request categories, so the new label made visible a recurring feature that we had not named separately."
