# Game-based and non-game-based number line estimation training produced statistically indistinguishable pretest-to-posttest learning gains in fraction magnitude understanding

## Subclaims
`q3 i?` Adults improved fraction magnitude estimation from pretest to posttest in both conditions, with no significant condition effect or time-by-condition interaction. [→ Manuel Ninaus 2023](#manuel-ninaus-2023)

## Evidence

### Manuel Ninaus 2023

Manuel Ninaus, Rodolpho Cortez, Izabel Hazin, Kristian Kiili, Silke M. Wortha, Elise Klein, Elisabeth M. Weiss, Korbinian Moeller. (2023). The added value of game elements: better training performance but comparable learning gains. Education Tech Research Dev. https://doi.org/10.1007/s11423-023-10263-8

`q3 · i?` · `causal · r2`

Linear mixed model on PAE from pretest to posttest in a randomized pre-post training study with 85 adults (game n = 41, non-game n = 44). The time effect was significant (beta = -0.54, p = 0.005), but "nor the interaction between time and condition was statistically significant" (p = 0.449).

> "Neither the effect of condition (beta = 0.35, 95% CI [− 0.15, 0.85]; t(164) = 1.36, p = 0.173; Std. beta = 0.20, 95% CI [− 0.15, 0.55]) nor the interaction between time and condition was statistically significant"
