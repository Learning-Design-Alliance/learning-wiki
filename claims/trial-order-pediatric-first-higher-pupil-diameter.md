## Evidence

### Khanfar Aseel F. 2025

Khanfar Aseel F., Motamedi Sanaz, Safford Shawn D., Moore Jason, Menold Jessica, Miller Scarlett. (2025). Visual attention and cognitive workload using different laparoscopic box trainers and mixed-reality feedback. Surgical Endoscopy. https://doi.org/10.1007/s00464-025-11881-4

`q3 · i3` · `causal · r2`

Follow-up mixed ANOVA in the same novice experiment; trial order significantly affected pupil diameter, "with higher pupil diameters for participants who started with the pediatric box trainer" (partial η2 = 0.255, p = 0.016).

> "The main effect of the trial order showed a statistically significant difference in pupil diameter, F(1, 20) = 6.85, p = 0.016, partial η2 = 0.255, with higher pupil diameters for participants who started with the pediatric box trainer (mean difference = 0.65, standard error = 0.248 mm, p = 0.016)"
