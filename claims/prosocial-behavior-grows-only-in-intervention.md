## Evidence

### Premo Joshua 2018

Premo Joshua, Cavagnetto Andy, Davis William B. (2018). Promoting Collaborative Classrooms: The Impacts of Interdependent Cooperative Learning on Undergraduate Interactions and Achievement. CBE—Life Sciences Education 17(2). https://doi.org/10.1187/cbe.17-08-0176

`q3 · i?` · `causal · r2`

Longitudinal analysis of weekly CCOP prosocial behavior (Figure 3, n = 20 classrooms) found a significant condition-by-time interaction for prosocial behavior only in intervention classrooms (F(1, N = 179) = 10.3, R2 = 0.05); no time effect for discussion practices in either condition.

> "Prosocial behavior also had a minor, but significant interaction with time in the intervention condition (F(1, N = 179) = 10.3, p < 0.05, R2 = 0.05) but not in the comparison condition (F(1, N = 179) = 0.30, p = 0.59, R2 < 0.001"
