Background-item comparison between the two anonymous questionnaire rounds (N=229 and N=206), with the printed effect size r=−.330 described as "a medium-sized difference". The item's referent differs across sessions, so the authors report it descriptively and do not adjust for it.

> "In the dialogue TTS session 66.0% reported knowing nothing at all about the content, against 34.1% in the single TTS session (𝜒 2(1)=43.05,𝑝 < .001;𝑈=31369,𝑝 < .001,𝑟=−.330, a medium-sized difference)."
