Arun-Balajiee Lekshmi-Narayanan, Mohammad Hassany, Peter Brusilovsky. (2026). Exploring the Effectiveness of Using LLMs for Automated Assessment of Student Self–Explanations in Programming Education. https://arxiv.org/abs/2605.21614 doi:10.48550/arxiv.2605.21614

q2 · i? · design · r2

Comparison experiment on the balanced SelfCode2.0 subset using 5-fold cross-validation, with LLMs run zero-shot and semantic similarity thresholds tuned on training folds. Table 1 reports LLM Behavior at "F1 = 0.98, Accuracy = 0.96" versus Deep Tutor, RoBERTa and GPT-SE (best F1 = 0.72, accuracy = 0.65).

"the LLM Behavior (F1 = 0.98, Accuracy = 0.96) outperforms Deep Tutor (F1 = 0.69, Accuracy = 0.6) and RoBERTa (F1 = 0.7, Accuracy = 0.61)"

Related Claims¶

  • LLM-based assessment can replace similarity-based methods because it needs no ground-truth response and no correctness threshold — related
  • A construction-focused correctness rubric underperformed behavior-focused and undefined prompts for LLM scoring of code explanations — related
  • Frontier LLMs achieve the best balance between detecting misconceptions in correct-answer cases and not over-flagging correct students, while fine-tuned local models achieve under 58% TM recall — related
  • LLM-based scoring produced fewer false negatives than Deep Tutor on a balanced test set, which the authors expect would spare students the frustration of correct explanations judged incorrect — related
