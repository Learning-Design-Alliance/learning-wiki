# Earlier studies reported that quicker recall accompanied better memory results, but with little supporting evidence

> **Claim** · [All claims](index.md)

## Subclaims
`q1 i?` The article reports, citing Bigham, that the longer the interval after learning the longer the recall time, that errors increased with recall time, and that quicker memory discharge gave better results, while noting Bigham presented very little evidence; Myers' incidental memory study similarly reported subjects using least time remembered the most correct words. ## Evidence

### Myers 1913

Myers, G. C. (1913). Some correlations between learning and recall. Communications and Discussions. https://www.google.com/search?q=%22Some+correlations+between+learning+and+recall%22+Myers

`q1 · i?` · `associational · r1`

The article attributes these conclusions to Bigham's 1894 Memory paper and explicitly states he "presented very little evidence in support of these conclusions"; it also cites Myers' 1913 incidental memory study reporting similar observations without a satisfactory figure-based correlation.

> "Bigham' concluded that the longer the interval after learning the longer the time for recall, that the number of errors increased with the time used for recall and that "the quicker the memory is- discharged the better is the result." He presented very little evidence in support of these conclusions, however."
