## Subclaims

## Evidence

### Tse et al. 2007

Dorothy Tse, Rosamund F. Langston, Masaki Kakeyama, Ingrid Bethus, Patrick A. Spooner, Emma R. Wood, Menno P. Witter, Richard G. M. Morris. (2007). Schemas and Memory Consolidation. Science. https://doi.org/10.1126/science.1135935

`q3 · i?` · `causal · r2`

After experiment 2, the same animals were trained on a new set of PAs first in the same arena and then in a novel arena with new landmarks, flavors, and spatial geometry. Gradual acquisition with effective probe performance only by session 67 argues against a response-based learning set, which would predict fast learning in a new context.

> "The now experienced sham group (n = 8) learned a new set of six PAs in the second event arena at a comparable rate to that shown by normal animals in the first event arena (Group × Session F = 1.97, df = 6.9/116.9, 0.10 > P > 0.05"
