Descriptive analysis of LSCI pre/post gain scores for the 454-student participant group across three semesters. The printed gains place these classes in the top 10% of courses nationally, per the authors' comparison to a national study; no standardized effect size is printed.

> "we averaged these scores and found the average normalized gain is <g>=0.46 for the spring 2010 sample, <g>=0.48 for the spring 2011 sample, and <g>=0.47 for the spring 2012 sample. These values are higher than what is achieved by the vast majority of Astro 101 classes for these topics"
