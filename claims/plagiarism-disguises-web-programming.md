## Evidence

### Oscar Karnalim 2023

Oscar Karnalim, Hapnes Toba, Meliana Christianti Johan, Erico Darmawan Handoyo, Yehezkiel David Setiawan, Josephine Alvina Luwia. (2023). Plagiarism and AI Assistance Misuse in Web Programming: Unfair Benefits and Characteristics. [doi:10.1109/tale56641.2023.10398397](https://doi.org/10.1109/tale56641.2023.10398397)

`q2 · i?` · `causal · r1`

Qualitative summary of participants' disguise reports from the plagiarism session identified "16 modifications", with "color change (9) and identifier renaming (9)" the most common.

> "Based on participants’ reports, Table I identified 16 modifications they used to disguise their plagiarized code. The most common disguises were about color change (9) and identifier renaming (9)."

### Oscar Karnalim 2023 (2)

Oscar Karnalim, Hapnes Toba, Meliana Christianti Johan, Erico Darmawan Handoyo, Yehezkiel David Setiawan, Josephine Alvina Luwia. (2023). Plagiarism and AI Assistance Misuse in Web Programming: Unfair Benefits and Characteristics. [doi:10.1109/tale56641.2023.10398397](https://doi.org/10.1109/tale56641.2023.10398397)

`q2 · i?` · `causal · r1`

Comparison of first-session originals with third-session plagiarized submissions showed plagiarized work "typically shared the same program semantic with the original ones", disguised via color, identifier, HTML text, constant, and position changes.

> "Plagiarized submissions typically shared the same program semantic with the original ones. However, they might be disguised with some changes in color, identifier names, HTML text, constants, and HTML position."
