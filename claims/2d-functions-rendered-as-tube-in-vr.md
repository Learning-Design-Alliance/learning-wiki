# Two-dimensional functions are rendered as a tube (with depth fixed at 0.05f) so students can observe them while moving around

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · design `r1` · `q1`

## Subclaims
`q1 i?` For two-dimensional functions like the sine function, a single for cycle with a depth fixed at 0.05f represents the function as a tube, which the authors say allows better observation when moving around it. [→ Marco Simonetti 2020](#marco-simonetti-2020)

## Evidence

### Marco Simonetti 2020

Marco Simonetti, Damiano Perri, Natale Amato, Osvaldo Gervasi. (2020). Teaching Math with the help of Virtual Reality. [doi:10.1007/978-3-030-58820-5_57](https://doi.org/10.1007/978-3-030-58820-5_57)

`q1 · i?` · `design · r1`

Definitional/design statement about the rendering technique in the Unity3D implementation section: 2D periodic functions are given a small depth ("a depth ﬁxed at 0.05f") so the curve becomes a tube viewable from all sides. No user evaluation is reported for this choice.

> "In that case only one ”for cycle” was suﬃcient and a depth ﬁxed at 0.05f. In this way we can represent a two-dimensional function as if it were a tube, which allows us to observe it better when we move around it"
