## Evidence

### Yiasemidou M 2017

Yiasemidou M, Glassman D, Mushtaq F, Athanasiou C, Williams M-M, Jayne D, Miskovic D. (2017). Mental practice with interactive 3D visual aids enhances surgical performance. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5459-3

`q2 · i?` · `causal · r1`

Instrumental Tip Path Length (PL) from the same simulator study; the control condition "led to longer distances covered" than both intervention groups. This is the only performance metric on which MP-only alone significantly beat the control.

> "For PL, a significant main effect was found (F(2,17) = 7.57, p = .004 η p ² = 0.47) and we observed that the control condition (M = 2837, SD = 633) led to longer distances covered in comparison to the 3D & MP condition (M = 1540, SD = 957, p = .008) and the MP-only condition (M = 1800, SD = 370; p = .038)"
