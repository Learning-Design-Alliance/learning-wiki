Evidence¶

Akram 2017¶

Akram, B., Mott, B., Min, W., Boyer, K. E., Wiebe, E., & Lester, J. (2017). Improving Stealth Assessment in Game-based Learning with LSTM-based Analytics. https://scholar.google.com/scholar?q=Improving+Stealth+Assessment+in+Game-based+Learning+with+LSTM-based+Analytics

q2 · i? · design · r2

Comparison of two LSTM versions on the same train/test split of 168 students' data: full feature set (pre-test plus strategy cluster sequences) versus pre-test-only feature set. The full-set model reached "an accuracy of 64.82%" against 44.66% for pre-test only (Table 3).

"Compared to the 44.66% accuracy achieved by the partial feature set version (pre-test features only), the model that u ses in-game strategy features in addition to pre -test features achieves an accuracy of 64.82%."
