# Dual coding elucidation raises adolescent EFL learners' awareness of lexical errors and correct usage more than verbal-only elucidation

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3` · `i2` medium

## Subclaims
`q3 i2` Students studying incorrect and correct usage with verbal-plus-visual code corrected significantly more lexical errors than students studying verbal code only, with a moderate-to-large effect size. [→ Lee 2017](#lee-2017)

## Evidence

### Lee 2017

Lee, Sunjung. (2017). Raising EFL learners' awareness of L2 lexical errors and correct usage: A dual coding approach. English Teaching, 72(2), 29-50. https://doi.org/10.15858/engtea.72.2.201706.29

`q3 · i2` · `causal · r2`

Quasi-experiment with six intact ninth-grade classes (pictorial n = 67, verbal n = 68) studying 25 confusing lexical pairs; repeated-measures analysis with L2 proficiency as covariate showed the pictorial group corrected more errors, "F (1,132) = 14.66, p < .001, η p 2 = . 10". Immediate means: 16.28 vs 12.90 of 25.

> "significant main effect of pictorial elucidation with a moderate to large effect size, F (1,132) = 14.66, p < .001, η p 2 = . 10, demonstrating that students in the pictoria l group corrected significantly more errors than those in the verbal group."
