## Evidence

### Spitzer Markus Wolfgang Hermann 2023

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Logistic mixed-model analysis of the stars outcome (100% accuracy) for the first closure. The assignment main effect favoured single problem sets, but the closure-by-assignment interaction was not significant, so the closure-specific benefit did not appear for stars.

> "The main effect of assignment was significant (b = .15; z = 5.94; p < .001), with more stars gained on single problem set assignments compared to book assignments. The main effect of computed problem sets was not significant (b < .001; z = 0.91; p = .364). The interaction of time window and assignment was not significant (b = .03; z = 1.12; p = .264)."

### Spitzer Markus Wolfgang Hermann 2023 (2)

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Replication for the second closure. The interaction was significant here, and the main effect of time window showed fewer stars during closure (b = -.15; z = -3.81; p < .001).

> "The interaction of time window and assignment was significant (b = .15; z = 5.78; p < .001), indicating that the difference between stars gained during the two time windows was more expressed for single problem set assignments as compared to book assignments."
