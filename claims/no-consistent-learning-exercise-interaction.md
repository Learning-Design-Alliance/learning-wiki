## Evidence

### Loprinzi Paul D. 2019

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i?` · `causal · r2`

Experiment 1's mixed-measures ANOVA showed no significant learning by exercise interaction (p = 0.68); equivalence was not tested.

> "or learning by exercise interaction, F(1, 76) = 0.16, p = 0.68, ƞ2 = 0.002, but there was a significant main effect for learning"

### Loprinzi Paul D. 2019 (2)

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i?` · `causal · r2`

Experiment 2's between-subject effects showed neither an exercise main effect (p = 0.48) nor a learning by exercise interaction (p = 0.42); equivalence was not tested.

> "there was no main effect for exercise, F(1, 73) = 0.48, p = 0.48, ƞ2 = 0.007, or the learning by exercise interaction, F(1, 73) = 0.64, p = 0.42, ƞ2 = 0.007"

### Loprinzi Paul D. 2019 (3)

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i?` · `causal · r2`

Experiment 3's ANOVA also showed no significant learning by exercise interaction (p = 0.17); the authors note the hypothesized additive effect was not observed, possibly due to a ceiling effect.

> "For the between-subject effects, there was no learning by exercise interaction, F(2, 152) = 1.92, p = 0.17, ƞ2 = 0.005"
