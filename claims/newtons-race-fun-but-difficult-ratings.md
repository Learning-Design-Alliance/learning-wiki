# Players found Newton's Race fun but difficult, with both ratings significantly above neutral

## Subclaims
`q3 i?` On Likert scales from -2 to 2, players rated the game as difficult (M = -.45) and fun (M = .87), both significantly different from neutral. [→ Anne van der Linden 2022](#anne-van-der-linden-2022)

## Evidence

### Anne van der Linden 2022

Anne van der Linden, Ralph F. G. Meulenbroeks and Wouter R. van Joolingen. (2022). Learning Newtonian mechanics with an intrinsically integrated educational game. Originally published 2020. [doi:10.48550/arXiv.2206.11627](https://doi.org/10.48550/arXiv.2206.11627)

`q3 · i?` · `design · r2`

Likert-scale game-experience questions (range -2 to 2) in the posttest of the 223-participant study. Players found the game difficult (M = -.45, SD = .994) and fun (M = .87); no effect sizes were printed, so magnitudes are null.

> "In general, players found the game difficult (M = -.45, SD = .994); t(222) = -6.806, p < .000 and fun (M = .87, SD = 1.068); t(222) = 12.164, p < .000."
