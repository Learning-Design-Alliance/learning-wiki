# The valence model and the force model each predict a student's current level of study effort

## Subclaims
`q3 i?` The valence model was positively associated with students' current study effort in a within-person multilevel analysis. [→ Permzadian 2024](#permzadian-2024)
`q3 i?` The force model was positively associated with students' current study effort in the same analysis. [→ Permzadian 2024 (2)](#permzadian-2024-2)

## Evidence

### Permzadian 2024

Permzadian, V., & Shen, T. (2024). Assessing the predictive validity of expectancy theory for academic performance. BMC Psychology, 12. https://doi.org/10.1186/s40359-024-01935-y

`q3 · i?` · `associational · r1`

Multilevel modeling of effort (Level 1: four courses) nested within 123 undergraduates who took the initial survey early in the term. The valence model was "positively associated with effort" with γ20 = 0.028, p < .001, pseudo R2 = .028; no standardised effect size printed.

> "In support of this hypothesis, the valence model (γ20 = 0.028, p < .001, pseudo R2 = .028) was positively associated with effort (see Table 3, Model 3a)."

### Permzadian 2024 (2)

Permzadian, V., & Shen, T. (2024). Assessing the predictive validity of expectancy theory for academic performance. BMC Psychology, 12. https://doi.org/10.1186/s40359-024-01935-y

`q3 · i?` · `associational · r2`

Same within-person MLM analysis (L1 N = 492 observations, L2 = 123). The force model showed a positive fixed effect on study effort, γ20 = 0.039, p < .001, pseudo R2 = .063; no standardised effect size reported.

> "This hypothesis was also supported as the force model (γ20 = 0.039, p < .001, pseudo R2 = .063) was positively associated with effort (see Table 3, Model 3b)."
