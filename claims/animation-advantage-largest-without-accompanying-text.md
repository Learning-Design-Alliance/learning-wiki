# The animation advantage is largest when instruction includes no accompanying text

> **Claim** · [All claims](index.md)

## Subclaims
`q4 i3` Moderator analysis indicates a substantial effect size for animation over static graphics when the instruction did not include any accompanying text (g = 0.883). [→ BERNEY 2016](#berney-2016)

## Evidence

### BERNEY 2016

BERNEY, Sandra, BETRANCOURT, Mireille. (2016). Does animation enhance learning? A meta-analysis. Computers and education. https://doi.org/10.1016/j.compedu.2016.06.005

`q4 · i3` · `quant-synthesis · r2`

Moderator analysis within the random-effects meta-analysis of animated vs. static graphic comparisons. The review reports a substantial effect "when the nstruction did not include any accompanying text (g = 0.883)" — the largest moderator effect reported.

> "Additional moderator analyses indicated substantial effect sizes when the animation was system-paced (g = 0.309), when it was coupled with auditory commentary (g = 0.336) or when the nstruction did not include any accompanying text (g = 0.883)."
