## Evidence

### Tom Murray 2015

Tom Murray. (2015). Coordinating the Complexity of Tools, Tasks, and Users: On Theory-based Approaches to Authoring Tool Usability. Int J Artif Intell Educ 26:37–71. https://doi.org/10.1007/s40593-015-0076-6

`q1 · i?` · `theoretical · r2`

Analytical discussion of runnable artifacts and dynamic complexity in authoring tools. The article argues ITSs are dynamic systems that must be run to test, with unpredictable behaviors, so creators of tools allowing this task complexity must not overestimate user skill and must "provide real debugging and tracing tools" for the systems to be viable.

> "If an authoring tool allows branches, if/then rules, procedures, loops, parameterized subroutines, or recursion (in rough order of difficulty) the level of authoring complexity jumps dramatically"
