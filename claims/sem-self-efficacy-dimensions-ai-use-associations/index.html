Structural equation model estimated by maximum likelihood with 1,000 bootstrap resamples (N = 102); 95% bias-corrected CIs remained above zero for all three dimensions. The quote fragment "β = .47, p < .001" grounds the Excellence path; fit indices were RMSEA = .065, CFI = .94, TLI = .92, SRMR = .067.

"Excellence showed the strongest association (β = .47, p < .001), followed by Communication (β = .31, p < .01) and Attention (β = .22, p < .05)."
