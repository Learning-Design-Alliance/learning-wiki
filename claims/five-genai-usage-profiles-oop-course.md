# Cluster analysis of self-reported GenAI use identifies five profiles, including a strategic high-usage profile low on code generation but high on debugging and explanations

## Subclaims
`q2 i?` K-means clustering yielded Zero, Low, Moderate, "Smart" high, and Very high usage clusters, with the "Smart" high cluster distinguished by low code generation but high debugging and explanation use. [→ Marina Lepp 2026](#marina-lepp-2026)

## Evidence

### Marina Lepp 2026

Marina Lepp. (2026). Patterns of Learner–AI Interaction and Academic Performance in an Object-Oriented Programming Course. IEEE Frontiers in Education (FIE) 2026 Conference. https://arxiv.org/abs/2607.24755

`q2 · i?` · `associational · r1`

K-means clustering on standardized usage indicators for non-zero users, with zero-usage students assigned a separate cluster; the four-plus-zero-cluster solution had silhouette 0.311 and inertia 193.91. The "Smart" high usage cluster showed "relatively low code generation (M = 1.19)".

> "The “Smart” high usage cluster was distinguished by relatively low code generation (M = 1.19) but high use of debugging (M = 3.66) and explanations (M = 4.00), suggesting a strategic and reflective use of the AI assistants."

### Marina Lepp 2026 (2)

Marina Lepp. (2026). Patterns of Learner–AI Interaction and Academic Performance in an Object-Oriented Programming Course. IEEE Frontiers in Education (FIE) 2026 Conference. https://arxiv.org/abs/2607.24755

`q2 · i?` · `associational · r1`

Kruskal–Wallis tests confirmed the clusters differed on each clustering variable, with the printed statistics H(4) = 159.01, 157.42, and 154.90, all p < 0.001.

> "Significant differences were found across all three dimensions: code generation, H(4) = 159.01, p < 0.001; debugging, H(4) = 157.42, p < 0.001; and explanations, H(4) = 154.90, p < 0.001."
