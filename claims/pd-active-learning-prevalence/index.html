Darling-Hammond 2017¶

Darling-Hammond, L., Hyler, M. E., Gardner, M. (2017). Effective Teacher Professional Development. Palo Alto, CA: Learning Policy Institute. https://learningpolicyinstitute.org/product/teacher-prof-dev. doi:10.54300/122.311

Coding result across the report's 35 reviewed studies. Active learning is described as engaging teachers directly in designing and trying out teaching strategies, using "authentic artifacts, interactive activities" rather than lecture-based formats.

"Overall, 34 of the 35 studies incorporated some element of active learning in the design of the PD, while one study did not provide enough description of the PD model to ascertain whether active learning was present."
