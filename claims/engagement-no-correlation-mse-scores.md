## Subclaims
`q3 i?` There was no relationship between self-reported time on modules and test performance across groups (r = −0.004, p = 0.9, N = 135), nor between number of authentic videos watched and MSE scores in the Full group (r = −0.077, p = 0.6, N = 49). [→ Mikkelsen N 2025](#mikkelsen-n-2025)

## Evidence

### Mikkelsen N 2025

Mikkelsen N, Larsen EB, Arnfred SM. (2025). Authentic Versus Simulated Patient Videos: Effect on Mental Status Examination—An Educational Randomized Controlled Trial. Academic Psychiatry 49(3):222–230. https://doi.org/10.1007/s40596-024-02111-5

`q3 · i?` · `causal · r2`

Pearson correlation analyses within the cluster-RCT using self-reported time on modules, digital tracking data, and self-reported videos watched. The quoted sentence reports the near-zero correlations; the Full-group video-count correlation (r = −0.077, p = 0.6, N = 49) is reported in the adjacent sentence.

> "There was no relationship between the time spent on the modules and test performance, neither within nor across groups (total sample r − 0.004, p = 0.9, N = 135), nor was there any association with interest in psychiatry (total sample r − 0.064, p = 0.4, N = 190)"
