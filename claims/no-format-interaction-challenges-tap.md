# No interaction between practice and final test question format: matching formats does not enhance the retrieval effect, challenging transfer-appropriate processing

## Subclaims
`q3 i?` There was no interaction effect between question format on practice test and final test (F(1, 44) = 0.16, p = 0.69, η2 < 0.01), so matching question formats across practice and final test did not improve retention. [→ van Wijk EV 2024](#van-wijk-ev-2024)

## Evidence

### van Wijk EV 2024

van Wijk EV, de Jonge M, van Blankenstein FM, Janse RJ, Langers AMJ. (2024). The battle of question formats: a comparative study of retrieval practice using very short answer questions and multiple choice questions. BMC Medical Education, 24:1547. https://doi.org/10.1186/s12909-024-06538-0

`q3 · i?` · `causal · r2`

The within-subjects ANOVA in the real-life SELF course (n = 45) tested transfer-appropriate processing by including congruent and incongruent question-format pairings. It found "no interaction effect between question format on practice test and final test" (η2 < 0.01).

> "There was no interaction effect between question format on practice test and final test (F(1, 44) = 0.16, p = 0.69, η2 < 0.01)."
