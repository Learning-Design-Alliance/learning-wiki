## Subclaims
`q3 i1` In Experiment 3, participants who exercised showed significantly greater memory performance than those who did not (ƞ2 = 0.01). [→ Loprinzi Paul D. 2019](#loprinzi-paul-d-2019)

## Evidence

### Loprinzi Paul D. 2019

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i1` · `causal · r2`

Experiment 3's four-arm randomized trial found a significant exercise main effect (F = 5.03, p = 0.02) with a small printed effect size, eta-squared ƞ2 = 0.01, after a 15-min bout at about 64% of estimated heart rate max prior to encoding.

> "Similarly, post-hoc tests were computed for the exercise factor, which demonstrated a significantly greater memory performance for those who received the exercise manipulation when compared to those not receiving the acute exercise manipulation (Mdiff = 1.92, SE = 0.85, t = 2.24, p = 0.02)."
