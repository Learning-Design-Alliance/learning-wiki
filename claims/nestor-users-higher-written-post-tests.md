## Evidence

### Back David A 2014

Back David A, Haberstroh Nicole, Antolic Andrea, Sostmann Kai, Schmidmaier Gerhard, Hoff Eike. (2014). Blended learning approach improves teaching in a problem-based learning environment in orthopedics - a pilot study. BMC Medical Education. https://doi.org/10.1186/1472-6920-14-17

`q2 · i?` · `associational · r1`

Between-group comparison in the pilot study's written test analysis (44 tested students; self-declared users vs non-users); users scored better on both post-tests. Self-selection into use prevents attributing the effect exclusively to NESTOR.

> "NESTOR users scored better in the written post-tests than non-users and showed further improvement between post-test 1 and 2."

### Back David A 2014 (2)

Back David A, Haberstroh Nicole, Antolic Andrea, Sostmann Kai, Schmidmaier Gerhard, Hoff Eike. (2014). Blended learning approach improves teaching in a problem-based learning environment in orthopedics - a pilot study. BMC Medical Education. https://doi.org/10.1186/1472-6920-14-17

`q2 · i?` · `associational · r1`

Within-group change analysis from post-test 1 to the end-of-semester post-test 2: users improved significantly (p = 0.009), non-users did not. No effect size printed, so magnitude is unreported.

> "Students who used NESTOR further improved their results significantly between post-test 1 and 2 (p = 0.009), whereas non-users did not."
