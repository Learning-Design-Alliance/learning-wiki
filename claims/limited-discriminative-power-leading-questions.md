### Qu Yufei 2026

A Large Language Model–Powered Multiagent Framework Emulating Standardized Patients in Clinical Communication Skills Training: Development and Evaluation Study. `q2 · i?` · `design · r2`

An exploratory analysis used a low-quality inquiry test set with 5 prevalent error types including vague inquiries and terminology stacking. The framework "demonstrated a tendency toward overreaction" when addressing leading questions. Regarding lack of humanistic care, scores remained consistently high across different methods without significant differences.

> "performance was notably inferior when addressing leading questions, in which the model demonstrated a tendency toward overreaction"
