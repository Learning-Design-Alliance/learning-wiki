`q2 · i?` · `associational · r2`

Chi square goodness of fit tests compared the number of grantees with each topical goal against the number receiving TA on that topic, using TARS entries for all 102 grantees. The tests identified seven topics with significant under-provision; only test statistics are printed.

> "Results of the chi square analyses indicate that grantees received significantly less TA than expected on the following topics: trauma-informed services/systems (χ2 = 55.87, p < 0.001), evidence-based practices (χ2 = 172.79, p < 0.001), communications (χ2 = 18.96, p < 0.001), cultural competence (χ2 = 16.50, p < 0.001), workforce development (χ2 = 65.94, p < 0.001), service array and access (χ2 = 7.62, p = 0.006), and system of care infrastructure and governance (χ2 = 101.00, p < 0.001)."
