# Children trained with the GPT-3-driven open-cue agent generated a significantly higher percentage of divergent questions than children with either incentive agent

## Subclaims
`q3 i?` The open GPT-3 agent group outperformed both the hand-crafted incentive agent (t=-3.17, p=0.003) and the GPT-3-driven incentive agent (t=-1.88, p=0.04) on percentage of divergent questions generated. [→ Abdelghani 2023](#abdelghani-2023)

## Evidence

### Abdelghani 2023

Abdelghani, R., Wang, Y.-H., Yuan, X., Wang, T., Lucas, P., Sauzéon, H., & Oudeyer, P.-Y. (2023). GPT-3-driven pedagogical agents for training children's curious question-asking skills. International Journal of Artificial Intelligence in Education. https://hal.science/hal-03890447v1

`q3 · i?` · `causal · r2`

Controlled experiment with 75 fourth-grade students assigned to three agent conditions; one-way ANOVA showed a significant difference (F(2,72)=4.11, p-value=0.02), with pairwise t-tests showing the "automated open agent had a significantly better performance" than both incentive agents.

> "the group that interacted with the automated open agent had a significantly better performance that the Hand-crafted incentive agent (t=-3.17, p-value=0.003 and power=0.82) and the GPT-3-driven incentive agent (t=-1.88, p=0.04 and power=0.45)"
