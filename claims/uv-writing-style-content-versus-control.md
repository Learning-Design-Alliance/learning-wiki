# UV writing assignments showed more personal focus, more social and cognitive process content, and higher articulated utility value than control summary assignments

> **Claim** · [All claims](index.md)

## Subclaims
`q3 i?` Compared with control summaries, UV assignments used more first- and second-person pronouns (β = 0.56, p < .001), more social processes content (β = 0.37, p < .001), more cognitive processes content (β = 0.28, p < .001), and higher articulated utility value (β = 0.66, p < .001). ## Evidence

### Priniski 2019

Exploratory content analyses in the RCT used LIWC dictionaries and hand-coded articulated utility value (interrater κ = 0.88). All four contrasts favoring UV writing were significant as quoted. Choice did not significantly influence writing style or content (βs < 0.06).
