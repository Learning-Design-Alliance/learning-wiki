Evidence¶

Sophia C. Weissgerber 2024¶

Sophia C. Weissgerber, Denia Indah Permatasari Terhorst, Ralf Rummer. (2024). Is the perceptual disfluency effect moderated by working memory capacity? Direct replication of Lehmann et al. (2016). Metacognition and Learning. https://doi.org/10.1007/s11409-023-09366-7

q3 · i? · causal · r2

Pre-registered supervised online replication experiment (final N = 96; fluent n = 47, disfluent n = 49) using the same materials, WMC measure, and analytical approach as Lehmann et al. (2016). The regression model was significant overall (F(9, 84) = 2.76, p = 0.007, R2 adj. = 0.15), but "the interaction between disfluency manipulation * WMC, (β = 4.19, SE = 4.92, t(84) = 0.85, p = 0.397), were not predictors of retention". Based on the significance-and-direction criterion, this does not replicate the primary study's interaction (β = 11.66, p = 0.02).

"Disfluency manipulation (β = 0.82, SE = 4.77, t(84) = 0.17, p = 0.864), WMC (both in fluent (β = -0.07, SE = 3.94, t(84) = -0.17, p = 0.865; disfluent β = 3.52, SE = 3.04, t(84) = 1.16, p = 0.25 condition), and the interaction between disfluency manipulation * WMC, (β = 4.19, SE = 4.92, t(84) = 0.85, p = 0.397), were not predictors of retention"
