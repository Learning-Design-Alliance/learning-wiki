Error analysis of the exam's image-based questions, presented as a single screenshot. These were the only questions receiving zero points; chatbots sometimes described image elements in reversed positions or could not select the correct resulting image.

> "All evaluated GenAI systems achieved noticeably lower scores on graphics -related questions that required interpreting JavaFX output. While current systems are capable of processing images, they freque ntly misinterpret graphical objects or fail to correctly associate source code with the corresponding visual output."
