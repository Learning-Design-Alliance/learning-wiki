`q2 · i?` · `associational · r1`

Comparative analysis of logged platform usage: the non-pandemic cohort (68 users, 70 days) performed 0.16 reads per user a day versus 0.28 in the pandemic cohort (201 users, 28 days). The Mann–Whitney test showed significance only for reads per user per day, "p = 0.0059".

> "To conclude, reads and downloads per user and day approximately doubled during the pandemic study period with a significant difference for the reads per user and day (p = 0.0059; Mann–Whitney test, see Figure 2B)."
