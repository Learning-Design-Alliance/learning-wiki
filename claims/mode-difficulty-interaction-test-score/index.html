James Pengelley · Peter R. Whipp · Nina Rovis-Hermann 2023¶

James Pengelley · Peter R. Whipp · Nina Rovis-Hermann. (2023). A Testing Load: Investigating Test Mode Effects on Test Score, Cognitive Load and Scratch Paper Use with Secondary School Students. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09781-x

q3 · i? · causal · r2

Hierarchical linear modelling of test scores in the repeated-measures study found "a significant main effect for mode (F(1,767.18) = 4.07, p = 0.044)" and for difficulty, plus the significant mode*difficulty interaction reported in the quote.

"there was a significant main effect for mode (F(1,767.18) = 4.07, p = 0.044); difficulty (F(1,7.82) = 570.92, p < 0.001); and also for the mode*difficulty interaction (F(1,759.66) = 63.14, p < 0.001)"
