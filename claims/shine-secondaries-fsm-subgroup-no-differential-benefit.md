Pre-specified subgroup analysis repeating the primary RDD analysis for FSM eligibility, including an FSM-by-group interaction for each school. The report states it "showed no evidence of the intervention differentially benefiting pupils eligible for free school meals"; no effect size is printed, so the null is not an equivalence finding.
