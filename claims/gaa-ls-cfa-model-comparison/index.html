q3 · i? · design · r3

Study 2 confirmatory factor analysis with 798 students using robust maximum likelihood in Mplus 8.3. Model comparison showed the "three-factor collapsed model and the one-factor model fitted the data substantially less well"; the one-factor model reached CFI = .738.

"The hypothesized five-factor correlated model showed good fit to the data, χ2(125) = 344.72, χ2/df = 2.76, CFI = .954, TLI = .944, RMSEA = .047, and SRMR = .042."
