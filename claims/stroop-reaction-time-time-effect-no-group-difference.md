`q3 · i?` · `causal · r1`

GEE analysis of computerized Stroop Color word test reaction times pre/post in the cluster-controlled trial (intervention n = 22, control n = 27); only time effects were significant. No effect sizes printed.

> "We observed a time effect in the reaction time for the congruent (p < 0.001), neutral (p = 0.011), and incongruent (p = 0.008) phases, where both groups reduced, with no difference between them."
