Evidence¶

Kroesbergen 2023¶

Kroesbergen, E. H.; Huijsmans, M. D. E.; Friso-van den Bos, I. (2023). A Meta-Analysis on the Differences in Mathematical and Cognitive Skills Between Individuals With and Without Mathematical Learning Disabilities. Review of Educational Research. https://doi.org/10.3102/00346543221132773

q3 · i? · quant-synthesis · r?

Moderator analysis of working-memory task type within the meta-analysis. The article also reports that "processing-speed measures yielded larger effect sizes than all other working memory measures (ps < .05) except visuospatial updating tasks."

"Specifically, inhibition tasks yielded smaller effect sizes than both verbal updating tasks, p = .041, and visuospatial updating tasks, p = .015."

Kroesbergen 2023 (2)¶

Kroesbergen, E. H.; Huijsmans, M. D. E.; Friso-van den Bos, I. (2023). A Meta-Analysis on the Differences in Mathematical and Cognitive Skills Between Individuals With and Without Mathematical Learning Disabilities. Review of Educational Research. https://doi.org/10.3102/00346543221132773

q3 · i? · quant-synthesis · r2

Null moderator result within the meta-analysis: numerical content of working-memory tasks did not explain variance (p = .839), nor did digit naming in RAN tasks (p = .484). The authors interpret this as no evidence for difficulty with processing numbers per se.

"The predictor indicating whether the working memory task included the use of any numerical information did not relate to the effect sizes, p = .839."
