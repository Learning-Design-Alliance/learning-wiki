# In unit 5 of the online anatomy course, the question-constructing, jigsaw, and control groups outperformed the team-learning module group, and jigsaw and control outperformed the concept-mapping group.

## Evidence

### Bradley LJ 2025

Bradley LJ, Meyer KE, Kerr MS, Maddux SD, Heck AJ, Reeves RE, Handler EK. (2025). Do active learning techniques promote higher academic performance in an online graduate anatomy course? Anatomical Sciences Education. https://doi.org/10.1002/ase.70066

`q3 · i1` · `causal · r2`

Kruskal-Wallis analysis of unit 5 examination scores in the online anatomy course showed a significant difference (H = 12.5, p = 0.01); post hoc tests showed "QC, jigsaw, and the control groups outperformed the TLM group" with effect size 0.42, and jigsaw and control outperformed CM with effect size 0.25.

> "However, during unit 5, a statistically significant difference was identified (H  =  12.5, p  =  0.01) with Dunn's post hoc test revealing that QC, jigsaw, and the control groups outperformed the TLM group (p  =  0.05, effect size  =  0.42). Additionally, jigsaw and control groups outperformed the CM group (p  =  0.05, effect size  =  0.25)."
