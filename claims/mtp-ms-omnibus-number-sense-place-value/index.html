Omnibus test from the same two-level HLM analysis of 444 children in 42 classrooms, measured with the Number Sense and Place Value Assessment in spring. The article reports a "signiﬁcant omnibus effect of treatment" with Wald Z = 6.88, p = .03; no effect size is printed for this test.
