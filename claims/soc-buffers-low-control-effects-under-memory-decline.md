Adjusted multilevel model (n = 103) testing the SOC * Control * Memory decline three-way interaction, significant in unadjusted and adjusted models (Est. = -0.28, p = .036). Johnson-Neyman regions of significance for SOC were between mean-centered values of -1.57 and 0.59.

> "Low perceived control reported in a weekly diary was associated with more everyday memory problems among those with greater memory decline and low SOC strategy use (Est.=−0.28, SE=0.13, p=.036)."
