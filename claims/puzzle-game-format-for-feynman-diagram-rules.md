# The authors argue that a puzzle-game format is well suited to learning Feynman diagram rules because learning to draw diagrams is rule application and problem solving, the format in which players readily learn complicated rules through play

## Subclaims
`q1 i?` Learning to draw Feynman diagrams is framed as learning a rule set and applying it to solve puzzles, so a computer game may let users quickly and enjoyably learn the rules through play. [→ Gaunt 2025](#gaunt-2025)

## Evidence

### Gaunt 2025

Gaunt, J. R. and Owen, A. (2025). FeynCraft: A Game of Feynman Diagrams. [doi:10.48550/arXiv.2510.14082](https://doi.org/10.48550/arXiv.2510.14082)

`q1 · i?` · `design · r1`

Theoretical argument in the introduction, citing bestselling puzzle games (Braid, The Talos Principle, Baba is You, Portal) whose complicated rules players enjoy engaging with; the authors state "one may hope to tap into the same mechanisms where users quickly and enjoyably learn the rules through play". No empirical evaluation is reported.

> "The process of learning to draw Feynman diagrams is ultimately one of learning a set of rules and applying them to solve problems (or puzzles), which is the broad structure shared by a wide variety of puzzle games."
