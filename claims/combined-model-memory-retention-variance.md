# A combined model of demographics, aerobic fitness, and the two critical activity windows accounts for over 30% of variance in long-term memory retention

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q3` peer-reviewed experiment

## Subclaims
`q3 i?` The best stepwise model included Sex, Age, Aerobic Fitness, post-encoding sedentary time, and pre-retrieval sedentary time, explaining R2 = 0.32 of retention variance. [→ Pontifex 2016](#pontifex-2016)

## Evidence

### Pontifex 2016

Pontifex, M. B., Gwizdala, K. L., Parks, A. C., Pfeiffer, K. A. & Fenn, K. M. (2016). The Association between Physical Activity During the Day and Long-Term Memory Stability. Scientific Reports 6, 38148. https://doi.org/10.1038/srep38148

`q3 · i?`

Follow-up stepwise hierarchical regression on the 92-participant dataset. The best model combined demographics, fitness, and both critical sedentary windows, yielding "R2 = 0.32, F (5, 86) = 8.1, p < 0.001". R² is variance explained, not an effect size.

> "the best model to predict long-term memory in the present dataset incorporated Sex, Age, Aerobic Fitness, time sedentary 0:56:20 to 1:51:20 following the first session, and time spent sedentary 0:50:40 up to the start of the second session (R2 = 0.32, F (5, 86) = 8.1, p < 0.001)"
