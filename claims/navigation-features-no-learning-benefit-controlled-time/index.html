Evidence¶

Beege 2025¶

Beege, M., & Ploetzner, R. (2025). Learning from interactive video: the influence of self-explanations, navigation, and cognitive load. Instructional Science. https://doi.org/10.1007/s11251-024-09693-5

q3 · i? · causal · r2

In the 2×2 experiment with 128 university students learning about thunderstorms with time capped at 12 minutes, the MANOVA showed "no significant main effect for navigation features"; Bayes factors BF10 = 0.19 supported the null for both outcomes. Equivalence was not established beyond these Bayes factors.

"A MANOV A with retention and comprehension scores as depended variables revealed no significant main effect for navigation features ( Wilk' s Λ = 1.00, F(2, 123) = 0.04, p = .962). Bayes factors indicated support for the null-hypothesis regarding retention ( BF10 = 0.19)"
