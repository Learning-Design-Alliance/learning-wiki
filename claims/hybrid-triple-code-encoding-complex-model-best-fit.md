## Evidence

### Rhodes Katherine T. 2017

Rhodes Katherine T., Branum-Martin Lee, Washington Julie A., Fuchs Lynn S. (2017). Measuring arithmetic: A psychometric approach to understanding formatting effects and domain specificity. Journal of Educational Psychology. https://doi.org/10.1037/edu0000189

`q2 · i?` · `associational · r2`

Post-hoc hybrid model, combining the Triple Code three-factor arithmetic structure with Encoding Complex direct predictors, in the N=1314 confirmatory factor analysis; the article reports it fit better than the Abstract Code (CFI=.87), Encoding Complex (CFI=.96), Triple Code (CFI=.95), and Exact versus Approximate (CFI=.88) full models.

> "Global fit statistics indicated that this factor model was an approximate excellent fit for the data, (χ2 (124) = 327.82, p < .001, RMSEA = .04, CFI = .97)."
