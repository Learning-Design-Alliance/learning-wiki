# Fourth graders with poor arithmetic-fact abilities (PoorAF) and matched controls did not differ on a perceptual shape-matching speed task

## Subclaims
`q3 i?` The two groups did not differ in a perceptual shape-matching task requiring no memory retrieval, so the findings did not support a general speed-of-processing deficit explanation (one non-significant task, not a refutation). [→ Mussolin 2008](#mussolin-2008)

## Evidence

### Mussolin 2008

Mussolin, C. and Noël, M-P. (2008). Specific Retrieval Deficit from Long-Term Memory in Children with Poor Arithmetic Facts Abilities. The Open Psychology Journal. https://doi.org/10.2174/1874350100801010026

`q3 · i?` · `associational · r2`

A second ANCOVA with L3 scores as covariate confirmed a group effect only for the multiplication selection task (F(1, 33) = 11.695, p = .002) and not for the other tasks including the perceptual task. The article states the deficit "was not associated with a global low processing speed".

> "Further analyses by task indicated a group effect for the selection task with multiplication problems ( F(1, 33) = 11.695, p = .002), but not for the other tasks (p > .05)."
