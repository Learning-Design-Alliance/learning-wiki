Evidence¶

Rachel Love 2025¶

Rachel Love, Edith Law, Philip R. Cohen, Dana Kulić. (2025). Teaching a Conversational Agent using Natural Language: Effect on Learning and Engagement. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-025-00461-1

q3 · i? · causal · r2

Repeated measures ANOVA on teaching metrics in the 46-participant within-subjects study. "Participants took signiﬁcantly longer to formulate their response when teaching using natural language" and made significantly fewer attempts, consistent with the need to read and type paraphrased responses.

"Participants took signiﬁcantly longer to formulate their response when teaching using natural language ( F(1, 45) = 63.053, p <. 001), and made signiﬁcantly fewer teaching attempts in total ( F(1, 45) = 105.361, p <. 001; natural lan- guage M = 12.4 (SD = 5.62); sentence-selection M = 19.2 (SD = 6.26))."

Rachel Love 2025 (2)¶

Rachel Love, Edith Law, Philip R. Cohen, Dana Kulić. (2025). Teaching a Conversational Agent using Natural Language: Effect on Learning and Engagement. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-025-00461-1

q3 · i? · causal · r1

Same repeated measures ANOVA on teaching metrics. Fewer features were taught in the natural language condition, attributed by the authors to the fixed interaction length restricting the number of attempts possible.

"Participants also taught signiﬁcantly fewer features when using natural language (F(1, 45) = 14.814, p <. 001; natural language M = 11.0 (SD = 4.10); sentence- selection M = 13.6 (SD = 4.40))."
