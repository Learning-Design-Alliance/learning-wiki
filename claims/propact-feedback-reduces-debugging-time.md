## Evidence

### Anahita Golrang 2026

Anahita Golrang, Kshitij Sharma, Simon Dehaen, Olga Viberg. (2026). ProPACT: A Proactive AI-Driven Adaptive Collaborative Tutor for Pair Programming. https://arxiv.org/abs/2605.02703

`q3 · i?` · `causal · r2`

Same within-subjects experiment (26 dyads); paired t-test on total time spent in seconds showed the feedback condition completed debugging significantly faster than control, per the printed t statistic. No effect size printed.

> "Another t-test with the feedback category as the independent variable and debugging time on task as the dependent variable shows a clear difference in the debugging time on task among the feedback categories (t[44.70] = 4.39, p<.0001, figure 3b). The debugging time on task is significantly lower in the feedback condition than the control condition."
