q3 · i? · quant-synthesis · r?

One-stage MASEM (OSSEM) of pooled correlational matrices from 288 independent samples of native Chinese-speaking children, fitting a theory-driven path model with nonverbal reasoning controlled. The saturated baseline model showed "perfect model fits: CFI = 1, TLI = 0, and RMSEA = 0" with the printed path coefficients above.

"all cognitive-linguistic skills significantly and independently predicted Chinese word reading, controlling for nonverbal reasoning (RAN: β = -.121, OA: β = .134, PA: β = .125, MA: β = .209, vocabulary: β = .185; all ps < .001)"
