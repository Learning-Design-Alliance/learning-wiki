`q3 · i2` · `causal · r2`

Sensitivity analysis for the Empower domain, motivated by a significant baseline difference (p = 0.031) with control starting higher; the restricted subset (Control n = 20; SOPHIE n = 24) showed no detectable baseline differences (p = 0.79).

> "The Results remained consistent with the full sample (Control: ∆ = 0 .08; SOPHIE: ∆ = 0 .16, p = 0.036, Cohen’s d = 0.65), supporting the robustness of the observed intervention effects"
