## Evidence

### Ananya Ipsita 2025

Ananya Ipsita, Ramesh Kaki, Mayank Patel, Asim Unmesh, Kylie A Peppler, and Karthik Ramani. (2025). Interactive authoring of outcome-oriented lesson plans for immersive Virtual Reality training. [doi:10.2139/ssrn.5574179](https://doi.org/10.2139/ssrn.5574179)

`q2 · i?` · `causal · r1`

Timing analysis in the 8-participant comparative study: no significant complexity effect for either system and no significant between-system difference. Descriptively, SystemB dropped from 4.94 seconds (SD = 3.48) in Session 1 to 1.71 seconds (SD = 0.77) in Session 3.

> "Friedman tests revealed no statistically significant effect of task complexity on timing for either system (SystemA:𝜒2 = 4.75, 𝑝 = 0.0930; SystemB:𝜒2 = 5.25, 𝑝 = 0.0724), and the Wilcoxon test showed no significant difference in timing variability between the systems (𝑝 = 0.3828)."
