### Pingjing Yang 2025

Pingjing Yang, Jennifer Cromley, and Jana Diesner. (2025). More Expert-like Eye Gaze Movement Patterns are Related to Better X-ray Reading. [doi:10.1007/978-3-031-98414-3_28](https://doi.org/10.1007/978-3-031-98414-3_28)

`q2 · i?` · `associational · r2`

Same mixed linear model of normalized BFD scores (3,425 observations, 165 participants). Nodes, edges, and average PageRank were "significant positive predictors"; the printed β values are unstandardized coefficients, so no standardized effect size is reported.

> "the number of nodes (β = 0.015, SE = 0.006, z = 2.761, p = 0.006), number of edges (β = 0.002, SE = 0.001, z = 3.398, p = 0.001), and average PageRank (β = 0.701,SE = 0.192,z = 3.651,p < 0.001) were significant positive predictors"
