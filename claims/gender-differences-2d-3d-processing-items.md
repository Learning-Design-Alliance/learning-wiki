## Subclaims
`q2 i?` The authors report no gender differences on items requiring 2D to 2D processing, while significant differences appeared on items requiring 2D-3D movement (Retinal-list Item 10, Map Item 16) and horizontal Connection processing (Item 20). [→ Lowrie 2010](#lowrie-2010)

## Evidence

### Lowrie 2010

Lowrie, Tom and Diezmann, Carmel. (2010). Solving graphics tasks: Gender differences in middle-school students. Learning and Instruction. https://doi.org/10.1016/j.learninstruc.2009.11.005

`q2 · i?` · `associational · r2`

Authors' item-level interpretation (Discussion §4.3) of the GLIM results: the Retinal-list item and one Map item both "required moveme nt between 2D and 3D processing", and the Connection item requiring horizontal linking showed differences, whereas 2D-to-2D items did not. No effect size is printed for this pattern.

> "It is important to note that there were no gende r differences on items that required 2D to 2D processing. There were gender differen ces in one of the Connection language items (Item 20)."
