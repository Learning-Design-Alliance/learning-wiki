# Socratic feedback is associated with higher task orientation and comprehension monitoring than directive feedback, with no effect on feedback regulation

## Evidence

### Han Xue 2026

Han Xue, Cao Jing, Wang Zi, Luo Heng. (2026). The Effects of Agent Type and Feedback Style on Self-Directed Learning: A Mixed-Methods Study. Behavioral Sciences. https://doi.org/10.3390/bs16071069

`q3 · i3` · `causal · r?`

Mixed-design ANOVA of coded self-regulatory behaviors from interaction logs in the 2×2 study (51 postgraduate students). Descriptively, scores for both task orientation and comprehension monitoring were higher under Socratic than directive feedback across both agent types. No significant main effect of agent type was found for these dimensions.

> "feedback style showed significant main effects on task orientation (η2p = 0.226) and comprehension monitoring (η2p = 0.339), indicating moderate to large effects."

### Han Xue 2026 (2)

Han Xue, Cao Jing, Wang Zi, Luo Heng. (2026). The Effects of Agent Type and Feedback Style on Self-Directed Learning: A Mixed-Methods Study. Behavioral Sciences. https://doi.org/10.3390/bs16071069

`q3 · i2` · `causal · r?`

Mixed-design ANOVA on feedback regulation ratings from the same interaction-log coding. No significant main effect of feedback style was observed for feedback regulation, but the agent type × feedback style interaction was significant (η2p = 0.078).

> "However, a significant interaction effect emerged for feedback regulation (η2p = 0.078), indicating that the pattern of feedback regulation varied across the combinations of agent type and feedback style."
