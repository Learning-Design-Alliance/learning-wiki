Abdelghani 2026¶

Abdelghani, R., Kaiser, P., Murayama, K. (2026). Changes in Help-Seeking Strategies Predict unaided Performance during AI-based Mathematical Learning. https://arxiv.org/abs/2606.28472

q2 · i? · associational · r?

Regression analysis with N = 89 students with complete pre/post-tests and computable indicators, predicting unaided post-test performance from pre-test plus four whole-session features (regulatory-turn proportion, understanding-oriented request proportion, chat time, response-review time). The increment was non-significant: "F(4,83) = 0.57,p=.684".
