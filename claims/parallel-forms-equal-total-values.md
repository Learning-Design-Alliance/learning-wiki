# The two test forms were built to pair exercises of closely the same value, equal total values, and similar inter-exercise intervals, with 100 total points per form

## Subclaims
`q1 i?` In arranging exercises into the two standardized forms, exercises of closely the same value were paired across forms, the ten exercises per form were selected to have the same total values and closely the same inter-exercise interval, and unit values were converted so the total possible score is 100 points. Definitional/descriptive statement of the test construction procedure. The article reports that of two easy exercises of closely the same value one went in Form A and the other in Form B, and that unit values were converted to point values so the total possible score on a given form is 100 points.
