# The small SJT difference between SEMED and gateway students disappears after controlling for attainment and aptitude on entry

## Subclaims
`q2 i?` Course type predicts SJT z-scores before controls, but is no longer a significant predictor once A-level and UCAT scores are included. [→ Curtis Sally 2020](#curtis-sally-2020)

## Evidence

### Curtis Sally 2020

Curtis Sally, Smith Daniel. (2020). A comparison of undergraduate outcomes for students from gateway courses and standard entry medicine courses. BMC Medical Education. https://doi.org/10.1186/s12909-019-1918-y

`q2 · i?` · `associational · r3`

Regression analysis of SJT z-scores in the UKMED cohort (N = 3375). Model 1 showed a course-type difference (R2 adj = 0.008) but Model 2 showed "no difference across the two course types or the three schools on SJT z-scores". No effect size is printed for the null finding.

> "However, this is no longer the case when the UCAT and A-level points are included in SJT Model 2 (R2 adj = 0.035. N = 3375, P < 0.001) showing that when controlling for attainment of entry there is no difference across the two course types or the three schools on SJT z-scores."
