## Evidence

### Devine OP 2015

Devine OP, Harborne AC, McManus IC. (2015). Assessment at UK medical schools varies substantially in volume, type and intensity and correlates with postgraduate attainment. BMC Medical Education. https://doi.org/10.1186/s12909-015-0428-9

`q2 · i?` · `associational · r3`

Institutional-level correlations using published UKFPO 2014 school means; the article reports the null correlations for both EPM and SJT against postgraduate attainment and assessment time. Equivalence was not tested.

> "EPM, which it must be remembered is a measure of educational performance within medical schools did not correlate with postgraduate attainment (rS = .224, n = 22, p = .316) or with assessment time (rS = .210, n = 22, p = .349), and neither did SJT relate to postgraduate attainment (rS = .046, n = 22, p = .316) or assessment time (rS = −.225, n = 22, p = .313)."
