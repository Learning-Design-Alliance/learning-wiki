Evidence¶

Daniela Decker 2025¶

Daniela Decker, Martin Merkt. (2025). Look at me! Can a pedagogical agent facilitate orientation and support learning in VR? Education Tech Research Dev. https://doi.org/10.1007/s11423-025-10531-9

q3 · i? · causal · r3

Pre-registered between-subjects laboratory experiment with 91 German-speaking participants randomly assigned to pedagogical agent cue, light cue, or no cue. The search-time ANOVA showed a significant effect of cueing, F(2, 88) = 10.13, p <.001, ηp2 =.19; post-hoc tests showed "faster search times for the pedagogical agent cue" and for the light cue versus no cueing, with no difference between the two cue types (p = 0.272).

"Post-hoc tests with Bonferroni adjustment showed faster search times for the pedagogical agent cue (M = 11.87, SD = 5.05) compared to the condition without cueing (M = 15.94, SD = 6.78), p =.026"
