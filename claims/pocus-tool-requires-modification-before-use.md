### Sheppard Gillian 2023

Sheppard Gillian, Williams Kerry-Lynn, Metcalfe Brian, Clark Marcia, Bromley Mark, Pageau Paul, Woo Michael, Yi Yanqing, Devasahayam Augustine Joshua, Dubrowski Adam. (2023). Using Kane's framework to build an assessment tool for undergraduate medical student's clinical competency with point of care ultrasound. BMC Medical Education. https://doi.org/10.1186/s12909-023-04030-9

`q3 · i?` · `design · r2`

Authors' conclusion from the multi-center reliability study: given fair-to-moderate checklist and slight-to-fair GRS agreement, the tool "must therefore be modified and tested again" before undergraduate POCUS assessment use.

> "Overall, the scores between the raters were not reliable enough to use this scoring system to generalize, extrapolate or make inferences about undergraduate students POCUS skill level. The checklists and the global rating scale must therefore be modified and tested again before using them to assess undergraduate POCUS skills."
