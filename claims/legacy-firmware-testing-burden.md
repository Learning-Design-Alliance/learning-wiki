## Subclaims
`q2 i?` The testing procedure relied on firmware dependent on Altium 2009 and Windows 7, requiring students to locate and install old software and an old operating system, a process the article calls cumbersome and nearly impossible without legacy expertise. `q2 · i?` · `design · r2`

Testing challenge encountered by both teams, especially the high school students, who had to find an old computer with Windows 7 and install the old Altium version. The article states the process "would have been virtually impossible without expertise in legacy products".

> "the testing of the boards not only required the old version of the software to be installed, but also the old version of the operating system with which the software is compatible with, in this case Windows 7."
