## Evidence

### Hans-Alexander Kruse 2024

Hans-Alexander Kruse, Tim Puhlfürß, Walid Maalej. (2024). Can Developers Prompt? A Controlled Experiment for Code Documentation Generation. [doi:10.1109/icsme58944.2024.00058](https://doi.org/10.1109/icsme58944.2024.00058)

`q2 · i?` · `causal · r2`

True/False comprehension questions answered before and after documentation generation in the controlled experiment (Table III). For function 2, correct answers increased in both groups (Q1: 22+18; Q2: 21+21); the article concludes documentation helped inexperienced developers comprehend code while the effect on professionals was mixed.

> "Students had the highest increases: in the ad-hoc prompt group for Q1 from 5 to 13, and in the predefined prompt group for Q2 from 5 to 14."

### Hans-Alexander Kruse 2024 (2)

Hans-Alexander Kruse, Tim Puhlfürß, Walid Maalej. (2024). Can Developers Prompt? A Controlled Experiment for Code Documentation Generation. [doi:10.1109/icsme58944.2024.00058](https://doi.org/10.1109/icsme58944.2024.00058)

`q2 · i?` · `causal · r2`

For function 1 question 2, correct answers slightly decreased after tool use (Q2: 21+20) for both students and professionals. The article reports the generated documentation could lead to confusion, even for professionals.

> "Thinking-aloud observations revealed that many participants were confused by the less technical documentation generated by both tools regarding this question, as it did not include the term iterable."
