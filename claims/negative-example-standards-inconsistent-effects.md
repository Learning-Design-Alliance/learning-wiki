# Negative example standards do not reliably improve judgment accuracy and significantly decrease relative accuracy in evaluating self-generated examples

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · `q3` peer-reviewed experiment · `i1` small

## Subclaims
`q3 i?` Negative example standards showed no statistically significant main effect on bias or absolute accuracy. [→ Linda Froese 2023](#linda-froese-2023)
`q3 i1` Negative example standards significantly decreased rather than increased relative accuracy. [→ Linda Froese 2023 (2)](#linda-froese-2023-2)

## Evidence

### Linda Froese 2023

Linda Froese, Julian Roelle. (2023). Expert example but not negative example standards help learners accurately evaluate the quality of self-generated examples. Metacognition and Learning. https://doi.org/10.1007/s11409-023-09347-w

`q3 · i?`

In the same ANCOVA on absolute accuracy, negative example standards showed no significant main effect, "F(1, 122) = 0.57, p = .450, ηp2 < .01". For bias the main effect was also non-significant (p = .057), though it became significant when the prior-knowledge outlier was retained.

> "By contrast, there was no statistically significant main effect of negative example standards, F(1, 122) = 0.57, p = .450, ηp2 < .01, and also no statistically significant interaction effect, F(1, 122) = 1.57, p = .213, ηp2 = .01."

### Linda Froese 2023 (2)

Linda Froese, Julian Roelle. (2023). Expert example but not negative example standards help learners accurately evaluate the quality of self-generated examples. Metacognition and Learning. https://doi.org/10.1007/s11409-023-09347-w

`q3 · i1`

On relative accuracy, negative example standards had a significant but detrimental effect, "F(1, 114) = 4.45, p = .037, ηp2 = .03"; the authors report the resulting gamma correlation of G = -.02 indicates learners could not discriminate quality levels.

> "We also found a statistically significant main effect of negative example standards, F(1, 114) = 4.45, p = .037, ηp2 = .03. Surprisingly, contrary to Hypothesis 1b, negative example standards decreased rather than increased relative accuracy."
