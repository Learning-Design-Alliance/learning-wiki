# Perceived mental effort has a negative indirect association with learning outcomes, mediated by monitoring judgments (β = -0.05)

## Subclaims
`q3 i0` The indirect effect of perceived mental effort on learning outcomes via monitoring judgments is negative and significant but small (β = -0.05), indicating effort is routed through monitoring as a cue. [→ Louise David 2024](#louise-david-2024)

## Evidence

### Louise David 2024

Louise David, Felicitas Biwer, Martine Baars, Lisette Wijnia, Fred Paas, Anique de Bruin. (2024). The Relation Between Perceived Mental Effort, Monitoring Judgments, and Learning Outcomes: A Meta-Analysis. Educational Psychology Review. https://doi.org/10.1007/s10648-024-09903-z

`q3 · i0` · `quant-synthesis · r?`

MASEM full mediation model (effort → monitoring → outcomes) fit the data well (χ2(1) = 2.57, p = 0.1; RMSEA 0.01; CFI 0.98) and was preferred over the saturated partial mediation model. The indirect path was "a negative parameter estimate was found β = -0.05".

> "In support of Hypothesis 3, representing the indirect effect between mental effort and learning outcomes via monitoring judgments, a negative parameter estimate was found β = -0.05, 95% LBCI [-0.08; -0.03]."
