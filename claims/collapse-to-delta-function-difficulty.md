Yangqiuting Li and Chandralekha Singh. (2025). Improving student understanding of quantum measurement in infinite-dimensional Hilbert space using a research-based multiple-choice question sequence. Originally published 2024. [doi:10.1103/physrevphyseducres.21.010104](https://doi.org/10.1103/physrevphyseducres.21.010104)

`q2 · i?` · `design · r2`

Analysis of incorrect pretest responses to question 4a in the combined two-year data. The most common wrong answer was obtained "by simply replacing the variable x in the initial state" with the measured position, showing difficulty recognizing collapse to a delta function.

> "The most common student response was that the wave function right after the  position measurement is4"&𝛹!(𝑥1)+4’&𝛹"(𝑥1), which is obtained by simply replacing the variable x in the initial state Ψ(𝑥,0) with position 𝑥1. However, this expression is actually the probability amplitude at x =	𝑥1 before the position measurement. This result shows that some students had difficulties in recognizing that a position measurement will instantaneously collapse the wave function to a delta function in position [46]."
