Laura Dörrenbächer-Ulrich 2021¶

Laura Dörrenbächer-Ulrich, Marie Weißenfels, Lea Russer, Franziska Perels. (2021). Multimethod assessment of self-regulated learning in college students: different methods for different components? Instructional Science. https://doi.org/10.1007/s11251-020-09533-2

q2 · i? · associational · r1

Monotrait-heteromethod correlational analysis (Table 7) in 70 college students; the questionnaire–closed-ended microanalysis motivation correlation is printed as 0.29*. The discussion attributes this to both measures using four-point rating scales.

"No correlations were found except for the motivational component assessed by questionnaire and closed-ended microanalytic questions."
