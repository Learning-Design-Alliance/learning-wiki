Evidence¶

Amita Goyal Chin 2016¶

Amita Goyal Chin, Ugochukwu Etudo, Mark A. Harris. (2016). On Mobile Device Security Practices and Training Efficacy: An Empirical Study. Informatics in Education, 15(2). https://doi.org/10.15388/infedu.2016.12

q2 · i3 · causal · r1

Two-group post-test only quasi-experiment comparing undergraduates who completed SANS online security training modules (treated) with those who did not. The omnibus MANOVA was significant, F (5, n = 342) = 27.158, p < .001, "Partial η 2 = .288", but means showed the treated group riskier.

"There is a statistically significant difference in the propensity to practice harmful mobile security behaviors depending on whether or not a respondent received the treatment, F (5, n = 342) = 27.158, p < .001; Wilk's Λ = .712, Partial η 2 = .288."

Amita Goyal Chin 2016 (2)¶

Amita Goyal Chin, Ugochukwu Etudo, Mark A. Harris. (2016). On Mobile Device Security Practices and Training Efficacy: An Empirical Study. Informatics in Education, 15(2). https://doi.org/10.15388/infedu.2016.12

q2 · i3 · causal · r1

Univariate follow-ups within the same MANOVA each reached significance; for example, downloading applications requesting access to personal information showed "partial η 2 = .237" with treated students scoring less desirably (2.03 vs 2.78).

"download applications requesting access to personal information (F (1, n = 342) = 105.859; p < .001, partial η 2 = .237)"
