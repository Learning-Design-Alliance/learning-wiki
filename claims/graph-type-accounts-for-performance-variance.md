### Brockbank 2025

Brockbank, E., Verma, A., Lloyd, H., Huey, H., Padilla, L., & Fan, J. E. (2025). Evaluating convergence between two data visualization literacy assessments. Cognitive Research: Principles and Implications. https://doi.org/10.1186/s41235-025-00622-9

`q3 · i?` · `associational · r2`

Mixed-effects logistic regression on item accuracy in the combined assessment and within each test; the combined analysis reported "χ2(12) = 5066.18, p < .0001" for graph type. Only test statistics are printed, no effect size.

> "we find that performance varies significantly by graph type even when considering each assessment individually (GGR: χ2(3) = 125.18, p < .0001; VLAT: χ2(11) = 4919.30, p < .0001)"
