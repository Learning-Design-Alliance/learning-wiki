# Changes in self-efficacy correlate with changes in visual discrimination sensitivity after regressing out objective ability and baseline self-efficacy

> **Claim** · [All claims](index.md)

## Subclaims
`q3 i?` Partial correlations between SE change and VDS change were statistically significant in both tasks (contrast r =2.403, N = 38, p = .012; orientation r =2.342, N = 42, p = .027). [→ Zacharopoulos G 2014](#zacharopoulos-g-2014)

## Evidence

### Zacharopoulos G 2014

Zacharopoulos G, Binetti N, Walsh V, Kanai R (2014) The Effect of Self-Efficacy on Visual Discrimination Sensitivity. PLoS ONE 9(10): e109392. https://doi.org/10.1371/journal.pone.0109392

`q3 · i?` · `causal · r2`

Correlational analysis on the same experiment's data: partial correlations regressing out objective VDS ability and baseline SE. The authors interpret that "the greater the positive change in SE the greater the VDS improvement"; the printed r values carry an ambiguous minus sign in the source text.

> "This analysis yielded a statistically significant correlation between the VDS change and the SE change both in the contrast (r =2.403, N = 38, p = .012, two-tailed) and in the orientation (r =2.342, N = 42, p = .027, two-tailed) tasks."
