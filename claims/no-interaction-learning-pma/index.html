Two-way ANOVA interaction test (Table 3 and text) on 140 students. Both the text (F = 0.730, Sig. 0.484) and the table (F = 1.038, Sig. 0.357, H0 accepted) exceed 0.05, so both support no detected interaction; the printed F values disagree. No effect size is printed.
