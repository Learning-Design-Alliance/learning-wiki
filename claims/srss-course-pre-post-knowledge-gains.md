Pre-test/post-test analysis (Table 2) across course cohorts using an identical five-question test covering confidence and course knowledge items. Mean confidence rose from 3.32 to 3.96 (+0.64) and percent correct rose on each knowledge item, e.g. PRISMA-S categories from 62 to 78 (+16). No statistical test or effect size is reported.

> "The participant pre-test/post-test scores demonstrate an increase in knowledge for skills important to systematic review searching which are outlined in the list of SRSS skills (Table 2)."
