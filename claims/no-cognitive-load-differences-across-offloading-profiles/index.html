Poquet 2026¶

Poquet, O., Nanduri, M. S., Salinas Loyer, M. X., Stadler, M., Sailer, M., Jovanovic, J. (2026). Profiling Cognitive Offloading in LLM-mediated Synthesis Writing: Volume vs. Content. https://arxiv.org/abs/2606.10434

q2 · i? · associational · r1

In the volume-based profile comparison, NASA TLX ratings (α=.68) showed "no significant differences" across the four profiles; the authors attribute this partly to insufficient observations per cluster. The content-based comparison likewise showed no differences. No effect size was printed.

"Self-reported cognitive load showed no significant differences. There are insuf- ficient observations in each cluster to capture differences"
