## Subclaims
`q2 i?` Using normalized learning gains instead of raw gains, the Bayesian multilevel d_n was 1.04 with 95%-CrI [0.87, 1.21] and a class-wise SD of 0.38 for the control condition, and 1.07 with 95%-CrI [0.83, 1.27] and SD 0.28 for the intervention condition. Bayesian multilevel paired-comparison model (Listing 8, skew-normal family) on normalized learning gains gain_n := (po − pr)/(1 − pr) for the demonstration dataset. The article states it provides no model output because "the interpretation of the parameter estimates is not as straightforward as in the case of raw learning gains."

> "however, we can compute d n =1.04 with a 95%-CrI of [0.87,1.21] and a standard deviation of 0.38 across classes using (5). For the intervention condition, we obtain d n =1.07 with a 95%-CrI of [0.83,1.27] and a standard deviation of 0.28"
