`q2 · i?` · `design · r2`

Pairwise comparison analysis (Multimedia Appendix 2) of the five-model accuracy data using Tukey's honestly significant difference test following ANOVA, showing GPT-4 "significantly outperformed all other models" with the printed P values.

`q2 · i?` · `design · r2`
