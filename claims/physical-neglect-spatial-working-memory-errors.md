# Physical neglect exposure is associated with more double errors in the Spatial Working Memory test in healthy adults

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r2` · `q2`

## Subclaims
`q2 i?` Higher physical neglect scores were significantly associated with a higher number of double errors in the Spatial Working Memory test. [→ Majer M 2010](#majer-m-2010)

## Evidence

### Majer M 2010

Majer M, Nater UM, Lin J-MS, Capuron L, Reeves WC. (2010). Association of childhood trauma with cognitive function in healthy adults: a pilot study. BMC Neurology. https://doi.org/10.1186/1471-2377-10-61

`q2 · i?` · `associational · r2`

Multiple linear regression analysis in a pilot study of 47 healthy adults found a significant association between the physical neglect score and the number of double errors in the Spatial Working Memory test, described as a "significant association between the physical neglect score".

> "Furthermore, there was a significant association between the physical neglect score and the number of double errors in the Spatial Working Memory test and the latency for a correct response in the Pattern Recognition Memory test."
