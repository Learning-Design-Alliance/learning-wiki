Theoretical argument completing the definition's output component. The authors reject novelty requirements as ill-defined, noting a system can continue to learn from repeated presentation of the same information.

> "It therefore seems more appropriate to describe learning in terms of changes in how the system reacts to the information it has processed. This restriction does not mean that learning cannot also materialize in other changes, but just that it has to react differently to repeated information."
