`q3 · i?` · `associational · r1`

Chi-squared independence tests for the learned versus PT groups on the remaining five CWM items (Table 7). The article reports no significant associations, with printed effect sizes ranging from φ = 0 to φ = 0.19; no effect sizes exceed small thresholds.

> "No significant associations were observed for explanation of movement methods (p = 0.309, effect size: φ = 0.19), checking patients’ understanding of the movement method (effect size: φ = 0), explanations using the body (p = 0.309, effect size: φ = 0.19), pain assessment (p = 0.361, effect size: φ = 0.17), or paraphrasing technical terms (p = 0.309, effect size: φ = 0.19) between the learned and PT groups (Table 7)."
