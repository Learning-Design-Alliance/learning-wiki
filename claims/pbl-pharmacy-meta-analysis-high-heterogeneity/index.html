Heterogeneity assessment across the 16 pooled randomized controlled trials using Cochran's Q and I2 statistics in RevMan 5.3. The analysis found "high heterogeneity (I2 = 93 %, P < 0.00001)", prompting use of a random-effects model for pooling.

"There was high heterogeneity (I2 = 93 %, P < 0.00001); thus, the random-effects model was used."
