Evidence¶

Veit Kubik 2022¶

Veit Kubik, Kenneth Koslowski, Torsten Schubert, Alp Aslan. (2022). Metacognitive judgments can potentiate new learning: The role of covert retrieval. Metacognition and Learning (2022) 17:1057–1077. https://doi.org/10.1007/s11409-022-09307-w

q3 · i2 · causal · r3

Two-factorial ANOVA on Lists 1–4 interim JOL magnitudes for both JOL groups in the same experiment; post-hoc tests showed JOLs decreased between early and later lists (e.g., List 1 vs. List 4, t(70) = 6.17, p < .001, d = 0.74), which the authors read as learners' belief that interim recall decreases with new learning.

"The results revealed that there was a significant main effect of list, F(2.47, 172.75) = 20.83, p < .001, ̂ω2p = .06, but neither a main effect of practice type (JOLs with word stems vs. JOLs with complete words), F(1, 70) = 0.05, p = .821, ̂ω2p < .001"
