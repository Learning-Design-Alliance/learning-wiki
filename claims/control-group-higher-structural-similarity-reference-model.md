# Unprompted pre-service teachers' texts match the combined source-text reference model more closely on structural matching than prompted groups' texts

## Subclaims
`q3 i?` The control group achieved significantly higher structural matching (STRU) similarity to the reference model than both experimental groups. [→ Inka Sara Hähnlein 2024](#inka-sara-hahnlein-2024)

## Evidence

### Inka Sara Hähnlein 2024

Inka Sara Hähnlein, Pablo Pirnay-Dummer. (2024). Promoting pre-service teachers' knowledge integration from multiple text sources across domains with instructional prompts. Education Tech Research Dev. https://doi.org/10.1007/s11423-024-10363-z

`q3 · i?` · `causal · r2`

Tukey HSD post-hoc follow-up to a significant MANOVA (Wilks' λ = 0.79, F[14,200] = 1.83, p = .04) on T-MITOCAR similarity measures for N = 109 student texts versus the combined source-text reference model. The control group's higher STRU similarity reached significance against both prompted groups.

> "Tukey HSD post-hoc for structural matching revealed that the control group (STRU: M = 0.43, SD = 0.10) achieved significantly higher similarities with the reference model than experimental group 1 (STRU: M = 0.31, SD = 0.15, p < .001) and experimental group 2 (STRU: M = 0.34, SD = 0.14, p = .02; see Figure 4)."
