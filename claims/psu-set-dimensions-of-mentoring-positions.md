## Subclaims
`q2 i?` Each mentoring position pairs a PSU type with a SET type: facilitator (service providing, responsive), coach (development supporting, responsive), monitor (signaling, collaborative), exemplar (service providing or development supporting, directive). [→ Loosveld LM 2020](#loosveld-lm-2020)

## Evidence

### Loosveld LM 2020

Loosveld LM, Van Gerven PWM, Vanassche E, Driessen EW. (2020). Mentors’ Beliefs About Their Roles in Health Care Education: A Qualitative Study of Mentors’ Personal Interpretative Framework. Academic Medicine. https://doi.org/10.1097/ACM.0000000000003159

`q2 · i?` · `qualitative · r3`

Cross-case analysis of 18 mentor interviews clustered biographical case reports into 3 PSU types and 3 SET types; the quoted sentence names how each of the 4 positions combines a PSU dimension with a SET dimension, as summarized in Table 2.

> "(1) facilitator, a service-providing, responsive mentor; (2) coach, a development-supporting, responsive mentor; (3) monitor, a signaling, collaborative mentor; and (4) exemplar, a service-providing or development-supporting, directive mentor"
