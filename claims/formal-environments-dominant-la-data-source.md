Systematic literature review coding of 137 LA tools from nine academic databases using template analysis. The review reports the formal environments category (LMS/VLE data) as the highest-ranking data source category, used by 82 tools, "because educational institutions are the largest producers of the data sets used for LA".

> "It is the highest- ranking category, which is used as data sources by 82 tools analyzed for this review. This is because educational institutions are the largest producers of the data sets used for LA (Ferguson, 2012)."
