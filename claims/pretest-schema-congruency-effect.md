# Students already show a pretest congruency effect: existing knowledge yields better baseline performance for schema-related questions

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r1` · `q3`

## Subclaims
`q3 i?` On the pretest, before any learning, performance was better for schema-related than schema-unrelated questions, and only schema-related performance exceeded chance. [→ van Kesteren 2014](#van-kesteren-2014)

## Evidence

### van Kesteren 2014

van Kesteren, M. T. R., Rijpkema, M., Ruiter, D. J., Morris, R. G. M., & Fernández, G. (2014). Building on Prior Knowledge: Schema-dependent Encoding Processes Relate to Academic Performance. Journal of Cognitive Neuroscience, 26(10), 2250–2261. https://doi.org/10.1162/jocn_a_00630

`q3 · i?` · `causal · r1`

Self-paced pretest of 40 questions on Day 1 before learning, in 31 analyzed students. Schema-related accuracy was "50.41% [ SD = 13%] average correct" versus 34.15% (SD = 9%), t(30) = 6.71, p < .001; schema-related performance differed from chance (t(30) = 7.15, p < .001) while schema-unrelated did not (t(30) = .51, ns).

> "Performance on the pretest showed a congruency effect with better performance for schema-related information (t(30) = 6.71, p < .001, schema-related = 50.41% [ SD = 13%] average correct, schema-unrelated = 34.15% [ SD = 9%] average correct)"
