## Evidence

### Schleepen TMJ 2016

Schleepen TMJ, Van Mier HI, De Smedt B (2016) The Contribution of Numerical Magnitude Comparison and Phonological Processing to Individual Differences in Fourth Graders' Multiplication Fact Ability. PLoS ONE 11(6): e0158335. https://doi.org/10.1371/journal.pone.0158335

`q3 · i?` · `associational · r2`

Additional analysis (N = 63) correlating multiplication RT with RT on four nonsymbolic trial types (Table 4: rs .51–.66); re-analyzed regressions replacing the nonsymbolic task with each trial type showed similar results.

> "This analysis revealed that all four trial types significantly correlated with multiplication fact performance (all rs between .51 and .65, all ps < .001) showing that all four trial types displayed more or less similar correlations with multiplication fact retrieval."

### Schleepen TMJ 2016 (2)

Schleepen TMJ, Van Mier HI, De Smedt B (2016) The Contribution of Numerical Magnitude Comparison and Phonological Processing to Individual Differences in Fourth Graders' Multiplication Fact Ability. PLoS ONE 11(6): e0158335. https://doi.org/10.1371/journal.pone.0158335

`q3 · i?` · `associational · r2`

Additional analysis (N = 63) splitting symbolic comparison trials by numerical distance found similar correlations with multiplication fact speed for small (r = .57) and large (r = .54) distances; regression re-analyses yielded the same results.

> "This analysis showed that multiplication fact performance showed a more or less similar correlation with trials including a small numerical distance ( r = .57, p < .001) or a large numerical distance ( r = .54, p < .001)."
