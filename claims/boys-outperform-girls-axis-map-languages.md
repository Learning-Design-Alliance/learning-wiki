## Evidence

### Lowrie 2010

Lowrie, Tom and Diezmann, Carmel. (2010). Solving graphics tasks: Gender differences in middle-school students. Learning and Instruction. https://doi.org/10.1016/j.learninstruc.2009.11.005

`q3 · i2` · `associational · r2`

Repeated measures MANCOVA of GLIM scores pooled over Grades 4-6 (possible totals 0-18 per language), with gender as between-subjects factor and Raven's score as covariate. Post hoc tests showed "statistically significant differences across the gender variable for the Axis language" (partial η2 = .11) and for Map language (partial η2 = .03); the other four languages showed no significant gender effect.

> "Subsequent post hoc analysis revealed statistically significant differences across the gender variable for the Axis language, F(1, 326) = 13.1, p < .001, partial η2 = .11, and the Map language , F(1, 326) = 3.99, p < .001, partial η2 = .03."
