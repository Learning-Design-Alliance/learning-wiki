Evidence¶

Dryden Adam 2017¶

Dryden Adam, Allen Harriet A., Henshaw Helen, Heinrich Antje. (2017). The Association Between Cognitive Performance and Speech-in-Noise Perception for Adult Listeners: A Systematic Literature Review and Meta-Analysis. Trends in Hearing. https://doi.org/10.1177/2331216517744675

q3 · i2 · quant-synthesis · r?

Set of random-effects meta-analyses per cognitive subdomain with SiN collapsed (Table 4): inhibitory control r = .34, working memory r = .28, episodic memory r = .26, crystallized IQ r = .18 (Z = 1.00, p = .32), processing speed r = .39. The review reports associations "ranged between .18 and .39".

"Associations ranged between .18 and .39 and were significant for all subdomains, except crystallized intelligence."
