Evidence¶

Jing Zhang 2025¶

Jing Zhang, Xiaoning Huo, Hongbo Lv, Jiahua Xu & Xiaofeng Ma. (2025). Offline consolidation mechanisms of the retrieval practice effect: an analysis based on EEG signal characteristics. npj Science of Learning. https://doi.org/10.1038/s41539-025-00349-8

q2 · i? · causal · r1

Null correlational analysis of PSG sleep statistics against recall change rate across all three learning conditions in the nap group; all printed p values exceed 0.10. No equivalence test was reported.

"There were no signiﬁcant correlations between change in memory (for either all items or any of the three encoding strengths) and time or percentage of the nap spent in any sleep stage (all p values > 0.10)"
