## Evidence

### Antoniou Mark 2016

Antoniou Mark, Ettlinger Marc, Wong Patrick C. M. (2016). Complexity, Training Paradigm Design, and the Contribution of Memory Subsystems to Grammar Learning. PLoS ONE. https://doi.org/10.1371/journal.pone.0158812

`q3 · i?` · `causal · r2`

Experiment 1's test-only control group (n = 25), matched to the baseline group on memory measures, showed a different correlational pattern: "the only significant correlation was a negative correlation between declarative memory and learning of the simple grammar" (r = –.430, p = .032). No significant predictors emerged for the complex grammar.

> "For the test-only group, the only significant correlation was a negative correlation between declarative memory and learning of the simple grammar."
