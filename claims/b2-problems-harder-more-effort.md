`q2 · i?` · `associational · r1`

Descriptive statistics (Table 1) for students completing B1 (N= 887) and B2 (N= 876), showing higher means and variance for messages and code executions in B2; Table 2 shows success rates falling to 0.44 on B2-3. No inferential tests were run because samples were not independent.

> "Overall, the results align with B2 problems requiring more ef-fort, with greater variance in the variables (though, notably, there is a large variation in the number of messages sent for both batches)."
