# Profile membership related to mathematics test scores at both T1 and T3, with Positive-profile students scoring highest

## Subclaims
`q3 i?` There was a main effect of profile membership on T1 scores (χ2(2) = 27.95, p < .001) and on T3 scores (χ2(2) = 72.19, p < .001), with Positive-profile students scoring significantly higher than both other profiles at each time point. [→ Symes 2025](#symes-2025)

## Evidence

### Symes 2025

Symes, W., Lichtenfeld, S., Wood, P., & Putwain, D. W. (2025). Profiles of control, value and achievement emotions in primary school mathematics lessons. British Journal of Educational Psychology, 95, 888–902. https://doi.org/10.1111/bjep.12768

`q3 · i?` · `associational · r2`

Unadjusted Wald tests on T3 mathematics test scores (gender controlled) in the latent profile sample; T1 showed the same pattern (χ2(2) = 27.95, p < .001). The quote names the Positive profile as outperforming both the Negative and Mixed profiles.

> "A Wald test indicated that there was a main effect of profile membership on mathematics test scores at T3: χ2(2) = 72.19, p < .001. Pairwise difference tests indicated that students in the Positive profile had significantly higher test scores at T3 than students in the Negative profile (z = 3.53, p < .001) and Mixed profile (z = 8.18, p < .001)."
