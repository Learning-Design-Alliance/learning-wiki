# No evidence of publication bias in the flipped classroom meta-analysis

## Subclaims
`q4 i?` Funnel plot inspection, rank correlation, Egger's regression, trim-and-fill, and fail-safe N tests found no indication that the pooled effect was inflated by publication bias. [→ HEW Khe Foon; LO Chung Kwan 2018](#hew-khe-foon-lo-chung-kwan-2018)

## Evidence

### HEW Khe Foon; LO Chung Kwan 2018

HEW Khe Foon; LO Chung Kwan. (2018). Flipped classroom improves student learning in health professions education: a meta-analysis. BMC Medical Education. https://doi.org/10.1186/s12909-018-1144-z

`q4 · i?`

Publication bias assessment for the 28-study meta-analysis using five standard tests. Begg and Mazumdar Kendall's tau = 0.08 (p = 0.27) and Egger's intercept 0.79 (p = 0.24); trim-and-fill trimmed no studies, and the fail-safe N was 747.

> "Results showed that 747 additional missing studies with zero mean effect size would be required to make the overall effect statistically insignificant."
