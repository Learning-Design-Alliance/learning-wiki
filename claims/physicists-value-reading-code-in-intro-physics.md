## Evidence

### Justin Gambrell and Eric Brewe 2024

Justin Gambrell and Eric Brewe. (2024). Towards a Generalized Assessment of Computational Thinking for Introductory Physics Students. Originally published 2023. [doi:10.1103/physrevphyseducres.20.010128](https://doi.org/10.1103/physrevphyseducres.20.010128)

`q2 · i?` · `qualitative · r2`

Qualitative analysis of 26 semi-structured interviews with academic and industrial physicists, coded with constant comparison in Nvivo 12 Plus. The read-code response code "had the highest response rate out of all the response codesq in this study."

> "Twenty of the twenty-six participants (77%) mentioned that students should know how to read codec by the end of a computationally integrated introductory physics class."

### Justin Gambrell and Eric Brewe 2024 (2)

Justin Gambrell and Eric Brewe. (2024). Towards a Generalized Assessment of Computational Thinking for Introductory Physics Students. Originally published 2023. [doi:10.1103/physrevphyseducres.20.010128](https://doi.org/10.1103/physrevphyseducres.20.010128)

`q2 · i?` · `qualitative · r2`

Same interview corpus; participants qualified the reading-code goal to code encountered in the course, e.g. objecting to handing students a for loop after a semester of while loops.

> "Almost all participants that men- tioned that students should be able to read code c, also added that students should only be able to read code c that they have seen before."
