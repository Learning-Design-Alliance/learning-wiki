Reading mixed-design ANOVA in the same pilot found significant main effects (e.g., intervention F(1, 22) = 353.51, partial η² = .95) but a non-significant time × measure × intervention interaction (F(2.66, 53.29) = 0.08); the authors offer this interpretation in the discussion.
