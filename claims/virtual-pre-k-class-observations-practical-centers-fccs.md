A pilot study conducted by Mathematica in partnership with Oregon's Early Learning Division tested virtual observations using the Pre-K CLASS in Oregon during the 2021-2022 program year. The key finding states that virtual observations "was practical in both centers and FCCs."

> "Conducting virtual observations using the Pre-K Classroom Assessment Scoring System (Pre-K CLASS) was practical in both centers and FCCs; however, doing so comes with substantial logistical challenges."
