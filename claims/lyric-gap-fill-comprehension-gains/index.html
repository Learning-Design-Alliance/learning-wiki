The review reports this single empirical study (n = 60 Korean university students per Table 2) using lyric gap-fill plus micro-listening with pre/post listening tests and a survey; only the p-value is printed, no effect size.

"Kim and Lee (2024) demonstrated that a six-week lyric gap-fill program with Korean university students led to significant gains in both listening comprehension scores (p < .01) and self-reported engagement."
