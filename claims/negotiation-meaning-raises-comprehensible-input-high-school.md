# In high school groups, learners with negotiation of meaning obtained more comprehensible input in the match task than learners with pre-modified input only

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r1` · `q3`

## Subclaims
`q3 i?` High school experimental groups (pre-modified input plus negotiation of meaning) scored significantly higher on comprehensible input in the match task than high school control groups (pre-modified input only). [→ Baoshu Yi & Zhinong Sun 2013](#baoshu-yi-zhinong-sun-2013)

## Evidence
