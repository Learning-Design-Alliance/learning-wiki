Between-group comparison using Kruskal-Wallis tests across three experience groups (experts n = 11, fellows n = 10, other MFM specialists n = 10) in the prospective questionnaire validation study. Table 2 reports mean ± SD ratings per domain, with the other-MFM group consistently lower but positive.

> "Kruskal‐Wallis analysis revealed significant differences between groups across all domains (p < 0.01). As shown in Table 2, experienced fetal therapy specialists rated environmental realism notably high (H = 12.3, p = 0.002), while fellows provided the strongest endorsement for training effectiveness (H = 10.8, p = 0.004)."
