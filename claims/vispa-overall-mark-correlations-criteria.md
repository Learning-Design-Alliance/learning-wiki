### Erdmann M 2014

Erdmann M, Fischer R, Glaser C, Klingebiel D, Krause R, Kuempel D, Müller G, Rieger M, Steggemann J, Urban M, Walz D, Weidenhaupt K, Winchen T, Weltermann B. (2014). A field study of data analysis exercises in a bachelor physics course using the internet platform VISPA. [doi:10.1088/0143-0807/35/3/035018](https://doi.org/10.1088/0143-0807/35/3/035018)

`q2 · i?` · `associational · r1`

Pearson correlation analysis of survey questions against the overall mark. The authors report the recommendation "strongly correlated by 85% with the overall mark" and, separately, 83% for the platform being suited for data analyses. Only percentage correlations are printed; no standardised effect size is reported.

> "the recommendation of the students for a future course using VISPA in data analysis exercises was strongly correlated by 85% with the overall mark"

### Erdmann M 2014 (2)

Erdmann M, Fischer R, Glaser C, Klingebiel D, Krause R, Kuempel D, Müller G, Rieger M, Steggemann J, Urban M, Walz D, Weidenhaupt K, Winchen T, Weltermann B. (2014). A field study of data analysis exercises in a bachelor physics course using the internet platform VISPA. [doi:10.1088/0143-0807/35/3/035018](https://doi.org/10.1088/0143-0807/35/3/035018)

`q2 · i?` · `associational · r1`

In the same correlational analysis, the largest learning-style correlation was the fun aspect at 79%; the mark also correlated 69% with deepening lecture contents (figure 7a). Only percentage correlations are printed; no standardised effect size is reported.

> "The largest correlation corresponds to the fun aspect, which accounts to 79%."
