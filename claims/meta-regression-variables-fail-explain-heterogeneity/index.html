q2 · i? · quant-synthesis · r2

Meta-regression with theoretical knowledge scores as outcome and intervention methods, duration, and participant type as predictors; all p-values non-significant. The same held for practical skills (β = -0.62, p = 0.44; β = 0.73, p = 0.20; β = 0.28, p = 0.72).

"The results demonstrated that none of the three variables contributed remarkably to the heterogeneity in theoretical knowledge scores (intervention methods: β = -0.26, p = 0.54; intervention duration: β = 0.49, p = 0.12; participants: β = 0.22, p = 0.61; Table 2)."
