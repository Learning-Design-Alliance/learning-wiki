Evidence¶

Laura B. Lang 2014¶

Laura B. Lang, Robert R. Schoen, Mark LaVenia, and Maureen Oberlin. (2014). Mathematics Formative Assessment System – Common Core State Standards: A Randomized Field Trial in Kindergarten and First Grade. SREE Spring 2014 Conference. https://eric.ed.gov/?id=ED562773

q3 · i1 · causal · r2

Three-level multilevel model (students nested within teachers within schools) of Z-scored total number correct for 2,317 Kindergarten students, controlling for school percent FRPL, found an effect size of 0.20 (p < .05) for MFAS.

"A statistically significant positive main effect was found for both grade levels: 0.20 (p < .05) in Kindergarten and 0.24 (p < .01) in Grade 1."
