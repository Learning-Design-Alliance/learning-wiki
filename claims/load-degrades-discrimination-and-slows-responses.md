# Working memory load degrades discrimination accuracy and slows responses in youth

## Subclaims

### Satterthwaite Theodore D. M.D. 2012

Satterthwaite Theodore D. M.D., M.A.; Ruparel Kosha M.S.; Loughead James Ph.D; Elliott Mark A. Ph.D.; Gerraty Raphael T. B.A.; Calkins Monica E. Ph.D.; Hakonarson Hakon M.D. Ph.D.; Gur Ruben C. Neuroimage. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC3358426/

`q3 · i?`

Mixed-effects behavioral analysis with load as fixed factor, subject random, gender and age covariates. Found "a lower Pr (indicating less accurate discrimination) at higher levels of working memory load" [F(2,606)=469.83; p<0.001].

> "As expected, subjects had a lower Pr (indicating less accurate discrimination) at higher levels of working memory load [F (2, 606)= 469.83; p<0.001)]."
