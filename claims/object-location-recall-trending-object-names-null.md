## Evidence

### Marino 2025

Marino, C. E., Rjabtsenkov, P., Sharp, C., Ali, Z., Pineda, E., Bavdekar, S. Y., Garg, T., Jordan, K., Halvorsen, M., Aponte, C., Blue, J., Zhu, X. & Suarez-Jimenez, B. (2025). Using virtual reality to study spatial mapping and threat learning. npj Science of Learning 10:14. https://doi.org/10.1038/s41539-025-00305-6

`q2 · i?` · `associational · r1`

Post-task interviews compared memory of the virtual environment via Welch's t-tests. The number of recalled object names did not differ (t(19) = 1.00, p = 0.330), but "a trending difference in the number of recalled object locations between groups" favored learners; no effect size was printed for this null/trending pair.

> "However, we found a trending difference in the number of recalled object locations between groups ( t(20.06) = 1.82, p = 0.085, 95%CI[−0.073, 1.053]; learners: mean = 3.94, SD = 0.31; non-learners: mean=3.45, SD = 1.19)"
