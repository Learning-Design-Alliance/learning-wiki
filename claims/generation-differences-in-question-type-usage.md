Mean-difference analysis of Graesser question-type usage between generation groups across both sessions (Figure 2). The article reports Δ = +1.03, p = .013 in Session 1 and Δ = +1.44 in Session 2 for instrumental/procedural questions; these are raw mean differences, not standardized effect sizes.

> "Instrumental/proceduralquestions — in which students ask the AI howto accomplish a task — showed the largest statistically signifi- cant difference in Session 1 (Δ=+ 1.03, 𝑝=. 013), and remained the second-largest advantage in Session 2 ( Δ=+ 1.44)."

### Matin Amoozadeh and Amin Alipour 2026 (2)

`q2 · i?` · `associational · r1`

Descriptive mean-difference patterns from the same generation comparison. The article characterizes first-generation students as adopting "a more confirmatory role, using the AI to check and validate rather than to generate or explore"; no effect size is printed for this contrast.

> "By contrast, first-generation students demonstrated relatively higher usage ofVerificationquestions — asking whether a given answer or piece of code is correct — andExpectationalquestions, which ex- plore hypothetical outcomes."
