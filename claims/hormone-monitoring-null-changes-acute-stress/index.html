Tjønnås Maria Suong, Guzmán-García Carmen, Sánchez-González Patricia, Gómez Enrique Javier, Oropesa Ignacio, Våpenstad Cecilie. (2022). Stress in surgical educational environments: a systematic review. BMC Medical Education. https://doi.org/10.1186/s12909-022-03841-6

q2 · i? · review · r3

Review synthesis of 10 articles using hormone-based monitoring (cortisol, alpha-amylase, testosterone). The review reports "no statistically significant changes were found in hormone levels when participants encountered stressors"; no effect size is printed, so no magnitude is asserted.

"For several studies included in this review, no statistically significant changes were found in hormone levels when participants encountered stressors [20, 23, 82, 85, 92]."
