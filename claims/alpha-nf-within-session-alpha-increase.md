# Alpha neurofeedback training increases alpha amplitude within training sessions relative to sham control, but the increase does not persist across sessions

## Subclaims
`q3 i3` A significant Group × Block interaction showed alpha changes across blocks differed between the NF and sham groups, with alpha increased in blocks 3–5 versus block 1 in the NF group only (ηp2 = 0.273). [→ Zhou 2024](#zhou-2024)
`q3 i?` Neither the Group × Day interaction nor the Group main effect was significant for alpha across sessions, indicating unsuccessful long-term NF learning. [→ Zhou 2024 (2)](#zhou-2024-2)

## Evidence

### Zhou 2024

Zhou, W., Nan, W., Xiong, K., & Ku, Y. (2024). Alpha neurofeedback training improves visual working memory in healthy individuals. npj Science of Learning 9, 32. https://doi.org/10.1038/s41539-024-00242-w

`q3 · i3` · `causal · r2`

Within-session alpha amplitude analysis (2×5 mixed-design repeated-measures ANOVA on mean alpha per block) during NF training; the interaction printed ηp2 = 0.273. "Further analysis found a signiﬁcant increase in alpha amplitude in the last three blocks (blocks 3 to 5) compared to Block 1 in the NF group, which was not the case in the sham control group."

> "Group × Block has a signiﬁcant interaction (F (4,35) = 3.29, p = 0.022, ηp 2 = 0.273), indicating that alpha changes across blocks signiﬁcantly differed between the NF training group and the sham control group"

### Zhou 2024 (2)
