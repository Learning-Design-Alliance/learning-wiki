Hornung 2026¶

Hornung, I., Marasinghe Arachchige, D., Kumarage, T., Agrawal, G., Deng, Y., Chen, Y.-C., & Liu, H. (2026). CyberAGENTS: Structured Autonomy for Agentic Gamified Learning in Cybersecurity. Preprint. https://arxiv.org/abs/2608.07965

q2 · i? · design · r2

Classroom deployment with 24 undergraduate students using a within-subjects design; each participant completed one interactive cybersecurity scenario with the full agent loop and a mixed-format post-study survey. Descriptive Likert statistics show "scenario authenticity (M = 4.21, SD = 0.88)" as highest rated; no inferential tests or effect sizes are reported.

"The highest-rated dimension was scenario authenticity (M = 4.21, SD = 0.88), followed by gamification impact (M = 3.96, SD = 1.11), trust in system feedback (M = 3.92, SD = 1.18)"
