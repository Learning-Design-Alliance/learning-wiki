`q3 · i?` · `causal · r1`

Linear mixed-effects model analysis of upper-arm sensor data from 54 surgical novices, with Holm correction applied to the primary interaction tests. The analysis found "Hand size interacted with modality for angular velocity" with the printed p values and slope directions; no standardised effect size was printed.

> "Hand size interacted with modality for angular velocity (p = 0.008; Holm-adjusted p = 0.0499), but this reflected a non-significant positive slope during RA rather than an association during LAP (p = 0.892) (Fig. 5)."
