## Evidence

### Noemi Mauro 2024

Noemi Mauro, Liliana Ardissono, Federica Cena, Livio Scarpinati, Gianluca Torta. (2024). An Intelligent Support System to Help Teachers Plan Field Trips. Int J Artif Intell Educ 34, 793–824. https://doi.org/10.1007/s40593-023-00366-x

`q2 · i?` · `causal · r1`

Within-subjects task experiment in which 18 science teachers used both applications and filled the translated Italian SUS. The study reports "FieldTripOrganizer SUS scored 79.47/100" against 34.44/100 for Klarna.Trips, graded A- versus D on the Sauro-Lewis scale.

> "FieldTripOrganizer SUS scored 79.47/100 (Brooke, 1996). If we refer to the Sauro-Lewis curved grading scale (Lewis and Sauro, 2018), which turns the average value of the SUS into grades, our application obtained an A- score. In comparison, the baseline Klarna.Trips scored 34.44/100 which corresponds to the D score."

### Noemi Mauro 2024 (2)

Noemi Mauro, Liliana Ardissono, Federica Cena, Livio Scarpinati, Gianluca Torta. (2024). An Intelligent Support System to Help Teachers Plan Field Trips. Int J Artif Intell Educ 34, 793–824. https://doi.org/10.1007/s40593-023-00366-x

`q2 · i?` · `causal · r1`

Post-hoc analysis of the SUS data from the same 18-teacher within-subjects study; the article reports "a Mann-Whitney test which showed a statistical significance of the difference between the results on all the statements", with per-item significance levels printed in Table 1.

> "We conducted a post-hoc comparison using a Mann-Whitney test which showed a statistical significance of the difference between the results on all the statements."
