# The exam benefit of the TQ assignment was significant only for low-transition reasoners, with no significant interaction between reasoning ability and treatment

## Subclaims
`q3 i?` Low-transition reasoners in the TQ section significantly outperformed low-transition reasoners in the R section on the final exam. [→ Bailey E. G. 2018](#bailey-e-g-2018)
`q3 i3` The two-way ANOVA found no significant interaction between reasoning stage and course section, though reasoning stage itself had a large effect (ηp2 = 0.23). [→ Bailey E. G. 2018 (2)](#bailey-e-g-2018-2)

## Evidence

### Bailey E. G. 2018

Bailey E. G., Baek D., Meiling J., Morris C., Nelson N., Rice N. S., Rose S., Stockdale P. (2018). Learning Gains from a Recurring “Teach and Question” Homework Assignment in a General Biology Course: Using Reciprocal Peer Tutoring Outside Class. CBE—Life Sciences Education. https://doi.org/10.1187/cbe.17-12-0259

`q3 · i?` · `causal · r2`

Post hoc t tests within reasoning-level groups (LT, HT, PFO) defined by LCTSR scores; only the low-transition group showed a significant section difference (p = 0.0498). No effect size printed, so impact is coded i? (no magnitude reported; not a null effect).

> "t tests showed that LT thinkers in the TQ section significantly outperformed LT thinkers in the R section (p = 0.0498), while scores of HT and PFO thinkers were indistinguishable between sections (p = 0.44 and 0.43, respectively)."

### Bailey E. G. 2018 (2)

Bailey E. G., Baek D., Meiling J., Morris C., Nelson N., Rice N. S., Rose S., Stockdale P. (2018). Learning Gains from a Recurring “Teach and Question” Homework Assignment in a General Biology Course: Using Reciprocal Peer Tutoring Outside Class. CBE—Life Sciences Education. https://doi.org/10.1187/cbe.17-12-0259

`q3 · i3` · `causal · r2`

Two-way ANOVA on final exam scores by reasoning stage and section; the omnibus interaction was not significant (p = 0.15), so the subgroup pattern should be interpreted cautiously. Reasoning stage ηp2 = 0.23 (large) and section ηp2 = 0.06 as printed.

> "Reasoning stage (p < 0.0001, ηp2 = 0.23) and course section (p = 0.03, ηp2 = 0.06) both significantly explained variation in final exam scores, but there was no significant interaction between them (p = 0.15; n = 3–21)."
