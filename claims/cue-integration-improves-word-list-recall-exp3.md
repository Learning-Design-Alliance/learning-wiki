## Evidence

### Loprinzi Paul D. 2019

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i3` · `causal · r2`

Experiment 3 (n = 80; Mage = 21.04) was a four-arm randomized trial using a 50-word list and cue-integration strategy. The learning main effect was large, with printed effect size eta-squared ƞ2 = 0.77; post-hoc Mdiff = 14.38, t = 16.75, p < 0.001 favoring the learning manipulation.

> "We observed a significant main effect for learning, F(2, 152) = 280.6, p < 0.001, ƞ2 = 0.77, and a significant main effect for exercise, F(2, 152) = 5.03, p = 0.02, ƞ2 = 0.01."

### Loprinzi Paul D. 2019 (2)

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i3` · `causal · r2`

In Experiment 3's mixed-measures ANOVA with three time levels (immediate, delayed 1, delayed 2 with cues), the time by learning interaction was large, with printed effect size eta-squared ƞ2 = 0.51; post-hoc tests showed delayed 2 memory exceeded delayed 1 (Mdiff = −11.43, t = 8.33, p < 0.001).

> "there was a main effect for time, F(2, 152) = 468.5, p < 0.001, ƞ2 = 0.42), and a time by learning interaction, F(2, 152) = 568.6, p < 0.001, ƞ2 = 0.51"
