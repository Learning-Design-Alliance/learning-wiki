# The evolutionary analogy for a smaller working memory being more efficient is doubtful

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · theoretical `r2` · `q1`

## Subclaims
`q1 i?` The authors doubt Sweller's argument that a smaller working memory is more efficient, since a larger working memory would allow longer operation sequences to be stored and anticipated. [→ Schnotz 2007](#schnotz-2007)

## Evidence

### Schnotz 2007

Schnotz, W., Kürschner, C. (2007). A Reconsideration of Cognitive Load Theory. Educational Psychology Review 19, 469–508. https://doi.org/10.1007/s10648-007-9053-4

`q1 · i?` · `theoretical · r2`

Theoretical counter-argument in the notes: the authors are "in doubt, however, whether the analogy between biological evolution and cognition really holds", arguing a larger working memory would be "more advantageous for learning than a smaller working memory".

> "A larger working memory would then allow longer sequences of operations being stored and memorized and, thus, be more advantageous for learning than a smaller working memory."
