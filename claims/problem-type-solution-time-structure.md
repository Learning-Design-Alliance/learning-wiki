# Problem type modulated solution times, with large problems slowest and +1 problems fastest in both age groups

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q3` peer-reviewed experiment · `i3` large

## Subclaims
`q3 i3` Solution times varied by problem type (ηp2 = .58): large problems (947 ms) were slower than +0 (835 ms), small (809 ms), tie (770 ms), and +1 problems (747 ms). [→ Thevenot 2018](#thevenot-2018)

## Evidence

### Thevenot 2018

Thevenot, C., Dewi, J., Bagnoud, J., Wolfer, P., Fayol, M., & Castel, C. (2018). The use of automated procedures by older adults with high arithmetic skills during addition problem solving. https://eric.ed.gov/?id=ED

`q3 · i3`

ANOVA on solution times across five problem categories in both age groups. "Large problems were solved slower (947 ms)" than +0 problems, which did not differ from small problems; ties (770 ms) and +1 problems (747 ms) were fastest.

> "solution times varied as a function of Type of problems, F(4, 168) = 58.38, MSE = 1027741.17, ηp2 = .58, p < .001. Large problems were solved slower (947 ms) than problems involving 0 (835 ms, F(1, 42) = 32.71, ηp2 = .44, p < .001), which were not solved slower than small problems (809 ms, F(1, 42) = 2.14, p = .15)."
