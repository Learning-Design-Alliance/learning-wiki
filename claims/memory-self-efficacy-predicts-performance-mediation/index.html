Evidence¶

Hastings 2011¶

Hastings, E. C., & West, R. L. (2011). Goal orientation and self-efficacy in relation to memory in adulthood. Neuropsychology, Development, and Cognition. Section B, Aging, Neuropsychology and Cognition, 18(4), 471-493. https://doi.org/10.1080/13825585.2011.575926

q2 · i1 · associational · r2

Final SEM of the pooled sample; about 24.8% of total variance in memory performance was explained. Sobel tests showed the learning-goal indirect effect was significant (statistic=1.97, p<.05) and the performance-goal indirect effect marginally significant (statistic= −1.81, p=.07). The data are cross-sectional: the model is estimated as causal, but the authors note that longitudinal work is needed to examine these relationships, which may be reciprocal, so the paths cannot show that self-efficacy causes better performance.

"Memory self-efficacy had a significant positive impact on memory performance (β= .16, p<.05), with higher memory self-efficacy leading to better performance."
