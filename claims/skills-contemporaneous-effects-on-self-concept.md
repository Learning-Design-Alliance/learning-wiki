The model showed "contemporaneous effects on self-concept at each wave" with β3′ = [.157, .221], p < .001, plus smaller significant lagged effects; no standardized effect size is printed for this path in this section.

`q3 · i?` · `associational · r3`

RI-CCLPM solution for French (language arts) in the ProFAN sample (N = 9,041). Skills predicted "variations in self-concept within the same semester via contemporaneous effects" (β3′ = [.113, .115], p < .001); the reverse contemporaneous path was nonsignificant and omitted.
