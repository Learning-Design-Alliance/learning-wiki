## Evidence

### Murat Oztok 2012

Murat Oztok, Daniel Zingaro, Clare Brett, Jim Hewitt. (2012). Exploring Asynchronous and Synchronous Tool use in Online Courses. Preprint submitted to Computers & Education. https://doi.org/10.1016/j.compedu.2012.08.007

`q2 · i?` · `associational · r2`

Correlational analysis of logs from all 222 students in nine dual-mode courses, relating messages written to average note length. The quote reports "no signiﬁcant correlation ( p = 0.21)"; no effect size is printed for this null finding.

> "we found a highly signiﬁcant positive correlation between number of messages written and number of notes written (r = 0.6,p = 0), but no signiﬁcant correlation ( p = 0.21) between number of messages written and average length of notes"
