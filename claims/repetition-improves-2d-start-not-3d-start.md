Table 1 comparison of first–third versus eighth–tenth attempts in the 40-participant crossover study. For task 2 in the 3D start group, technical errors rose from 1.4 to 2.8 (P = 0.016, significantly worse), while the 2D start group improved on all task 2 scores (e.g., operative time 30.7 to 18.0 s, P < 0.001).

> "In the 3D start group, operative times and path lengths were not improved by repetition, and technical errors in the later phase were significantly worse than in the early phase."
