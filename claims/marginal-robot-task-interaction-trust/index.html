q3 · i1 · causal · r2

Repeated-measures ANOVA interaction term in the N = 81 video-based experiment; sphericity was violated for the interaction (p<.001) and Greenhouse–Geisser and Huynh–Feldt corrections were applied. The printed effect size is "η2 = .036".

"The ROBOT x TASK interaction was marginal F (2.94, 232.64) p = .034, η2 = .036, suggesting a limited combined influence of robot type and task context on trust ratings (see Fig. 4)."

Related Claims¶

  • Robot appearance showed no meaningful effect on trust: pairwise robot differences did not reach significance after Bonferroni adjustment — related
  • A conceptual framework paper reports, citing a meta-analysis (Roesler et al., 2021), that anthropomorphism benefits human-robot interaction with effects varying across task contexts and design implementations — a broader claim this one bears on
  • Hypotheses that specific robot appearances would be trusted more in matching tasks (humanoids for teaching, task-oriented robots for instructions, soft robots for personal disclosure) were not confirmed — related
  • Task type strongly determines trust in educational robots, with highest trust for procedural instruction, moderate trust for teaching, and lowest trust when robots request personal information — related
  • Trust evaluations were strongly and positively correlated across all robot–task combinations, suggesting trust in social robots may be a stable, generalized attitude — related
