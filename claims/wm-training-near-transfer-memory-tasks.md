# Working memory training produces a robust near-transfer effect on other memory tasks regardless of control-group type

## Subclaims
`q3 i2` WM training improved performance on other memory tasks by 0.44 SD against active controls and 0.46 SD against passive controls. [→ Sala Giovanni 2017](#sala-giovanni-2017)

## Evidence

### Sala Giovanni 2017

Sala Giovanni, Gobet Fernand. (2017). Does Far Transfer Exist? Negative Evidence From Chess, Music, and Working Memory Training. Current Directions in Psychological Science. https://doi.org/10.1177/0963721417712760

`q3 · i2` · `quant-synthesis · r2`

Meta-analysis of WM training in typically developing children found a robust near-transfer effect on other memory tasks of 0.44 SD (active controls) and 0.46 SD (passive controls) — printed effect sizes of 0.44 and 0.46 SD that held across control-group types, unlike far-transfer outcomes which collapsed with active controls.

> "The only exception to this pattern was the robust near-transfer effect that WM training exerted on other memory tasks (0.44 and 0.46 SD when the treated groups were compared with active and passive control groups, respectively)."
