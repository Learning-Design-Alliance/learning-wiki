## Evidence

### Hans van der Meij 2015

Hans van der Meij, Jan van der Meij, Ruth Harmsen. (2015). Animated pedagogical agents effects on enhancing student motivation and learning in a science inquiry learning environment. Education Tech Research Dev. https://doi.org/10.1007/s11423-015-9378-5

`q3 · i3` · `causal · r2`

Agent questionnaire (11 items, Cronbach's alpha 0.89) administered only in the agent condition to 21 students. Girls' mean was 5.57 (SD 1.23), about half a standard deviation above the midpoint; boys' mean was 3.94 (SD 2.08), below it. The article reports this as supporting Hypothesis 4.

> "An ANOVA with gender as a ﬁxed factor and model ratings for the agent as dependent variable showed a signiﬁcant effect for gender, F(1,20) = 4.87, p = 0.04, d = 0.95. Girls rated the agent as a better model than boys"
