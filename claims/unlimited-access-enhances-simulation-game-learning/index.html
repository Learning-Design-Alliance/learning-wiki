Evidence¶

Traci Sitzmann 2011¶

Traci Sitzmann. (2011). A Meta-Analytic Examination of the Instructional Effectiveness of Computer-Based Simulation Games. Personnel Psychology, 64, 489-528. https://onlinelibrary.wiley.com/journal/17446570

q3 · i2 · quant-synthesis · r?

Meta-analytic moderator analysis comparing 10 unlimited-access samples (N = 925) with 45 limited-access samples (N = 2,738); the QB was significant (21.11), supporting the hypothesis that repeated voluntary engagement realizes the games' learning potential.

"trainees in the simulation game group outperformed the comparison group to a greater extent when they had unlimited access to the simulation game (d = .68) than when trainees had limited access to the simulation game (d = .31)."

Related Claims¶

  • Simulation games are effective as a supplement to other instruction but not as standalone instruction, where comparison groups learned slightly more (a difference not statistically significant) — related
  • Simulation games are more effective when they actively rather than passively convey course material — related
  • A 2017 cyberlearning community report states that students learn more from games when bridging activities connect game learning to classroom instruction, and that learning analytics can strengthen the connection — related
  • Graduate SLP students perceive the learning mode of computer-based simulation as highly beneficial because it allows unlimited attempts without grade penalty — a narrower finding that bears on this claim
