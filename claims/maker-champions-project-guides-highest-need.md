Final survey question asked champions to rank seven resource types in order of importance; Figure 4 reports average ranks (student project ideas and guides 4.96; in-person PD 4.38; cross-curricular integration 4.2; project documentation 4.14; assessment 3.76; online PD 3.54; advocacy 3.02).
