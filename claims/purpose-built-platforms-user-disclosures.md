## Evidence

### Brulet A 2015

Brulet A, Llorca G, Letrilliart L. (2015). Medical Wikis Dedicated to Clinical Practice: A Systematic Review. Journal of Medical Internet Research. https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4392552/

`q2 · i?` · `review · r3`

Platform description across 25 wikis: MediaWiki natively supported 15 sites, three hosted by online wiki farms, seven purpose-built (two upon MediaWiki). The review reports: "only one site using MediaWiki natively systematically managed users' real names and credentials."

> "As opposed to every purpose-built platform, only one site using MediaWiki natively systematically managed users' real names and credentials."
