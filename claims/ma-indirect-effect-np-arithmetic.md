# Math anxiety has a statistically significant indirect effect on arithmetic calculation through symbolic number processing

> **Claim** · [All claims](index.md)

## Subclaims
`q3 i?` In the same arithmetic path model, MA also exerted a statistically significant indirect effect on arithmetic via number processing (standardized estimate = -.09, p = .027). [→ Skagerlund K 2019](#skagerlund-k-2019)

## Evidence

### Skagerlund K 2019

Skagerlund K, Östergren R, Västfjäll D, Träff U (2019) How does mathematics anxiety impair mathematical abilities? Investigating the link between math anxiety, working memory, and number processing. PLoS ONE 14(1): e0211283. https://doi.org/10.1371/journal.pone.0211283

`q3 · i?`

Same confirmatory SEM path analysis of arithmetic calculation (N = 170 adults, Mplus 7). The indirect MA→NP→arithmetic path was significant (p = .027, standardized estimate = -.09), corroborating domain-specific number-processing mechanisms as a second pathway.

> "The path from math anxiety via working memory had a statistically significant indirect effect to arithmetic calculation (p = .001, standardized estimate = -.15) and also a significant indirect effect via NP to arithmetic (p = .027, standardized estimate = -.09)."
