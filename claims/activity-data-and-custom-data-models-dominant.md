## Evidence

### Arham Muslim 2020

Arham Muslim, Mohamed Amine Chatti, Mouadh Guesmi. (2020). Open Learning Analytics: A Systematic Literature Review and Future Perspectives. University of Duisburg-Essen. Originally published 2019. [doi:10.1007/978-3-030-41099-5_1](https://doi.org/10.1007/978-3-030-41099-5_1)

`q3 · i?` · `review · r3`

Template-analysis coding in the review's Data Types section. The review reports log-based activity data as the main data type for "almost 107 reviewed LA tools", and notes assessment data (37 tools), user profile data (14), and multimodal data (12) have grown since 2017.

> "The main data type used by almost 107 reviewed LA tools is 'Activity data', which represents the data of learning activities performed by different stakeholders available through default logging mechanism in a learning environment."

### Arham Muslim 2020 (2)

Arham Muslim, Mohamed Amine Chatti, Mouadh Guesmi. (2020). Open Learning Analytics: A Systematic Literature Review and Future Perspectives. University of Duisburg-Essen. Originally published 2019. [doi:10.1007/978-3-030-41099-5_1](https://doi.org/10.1007/978-3-030-41099-5_1)

`q3 · i?` · `review · r2`

Data Models subsection of the review. The majority implemented custom data models; Experience API (xAPI) is "at the top of the list" among standards, used by 22 tools, with Activity Streams, IMS Caliper, and LCDM each adopted by two tools.

> "The majority (110 tools) of the tools in this analysis implemented their own custom data model to manage raw data."
