# In a 139-classroom scale-up cluster randomized trial (TRIAD), Building Blocks raised end-of-intervention REMA scores with an effect size of 0.55 (improvement index +21)

## Subclaims
`q3 i2` Hofer et al. (2013), a cluster randomized controlled trial with 1,714 children in 139 preschool classrooms, found a statistically significant effect of Building Blocks on the REMA (effect size 0.55, improvement index +21, p < 0.01). [→ study-2013](#study-2013)
