# Exploratory heat maps reveal three student groups, including disengaged-but-successful students more prevalent in the Python courses, showing low content completion can link to both positive and negative outcomes

## Subclaims
`q2 i?` Course-level heat maps showed disengaged at-risk students in all courses and disengaged successful students mainly in Beginners Python and Intermediate Python; module-level maps additionally showed engaged high-performers. [→ Vincent Zhang 2025](#vincent-zhang-2025)

## Evidence

### Vincent Zhang 2025

Vincent Zhang, Bryn Jeffries, Irena Koprinska. (2025). A Machine Learning Approach for Predicting Student Progress in Online Programming Education. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-025-00510-9

`q2 · i?` · `associational · r2`

Exploratory data analysis plotting course-level and module-level heat maps of problem versus content slide completion (Figs. 5-6), comparing Beginners Python against Beginners Blockly, which share the same slides. The article defines three student groups by slide-completion ranges (Table 2).

> "We observe that there is a higher density of disengaged but successful students in the top-left of the Beginners Python heat map. This result provides useful context for modelling student progress — a lack of content slide completion can be linked to both positive outcomes (high problem slide completion) and negative outcomes (low problem slide completion)."
