# Time of day of encoding (9am vs 9pm) has no effect on training performance or initial memory for either word pair type

## Subclaims
`q3 i?` At 30 min retest, a 2x2 ANOVA revealed no effect of Condition (Morning vs Evening), no effect of Word-pair type, and no interaction. [→ Payne JD 2012](#payne-jd-2012)

## Evidence

### Payne JD 2012

Payne JD, Tucker MA, Ellenbogen JM, Wamsley EJ, Walker MP, Schacter DL, Stickgold R. (2012). Memory for Semantically Related and Unrelated Declarative Information: The Benefit of Sleep, the Cost of Wake. PLoS ONE 7(3): e33079. https://doi.org/10.1371/journal.pone.0033079

`q3 · i?` · `causal · r2`

Null result from the 30 min retest condition (N = 60): performance was not influenced by morning vs evening encoding, and initial memory at 30 min was the same regardless of word pair type. Equivalence was not formally tested.

> "A2 62 ANOVA with Condition (Morning, Evening) and Word-pair type (Related, Unrelated) as between-subjects factors revealed no effect of Word-pair type (F 1,56 = 0.20, p = .89) or Condition (F1,56 = 1.05, p = .31), nor a Condition 6Word-pair type interac-tion (F 1,56 = 0.47, p = .50)"
