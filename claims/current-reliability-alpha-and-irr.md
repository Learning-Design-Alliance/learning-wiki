## Evidence

### Charles Baily 2017

Charles Baily, Qing X. Ryan, Cecilia Astolfi and Steven J. Pollock. (2017). Conceptual Assessment Tool for Advanced Undergraduate Electrodynamics. PHYS. REV. – PHYS. ED. RES. [doi:10.1103/physrevphyseducres.13.020113](https://doi.org/10.1103/physrevphyseducres.13.020113)

`q2 · i?` · `design · r3`

Internal-consistency analysis of the full N=500 data set using Cronbach's alpha. A more conservative computation treating each question (including all subparts) as a single item yielded α=0.70; the authors argue the values are likely underestimates because the test is not unidimensional.

> "By treating each subpart (e.g., 1a, 1b, etc.) as individual test items, we obtained α=0.74 (N=500), where α-values between 0.7-0.9 are normally considered adequate"

### Charles Baily 2017 (2)

Charles Baily, Qing X. Ryan, Cecilia Astolfi and Steven J. Pollock. (2017). Conceptual Assessment Tool for Advanced Undergraduate Electrodynamics. PHYS. REV. – PHYS. ED. RES. [doi:10.1103/physrevphyseducres.13.020113](https://doi.org/10.1103/physrevphyseducres.13.020113)

`q2 · i?` · `design · r3`

Inter-rater reliability study in which 90 version-4 exams (CU N=47, a 4-yr college N=43) were scored independently by two raters after brief discussion of 11 training exams. Raters agreed on individual total scores to within ±5% for 86% of students; Cohen's κ for all sub-questions was substantial or better.

> "The inter-rater reliability for the two raters work ing independently was very high; the average total score for the entire data set differed by only 0.2% (0.1% after discussion)."
