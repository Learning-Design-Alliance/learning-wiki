## Evidence

### Weaver K. F. 2016

Weaver K. F., Morales V., Nelson M., Weaver P. F., Toledo A., Godde K. (2016). The Benefits of Peer Review and a Multisemester Capstone Writing Series on Inquiry and Analysis Skills in an Undergraduate Thesis. CBE—Life Sciences Education. https://doi.org/10.1187/cbe.16-01-0072

`q2 · i?` · `causal · r1`

Randomized complete block design ANOVAs on composite scores with ethnicity, Hispanic identity, and legacy as blocks; Hispanic identity (block F value = 0.19, p value = 0.6682) and legacy (block F value = 0.03, p value = 0.9917) showed the same pattern of no block association.

> "It can be concluded that there was no significant correlation with ethnicity in these data (treatment F value = 22.84, df = 1, p value ≤ 0.0001; block F value = 0.48, df = 4, p value = 0.7526)"
