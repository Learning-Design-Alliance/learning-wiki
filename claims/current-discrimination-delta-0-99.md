## Subclaims

## Evidence

### Charles Baily 2017

Charles Baily, Qing X. Ryan, Cecilia Astolfi and Steven J. Pollock. (2017). Conceptual Assessment Tool for Advanced Undergraduate Electrodynamics. PHYS. REV. – PHYS. ED. RES. [doi:10.1103/physrevphyseducres.13.020113](https://doi.org/10.1103/physrevphyseducres.13.020113)

`q2 · i?` · `design · r3`

Discrimination analysis of the N=500 score distribution. Because no standard method exists for open-ended tests, the authors computed Ferguson's delta two ways (points as items; scoring elements dichotomized) and obtained δ=0.99 both times, indicating substantial discriminatory power.

> "We obtained δ=0.99 using both methods. The possible range of δ values is [0,1]. Traditionally, δ >0.9 is considered good discrimination"

### Charles Baily 2017 (2)

Charles Baily, Qing X. Ryan, Cecilia Astolfi and Steven J. Pollock. (2017). Conceptual Assessment Tool for Advanced Undergraduate Electrodynamics. PHYS. REV. – PHYS. ED. RES. [doi:10.1103/physrevphyseducres.13.020113](https://doi.org/10.1103/physrevphyseducres.13.020113)

`q2 · i?` · `design · r3`

Item-test correlation analysis using Pearson correlations of each question with the rest of the test (item excluded), since point-biserial applies only to dichotomous items. All six questions fell between 0.32 and 0.47, above the ~0.2 minimum generally considered acceptable.

> "The correlation coefficient for each of the six questions ranged from 0.32 and 0.47"
