Pooriya Jamie, Reyhaneh Hajihashemi, and Sharareh Alipour. (2025). Utilizing ChatGPT in a Data Structures and Algorithms Course: A Teaching Assistant's Perspective. CHI EA '25. https://doi.org/10.1145/3706599.3720291

`q2 · i?` · `causal · r1`

Qualitative evaluation of ChatGPT's responses across theoretical and practical DSA questions, verified by the TA across accuracy, depth, novel scenarios, visual representation, and code generation. The article reports ChatGPT "often producing incomplete or incorrect solutions" for complex topics.

> "ChatGPT struggled with topics like dynamic programming and recursion, often producing incomplete or incorrect solutions. For example, it generated misleading graphs for sorting algorithms and failed to adapt code for specific complexities."

### Pooriya Jamie 2025 (2)

Pooriya Jamie, Reyhaneh Hajihashemi, and Sharareh Alipour. (2025). Utilizing ChatGPT in a Data Structures and Algorithms Course: A Teaching Assistant's Perspective. CHI EA '25. https://doi.org/10.1145/3706599.3720291

`q2 · i?` · `causal · r1`

The same limitation analysis, informed by feedback from students and professors who used ChatGPT, found code that was "syntactically correct but prone to logical errors" in advanced tasks; explanations for algorithms like Dijkstra's were too abstract.

> "Generated code was syntactically correct but prone to logical errors, particularly in advanced tasks. Issues in hashing techniques and optimization problems like the knapsack problem highlighted gaps in its ability to break down complex steps comprehensibly."
