Paired pre/post tests for the Minimally-invasive Assistance baseline group in the same user study. Neither outcome showed reliable change: lap time p = 0.62 (dz = -0.15), failure count p = 0.38 (dz = -0.28); both printed effect sizes fall below d = 0.2-equivalent negligible magnitude or are non-significant.
