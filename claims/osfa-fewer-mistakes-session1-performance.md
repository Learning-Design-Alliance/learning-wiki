Preliminary robust ANOVA on performance (errors per assessment) found design's main effect nonsignificant (F(1 24.8985) = 0.9042; p = 0.35) but the design-by-session interaction statistically significant (p = 0.0041); post hoc Yuen's tests showed the session-1 difference described in "made fewer mistakes per assessment item". No effect size was printed.

> "The results provide evidence that participants of the OSFA condition made fewer mistakes per assessment item (M = 0.964; SD = 0.509) than those of the Personalized condition (M = 1.19; SD = 0.459)."
