## Evidence

### Spitzer Markus Wolfgang Hermann 2023

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Post-hoc logistic mixed model on data collected before school closures, with computed problem sets as covariate. The assignment effect favoured single problem sets over entire books; more computed assignments predicted lower completion (b = -0.01; z = -3.00; p = .003).

> "Results of this logistic mixed model revealed a significant effect of assignment (b = 0.15; z = 5.16; p < .001), with higher completion rates on single problem set assignments compared to entire book assignments."

### Spitzer Markus Wolfgang Hermann 2023 (2)

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Pre-closure post-hoc model contrasting single versus self-selected assignments on completion: no significant assignment effect, so the single-versus-self-selected advantage emerged specifically during closures.

> "The post-hoc analysis on the main effect of assignment before school closures was not significant (b = -0.45; z = -1.85; p = .064)."
