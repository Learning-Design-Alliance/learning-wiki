Sara Hiller · Stefan Rumann · Kirsten Berthold · Julian Roelle. (2020). Example-based learning: should learners receive closed-book or open-book self-explanation prompts? Instructional Science. https://doi.org/10.1007/s11251-020-09523-4

q2 · i? · causal · r2

Exploratory mediation analysis with Hayes' PROCESS macro (10,000 bootstrap samples) in Experiment 1's no-active-processing groups; the indirect effect "a × b = 3.46 [0.09, 8.31]" gave open-book learners a 3.46-unit advantage via self-explanations.

Related Claims¶

  • Closed-book self-explanation prompts reduce the number of generated self-explanations when learners are not prompted to actively process the instructional explanations beforehand — related
  • Closed-book prompts reduce immediate posttest performance only when learners were not prompted to actively process the instructional explanations — related
  • Both open and assisting self-explanation prompts foster procedural knowledge when learning with multiple representations, an effect mediated by self-explanations directed to domain principles — related
