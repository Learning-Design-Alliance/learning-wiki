# Context-personalized learning material improves learning performance in a t-test but the ANOVA main effect is marginal, making the evidence mixed

## Subclaims
`q3 i1` A one-tailed t-test showed personalized-material students outperformed standard-material students (d = 0.37), but the ANOVA main effect of learning material was not significant. [→ Osman Tasdelen 2025](#osman-tasdelen-2025)

## Evidence

### Osman Tasdelen 2025

Osman Tasdelen, Daniel Bodemer. (2025). Generative AI in the Classroom: Effects of Context-Personalized Learning Material and Tasks on Motivation and Performance. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-025-00491-9

`q3 · i1` · `causal · r2`

Learning-performance analyses in the classroom experiment: personalized-material students (M = 4.97, SD = 2.40) outscored standard-material students (M = 4.04, SD = 2.67), "t(112) = 1.96, p = .027, d = 0.37", while the ANOVA main effect missed significance.

> "The ANOV A revealed no main effect of learning material, F(1, 112) = 3.82, p = .053,η 2 p = .03. However, a one-tailed t-test revealed a signiﬁcant difference in the hypothesized direction, t(112) = 1.96, p = .027, d = 0.37"
