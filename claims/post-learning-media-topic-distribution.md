## Evidence

### Rohaeti 2019

Rohaeti, E.E., Bernard, M., & Primandhika, R.B. (2019). Developing interactive learning media for school level mathematics through open-ended approach aided by Visual Basic application for Excel. Journal on Mathematics Education, 10(1), 59-68. https://eric.ed.gov/?id=EJ1204890

`q2 · i?` · `causal · r1`

Descriptive analysis of the learning media produced after the open-ended VBA-based course. The article reports that "60% of students were able to use shapes to be given a command to run the result of the code", plus 51.43% explaining prop creation, 42.8% geometry props, 28.57% arithmetic props, and 20% making games.

> "60% of students were able to use shapes to be given a command  to run the result of the code they made using VBA for Excel. 20% of students can make games in Microsoft Excel. 51.43% of students were able to explain to create props using Microsoft Excel"
