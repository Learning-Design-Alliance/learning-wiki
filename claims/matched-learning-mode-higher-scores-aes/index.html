Evidence¶

Surjono 2015¶

Herman Dwi Surjono. (2015). The Effects of Multimedia and Learning Style on Student Achievement in Online Electronics Course. TOJET: The Turkish Online Journal of Educational Technology, 14(1). https://eric.ed.gov/?id=EJ1057334

q3 · i? · causal · r2

Multilevel analysis of repeated test scores within the AES experimental group (34 of 67 randomly assigned students), comparing actual printed-questionnaire preferences with the ls and mm values stored in each student's profile; the null hypothesis was rejected at p = 0.05. No effect size is printed.

"It can be concluded that students who study using the AES system in which their learning mode is suited have higher test score at repeat 0, repeat 1 and repeat 2 than students who study using the same system in which their learning mode is not suited."
