q2 · i? · qualitative · r?

Coding of 1,286 initial incorrect prompts (half of all incorrect first prompts per problem) for missing elements such as function return type and argument names. The authors interpret omissions as "suggesting both a failure to acknowledge their importance and over-reliance on AI to infer them"; frequencies are printed per problem in Table 3.

"Common errors were omit- ting aSpecified Function Return TypeorSpecified Argument Namesfrom a prompt across most of the problems. The results sug- gested that omissions often co-occurred."

Discussion¶

Related Claims¶

  • When prompts failed, students most commonly reported clarifying intent or specifying more detail, and reflecting on the problem depiction, rather than tracing code or examining test cases — related
  • Missing prompt-element types significantly co-occur: failure to provide appropriate functionality explanation correlates strongly with missing expected output/return and with extraneous elements — related
  • Correlations between the number of prompt mistakes and number of messages sent were non-significant or weak, giving little evidence that mistake count influenced prompting effort — related
