Linear mixed modeling comparison of use patterns and scores across the same 1,393-map observational dataset, contrasting group C (first-attempt correct) with group W (correct after multiple attempts). The article states the only significant difference "was a lower score for the differential diagnoses in group W"; no effect size is printed, so the finding is reported as a tested non-significant set of contrasts otherwise.
