# Animated-media instruction (video or animation-enriched VP) yields better adherence to temporal demands of PBLS than static-media VP in a randomized trial

## Subclaims
`q3 i?` Self-instruction with animated media (video group 64.5±26.3 and animation-enriched VP group 50.7±25.7) resulted in better adherence to temporal demands than static-media VP (23.8±21.0), with very large effect sizes reported. [→ Lehmann Ronny 2019](#lehmann-ronny-2019)

## Evidence

### Lehmann Ronny 2019

Lehmann Ronny, Lutz Thomas, Helling-Bakki Astrid, Kummer Sebastian, Huwendiek Sören, Bosse Hans Martin. (2019). Animation and interactivity facilitate acquisition of pediatric life support skills: a randomized controlled trial using virtual patients versus video instruction. BMC Medical Education. https://doi.org/10.1186/s12909-018-1442-5

`q3 · i?` · `causal · r2`

Three-group randomized trial (N=103 fifth-year medical students; Vid N=37, VPanim N=35, VPstat N=31) with blinded video rating of PBLS demonstrations. Domain means were 64.5±26.3 (Vid), 50.7±25.7 (VPanim), 23.8±21.0 (VPstat); "Post hoc tests revealed superior and highly significant differences for both groups using animated media" versus static VP. No effect size value is printed in the quoted passage.

> "Statistical significant differences were found between groups for adherence to temporal demands with F(2,100) = 23.540, p < 0.001. Post hoc tests revealed superior and highly significant differences for both groups using animated media (group Vid and VPanim) compared with group VPstat. Here, very large effect sizes were found."
