# In multimodal collaboration, the whiteboard primarily represents the state of problem solving while chat grounds whiteboard content, contrary to the expectation that schemata on the whiteboard would disambiguate chat utterances

## Subclaims
`q2 i?` The whiteboard is primarily used to represent the state of problem solving and the chat is used for grounding information created on the whiteboard, rather than the whiteboard disambiguating chat utterances. [→ Pierre Dillenbourg 2006](#pierre-dillenbourg-2006)

## Evidence

### Pierre Dillenbourg 2006

Pierre Dillenbourg, David Traum. (2006). Sharing solutions: persistence and grounding in multi-modal collaborative problem solving. The Journal of the Learning Sciences, 15 (1), pp.121-151. https://doi.org/10.1207/s15327809jls1501_9

`q2 · i?`

Exploratory study of grounding and problem solving in multimodal computer-mediated collaboration comparing a shared whiteboard and a MOO text chat. The reported result contradicts the expectation: "the whiteboard is primarily used to represent the state of problem solving and the chat is used for grounding information created on the whiteboard."

> "It was expected that the whiteboard would serve to draw schemata that disambiguate chat utterances. Instead, results show that the whiteboard is primarily used to represent the state of problem solving and the chat is used for grounding information created on the whiteboard."
