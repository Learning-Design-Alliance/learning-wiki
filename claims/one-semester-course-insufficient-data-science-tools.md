## Evidence

### Jozef Hanˇc 2020

Jozef Hanˇc, Peter ˇStrauch, Eva Paˇnkov´a and Martina Hanˇcov´a. (2020). Teachers' perception of Jupyter and R Shiny as digital tools for open education and science. [doi:10.48550/arXiv.2007.11262](https://doi.org/10.48550/arXiv.2007.11262)

`q2 · i?` · `qualitative · r2`

Qualitative case study of N=9 PER Ph.D. candidates, combining content analysis of theses and short interviews in phase one (May-June 2017). The authors state that "a one-semester long course in using data science tools ... is not enough"; Excel remained the main analysis tool.

> "a one-semester long course in using data science tools for Ph.D. PER candidates in the context of advanced statistical methods is not enough to start using them as main tools in their own research and analysis."
