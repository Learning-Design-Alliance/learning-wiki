Evidence¶

Feng Z and Huang K 2026¶

Feng Z and Huang K (2026) Bayesian cognitive diagnosis optimizes personalized learning paths via mediation of cognitive load and Hidden Markov Model state transitions. Front. Psychol. 17:1879982. https://doi.org/10.3389/fpsyg.2026.1879982

q3 · i3 · causal · r2

Randomized experiment with 120 undergraduates assigned 1:1 to personalized or fixed-order paths over the same probability-theory content. The personalized group's "average learning time ... 57.6 min" versus 73.8 min yielded d = 1.52 and a 22.0% time saving.

"the average learning time for students following personalized path 57.6 min (SD = 12.0), compared to 73.8 min (SD = 8.5) for the control group, a signiﬁcant diﬀerence (t = 8.22, p < 0.001, d = 1.52). The time saving was 16.2 min (22.0%)."

Feng Z and Huang K 2026 (2)¶

Feng Z and Huang K (2026) Bayesian cognitive diagnosis optimizes personalized learning paths via mediation of cognitive load and Hidden Markov Model state transitions. Front. Psychol. 17:1879982. https://doi.org/10.3389/fpsyg.2026.1879982

q3 · i2 · causal · r2

ANCOVA on post-test scores (20 items) with pre-test as covariate in the same 120-participant randomized experiment; baseline pre-test scores did not differ (t = 0.52, p = 0.604). The printed effect size is "η2 = 0.065".

"the experimental group signiﬁcantly outperformed the control group on the post-test after controlling for pre-test performance (F = 8.24, p = 0.005, η2 = 0.065)"
