## Evidence

### Permzadian 2024

Permzadian, V., & Shen, T. (2024). Assessing the predictive validity of expectancy theory for academic performance. BMC Psychology, 12. https://doi.org/10.1186/s40359-024-01935-y

`q3 · i?` · `associational · r2`

Within-person MLM on grades (L1 = 492 course observations within 123 students) with cognitive ability as covariate in incremental models; simplified force model γ20 = 0.035, p < .05, pseudo R2 = .011. Only pseudo R2 printed.

> "These hypotheses were also supported as the simplified force model (γ20 = 0.035, p < .05, pseudo R2 = .011) was positively associated with course grades and accounted for incremental variance (see Table 5, Model 3b and 4b)."

### Permzadian 2024 (2)

Permzadian, V., & Shen, T. (2024). Assessing the predictive validity of expectancy theory for academic performance. BMC Psychology, 12. https://doi.org/10.1186/s40359-024-01935-y

`q3 · i?` · `associational · r2`

Directly measured valence for an A grade (±10 scale) predicted grades in the same MLM framework, γ20 = 0.056, p < .01, pseudo R2 = .022, with incremental validity beyond SAT-based cognitive ability. No standardised effect size.

> "In support of these hypotheses, valence (γ20 = 0.056, p < .01, pseudo R2 = .022) was positively associated with grades and accounted for incremental variance (see Table 5, Model 3a and 4a)."
