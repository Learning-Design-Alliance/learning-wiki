# Professionals showed no statistically significant rating differences between ad-hoc and predefined prompt tools, partly because some used the Docstring keyword

## Subclaims
`q2 i?` Among professionals, no statistically significant differences were found between the ad-hoc and predefined prompt groups on the documentation quality dimensions. [→ Hans-Alexander Kruse 2024](#hans-alexander-kruse-2024)
`q2 i?` Professionals used the Docstring keyword in ad-hoc prompts more often than students, and such prompts produced documentation similar to the predefined prompt tool. [→ Hans-Alexander Kruse 2024 (2)](#hans-alexander-kruse-2024-2)

## Evidence

### Hans-Alexander Kruse 2024

Hans-Alexander Kruse, Tim Puhlfürß, Walid Maalej. (2024). Can Developers Prompt? A Controlled Experiment for Code Documentation Generation. [doi:10.1109/icsme58944.2024.00058](https://doi.org/10.1109/icsme58944.2024.00058)

`q2 · i?` · `causal · r2`

Subgroup analysis of the controlled experiment's MWU tests for the ten professionals per group. The article notes the small sample size as a possible reason and reports large effect sizes for Readability (4.3/4.8 and 4.0/4.8) and Unnecessary Information (3.1/4.4).

> "Among the professionals, we found no statistically significant differences between the ad-hoc and predefined prompt groups. However, three dimensions showed large effect sizes (≥ 0.8), indicating a practical significance."

### Hans-Alexander Kruse 2024 (2)

Hans-Alexander Kruse, Tim Puhlfürß, Walid Maalej. (2024). Can Developers Prompt? A Controlled Experiment for Code Documentation Generation. [doi:10.1109/icsme58944.2024.00058](https://doi.org/10.1109/icsme58944.2024.00058)

`q2 · i?` · `causal · r2`

Analysis of the 50 successful ad-hoc prompts collected in the experiment (Table I). The article states that as professionals used the Docstring keyword more often, the ad-hoc prompts in these cases resulted in documentation similar to the predefined prompt tool.

> "Professionals used the Docstring term more often (9x) than students (3x), which is in line with the higher Python experience of most participating professionals."
