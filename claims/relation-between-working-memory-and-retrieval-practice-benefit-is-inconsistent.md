# Studies disagree on whether low or high working memory learners benefit more from retrieval practice, and several find no relationship

> **Claim** · [All claims](index.md)
> **Evidence** · 3 studies · `q2` quasi-experiment

## Subclaims
`q2 i?` The chapter reports, citing Agarwal et al. (2016), that low working memory subjects benefited more from retrieval practice than high working memory subjects. [→ Karpicke 2017](#karpicke-2017)
`q2 i?` The chapter reports, citing Tse and Pu (2012), the opposite pattern, with high working memory subjects benefiting more. [→ Karpicke 2017 (2)](#karpicke-2017-2)
`q2 i?` The chapter reports, citing Brewer and Unsworth (2012), that working memory and attentional control were unrelated to benefits, while low episodic memory subjects showed larger effects. [→ Karpicke 2017 (3)](#karpicke-2017-3)
