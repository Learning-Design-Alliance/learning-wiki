A follow-up McNemar analysis by gender found "no significant difference for females, χ2 (1, 23) = .006, p = .388, but a significant difference, χ2 (1, N = 26) = 2.006, p = .031, for the males".

"A subsequent analysis of more-traditional-in-school versus more-interactive-in-school by gender reveals no significant difference for females, χ2 (1, 23) = .006, p = .388, but a significant difference, χ2 (1, N = 26) = 2.006, p = .031, for the males."
