# In NSLM, students' prior expectations (S3) are associated with a larger estimated effect only when average school-level mindset is sufficiently high, and this interaction pattern disappears under a linear model.

## Subclaims
`q2 i?` S3 (student's expectations) appears associated with a larger effect only if the average mindset of the school is sufficiently high; this non-linear interaction is not captured by a linear model. [→ Fredrik D. Johansson 2018](#fredrik-d-johansson-2018)

## Evidence

### Fredrik D. Johansson 2018

Fredrik D. Johansson. (2018). Machine Learning Analysis of Heterogeneity in the Eﬀect of Student Mindset Interventions. arXiv preprint. [doi:10.48550/arXiv.1811.05975](https://doi.org/10.48550/arXiv.1811.05975)

`q2 · i?` · `associational · r2`

Post-workshop regression tree fit to pairs of covariates on imputed CATEs, with leaves required to contain at least 1000 students; the tree revealed this interaction while the linear model did not. High-variance school-level patterns are emphasized by the authors.

> "In the right-hand ﬁgure,S3 (student’s expectations) appears associated with a larger eﬀect only if the average mindset of the school is suﬃciently high. This pattern disappears when using a linear model."
