# Cueing did not reduce learners' self-rated cognitive load in the immersive VR dual-task environment

## Evidence

### Daniela Decker 2025

Daniela Decker, Martin Merkt. (2025). Look at me! Can a pedagogical agent facilitate orientation and support learning in VR? Education Tech Research Dev. https://doi.org/10.1007/s11423-025-10531-9

`q3 · i?` · `causal · r2`

Explorative cognitive load evaluation using the Andersen and Makransky (2021) VR-adapted scale in the 91-participant experiment found "no observed effects of cueing on intrinsic cognitive load" or germane load; extraneous load subscales for environment and instruction showed F < 1, and interaction load was non-significant (p =.070).

> "Specifically, there were no observed effects of cueing on intrinsic cognitive load (M = 3.32, SD = 2.59), F < 1, germane cognitive load (M = 3.45, SD = 2.47), F(2, 88) = 1.34, p = 0.268, ηp2 =.03"
