Simulation analysis of value-added estimation error using OLS and Empirical Bayes estimators applied to student test score gain data in the upper elementary grades. The abstract concludes estimates are "likely to be noisy" with typically available data.

> "Simulation results suggest that value-added estimates are likely to be noisy using the amount of data that are typically used in practice."
