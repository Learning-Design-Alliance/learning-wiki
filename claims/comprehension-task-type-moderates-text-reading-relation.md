## Evidence

### Leachman 2025

Leachman, M., Wolters, A., & Kim, Y.-S. G. (2025). The Relation Between Text Reading and Reading Comprehension Varies as a Function of Developmental Phase, Orthographic Depth, and Measurement Characteristics: Evidence From a Meta-Analysis. Journal of Educational Psychology. https://doi.org/10.1037/edu0000932

`q4 · i1` · `quant-synthesis · r2`

Meta-regression (Table 5) comparing reading comprehension task types, controlling for grade level (and orthographic depth for multiple-choice); β = −.17 for the written open-ended task and β = −.20 for retell, with null differences for cloze and oral open-ended.

> "the relation was weaker for the written open-ended task (β = −.17, p < .01) and retell task (β = −.20, p < .001) but the relation did not differ for the cloze task (β = .02, p = .50) and oral open-ended task (β = −.05, p = .23)."
