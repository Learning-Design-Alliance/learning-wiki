Evidence¶

Dawid Ratajczyk 2026¶

Dawid Ratajczyk, Agata Dymarska, Adam Matłoka, Michał Tomczyk, Małgorzata Wiącek. (2026). Thinking With AI, Reasoning Without It: Cognitive Offloading to Generative AI Weakens Effort Regulation. Preprint. https://osf.io/59qtm/ doi:10.31234/osf.io/83jum_v1

q3 · i0 · causal · r2

Preregistered 2×2 ANOVA on the 10-item Stage 3 memory test in the lab experiment; overall memory performance was M = 57.5% (SD = 17.6%). The quoted tests show negligible effects (η²p = .001 and η²p < .001), providing no support for H3.

"There was no significant main effect of prior genAI access (𝐹(1,153) = 0.095,𝑝=.758,𝜂 2 𝑝 =.001) and no significant main effect of incentives (𝐹(1,153) = 0.022,𝑝=.882,𝜂 2 𝑝 < .001)."
