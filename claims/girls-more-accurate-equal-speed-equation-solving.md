## Evidence

### Susac A 2014

Susac A, Bubic A, Vrbanc A and Planinic M (2014) Development of abstract mathematical reasoning: the case of algebra. Front. Hum. Neurosci. 8:679. https://doi.org/10.3389/fnhum.2014.00679

`q3 · i1` · `associational · r1`

Two-way ANOVA (Age × Gender) on accuracy in the computerized equation test; printed effect size η2 p = 0.019 for the Gender main effect. "On average, girls were more accurate than boys."

> "a statistically signiﬁcant main effect of Age [F(3,323) = 9.43, p < 0.001, η2 p = 0.081] and Gender [ F(1,323) = 6.40, p < 0.05, η2 p = 0.019]"

### Susac A 2014 (2)

`q3 · i?` · `associational · r2`

Same ANOVA design on reaction times: the Gender main effect was not statistically significant (F(1,322) = 0.09); no meaningful effect size printed, so no speed difference was detected.

> "The main effect of Gender was not statistically signiﬁcant for RT s [F(1,322) = 0.09, p > 0.05, η2 p < 0.0001]"
