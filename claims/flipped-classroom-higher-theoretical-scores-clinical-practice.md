`q2 · i?` · `quant-synthesis · r3`

Meta-analysis of 18 RCTs (1,460 participants) using random effect models due to high heterogeneity (I2 = 98%, P < 0.001). The pooled effect size had "a significant difference between the two groups (SMD = 8.33, 95% CI: 5.91–10.75, P < 0.001)". No standardised effect size interpretation is possible given the extreme value.
