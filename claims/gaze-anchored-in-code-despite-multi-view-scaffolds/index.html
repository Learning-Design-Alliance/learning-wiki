gaze-dwell¶

Naaz Sibia, Jessica Wen, Amber Richardson, Yashika Jain, Khushi Malik, Bogdan Simion, Carolina Nobre, Angela Zavaleta Bernuy, Andrew Petersen, and Michael Liut. 2026. Code as Anchor, Memory and Metaphor as Support: Learner Experiences with Multi-View Visualizations. ICER 2026 Vol. 1. https://doi.org/10.1145/3765964.3811662

q2 · i? · associational · r1

Descriptive webcam gaze analysis (WebGazer.js) of 19 undergraduates' dwell time across the three AOIs of the multi-representational tool during scope, while-loop, and linked-list tasks. The article reports "Memory engagement peaked in linked-list tasks (47% median)" and metaphor peaked in loop tasks. No effect size is printed for the overall distribution.

"Overall, Code drew a median 47% of attention, Memory 34%, and Metaphor 9%. This pattern was task-dependent: Memory engagement peaked in linked-list tasks (47% median), while Metaphor gained traction in loop tasks (19% median)."
