Evidence¶

Emmanuel Ayedoun 2018¶

Emmanuel Ayedoun, Yuki Hayashi, Kazuhisa Seta. (2018). Adding Communicative and Affective Strategies to an Embodied Conversational Agent to Enhance Second Language Learners' Willingness to Communicate. Int J Artif Intell Educ. https://doi.org/10.1007/s40593-018-0171-6

q3 · i? · causal · r?

The authors' summary of the pilot study's three-version comparison notes that the AB-only version showed some WTC-enhancing potential; the marginal pairwise result (Group 3's confidence versus Group 2's, p = 0.077) is consistent with this hedged statement. No effect size is printed for the AB-only effect itself.

"We also found that even the AB-only version of the system had the potential to enhance WTC to some extent."
