Evidence¶

Mehak Maniktala 2020¶

Mehak Maniktala, Christa Cody, Tiffany Barnes, Min Chi. (2020). Avoiding Help Avoidance: Using Interface Design Changes to Promote Unsolicited Hint Usage in an Intelligent Tutor. https://arxiv.org/abs/2009.13371

q3 · i? · causal · r2

Same 100-student tutor study; the ART ANOVA on unsolicited hints given showed a main effect of Condition (F(1,100) = 40.26, p < 0.001). Table 1 reports means of 48.82 (Assertions) vs 32.74 (Messages). The article notes the difference was expected "because of the system design" since Assertions were delivered after about 40% of steps; no effect size is printed.

"For the #Given metric, we found a signiﬁcant main eﬀect of Condition (F(1,100) = 40.26, p < 0.001). While we expected this result because of the system design, we will discuss this further in the next section."
