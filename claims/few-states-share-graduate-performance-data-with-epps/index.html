Evidence¶

Data Quality Campaign 2017¶

Data Quality Campaign. (2017). Using Data to Ensure That Teachers Are Learner Ready on Day One. https://eric.ed.gov/?id=ED586474

q2 · i? · review · r1

The brief cites a 2016 report on state EPP accountability practices, stating that "only 10 states include educator preparation program (EPP) graduates' observed performance as teachers of record as an indicator in their program review." No effect size is printed.

"The Council of Chief State School Officers and Teacher Preparation Analytics' 2016 report on EPP accountability found that only 10 states include educator preparation program (EPP) graduates' observed performance as teachers of record as an indicator in their program review."

Data Quality Campaign 2017 (2)¶

Data Quality Campaign. (2017). Using Data to Ensure That Teachers Are Learner Ready on Day One. https://eric.ed.gov/?id=ED586474

q2 · i? · theoretical · r1

The brief cites its organization's 2014 Data for Action survey of states, which found that "only 22 states report sharing teachers' classroom performance annually with in-state EPPs." No effect size is printed.

"The Data Quality Campaign's 2014 Data for Action survey found that only 22 states report sharing teachers' classroom performance annually with in-state EPPs."

Data Quality Campaign 2017 (3)¶

Data Quality Campaign. (2017). Using Data to Ensure That Teachers Are Learner Ready on Day One. https://eric.ed.gov/?id=ED586474

q2 · i? · review · r1

The brief attributes to Deans for Impact a survey of program leaders in which "only 6 out of 23 surveyed program leaders have access to data on teacher performance as measured by students' academic performance." No effect size is printed.

"According to Deans for Impact, only 6 out of 23 surveyed program leaders have access to data on teacher performance as measured by students' academic performance."
