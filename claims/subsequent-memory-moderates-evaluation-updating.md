Item-level Bayesian linear mixed model on immediate evaluation change revealed a significant subsequent-memory by feedback interaction (median = 2.94, 95% HDI [1.93, 3.85]). "when participants correctly remembered the feedback direction" higher feedback produced larger increases; with incorrect memory the pattern reversed (mediandiff = −1.54).
