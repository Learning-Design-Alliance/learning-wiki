# In a non-adaptive e-learning system, students whose learning mode matches the presentation mode achieve higher test scores than mismatched students

## Subclaims
`q3 i?` Students using the NON-AES whose actual learning mode preferences are suited to the system's fixed default (sequential, non-multimedia) score higher at repeat 0 and repeat 1 than unsuited students, significant at p = 0.05. [→ Surjono 2015](#surjono-2015)

## Evidence

### Surjono 2015

Herman Dwi Surjono. (2015). The Effects of Multimedia and Learning Style on Student Achievement in Online Electronics Course. TOJET: The Turkish Online Journal of Educational Technology, 14(1). https://eric.ed.gov/?id=EJ1057334

`q3 · i?` · `causal · r1`

Multilevel analysis of repeated test scores within the NON-AES control group (33 of 67 randomly assigned students), comparing suited versus unsuited learning-mode preferences against the fixed sequential non-multimedia default; the null hypothesis was rejected at the significance level of p = 0.05. No effect size is printed.

> "It can be concluded that students who learn using the NON-AES in which their learning mode is suited have higher test score at repeat 0 and repeat 1 than students using the same system in which their learning mode is not suited."
