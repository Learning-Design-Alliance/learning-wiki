q3 · i? · associational · r2

Post-hoc linear model comparison of procedural memory learning scores (last 25 vs. first 25 trials) among 19 lower-SES and 28 higher-SES adolescents who completed the task. The groups "did not signiﬁcantly diﬀer" (p = 0.76); no effect size was printed, so equivalence was not tested.

"the lower-SES group and higher-SES group did not signiﬁcantly diﬀer on their procedur al memory learning score [lower-SES: M = 0.08, SD = 0.22; higher- SES: M = 0.06, SD = 0.19; b = 0.02, t(44) = 0.31, p = 0.76, r2 = −0.04, 95% CI [ −0.11, 0.14]"
