## Subclaims
`q3 i?` ANOVA on pre-survey scores across semesters in six courses found no statistically significant differences after Holm-Bonferroni correction, including for the one class (Class C) that was nominally significant uncorrected. [→ Cole Walsh 2019](#cole-walsh-2019)

## Evidence

### Cole Walsh 2019

Cole Walsh, Katherine N. Quinn, C. Wieman, and N.G. Holmes. (2019). Quantifying critical thinking: Development and validation of the Physics Lab Inventory of Critical thinking (PLIC). [doi:10.1103/physrevphyseducres.15.010135](https://doi.org/10.1103/physrevphyseducres.15.010135)

`q3 · i?` · `design · r3`

Test-retest estimated by comparing pre-survey scores of the same course across semesters in six courses from three institutions, using ANOVA with η² per course. Uncorrected p-values showed no differences except Class C (p = 0.034, η² = 0.021), which did not survive correction.

> "After correcting for multiple testing eﬀects using either the Bonferroni or Holm-Bonferroni method at α < 0.05 signiﬁcance, pre- survey means were not statistically diﬀerent for Class C."
