# Working memory factor relationships are similar across mathematical subdomains at age 9–10, with one exception: the verbal working memory link to operations is higher

## Subclaims
`q3 i?` Constraining betas from each working memory factor to be equal across the mathematics subdomains did not worsen fit, indicating similar relationships across subdomains. [→ Allen 2020](#allen-2020)

## Evidence

### Allen 2020

Allen, K., Giofrè, D., Higgins, S., & Adams, J. (2020). Using working memory performance to predict mathematics performance 2 years on. Psychological Research. https://doi.org/10.1007/s00426-020-01382-5

`q3 · i?` · `associational · r2`

Additional SEM analyses at Y5 with the mathematics subdomains (number, operations, fractions, geometry, measures, statistics) entered separately and betas progressively constrained equal; the constrained models had lower AIC and were not statistically different (e.g., Δχ2(5) = 4.38, p = 0.4958), supporting similar betas.

> "These findings taken together indicate that betas from simultaneous, sequential and verbal factors to each individual mathematic subdomain are similar, with only one exception"

### Allen 2020 (2)

Allen, K., Giofrè, D., Higgins, S., & Adams, J. (2020). Using working memory performance to predict mathematics performance 2 years on. Psychological Research. https://doi.org/10.1007/s00426-020-01382-5

`q3 · i?` · `associational · r2`

The best-fitting subdomain model freed the beta from the verbal working memory factor to operations after misfit was detected (Δχ2(5) = 25.55, p = 0.0001 for the fully constrained verbal model). No effect size value is printed for this link.

> "the link between verbal working memory and a specific component (i.e., operations) seemed to be higher as compared with the other tasks."
