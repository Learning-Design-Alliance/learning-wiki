Kang Xue 2020¶

Kang Xue, Victoria Yaneva, Christopher Runyon, Peter Baldwin. (2020). Predicting the difficulty and response time of multiple choice questions using transfer learning. 15th Workshop on Innovative Use of NLP for Building Educational Applications. https://www.nwea.org/research/publication/predicting-the-difficulty-and-response-time-of-multiple-choice-questions-using-transfer-learning/

q2 · i? · associational · r2

In the same modeling study, the authors report that "all parts of the item were important for predicting the response time," contrasting with the stem-based pattern for difficulty; no effect size is printed in the available text.

"In addition, difficulty was best predicted using signal from the item stem (the description of theclinical case), while all parts of the item were important for predicting the response time."
