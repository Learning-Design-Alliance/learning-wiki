Evidence¶

Lester Loschky 1994¶

Lester Loschky. (1994). Comprehensible Input and Second Language Acquisition: What is the Relationship? Studies in Second Language Acquisition, Volume 16, Issue 3, pp. 303-323. https://doi.org/10.1017/S0272263100013103

q3 · i? · causal · r?

In this experimental study, three groups of Japanese learners were differentiated by input and interaction conditions: unmodified input with no interaction, premodified input with no interaction, and unmodified input with the chance for negotiated interaction. The article reports that "moment-to-moment comprehension was highest for the negotiated interaction group." No effect size is printed.

"The results indicated that moment-to-moment comprehension was highest for the negotiated interaction group, whereas there was no significant difference between the two noninteraction groups."
