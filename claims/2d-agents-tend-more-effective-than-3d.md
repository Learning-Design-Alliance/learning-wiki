# 2D pedagogical agents tended to be more effective than 3D agents (g+ = 0.38 vs. g+ = 0.11), as predicted by the redundancy effect and the coherence principle

> **Claim** · [All claims](index.md)

## Subclaims
`q4 i1` 2D agents (g+ = 0.38) tended to be more effective than 3D agents (g+ = 0.11), a pattern the authors attribute to the redundancy effect of cognitive load theory and the coherence principle of cognitive theory of multimedia learning. [→ Castro-Alonso 2021](#castro-alonso-2021)

## Evidence

### Castro-Alonso 2021

`q4 · i1` · `quant-synthesis · r?`

Meta-analytic moderator comparison of agent dimensionality across the pooled effect sizes. Printed moderator effect sizes: g+ = 0.38 for 2D agents versus g+ = 0.11 for 3D agents; the article hedges the difference as a tendency.

> "As predicted by the redundancy effect of cognitive load theory and the coherence principle of cognitive theory of multimedia learning, 2D agents ( g + = 0.38) tended to be more effective than 3D agents ( g + = 0.11)."
