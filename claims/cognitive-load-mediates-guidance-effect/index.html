Evidence¶

Julia Kienzler 2023¶

Julia Kienzler, Thamar Voss, Jörg Wittwer. (2023). Student teachers' conceptual knowledge of operant conditioning: How can case comparison support knowledge acquisition? Instructional Science. https://doi.org/10.1007/s11251-023-09627-7

q3 · i? · causal · r2

Multi-categorical mediation (PROCESS, 5000 bootstrap samples) on the full sample of 181, with input after-key features not provided as reference. Higher germane and lower extraneous load related to higher knowledge; only unstandardized indirect effects printed, so no standardized effect size.

"For germane load as a mediator, the results indicated significant indirect effects a2b = 0.1512, 95% CI [0.046, 0.281] and a 3b = 0.151, 95% CI [0.044, 0.281], but a non-significant indirect effect a 1b = − 0.027, 95% CI [− 0.115, 0.058]."
