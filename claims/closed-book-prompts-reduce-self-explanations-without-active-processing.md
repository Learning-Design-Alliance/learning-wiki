# Closed-book self-explanation prompts reduce the number of generated self-explanations when learners are not prompted to actively process the instructional explanations beforehand

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3` · `i2` medium

## Subclaims
`q3 i2` In Experiment 1, the closed-book format reduced the number of generated self-explanations for learners without active processing prompts (ηp2 = .09) but not for learners with them. [→ Sara Hiller · Stefan Rumann · Kirsten Berthold · Julian Roelle 2020](#sara-hiller-stefan-rumann-kirsten-berthold-julian-roelle-2020)

## Evidence

### Sara Hiller · Stefan Rumann · Kirsten Berthold · Julian Roelle 2020

Sara Hiller · Stefan Rumann · Kirsten Berthold · Julian Roelle. (2020). Example-based learning: should learners receive closed-book or open-book self-explanation prompts? Instructional Science. https://doi.org/10.1007/s11251-020-09523-4

`q3 · i2` · `causal · r2`

ANCOVA on learning processes in Experiment 1 with N = 97 eighth-graders found a significant format × active-processing interaction; the simple effect of prompt format held only for learners without active processing prompts, "F(1, 44) = 4.44, p = .041, ηp2 = .09".

> "Probing the interaction revealed that the closed-book format reduced the number of generated self-explanations for the learners who did not receive active processing of instructional explanation prompts, F(1, 44) = 4.44, p = .041, ηp2 = .09"
