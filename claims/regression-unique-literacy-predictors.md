# Set size, crowding and pre-cue use jointly predict literacy, with set size uniquely predicting spelling and pre-cue use uniquely predicting reading

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r1` · `q2`

## Subclaims
`q2 i?` In simultaneous multiple regressions, the three predictors explained about 70% of variance in spelling and reading, but only set size uniquely predicted spelling and only pre-cue use uniquely predicted reading. [→ Moores 2011](#moores-2011)

## Evidence

### Moores 2011

Moores, E., Cassim, R. and Talcott, J.B. (2011). Adults with dyslexia exhibit large effects of crowding, increased dependence on cues, and detrimental effects of distractors in visual search tasks. Frontiers in Psychology. [doi:10.1016/j.neuropsychologia.2011.10.005](https://doi.org/10.1016/j.neuropsychologia.2011.10.005)

`q2 · i?` · `causal · r1`

Simultaneous multiple regression analyses entering set size, crowding and pre-cue use as predictors. The spelling model explained 69.8% of variance (adjusted R2=.43) with only set size significant (β=-.35, p<.05); the reading model explained 70.9% (adjusted R2=.45) with only pre-cue use significant (β=-.57, p<.05).

> "only set size (β=-.35, t(27)=-2.26, p<.05) accounted for statistically significant unique variance in spelling ability, while measures of crowding (β=-.31,t(27)=-1.30) and pre-cue use (β=-.31,t(27)=1.28) were not significant predictors."
