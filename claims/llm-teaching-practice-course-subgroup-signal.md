Exploratory subgroup analysis within the pooled score-based synthesis, stratified by course type (5 theory vs. 2 practice studies) and learning duration. Only test statistics are printed (Qbetween = 24.31, P = 8.2e-07), so no effect size for the interaction; the practice-course signal was "driven mainly by only two practice-oriented studies".

> "The fixed-effect interaction test for course type suggested a statistical signal (Qbetween = 24.31, P = 8.2e-07), but this result was driven mainly by only two practice-oriented studies and within-group heterogeneity remained high."
