## Evidence

### Weil-Lotan D 2026

Weil-Lotan D, Solnica A, Benbenishty J, Ilsar T. (2026). Does the Addition of Images to the Medication Dosage Calculation Exam Improve Metacognitive Components and Performance? A Randomized Prospective Study. Nurse Educator. https://doi.org/10.1097/NNE.0000000000002215

`q3 · i3` · `causal · r2`

In a randomized controlled trial, 120 nursing students were assigned to an exam with images (n = 63) or without (n = 57). Welch t-test showed the image group scored higher, "with a large effect size (Cohen d = 0.84)."

> "Participants in the image group achieved higher performance scores (M = 7.25, SD = 1.80) than those in the control group (M = 6.00, SD = 1.16). Analysis revealed a statistically significant difference between the groups, t(89.96) = 4.41, P < .001, with a large effect size (Cohen d = 0.84)."
