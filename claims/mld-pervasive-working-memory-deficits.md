# Children with MLD show pervasive working memory deficits while both LA groups score in the average range on all three working memory components

## Subclaims

## Evidence

### Geary 2012

Geary, D. C., Hoard, M. K., & Bailey, D. H. (2012). Fact Retrieval Deficits in Low Achieving Children and Children with Mathematical Learning Disability. Journal of Learning Disabilities, 45(4). https://doi.org/10.1177/0022219410392046

`q3 · i3` · `associational · r2`

First-grade administration of the Working Memory Test Battery for Children to 270 children; ANOVA across the four achievement groups. The study reports the printed effect sizes d = 2.17, 1.25, and 2.67, and that children with MLD scored lower than all other groups on each measure.

> "Overall differences were significant for the phonological loop, F(3, 214) = 15.94, p<.0001, d = 2.17, visuospatial sketch pad, F(3, 214) = 6.25, p<.001, d = 1.25, and central executive, F(3, 214) = 27.28, p<.0001, d = 2.67."
