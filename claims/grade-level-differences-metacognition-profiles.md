# Metacognition profile classifications differ between second and fourth graders

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q2` quasi-experiment

## Subclaims
`q2 i?` Grade level significantly predicted latent profile classification, requiring separate LPAs per age group. [→ Mariëtte van Loon 2024](#mariette-van-loon-2024)

## Evidence

### Mariëtte van Loon 2024

Mariëtte van Loon, Claudia M. Roebers. (2024). Development of metacognitive monitoring and control skills in elementary school: a latent profile approach. Metacognition and Learning. https://doi.org/10.1007/s11409-024-09400-2

`q2 · i?`

In the initial full-sample LPA with grade as an active nominal covariate, the Wald test showed a significant grade effect, χ²(1) = 17.37, p = .002; follow-up LPAs were therefore run separately for each grade. A parallel test at M2 gave χ²(1) = 17.20, p < .001.

> "The Wald test showed a significant effect of the covariate grade level, χ²(1) = 17.37, p = .002, indicating that classification outcomes differed for both age groups"
