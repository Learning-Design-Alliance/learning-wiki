Modeling student test-taking motivation in the context of an adaptive achievement test 2016¶

Modeling student test-taking motivation in the context of an adaptive achievement test. (2016). Journal of Educational Measurement, 53(1), 86–105. https://www.nwea.org/research/publication/modeling-student-test-taking-motivation-in-the-context-of-an-adaptive-achievement-test/

q2 · i? · associational · r?

Response time-based analysis of data from an adaptive achievement test compared observed rapid-guessing patterns to model expectations; the study found behavior "inconsistent with these models, with the exception of the effort‐moderated model." No effect size is printed.

"patterns of observed rapid‐guessing behavior and item response accuracy were compared to the behavior expected under several types of models that have been proposed to represent unmotivated test taking behavior. Test taker behavior was found to be inconsistent with these models, with the exception of the effort‐moderated model."
