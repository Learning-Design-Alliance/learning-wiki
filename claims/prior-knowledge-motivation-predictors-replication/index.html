Evidence¶

Sophia C. Weissgerber 2024¶

Sophia C. Weissgerber, Denia Indah Permatasari Terhorst, Ralf Rummer. (2024). Is the perceptual disfluency effect moderated by working memory capacity? Direct replication of Lehmann et al. (2016). Metacognition and Learning. https://doi.org/10.1007/s11409-023-09366-7

q3 · i? · causal · r2

In the replication's comprehension regression (N = 95), "The only significant predictor for comprehension was prior knowledge (β = 9.19, SE = 2.81, t(85) = 3.27, p = 0.002)". In the transfer model the only significant predictor was likewise prior knowledge (β = 14.06, SE = 3.11, t(83) = 4.52, p < 0.001), and in the retention model it was motivation during learning (β = 7.32, SE = 3.24, t(84) = 2.26, p = 0.026).

"The regression model was significant (F(9, 85) = 3.17, p = 0.002, R2 adj. = 0.17). The only significant predictor for comprehension was prior knowledge (β = 9.19, SE = 2.81, t(85) = 3.27, p = 0.002)."
