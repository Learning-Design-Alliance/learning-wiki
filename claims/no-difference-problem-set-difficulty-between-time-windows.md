## Evidence

### Spitzer Markus Wolfgang Hermann 2021

Spitzer Markus Wolfgang Hermann, Musslick Sebastian (2021). Academic performance of K-12 students in an online-learning environment for mathematics increased during the shutdown of schools in wake of the COVID-19 pandemic. PLoS ONE 16(8): e0255629. https://doi.org/10.1371/journal.pone.0255629

`q3 · i?` · `associational · r2`

Linear mixed model on the within-group cohort, operationalizing assigned problem set difficulty as the average error rate of the pre-pandemic reference group on each problem set. There was "no statistically significant difference between the two time windows on problem set difficulty"; equivalence was not tested.

> "There was no statistically significant difference between the two time windows on problem set difficulty (b = -1.08e-03; t = -0.56; p = .574)."
