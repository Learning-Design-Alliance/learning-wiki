# Control groups show no significant pre-to-post change in visual discrimination thresholds, indicating the two blocks did not interact

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q3` peer-reviewed experiment

## Subclaims
`q3 i?` Repeated-measures t-tests in the control groups found no significant change in thresholds for either task (contrast t(17) = .01, p = .992; orientation t(19) = .410, p = .687). [→ Zacharopoulos G 2014](#zacharopoulos-g-2014)

## Evidence

### Zacharopoulos G 2014

Zacharopoulos G, Binetti N, Walsh V, Kanai R (2014) The Effect of Self-Efficacy on Visual Discrimination Sensitivity. PLoS ONE 9(10): e109392. https://doi.org/10.1371/journal.pone.0109392

`q3 · i?`

Null result from the control groups of the same experiment, which received no self-efficacy manipulation. The authors state this indicates "pre- and post-manipulation blocks were independent and did not interact"; equivalence was not tested and no effect size is printed.

> "Comparing the pre-manipulation and post manipulation scores using repeated measures t-test yields no significant results for either contrast (t(17) = .01, p = .992) or orientation (t(19) = .410, p = .687)."
