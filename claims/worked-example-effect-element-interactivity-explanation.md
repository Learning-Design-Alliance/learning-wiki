# The worked example effect is explained by reduced element interactivity relative to problem solving, and reverses with expertise

## Subclaims
`q2 i?` Studying worked examples reduces extraneous cognitive load compared with problem solving because learners process fewer interacting elements, and for more knowledgeable learners the advantage is reduced or eliminated. [→ Ouhao Chen · Fred Paas · John Sweller 2023](#ouhao-chen-fred-paas-john-sweller-2023)

## Evidence

### Ouhao Chen · Fred Paas · John Sweller 2023

Ouhao Chen · Fred Paas · John Sweller. (2023). A Cognitive Load Theory Approach to Defining and Measuring Task Complexity Through Element Interactivity. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09782-w

`q2 · i?` · `theoretical · r3`

Theoretical explanation in the review: novices solving problems use means-ends analysis involving many interacting elements, whereas worked examples let learners "focus on a limited number of moves as the correct solution is provided", reducing extraneous cognitive load.

> "The effect suggests that asking novices to study examples improves learning more than having them solve the equivalent problems (Sweller & Cooper, 1985)."
