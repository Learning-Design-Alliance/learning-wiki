Dynamic Framework for Collaborative Learning: Leveraging Advanced LLM with Adaptive Feedback Mechanisms. arXiv. [doi:10.1109/abc64332.2025.11118419](https://doi.org/10.1109/abc64332.2025.11118419)

`q1 · i?` · `design · r2`

Conversation-dynamics analysis of the simulated discussion (Section VI.B), where a persona named Jordan generated toxic remarks via DeepSeek V3. The moderator's calibrated responses "prevented escalation and preserved group cohesion". Qualitative; no effect size printed.
