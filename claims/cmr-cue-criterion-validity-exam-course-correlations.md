### Bethany R. Wilcox and Steven J. Pollock 2015

Bethany R. Wilcox and Steven J. Pollock. (2015). Validation and analysis of the coupled multiple response Colorado upper-division electrostatics (CUE) diagnostic. arXiv preprint. [doi:10.1103/physrevstper.11.020130](https://doi.org/10.1103/physrevstper.11.020130)

`q2 · i0` · `design · r2`

Criterion-validity analysis using final course and exam scores available only for a CU subset (N=154, 4 courses); correlations used standardized z-scores calculated separately for each class. The authors state this establishes criterion validity for the CU population only.

> "we find a high correlation of CMR CUE scores with aggregate exam score (Pearson's Correlation Coeﬃcient [11] r = 0 .71) as well as ﬁnal course score ( r = 0 .64)."
