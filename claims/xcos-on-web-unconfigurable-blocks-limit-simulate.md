## Subclaims
`q1 i?` In the preliminary-development version of Xcos on Web, the first-order aperiodic link (CLR) and amplifier (GAIN) blocks cannot be configured, which makes running experiments with the Simulate button impossible. [→ Y. O. Modlo 2018](#y-o-modlo-2018)

## Evidence

### Y. O. Modlo 2018

Y. O. Modlo, S. O. Semerikov. (2018). Xcos on Web as a promising learning tool for Bachelor's of Electromechanics modeling of technical objects. Originally published 2015. [doi:10.48550/arXiv.1808.04203](https://doi.org/10.48550/arXiv.1808.04203)

`q1 · i?` · `design · r1`

The authors' hands-on description of the Xcos on Web interface, based on a DC motor model built in the service. Block parameters are normally set by double-clicking, but the CLR and GAIN blocks "є неналаштованими", indicated by the '%s' format specifier, blocking the Simulate button.

> "так, блоки аперіодичної ланки першого порядку (CLR) та підсилювача (GAIN) у побудованій моделі є неналаштованими, про що свідчить специфікатор формату ‘%s’. Це унеможливлює проведення експериментів на моделі натисканням кнопки Simulate."
