## Evidence

### Huib K. Tabbers 2010

Huib K. Tabbers, Bastiaan de Koeijer. (2010). Learner control in animated multimedia instructions. Instructional Science, 38, 441–453. https://doi.org/10.1007/s11251-009-9119-4

`q3 · i3` · `causal · r2`

Correlational analysis of log data and questionnaires in the learner control group (n = 26). Prior knowledge correlated "r = .40", r = .39, and r = .42 with time-on-task, slides, and narration segments; interest and estimated prior knowledge were unrelated to any interactive behavior measure.

> "Of the variables that were measured before the multimedia instruction, only the prior knowledge score had a significant positive correlation with the time-on-task ( r = .40, p = .04), the number of slides ( r = .39, p = .04), and the number of narration segments requested ( r = .42, p = .03)."
