## Evidence

### Walker L 2017

Walker L, Warfa A-R M. (2017). Process oriented guided inquiry learning (POGIL®) marginally effects student achievement measures but substantially increases the odds of passing a course. PLoS ONE. https://doi.org/10.1371/journal.pone.0186203

`q2 · i?` · `quant-synthesis · r2`

Meta-regression of the achievement omnibus effect by class size and discipline (chemistry n = 15, other n = 11) in the metafor package. The authors state unaccounted moderators, possibly including lack of "fidelity of implementation measures", may explain the variation.

> "Both variables, class size and disciplinary domain, were not significant moderators [QM = 2.22, df = 3, p = 0.527]. However, the test for residual heterogeneity was significant [QE = 142.90, df = 22, p < 0.0001]"
