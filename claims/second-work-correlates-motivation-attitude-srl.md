# In the experimental group, second website performance correlated with motivation, attitude, and SRL while first website performance did not

## Subclaims
`q2 i3` Second work performance correlated significantly with learning motivation (r = 0.44), learning attitude (r = 0.43), and self-regulated performance (r = 0.45), whereas first work performance showed no significant correlations with these measures. [→ Yen-Fen Lee 2025](#yen-fen-lee-2025)

## Evidence

### Yen-Fen Lee 2025

Yen-Fen Lee, Gwo-Jen Hwang, Pei-Ying Chen. (2025). Technology-based interactive guidance to promote learning performance and self-regulation: a chatbot-assisted self-regulated learning approach. Education Tech Research Dev. https://doi.org/10.1007/s11423-025-10478-x

`q2 · i3` · `causal · r2`

Pearson correlation analysis of the experimental group's data (Table 11) in the quasi-experiment; the second work performance correlated with learning motivation "(r = 0.44, p < 0.05)", learning attitude (r = 0.43), and self-regulated performance (r = 0.45), while first work performance showed no significant correlations.

> "there was no significant correlation between the first work performance and learning performance, learning motivation, learning attitude, self-regulated performance, reflection, and meta-cognition tendency; there was, however, a significant correlation between the second work performance and learning motivation (r = 0.44, p < 0.05), learning attitude (r = 0.43, p < 0.05), and self-regulated performance (r = 0.45, p < 0.05)."
