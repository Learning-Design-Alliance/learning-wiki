## Evidence

### Bing 2007

Bing, T. J., & Redish, E. F. (2007). Analyzing Problem Solving Using Math in Physics: Epistemological Framing via Warrants. https://www.compadre.org/PER/

`q2 · i?` · `qualitative · r2`

The authors' illustrative analysis of the expression xf = xi + <v>Δt in the introduction shows one elementary expression filling four roles: calculational scheme, physical relation among measurements, encoded rule, and node in a web of mathematical ideas. This is a conceptual/definitional analysis, not a tested comparison; no effect size is printed.

> "Mathematics thus fills many different epistemic rolls for a physicist. It reflects physical relations, provides a calculation framework, forms a web of intercon- nected ideas, and provides a packaging system for en- coding rules and previous results."
