# Epistemic Network Analysis revealed a knowledge co-construction tendency in active questioners versus a co-regulation tendency in responsive navigators

## Subclaims
`q2 i3` ENA subcluster means differed significantly along the first network dimension, with a printed effect size of Cohen's d = 2.26 separating active questioners from responsive navigators. [→ Hao 2025](#hao-2025)

## Evidence

### Hao 2025

Hao, Z., Jiang, J., Yu, J., Liu, Z., & Zhang, Y. (2025). Student-AI Interaction in an LLM-Empowered Learning Environment: A Cluster Analysis of Engagement Profiles. arXiv:2503.01694v3. [doi:10.48550/arXiv.2503.01694](https://doi.org/10.48550/arXiv.2503.01694)

`q2 · i3` · `associational · r2`

Epistemic Network Analysis of coded student message logs (rENA; model fit Pearson correlation above 0.95). A t-test on the first network dimension (MR1) separated the two subclusters with a large printed effect size, "Cohen’s d= 2.26", supporting the distinct interaction modes.

> "Along the x-axis (MR1), the t-test shows that Cluster 4–I (M= 0.14 , SD= 0.13 , n = 45) is statistically significantly different from Cluster 4–II (M=−0.22 , SD= 0.25 , n = 28; t(40.26) = 8.47,p <0.001, Cohen’s d= 2.26)."

### Hao 2025 (2)

Hao, Z., Jiang, J., Yu, J., Liu, Z., & Zhang, Y. (2025). Student-AI Interaction in an LLM-Empowered Learning Environment: A Cluster Analysis of Engagement Profiles. arXiv:2503.01694v3. [doi:10.48550/arXiv.2503.01694](https://doi.org/10.48550/arXiv.2503.01694)

`q2 · i?` · `associational · r2`

ENA subtraction network between the two subclusters showing a co-regulation tendency in responsive navigators, contrasting with the knowledge co-construction tendency of active questioners. No effect size is printed for the network-connection pattern itself.

> "students in Cluster 4–II made stronger interconnections among the other three core dimensions: progress regulation, peer management and emotion sharing. The denser network connections observed in both the second quadrant and the third quadrant suggest that this student cohort exhibits a pronounced propensity for learning regulation"
