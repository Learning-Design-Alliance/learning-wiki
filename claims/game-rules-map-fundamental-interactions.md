# Card-placement rules can be mapped onto the conditions of the four fundamental particle interactions

> **Claim** · [All claims](index.md)

## Subclaims
`q1 i?` The game encodes interaction conditions as placement rules: strong interaction only between quarks of different colors within the same baryon, electromagnetic between any charged particles, weak between same-generation leptons and flavor-changing quark combinations of the same color, and gravitational as a once-per-game universal move. [→ Uzelac 2024](#uzelac-2024)

## Evidence

### Uzelac 2024

Uzelac, A. (2024). A new game with Quark Matter Cards: Interactions of elementary particles. [doi:10.48550/arXiv.2401.10260](https://doi.org/10.48550/arXiv.2401.10260)

`q1 · i?` · `design · r1`

Design description in the rules section: the author defines the four interaction-specific placement rules, e.g. "for each quark (u, c, or d), you can place any other quark (u, c, or d), provided that their color is different from the initial quark's color" for the strong force, and same-color placement for weak flavor changes.

> "it is only possible to place a card on the central card if it represents a particle that can interact with the central card, and it is necessary to always state the type of interaction!"
