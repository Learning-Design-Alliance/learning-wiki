Simulation result (Figure 3) for problem-selection constraints, which bias sampling toward harder problems within a chosen skill. The article reports "a large Cohen's d effect size value of 1.86" for the equation-solving dataset. No effect size is printed for graph-interpretation under this constraint.

> "When paired with the Prefer Harder constraint, Minimize Worst Case Loss showed a greatly reduced overpractice value from 30.28 to 1.98 times in the equation-solving dataset, a large Cohen's d effect size value of 1.86, leveling the other strategies without the constraint"
