## Evidence

### Jie Yang 2020

Jie Yang, Seth DeVore, Dona Hewagallage, Paul Miller, Qing X. Ryan, and John Stewart. (2020). Using Machine Learning to Identify the Most At-Risk Students in Physics Classes. [doi:10.1103/physrevphyseducres.16.020130](https://doi.org/10.1103/physrevphyseducres.16.020130)

`q2 · i?` · `associational · r2`

Sample 2 weekly model comparison using variables available to instructors in class (clickers, homework, tests, FMCE pretest). The article reports in-class-only models "became better than the model including only institutional data after the first test was given in week 5".

> "The performance of models using only the in-class data easily available to instructors consistently performed more weakly than those which mixed in-class and institutional data. The in-class-only models improved as the class progressed and became better than the model including only institutional data after the first test was given in week 5."
