# Novices trained first on 3D performed significantly worse after switching to 2D, especially on technical errors in complicated tasks

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · causal `r2` · `q3`
> **Currency** · newest study 2017 · not yet checked against its sources · not reviewed by a person

## Subclaims
`q3 i?` After switching to the 2D system, the 3D start group's scores worsened significantly, while the 2D start group's scores improved after switching to 3D. [→ Harada Hitoshi 2017](#harada-hitoshi-2017)

## Evidence

### Harada Hitoshi 2017

Harada Hitoshi, Kanaji Shingo, Nishi Masayasu, Otake Yoshito, Hasegawa Hiroshi, Yamamoto Masashi, Matsuda Yoshiko, Yamashita Kimihiro, Matsuda Takeru, Oshikiri Taro, Sumi Yasuo, Nakamura Tetsu, Suzuki Satoshi, Sato Yoshinobu, Kakeji Yoshihiro. (2017). The learning effect of using stereoscopic vision in the early phase of laparoscopic surgical training for novices. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5654-2

`q3 · i?` · `causal · r2`

Comparison of fourth–fifth versus sixth–seventh attempts (Table 2) in the crossover study. For task 2, the 3D start group's operative time rose from 21.4 to 29.0 s (P = 0.004), path length from 1007 to 1303 mm (P = 0.003), and technical errors from 0.7 to 3.2 (P < 0.001), all significantly worse.

> "In task 2, all 2D start group scores were significantly improved just after switching to the 3D system as opposed to the significantly worse scores for the 3D start group after switching to the 2D system."

### Harada Hitoshi 2017 (2)

Harada Hitoshi, Kanaji Shingo, Nishi Masayasu, Otake Yoshito, Hasegawa Hiroshi, Yamamoto Masashi, Matsuda Yoshiko, Yamashita Kimihiro, Matsuda Takeru, Oshikiri Taro, Sumi Yasuo, Nakamura Tetsu, Suzuki Satoshi, Sato Yoshinobu, Kakeji Yoshihiro. (2017). The learning effect of using stereoscopic vision in the early phase of laparoscopic surgical training for novices. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5654-2

`q3 · i?` · `causal · r2`

For task 3 in the same study, technical errors improved for the 2D start group after switching to 3D (11.9 to 8.0, P = 0.021) but worsened for the 3D start group after switching to 2D (8.2 to 11.6, P = 0.005).

> "However, technical errors by the 2D start group were significantly improved after switching to the 3D system, whereas technical errors were significantly worse in the 3D start group after switching to the 2D system."
