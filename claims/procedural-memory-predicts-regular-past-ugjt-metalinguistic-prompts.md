# Procedural memory predicts immediate UGJT posttest gains for regular past tense only under metalinguistic prompts

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r1` · `q2` · `i2` medium

## Subclaims
`q2 i2` Among learners receiving metalinguistic prompts, procedural memory (SRT) significantly predicted immediate UGJT posttest scores for regular past tense forms (β = .33, p = .00), but was not a significant predictor for the recast or explicit correction groups. [→ Yusuke Sato 2023](#yusuke-sato-2023)

## Evidence

### Yusuke Sato 2023

Yusuke Sato. (2023). Interactions Among Declarative and Procedural Memory Systems, Different Linguistic Structures, and the Efficacy of Different Corrective Feedback Types. Journal for the Psychology of Language Learning, 5(1). https://doi.org/10.52598/jpll/5/1/4

`q2 · i2` · `causal · r1`

Multiple regression analyses for the regular past tense UGJT across three classroom CF groups (recast n=32, explicit correction n=30, metalinguistic prompts n=30), with pretest as covariate. The SRT predictor reached significance only for the metalinguistic prompt immediate posttest (β = .33, p = .00, adjusted R² = .77); the article reports "significant predictors of only the UGJT immediate posttest scores of the metalinguistic prompt group."

> "Procedural memory scores measured using the SRT were significant predictors of only the UGJT immediate posttest scores of the metalinguistic prompt group."
