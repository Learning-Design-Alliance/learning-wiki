Fajriah and Churiyah 2016¶

Ulfah Nur Fajriah, Madziatul Churiyah. (2016). Utilizing Instructional Media for Teaching Infrastructure Administration. Journal of Education and Practice, Vol.7, No.6. https://eric.ed.gov/?id=EJ1092480

Quasi-experiment with class XI AP1 (33 students) as the experimental class and XI AP2 as control, assigned by mid-term scores (AP1 63, AP2 69.4). The experimental class posttest average reached 90; the control class reached 79.7.
