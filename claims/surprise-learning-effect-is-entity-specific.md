# Learning enhancements from core knowledge violations are entity-specific: no benefit for unrelated bystander objects

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · review `r2` · `q2`

## Subclaims
`q2 i?` Infants and children taught about an entirely new object immediately after a violation were no better at learning than those taught after an expected event, arguing against a diffuse arousal account. [→ Stahl Aimee E. 2019](#stahl-aimee-e-2019)

## Evidence

### Stahl Aimee E. 2019

Stahl Aimee E., Feigenson Lisa. (2019). Violations of Core Knowledge Shape Early Learning. Topics in Cognitive Science. https://doi.org/10.1111/tops.12389

`q2 · i?` · `review · r2`

Experiments (Stahl & Feigenson, 2015; 2017) in which the taught object had not participated in the violation. Learning about the bystander object did not differ between surprising and expected preceding events, suggesting learning improves only for entities involved in failed predictions.

> "Infants and children were no better at learning about this "innocent bystander" object when taught following a surprising violation event than following an expected event"
