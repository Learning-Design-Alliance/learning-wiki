Evidence¶

Schenck 2024¶

Schenck, A. (2024). Learning How to Use Input-Based and Output-Based Form-Focused Instruction: A Meta-Analytic Comparison of Persian EFL Learners. Journal of Second Language Acquisition and Teaching, 30. https://eric.ed.gov/?id=EJ1457419

q2 · i? · quant-synthesis · r1

Meta-analytic collation by grammatical complexity; Table 2 reports clausal output mean 4.1901 (n=4) vs input 3.0655 (n=5). The 1.12 is a difference between mean effect sizes, not a standardized effect size for the contrast, so no i value is coded; the article states it "is sizable, representing a large effect".

"Output-based instruction was more effective when more complex, clausal features were emphasized (Table 2). At the more complex clausal level, the difference in effect was 1.12."
