## Evidence

### Eugenio Tufino 2024

Eugenio Tufino, Stefano Oss, and Micol Alemani. (2024). Integrating Python data analysis in an existing introductory laboratory course. Originally published 2023. [doi:10.1088/1361-6404/ad4fcc](https://doi.org/10.1088/1361-6404/ad4fcc)

`q2 · i?` · `design · r2`

Analysis of student groups' laboratory notebooks during two first-semester experiments (elastic-band/Hooke's law and pendulum). The authors report that "83% of student groups used Python and JNs" in the first experiment and 100% in the second, despite non-mandatory use.

> "Even if the use of Python and JN was not mandatory, 83% of student groups used Python and JNs for their data analysis in the first experiment and 100% in the second experiment. These results indicate an increase in students’ confidence and proficiency in using these tools."
