## Subclaims
`q3 i?` The three-way feedback-by-order-by-congruence interaction on recognition was significant (χ2(1) = 4.74, p = 0.03); for incongruent items, feedback showed only a non-significant trend toward improving memory (OR = 1.62, p = 0.08) independent of order (p = 0.55). [→ Vavra 2023](#vavra-2023)

## Evidence

### Vavra 2023

Vavra, P., Sokolovič, L., Porcu, E., Ripollés, P., Rodriguez-Fornells, A., & Noesselt, T. (2023). Entering into a self-regulated learning mode prevents detrimental effects of feedback removal on memory. npj Science of Learning, 8(1). https://doi.org/10.1038/s41539-022-00150-x

`q3 · i?` · `causal · r2`

GLMM on day-2 recognition in the laboratory recognition group (N = 29) contrasting congruent and incongruent items; incongruent items were recognized above chance in all four conditions (all p's < 0.044).

> "In contrast, this pattern was absent for the new-words, which had been associated with two incongruent sentences (3-way interaction of feedback by order by congruence: χ2(1) = 4.74, p = 0.03). We observed a trend for feedback improving the memory for the incongruent new-words (for incongruent only, main effect of feedback: odds-ratio = 1.62 ± 0.45, p = 0.08)"
