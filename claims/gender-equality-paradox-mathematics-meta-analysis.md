`q4 · i?` · `quant-synthesis · r2`

Meta-regression moderator analysis using the Global Gender Gap Index as a numeric moderator entered jointly with content, grade, and region; removing GGGI significantly worsened fit (χ²(1) = 3.93, p = .048). The coefficient was only marginal (p = .051).
