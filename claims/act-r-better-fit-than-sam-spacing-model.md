## Evidence

### Philip I. Pavlik Jr. 2005

Philip I. Pavlik Jr., John R. Anderson. (2005). Practice and Forgetting Effects on Vocabulary Memory: An Activation-Based Model of the Spacing Effect. Cognitive Science 29. https://doi.org/10.1207/s15516709cog0000_14

`q2 · i?` · `causal · r2`

Numerical model comparison (minimized χ2 statistic on condition means) in which the modified Raaijmakers model and the authors' extended ACT–R model were fit to the same restricted experiment data; ACT–R's χ2 = 43.3 (df = 28) was better than SAM's χ2 = 166 (df = 23).

> "With this modification the Raaijmakers (2003) model was able to cope with the 98-spacing condition and produce a reasonable overall fit (χ2 = 166, df = 23). However, the ACT–R model resulted in a better fit (χ2 = 43.3, df = 28) with the same restricted data set"
