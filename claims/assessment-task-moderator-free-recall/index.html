Evidence¶

Julia Schindler · Tobias Richter 2023¶

Julia Schindler · Tobias Richter. (2023). Text Generation Benefits Learning: a Meta-Analytic Review. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09758-w

q3 · i2 · quant-synthesis · r?

Subset moderator analysis within the multi-level meta-analysis comparing learning assessment task categories. All pairwise group differences were significant (e.g., free vs. cued recall: QM(df = 1) = 13.61, p < 0.001). The 'other tasks' category rests on only five effect sizes and is heterogeneous.

"We found a significant moderator effect of the learning assessment task. The generation effect was largest in studies based on free-recall tasks (g = 0.60, p < 0.001), smaller in studies based on cued-recall tasks (g = 0.27, p < 0.001), and non-existent in studies based on other tasks such as single-choice or verification tasks (g = 0.03, p = 0.851)."
