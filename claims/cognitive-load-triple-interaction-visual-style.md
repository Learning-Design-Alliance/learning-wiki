Analysis of the self-report cognitive load scale (18-point maximum, α = .72) with visual cognitive style as covariate (N = 235) yielded only this triple interaction with printed effect size ηp² = .018 (small by the η² code); the printed correlation "r = .20" for self-paced static pictures is likewise small.
