Apekshya Ghimire and Chandralekha Singh. (2026). What does it mean to think like a physicist? Insights from physics graduate students. Originally published 2025. [doi:10.1088/1361-6404/ae4e70](https://doi.org/10.1088/1361-6404/ae4e70)

`q2 · i?` · `qualitative · r3`

Interview data from the seven-participant study; one astrophysics participant stated "I don't think there is a threshold to be able to say yes, I think like a physicist," while all participants emphasized repeated practice and curiosity, and one cited role models and environment.

> "I think learning how to think is a skill that one develops throughout [ one's] lifetime. I don't think there is a threshold to be able to say yes, I think like a physicist."
