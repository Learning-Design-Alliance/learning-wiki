Claims

Age, general cognition (MoCA), visual working memory, and hearing loss showed no significant main association with the extent of training-induced change, though hearing loss and auditory working memory each moderated it by training modality; the three-way interaction was not significant

In older adults, age, MoCA, auditory and visual working memory and hearing loss had no significant main association with training-induced speech-in-noise change, but training modality interacted significantly with auditory working memory (p = .002) and with hearing loss (p = .004); the three-way modality-by-AWM-by-hearing-loss interaction was not significant
