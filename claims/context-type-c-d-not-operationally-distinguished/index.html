Qiang Liu and Chunyi Zhao 2026¶

Qiang Liu and Chunyi Zhao. (2026). Literary Axioms: A Conceptual Framework for Literary Creation, Interpretation, and Evaluation. arXiv. https://arxiv.org/abs/2609.25504 doi:10.48550/arxiv.2609.25504

q2 · i? · theoretical · r?

Descriptive audit of the snapshot's context-type fields. All 1,189 Type A records have empty era and region lists; of 96 Type B records, 95 have an era but no region; all 47 Type C and 123 Type D records have both lists populated, so "the stored context fields do not operationally distinguish Types C and D."

"Consequently, the stored context fields do not operationally distinguish Types C and D, despite their intended definitions. This should be corrected or the type scheme revised before type labels are used in comparative analysis."
