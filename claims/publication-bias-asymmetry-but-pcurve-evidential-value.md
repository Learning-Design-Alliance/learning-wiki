## Evidence

### Louise David 2024

Louise David, Felicitas Biwer, Martine Baars, Lisette Wijnia, Fred Paas, Anique de Bruin. (2024). The Relation Between Perceived Mental Effort, Monitoring Judgments, and Learning Outcomes: A Meta-Analysis. Educational Psychology Review. https://doi.org/10.1007/s10648-024-09903-z

`q2 · i?` · `quant-synthesis · r3`

Publication-bias assessment of all 236 effect sizes via a three-level funnel plot and p-curve app analyses. The funnel plot showed asymmetry; p-curve tests for all three correlations were right-skewed (e.g., effort–monitoring continuous test Z = -19.31, p < 0.001), indicating "evidential value underlying the relationships".

> "Visual inspections of the plot reveal an asymmetric shape as there are for example few studies with a larger, negative effect size and larger standard error, which indicates that there could potentially be selection or publication bias."
