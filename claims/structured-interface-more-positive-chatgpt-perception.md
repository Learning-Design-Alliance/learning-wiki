# Intervention students perceived ChatGPT more positively after using the structured interface than control students

> **Claim** · [All claims](index.md)

## Subclaims
`q3 i2` Post-intervention, intervention students rated ChatGPT as more effective for solving tasks (d = 0.63), easier to use (d = 0.76), more enjoyable (d = 0.62), and more likely to be used in future labs (d = 0.46). [→ Brender 2025](#brender-2025)

## Evidence

### Brender 2025

Brender, J., El-Hamamsy, L., Uittenhove, K., Mondada, F., Bumbacher, E. (2025). Structured Prompts, Better Outcomes? Exploring the Effects of a Structured Interface with ChatGPT in a Graduate Robotics Course. [doi:10.1007/978-3-032-03870-8_7](https://doi.org/10.1007/978-3-032-03870-8_7)

`q3 · i2` · `causal · r2`

Mann-Whitney U tests on post-intervention TAM-based survey data comparing conditions; significant differences also found for enjoyment (U = 334, p = 0.006, d = 0.62) and intent to continue using ChatGPT (U = 392, p = .049, d = 0.46).

> "students in the intervention group were more likely to consider the use of ChatGPT to be effective for solving tasks, U = 345, p = .01, Cohen's d = 0.63, to generate high quality code, U = 387, p = .046, Cohen's d = 0.52, to be easy to use, U = 324, p = .0042, Cohen's d = 0.76"
