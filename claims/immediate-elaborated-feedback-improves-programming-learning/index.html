Narrative review attribution: the review reports, citing Hooshyar et al. [125], a formative assessment game (TRIS-Q-SP) integrated into a Flowchart-based ITS using Bayesian networks for decision-making. The article reports significance without a printed effect size, so no magnitude is stated.

"the system provides Immediate Elaborated Feedback (IEF), which was found to significantly improve students' programming knowledge acquisition, interest, and problem-solving abilities compared to systems without immediate feedback."
