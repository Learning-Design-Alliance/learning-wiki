## Evidence

### Spitzer Markus Wolfgang Hermann 2023

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Logistic mixed-model analysis contrasting single problem set assignments against self-selected problem sets for the first closure. The interaction favoured teacher-assigned single sets; the article prints the coefficient as b = 14, an apparent typo.

> "The interaction of time window and assignment was significant (b = 14; z = 4.24; p < .001). The interaction indicates that the difference in completion rate as a function of school closures was larger for students who got assigned single problem sets by their teachers compared to students who selected their problem sets."

### Spitzer Markus Wolfgang Hermann 2023 (2)

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

Replication for the second closure on the coins outcome. The main effect of assignment was also significant (b = .66; z = 2.86; p = .004), with more coins on single problem set assignments than self-selected sets.

> "The interaction of time window and assignment was significant (b = .37; z = 8.73; p < .001) with the difference in coins gained between the two time windows being more pronounced for single problem set assignments by teachers."

### Spitzer Markus Wolfgang Hermann 2023 (3)

Spitzer Markus Wolfgang Hermann, Moeller Korbinian, Musslick Sebastian. (2023). Assignment strategies modulate students’ academic performance in an online learning environment during the first and second COVID-19 related school closures. PLOS ONE. https://doi.org/10.1371/journal.pone.0284868

`q2 · i?` · `associational · r2`

First-closure stars analysis contrasting single versus self-selected problem sets: no significant assignment effect and no significant interaction, so no closure-specific star advantage over self-selection was detected; equivalence was not tested.

> "The main effect of assignment was not significant (b = -.03; z = -0.12; p = .906). The main effect of computed problem sets was not significant (b < -.001; z = -0.27; p = .786). The interaction of time window and assignment was not significant (b = .04; z = 1.14; p = .255)."
