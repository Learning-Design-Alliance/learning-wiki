# Students guided to use LiquidText show lower acceptance of tablets for multiple document work than controls despite better performance

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · `q3` peer-reviewed experiment · `i3` large

## Subclaims
`q3 i3` The LiquidText Guidance group perceived the tablet as less useful than the control group, with d = 1.22. [→ Jordan Lombard 2021](#jordan-lombard-2021)
`q3 i3` The LiquidText Guidance group reported lower intention to use a tablet than the control group, with d = 1.12. [→ Jordan Lombard 2021 (2)](#jordan-lombard-2021-2)

## Evidence

### Jordan Lombard 2021

Jordan Lombard, Ivar Bråten, Cécile van de Leemput, Franck Amadieu. (2021). Performance and acceptance when using tablets as a multiple document learning tool: do application and guidance matter? Instructional Science. https://doi.org/10.1007/s11251-021-09537-6

`q3 · i3` · `causal · r2`

One-way ANOVA on the perceived usefulness measure (five items, α = .91) showed a condition effect, F(3, 84) = 4.43, p = .006. The guided group scored lowest, also below "the control condition (M = 6.82, SD = 1.66, Cohen’s d = 1.22)". Item example: "Using a tablet is beneficial when comparing multiple documents".

> "participants in the LiquidText Guidance condition (M = 4.72, SD = 1.78) perceived the tablet to be less useful than did participants in the LiquidText Non-Guidance condition (M = 6.01, SD = 1.84, Cohen’s d = 0.71)"

### Jordan Lombard 2021 (2)

Jordan Lombard, Ivar Bråten, Cécile van de Leemput, Franck Amadieu. (2021). Performance and acceptance when using tablets as a multiple document learning tool: do application and guidance matter? Instructional Science. https://doi.org/10.1007/s11251-021-09537-6

`q3 · i3` · `causal · r2`

One-way ANOVA on intention to use (two items, α = .89) showed a condition effect, F(3, 83) = 4.21, p = .008. The guided group reported the lowest intention, and there were no significant differences among the three LiquidText conditions.

> "participants in the LiquidText Guidance condition (M = 3.86, SD = 2.92) scored lower than the control group (M = 6.75, SD = 2.25, Cohen’s d = 1.12)"
