Heidi Taveter and Marina Lepp. (2026). From Idea to Classroom in Days: Using “Vibe Coding” to Create a Programming Process Visualizer from IDE Activity Logs. https://arxiv.org/abs/2607.24757 doi:10.48550/arxiv.2607.24757

Developer-reported development accounting within the AI-assisted vibe coding workflow: of 207 total Lovable prompts, the replay view required 31, the most of any view, because of reliability, cross-tab consistency, point inspection, and edge-case handling. No effect size is applicable.

"Compared to other views, developing the programming-process replay required the largest number of prompts (31): to make it work reliably and consistently, ensure that information across tabs and logs is displayed correctly, allow the user to inspect points of interest in more detail, and account for edge cases."
