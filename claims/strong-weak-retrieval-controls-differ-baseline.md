Post-hoc analysis of control groups found CTRw groups homogeneous (F(6,150) = 0.74, p = 0.62) and CTRs groups homogeneous (F(6,167) = 1.72, p = 0.12), but CTRw vs CTRs means differed significantly (t = 6.65, p < 0.001), so each control type was compared only with its paired EXM groups.
