# Self-reported retrieval use moderated the forward benefit of cue-only JOLs: higher retrieval ratings predicted better Phase B memory and transfer only in the cue-only JOLs condition

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r3` · `q3`

## Subclaims
`q3 i?` Retrieval rating × condition interactions were significant for memory and transfer; within cue-only JOLs, higher ratings predicted better Phase B performance, while ratings were unrelated or negatively related in low-retrieval groups. [→ Ritter 2025](#ritter-2025)

## Evidence

### Ritter 2025

Ritter, C., Hausman, H., Gaschler, R., Tiffin-Richards, S. P., & Kubik, V. (2025). The Forward Effect of Judgements of Learning on Memory and Transfer in Inductive Learning. Educational Psychology Review. https://doi.org/10.1007/s10648-025-10094-4

`q3 · i?` · `causal · r3`

Exploratory participant-level regression in Experiment 1 testing retrieval rating, group, and their interaction; interactions were significant for memory, F(1,115) = 7.88, p = .006, and transfer, F(1,115) = 9.20, p = .003. The printed b coefficients are unstandardized, so no standardized effect size is reported.

> "higher retrieval ratings in the cue-only JOLs group predicted significantly better memory ( b = 0.05, 95% CI [.006, .095], p = .026) and transfer (b = 0.05, 95% CI [.006, .088], p = .024)."
