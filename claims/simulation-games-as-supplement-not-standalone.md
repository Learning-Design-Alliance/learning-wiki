`q3 i2` When simulation games supplemented other instructional methods the game group had higher knowledge than the comparison group (d = .51), but when games were standalone the comparison group learned slightly more on average (d = −.12, 95% CI −.26 to .01, an interval that includes zero). ## Evidence

### Traci Sitzmann 2011

Traci Sitzmann. (2011). A Meta-Analytic Examination of the Instructional Effectiveness of Computer-Based Simulation Games. Personnel Psychology, 64(2), 489-528. [doi:10.1111/j.1744-6570.2011.01190.x](https://doi.org/10.1111/j.1744-6570.2011.01190.x)

`q3 · i2` · `quant-synthesis · r2`

Meta-analytic moderator analysis across 40 effect sizes for games used as a supplement (N = 3,109) and 21 for standalone games (N = 946); the QB was significant (64.59), supporting the embedding hypothesis. The standalone estimate (d = −.12) has a 95% confidence interval of −.26 to .01, which includes zero, so it does not show standalone games to be reliably worse than the comparison condition.

> "when simulation games were used as a supplement to other instructional methods, the simulation game group had higher knowledge levels than the comparison group (d = .51). However, when simulation games were used as standalone instruction, trainees in the comparison group learned more than trainees in the simulation game group (d =− .12)."
