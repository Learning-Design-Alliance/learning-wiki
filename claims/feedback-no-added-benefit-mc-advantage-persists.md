## Evidence

### Hildenbrand Lena; Wiley Jennifer 2025

Hildenbrand Lena; Wiley Jennifer. (2025). Supporting comprehension: The advantages of multiple–choice over true—false practice tests. Memory & Cognition. https://doi.org/10.3758/s13421-025-01726-9

`q3 · i1` · `causal · r2`

Experiment 3 used a 2 (format) × 3 (feedback: KCR, EF, NF) between-subjects design with 297 undergraduates. The format main effect was F(1, 291) = 6.78, p = 0.010, ηp2 = 0.02; "performed significantly better" for multiple-choice is the format contrast.

> "participants who had completed a multiple-choice practice test performed significantly better (M = 2.62, SD = 1.49) than did those who took a true—false practice test (M = 2.18, SD = 1.50), t(291) = 2.60, p = 0.010, d = 0.31."

### Hildenbrand Lena; Wiley Jennifer 2025 (2)

Hildenbrand Lena; Wiley Jennifer. (2025). Supporting comprehension: The advantages of multiple–choice over true—false practice tests. Memory & Cognition. https://doi.org/10.3758/s13421-025-01726-9

`q3 · i?` · `causal · r2`

In the same 2 × 3 ANOVA on final SA test performance in Experiment 3, neither feedback type (KCR vs. EF vs. no feedback) nor its interaction with format reached significance; the article prints no effect size beyond ηp2 < 0.01.

> "There was no main effect for feedback, F(2, 291) = 0.61, MSE = 2.26, p = 0.764, ηp2 < 0.01. There also was no interaction, F(2, 291) = 0.27, MSE = 2.26, p = 0.890, ηp2 < 0.01."
