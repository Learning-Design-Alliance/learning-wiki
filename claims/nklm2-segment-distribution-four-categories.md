`q2 · i?` · `qualitative · r2`

Qualitative content analysis (Mayring) of the 1,467-page NKLM 2.0 PDF using MAXQDA, with a code system of "43 deductive and 39 inductive codes". The distribution of all 1,426 coded segments across the four categories is reported descriptively.

> "The final code system consisted of 82 codes. All 1,426 coded segments were distributed across the code categories as follows: “Preventive nutritional knowledge”: 532 (37.31%), “Communication competencies”: 442 (31%), “NC competencies”: 216 (15.15%), “Nutritional medicine”: 236 (16.55%)."
