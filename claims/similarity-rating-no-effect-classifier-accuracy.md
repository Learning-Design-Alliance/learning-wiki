# Participants' ratings of how similar curiosity and interest are did not predict classifier accuracy

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r2` · `q3`
> **Currency** · newest study 2021 · not yet checked against its sources · not reviewed by a person

## Subclaims
`q3 i?` Likert similarity/difference ratings had no main effect on absolute or relative classifier accuracy and did not interact with definition type. [→ Donnellan 2021](#donnellan-2021)

## Evidence

### Donnellan 2021

Donnellan, E., Aslan, S., Fastrich, G. M., & Murayama, K. (2021). How Are Curiosity and Interest Different? Naïve Bayes Classification of People's Beliefs. Educational Psychology Review. https://doi.org/10.1007/s10648-021-09622-9

`q3 · i?` · `associational · r2`

Probit (absolute) and linear (relative) regression models on main test data, with standard errors corrected for data dependency, found the similarity rating predicted neither accuracy measure; the article reports "no effect on classifier accuracy for either definition type" with the printed coefficients. No effect size is printed.

> "The rating had no effect on classifier accuracy for either definition type (no main effect on absolute, b = 0.007, SE = 0.038, z = 0.186, p = .852; relative, b =- 0.011, SE = 0.028, z = -0.411, p = .681"
