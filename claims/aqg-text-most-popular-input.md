Ghader Kurdi, Jared Leo, Bijan Parsia, Uli Sattler, Salam Al-Emari. (2020). A Systematic Review of Automatic Question Generation for Educational Purposes. International Journal of Artificial Intelligence in Education. https://doi.org/10.1007/s40593-019-00186-y

`q2 · i?` · `review · r3`

Input analysis across included studies found text used by 42 studies, mostly for language learning (18 studies) or simple factual questions (16 studies); among Semantic Web studies, nine of ten tackled domain-unspecific questions.

> "As in the findings of Alsubait (Table 1), text is still the most popular type of input with 42 studies using it. Ontologies and resource description framework (RDF) knowledge bases come second, with eight and six studies, respectively, using these."
