# Test performance in laparoscopic tasks is dictated by the viewing mode used during testing, not the mode used during training

## Subclaims
`q3 i3` Groups tested in the same viewing mode did not differ significantly at test regardless of training mode (η2 = 0.29 for the overall group effect). [→ Beattie 2021](#beattie-2021)

## Evidence

### Beattie 2021

Beattie, K. L., Hill, A., Horswill, M. S., Grove, P. M., & Stevenson, A. R. L. (2021). Laparoscopic skills training: the effects of viewing mode (2D vs. 3D) on skill acquisition and transfer. Surgical Endoscopy, 35(8), 4332–4344. https://doi.org/10.1007/s00464-020-07923-8

`q3 · i3` · `causal · r2`

Testing-phase analysis of the four-group counterbalanced experiment on total test performance score (time + error penalties across 12 attempts). Main effect of group was significant (F = 7.69, p < .001, η2 = 0.29), a large effect, but the "different training, same testing" post hoc comparisons were non-significant (p = 0.882 both).

> "Regardless of the viewing mode used in training, there were no significant differences found between the test scores of the two groups tested in 2D (the 2D → 2D and 3D → 2D groups), and between the two groups tested in 3D (the 3D → 3D and 2D → 3D groups)"
