## Subclaims
`q1 i?` Exporting smartphone experiment data to a computer for analysis tasks such as finding time codes or numerical integration requires detailed instructions, more time than the hands-on activity, and poses extraneous cognitive load that may hinder learning of the physical content. [→ Staacks 2018](#staacks-2018)

## Evidence

### Staacks 2018

Staacks, S., Hütz, S., Heinke, H., & Stampfer, C. (2018). Advanced tools for smartphone-based experiments: phyphox. arXiv. [doi:10.1088/1361-6552/aac05e](https://doi.org/10.1088/1361-6552/aac05e)

`q1 · i?` · `design · r1`

The authors' analytical argument in the introduction about the second obstacle of smartphone experiments: students must export data to a computer for tasks "from finding the time code of a recorded event to numerical integration in a spreadsheet software like Excel". No empirical measurement is reported; the authors state the load "might hinder" learning.

> "Since these often are not simple tasks for students, this usually requires not only detailed instructions and more time than the hands-on activity, but poses an enormous extraneous cognitive load which might hinder the learning progress concerning the physical content."
