Correlational analysis in the combined grade 4 dataset between Tempo Test Arithmetic scores and symbolic number comparison reaction times, printing the effect size "r(83) = - 0.35, p < 0.001" with BF10 = 44.70. The negative sign reflects faster reaction times going with better arithmetic.
