# Ancillary boilerplate code in notebooks dilutes students' focus and repetitive rerun actions hinder learning in computational experiments

## Subclaims
`q1 i?` Notebooks populated by ancillary code that does not contribute to core learning outcomes dilute students' focus, and learning is hindered by repetitive actions needed to rerun experiments. [→ Goscinski 2025](#goscinski-2025)

## Evidence

### Goscinski 2025

Goscinski, A., Baird, T. J., Du, D., Prado, J., Suman, D., Sodjargal, T.-E., Bonella, S., Pizzi, G., & Ceriotti, M. (2025). scicode-widgets: Bringing Computational Experiments to the Classroom with Jupyter Widgets. [doi:10.48550/arXiv.2507.05734](https://doi.org/10.48550/arXiv.2507.05734)

`q1 · i?` · `design · r1`

The authors' design-motivation argument in the introduction: even teacher-provided data-processing code dilutes students' focus when the notebook is "populated by ancillary code that does not contribute to the core learning outcomes". No empirical test is reported for this assertion.

> "While the code for data processing can be provided by the teacher, it still dilutes students’ focus if the notebook is populated by ancillary code that does not contribute to the core learning outcomes."
