## Subclaims
`q2 i?` Relative delayed start remained a significant negative predictor of standardized state test performance in i-Ready data (forward model beta = -0.13, p < 0.001; backward model beta = -0.12, p < 0.001). [→ Ashish Gurung 2025](#ashish-gurung-2025)
`q2 i?` Neither early stop (beta = 0.04, p = 0.19) nor idle time (beta = -0.03, p = 0.30) showed a significant relationship with state test performance in i-Ready data. [→ Ashish Gurung 2025](#ashish-gurung-2025)

## Evidence

### Ashish Gurung 2025

Ashish Gurung, Jionghao Lin, Zhongtian Huang, Conrad Borchers, Ryan S. Baker, Vincent Aleven, Kenneth R. Koedinger. (2025). Starting Seatwork Earlier as a Valid Measure of Student Engagement. arXiv. [doi:10.48550/arXiv.2505.13341](https://doi.org/10.48550/arXiv.2505.13341)

`q2 · i?` · `associational · r2`

Replication of the RQ2 stepwise models on i-Ready log data from 818 grade 7 students (717 took the state test) in a West Coast state, predicting grade 7 state test scores controlling for grade 6 scores. Forward model: BIC = 1526, R2 = 0.52.

> "Relative delayed start (β = −0.13, p <0.001) had a significant negative correlation with student performance on the state test."
