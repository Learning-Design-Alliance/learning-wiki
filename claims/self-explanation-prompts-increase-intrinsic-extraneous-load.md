# Self-explanation prompts increase intrinsic and extraneous cognitive load but not germane load in instructional video learning

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q3` peer-reviewed experiment · `i2` medium

## Subclaims
`q3 i2` Self-explanation prompts significantly increased perceived intrinsic load and extraneous load, while navigation features had no effect on any load facet and germane load was unaffected. [→ Beege 2025](#beege-2025)

## Evidence

### Beege 2025

Beege, M., & Ploetzner, R. (2025). Learning from interactive video: the influence of self-explanations, navigation, and cognitive load. Instructional Science. https://doi.org/10.1007/s11251-024-09693-5

`q3 · i2` · `causal · r2`

Follow-up ANOVAs after a significant MANOVA main effect for self-explanation prompts (Wilk' s Λ = 0.88, p = .001) showed increased intrinsic load (ηp² = 0.06) and extraneous load (ηp² = 0.09); germane load showed no effect. Navigation features were nonsignificant throughout.

> "Results revealed a significant effect regarding intrinsic load (F(1, 124) = 8.40, p = .004, ηp 2 = 0.06), a significant effect regarding extraneous load ( F(1, 124) = 11.93, p < .001, η p 2 = 0.09) but no effect regarding germane load ( F(1, 124) = 0.33, p = .564, ηp 2 = 0.003)"
