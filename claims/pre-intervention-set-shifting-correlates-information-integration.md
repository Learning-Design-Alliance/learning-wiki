## Evidence

### Zwilling 2019

Zwilling, C. E., Daugherty, A. M., Hillman, C. H., Kramer, A. F., Cohen, N. J. & Barbey, A. K. (2019). Enhanced decision-making through multimodal training. npj Science of Learning 4:11. https://doi.org/10.1038/s41539-019-0049-x

`q2 · i2` · `causal · r2`

Correlational analysis of the full sample at baseline (n = 137). Only "information integration: r = 0.24, p = 0.004" was significant; belief assessment was marginal (r = 0.16, p = 0.06) and value assessment null (r = 0.03, p = 0.73).

> "we also examined correlations between these cognitive processes at pre-intervention and observed associations only for information integration and the set shifting measure of executive function in the full sample (value assessment: r = 0.03, p = 0.73, n = 137; belief assessment: r = 0.16, p = 0.06, n = 137; information integration: r = 0.24, p = 0.004, n = 137)."
