## Evidence

### Pattinson 2025

Pattinson, S. R., Savelberg, H., & Atherley, A. (2025). Readiness for the Realities of Internship: An Ethnographic Study Using Legitimation Code Theory. Perspectives on Medical Education, 14(1), 628–640. https://doi.org/10.5334/pme.1802

`q2 · i?` · `qualitative · r3`

Thematic codes were plotted on the LCT Specialisation Plane (Figure 1), a Cartesian visualisation of epistemic and social relations, revealing the code shift between contexts. The authors state "there is a code shift in the basis of achievement" between the two settings.

> "When these results are plotted on the Specialisation Plane (Figure 1 below), it is clear to see that there is a code shift in the basis of achievement between the knowledge code (ER+, SR–) basis in medical school and the knower code (ER–, SR+) basis in internship."
