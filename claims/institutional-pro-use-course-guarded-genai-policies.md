# Institutional GenAI guidance is more pro-use than computing course syllabus policies, where 92% of syllabi set explicit permissions and half prohibit use outright

## Subclaims

## Evidence

### Amrita Ganguly 2026

Amrita Ganguly, Aditya Johri, Nora McDonald, Areej Ali, Umama Dewan, and Aayushi Hingle Collier. (2026). A Comparative Analysis of Institutional and Course Generative AI Policies within Higher Education: Implications for Instruction in Computing Education. https://arxiv.org/abs/2607.12296

`q2 · i?` · `qualitative · r3`

Document analysis of 98 computer science syllabi from 54 R1 universities, coded by three researchers with a 16-code codebook. The course-level analysis found "half (50%, N=49) outright prohibiting use" and 41% permitting partial use for specified activities.

> "Almost all (92%, N=90) syllabi provided explicit guidelines about permissions to use GenAI in their course, with half (50%, N=49) outright prohibiting use and a few only allowing it with explicit permission (N=6)."
