Nour, G., Singh, H., Longbottom, E., Hayes, J., Farnell, D., & Dutta, A. (2025). Assessment of Case Complexity of Root Canal Treatments Using Contemporary Complexity Grading Systems: A Clinical Service Evaluation. International Endodontic Journal. [doi:10.1111/iej.70039](https://doi.org/10.1111/iej.70039)

`q2 · i?` · `associational · r1`

A clinical service evaluation of 201 consecutive case records at Cardiff University Dental Hospital, graded by two calibrated examiners using each system. The results section reports "Most cases were classified as level 3 complexity by ECS (82%, n = 165)" with EA highest and E-CAT lowest; no effect size is printed for these descriptive distributions.

> "Most cases were classified as level 3 complexity by ECS (82%, n = 165). EA had the highest percentage of level 3 cases (92%, n = 184), while E‐CAT had the lowest (74.1%, n = 149)."
