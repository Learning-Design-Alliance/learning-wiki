# Game accuracy increases across sessions only in the encoding phase of the word-object task, and encoding accuracy exceeds recognition accuracy

## Subclaims
`q3 i?` Accuracy was significantly higher in the encoding phase than the recognition phase in both tasks in both experiments (e.g., word-object Wald-Type Statistic = 153.64, P < 0.001 in toddlers). [→ Peña 2024](#pena-2024)
`q3 i?` Accuracy increased across sessions only in the word-object task (Session × Task interaction) and only in the encoding phase (Session × Phase interaction). [→ Peña 2024 (2)](#pena-2024-2)

## Evidence

### Peña 2024

Peña, M., Vásquez-Venegas, C., Cortés, P., Pittaluga, E., Herrera, M., Pino, E. J., Escobar, R. G., Dehaene-Lambertz, G., & Guevara, P. (2024). A brief tablet-based intervention benefits linguistic and communicative abilities in toddlers and preschoolers. npj Science of Learning. https://doi.org/10.1038/s41539-024-00249-3

`q3 · i?` · `causal · r2`

Non-parametric longitudinal analysis of game accuracy in the toddler experiment (n=101 analyzed). "The accuracy was signiﬁcantly higher for the encoding phase than the recognition phase" in both tasks; replicated in preschoolers (letter-sound WTS = 290.73; word-object WTS = 186.28, both P < 0.001).

> "The accuracy was signiﬁcantly higher for the encoding phase than the recognition phase (Fig. 2c) in both the letter-sound task (Wald-Type Statistic = 131.55, df = 1;P < 0.001) and the word-object task (Wald-Type Statistic = 153.64, df = 1;P < 0.001)."

### Peña 2024 (2)

Peña, M., Vásquez-Venegas, C., Cortés, P., Pittaluga, E., Herrera, M., Pino, E. J., Escobar, R. G., Dehaene-Lambertz, G., & Guevara, P. (2024). A brief tablet-based intervention benefits linguistic and communicative abilities in toddlers and preschoolers. npj Science of Learning. https://doi.org/10.1038/s41539-024-00249-3

`q3 · i?` · `causal · r2`

Longitudinal game analysis in toddlers: "accuracy increased acrosssessions only in the word-object task" (WTS = 31.53, P < 0.001) and "accuracy increased across sessions only in the encoding phase" (WTS = 14.29, P = 0.014). Replicated in preschoolers for Session × Task (WTS = 22.96, P < 0.001).

> "Session and Task interacted sig- nificantly, as accuracy increased acrosssessions only in the word-object task (Wald-Type Statistic = 31.53, df = 5; P < 0.001). Likewise, the interaction between Session and Phase revealed that the accuracy increased across sessions only in the encoding phase ( Wald-Type Statistic = 14.29, df = 5; P = 0.014)"
