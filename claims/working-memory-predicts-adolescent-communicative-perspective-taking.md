## Evidence

### Nilsen 2017

Nilsen, E. S., & Bacso, S. A. (2017). Cognitive and Behavioural Predictors of Adolescents’ Communicative Perspective-taking and Social Relationships. Adolescence. https://doi.org/10.1016/j.adolescence.2017.01.004

`q3 · i?` · `associational · r1`

Hierarchical regression in a community sample of 46 adolescents (regressions n=38) tested executive function and ADHD traits as predictors of communicative perspective-taking. Working memory was the only significant predictor (β = .43, p = .013), consistent with the finding that "Adolescents with smaller working memory capacities were found to have worse communicative perspective-taking."

> "When examining the regression weights of the predictors, working memory ( β = .43, p = .013) was the only significant predictor while ADHD traits no longer significantly predicted communicative perspective-taking"
