### Joseph Jay Williams 2015

Joseph Jay Williams, Korinn Ostrow, Xiaolu Xiong, Elena Glassman, Juho Kim, Samuel G. Maldonado, Na Li, Justin Reich, Neil Heffernan. (2015). Using and Designing Platforms for In Vivo Educational Experiments. L@S 2015, Vancouver, BC, Canada. http://dx.doi.org/10.1145/2724660.2728704

`q2 · i?` · `design · r1`

Case report of iterative improvement in ASSISTments: teachers revised hints and feedback for library exercises via a browser-based WYSIWYG editor. The authors state these are "now being tested in an ongoing experiment" and could be incorporated by clicking a button if shown effective.

> "One way in which this has supported successive improvements was having a group of teachers look at 50 exercises from the library and create new hints and feedback them, just using their web browser and with no programming experience."
