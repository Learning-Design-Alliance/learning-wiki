Using Think-Aloud Data to Understand Relations between Self-Regulation Cycle Characteristics and Student Performance in Intelligent Tutoring Systems. Exploratory χ²-based unigram analysis of N = 838 tested unigram pairs from think-aloud utterances; descriptively, formula representations (e.g., p4, co2) preceded correct attempts and substance names (e.g., hydrogen, glucose) preceded incorrect ones, but no comparison survived correction.

> "However, after adjusting the Type I error level𝛼 via the Benjamini-Hochberg procedure at a false-discovery rate of 0.05, none of the tested pairwise comparisons were statistically significant."
