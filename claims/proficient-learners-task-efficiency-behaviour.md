## Evidence

### Tanya Chichekian 2026

Tanya Chichekian, Maria Cutumisu, Annie Savard and Yi-Mei Zhang. (2026). Profiling Pre-service Teachers' Computational Thinking: The Role of Metacognition and Coding Experience. Journal of Learning Analytics, 13(1), 31–41. https://doi.org/10.18608/jla.2026.9077

`q2 · i3` · `associational · r1`

One-way ANOVA on Qualtrics trace data from the Programming Lamps task compared online behaviours across the three CT profiles. Proficient learners' mean task completion time was 80.12 s versus 150.45 s (Novice) and 125.67 s (Developing); the article reports "F(2, 96) = 10.45, p < .001, η² = .18".

> "For L_Time ( M = 124.33, SD = 73.27, n = 99), F(2, 96) = 10.45, p < .001, η²  = .18, Proficient learners ( M = 80.12, SD = 40.10) completed tasks faster than Novice (M = 150.45, SD = 80.20, p < .001) and Developing (M = 125.67, SD = 70.50, p = .002), indicating greater efficiency in CT."

### Tanya Chichekian 2026 (2)

Tanya Chichekian, Maria Cutumisu, Annie Savard and Yi-Mei Zhang. (2026). Profiling Pre-service Teachers' Computational Thinking: The Role of Metacognition and Coding Experience. Journal of Learning Analytics, 13(1), 31–41. https://doi.org/10.18608/jla.2026.9077

`q2 · i3` · `associational · r1`

The same ANOVA on click counts showed Proficient learners averaged 35.89 clicks versus 65.34 (Novice) and 52.12 (Developing); the article reports "F(2, 96) = 7.89, p < .001, η² = .14" and attributes the pattern to possibly reduced trial-and-error.

> "For L_Clicks ( M = 50.07, SD = 37.23, n = 99), F(2,  96) = 7.89, p < .001, η²  = .14, Proficient learners ( M = 35.89, SD = 20.40) had fewer clicks than Novice ( M = 65.34, SD = 45.60, p < .001) and Developing ( M = 52.12, SD = 35.30, p = .008), possibly reflecting reduced trial -and-error."

### Tanya Chichekian 2026 (3)

Tanya Chichekian, Maria Cutumisu, Annie Savard and Yi-Mei Zhang. (2026). Profiling Pre-service Teachers' Computational Thinking: The Role of Metacognition and Coding Experience. Journal of Learning Analytics, 13(1), 31–41. https://doi.org/10.18608/jla.2026.9077

`q2 · i2` · `associational · r1`

ANOVA on playground exploration time showed Proficient learners spent less time (M = 45.21 s) than Novice (M = 85.67 s) and Developing (M = 65.43 s) learners; the article reports "F(2, 124) = 8.32, p < .001, η² = .12" from LSD post-hoc tests.

> "For PG_Time (M = 64.77, SD = 37.09, n = 127), F(2, 124) = 8.32, p < .001, η² = .12, LSD post -hoc tests show ed that  Proficient learners ( M = 45.21, SD = 25.30) spent less time in the playground than Novice ( M = 85.67, SD = 45.10, p < .001) and Developing ( M = 65.43, SD = 35.20, p = .012), suggesting greater initial familiarity."
