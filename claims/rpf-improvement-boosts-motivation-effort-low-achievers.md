## Evidence

### Hermes et al. 2021

Henning Hermes, Martin Huschens, Franz Rothlauf, Daniel Schunk. (2021). Motivating low-achievers—Relative performance feedback in primary schools. Journal of Economic Behavior and Organization. https://doi.org/10.1016/j.jebo.2021.04.004

`q3 · i2` · `causal · r2`

Class-wise RCT comparing treatment (ranking feedback) and control (individual feedback) groups using the same math e-learning software; OLS regressions with baseline controls, n = 378. The printed linear-combination effect sizes favoring treated low-achievers were an effect size of 0.34 SD (p = .026) on the motivation task and an effect size of 0.47 SD (p = .094) on teacher-rated motivation.

> "For the motivation test task and teacher-rated motivation, we ﬁnd a strong and signiﬁcant heterogeneous treatment effect for low-achieving children (0.47 SD ( p = .034) for the motivation test, 0.43 SD ( p = .008) for teacher-rated motivation)."

### Hermes et al. 2021 (2)

Henning Hermes, Martin Huschens, Franz Rothlauf, Daniel Schunk. (2021). Motivating low-achievers—Relative performance feedback in primary schools. Journal of Economic Behavior and Organization. https://doi.org/10.1016/j.jebo.2021.04.004

`q3 · i2` · `causal · r2`

Behavioral effort measures collected within the e-learning software during the intervention: voluntary practice tasks and time spent. The printed heterogeneous treatment effect sizes for low-achievers were an effect size of 0.39 SD (p = .044) for number of tasks and an effect size of 0.41 SD (p = .078) for time spent; the linear combination was not significant.

> "there is a strong and signiﬁcant heterogeneous treatment effect for low-achieving children (0.39 SD ( p = .044) for number of tasks, 0.41 SD ( p = .078) for time spent on voluntary practice); the linear combination with the treatment effect is, however, not signiﬁcant."
