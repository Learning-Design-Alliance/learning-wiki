# Children's age did not moderate gesture enrichment benefits on vocabulary test performance in Experiment 1

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3`

## Subclaims
`q3 i?` Exploratory regression analyses in Experiment 1 found no significant moderation of gesture enrichment effects by children's age for any test type. [→ Andrä 2020](#andra-2020)

## Evidence

### Andrä 2020

Andrä, C., Mathias, B., Schwager, A., Macedonia, M., & von Kriegstein, K. (2020). Learning Foreign Language Vocabulary with Gestures and Pictures Enhances Vocabulary Memory for Several Months Post-Learning in Eight-Year-Old School Children. Educational Psychology Review. https://doi.org/10.1007/s10648-020-09527-z

`q3 · i?` · `causal · r2`

Exploratory multiple linear regression in Experiment 1 (n = 54, ages 8.5–10.2 years) compared null and moderator models via chi-square tests; no significant differences emerged (free recall p(χ2) = 0.46; L1-L2 translation p(χ2) = 0.82; L2-L1 translation p(χ2) = 0.92).

> "These nonsignificant comparisons suggest that children's ages did not moderate the effects of gesture enrichment on vocabulary test performance."
