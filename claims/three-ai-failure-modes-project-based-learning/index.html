q1 · i? · qualitative · r1

Authors' qualitative reflection on failure modes encountered across the ten-week project (RQ2). The three categories are plausible but incorrect code, lack of specialized knowledge such as niche libraries like curl-impersonate, and limited long-term context windows risking incorrect advice.

"Plausible but incorrect code:AI-generated code often ran without errors but could contain errors or methodological flaws, including issues associated with assumptions around modeling, feature construction, etc."
