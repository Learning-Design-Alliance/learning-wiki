## Evidence

### Lieu 2017

Lieu, R., Wong, A., Asefirad, A., & Shaffer, J. F. (2017). Improving Exam Performance in Introductory Biology through the Use of Preclass Reading Guides. CBE—Life Sciences Education. [doi:10.1187/cbe.16-11-0320](https://doi.org/10.1187/cbe.16-11-0320)

`q3 · i?` · `associational · r2`

Regression analysis using number of reading guides fully completed before class as response variable with gender, ethnicity, SAT math/reading, and section as explanatory variables, per exam (n = 416–602). Adjusted R2 values were low (0.013–0.026), indicating "few cases and in an inconsistent manner."

> "Student demographics significantly contributed to reading guide completion before class in few cases and in an inconsistent manner."
