q2 · i? · associational · r1

Descriptive participation counts from the report's introduction for the spring 1997 survey administration. The report attributes the high return rate to CPS support, including financial support and encouragement of schools, so that "more schools would have access to this relevant information."

"Because of this strong support, these surveys produced the greatest return rate of any Consortium study, Four hundred eight CPS elementary schools and 62 high schools participated in these surveys and are receiving this report."
