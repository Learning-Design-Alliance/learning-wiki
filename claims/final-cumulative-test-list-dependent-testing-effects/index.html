Evidence¶

Veit Kubik 2022¶

Veit Kubik, Kenneth Koslowski, Torsten Schubert, Alp Aslan. (2022). Metacognitive judgments can potentiate new learning: The role of covert retrieval. Metacognition and Learning (2022) 17:1057–1077. https://doi.org/10.1007/s11409-022-09307-w

q3 · i? · causal · r3

A 4 (practice type) × 5 (list) ANOVA on final cumulative recall in the N = 161 experiment found a significant "Practice Type × List interaction effect, F(12, 628) = 4.61, p < .001"; no main effect of practice type. No standardized effect size is printed for the interaction, so impact is null.

"Critically, we observed a significant Practice Type × List interaction effect, F(12, 628) = 4.61, p < .001, ̂ω2p = 0.02, indicating the effect of practice type was modulated in magnitude as a function of list."

Veit Kubik 2022 (2)¶

Veit Kubik, Kenneth Koslowski, Torsten Schubert, Alp Aslan. (2022). Metacognitive judgments can potentiate new learning: The role of covert retrieval. Metacognition and Learning (2022) 17:1057–1077. https://doi.org/10.1007/s11409-022-09307-w

q3 · i2 · causal · r2

Planned contrasts on final cumulative recall: word-stem JOLs and retrieval practice "trumped restudy" for List 5; for List 1, restudy showed a significant advantage over word-stem JOLs, t(78) = 2.46, p = .016, d = 0.56, and retrieval practice, t(78) = 3.34, p = .001, d = 0.76. JOLs with complete words did not differ from restudy for List 5 (d = 0.14, ns).

"making JOLs with word stems, t(78) = 2.0, p = .025, d = 0.45, 95% CI [0.07, ∞] (one-tailed), and retrieval practice, t(78) = 2.52, p = .007, d = 0.57, 95% CI [0.19, ∞] (one-tailed), trumped restudy in final cumulative test recall performance of List 5"
