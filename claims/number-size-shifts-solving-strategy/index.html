Evidence¶

Hippolyte Gros 2020¶

Hippolyte Gros, Jean-Pierre Thibaut, Emmanuel Sander. (2020). Semantic Congruence in Arithmetic: A New Conceptual Model for Word Problem Solving. Educational Psychologist. https://doi.org/10.1080/00461520.2019.1691004

q2 · i? · theoretical · r3

The article reports, citing Thevenot and Oakhill (2005), an experiment using an operand-recognition paradigm in which recognition performance indicated whether numbers were still held in working memory. Strategy choice depended on value size; no effect size is printed.

"participants used the grouping algorithm “x − (y + z)” when the task was not especially demanding due to the problem’s values being small, whereas they used the more economical sequential strategy “(x − y) − z” when the use of larger values implied that the task had higher cognitive costs."
