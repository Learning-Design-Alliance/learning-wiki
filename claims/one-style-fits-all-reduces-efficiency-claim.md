# Non-intelligent E-learning systems applying one style to all learners are argued to reduce efficiency because learners differ

## Subclaims
`q1 i?` The authors argue that because learners vary in awareness and mentality, non-intelligent systems that apply the same style for all learners suffer reduced efficiency, motivating intelligent adaptive systems. [→ H. Movafegh Ghadirli and M. Rastgarpour 2012](#h-movafegh-ghadirli-and-m-rastgarpour-2012)

## Evidence

### H. Movafegh Ghadirli and M. Rastgarpour 2012

H. Movafegh Ghadirli and M. Rastgarpour. (2012). A Model for an Intelligent and Adaptive Tutor based on Web by Jackson's Learning Styles Profiler and Expert Systems. Manuscript received January 07, 2012; revised January 27, 2012. [doi:10.1142/9789814439084_0019](https://doi.org/10.1142/9789814439084_0019)

`q1 · i?` · `design · r1`

A theoretical argument in the introduction, not an empirical test: the authors assert that uniform delivery fits learners unevenly, since some learners need repetition of some lessons while for others lessons must be removed, and conclude learning processes must be dynamic and intelligent.

> "Learners are different. It leaded to decrease the efficiency of this style. It means that some learners need to repeat some lessons meanwhile some lessons must be removed for others."
