# Working memory did not reliably correlate with grammar learning in any of the three experiments

## Subclaims
`q3 i?` Across Experiments 1–3, working memory showed no significant correlations with simple or complex grammar learning in any training condition. [→ Antoniou Mark 2016](#antoniou-mark-2016)

## Evidence

### Antoniou Mark 2016

Antoniou Mark, Ettlinger Marc, Wong Patrick C. M. (2016). Complexity, Training Paradigm Design, and the Contribution of Memory Subsystems to Grammar Learning. PLoS ONE. https://doi.org/10.1371/journal.pone.0158812

`q3 · i?` · `causal · r2`

Across all 122 participants and all training conditions, correlations between the WJ-III Auditory Working Memory subtest and grammar learning were non-significant (e.g., baseline simple r = .106, complex r = –.030), so that "working memory did not reliably correlate with grammar learning in any of the three experiments". The authors note this fails to replicate Martin and Ellis but is consistent with Ettlinger et al.

> "A surprising finding was that working memory did not reliably correlate with grammar learning in any of the three experiments."
