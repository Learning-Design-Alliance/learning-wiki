## Evidence

### Leila Etemadi 2023

Leila Etemadi, Dan-Anders Jirenhed and Anders Rasmussen. (2023). Effects of working memory load and CS-US intervals on delay eyeblink conditioning. npj Science of Learning 8:16. https://doi.org/10.1038/s41539-023-00167-w

`q2 · i?` · `causal · r1`

Secondary linear mixed effects model including only working memory group participants tested whether relative ranking on working memory performance predicted CR percentage. "The results showed this was not the case" with no statistically significant effect; no effect size was printed.

> "In a separate model, which included only participants that did the working memory tasks, we tested whether a subject ’s relative ranking on working memory performance predicted the percentage of CRs. The results showed this was not the case ( t = 1.3189, P = 0.18, CI = −0.9 to 5.0%)."
