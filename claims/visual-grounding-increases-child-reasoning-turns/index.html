Evidence¶

LUO Lan 2024¶

LUO Lan, WANG Anqi, ZHOU Muzhi, ZHU Junhua, CAI Jie, YU Ao, and PAN Hui. (2024). ParaTutor: Coordinating Parent-Child Math Tutoring through Role-Separated LLM Scaffolding. https://arxiv.org/abs/2606.18030 doi:10.48550/arxiv.2606.18030

q2 · i? · causal · r2

Interaction coding of 23 parent-child dyads across four counterbalanced tutoring conditions in a Latin Square design. Dyad-by-mode counts aggregated across three problems per condition showed children "produced more reasoning turnsin Mode C" and Mode D than in Mode A and Mode B. No effect size or significance test reported.

"Using dyad-by-mode counts aggregated across the three problems in each condition, childrenproduced more reasoning turnsin Mode C (M= 15.52,SD= 3.13) and Mode D (M= 16.83,SD= 3.39) than in Mode A (M= 8.61,SD= 2.79) and Mode B (M= 9.61,SD= 2.80)."
