# The CLI Model Classroom program significantly improves teachers' classroom environment (ES = 0.52, p=0.003) as measured by the ELLCO

## Subclaims
`q3 i2` CLI treatment teachers scored significantly higher than control teachers on the ELLCO general Classroom Environment subscale, with an estimated effect size of 0.52 standard deviations (p=0.003). [→ Parkinson 2015](#parkinson-2015)

## Evidence

### Parkinson 2015

Parkinson, J., Meakin, J., & Salinger, T. (2015). Longitudinal Impacts of the Children's Literacy Initiative Professional Development, Coaching, and Model Classroom Intervention on Early Literacy Achievement. SREE Spring 2015 Conference. https://eric.ed.gov/?id=ED562357

`q3 · i2` · `causal · r2`

Second-year teacher impact analysis of the CLI i3 cluster-randomized study: ELLCO observations of 130 teachers analyzed with a two-level hierarchical model controlling for block, grade, and school-average percent LEP. The printed effect size of 0.52 standard deviations (p=0.003) on classroom environment is a medium effect, described as "the impact on classroom environment was 0.52 standard deviations".

> "The estimated standardized effect size of the CLI Model Classroom program on language and literacy practices was 0.68 standard deviations (p<0.001), and the impact on classroom environment was 0.52 standard deviations (p=0.003), as measured by the ELLCO."
