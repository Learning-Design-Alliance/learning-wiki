## Evidence

### Karen B. Schloss 2021

Karen B. Schloss, Melissa A. Schoenlein, Ross Tredinnick, Simon Smith, Nathaniel Miller, Chris Racey, Christian Castro, and Bas Rokers. (2021). The UW Virtual Brain Project: An immersive approach to teaching functional neuroanatomy. Preprint. [doi:10.1037/tps0000281](https://doi.org/10.1037/tps0000281)

`q2 · i3` · `causal · r2`

In the Classroom Implementation survey (n = 40 students who experienced both lessons, voluntary self-reports on 5-point scales), "Ratings were higher for system pathways" than the other two outcomes; the learning-outcome main effect did not interact with perceptual system.

> "Ratings were higher for system pathways, the key learning outcome for Virtual Brain lessons, compared with sensory input (t(78) = 5.05, p < .001, d = .80) and system purpose (t(78) = 4.42, p < .001, d = .70)."

### Karen B. Schloss 2021 (2)

Karen B. Schloss, Melissa A. Schoenlein, Ross Tredinnick, Simon Smith, Nathaniel Miller, Chris Racey, Christian Castro, and Bas Rokers. (2021). The UW Virtual Brain Project: An immersive approach to teaching functional neuroanatomy. Preprint. [doi:10.1037/tps0000281](https://doi.org/10.1037/tps0000281)

`q2 · i3` · `causal · r2`

A repeated-measures ANOVA on the classroom survey showed "students reported more progress from the auditory system lesson than the visual system lesson" (F(1, 39) = 10.70, p = .002, η2p = .215).

> "The main effect of system indicated students reported more progress from the auditory system lesson than the visual system lesson. This may have been because the auditory lesson was embedded in pre-VR/post-VR activities, using gradual release of instruction (Bransford et al., 2000), whereas the visual system was not."
