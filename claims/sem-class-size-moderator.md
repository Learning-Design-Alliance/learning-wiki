# SEM effectiveness is greatest in small class sizes and non-significant in large classes

## Evidence

### Yao Gege 2025

Yao Gege, Zhang Junlong, Soh Kim Geok, Bai Xiaorong, Xiao Wensheng, Anuar Mohd Ashraff Mohd, Bao Lixia. (2025). Effective implementation of the Sport Education Model in physical education: A meta-analysis of participant and intervention characteristics. PLoS One. https://doi.org/10.1371/journal.pone.0331228

`q3 · i2` · `quant-synthesis · r2`

Subgroup analysis for medium classes (31–50 students) found a significant moderate effect (ES = 0.791, 95% CI 0.192–1.390, P = 0.010).

> "SEM demonstrated a significant moderate positive effect on students in medium class sizes (Effect size = 0.791; P = 0.010)"

### Yao Gege 2025 (2)

Yao Gege, Zhang Junlong, Soh Kim Geok, Bai Xiaorong, Xiao Wensheng, Anuar Mohd Ashraff Mohd, Bao Lixia. (2025). Effective implementation of the Sport Education Model in physical education: A meta-analysis of participant and intervention characteristics. PLoS One. https://doi.org/10.1371/journal.pone.0331228

`q3 · i?` · `quant-synthesis · r2`

Subgroup analysis for large classes (>50 students) found no statistically significant effect (P = 0.837, ES = −0.018); equivalence was not tested.

> "SEM did not achieve statistical significance for physical education learning among students in large class sizes (P = 0.837)"
