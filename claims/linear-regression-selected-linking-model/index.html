NWEA Psychometrics and Analytics. (2024). Predicting Amira Reading Mastery Based on NWEA MAP Reading Fluency Benchmark Assessment Scores. https://www.nwea.org/research/publication/predicting-amira-reading-mastery-based-on-nwea-map-reading-fluency-benchmark-assessment-scores/

Model comparison on the common student sample using Root-Mean-Square Error (Table 3.7); e.g., grade 3 winter RMSE 0.35 for regression versus 0.39 equipercentile and 0.37 mean-sigma. The report notes differences in performance are minimal across models.

"Although the equipercentile method showed slightly better performance for grade 1 data, the linear regression model consistently outperformed all other models for the remaining grades and was therefore selected as the final prediction model."
