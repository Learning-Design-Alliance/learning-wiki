# Across the seven EF performance tasks, the omnibus MANOVA showed a large main effect of Time but no main effect of Treatment condition and only a non-significant trend toward a Treatment x Time interaction

## Subclaims
`q3 i3` The 3x3 repeated measures MANOVA on the seven EF task scores showed a main effect of Time with a printed partial eta squared of ηp2 = .22, a large effect by the article's own scale. [→ Dovis Sebastiaan 2015](#dovis-sebastiaan-2015)

## Evidence

### Dovis Sebastiaan 2015

Dovis Sebastiaan, Van der Oord Saskia, Wiers Reinout W., Prins Pier J. M. (2015). Improving Executive Functioning in Children with ADHD: Training Multiple Executive Functions within the Context of a Computer Game. A Randomized Double-Blind Placebo Controlled Trial. PLoS ONE. https://doi.org/10.1371/journal.pone.0121651

`q3 · i3` · `causal · r3`

Omnibus 3x3 (Treatment condition x Time) repeated measures MANOVA on Stoptask, Stroop, CBTT-fwd, CBTT-bkw, Digit recall, TMT, and Raven scores, analyzed simultaneously in the RCT. It showed "a main effect of Time, F (14,334) = 6.74, p < .001, η p 2 = .22" with no main effect of Treatment condition; the printed effect size for the Time effect is ηp2 = .22, which the article's own scale (.14 = large) rates large.

> "showed a main effect of Time, F (14,334) = 6.74, p < .001, η p 2 = .22, no main effect of Treatment condition, F (14,162) = 1.41, p = .154, η p 2 = .11, and a non-significant trend towards an interaction between Treatment condition and Time, F (28,676) = 1.59, p = .027, η p 2 = .06"
