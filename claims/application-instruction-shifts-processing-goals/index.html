Evidence¶

Knellesen 2024¶

Knellesen, J., Händel, M., & Golke, S. (2024). Effects of reading instructions on pre-service teachers' judgment bias when learning from texts. Metacognition and Learning. https://doi.org/10.1007/s11409-023-09371-w

q3 · i3 · causal · r2

Manipulation check in Experiment 2 using the goal questionnaires: "the average rating of importance for the application processing goals yielded a significant difference between instruction groups" (η² = 0.16); planned contrasts showed the application group rated these goals as more relevant (d = 0.95). Memorization goals showed no group difference.

"As expected, the average rating of importance for the application processing goals yielded a significant difference between instruction groups, F(2, 158) = 8.73, p < .001, η² = 0.16."
