# Changing the default order in which schools are presented induces meaningful changes in the types of schools low-income parents choose

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r?` · `q3`

## Subclaims
`q3 i?` In a randomized factorial experiment, changing the default order of school presentation induced meaningful changes in the types of schools selected by low-income parents. [→ Steven Glazerman 2020](#steven-glazerman-2020)

## Evidence

### Steven Glazerman 2020

Steven Glazerman, Ira Nichols-Barrer, Jon Valant, Jesse Chandler, Alyson Burnett. (2020). The Choice Architecture of School Choice Websites. Journal of Research on Educational Effectiveness, vol. 13, issue 2. https://www.mathematica.org/publications/the-choice-architecture-of-school-choice-websites

`q3 · i?` · `causal · r?`

Randomized factorial experiment with 3,500 low-income parents choosing schools in a hypothetical district. The article reports that "a small design manipulation, such as changing the default order in which schools were presented, induced meaningful changes in the types of schools selected." No effect size is printed.

> "In a sample of 3,500 low-income parents of school-aged children, a small design manipulation, such as changing the default order in which schools were presented, induced meaningful changes in the types of schools selected."
