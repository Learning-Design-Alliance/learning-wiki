## Evidence

### Trevor I. Smith 2020

Trevor I. Smith, Kyle J. Louis, Bartholomew J. Ricci, IV, and Nasrine Bendjilali. (2020). Quantitatively ranking incorrect responses to multiple-choice questions using item response theory. Originally published 2019. [doi:10.1103/physrevphyseducres.16.010107](https://doi.org/10.1103/physrevphyseducres.16.010107)

`q2 · i?` · `associational · r2`

Secondary analysis of combined FMCE response sets from four colleges and PhysPort's Data Explorer; the authors state that using the mirt package, "every response choice within each question has a unique ak value". The usable data set was N = 12,388 response sets, sufficient for the 722 necessary parameters.

> "As a result of using the mirt package to apply the 2PL-NRM nested logit model, every response choice within each question has a unique ak value, implying that all answers are meaningfully different from each other."
