## Evidence

### Latino Francesca 2023

Latino Francesca, Tafuri Francesco, Saraiello Emma, Tafuri Domenico. (2023). Classroom-Based Physical Activity as a Means to Improve Self-Efficacy and Academic Achievement among Normal-Weight and Overweight Youth. Nutrients 15(9):2061. https://doi.org/10.3390/nu15092061

`q3 · i3` · `causal · r2`

Post hoc paired comparisons in the 100-student trial following significant Time × Group interactions on all four standardized motor tests (η2p = 0.19 to 0.79); the control group reported no significant changes (p > 0.05).

> "post hoc analysis showed that, from pre- to post-test, the experimental group made a meaningful increase in standing long jump test (t = 9.86, p < 0.001, d = 1.39 large effect size), Harvard step test (t = 25.78, p < 0.001, d = 3.64, large effect size), push up test (t = 20.42, p < 0.001, d = 2.88, large effect size) and sit and reach test (t = 19.04, p < 0.001, d = 2.69, large effect size)."
