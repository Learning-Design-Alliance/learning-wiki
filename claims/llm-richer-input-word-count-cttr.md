# LLM interfaces elicit learning inputs with significantly higher word count and lexical diversity (CTTR) than search interfaces

## Subclaims
`q2 i?` In a within-subjects experiment, Word Count and Corrected Type Token Ratio of inputs differed significantly between LLM and search conditions with a large effect size, while Number of Inputs showed only a trending non-significant difference. [→ Divekar 2025](#divekar-2025)

## Evidence

### Divekar 2025

Divekar, R. R., Guerra, S., Gonzalez, L., Boos, N. (2025). Exploring The Interaction-Outcome Paradox: Seemingly Richer and More Self-Aware Interactions with LLMs May Not Yet Lead to Better Learning. arXiv:2511.09458. [doi:10.48550/arXiv.2511.09458](https://doi.org/10.48550/arXiv.2511.09458)

`q2 · i?` · `causal · r2`

Repeated Measures MANOVA of input features from N=20 university students in a within-subjects experiment comparing ChatGPT (LLM) and Google (Search) for learning two topics; univariate tests found Word Count and CTTR differed between conditions "with a large effect size for Word Count and CTTR".

> "Word Count and Corrected Type Token Ratio (CTTR) had a statistically significant difference between the two conditions with a large effect size for Word Count and CTTR but a trending non-statistically significant difference on Number of Inputs."

### Divekar 2025 (2)

Divekar, R. R., Guerra, S., Gonzalez, L., Boos, N. (2025). Exploring The Interaction-Outcome Paradox: Seemingly Richer and More Self-Aware Interactions with LLMs May Not Yet Lead to Better Learning. arXiv:2511.09458. [doi:10.48550/arXiv.2511.09458](https://doi.org/10.48550/arXiv.2511.09458)

`q2 · i?` · `causal · r2`

Descriptive distributions of the same input measures reported in the results text for Fig. 2: LLM word count per input 10.48±7.6 versus Search 5.34±1.25; CTTR 2.02±0.45 versus 1.59±0.2; number of inputs 4.1±2.4 versus 3.15±1.8.

> "Fig. 2 shows the distributions with the LLM conditions having a higher and more distributed Word Count (LLM: 10.48±7.6, Search: 5.34±1.25), CTTR (LLM: 2.02±0.45, Search:1.59±0.2) and Number of Inputs (LLM: 4.1±2.4, Search:3.15±1.8)."
