# Ethical norms for AIED were grouped into a combined matrix of stakeholder sets by main ethical values, with educational institutes the only stakeholder set covering all six values

## Subclaims

## Evidence

### Agarwal 2022

Agarwal, B., Urlings, C., van Lankveld, G., & Klemke, R. (2022). Identifying the Ethical Values and Norms of Artificial Intelligence in Education: a Systematic Literature Review. Open University of the Netherlands. https://orcid.org/0000-0002-7347-8465

`q2 · i?` · `review · r2`

Analysis step of the systematic review in which 15 articles' ethical norms, coded alphanumerically, were grouped per stakeholder set (after Smuha, 2022) and per main ethical value, then combined into a matrix (Table 9). The review reports educational institutes' norm counts and that this is "the only stakeholder set that contains ENs for all six main EVs".

> "For Educational institutes, the most number of ENs are available for Human Oversight (eight ENs), followed by Data Stewardship (six ENs) and Non-discrimination (five ENs). This is the only stakeholder set that contains ENs for all six main EVs."
