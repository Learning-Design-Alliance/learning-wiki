## Evidence

### Duncombe Justin M.T. 2026

Duncombe Justin M.T., Camaly de Brosses Pierre, Kassam Al-Amin M., Harris David J., Buckingham Gavin. (2026). Investigating Hip Arthroplasty Femur Preparation Training Using a Haptic-Enabled Virtual Reality Simulation. Surgical Innovation, 33(2), 169-180. https://doi.org/10.1177/15533506251383830

`q3 · i0` · `causal · r2`

An orthopaedic consultant blinded to group condition rated recorded SawBone performances using the Global Assessment 5-Point Rating Scale, randomized video order. The study found "no significant difference in technical skills was found between the VR (median = 13, IQR = 12) and control groups (median = 12, IQR = 10)" (r = 0.085).

> "no significant difference in technical skills was found between the VR (median = 13, IQR = 12) and control groups (median = 12, IQR = 10), z = 0.380, P = .704, r = 0.085"
