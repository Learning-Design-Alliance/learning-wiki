Broad sensitivity network meta-analysis. Because Akil (39) was Cooperative's only contributing study, "its exclusion removed the Cooperative node rather than changing estimates among the remaining connected treatments." The extreme rank is a single-study artifact.

"In the 19-study broad network, Cooperative produced the largest estimated effect and the highest P-score (P-score = 0.994; SMD = 3.855, 95% CI 2.141 to 5.568), but this node was defined solely by Akil (39) and therefore did not constitute replicated evidence."
