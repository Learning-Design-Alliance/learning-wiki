## Evidence

### Harada Hitoshi 2017

Harada Hitoshi, Kanaji Shingo, Nishi Masayasu, Otake Yoshito, Hasegawa Hiroshi, Yamamoto Masashi, Matsuda Yoshiko, Yamashita Kimihiro, Matsuda Takeru, Oshikiri Taro, Sumi Yasuo, Nakamura Tetsu, Suzuki Satoshi, Sato Yoshinobu, Kakeji Yoshihiro. (2017). The learning effect of using stereoscopic vision in the early phase of laparoscopic surgical training for novices. Surgical Endoscopy. https://doi.org/10.1007/s00464-017-5654-2

`q3 · i?` · `causal · r2`

Early-phase (first to fifth attempts) group comparison in the same 40-participant crossover study. Median technical errors were lower for the 3D start group on all tasks (task 1: 1.4 vs 1.0, P = 0.047; task 2: 3.8 vs 1.1, P < 0.001; task 3: 12.8 vs 8.6, P < 0.001).

> "During early phase, the performance under 3D was significantly better than under 2D for all tasks, especially in technical error."
