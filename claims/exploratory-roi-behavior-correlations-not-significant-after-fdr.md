# Exploratory ROI volume–behavior correlations within SES groups did not survive FDR correction

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q2` quasi-experiment

## Subclaims
`q2 i?` Exploratory within-group analyses found associations such as greater right hippocampal volume predicting greater working memory in the higher-SES group, but no models reached significance after FDR correction for 12 comparisons. [→ Leonard JA 2015](#leonard-ja-2015)

## Evidence

### Leonard JA 2015

Leonard JA, Mackey AP, Finn AS and Gabrieli JDE (2015) Differential effects of socioeconomic status on working and procedural memory systems. Front. Hum. Neurosci. 9:554. https://doi.org/10.3389/fnhum.2015.00554

`q2 · i?`

Exploratory analyses related each ROI volume to procedural and working memory performance within each SES group. Several uncorrected associations appeared (e.g., right hippocampus with working memory, p = 0.04), but "No models reached signiﬁcance after FDR correction for the 12 comparisons made within each SES group."

> "Within the higher-SES group, greater right hippocampal volume predicted greater working memory [ b = 0.001, t(31) = 2.10, p = 0.04, r2 = 0.08, 95% CI [0.00004, 0.003]], and smaller left caudate volume predicted greater procedural memory learning"
