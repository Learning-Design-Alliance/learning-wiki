## Evidence

### Üstünbaş 2017

Üstünbaş, Ü. (2017). Language Learners' Feelings about Pragmatics in Action. Novitas-ROYAL (Research on Youth and Language), 11(2), 155-168. https://dergipark.org.tr/en/pub/novitasroyal

`q2 · i2` · `causal · r1`

Quasi-experimental comparison of pooled treatment groups (N=38 explicit, N=35 implicit) against a control group (N=35) using the Mann-Whitney U test on VKS-based pre- and post-test scores; the article reports the post-test difference "had a large effect size (d=0.7)".

> "there was no statistically significant difference between treatment and control groups in the pre-test (U=1188.5, p=.55) which had a small effect size according to Cohen's d (1988), there was a statistically significant difference between treatment and control groups in the post- test (U=103.5, p=.000) which had a large effect size (d=0.7)."
