Evidence¶

human-pilot¶

Iyiola E. Olatunji, Alberick Euraste Djire, Jacques Klein, and Tegawendé F. Bissyandé. 2026. Do Not Copy/Paste: Soft Barriers for Copying in AI-Assisted Programming. Proceedings of the 41st IEEE/ACM International Conference on Automated Software Engineering (ASE '26). https://doi.org/10.1145/3832783.3834554

q2 · i? · causal · r1

Exploratory behavioral pilot with 18 participants using GPT-5.2 in a browser-based tool with two Python tasks; Group A used an invisible-character system prompt, Group B the same model without intervention. Likert responses and clipboard/submission logs were collected; results appear in Table 4.

"Group A reported less direct copying and more code modification than Group B (4.00 vs. 1.00 for Task 1; 3.67 vs. 1.00 for Task 2), consistent with a shift toward editing and reconstruction."
