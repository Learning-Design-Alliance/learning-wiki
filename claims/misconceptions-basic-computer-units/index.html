Evidence¶

Unal Cakiroglu 2017¶

Unal Cakiroglu, Huseyin Yilmaz. (2017). Using Videos and 3D Animations for Conceptual Learning in Basic Computer Units. Contemporary Educational Technology, 8(4), 390-405. https://eric.ed.gov/?id=EJ1158165

q2 · i? · causal · r1

Qualitative analysis of pre-test responses on the three-phase concept test identified frequently-faced misconceptions, e.g. "processors only exist in the personal computers" and confusion of ram memory with hard disks. The article lists unit-specific misconceptions in the Results section.

"It was observed that various kinds of misconceptions existed in the computer system units such as ethernet card, ram, hard disk, optic disk, processor or graphic card."
