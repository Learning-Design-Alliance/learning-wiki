Evidence¶

Gao X 2026¶

Gao X (2026) From unified to differentiated materials: generative AI–supported adaptation of EAP reading materials. Front. Psychol. 17:1887565. https://doi.org/10.3389/fpsyg.2026.1887565

q2 · i? · causal · r2

Automated structural-complexity analysis treating each material version as the unit of analysis, using six z-standardized indicators and leave-one-out cross-validated linear discriminant analysis. The result shows "limited structural separation" — the differentiated versions did not form a stable passage-level structural gradient.

"The six selected indicators yieldedη2 p = 0.043, and the leave-one-out classiﬁcation accuracy was 11.1%, compared with the 33.3% benchmark for the balanced three-label task."
