# Learners attempted more coding quizzes and example-code experiments in EDBook than with webpage content plus ChatGPT

## Subclaims
`q2 i?` Participants made significantly more attempts to answer quiz questions and experiment with example code in the EDBook condition than in the webpage-plus-ChatGPT condition (p < 0.001, ANOVA). [→ Steve Oney 2024](#steve-oney-2024)

## Evidence

### Steve Oney 2024

Steve Oney, Yue Shen, Fei Wu, Young Suh Hong, Ziang Wang, Yamini Khajekar, Jiacheng Zhang, and April Yi Wang. (2024). EDBooks: AI-Enhanced Interactive Narratives for Programming Education. [doi:10.48550/arXiv.2411.10687](https://doi.org/10.48550/arXiv.2411.10687)

`q2 · i?` · `causal · r1`

In the same within-subjects study of 20 learners, the number of attempts to try example code differed significantly between conditions (p < 0.001, ANOVA), with means of 0.95 in EDBook versus 0.40 in the webpage condition. The article reports no effect size for this difference.

> "participants in theCEDBook (𝑥 = 0.95, 𝜎=0.13) made more attempts to answer the quiz questions and experiment with the example code than those in theCWeb+GPT (𝑥 = 0.40, 𝜎=0.36)"
