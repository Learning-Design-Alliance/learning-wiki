Pearson correlation analysis in the Results section of the 133-child study; correlations are negative because high BRIEF-2 scores indicate problems. The quote reports the printed r values and p < 0.01 for both named factors across the three achievement criteria.

> "task supervision was more relevant for general academic achievement (r = −0.531, p < 0.01) than working memory (r = −0.512, p < 0.01), but working memory was more relevant for specific achievements, such as those in Mathematics (r = −0.505, p < 0.01) and Language Arts (r = −0.475, p < 0.01)"
