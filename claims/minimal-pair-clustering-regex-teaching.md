## Subclaims
`q2 i?` Strings within teacher corpora cluster by edit distance far more than expected by chance, reflecting minimal-pair teaching of the concept boundary. [→ Long Ouyang 2017](#long-ouyang-2017)

## Evidence

### Long Ouyang 2017

Long Ouyang, Michael C. Frank (2017). Pedagogical learning. 31st Conference on Neural Information Processing Systems (NIPS 2017). [doi:10.48550/arXiv.1711.09401](https://doi.org/10.48550/arXiv.1711.09401)

`q2 · i?` · `associational · r1`

Clustering analysis of corpora generated by Mechanical Turk teachers for four regexes: strings clustered by edit distance (threshold 2) gave "the number of clusters per corpus (3.27)", far below the bootstrapped chance interval of 4.98—5.11 (p < 0.0001).

> "if we cluster the strings within corpora by edit distance with a threshold of 2, we ﬁnd that the number of clusters per corpus (3.27) is far lower than would be expected by chance,p < 0.0001, 95% CI for bootstrapped permutation test with 1000 samples: 4.98—5.11."
