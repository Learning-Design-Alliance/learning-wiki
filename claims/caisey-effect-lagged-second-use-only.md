## Evidence

### Wang 2026

Wang, D. J., Jain, N. M., Burbano, V., Guzman, J., Keum, D., Kim, S., Kogut, B., & Wright, N. (2026). How assigned AI use before class shapes active student engagement in class. Originally published 2025. [doi:10.2139/ssrn.7585318](https://doi.org/10.2139/ssrn.7585318)

`q4 · i?` · `causal · r3`

Next-session and all-future-sessions horizons of the same panel models. A first assigned opportunity showed no benefit: lower next-session participation after qualifying use (β1 = −0.151, p < 0.05) and no detectable all-future-sessions effect; no effect size printed.

> "In the next session, participation was lower after qualifying use at the first assigned opportunity (Supplementary Table S4, Model 5: 𝛽1 = −0.151, SE = 0.066, p < 0.05), and across all future sessions it was not detectably different from zero (Model 7: 𝛽1 = −0.059, SE = 0.087, p > 0.1; Figure 2)."

### Wang 2026 (2)

Wang, D. J., Jain, N. M., Burbano, V., Guzman, J., Keum, D., Kim, S., Kogut, B., & Wright, N. (2026). How assigned AI use before class shapes active student engagement in class. Originally published 2025. [doi:10.2139/ssrn.7585318](https://doi.org/10.2139/ssrn.7585318)

`q4 · i?` · `causal · r3`

Next-session horizon of the same randomized panel models. The second assigned opportunity raised next-session participation under both assignment (β2 = 0.091, p < 0.05) and qualifying use (β2 = 0.183, p < 0.05); no standardized effect size printed.

> "After the second assigned opportunity, students participated more in the next session, whether measured by assignment (Supplementary Table S4, Model 4: 𝛽2 = 0.091, SE = 0.043, p < 0.05) or by qualifying use (Model 5: 𝛽2 = 0.183, SE = 0.087, p < 0.05)."
