# Contiguity effects show no statistically reliable difference between static and dynamic presentation of visual information

> **Claim** · [All claims](index.md)

## Subclaims
`q3 i?` Moderation of the contiguity effect by static versus dynamic presentation was not statistically reliable, suggesting split-attention costs occur across media. [→ Ginns 2006](#ginns-2006)

## Evidence

### Ginns 2006

Ginns, P. (2006). Integrating information: A meta-analysis of the spatial contiguity and temporal contiguity effects. Learning and Instruction, 16(6), 511-525. https://doi.org/10.1016/j.learninstruc.2006.10.001

`q3 · i?` · `quant-synthesis · r2`

Moderator analysis within the meta-analysis comparing effects from static (e.g. textbook page) versus dynamic (e.g. computer animation) presentations. The article reports "no statistically reliable difference was found", supporting the claim that cognitive load factors matter regardless of medium.

> "For the “static versus dynamic  presentation” moderator, there was one study that was coded as using both static and dynamic presentation (Bodemer et al., 2004), and this study was excluded from this moderation test; no statistically reliable difference was found between effects from static versus dynamic presentation studies."
