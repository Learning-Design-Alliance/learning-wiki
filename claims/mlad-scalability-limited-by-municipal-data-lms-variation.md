In the implementation phase the authors report that "each municipality had different educational data sources" and varied LMS platforms, requiring customization; teachers' differing familiarity with data-driven dashboards also required targeted support.

> "Each municipality had different educational data sources, and the learning management systems (LMS) used by each municipality varied. This made it difficult to create a one-size-fits-all solution for all municipalities."
