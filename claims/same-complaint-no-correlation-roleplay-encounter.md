# Role-play scores did not correlate with next-day patient-encounter scores when the complaint was the same

## Subclaims
`q2 i1` For cases where the role-play complaint was the same as the patient encounter's (N = 13), history-taking correlated at r = -.10, physical examination at r = -.16, and communication at r = .57; for different complaints (N = 51), history-taking r = .57, physical examination r = .27, communication r = .43. ## Evidence

### Yamauchi Kazuyo 2021

Yamauchi Kazuyo, Hagiwara Yoko, Iwakura Nahoko, Kubo Saori, Sato Azusa, Ohtsuru Tadahiko, Okazaki Ken, Okubo Yumiko. (2021). Using peer role-playing to improve students’ clinical skills for musculoskeletal physical examinations. BMC Medical Education. https://doi.org/10.1186/s12909-021-02742-4

`q2 · i1` · `causal · r2`

Correlational analysis of mini-CEX scores between role-play and next-day patient encounters, split by whether the complaint was the same (N = 13) or different (N = 51). The article prints "r = -.10 for the same complaint and r = .57 for different complaints" for history-taking and corresponding values for the other domains.

> "For history-taking, the correlation coefficient was r = -.10 for the same complaint and r = .57 for different complaints. For physical examination, it was r = -.16 for the same complaint and r = .27 for different complaints. For communication, it was r = .57 for the same complaint and 0.43 for different complaints."
