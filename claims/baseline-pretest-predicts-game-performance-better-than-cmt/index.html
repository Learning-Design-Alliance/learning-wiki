Evidence¶

Prell et al. 2012¶

Jerry Prell, William R. Nelson, and John Foshay. (2012). The Effectiveness of Learning Geography Using Computer-based Games. Journal of Special Education Apprenticeship, Vol. 1, No. 2. https://sheppardsoftware.com/USA_Geography/USA_G2_double2.html

q2 · i3 · causal · r2

SPSS regression analysis from the matched-pairs study testing CMT and baseline U.S.A. scores as predictors of game performance; U.S.A. baseline also yielded r = 0.549 for distance error and r = 0.369 for seconds.

"the r value of percent correct for U.S.A. tests as dependent variable was 0.627, meaning for percent correct, U.S.A. tests were a strong predictor of student performance."

Prell et al. 2012 (2)¶

Jerry Prell, William R. Nelson, and John Foshay. (2012). The Effectiveness of Learning Geography Using Computer-based Games. Journal of Special Education Apprenticeship, Vol. 1, No. 2. https://sheppardsoftware.com/USA_Geography/USA_G2_double2.html

q2 · i2 · causal · r1

Same regression analysis: CMT math spatial-reasoning scores showed weak correlations with all three performance measures (r = 0.292, 0.167, 0.170), which the authors describe as unexpected given prior spatial-ability findings.

"With CMT scores as the dependent variable, percent correct had an r value of 0.292. Therefore, CMT scores are a weak predictor of student outcomes for percent correct."
