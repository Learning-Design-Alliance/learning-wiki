# Mobile-3G classroom use produced off-task use, network difficulties and classroom-design problems, and network troubles were linked to reduced student liking

## Subclaims
`q1 i?` Teacher observations identified off-task mobile use (games, instant messaging), a traditional lecture room ill-suited to group work, few power outlets, and network connection problems. [→ Jabbour 2014](#jabbour-2014)
`q1 i?` The authors attribute the observed negative effect on student liking to difficulties with network and 3G access. [→ Jabbour 2014 (2)](#jabbour-2014-2)

## Evidence

### Jabbour 2014

Khayrazad Kari Jabbour. (2014). An Analysis of the Effect of Mobile Learning on Lebanese Higher Education. Informatics in Education, 13(1), 1–15. https://informatica.vu.lt/journal/informatics-in-education

`q1 · i?` · `causal · r1`

Qualitative observation and discussion-group findings in section 4.5.3; off-task use occurred more toward the end of sessions and among students seated in back rows, and the room hindered seat rearrangement for teamwork.

> "One issue that was identified by the teacher observations that there were some participants who chose to use the mobile for activities that is not related classes, such as such as playing games or instant messaging."

### Jabbour 2014 (2)

Khayrazad Kari Jabbour. (2014). An Analysis of the Effect of Mobile Learning on Lebanese Higher Education. Informatics in Education, 13(1), 1–15. https://informatica.vu.lt/journal/informatics-in-education

`q1 · i?` · `causal · r1`

Authors' interpretation in the discussion, offered as an explanation for reduced liking; when 3G connection problems occurred students could not use the net and struggled with class assignments.

> "One explanation for this nega - tive effect on student attitudes seems to be associated to troubles with network and 3G accesses."
