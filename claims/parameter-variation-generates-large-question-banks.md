## Subclaims
`q2 i?` By changing input parameters of a single problem setup, instructors can produce many different instances of the same problem in GIFT format, extending the complexity of problems beyond Moodle's built-in calculated questions. [→ Jon Sáenz 2020](#jon-saenz-2020)

## Evidence

### Jon Sáenz 2020

Jon Sáenz, Idoia G Gurtubay, Zunbeltz Izaola and Gabriel A López. (2020). pygiftgenerator: A python module designed to prepare Moodle-based quizzes. Submitted to Eur. J. Phys. [doi:10.1088/1361-6404/abb114](https://doi.org/10.1088/1361-6404/abb114)

`q2 · i?` · `design · r2`

The article's methodological demonstration (Sections 2–4): the module takes a single problem setup, randomizes input parameters either from user-specified lists or from random number generators, and emits many question instances. "many different instances of the same problem can be easily produced in GIFT format", each with its answer recalculated for the new parameter values.

> "Since the system works by allowing to change the values for the parameters involved in the problem, many diﬀerent instances of the same problem can be easily produced in GIFT format."
