## Evidence

### Amita Goyal Chin 2016

Amita Goyal Chin, Ugochukwu Etudo, Mark A. Harris. (2016). On Mobile Device Security Practices and Training Efficacy: An Empirical Study. Informatics in Education, 15(2). https://doi.org/10.15388/infedu.2016.12

`q2 · i?` · `causal · r1`

Separate MANOVA testing H2 with device-feature practices as dependent variables in the same two-group quasi-experiment. The omnibus test was non-significant ("F (3, n = 344) = .748, p = .524"), and no univariate effect was significant.

> "We found no statistically significant difference between treatment groups on these dependent variables. Results of the omnibus MANOV A are F (3, n = 344) = .748, p = .524; Wilk's Λ = .993, Partial η 2 = .007."
