LUO Lan 2024¶

LUO Lan, WANG Anqi, ZHOU Muzhi, ZHU Junhua, CAI Jie, YU Ao, and PAN Hui. (2024). ParaTutor: Coordinating Parent-Child Math Tutoring through Role-Separated LLM Scaffolding. https://arxiv.org/abs/2606.18030 doi:10.48550/arxiv.2606.18030

q2 · i? · causal · r2

Interaction coding from the same 23-dyad counterbalanced user study. Child-initiated questions "showed the same pattern" across conditions, with higher means in both ParaTutor modes than either baseline. No effect size or significance test reported.

"Child-initiated questionsshowed the same pattern, increasing from Mode A (M= 1.74,SD= 0.92) and Mode B (M= 2.09,SD= 0.95) to Mode C (M= 3.61,SD= 1.03) and Mode D (M= 4.09,SD= 1.08)."
