`q3 · i?` · `associational · r2`

Experiment 2 (N = 81 children, ages 4–7) replicated Experiment 1 using only the 15 area trials of the confidence task to reduce fatigue. Correlations controlling for age were significant for Winner and Ask choices but not Endorse choices, per Table 2.

> "In contrast to Experiment 1, and as predicted by the SDT/Simulation account, the Confidence Task correlated with both the Winner and Ask choices, but not with Endorse choices (see Table 2, all correlations controlling for age)."
