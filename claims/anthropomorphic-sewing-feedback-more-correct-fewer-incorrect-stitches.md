# Anthropomorphic video-based sewing instruction that facilitates affordances produced significantly more correct stitches and fewer incorrect stitches than non-anthropomorphic diagram-and-text instruction for both easy and difficult stitch tasks

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q2`

## Subclaims
`q2 i?` In a between-users experiment with 40 participants, the anthropomorphic condition produced significantly more correct and significantly fewer incorrect stitches on both the easier back-stitch task and the more difficult chain-stitch task. [→ Murano 2012](#murano-2012)

## Evidence

### Murano 2012

Murano, P. & Sethi, T. (2012). Anthropomorphic User Interface Feedback in a Sewing Context and Affordances. International Journal of Advanced Computer Science and Applications, Vol. 2, No. 4. Originally published 2011. [doi:10.48550/arXiv.1208.3323](https://doi.org/10.48550/arXiv.1208.3323)

`q2 · i?` · `causal · r2`

Between-users experiment in which 40 sewing novices were randomly allocated to an anthropomorphic video tutorial or a non-anthropomorphic static diagram-and-text tutorial with identical instructional content. MANOVA showed "a significant (p < 0.01) difference" favouring the anthropomorphic group for correct stitches; equivalent significant differences are reported for incorrect stitches on both tasks (tables I–II, IV–V).

> "For the variables task 1 - number of correct stitches, experimental condition, age range and gender, there is a significant (p < 0.01) difference. The anthropomorphic condition produced significantly more correct stitches than the non-anthropomorphic group"
