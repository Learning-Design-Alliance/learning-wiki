## Evidence

### Loprinzi Paul D. 2019

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i3` · `causal · r2`

Experiment 2 replicated Experiment 1 (n = 77; Mage = 21.10) with a 15-min high-intensity jog (70%–85% of HRmax) and equal story exposure for all four groups. The learning main effect remained significant with a large printed effect size, eta-squared ƞ2 = 0.17; post-hoc Mdiff = 5.90, t = 3.84, p < 0.001.

> "but there was a significant main effect for learning, F(1, 73) = 14.76, p < 0.001, ƞ2 = 0.17. Post-hoc tests were computed for the learning factor, which demonstrated a significantly greater memory performance for those who received the learning manipulation"

### Loprinzi Paul D. 2019 (2)

Loprinzi Paul D., Harris Faith, McRaney Kyle, Chism Morgan, Deming Raymond, Jones Timothy, Zou Liye, Tan Miaoqing. (2019). Effects of Acute Exercise and Learning Strategy Implementation on Memory Function. Medicina. https://doi.org/10.3390/medicina55090568

`q3 · i3` · `causal · r2`

In Experiment 2's mixed-measures ANOVA, the within-subject time factor was significant with a large printed effect size, eta-squared ƞ2 = 0.29; post-hoc tests showed significantly greater short-term than long-term memory (Mdiff = 1.58, t = 5.65, p < 0.001).

> "there was a main effect for time, F(1, 73) = 30.68, p < 0.001, ƞ2 = 0.29, but no time by learning interaction"
