Evidence¶

Selbing 2025¶

Selbing, I., Becker, N., Pan, Y., Lindström, B., & Olsson, A. (2025). Effects of described demonstrator ability on brain and behavior when learning from others. npj Science of Learning. https://doi.org/10.1038/s41539-024-00292-0

q3 · i? · causal · r2

Manipulation-check analysis using Cumulative Link Models of performance ratings from 37 participants (one excluded for missing ratings). Ratings ran from one (very poor) to five (very good); the description effect was β = 2.32, Z = 4.10, p ≤ 0.001.

"Indeed, demonstrators described as Best vs. Worst were rated as performing better (β = 2.32,SE = 0.57,Z = 4.10,p ≤ 0.001), Fig.1."
