# The effort versus no self-talk contrast improved mathematics performance overall, via within-person improvement in the effort condition only

## Subclaims
`q3 i?` The effort versus no self-talk contrast main effect on postmanipulation mathematics performance was significant (t = 2.254, p = .025, b = .122). [→ Thomaes 2020](#thomaes-2020)
`q3 i2` In the effort self-talk condition, mathematics performance improved from baseline to postmanipulation (Δ = .158, ηp² = .057); in the control condition it did not change significantly. [→ Thomaes 2020 (2)](#thomaes-2020-2)

## Evidence

### Thomaes 2020

Thomaes, Tjaarda, Brummelman, and Sedikides. (2020). Effort Self‐Talk Benefits the Mathematics Performance of Children With Negative Competence Beliefs. Child Development, 91(6), 2211–2220. https://doi.org/10.1111/cdev.13347

`q3 · i?` · `causal · r2`

First hierarchical regression analysis of the field experiment (N = 212): the effort versus no self-talk contrast main effect on standardized postmanipulation performance "was significant, t = 2.254, p = .025, b = .122".

> "The effort versus no self‐talk contrast main effect (i.e., first analysis) was significant, t = 2.254, p = .025, b = .122."

### Thomaes 2020 (2)

Thomaes, Tjaarda, Brummelman, and Sedikides. (2020). Effort Self‐Talk Benefits the Mathematics Performance of Children With Negative Competence Beliefs. Child Development, 91(6), 2211–2220. https://doi.org/10.1111/cdev.13347

`q3 · i2` · `causal · r2`

Within-condition analysis in the effort self-talk condition (N = 69): performance "improved from baseline to postmanipulation (i.e., within‐person change)", Δ = .158, ηp² = .057.

> "Separate analyses by condition showed that, in the effort self‐talk condition, children’s mathematics performance improved from baseline to postmanipulation (i.e., within‐person change), Δ = .158, SD = 0.643, F = 4.021, p = .049, ηp 2 = .057."

### Thomaes 2020 (3)

Thomaes, Tjaarda, Brummelman, and Sedikides. (2020). Effort Self‐Talk Benefits the Mathematics Performance of Children With Negative Competence Beliefs. Child Development, 91(6), 2211–2220. https://doi.org/10.1111/cdev.13347

`q3 · i?` · `causal · r2`

Same within-condition analysis in the no self-talk control condition (N = 70): performance change "did not, Δ = −.128, SD = 0.748, F = 2.041, p = .158, ηp 2 = .029".

> "In the no self‐talk control condition, it did not, Δ = −.128, SD = 0.748, F = 2.041, p = .158, ηp 2 = .029."
