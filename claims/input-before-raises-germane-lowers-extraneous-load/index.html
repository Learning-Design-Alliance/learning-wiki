Evidence¶

Julia Kienzler 2023¶

Julia Kienzler, Thamar Voss, Jörg Wittwer. (2023). Student teachers' conceptual knowledge of operant conditioning: How can case comparison support knowledge acquisition? Instructional Science. https://doi.org/10.1007/s11251-023-09627-7

q3 · i3 · causal · r2

MANCOVA on self-report cognitive load (Leppink-adapted questionnaire) in the 2×2 experiment. Printed effect sizes: ηp² = 0.26 omnibus; univariate tests showed timing effects on "extraneous load, F(2, 169) = 49.29, p < .001, ηp2 = 0.23, and germane load, F(2, 169) = 32.73, p < .001, ηp2 = 0.61".

"We found a large and significant main effect of timing of input, F(2, 169) = 29.60, p < .001, ηp2 = 0.26, but no significant effect of provision of key features, F(2, 169) = 0.18, p = .834, ηp2 = 0.002"
