Evidence¶

Kueider Alexandra M. 2012¶

Kueider Alexandra M., Parisi Jeanine M., Gross Alden L., Rebok George W. (2012). Computerized Cognitive Training with Older Adults: A Systematic Review. PLoS ONE. https://doi.org/10.1371/journal.pone.0040588

q2 · i3 · review · r3

Review synthesis of a 12-week working memory training study (Buschkuehl et al.) in older adults aged 77 to 84. The review reports improved performance "transferred to non-trained working memory tasks (block span: d = 1.34; digit span: d = 0.29)" and visual memory.

"Additionally, improved performance transferred to non-trained working memory tasks (block span: d = 1.34; digit span: d = 0.29) and visual memory (visual free recall: d = 0.26)."
