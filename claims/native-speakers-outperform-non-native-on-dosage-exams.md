`q3 · i2` · `causal · r2`

Welch t-test across the full sample of 120 students compared performance by native language status, showing a "medium effect size (Cohen d = 0.53)" favoring native speakers.

> "Native language speakers demonstrated significantly higher performance scores (M = 7.17, SD = 1.26) than nonnative speakers (M = 5.89, SD = 1.62), t(72.4) = 4.17, P < .001, representing a medium effect size (Cohen d = 0.53)."
