Evidence¶

Lortie-Forgues 2017¶

Lortie-Forgues, Hugues and Siegler, Robert S (2017) Conceptual knowledge of decimal arithmetic. Journal of Educational Psychology. pp. 374-391. ISSN: 0022-0620. https://doi.org/10.1037/edu0000148

q3 · i2 · causal · r2

Study 2 judgment-only task with 54 7th graders: the operation X whole number operand X decimal size interaction was significant (F(2, 88) = 3.48, p = 0.035, ηp2 = 0.073); "direction of effect judgments were more accurate when one operand was a whole number" only for multiplication below one.

"direction of effect judgments were more accurate when one operand was a whole number (WD problems) (M = 47%, SD = 47%) than when both operand were decimals (DD problems) (M = 31%, SD = 42%) (t(53) = 2.97, p < 0.01, Cohen’s d = 0.41)."
