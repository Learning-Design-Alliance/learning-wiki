Evidence¶

Joanne Eaves 2018¶

Joanne Eaves, Nina Attridge, Camilla Gilmore. (2018). Increasing the use of conceptually-derived strategies in arithmetic: using inversion problems to promote the use of associativity shortcuts. Learning and Instruction. https://figshare.com/s/230ee9491e0b67d9d3f3

q3 · i3 · associational · r1

Study 2 validity analysis comparing problem-solving performance of self-reported users versus non-users. Users solved "significantly more conducive problems correctly" with a large effect (d = 1.28) but showed no significant difference on non-conducive problems (d = 0.32).

"Users solved significantly more conducive problems correctly (M = 11.79, SD = 5.89) than non-users (M = 4.96, SD = 4.80), t(49) = 4.56, p <0.001, d = 1.28, and attempted more conducive problems (M = 12.25, SD = 5.46) than non-users (M = 5.67, SD = 4.55), t(49) = 4.70, p <0.001, d = 1.32."
