## Evidence

### Javier Pulgar 2019

Javier Pulgar, Carlos Rios and Cristian Candia. (2019). Physics problems and instructional strategies for developing social networks in university classrooms. [doi:10.48550/arXiv.1904.02840](https://doi.org/10.48550/arXiv.1904.02840)

`q3 · i?` · `associational · r2`

OLS regression model 5 (Table 1) on in-degree centrality — the number of incoming ties, indicating "the degree to which students were sought for advice during the problem solving session" — with 79 observations and R2 = 0.309. Class 2 exceeded Class 1 significantly; Class 3 did not differ significantly from Class 1.

> "Coeﬃcients indicate that in Class 2 students were more connected compared to Class 1 (1.977, p <0.01), while this diﬀerence is not signiﬁcant between Class 3 and 1."
