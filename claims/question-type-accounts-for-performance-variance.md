### Brockbank 2025

Brockbank, E., Verma, A., Lloyd, H., Huey, H., Padilla, L., & Fan, J. E. (2025). Evaluating convergence between two data visualization literacy assessments. Cognitive Research: Principles and Implications. https://doi.org/10.1186/s41235-025-00622-9

`q3 · i?` · `associational · r2`

Mixed-effects logistic regression of item accuracy on question type in the Results section; the question-type effect was larger in the demographically representative sample (overall χ2(10) = 94.18, p < .0001). No effect size is printed.

> "performance reliably varied by question type, both when each assessment was analyzed independently (GGR: χ2(2) = 1331.61, p < .0001; VLAT: χ2(7) = 1981.92, p < .0001; Fig. 5) and when conducting the same analysis for all 11 question types in both assessments (χ2(10) = 3585.91, p < .0001)"
