# Larger font sizes produce higher judgments of learning than smaller font sizes, with a small-to-moderate pooled effect

## Subclaims
`q3 i?` Across studies, font size has a small-to-moderate effect on judgments of learning. [→ Chang 2022](#chang-2022)

## Evidence

### Chang 2022

Chang, M., Brainerd, C.J. (2022). Association and dissociation between judgments of learning and memory: A Meta-analysis of the font size effect. Metacognition and Learning. https://doi.org/10.1007/s11409-021-09287-3

`q3 · i?`

Meta-analysis of studies providing JOL data for the font size effect, using univariate and multivariate meta-regressions to isolate moderators. The pooled result was "a small-to-moderate effect of font size on JOLs"; no standardized effect size value is printed in the available text.

> "The results revealed a small-to-moderate effect of font size on JOLs."
