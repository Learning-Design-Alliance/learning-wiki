Evidence¶

Mutlu Cukurova 2025¶

Mutlu Cukurova, Wannapon Suraworachet, Qi Zhou, and Sahan Bulathwela. (2025). Towards Synergistic Teacher-AI Interactions with Generative Artificial Intelligence. https://arxiv.org/abs/2511.19580 doi:10.48550/arxiv.2511.19580

q1 · i? · theoretical · r3

Definitional/descriptive analysis adapting Russell and Norvig's agent framework to GenAI: the chapter argues GenAI maintains prior contextual understanding (model-based), executes actions per user prompts (goal-based), and can improve via deliberate fine-tuning, but not autonomously. The chapter states it is difficult to categorise without model specifics.

"These five agent types are: simple-reflex, model-based, goal-based, utility-based and learning agents."
