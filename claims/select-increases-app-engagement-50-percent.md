## Evidence

### Utkarsh Upadhyay 2021

Utkarsh Upadhyay, Graham Lancashire, Christoph Moser, and Manuel Gomez-Rodriguez. (2021). Large-scale randomized experiment reveals machine learning helps people learn and remember more effectively. arXiv. Originally published 2020. [doi:10.1038/s41539-021-00105-8](https://doi.org/10.1038/s41539-021-00105-8)

`q3 · i?` · `causal · r2`

Engagement analysis using Firebase Analytics comparing the three randomized groups (Table 1); engagement is return within 4–7 days. Table 1 reports select improvement of +50.6% (+43.7% to +57.7%) over baseline with probability to be best of 80%. No standardized effect size is printed.

> "learners of the 'select' ('diﬃculty') group were 50.6% (47.6%) more likely, in median, to return to the app within 4–7 days than learners of the 'random' group. Moreover, Firebase Analytics estimates that, with probability 80%, the Select algorithm is the top performer in terms of engagement."
