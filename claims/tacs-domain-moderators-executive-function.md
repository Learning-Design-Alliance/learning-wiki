## Subclaims
`q3 i1` Online theta-band tACS significantly improved executive function/complex attention (SMD = 0.325); online gamma improved executive function (SMD = 0.154) and perceptual-motor function (SMD = 0.264); offline theta improved executive function (SMD = 0.204). ## Evidence

### Tae Lee Lee 2023

Tae Lee Lee, Hanall Lee and Nyeonju Kang. (2023). A meta-analysis showing improved cognitive performance in healthy young adults with transcranial alternating current stimulation. npj Science of Learning 8:1. https://doi.org/10.1038/s41539-022-00152-9

`q3 · i1` · `quant-synthesis · r3`

Fourth moderator analysis of online-tACS comparisons by cognitive domain found significant effects for executive function with theta (SMD = 0.325) and gamma (SMD = 0.154), and for perceptual-motor function with gamma (SMD = 0.264); remaining conditions were not significant. Offline theta on executive function was also significant (SMD = 0.204).

> "(a) 17 executive function / complex attention in the theta frequency band comparisons from 14 studies: SMD = 0.325; SE = 0.102; 95% CI = 0.125–0.526; Z = 3.180; P = 0.001"
