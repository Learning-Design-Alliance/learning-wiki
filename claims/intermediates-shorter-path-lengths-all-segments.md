## Evidence

### Gholami Soheil 2024

Gholami Soheil, Manon Anaëlle, Yao Kunpeng, Billard Aude, Meling Torstein R. (2024). An objective skill assessment framework for microsurgical anastomosis based on ALI scores. Acta Neurochirurgica 166(1):104. https://doi.org/10.1007/s00701-024-05934-1

`q3 · i?` · `associational · r1`

Motion-capture analysis of tool-tip path length (MPL) in the anastomosis task; the reported Wilcoxon comparisons across all four segments and both instruments reached significance (e.g., S.1 tweezers U=3.63, p<.001), which the authors link to more accurate, efficient movements.

> "In all segments and for both instruments, the intermediate group of participants demonstrated significantly shorter path lengths compared to the novices"
