# Number naming and number comparison are better predictors of kindergarten arithmetic than number line estimation

## Subclaims

## Evidence

### Praet 2013

Praet, M., Titeca, D., Ceulemans, A., & Desoete, A. (2013). Language in the prediction of arithmetic in kindergarten and grade 1. Learning and Individual Differences (manuscript LAEIND-D-12-OO174R1). https://www.sciencedirect.com/science/article/LAEIND-D-12-OO174R1

`q2 · i?` · `associational · r2`

Second preparatory regression on the 63 kindergarteners with the three estimation tasks simultaneously entered; number naming explained 29.6% of variance in the main model, while NLE (PAE) was non-significant.

> "The regression was significant (F 3, 57) = 11.326, p < .001, R² = .386) for number comparison (p =.009) and number naming (p = .011) but not for number line estimation (p = .199; see Table 2)."
