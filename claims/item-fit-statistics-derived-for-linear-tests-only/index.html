Shudong Wang 2013¶

Presentation paper. https://www.nwea.org/research/publication/the-effect-of-nonignorable-missing-data-in-computerized-adaptive-test-on-item-fit-statistics-for-polytomous-item-response-models/

q1 · i? · causal · r?

The authors' framing statement in the presentation description asserts that fit-statistic research to date concerns linear testing, with adaptive-testing contexts unaddressed; the description offers this assertion without reported data.

"To date, all item fit statistics are derived based on linear tests and almost all studies have been done in the context of linear testing."
