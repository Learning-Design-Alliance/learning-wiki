The article quotes Hattie (2009, p. 88) concluding that "reducing class size has not been a powerful moderator on outcomes", and contrasts this with Glass, McGaw, and Smith (1981): "There is little doubt that, other things equal, more is learned in smaller classes". Both are second-hand quotes used to illustrate meta-analytic inconsistency.

> "“The reader is reminded that meta-analysis is a method of literature review—the lack of effects from lowering class size and these experiences indicate that reducing class size has not been a powerful moderator on outcomes” (Hattie, 2009, p. 88)."
