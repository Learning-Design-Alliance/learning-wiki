### Y. O. Modlo 2018

Y. O. Modlo, S. O. Semerikov. (2018). Xcos on Web as a promising learning tool for Bachelor's of Electromechanics modeling of technical objects. Originally published 2015. [doi:10.48550/arXiv.1808.04203](https://doi.org/10.48550/arXiv.1808.04203)

`q2 · i?` · `design · r1`

Expert evaluation of the most common visual modeling environments, reported in Table 1, scored environments on free availability, supported operating systems, Web interface and modeling libraries. The authors state the weightiest criteria behind choosing Scilab were "наявність бібліотек для моделювання неперервних систем (5 бал ів)" and the Web interface (3 points).

> "Найбільш вагомими критеріями, що зумовили вибір Scilab як засобу навчання моделювання технічних об’єктів бакалаврів електромеханіки, є наявність бібліотек для моделювання неперервних систем (5 бал ів), наявність бібліотек дл я моделювання дискретних систем (5 бал ів) та наявність Web -інтерфейсу (3 бали) ."
