## Evidence

### Desi Anggrianto 2016

Desi Anggrianto, Madziatul Churiyah, Mohammad Arief. (2016). Improving Critical Thinking Skills Using Learning Model Logan Avenue Problem Solving (LAPS)-Heuristic. Journal of Education and Practice, Vol.7, No.9. https://eric.ed.gov/?id=EJ1095745

`q3 · i?` · `causal · r1`

Equivalence testing on UAS end-of-semester Introduction to Economics and Business scores: experimental class mean 82.38 (n=32), control 82.35 (n=31). Normality was 0.111 and homogeneity 0.838, both above 0.05, so classes were judged "similar so it is worth doing the research."

> "The results of the homogeneity test is 0.838> 0.05, which means homogeneous. It can be concluded that the experimental class and control class is similar so it is worth doing the research."
