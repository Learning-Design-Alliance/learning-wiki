## Evidence

### Hapnes Toba 2024

Hapnes Toba, Oscar Karnalim, Meliana Christianti Johan, Terutoshi Tada, Yenni Merlin Djajalaksana, and Tristan Vivaldy. (2024). Inappropriate Benefits and Identification of ChatGPT Misuse in Programming Tests: A Controlled Experiment. Originally published 2023. [doi:10.1007/978-3-031-51979-6_54](https://doi.org/10.1007/978-3-031-51979-6_54)

`q1 · i?` · `causal · r1`

LDA topic modeling of open-ended survey answers Q10-Q13 (8 topics, coherence score 0.749) with a topic relation graph; core keywords such as GPA, rupiah, rectangle, coordinate, box and discount came from the assignment descriptions.

> "In this figure can be inferred that the participants are mainly using a copy-and-paste strategy from the textual description of the programming assignments."

### Hapnes Toba 2024 (2)

Hapnes Toba, Oscar Karnalim, Meliana Christianti Johan, Terutoshi Tada, Yenni Merlin Djajalaksana, and Tristan Vivaldy. (2024). Inappropriate Benefits and Identification of ChatGPT Misuse in Programming Tests: A Controlled Experiment. Originally published 2023. [doi:10.1007/978-3-031-51979-6_54](https://doi.org/10.1007/978-3-031-51979-6_54)

`q1 · i?` · `causal · r1`

Same Q10-Q13 analysis: some participants varied input-output formats, considered the programming language, translated assignments into English, and made "subsequently some adjustments to functions and variable naming".

> "After they found the suitable retrieved code example from ChatGPT, in the subsequent steps they will try to adapt the code and repair it as completely as possible according to the assignment."
