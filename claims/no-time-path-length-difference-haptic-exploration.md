## Subclaims

## Evidence

### Postema Roelf R. 2020

Postema Roelf R., van Gastel Leonie A., Hardon Sem F., Bonjer H. Jaap, Horeman Tim. (2020). Haptic exploration improves performance of a laparoscopic training task. Surgical Endoscopy. https://doi.org/10.1007/s00464-020-07898-6

`q3 · i?` · `causal · r2`

Final-trial comparison of time and path length between the touch and no-touch groups in the same randomized experiment, using non-parametric tests; the authors report "no difference for time and path length for both groups", statistically confirmed, with a path-length trend.

> "One can see from these figures that there is no difference for time and path length for both groups. This was statistically confirmed although for path length a trend seems to be present towards less path length used in the "Touch" group."

### Postema Roelf R. 2020 (2)

Postema Roelf R., van Gastel Leonie A., Hardon Sem F., Bonjer H. Jaap, Horeman Tim. (2020). Haptic exploration improves performance of a laparoscopic training task. Surgical Endoscopy. https://doi.org/10.1007/s00464-020-07898-6

`q2 · i?` · `causal · r1`

Post-hoc power analysis reported in the Discussion, based on the study's task time and path length data, "indicates a trend towards a significant reduction of path length and Task time if 111 and 749 participants are included".

> "A post-hoc power analysis (samplesizepwr.m, Mathworks, Natick, MA), based on the task time and path length data indicates a trend towards a significant reduction of path length and Task time if 111 and 749 participants are included."
