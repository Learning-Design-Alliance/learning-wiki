Evidence¶

Peter Z. Schochet 2020¶

Peter Z. Schochet. (2020). Analyzing Grouped Administrative Data for RCTs Using Design-Based Methods. Journal of Educational and Behavioral Statistics, vol. 45, issue 1. https://www.mathematica.org/publications/analyzing-grouped-administrative-data-for-rcts-using-design-based-methods

q2 · i? · theoretical · r?

Analytical result stated in the article's abstract: due to "the linearity of the regression model underlying RCTs," group-level estimators "match those using individual data" asymptotically, for both nonclustered and clustered designs. No effect size applies.

"Because of the linearity of the regression model underlying RCTs, the asymptotic properties of design-based estimators using group-level averages—formed randomly or by covariates for nonclustered designs and as cluster-level averages for clustered designs—match those using individual data."
