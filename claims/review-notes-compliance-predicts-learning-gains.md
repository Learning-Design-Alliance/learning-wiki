# Higher compliance with MetaTutor's review-notes prompt is associated with larger proportional learning gains

## Subclaims

## Evidence

### Lallé 2017

Lallé, S., Mudrick, N., Conati, C., Taub, M., Azevedo, R. (2017). On the Influence on Learning of Student Compliance with Prompts Fostering Self-Regulated Learning. Proceedings of the 10th International Conference on Educational Data Mining. https://educationaldatamining.org/EDM2017/

`q3 · i3` · `associational · r1`

Same multiple linear regression over explicit compliance rates in the 28-student MetaTutor user study. The review notes prompt showed a significant main effect, "F1,20 = 7.43, p=.013, ηp2 =.16", an effect size in the paper's medium-to-large range (ηp2 ≥ 0.13).
