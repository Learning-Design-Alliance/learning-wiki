# Anticipatory self-explanation prompts benefited higher-prior-knowledge apprentices on diagnostic strategy description scores, whereas retrospective prompts benefited lower-prior-knowledge apprentices

## Subclaims
`q3 i?` A significant three-way interaction of timepoint, prompt condition, and DRC prior-knowledge score on strategy description test scores; for mean-centered DRC scores above 1.68 anticipatory prompts had beneficial effects and retrospective prompts detrimental effects. [→ Meier 2024](#meier-2024)

## Evidence

### Meier 2024

Meier, J., Hesse, P., Abele, S., Renkl, A., & Glogger-Frey, I. (2024). Better self-explaining backwards or forwards? Prompting self-explanation in video-based modelling examples for learning a diagnostic strategy. Instructional Science, 52, 613–638. https://doi.org/10.1007/s11251-023-09651-7

`q3 · i?`

RM-ANOVA moderation analysis among the two prompt conditions (n = 21 retrospective, n = 25 anticipatory) revealed a three-way interaction (F(1, 40) = 4.368, p = .043, η2partial = 0.098); the Johnson-Neyman boundary was explored as quoted: "t(42) = 2.02, p = .05".

> "the Johnson-Neyman procedure indicated that for learners with mean-centered DRC test scores larger than 1.68, that is, the higher prior knowledge participants, retrospective prompts had detrimental effects and anticipatory prompts had beneficial effects on the difference of strategy description test scores, t(42) = 2.02, p = .05."
