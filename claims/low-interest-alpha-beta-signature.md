The same spectral analysis (n=32) found no significant main effect of noise condition on alpha or beta power; no effect size printed. The authors call this replicated null noteworthy.

> "Repeated-measured ANOVA revealed no main effect of noise condition in either band [Alpha -power: F(2,31)=1.166, p=0.318 ; Beta -power: F(2,31)=1, p=0.373]."
