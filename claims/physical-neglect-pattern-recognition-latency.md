# Physical neglect exposure is associated with prolonged latency for correct responses in the Pattern Recognition Memory test in healthy adults

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · `q2` quasi-experiment

## Subclaims
`q2 i?` Higher physical neglect scores were significantly associated with longer latency for a correct response in the Pattern Recognition Memory test. [→ Majer M 2010](#majer-m-2010)

## Evidence

### Majer M 2010

Majer M, Nater UM, Lin J-MS, Capuron L, Reeves WC. (2010). Association of childhood trauma with cognitive function in healthy adults: a pilot study. BMC Neurology. https://doi.org/10.1186/1471-2377-10-61

`q2 · i?`

Multiple linear regression analysis in a pilot study of 47 healthy adults found a significant association between the physical neglect score and the latency for a correct response in the Pattern Recognition Memory test, described as a "significant association between the physical neglect score".

> "Furthermore, there was a significant association between the physical neglect score and the number of double errors in the Spatial Working Memory test and the latency for a correct response in the Pattern Recognition Memory test."
