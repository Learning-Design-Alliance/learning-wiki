Brazilian Oral Research. https://doi.org/10.1590/1807-3107bor-2026.vol40.039

`q3 · i?` · `design · r3`

Unidimensionality assessment within the same psychometric analysis of 404 dentists. The article reports UniCo, ECV, and MIREAL values with 95% confidence intervals, concluding the internal structure is multidimensional. No effect size is printed.

> "Unidimensionality was rejected, as the UniCo value (0.939; 95% CI: 0.907–0.975) and the ECV value (0.762; 95% CI: 0.719–0.830) did not reach the recommended thresholds, whereas only the MIREAL value (0.288; 95% CI: 0.254–0.323) met the criterion."
