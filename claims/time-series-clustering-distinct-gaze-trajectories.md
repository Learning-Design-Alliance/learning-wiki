K-means-based time series clustering (tslearn, DTW distance) of participants' network metric trajectories, visualized in Figure 2. Clusters showed distinct temporal patterns; cluster numbers are arbitrary and imply no ordinal relationship. No effect size is printed.

> "The results show distinct patterns in network metrics across clusters. For example, metrics such as Node Connectivity display trends across the three clusters: Cluster 1 shows a pattern of decrease over time, Cluster 2 shows an increasing trend, and Cluster 3 shows a relative stable trend"
