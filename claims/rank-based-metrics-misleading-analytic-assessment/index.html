Evidence¶

Stefano Bannò 2026¶

Stefano Bannò, Kate Knill, Mark Gales. (2026). Towards Self-Referential Analytic Assessment: A Profile-Based Approach to L2 Writing Evaluation with LLMs. https://arxiv.org/abs/2605.04298 doi:10.48550/arxiv.2605.04298

q2 · i? · associational · r2

Correlational analysis in Section 3.3 (Table 3): e.g. GPT-4.1 prompted for holistic scores correlates 0.927 with Complexity vs 0.848 when prompted analytically; Qwen 2.5 correlates 0.754 with Willingness vs 0.457. The operational rater shows the same pattern.

"when we use LLMs prompted to predict holistic scores, we observe strong correlations with analytic scores, in some cases even stronger than when we prompt them for the respective analytic aspect."
