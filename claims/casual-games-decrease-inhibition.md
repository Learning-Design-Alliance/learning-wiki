## Evidence

### Sora Chi-Fang Huang 2026

Sora Chi-Fang Huang, Zhi-Hong Chen, Yu-Tzu Lin. (2026). Enhancing inhibition ability through situational training games: effectiveness, motivation and experience. Education Tech Research Dev 74. https://doi.org/10.1007/s11423-026-10593-3

`q3 · i3` · `causal · r2`

Paired-sample t-test within the casual game condition (n = 38) on Trail Making Test scores. The test showed a large effect size, Cohen’s d = 0.81 (t (37) = 4.98, p < .001).

> "for the casual game condition, inhibition ability significantly decreased from pretest (M = 0.63, SD = 0.21) to posttest (M = 0.54, SD = 0.22), t (37) = 4.98, p < .001, Cohen’s d = 0.81, power = 1.00, showing a large effect size."
