Relations Between the Worked Example and Generation Effects on Immediate and Delayed Tests 2016¶

Relations Between the Worked Example and Generation Effects on Immediate and Delayed Tests. (2016). Submitted 29/01/2016. https://doi.org/10.1016/j.learninstruc.2016.06.007

q2 · i2 · causal · r2

Simple-effects tests following the significant delayed-test guidance x element interactivity interaction (F(1, 76) = 5.53, p = .021): "low guidance (generation) was superior to high guidance (presentation)" for low element interactivity material, d = .44; no significant difference for high element interactivity material.

"for low element interactivity materials, low guidance (generation) was superior to high guidance (presentation), t(78) = 2.03, SEdiff = 6.08, p = .04, d = .44, indicating a generation effect, while there was no significant difference for high element interactivity materials."
