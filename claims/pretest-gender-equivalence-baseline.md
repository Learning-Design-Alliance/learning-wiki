Welch's t-test at baseline (males n = 37, M = 18.43, SD = 5.07; females n = 47, M = 20.21, SD = 7.68) was non-significant, p = .206, with a small effect size (Cohen's d = −0.27) favoring females, supporting baseline comparability before the intervention.

> "an independent-samples t-test revealed no statistically significant difference between males and females on the English academic performance test, t (79.80) = − 1.28, p = 0.206"
