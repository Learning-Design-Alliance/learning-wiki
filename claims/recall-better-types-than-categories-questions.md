# Post-test recall was better on type-focused than category-focused questions regardless of diagram condition

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3`

## Subclaims
`q3 i?` Type of header content significantly affected scores on type-focused questions but not category-focused questions; arrow orientation had no significant effect on either. [→ Jan van der Meij 2017](#jan-van-der-meij-2017)

## Evidence

### Jan van der Meij 2017

Jan van der Meij, Marije van Amelsvoort, Anjo Anjewierden. (2017). How design guides learning from matrix diagrams. Instructional Science. https://doi.org/10.1007/s11251-017-9425-1

`q3 · i?` · `causal · r2`

MANOVA and univariate tests on post-test scores (mean 8.59 of 16, SD 2.71) for 81 participants across four conditions. Only header content affected type-question scores; arrow orientation showed no significant effect on either question type.

> "Univariate results for type of header content showed a signiﬁcant effect on questions that focus on types, but not on questions that focus on categories, F(1,77) = 5.549, p = 0.021 and F(1,77) = 0.972, p = 0.327."
