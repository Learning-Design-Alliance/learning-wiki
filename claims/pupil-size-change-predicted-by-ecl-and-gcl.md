## Evidence

### Tianlong Zu 2017

Tianlong Zu, John Hutson, Lester C. Loschky, and N. Sanjay Rebello. (2017). Use of Eye-Tracking Technology to Investigate Cognitive Load Theory. 2017 PERC Proceedings. https://doi.org/10.1119/perc.2017.pr.113

`q2 · i1` · `causal · r2`

Hierarchical regression (N = 46) on ratio of pupil size change relative to a no-information baseline. Table 4 reports ECL β = .13 (p = .013) and GCL β = -.131 (p = .012) in Model 1; O-span was not significant (β = -.042, p = .442), and the Model 2 R² increment was ns.

> "We conducted a hierarchical regression analysis for RPSC, using the same two models as before. We found that GCL, ECL and o -span score all can uniquely predict RPSC."
