## Subclaims
`q3 i3` Visuospatial memory showed the largest first-to-fifth grade gains of the three working memory components, with d = 2.4 versus d = 1.6 for central executive and d = 1.1 for phonological memory. [→ Li Y 2013](#li-y-2013)

## Evidence

### Li Y 2013

Li Y, Geary DC (2013) Developmental Gains in Visuospatial Memory Predict Gains in Mathematics Achievement. PLoS ONE 8(7): e70160. https://doi.org/10.1371/journal.pone.0070160

`q3 · i3` · `associational · r2`

Longitudinal repeated-measures analysis of 177 children assessed with the WMTB-C in first and fifth grade. Span-score effect sizes were d = 2.4 for visuospatial memory, "larger than gains in the capacity of the central executive (d = 1.6)" and d = 1.1 for phonological memory.

> "Developmental gains in visuospatial memory span (d = 2.4) were larger than gains in the capacity of the central executive (d = 1.6) that in turn were larger than gains in phonological memory span (d = 1.1)."
