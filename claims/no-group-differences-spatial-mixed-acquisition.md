## Evidence

### Wang Chris 2020

Wang Chris, Daniel Ben Kei, Asil Mustafa, Khwaounjoo Prashanna, Cakmak Yusuf Ozgur. (2020). A Randomised Control Trial and Comparative Analysis of Multi-Dimensional Learning Tools in Anatomy. Scientific Reports. https://doi.org/10.1038/s41598-020-62855-6

`q3 · i?` · `causal · r2`

In the same randomised three-group experiment, one-way ANOVA on anatomy test 1 found no significant differences for spatial type questions (F(2,49) = 0.353, p = 0.704) or mixed type questions (F(2,49) = 0.776, p = 0.466); equivalence was not tested and no effect size was printed.

> "There were no significant differences in the performance of the learning groups when comparing spatial type questions (F(2,49) = 0.353, p = 0.704) or mixed type questions (F(2,49) = 0.776, p = 0.466)."
