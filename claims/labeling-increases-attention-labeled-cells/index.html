Evidence¶

Clinton 2016¶

Clinton, V., Morsanyi, K., Alibali, M. W., & Nathan, M. J. (2016). Learning about Probability from Text and Tables: Do Color Coding and Labeling through an Interactive-user Interface Help? Applied Cognitive Psychology, 30(3), 440-453. https://doi.org/10.1002/acp.3223

q3 · i? · causal · r2

Mixed effects model of total fixation time on the four labeled cells, with color coding, labeling, pretest and need for cognition as predictors; the labeling effect was significant at p = .05 with no effect size printed.

"As expected, labeling increased total fixation time on target areas for labeling, b = 6.04, Wald t = 1.99, Wald χ2(1, N = 98) = 3.94, p = .05."

Clinton 2016 (2)¶

Clinton, V., Morsanyi, K., Alibali, M. W., & Nathan, M. J. (2016). Learning about Probability from Text and Tables: Do Color Coding and Labeling through an Interactive-user Interface Help? Applied Cognitive Psychology, 30(3), 440-453. https://doi.org/10.1002/acp.3223

q3 · i? · causal · r2

Mixed effects model of total fixation time on the ten color-coded cells; the color coding effect was not significant. No interaction between color coding and labeling was significant in either model.

"However, color coding did not significantly increase total fixation time on target areas for color coding, b = 3.95, Wald t = 1.52, Wald χ2(1, N = 98) = 2.32, p = .12."
