## Subclaims

## Evidence

### Causer Joe 2017

Causer Joe, Smeeton Nicholas J., Williams A. Mark. (2017). Expertise differences in anticipatory judgements during a temporally and spatially occluded task. PLoS ONE. https://doi.org/10.1371/journal.pone.0171330

`q3 · i2` · `causal · r2`

Main effect of temporal occlusion in the 2x3x2 mixed ANOVA on correct response; the main effect was significant, F2, 44 = 209.56, partial eta squared = 0.91, with ball contact "M = 71, SD = 18%" highest.

> "Response accuracy was significantly higher in the ball contact (M = 71, SD = 18%) condition when compared to the -80 ms (M = 56, SD = 14%; p < 0.001) and -160 ms (M = 46, SD = 14%; p < 0.001) conditions."

### Causer Joe 2017 (2)

Causer Joe, Smeeton Nicholas J., Williams A. Mark. (2017). Expertise differences in anticipatory judgements during a temporally and spatially occluded task. PLoS ONE. https://doi.org/10.1371/journal.pone.0171330

`q3 · i?` · `causal · r2`

In the correct-height analysis the temporal main effect was smaller (partial eta squared = 0.15); only ball contact ("M = 69, SD = 15%") exceeded -160 ms ("M = 64, SD = 12%"), with no -160 vs -80 ms difference reported.

> "Follow up analysis showed that response accuracy was significantly higher in the ball contact (M = 69, SD = 15%) when compared to the -160 ms (M = 64, SD = 12%; p = 0.017) condition."
