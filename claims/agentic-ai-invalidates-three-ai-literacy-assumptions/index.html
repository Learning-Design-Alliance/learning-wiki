Nama 2026¶

Nama, R. (2026). Agentic Literacy Debt: A Structural Problem the AI Literacy Field Has Not Yet Named. Author's accepted manuscript, AI and Ethics (Springer Nature). https://arxiv.org/abs/2605.27396

q1 · i? · theoretical · r3

Theoretical argument in a conceptual paper: the author analyzes how agentic systems invert the evaluative relationship assumed by frameworks built on Long and Magerko's definition, noting "Agentic systems produce action chains most of which the user never observes." No empirical data are reported.

"It assumes evaluation is possible: the user sees an output and judges it. Agentic systems produce action chains most of which the user never observes."
