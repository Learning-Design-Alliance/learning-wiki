Tanja Fritz 2023¶

Tanja Fritz, Hernán González Cruz, Stefan Janke, Martin Daumiller. (2023). Elucidating the Associations Between Achievement Goals and Academic Dishonesty: a Meta-analysis. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09753-1

q2 · i? · quant-synthesis · r?

Publication bias assessment using Egger's Regression test, Begg's Rank Correlation test, and Tests of Excess Significance, run per goal type with contour-enhanced funnel plots; grey literature was limited to four dissertation theses.

"We used these methods within each type of goal individually and visualized effect size distribution with contour-enhanced funnel plots (indicating areas of statistical significance). No indication for publication bias was found"
