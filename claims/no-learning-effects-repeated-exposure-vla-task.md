Preliminary mixed linear model with phase as fixed effect and participant as random effect, run before the main RQ analyses. The article reports "𝛽 = 0 .120,𝑧 = 0 .948,𝑝 = 0 .343" for the intervention-to-post contrast and interprets this as minimal learning effects due to repeated exposure; no standardised effect size is printed.

> "The preliminary analysis of the phase effects demonstrated no significant change in scores from the intervention to the post-intervention phase (𝛽 = 0 .120,𝑧 = 0 .948,𝑝 = 0 .343), indicating minimal learning effects due to repeated exposure."
