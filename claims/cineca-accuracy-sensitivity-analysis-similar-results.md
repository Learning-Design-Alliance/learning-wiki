Sensitivity analysis accompanying the main chi-square comparison, prompted by 12 image-based questions that could only be entered into Microsoft Copilot. Results were reported in Additional file 4; the main-text sentence states they were similar.

> "A sensitivity analysis excluding answers that were not applicable (e.g., if the answers had images with graphs or drawings) showed similar results reported in Additional file 4."
