## Evidence

### Leonard JA 2015

Leonard JA, Mackey AP, Finn AS and Gabrieli JDE (2015) Differential effects of socioeconomic status on working and procedural memory systems. Front. Hum. Neurosci. 9:554. https://doi.org/10.3389/fnhum.2015.00554

Kruskal–Wallis H-test on count span scores (data not normally distributed, Shapiro–Wilk p < 0.05) from 23 lower-SES and 34 higher-SES adolescents. "Working memory capacity was signiﬁcantly smaller in the lower-SES" group, X2(1) = 8.72, p = 0.003; no effect size was printed.
