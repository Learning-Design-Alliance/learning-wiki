G. Singaravelu 2011¶

G. Singaravelu. (2011). Interactive Multimedia Package in Ameliorating Communicative Skill in English. i-manager's Journal of English Language Teaching, 1(4), October-December. https://eric.ed.gov/?id=EJ1071105

q2 · i? · causal · r1

Descriptive comparison of pre-test/post-test percentage scores across eight skills (Table 1): e.g. fluency in response 6.24 vs 18.18, narrating a story 7.14 vs 21.26, skill of questioning 8.08 vs 24.55, using appropriate words 2.45 vs 8.36. Values are descriptive percentages; no inferential test per skill is reported.
