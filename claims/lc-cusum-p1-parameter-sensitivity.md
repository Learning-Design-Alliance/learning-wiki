## Evidence

### Ward Stephen Thomas 2014

Ward Stephen Thomas, Mohammed Mohammed A, Walt Robert, Valori Roland, Ismail Tariq, Dunckley Paul. (2014). An analysis of the learning curve to achieve competency at colonoscopy using the JETS database. Gut. https://doi.org/10.1136/gutjnl-2013-305973

`q3 · i?` · `associational · r2`

Sensitivity analysis of the LC-Cusum unacceptable failure rate parameter using the trainee dataset: table 2 shows proportions competent after 200 procedures of 0% (p1=0.15), 41% (0.20), 88% (0.25) and 96% (0.30).

> "Adjustment of the p1 value from 0.20 to 0.25 increased the proportion of trainees that were deemed competent by the LC-Cusum method from 41% to 88%."

### Ward Stephen Thomas 2014 (2)

Ward Stephen Thomas, Mohammed Mohammed A, Walt Robert, Valori Roland, Ismail Tariq, Dunckley Paul. (2014). An analysis of the learning curve to achieve competency at colonoscopy using the JETS database. Gut. https://doi.org/10.1136/gutjnl-2013-305973

`q2 · i?` · `associational · r3`

Validation using sequential 12-month data from 15 independent colonoscopists at two hospitals, all achieving CIR of at least 90% and performing more than 140 procedures. The study concludes "the lower limit for p1 used in LC-Cusum analysis of colonoscopy competency should be around 0.20."

> "All practitioners crossed the upper control limit with p1 set to values of ≥0.20. When p1 was <0.20, some independent practitioners failed to reach LC-Cusum defined competence."
