# The multirepresentational exercise relating centered and conventional unit vectors achieves superior outcomes for interpreting centered unit vector representations

## Evidence

### Christoph Hoyer 2024

Christoph Hoyer, Raimund Girwidz. (2024). Vector representations and unit vector representations of fields — problems of understanding and possible teaching strategies. [doi:10.1103/physrevphyseducres.20.010150](https://doi.org/10.1103/physrevphyseducres.20.010150)

`q3 · i2` · `causal · r2`

Mann–Whitney U-test on centered unit vector difference scores between the two randomly assigned groups, reporting "U = 1483.5, Z = -2.282, p < 0.5, r = -0.29, R2 ≈ 0.08" favoring the multirepresentational group.

> "However, when investigating the difference scores in the “multirepresentational” (Mrank = 69.57) and “unirepresentational” (Mrank = 55.43) groups when working with centered unit vectors, there are clear differences (U = 1483.5, Z = -2.282, p < 0.5, r = -0.29, R2 ≈ 0.08)."

### Christoph Hoyer 2024 (2)

Christoph Hoyer, Raimund Girwidz. (2024). Vector representations and unit vector representations of fields — problems of understanding and possible teaching strategies. [doi:10.1103/physrevphyseducres.20.010150](https://doi.org/10.1103/physrevphyseducres.20.010150)

`q3 · i?` · `causal · r2`

Wilcoxon pre-post tests within each intervention group on centered unit vector items: only the multirepresentational group improved significantly (z = 2.204, p < 0.05); the unirepresentational group did not.

> "However, for the items concerning centered unit vectors, only the “multirepresentational” group (z = 2.204, p < 0.05) showed a significant improvement, whereas no significant improvement was identified in the “unirepresentational” group (z = -1.248, p > 0.05)."
