# Retrieval practice produced a reliable overall testing effect and a main effect of working memory capacity on final-test accuracy

## Subclaims
`q2 i?` Items practiced by testing were recalled better than restudied items, and accuracy was higher for participants with higher WM capacity. [→ Yicong Zheng 2023](#yicong-zheng-2023)

## Evidence

### Yicong Zheng 2023

Yicong Zheng, Pengyuan Sun and Xiaonan L. Liu. (2023). Retrieval practice is costly and is beneficial only when working memory capacity is abundant. npj Science of Learning 8:8. https://doi.org/10.1038/s41539-023-00159-w

`q2 · i?` · `causal · r2`

Main-effect mixed-effects logistic regression model in the 30-participant experiment; the printed coefficients are "b = 0.23, z = 2.29, p = 0.022" for Condition and "b = 0.51, z = 2.32, p = 0.020" for WM.

> "The main-effect model revealed a signiﬁcant testing effect ( b = 0.23, z = 2.29, p = 0.022) and a signiﬁcant main effect of WM capacity (b = 0.51, z = 2.32, p = 0.020)."
