Evidence¶

Moores 2011¶

Moores, E., Cassim, R. and Talcott, J.B. (2011). Adults with dyslexia exhibit large effects of crowding, increased dependence on cues, and detrimental effects of distractors in visual search tasks. Frontiers in Psychology. doi:10.1016/j.neuropsychologia.2011.10.005

q2 · i3 · causal · r2

Two-factor ANOVAs in post-cued conditions. Controls showed no set size effect (F1,15=1.04) whereas AwD showed a significant set size effect (F1,14=24.43, p<.001, η2p=.64), with difficulty narrowly missing significance (p=0.055).

"In post-cued conditions, the controls showed an effect of difficulty (F 1,15 =5.60, p<.05, η2p =.27), but no effect of set size (F 1,15 =1.04) or interaction (F<1). In contrast, the AwD showed a significant effect of set size (F 1,14 =24.43, p<.001, η2p =.64)."

Related Claims¶

  • Crowding effects, pre-cue dependence and set size effects each correlate significantly with reading and spelling measures — related
  • Adults with dyslexia show disproportionately reduced discrimination accuracy in crowded displays compared to controls — related
  • Adults with dyslexia use pre-cues to enhance discrimination accuracy, with pre-cued performance exceeding both post-cued and uncued conditions — related
  • AwD showed significant set size effects in uncued conditions alongside difficulty effects, unlike controls — related
  • The four-way interaction between cue, group, display type and difficulty was significant, with group differences largest for uncued crowded stimuli — related
  • AwD required significantly longer calibrated display durations than controls despite attempts to equate overall accuracy — related
  • Set size, crowding and pre-cue use jointly predict literacy, with set size uniquely predicting spelling and pre-cue use uniquely predicting reading — related
