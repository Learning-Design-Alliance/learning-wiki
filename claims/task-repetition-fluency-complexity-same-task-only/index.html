Evidence¶

Yingli Wang 2008¶

Yingli Wang. (2008). Influence of Planning on Students' Language Performance in Task-based Language Teaching. English Language Teaching, 1(1). https://www.ccsenet.org/journal/index.php/elt doi:10.5539/elt.v1n1p83

q2 · i? · review · r2

The review reports Bygate's (2001) larger study of practicing a type of task on second-time performance and on a new task of the same type, finding "greater fluency and complexity of performance on the same task" without transfer. No effect sizes are printed.

"It was proved that practice led to greater fluency and complexity of performance on the same task, but it did not help with performance of another task of the same type."
