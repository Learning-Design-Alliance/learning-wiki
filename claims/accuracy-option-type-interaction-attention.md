# Incorrect responses are associated with longer visit durations on incorrect options and less time on correct options, with a large interaction effect

## Subclaims
`q3 i3` The interaction between response accuracy and option type on visit duration is significant with large effect size, F(1, 2919) = 540, d = 0.95: correct responses attend more to correct options, incorrect responses to incorrect options. [→ P Klein 2020](#p-klein-2020)
`q3 i3` Correct options receive more attention than incorrect options overall (main effect of option type, F(1, 2921) = 402, d = 0.80). [→ P Klein 2020](#p-klein-2020)

## Evidence

### P Klein 2020

P Klein, A Lichtenberger, S Küchemann, S Becker, M Kekule, J Viiri, C Baadte, A Vaterlaus and J Kuhn. (2020). Visual attention while solving the test of understanding graphs in kinematics: An eye-tracking analysis. Originally published 2019. [doi:10.1088/1361-6404/ab5f51](https://doi.org/10.1088/1361-6404/ab5f51)

`q3 · i3` · `associational · r1`

Repeated measures ANOVA (2×2) with response accuracy as between-subject factor and option type as within-subject factor, using data from all 26 items. Printed effect sizes are d = 0.80 for option type and d = 0.95 for the interaction.

> "We found a signiﬁcant main eﬀect of option type, F (1, 2921) = 402 , p < 10−20, eﬀect size d = 0 .80. That is, correct options received more attention from students than incorrect options. The interaction between accuracy and option type is also statistically signiﬁcant with large eﬀect size, F (1, 2919) = 540 , p < 10−20, d = 0 .95:"
