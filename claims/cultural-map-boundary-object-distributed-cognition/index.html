RQ3 qualitative analysis applying Star and Griesemer's boundary-object concept to the case artifact. The authors report the interface accommodated "competing priorities across sectors without requiring semantic consensus, sustaining SDG-focused partnerships."

"The Bilingual Cultural Map Interface functions as a boundary object—an artifact that enables coordinated action across social worlds while supporting divergent interpretations [22]: students view it as code architecture; museum educators as curriculum infrastructure; end-users as cultural heritage for place-based learning."
