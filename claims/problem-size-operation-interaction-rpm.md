Interaction effect from the same linear-mixed effects model of RPM. The article reports a "signiﬁcant interaction between problem size and operation" with partial R2 = 0.007, in which the problem-size slope was slightly greater for subtraction problems; partial R2 from regression is not treated as an effect size.

> "a subtle, yet, signiﬁcant interaction between problem size and operation (R2partial = 0.007, t(10,800) = 9.90,padj < 0.001), suggesting that the slope of the problem size effect was slightly greater for subtraction problems."
