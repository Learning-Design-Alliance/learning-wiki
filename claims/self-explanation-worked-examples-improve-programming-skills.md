`q2 · i3` · `causal · r1`

Independent-samples t-test on the skills posttest, in which learners wrote Visual Basic code scored on a five-point scale, showed the experimental group outperformed the control group; the printed effect size ƞ2 = 0.416 exceeded Cohen's 0.14 threshold for a high effect.

> "Table 3 shows that there was a statistically significant difference between the control (M=22.0) and experimental groups (M=34.73) in the mean scores of the achievement posttest of programing skills where t value equals 8.836 at the significance level of 0.00."
