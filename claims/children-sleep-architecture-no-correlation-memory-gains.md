## Evidence

### Wilhelm et al. 2008

Ines Wilhelm, Susanne Diekelmann, and Jan Born. (2008). Sleep in children improves memory performance on declarative but not procedural tasks. Learning & Memory 15:373-377. https://doi.org/10.1101/lm.803708

`q3 · i?` · `causal · r2`

Polysomnographic comparison during the nocturnal retention interval: the article reports that "children slept longer (t = 6.13; P < 0.001)" with a lower stage 2 proportion and greater SWS proportion than adults; Table 1 prints total sleep time of 567.05 vs 413.15 min and SWS of 29.92% vs 20.01%.

> "Compared with adults, children slept longer (t = 6.13; P \ < 0.001) and had a lower proportion of lighter non-REM sleep stage 2 (t = ⳮ2.92; P \ < 0.01) and a greater proportion of SWS (t = 2.31; P \ < 0.05; Table 1)."

### Wilhelm et al. 2008 (2)

Ines Wilhelm, Susanne Diekelmann, and Jan Born. (2008). Sleep in children improves memory performance on declarative but not procedural tasks. Learning & Memory 15:373-377. https://doi.org/10.1101/lm.803708

`q3 · i?` · `causal · r2`

Null correlational analysis across both age groups and all three tasks: the article reports that "None of the sleep parameters was significantly associated with the gain in memory performance" (r < 0.32), which the authors take to indicate that time in sleep stages does not sensitively reflect consolidation processes.

> "None of the sleep parameters was significantly associated with the gain in memory perfor- mance for any of the three tasks in both age groups (r \ < 0.32), consonant with the view that time in certain sleep stages per se does not sensitively reflect the processes that mediate memory consolidation"
