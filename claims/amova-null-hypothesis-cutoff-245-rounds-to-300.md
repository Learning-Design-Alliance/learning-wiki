# AMOVA uses a null-hypothesis rejection cutoff at a TPE score of 2.45, which rounds via the nearest-integer function to 3.00

## Subclaims
`q1 i?` The AMOVA hypothesis test rejects the null hypothesis when the accumulative score reaches 2.45 on the Taxonomy of Process Education, which the nearest-integer function rounds to a holistic 3.00. [→ Osler 2015](#osler-2015)

Definitional statement of the AMOVA decision rule in the methodology section. No empirical data support the cutoff choice; it is a stated convention of the method.
