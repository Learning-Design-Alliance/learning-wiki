As-implemented sensitivity analysis of the same stepped-wedge trial, using the date of the first local training session to define exposure; units that did not implement were treated as unexposed throughout. Result: "there was no evidence of improvement" (OR=1.01, 0.84 to 1.22).

> "When the actual date of implementation of the intervention in each unit was considered in the analysis, there was no evidence of improvement (OR=1.01 (0.84 to 1.22))."
