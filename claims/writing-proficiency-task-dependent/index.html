Evidence¶

Puranik 2011¶

Puranik, Cynthia S., Lonigan, Christopher J. (2011). From Scribbles to Scrabble: Preschool Children's Developing Knowledge of Written Language. Reading and Writing. https://doi.org/10.1007/s11145-009-9220-8

q3 · i? · associational · r2

Cross-sectional analysis of 372 preschoolers' performance across five writing tasks of differing difficulty. The article reports that "Children used advanced writing features for easier writing tasks" but reverted to basic features or drawing on more challenging composition tasks, showing progression from scribbling to conventional spelling is task dependent.

"Children used advanced writing features for easier writing tasks (e.g., Write Name) but resorted to more basic features or even drawing when the writing task proved more challenging (e.g., Picture Description)."
