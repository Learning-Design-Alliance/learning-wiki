## Subclaims
`q2 i?` A worked a priori analysis counts the interacting elements a novice must process, e.g. 28 elements for solving a/b = c, versus an element interactivity count of 1 for an expert who holds the solution in long-term memory. [→ Ouhao Chen · Fred Paas · John Sweller 2023](#ouhao-chen-fred-paas-john-sweller-2023)
`q2 i?` For a composite shape area problem, the analysis yields about 25 interactive elements, while memorising formulae is low in element interactivity. [→ Ouhao Chen · Fred Paas · John Sweller 2023 (2)](#ouhao-chen-fred-paas-john-sweller-2023-2)

## Evidence

### Ouhao Chen · Fred Paas · John Sweller 2023

Ouhao Chen · Fred Paas · John Sweller. (2023). A Cognitive Load Theory Approach to Defining and Measuring Task Complexity Through Element Interactivity. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09782-w

`q2 · i?` · `theoretical · r3`

A priori analysis technique demonstrated in the review using the a/b = c example from Sweller and Chandler (1994): for an expert the equation "impose an element interactivity count of only 1" because the solution is retrieved as a single entity.

> "These 28 elements all interact. To understand this solution, at some point they all must be processed simultaneously in working memory."

### Ouhao Chen · Fred Paas · John Sweller 2023 (2)

Ouhao Chen · Fred Paas · John Sweller. (2023). A Cognitive Load Theory Approach to Defining and Measuring Task Complexity Through Element Interactivity. Educational Psychology Review. https://doi.org/10.1007/s10648-023-09782-w

`q2 · i?` · `theoretical · r3`

The review describes Chen et al.'s (2015) geometry materials (Fig. 1): calculating the area of a composite shape involved "about 25 interactive elements", whereas memorising the parallelogram area formula involved 4 interacting elements for a novice.

> "Finally, the two separate area values added together involved another 3 elements giving, in total, about 25 interactive elements."
