# In Experiment 1, cue-only JOLs produced significantly better Phase B memory and transfer than restudy, while overt retrieval's memory advantage over restudy was only marginal

## Subclaims
`q3 i1` Cue-only JOLs yielded significantly higher memory (OR = 1.93) and transfer (OR = 1.83) than restudy; overt retrieval vs. restudy was significant for transfer but not memory. [→ Ritter 2025](#ritter-2025)

## Evidence

### Ritter 2025

Ritter, C., Hausman, H., Gaschler, R., Tiffin-Richards, S. P., & Kubik, V. (2025). The Forward Effect of Judgements of Learning on Memory and Transfer in Inductive Learning. Educational Psychology Review. https://doi.org/10.1007/s10648-025-10094-4

`q3 · i1` · `causal · r3`

One-sided pairwise comparisons with restudy in Experiment 1's GLMMs, reported as corollaries of the preregistered contrasts. Cue-only JOLs beat restudy on both tests; overt retrieval beat restudy on transfer only, with the memory contrast marginal (p = .054).

> "For memory, overt retrieval was numerically but not statistically higher than restudy ( OR = 1.79, p = .054), whereas cue‐only JOLs showed a significant advantage (OR = 1.93, p = .034). Similarly, both overt retrieval (OR = 1.87, p = .023) and cue‐only JOLs ( OR = 1.83, p = .027) produced significantly greater transfer accuracy than restudy."
