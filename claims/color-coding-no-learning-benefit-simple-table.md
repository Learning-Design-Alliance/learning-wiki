## Subclaims
`q3 i?` The effect of color coding on posttest scores was not significant, and there was no color coding × labeling interaction. [→ Clinton 2016](#clinton-2016)

## Evidence

### Clinton 2016

Clinton, V., Morsanyi, K., Alibali, M. W., & Nathan, M. J. (2016). Learning about Probability from Text and Tables: Do Color Coding and Labeling through an Interactive-user Interface Help? Applied Cognitive Psychology, 30(3), 440-453. https://doi.org/10.1002/acp.3223

`q3 · i?` · `causal · r2`

Same ANCOVA on posttest scores as the labeling finding: color coding showed no significant effect and the interaction was not significant; no effect size was printed for either test.

> "The effect of color coding on posttest scores was not significant, F(1, 95) = .17, p = .68, and there was no interaction between color coding and labeling, F(1, 95) = .76, p = .39."
