The editorial summarizes special-issue studies in computer science and data science education, noting students' positive attitudes and "strong intentions to continue using such tools" alongside exam struggles with LLM-generated code. No statistics are printed.

"While students appreciated the utility of GAI in coursework and demonstrated strong intentions to continue using such tools, they struggled when asked to correct LLM-generated code during exams, underscoring the need for improved AI literacy."
