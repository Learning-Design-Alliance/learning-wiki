# Preclass preparation, measured as average iRAT performance, was the only significant predictor of exam performance in each course unit.

## Subclaims
`q3 i?` Student average iRAT performance significantly explained exam performance on all three exams (p < 0.001 in printed tables). [→ Woodbury J 2024](#woodbury-j-2024)

## Evidence

### Woodbury J 2024

Woodbury J, Offerdahl E. (2024). Mind the Gap: Investigating Disaggregated Student Performance in an Upper-Division Biochemistry Course Following Team-Based Learning. CBE—Life Sciences Education 23(3):ar39. https://doi.org/10.1187/cbe.24-02-0090

`q3 · i?` · `associational · r2`

Linear mixed models of exam scores across three semesters; printed coefficients for iRAT average were B = 0.57 (Exam 1), 0.49 (Exam 2), 0.38 (Exam 3), each p < 0.001. Adjusted R2 = 0.35 (Exam 1), 0.2506 (Exam 2); Exam 3 marginal R2 = 0.23. No standardized effect size printed.

> "The only significant factor that explained exam performance in the initial models (Tables 2–4) was preparation (i.e., student average iRAT performance)."
