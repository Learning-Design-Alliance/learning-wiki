# CCT yields small significant gains in nonverbal memory, working memory, and visuospatial skills, but only weak evidence for verbal memory

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · quant-synthesis `r3` · `q4` · `i1` small

## Subclaims
`q4 i1` Nonverbal memory (g = 0.24), working memory (g = 0.22), and visuospatial skills (g = 0.22) showed small significant effects; verbal memory was very small (g = 0.08) under a conservative fixed-effects model. [→ Lampit A 2014](#lampit-a-2014)

## Evidence

### Lampit A 2014

Lampit A, Hallock H, Valenzuela M (2014) Computerized Cognitive Training in Cognitively Healthy Older Adults: A Systematic Review and Meta-Analysis of Effect Modifiers. PLoS Med 11(11): e1001756. https://doi.org/10.1371/journal.pmed.1001756

`q4 · i1` · `quant-synthesis · r3`

Domain-specific meta-analyses: nonverbal memory g = 0.24 (13 studies), WM g = 0.22 (28 studies), visuospatial g = 0.22 (8 studies), all significant. For verbal memory, potential publication bias prompted a fixed-effects analysis showing "a very small effect size" of g = 0.08.

> "A fixed-effects analysis was therefore conducted and revealed a very small effect size ( g = 0.08, 95% CI 0.01 to 0.15, p = 0.03; Figure 4)."
