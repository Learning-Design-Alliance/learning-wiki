Christina Maria Mayr. (2026). Knowledge Markers: An AI-Agnostic Concept for the Design of Programming Courses. [doi:10.48550/arXiv.2604.06331](https://doi.org/10.48550/arXiv.2604.06331)

`q1 · i?` · `design · r2`

Descriptive chapter-level annotation of the existing open course materials, assigning one primary marker per chapter, found that "early chapters focus on conceptual foundations, followed by application-oriented Python chapters", which the authors judge to violate the interleaving requirement R2.

> "This initial annotation highlights a pronounced split: early chapters focus on conceptual foundations, followed by application-oriented Python chapters. This violates R2 because it separates theory and practice for long stretches instead of interleaving them."
