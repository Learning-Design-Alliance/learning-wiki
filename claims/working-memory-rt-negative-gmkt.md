# Longer working memory reaction time predicts lower GMKT performance, but working memory accuracy shows no such correlation

## Subclaims
`q2 i?` Working memory 3-back reaction time had a direct negative effect on GMKT performance (β = -0.104, P < 0.05), interpreted as better working memory predicting better GMKT performance. [→ Sun Jie 2025](#sun-jie-2025)
`q2 i?` No correlation between working memory accuracy and GMKT performance was evident; the authors state conclusions about working memory should be interpreted with caution. [→ Sun Jie 2025 (2)](#sun-jie-2025-2)

`q2 · i?` · `associational · r2`

Limitation reported in the Discussion: the reaction-time effect did not extend to working memory accuracy, so the authors caution that "any conclusions pertaining to working memory should be interpreted with caution" and that the relationship needs future verification.

> "we only observed a negative correlation between working memory reaction time and GMKT performance, whereas no such correlation is evident in terms of working memory accuracy."
