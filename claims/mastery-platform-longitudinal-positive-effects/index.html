Evidence¶

Weatherholtz 2024¶

Weatherholtz, K., Grimaldi, P., Yamkovenko, B., Hill, K.M. (2024). Evaluating the Impact of a Mathematics Mastery Learning Platform on Student Achievement: A Large-Scale Longitudinal Analysis. EC-TEL 2024, Lecture Notes in Computer Science, vol 15159, Springer, Cham. https://doi.org/10.1007/978-3-031-72315-5_32

q2 · i? · associational · r2

A large-scale longitudinal observational analysis of multi-year panel data from a mastery learning platform, using within-student changes to control time-invariant confounding. The abstract states this approach "replicated the previous findings and found positive treatment effects"; no effect size is printed.

"By examining the changes in individual students’ platform usage and standardized test scores across years, we were able to treat each student as their own control, thereby eliminating confounding from time-invariant student factors"
