## Subclaims
`q2 i?` Regression analyses with logarithmic variables did not consistently show higher explained variance than linear regression, providing no support for a diminishing return relation between self-explanations and learning. [→ Renkl 1997](#renkl-1997)

## Evidence

### Renkl 1997

Renkl, A. (1997). Learning from Worked-Out Examples: A Study on Individual Differences. Cognitive Science, 21(1), 1-29. https://www.cogsci.org/journal/21-1

`q2 · i?` · `associational · r2`

Logarithmic regression analyses comparing power function to linear models showed "no consistent pattern was obtained"; in more than half of the cases linear regression explained more variance. The authors concluded linear relations should be assumed.

> "no consistent pattern was obtained. In more than half of the cases, the ordinary linear regression could explain higher proportions of variance than the power function regression"
