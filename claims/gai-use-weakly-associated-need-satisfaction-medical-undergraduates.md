Cross-sectional survey of 498 medical undergraduates analyzed with CB-SEM using robust maximum likelihood. The structural path from GAI use (observed variable) to latent basic psychological need satisfaction was "significantly but weakly positively associated" (β = 0.155, p = 0.002).

> "After controlling for gender, year of study, and academic program, GAI use was significantly but weakly positively associated with basic psychological need satisfaction (B = 0.017, β = 0.155, p = 0.002)."
