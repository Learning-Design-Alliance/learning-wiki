## Evidence

### Garvin Brod 2021

Garvin Brod. (2021). Toward an understanding of when prior knowledge helps or hinders learning. npj Science of Learning 6:24. https://doi.org/10.1038/s41539-021-00103-w

`q2 · i?` · `theoretical · r3`

Review-reported memory research: the memory congruency effect, suggested to arise from a more elaborate memory trace laid down during encoding and facilitated memory search during retrieval. The commentary keeps the hedge that congruent information tends to be better remembered.

> "new information that is congruent with prior knowledge tends to be better remembered than information this is incongruent with it; a phenomenon that has been dubbed the memory congruency effect"

### Garvin Brod 2021 (2)

Garvin Brod. (2021). Toward an understanding of when prior knowledge helps or hinders learning. npj Science of Learning 6:24. https://doi.org/10.1038/s41539-021-00103-w

`q2 · i?` · `theoretical · r2`

Review-reported finding cited from Brod, Hasselhorn and Bunge on prediction generation and the element of surprise: incongruent information was learned well only when it produced strong surprise, a boundary condition on the congruency effect.

> "Highly incongruent new information has been shown to be learned well, but only when it leads to strong surprise in learners"
