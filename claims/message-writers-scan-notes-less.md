## Subclaims
`q2 i1` Number of synchronous messages written correlates negatively with note scan rate while reading others' notes (r = −0.18, p = 0.007). [→ Murat Oztok 2012](#murat-oztok-2012)

## Evidence

### Murat Oztok 2012

Murat Oztok, Daniel Zingaro, Clare Brett, Jim Hewitt. (2012). Exploring Asynchronous and Synchronous Tool use in Online Courses. Preprint submitted to Computers & Education. https://doi.org/10.1016/j.compedu.2012.08.007

`q2 · i1` · `associational · r1`

Correlational log analysis over all 222 students in the nine courses, using the scan-rate metric defined as reading at eight words-per-second or more. The quote reports "r = −0.18,p = 0.007", so heavier message writers scan less.

> "In considering scan rate, we ﬁnd a signiﬁcant negative correlation between number of messages written and scan rate while reading other students’ notes ( r = −0.18,p = 0.007)."
