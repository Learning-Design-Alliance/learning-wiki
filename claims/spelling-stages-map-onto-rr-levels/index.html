Chi-squared test relating stage allocation to representational-level allocation in the 51-child sample was significant, but the authors flag "a number of empty cells"; the relationship is explored for descriptive purposes only, with anomalies such as six stage-5 children at E1B.

"A Chi-squared Goodness of Fit test proved to be significant: ² (N = 51, 12) = 39.91, p < .05 however there are a number of empty cells which should be mentioned"
