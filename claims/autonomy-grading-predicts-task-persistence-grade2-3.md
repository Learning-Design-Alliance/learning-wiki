# Maternal autonomy granting in Grade 2 positively predicts children's task persistence in Grade 3, but not from Grade 3 to Grade 4

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · associational `r3` · `q3`

## Subclaims
`q3 i?` The more autonomy granting mothers reported in Grade 2, the more task-persistent behavior teachers reported children exhibiting in Grade 3, controlling for academic performance. [→ Viljaranta 2017](#viljaranta-2017)

## Evidence

### Viljaranta 2017

Viljaranta, J., Silinskas, G., Lerkkanen, M.-K., Hirvonen, R., Pakarinen, E., Poikkeus, A.-M., & Nurmi, J.-E. (2017). Maternal Homework Assistance and Children’s Task-Persistent Behavior in Elementary School. https://scholar.google.com/scholar?q=Maternal+Homework+Assistance+and+Children%E2%80%99s+Task-Persistent+Behavior+in+Elementary+School

`q3 · i?` · `associational · r3`

Cross-lagged path model of 365 parent–teacher–child triads across Grades 2–4, using mother-reported assistance and teacher-rated task persistence (BSRS). The final model (CFI = .96, TLI = .90, RMSEA = .080, SRMR = .040) showed that "maternal autonomy granting predicted children’s task persistence positively" from Grade 2 to Grade 3. No standardized coefficient for this path is printed.

> "maternal autonomy granting predicted children’s task persistence positively, and maternal help predicted children’s task persistence negatively from grade 2 to grade 3"
