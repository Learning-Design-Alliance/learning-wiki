Analysis of how psychomotor skill training is structured across the systems in the review's Table 4. Selfit prescribes micro cycle workouts from a template and user data (perceived fatigue, repetitions, initial challenges); even it does not yet support meso or macro cycle prescriptions.

"We find that Selfit is the only ITS that organizes exercises in, e.g. micro, meso, and macro cycles. To date, Seflit only supports micro cycle exercise prescriptions based on a template and user information like fatigue."
