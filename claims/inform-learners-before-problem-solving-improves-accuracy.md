# Informing learners about the to-be-monitored cue before the problem-solving phase improves self-assessment accuracy compared with informing them only afterwards

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r2` · `q3` · `i1` small

## Subclaims

## Evidence

### Waldeyer 2024

Waldeyer, J., Endres, T., Roelle, J., Baars, M., & Renkl, A. (2024). How to Optimize Self-Assessment Accuracy in Cognitive Skill Acquisition When Learning from Worked Examples. Educational Psychology Review, 36, 103. https://doi.org/10.1007/s10648-024-09944-4

`q3 · i1` · `causal · r2`

Experiment 1, 2 × 2 ANOVA (N = 129) on absolute accuracy. The main effect of timing of cue prompt was significant, F(1, 125) = 4.09, p = 0.046, with printed effect size ηp2 = 0.03; learners "informed about the to-be-monitored cue already before the problem-solving phase showed better self-assessment accuracy".

> "the 2 × 2 ANOVA revealed that the groups that were informed about the to-be-monitored cue already before the problem-solving phase showed better self-assessment accuracy, F(1, 125) = 4.09, p = 0.046, ηp2 = 0.03."
