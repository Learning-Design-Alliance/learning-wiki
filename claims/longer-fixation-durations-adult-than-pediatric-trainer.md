## Evidence

### Khanfar Aseel F. 2025

Khanfar Aseel F., Motamedi Sanaz, Safford Shawn D., Moore Jason, Menold Jessica, Miller Scarlett. (2025). Visual attention and cognitive workload using different laparoscopic box trainers and mixed-reality feedback. Surgical Endoscopy. https://doi.org/10.1007/s00464-025-11881-4

`q3 · i3` · `causal · r2`

Two-way mixed ANOVA on novice trials (n = 54 trials analyzed) comparing adult vs pediatric trainer; the main effect of task type on fixation duration was significant, "with longer fixation durations in the adult box trainer" (partial η2 = 0.437).

> "The main effect of the task type showed a statistically significant difference in fixation duration, F(1, 20) = 15.554, p < 0.001, partial η2 = 0.437, with longer fixation durations in the adult box trainer (mean difference = 69.231, standard error = 17.55 s, p < 0.001)"
