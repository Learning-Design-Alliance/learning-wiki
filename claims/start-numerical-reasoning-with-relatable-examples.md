Author's concluding argument (interpretive, no data): in a course where every question involves numerical calculation, starting from universally shared experience such as eating supports successful quantitative reasoning. The author offers this as a pedagogical rationale rather than a tested result.

> "it’s pretty arrogant to assume that “those students” don’t need to (or can’t) do the math. If you’re going to have success talking about numerical calculations, you might as well start with examples that everyone can relate to, and everyone eats!"
