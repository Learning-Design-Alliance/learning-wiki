Qiang Liu and Chunyi Zhao 2026¶

Qiang Liu and Chunyi Zhao. (2026). Literary Axioms: A Conceptual Framework for Literary Creation, Interpretation, and Evaluation. arXiv. https://arxiv.org/abs/2609.25504 doi:10.48550/arxiv.2609.25504

q2 · i? · design · r?

Descriptive audit of the JSON snapshot, recomputed with standard-library Python scripts stored with the manuscript. The audit found 1,455 unique axiom identifiers, 1,464 work-axiom mappings to 149 unique works, and reports that "Only seven axioms map to more than one work, with a maximum of four mappings."

"Only seven axioms map to more than one work, with a maximum of four mappings, so the present artifact is better characterized as a set of work-derived records than as a densely reused cross-work ontology."
