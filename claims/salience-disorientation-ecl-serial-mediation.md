# Serial mediation: map-structure salience affects disorientation, which affects extraneous load and learning performance; the chain is only partially confirmed

## Subclaims
`q3 i3` Salience significantly affected disorientation (β = −0.53), disorientation significantly affected ECL (β = 0.80) and learning performance (β = −0.37), but the total effect of salience on performance was not significant. [→ Felix Krieglstein 2022](#felix-krieglstein-2022)

## Evidence

### Felix Krieglstein 2022

Felix Krieglstein, Sascha Schneider, Maik Beege, Günter Daniel Rey. (2022). How the design and complexity of concept maps influence cognitive learning processes. Education Tech Research Dev 70, 99–118. https://doi.org/10.1007/s11423-022-10083-2

`q3 · i3` · `causal · r2`

Serial mediation (Hayes macro) in the N = 122 experiment tested disorientation and ECL as sequential mediators. The salience→disorientation path ("β = − 0.53"), disorientation→ECL ("β = 0.80") and disorientation→performance ("β = − 0.37") were significant; the salience→ECL path (p = .722) and ECL→performance path (p = .371) were not.

> "The serial mediation analysis (see Fig. 3) showed that the salience of the map structure had a significant effect on disorientation (a1; β = − 0.53, SE = 0.28, p = .003). Disorientation, in turn, had a significant effect on ECL (d; β = 0.80, SE = 0.06, p < .001) and on learning performance (b1; β = − 0.37, SE = 0.69, p = .007)."
