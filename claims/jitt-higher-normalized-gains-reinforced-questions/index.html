Evidence¶

Marrs 2004¶

Marrs, K.A., and Novak, G. (2004). Just-in-Time Teaching in Biology: Creating an Active Learner Classroom Using the Internet. Cell Biology Education 3, 49–61. https://doi.org/10.1187/cbe.03-11-0022

q2 · i? · design · r2

Preclass/postclass 20-question test analysis within individual N100 classes using average normalized gain (Hake method). Questions reinforced by Warm Up or Cooperative Learning showed gains of ~52%, and ~60% when reinforced by both, versus ~15% for class-discussion-only questions; no standardized effect size is printed.

"students tended to show an average normalized gain of ~15% on test questions about concepts that were discussed in class, but not necessarily reinforced by any additional class activities"
