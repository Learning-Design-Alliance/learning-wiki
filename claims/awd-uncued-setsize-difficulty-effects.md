# AwD showed significant set size effects in uncued conditions alongside difficulty effects, unlike controls

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study · causal `r1` · `q2` · `i3` large

## Subclaims
`q2 i3` In uncued conditions the AwD showed significant effects of set size, difficulty and a difficulty by set size interaction, while controls showed no main effect of difficulty or interaction. [→ Moores 2011](#moores-2011)

## Evidence

### Moores 2011

Moores, E., Cassim, R. and Talcott, J.B. (2011). Adults with dyslexia exhibit large effects of crowding, increased dependence on cues, and detrimental effects of distractors in visual search tasks. Frontiers in Psychology. [doi:10.1016/j.neuropsychologia.2011.10.005](https://doi.org/10.1016/j.neuropsychologia.2011.10.005)

`q2 · i3` · `causal · r1`

Two-factor ANOVAs on set size eight crowded vs sixteen displays in uncued conditions. Both groups showed significant set size effects (η2p =.37 controls; η2p =.44 AwD), but only AwD showed significant difficulty (η2p =.44) and difficulty by set size interaction (η2p =.50) effects.

> "In uncued conditions, both the controls (F 1,15 =8.93, p<.01, η2p =.37) and the AwD (F 1,14 =10.89, p<.005, η2p =.44) showed significant effects of set size. The AwD also showed a significant effect of difficulty (F 1,14 =11.15, p<.005, η2p =.44) and a difficulty by set size interaction (F 1,14 =13.81, p<.005, η2p =.50)."
