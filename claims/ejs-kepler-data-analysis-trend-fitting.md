## Subclaims

## Evidence

### Loo Kang WEE 2013

Loo Kang WEE, Giam Hwee GOH, Ee-Peow LIM. (2013). Easy Java Simulation, Innovative Tool for Teachers as Designers of Gravity-Physics Computer Models. MPTL18, Madrid. [doi:10.48550/arXiv.1401.3061](https://doi.org/10.48550/arXiv.1401.3061)

`q1 · i?` · `design · r2`

Numerical best-fit results from the Kepler's System Model's built-in data analysis tool, shown in Figures 7 and 8: coefficients A = 0.999 for the T^2–R^3 fit and A = 1.498 for the lg–lg fit. The article states these are untried features: "We have not tried out these newly developed features-ideas (Figure 5) for supporting learning".

> "EJS is also an effective tool for the authors because we are able to make EJS plot all the data points (Figure 6), with two possible data analysis to study trends of 32 999.0 RT  (Figure 7) and  RT lg498.1lg  (Figure 8)."
