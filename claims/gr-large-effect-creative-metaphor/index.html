Roger E. Beaty & Paul J. Silvia 2013¶

Roger E. Beaty & Paul J. Silvia. (2013). Metaphorically speaking: cognitive abilities and the production of figurative language. Memory & Cognition. https://doi.org/10.3758/s13421-012-0258-5

In the same SEM of 191 undergraduates, three verbal fluency tasks indexed Gr. The model found Gr "had a similarly large effect on metaphor creativity ( β 0 .52, p < .001)", while Gc's effect was moderate but nonsignificant.

"Gr had a similarly large effect on metaphor creativity ( β 0 .52, p < .001), and Gc had a moderate but nonsignificant effect ( β 0 .24, p 0 .206)."
