Evidence¶

Olga C. Santos 2016¶

Olga C. Santos, Milos Kravcik, Jesus G. Boticario. (2016). Preface to Special Issue on User Modelling to Support Personalization in Enhanced Educational Settings. Int J Artif Intell Educ 26:809–820. https://doi.org/10.1007/s40593-016-0114-z

q2 · i? · review · r2

The review reports, citing Janning et al. (2016), classification of perceived task difficulty from statistically significant low-level log-file features; the presented approach "outperforms classical ensemble methods". No effect size or test statistic is printed.

"The presented approach outperforms classical ensemble methods and is able to improve the classification performance substantially, enabling perceived task-difficulty recognition that is satisfactory for employing its output for components of a real system like task independent support or task sequencing."
