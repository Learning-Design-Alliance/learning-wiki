# Time-reversed analysis of simulated data suggests a decreasing rather than increasing effect of self-concept on achievement, yielding inconsistent conclusions from the same data

## Subclaims
`q2 i?` In SIM-ORG data simulated to resemble the data used by Marsh et al., the reversed model yielded a positive focal effect (β = 0.418), which the authors interpret as indicating a paradoxical decreasing effect of within-individual self-concept on achievement, contradicting the REM's predicted increasing effect. [→ Kimmo Sorjonen 2025](#kimmo-sorjonen-2025)

## Evidence

### Kimmo Sorjonen 2025

Kimmo Sorjonen, Bo Melin, Gustav Nilsonne. (2025). Still No Convincing Evidence for a Causal Effect of Academic Self-Concept on Achievement: A Reply to Núñez-Regueiro et al., 2025. Educational Psychology Review. https://doi.org/10.1007/s10648-025-10083-7

`q2 · i?` · `theoretical · r3`

Simulation analysis fitting both the RI-CCLPM-C and a time-reversed model to SIM-ORG data. In SIM-ORG the RI-CCLPM-C gave β = 0.155 [0.127; 0.184] while the reversed model gave β = 0.418 [0.398; 0.437], both p < 0.001; model fit was good for all four data-model combinations (CFI > 0.96, RMSEA < 0.08).

> "However, the focal effect was positive also in the reversed model, suggesting a paradoxical decreasing effect of within-individual self-concept on within-individual achievement."
