Different approaches to assessing the quality of explanations following a multiple-document inquiry activity in science. Educational Psychology Review. https://doi.org/10.1007/s40593-017-0138-z

`q3 · i?` · `associational · r1`

Simultaneous regression on 178 explanation essays found TARGCONC and MODELCONN accounted for 33% of variance in IVT scores, with "MODELCONN .04 .01 .47 6.30 <.001".

> "the best fitting model included only the number of target concepts (TARGCONC) and number of connections between concepts (MODELCONN). This model, shown in Table 4, provided a good fit for the data, (F(2, 179) = 43.19, MSE = .01, p < .001), and accounted for 33% of the variance in test scores."
