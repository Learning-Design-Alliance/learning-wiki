# Gesture enrichment specifically aided translation of abstract words in Experiment 1, but this word-type specificity did not replicate in Experiment 2

## Subclaims
`q3 i3` In Experiment 1, gesture enrichment yielded higher L1-L2 translation scores for abstract words than no enrichment (Hedge's g = 0.69), contrary to the hypothesis of equivalent benefits. [→ Andrä 2020](#andra-2020)
`q3 i?` In Experiment 2, the learning condition × word type interaction was not significant for either translation test, so the abstract-word specificity did not replicate. [→ Andrä 2020 (2)](#andra-2020-2)

## Evidence

### Andrä 2020

Andrä, C., Mathias, B., Schwager, A., Macedonia, M., & von Kriegstein, K. (2020). Learning Foreign Language Vocabulary with Gestures and Pictures Enhances Vocabulary Memory for Several Months Post-Learning in Eight-Year-Old School Children. Educational Psychology Review. https://doi.org/10.1007/s10648-020-09527-z

`q3 · i3` · `causal · r2`

Experiment 1 within-subjects ANOVA (n = 54) showed a learning condition × word type interaction (η²p = 0.30) and a three-way interaction (η²p = 0.06). Abstract nouns learned with gestures were translated better "across time points" than abstract nouns without enrichment (g = 0.69).

> "significantly higher L1-L2 translation test scores were observed across time points for abstract nouns learned with gesture enrichment compared with abstract nouns learned without enrichment ( p < 0.01, Hedge's g = 0.69)."

### Andrä 2020 (2)

Andrä, C., Mathias, B., Schwager, A., Macedonia, M., & von Kriegstein, K. (2020). Learning Foreign Language Vocabulary with Gestures and Pictures Enhances Vocabulary Memory for Several Months Post-Learning in Eight-Year-Old School Children. Educational Psychology Review. https://doi.org/10.1007/s10648-020-09527-z

`q3 · i?` · `causal · r2`

Experiment 2 (n = 43, reduced 24-word set) found no significant learning condition × word type interaction for L1-L2 translation (p = 0.24) or three-way interaction (p = 0.50); the same held for L2-L1 translation (p = 0.61, p = 0.31).

> "Unlike Experiment 1, the three-way ANOV A did not yield a significant interaction between learning condition and word type variables ( p = 0.24) or significant three-way interaction ( p = 0.50), suggesting that benefits of enrichment on the L1-L2 translation test did not differ across the two word types (Fig. 5b)."
