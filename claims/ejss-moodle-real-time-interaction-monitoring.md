## Evidence

### Garcia Clemente 2019

Garcia Clemente, F. J., Wee, L. K., Esquembre, F., Leong, T. K., & Tan, D. (2019). Development of Learning Analytics-Moodle Extension for Easy JavaScript Simulation (EjsS) Virtual Laboratories. GIREP-ICPE-EPEC-MPTL conference, Budapest. [doi:10.48550/arXiv.1911.06654](https://doi.org/10.48550/arXiv.1911.06654)

`q2 · i?` · `design · r2`

Prototype development paper describing the authors' extension, which they report was piloted with educational physics simulations. The system 'monitors and records, in real-time, all the student interactions' such as mouse clicks, button and slider states, and variable assignments. No evaluation or outcome data are reported.

> "The Moodle extension that we have developed monitors and records, in real-time, all the student interactions with the Easy JavaScript Simulation."

### Garcia Clemente 2019 (2)

Garcia Clemente, F. J., Wee, L. K., Esquembre, F., Leong, T. K., & Tan, D. (2019). Development of Learning Analytics-Moodle Extension for Easy JavaScript Simulation (EjsS) Virtual Laboratories. GIREP-ICPE-EPEC-MPTL conference, Budapest. [doi:10.48550/arXiv.1911.06654](https://doi.org/10.48550/arXiv.1911.06654)

`q2 · i?` · `design · r2`

Description of the dashboard output of the same prototype: interaction information is shown on the instructor dashboard with 'a metric of each individual students' degree of being "on task"' plus students' current simulation state. This is a system demonstration, not a measured learning result.

> "This information is displayed on the instructor's dashboard with a metric of each individual students' degree of being "on task" and also shows students' current state on the simulation."
