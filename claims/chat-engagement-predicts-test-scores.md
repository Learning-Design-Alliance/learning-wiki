Correlational analysis of over 100,000 learning records from the MAIC pilot, regressing standardized test scores on log message number and length with Module 1 controls (Table 2). The article reports 'in-class chat engagement is found to significantly predict higher test scores'; e.g., uncontrolled µ(log(MsgNum)) with AvgQuiz is 0.341***.

> "A regression analysis of standardized test scores on in-class chat message metrics was performed, controlling for normalized scores from Module 1. As Table 2 shows, in-class chat engagement is found to significantly predict higher test scores."
