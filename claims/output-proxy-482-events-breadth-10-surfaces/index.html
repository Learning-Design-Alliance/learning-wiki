q1 · i? · design · r2

Keyword/rule-based extraction of dated memory entries in the single-investigator case study; output-proxy events are dated memory entries indicating completion or delivery of manuscripts, teaching artifacts, software changes, deployments, protocols, analyses, or operational deliverables. The article notes these are keyword/rule-derived proxies.

"Memory-derived records identified 482 output-proxy events and 1,423 dated memory sections (Table 3). The output-proxy rate was 5.02 events per active day (OPR = 482/96)."
