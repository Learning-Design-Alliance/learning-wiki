Maria A. Woitow, Anthony I. Jang, Ben Eppinger, Matthew R. Nassar, Marcel Brass & Julia M. Rodriguez Buritica. (2026). Shared effects of one's own and others' experiences during reinforcement learning on episodic memory. npj Science of Learning 11:16. https://doi.org/10.1038/s41539-026-00409-7

q3 · i? · causal · r2

Regression of memory strength on binned extreme trial values (deviating from the average value of 10) in 79 participants; the negative association was significant (ß0 = −0.1, t = −3.48, p < 0.001) and did not vary by learning condition or choice. No linear effect of trial value was found.
