# Both color coding and labeling increase looks between text and corresponding table information

> **Claim** · [All claims](index.md)
> **Evidence** · 1 study (2 entries) · causal `r2` · `q3`
> **Currency** · newest study 2016 · not yet checked against its sources · not reviewed by a person

## Subclaims
`q3 i?` Color coding increased the number of looks between sentences and relevant target areas for color coding (p = .05). [→ Clinton 2016](#clinton-2016)
`q3 i?` Labeling increased the number of looks between relevant sentences and target areas for labeling (p < .001). [→ Clinton 2016 (2)](#clinton-2016-2)

## Evidence

### Clinton 2016

Clinton, V., Morsanyi, K., Alibali, M. W., & Nathan, M. J. (2016). Learning about Probability from Text and Tables: Do Color Coding and Labeling through an Interactive-user Interface Help? Applied Cognitive Psychology, 30(3), 440-453. https://doi.org/10.1002/acp.3223

`q3 · i?` · `causal · r2`

Mixed effects Poisson model of looks between sentences and color-coded target cells, adjusted for pretest and need for cognition; the color coding effect was significant at p = .05.

> "Consistent with expectations, color coding increased the number of looks between sentences to relevant target areas for color coding, b = .30, Wald z = 1.98, Wald χ2(1, N = 98) = 3.92, p = .05."

### Clinton 2016 (2)

Clinton, V., Morsanyi, K., Alibali, M. W., & Nathan, M. J. (2016). Learning about Probability from Text and Tables: Do Color Coding and Labeling through an Interactive-user Interface Help? Applied Cognitive Psychology, 30(3), 440-453. https://doi.org/10.1002/acp.3223

`q3 · i?` · `causal · r2`

Mixed effects Poisson model of looks between sentences and labeled target cells; the labeling effect was significant, p < .001, with no color coding effect and no interaction.

> "Consistent with expectations, labeling increased the number of looks between relevant sentences and target areas for labeling, b = .73, Wald z = 3.80, Wald χ2(1, N = 98) = 14.46, p < .001."
