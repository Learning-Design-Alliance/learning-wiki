The review defines coaching systems as those that offer advice based on an interpretation of interaction indicators, distinguishing them from mirroring systems and metacognitive tools within the proposed classification framework.

> "Our framework distinguishes between mirroring systems, which display basic actions to collaborators, metacognitive tools, which represent the state of interaction via a set of key indicators, and coaching systems, which offer advice based on an interpretation of those indicators."
