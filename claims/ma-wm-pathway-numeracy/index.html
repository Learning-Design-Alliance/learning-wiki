Evidence¶

Skagerlund K 2019¶

Skagerlund K, Östergren R, Västfjäll D, Träff U (2019) How does mathematics anxiety impair mathematical abilities? Investigating the link between math anxiety, working memory, and number processing. PLoS ONE 14(1): e0211283. https://doi.org/10.1371/journal.pone.0211283

q3 · i? · associational · r1

Confirmatory SEM path analysis of numeracy (Berlin Numeracy Test) in 170 Swedish adults, estimated in Mplus 7. The model showed good fit (χ2 = 44.57 (32), p = .069, CFI = .97, RMSEA = 0.05) and "explained 29% of the variance in numeracy". The MA→WM→numeracy path was significant; the MA→NP→numeracy path was not.

"The path from math anxiety via working memory had a statistically significant indirect effect to numeracy (p = .004, standardized estimate = -.14) but not a significant indirect effect via NP to numeracy (p = .807)."
