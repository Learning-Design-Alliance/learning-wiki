## Evidence

### Santomauro Chiara M. 2020

Santomauro Chiara M., Hill Andrew, McCurdie Tara, McGlashan Hannah L. (2020). Improving the Quality of Evaluation Data in Simulation-Based Healthcare Improvement Projects: A Practitioner's Guide to Choosing and Using Published Measurement Tools. Simulation in Healthcare. https://doi.org/10.1097/SIH.0000000000000442

`q1 · i?` · `theoretical · r3`

Theoretical exposition in the article's reliability section, framed via generalizability theory, explaining that facets of the measurement situation (occasions, conditions, raters) contribute error variation. The article states reliability 'depends on the context in which the tool is intended to be used.'

> "reliability is not simply a static attribute of a tool (or the measurements derived from it); rather, reliability depends on the context in which the tool is intended to be used."
