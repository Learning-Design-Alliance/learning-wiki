The paper's key finding on regression discontinuity designs: robust methods guard against "inaccuracies from incorrect regression models," but "much larger sample sizes are needed in order to detect small effects when using these methods." No effect size is printed.

"For RDDs, state-of-the-art statistical methods can protect against inaccuracies from incorrect regression models, but this protection comes at a cost – much larger sample sizes are needed in order to detect small effects when using these methods."
