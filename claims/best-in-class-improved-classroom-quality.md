## Evidence

### Maureen A. Conroy 2019

Maureen A. Conroy, Kevin S. Sutherland, James Algina, Crystal Ladwig, Brittany Werch, Jose Martinez, Gabriel Jessee, Maria Gyure. (2019). Outcomes of the BEST in CLASS Intervention on Teachers' Use of Effective Practices, Self-Efficacy, and Classroom Quality. School Psychology Review. https://doi.org/10.17105/SPR-2018-0003.V48-1

`q3 · i2` · `causal · r2`

CLASS observations (four 10- to 20-min cycles, 1–7 ratings; n = 186) at pretest and posttest in the cluster randomized trial, analyzed in Mplus 8.0. Adjusted means were e.g. "AM B = 5.34 for BEST in CLASS and AMC = 4.82 for the comparison group" for classroom organization; the discussion prints an emotional support effect size of .47 and instructional support d = .65 in Table 3.

> "Therefore, BEST in CLASS increased teacher performance on all three CLASS domains. Effect sizes for all three CLASS domains were .50 or larger."
