Luke 2017¶

Luke, Christina C.; Gibson, Sierra; Francisco, Aubrey T. (2017). Rapid Cycle Pilots: Using Edtech to Support English Learners. Digital Promise. https://digitalpromise.dspacedirect.org/items/383e02ba-587a-4192-be68-175543798661

q2 · i? · design · r2

Hierarchical multiple regression on Cajon Valley data with current Lexile as dependent variable and pre-test Lexile, Achieve3000 usage, motivation to learn English, and student age as predictors, run in IBM SPSS. Percentages are variance shares as printed; no standardized effect size is reported.

"The final multiple regression model indicated that pre-Lexile score serves as a 76 percent indicator of students' current Lexile scores, while Achieve3000 usage accounts for about 3.5 percent and students' motivation to learn English predicts roughly 1 percent of students' current Lexile score (p < 0.01)"
