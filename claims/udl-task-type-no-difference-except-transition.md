# Task type did not differ significantly between groups except for more no-task/transition time in control classes

## Subclaims
`q3 i2` Types of task did not differ significantly between treatment and control classes for paper and pencil (partial η = .005) or other media tasks (η = .003), but control classes had significantly more no task/transition time (F = 5.889, p = .02, η = .072); the overall task effect had partial η = .139. [→ Katz 2013](#katz-2013)

## Evidence

### Katz 2013

Jennifer Katz. (2013). The Three Block Model of Universal Design for Learning (UDL): Engaging students in inclusive education. Canadian Journal of Education, 36(1). https://journals.sfu.ca/cje/index.php/cje

`q3 · i2` · `causal · r1`

MANCOVA of observed task types (Table 8): task overall F(9,68) = 4.415, partial η = .139, p < .001; paper and pen η = .005; other media η = .003; no task/transition F = 5.889, p = .02, η = .072. Means show over half of observed time in both class types was spent in differentiated tasks.

> "In this study, types of task did not differ significantly, with the exception of a significantly greater amount of time with no task/in transition in control classes."
