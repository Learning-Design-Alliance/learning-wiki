Princeton, NJ: Mathematica Policy Research. https://www.mathematica.org/publications/can-more-teachers-be-covered-the-accuracy-credibility-and-precision-of-value-added-estimates

The authors propose, based on the Oklahoma analysis, that "empirical Bayes shrinkage... might also be used to address bias" in proxy pre-test value-added estimates. This is a forward-looking proposal, not a tested manipulation in the available text.

> "empirical Bayes shrinkage, an approach typically used to address precision, might also be used to address bias so that value-added estimates that rely on proxy pre-tests can be given more appropriate weights in teachers' evaluations."
