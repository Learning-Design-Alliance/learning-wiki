## Subclaims
`q2 i3` In the control group, first work performance (r = 0.44, p < 0.05) and second work performance (r = 0.41, p < 0.015) correlated significantly with motivation to learn, while learning performance, learning attitude, self-regulated performance, and reflection showed no significant correlations with work performance. ## Evidence

### Yen-Fen Lee 2025

Yen-Fen Lee, Gwo-Jen Hwang, Pei-Ying Chen. (2025). Technology-based interactive guidance to promote learning performance and self-regulation: a chatbot-assisted self-regulated learning approach. Education Tech Research Dev. https://doi.org/10.1007/s11423-025-10478-x

`q2 · i3` · `causal · r2`

Pearson correlation analysis of the control group's data (Table 12); the article reports "significant correlations between first work performance (r = 0.44, p < 0.05) and second work performance (r = 0.41, p < 0.015), with motivation to learn", but no significant correlations with the other measures.

> "there were significant correlations between first work performance (r = 0.44, p < 0.05) and second work performance (r = 0.41, p < 0.015), with motivation to learn. However, there was no significant correlation between learning performance, learning attitude, self-regulated performance, reflection, and postulated cognitive perception tendency."
