# Exploratory: RL-timed access reduces task errors and time per question relative to full withholding, but not after controlling for gender

## Subclaims
`q3 i2` RL participants made significantly fewer mistakes per question than Never participants (d = 0.51), an effect no longer significant after controlling for gender. [→ Janne Rotter 2026](#janne-rotter-2026)
`q3 i2` RL participants took marginally significantly less time per question than Never participants (d = 0.47), also non-significant after controlling for gender. [→ Janne Rotter 2026 (2)](#janne-rotter-2026-2)

## Evidence

### Janne Rotter 2026

Janne Rotter, Pau Benazet i Montobbio, Davinia Hernández-Leo. (2026). Access Timing as Scaffolding: A Reinforcement Learning Approach to GenAI in Education. [doi:10.48550/arXiv.2605.15850](https://doi.org/10.48550/arXiv.2605.15850)

`q3 · i2` · `causal · r2`

Exploratory analysis in the same N=105 lab experiment comparing average mistakes per question. The RL vs Never contrast printed "t(67) = 2.05,p= .047,d= 0.51"; after controlling for gender it was no longer significant (b = 0.46, p = .513).

> "participants in the RL condition made significantly fewer mistakes than those in the Never condition,t(67) = 2.05,p= .047,d= 0.51"

### Janne Rotter 2026 (2)

Janne Rotter, Pau Benazet i Montobbio, Davinia Hernández-Leo. (2026). Access Timing as Scaffolding: A Reinforcement Learning Approach to GenAI in Education. [doi:10.48550/arXiv.2605.15850](https://doi.org/10.48550/arXiv.2605.15850)

`q3 · i2` · `causal · r2`

Exploratory time-on-task analysis in the same experiment; the RL vs Never contrast was marginal, "t(67) = 1.94,p= .058,d= 0.47", and non-significant after controlling for gender (b = 2.74, p = .769). RL vs Always time showed no difference (t(71) = 0.37, p = .714).

> "participants in the RL condition took marginally significantly less time per question than those in the Never condi-tion,t(67) = 1.94,p= .058,d= 0.47"
