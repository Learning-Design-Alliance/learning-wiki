Evidence¶

Sasan Baleghizadeh and Atieh Masoun 2013¶

Sasan Baleghizadeh and Atieh Masoun. (2013). The Effect of Self-Assessment on EFL Learners' Self-Efficacy. TESL Canada Journal/Revue TESL du Canada, Volume 31, Issue 1. https://eric.ed.gov/?id=EJ1033761

q2 · i3 · causal · r2

Quasi-experimental pretest/posttest control group study with two intact classes of female adult intermediate EFL learners (experimental n = 27, control n = 30). ANCOVA compared posttest self-efficacy with pretest as covariate; the treatment effect was significant with a printed effect size of η² = 0.3: "The eta squared value for the independent variable (treatment) is 0.3".

"The eta squared value for the independent variable (treatment) is 0.3 indicating that 30 percent of the variance in the dependent variable is explained by the independent variable."
