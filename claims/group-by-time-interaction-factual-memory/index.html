Evidence¶

Cousins 2019¶

Cousins, J. N., van Rijn, E., Ong, J. L., Wong, K. F., & Chee, M. W. L. (2019). Does splitting sleep improve long-term memory in chronically sleep deprived adolescents? npj Science of Learning 4:8. https://doi.org/10.1038/s41539-019-0047-z

q3 · i? · causal · r2

Omnibus mixed ANOVA on certain memory scores (correct minus incorrect) from the factual knowledge task, factors group and time. "an interaction, F(1,56) = 5.646, p = 0.021" indicates the split-sleep advantage was time-specific; no effect size was printed for the interaction.

"a mixed ANOVA with group (split sleep/continuous sleep) and time (morning/afternoon) showed a signiﬁcant main effect of group, F(1,56) = 4.172, p = 0.046, an interaction, F(1,56) = 5.646, p = 0.021, but no effect of time, F(1,56) = 0.117, p = 0.734"
