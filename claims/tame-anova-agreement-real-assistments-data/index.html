Evidence¶

Thanaporn Patikorn 2016¶

Thanaporn Patikorn, Douglas Selent, Neil T. Heffernan, Joseph E. Beck, Jian Zou. (2016). Using a Single Model Trained across Multiple Experiments to Improve the Detection of Treatment Effects. Proceedings of the 10th International Conference on Educational Data Mining. https://sites.google.com/site/tamemethod/

q2 · i? · design · r2

Application of both methods to a dataset of twenty-two randomized controlled experiments run inside the ASSISTments online learning platform, each a Skill Builder with one control and one treatment group. Since each experiment had more than 100 students, the simulation study suggested TAME would be as good as ANOVA at detecting significant differences.

"Both TAME and ANOVA detected significant differences between conditions of the same experiments (2, 3, 4, 10, and 22 ). This result further supports our claim that TAME is a good alternative to ANOVA, if not better."
