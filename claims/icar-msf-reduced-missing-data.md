# Using the modified ICAR in an MSF process significantly reduced missing assessment data compared with daily assessments (8.8% vs 13.1%)

## Subclaims
`q2 i?` Missing data decreased from 13.1% with daily assessments to 8.8% with the MSF process, a statistically significant reduction. [→ Hayward Mark F 2014](#hayward-mark-f-2014)

## Evidence

### Hayward Mark F 2014

Hayward Mark F, Curran Vernon, Curtis Bryan, Schulz Henry, Murphy Sean. (2014). Reliability of the Interprofessional Collaborator Assessment Rubric (ICAR) in Multi Source Feedback (MSF) with post-graduate medical residents. BMC Medical Education. https://doi.org/10.1186/s12909-014-0279-9

`q2 · i?` · `design · r2`

Field test of the modified ICAR in an MSF process compared with an earlier daily-assessment pilot study; paired samples t-test showed the reduction was significant (p = .032), with "8.8% vs. 13.1% respectively". No effect size was printed.

> "A paired samples t-test analysis of missing data revealed a significant reduction between the MSF field test study using the ICAR and the initial pilot study, 8.8% vs. 13.1% respectively, p = .032"
