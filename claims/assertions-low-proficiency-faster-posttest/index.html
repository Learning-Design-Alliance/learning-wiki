Mehak Maniktala 2020¶

Mehak Maniktala, Christa Cody, Tiffany Barnes, Min Chi. (2020). Avoiding Help Avoidance: Using Interface Design Changes to Promote Unsolicited Hint Usage in an Intelligent Tutor. https://arxiv.org/abs/2009.13371

q3 · i? · causal · r2

ANCOVA on posttest total time in the same study found a Condition x Prior Proficiency interaction (F(1,100) = 6.236, p = 0.014) and a main effect of Condition (F(1,100) = 6.913, p = 0.010); Table 2 reports means of 36.03 vs 52.94 minutes for the Low groups. No standardised effect size is printed.

"A pairwise Tukey's Honest Signiﬁcant (HSD) test for multiple comparisons on the total posttest time shows a signiﬁcant diﬀerence ( p = 0.008) between Assertions-Low and Messages-Low groups. The Assertions-Low group spent signiﬁcantly less time on the posttest than the Messages-Low group."
