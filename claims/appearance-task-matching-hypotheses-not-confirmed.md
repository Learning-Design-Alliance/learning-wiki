# Hypotheses that specific robot appearances would be trusted more in matching tasks (humanoids for teaching, task-oriented robots for instructions, soft robots for personal disclosure) were not confirmed

`q3 · i?` · `causal · r2`

In the N = 81 within-subjects experiment, participants had hypothesized higher trust for humanoids (especially NAO) in teaching, task-oriented robots (Pepper) in step-by-step instructions, and the soft robot Daisy in personal-information tasks; the article states these hypotheses "were not confirmed". No effect size is printed for this null finding.

> "The hypotheses related to matching robot appearance to task based on each robot's external characteristics were not confirmed."
