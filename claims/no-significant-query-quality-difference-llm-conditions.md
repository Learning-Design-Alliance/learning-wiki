## Evidence

### Kumar 2025

Kumar, H., Reza, M., Mitchell, J., Musabirov, I., Zhang, L., & Liut, M. (2025). Understanding Help-Seeking Behavior of Students Using LLMs vs. Web Search for Writing SQL Queries. Preprint. Originally published 2024. [doi:10.1145/3735091.3737569](https://doi.org/10.1145/3735091.3737569)

`q2 · i?` · `causal · r2`

Query quality was scored (0-100) using the course instructor's grading rubric in the randomized interview study with 39 students. The test was not significant, but "correctness was directionally higher for both LLM conditions than for the web search condition."

> "The Kruskal-Wallis H test for the correctness between conditions was not significant ( 𝜒 2(2) = 3.85, 𝑑 𝑓 = 2, 𝑝 = 0.14). However, correctness was directionally higher for both LLM conditions than for the web search condition."
