## Evidence

### Marlieke Tina Renée van Kesteren 2018

Marlieke Tina Renée van Kesteren, Lydia Krabbendam and Martijn Meeter (2018). Integrating educational knowledge: reactivation of prior knowledge during educational learning enhances memory integration. npj Science of Learning 3:11. https://doi.org/10.1038/s41539-018-0027-8

`q3 · i?` · `causal · r2`

Null result from experiment 1's combined congruency × curiosity ANOVAs; e.g. for associative recall the curiosity effect was F(1,11) = 1.90, P = .20, η2 = .15, with no significant effect and no printed standardized effect size for the null. "No effects of curiosity on memory performance were found." Curiosity was replaced by metamemory ratings in experiment 2.

> "No effects of curiosity on memory performance were found."

### Marlieke Tina Renée van Kesteren 2018 (2)

Marlieke Tina Renée van Kesteren, Lydia Krabbendam and Martijn Meeter (2018). Integrating educational knowledge: reactivation of prior knowledge during educational learning enhances memory integration. npj Science of Learning 3:11. https://doi.org/10.1038/s41539-018-0027-8

`q3 · i3` · `causal · r2`

Experiment 2 replaced curiosity with metamemory judgments; main effects of metamemory on item recognition (F(1,19) = 15.63, P = .001, η2 = .45) and associative recall (F(1,17) = 19.43, P < .001, η2 = .53) were large. "metamemory ratings did for both item recognition and associative memory".

> "Lastly, we found that curiosity ratings did not relate to subsequent memory, but metamemory ratings did for both item recognition and associative memory."
