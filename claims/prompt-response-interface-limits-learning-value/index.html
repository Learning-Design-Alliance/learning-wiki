The Perspective reports, citing prior empirical work, that the prompt–response structure centres the student's task on learning to ask the right question while the system delivers a coherent authoritative answer, mirroring instructionist pedagogies that decompose knowledge into discrete units and evaluate progress through correctness and fluency.
