# A remote educational escape room for databases produced a statistically significant pre-to-post knowledge increase with a large effect size (r=0.69)

## Subclaims
`q2 i3` Students' post-test scores were significantly higher than pre-test scores after the remote database escape room, with a large effect size (r=0.69). [→ Enrique Barra 2023](#enrique-barra-2023)

## Evidence

### Enrique Barra 2023

Enrique Barra, Sonsoles López-Pernas, Aldo Gordillo, Alejandro Pozo, Andres Muñoz-Arcentales, Javier Conde. (2023). Empowering Database Learning through Remote Educational Escape Rooms. IEEE Internet Computing. https://doi.org/10.1109/MIC.2023.3333199

`q2 · i3` · `design · r2`

Pre/post-test evaluation of the escape room across four higher education courses in two academic years (299 participants). The average pre-test score was 5.8 (SD = 2.1) and the average post-test score was 7.24 (SD = 2.0), with "a large effect size (p-value < 0.001; r=0.69)" on the Wilcoxon Signed-Ranks Test.

> "According to the results obtained in the Wilcoxon test, the difference between the post -test and pre -test scores was statistically significant with a large effect size (p-value < 0.001; r=0.69)."
