`q2 · i?` · `design · r?`

Simulation numérique (figure 16, utilisateur de téléphonie mobile à 900 MHz) réalisée avec le modèle 3D Microstripes, qui utilise la méthode TLM nécessitant moins de ressources que HFSS. Le modèle intègre les permittivités des principaux tissus humains pour illustrer la pénétration des ondes dans le corps.

> "Cet exemple nous permet d'aborder les changements de longueurs d'ondes dans les milieux (ici un être humain), les notions de profondeur de pénétration ou de DAS (débit d'absorption spécifique). Des permittivités des principaux tissus humains sont intégrés dans le modèle [11]."
