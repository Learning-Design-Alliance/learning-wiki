## Evidence

### Catrysse 2025

Catrysse, L., van Daal, T., Jarodzka, H., Kaakinen, J. K., Donche, V., & Gijbels, D. (2025). How Eye Read: A Social Network Approach. Educational Psychology Review. https://doi.org/10.1007/s10648-025-10000-y

`q3 · i?` · `associational · r1`

Linear mixed-effects model on betweenness centrality from the same 31-reader eye-tracking dataset; the printed fixed effect of WMC was β = −0.709, p = 0.017, with marginal R² = 0.024 and conditional R² = 0.260.

> "Betweenness is related to working memory capacity: when working memory capacity increases, betweenness decreases."
