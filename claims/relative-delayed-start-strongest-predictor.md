## Subclaims
`q2 i?` Adding relative delayed start to a baseline model of prior math scores produced the largest BIC reduction (BIC = 376, R2 = 0.53) among all explored measures, with strong evidence of improvement. [→ Ashish Gurung 2025](#ashish-gurung-2025)

## Evidence

### Ashish Gurung 2025

Ashish Gurung, Jionghao Lin, Zhongtian Huang, Conrad Borchers, Ryan S. Baker, Vincent Aleven, Kenneth R. Koedinger. (2025). Starting Seatwork Earlier as a Valid Measure of Student Engagement. arXiv. [doi:10.48550/arXiv.2505.13341](https://doi.org/10.48550/arXiv.2505.13341)

`q2 · i?` · `associational · r2`

Regression analysis predicting standardized teacher-assigned year-end math scores from prior-year scores plus each measure individually (222 students, 9 months of Cognitive Tutor data), evaluated with BIC following Raftery's guidelines. Relative delayed start had beta = -0.25, p < 0.001.

> "we observed strong evidence of performance improvements for delayed start (BIC = 380, R2 = 0.51), relative delayed start (BIC = 376, R2 = 0.53), relative session length (BIC = 383, R2 = 0.50), idle time (BIC = 386, R2 = 0.49)"
