# Positive image reward prediction errors during gambling or observed gambling selectively enhance memory in both experiential and observational learning

## Subclaims
`q3 i1` Trials eliciting positive image RPEs in which participants gambled or observed gambling were associated with enhanced memory (EL d = 0.30; OL d = 0.27), whereas pass trials were not. [→ Maria A. Woitow 2026](#maria-a-woitow-2026)

## Evidence

### Maria A. Woitow 2026

Maria A. Woitow, Anthony I. Jang, Ben Eppinger, Matthew R. Nassar, Marcel Brass & Julia M. Rodriguez Buritica. (2026). Shared effects of one's own and others' experiences during reinforcement learning on episodic memory. npj Science of Learning 11:16. https://doi.org/10.1038/s41539-026-00409-7

`q3 · i1` · `causal · r2`

Exploratory one-sample t-tests on memory performance for positive image RPE trials in 79 participants: EL d = 0.30 (t78 = 2.66, p = 0.009), OL d = 0.27 (t78 = 2.37, p = 0.02); "pass trials were not" significant, and negative RPE trials did not differ from average.

> "Trials eliciting positive RPEs in which participants gambled or observed gambling were associated with enhanced memory (EL: t78 = 2.66, p = 0.009, d = 0.30, 95% CI = 0.03–0.19; OL: t78 = 2.37, p = 0.02, d = 0.27, 95% CI = 0.01–0.16; one- sample t-tests against 0"
