# Recent/up-to-date sepsis training, belief in pre-hospital care's importance, and belief in pre-notification value predict diagnostic confidence (R² = 0.657)

## Subclaims
`q2 i?` In an exploratory multiple linear regression, recent/up-to-date sepsis training (B = 0.385), belief in PHEMC's importance (B = 0.295), and belief in pre-notification value (B = 0.214) each significantly predicted diagnostic confidence, while previous missed diagnosis did not (B = −0.053, p = 0.126). Exploratory multiple linear regression with Q1 diagnostic confidence as dependent variable in a cross-sectional survey of 221 practitioners. The model "explained 65.7% of the variance in self-reported diagnostic confidence" with significant predictors reported in Table 5.

> "The model explained 65.7% of the variance in self-reported diagnostic confidence (R2 = 0.657, F (4,216) = 103.60, p < 0.001)."
