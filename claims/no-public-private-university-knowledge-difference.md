Chi-square and regression analyses of the 506-participant cross-sectional survey found no significant university-type association in either domain (Table 2 p = 0.787; Table 3 p = 0.375; Table 4 p = 0.54 and p = 0.17). Equivalence was not tested; only non-significant tests are reported, so no effect size is printed.
