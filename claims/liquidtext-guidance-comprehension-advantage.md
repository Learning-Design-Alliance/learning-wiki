## Evidence

### Jordan Lombard 2021

Jordan Lombard, Ivar Bråten, Cécile van de Leemput, Franck Amadieu. (2021). Performance and acceptance when using tablets as a multiple document learning tool: do application and guidance matter? Instructional Science. https://doi.org/10.1007/s11251-021-09537-6

`q3 · i3` · `causal · r2`

One-way ANOVA in a randomized between-subjects experiment with 88 undergraduates showed conditions differed on comprehension, F(3, 84) = 7.46, p < .001. The guided LiquidText condition beat each other group, including "the control condition (M = 9.38, SD = 2.34, Cohen’s d = 1.41)".

> "Post-hoc comparisons using the REGWF procedure showed that participants in the LiquidText Guidance condition (M = 12.27, SD = 1.77) scored statistically significantly higher than did participants in the LiquidText Non-Guidance condition (M = 10.42, SD = 2.09, Cohen’s d = 0.96)"
