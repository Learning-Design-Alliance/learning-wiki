# Reactivations do not increase false memories: no reactivation effect on falsely recalled images or details

## Subclaims
`q3 i?` Neither reactivation type increased false recalled images or false details; the reactivation main effect and interaction were non-significant on both error measures. [→ MacLeod 2018](#macleod-2018)

## Evidence

### MacLeod 2018

MacLeod, S., Reynolds, M. G. & Lehmann, H. (2018). The mitigating effect of repeated memory reactivations on forgetting. npj Science of Learning 3:9. https://doi.org/10.1038/s41539-018-0025-x

`q3 · i?` · `causal · r2`

For false images, only the interval main effect was significant, F(2, 155) = 13.57, p < 0.001; the 1-h condition reported fewer false images than the 9-day and 28-day conditions. For false details, the ANOVA "failed to reveal any signi ﬁcant effects".

> "Neither the main effect of reactiva- tion, F (3, 155) = 0.40, p = 0.76, nor the interaction, F (6, 155) = 0.77, p = 0.59, approached signi ﬁcance."
