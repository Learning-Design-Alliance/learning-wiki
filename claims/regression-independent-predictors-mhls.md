# Gender, marital status, and specialty type remained independent predictors of MHLS total scores in multivariable regression, while age and psychiatry experience did not

## Subclaims
`q3 i?` In multivariable linear regression (N = 305), gender (β = −0.12, p = 0.034), marital status (β = 0.13, p = 0.022), and specialty type (β = −0.11, p = 0.049) remained significant independent predictors; age and psychiatry experience were not (p > 0.05).
