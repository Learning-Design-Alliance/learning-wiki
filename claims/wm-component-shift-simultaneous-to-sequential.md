# Between ages 7–8 and 9–10, the influential visuospatial working memory subcomponent for mathematics shifts from spatial–simultaneous to spatial–sequential, while verbal working memory remains a significant predictor

## Subclaims
`q3 i?` Spatial–simultaneous working memory predicted mathematics at T1 (age 7–8) but not at T2 (age 9–10), where spatial–sequential became significant. [→ Allen 2020](#allen-2020)
`q3 i?` The article concludes that the predictors of mathematics changed between the two ages from spatial–simultaneous and verbal to spatial–sequential and verbal. [→ Allen 2020 (2)](#allen-2020-2)

## Evidence

### Allen 2020

Allen, K., Giofrè, D., Higgins, S., & Adams, J. (2020). Using working memory performance to predict mathematics performance 2 years on. Psychological Research. https://doi.org/10.1007/s00426-020-01382-5

`q3 · i?` · `associational · r2`

Results of the longitudinal SEM reported in the Results section: at T1 the significant paths to mathematics came from the simultaneous and verbal working memory factors, while the sequential path was not significant. No effect size value is printed for these paths.

> "In this model, paths from simultaneous and verbal working memory factors to mathematics at T1 were statistically significant, whilst the path from sequential working memory was not."

### Allen 2020 (2)

Allen, K., Giofrè, D., Higgins, S., & Adams, J. (2020). Using working memory performance to predict mathematics performance 2 years on. Psychological Research. https://doi.org/10.1007/s00426-020-01382-5

`q3 · i?` · `associational · r2`

The article's concluding statement of the longitudinal contrast in the same children, naming spatial–sequential and verbal as the T2 predictors "as opposed to spatial–simultaneous and verbal" at T1. No effect size is printed in this sentence.

> "Spatial–sequential and verbal working memory tasks are predictive of 9–10-year-old performance in mathematics, as opposed to spatial–simultaneous and verbal measures in the same children at 7–8 years of age."
