# Four-metric behavioral taxonomy for distinguishing authentic iterative coding from automated workflows

## Description
The article defines four analytical metrics derived from explicit API event logs to "differentiate authentic learning behaviors from automated or externally synthesized workflows": (a) a class rhythm heatmap of temporal interaction density, (b) cumulative platform engagement showing staircase-like growth, (c) session intensity defined as the ratio of recorded explicit actions to session duration, and (d) daily work volume aggregating events over 24-hour periods. Triangulated, these metrics anchor a behavioral profile distinguishing iterative human development—variable intensity, plateaus, diurnal rhythms—from rigid, unbroken automated patterns.
