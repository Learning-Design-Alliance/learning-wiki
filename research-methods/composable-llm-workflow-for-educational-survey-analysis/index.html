Composable LLM workflow for educational survey analysis¶

Research Method · All research methods
Evidence · 1 claim (1 for) · 1 study (1 design), q3 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

A framework treating educational survey analysis goals as sequences of natural language processing tasks — multi-label, multi-class, and binary classification, extraction, inductive thematic analysis, and sentiment analysis — each performed by an LLM in zero-shot mode. High-level analysis proceeds bottom-up via inductive thematic analysis or top-down via multi-label classification with predefined labels; focused analysis chains extraction followed by classification or thematic analysis, with sentiment analysis as a final step. The authors demonstrate these "composable building blocks" on real end-of-course survey comments, with quantification supported by classification counts.
