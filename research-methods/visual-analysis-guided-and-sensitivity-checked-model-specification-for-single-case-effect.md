## Description
The article recommends that analysts choose the hierarchical model for single-case data by first using visual inspection of the data series, then conducting preliminary analyses such as information criteria and likelihood ratio tests. It states: "we recommend researchers using visual analysis to guide the initial model specification and then conduct preliminary analyses, including information criteria and likelihood ratio tests, to reach an appropriate model specification." Because different specifications yield different effect size estimates, it also recommends reporting sensitivity analyses across plausible models.
