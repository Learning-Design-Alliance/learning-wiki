## Description
Ultra Strong Machine Learning (USML), proposed by Michie and operationalised via the Eex framework, distinguishes learning systems by whether their explanations improve human performance. USML "builds on strong machine learning, requiring its explanations to quantifiably improve human out-of-sample performance compared to self-learning". Eex compares unaided human comprehension (a group studying input-output examples) with machine-explained comprehension (a similar group studying the machine's output M(E)), defining the effect as the difference between the two measurements; Eex > 0 with appropriate statistical tests is a necessary condition to conclude a machine is USML. The framework does not restrict explanation format or limit Eex to predictive accuracy.
