# Five trustworthiness metrics comprising 20 measures for evaluating LLM trustworthiness in education

> **Research Method** · [All research methods](index.md)

## Description
The article co-constructed a set of five trustworthiness metrics comprising 20 quantitative measures tailored to pedagogical use. Metrics visible in the article include Misinformation, Sycophancy, Diplomacy, Disposition, Learning Method, and Response Quality, each defined by criteria such as "The LLM only generates true, substantiated factual claims" and "The LLM response follows established principles of learning." Measures were sourced from ML trustworthiness literature, education literature on pedagogical prompt patterns, and task-based response quality criteria, then refined through collaborative whiteboarding sessions with learning engineers.
