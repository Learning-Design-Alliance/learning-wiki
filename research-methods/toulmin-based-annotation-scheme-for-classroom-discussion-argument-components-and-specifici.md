# Toulmin-based annotation scheme for classroom discussion argument components and specificity

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article applies an ELA classroom-oriented annotation scheme based on the Toulmin model, in which "The argument component types in this scheme, which is based on the Toulmin model (1958), are: (i) Claim: an arguable statement that presents a particular interpretation of a text or topic", plus evidence (facts, documentation, text reference, or testimony supporting a claim) and warrant (reasons explaining how evidence supports a claim). A parallel specificity scale (low, medium, high) codes four elements such as being specific to a character or scene, using content-specific vocabulary, or providing a chain of reasons. The scheme enables automatic classification of student utterances as a first step toward tools that help teachers analyze student arguments.
