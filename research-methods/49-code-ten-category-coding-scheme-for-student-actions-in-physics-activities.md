# 49-code, ten-category coding scheme for student actions in physics activities

## Description
A qualitative coding scheme developed via the constant comparative method from three triangulated sources: designer interviews, the 2014 AAPT lab report, and published research-based activities. The article reports "The final scheme consisted of 49 codes in ten categories as shown in Table II", covering observation, prediction, spoken representation, design, qualifications, miscellaneous, epistemology, written representation, and revisiting. Six features were selected for the cluster analysis. Inter-rater reliability averaged "an average Cohen's kappa of 0.78 per activity".
