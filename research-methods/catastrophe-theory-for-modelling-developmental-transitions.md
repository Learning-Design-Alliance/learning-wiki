# Catastrophe theory for modelling developmental transitions

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A mathematical framework describing the relationship between control variables and behavioural (state) variables 'in so-called gradient systems', in which a system always seeks an equilibrium state. Small continuous changes in a control variable can then produce large discontinuous changes in the state variable at bifurcation points. The article uses this framework to define transitions formally and notes that with at most two behavioural variables there are only seven qualitatively different gradient systems, the elementary catastrophes, with the cusp most used in experimental research.
