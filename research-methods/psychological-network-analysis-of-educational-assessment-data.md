# Psychological network analysis of educational assessment data

## Description
The article applies psychological-network methods to OSCE module scores, estimating a regularized partial correlation network (EBICglasso) and computing centrality indices, with expected influence treated as primary: "Expected influence (EI) is a measure calculated by adding up the weights of edges connected to a node in a network." High-EI nodes are read as modules whose improvement can boost related competencies, complementing t-tests, ANOVA, and correlations. Accuracy and stability were checked with bootnet bootstrapping, including correlation stability coefficients.
