# Recognize-recall-generate framework for coding translation questions in quantum mechanics

> **Research Method** · [All research methods](index.md)

## Description
The article codes questions about translating state vectors between Dirac notation and position or momentum representations into three categories. As the authors state, "the researchers jointly agreed that “recognize, recall, generate” is one way to code these types of questions." Recognition asks students to evaluate the correctness of a written statement, recall asks them to state the physical significance of an expression, and generation asks them to produce the wave function for a generic state vector, a position eigenstate, or a momentum eigenstate. The framework reveals that student performance depends on the cues or scaffolding provided in the problem statement.
