# Matrix-based CLO–SO–PEO attainment evaluation framework

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article presents a complete evaluation process for assessment data built on mapping matrices: questions to CLOs (binary), CLOs to SOs (relevance 1-3), and PEOs to SOs. It states that "Every question contributes to one or more CLOs and every CLO contributes to one or more student outcomes (SO)". Metrics include CLO attainment, CLO weightage, student achievement per CLO, student perception, and x-th percentile marks, aggregated to SO and PEO levels via weighted averages.
