## Description
Adapting Cashman et al.'s four levels of interaction, the report categorizes Core to College network engagement into three primary kinds: "Information Sharing—providing information and/or raising awareness about the Common Core State Standards and aligned assessments"; "Feedback—gathering feedback and input from network members on key issues"; and "Collaboration—fostering collaboration between network members on activities such as course alignment, transition course development, teacher training, and/or developing definitions of college readiness." The typology structures the state network diagrams and cross-state analysis.
