# MMA-P: Modified Module Analysis using partial correlation matrix to include correct responses

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
MMA-P extends Modiﬁed Module Analysis by replacing the correlation matrix with the partial correlation matrix controlling for overall FCI test score, allowing correct and incorrect responses to be analyzed in the same network. The article explains that "the partial correlation matrix controls for overall test score," removing correlations due to overall performance. Community detection (fast-greedy CDA) with bootstrapping (1000 replications, C > 80%) identiﬁes response communities.
