# M3 evaluation framework (Micro, Meso, Macro) for mobile learning interventions

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The study adopts Vavoula and Sharples' (2011) M3 evaluation framework, which provides a "structured format to assess usability, educational and organisational impact and their inter-relationships". Micro-level evaluates individual user experience of the technology via end-activity evaluations; meso-level examines student experience via group and teacher interviews; macro-level evaluates effects on attitudes and performance via pre-post designs with experimental and control groups. The authors report it was "valuable for data validation and triangulation".
