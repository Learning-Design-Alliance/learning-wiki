# Confusion-matrix annotation by a domain expert as a rapid parser-refinement methodology

> **Research Method** · [All research methods](index.md)

## Description
A practical methodology for refining analytics tools with time-poor domain experts: the lecturer annotates AWA output pasted into Word using signal detection theory codes (True/False Positives/Negatives) in a 2×2 confusion matrix, with margin comments; the linguist responds in the shared document. The article describes this as "a rapid version of the more systematic coding that a qualitative data analyst would normally perform on a large corpus". The structured exchange builds a corpus from which precision, recall and F1 could in principle be calculated.
