# N-gram text mining with elastic net variable selection for gender-bias detection in narrative evaluations

> **Research Method** · [All research methods](index.md)

## Description
The article presents an analytic pipeline in which free-text evaluations are preprocessed (lowercased, punctuation and stop words removed, names replaced with placeholders), converted into unigrams and bigrams, and counted into a matrix of binary indicators. Elastic net regression selects variables, and mixed-effects logistic regression clustered on faculty tests each n-gram's association with gender using Benjamini-Hochberg false discovery rate control. The authors argue this "may provide a quantitative method to identify subtle linguistic differences in narrative evaluation that may not be captured by qualitative coding and thematic analysis."
