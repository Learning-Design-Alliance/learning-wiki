# Target trial emulation framework for causal analysis of observational learning data

## Description
The target trial framework requires researchers "to explicitly state the hypothetical trial they want to emulate with an observational study, specifying eligibility criteria, treatment strategies, follow-up period, and a time-zero". It prevents pitfalls such as using post-treatment information for assignment or estimating non-causal contrasts such as always-takers versus never-takers. The article applies it to emulate a pretest–posttest control group design, estimating the intention-to-treat ('as-started') effect of ADHD medication initiation on national test scores.
