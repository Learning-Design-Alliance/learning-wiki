## Description
This framework holds that evaluating remedial interventions solely by group-level improvement can obscure subgroup effects, so outcomes should be examined "at both the group and individual (or ''person-oriented'') level". The special issue's five papers apply this by comparing persisters with dropouts and gainers with non-gainers, using methods such as WIGROT, latent change scores, and multiple change metrics. The editorial argues this reveals which instructional approaches benefit which learners.

- **Group-plus-individual (person-oriented) analysis of intervention outcomes**: This framework holds that evaluating remedial interventions solely by group-level improvement can obscure subgroup effects, so outcomes should be examined "at both the group and individual (or ''person-oriented'') level". The special issue's five papers apply this by comparing persisters with dropouts and gainers with non-gainers, using methods such as WIGROT, latent change scores, and multiple change metrics. The editorial argues this reveals which instructional approaches benefit which learners. (Mary Beth Calhoon et al. (2013))
- **Two-step person-centered approach: latent profile analysis of learner characteristics followed by BCH-based modeling of profile-by-intervention interactions**: The article proposes moving "the focus of analysis from the interactions of single variables to entire persons and their characteristic constellation of learning prerequisites". In step one, learners are grouped by latent profile analysis, chosen because it is "a model-based clustering approach" allowing measurement-error-corrected estimates. In step two, profiles are related to instructional parameters via the manual BCH approach, which "enables relating latent profiles to any parameters that can be modeled in the framework of structural equation modeling". Grouping many learners into few categories helps achieve high statistical power while capturing multivariate, potentially non-linear information. (Tetzlaff et al. (2023))
