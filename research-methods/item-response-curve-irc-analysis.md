# Item Response Curve (IRC) analysis

## Description
IRC analysis, following Morris et al. (2006, 2012), plots the percentage of students selecting each answer option at each total-score (ability) level, giving "a graph that displays, for test -takers at various points in the ability range of an assessment tool, the probability of the correct/incorrect item responses plotted to the item". It characterises both correct and wrong options, so distractor functioning is visible, and classifies items as efficient, moderately efficient, or inefficient by curve shape. The study applies it to all 30 FCI items in Uganda, using a logistic response function for goodness-of-fit of correct responses.
