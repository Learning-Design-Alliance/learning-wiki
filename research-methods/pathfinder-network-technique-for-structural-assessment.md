## Description
Pathfinder is a graph-theoretic distance technique that represents a proximity matrix in a graphical network structure (PFnet). It uses the distance measured by the minimum number of links connecting two nodes in a graph. The algorithm removes direct links if a shorter, indirect path connects both concepts. Pathfinder was adopted because it does not force a hierarchical structure on the data and identifies meaningful links between concepts.
