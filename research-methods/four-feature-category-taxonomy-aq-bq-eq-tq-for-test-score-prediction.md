# Four-feature-category taxonomy (AQ, BQ, EQ, TQ) for test-score prediction

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article organizes predictive features into four hypothesized categories driving test score: academic attributes (AQ), behavioral attributes (BQ), effort attributes (EQ) and test-taking attributes (TQ). AQ features include individualized BKT parameters such as learned state and guessing tendency plus deepFM-derived competency across 1,242 concepts reduced to 50 dimensions by random projections. TQ features summarize event-level question-answering behavior during tests, including first-look attempts and questions attempted too quickly or too slowly relative to ideal time. BQ features proxy traits such as carelessness and over-confidence (e.g. ratio of careless mistakes to all attempts), and EQ features quantify engagement effort between two tests based on time spent and navigation across platform environments.
