# CORDFU chart for two-dimensional collaboration documentation

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The Chronologically Ordered Dialogue & Features Used (CORDFU) chart is the development of the original annotated user log from the Ecolab evaluation for group use of multimedia. Its vertical axis records CD-ROM features above a bold horizontal line and categories of talk below it, while the horizontal axis records the amount of attention paid to a feature or dialogue category in text units of up to 24 characters. For each X recording a CD-ROM feature there is a O indicating the type of talk that occurred whilst this feature was in use.
