# Affine velocity trajectory-smoothness metric for surgical skill assessment

## Description
Affine velocity is a motion metric that takes both the geometry and the dynamics of a trajectory into account, building on the empirical two-thirds power law relating hand velocity to trajectory curvature, adapted for 3D tool motion. The article states that "Affine velocity was used instead of the velocity itself because it provides valuable information about the quality and smoothness of the trajectory." The parameters were tuned for laparoscopic skills by multivariate linear regression over 46 reference trajectories, yielding α = −0.048 and β = −0.0026, and the metric is proposed as an objective expertise-discrimination variable complementing time and collision counts.
