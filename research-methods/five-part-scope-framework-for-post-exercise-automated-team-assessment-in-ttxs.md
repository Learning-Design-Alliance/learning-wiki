# Five-part scope framework for post-exercise automated team assessment in TTXs

> **Research Method** · [All research methods](index.md)

## Description
The article defines its assessment scope through five grounded characteristics: assessment targets teams rather than individuals, since a team is the fundamental unit and succeeds only when members collectively resolve tasks; it is summative, using milestones as predefined checkpoints that serve as indicators of the learning objectives the team has met; it is exercise-specific, relying only on data collected during the TTX to protect privacy; it is post-exercise, delivering instant results within minutes; and it is fully automated, with manual assessment used only as an evaluation benchmark. This framework organizes the study's two methods and their educational purposes, including grading, hot-wash debriefing, and feedback on deviations from expected procedures.
