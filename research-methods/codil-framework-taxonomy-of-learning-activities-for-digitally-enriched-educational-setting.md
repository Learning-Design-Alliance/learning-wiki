## Description
The CoDiL framework enumerates learning activities that digital instructional features may initiate and stimulate, each with an external behavioral side (observable student-tool interactions) and an internal cognitive side. The article lists abstraction, conducting experiments, creating examples, exploration, formulating hypothesis, refinement, revision, and self-explanation, each defined with cited literature. These activities function as a link between external behavior and internal cognitive processes and are understood as theoretical predictors of learning outcomes. The authors state that "students' engagement in these learning activities as necessity for successful learning—in line with the ULO framework and generative learning theory."
