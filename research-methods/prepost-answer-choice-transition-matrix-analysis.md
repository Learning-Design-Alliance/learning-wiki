# Pre/post answer-choice transition-matrix analysis

> **Research Method** · [All research methods](index.md)

## Description
A transition matrix tabulates, for one assessment item, the percentage of students selecting each pre-test answer choice (rows) crossed with each post-test answer choice (columns), with rows and columns ordered from worst incorrect answer to the correct answer. The article explains that "Transition matrices can be thought of as an adaptation of a two-observation/one-link Markov chain, where the sum of the all of the elements in the matrix is 100%". Above-diagonal entries show movement to better answers, below-diagonal entries movement to worse answers, and diagonal entries no change.

<!-- How each source describes or uses the method -->
- **Transition matrices: an adapted two-observation/one-link Markov chain representation of pre-/post answer-choice change**: A transition matrix tabulates, for one assessment item, the percentage of students selecting each pre-test answer choice (rows) crossed with each post-test answer choice (columns), with rows and columns ordered from worst incorrect answer to the correct answer. The article explains that "Transition matrices can be thought of as an adaptation of a two-observation/one-link Markov chain, where the sum of the all of the elements in the matrix is 100%". Above-diagonal entries show movement to better answers, below-diagonal entries movement to worse answers, and diagonal entries no change. (Gary A. Morris et al. (2017))
- **Transition matrix analysis: a resources-framework method connecting pretest and posttest state vectors of cognitive resource activation**: Transition matrix analysis (TMA) represents a student's probability distribution over w cognitive resources across m resources-equivalent questions as a state vector, inspired by the probabilistic view of student thinking of Bao and Redish. The article proposes that "these two vectors are connected by a transition matrix which allows researchers to see how students change the cognitive resources activation from pretest to posttest". Each matrix element Tij represents how a student changes the resources used from pretest to posttest, and class-level matrices are obtained by averaging individual students' matrices. The authors state it is more informative than comparing only initial and final state vectors. (Tianlong Zu et al. (2017))
