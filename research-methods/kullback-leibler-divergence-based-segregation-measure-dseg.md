# Kullback-Leibler divergence based segregation measure (Dseg)

> **Research Method** · [All research methods](index.md)

## Description
A network measure the article develops to quantify how student groups found by a grouping algorithm are structured according to an attribute such as gender, grade, or lab class. For each group, surprisal is computed as log2 of the ratio of the group's attribute distribution to the cohort distribution, and the weighted sum over groups gives the network segregation Dseg(M). Significance is assessed by resampling attribute values 10^4 times while keeping module structure, yielding Z-scores of deviation from random variation.
