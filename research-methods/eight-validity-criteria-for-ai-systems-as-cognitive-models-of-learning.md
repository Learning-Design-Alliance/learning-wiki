# Eight validity criteria for AI systems as cognitive models of learning

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The review's central contribution is an evaluative framework of eight criteria that an AI system must satisfy before its cognitive-model status is granted rather than assumed: theoretical grounding, construct validity, mechanistic transparency, alignment with human learning trajectories, error-signature matching, causal-intervention tests, ecological validity, and instructional usefulness. The framework shifts the question from whether AI can model cognition to when it should be allowed to count as one, treating the criteria as "a structured set of validity criteria that together determine when an AI system should be allowed to count as a cognitive model of learning".
