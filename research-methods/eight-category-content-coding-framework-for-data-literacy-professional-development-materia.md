# Eight-category content coding framework for data-literacy professional development materials

> **Research Method** · [All research methods](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The materials analysis produced a coding framework for the knowledge and skills addressed by professional development texts on data use. The paper reports that "The content focus categories of the framework were assigned eight superordinate codes: precursor conditions, inquiry process, assessment, data, data analysis, instructional planning, programmatic planning, and understanding research evidence." Each code carries subcodes; for example, the precursor conditions code includes school vision, connection to other initiatives, authority, understanding of the change process, collaboration, focus on equity, cultural proficiency, school culture, and characteristics of professional development. Texts were rated for relative emphasis on each concept using page-coverage values consolidated into high, medium, and low levels.
