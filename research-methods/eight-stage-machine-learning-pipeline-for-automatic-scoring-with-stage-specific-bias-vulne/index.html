Eight-stage machine-learning pipeline for automatic scoring with stage-specific bias vulnerabilities¶

Research Method · All research methods
Evidence · 1 claim (1 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

The article describes a machine-learning pipeline for automatic short-answer scoring comprising eight stages: data collection, scoring/labeling, preprocessing, feature engineering, model selection, data split, model training, and model evaluation. For each stage it names a characteristic bias vulnerability, e.g. unrepresentative samples create "representation bias", human labeling creates "annotation bias", and unstratified data splits can induce "sampling bias". It is used to explain where unfairness can enter automatic scoring systems before it surfaces at model evaluation.
