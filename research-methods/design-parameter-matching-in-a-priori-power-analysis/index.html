Design-parameter matching in a priori power analysis¶

Research Method · All research methods
Evidence · 1 claim (1 for) · 1 study (1 quant-synthesis), q3 · 0 of 1 report an effect size · 1 claim rests on one study

Description¶

This principle holds that a priori power analyses should strive for an ideal match between the selected design parameters and the planned study's characteristics: the clustering structure (single-, two-, or three-level), the target outcome domain, the assessment method, and the target age group. The article urges selecting "design parameters that offer the best match to the assumptions of how the data of the planned study will be clustered" and, given heterogeneity, using estimates from the same or a very similar target measure and age group.

Accounts¶

  • Match design parameters to the key characteristics of the planned intervention study when conducting a priori power analyses: This principle holds that a priori power analyses should strive for an ideal match between the selected design parameters and the planned study's characteristics: the clustering structure (single-, two-, or three-level), the target outcome domain, the assessment method, and the target age group. The article urges selecting "design parameters that offer the best match to the assumptions of how the data of the planned study will be clustered" and, given heterogeneity, using estimates from the same or a very similar target measure and age group. (Martin Brunner et al. (2025))
  • Treat optimal designs as locally optimal and apply a rule of thumb when the optimal number of students per class exceeds typical class size: The article cautions that "the optimal design is only 'locally optimal,' meaning that it is optimal only for the specific values that the researcher specified for the quantities and can be suboptimal for other values," suggesting maximin designs as a workaround. It also notes that power computations assume unbiased estimation, which holds in large samples but not small ones, and offers a practical rule: "set this number to 25 and then increase the number of classes to compensate for the loss of power" when the optimal students per class exceeds typical class size. (Steffen Zitzmann et al. (2021))
