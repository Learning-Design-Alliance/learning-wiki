# Theory-driven taxonomy of six motivation constructs for pedagogical agent research

## Description
The article organizes PA motivation research around four prominent theories — social cognitive theory, situated expectancy-value theory, interest theory, and self-determination theory — arguing that lumping motivation into one meta-construct is "theoretically unstable." From these theories it derives six discrete constructs: "self-efficacy expectancies (SCT, SEVT), subjective task values or task relevance (SEVT), utility value (SEVT), engagement (SEVT), interest (interest theory), and intrinsic motivation (SDT)," plus a broad "motivation" category for unspecified measures. The taxonomy structures the seven meta-analyses and is offered as categories future PA researchers can use for theory-driven measurement.

- **Six-category taxonomy of motivational constructs targeted by instructional design strategies**: The review organizes motivational constructs targeted by online design strategies into six a priori categories derived from prominent motivation theories and prior research. The authors state: "Our list included the following categories of motivational constructs: intrinsic value beliefs (eg, interest), extrinsic value beliefs (eg, instrumentality), competence and control beliefs (eg, self-efficacy), social connectedness (eg, relatedness), autonomy, and goals." Intrinsic value refers to value derived from completing an activity, whereas extrinsic value refers to value derived from outcomes external to the activity. This taxonomy served as the deductive coding scheme for the directed content analysis. (Lesselroth Blake; Papadakis Stamatis; Lo Chung; Gavarkovs Adam PhD; Miller Erin PhD; Coleman Jaimie MPT; Gunasegaran Tharsiga HBSc; Kusurkar Rashmi A MD (2025))
