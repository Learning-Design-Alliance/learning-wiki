# Combined quantitative–qualitative evaluation framework and metric set for AI-DSSs

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The review defines a balanced evaluation approach for AI-driven decision support systems combining technical metrics (accuracy, precision, recall, scalability, response time) with user-focused outcomes (user satisfaction via validated surveys drawing on the Technology Acceptance Model, and engagement measured through interaction frequency, task completion rates, or time-on-task). Quantitative methods include k-fold cross-validation and statistical comparisons via t-tests or ANOVA; qualitative methods include surveys, interviews, and case studies. The article concludes that "By combining these complementary approaches, evaluations achieve a balance of technical precision and practical relevance, ensuring AI-DSSs meet both performance and user needs."
