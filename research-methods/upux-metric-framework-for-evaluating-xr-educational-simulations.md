# UP/UX metric framework for evaluating XR educational simulations

## Description
The review defines user performance (UP) as "a set of metrics that quantifies the efficiency and effectiveness of a surgical simulation carried out on an XR system", including accuracy, precision, surgical outcome, speed, and attempts per user. User experience (UX) accounts for how subjects perceive events, interactions, and feedback, organized into ten categories: usefulness, self-assessment, haptic interaction, ease of use, system feedback, comfort, time requirements, engagement, immersiveness, and realism. The framework is used to group indicators across the 31 included studies and to detect which metrics are shared versus study-specific.
