# Eight-tag course feedback classification system

> **Research Method** · [All research methods](index.md)

## Description
A set of eight generalizable tags (course logistics and fit, curriculum, teaching modality, teaching, assessment, resources, peer and teacher interaction, other) developed by the authors for multi-label classification of open-ended course feedback. Each tag carries "A one to three sentence description of each tag" so humans or LLMs can apply it, and the same descriptions served as LLM prompt context. The set was reduced from 71 initial labels after low inter-rater agreement, then iteratively tested on sets of 100 responses.
