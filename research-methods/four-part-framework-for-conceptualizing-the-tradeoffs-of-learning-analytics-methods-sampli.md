# Four-part framework for conceptualizing the tradeoffs of learning analytics methods: sampling, capturing, reduction, and pattern finding

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article proposes a framework for thinking about what LA methods add to the learning sciences method space. It states: "We suggest here a simple four-part framework to help us conceptualize this new space of tradeoffs: (a) sampling, (b) capturing, (c) reduction, and (d) pattern ﬁnding." Each part is a stage at which any method trades breadth against depth: sampling concerns which learning phenomena are studied, capturing which aspects are recorded, reduction how captured data are transformed, and pattern finding how patterns are discovered and confirmed. LA reshapes each tradeoff rather than eliminating it.
