# Five-theme, sixteen-indicator framework for coding spatial skills in early childhood curricula

> **Research Method** · [All research methods](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
The study coded curricular documents with a deductive six-phase latent thematic analysis in which "Five themes with a total of sixteen indicators were identified based on previous literature." The framework organizes the curricular representation of spatial skills — abilities underpinning processing of shapes, locations, and inter-relations among entities and frames of reference — into themes whose indicator occurrences were compared across country-specific curricula. It serves as a reusable coding scheme for analyzing how curricula represent spatial skills.
