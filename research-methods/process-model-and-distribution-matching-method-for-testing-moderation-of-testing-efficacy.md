# Process-model and distribution-matching method for testing moderation of testing efficacy

## Description
When both restudy and test condition means shift in the same direction across levels of another factor, an ANOVA interaction on proportion correct is theoretically uninterpretable, because the mapping from latent memory strength to accuracy is non-linear and unknown. The article instead evaluates an empirically supported process model as a yardstick and applies a matching strategy via cumulative proportion-correct distributions. This revealed a real relatedness × testing-efficacy interaction that "a traditional ANOVA interaction" masked.
