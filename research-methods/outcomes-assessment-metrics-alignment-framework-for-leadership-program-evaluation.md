## Description
The article presents metrics, outcomes, and assessment as an interrelated system for leadership program evaluation: stated outcomes drive the assessment plan, and metrics execute that plan. The authors state that "Stated program outcomes ultimately drive the plan for assessment, and its metrics are the mechanism through which the assessment plan is successfully executed," with outcomes foreshadowing metrics and metrics mapped to the assessment plan.
