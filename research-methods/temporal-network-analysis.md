## Description
Temporal networks are a method that models both the relational aspects (who interacts with whom) and the temporal aspects (order, duration, concurrency) of collaborative learning. The article presents it as bringing the "best of both worlds" — combining network analysis's relational dimension with sequence methods' temporal dimension. Each node and edge carries timestamps marking start and end of activity; connections are temporary, only past interactions relate to future ones, and time-respecting paths replace static path length.
