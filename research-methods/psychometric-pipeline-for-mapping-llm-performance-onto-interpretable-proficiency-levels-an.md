# Psychometric pipeline for mapping LLM performance onto interpretable proficiency levels and subskill mastery

> **Research Method** · [All research methods](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 design), `q3` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
The article's organizing framework integrates educational measurement methods into LLM evaluation: "we estimate item difficulty using a two-parameter logistic (2PL) item response theory (IRT) model fitted to responses from 2,050 Chinese EFL learners", then conduct a Bookmark standard-setting study with trained experts to establish cut scores for CSE Levels 3–6, and finally perform cognitive diagnosis using an expert-defined Q-matrix with higher-order cognitive diagnosis models selected by fit (HO-GDINA won). This yields scale-referenced proficiency levels and subskill mastery probabilities rather than raw accuracy, enabling educationally meaningful interpretation of model ability.
