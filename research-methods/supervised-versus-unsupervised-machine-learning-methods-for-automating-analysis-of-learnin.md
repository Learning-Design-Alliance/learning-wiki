# Supervised versus unsupervised machine learning methods for automating analysis of learning data

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article introduces the machine learning distinction it uses to organize the special issue. "In supervised methods, we begin with a set of instances of data that have already been labeled (i.e., coded), usually by a human coder," producing a classifier that labels uncoded items, with data divided into training, testing, and optionally held-out corpora. "In contrast, unsupervised methods seek to discover structure in data that have not previously been labeled," typically via clustering that requires defining a similarity measure. Unsupervised methods add the burden of interpreting whether clusters are meaningful.
