# A four-type classification framework for prerequisite relation learning methods based on feature types and enhancement relationships

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The survey introduces a novel classification framework that organizes prerequisite relation learning methods along two axes: the nature of features (multi-source knowledge features for KCs vs. semantic knowledge features for LOs) and enhancement relationships (LOs-enhanced learning for KCs vs. KCs-enhanced learning for LOs). The article states it provides "a novel classification framework for prerequisite relation learning methods based on both feature types and enhancement relationships". Each of the four types is further divided into subcategories such as link-based, semantic, and behavioral features, or optimization-based, graph-based, and pre-trained model approaches.
