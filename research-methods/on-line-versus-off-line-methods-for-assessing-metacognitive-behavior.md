# On-line versus off-line methods for assessing metacognitive behavior

## Description
The article argues that metacognitive behavior cannot be adequately captured by retrospective self-report and should instead be measured on-line during task performance. Following prior reviews, it notes self-reports "did not measure components of metacognitive behavior adequately," and its own results showed the on-line judgment measure had the stronger effect on programming performance. The article therefore advocates embedding judgments into performance assessment as a practical on-line alternative to time-consuming think-aloud protocols.
