# Resource graph representation for visualizing coordination of semiotic and conceptual resources

## Description
A resource graph is an analytic representation in which "each circle represents either a semiotic or a conceptual resource" and links show how resources connect to produce compound representations at each stage of problem solving. The authors use it across three episodes to display how Larry brings in and combines more resources as the problem progresses, e.g. connecting current sheet with parallelogram as current sheet in the initial graph.
