# Evaluation frameworks for implementation endeavours

> **Research Method** · [All research methods](index.md)

## Description
The fifth category, evaluation frameworks, provides "a structure for evaluating implementation endeavours" by specifying aspects of implementation that could be evaluated to determine implementation success. Examples are RE-AIM (Reach, Effectiveness, Adoption, Implementation, Maintenance), PRECEDE-PROCEED, and Proctor et al.'s framework of eight implementation outcomes: acceptability, adoption, appropriateness, costs, feasibility, fidelity, penetration and sustainability. Approaches from the other four categories can also serve evaluation purposes because they specify concepts that may be operationalized and measured.
