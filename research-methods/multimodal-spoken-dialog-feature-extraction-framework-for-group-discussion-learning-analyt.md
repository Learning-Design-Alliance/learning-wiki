# Multimodal spoken-dialog feature extraction framework for group-discussion learning analytics

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article defines a feature extraction framework covering speech features (Speech Time, Number of Words, Number of Turns, Speaking Rate Score), semantic features (math terms, topic relevance score via word embeddings, cohesion score, LIWC sentiment and cognitive-processing categories), and acoustic features (F0, energy, formants, glottal features), all gender-normalized. Segment-level features are aggregated into "7 types of group-level features in 2 aspects" by taking sum/mean/variance across segments and students. The authors state the tools and customized techniques "could be generalized to other discussion dialogs."
