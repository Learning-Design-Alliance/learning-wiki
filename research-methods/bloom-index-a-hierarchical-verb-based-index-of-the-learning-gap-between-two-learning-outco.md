# Bloom Index: a hierarchical verb-based index of the learning gap between two learning outcomes

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The Bloom Index is a similarity measure the authors establish to "represent the learning gap between two learning outcomes according to the verbs in LOs". Action verbs are tagged with the Stanford POS tagger, each Bloom's hierarchy layer is assigned a numerical value from 1 to 6, and the absolute distance between verbs' layer values is converted into an absolute bloom index via the formula α×distance+β with α = -0.20 and β = 1; verb pairs in the same category receive maximum similarity 1, and pairwise indices are averaged over the total number of verb-pair comparisons to yield a Bloom Index between 0 and 1. In an illustrative example comparing two sentences, verb pairs with hierarchical distances of 1 and 3 yield absolute indices of 0.8 and 0.4, giving a Bloom's Index of (0.8+0.4)/2 = 0.6.
