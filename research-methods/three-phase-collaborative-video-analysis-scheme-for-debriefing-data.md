# Three-phase collaborative video analysis scheme for debriefing data

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The authors developed a model for collaborative analysis of video data adopting "a layered, purposeful constant comparative analysis as described by Boeije". Phase 1 compares multiple perspectives within a single recording to build shared understanding and formulate structural features (openings, interaction, closings); phase 2 compares recordings of the same scenario, producing transcripts and provisional relational interpretations; phase 3 compares recordings across scenarios, refining interpretations against wider data and identifying variation.
