# Elaborative style: an utterance-level coding framework for adult–child reminiscing

## Description
Elaborative style is a dimension of adults' language assessed in reminiscing research, classified on a continuum from high to low. High elaborative style uses open-ended questions, details and embellished descriptions producing co-constructed dialog with a strong narrative thread; coding proceeds "on an utterance-by-utterance basis followed by a quantitative assessment of the amount ofelaborationsand repetitionsa parent uses". Elaborations add new information; repetitions repeat the gist of a prior turn; evaluations confirm or negate and extend the child's utterance. The review proposes this framework as a transferable model for analyzing other adult–child conversations.
