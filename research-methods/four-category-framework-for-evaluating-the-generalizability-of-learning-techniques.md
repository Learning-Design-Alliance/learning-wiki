# Four-category framework for evaluating the generalizability of learning techniques

> **Research Method** · [All research methods](index.md)

## Description
The monograph organizes each technique review around four categories of variables, inspired by Jenkins' (1979) model: "materials, learning conditions, student characteristics, and criterion tasks." Materials pertain to the content to be learned; learning conditions concern how and where the technique is implemented (e.g., dosage, group vs. individual); student characteristics include age, ability, prior knowledge, and motivation; criterion tasks range from cued recall to problem solving and essay writing. Each of the 10 technique reviews assesses generalizability across these categories before assigning a utility rating.
