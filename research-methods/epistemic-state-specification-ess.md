# Epistemic State Specification (ESS)

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
ESS is a required system declaration stating what the simulated learner can access at a given moment, how errors are generated, and whether and how the state changes over time. The article operationalizes it as "a lightweight reporting label with five levels", from E0 (unspecified) through E1 static bounded, E2 curriculum-indexed, and E3 misconception-structured, to E4 calibrated or learned against human interaction data. It is intended to prevent overclaiming and enable cross-system comparison.
