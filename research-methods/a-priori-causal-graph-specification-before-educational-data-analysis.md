## Description
The paper argues that researchers should articulate their causal assumptions graphically before collecting or analyzing data, because "there are no causal conclusions without causal assumptions". Explicit assumptions make it possible to trace whether a proposed causal effect is identified given the assumed structure, and to detect confounding, overcontrol, and collider bias before they distort estimates.

(Weidlich et al. (2024))
- **Directed Acyclic Graphs as a framework for representing and testing causal assumptions in education research**: The article introduces graphical causal models, developed especially by Pearl and coworkers, as the framework it uses to audit PER papers. Graphs called Directed Acyclic Graphs "represent this one-way feature by using arrows to show the causal directions": changes in a variable affect only downstream variables, with no causal loops. A DAG encodes conditional independence relations, which interventions can have no effect on which variables, and guides which variables to control for. Bidirectional arrows in ADMGs are shorthand for an unmeasured common cause, not bidirectional causation. The author pairs DAGs with linear SEMs, whose coefficients along paths sum to net causal effects. (M. B. Weissman (2021))
