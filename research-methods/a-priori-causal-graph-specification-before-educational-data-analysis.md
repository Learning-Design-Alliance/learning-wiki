# A priori causal-graph specification before educational data analysis

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The paper argues that researchers should articulate their causal assumptions graphically before collecting or analyzing data, because "there are no causal conclusions without causal assumptions". Explicit assumptions make it possible to trace whether a proposed causal effect is identified given the assumed structure, and to detect confounding, overcontrol, and collider bias before they distort estimates.
