# Multi-level framework separating posting activity, communication structures, and emergent relational structures in online discussions

## Description
The framework holds that analysis of digital learner interactions should differentiate three overlapping processes: posting activity at the individual level, communication structures as learner-to-learner projections, and emergent relational structures as filtered backbones of communication networks. The article proposes that "posting activity gives rise to communication patterns and emergent relational structures," operationalizing the levels as interdependent so that statistical modeling of lower levels affords inference about higher ones. It supplies level-specific units of analysis, comparison methods, and example research questions (Table 1), demonstrated on twenty courses.
