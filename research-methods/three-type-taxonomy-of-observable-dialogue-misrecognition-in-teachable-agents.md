# Three-type taxonomy of observable dialogue misrecognition in teachable agents

## Description
The article defines dialogue misrecognition as "the situation where an agent responds differently to raw ASR inputs and “true” inputs", quantified as the proportion of turns where the simulated true response differs from the actual ASR-based response. It further categorizes misrecognition into three types: Prevented, where the student could not move to the next step; Different, where the agent suggested a different solution path; and Proceeded, where the agent went to the next step by accident. The measures simulate true responses by sending human transcriptions to the agent and compare them with actual responses.
