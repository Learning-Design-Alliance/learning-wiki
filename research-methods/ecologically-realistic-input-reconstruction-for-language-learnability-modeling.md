## Description
The article argues that for language learnability, unlike most scientific problems, simplification of the input is not acceptable, because "learning is a process whose outcome is exquisitely sensitive to details of the input signal". Slightly incorrect assumptions about input mean studying a different learning problem altogether. The advocated solution is to reconstruct infants' sensory experience from actual raw, large-scale ecological recordings, confronting data selection directly.
