# Model-comparison approach for linear vs non-linear mental-effort relations (Models 0–4)

## Description
A reusable analytic procedure the article introduces: five competing two-level mixed-effects models (random participant intercepts) ordered by complexity — no relation, linear, quadratic, cubic, and more complex than cubic (mental effort as factor) — compared on marginal R2, AIC and BIC. Model 4 sets "the maximum possible R2M for a set of fixed effects", letting researchers quantify what is lost by simplifying. The authors state "the approach we have provided is applicable to any study that involves sufficiently large samples and/or includes multiple measurements from the same participants".
