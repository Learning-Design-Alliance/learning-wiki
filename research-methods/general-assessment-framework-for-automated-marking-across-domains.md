# General Assessment Framework for Automated Marking Across Domains

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The authors specify a general framework for the assessment process consisting of four stages: (1) specify similarity between student answer and correct answer, (2) categorize student answer according to the answer categorization scheme, (3) check for important errors, and (4) calculate the mark via the automated marker. The framework can be used in different domains by proper instantiations of three elements: similarity metric, answer categorization scheme, and automated marking algorithm. As implemented in AITS, it could easily be used for domains where answers are strings or could be transformed into strings.
