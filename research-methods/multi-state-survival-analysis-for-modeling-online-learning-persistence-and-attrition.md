## Description
The article applies a Multi-State Survival Model to online learning data, defining three quitting states: the student is playing (persisting), quits an exercise prematurely but stays in the environment (soft-quit), or exits the environment entirely (hard-quit). Hard-quitting is treated as an absorbing state. The model estimates transition intensities between states over continuous time and allows covariates to modify them via hazard ratios. It fulfills the Markov property, so transitions depend only on the current state and time.
