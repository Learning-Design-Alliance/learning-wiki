# Adapted S.P.A.R.K. model for coding peer feedback quality

> **Research Method** · [All research methods](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The S.P.A.R.K. mnemonic, from Gardner (2019), presents five recommended traits of feedback: "it should be Specific, Prescriptive, Actionable, Referenced, Kind." Because the original points were memorization suggestions rather than a coding scheme, the authors adapted the definitions — revising the overlapping "prescriptive" and "actionable" criteria for a tighter distinction — and used the adapted scheme in NVIVO to code sampled comments. Double coding of 30% of comments per group yielded a Cohen's Kappa of 0.83 with 95.2% inter-rater agreement.
