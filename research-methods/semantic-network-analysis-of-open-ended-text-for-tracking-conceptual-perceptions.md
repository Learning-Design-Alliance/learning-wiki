# Semantic network analysis of open-ended text for tracking conceptual perceptions

## Description
Semantic network analysis represents text as a network in which "the words that constitute text as nodes and the co-occurrences of pair of word as links"; it rests on the assumption that perceptions are constructed from links among fragmented concepts and are represented in word connections. The study applied it via pre-processing (KrKwic morpheme segmentation, selecting the 30 most frequent words, excluding 'patient' and 'doctor'), network matrix construction, and analysis with visualization using degree centrality, betweenness centrality, and sub-community identification, yielding quantitative topological indexes of perception change.
