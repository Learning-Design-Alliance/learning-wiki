# Four-way classification of regulative activity: self-regulation, mirroring, formative assessment, coaching

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article classifies regulative approaches by how much of the loop the system executes. If students execute the whole loop themselves, the activity is self-regulation; if the system monitors performance and presents it back, mirroring; if it also compares to a gold standard and reports the comparison, formative assessment; if it additionally generates advice or modifies the task or context, coaching. Coaching is "just what an intelligent tutoring system typically does."
