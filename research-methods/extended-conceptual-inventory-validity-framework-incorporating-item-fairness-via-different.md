# Extended conceptual-inventory validity framework incorporating item fairness via Differential Item Functioning

## Description
The article adopts the Jorion et al. framework for validating conceptual inventories, which "collects some standard methods of item analysis used in Classical Test Theory (CTT) and Item Response Theory (IRT)". The authors extend it because the original "does not evaluate item fairness, a critical oversight" for instruments used where some populations are underrepresented. The extension adds item-fairness analysis using Diﬀerential Item Functioning, combining CTT difficulty and discrimination thresholds, 2PL IRT parameters, Cronbach's alpha, and the Mantel-Haenszel and Lord DIF statistics on the ETS Delta scale.
