# ASIMeC analysis scheme for coding message characteristics and role adoption

> **Research Method** · [All research methods](index.md)

## Description
ASIMeC is a content analysis scheme developed by the authors to identify message characteristics along five dimensions: moderating, summarising, adding new discussion points, adding theory, and adding external information. Unlike the Gunawardena et al. (1997) interaction analysis model, it "is specifically related to the different roles", and was developed "to provide more information about the actual role adoption in the discussion groups". Each unit of analysis (the complete message) receives a code along each dimension, with ordered categories such as mentioning versus actively discussing theory or sources. Krippendorff's alpha reliabilities ranged from 0.59 to 0.75 across dimensions.
