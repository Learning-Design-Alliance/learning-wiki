# Closely spaced longitudinal assessment for detecting U-shaped conceptual development

## Description
Because apparent regression during learning escapes detection under conventional pre/post or widely spaced assessment designs, assessments intended to reveal conceptual development should measure the same concept set at closely spaced intervals across an extended instructional period. The article states that "U-shaped development usually reveals itself only in situations where closely spaced observations are being conducted over an extended period of instructional time centered on the same set of concepts". This is offered as an implication for research practice, since widely spaced observations may miss the rapid changes characteristic of the effect.
