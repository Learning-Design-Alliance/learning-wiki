## Description
Network meta-analysis (NMA) is presented as "a new type of meta-analysis, which can compare the effectiveness of multiple interventions more intuitively and in detail, while traditional meta-analysis can only compare them in pairs". The article applies it with Stata 16.0's mvmeta package, using SMDs for continuous outcomes and ORs for binary outcomes, SUCRA curves to rank treatments probabilistically, node-splitting for inconsistency, and a league table for pairwise comparisons. It integrates direct and indirect evidence across 13 interventions.
