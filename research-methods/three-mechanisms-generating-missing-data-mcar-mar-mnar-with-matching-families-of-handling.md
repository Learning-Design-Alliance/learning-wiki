# Three mechanisms generating missing data (MCAR, MAR, MNAR) with matching families of handling techniques

## Description
The article presents a taxonomy of three mechanisms by which missing data arise in longitudinal research. MCAR holds when "the cases for which the data are missing can be thought of as a random sample of all the cases"; MAR ties missingness to observed study variables; MNAR ties it to unobserved values such as change over time. Each mechanism maps to techniques: listwise deletion for MCAR; maximum likelihood, multiple imputation and their auxiliary-variable variants for MAR; and pattern mixture and selection models for MNAR. The tutorial uses this framework to organise its sensitivity analysis of learning-strategy growth.
