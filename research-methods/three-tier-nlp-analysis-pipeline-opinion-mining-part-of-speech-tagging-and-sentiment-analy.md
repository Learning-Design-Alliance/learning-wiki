# Three-tier NLP analysis pipeline: opinion mining, part-of-speech tagging, and sentiment analysis

> **Research Method** · [All research methods](index.md)

## Description
To analyze how integrating NLP into an ALT could provide just-in-time SRL support, the authors "employed a three-tier approach, namely using opinion mining, POS, and sentiment analysis." Opinion mining compares learner lexicons against reference lexicons built from SRL components of the MSLQ and LASSI using cosine similarity (0 to 1); POS tagging assigns syntactic tags to contextualize word pairs; sentiment analysis uses the DE-LIWC2015 dictionaries covering positive and negative emotions. The approach is explicitly informed by qualitative interview data from the co-design process.
