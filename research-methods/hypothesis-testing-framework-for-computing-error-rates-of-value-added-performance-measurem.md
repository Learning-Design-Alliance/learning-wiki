## Description
The report frames teacher and school performance measurement as a hypothesis-testing problem, in which a decision (for example, whether an educator's performance differs from the average) can be a true positive, false positive, true negative, or false negative. "Using realistic performance measurement system schemes based on hypothesis testing, we develop error rate formulas based on OLS and Empirical Bayes estimators," allowing error rates to be computed as a function of data quantity and estimator choice.
