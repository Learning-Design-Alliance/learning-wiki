# Machine-learned moment-of-learning prediction from tutoring-system transaction logs

> **Research Method** · [All research methods](index.md)

## Description
Two non-identical feature sets distilled from prior detectors of off-task behavior and gaming the system were used to predict P(J). The Cognitive Tutor used "23 features previously distilled to use in the development of contextual models of guessing and slipping", and ASSISTments used "a similar but non-identical list of 22 features", differing primarily due to the systems' different features and problem organization. Feature categories include correctness assessments, time measurements, hint usage, scaffolding usage (ASSISTments only), and other measurements such as whether the response was selected from a list or filled in, plus P(Ln-1) and P(Ln).
