# DeFT framework for multiple external representations (Designs, Functions, Tasks)

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The Designs, Functions, Tasks (DeFT) framework is a theoretical framework for combining multiple external representations (MERs), consisting of three layers. The Function layer describes three roles MERs can play: "Firstly, to complement, which means to provide various perspectives and information on the same concept", secondly to constrain interpretation by specifying ambiguous information, and thirdly to construct deeper understanding. The Design layer covers number, form, sequence and translation of representations; the Task layer covers the cognitive tasks learners must overcome, analysed via Cognitive Load Theory. The article applies DeFT to quantum teleportation across descriptive, symbolic and graphical representations in each targeted skill area.
