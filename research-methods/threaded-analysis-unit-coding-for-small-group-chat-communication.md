## Description
A design principle for chat communication analysis methodology: coding procedures for small group chat should build in threading, i.e. "connections between analysis units", because the article found threading "proved essential to handle unit fragmentation, to reconstruct the response structure and for reliability of coding". Without threading, unit fragmentation and an unreconstructable response structure undermine both the analysis and the trustworthiness of reliability figures.
