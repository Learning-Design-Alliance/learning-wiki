# Interaction states: a three-level framework enriching pass-fail events with where, when, and how contextual information

> **Research Method** · [All research methods](index.md)
> **Evidence** · 3 claims (2 for, 1 mixed) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The framework defines an "interaction state" as the combination of a pass-fail event and its contextual information, built in three nested levels: Level I (3 states: Pass, Fail, Abort by module), Level II (6 states adding whether the event occurred before or after studying the instructional component), and Level III (9 states adding whether attempts were Brief or Normal by duration). Each level maps to one of Gašević's contextual conditions: the article states "the “where” reflects the instructional condition", "the “when” reflects students’ internal state", and "the “how” serves as one indication of the strategy". The framework grounds linear regression models and parallel coordinate visualizations of student behavior.

- **Include detailed contextual information for each learning event to improve learning analytics accuracy and actionability**: This principle holds that learning analytics can be improved by enriching each learning event with contextual information (module location, timing relative to instruction, attempt duration, learning strategy) rather than only counting events or employing more complex algorithms. The article states that "including detailed contextual information for each event analyzed can in some cases also be an effective approach for improving not only the accuracy of data analysis models, but more importantly in improving the ability to provide actionable and targeted instructional suggestions for instructors." In the study, each added contextual level produced models with higher adjusted R² and more interpretable behavioral descriptions. (Chen et al. (2021))
