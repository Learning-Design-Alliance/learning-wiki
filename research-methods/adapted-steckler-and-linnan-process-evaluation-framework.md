# Adapted Steckler and Linnan process evaluation framework

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article adapts a process evaluation framework proposed by Steckler and Linnan to structure its mixed-methods evaluation of the training. The framework organises findings into labelled categories: Context (geographical and mortality description), Reach (the trainee pool), Dose delivered (session delivery and attendance), Dose received (participation and perceptions of learning), and Early and Later implementation (use of learning in clinical work and cascading). Each framework item is mapped to a data source and an analysis approach in the article's table 1, with qualitative thematic analysis as the predominant method.
