# TETRAD-based causal inference pipeline with GFCI and PC algorithms and sparse multiple CCA composites

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
Causal discovery and inference are performed in the TETRAD software suite, adopting "two algorithms: Greedy Fast Causal Inference (GFCI) and PC algorithm." GFCI analyzes continuous login variables and can represent hidden confounders, while PC handles categorical demographics but cannot show confounding relations. Sparse multiple CCA first compresses each feature group into one composite variable so the causal analysis stays interpretable.
