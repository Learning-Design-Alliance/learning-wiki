## Description
A three-pronged coding framework grounded in social semiotics for systematically characterizing any curricular material. "Our curriculum characterization framework is designed to meaningfully code the information contained in the multiple-choice questions using a three-pronged approach": the types and number of modes of representation used, the types and number of intellectual tasks the learner engages in, and the robustness of discourse via a modified Question Complexity Rubric (QCR codes 1–4). It comprises coding schemata for modes (Table I) and tasks (Table II) plus the QCR, finalized iteratively with calibration questions and trained coders.
