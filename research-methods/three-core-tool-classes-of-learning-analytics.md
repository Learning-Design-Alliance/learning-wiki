# Three core tool classes of learning analytics

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article describes a core set of tools that LA contributes to learning research. "Tools for data capture and archiving" extract attributes of student behavior for later analysis, from stored text to real-time speech transcription, facial expression recognition, and eye-gaze tracking. "Tools for data analysis" apply specialized algorithms for search, retrieval, and pattern discovery to very large datasets. "Tools for data representation and use" make discovered patterns useful to researchers, teachers, and learners through new representations and responsive learning technologies.
