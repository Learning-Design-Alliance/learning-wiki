# Case-level evaluation framework: case pass rate and consistency gap

## Description
The article proposes a multidimensional metric framework that goes beyond simple per-question accuracy. The case pass rate (CPR) defines success only when the model answers all subquestions associated with a case correctly, treating partial correctness as failure. The consistency gap, the arithmetic difference between QPR and CPR, quantifies performance degradation from question-level to case-level aggregation. The authors argue this shift "provides a more stringent and clinically meaningful benchmark, thereby revealing limitations of current LLMs that are masked by high accuracy scores in traditional assessments."
