# McGaghie's five-level simulation-based translational outcomes framework

> **Research Method** · [All research methods](index.md)

## Description
The review applies McGaghie's proposed levels of simulation-based translational outcomes, adapted to direct ophthalmoscopy, as an effectiveness assessment framework. Levels range from "Internal acceptability" (trainee satisfaction with simulator, Level 1) through "Contained effects" (changes in performance using the simulator, Level 2), "Downstream effects" (changes in clinical behaviour, Level 3), "Target effects" (changes in patient outcomes, Level 4) and "Collateral effects" (hospital-wide or systems-level changes, Level 5). The review uses this scale alongside the Kirkpatrick Model and a Messick-based validity scale to rate each included study.
