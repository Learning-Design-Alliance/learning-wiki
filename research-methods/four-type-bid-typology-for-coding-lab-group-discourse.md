## Description
The article's Table 1 defines four kinds of bids used in the analysis: a prompt is "A question or statement that directs the flow of discourse", a command directs lab partners' behavior, a suggestion is "An idea or plan put forward for consideration", and an opinion is "A thought or judgment about the investigation". Acknowledgments include verbal responses and gestures such as nodding or following through; non-acknowledgments include lack of response and dismissals.
