# Positional analysis via CONCOR

## Description
Positional analysis divides a network into blocks of actors with similar connection patterns, using structural equivalence as the similarity measure. The CONCOR algorithm iterates Pearson correlations on the sociomatrix until entries converge to +1 or -1, yielding blockmodels, image matrices, and reduced networks. The authors introduce it to physics education research as "a kind of mid-scale description of group social structure", sitting between whole-network statistics and node-level centrality: if centrality asks "who has the most power?", positional analysis asks "what is the terrain?".
