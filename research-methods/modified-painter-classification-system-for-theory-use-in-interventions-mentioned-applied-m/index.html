Modified Painter classification system for theory use in interventions (mentioned, applied, measured)¶

Research Method · All research methods
Evidence · 3 claims (3 for) · 1 study (1 review), q3 · 0 of 1 report an effect size · 3 claims rest on one study

Description¶

The review applies a modified version of Painter et al.'s classification system to categorize how each CBI uses theory. A CBI is classified as "mentioned" if an established broad theory is named, "applied" if any associated article describes how the theory informed the intervention, and "measured" if any article includes at least one measure of a construct within the theoretical framework. The authors state the classification system "offers a guiding framework for reporting how theory based principles can be applied to computer based interventions".
