# Ordered network analysis (ONA)

## Description
Ordered network analysis extends epistemic network analysis by incorporating temporal ordering into network construction, "allowing edges to represent ordered transitions between codes rather than unordered co-occurrence." The article applies ONA to retrospective cued-recall affect reports from a short situated CPS task, using a moving window of 2 events, groups as units of analysis, and difference networks to compare conditions. This makes ONA suited to modeling affect dynamics where the sequence of states is as informative as their co-presence, even in small datasets where descriptive summaries treat states as independent.

- **Ordered network analysis (ONA) as a method for modeling directional temporal transitions among affective states in small, temporally coarse educational datasets**: Ordered network analysis extends epistemic network analysis by incorporating temporal ordering into network construction, "allowing edges to represent ordered transitions between codes rather than unordered co-occurrence." This makes ONA suited to modeling affect dynamics where the sequence of states is as informative as their co-presence, even in small datasets where descriptive summaries treat states as independent. (Sifatul Anindho et al. (2026))
- **Ordered network analysis (ONA) as a method for modeling team communication sequences as dynamic networks**: ONA is a network-modeling methodology that takes coded interaction data as input and models sequences of coded behaviors as networks. The article states that "ONA models sequences of coded behaviors as networks, quantitatively identifying the frequency of speech acts, order, and temporal connections between them." Using a moving stanza window and singular value decomposition, it represents each team's communication pattern as a point in a metric space, enabling statistical and visual comparison of networks between groups (e.g., high- vs low-performing teams). In this study ONA was applied to TuRBO-coded simulation dialogue with a 4-line moving stanza window. (Popov V (2025))
