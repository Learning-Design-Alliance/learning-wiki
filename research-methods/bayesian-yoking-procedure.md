# Bayesian Yoking Procedure

## Description
A novel methodological approach in which each yoked participant observes the responses of an "ideal Bayesian learner" personalized to have that participant's individual prior beliefs. It proceeds in three steps: (1) creating profiles of children's prior belief distributions from pretest data using a hypothesis space of four competing theories (size, material, mass, random guessing) and k-means clustering into six profiles, (2) performing trial-by-trial Bayesian posterior updating for each prototypical profile across the 34 learning trials, and (3) assigning new learners to the best-fitting profile via lowest Wasserstein distance, so yoked children see the responses they would most likely have generated themselves.
