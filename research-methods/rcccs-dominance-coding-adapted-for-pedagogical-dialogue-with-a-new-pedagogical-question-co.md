# RCCCS dominance coding adapted for pedagogical dialogue with a new pedagogical-question code

## Description
The article applies Rogers and Farace's Relational Communication Control Coding Scheme, a three-level dyadic coding scheme in which turns receive numeric codes by message format and response mode, then control codes (one-up, one-down, one-across), then transaction agreement codes (complementary, symmetrical, transitory). Because the scheme "was not developed to specifically cover pedagogical dialogue", the authors "created a special code for pedagogical questions, which translates to a 'one-up' code", used only for students in the tutor role. This adaptation lets dominance be measured in learning conversations with a teachable agent.
