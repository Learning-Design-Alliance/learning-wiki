# CFFD chart for multi-dimensional collaboration documentation

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The CFFD chart provides a Chronologically ordered record of Features in use, Focus of interactivity and Dialogue, extending CORDFU to four dimensions of collaboration: software features and on-screen dialogue, dialogue between children or researcher and children, children's use of toy features and dialogue with the toy, and interactions between toy and software. Each horizontal line shows one of the categories of speech and action performed by the researcher, the children, the toy and the software, and the links between the horizontal lines indicate the interactions between the participants along these dimensions.
