## Description
The article applies cumulative sum (CUSUM) methods as a quantitative framework for defining surgical proficiency. For a binary outcome, CUSUM(i) = CUSUM(i − 1) + [X(i) – p0], where the curve peak "identifies the proficiency point, i.e. the case after which performance was consistently better than the cohort average"; for operative time the trough marks the inflection. The authors offer this as "a reproducible framework for benchmarking THD proficiency" and a pragmatic reference point for training, credentialing, and audit.
