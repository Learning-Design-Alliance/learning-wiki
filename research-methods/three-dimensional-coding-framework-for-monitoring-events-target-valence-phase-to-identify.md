# Three-dimensional coding framework for monitoring events (target, valence, phase) to identify adaptive regulation and maladaptive behavior in collaborative learning

> **Research Method** · [All research methods](index.md)

## Description
The study contributes an empirical framework, built on the socially shared regulation of learning (SSRL) framework, for identifying adaptive regulation and maladaptive behavior from process data. Monitoring events are coded on "target (cognition, motivation, emotion, behavior), valence (positive or negative), and phase in which monitoring occurs (task definition, goals and planning, task enactment, or reflection)". Combining valence with the group's reaction or lack of reaction defines on-track, adaptive, and maladaptive sequences: negative-valence monitoring followed by a reaction is adaptive, and without a reaction is maladaptive.
