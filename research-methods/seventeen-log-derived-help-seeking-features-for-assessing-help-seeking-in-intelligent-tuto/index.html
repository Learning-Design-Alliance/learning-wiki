Seventeen log-derived help-seeking features for assessing help seeking in intelligent tutors¶

Research Method · All research methods
Evidence · 2 claims (2 for) · 1 study (1 associational), q2 · 0 of 1 report an effect size · 2 claims rest on one study

Description¶

A set of 17 behavioral features distilled from tutor log files and normalized as a percentage of total student actions, designed to "encompass a wide array of possible help-seeking behaviors". Features include help avoidance (NHP), help abuse (HPQ), self-explanation pauses after help use (HPL), help non-use on well-known skills (NHW), pauses before and after hints and bug messages, and first-encounter hint requests, each labeled with a predicted positive, negative, or ambiguous relationship to help seeking.
