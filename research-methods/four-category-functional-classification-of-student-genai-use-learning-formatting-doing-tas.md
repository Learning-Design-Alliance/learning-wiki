# Four-category functional classification of student GenAI use (Learning, Formatting, Doing Task, Feedback)

> **Research Method** · [All research methods](index.md)
> **Evidence** · 1 claim (1 for) · 1 study (1 qualitative), `q2` · 0 of 1 report an effect size · 1 claim rests on one study

## Description
A descriptive coding framework developed inductively from students' mandatory GenAI-use declarations in the physics unit, classifying the "clearly stated pedagogical function of each reported GenAI use" into four themes: Learning (researching, understanding, conceptualising, refining understanding), Formatting (structure, organisation, admin tasks), Doing Task (calculations), and Feedback (clarification, feedback, verification, checking results). Each category was mapped to SAMR levels: Learning to Substitution→Augmentation, Formatting to Substitution, Doing Task to Modification→Redefinition, and Feedback across all levels. Frequencies per assessment provided the primary evidence for evaluating student GenAI use.
