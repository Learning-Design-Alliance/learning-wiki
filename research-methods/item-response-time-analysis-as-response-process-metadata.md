# Item response time analysis as response-process metadata

> **Research Method** · [All research methods](index.md)
> **Evidence** · 5 claims (5 for) · 2 studies (2 associational), `q2` · 1 of 2 report an effect size · 5 claims rest on one study

## Description
The article treats item response time as one common type of test metadata generated by computer-based assessment. Such metadata relate to "examinees' response processes, which include solution strategies, concentration, and operating speed." Response times have been used extensively to improve achievement estimates, but the article extends this metadata concept to social-emotional constructs, using time-on-item after accounting for item difficulty and true achievement as an indicator of motivation and self-efficacy.

- **Normalized item response time (τ) based on the lognormal distribution of response times**: The article defines normalized item response time as a relative, per-item-standardized measure: for each item, log RT is approximately normally distributed, and τkl is the item-level z-score of a student's log response time. Students with "normalized item response time greater than zero" responded slower than average on that item. This normalization "enables us to represent RT for all items on a common scale and explore more subtle effects influencing item response time", such as the position-dependent warm-up effect.
