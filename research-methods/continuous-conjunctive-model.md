# Continuous Conjunctive Model

> **Research Method** · [All research methods](index.md)

## Description
The CCM is an extension of the NIDA cognitive diagnostic model that "utilizes continuous variables instead of binary latent variables to represent attributes, thus it offers a more generalized diagnosis" (Hong et al., 2015). Because it assumes conjunctive relations among latent attributes, learners must apply all required attributes to answer an item correctly. It involves no item-level parameters, so a learner's attribute profile can be estimated even when the number of skills is large, making it suited to DGBL where items are randomly generated. This study applied it to fit The Nomads game log data, estimating skill profiles for the first and second halves of gameplay.

## Description
The CCM is an extension of the NIDA cognitive diagnostic model that "utilizes continuous variables instead of binary latent variables to represent attributes, thus it offers a more generalized diagnosis" (Hong et al., 2015). Because it assumes conjunctive relations among latent attributes, learners must apply all required attributes to answer an item correctly. ## Design Implications

### Context
#### Requirements
- A Q-matrix specifying which attributes each game task requires, determined by subject experts
- Randomly generated items with no item-level parameters, so items sharing attribute patterns share psychometric properties
#### Constraints
- The CCM assumes learners cannot answer an item correctly by guessing; this study adopted a revised CCM with a guessing parameter for tasks 7 and 9 to accommodate this

### Target Learners
- Fourth to sixth graders learning rational number arithmetic

### Target Learning Objectives
- Adaptive expertise in rational number arithmetic
- Fine-grained diagnosis of five math attributes (operations, flexibility/adaptivity, nice numbers, algebraic thinking, ratio and area/volume reasoning)
