# Five-feature framework for assessing the quality of verbal collaborative argumentation

## Description
Drawing on Chinn and Anderson's (1998) argumentation framework, the researchers assessed quality via argumentation diagrams whose core units are claim, datum, and warrant. They "identified the quality of the collaborative argumentation based on a number of features: size, breadth, depth, types of rhetorical moves, and co-construction of argumentation." Each feature has quantitative measures: size as node count, breadth as positions and lines of argumentation, depth as argumentations with five or fewer nodes, rhetorical moves as reasons, evidence, counterarguments, and rebuttals, and co-construction as argumentations built by two or more students.
