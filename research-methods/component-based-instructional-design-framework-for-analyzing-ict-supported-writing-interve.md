# Component-based instructional design framework for analyzing ICT-supported writing interventions

> **Research Method** · [All research methods](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 quant-synthesis), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The article adopts a component-based instructional design perspective, coding each intervention on four design aspects: Merrill's instructional principles (problem centered, activation, demonstration, application, integration), the instructional activities that operationalize them, the types of feedback, and the types of scaffolding. Each element is additionally coded by delivery agent (teacher, ICT, or both). The article argues that "analyzing ICT-supported writing interventions at a fine-grained, componential level provides clearer insight into how instructional design shapes learning outcomes" than aggregating interventions as a single category.
