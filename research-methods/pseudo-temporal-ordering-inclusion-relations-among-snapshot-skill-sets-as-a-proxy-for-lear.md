# Pseudo-temporal ordering: inclusion relations among snapshot skill sets as a proxy for learning progression

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article proposes a framework in which, absent temporal logs, set-inclusion relations among learners' mastered-skill sets induce a pseudo-temporal axis: a learner whose mastered-skill set is a superset of another's can be viewed as a plausible later state. Learning is modeled as accumulation of expected one-skill increments, so that "a learner's mastered-skill set expands monotonically over time" under a non-forgetting assumption. This supports next-skill prediction from CDM-derived snapshot mastery patterns.
