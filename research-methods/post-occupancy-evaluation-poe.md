## Description
Post-occupancy evaluation (POE) is presented as an established methodology for evaluating non-domestic buildings, which the review charts historically to contextualize learning-space evaluation. The authors write that "we initially chart the development of post-occupancy evaluation (POE) for non-domestic buildings." POE serves as the foundational evaluative tradition from which the later, broader building performance evaluation framework emerged, and the review treats its development as the starting point for understanding how learning environments have been evaluated.
