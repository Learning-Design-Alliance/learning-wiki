# Three-level hierarchical clickstream operationalization and Information Processing Index (IPI)

> **Research Method** · [All research methods](index.md)

## Description
The report develops a hierarchical framework that encodes raw video-player clicks into eight operations (Play, Pause, SeekFw, SeekBw, ScrollFw, ScrollBw, RatechangeFast, RatechangeSlow), groups frequent 4-gram click patterns into seven behavioral categories, and maps those categories onto stages of the "Limited Capacity Information Processing Approach" to compute a quantitative Information Processing Index. The index weights each behavioral action positively or negatively, so that "When IPI > 0, it can be inferred that high information processing is being done by students", while IPI < 0 signals low information processing and IPI = 0 a neutral counterbalancing. It is grounded in the assumption that people are limited-capacity processors who allocate a shared cognitive resource pool across perception, meaning processing and memory stages.
