# Mixed functional data analysis for grade-varying longitudinal predictor effects

## Description
The article applies longitudinal mixed functional data analysis (FDA) to estimate regression effects as functions of grade, using linear splines for fixed and random effect functions. It argues FDA "is not constrained by the parametric assumptions of cross-lagged and related models" and enables simultaneous estimation of overall domain-general and domain-specific effects, grade-by-grade contributions of individual variables, and linear and non-linear across-grade change in these effects on subsequent mathematics achievement.

- **Functional data analysis pipeline for modeling sleep as a continuous four-year trajectory**: This element is the study's analytical apparatus: daily Fitbit sleep minutes are converted into smooth continuous functions using cubic B-spline basis functions (order 4), with the number of basis functions chosen by generalized cross-validation and knots placed at semester boundaries. Concurrent functional linear regression with roughness-penalty smoothing estimates time-varying sleep–GPA coefficients, and pointwise functional t-tests with permutation testing compare sleep curves between social-activity groups. The authors present FDA as "particularly well-suited for examining continuous temporal processes in naturalistic settings", revealing dynamics that discrete-time analyses would miss. (Zhao Yao (2026))
