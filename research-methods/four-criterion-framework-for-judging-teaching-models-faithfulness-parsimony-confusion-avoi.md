# Four-criterion framework for judging teaching models: faithfulness, parsimony, confusion avoidance and accessibility

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The review proposes judging model quality by four criteria: "Faithfulness: the model represents all important features of the original", "Parsimony: non-essential, potentially distracting features are kept to a minimum", "Confusion avoidance: the model has no (obtrusive) misleading features", and "Accessibility: the target audience is capable of understanding the structure of the model". Faithfulness and parsimony can be analysed within physics without reference to an audience; confusion avoidance and accessibility are audience-specific and can ultimately only be tested in real-life teaching situations.
