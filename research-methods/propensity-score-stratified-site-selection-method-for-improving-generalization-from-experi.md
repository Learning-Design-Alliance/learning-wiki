# Propensity-score stratified site-selection method for improving generalization from experiments

> **Research Method** · [All research methods](index.md)

## Description
A multistep design-based method for selecting experiment sites so the sample resembles a defined inference population. It uses propensity score methodology to compare the population to eligible sites and create strata for site selection, so that, when perfectly implemented, the sample is "like a miniature of the inference population of interest". The method calls for defining the inference population, eligibility requirements, treatment-effect-relevant covariates, proportional strata allocation, and recruiting at least some eligible sites in each stratum.
