# Stepwise ESU/SISE validation framework for surgical simulators

> **Research Method** · [All research methods](index.md)

## Description
The article organizes simulator development within the ESU/Standardisation in Surgical Education (SISE) framework as a stepwise evaluation program. The present study is framed as "a Phase 0 opportunistic expert appraisal of a prototype station delivered at a large-scale educational meeting", capturing early face and content validity evidence. Planned next steps include cognitive task analysis (CTA) and Delphi expert consensus to refine task breakdown, training requirements and assessment criteria, followed by construct validity testing with objective performance metrics and multi-center evaluation of skill transfer. Within this framework the simulator is classified as a Lower Urinary Tract Step 2 training tool for skill development and initial procedural comprehension.
