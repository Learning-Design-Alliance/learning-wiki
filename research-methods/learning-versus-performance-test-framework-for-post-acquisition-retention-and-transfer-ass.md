# Learning-versus-performance test framework for post-acquisition, retention, and transfer assessment

## Description
The review organises outcome measurement for procedural skill learning into three test types. Post-acquisition tests measure performance immediately after intervention but "should not be associated with a relatively permanent change associated with learning". Retention tests insert a rest period so non-permanent effects are eliminated, and transfer tests assess adapting the skill to a different situation. The review uses this framework to interpret all four motor learning principle comparisons.
