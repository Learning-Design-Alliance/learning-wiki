# Gesture-level video annotation method for robotic surgical skill assessment

## Description
The article builds on a gesture classification system that "deconstructs robotic tissue dissection into basic surgical maneuvers," involving "nine dissection gestures (e.g., hook) and four supporting gestures (e.g., retraction)." Annotators label each gesture's name, duration, and arm, achieving 91.2% inter-rater agreement. The framework positions gestures as "a novel method to objectively evaluate dissection performance and anticipate outcomes," offering more granular, explainable insight than reviewer-scored tools like DART.
