CFIR five-domain framework for organizing e-learning implementation determinants¶

Research Method · All research methods
Evidence · no claims cited

Description¶

The review uses the updated Consolidated Framework for Implementation Research (CFIR) to code and organize implementation determinants. Determinants were "mapped across CFIR’s five domains (Innovation, Outer setting, Inner setting, Individuals, and Implementation process)", coded one at a time to the domain, subdomain, and construct best reflecting the original description, with two researchers coding independently and discrepancies resolved by consensus. In this review it serves as the synthesis structure for facilitators and barriers.
