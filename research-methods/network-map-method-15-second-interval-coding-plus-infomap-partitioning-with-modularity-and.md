# Network-map method: 15-second interval coding plus Infomap partitioning with modularity and segregation measures

> **Research Method** · [All research methods](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 2 claims rest on one study

## Description
A method for characterizing teaching-learning situations: classroom teaching is coded in 15-second intervals across four categories (Activity, Interaction, Subject, Learning Aim), networks are built from time-ordered codes, and partitioned with Infomap. The authors state "Teaching was coded in 15 second intervals while observing and audio-recordings were used to verify codes." Modularity Q, segregation Dseg, and NMI characterize and allow comparison between implementations, and named module maps visualize teaching.
