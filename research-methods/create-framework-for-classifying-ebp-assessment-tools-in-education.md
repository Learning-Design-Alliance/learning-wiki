# CREATE framework for classifying EBP assessment tools in education

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The CREATE framework (Classification Rubric for EBP Assessment Tools in Education), developed in 2011, provides guidance for developing new EBP instruments by "purposively classifying the assessment domains (e.g. self-efficacy, knowledge, skills) and types (e.g. self-report, performance assessment) within the five EBP steps". The review uses its seven outcome-domain categories to organise the outcomes measured in included studies and cites it to help EBP educators identify the best available instruments.

(Albarqouni Loai et al. (2018))
- **CREATE framework for classifying EBP assessment tools**: The CREATE framework (Sicily statement) classifies evidence-based practice assessment tools by category (reaction to educational experience, attitudes, self-efficacy, knowledge, skills, behaviours, benefit to patients) and type (self-report, cognitive testing, performance assessment, activity monitoring, patient-oriented outcomes), crossed with the five EBM steps. The article uses it to justify assessing knowledge and skills via performance assessment: "EBM related knowledge and skills are the only assessment categories that are best examined via performance, or cognitive, assessment". It also guides which constructs suit self-report versus observation. (Ilic Dragan et al. (2014))
