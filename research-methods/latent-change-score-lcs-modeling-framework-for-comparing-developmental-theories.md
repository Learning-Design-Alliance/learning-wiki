# Latent change score (LCS) modeling framework for comparing developmental theories

## Description
The article uses bivariate latent change score (LCS) models, which "conceptualize differences between successive measurements as latent change factors," allowing within-subject change to be modeled via self-feedback (β) and coupling (γ) parameters. This framework let the authors translate g-factor, investment, and mutualism accounts into competing psychometric models and compare them directly on the same longitudinal data — something prior studies had not done. The coupling parameter indexes whether change in one domain is affected by the prior level of the other domain.
