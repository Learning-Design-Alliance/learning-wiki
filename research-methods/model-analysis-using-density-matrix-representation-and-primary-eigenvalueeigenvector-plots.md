# Model analysis using density-matrix representation and primary eigenvalue/eigenvector plots

## Description
Model analysis, introduced by Bao and Redish, represents student learning measured by multiple-choice surveys in terms of probabilities of using well-defined models. A class density matrix is built from each student's probabilities of using each model, and "The primary eigenvalue and the components of its associated eigenvector are used to create a single point on a model plot representing a class's probability of using each model at a given time." The plot is divided into regions (Model 1, Model 2, Mixed, Secondary) characterizing the class knowledge state.

- **Model analysis: density-matrix representation of class knowledge state plotted via primary eigenvalue and eigenvector**: Model analysis, introduced by Bao and Redish, represents student learning measured by multiple-choice surveys in terms of probabilities of using well-defined models. A class density matrix is built from each student's probabilities of using each model, and "The primary eigenvalue and the components of its associated eigenvector are used to create a single point on a model plot representing a class's probability of using each model at a given time." The plot is divided into regions (Model 1, Model 2, Mixed, Secondary) characterizing the class knowledge state. (Trevor I. Smith (2016))
- **Class model density matrix as a tool for extracting class-level model structure**: The class model density matrix is computed as the average of individual students' model density matrices. Its diagonal elements reflect the percentage of responses generated with each model, while off-diagonal elements reflect the consistency of individual students' model use. Eigenvalue decomposition of this matrix yields quantitative information about whether the class is dominated by one consistent model, partitioned into groups with different consistent models, or characterized by individual students in mixed states. (Lei Bao et al. (2001))
- **Model Analysis: a cognitive framework representing student knowledge as probabilistic mixtures of mental models in a model space**: Model Analysis is a method for assessing student knowledge that represents each student's mental state as a vector in a model space spanned by basis vectors corresponding to distinct mental models identified through qualitative research. The framework treats students as being in mixed model states, where the probability of activating each model varies by context. It uses a density-matrix formalism to aggregate individual student states into class-level information about model consistency and distribution. (Lei Bao et al. (2001))
- **Model estimation algorithm for extracting student model states from multiple-choice data**: Model estimation is a procedure for extracting information about student mental models from responses to research-based multiple-choice questions. It maps each answer choice to a common model, computes individual student probability vectors, and aggregates them into a class density matrix. The article states it "can provide a way to extract" information that score-based analysis cannot distinguish, such as whether a low score reflects a consistent incorrect model, calculation errors, random guessing, or a persistently triggered incorrect model within a mixed state. (Lei Bao et al. (2001))
- **Model analysis: a quantitative representation framework for students' alternative knowledge**: Model analysis applies qualitative research on student alternative knowledge to establish a quantitative representation framework. As the article states, it 'applies qualitative research to establish a quantitative representation framework,' so that alternative knowledge and its probability of use in a range of equivalent contexts can be assessed rather than collapsed into correct/incorrect scores. (L. Bao et al. (2006))
