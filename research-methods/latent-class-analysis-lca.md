## Description
Latent class analysis is a model-based clustering method that identifies unobserved latent subgroups from categorical data, where each class is characterized by "a unique pattern of response probabilities to the input variables". It estimates structural parameters (class proportions) and measurement parameters (conditional item probabilities) via an Expectation-Maximization algorithm, and sits within the broader mixture modeling framework so that class membership and its relations to auxiliary variables are estimated simultaneously. The article presents LCA to the PER community as an alternative to k-modes clustering that accounts for classification errors through probabilistic rather than definitive assignment.

- **Latent class analysis as a statistically testable alternative to rule assessment methodology for detecting children's mental models**: The article proposes LCA, a latent structure model for categorical data, to detect underlying mental models in children's response patterns. "LCA divides a sample of response patterns into a limited number of groups, the so-called latent classes." Each class is characterized by conditional probabilities of item responses, and the technique offers statistical fit measures, so "the criterion used to classify children, therefore, is not arbitrary but is amenable to statistical testing." Unlike rule assessment methodology, LCA can model response errors and detect unexpected response patterns without models being formulated beforehand. The article applies LCA to EARTH responses in both experiments. (Straatemeier et al. (2008))
