# Reproducible Bayesian bivariate generalized linear modeling framework for evaluating instructional innovations

> **Research Method** · [All research methods](index.md)

## Description
The article provides a transparent analytic framework pairing outcome-appropriate likelihoods in a Bayesian bivariate generalized linear model: "Bayes' theorem exam scores were modeled with a zero–one inflated Beta distribution because the scores were bounded between 0 and 100 and included many perfect scores," while satisfaction used a cumulative logit formulation with three ordered levels. Both submodels shared predictors (instructional style, major type, gender, race), used weakly regularizing priors, and were fit in brms with Stan, reporting posterior means and 95% credible intervals. Deidentified data, analysis code, and instructional materials are archived in an Open Science Framework repository.
