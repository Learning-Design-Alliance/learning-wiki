# Gesture–speech match, mismatch, and discordance coding method

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A coding procedure in which verbal and gestural explanations are coded independently (speech from audio only, gesture from video only) according to a lexicon of procedures such as Add All, Add to Equal, Carry, Grouping, Add-Subtract, and Equalizer, then compared per explanation. A child "who produced 3 or more (i.e., 50% or more) explanations characterized by gesture-speech mismatch within a set of six explanations was considered to be in a “discordant” state"; fewer than 3 mismatches defined a concordant state. No-gesture responses were coded as matches.
