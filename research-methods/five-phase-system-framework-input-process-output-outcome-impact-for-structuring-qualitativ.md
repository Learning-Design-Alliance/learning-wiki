# Five-phase system framework (input, process, output, outcome, impact) for structuring qualitative SBE research

## Description
The study's conceptual framework organizes 16 thematic categories into five sequential phases of a system: input (facilities, personnel, teaching materials), process (pre-brief, simulation, debrief), output (direct effects on knowledge, attitude, skills), outcome (effects on learning and teaching at the college), and impact (long-term effects on curriculum, quality of care, and the profession). The researchers fitted categories to the general system theory, stating it "can reveal the multidisciplinary nature of the phenomenon under investigation". They conclude that using it "proved to be useful for structuring and analyzing qualitative data in SBE research".
