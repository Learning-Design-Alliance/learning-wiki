# Drawing-based survey and network analysis methodology for studying learning-community perceptions

> **Research Method** · [All research methods](index.md)
> **Evidence** · 2 claims (2 for) · 1 study (1 qualitative), `q2` · 1 of 1 report an effect size · 2 claims rest on one study

## Description
The article introduces a proof-of-concept methodology combining a drawing-based survey with network analysis of the cataloged drawing elements. Students draw and annotate their perceptions, then a checklist prompts them to depict “the goals, members, and practices of the introductory lab’s COP.” Each element becomes a network node, with edges connecting elements co-occurring in a drawing; frequency and betweenness centrality are compared across identity-group subnetworks using Poisson-based bootstrapping (1200 bootstrap networks) and Cohen’s d. The network analysis code and anonymized code book are released for use.
