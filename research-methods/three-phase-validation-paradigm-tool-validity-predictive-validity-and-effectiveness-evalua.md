# Three-phase validation paradigm: tool validity, predictive validity, and effectiveness evaluation

> **Research Method** · [All research methods](index.md)

## Description
The study introduces a reusable three-phase evidence chain for evaluating AI teaching tools: Phase 1 assessed AI scoring reliability using the intraclass correlation coefficient (ICC) based on 20 records blindly evaluated by two experts; Phase 2 analyzed the correlation between post-rotation AI scores and Mini-CEX scores; Phase 3 used ANCOVA for comparing post-rotation AI scores between groups. The authors state this is "the first study to chain instrument validation, predictive validity, and effectiveness evaluation in a single three-phase paradigm, offering a reusable framework for evaluating AI-assisted teaching tools in clinical documentation training."
