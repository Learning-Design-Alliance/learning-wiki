## Description
Latent profile analysis is a statistical method the article describes as using "Gaussian mixture modeling to uncover hidden groupings, also known as classes or profiles, of data based on some measured variable". LPA iteratively adjusts Gaussian distributions for each profile until points are assigned so the expectation value is maximized, assigning weighted profile memberships via probability distributions. The CALEP project uses COPUS profiles (percentage of class time per code) as input variables, expecting LPA to group observations with similar profiles that align with the known physics pedagogies.

- **Person-centered latent profile approach to non-cognitive factors in academic achievement**: The article applies latent profile analysis (LPA) as a person-centered alternative to variable-centered methods like cluster analysis and multiple regression. LPA is "a probabilistic, or model-based, variant of traditional cluster analysis" that groups individuals into categories of similar profiles. The authors argue this approach "could benefit us to figure out the effects of different levels of variables, which opposes to a purely linear effect in the traditional way," enabling identification of motivational patterns within individuals rather than average effects across variables.
