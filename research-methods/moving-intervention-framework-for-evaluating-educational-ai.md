# Moving intervention framework for evaluating educational AI

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A conceptual account of why conventional evaluation lags educational AI: the intervention "may be better understood as a versioned configuration of technological capabilities, pedagogical functions and implementation practices at a particular point in time: a moving intervention rather than a fixed product". Movement comes both from technological change and from implementation, so evaluation requires documenting software version, pedagogical framing and implementation conditions. The authors distinguish technological implementation (interfaces, underlying models, which change quickly), instructional features (adaptive practice, diagnostic feedback, scaffolding, more stable) and pedagogical intention (most stable), arguing cumulative evaluation needs enough version information to identify technological change while documenting pedagogical conditions that permit learning across versions.
