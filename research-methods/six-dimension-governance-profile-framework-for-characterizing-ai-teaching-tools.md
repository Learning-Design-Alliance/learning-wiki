# Six-dimension governance profile framework for characterizing AI teaching tools

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A governance profile is "an explicit account of how an AI-mediated teaching tool distributes pedagogical authority, learner agency, human accountability, contextual boundaries, and evaluation visibility". The framework comprises six dimensions: pedagogical grounding, AI instructional authority, human accountability and control, learner agency and cognitive engagement, context specificity and boundary setting, and evaluation visibility and revision. Each dimension carries a core design question, typical mechanisms, and evidence of fit, avoiding collapse of governance into a single strict-to-permissive continuum.
