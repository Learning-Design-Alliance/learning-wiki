# Multi-turn Framing-Prompting Loop with prompt trajectory as unit of analysis

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The paper proposes a recursive loop in which 'Prompt 0 establishes a provisional macro-frame' and each subsequent turn operationalizes learner uptake by maintaining, specifying, challenging, repairing, transforming, reframing, or closing the task, with seeing, thinking, and acting as recursive framing actions. The unit of analysis is the prompt trajectory rather than the isolated prompt. Accumulated context stabilizes terms and assumptions, but the article warns that 'an early error can be embedded in subsequent turns and gain apparent legitimacy through repetition', so the loop must include opportunities to return to earlier assumptions and criteria.
