# Five-category taxonomy of keystroke features for writing-process analysis

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article organizes keystroke-log features drawn from prior literature into five groups: "features related to timings of pauses, revisions, typing bursts, verbosity, and other (non-typing) events". Pause features include IKI metrics and long-pause percentages; revision features cover backspaces and leading-edge versus in-text revisions; fluency features capture bursts; verbosity features count keystrokes and words plus 30-s variability measures; other-event features include focus shifts and cut/paste/jump durations. The study extracted 54 features in these categories from Inputlog raw logs for prediction modeling.
