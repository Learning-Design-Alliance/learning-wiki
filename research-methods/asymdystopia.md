# Asymdystopia

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
Asymdystopia is the authors' named concept for a context in which increasing sample size does not improve, and can worsen, inference. They define it as "a context in which a larger sample size is not necessarily better and could even be worse from the perspective of controlling the Type 1 error rate." The mechanism is that the standard error in the t-statistic denominator shrinks faster than a biased numerator, so a fixed bias can turn a non-significant estimate significant as samples grow.

- **Asymdystopia: larger samples are not necessarily better for Type 1 error control when bias persists**: Asymdystopia is the authors' named concept for a context in which increasing sample size does not improve, and can worsen, inference. They define it as "a context in which a larger sample size is not necessarily better and could even be worse from the perspective of controlling the Type 1 error rate." The mechanism is that the standard error in the t-statistic denominator shrinks faster than a biased numerator, so a fixed bias can turn a non-significant estimate significant as samples grow. (John Deke et al. (2018))
- **Asymdystopia: larger finite samples are not necessarily better for Type 1 error control**: Asymdystopia is the article's name for a context in which "a larger (but finite) sample size is not necessarily better and could even be worse from the perspective of controlling the Type 1 error rate". It arises because as sample size grows the standard error of the impact estimate shrinks while bias stays the same or shrinks more slowly, so the t-statistic's denominator shrinks faster than its numerator and biased estimates become statistically significant. The article examines this for attrition bias in RCTs and functional form misspecification in RDDs, the two most rigorous designs commonly used in education research. (Deke et al. (2017))
