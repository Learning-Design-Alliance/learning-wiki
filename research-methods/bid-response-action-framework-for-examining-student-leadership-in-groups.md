## Description
The article introduces a framework distinguishing three variants of leadership codes: a "Bid: An attempt at establishing oneself as a possible leader", a "Response: An external marker that demonstrates whether one’s bid is acknowledged or dismissed by the group", and an "Action: Demonstrating a leadership-based behavior within the classroom". Each code occurrence is assigned one variant to specify the level of leadership portrayed. Not all codes carry all three variants — Responsible For The Group's Actions has only an action — and many observed interactions showcase only one variant.
