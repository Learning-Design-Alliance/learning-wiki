# Expectation-Misconception Tailored Dialogue framework adapted for assessment

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The AutoTutor-based Expectation-Misconception Tailored Dialogue framework structures agent responses around a main question with a pre-programmed complete expected answer. When the student cannot fulfill the answer, the agent provides a pump such as "can you tell me more", then hints (open-ended clues), then prompts (single-word clues), followed by an assertion; stated misconceptions are corrected and correct answers receive an assertion. CBAs adapt this framework but provide less scaffolding information, because the goal is to probe what the student already knows rather than give away the answer, so assertions are often withheld. The framework also defines response categories the agent must recognize: correct, incomplete, irrelevant, meta-communicative, meta-cognitive, and no response.
