## Description
The article identifies automated analysis techniques for detecting learners' internal argumentative scripts during CABLe. "Scheuer et al. ( 2012) classified available automated analysis techniques to this effect into four categories, namely syntactical anal ysis, problem-specifi c analysis, reasoning analysis, and collaborative filtering analysis." Named educational technologies using AI and language content analysis to analyze student argumentation moves and structures include ARGUNAUT, TagHelper, Rashi, Belvédère, and LARGO; NLP has also been used to code micro-argumentation prior to a learning phase.
