# Salient distracting feature (SDF) experimental paradigm with time-per-word processing measure

> **Research Method** · [All research methods](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 causal), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The study uses Mamede's salient distracting feature (SDF) paradigm: 12 clinical vignettes based on real patients, presented in three versions (no SDF, SDF at the beginning, SDF at the end) in a within-subject incomplete block design via Qualtrics. Time spent on each case section was divided by word count, yielding "seconds per word", enabling direct observation of processing investment alongside accuracy and SDF-related error scoring.
