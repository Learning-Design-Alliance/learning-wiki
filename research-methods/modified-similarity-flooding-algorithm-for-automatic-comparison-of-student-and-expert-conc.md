# Modified similarity flooding algorithm for automatic comparison of student and expert concept maps

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The project programmed software using a similarity flooding algorithm (Melnik, Garcia-Molina, & Rahm, 2002), which 'provides a means of comparing two graphic items such as conceptual maps.' The team modified the original algorithm to include an automatic thesaurus for synonyms, relative versus full similarity, node weighting, and threshold values. Each modification significantly improved accuracy, validated so expert maps matched themselves at 100%. It generated the automatic feedback students received on their maps.
