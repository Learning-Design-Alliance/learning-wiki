## Description
RE-AIM (Reach, Effectiveness, Adoption, Implementation and Maintenance) is an established implementation framework the authors used "to enhance the replicability of the programme". It defines five evaluation dimensions: Reach describes the target population and participation; Effectiveness evaluates outcomes; Adoption assesses institutional uptake; Implementation examines fidelity, consistency and adaptations; and Maintenance explores long-term sustainability. The article structures its entire Evaluation section according to these five domains and uses the framework to organise the qualitative framework-method coding of focus group data.
