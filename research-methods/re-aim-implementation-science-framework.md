## Description
RE-AIM (Reach, Effectiveness, Adoption, Implementation and Maintenance) is an established implementation framework the authors used "to enhance the replicability of the programme". It defines five evaluation dimensions: Reach describes the target population and participation; Effectiveness evaluates outcomes; Adoption assesses institutional uptake; Implementation examines fidelity, consistency and adaptations; and Maintenance explores long-term sustainability. The article structures its entire Evaluation section according to these five domains and uses the framework to organise the qualitative framework-method coding of focus group data.

- **RE-AIM framework for evaluating e-learning implementation outcomes**: RE-AIM (Reach, Effectiveness, Adoption, Implementation, and Maintenance) is an implementation science framework the article applies to e-learning resources. Reach is "the access of RLOs by the users"; effectiveness applies the 4-level Kirkpatrick model (reaction and learning measured, behavior and results not measured); adoption counts institutions using RLOs; implementation measures fidelity via completion and nonbounced users; maintenance measures sustained access after project end. The authors conclude the framework provides a comprehensive, objective evaluation that existing models like Kirkpatrick, CIPP, and ADDIE lack. (Lim HM et al. (2025))
