# Risk-adjusted cumulative sum (RA-CUSUM) learning-curve analysis

## Description
RA-CUSUM is a statistical monitoring method that plots the difference between the cumulative expected occurrence of an event (here, recurrence) and the actual observation, adjusting each patient's individual risk of surgical failure through a likelihood-based scoring method. In this study it was used with two charts — RA-CUSUM+ to detect a doubling and RA-CUSUM− to detect a halving of the odds of recurrence — to identify the learning phase and plateau of a surgical team. The authors describe formal CUSUM analysis as "considered the reference standard for studying surgical learning curves".
