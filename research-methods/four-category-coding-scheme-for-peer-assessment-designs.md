## Description
The review defines peer assessment as "a learning phenomenon where individuals or social constellations (e.g., pair, group, team, community)—within a physical and/or virtual environment—exchange, react to, interact and/or act upon information about individual performance and/or individual contributions" with the purpose of accomplishing shared and individual learning goals. It extends Topping's (1998) definition to cover social constellations and virtual environments, and frames instructional scaffolds provided by agents (teacher, peer, self, technology) as fadable supports. The definition underpins a coding scheme of 27 design elements grouped into four categories: context (what designers cannot manipulate), instructional design (what designers can manipulate), outcomes, and moderators/mediators.
