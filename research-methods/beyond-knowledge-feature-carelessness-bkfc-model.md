# Beyond-Knowledge Feature Carelessness (BKFC) model

> **Research Method** · [All research methods](index.md)

## Description
The BKFC model operationalizes carelessness as errors where "the mistake appears to be unrelated to their level of knowledge," rather than as mistakes made despite having knowledge. It estimates knowledge with Performance Factor Analysis, which handles multi-skill items, then fits a logistic regression combining the PFA estimate with seventeen behavioral features distilled from log data; the behavioral contribution ω is inverted to yield a probability of carelessness for incorrect answers. In this study it was applied to a decimal learning game dataset for comparison with contextual slip approaches.
