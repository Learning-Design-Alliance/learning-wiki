# Text-estimated IRT parameter initialization for newly generated assessment items

> **Research Method** · [All research methods](index.md)

## Description
Newly generated multiple-choice questions can be used in assessment tests immediately with text-estimated IRT latent traits instead of waiting for full pretesting with hundreds or thousands of students. The article concludes that "R2DE reduces the importance of pretesting newly generated questions" because the estimated traits "only require some fine-tuning, which is much faster than performing pretesting from scratch".
