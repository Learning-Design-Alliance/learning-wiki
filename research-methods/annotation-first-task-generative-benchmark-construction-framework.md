# Annotation-first, task-generative benchmark construction framework

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
MUSE's construction framework separates what an image contains from how a capability is queried: "each artwork is annotated once with a reusable structured representation of its visual and semantic content, after which task-specific questions are instantiated through predefined generation rules." This decoupling supports annotation reuse across tasks, consistent semantics between independently generated tasks, and explicit control over question format and difficulty, while reducing the annotation effort required to extend a benchmark to new tasks.
