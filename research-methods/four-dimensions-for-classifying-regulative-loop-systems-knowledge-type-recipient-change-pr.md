# Four dimensions for classifying regulative loop systems: knowledge type, recipient, change process, granularity

## Description
Beyond the main classification, the article augments it with four independent dimensions, summarized in Table 1: "Type of knowledge: Cognitive, meta-cognitive, collaborative skill, motivations; Recipient: Student, teacher, activity structure (interventions only); Type of change process: Reminding, persuasion, teaching, remediation; Granularity: Step, task, module." Knowledge type distinguishes cognitive knowledge, meta-cognitive knowledge addressed by meta-tutors, collaboration skill, and motivations. Recipient covers whether information goes to the student directly, to a teacher, or restructures the activity.
