## Description
The article proposes expanding assessment beyond the standard select-a-correct-answer-and-justify format with a set of four question types all based on the same physical situation: traditional (select a correct response and explain), incorrect traditional (select an incorrect response and explain), given increase (ask if a stated answer is correct), and given correct (tell students the correct answer and ask them to justify it). As the article puts it, "Asking the incorrect traditional question type lets us know which answers students think are incorrect, and why they disbelieve them." Read jointly, the types reveal how students' views of each response vary across tasks.
