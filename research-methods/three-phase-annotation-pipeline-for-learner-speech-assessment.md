# Three-phase annotation pipeline for learner speech assessment

## Description
The corpus was annotated by ELiT human annotators using a three-stage approach: Phase 1 awards audio quality and holistic scores, Phase 2 produces detailed disfluent transcriptions with word and phrase tags, and Phase 3 generates grammatically corrected transcriptions. Phase 3 annotators work "provided with texts only, to avoid any conflict of interpretation or second guessing" about Phase 2 decisions. Comparing fluent and corrected transcriptions yields reference edits that can be fed back to learners.
