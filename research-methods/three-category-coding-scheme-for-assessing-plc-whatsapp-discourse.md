# Three-category coding scheme for assessing PLC WhatsApp discourse

> **Research Method** · [All research methods](index.md)
> **Evidence** · 3 claims (3 for) · 1 study (1 associational), `q2` · 0 of 1 report an effect size · 3 claims rest on one study

## Description
The article synthesizes a coding scheme for assessing PLC discourse, built on teacher-knowledge frameworks (CK, PCK, TK) and PLC characteristics. It classifies each WhatsApp message into "three main categories": Community Development (building community, cooperation, sharing, positive feedback), Professional Knowledge Development (CK/PCK/TK and matching ASK- subcategories), and Administrative Issues, plus Media and Not Applicable tags. Messages are multi-labeled, discursive sequences are delimited into threads, and tags serve as indications of teachers' learning or PLC development.
