# Exponential Learning with Sigmoidal Decay (ELSD) model of syntax acquisition

## Description
The ELSD model represents syntax acquisition as "a simple exponential learning process" in which grammatical proficiency grows with experience, with an experience discount factor modeled separately for simultaneous bilinguals, immigrants, and non-immersion learners. The learning rate is a piecewise function: constant from birth to age tc, then declining according to a sigmoid whose parameters control steepness and center. The authors state this structure "allows it to capture a very wide range of developmental trajectories", and they fit it simultaneously to monolingual, immersion, and non-immersion performance curves to estimate when underlying learning ability declines.
