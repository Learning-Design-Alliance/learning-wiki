# Four-code scheme for coding self-initiated SRL processes by type and accuracy

> **Research Method** · [All research methods](index.md)

## Description
For sequence mining, the authors coded every self-initiated SRL behavior from log files into "separate codes (see Table 1) of behaviors, which contained two separate elements, with four codes in total (2 × 2)": cognitive-high accuracy, cognitive-low accuracy, metacognitive-high accuracy, metacognitive-low accuracy. Accuracy was defined per strategy: notes scored via Latent Semantic Analysis against content (50% similarity threshold), summaries by key words and length on first attempt, judgments of learning and feelings of known via a coding scheme relating ratings to page-quiz performance, and monitoring progress toward goals via a 60% quiz threshold. This allowed sequences to be analyzed by both process type and accuracy.
