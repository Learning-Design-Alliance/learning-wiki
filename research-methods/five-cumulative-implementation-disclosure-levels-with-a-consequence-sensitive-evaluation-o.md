# Five cumulative implementation-disclosure levels with a consequence-sensitive evaluation override

## Description
PRISMA-LLM organizes implementation disclosure into five cumulative levels: off-the-shelf software; prompt-only LLM; structured/engineered workflows; retrieval/adapted/single-agent workflows; and multi-agent/swarm systems, each adding the technical detail needed to reconstruct the workflow. Minimum evaluation breadth increases with implementation complexity, but "implementation level is not a risk score": a consequence override requires stronger validation at any level when outputs can change the evidence base, human verification is limited, the system is proprietary or mutable, or errors are hard to reconstruct or reverse.
