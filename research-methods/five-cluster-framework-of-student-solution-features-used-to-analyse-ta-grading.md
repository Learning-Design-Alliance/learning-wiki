# Five-cluster framework of student-solution features used to analyse TA grading

## Description
The article codes the solution features TAs list into five clusters: C1 problem description and evaluation, C2 explication of the problem-solving approach, C3 domain knowledge, C4 elaboration (coded productive, counterproductive, or neutral), and C5 correctness. It distinguishes features TAs merely mention from those they weigh in grading, to judge whether grading encourages prescribed problem-solving strategies: 'We identified 21 features that were grouped into 5 clusters'.
