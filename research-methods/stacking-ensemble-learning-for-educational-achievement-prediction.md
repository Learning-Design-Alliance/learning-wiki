# Stacking ensemble learning for educational achievement prediction

> **Research Method** · [All research methods](index.md)

## Description
A Stacking ensemble learning model in which four heterogeneous individual learners—Support Vector Machine, Decision Tree, Logistic Regression, and Linear Discriminant Analysis—serve as base classifiers. Their outputs form a meta-dataset passed to a next-layer meta-classifier that produces the final prediction, with base outputs treated as new features and raw labels retained. In this study it was used to predict primary school students' academic achievement and achieved 68.33% average cross-validation accuracy.
