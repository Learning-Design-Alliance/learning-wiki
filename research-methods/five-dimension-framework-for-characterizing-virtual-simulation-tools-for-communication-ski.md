# Five-dimension framework for characterizing virtual simulation tools for communication skills training

> **Research Method** · [All research methods](index.md)
> **Evidence** · 4 claims (4 for) · 1 study (1 review), `q3` · 0 of 1 report an effect size · 4 claims rest on one study

## Description
The review organizes the 24 virtual tools along the extraction dimensions it coded for each tool: training language, learning objective, degree of learning autonomy (fully autonomous vs instructor-mediated), patient type (avatar, virtual patient with human-like appearance, real person), type of trainee responses (written or oral conversation), and type of technology used. It reports that "we noted the tool name, training language, learning objective, degree of learning autonomy... patient type... type of answers given by the trainee... and type of technology used." This framework lets educators and researchers compare heterogeneous tools and locate gaps, such as the scarcity of non-English and fully immersive tools.
