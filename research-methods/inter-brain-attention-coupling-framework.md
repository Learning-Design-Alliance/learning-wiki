# Inter-brain attention coupling framework

## Description
The framework holds that learning-related attention follows the structure of course contents, so attention dynamics shared across students reflect course-content-driven processing. It defines "the degree to which an individual student’s attention dynamics match the attention dynamics averaged across classmates" as inter-brain attention coupling, computed with Pearson correlation over 30-s epochs. Comparing a student to the class average is expected to "filter out idiosyncratic dynamics responsive to distractors", capturing attention intended by the course contents even when a student's raw attention level is high but off-task.
