## Description
Chain-CAT is a computerized adaptive testing algorithm in which each short test in a course uses the student's proficiency estimate from the previous test as collateral information. The article states that "This algorithm sequentially links the results of each CAT administration using collateral information." Concretely, the prior proficiency estimate sets the mean of the normal prior distribution for Bayesian (EAP) proficiency estimation and guides first-item selection via the Fisher information criterion in each subsequent test, accelerating convergence. The authors developed it for the Force Concept Inventory to enable frequent, short, formative assessments.
