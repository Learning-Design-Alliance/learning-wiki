# Nine attribute categories framework for classifying game design elements

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A proposed framework categorizes game design elements into nine attribute categories, aiming to consolidate research and facilitate comparisons between studies. The article notes that "A revised definition of gamification are suggested replacing game design elements with the attributes categories". The framework is recommended to improve health professions education and is used in this review to characterize interventions across included studies.
