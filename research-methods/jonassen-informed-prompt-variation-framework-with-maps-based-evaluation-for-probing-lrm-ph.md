# Jonassen-informed prompt-variation framework with MAPS-based evaluation for probing LRM physics reasoning

## Description
The article adapts Jonassen's problem-classification framework to generative-AI problem solving along two dimensions: "prompt-specificity, or how much information is explicitly given versus left for the model to infer, and modality, or whether the problem is presented through text alone or with visual representations". Combined with the MAPS rubric, which scores useful descriptions, physics approach, specific application, mathematical procedures, and logical progression, this provides "a structured way to probe these dimensions of LRM reasoning" beyond final-answer accuracy.
