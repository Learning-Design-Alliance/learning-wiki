# jRate sorting task with Pathfinder network analysis

> **Research Method** · [All research methods](index.md)

## Description
jRate (Schuelke, 2012) is the computer sorting task software used in both studies: participants drag topic-level key terms around a screen to form clusters according to their understanding, and the software converts the sorting into a proximity file of term-term distances in screen pixels. These files are analyzed by Pathfinder software (Schvaneveldt, 2020) with Minkowski r = infinity and q = n−1 to produce networks compared to an expert referent network by percent overlap and Freeman's graph centrality.
