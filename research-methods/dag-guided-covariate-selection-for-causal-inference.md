# DAG-guided covariate selection for causal inference

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article recommends constructing a DAG before data collection so that decisions about when to control, what to control for, and when to avoid control can be derived by inspecting the graph. It notes that "statistical controlling for a variable requires that it has been measured in some way, highlighting the need for working with DAGs in the design stage of a research study." This principled approach replaces indiscriminate inclusion of correlated covariates, which the article calls garbage-can regression.
