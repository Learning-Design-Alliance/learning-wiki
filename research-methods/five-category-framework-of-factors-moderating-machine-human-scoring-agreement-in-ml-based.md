## Description
The chapter presents an extended framework, derived from the author's prior literature review and meta-analysis, that organizes the factors moderating Machine-Human Agreements (MHAs) into five categories. As printed, it "identifies five categories of factors moderating MHAs: (i) assessment external features, (ii) assessment internal features, (iii) examinee features (e.g., grade, school level, ELL), (iv) machine training and validation approaches (e.g., sample size, human rater reliability), and (v) technical features (e.g., algorithm, attribute abstraction)." It guides educators and researchers in developing accurate ML-based assessment tools.
