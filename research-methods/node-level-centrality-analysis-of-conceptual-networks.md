## Description
The article advocates that educational research using network analysis on conceptual data should compute and report node-level centrality measures, because its analysis showed 'the most significant graph-derived metrics to distinguish learner groups are node-level ones'. Centrality scores such as degree, betweenness and eigenvector centrality capture how individual concepts are positioned within a learner's graph, and the authors explicitly 'recommend all educational research using network analysis on conceptual data to include centrality measures in their analysis'.
