# Rank-order versus distributional agreement framework for automated marking validity

## Description
The article distinguishes two properties a marking system can have: distributional agreement, whether the overall spread of marks matches the reference, and rank-order agreement, "whether a system places responses in the same quality order as the reference". A system can match the distribution while ordering work backwards, so mean absolute error and calibration can be satisfied by distribution matching alone. The framework holds that only rank-order metrics test whether a system discriminates quality, and that agreement with an unreliable human reference cannot support strong ranking claims.
