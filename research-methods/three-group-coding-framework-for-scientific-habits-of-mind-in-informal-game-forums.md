# Three-group coding framework for scientific habits of mind in informal game forums

## Description
The article develops a set of 18 codes (following Chi 1997) based on AAAS benchmarks for scientific literacy, Chinn and Malhotra's framework for evaluating inquiry tasks, and Kuhn's epistemological framework. The codes address "Scientific discursive practices (including social knowledge construction), systems- and model-based reasoning, and tacit epistemologies", applied by four raters with 92% four-way interrater reliability on roughly 10% of the corpus. It deliberately omits content-specific science understanding because the investigated world "makes no claims of correspondence with the natural one".
