## Description
The CBLIM is a probabilistic latent class model introduced in the article as "a competence-based extension of the basic local independence model (BLIM)". It serves as one of the two focal models whose equivalence with the Multiple Strategy DINA model is proved, connecting competence-based skill assignment (a KST concept) with noisy latent class measurement models used in cognitive diagnosis.
