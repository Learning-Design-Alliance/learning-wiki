# Adapted Personalized Learning Continuum Framework (PLCF)

## Description
The article adapts the Personalized Learning Continuum Framework of Lokey-Vega and Stephens (2019) as an analytical lens for classifying AI-enabled personalized learning models along the proportion of Academic Learning Time spent on automated versus student-centered pedagogies and the distribution of power and agency. Model A is "fully automated, with 100% of ALT delivered through an adaptive platform and minimal teacher or peer involvement"; Model B is a balanced hybrid; Model C is learner-driven with 80% collaborative, project-based learning. The framework served as the coding scheme for the learning-model-type moderator in the meta-analysis.
