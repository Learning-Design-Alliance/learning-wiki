# OPI-derived weighted-distance learning-curve analysis

> **Research Method** · [All research methods](index.md)

## Description
A methodological framework in which robotic-platform OPIs are binned by month, reduced with t-distributed stochastic neighbor embedding, and compared across consecutive time bins using "Euclidean distance between consecutive bins" weighted by days elapsed and case volume, then smoothed. Exponential decay fits on eigendecomposition and convex hull analyses segment the curve into novice versus expert phases. The article presents it as a "novel approach combining case complexity along with multidimension reduction and weighted Euclidean distances" to capture skill evolution over an eight-year series.
