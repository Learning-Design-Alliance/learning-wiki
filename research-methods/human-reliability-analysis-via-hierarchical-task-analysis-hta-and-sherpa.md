## Description
Human reliability analysis (HRA) is a structured approach that identifies systematically the impact of human error on a system to reduce adverse events. It combines hierarchical task analysis (HTA), the systematic decomposition of a procedure into component steps with focus on human factors, with SHERPA, which "identifies credible errors in a process and suggests methods of error mitigation at each step." HTA serves as the framework for applying SHERPA. The article applies this framework to carpal tunnel decompression to show trainees the sequential tasks, highlight error-prone steps and alert them to high-criticality steps.
