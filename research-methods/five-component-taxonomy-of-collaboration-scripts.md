# Five-component taxonomy of collaboration scripts

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article proposes that collaboration scripts can be analyzed into five components, which serve as a basis for comparing different script approaches. As printed, collaboration scripts consist of at least five components: (a) learning objectives, (b) type of activities, (c) sequencing, (d) role distribution, and (e) type of representation. These components function as an analytical taxonomy for describing and comparing prototypical script approaches.
