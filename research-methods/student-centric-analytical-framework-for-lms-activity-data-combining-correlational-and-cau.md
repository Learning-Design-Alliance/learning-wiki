# Student-centric analytical framework for LMS activity data combining correlational and causal insights

## Description
The article proposes a student-centric analytical framework for LMS activity data that models students across all their courses rather than within a single course, and that can provide "not only correlational but causal insights mined from observational data." It combines aggregate login features, chronotype clustering, predictive modeling with post hoc LIME explanation, and TETRAD-based causal discovery and inference to identify actionable factors for student-level intervention.
