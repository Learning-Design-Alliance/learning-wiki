# Coding framework of vector placement categories for observation-location responses

## Description
The article develops an empirical coding framework for where students draw arrows representing electric or magnetic fields. "Using an iterative and emergent coding process with multiple coders", the authors identified placement categories defined in Table I: 'Source' (tail of an arrow at a point charge or current), 'Asterisk' (tail at the asterisk and/or on a separate coordinate system where the asterisk is explicitly identified), 'Without Asterisk' (arrows only on a separate coordinate system without identifying the asterisk), and 'Unclear'. They apply it to responses from two quizzes to quantify placement prevalence, then code direction and magnitude only for vectors placed plausibly.
