# Gated Recurrent Unit (GRU) network

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The GRU is a recurrent neural network architecture used in the proposed model to capture temporal patterns in student engagement, quiz performance and content interaction. The article explains that "the Gate Recurrent Unit is a type of Recurrent Neural Network (RNN) that focusses on solving the gradient disappearance problem", operating with a reset gate that decides how new input combines with old memories and an update gate that controls how much previous memory is retained at each time step. Its lightweight architecture is described as enabling quicker training and lower computational cost than typical LSTM models, suiting real-time online learning applications.
