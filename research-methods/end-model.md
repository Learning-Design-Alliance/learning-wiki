# βEND model

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The βEND model assigns each course a difficulty term D and each user an engagement term EU, parameterizing a Weibull survival function in which the article states that "The weakest-link concept is formalized by the Weibull survival function." D acts as a time-to-failure threshold a user must persist beyond to earn a certificate, EU is the scale parameter, and burst size N divides certificate probability. It formally connects MOOC certificate rates to systems reliability theory.
