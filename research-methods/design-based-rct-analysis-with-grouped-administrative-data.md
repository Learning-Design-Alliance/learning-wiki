# Design-based RCT analysis with grouped administrative data

> **Research Method** · [All research methods](index.md)

## Description
The article recommends analyzing RCTs with grouped administrative data "to help improve data access," using design-based estimators formed as group-level averages. This allows evaluators to estimate average treatment effects when individual-level data cannot be obtained, provided the design conditions the article identifies are met.

- **Use grouped administrative data with design-based methods to improve data access for RCT analysis**: The article recommends analyzing RCTs with grouped administrative data "to help improve data access," using design-based estimators formed as group-level averages. This allows evaluators to estimate average treatment effects when individual-level data cannot be obtained, provided the design conditions the article identifies are met. (Peter Z. Schochet (2020))
- **Design-based estimators framework for analyzing grouped administrative data in RCTs**: The article presents a framework of "design-based estimators, derived using the building blocks of experiments" for estimating average treatment effects in randomized controlled trials when analysts have access only to grouped administrative data. The framework is "conducive to grouped data for a wide range of RCT designs, including clustered and blocked designs, and models with weights and covariates." It aims to improve data access by allowing analysis at the group level rather than the individual level. (Peter Z. Schochet (2020))
- **A unified framework of minimum aggregate-data requirements for estimating ATEs across education RCT designs**: The paper proposes a unified framework specifying which aggregate statistics suffice for unbiased ATE and standard-error estimation from administrative records. It states: "A contribution of this article is that it will use a unified framework for developing estimators, variance formulas, and approaches for significance testing that education researchers can apply using the aggregate statistics from the administrative records." Model assumptions about generalization to broader populations versus the fixed study sample are to be spelled out. (Schochet (2013))
