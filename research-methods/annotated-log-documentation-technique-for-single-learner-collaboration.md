# Annotated log documentation technique for single-learner collaboration

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The documentation of collaborations between child and computer took the shape of an annotated user log represented graphically, first developed for evaluating Ecolab I. Each line in the chart represents a type of event, with blocks annotated by letters and numbers specifying activity type, curriculum node, difficulty level and help level. From these logs the Amount of support and Depth of support provided by the system were extracted to differentiate collaborative styles into Collaboration Profile groups.
