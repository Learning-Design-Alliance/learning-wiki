## Description
Legitimation Code Theory (LCT) is an explanatory framework for analysing the basis of achievement underlying practices. Its specialisation dimension analyses epistemic relations (ER) — the value placed on specialised knowledge — and social relations (SR) — the value placed on 'ways of being' such as resilience and teamwork — yielding knowledge, knower, elite and relativist codes. The authors used it as a "grounding framework in a fully theory-informed inductive approach" with a translation device to code qualitative data and plot themes on a Specialisation Plane.
