## Description
The article proposes "a novel learning analytic method that combines three data analytic techniques, including a cluster analysis, a process mining technique, and an epistemic network analysis". Clustering detects learning tactics within sessions using the EM algorithm; process mining examines tactic usage across sessions; ENA visualises and statistically analyses connections between tactics and learning-design units for each performance group. The combination is offered as a new methodological approach for studying links between learning design and learning tactics.
