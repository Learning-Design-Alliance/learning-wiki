# Five critical components framework for classroom-administered values-affirmation implementation fidelity

> **Research Method** · [All research methods](index.md)

## Description
The article proposes a critical components approach to specifying an ideal classroom-administered values-affirmation intervention against which real-world implementation can be compared. Through study of prior work it identifies "intervention design (the intervention is tailored to fit the students' capabilities and needs), teacher-centered delivery, stealth, timing, and student engagement" as the critical components that could moderate intervention success. The framework maps Cohen et al.'s protocols and the authors' own onto indicators including timing, dosage, and participant responsiveness, generating student- and teacher-centered fidelity indices intended to help measure fidelity in other studies.
