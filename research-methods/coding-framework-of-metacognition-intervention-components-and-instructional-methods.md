# Coding framework of metacognition intervention components and instructional methods

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article develops a fine-grained coding framework for metacognition interventions, distinguishing intervention focus (primary vs. secondary focus on metacognition), four metacognition components, and six instructional methods. Components are defined temporally: "Before starting a task, children are encouraged to think about how they could approach a task or set goals for themselves" (planning), monitoring during tasks, control during tasks, and reflection after tasks. Instructional methods include informed instruction, modelling, prompts, practice, feedback, and peer activities. This framework enabled the first meta-analytic tests of which components and methods drive effectiveness.
