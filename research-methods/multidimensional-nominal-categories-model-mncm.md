## Description
The Multidimensional Nominal Categories Model (MNCM) is an item-response model in which response probabilities for each answer choice depend linearly on student traits via per-choice slope parameters. Its distinguishing feature is that "it treats multidimensionality as a property of the individual answer options", so different distractors within one question can point in different directions in the knowledge space. The authors' hierarchical Bayesian implementation (MNCM-Bayes) with variational inference makes fitting tractable on large datasets and exhibits self-selecting dimensionality.
