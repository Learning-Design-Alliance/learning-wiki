# Four-dimension framework for analyzing tutoring system evolution: AI, system behavior, engagement, and affordances

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The review introduces a generational analysis framework structured around "four dimensions: Artificial Intelligence, system behavior, engagement, and affordances." AI covers the algorithms enabling personalized adaptive learning (from concept trees and student models to BKT and LLMs); system behavior covers adaptability of instructional strategies to student inputs; engagement covers features maintaining active involvement; affordances cover physical and interactive features such as robotic gestures and virtual environments. Representative papers from each generation were selected and analyzed through this lens to trace technological and pedagogical evolution.
