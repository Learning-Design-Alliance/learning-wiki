# Population-first versus individual-first measurement framework

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
The article articulates an epistemic framework contrasting two measurement traditions. In the psychoeducational tradition, individual students' minds are 'upstream from all other patterns we observe', with population inferences extrapolated from reliable individual scores. Large-scale assessments reverse this: 'modeling population distributions as conditioned on student background variables first and then generating student test scores'. The framework organizes the paper's comparison of what each data type can validly support.
