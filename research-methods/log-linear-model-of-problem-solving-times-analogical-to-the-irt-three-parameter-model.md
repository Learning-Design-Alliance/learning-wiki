# Log-linear model of problem solving times analogical to the IRT three-parameter model

> **Research Method** · [All research methods](index.md)
> **Evidence** · no claims cited

## Description
A generative student model for interactive problem solving that specifies the distribution of problem solving times rather than correctness probability. It assumes, in the article's words, "a linear relationship between a problem solving skill and a logarithm of time to solve a problem": tsp = bp + apθs + N(0, cp²), where b is basic difficulty, a a discrimination factor, and c a randomness factor. The notation is deliberately chosen to mirror the IRT three-parameter logistic model, and the model is also related to k=1 collaborative filtering. It supports prediction of solving times and estimation of problem and student parameters.
