# Individual-curve analysis for testing cognitive skill-acquisition mechanisms

## Description
The article argues that because power functions can fit aggregated learning curves almost perfectly even when every underlying individual curve is discontinuous, a good aggregate power-function fit provides no evidence that individual learning is continuous or that any particular learning mechanism operates. The authors recommend against treating the power law of practice as a benchmark: "using the power-function fit as a benchmark test for the validity of models of cognitive skill acquisition is severely misguided, might well conceal important empirical findings". Whether good fits occur depends on how quickly a new strategy is generated and how consistently it is applied.
