# Integrated psychometric evaluation framework combining measurement invariance testing and item response theory

## Description
The article advocates a dual analytical framework for evaluating communication-skill instruments in performance-based assessment: multi-group confirmatory factor analysis to test whether a scale measures the same latent construct across stations (configural, metric, scalar and strict invariance), and IRT to assess each item's difficulty and discrimination and to reveal where along the trait spectrum items provide information. The authors state that "IRT can prove to be very useful for the continuous evaluation of CS measurement instruments in performance-based assessments" and that the joint use of these techniques provides knowledge to improve instrument adoption. The framework treats instrument evaluation as continuous rather than one-off validation.
