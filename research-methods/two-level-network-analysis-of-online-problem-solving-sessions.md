# Two-level network analysis of online problem-solving sessions

## Description
The article introduces a general methodology for mining server logs of online problem solving. At the first level, time-ordered actions tied by session-id become session networks whose nodes are unique action combinations and whose links carry inter-action time. At the second level, "At one level, we create action networks that depict student online behaviors. At another level we create a network of similar action networks", using rotated PCA scores, LANS sparsification, and fuzzy Infomap to find overlapping clusters. The method requires only that student actions form a meaningful ordered sequence.
